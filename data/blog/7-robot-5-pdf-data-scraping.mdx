# 출력 시트에 데이터를 추가하는 방법 결정 ( Deciding How to Add Data Into Output Sheet )

```python
이번에는 엑셀 액티비티 같은 화려한 엑셀 작업은 필요 없다

대신 워크북 액티비티를 사용해서 진행한다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380853/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_7_Robot_5_PDF_Data_Scraping/Untitled_25.png)

```python
Write Cell: 개별 셀에 데이터를 추가하고 문자열을 입력

Write Range: 데이터 테이블을 입력으로 받아 왼쪽 위 셀부터 데이터를 씀

Append Range: 데이터 테이블을 입력으로 받아 시트에서 사용 가능한 첫 번째 빈 행에 데이터를 추가
```

```python
권장 옵션: Append Range

Append Range는 엑셀 워크시트에 데이터를 추가할 때 가장 효율적인 옵션

다음과 같은 이유로 Append Range가 Write Cell이나 Write Range보다 좋은 선택임:

**활동 수 감소 ( 손이 덜감 )**

Append Range는 데이터 테이블 형태로 한 번에 여러 셀의 데이터를 입력할 수 있음

Write Cell은 개별 셀마다 활동이 필요하므로 활동 수가 많아짐

활동 수가 적으면 전체 프로세스 속도가 향상됨

**데이터 재정의 불필요**

Write Range는 지정한 왼쪽 상단 셀부터 데이터를 씀

기존 데이터가 있는 셀에 새 데이터를 덮어쓰게 됨

Append Range는 비어있는 새 행에만 데이터를 추가하므로 재정의 없음

**트랜잭션 데이터 추가에 적합**

이 사례에서는 각 트랜잭션마다 새로운 행에 데이터를 추가해야 함

Append Range는 이러한 용도에 가장 적합한 옵션임

따라서 간편성, 속도, 데이터 보존 측면에서 Append Range가 엑셀 데이터 출력을 위한 최적의 방식임

간단히 말해, Append Range는 활동 수가 적고 기존 데이터를 훼손하지 않으며, 지속적인 행 추가에 적합하므로 권장되는 옵션
```
