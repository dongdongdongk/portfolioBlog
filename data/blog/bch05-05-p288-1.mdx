```java
// 게시물 조회,수정
    @GetMapping({"/read","/modify"})
    public void read(@ModelAttribute("requestDTO") PageRequestDTO pageRequestDTO, Long bno, Model model) {

        log.info("bno: " + bno);

        BoardDTO boardDTO = boardService.get(bno);

        log.info("{}", boardDTO);

        model.addAttribute("dto", boardDTO);

    }

    // 게시물 삭제
    @PostMapping("/remove")
    public String remove(Long bno, RedirectAttributes redirectAttributes){

        log.info("bno: " + bno);

        boardService.removeWithReplies(bno);

        redirectAttributes.addFlashAttribute("msg", bno);

        return "redirect:/board/list";

    }
```

```java
게시물 수정페이지 이동은 read 와 받는 파라미터가 같기 때문에 주소를 {} 이렇게 받아서 한번에 해결하도록 한다
```

### **addAttribute, addFlashAttribute**

```java
**addAttribute**는 URL에 붙어서 값이 전달되어 유지가 되지만

**addFlashAttribute**는 일회성으로 URL에 붙지 않고 한 번의 리다이렉션 요청 후에는 값이 사라진다.

이는 일시적인 데이터를 한 페이지에서 다음 페이지로 전달하는 데 유용

* 여기서 사용하는 이유는 read 로 갔다가 다시 list 로 이동하려면 URL 에서 값이 유지되어야 하기 때문이다
```
