- 인터페이스란 객체의 사용 방법을 정의한 타입이다.
- 인터페이스를 통해 다양한 객체를 동일한 사용 방법으로 이용할 수 있다. (동일한 인터페이스로 다양한 객체를 사용할 수 있다.).
- 인터페이스 또한 다형성을 구현할 수 있다.(실제로 인터페이스를 이용한 다형성이 더 많다.)
- 인터페이스 뒷편에 어떤 객체가 있느냐에 따라서 다른 m1 메소드(ex) 가 실행될수 있다.(다형성)

## 인터페이스(interface)

- 인터페이스는 개발 코드와 객체 사이에서 서로 통신하는 것을 도와주는 역할을 한다.
- 인터페이스의 메소드 에는 내용이 없지만 개발 코드에서 인터페이스 메소드 호출시 뒷쪽 객체의 메소드가 호출이 된다.
- 개발 코드를 수정하지 않으면서 객체 교환이 가능하다
  개발 코드가 인터페이스 만을 보고 개발을 한다면 인터페이스 뒷쪽의 객체만 쉽게 수정하여 다른 기능으로 대체 가능

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381030/notion-blog/_/JAVA/_/46_/Untitled_1.png)

- .java 형태의 소스 파일로 작성 컴파일을 통해 class 형태로 컴파일 된다.
- 클래스와 물리적 파일 형태는 같으나 소스 작성 내용이 다르다.

```java
문법 : [public] interface 인터페이스 이름 { 내용 }
```

```java
//인터페이스는 객체로 생성할 수 없으므로 생성자를 가질 수 없다.

interface 인터페이스이름 {

	//상수
	타입 상수이름 = 값;    // interface 는 static final 을 붙이지 않아도 자동으로 상수가 된다.

	//추상 메소드
	타입 메소드이름(매개변수,...); // 이 역시 interface 에서는 abstract 를 생략 가능하다.
}
```

## 상수 필드

- 데이터를 저장할 인스턴스 혹은 정적 필드 선언 불가
- 상수 필드만 선언 가능

```java
[public static final] 타입 상수이름 = 값;
```

- 상수 이름은 대문자로 작성하되 서로 다른 단어로 구성되어 있을 경우 \_ 언더바 사용

```java
public interface RemoteControl {
	public int MAX_VOLUME = 10; // 상수니까 값을 바로 입력 해주어야함
	public int MIN_VOLUME = 0;
}
```

## 추상 메소드 선언

- 인터페이스를 통해 호출된 메소드는 최종적으로 객체(인터페이스를 재정의 한)에서 실행된다.
- 최종적으로 객체에서 실행되기 때문에 인터페이스는 실행 블록이 필요가 없다.

```java
문법 : [public abstract] 리턴타입 메소드이름(매개변수,...);  //추상 메소드고 {} 가 없다.
```

```java

	public void trunOn();
	public void turnOff();
	public void setVolume(int volume);
}
```

## 구현 클래스

- 인터페이스에서 정의된 추상 메소드를 재정의 해서 실행 내용을 가지고 있는 클래스
- 클래스 선언부에 implements 키워드를 추가하고 인터페이스 이름을 적어준다.

```java
public class 구현클래스 이름 implements 인터페이스이름 {

// 인터페이스에 선언된 추상 메소드의 실체 메소드 선언

}
```

```java
// 이렇게 RmoteControl 을 인터페이스로 사용할시 Television 은 사용 인터페이스의 추상 메소드를
```
