### 4. DB 생성

- Oracle DB

  ```jsx
  1. RDS 대시보드에서 Database 생성 클릭
  2. 표준 생성 선택
  3. 엔진옵션 - 사용할 DB 선택
  		- oracle
  		- 12버전 선택
  4. 템플릿
  		- 프리티어 선택

  5. DB 인스턴스 식별자
  		- 중복 X
  		- dk-oracle
  6. 마스터 사용자 이름
  		- 로그인 ID
  		- admin

  7. 암호 입력
  		- oracle1234

  8. 할당된 스토리지
  		- 20G

  9. 스토리지 자동 조정 활성화 체크 해제
  		- 돈이 나갈 수 있음

  10. 퍼블릭 액세스를 '예' 로 체크

  11. 데이터베이스 인증 - 암호인증

  12. 추가 구성
  	a) 초기데이터베이스 이름- orcl
  	b) 문자집합 - UTF-8

  13. 자동백업을 활성화 체크 해제

  14. 암호화 활성화 체크 해제

  15. 성능 개선 도우미 체크 해제

  16. 삭제 방지 활성화 체크 해제

  ```
