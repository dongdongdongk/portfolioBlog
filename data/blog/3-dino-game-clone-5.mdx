```jsx
구름은 게임 화면에서 단순한 이미지 객체로 구현됩니다.

구름은 화면의 오른쪽에서 왼쪽으로 일정한 속도로 움직이고,

화면을 벗어나면 다시 오른쪽 끝에서 나타나도록 설정됩니다.

이 작업은 **구름 그룹(group)**을 만들고, 재활용(recycling) 로직을 추가하여 구현합니다.
```

# { 점수 증가 로직 추가 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380501/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_3_Dino_Game_Clone_-_5_-/image_2.png)

```jsx
이 강의에서는 **점수 시스템(score system)**을 구현하는 방법을 다룹니다.

점수를 증가시키고

게임 화면에 표시하기 위해 필요한 변수와 로직을 추가하는 과정을 설명합니다.
```

## 1. 점수와 관련된 변수 만들기

```jsx
우선, 점수를 관리하기 위한 변수를 선언합니다. 여기에 사용된 변수는 다음과 같습니다:

1. score: 현재 점수를 저장하는 변수입니다. 초기값은 0으로 설정합니다.

2. scoreInterval: 점수를 증가시키는 간격(시간)을 설정하는 변수입니다.

									예를 들어, 100 밀리초마다 점수가 1씩 증가하도록 설정합니다.

3. scoreDeltaTime: 점수 증가 간격을 계산하는 데 사용되는 변수입니다.

									 시간 누적 값을 저장합니다. 초기값은 0입니다.
```

```jsx
score: number = 0 // 현재 점수
scoreInterval: number = 100 // 점수 증가 간격 (100ms)
scoreDeltaTime: number = 0 // 시간 누적 값
```

## 2. 점수를 증가시키는 로직 추가

```jsx
게임 화면을 계속 업데이트하는 update 함수에서 점수를 증가시키는 로직을 추가합니다.

이 함수는 매 프레임마다 호출되므로, 점수 증가 간격을 계산할 수 있습니다.
```

### **1. 시간 누적**: `scoreDeltaTime`에 경과 시간(`delta`)을 더합니다.

```jsx
this.scoreDeltaTime += delta
```

### **2. 점수 증가 조건 확인**: `scoreDeltaTime`이 `scoreInterval`보다 크거나 같다면 점수를 1 증가시킵니다.

```jsx
if (this.scoreDeltaTime >= this.scoreInterval) {
  this.score++ // 점수 증가
  this.scoreDeltaTime = 0 // 누적 시간 초기화
}
```

### **3. 테스트 출력**: 점수가 제대로 증가하는지 확인하기 위해 `console.log`로 점수를 출력합니다.

```jsx
console.log(this.score)
```

### 3. 게임 오버 시 점수 초기화

```jsx
게임이 종료될 때 점수 관련 변수들을 초기화해야 합니다.

점수가 계속 증가하지 않도록 handleObstacleCollisions 함수에 다음 로직을 추가합니다:
```

```jsx
this.score = 0 // 점수 초기화
this.scoreDeltaTime = 0 // 누적 시간 초기화
```

### 4. 점수 증가 테스트

```jsx
1. 게임을 실행하고, 점수가 100 밀리초마다 1씩 증가하는지 확인합니다.

2. 게임이 종료된 후 점수가 초기화되는지 테스트합니다.

3. scoreInterval 값을 줄이면 점수가 더 빨리 증가하는 것을 볼 수 있습니다
```

```jsx
this.scoreInterval = 50 // 점수 증가 간격을 50ms로 변경
```

# { **"델타(delta)"**라는 개념 }

## 1. 델타(delta)란?

```jsx
게임에서는 화면이 초당 여러 번(예: 60FPS에서 60번) 업데이트됩니다.

이때, 각 업데이트 사이에 얼마나 시간이 흘렀는지를 "델타(delta)"라고 합니다.

"델타"는 두 업데이트 사이의 시간 차이입니다.

보통 밀리초(milliseconds) 단위(1초 = 1000ms)로 계산됩니다
```

## 2. 델타는 왜 필요한가?

```jsx
게임은 플레이어의 컴퓨터 성능에 따라 **프레임 속도(FPS)**가 달라질 수 있습니다.

예를 들어:

성능이 좋은 PC: 1초에 120프레임 → 프레임마다 걸리는 시간은 8.3ms 정도.

성능이 낮은 PC: 1초에 30프레임 → 프레임마다 걸리는 시간은 33.3ms 정도.

델타를 사용하면 FPS가 달라도 게임이 동일한 속도로 작동하도록 보장할 수 있습니다.
```

## 3. 델타와 타임의 차이

```jsx
타임(time): 게임이 시작된 이후 누적된 총 시간입니다.

		예) 게임이 시작한 지 5초가 지났다면, time = 5000ms.

델타(delta): 이전 프레임과 현재 프레임 사이에 흐른 시간입니다.

		예) 이전 프레임에서 현재 프레임까지 걸린 시간이 16ms라면, delta = 16ms.

비유로 이해하기:

		타임(time): 지금까지 살아온 나이(총 시간).

		델타(delta): 어제와 오늘 나이의 차이(시간 차이).
```

## 4. 델타가 사용되는 예

```jsx
델타를 활용하면 게임이 매끄럽게 작동하도록 만들 수 있습니다.

예제: 캐릭터 이동

		캐릭터가 초당 100픽셀 이동한다고 가정합니다.

		FPS가 다르면 델타를 사용해 다음과 같이 계산합니다:
```

```jsx
const speed = 100 // 초당 이동 속도
const distance = speed * (delta / 1000) // delta를 초 단위로 변환
character.x += distance // 캐릭터 이동
```

```jsx
FPS가 다르더라도:

60FPS → delta = 약 16ms → 100 × (16 / 1000) ≈ 1.6픽셀 이동.

30FPS → delta = 약 33ms → 100 × (33 / 1000) ≈ 3.3픽셀 이동.

이렇게 하면 어떤 컴퓨터에서도 일정한 속도로 이동하게 됩니다.
```

## 한 줄 요약

```jsx
**델타(delta)**는 프레임 간 시간 차이를 의미하며, FPS가 달라도 게임이 일정하게 작동하도록 도와줍니다.

"전체 시간(time)"은 누적 시간이고, 델타는 "짧은 순간의 변화량"이라고 이해하면 됩니다!
```

## 1. 점수 증가 로직 ( 복습 )

```jsx
update(time: number, delta: number): void {
    this.scoreDeltaTime += delta;

    if (this.scoreDeltaTime >= this.scoreInterval) {
        this.score++; // 점수 증가
        this.scoreDeltaTime = 0; // 누적 시간 초기화
    }
}
```

```jsx
delta는 이전 프레임과 현재 프레임 사이의 시간 차이(밀리초)입니다.

this.scoreDeltaTime에 delta 값을 누적합니다.

this.scoreInterval(100ms)을 초과하면 score를 1 증가시키고, scoreDeltaTime을 0으로 초기화합니다.
```

## 2. 점수를 5자리 숫자로 변환하는 과정

```jsx
const score = Array.from(String(this.score), Number)

for (let i = 0; i < 5 - String(this.score).length; i++) {
  score.unshift(0)
}

this.scoreText.setText(score.join(''))
```

```jsx
1. String(this.score) → 점수를 문자열로 변환합니다.

2. Array.from(..., Number) → 문자열을 숫자로 이루어진 배열로 변환합니다.

		예) score = 15이면

		String(15) // "15"
		Array.from("15", Number) // [1, 5]



3. for (let i = 0; i < 5 - String(this.score).length; i++) {
    score.unshift(0);
	 }

	 5 - String(this.score).length 만큼 0을 앞에 추가합니다.

	 score = 15이면

	 String(15).length // 2
	 5 - 2 = 3

	 → [0, 0, 0, 1, 5]가 됩니다.



4. score.join("")을 사용하여 문자열로 변환하고 setText를 호출하여 점수를 업데이트합니다.

	 최종적으로 "00015"가 표시됩니다.
```

# { 게임 속도 증가 }

## 1. 게임 속도 (`gameSpeed`) 개념

```jsx
현재 게임에서는 gameSpeed 값을 사용하여 장애물과 배경이 이동하는 속도를 제어하고 있습니다.

기본적으로 gameSpeed = 10으로 설정되어 있으며, 이 값이 높아질수록 장애물이 더 빠르게 이동합니다.
```

## 2. 게임 속도 증가 (`gameSpeedModifier`) 개념

```jsx
1. gameSpeedModifier는 기본적으로 1로 설정됩니다.

2. 게임이 진행되면서 점수가 증가할 때,

gameSpeedModifier를 증가시키면 전체적인 게임 속도가 빨라집니다.

3. gameSpeedModifier를 2로 설정하면

gameSpeed * gameSpeedModifier = 10 * 2 = 20이 되어 장애물이 두 배 빠르게 움직입니다.
```

## 3. 코드 적용 방법


# { 게임 속도 증가 로직 }

## 1. 게임 속도 조절의 개념

```jsx
게임 속도를 조절하기 위해 게임 속도 수정자(gameSpeedModifier) 변수를 사용합니다.

		기존 값: 2 → 이를 1로 변경하여 기본 속도로 시작

		점수가 일정 단위(100점) 증가할 때마다 gameSpeedModifier 값을 증가시켜 게임 속도를 점진적으로 증가

💡 게임 진행에 따른 속도 증가 방식

		점수가 100점이 될 때 gameSpeedModifier = 2

		200점이 되면 gameSpeedModifier = 3

		300점이 되면 gameSpeedModifier = 4

		→ 이렇게 증가하는 방식은 속도가 급격하게 변할 수 있음

👉 그래서, 속도 증가 폭을 조절하여 부드러운 변화를 주는 것이 필요

		예를 들어,

		매 100점마다 gameSpeedModifier += 0.1

		또는 매 500점마다 gameSpeedModifier += 1
```

## 2. 게임 속도 증가 로직 구현

### 1️⃣ **`update` 함수에서 점수 증가 시점에 속도 조절 로직 추가**

```jsx
update(time: number, delta: number): void {
    this.scoreDeltaTime += delta;

    if (this.scoreDeltaTime >= this.scoreInterval) {
        this.score++; // 점수 증가
        this.scoreDeltaTime = 0; // 누적 시간 초기화

        if (this.score % 100 === 0) { // 100점 단위로 속도 증가
            this.gameSpeedModifier += 0.1; // 점진적으로 증가
        }
    }
}
```

```jsx
this.score가 100의 배수일 때 (this.score % 100 === 0) gameSpeedModifier를 증가
```

## 3. 속도가 증가할 때 게임 오브젝트의 움직임 적용

```jsx
속도 증가에 따라 장애물과 배경이 더 빠르게 이동해야 합니다.

아래 코드에서 gameSpeedModifier가 적용됨
```

```jsx
Phaser.Actions.IncX(this.obstacles.getChildren(), -this.gameSpeed * this.gameSpeedModifier)
Phaser.Actions.IncX(this.clouds.getChildren(), -0.5)
this.ground.tilePositionX += this.gameSpeed * this.gameSpeedModifier
```

```jsx
장애물(obstacles)과 땅(ground)의 이동 속도를 gameSpeedModifier와 곱하여 증가

구름(clouds)은 상대적으로 천천히 이동하므로 속도 증가 영향이 적음 ( 적용 x )
```

## 4. 게임 오버 시 속도 초기화

```jsx
게임 오버가 되면 속도를 다시 기본값(1)으로 되돌려야 합니다.
```

```jsx

    this.physics.add.collider(this.obstacles, this.player, () => {
        this.isGameRunning = false;
        this.physics.pause();
        this.anims.pauseAll();

        this.player.die();
        this.gameOverContainer.setAlpha(1);

        this.spawnTime = 0;
        this.gameSpeed = 10;

        this.score = 0; // 점수 초기화
        this.scoreDeltaTime = 0; // 누적 시간 초기화
        this.gameSpeedModifier = 1; // 속도 증가량 초기화
    });
}
```

```jsx

```

# { 점수 100마다 점멸 효과 적용하기 }

```jsx
이번 강의에서는 점수가 100 단위로 증가할 때

**점수 텍스트(scoreText)**에 깜빡이는 효과를 추가하는 방법을 배웁니다.
```

```jsx
if (this.scoreDeltaTime >= this.scoreInterval) {
  // 일정 시간(scoreInterval)이 지나면 점수를 증가시킴
  this.score++ // 점수 증가
  this.scoreDeltaTime = 0 // 누적된 시간 초기화 (다음 점수 증가를 위한 준비)

  if (this.score % 100 === 0) {
    // 점수가 100의 배수일 때 실행
    this.gameSpeedModifier += 0.2 // 게임 속도를 점진적으로 증가시킴

    // 점수 텍스트에 깜빡이는 효과 추가
    this.tweens.add({
      targets: this.scoreText, // 효과를 적용할 대상 (점수 텍스트)
      duration: 100, // 깜빡이는 지속 시간 (100ms)
      repeat: 3, // 총 3번 깜빡임
      alpha: 0, // 투명도를 0으로 설정 (텍스트가 사라짐)
      yoyo: true, // 다시 원래 상태로 돌아오도록 설정 (깜빡이는 효과)
    })
  }
}
```

## 구현 과정

```jsx
1. this.scoreDeltaTime >= this.scoreInterval

		일정 시간(scoreInterval)이 지나면 점수를 증가시킴

		scoreDeltaTime은 점수 증가 간격을 조절하는 역할

2. this.score++

		점수를 1 증가시킴

3. this.scoreDeltaTime = 0

		점수 증가 후, 누적 시간을 초기화하여 다시 계산 시작

4. if (this.score % 100 === 0)

		점수가 100, 200, 300...과 같이 100의 배수일 때 실행

5. this.gameSpeedModifier += 0.2

		게임 속도를 점진적으로 증가시켜 난이도를 올림

6. this.tweens.add({...})

		점수 텍스트(scoreText)에 깜빡이는 효과 추가

		duration: 100 → 한 번 깜빡이는 시간 100ms

		repeat: 3 → 총 3번 깜빡임

		alpha: 0 → 투명도를 0으로 설정 (텍스트 사라짐)

		yoyo: true → 깜빡였다가 다시 원래 상태로 돌아오도록 설정
```

```jsx
export class Player extends Phaser.Physics.Arcade.Sprite {
    jumpSound: Phaser.Sound.HTML5AudioSound;

    constructor(scene: GameScene, x: number, y: number) {
        super(scene, x, y, "dino-run");

        scene.add.existing(this);
        scene.physics.add.existing(this);

        this.init();

        this.scene.events.on(Phaser.Scenes.Events.UPDATE, this.update, this);
    }

    init() {
        this.jumpSound = this.scene.sound.add("jump", { volume: 0.5 }) as Phaser.Sound.HTML5AudioSound;
    }

    update() {
        const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(this.scene.input.keyboard.createCursorKeys().space);
        const onFloor = (this.body as Phaser.Physics.Arcade.Body).onFloor();

        if (isSpaceJustDown && onFloor) {
            this.setVelocityY(-1600);
            this.jumpSound.play();
        }
    }
}
```
