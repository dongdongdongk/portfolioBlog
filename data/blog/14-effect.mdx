## 1. Effect 개념 이해하기

### 🎧 Effect란?

- 사운드에 **공간감, 질감, 잔향, 지연 등**을 더해주는 **오디오 처리 도구**.
- 일반적으로 **게임 엔진의 오디오 시스템(Wwise, Unity Audio 등)** 안에서 사용됨.
- **목적:** 현실감과 몰입감 향상.

### 💡 주요 Effect 종류

| Effect                | 설명                                           | 사용 예시                  |
| --------------------- | ---------------------------------------------- | -------------------------- |
| **Delay**             | 입력 신호를 일정 시간 지연시켜 반복적으로 재생 | 메아리, 잔향 길이 확장     |
| **Reverb(RoomVerb)**  | 공간 반사의 잔향을 시뮬레이션                  | 동굴, 복도, 실내 소리 표현 |
| **Dynamic Processor** | 음량의 다이내믹 범위 조절 (압축기/리미터 등)   | 폭발음이나 배경음 조정     |
| **EQ (Equalizer)**    | 특정 주파수 대역 강조/감쇠                     | 저음 강조, 고음 제거 등    |

## 2. Delay Effect로 사운드 길이 늘리기

### 🔊 상황

- 텔레포터 사운드는 **짧은 효과음**이라 순간적으로 들림.
- 하지만 텔레포트 후에도 **여운(Echo)** 이 남아있으면 더 “마법적인 느낌”을 줄 수 있음.

### ⚙️ Delay Effect 설정

- **Delay(지연)** 는 원본 사운드를 일정 시간 뒤에 반복 재생함.
- **지속적인 반사음**을 만들어 **사운드 길이를 늘리는 효과**를 냄.

### 🔍 주요 속성

| 옵션                       | 설명                                | 추천값(예시) |
| -------------------------- | ----------------------------------- | ------------ |
| **Delay Time (지연 시간)** | 원본과 지연된 소리의 간격 (ms 단위) | 200~400ms    |
| **Feedback (피드백)**      | 지연 신호를 다시 입력으로 넣는 비율 | 30~60%       |
| **Mix (드라이/웻 비율)**   | 원본과 이펙트 소리의 혼합 비율      | Wet 50% 정도 |

💬 즉, 텔레포터 사운드가 끝난 후에도 공간감 있는 “딜레이 잔향”이 남게 됨.

---

## 3. RoomVerb Effect로 리버브 추가하기

### 🎶 목적

- Cube 게임의 **좁은 복도 공간감**을 표현하기 위해 **RoomVerb(리버브)** 사용.
- 리버브는 소리가 벽이나 천장에 반사되어 귀에 도달하는 **잔향 효과**를 시뮬레이션함.

### 🎛 주요 속성

| 속성                        | 설명                           | 예시               |
| --------------------------- | ------------------------------ | ------------------ |
| **Room Size (방 크기)**     | 공간의 크기 시뮬레이션         | 좁은 복도 → 20~40% |
| **Reverb Time (감쇠 시간)** | 잔향이 사라지는 데 걸리는 시간 | 0.5~1.5초          |
| **Damping (감쇠율)**        | 고음 반사의 감소 정도          | 중간값(0.5)        |
| **Mix Level (믹스 비율)**   | 원본 + 리버브 신호의 혼합 정도 | Wet 40~60%         |

💡 **결과:**

좁은 복도 안에서 텔레포터 소리가 “공간에 울리는 듯한 현실감”을 줌.

## 4. Effect 삽입하기

### 🎛 삽입 개념

- 특정 **사운드 오브젝트(Sound Object)** 또는 **버스(Bus)** 에 직접 이펙트를 추가함.
- 삽입 위치에 따라 적용 범위가 달라짐.

### 적용 예시

1. **개별 사운드에 직접 삽입**

   → 특정 사운드에만 효과 적용 (예: 텔레포터 효과음에만 Delay 추가)

2. **버스에 삽입 (상위 계층)**

   → 그 버스를 사용하는 모든 사운드에 동일한 효과 적용 (예: 전체 배경 사운드에 리버브)

---

## 5. 상위 계층 Effect 덮어쓰기

### 🧩 개념

- 하위 사운드 오브젝트는 기본적으로 **상위 버스의 이펙트 설정을 상속**함.
- 하지만 **필요에 따라 개별 사운드가 상위 설정을 덮어쓸 수 있음**.

### 예시

- 상위 버스: RoomVerb(리버브) 적용
- 하위 사운드: Delay만 적용하고 싶음 → 상위의 리버브를 덮어쓰기 설정
  → 해당 사운드에는 리버브 대신 Delay만 들림.

💡 이렇게 하면 **특정 사운드만 별도로 처리** 가능.

---

## 6. 보조 버스 만들기 (Auxiliary Bus)

### 🪄 개념

- 여러 사운드가 **공통으로 사용할 Effect**를 묶어두는 별도의 오디오 경로.
- 예: “모든 캐릭터 사운드가 공유하는 리버브 공간”

### 생성 순서

1. 오디오 엔진에서 **Auxiliary Bus 생성**
2. 이름 예시: `Reverb_Corridor`
3. 해당 버스에 **RoomVerb Effect** 삽입
4. Bus Output → Master Audio Bus 로 연결

### 장점

- **효율적 처리:** 여러 사운드가 같은 리버브를 공유하므로 CPU 사용 절약
- **일관된 공간감:** 동일한 공간 내 사운드들이 자연스럽게 섞임

---

## 7. 보조 센드 설정하기 (Aux Send)

### 🎚 개념

- 각 사운드가 자신 신호의 일부를 **보조 버스로 “보낸다(Send)”** 설정.
- 즉, 원본 소리는 그대로 두고, 복제된 신호만 리버브나 딜레이에 보냄.

### 예시

- 텔레포터 사운드 → `Reverb_Corridor` 버스로 Send
  → 일부 소리만 리버브 처리되어 “공간에 울리는” 효과.

### 설정 항목

| 옵션               | 설명                                |
| ------------------ | ----------------------------------- |
| **Send Level**     | 보낼 신호의 양 (리버브의 강도 조절) |
| **Target Aux Bus** | 연결할 보조 버스 선택               |
| **Enable Bypass**  | 특정 조건에서 이펙트 비활성화 가능  |

💡 이렇게 하면 한 사운드가 여러 공간에 “부분적으로 섞이는” 복합적인 효과를 낼 수 있음.

## 1. 사운드 이펙트 개념 이해하기

- **Effect(이펙트)** : 사운드에 **딜레이, 리버브, 에코, 디스토션** 같은 효과를 추가하여 청각적 느낌을 변화시키는 기능.
- 이펙트를 활용하면 같은 소스 사운드라도 전혀 다른 분위기를 낼 수 있음.
  - 예: **텔레포트 소리** → 에코(잔향)를 주면 공간감이 커짐.
- Wwise에서는 각 **사운드 오브젝트(Sound Object)** 또는 **Actor-Mixer** 단위로 이펙트를 설정 가능.

---

## 2. Cube 실행 및 연결

1. **Cube 실행하기**
   - Cube는 게임 오디오 테스트용 샘플 게임.
   - 실시간으로 Wwise 프로젝트와 연결해 변경 사항을 바로 들어볼 수 있다.
2. **Wwise 프로젝트 열기**
   - `Module 14` 프로젝트 파일을 엶.
   - 이 프로젝트에는 Teleport 사운드와 관련 리소스가 포함되어 있다.
3. **Cube와 연결하기**
   - Wwise 상단의 **Remote Connection** 기능을 사용해 Cube와 연결.
   - 연결 후에는 Wwise에서 변경한 이펙트를 게임 내에서 실시간 테스트할 수 있다.

---

## 3. Teleport 사운드 선택하기

1. **Project Explorer → Actor-Mixer Hierarchy** 경로로 이동.
2. **Items Actor-Mixer** 폴더를 확장한 뒤

   `Teleport` 오브젝트를 선택한다.

3. **Transport Control (재생 제어기)** 에서 ▶ **Play 버튼** 또는 **Spacebar(스페이스바)** 를 눌러

   **원본 Teleport 사운드**를 재생해본다.

---

## 4. Effect 탭에서 상위 설정 무시하기

- Wwise의 모든 오브젝트는 **상위 계층(Parent)** 의 이펙트 설정을 **상속**받는다.
- Teleport에 **독립적인 이펙트**를 적용하려면
  먼저 상속을 끊어야 한다.

**설정 방법:**

1. 기본 편집기에서 **Effects 탭** 선택.
2. **Override parent (상위 설정 무시)** 체크박스를 선택.

   → 이제 Teleport 오브젝트에 직접 이펙트를 설정할 수 있다.

## 6. Preset 비교 및 청음 테스트

- Spacebar를 눌러 **Effect가 적용된 Teleport 사운드**를 들어본다.
- 그런 다음 **Next** 버튼을 눌러 다음 Preset으로 이동하며 여러 가지를 들어본다.
- `Delay\One_Tap_Quarter_Second` Preset까지 순서대로 비교 청음한다.

**결과 분석:**

- 선택한 Preset이 원래 의도한 사운드에 가깝지만,
  **Echo(에코)** 가 너무 길게 지속됨.
- 따라서 효과의 세기를 조정해야 한다.

---

## 7. Effect 속성(Feedback) 조정하기

- **보조 편집기(Auxiliary Editor)** 를 열면 Delay 플러그인의 세부 매개변수를 조정할 수 있다.
- 여기서 **Feedback** 값을 **25**로 설정한다.

> Feedback : 출력된 신호가 다시 입력으로 되돌아가는 비율.
>
> 값이 높을수록 에코가 길게 이어지며, 낮을수록 짧아진다.

- 값을 조정한 뒤 **Spacebar**를 눌러 사운드를 다시 들어보며 차이를 확인한다.

## 8. Wet/Dry Mix 개념 이해하기

- 대부분의 이펙트에는 **Wet/Dry Mix** 매개변수가 존재한다.

| 비율                 | 의미                                           |
| -------------------- | ---------------------------------------------- |
| **0% (Dry)**         | 이펙트가 전혀 적용되지 않고 원본 소리만 재생됨 |
| **100% (Wet)**       | 원본 소리는 제거되고 이펙트만 들림             |
| **중간값 (예: 50%)** | 원본 사운드와 이펙트가 섞여 들림               |

- **Tip:**
  Wet/Dry Mix를 조정하면서 원본과 이펙트의 비율을 세밀하게 맞출 수 있다.

---

## 9. Effect 렌더링(Render) 개념과 설정

- **기본적으로**, Effect는 **게임 실행 중 실시간으로 계산**된다.
  → 즉, CPU에서 이펙트를 실시간 처리하므로 연산 비용이 발생한다.
- **문제점:**
  이펙트가 많아지면 **게임의 퍼포먼스(성능)** 에 영향을 줄 수 있다.
- **해결 방법:**
  이펙트를 **사전 렌더링(Pre-rendering)** 해서
  게임 실행 시 계산하지 않고 **새로운 오디오 파일로 저장**한다.

**설정 방법:**

1. Effects 탭에서 **Render** 체크박스를 선택한다.
2. 이렇게 설정하면, **SoundBank를 생성할 때** 해당 이펙트가 **오디오 파일에 미리 적용되어 렌더링**된다.

> 📘 참고:
>
> 이 렌더링 과정은 **1단원: 적막에서 소리까지** 강의에서 자세히 다룸.

## 1. Auxiliary Bus와 Send 개념 이해하기

### 🎚️ Auxiliary Bus란?

- **보조 버스(Aux Bus)** 는 여러 사운드 오브젝트가 **공통의 효과(Effect)** 를 함께 사용할 수 있도록 하는 **공유 경로**입니다.
- 예를 들어, 복도 전체에 “리버브 효과”를 적용하려면, 각 사운드에 리버브를 개별로 넣는 대신
  하나의 Auxiliary Bus에 RoomVerb(룸 리버브) 이펙트를 추가하고,
  여러 사운드가 이 버스로 신호를 보내도록 설정하면 효율적입니다.

### 🔄 Auxiliary Send란?

- **보조 센드(Send)** 는 특정 오브젝트의 소리를 얼마나 보조 버스로 보낼지를 결정하는 **전송 경로**입니다.
- 즉, “이 소리를 리버브 버스로 얼마나 보낼까?”를 조절하는 기능입니다.

### 💡 이번 강의 목표

- Main Character의 모든 소리가 복도 환경(env_corridor) 리버브를 받도록 설정합니다.
- 두 가지 방식으로 실습합니다:
  1. **사용자 정의(User-Defined) 방식**
  2. **게임 정의(Game-Defined) 방식**

---

## 2. User-Defined Auxiliary Send 설정하기

먼저 **직접 수동으로 설정하는 방식**부터 진행합니다.

### ⚙️ 설정 단계

1. **Project Explorer에서 Main Character Actor-Mixer 선택**
   - 주인공 관련 모든 사운드를 포함하는 상위 믹서 오브젝트입니다.
2. **Property Editor → Routing 탭으로 이동**
   - Routing(라우팅) 탭은 오디오 신호가 어디로 전송되는지 정의하는 부분입니다.
3. **Set User-Defined Auxiliary Send 0 클릭**
   - Aux Send 슬롯 중 첫 번째(0번)를 선택합니다.
4. **env_corridor Auxiliary Bus 선택 → OK**
   - 리버브가 적용된 보조 버스(`env_corridor`)를 연결합니다.

### 💡 빠른 팁

- Project Explorer에서 `env_corridor` 오브젝트를 **User-Defined Auxiliary Sends 목록으로 드래그 앤 드롭**하면 더 빠르게 추가할 수 있습니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380545/notion-blog/_/WWISE/Wwise_/14_Effect_/image_5.png)

---

## 3. 리버브 효과 조정 및 테스트

이제 설정이 완료되었으니 **소리 테스트**로 리버브를 들어봅니다.

1. **Main Character Actor-Mixer 확장**
   - 그 안에 포함된 개별 사운드 오브젝트를 확인합니다.
2. **Body_Impact Sound SFX 선택 후 Spacebar 재생**
   - 주인공의 몸이 충돌하는 소리를 들어보고 리버브 효과를 확인합니다.
3. **리버브가 약하게 들리면 센드 볼륨 조절**
   - Property Editor에서 **env_corridor Volume** 값을 `12`로 올립니다.
   - 다시 Spacebar를 눌러 재생해보면 리버브가 더 강하게 들립니다.

## 4. Game-Defined Auxiliary Send로 전환하기

이번에는 **게임 엔진이 동적으로 리버브를 제어**하도록 바꿉니다.

이 방식은 플레이어의 위치에 따라 리버브 강도가 달라지는 **현실적인 공간감 표현**에 적합합니다.

### 🔁 전환 과정

1. **기존 User-Defined Auxiliary Send 제거**
   - Project Explorer에서 `Main Character Actor-Mixer` 선택
   - Property Editor의 **Send 0 → More options** 클릭
   - **None** 선택하여 `env_corridor` 연결 해제
2. **Game-Defined Auxiliary Sends 활성화**
   - Property Editor에서
     **Game-Defined Auxiliary Sends 아래의 Enable 체크박스**를 선택

이제 게임 엔진이 직접 Wwise에 메시지를 보내

“이 캐릭터가 어느 환경에 있는지”와 “얼마나 리버브를 적용할지”를 제어할 수 있습니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380546/notion-blog/_/WWISE/Wwise_/14_Effect_/image_7.png)

---

### ⚙️ 추가 팁

- **Use game-defined aux sends** 옵션 아래의 **Volume 컨트롤**은
  게임으로부터 받은 리버브 값을 **추가적으로 조절(오프셋)** 할 수 있는 기능입니다.
  → 프로그래머 도움 없이도 리버브 양을 세밀하게 조절 가능!

## 5. Cube 게임에서 리버브 확인하기

이제 Wwise를 연결한 **Cube 게임으로 돌아가** 실제 리버브 효과를 체험해봅니다.

1. Cube 실행 후 **복도로 이동**
   - 복도 입구로 들어가면 화면 우하단에 `"env 194525"` 표시가 나타남.
   - 이 숫자는 **게임에서 정의한 보조 센드(Environment ID)** 를 의미합니다.
     → 해당 환경의 리버브 강도를 Wwise에 알려주는 신호입니다.
2. **Spacebar로 점프 사운드 재생**
   - 플레이어가 복도 안에 있을 때 점프하면
     리버브가 적용된 소리를 들을 수 있습니다.
   - 실제처럼 미세하고 자연스러운 잔향이 느껴집니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380546/notion-blog/_/WWISE/Wwise_/14_Effect_/image_8.png)

## 6. 보조 버스 리버브 튜닝하기

리버브가 너무 약하거나 길게 느껴진다면, Wwise에서 **보조 버스의 효과 파라미터를 직접 조정**할 수 있습니다.

1. **Wwise로 돌아가기**
   - **Master-Mixer Hierarchy → env_corridor Auxiliary Bus 선택**
2. **RoomVerb 설정 변경**
   - **Decay Time** : 잔향이 사라지는 속도 (값을 높이면 리버브 길어짐)
   - **HF Damping** : 고음이 얼마나 빨리 감쇠되는지 (값을 높이면 부드러운 리버브)
3. Cube 게임으로 돌아가 다시 플레이하면서

   **변경된 리버브의 차이**를 실시간으로 확인합니다.
