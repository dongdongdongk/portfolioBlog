## HTML<thead>, <tbody>, <tfoot>

```html
<table>
  <thead>
    <tr>
      <th>출장비 내역</th>
      <th>금액</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>교통비</td>

    </tr>

  <tfoot>
    <tr>
      <td>총 합계</td>

    </tr>

**//
<thead>
  : 표의 제목을 나타내는 태그 //
</thead>

<tbody>
  : 표의 본문 영역을 나타내는 태그 //
</tbody>

<tfoot>
  : 표의 바닥글 영역을 나타내는 태그 //** 이들은 필수적으로 사용해야 하는 요소는 아니고 표의 영역을
  구분 해주고 싶을때 사용한다. ( 시멘틱 태그 처럼 눈으로 확인할수 있는 변화는 없다. )
</tfoot>
```

## HTML rowspan, colspan

```html
<table>
  <tr>
    <th>밥류</th>
    <th>면류</th>
    <th>분식류</th>
  </tr>
  <tr>
    <td>김밥</td>
    <td>라면</td>
    <td rowspan="2">떡볶이</td>
  </tr>
  <tr>
    <td>주먹밥</td>
    <td>우동</td>
  </tr>
</table>

**//이들은 셀을 가로 세로로 병합할때 사용한다. //rowspan : 아래로 셀을 병합한다.** **//colspan :
가로로 셀을 병합한다. //해당 데이터 셀(data cell)이 확장될 행, 열 의 개수이며, 기본값은 1임. 이때
속성값을 0으로 명시하면, 해당 셀은 자신이 포함된 테이블 영역 (thead, tbody, tfoot)의 마지막 행까지
확장됨.**
```

```html
문법 :
<td rowspan="숫자">아래셀 병합</td>
<td colspan="숫자">가로 셀 병합</td>
```

## **HTML <form>**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381356/notion-blog/_/The_Web_Developer_2022/HTML/HTML_/Untitled_5.png)

<form> 은 웹에서 많이 사용되는 중요한 요소이다.

사용자의 의견이나 정보를 알기 위해 입력할 큰 틀을 만드는데 사용된다.

폼은 입력된 데이터를 한번에 서버로 전송하고 전송한 데이터는 웹 서버가 처리하고 결과에 따른

또 다른 웹 페이지를 보여준다.

ex) 로그인 화면

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381361/notion-blog/_/The_Web_Developer_2022/HTML/HTML_/Untitled_6.png)

- form 요소는 "정보를 제출하기 위한 대화형 컨트롤을 포함하는 문서 섹션을 나타낸다.
- action 특성은 form 데이터를 보낼 위치를 지정
- method 속성은 사용할 HTTP 메서드를 지정(뒤에 설명)

**form 이 작동하는 원리**

1. form 제출
2. HTTP 요청 전송
3. action 속성을 통해 해당 요청이 어디로 가는지 제어
4. 어떤 유형의 HTTP 메서드를 사용할지 제어

```html
문법 :
<form action="이동할 경로"></form>
```

```html
<form action="/examples/media/action_target.php">
  이름 : <input type="text" name="st_name" /><br />
  학번 : <input type="text" name="st_id" /><br />
  학과 : <input type="text" name="department" /><br />
  <input type="submit" />
</form>

**//
<form></form>
: 입력 양식 전체를 감싸는 태그 //
<form action="주소">
  : form을 전송할 서버 쪽의 script 파일을 지정 (전송되는 서버 url 또는 html 링크) //<input
    type="타입"
  />
  : form의 요소중 하나.사용자가 정보를 입력하는 부분을 만들어야 할 때 사용한다.type에 따라 어떤
  형식으로 정보를 받을지 결정된다. id 값을 통해 서로 구분할 수도 있다. //<input
    type="text"
    placeholder="username"
  />
  : 요소에 무엇을 입력 해야하는지 보여준다. (유저가 입력을 시작하면 사라짐)**
</form>
```

## **HTML <range>**

```html
문법 : <input type="range" />

<input type="“range”" />는 슬라이드 바를 조정하여 범위 내의 숫자를 선택할 수 있는 입력 필드를
정의한다. 기본 범위는 0부터 100까지 - max : <input /> 요소의 최댓값을 명시함. - min :
<input /> 요소의 최솟값을 명시함. - step : <input /> 요소에 입력할 수 있는 숫자들 사이의 간격을
명시함. - value : <input /> 요소의 초깃값을 명시함.
```

```html
<p>Audio settings:</p>

<div>
  <input type="range" id="volume" name="volume" min="0" max="11" />
  <label for="volume">Volume</label>
</div>

<div>
  <input type="range" id="cowbell" name="cowbell" min="0" max="100" value="90" step="10" />
  <label for="cowbell">Cowbell</label>
</div>
```

## **HTML5 form 의 유효성 검사**

```html
문법 : <input type="text" name="st_name" required />

<input /> 태그의 required 속성은 폼 데이터(form data)가 서버로 제출되기 전 반드시 채워져 있어야 하는
입력 규칙을 명시한다. required 속성이 제대로 동작하는 <input /> 요소의 type 속성값은 다음과 같다.
checkbox, date, email, file, number, password, pickers, radio, search, tel, text, url 몇몇 타입은
디폴트로 required 가 포함 되어있다. ex) email 은 aaa@aaa 처럼 @ 앞과 뒤로 판단 그러나 required 는
붙여줘야 한다.(없이 하면 미 입력으로 제출 가능) 이는 브라우저 에서 유효성을 검사 하는 것 이고
과거에는 서버에서 유효성 검사를 추가로 많이 하였다.(지금도 많이함)
```

```html
<form action="/examples/media/action_target.php" method="get">
  이름 : <input type="text" name="st_name" required /><br />
  학과 : <input type="text" name="department" /><br />
  <input type="submit" />
</form>

**//required 를 사용하면 텍스트를 입력 해야지 form 을 제출할 수 있다.**

<input type="text" name="st_name" minlenght="5" maxlenght="20" required />

// minlenght, maxlenth 를 사용하여 최대, 최소 입력을 조절할수 있다.
```
