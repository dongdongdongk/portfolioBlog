## Java 개발 환경

### 1. JDK 설치

[Download the Latest Java LTS Free](https://www.oracle.com/java/technologies/downloads/#jdk17-windows)

```java
- JDK 다운
   https://www.oracle.com/java/technologies/javase-downloads.html
	 JDK 11 버전

 - JDK 설치
   확인 : cmd, terminal   : java -version

 - JDK 환경변수 설정
   Java에 관련된 명령어의 위치를 OS에 알려주려는 목적

   1) 제어판 > 시스템 및 보안 > 시스템
   2) 고급시스템 설정 > 고급탭 > 환경변수
   3) 시스템변수 > 새로만들기
   4) 변수이름 : JAVA_HOME
   5) 변수값    : java가 설치된 폴더(C:\Program Files\Java\jdk-11.0.10)
   6) path > 편집
   7) 새로만들기 : %JAVA_HOME%\bin
```
