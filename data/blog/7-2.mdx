# { 🎯 Widget Blueprint로 십자선 만들기 }

## 📌 이 강의의 목표

Widget Blueprint를 사용하여 화면에 십자선 HUD를 표시합니다.

- Widget Blueprint 생성
- Overlay와 Image 위젯 사용
- 십자선 UI 구성
- 뷰포트에 추가
- 카메라 오프셋 조정

## 🧩 4단계: Overlay 위젯

### 왜 Overlay?

```
Image 직접 추가
  └─ 화면 전체로 늘어남
      └─ 여러 이미지 겹칠 수 없음 ✗

Overlay 사용
  └─ 여러 위젯 겹칠 수 있음 ✅
```

### Overlay 추가

```
Palette 패널
  ↓
"Overlay" 검색
  ↓
Canvas로 드래그
```

**Overlay**: 자식 위젯들을 겹쳐서 배치하는 컨테이너

## 📐 Alignment 옵션 설명

```

  ├─ Bottom: 아래쪽 정렬
  └─ Fill: 늘어남
```

```
Create Widget 노드

```


```
역할: 위젯을 화면에 표시
입력: User Widget (Create Widget 결과)
```

**중요**: Create만 하면 안 보임!
**Add to Viewport 필수!**

### 연결

```

  ↓
Create Widget
  ├─ Class: WBP_OverlayHUD
  └─ Return Value → Add to Viewport
```

```
BP_BotPawn
  ↓
SpringArm 선택
  ↓
Details 패널
  └─ Camera Settings
      └─ Socket Offset
```

### Socket Offset이란?

```
Socket Offset
  └─ Spring Arm 끝에서의 오프셋
      └─ 카메라 위치 조정

vs

Location Offset
  └─ Spring Arm 자체 이동
```

**장점**: Spring Arm 기능 유지하면서 카메라만 이동!

### 설정

```
Socket Offset
  ├─ X: 0
  ├─ Y: 0
  └─ Z: 45
```

**Z: 45**: 위로 45 유닛 이동

## 🔧 노드 흐름도 분석

### Widget 생성 흐름

```
Event BeginPlay
  │
  └── Create Widget
        │
        ├── Class: WBP_OverlayHUD (어떤 Widget?)
        ├── Owning Player: (누구 것?)
        │
        └── Return Value (생성된 Widget)
              │
              └── Add to Viewport
                    │
                    └── (화면에 표시!)
```

### 각 노드 역할

### Event BeginPlay

```
언제: 게임 시작 시
역할: 초기화 시작점
```

### Create Widget

```
입력:
  ├─ Class (Widget Blueprint Class)
  │   └─ 어떤 Widget을 만들지
  │
  └─ Owning Player (Player Controller)
      └─ 누구의 Widget인지

출력:
  └─ Return Value (User Widget)
      └─ 생성된 Widget 인스턴스
```

**Class 예시**: WBP_OverlayHUD

### Add to Viewport

```
입력:
  └─ Target (User Widget)
      └─ 어떤 Widget을 추가할지

역할:
  └─ Widget을 화면에 표시
```

**주의**: 이거 없으면 Widget 생성만 되고 안 보임!

# { 🎯 Line Trace로 정확한 조준 구현 }

## 📌 이 강의의 목표

Line Trace를 사용하여 십자선이 가리키는 위치로 정확하게 발사체를 날립니다.

- Line Trace 개념
- 카메라에서 Line Trace 발사
- Hit Result 처리
- 발사체 방향 설정

---

## ⚠️ 현재 문제점

### 조준 불일치

```
십자선 위치 ≠ 발사체 방향
  ↓
카메라는 위로
메시는 앞으로
  ↓
발사체는 메시 Forward Vector
  ↓
빗나감! 😱
```

### 테스트

```
봇 조준
  ↓
발사
  ↓
봇 아래로 날아감
  └─ 빗나감!
```

---

## 💡 해결책: Line Trace

### 원리

```
1. 화면 중앙(십자선)에서 Line Trace
   ↓
2. Hit Point 획득
   ↓
3. 발사체를 Hit Point 방향으로 발사
   ↓
4. 정확한 조준! ✅
```

### Line Trace란?

```
보이지 않는 선을 쏴서
  ↓
충돌 확인
  ↓
Hit 정보 반환
```

**용도**: 조준, 시선 체크, 레이캐스트

## 🔍 3단계: Debug Sphere (Start)

### 시작점 시각화

```
Camera → Get World Location
  ↓
Draw Debug Sphere
  ├─ Center: Camera Location
  ├─ Radius: 5
  ├─ Line Color: Red
  ├─ Duration: 60
  └─ Thickness: 0
```

## 📏 4단계: End 위치 계산

### 계산식

```

```

```
  +
```

### Get Forward Vector

```
역할: Scene Component의 앞쪽 방향 가져오기
Target: Camera
출력: Vector (방향, 길이 = 1)
```

**Unit Vector**: 길이가 1인 방향 벡터

### Multiply (Vector × Float)

```
노드: Vector * Float
입력:
  ├─ A: Forward Vector (방향)
  └─ B: TraceDistance (거리)
출력: 스케일된 벡터
```

**결과**: Forward × 5000 = 앞으로 5000 유닛

### Add (Vector + Vector)

```
노드: Vector + Vector
입력:
  ├─ A: Camera Location (시작)
  └─ B: Forward × Distance (오프셋)
출력: 최종 위치
```

**결과**: 카메라에서 앞으로 5000 유닛 떨어진 위치
