# Querydsl 테스트

## Querydsl 사용 상황

```java
제목/내용/작성자 와 같이 단 하나의 항목으로 검색하는 경우

제목 + 내용 / 내용 + 작성자 / 제목 + 작성자 와 같이 2개의 항목으로 검색하는 경우

제목 + 내용 + 작성자 와 같이 3개의 항목으로 검색하는 경우

이렇게 다양한 조건으로 검색할 때 매번 메소드를 만들면 효율적이지 못하기 때문에 이때

Querydsl 을 사용한다
```

## Querydsl의 사용법

```java
* QueryDSL을 사용하기 위한 엔티티에 해당하는 Query 클래스 "Q클래스명" 을 생성

* BooleanExpression 을 이용해서 조건을 만들고

* BooleanBuilder 에 작성된 조건 Predicate(expression) 를 추가하고

*  booleanBuilder 를 이용해서 실행  (Page<Guestbook> result = guestbookRepository.findAll(**booleanBuilder**,pageable);)
```

## Querydsl 단일항목 테스트

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381205/notion-blog/_/_/_/_/BCh04_03_p148_/Untitled_5.png)

```java
  	@Test
    public void testQuery1() {
        Pageable pageable = PageRequest.of(0,10, Sort.by("gno").descending());

        //fidAll 은 JpaRepository 에 있는 메서드인데 거기에 Querydsl 을 적용하려면 QuerydslPredicateExecutor<> 를 사용한다

        //Predicate 는 자바에도 있기 때문에 임포트 할때 주의
        QGuestbook qGuestbook = QGuestbook.guestbook;

        BooleanBuilder booleanBuilder = new BooleanBuilder();

        //title like %1% 같은걸 코드를 통해서 만들어 내는것이라 생각하면 편하다
        BooleanExpression expression = qGuestbook.title.contains("1");

        //익스프레션을 빌더에 추가해서 조건을 추가해준다
        booleanBuilder.and(expression);

        Page<Guestbook> result = guestbookRepository.findAll(booleanBuilder,pageable);

        result.forEach(guestbook -> {
            System.out.println(guestbook);
        });

    }
```

```java
* Pageable pageable = PageRequest.of(0, 10, Sort.by("gno").descending());: 페이징 처리를 위한 설정을 생성. 페이지 번호는 0부터 시작하고 한 페이지에 10개의 항목을 표시하며, gno 필드를 내림차순으로 정렬

* QGuestbook qGuestbook = QGuestbook.guestbook;: QueryDSL을 사용하기 위한 Guestbook 엔티티에 해당하는 Query 클래스 QGuestbook을 생성

* BooleanBuilder booleanBuilder = new BooleanBuilder();: 동적 검색 조건을 추가하기 위한 빌더를 초기화

* BooleanExpression expression = qGuestbook.title.contains("1");: "1"을 포함하는 title 필드의 검색 조건을 생성

* booleanBuilder.and(expression);: 앞서 생성한 검색 조건을 빌더에 추가하여 "1"을 포함하는 title을 검색하는 조건을 설정

* Page<Guestbook> result = guestbookRepository.findAll(booleanBuilder, pageable);: 조건에 맞는 데이터를 조회하고, 해당 결과를 페이지별로 가져옴

* result.forEach(guestbook -> { System.out.println(guestbook); });: 조회한 결과를 반복문을 통해 출력
```

## 상세한 사용법 설명

```jsx

4. 만들어진 조건은 where문에 and 나 or 같은 키워드로 결합시킨다 (BooleanBuilder builder 에 builder.and(expression);)

5. BooleanBuilder 는 GuestbookRepository에 추가된 QuerydslPredicateExcuter 인터페이스의
```
