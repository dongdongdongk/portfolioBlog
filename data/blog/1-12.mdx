# **LESSON 01 네트워크의 구조**

## **컴퓨터 네트워크?**

```jsx
컴퓨터 간의 네트워크를 연결한 것을 컴퓨터 네트워크라고 하며, 두 대 이상 연결되어 있으면 컴퓨터 네트워크가 된다.

네트워크를 사용하여 파일 전송, 웹 사이트 열람, 메일 송·수신 등을 할 수 있다.

인터넷은 TCP/IP 프로토콜을 사용하는 세계 최대 규모의 거대한 네트워크이다.
```

## **패킷?**

```jsx
네트워크나 인터넷에서 데이터를 주고받을 때는 규칙이 필요합니다. 이 규칙에 따라 데이터를 주고받을 때는 최소한의 단위인 패킷(packet) 단위로 나누어 전송합니다.

1. 패킷 단위로 전송하는 이유

	대역폭 관리: 큰 데이터를 한 번에 전송하면 네트워크의 대역폭(bandwidth)을 너무 많이 차지하여 다른 패킷의 흐름을 막을 위험이 있습니다.

	따라서, 데이터를 작은 단위인 패킷으로 나누어 전송하여 네트워크 효율성을 높입니다.

2. 패킷의 재조립

	목적지에서 재조립: 패킷으로 나누어 전송한 데이터는 목적지에서 원래 데이터로 되돌리는 작업을 합니다.

	순서 보장: 패킷은 순서를 보장하지 않지만, 각 패킷에 번호를 붙여 전송하기 때문에 수신 측에서 이를 정렬하여 원래 데이터를 복원할 수 있습니다.

이를 통해 네트워크 상에서 효율적이고 신뢰성 있게 데이터를 전송할 수 있습니다.
```

# LESSON 02: 정보의 양을 나타내는 단위

## 비트와 바이트

```jsx
디지털 데이터: 0과 1의 집합으로, 모든 컴퓨터는 이를 다룬다.

비트(bit): 0과 1의 정보를 나타내는 최소 단위.

바이트(byte): 8비트 = 1바이트. 컴퓨터는 주로 바이트 단위로 데이터를 읽고 씀.

문자 코드: 예를 들어, 알파벳 'A'를 입력하면 컴퓨터는 아스키(ASCII) 코드 65를 확인해 화면에 'A'를 표시.
```

# LESSON 03 랜과 왠

## 정의

```jsx
랜(LAN : Local Area Network, 근거리 통신망)

	가정이나 사무실과 같이 비교적 좁은 범위에서 사용되는 네트워크.

왠(WAN : Wide Area Network, 광역 통신망)

	랜과 랜이 연결된 비교적 넓은 범위에서 사용되는 네트워크. 인터넷 서비스 제공자(ISP: Internet Service Provider,

	인터넷 상용 서비스 사업자)가 제공하는 서비스를 사용하여 구축됨.
```

## 주요 차이점

```jsx
접속 범위

	랜: 좁은 범위 (가정, 사무실 등)

	왠: 넓은 범위 (도시, 국가, 전 세계)

신호 강도 및 오류 발생

	랜: 거리가 짧아 신호 약화와 오류 발생이 적음.

	왠: 거리가 멀어 상대적으로 오류 발생률이 높음.


속도

	랜: 빠름.

	왠: 랜에 비해 상대적으로 느림.
```

# **LESSON 04 가정에서 하는 랜 구성**

```jsx
가정에서 네트워크를 구성하는 방법

ISP와 인터넷 회선 선택

	인터넷 회선: 인터넷 서비스 제공업체(ISP)의 ex)kt 인터넷과 연결된 회선입니다. 이 회선을 통해 인터넷에 접속할 수 있습니다.

	일반적으로 광랜(이더넷)이나 FTTH(Fiber To The Home) 회선을 사용합니다.

인터넷 공유기(라우터) 설치

	인터넷 공유기: 가정용 라우터로, 내부 네트워크(사설망)를 구성하고 다양한 기기를 인터넷에 연결할 수 있게 합니다.

	유선 랜: 랜 케이블을 사용해 기기를 연결하는 방식입니다.

	무선 랜: 와이파이를 사용해 기기를 연결하는 방식입니다.

네트워크 보안

	가정의 네트워크는 외부에 공개할 필요가 없습니다. 따라서 보안을 철저히 하는 것이 중요합니다.
```

# **LESSON 05 회사에서 하는 랜 구성**

```jsx
회사의 네트워크 구성은 가정과는 다릅니다. 특히, 외부에 공개할 필요가 있는 네트워크 영역인 DMZ(DeMilitarized Zone)가 추가됩니다.

다음은 회사에서의 네트워크 구성 요소와 운영 방식입니다.
```

```jsx
DMZ(비무장 지대)

DMZ: 외부 네트워크와 내부 네트워크 사이에 위치한 중간 지대로, 외부에 공개할 서버를 둡니다. 이를 통해 외부 공격자가 내부 네트워크로 침투하는 것을 방지합니다.
서버

서버: 네트워크에서 다른 컴퓨터에 서비스를 제공하는 컴퓨터나 프로그램입니다. 서버는 정보를 제공하는 공급자이며, 클라이언트는 그 정보를 소비하는 역할을 합니다.
서버 종류:

	웹 서버: 웹 사이트를 외부에 공개합니다.

	메일 서버: 외부와 메일을 주고받습니다.

DNS 서버: 도메인 이름을 사용하여 서버에 접속할 수 있게 합니다.

	서버는 스위치나 무선 랜 기능을 통해 사내 네트워크에 접속합니다.


서버 운영 방식

	온프레미스(On-Premise): 회사 내에서 직접 서버와 자원을 관리합니다.

	데이터 센터: 대량의 데이터를 보관하기 위해 전용 시설에 서버와 네트워크 기기를 설치합니다.

	사내 설치: 회사 내부에 서버 장비실이 존재하여 관리합니다.

	클라우드: 인터넷을 통해 소프트웨어/하드웨어 등의 컴퓨팅 서비스를 제공합니다. 장소에 구애받지 않으며, 클라우드 서비스 제공자가 자원을 관리합니다.
```
