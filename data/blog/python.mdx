```python
파이썬(Python)에서 반복문은 주로 while과 for 두 가지 형태로 사용된다.

이 반복문들은 코드 블록을 조건이 만족하는 동안(while) 또는 주어진 시퀀스를 따라(for) 반복 실행하도록 설계되었다.
```

# **While 반복문**

```python
while 반복문은 주어진 조건이 참(True)인 동안, 반복해서 코드 블록을 실행한다. 조건이 거짓(False)이 되면 반복이 중단된다.
```

## **기본 구조:**

```python
while 조건:
    # 실행할 코드
```

```python
i가 1부터 시작하여 5이하일 동안 반복
```

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

# **For 반복문**

```python
for 반복문은 시퀀스(리스트, 튜플, 딕셔너리, 집합, 문자열 등)를 순회하면서 반복 실행한다.

각 반복마다 시퀀스의 다음 요소를 가져와서 코드 블록을 실행
```

## **기본 구조:**

```python
for 변수 in 시퀀스:
    # 실행할 코드
```

```python
fruits 리스트의 각 요소를 순회하며 출력

for 반복문이 fruits 리스트의 처음부터 끝까지 진행하면서, 각 요소를 fruit 변수에 할당하고 print 함수를 사용하여 출력
```

```python
fruits = ['apple', 'banana', 'cherry']
for fruit in fruits:
    print(fruit)
```

# **range() 함수와 함께 for 반복문 사용**

```python
range() 함수는 숫자 시퀀스를 생성하며, for 반복문과 함께 자주 사용

예를들면 10번 반복하고 싶으면 11을 넣어주면 되는것
```

```python
for i in range(5):
    print(i)
```

```python
range(5)는 0부터 4까지의 숫자를 생성하며, for 반복문은 이 숫자들을 하나씩 i에 할당하고 출력
```

## 응용 사용

```python
for i in range(1, 11):
    print(i)

이런식으로도 사용이 가능하다
```

```python
range() 함수의 첫 번째 인자는 시작 숫자이고, 두 번째 인자는 끝 숫자의 다음 숫자이다.

즉, 위 코드에서는 1부터 시작하여 10까지의 숫자를 생성하게 된다
```

# **break, continue**

## break

```python
break 키워드는 반복문(주로 for나 while문)을 중단하는 데 사용된다.

특정 조건이 만족되면 반복문이 즉시 종료되고, 반복문을 빠져나와 다음 코드로 이동한다.

보통은 특정 조건이 충족되었을 때 더 이상 반복이 필요하지 않을 때 break를 사용한다.

break는 반복문을 완전히 종료하므로 해당 반복문 다음의 코드가 실행된다.
```

```python
for i in range(1, 11):
    if i == 5:
        break
    print(i)
```

## **continue**

```python
continue 키워드는 반복문 내에서 특정 조건을 만족할 때 해당 반복을 건너뛰고 다음 반복으로 진행하는 데 사용된다.

특정 조건이 만족되면 현재 반복을 중단하고 다음 반복으로 넘어가며, 다음 반복은 조건을 다시 확인한다.

보통은 특정 조건을 만족하는 경우에는 해당 반복을 건너뛰고 다음 반복으로 이동해야 할 때 continue를 사용한다.

continue를 사용하면 현재 반복은 종료되지 않고 다음 반복으로 이동하므로, 해당 반복문의 나머지 코드는 실행되지 않고 다음 반복이 실행된다.
```

```python
for i in range(1, 11):
    if i % 2 == 0:
        continue
    print(i)
```
