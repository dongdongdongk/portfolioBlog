# forEach

```jsx
forEach는 배열의 각 요소에 대해 주어진 함수를 실행하는 메서드

forEach를 사용하면 간결하게 반복 작업을 수행할 수 있으며, 콜백 함수를 통해 다양한 작업을 수행할 수 있다.

( for of 가 나오기 전에는 훨씬 많이 쓰였다 )
```

## **`forEach` 메서드의 기본 구조:**

```jsx
배열.forEach(function (요소, 인덱스, 배열) {
  // 각 요소에 대해 실행할 코드
})
```

```jsx
요소: 현재 처리 중인 배열의 요소

인덱스: 현재 처리 중인 배열의 요소의 인덱스

배열: forEach를 호출한 배열 자체
```

## 예제

### **배열의 각 요소 출력:**

```jsx
let numbers = [1, 2, 3, 4, 5]

numbers.forEach(function (number) {
  console.log(number)
})
// 출력: 1
//       2
//       3
//       4
//       5
```

### **각 요소에 대한 연산 수행**

```jsx
let numbers = [1, 2, 3, 4, 5]
let squaredNumbers = []

numbers.forEach(function (number) {
  squaredNumbers.push(number * number)
})

console.log(squaredNumbers) // 출력: [1, 4, 9, 16, 25]
```

### **각 요소의 인덱스와 함께 사용**

```jsx
let fruits = ['사과', '바나나', '딸기']

fruits.forEach(function (fruit, index) {
  console.log(index + '. ' + fruit)
})
// 출력: 0. 사과
//       1. 바나나
//       2. 딸기
```

### **원본 배열을 변경하는 경우**

```jsx
let numbers = [1, 2, 3, 4, 5]

numbers.forEach(function (number, index, array) {
  array[index] = number * 2
})

console.log(numbers)
// 출력: [2, 4, 6, 8, 10]
```

```jsx
forEach는 배열을 수정할 수 있기 때문에 주의가 필요하다.

forEach에서 콜백 함수 내에서 배열의 요소를 변경하면, 원본 배열도 영향을 받는다. (위의 array 사용)

콜백 함수에서 배열의 요소를 수정하면 해당 인덱스의 요소가 변경되는 것이기 때문
```

# Map

```jsx
.map() 메서드는 배열의 각 요소에 대해 주어진 함수를 호출하고, 그 결과를 새로운 배열로 반환하는 메서드

( .map() 메서드는 **원본 배열을 변경하지 않고**, 각 요소를 변환한 새로운 배열을 반환 )
```

## **`.map()` 메서드의 기본 구조**

```jsx
const 새로운배열 = 기존배열.map(function (요소, 인덱스, 배열) {
  // 각 요소에 대해 실행할 코드
  return 변환된값
})
```

```jsx
요소: 현재 처리 중인 배열의 요소

인덱스: 현재 처리 중인 배열의 요소의 인덱스

배열: .map()을 호출한 배열 자체 ( 배열을 전부 출력함 )
```

## 예제

### **각 요소를 두 배로 변환하여 새로운 배열 생성**

```jsx
let numbers = [1, 2, 3, 4, 5]

let doubledNumbers = numbers.map(function (number) {
  return number * 2
})

console.log(doubledNumbers)
// 출력: [2, 4, 6, 8, 10]
```

```jsx
.map() 메서드를 사용하여 배열 numbers의 각 요소를 두 배로 변환한 새로운 배열 doubledNumbers를 생성
```

### **각 문자열의 길이를 구하여 새로운 배열 생성**

```jsx
let fruits = ['사과', '바나나', '딸기']

let lengths = fruits.map(function (fruit) {
  return fruit.length
})

console.log(lengths)
// 출력: [2, 3, 2]
```

```jsx
.map() 메서드를 사용하여 배열 fruits의 각 문자열의 길이를 구한 새로운 배열 lengths를 생성
```

### **각 요소의 인덱스와 함께 사용**

```jsx
let numbers = [1, 2, 3, 4, 5]

let indexedNumbers = numbers.map(function (number, index) {
  return { index, value: number }
})

console.log(indexedNumbers)
// 출력: [ { index: 0, value: 1 },
//        { index: 1, value: 2 },
//        { index: 2, value: 3 },
//        { index: 3, value: 4 },
//        { index: 4, value: 5 } ]
```

```jsx
.map() 메서드를 사용하여 배열 numbers의 각 요소와 인덱스를 객체로 변환한 새로운 배열 indexedNumbers를 생성
```

### 인수 원본 배열 사용

```jsx
let numbers = [1, 2, 3, 4, 5]

let squaredDoubledNumbers = numbers.map(function (number, index, array) {
  console.log(`현재 처리 중: ${number}, 인덱스: ${index}`)
  console.log('원본 배열:', array)

  // 각 요소를 제곱하고 두 배로 변환
  return number * number * 2
})

console.log('최종 결과 배열:', squaredDoubledNumbers)

// 출력
//현재 처리 중: 1, 인덱스: 0
//원본 배열: [1, 2, 3, 4, 5]
//현재 처리 중: 2, 인덱스: 1
//원본 배열: [1, 2, 3, 4, 5]
//현재 처리 중: 3, 인덱스: 2
//원본 배열: [1, 2, 3, 4, 5]
//현재 처리 중: 4, 인덱스: 3
//원본 배열: [1, 2, 3, 4, 5]
//현재 처리 중: 5, 인덱스: 4
//원본 배열: [1, 2, 3, 4, 5]
//최종 결과 배열: [2, 8, 18, 32, 50]
```
