# JSON 이란?

```java
JavaScript Object Notation 의 약자

자바 스크립트 에서는 오브젝트가 {key : value} 로 이루어져 있는데 JSON 또한 같은 방식으로 이루어져 있다
```

# JSON 의 사용방법

```java
JSON 은 {key : value} 를 스트링 타입으로 변환한뒤 서버로 전달한 뒤

서버에서 다시 {key : value} 의 스트링 타입으로 클라이언트로 전달받고 이를 오브젝트로 다시 변환한다.
```

## 1. Object 에서 JSON 으로 변환하기 (stringfy(obj))

```java
오브젝트를 스트링타입(JSON)으로 변환하려면 stringify 메서드를 사용해서 JSON 으로 변환할 수 있다.

let test = JSON.stringify(오브젝트)

```

### 예제

```java
let json = JSON.stringfy(true);
console.log(json);

결과 : true  (JSON타입임)

---------------------------------------------------------------------------------------------------------------------

json = JSON.stringify(['apple', 'banana']);       //배열 타입을 JSON 으로 변환
consol.log(json);

결과 : ["apple","banana"]   (JSON 타입)

-----------------------------------------------------------------------------------------------------------------------

const rabbit = {
	name : 'tori',
	color : 'white',
	size : null,
	birthDate : new Date(),
	jump : () => {                              // 함수를 넣어줬다
		console.log('${name} can jump!');
	},
};

json = JSON.stringify(rabbit);
console.log(json);

결과 : {"name" : "tori" , "color" : "white", "size" : null , "birthDate" : "2020-05-29"}

(함수는 JSON 으로 변환되지 않는다)

json = JSON.stringify(rabbit, ['name', 'color', 'size']);
console.log(json);

결과 : {"name" : "tori" , "color" : "white", "size" : null}

(이런식으로 필요한 정보만 선택해서 사용할수도 있다)

--------------------------------------------------------------------------------------------------------------------------
```

## JSON 에서 Object 로 변환하기 (parse(json))

```java
JSON 을 Object 로 변환하려면 .parse() 를 사용하면 된다.
```

### 예제

```java
const obj = JSON.parse(json);      // JSON 타입의 json 을 오브젝트로 만들어 줬다.
```
