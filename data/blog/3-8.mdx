# { 함수(Function) - 코드 정리하기 }

## 🎯 목표

```
복잡한 Blueprint 정리
  ↓
함수로 깔끔하게!
  ↓
스파게티 코드 제거
```

---

## 🍝 스파게티 코드란?

### 문제 상황

```
Event Graph가 복잡함
  ├─ 노드 너무 많음
  ├─ 와이어 교차
  └─ 스파게티처럼 엉킴!
      ↓
읽기 어려움 😰
```

### 해결책

```
함수로 묶기!
  ├─ 관련 노드들을 그룹화
  ├─ 하나의 노드로 압축
  └─ 깔끔한 Graph
```

---

## 🔧 함수(Function)란?

### 개념

```
특정 작업을 수행하는 노드 묶음
  ↓
재사용 가능
  ↓
한 가지 일만 함
```

### 비유

```
요리 레시피
  ├─ 재료 (입력)
  ├─ 조리 과정 (함수 내부)
  └─ 완성 요리 (출력)
```

## 🎨 함수 구조

### Entry 노드

```

  ├─ 함수 시작점
  └─ 실행 출력 ▶
```

```

  ↓

      ↓
```

## ✨ Pure Function (순수 함수)

### 일반 함수 vs 순수 함수

### 일반 함수

```
[Function]
  ├─ 실행 입력 ▶
  ├─ 실행 출력 ▶
  └─ 데이터 출력
```

### 순수 함수

```
[Pure Function]
  ├─ 실행 핀 없음! ❌
  └─ 데이터 출력만
      ↓
깔끔함!
```

### 예시

```
Get Socket Transform
  ├─ 실행 핀 없음
  ├─ 입력: Socket 이름
  └─ 출력: Transform
      ↓
순수 함수!
```

## 📐 Sprite Size

### Random Uniform (기본)

```
모든 방향 같은 크기
  ├─ 원형
  └─ Min/Max: 같은 값
```

### Random Non-Uniform

```
X, Y 다른 크기
  ├─ X: 2 (가로)
  ├─ Y: 8 (세로)
  └─ 길쭉한 모양!
```

### 추천 설정

```
Sprite Size Mode: Random Non-Uniform
  ├─ X Min: 2, X Max: 2
  └─ Y Min: 6, Y Max: 8
      ↓
속도 방향으로 늘어난 효
```
