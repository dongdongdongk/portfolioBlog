## Anaconda란 무엇인가?

```python
Anaconda는 데이터 과학 및 머신 러닝을 위한 통합 개발 환경(IDE)

Anaconda에는 다양한 데이터 과학 패키지와 도구들이 포함되어 있어, 데이터 분석, 머신 러닝, 인공지능 개발을 위한 작업을 쉽게 할 수 있다.

주요 특징은 다음과 같다:

패키지 관리자:

Anaconda는 conda라는 패키지 관리자를 포함하고 있어, 다양한 패키지와 의존성을 손쉽게 설치하고 관리할 수 있다.

가상 환경 관리:

다양한 프로젝트에서 서로 다른 패키지 버전과 의존성을 필요로 할 때,

각 프로젝트마다 독립적인 가상 환경을 만들고 관리할 수 있다.

포함된 도구:

Anaconda에는 Jupyter Notebook, Spyder, RStudio 등 다양한 개발 도구가 포함되어 있어 데이터 분석과 개발 작업을 쉽게 수행할 수 있다.
```

### 가상 환경이란 무엇인가?

```python
가상 환경(Virtual Environment)은 하나의 시스템 내에서 독립적인 Python 실행 환경을 만드는 도구이다.

가상 환경을 사용하면 다음과 같은 장점이 있다:

독립성 유지:

프로젝트마다 별도의 패키지와 의존성을 설치할 수 있어, 한 프로젝트에서 사용하는 패키지가 다른 프로젝트에 영향을 주지 않는다.

버전 관리:

특정 프로젝트가 특정 버전의 패키지와 Python을 필요로 할 때, 가상 환경을 사용하여 이를 관리할 수 있다.

충돌 방지:

서로 다른 프로젝트에서 필요한 패키지의 버전이 다를 경우, 가상 환경을 사용하면 충돌 없이 각각의 프로젝트가 필요한 버전의 패키지를 사용할 수 있다.
```

```python
Scrapy에는 두 가지 주요 스파이더 템플릿이 있습니다: Scrapy Spider와 Crawl Spider이다.
```

```python
Scrapy Spider

가장 단순한 스파이더이다.

특별한 기능을 제공하지 않지만, 우리가 원하는 방식으로 맞춤 설정할 수 있다.

사용 예: 특정 페이지에서 데이터를 추출할 때. ( 간단한 작업 )

Crawl Spider

일반 웹사이트 크롤링에 가장 자주 사용되는 스파이더입니다.

링크를 자동으로 따라가며 여러 페이지를 크롤링할 수 있다.

크롤링(crawling)은 웹 인덱싱을 목적으로 월드 와이드 웹을 탐색하는 것이고, 웹 스크래핑(web scraping)은 웹사이트에서 정보를 추출하는 것이다.

따라서 크롤 스파이더는 모든 웹 스크래핑 프로젝트에 적합하지 않을 수 있다.

사용 예: 여러 페이지를 자동으로 탐색하며 데이터를 추출할 때. ( 복잡한 작업 )
```

## `yield` 키워드 사용

```python
yield 키워드는 함수에서 값을 반환하는 방식으로, 함수의 로컬 변수를 유지한 채로 값을 반환할 수 있다
```

```python
예제)

def parse(self, response):
    for item in response.xpath('//item'):
        yield {
            'name': item.xpath('.//name/text()').get(),
            'price': item.xpath('.//price/text()').get(),
        }
```

### `yield`와 `return`의 차이점

```python
return

설명: 함수가 값을 반환하고 완전히 종료한다. 함수가 종료되면 다시 호출할 때 처음부터 시작한다.

비유: 한 번의 배달로 모든 물건을 한꺼번에 배달하는 것과 같다.

def get_numbers():
    return [1, 2, 3]

numbers = get_numbers()
print(numbers)  # 출력: [1, 2, 3]
```

```python
yield

설명: 함수가 값을 반환하고 멈춘 상태로 유지한다. 함수가 호출될 때마다 마지막에 멈춘 지점부터 다시 시작한다.

비유: 여러 번에 걸쳐 물건을 나누어 배달하는 것과 같다. 한 번에 하나씩 배달하고,

		  다음 배달을 위해서 다시 출발 지점으로 돌아가지 않고 멈춘 위치에서 시작한다.


def get_numbers():
    yield 1
    yield 2
    yield 3

numbers = get_numbers()
for number in numbers:
    print(number)


* get_numbers 함수는 한 번에 하나씩 값을 반환한다.

	이 함수는 1을 반환하고 멈춘 다음, 다음 호출에서 2를 반환하고 또 멈훈다. 이런 식으로 마지막 값 3까지 반복한다.
```

### `yield`의 작동 방식

```python
yield는 함수를 제너레이터로 만든다. 제너레이터는 값을 하나씩 생성해 내며, 호출할 때마다 이전 상태를 유지한다.

예제: )

def count_up_to(max):
    count = 1
    while count <= max:
        yield count
        count += 1

counter = count_up_to(3)
print(next(counter))  # 출력: 1
print(next(counter))  # 출력: 2
print(next(counter))  # 출력: 3

* 이 예제에서 일어나는 일:

1. count_up_to(3) 함수를 호출하면, 제너레이터 객체 counter가 생성됩니다. 이 객체는 아직 실행되지 않은 상태입니다.

2. next(counter)를 처음 호출하면:

	1. count_up_to 함수가 실행을 시작하고, count는 1로 초기화됩니다.

	2. while 루프가 실행되고, yield count가 실행됩니다.

	3. yield count는 1을 반환하고, 함수 실행은 멈춥니다. 이때 함수의 상태(변수 count의 값 등)는 저장됩니다.

3. 다시 next(counter)를 호출하면:

	1. 함수는 yield가 있던 지점 바로 다음 줄(count += 1)에서 실행을 재개합니다.

	2. count는 2로 증가합니다.

	3. 다시 while 루프가 실행되고, yield count가 실행됩니다.

	4. yield count는 2를 반환하고, 함수 실행은 또 멈춥니다. 이때도 함수의 상태는 저장됩니다.

4. 또 다시 next(counter)를 호출하면:

	1. 함수는 이전에 멈춘 지점(count += 1)에서 실행을 재개합니다.

	2. count는 3으로 증가합니다.

	3. 다시 while 루프가 실행되고, yield count가 실행됩니다.

	4. yield count는 3을 반환하고, 함수 실행은 다시 멈춥니다.
```

### 멈춘 지점에서 다시 시작하는 것의 의미

```python
def simple_generator():
    print("첫 번째 출력")
    yield 1
    print("두 번째 출력")
    yield 2
    print("세 번째 출력")
    yield 3

gen = simple_generator()

print(next(gen))  # 첫 번째 출력, 1
print(next(gen))  # 두 번째 출력, 2
print(next(gen))  # 세 번째 출력, 3

* yield에서 멈춘 후, 호출자가 next를 호출하면 바로 그 다음 줄부터 실행을 재개한다.

	이를 통해 상태를 기억하고, 중단된 지점에서 계속 진행할 수 있다.

	이처럼 yield는 함수 실행을 일시 중지하고, 필요할 때 다시 이어서 실행할 수 있게 해준다.

	이를 통해 데이터 생성 및 처리의 효율성을 높일 수 있다.
```

```python
1. next(gen) 호출 시, "첫 번째 출력"이 출력되고 yield 1에서 멈추며 1을 반환

2. 다시 next(gen) 호출 시, "두 번째 출력"이 출력되고 yield 2에서 멈추며 2를 반환

3. 또 다시 next(gen) 호출 시, "세 번째 출력"이 출력되고 yield 3에서 멈추며 3을 반환
```

### return, yield요약

```python
return은 샷건과 같다: 샷건은 한 번에 많은 탄환을 발사한다. 샷건을 발사하면 모든 탄환이 동시에 발사되고,

그 후에는 다시 장전해야 한다.( 한번에 모든 값을 반환한다. 함수가 종료되면 다시 호출할 때 처음부터 시작해야 한다. )

yield는 리볼버와 같다: 리볼버는 한 번에 한 발씩 탄환을 발사한다. 발사할 때마다 다음 탄환이 준비된다.

한 번 발사한 후에도 리볼버는 계속해서 다음 탄환을 발사할 준비가 되어 있다.

( 한 번에 하나씩 값을 반환한다. 함수가 멈췄다가 다시 호출될 때마다 이전 상태를 기억하고 다음 값을 반환한다. )
```

# 스파이더 만들기 ( Building a Spider )

```python

import scrapy

# 스파이더 클래스를 정의합니다. Scrapy의 Spider 클래스를 상속받습니다.
class FirstspiderSpider(scrapy.Spider):
    # 스파이더의 이름을 정의합니다. 이 이름은 스파이더를 실행할 때 사용됩니다.
    name = "firstspider"

    # 크롤링을 허용할 도메인을 정의합니다. 이 도메인 외의 URL은 크롤링하지 않습니다.
    allowed_domains = ["www.worldometers.info"]

    # 스파이더가 시작할 URL 리스트를 정의합니다. 이 URL에서 크롤링을 시작합니다.
    start_urls = ["https://www.worldometers.info/world-population/population-by-country/"]

    # 페이지를 파싱(분석)하는 메서드를 정의합니다. response는 페이지의 응답 객체입니다.
    def parse(self, response):
        # XPath를 사용하여 페이지의 타이틀(h1 요소의 텍스트)을 추출합니다.
        title = response.xpath('//h1/text()').get()

        # XPath를 사용하여 페이지의 모든 나라 이름(td > a 요소의 텍스트)을 추출합니다.
        countries = response.xpath('//td/a/text()').getall()

        # 추출한 데이터를 딕셔너리 형태로 반환합니다. 이 데이터는 이후에 저장되거나 처리될 수 있습니다.
        yield {
            'title': title,
            'countries': countries,
        }
```

# **상대 링크와 절대 링크 (** Relative vs Absolute Links )

```python
Scrapy를 사용해 웹 크롤링을 할 때 절대 링크(absolute link)와 상대 링크(relative link)를 모두 다룰 수 있다.
```

```python
import scrapy

# FirstspiderSpider 클래스는 scrapy.Spider를 상속받아 생성한 스파이더 클래스입니다.
class FirstspiderSpider(scrapy.Spider):
    # 스파이더 이름 설정. 이 이름은 스파이더를 실행할 때 사용됩니다.
    name = "firstspider"

    # 크롤링할 도메인을 설정. 이 도메인 외의 사이트는 크롤링하지 않습니다.
    allowed_domains = ["www.worldometers.info"]

    # 시작할 URL 리스트 설정. 이 URL들에서 크롤링을 시작합니다.
    start_urls = ["https://www.worldometers.info/world-population/population-by-country/"]

    # 스크랩한 데이터를 처리할 parse 함수 정의
    def parse(self, response):
        # 사이트의 제목을 가져오는 코드 (현재 주석 처리됨)
        # title = response.xpath('//h1/text()').get()

        # 모든 국가 링크를 가져오는 XPath 표현식. 'td' 태그 내 'a' 태그를 선택합니다.
        countries = response.xpath('//td/a')

        # 각 국가에 대해 반복 처리
        for country in countries:
            # 국가 이름을 가져옴. 'a' 태그 내의 텍스트를 선택합니다.
            country_name = country.xpath(".//text()").get()

            # 국가 페이지로의 상대 링크를 가져옴. 'a' 태그의 'href' 속성을 선택합니다.
            link = country.xpath(".//@href").get()

            # 절대 링크 생성 (현재 주석 처리됨)
            # 절대 링크를 f-string을 사용해 직접 생성
            # absolute_url = f'https://www.worldometers.info/{link}'

            # Scrapy의 urljoin 메서드를 사용해 절대 링크 생성
            # absolute_url = response.urljoin(link)

            # 절대 링크를 사용해 새로운 요청을 생성하고 이를 스케줄링 (현재 주석 처리됨)
            # yield scrapy.Request(url=absolute_url)

            # 상대 링크를 사용해 새로운 요청을 생성하고 이를 스케줄링
            # response.follow는 상대 링크를 받아 절대 링크로 변환하여 요청을 생성
            yield response.follow(url=link)
```

## 1.절대 링크 vs 상대 링크

```python
절대 링크:

브라우저 주소창에 표시되는 전체 주소이다. 예를 들어, https://www.worldometers.info/world-population/population-by-country/.

상대 링크:

전체 주소의 일부만 포함된 링크이다. 예를 들어, /world-population/population-by-country/.
```

## 2.절대 링크와 상대 링크 처리하기

### 1. 절대 링크 만들기

```python
우리는 상대 링크를 절대 링크로 변환하여 사용할 수 있다

# 상대 링크
link = country.xpath(".//@href").get()

# 절대 링크 만들기 (방법 1)
absolute_url = f'https://www.worldometers.info/{link}'

# 절대 링크 만들기 (방법 2 - Scrapy의 urljoin 사용)
absolute_url = response.urljoin(link)

# Scrapy 요청 생성
yield scrapy.Request(url=absolute_url)

* start_urls로 제공된 URL (https://www.worldometers.info/world-population/population-by-country/)이 초기 기준 URL

	urljoin 메서드는 기준 URL과 상대 URL을 결합하여 절대 URL을 생성한다.

	예를 들어, 기준 URL이 https://www.worldometers.info/world-population/population-by-country/이고

	상대 URL이 '/world-population/china-population/'일 경우, 결과는 https://www.worldometers.info/world-population/china-population/가 된다.
```

### 2. Scrapy의 `response.follow` 사용

```python
Scrapy는 상대 링크를 쉽게 처리할 수 있는 response.follow 메서드를 제공한다

# Scrapy의 follow 메서드를 사용하여 상대 링크 처리
yield response.follow(url=link)

* response.follow는 Scrapy에서 상대 URL을 절대 URL로 변환하고,

	해당 URL에 새로운 요청을 생성하는 데 사용

	이 메서드는 기준 URL과 상대 URL을 결합하여 절대 URL을 생성하고, 새로운 요청을 만들어 반환한다
```

### 예제

```python
import scrapy

class ExampleSpider(scrapy.Spider):
    name = "example"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com"]

    def parse(self, response):
        # 'Next' 링크를 찾기 위해 XPath 사용
        next_page = response.xpath('//a[@rel="next"]/@href').get()

        # 상대 URL을 절대 URL로 변환하고 새로운 요청 생성
        if next_page:
            yield response.follow(next_page, callback=self.parse_next)

    def parse_next(self, response):
        # 다음 페이지에서 데이터를 추출하는 로직
        self.log("Visited " + response.url)

 * 이 예제에서 response.follow는 next_page라는 상대 URL을 절대 URL로 변환하고,

	 새로운 요청을 생성 새로운 요청이 성공적으로 완료되면, callback으로 지정된 parse_next 메서드가 호출된다.
```

```python

2. 상대 링크 처리: Scrapy의 response.follow 메서드를 사용하여 상대 링크를 직접 처리했다.
```

# **여러 링크에서 데이터 스크래핑 (** Scraping Data from Multiple Links )

```python
Scrapy를 사용하여 여러 페이지에서 데이터를 스크래핑하는 방법을 배운다.

각 페이지에는 특정 국가의 인구 데이터가 포함되어 있다. 목표는 각 국가 페이지에서 데이터를 스크래핑하여 JSON 파일에 저장하는 것
```

```python
import scrapy

class FirstspiderSpider(scrapy.Spider):
    name = "firstspider"  # 스파이더의 이름을 정의합니다. 이 이름을 사용하여 스파이더를 실행할 수 있습니다.
    allowed_domains = ["www.worldometers.info"]  # 스파이더가 요청을 보낼 수 있는 도메인을 정의합니다.
    start_urls = ["https://www.worldometers.info/world-population/population-by-country/"]  # 스파이더가 크롤링을 시작할 초기 URL 목록을 정의합니다.

    def parse(self, response):
        """
        초기 URL에서 호출되는 함수입니다. 각 국가의 링크를 추출하여
        각 국가의 페이지로 이동하는 요청을 만듭니다.
        """
        # 페이지에서 모든 국가 링크를 선택합니다.
        countries = response.xpath('//td/a')

        for country in countries:
            # 각 국가의 이름을 추출합니다.
            country_name = country.xpath(".//text()").get()
            # 각 국가의 상세 페이지 링크를 추출합니다.
            link = country.xpath(".//@href").get()

            # 절대 URL을 사용하는 방법
            # absolute_url = f'https://www.worldometers.info/{link}'
            # absolute_url = response.urljoin(link)
            # yield scrapy.Request(url=absolute_url)

            # 상대 URL을 사용하는 방법
            # response.follow는 상대 URL을 절대 URL로 자동 변환합니다.
            # 'callback' 매개변수를 사용하여 각 요청이 완료되었을 때 호출될 함수를 지정합니다.
            # 'meta' 매개변수를 사용하여 국가 이름을 다음 요청에 전달합니다.
            yield response.follow(url=link, callback=self.parse_country, meta={'country': country_name})

    def parse_country(self, response):
        """
        각 국가의 상세 페이지에서 호출되는 함수입니다.
        해당 국가의 인구 데이터를 스크래핑합니다.
        """
        # 전달된 meta 데이터를 사용하여 국가 이름을 가져옵니다.
        country = response.request.meta['country']
        # 인구 데이터가 포함된 테이블의 모든 행을 선택합니다.
        rows = response.xpath("(//table[contains(@class,'table')])[1]/tbody/tr")

        for row in rows:
            # 각 행에서 연도를 추출합니다.
            year = row.xpath(".//td[1]/text()").get()
            # 각 행에서 인구 데이터를 추출합니다.
            population = row.xpath(".//td[2]/strong/text()").get()

            # 추출된 데이터를 딕셔너리 형태로 반환합니다.
            yield {
                'country': country,
                'year': year,
                'population': population,
            }
```

## 1. 초기 설정 및 함수 정의

```python
스파이더를 설정하고 parse 함수를 정의한다. 이 함수는 국가 목록 페이지에서 각 국가의 링크를 추출한다
```

```python
import scrapy

class FirstspiderSpider(scrapy.Spider):
    name = "firstspider"
    allowed_domains = ["www.worldometers.info"]
    start_urls = ["https://www.worldometers.info/world-population/population-by-country/"]

    def parse(self, response): # self: Scrapy 스파이더 클래스 자체를 가리킨다 , response: 초기 요청에 대한 응답을 나타내는 객체
        countries = response.xpath('//td/a')

        for country in countries:
            country_name = country.xpath(".//text()").get()
            link = country.xpath(".//@href").get()
            yield response.follow(url=link, callback=self.parse_country, meta={'country': country_name})
```

### Scrapy의 `parse` 메서드

```python
Scrapy의 스파이더 클래스에서 parse 메서드는 초기 요청을 처리하고,

각 응답에 대한 처리 로직을 정의하는 메서드이다.

이 메서드는 반드시 정의해야 하며, 스파이더가 크롤링을 시작하는 진입점 역할을 한다
```

### `meta` 매개변수

```python

메타(meta) 매개변수는 Scrapy에서 요청(request)과 응답(response) 사이에서 데이터를 전달하거나 추가 정보를 담을 수 있는 공간이다.

이 매개변수는 주로 다음과 같은 상황에서 사용된다:

1. 데이터 전달:

한 페이지에서 추출한 정보를 다음 페이지의 처리 함수로 전달할 때 사용한다.

2. 추가 정보 전송:

요청이나 응답에 대한 추가적인 정보를 전달할 수 있다. 예를 들어, 어떤 페이지에서 이 요청이 생성되었는지, 특정 설정 값을 전달할 수 있다.

yield response.follow(url=link, callback=self.parse_country, meta={'country': country_name})

* parse 메서드는 초기 URL에서 국가 목록을 추출하고, 각 국가 페이지로 이동하여 parse_country 메서드로 인구 데이터를 추출한다.

	response.follow에서 meta 매개변수를 사용하여 각 국가 페이지에 대한 국가 이름을 전달하고,

	parse_country 메서드에서 이를 사용하여 데이터를 추출한다.
```

## 2. 각 국가 페이지에서 데이터 추출

```python
각 국가 페이지에 대해 데이터를 추출하는 parse_country 함수를 정의한다.

이 함수는 전달된 메타 데이터를 사용하여 국가 이름을 가져오고, 페이지 내의 테이블에서 인구 데이터를 추출한다
```

```python
def parse_country(self, response):
    country = response.request.meta['country']
    rows = response.xpath("(//table[contains(@class,'table')])[1]/tbody/tr")

    for row in rows:
        year = row.xpath(".//td[1]/text()").get()
        population = row.xpath(".//td[2]/strong/text()").get()

        yield {
            'country': country,
            'year': year,
            'population': population,
        }
```
