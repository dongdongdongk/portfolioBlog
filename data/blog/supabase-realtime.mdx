# { 1. Supabase Realtime이란? }

## 1.1. 개념

```jsx
Supabase Realtime은 Supabase의 PostgreSQL 데이터베이스에서 특정 테이블의 데이터 변화(예: 새 데이터 추가, 수정, 삭제)를 실시간으로 감지해 클라이언트에 전송하는 기능입니다.

이를 통해 사용자들은 서버에 별도로 요청하지 않아도 데이터를 즉시 받아볼 수 있습니다.

비유 없이 쉽게 설명:

데이터베이스는 데이터를 저장하는 창고입니다.

Supabase Realtime은 창고에 새 물건(데이터)이 추가되거나 바뀌면 즉시 클라이언트(사용자의 브라우저)에 "새 물건 들어왔어요!"라고 알리는 메신저입니다.

TalentSwap에서는 새 메시지가 데이터베이스에 추가되면, 상대방의 화면에 즉시 표시되도록 합니다.
```

## 1.2. 역할

```jsx
실시간 메시지 업데이트: 사용자 A가 메시지를 보내면 사용자 B의 화면에 즉시 표시.

알림 시스템: 새 메시지가 도착하면 헤더의 종 모양 아이콘에 빨간 점 표시.

효율성: 서버에 주기적으로 데이터를 요청(polling)하지 않고, WebSocket을 통해 변화만 전송.
```

## 1.3. 사용 기술

```jsx
WebSocket: 클라이언트와 서버 간의 지속적인 연결을 유지해 실시간 데이터 전송.

PostgreSQL의 LISTEN/NOTIFY: 데이터베이스에서 변화가 발생하면 이벤트를 발생시킴.

Supabase 클라이언트: JavaScript/TypeScript로 작성된 클라이언트 라이브러리를 통해 쉽게 설정.
```

# { 2. 어떻게 동작하는가? }

## 2.1. 동작 원리

```jsx
Supabase Realtime은 WebSocket을 통해 데이터베이스와 클라이언트를 연결합니다. 동작 흐름은 다음과 같습니다:

1. 클라이언트가 구독 시작:

		클라이언트(브라우저)가 특정 테이블(예: messages)의 변화를 감지하도록 Supabase에 요청.

		예: "특정 채팅방의 새 메시지를 알려줘!"

2. 데이터베이스 변화 감지:

		PostgreSQL 데이터베이스에서 INSERT(추가), UPDATE(수정), DELETE(삭제) 같은 변화가 발생.

		Supabase는 이를 postgres_changes 이벤트로 포착.

3. 실시간 알림 전송:

		WebSocket을 통해 구독 중인 클라이언트에 변화 데이터를 전송.

		데이터는 JSON 형태로 전달됨 (예: 새 메시지의 내용, ID 등).

4. 클라이언트에서 처리:

		클라이언트는 받은 데이터를 화면에 반영 (예: 새 메시지를 채팅창에 추가).
```

## 2.2. TalentSwap에서의 예

```jsx
사용자 A가 메시지를 보내면, messages 테이블에 새 행이 추가됨.

Supabase Realtime이 이를 감지해 사용자 B에게 알림.

사용자 B의 Next.js 앱이 새 메시지를 받아 채팅창에 즉시 표시.
```

## 3.2. 채널 생성 및 구독

```jsx
Supabase Realtime은 채널(channel)을 통해 특정 데이터를 구독합니다.

채널은 WebSocket 연결의 특정 주제(topic)라고 생각하면 됩니다.
```

```jsx
const channel = supabase
  .channel('channel-name') // 고유한 채널 이름
  .on(
    'postgres_changes', // 이벤트 타입
    {
      event: 'INSERT', // 감지할 이벤트 (INSERT, UPDATE, DELETE 등)
      schema: 'public', // 데이터베이스 스키마
      table: 'table-name', // 대상 테이블
      filter: 'column=eq.value', // 필터 조건 (선택)
    },
    (payload) => {
      // 변화 발생 시 실행될 콜백 함수
      console.log('변화 발생:', payload)
    }
  )
  .subscribe() // 구독 시작
```

```jsx
.channel('channel-name'): 고유한 채널 이름을 지정 (예: messages:chat123).

.on('postgres_changes', ...): PostgreSQL의 변화 이벤트를 감지.

		event: 감지할 변화 타입 (INSERT, UPDATE, DELETE, 또는 *로 모두 감지).

		schema: 테이블이 속한 스키마 (보통 public).

		table: 대상 테이블 (예: messages).

		filter: 특정 조건에 맞는 변화만 감지 (예: chat_id=eq.chat123).

.subscribe(): WebSocket 연결을 시작해 구독 활성화.
```


```jsx
const channel = supabase
  .channel('channel-name')
  .on('postgres_changes', { ... }, (payload) => { ... })
```

## 4.1. 채팅방 메시지 실시간 업데이트

```jsx
상황: 사용자가 특정 채팅방(/chat/[id])에 있을 때, 상대방이 보낸 메시지를 즉시 화면에 표시.
```

```jsx
import { useState, useEffect } from 'react';
import { createClient } from '@supabase/supabase-js';

const supabase = createClient('https://your-project.supabase.co', 'your-public-anon-key');

export function useChat(chatId?: string) {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    if (!chatId) return;

    // 특정 채팅방 메시지 구독
    const channel = supabase
      .channel(`messages:${chatId}`)
      .on(
        'postgres_changes',
        {
          event: 'INSERT',
          schema: 'public',
          table: 'messages',
          filter: `chat_id=eq.${chatId}`,
        },
        (payload) => {
          // 자신이 보낸 메시지는 제외 (Optimistic Update로 이미 표시됨)
          if (payload.new.sender_id !== 'current_user_id') {
            setMessages((prev) => [...prev, payload.new]);
          }
        }
      )
      .subscribe((status) => {
        console.log('구독 상태:', status);
      });

    // 컴포넌트 언마운트 시 구독 정리
    return () => {
      supabase.removeChannel(channel);
    };
  }, [chatId]);

  return { messages, setMessages };
}
```

```jsx
동작 순서:

		1. Next.js 컴포넌트(/app/chat/[id]/page.tsx)에서 useChat 훅을 호출.

		2. chatId가 제공되면, 해당 채팅방의 메시지 구독 시작.

		3. 새 메시지가 messages 테이블에 추가되면, payload.new를 받아 messages 상태에 추가.

		4. 자신이 보낸 메시지는 제외 (Optimistic Update로 이미 화면에 표시됨).

		5. 컴포넌트가 언마운트되면(useEffect의 cleanup 함수), 구독을 정리해 메모리 누수 방지.

Next.js와의 통합:

		useEffect는 클라이언트 컴포넌트('use client')에서 실행.

		동적 라우팅(/chat/[id])에서 chatId를 params.id로 가져옴.
```

## 4.2. 새 메시지 알림

```jsx
상황: 사용자가 채팅방 밖에 있을 때, 새 메시지가 도착하면 헤더의 종 모양 아이콘에 알림 표시.
```

```jsx
import { useState, useEffect } from 'react';
import { createClient } from '@supabase/supabase-js';

const supabase = createClient('https://your-project.supabase.co', 'your-public-anon-key');

export function useNotifications(userId: string) {
  const [notifications, setNotifications] = useState([]);
  const [unreadCount, setUnreadCount] = useState(0);

  useEffect(() => {
    if (!userId) return;

    // 모든 메시지 감지 (전역 구독)
    const channel = supabase
      .channel(`user-notifications-${userId}`)
      .on(
        'postgres_changes',
        {
          event: 'INSERT',
          schema: 'public',
          table: 'messages',
        },
        (payload) => {
          if (payload.new.sender_id !== userId) {
            const newNotification = {
              id: `notif-${Date.now()}`,
              type: 'chat_message',
              title: 'New Message',
              message: payload.new.content,
              chatId: payload.new.chat_id,
            };
            setNotifications((prev) => [newNotification, ...prev]);
            setUnreadCount((prev) => prev + 1);
          }
        }
      )
      .subscribe();

    return () => supabase.removeChannel(channel);
  }, [userId]);

  const markAsRead = (notificationId: string) => {
    setNotifications((prev) => prev.filter((notif) => notif.id !== notificationId));
    setUnreadCount((prev) => prev - 1);
  };

  return { notifications, unreadCount, markAsRead };
}
```

```jsx
동작 순서:

		1. useNotifications 훅이 사용자 ID(userId)를 받아 전역 메시지 구독 시작.

		2. messages 테이블에 새 메시지가 추가되면, 발신자가 자신이 아닌 경우 알림 생성.

		3. 알림을 notifications 상태에 추가하고, unreadCount 증가.

		4. 알림 클릭 시 markAsRead로 읽음 처리 및 카운트 감소.

		5. 컴포넌트 언마운트 시 구독 정리.

Next.js와의 통합:

		/src/components/common/NotificationDropdown.tsx에서 사용.

		알림 클릭 시 window.location.href로 /chat/[chatId]로 이동.
```

```jsx
    return [...prev, newMessage];
  });
};
```

```jsx
메시지 ID로 중복 체크.

자신이 보낸 메시지는 제외
```

```jsx
if (newMessage.sender_id === userId) return
```

```jsx
Supabase Realtime은 TalentSwap 채팅 시스템에서 메시지와 알림을 실시간으로 처리하는 핵심 기술입니다. 주요 포인트는 다음과 같습니다:
```
