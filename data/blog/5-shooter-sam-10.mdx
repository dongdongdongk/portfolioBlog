## 🔧 Step 3: Blackboard 값 설정

### 3-1: SetValueAsVector

**전체 코드:**

```cpp
void AShooterAI::StartBehaviorTree(AShooterSamCharacter* Player)
{
    if (EnemyAIBehaviorTree)
    {
        MyCharacter = Cast<AShooterSamCharacter>(GetPawn());
        if (Player)
        {
            PlayerCharacter = Player;
        }

        RunBehaviorTree(EnemyAIBehaviorTree);

        // ===== Blackboard 설정 =====
        UBlackboardComponent* MyBlackboard = GetBlackboardComponent();

        if (MyBlackboard && PlayerCharacter && MyCharacter)
        {
            // 플레이어 위치 저장
            MyBlackboard->SetValueAsVector(
                "PlayerLocation",
                PlayerCharacter->GetActorLocation()
            );

            // 시작 위치 저장
            MyBlackboard->SetValueAsVector(
                "StartLocation",
                MyCharacter->GetActorLocation()
            );
        }
    }
}
```

---

### 3-2: SetValueAsVector 분석

**함수 시그니처:**

```cpp
void SetValueAsVector(

    FVector VectorValue // 저장할 Vector
```


**타입: FName**

# { 범위 기반 for 루프 (Range-based for loop) }

## 🎯 핵심 요약

**같은 기능, 더 짧은 코드!**

```cpp
// 기존 for 루프 (길다)
for (int32 i = 0; i < Array.Num(); i++)
{
    AActor* Actor = Array[i];
}

// 범위 기반 for 루프 (짧다!)
for (AActor* Actor : Array)
{
    // Actor 바로 사용!
}
```

---

## 📝 문법

### 기본 형태

```cpp
for (타입 변수명 : 배열)
{
    // 변수 사용
}
```

---

### 실제 예제

**우리 코드:**

```cpp
// 기존 방식 (주석 처리)
/*
for (int32 LoopIndex = 0; LoopIndex < ShooterAIActors.Num(); LoopIndex++)
{
    AActor* ShooterAIActor = ShooterAIActors[LoopIndex];
    AShooterAI* ShooterAI = Cast<AShooterAI>(ShooterAIActor);
    if (ShooterAI)
    {
        ShooterAI->StartBehaviorTree(Player);
    }
}
*/

// 범위 기반 방식 (더 짧음!)
for (AActor* ShooterAIActor : ShooterAIActors)
{
    AShooterAI* ShooterAI = Cast<AShooterAI>(ShooterAIActor);
    if (ShooterAI)
```

## 🔍 차이점 비교

### 기존 for 루프

```cpp
for (int32 i = 0; i < ShooterAIActors.Num(); i++)
{
    AActor* Actor = ShooterAIActors[i];
    // ↑ 인덱스로 직접 접근
}
```

**필요한 것:**

```
✓ 인덱스 변수 (i)
✓ 조건 (i < Num())
✓ 증가 (i++)
✓ 배열 인덱싱 [i]
```

---

### 범위 기반 for 루프

```cpp
for (AActor* Actor : ShooterAIActors)
{
    // Actor 바로 사용!
}
```

**자동으로 처리:**

```
✓ 인덱스 (숨김)
✓ 조건 (자동)
✓ 증가 (자동)
✓ 인덱싱 (자동)
```

---

## 💡 장단점

### 장점 ✅

```
1. 코드가 짧음
2. 읽기 쉬움
3. 실수 적음 (인덱스 오류 없음)
4. 타이핑 적음
```

---

### 단점 ❌

```
1. 인덱스 없음
   → i 값 필요하면 못 씀

2. 거꾸로 못 돌림
   → 역순 불가

3. 2개씩 건너뛰기 못 함
   → i += 2 불가

4. 유연성 낮음
   → 처음부터 끝까지만 가능
```

## ✅ 요약

**범위 기반 for 루프 = 짧고 간단한 for 루프**

```cpp
// 기존

{
    Type Item = Array[i];
}

// 범위 기반
for (Type Item : Array)
{
    // 끝!
}
```

# { Sequence 노드와 Wait Task }

## 🎯 이번에 할 것

**AI가 왔다갔다 반복하게 만들기!**

```
시작 위치
    ↓
플레이어 위치로 이동
    ↓
3초 대기
    ↓
시작 위치로 복귀
    ↓
3초 대기
    ↓
반복! 🔄
```

## 🎨 Behavior Tree 노드 종류

### 2가지 주요 타입

**1. Composite Nodes (복합 노드) - 회색**

```
흐름 제어
→ 어떤 순서로?
→ 어떤 조건으로?

종류:
  - Sequence (순차)
  - Selector (선택)
  - Simple Parallel (병렬)
```

**역할:**

```
직접 행동 X
자식 노드들을 제어만 함
→ 감독자 역할
```

---

**2. Task Nodes (작업 노드) - 보라색**

```
실제 행동
→ 이동하기
→ 쏘기
→ 대기하기

예시:
  - Move To
  - Wait
  - Play Sound
  - Play Animation
```

**역할:**

```
실제로 뭔가 함
→ 일꾼 역할
```

## 🔄 Sequence 노드 상세

### Sequence란?

**"순서대로 하나씩 실행"**

```
Sequence
  ├─ Task 1
  ├─ Task 2
  └─ Task 3

실행 순서:
  1 → 2 → 3
```

---

### 실행 규칙

**1. 왼쪽에서 오른쪽으로**

```
Sequence
  ├─ 1️⃣ Move To Player
  ├─ 2️⃣ Wait
  ├─ 3️⃣ Move To Start
  └─ 4️⃣ Wait

순서대로 실행!
```

**노드 번호:**

```
각 노드 위 동그라미 안 숫자
→ 실행 순서 표시
→ 1, 2, 3, 4...
```

---

**2. 실패하면 중단**

```
Sequence
  ├─ Task 1 → 성공 ✅
  ├─ Task 2 → 실패 ❌
  ├─ Task 3 (실행 안 됨)
  └─ Task 4 (실행 안 됨)

Task 2 실패
  ↓
Sequence 중단
  ↓
Root로 복귀
  ↓
처음부터 다시 시작
```

---

**3. 모두 성공해야 성공**

```
Sequence
  ├─ Task 1 → 성공 ✅
  ├─ Task 2 → 성공 ✅
  ├─ Task 3 → 성공 ✅
  └─ Task 4 → 성공 ✅

모두 성공!
  ↓
Sequence 성공 ✅
  ↓
Root로 복귀
  ↓
다음 프레임에 다시 시작
```

## ⏱️ Wait Task

### Wait 노드란?

**"지정된 시간만큼 대기"**

```
Wait (3초)
  ↓
3초 동안 멈춤
  ↓
완료 (성공) ✅
```

---

### Wait 노드 설정

**생성:**

```
1. 우클릭
2. Tasks 섹션
3. "Wait" 선택
```

**설정:**

```
Details 패널:
  Wait Time: 3.0 (초 단위)

  Random Deviation: 0.0
    → 랜덤 시간 추가 (선택)
    → 0.5면 ±0.5초 랜덤
```

---

### 예시

**3초 대기:**

```
Wait Time: 3.0
  ↓
항상 정확히 3초
```

**2~4초 랜덤 대기:**

```
Wait Time: 3.0
Random Deviation: 1.0
  ↓
3 ± 1초 = 2~4초 랜덤
```

## 📚 핵심 개념 정리

### Root 노드

```
시작점
→ 매 프레임 실행
→ 자식은 1개만 (항상 Composite)
```

### Sequence 노드

```
순차 실행
→ 왼쪽에서 오른쪽
→ 실패하면 중단
→ 모두 성공해야 성공
```

### Task 노드

```
실제 행동
→ Move To: 이동
→ Wait: 대기
→ 성공/실패 반환
```

### 성공/실패

```
성공 ✅: 다음 Task로
실패 ❌: Sequence 중단
```

## 💡 실전 팁

### Sequence 자식 순서 변경

**드래그로 순서 조정:**

```
Task를 좌우로 드래그
  ↓
순서 바뀜
  ↓
번호도 자동 업데이트
```

---

### Wait 활용

**전투 대기:**

```
공격
  ↓
Wait (1초)
  ↓
다음 공격
```

**순찰 대기:**

```
순찰 지점 도착
  ↓
Wait (5초)
  ↓
다음 순찰 지점
```

---

### Sequence vs Selector

**Sequence (AND):**

```
모두 성공해야 함
→ Task1 AND Task2 AND Task3
→ 순차적 행동
```

**Selector (OR) - 다음 강의:**

```
하나만 성공하면 됨
→ Task1 OR Task2 OR Task3
→ 선택적 행동
```
