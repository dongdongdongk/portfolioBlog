# 세션 설명

## **세션 개념 소개**

```jsx

세션은 쿠키와 유사한 개념으로, HTTP와 같이 무상태 프로토콜에서 상태를 유지할 수 있게 해주는 기술이다.

주로 한 요청에서 다음 요청으로 정보를 전달하거나 공유하는 데 사용된다.

세션은 데이터를 영구적으로 저장하는 것이 아니라, 브라우저 세션 동안만 상태를 유지한다. ( 데이터 베이스와 차이 )
```

## 세션의 원리

```jsx
세션은 일반적으로 쿠키를 사용하여 동작한다.

세션을 구현할 때 서버는 클라이언트(브라우저)에게 세션 ID를 쿠키로 전송한다.

이 세션 ID를 사용하여 브라우저는 세션에 대한 유일한 식별자를 가지게 되고, 서버는 이 세션 ID를 통해 세션 데이터를 식별한다.

일반적으로 세션 쿠키는 브라우저가 종료되거나 사용자가 로그아웃할 때까지 유지된다.

이러한 방식으로 세션은 한 요청에서 다음 요청으로 정보를 전달하고 유지할 수 있게 된다.

세션 쿠키는 보안적인 이유로 HTTPOnly 속성을 가지고 있어서 JavaScript에서 접근할 수 없도록 설계되어 있다.

따라서 세션은 쿠키를 통해 브라우저와 서버 간에 상태를 유지하고 데이터를 전달한다.
```

## **쿠키와 세션의 차이**

```jsx
쿠키는 브라우저에 저장되고, 세션은 서버 측에 저장된다.

쿠키는 브라우저의 크기 제한과 보안 이슈가 있지만, 세션은 서버 측에서 안전하게 데이터를 관리한다.

세션은 데이터베이스를 대체할 수 없으며, 주로 브라우저와 연결된 정보를 저장하기 위해 사용된다.
```

## **세션의 활용 예시**

```jsx
사용자의 로그인 상태, 사용자의 이름, 장바구니 정보 등을 세션을 통해 추적할 수 있다.

세션은 브라우저에 저장되는 것이 아니라 세션 ID만을 쿠키로 브라우저에 전달하여 상태를 유지한다.
```

## **세션의 구조**

```jsx
세션은 서버 측에 저장되며, 데이터 저장소를 통해 사용자 정보를 관리한다.

세션 ID는 브라우저에 쿠키로 저장되고, 이를 통해 서버는 세션 데이터를 찾아와 사용자 정보를 유지한다.
```

## **세션과 데이터베이스의 차이**

```jsx
세션은 주로 브라우저와 연결된 정보를 임시로 저장하는 용도로 사용되며, 데이터베이스와는 다르다.

데이터베이스는 영구적으로 데이터를 저장하고 관리하는데 사용되지만, 세션은 브라우저 세션 동안만 필요한 정보를 관리한다.
```

## 세션을 이용해서 조회수 추적하기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381413/notion-blog/_/The_Web_Developer_2022/node_js/_/Untitled_4.png)

```jsx
const express = require('express')
const session = require('express-session')

const app = express()

// Express 세션 미들웨어 설정
const sessionOptions = {
  secret: 'thisisnotagoodsecret', // 세션을 암호화하는 데 사용되는 키
  resave: false, // 세션 데이터가 변경되지 않아도 항상 저장 여부를 설정
  saveUninitialized: false, // 초기화되지 않은 세션도 저장 여부를 설정
}
// 이후에 세션을 활용한 기능을 추가할 수 있음

// 예시: 페이지 조회 수 세션 기록
app.get('/viewcount', (req, res) => {
  if (req.session.count) {
    req.session.count += 1
  } else {
    req.session.count = 1
  }
  res.send(`You have viewed this page ${req.session.count} times`)
})

// 앱을 포트 3000에서 실행
app.listen(3000, () => {
  console.log('Server is running on port 3000')
})
```

```jsx
이제 /viewcount 엔드포인트를 통해 세션을 사용하여 페이지 조회 수를 추적할 수 있다.

페이지를 새로고침할 때마다 조회 수가 증가하며, 각 브라우저는 고유한 세션 ID를 갖게 된다.

( 쿠키는 세션 내의 어떠한 정보도 포함하지 않는다는 걸 기억 )

Express 세션은 기본적으로 메모리에 데이터를 저장한다. ( 현재 count 도 메모리에 저장중 )

프로덕션에서는 이를 개선하기 위해 다양한 세션 저장소(예: Redis, MongoDB)를 사용할 수 있다.
```

```jsx
전송하는 정보는 오직 세션 ID이고

이는 다음에 오는 후속 요청에 서버로 함께 전송된다 ( 다음 req )

이제 세션 ID를 서버로 전송하면 Express 측에서

세션 패키지 Express 세션은 쿠키를 가져와서 일단은 변조되지 않았다는 걸 확인한다

유효한 세션 ID라면 세션 저장소 안을 살펴서 그 ID에 해당하는 정보를 찾으려고 할 거다

만약 그렇다면 req.session.count에 접근하게 된다
```

```jsx
const express = require('express')
const session = require('express-session')

const app = express()

const sessionOptions = {
  secret: 'thisisnotagoodsecret', // 세션을 암호화하는 데 사용되는 키
  resave: false, // 세션 데이터가 변경되지 않아도 항상 저장 여부를 설정
  saveUninitialized: false, // 초기화되지 않은 세션도 저장 여부를 설정
}
// Express 세션 미들웨어 설정
app.use(session(sessionOptions))

// 이후에 세션을 활용한 기능을 추가할 수 있음

// 예시: 페이지 조회 수 세션 기록
app.get('/viewcount', (req, res) => {
  if (req.session.count) {
    req.session.count += 1
  } else {
    req.session.count = 1
  }
  res.send(`You have viewed this page ${req.session.count} times`)
})

app.get('/register', (req, res) => {
  const { username = 'Anonymous' } = req.query // // 쿼리 문자열에서 'username' 값을 받아오고, 없으면 'Anonymous'로 설정
  req.session.username = username // 세션에 'username' 속성으로 저장
  res.send('register')
})

app.get('/greet', (req, res) => {
  const { username } = req.session // 세션에서 'username' 값을 가져오기
  res.send(`Welcome ${username}`)
})

// 앱을 포트 3000에서 실행
app.listen(3000, () => {
  console.log('Server is running on port 3000')
})
```

```jsx
**세션에 사용자 이름 등록**

"/register" 엔드포인트 추가

사용자 이름을 세션에 저장하고, 존재하지 않으면 "Anonymous"로 설정

**환영 메시지 업데이트**

"/greet" 엔드포인트 세션에서 사용자 이름을 가져와 환영 메시지 표시

( 만약 /register 로 가지않고 ( 세션 등록 없이 ) 바로 greet 로 가면 undefined 출력 )
```

```jsx
플래시는 세션에서 사용자에게 메시지를 전달하는 용도로 사용됨.

성공 메시지, 확인 메시지 등 한 번 뜨고 사라지는 메시지를 다룸.

* 리액트가 나오고 나서 플래시는 인기가 없어졌다
```

## 예제

### **새로운 농장 생성 라우트**

```jsx
app.post('/create-farm', (req, res) => {
  // 농장 생성 로직 수행...

  // 성공 메시지 설정
  req.flash('success', 'Successfully made a new farm!')

  // /farms 페이지로 리다이렉트
  res.redirect('/farms')
})
```

### **/farms 페이지 렌더링 라우트**

```jsx
app.get('/farms', (req, res) => {
  // 플래시 메시지를 가져옴
  const successMessage = req.flash('success')

  // farms 페이지 렌더링
  res.render('farms', { successMessage })
})
```
