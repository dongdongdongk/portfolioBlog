# { 블루프린트 기초 - 레벨 블루프린트 체험 }

## 🎯 이번에 할 것

레벨 블루프린트로 첫 스크립트 만들기!

```
블루프린트 열기
  ↓
Print String으로 메시지 출력
  ↓
Begin Play, Event Tick 이해
  ↓
Delta Seconds 활용
```

---

## 📋 블루프린트 두 가지 종류

### 1. 블루프린트 클래스

- 재사용 가능한 오브젝트
- 캐릭터, 무기, 아이템 등

### 2. 레벨 블루프린트 ⭐ (오늘 배울 것!)

- 각 레벨마다 하나씩 존재
- 해당 레벨에서만 작동
- 레벨 전체 이벤트 관리

---

## 🚪 레벨 블루프린트 열기

### 방법

```
1. 상단 툴바에서 아이콘 찾기
2. 드롭다운 클릭
3. "레벨 블루프린트 열기" 선택
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380709/notion-blog/_/_/_5_/_2_/image.png)

### 블루프린트 에디터 구성

```
┌─────────────────────────────┐
│  이벤트 그래프 (메인)        │ ← 노드 작업 공간
│  - 마우스 우클릭: 이동       │
│  - 휠: 확대/축소            │
└─────────────────────────────┘

┌──────────────┐  ┌──────────────┐
│ 내 블루프린트  │  │  세부 정보    │
│ - 노드 목록   │  │ - 선택 항목   │
│ - 그래프 구조  │  │   상세 정보   │
└──────────────┘  └──────────────┘
```

## 🖨️ Print String - 첫 번째 노드!

### Print String이란?

```
화면에 디버그 메시지 출력
  ↓
개발자만 보는 메시지
  ↓
코드가 작동하는지 확인용
```

### 노드 만들기

```
1. 이벤트 그래프에서 우클릭
2. 검색창에 "print" 입력
3. "Print String" 선택
```

### Print String 구조

```
[Print String]
  ├─ 실행 입력 ▶ (핀)
  ├─ In String (문자열 입력)
  │    └─ 기본값: "Hello"
  ├─ 실행 출력 ▶ (핀)
  └─ (드롭다운) ▼
       ├─ Text Color (색상)
       ├─ Duration (지속시간) - 기본 2초
       └─ Print to Log
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380706/notion-blog/_/_/_5_/_2_/image_1.png)

왼쪽: 입력
오른쪽: 출력
```

## 🔄 Event Tick - 매 프레임 실행

### Event Tick이란?

```
매 프레임마다 호출되는 이벤트
  ↓
게임이 돌아가는 동안 계속 실행
  ↓
화면이 업데이트될 때마다!
```

### 프레임(Frame)이란?

```
게임 화면 = 연속된 이미지들
  ↓
1초에 60장 → 60 FPS
1초에 30장 → 30 FPS
  ↓
빠를수록 부드러움!
```

## 🔑 Print String의 Key

### Key란?

```
메시지 식별자
  ↓
같은 Key를 가진 메시지는
서로 덮어씀
```

### 데이터 타입 비교

```
Name (이름)
  ├─ 식별자용
  ├─ 공백 불가 ❌
  └─ 예: Message1, PlayerName

String (문자열)
  ├─ 모든 문자 가능
  ├─ 공백 가능 ✅
  └─ 예: "안녕하세요!", "Hello World"
```

### Key 활용하기

```
[Print String]
  └─ Key: "Message1"
      ↓
Event Tick으로 매 프레임 출력해도
화면에 하나만 보임!
      ↓
새 메시지가 이전 메시지 대체
```

---

## 📊 Delta Seconds - 시간 측정

### Delta Seconds란?

```
Event Tick
  └─ Delta Seconds (출력 핀)
      ↓
이전 프레임 이후 경과 시간
      ↓
단위: 초 (Float)
```

### Float(부동소수점)란?

```
정수 (Integer)
  └─ 1, 2, 3, 100

부동소수점 (Float)
  └─ 1.5, 2.76, 0.00833
      ↓
소수점 있는 숫자!
```

---

## 🔄 데이터 타입 변환

### 자동 변환 노드

```
Event Tick
  └─ Delta Seconds (Float, 분홍색 핀)
      ↓
      [Float to String] ← 자동 생성!
      ↓
Print String
  └─ In String (String, 빨간색 핀)
```

### 언제 자동 변환?

```
다른 타입 핀끼리 연결하면
  ↓
블루프린트가 자동으로
변환 노드 생성!
  ↓
Float → String
Int → Float
등등...
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380708/notion-blog/_/_/_5_/_2_/image_2.png)

---

## 💻 Delta Seconds 출력하기

### 설정

```
Event Tick ──▶─┐
  │            │
  Delta ─────► [Float to String] ──► [Print String]
  Seconds                             Key: "DeltaTime"
```

### 실행 결과

```
▶ 재생
  ↓
화면에 숫자 출력
"0.00833" → "0.00834" → "0.00833"
  ↓
계속 변함!
```

### 왜 값이 변하나?

```
프레임 간격이 일정하지 않음
  ↓
0.00833초 (약 60 FPS)
0.00834초 (약 59.8 FPS)
  ↓
게임 부하에 따라 변동
  ↓
부하 ↑ → Delta ↑ → 랙 발생!
```

# { 블루프린트 클래스 만들기 }

## 🎯 이번에 할 것

```

  └─ 특정 맵에만 작동 ❌

  └─ 어디서나 재사용 가능! ✅
```

## 📁 블루프린트 클래스 생성하기

### 1단계: 폴더 만들기

```
콘텐츠 서랍 열기
  ↓
내 콘텐츠 폴더
  ↓

```

## 🎭 부모 클래스란?

### Actor 클래스 (가장 기본!)

```
Actor 클래스 선택
  ↓
Actor의 기능 상속받음
  ↓
월드에 배치 가능
이동, 회전, 스케일 가능
```

### 이름 짓기 규칙

```
BP_이름
  ↓
BP = Blueprint
  ↓
예: BP_Drone
```

## 🔍 블루프린트 클래스 에디터

### 레벨 블루프린트와 차이점

```
레벨 블루프린트

  └─ 이벤트 그래프
```

### 기본 이벤트 노드 (3개)

```

```

### 에디터 배치 팁

```
BP_Drone 탭을 드래그

기본 맵 옆에 도킹
  ↓

```

---

## 🏗️ 블루프린트 vs 인스턴스

### 핵심 개념! 🔑

```
블루프린트 클래스 = 설계도 📋
  ↓
인스턴스 = 실제 집 🏠
  ↓
설계도만 있고 집이 없으면
아무 일도 안 일어남!
```

### 왜 메시지가 안 보일까?

```
❌ 현재 상태:
   설계도만 만듦

✅ 필요한 것:
   월드에 실제 오브젝트 배치!
```

---

## 🎮 월드에 배치하기

### 인스턴스 생성 방법

```
콘텐츠 서랍 열기
  ↓
BP_Drone 클릭 & 드래그
  ↓
뷰포트에 놓기
  ↓
인스턴스 생성 완료!
```

### 확인하기

```
아웃라이너에서
  ├─ BP_Drone 표시됨 ✅
  └─ 작은 아이콘 보임
      ↓
월드에 실제 존재함!
```

```

## 👁️ 시각적 표현

### 현재 상태

```
뷰포트에서
  ├─ 작은 아이콘만 보임 👁️
  └─ 메시(3D 모델) 없음
      ↓
왜? 아직 안 추가해서!
```

### 아이콘의 역할

```
편집 모드
  └─ 아이콘 보임 (위치 확인용)

플레이 모드
  └─ 아이콘 안 보임
      ↓
실제 게임에선 안 보임!
```

# { 컴포넌트로 메시 추가하기 }

## 🎯 이번에 할 것

드론에 3D 메시 입히기!

```
현재: 아이콘만 보임 👁️
  ↓
추가: Static Mesh Component
  ↓
결과: 드론 모델 보임! 🚁
```

---

## 🧩 컴포넌트란?

### 핵심 개념

```
Actor = 레고 블록의 기본판
  ↓
Component = 붙이는 부품들
  ├─ 메시 (외형)
  ├─ 사운드 (소리)
  ├─ 라이트 (빛)
  └─ 등등...
```

### 컴포넌트 패널 위치

```
블루프린트 에디터
  └─ 왼쪽 상단
      └─ Components 패널
```

---

## 🌳 루트 컴포넌트

### 필수 규칙!

```
모든 Actor는
최소 1개 컴포넌트 필요
  ↓
이것이 Root Component
  ↓
Actor의 중심점!
```

### Default Scene Root

```
새 Actor 만들면
자동으로 생성됨
  ↓
Scene Component 타입
  ├─ 눈에 안 보임
  ├─ 위치만 표시
  └─ 다른 컴포넌트 부착 가능
```

## ➕ Static Mesh 추가하기

### 1단계: 컴포넌트 추가

```
Components 패널에서
  ↓
"+ Add" 버튼 클릭
  ↓
"Static" 검색

```

  ├─ 기본값: 0 (얇음)

## 🌍 World Space vs Local Space

### World Space (월드 공간)

```
게임 월드의 절대 방향
  ├─ X: 빨강 (고정)
  ├─ Y: 초록 (고정)
  └─ Z: 파랑 (고정)
      ↓
모든 오브젝트에 동일!
```

### Local Space (로컬 공간)

```
각 Actor의 상대 방향
  ├─ X: 정면 (Forward)
  ├─ Y: 오른쪽 (Right)
  └─ Z: 위쪽 (Up)
      ↓
Actor마다 다름!
```

---

### 전환 방법

```
뷰포트 상단
  ↓
지구본 아이콘 클릭
  ↓
World ⇄ Local 전환
```

### World Space 상태

```
기즈모가 월드 방향 표시
  ├─ 항상 같은 방향
  └─ 뷰포트 좌하단 좌표계와 일치
```

### Local Space 상태

```
기즈모가 Actor의 방향 표시
  ├─ Actor마다 다름
  └─ Actor의 회전을 반영
```

## 🤔 왜 Scene Component를 추가하나?

### 문제 상황

```
DroneMesh가 루트일 때:
  ↓
DroneMesh 자체를 회전하면
  ↓
Actor의 방향도 같이 회전됨 ❌
  ↓
결국 다시 문제 발생!
```

### 해결 방법

```
Scene (루트) - 방향 기준점
  └─ DroneMesh (자식) - 시각만 회전
      ↓
루트는 고정 (정면=X축)
메시만 90도 회전
  ↓
Actor 방향 유지하면서
메시 외형만 조정! ✅
```

### 핵심

```
루트 = Actor의 "진짜 방향"
자식 메시 = "보이는 방향"
  ↓
둘을 분리해서 제어!
```

**간단히: 루트를 건드리면 Actor 방향이 바뀌니까, 루트는 놔두고 메시만 돌리려고!** 🎯

## 📐 Unreal Engine 방향 규칙

### 핵심 규칙! 🔑

```
X축 = Forward (정면)
  └─ 빨간색 화살표

Y축 = Right (오른쪽)
  └─ 초록색 화살표

Z축 = Up (위쪽)
  └─ 파란색 화살표
```

### 왜 중요한가?

```
이동 명령:
  └─ Move Forward → X축 방향
  └─ Move Right → Y축 방향
  └─ Move Up → Z축 방향
      ↓
메시가 올바른 방향 필수!
```
