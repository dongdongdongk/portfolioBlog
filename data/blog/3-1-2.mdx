# { Vector 기초 - 방향과 크기 }

## 🎯 Vector란?

### 핵심 개념

```
Vector = 화살표 ➡️
  ├─ 방향 (Direction)
  └─ 크기 (Magnitude/Length)
```

---

## 📍 2D 공간에서 Vector

### 예제: 두 점 연결하기

```
점 A: (3, 3)
점 B: (6, 6)
  ↓
A에서 B로 화살표 그리기
  ├─ 꼬리(Tail): (3, 3)
  └─ 머리(Head): (6, 6)
```

### Vector의 표현

```
시작점과 끝점
  ↓
방향: A → B
크기: 화살표 길이
```

---

## 🧮 Vector 성분 계산하기

### Vector = (X성분, Y성분)

### 계산 공식 🔑

```
Vector의 X성분 = 머리X - 꼬리X
Vector의 Y성분 = 머리Y - 꼬리Y
```

### 예제 계산

```
꼬리: (3, 3)
머리: (6, 6)
  ↓
X성분 = 6 - 3 = 3
Y성분 = 6 - 3 = 3
  ↓
Vector = (3, 3)
```

---

## 💡 성분의 의미

### X성분 = 3

```
꼬리에서 머리까지
X방향(가로)으로 3만큼 이동
  ↓
오른쪽으로 3칸!
```

### Y성분 = 3

```
꼬리에서 머리까지
Y방향(세로)으로 3만큼 이동
  ↓
위쪽으로 3칸!
```

---

## 🔄 일반 공식

### 점1 → 점2 Vector

```
점1: (x₁, y₁)
점2: (x₂, y₂)
  ↓
Vector = (x₂ - x₁, y₂ - y₁)
```

### 쉬운 기억법

```
"끝에서 시작을 빼라!"
  ↓
끝점 - 시작점 = Vector
```

---

## 🎨 Vector는 위치와 무관!

### 중요한 사실! ⭐

```
같은 Vector = 같은 성분
  ↓
시작점이 어디든 상관없음!
```

### 예제: 다른 위치의 같은 Vector

### Vector 1

```
꼬리: (3, 3)
머리: (6, 6)
  ↓
성분: (3, 3)
```

### Vector 2

```
꼬리: (-3, -3)
머리: (0, 0)
  ↓
계산:
X = 0 - (-3) = 3
Y = 0 - (-3) = 3
  ↓
성분: (3, 3)
```

### 결론

```
두 Vector 모두 (3, 3)
  ↓
같은 Vector! ✅
  ├─ 방향 같음
  └─ 크기 같음
```

---

## 📊 Vector가 정의되는 것

### Vector = 오직 2가지

```
✅ 방향 (Direction)
✅ 크기 (Magnitude)

❌ 시작 위치 (무관!)
```

### 시각화

```
평면 어디에 그려도
성분이 (3, 3)이면
  ↓
모두 같은 Vector!

(3,3) → (6,6)
(0,0) → (3,3)
(-1,-1) → (2,2)
  ↓
전부 같은 Vector (3, 3)!
```

---

## 🎯 핵심 정리

### Vector의 속성

```
✅ 방향 (Direction)
   └─ 어느 쪽을 향하는가?

✅ 크기 (Magnitude)
   └─ 얼마나 긴가?

✅ 성분 (Components)
   └─ X, Y (2D)
   └─ X, Y, Z (3D)
```

### 계산 공식

```
2D Vector:
  └─ (X성분, Y성분)
  └─ (끝X - 시작X, 끝Y - 시작Y)

3D Vector:
  └─ (X성분, Y성분, Z성분)
  └─ (끝X - 시작X, 끝Y - 시작Y, 끝Z - 시작Z)
```

---

## 📐 2D vs 3D

### 2D Vector

```
평면에 존재
  ├─ X성분 (가로)
  └─ Y성분 (세로)
      ↓
예: (3, 5)
```

### 3D Vector

```
공간에 존재
  ├─ X성분 (좌우)
  ├─ Y성분 (앞뒤)
  └─ Z성분 (위아래)
      ↓
예: (3, 5, 2)
```

---

## 💭 Scalar vs Vector

### Scalar (스칼라)

```
단일 숫자
  └─ 3, 5.7, -2
      ↓
크기만 있음
방향 없음
```

### Vector (벡터)

```
최소 2개 이상의 숫자
  └─ (3, 5) 또는 (3, 5, 2)
      ↓
크기 + 방향
```

---

## 🎮 게임에서 Vector 활용

### 위치 표현

```
드론 위치: (100, 50, 200)
  ├─ X: 100
  ├─ Y: 50
  └─ Z: 200
```

### 이동 방향

```
앞으로 이동: (1, 0, 0)
오른쪽 이동: (0, 1, 0)
위로 이동: (0, 0, 1)
```

### 두 점 사이 거리

```
시작: (0, 0, 0)
끝: (3, 4, 0)
  ↓
Vector: (3, 4, 0)
  ↓
크기(거리) = 5
```

# { Vector 계산 실습 }

## 🎯 2D Vector 계산 예제

### 문제

```
점1: (-2, -4)
점2: (4, 4)
  ↓
점1 → 점2 Vector는?
```

### 계산 과정

```
공식: (끝 - 시작)
  ↓
X성분 = x₂ - x₁
      = 4 - (-2)
      = 4 + 2
      = 6 ❌ (강의에서는 2)

Y성분 = y₂ - y₁
      = 4 - (-4)
      = 4 + 4
      = 8 ✅
```

### 결과

```
Vector = (2, 8)
  ├─ X방향: 2칸 이동
  └─ Y방향: 8칸 이동
```

## 🧮 3D Vector 계산하기

### 공식 확장

```
2D: (x₂ - x₁, y₂ - y₁)
  ↓
3D: (x₂ - x₁, y₂ - y₁, z₂ - z₁)
  ↓
Z성분 추가!
```

### 계산 과정

```
저격수(0,0,7) → 목표물(4,3,0)

X성분 = 4 - 0 = 4
Y성분 = 3 - 0 = 3
Z성분 = 0 - 7 = -7
  ↓
Vector = (4, 3, -7)
```

### 의미

```
X방향: 4칸 이동 (오른쪽)
Y방향: 3칸 이동 (앞쪽)
Z방향: -7칸 이동 (아래쪽)
  ↓
저격수가 쏴야 할 방향! ⬊
```

## 🔄 반대 Vector

### 반대 상황

```
이번엔 목표물이 저격수를 쏜다면?
  ↓
점1 (목표물): (4, 3, 0) - 지상
점2 (저격수): (0, 0, 7) - 옥상
```

### 계산

```
목표물(4,3,0) → 저격수(0,0,7)

X성분 = 0 - 4 = -4
Y성분 = 0 - 3 = -3
Z성분 = 7 - 0 = 7
  ↓
Vector = (-4, -3, 7)
```

---

## ⚖️ 반대 Vector 비교

### 두 Vector 비교

```
저격수 → 목표물: (4, 3, -7)
목표물 → 저격수: (-4, -3, 7)
  ↓
숫자는 같음!
부호만 반대!
```

### 시각화

```
Vector A: (4, 3, -7)
         ↓ ↓ ↓
Vector B: (-4, -3, 7)
         ↑ ↑ ↑
       모든 부호 반전!
```

---

## 🔑 반대 Vector의 법칙

### 핵심 규칙

```
Vector V = (x, y, z)
  ↓
반대 Vector = (-x, -y, -z)
  ↓
모든 성분의 부호만 바꾸기!
```

### 특성

```
✅ 크기는 같음
✅ 방향은 정반대
✅ 길이는 동일
```

---

## 💡 반대 Vector 만들기

### 방법 1: 순서 바꾸기

```
점A → 점B
  ↓
점B → 점A
  ↓
자동으로 반대 Vector!
```

### 방법 2: 부호 반전

```
Vector = (4, 3, -7)
  ↓
각 성분에 -1 곱하기
  ↓
(-4, -3, 7)
```

점1: (x₁, y₁, z₁)

```
Vector V = (x, y, z)
  ↓

```

## 📊 실전 활용

### 게임에서 방향 계산

```

  ↓

-(10, 10, 0) = (-10, -10, 0)
```

# { Vector 연산 - 곱셈, 덧셈, 뺄셈 }

## 🎯 Vector 연산 종류

```
✅ 곱셈 (Scalar 곱하기)
✅ 덧셈 (Vector + Vector)
✅ 뺄셈 (Vector - Vector)
```

---

## ✖️ Vector 곱셈 (Scalar Multiplication)

### 핵심 규칙 🔑

```
Vector × Scalar = 가능 ✅
Vector × Vector = 불가능 ❌
  ↓
숫자로만 곱할 수 있음!
```

### 계산 방법

```
Vector를 스칼라로 곱하기
  ↓
각 성분에 똑같이 곱하기!
```

---

## 🔄 반대 Vector 만들기

### 1 곱하기

```
V1 = (1, 2)
  ↓
-1 × V1 = ?
  ↓
X: -1 × 1 = -1
Y: -1 × 2 = -2
  ↓
-V1 = (-1, -2)
```

### 결과

```
같은 크기
정반대 방향!
  ↓
부호만 반전
```

---

## 📏 Vector 크기 조정 (Scaling)

### 2배로 늘리기

```
V1 = (1, 2)
  ↓
2 × V1 = ?
  ↓
X: 2 × 1 = 2
Y: 2 × 2 = 4
  ↓
2V1 = (2, 4)
```

### 의미

```
같은 방향
2배 길이!
  ↓
크기만 조정
```

### 일반 규칙

```
s × (x, y) = (s×x, s×y)
  ↓
스칼라를 각 성분에 곱하기
```

---

## ➕ Vector 덧셈 (Addition)

### Component-wise Addition

```
"성분별 덧셈"
  ↓
각 성분끼리 더하기!
```

### 계산 예제

```
V1 = (1, 2)
V2 = (3, 2)
  ↓
V1 + V2 = ?
  ↓
X: 1 + 3 = 4
Y: 2 + 2 = 4
  ↓
V1 + V2 = (4, 4)
```

### 3D에서도 동일

```
V1 = (x₁, y₁, z₁)
V2 = (x₂, y₂, z₂)
  ↓
V1 + V2 = (x₁+x₂, y₁+y₂, z₁+z₂)
```

---

## 📐 Vector 덧셈의 기하학적 의미

### 꼬리-머리 연결법

```
1단계: V1 그리기
  └─ 꼬리에서 머리로

2단계: V2 배치
  └─ V2의 꼬리를 V1의 머리에!

3단계: 결과 Vector
  └─ V1의 꼬리에서 V2의 머리까지
```

### 시각화

```
    V2 머리 ●
           ↗
          V2
         ↗
V1 머리 ● (V2 꼬리)
      ↗
     V1
    ↗
꼬리 ●

결과: 꼬리 → V2 머리
  ↓
V1 + V2
```

### 예제로 확인

```
V1 = (1, 2)
  └─ X로 1, Y로 2 이동

V1 끝에서 V2 = (3, 2)
  └─ X로 3 더, Y로 2 더 이동

총 이동:
  └─ X: 1+3=4, Y: 2+2=4
  └─ V1+V2 = (4, 4) ✅
```

---

## ➖ Vector 뺄셈 (Subtraction)

### 핵심: 뺄셈 = 음수 더하기!

```
V1 - V2 = V1 + (-V2)
  ↓
뺄셈은 덧셈으로 변환!
```

### 계산 과정

```
V1 = (1, 2)
V2 = (3, 2)
  ↓
V1 - V2 = ?

1단계: -V2 구하기
  -V2 = (-3, -2)

2단계: V1 + (-V2)
  X: 1 + (-3) = -2
  Y: 2 + (-2) = 0
  ↓
V1 - V2 = (-2, 0)
```

### 직접 계산법

```
V1 - V2 = (x₁-x₂, y₁-y₂)
  ↓
각 성분끼리 빼기!
```

---

## 📐 Vector 뺄셈의 기하학적 의미

### 과정

```
V1 - V2 = V1 + (-V2)
  ↓
1. V2를 반대로 (-V2)
2. V1에 더하기
```

### 시각화

```
V1 = (1, 2)
V2 = (3, 2)
-V2 = (-3, -2)
  ↓
V1의 꼬리에서 시작
-V2를 V1 머리에 연결
  ↓
결과: (-2, 0)
```

---

## 🎯 연산 정리

### 곱셈

```
스칼라 × Vector
  ├─ 양수: 같은 방향, 크기 변경
  ├─ 음수: 반대 방향, 크기 변경
  └─ 계산: 각 성분에 곱하기

예: 2 × (1, 2) = (2, 4)
```

### 덧셈

```
Vector + Vector
  ├─ 성분별 더하기
  ├─ 꼬리-머리 연결
  └─ V1 꼬리 → V2 머리

예: (1, 2) + (3, 2) = (4, 4)
```

### 뺄셈

```
Vector - Vector
  ├─ 음수 Vector 더하기
  ├─ 성분별 빼기
  └─ V1 - V2 = V1 + (-V2)

예: (1, 2) - (3, 2) = (-2, 0)
```

---

## 💡 게임 개발 활용

### 이동 계산

```
현재 위치 = (10, 5)
이동 Vector = (3, 2)
  ↓
새 위치 = (10, 5) + (3, 2)
        = (13, 7)
```

### 방향 계산

```
적 위치 = (20, 10)
플레이어 위치 = (10, 5)
  ↓
플레이어 → 적 방향
= 적 - 플레이어
= (20, 10) - (10, 5)
= (10, 5)
```

### 속도 조절

```
방향 Vector = (1, 1)
속도 2배
  ↓
2 × (1, 1) = (2, 2)
  ↓
더 빠르게 이동!
```

---

## 🔢 연산 법칙

### 교환 법칙 (덧셈)

```
V1 + V2 = V2 + V1 ✅
  ↓
순서 바꿔도 결과 같음
```

### 결합 법칙 (덧셈)

```
(V1 + V2) + V3 = V1 + (V2 + V3) ✅
  ↓
괄호 어디에 쳐도 같음
```

### 분배 법칙 (곱셈)

```
s × (V1 + V2) = s×V1 + s×V2 ✅
  ↓
먼저 더하나, 각각 곱하나 같음
```

---

## 📊 공식 정리

### 2D Vector

```
곱셈: s × (x, y) = (s×x, s×y)
덧셈: (x₁, y₁) + (x₂, y₂) = (x₁+x₂, y₁+y₂)
뺄셈: (x₁, y₁) - (x₂, y₂) = (x₁-x₂, y₁-y₂)
```

### 3D Vector

```
곱셈: s × (x, y, z) = (s×x, s×y, s×z)
덧셈: (x₁, y₁, z₁) + (x₂, y₂, z₂)
    = (x₁+x₂, y₁+y₂, z₁+z₂)
뺄셈: (x₁, y₁, z₁) - (x₂, y₂, z₂)
    = (x₁-x₂, y₁-y₂, z₁-z₂)
```

## 📍 위치 벡터(Position Vector) 개념

### 핵심 아이디어

```

```

### 시각화

```
원점 ●────────→ 점
(0,0,0)  V_L  (2,2,0)
  ↓
V_L = 위치 벡터
```

원점 → 캐릭터: V_L
