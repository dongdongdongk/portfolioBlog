## css 란?

css는 문서가 시각적으로 표시되는 방식, 즉 배열 및 스타일 지정 방식을 설명하는 언어입니다.

## 무엇을 의미 하는가?

css는 cascading style sheets를 의미합니다. cascading 부분은 잠시 후에 다루겠습니다. 지금은 걱정하지 마세요.

## **<link>: 외부 리소스 연결 요소**

```html
문법 : <link href="main.css" rel="stylesheet" />

// href 특성에 스타일 시트의 경로 // rel 특성에 stylesheet rel 은 관계(relationship)를 뜻하며, 현재
문서와 연결한 아이템의 관계가 어떻게 되는지 설명한다.
```

## <color , background-color>

색상을 변경한다.

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381355/notion-blog/_/The_Web_Developer_2022/CSS/CSS_/Untitled_7.png)

```html
color : indigo; //색 지정 background-color; //배경색 지정
```

다양한 방식으로 색을 지정 가능

1. RGB 색상 값으로 표현 (색의 혼합을 이용한 방법 빨강,녹색,파랑) ranges 0-255

```html
문법 : rgb(255,0,0) (빨,노,파)
```

2.Hex

rgb 와 같은 원리지만 16 진법으로 색상을 표현한다.

```html
문법 : #ffff00 ff(red),ff(green),00(blue)
```

3.hsl

색조,채도,밝기 이용해 색상 정의

```html
문법 : hsl(0,100%,50%) (0~360 색깔방향 , 0~100% 채도 , 0~100% 명도)
```

## text-align 글자 정렬

텍스트를 가운데 정렬 왼쪽 정렬 등 정렬을 설정한다.

```html
문법 : h1 { text-align : center; (right , left) }
```

```html
text-align: left; text-align: right; text-align: center; text-align: justify; text-align:
justify-all; text-align: start; text-align: end; text-align: match-parent;
```

## **font-weight 글자 굵기**

글자의 굵기를 조절한다.

```html
font-weight: normal; font-weight: bold; /* Relative to the parent */ font-weight: lighter;
font-weight: bolder; font-weight: 100; font-weight: 200; font-weight: 300; font-weight: 400; // 기본
굵기 font-weight: 500; font-weight: 600; font-weight: 700; font-weight: 800; font-weight: 900; //
폰트에서 지원하지 않는 굵기 값 이 설정되면 가장 비슷한 굵기를 설정 해준다.
```

## **text-decoration 장식용 선 추가**

텍스트에 취소선,언더라인,오버라인 등 장식용 선을 추가한다.

```html
text-decoration: underline; text-decoration: underline dotted; text-decoration: underline dotted
red; text-decoration: green wavy underline; text-decoration: underline overline #FF3028;
text-decoration: line-through; //취소선 // 앵커 태그를 사용할때 자동으로 언더라인 이 생기는 것을
막고 싶으면 a { text-decoration : none; } 이렇게 코드를 짜줄수 있다.
```

## line-height , letter-spacing 텍스트 간격 조절

```html
line-height: normal; // 텍스트 간격 조절 letter-spacing; // 자간 조절
```

## **font-family**

```html
문법 : font-family: Georgia, "Times New Roman", serif; //font-family 는 텍스트의 폰트를 바꿔주며
기기에서 지원하지 않는 폰트라면 ,다음의 폰트를 출력한다.(백업 폰트) // 이런식의 목록을 font stack
이라고 한다 ex)Georgia, "Times New Roman", serif
```
