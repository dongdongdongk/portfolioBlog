![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380723/notion-blog/_/_/_5_/_5_-_2/image.png)

### Axis 2D 이해

```
Vector 2D = 2차원 벡터
  ├─ X: 좌우 (Left/Right)
  └─ Y: 위아래 (Up/Down)
  ↓
3D Vector (X, Y, Z)에서
  └─ Z 제거한 것
```

**값 범위**

```
X축:
  ├─ -1: 왼쪽으로 빠르게
  ├─  0: 움직임 없음
  └─ +1: 오른쪽으로 빠르게

Y축:
  ├─ -1: 아래로 빠르게
  ├─  0: 움직임 없음
  └─ +1: 위로 빠르게
```

## 🎮 Controller 회전

### 왜 Controller인가?

**초보자 생각**

```
Spring Arm 회전?
Bot Mesh 회전?
Camera 회전?
  ↓
보이는 것 회전하면 되지 않나?
```

**올바른 방법**

```
Controller 회전!
  ↓
보이지 않지만
  ↓
다른 Component들이 따라감
  ↓
더 깔끔하고 전문적
```

### Controller의 장점

```
Controller = 기준점
  ├─ 회전 정보 저장
  ├─ Component들이 따라감
  └─ 중앙 집중 제어
  ↓
Spring Arm → Controller 따라감
  ↓
Camera → Spring Arm 따라감
  ↓
체계적인 구조!
```

### 추가

```

```

### Negate란?

```
Negate = 부정, 반전
  ├─ 값의 부호 바꾸기
  ├─ + → -
  └─ - → +
```

### 옵션 설정

```
Negate 확장
  ├─ X: ✗ (체크 안 함)
  │   └─ 좌우는 정상
  │
  ├─ Y: ✓ (체크)
  │   └─ 위아래 반전
  │
  └─ Z: (없음, 2D라서)
```

### 작동 원리

```
마우스 위로 이동
  ↓
원래: Y = +1
  ↓
Negate 적용: Y = -1
  ↓
위를 봄 ✓
```

## 🔀 W/S키: Swizzle Modifier

### 문제

```
W와 S도 X축으로 입력됨
  ↓
전후 이동 불가
  ↓
Y축으로 바꿔야 함
```

### Swizzle Input Axis Values

```
축의 순서를 바꿈

기본: X, Y, Z
  ↓
Swizzle: Y, X, Z
  ↓
첫 번째 값이 Y축으로!
```

### W키 설정

```
W → Modifiers → + 버튼
  ↓
Swizzle Input Axis Values
  ↓
Order: YXZ
```

**의미**

```
W 누름
  ↓
원래: X = 1
  ↓
Swizzle 후: Y = 1
  ↓
전진! ✓
```

### S키 설정 (2개 Modifier!)

```
S → Modifiers
  ├─ 1. Swizzle (YXZ)
  │   └─ Y축으로 변경
  │
  └─ 2. Negate
      ├─ X: ✗
      ├─ Y: ✓ (체크)
      └─ Z: ✗
```

**왜 2개?**

```
1. Swizzle: Y축으로 변경
2. Negate: 음수로 변경
  ↓
S 누름 → Y = -1 (후진)
```

# 왜 Swizzle로 순서를 바꾸나?

## 💡 이유

키보드 키를 누르면 **무조건 첫 번째 칸(X축)에만** 값이 들어가는데, 우리는 W키는 "앞으로(Y축)", D키는 "오른쪽으로(X축)" 가게 하고 싶잖아요? 그래서 **W키에만 "첫 번째 칸을 Y로 바꿔!"**라고 Swizzle로 순서를 뒤집어버리는 거예요. 마치 우편 배달부한테 "이 편지는 1번 우편함 말고 2번 우편함에 넣어주세요!"라고 특별 지시하는 것처럼요. 그러면 W는 Y칸(앞), D는 X칸(오른쪽)으로 각각 다른 방향으로 움직일 수 있게 됩니다!

---

## 🎯 한 줄 요약

**모든 키가 기본적으로 X칸(오른쪽)에만 들어가니까, W키만 특별히 Y칸(앞)으로 바꿔서 다른 방향으로 움직이게 하려고!**

---

## 📊 최종 키 설정 요약

```
W:
  └─ Swizzle (YXZ)
  → Y = +1 (전진)

A:
  └─ Negate (X)
  → X = -1 (왼쪽)

S:
  ├─ Swizzle (YXZ)
  └─ Negate (Y)
  → Y = -1 (후진)

D:
  └─ (없음)
  → X = +1 (오른쪽)
```

```

  ↓

  ↓
```

```
  └─ World Vector: 이동 방향
```

### Get Right Vector

```
Get Control Rotation
  ↓
Get Right Vector
  ├─ Controller의 오른쪽 방향
  └─ Vector 반환
```

**Right Vector란?**

```
현재 바라보는 방향 기준
  ↓
오른쪽 방향의 단위 벡터

예:
  북쪽 바라봄 → Right = 동쪽
  동쪽 바라봄 → Right = 남쪽
```

### Scale (곱하기)

```
Get Right Vector
  ↓
Multiply (×)
  ├─ Right Vector
  └─ X (Float 변환)
  ↓
Add Input Vector
```

**왜 곱하나?**

```
D (X = +1):
  Right Vector × 1 = 오른쪽

A (X = -1):
  Right Vector × -1 = 왼쪽
  ↓
반대 방향!
```

```

  ↓

```
```
IA_Move
  ↓
```

```
  ↓
```

```
Vector
  ↓

  ├─ X
  ├─ Y
  └─ Z ← 필요한 것!
```

```
  ↓
Get Up Vector (위 방향)
```

## ⚙️ Camera Lag 옵션

### Enable Camera Lag

```
Camera → Camera Settings
  ↓
Enable Camera Lag: ✓
```

**효과**

```
체크 전:
  Pawn 이동 = Camera 즉시 따라감

체크 후:
  Pawn 이동 → Camera 천천히 따라감
  ↓
부드러운 느낌! ✨
```

### Camera Lag Speed

```
Lag → Camera Lag Speed: 20
  (기본값: 10)
```

**의미**

```
숫자가 클수록:
  └─ Camera가 빨리 따라잡음

숫자가 작을수록:
  └─ Camera가 천천히 따라잡음
```

**값 비교**

```
5: 매우 느린 추적 (과한 지연)
10: 적당한 추적 (기본)
20: 빠른 추적 (권장) ✓
50: 거의 즉시 (지연 미미)
```

### Camera Lag Max Distance

```
Lag → Camera Lag Max Distance: 0
  (기본값: 0 = 제한 없음)
```

**의미**

```
0: 제한 없음
  └─ 얼마든지 멀어질 수 있음

값 설정 (예: 100):
  └─ 100 이상 안 멀어짐
  └─ 그 이상은 즉시 따라감
```

```
게임에 생동감 주는 작은 효과들

예:
  ├─ Camera Lag
  ├─ Screen Shake
  ├─ Particle Effects
  └─ Sound Effects
  ↓
있으면: 좋다! ✨
없으면: 뭔가 부족...
```

**Camera Lag = Juice의 예**

```
미묘하지만
  ↓
게임 느낌을 크게 바꿈
  ↓
프로페셔널한 차이
```

```
1. Input Action (IA)
   "무엇을 할 건지"

   ↓
4. Event로 반응

```

## 📦 1단계: Input Action (무엇을)

### Input Action이란?

**쉬운 비유**

```
동작 메뉴판

메뉴:
  ├─ 발사하기
  ├─ 둘러보기
  └─ 이동하기

손님: "발사 1개요!"
  ↓
Input Action = 메뉴 항목
```

### 우리가 만든 것

```
IA_Fire (발사)
  └─ Value Type: Digital (Bool)
      └─ 눌림/안 눌림

IA_Look (둘러보기)
  └─ Value Type: Axis 2D
      └─ 마우스 X, Y

IA_Move (이동)
  └─ Value Type: Axis 3D
      └─ X, Y, Z 방향
```

---

## 🎮 Value Type 이해

### Digital (Bool) - 버튼용

```
상태: 2가지만
  ├─ True (눌림)
  └─ False (안 눌림)

예: IA_Fire
  클릭 → True
  뗌 → False
```

**언제 사용?**

```
단순 버튼 동작
  ├─ 발사
  ├─ 점프
  └─ 상호작용
```

### Axis 2D - 평면 이동용

```
상태: 2개 값
  ├─ X축 (-1 ~ +1)
  └─ Y축 (-1 ~ +1)

예: IA_Look
  마우스 좌우 → X
  마우스 위아래 → Y
```

**언제 사용?**

```
2방향 입력
  ├─ 마우스 이동
  ├─ 조이스틱
  └─ WASD (평면만)
```

### Axis 3D - 3차원 이동용

```
상태: 3개 값
  ├─ X축 (-1 ~ +1)
  ├─ Y축 (-1 ~ +1)
  └─ Z축 (-1 ~ +1)

예: IA_Move
  D/A → X (좌우)
  W/S → Y (전후)
  Space → Z (위아래)
```

**언제 사용?**

```
3방향 입력
  ├─ 비행 (드론)
  ├─ 수영
  └─ 우주선
```

## 🗺️ 2단계: Input Mapping Context (어떤 키로)

### IMC란?

**쉬운 비유**

```
리모컨 설정

메뉴(IA)와 버튼 연결:
  ├─ 발사 → 빨간 버튼
  ├─ 둘러보기 → 조이스틱
  └─ 이동 → 방향키

IMC = 리모컨 버튼 배치
```

### 우리가 만든 것

```
IMC_Bot
  ├─ IA_Fire → Mouse Left, F
  ├─ IA_Look → Mouse XY
  └─ IA_Move → W, A, S, D, Space
```

## 🔧 Modifier (수정자) 이해

### Modifier란?

**쉬운 비유**

```
우편함 스티커

기본: 모든 편지 → 1번 우편함
스티커: "이 편지는 2번으로!"

Modifier = 특별 지시 스티커
```

### 종류와 역할

### 1. Negate (부정/반전)

```
역할: 부호 바꾸기
  +1 → -1
  -1 → +1

예: A키
  기본: X = +1 (오른쪽)
  Negate: X = -1 (왼쪽)
```

**설정**

```
A키 → Modifiers
  └─ Negate
      ├─ X: ✓ (반전)
      ├─ Y: ✗
      └─ Z: ✗
```

### 2. Swizzle (순서 변경)

```
역할: 값이 들어갈 칸 바꾸기

기본 순서: X, Y, Z
  └─ 값 → 첫 번째(X)

Swizzle: Y, X, Z
  └─ 값 → 첫 번째(Y)
```

**예: W키**

```
기본:
  W 누름 → X = 1 (오른쪽) ✗

Swizzle (YXZ):
  W 누름 → Y = 1 (앞) ✓
```

**설정**

```
W키 → Modifiers
  └─ Swizzle Input Axis Values
      └─ Order: YXZ
```

### 최종 키 설정 정리

```
W: Swizzle (YXZ)
  → Y축 = 전진

A: Negate (X)
  → X축 = 왼쪽

S: Swizzle (YXZ) + Negate (Y)
  → Y축 음수 = 후진

D: (없음)
  → X축 = 오른쪽

Space: Swizzle (ZXY)
  → Z축 = 위
```

```
└────────┬────────────────────────┘
```

### 각 노드 설명

### Get Controller

```
역할: 이 Pawn을 조종하는 컨트롤러

비유:
  Pawn = 자동차
  Controller = 운전자

"이 차의 운전자 누구?"
```

### Cast to Player Controller

```
역할: 타입 변환

왜 필요?
  Get Controller → Controller (부모)
  필요한 것 → Player Controller (자식)

비유:
  "운전자"를 "사람 운전자"로 확인
```

### Get Enhanced Input Subsystem

```
역할: 입력 시스템 관리자

비유:
  우편 시스템 관리자
  "리모컨 설정 등록하러 왔어요"
```

### Add Mapping Context

```
역할: 우리 키 설정 등록

파라미터:
  ├─ Mapping Context: IMC_Bot
  └─ Priority: 0 (우선순위)

비유:
  "이 리모컨 설정 사용할게요!"
```

## 🎮 4단계: Event로 반응

### Input Action Event

```
Event Graph 우클릭
  ↓
"IA_Fire" 검색
  ↓
Event IA_Fire
```

### Event 실행 핀들

```
┌─────────────────────────┐
│    Event IA_Fire        │
├─────────────────────────┤
│  Started ────→          │  버튼 누르는 순간 (1회)
│  Triggered ──→          │  누르고 있는 동안 (매 프레임)
│  Ongoing ────→          │  (고급, 보통 안 씀)
│  Canceled ───→          │  (고급, 보통 안 씀)
│  Completed ──→          │  버튼 떼는 순간 (1회)
└─────────────────────────┘
```

### 실행 핀 사용법

**Started (시작)**

```
언제: 버튼 누르는 순간 1회

용도:
  ├─ 점프 시작
  ├─ 발사 (1발만)
  └─ 상호작용

예:
  Click → Started → Fire Rifle
```

**Triggered (트리거)**

```
언제: 버튼 누르고 있는 동안 매 프레임

용도:
  ├─ 연사
  ├─ 이동
  └─ 회전

예:
  Hold → Triggered (계속) → Move
```

**Completed (완료)**

```
언제: 버튼 떼는 순간 1회

용도:
  ├─ 차징 완료
  ├─ 점프 끝
  └─ 종료 처리

예:
  Release → Completed → Stop Fire
```
