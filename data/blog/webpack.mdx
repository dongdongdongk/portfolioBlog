## Webpack이란?

```jsx
Webpack은 자바스크립트, CSS, 이미지, 폰트 등 다양한 파일을 하나로 묶어주는( 번들링 ) 도구예요.

우리가 웹사이트를 만들 때, 여러 개의 파일을 사용하죠?

그런데 파일이 많으면 웹사이트가 느려지고 관리하기도 어려워져요.

그래서 Webpack을 사용하면 파일을 묶어서 최적화할 수 있어
```

## 번들링이란?

```jsx
번들링(Bundling) 은 여러 개의 파일(자바스크립트, CSS, 이미지 등)을 하나의 파일로 묶는 과정이에요.

이렇게 하면 웹사이트 로딩 속도가 빨라지고, 코드 관리가 쉬워져요.

📌 비유하자면?

번들링을 하지 않으면, 책 한 장 한 장을 따로 들고 다니는 것과 같아요. 📖📃📃📃

번들링을 하면, 모든 페이지를 한 권의 책으로 묶어서 들고 다니는 것과 같아요. 📕

👉 결과적으로, 웹사이트가 더 빠르고 효율적으로 동작할 수 있게 도와줘요!
```

### 번들링이 왜 필요할까?

```jsx
❌ 번들링이 없을 때 (파일이 많을 때 문제점)

✔ 웹사이트에는 여러 개의 HTML, CSS, JS, 이미지 파일이 필요해요.

✔ 브라우저가 이 파일들을 하나씩 다운로드하면 시간이 오래 걸려요.
```

```jsx
📌 예제

웹사이트에서 다음과 같은 파일을 사용한다고 해볼게요.
```

```jsx
/index.html
/style.css
/script1.js
/script2.js
/logo.png
```

```jsx
서버에서 파일을 하나씩 받아오면 느려짐!

네트워크 요청(Network Request)이 많아짐.

사이트 로딩 속도가 저하됨.
```

### 번들링을 하면?

```jsx
Webpack 같은 도구가 위의 파일들을 하나로 묶어줌!
```

```jsx
/dist/bundle.js  → 모든 JS 파일이 하나로 묶임
/dist/bundle.css  → 모든 CSS 파일이 하나로 묶임
/dist/assets/logo.png  → 이미지도 최적화됨
```

```jsx
✔ 파일 요청 수가 줄어들어서 웹사이트가 더 빨라짐! 🚀

✔ 중복 코드 제거! (필요 없는 부분을 제거해서 파일 크기를 줄임)

✔ 최신 JavaScript 문법을 옛날 브라우저에서도 사용 가능하도록 변환!
```

## 번들링 작동 방식 (Webpack을 기준으로)

### 1. Entry (입구 파일 지정)

```jsx
어떤 파일부터 묶을지 Webpack에 알려줘야 해요

📌 예시 (webpack.config.js)
```

```jsx
module.exports = {
  entry: './src/index.js', // 이 파일부터 시작해서 묶을 거야!
}
```

```jsx
index.js 파일을 기준으로 관련된 모든 파일을 찾아서 묶어요.
```

### 2. Dependency Graph (의존성 그래프 생성)

```jsx
모든 파일이 서로 연결된 관계를 분석!

📌 예제 코드 (index.js)
```

```jsx
import sayHello from './hello.js' // hello.js 파일을 가져옴
import './style.css' // CSS도 가져옴!

sayHello()
```

```jsx
✔ Webpack이 index.js를 분석해서 hello.js, style.css도 함께 묶어요.
```

```jsx
📌 Dependency Graph 예시

index.js
 ├── hello.js  (자바스크립트 파일)
 ├── style.css (CSS 파일)
```

```jsx
Webpack은 이 모든 파일을 하나로 묶어서 bundle.js를 생성!
```

### 3. Loaders (로더를 사용하여 변환)

```jsx
JS 외에도 CSS, 이미지 같은 파일도 묶어야 하니까 변환 과정이 필요함!

📌 예제 (webpack.config.js)
```

```jsx
module.exports = {
  module: {
    rules: [
      {
        test: /\.css$/, // CSS 파일을 찾고
        use: ['style-loader', 'css-loader'], // 변환해서 JS에서 불러올 수 있게 함
      },
    ],
  },
}
```

```jsx
1️⃣ style.css → Webpack이 css-loader로 변환
2️⃣ css-loader → style-loader가 브라우저에서 적용

➡ 이제 CSS도 bundle.js 안에 포함될 수 있음!
```

### 4. Output (출력 파일 생성)

```jsx
Webpack이 모든 파일을 묶어서 하나의 번들 파일을 만들어요.
```

```jsx
📌 예시 (webpack.config.js)
```

```jsx
module.exports = {
  output: {
    filename: 'bundle.js', // 최종 번들 파일 이름
    path: __dirname + '/dist', // 저장할 폴더
  },
}
```

```jsx
이제 dist/bundle.js 파일 하나만 브라우저에서 실행하면 됨!
```

## 번들링 결과 비교

### ❌ **번들링 없이 HTML에서 개별 파일 로드** (느림!)

```jsx
<script src="script1.js"></script>
<script src="script2.js"></script>
<script src="script3.js"></script>
```

```jsx
파일이 많아질수록 로딩 속도가 느려짐!
```

### **번들링 후 하나의 파일로 로드** (빠름!)

```jsx
<script src="bundle.js"></script>
```

```jsx
파일 요청이 1개로 줄어서 로딩 속도가 빨라짐!
```

## 정리: 번들링이 중요한 이유

```jsx
✔ 웹사이트 속도가 빨라짐! 🚀

✔ 파일 개수가 줄어들어 요청(Request)이 적어짐!

✔ 중복 코드 제거 → 파일 크기 최적화

✔ 최신 JavaScript 문법을 변환하여 모든 브라우저에서 사용 가능!

💡 Webpack, Vite, Parcel 같은 번들러는 이런 과정을 자동으로 처리해줌!
```

# { `.babelrc`란? }

```jsx
.babelrc는 Babel의 설정 파일입니다.

Babel이 코드를 변환할 때 어떤 규칙을 사용할지 정하는 역할을 합니다.
```

## 💡 Babel이란?

### ✅ Babel이 필요한 이유

```jsx
자바스크립트(특히 React와 같은 최신 기술)는 계속 발전하고 있지만,

모든 브라우저나 실행 환경(Electron, Node.js 등)이 최신 문법을 지원하는 것은 아닙니다.

👉 그래서 Babel을 사용하면 최신 JavaScript(ES6+) 코드를

구형 브라우저나 특정 환경에서도 동작할 수 있도록 변환해 줍니다.
```

### ✅ Babel의 역할

```jsx
let, const, async/await, arrow function 같은 최신 문법을 예전 문법으로 변환

JSX(React의 <div>Hello</div> 같은 문법)를 일반적인 JavaScript로 변환

TypeScript 코드를 JavaScript로 변환

기타 새로운 기능을 구형 환경에서도 사용할 수 있도록 지원
```

## 📂 `.babelrc`의 역할

```jsx
Babel이 변환할 때 어떤 기능을 사용할지 설정하는 파일입니다.

프로젝트 루트 디렉토리에 .babelrc라는 파일을 만들고 아래처럼 설정합니다.
```

```jsx
{
  "presets": ["@babel/preset-env", "@babel/preset-react"]
}
```

```jsx
@babel/preset-env: 최신 JavaScript 문법을 변환해 줌

@babel/preset-react: JSX 문법을 JavaScript로 변환해 줌

📌 만약 이 설정이 없다면?

Babel이 JSX와 최신 JavaScript 문법을 제대로 변환하지 못해서 코드가 실행되지 않을 수 있음!
```

## 결론

```jsx
.babelrc는 Babel이 코드를 변환하는 규칙을 정하는 파일이다.

Webpack을 직접 설정하는 프로젝트에서는 .babelrc가 필요하다.

create-react-app이나 Vite를 사용하면 자동으로 Babel 설정이 적용되므로 .babelrc가 필요 없다.

Babel이 없으면 최신 문법과 JSX를 지원하지 않는 환경에서 코드가 실행되지 않을 수 있다.
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381263/notion-blog/_/JavaScript/JavaScript_/_Webpack_/image_2.png)

```jsx
이 설정은 React와 Electron을 함께 사용하는 개발 환경을 위한 설정으로,

코드 압축, 스타일 파일 분리, 그리고 미들웨어 설정 등을 포함하고 있습니다.
```

```jsx
const webpack = require('webpack') // Webpack 관련 기능을 사용하기 위한 모듈을 불러옵니다.
const path = require('path') // 경로 관련 기능을 제공하는 Node.js 모듈을 불러옵니다.
const HtmlWebpackPlugin = require('html-webpack-plugin') // HTML 파일을 생성하는 플러그인
const BabiliPlugin = require('babili-webpack-plugin') // JavaScript 코드 압축 플러그인
const MiniCssExtractPlugin = require('mini-css-extract-plugin') // CSS 파일을 별도로 분리하여 추출하는 플러그인

module.exports = {
  module: {
    // Webpack이 파일을 어떻게 처리할지 정의하는 부분
    rules: [
      // 각 파일 유형별로 어떻게 처리할지 규칙을 정의
      {
        test: /\.css$/, // .css 확장자 파일에 대해 처리
        use: [MiniCssExtractPlugin.loader, 'css-loader'], // CSS 파일을 처리할 때 사용할 로더들
      },
      {
        test: /\.jsx?$/, // .js 또는 .jsx 확장자 파일에 대해 처리
        use: [{ loader: 'babel-loader', options: { compact: false } }], // Babel을 사용해 최신 JavaScript 문법을 브라우저 호환 코드로 변환
      },
      {
        test: /\.(jpe?g|png|gif)$/, // 이미지 파일 (jpg, jpeg, png, gif)에 대해 처리
        use: [{ loader: 'file-loader?name=img/[name]__[hash:base64:5].[ext]' }], // 이미지 파일을 dist 폴더에 저장하며, 파일 이름에 해시값을 추가
      },
      {
        test: /\.(eot|svg|ttf|woff|woff2)$/, // 폰트 파일에 대해 처리
        use: [{ loader: 'file-loader?name=font/[name]__[hash:base64:5].[ext]' }], // 폰트 파일을 dist 폴더에 저장하며, 파일 이름에 해시값을 추가
      },
    ],
  },
  target: 'electron-renderer', // Electron의 렌더러 프로세스 환경을 타겟으로 설정
  plugins: [
    // Webpack에서 사용할 플러그인 목록
    new HtmlWebpackPlugin({ title: 'React Electron App' }), // HTML 파일을 생성하고, title을 'React Electron App'으로 설정
    new MiniCssExtractPlugin({
      filename: 'bundle.css', // 분리된 CSS 파일 이름을 'bundle.css'로 설정
      chunkFilename: '[id].css', // 청크별로 파일 이름을 id로 설정
    }),
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production'), // 빌드 환경을 'production'으로 설정
    }),
    new BabiliPlugin(), // 코드 압축을 통해 최적화하는 플러그인
  ],
  devMiddleware: {
    // 개발 중에 미들웨어 관련 설정
    stats: {
      // 로그 관련 설정
      colors: true, // 로그에 색상 표시
      chunks: false, // 청크 관련 정보를 표시하지 않음
      children: false, // 자식 모듈에 대한 정보를 표시하지 않음
    },
  },
}
```

```jsx
const webpack = require('webpack') // Webpack 관련 기능을 사용하기 위한 모듈을 불러옵니다.
const path = require('path') // 경로 관련 기능을 제공하는 Node.js 모듈을 불러옵니다.
const HtmlWebpackPlugin = require('html-webpack-plugin') // HTML 파일을 생성하는 플러그인
const { spawn } = require('child_process') // 자식 프로세스를 실행하기 위한 Node.js 모듈

module.exports = {
  module: {
    // Webpack이 파일을 어떻게 처리할지 정의하는 부분
    rules: [
      // 각 파일 유형별로 어떻게 처리할지 규칙을 정의
      {
        test: /\.css$/, // .css 확장자 파일에 대해 처리
        use: [{ loader: 'style-loader' }, { loader: 'css-loader' }], // style-loader와 css-loader를 사용해 CSS 파일을 처리
      },
      {
        test: /\.jsx?$/, // .js 또는 .jsx 확장자 파일에 대해 처리
        use: [{ loader: 'babel-loader', options: { compact: false } }], // Babel을 사용해 최신 JavaScript 문법을 브라우저 호환 코드로 변환
      },
      {
        test: /\.(jpe?g|png|gif)$/, // 이미지 파일 (jpg, jpeg, png, gif)에 대해 처리
        use: [{ loader: 'file-loader?name=img/[name]__[hash:base64:5].[ext]' }], // 이미지 파일을 dist 폴더에 저장하며, 파일 이름에 해시값을 추가
      },
      {
        test: /\.(eot|svg|ttf|woff|woff2)$/, // 폰트 파일에 대해 처리
        use: [{ loader: 'file-loader?name=font/[name]__[hash:base64:5].[ext]' }], // 폰트 파일을 dist 폴더에 저장하며, 파일 이름에 해시값을 추가
      },
    ],
  },
  target: 'electron-renderer', // Electron의 렌더러 프로세스 환경을 타겟으로 설정
  plugins: [
    // Webpack에서 사용할 플러그인 목록
    new HtmlWebpackPlugin({ title: 'React Electron App' }), // HTML 파일을 생성하고, title을 'React Electron App'으로 설정
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('development'), // 빌드 환경을 'development'로 설정
    }),
  ],
  devtool: 'cheap-source-map', // 소스맵 생성, 빠르고 적은 용량의 소스맵 생성
  devServer: {
    // Webpack DevServer 관련 설정
    static: {
      // 정적 파일을 제공할 디렉토리 설정
      directory: path.resolve(__dirname, 'dist'), // dist 폴더에서 파일을 제공
    },
    devMiddleware: {
      // 개발 미들웨어 관련 설정
      stats: {
        // 로그 관련 설정
        colors: true, // 로그에 색상 표시
        chunks: false, // 청크 관련 정보를 표시하지 않음
        children: false, // 자식 모듈에 대한 정보를 표시하지 않음
      },
    },
    setupMiddlewares(middlewares, devServer) {
      // DevServer에 사용할 커스텀 미들웨어 설정
      middlewares.unshift((req, res, next) => {
        console.log('Custom middleware is working!') // 요청이 들어오면 콘솔에 로그를 출력
        next() // 미들웨어 체인 계속 실행
      })

      // Electron 실행
      spawn('electron', ['.'], {
        shell: true, // 쉘을 통해 실행
        env: process.env, // 환경 변수 설정
        stdio: 'inherit', // 입출력 스트림을 부모 프로세스와 연결
      })
        .on('close', (code) => process.exit(0)) // Electron이 종료되면 Webpack DevServer도 종료
        .on('error', (spawnError) => console.error(spawnError)) // 에러 발생 시 콘솔에 출력

      return middlewares // 미들웨어 배열 반환
    },
  },
}
```
