# 셀레니움으로 네이버 뷰탭 스크롤해서 크롤링하기

## 셀레니움이 data:, 에서 멈추거나 바로 꺼져 버리는 오류

```jsx
페이지가 로드되기 전에 페이지 소스를 가져오려고 하기 때문에 발생한다.

따라서 해결책은 페이지 로드가 완료된 후에 페이지 소스를 가져오는 것.

이를 위해 Selenium의 get() 메서드를 사용하여 페이지를 로드한 후에 페이지 소스를 가져올 수 있다.

driver.get(url)  # 페이지 로드를 기다리도록 수정
```

```python
from selenium import webdriver
from bs4 import BeautifulSoup
import time

base_url = "https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query="

keyword = input("검색어를 입력하세요 : ")

url = base_url + keyword

print(url)

driver = webdriver.Chrome()

driver.get(url)  # 페이지 로드를 기다리도록 수정
time.sleep(3) # 페이지를 불러오는데 대기 시간이 필요하기 떄문

# driver.execute_script("window.scrollTo(0,2000)") # 스크롤 약간 내리기
driver.execute_script("window.scrollTo(0, document.body.scrollHeight)") # 끝까지 스크롤
time.sleep(3)

html = driver.page_source

soup = BeautifulSoup(html, "html.parser")

items = soup.select(".view_wrap")

for rank, item in enumerate(items,1):
    name = item.select_one(".name")
    title = item.select_one(".title_link")

    print(f"<<{rank}>>")
    print(name.text)
    print(title.text)
    print("")

```

## 스크롤을 내려서 페이지 전부 로드하기

```python
페이지를 내리면 무한 스크롤로 데이터가 계속 출력된다면

스크롤을 내리는 로직을 작성해서 데이터가 끝까지 출력되도록 할 수 있다
```

```python
# 필요한 라이브러리를 가져옵니다
from selenium import webdriver  # 웹 브라우저 상호작용을 자동화하기 위해
from bs4 import BeautifulSoup  # HTML 파싱을 위해
import time  # 지연을 추가하기 위해

# 네이버 검색을 위한 기본 URL
base_url = "https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query="

# 사용자로부터 검색 키워드를 입력받습니다
keyword = input("검색어를 입력하세요 : ")

# 키워드를 기본 URL에 추가하여 전체 URL을 구성합니다
url = base_url + keyword

# 구성된 URL을 출력합니다
print(url)

# Chrome 웹드라이버를 초기화합니다
driver = webdriver.Chrome()

# 웹드라이버 제어 브라우저에 URL을 로드합니다
driver.get(url)

# 페이지가 완전히 로드될 때까지 대기하기 위해 지연을 추가합니다 (이 경우 3초)
time.sleep(3)

# 페이지를 아래로 스크롤하여 더 많은 콘텐츠를 로드합니다
for i in range(5):
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight)") # 페이지 맨 아래로 스크롤
    time.sleep(3)  # 콘텐츠가 로드되는 것을 기다리기 위해 지연을 추가합니다

# 페이지의 HTML 소스 코드를 추출합니다
html = driver.page_source

# BeautifulSoup을 사용하여 HTML을 파싱합니다
soup = BeautifulSoup(html, "html.parser")

# 클래스 'view_wrap'를 가진 요소를 선택합니다 (이것은 웹페이지 구조에 특정할 수 있음)
items = soup.select(".view_wrap")

# 각 선택된 항목에 대해 반복합니다
for rank, item in enumerate(items,1):
    name = item.select_one(".name")  # 클래스 'name'을 가진 요소를 선택합니다
    title = item.select_one(".title_link")  # 클래스 'title_link'을 가진 요소를 선택합니다

    # 각 항목의 순위, 이름 및 제목을 출력합니다
    print(f"<<{rank}>>")
    print(name.text)
    print(title.text)
    print("")

```

## execute_script() 사용하기

```python
 Selenium의 execute_script() 메서드를 사용하여 JavaScript 코드를 실행하는 것


 여기서 사용된 JavaScript 코드는 window.scrollTo() 함수를 호출하는 것

 함수는 현재 창을 지정된 좌표로 스크롤하는 역할을 한다.

 이때 window.scrollTo() 함수의 첫 번째 매개변수는 가로 스크롤 위치를 나타내는데,

 여기서는 0으로 지정되어 있어 가로 스크롤을 변경하지 않는다.

 두 번째 매개변수인 document.body.scrollHeight는 현재 문서의 세로 스크롤 높이를 나타낸다.

 따라서 가로를 유지하면서 최 하단으로 스크롤을 내리는것
```

```python
pip list 를 입력하면 설치한 pip 리스트를 보여준다

selenium           4.20.0

셀레니움 버전을 확인하면 4.6 이상이다 이러면 웹 드라이버 설치 완전 자동화가 가능하다

만약 버전이 낮다면

pip install --upgrade selenium 을 입력하면 업그레이드가 가능하다

이로써 앞의 직접 드라이버를 다운받아 설치 할 필요가 없어지고

크롬웹드라이버 매니저 또한 사용 할 필요가 없어졌다

( 이제 크롬 웹 드라이버는 사용자 폴더에 셀레니움이라는 폴더가 자동으로 생기고 거기에 드라이버가 설치되어 있다 )
```
