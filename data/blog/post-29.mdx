## **MySQL 테이블에 데이터 한글 입력 시 오류**

```java
ERROR 1366 (HY000): Incorrect string value: '\xEC\x9D\xB4\xEB\xAF\xB8...' for column 'name' at row 1

insert로 테이블에 한글로 정보를 입력할 때 다음과 같은 오류가 발생

*해결법

ALTER TABLE (테이블명) convert to charset utf8;

를 사용해서 오류가 나는 테이블의 인코딩을 utf8 로 바꿔준다.

JPA 등을 사용할떄는 테이블이 자동으로 만들어지기 때문에 인코딩을 변경할 시간이 없다 ( 연관 관계를 자동으로 연결해서 )

ALTER DATABASE 테이블면 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

DB를 만들고 어플리케이션을 실행해서 테이블을 자동으로 만들기전에 위의 설정을 추가해준다
```
