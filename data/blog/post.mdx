## 1 선택

```csharp
스페이스로 4개 다 체크(◼ 상태 유지)하고 엔터 누르면 돼요. 이미 다 체크되어 있는 것 같으니 그냥 엔터만 누르면 될 것 같아요.
각각 뭐하는 건지 간단히 보면:

vercel-composition-patterns — 컴포넌트 설계 패턴 (props 폭발 방지, 재사용성)
vercel-react-best-practices — Next.js 성능 최적화 45개 규칙 (핵심)
vercel-react-native-skills — RN/Expo 베스트 프랙티스
web-design-guidelines — UI 코드 리뷰 100개 접근성/성능 규칙

4개 다 있어도 필요할 때만 자동으로 로드되니까 무겁지 않아요. 그냥 전부 설치하세요.
```

## 2 선택

```csharp
Claude Code에 설치하는 거니까 "Claude Code"만 선택하면 돼요.
스페이스바로 Claude Code (.claude/skills) 체크하고 엔터.
○ → ● Claude Code (.claude/skills)
Universal 섹션(Amp, Codex 등)은 .agents/skills에 공통 설치되는 거라 Claude Code랑은 별개예요. 지금은 Claude Code만 쓸 거니까 그것만 선택하면 충분해요.
```

## 3 선택

```csharp
그냥 Symlink 선택하고 엔터 누르면 돼요 (이미 선택되어 있으니까 바로 엔터).
차이점만 간단히 설명하면:
Symlink (추천) — 원본 파일 하나 두고 Claude Code가 그걸 가리키는 방식. npx skills update 한 번으로 전체 업데이트 가능.
Copy — 파일을 직접 복사. 나중에 업데이트하려면 수동으로 다시 해야 함.
Symlink가 관리하기 훨씬 편하니까 기본값 그대로 엔터 누르세요.
```
