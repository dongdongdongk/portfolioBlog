# **프로토타입의 기본 개념**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381372/notion-blog/_/The_Web_Developer_2022/JavaScript/_OOP/Untitled.png)

```jsx
프로토타입(prototype)은 JavaScript 객체 간의 상속을 구현하는 중요한 개념이다

모든 JavaScript 객체는 다른 객체로부터 상속된 속성과 메서드를 포함하는데, 이를 프로토타입 체인(prototype chain)이라고 한다

프로토타입은 객체의 템플릿이자 청사진 역할을 하는데,

예를 들면 배열이나 문자열과 같은 내장 객체들이 특정 프로토타입을 공유하여

해당 객체들이 공통된 메서드나 속성을 사용할 수 있도록 한다.
```

### 개발자가 커스텀으로 만든 프로토 타입

```jsx
개발자가 직접 생성한 객체에도 프로토타입을 설정할 수 있어서 해당 객체들 간에도 코드를 공유할 수 있게 된다.

예를 들어, 문자열에 새로운 메서드를 추가하거나 배열에 새로운 특성을 설정하는 것처럼
```

## **Object.prototype**

```jsx
모든 JavaScript 객체는 Object.prototype을 상속받는다.

이 객체에는 JavaScript 객체에서 공통적으로 사용되는 메서드와 속성이 정의되어 있다.
```

```jsx
const obj = {}

console.log(obj.__proto__ === Object.prototype) // true
```

## **프로토타입 체인**

```jsx
객체는 __proto__ 속성을 통해 직접 상위 객체의 프로토타입을 참조한다.

이를 통해 여러 객체가 서로 연결되어 부모 객체의 속성과 메서드를 자식 객체가 상속할 수 있다.
```

```jsx
const parent = { name: 'Parent' }
const child = { age: 10 }

child.__proto__ = parent // child 객체는 parent 객체를 상속받음
console.log(child.name) // 'Parent'
```

## **프로토타입 체인 탐색**

```jsx
프로토타입 체인은 속성이나 메서드를 찾을 때 순차적으로 상위 객체를 탐색
```

```jsx
const grandparent = { lastName: 'Grandparent' }
const parent = { name: 'Parent', __proto__: grandparent }
const child = { age: 10, __proto__: parent }

console.log(child.name) // 'Parent' (parent 객체에서 상속)
console.log(child.lastName) // 'Grandparent' (grandparent 객체에서 상속)
```

## **생성자 함수와 프로토타입**

```jsx
생성자 함수를 사용하여 객체를 생성할 때,

해당 생성자 함수의 prototype 프로퍼티에 정의된 속성과 메서드는 생성된 객체의 프로토타입이 된다.
```

```jsx
function Person(name) {
  this.name = name
}

Person.prototype.sayHello = function () {
  console.log(`Hello, my name is ${this.name}`)
}

const john = new Person('John')
john.sayHello() // 'Hello, my name is John'
```

## **Object.create를 통한 프로토타입 생성**

```jsx
Object.create()를 사용하여 직접 프로토타입을 생성할 수 있다.
```

```jsx
const parent = { name: 'Parent' }
const child = Object.create(parent)
child.age = 10

console.log(child.name) // 'Parent'
```

# 프로토 타입을 사용하는 방법

## 1.**생성자 함수 정의**

```jsx
프로토타입을 사용하려면 먼저 생성자 함수를 정의해야 한다
```

```jsx
function MyClass() {
  // 생성자 함수 내용
}
```

## **2. 프로토타입에 메서드 또는 속성 추가**

```jsx
프로토타입에 메서드나 속성을 추가하여 해당 생성자 함수로 생성된 모든 객체가 공유할 수 있도록 한다
```

```jsx
MyClass.prototype.myMethod = function () {
  // 메서드 내용
}

MyClass.prototype.myProperty = 'some value'
```

## **3. 객체 생성**

```jsx
이제 생성자 함수를 사용하여 객체를 생성
```

```jsx
const myObject = new MyClass()
```

## **4. 프로토타입 메서드 호출**

```jsx
생성된 객체에서 프로토타입에 추가한 메서드를 호출할 수 있다.
```

```jsx
myObject.myMethod()
```

## **5. 프로토타입 속성 참조**

```jsx
프로토타입에 추가한 속성은 객체에서 참조할 수 있다.
```

```jsx
console.log(myObject.myProperty)
```

```jsx
// 생성자 함수 정의
function Dog(name) {
  this.name = name
}

// 프로토타입에 메서드 추가
Dog.prototype.bark = function () {
  console.log(`${this.name} is barking!`)
}

// 객체 생성
const myDog = new Dog('Buddy')

// 프로토타입 메서드 호출
myDog.bark() // 출력: Buddy is barking!

// 프로토타입 속성 참조
console.log(myDog.name) // 출력: Buddy
```

# \***\*proto\*\***

```jsx
__proto__는 JavaScript에서 객체의 프로토타입을 참조하는 특별한 속성

그러나 주의해야 할 점이 있어서 가능한 경우에는 다른 방법을 사용하는 것이 좋다
```

## **`__proto__` 사용 방법**

```jsx
_proto__를 사용하여 객체의 프로토타입을 직접 조작할 수 있다
```

```jsx
// 객체 생성
const myObject = {}

// 프로토타입 객체 생성
const myPrototype = {
  greet: function () {
    console.log('Hello!')
  },
}

// __proto__를 사용하여 객체의 프로토타입 설정
myObject.__proto__ = myPrototype

// 프로토타입 메서드 호출
myObject.greet() // 출력: Hello!
```

## **주의사항**

```jsx
비표준 속성: __proto__는 ECMAScript 표준에서 정의한 것이 아니라 브라우저에서 제공하는 확장 속성이다.

표준에서는 Object.setPrototypeOf()이나 Object.create()와 같은 메서드를 사용하는 것을 권장

Cross-browser 호환성: 모든 환경에서 __proto__가 지원되지 않을 수 있다. 특히 최신 ECMAScript 표준에 따라 동작하지 않는 경우도 있다.

가독성과 유지보수성: 코드의 가독성과 유지보수성을 위해 가능한 경우 Object.setPrototypeOf() 메서드나 Object.create()를 사용하는 것이 좋다.
```

## **`Object.setPrototypeOf()` 사용 방법:**

```jsx
// 객체 생성
const myObject = {}

// 프로토타입 객체 생성
const myPrototype = {
  greet: function () {
    console.log('Hello!')
  },
}

// Object.setPrototypeOf() 메서드 사용
Object.setPrototypeOf(myObject, myPrototype)

// 프로토타입 메서드 호출
myObject.greet() // 출력: Hello!
```

## **`Object.create()` 사용 방법:**

```jsx
// 프로토타입 객체 생성
const myPrototype = {
  greet: function () {
    console.log('Hello!')
  },
}

// 객체 생성 및 프로토타입 설정
const myObject = Object.create(myPrototype)

// 프로토타입 메서드 호출
myObject.greet() // 출력: Hello!
```

### 차이점

```jsx
Object.create()는 새로운 객체를 생성하고 해당 객체의 프로토타입을 설정하는 데 주로 사용

Object.setPrototypeOf()은 이미 존재하는 객체의 프로토타입을 변경할 때 사용
```

## 예제

```jsx
// 객체 생성
const person = {
  name: 'John',
  age: 30,
  greet: function () {
    console.log(`Hello, my name is ${this.name}`)
  },
}

// person 객체의 프로토타입에는 Object.prototype이 연결됨
console.log(person.__proto__ === Object.prototype) // true

// 새로운 객체 생성 (상속)
const student = {
  major: 'Computer Science',
}

student.__proto__ = person // person 객체를 student 객체의 프로토타입으로 지정

// student 객체는 person과 Object.prototype의 속성과 메서드에 접근 가능
console.log(student.name) // 'John'
console.log(student.age) // 30
student.greet() // 'Hello, my name is John'
```

```jsx
이 예제에서 person 객체는 Object.prototype을 상속받는다

그리고 student 객체는 person 객체를 프로토타입으로 지정함으로써, person 객체의 속성과 메서드를 상속받게 된다.
```

# **팩토리 함수**

```jsx
팩토리 함수는 객체를 생성하고 반환하는 함수이다.

이 함수를 사용하면 유연하게 여러 객체를 만들 수 있고, 코드의 재사용성과 가독성을 향상시킬 수 있다

**( 근데 이건 거의 사용되지 않는다 )**
```

## **팩토리 함수의 구조**

```jsx
function createObject(param1, param2, ...) {
    // 객체 생성 및 초기화
    const newObject = {
        property1: param1,
        property2: param2,
        // ... 다른 속성 및 메서드
    };

    // 생성한 객체 반환
    return newObject;
}
```

## **팩토리 함수 예제**

```jsx
// 간단한 팩토리 함수
function createPerson(name, age) {
  return {
    name: name,
    age: age,
    greet: function () {
      console.log(`안녕하세요, 제 이름은 ${this.name}이고 나이는 ${this.age}살입니다.`)
    },
  }
}

// 팩토리 함수를 이용하여 객체 생성
const person1 = createPerson('홍길동', 30)
const person2 = createPerson('김철수', 25)

// 객체의 메서드 호출
person1.greet() // 출력: 안녕하세요, 제 이름은 홍길동이고 나이는 30살입니다.
person2.greet() // 출력: 안녕하세요, 제 이름은 김철수이고 나이는 25살입니다.
```

## **장점**

```jsx
재사용성: 동일한 구조의 객체를 여러 번 생성할 때 코드를 반복 작성하지 않고 팩토리 함수를 활용할 수 있다

가독성: 팩토리 함수를 사용하면 객체 생성 로직이 하나의 함수에 모이기 때문에 코드가 간결하고 가독성이 높아진다.

유연성: 생성되는 객체의 속성이나 메서드를 동적으로 정의할 수 있어서 다양한 상황에 대응할 수 있다.
```

## **유연성 있는 팩토리 함수 예제**

```jsx
function createAnimal(type, sound) {
  return {
    type,
    sound,
    makeSound: function () {
      console.log(`${this.type}이(가) ${this.sound} 소리를 냅니다.`)
    },
    setName: function (name) {
      this.name = name
    },
  }
}

const dog = createAnimal('개', '왈왈')
const cat = createAnimal('고양이', '야옹')

dog.makeSound() // 출력: 개이(가) 왈왈 소리를 냅니다.
cat.makeSound() // 출력: 고양이이(가) 야옹 소리를 냅니다.

dog.setName('뽀삐')
console.log(dog.name) // 출력: 뽀삐
```

# **생성자 함수**

```jsx
생성자 함수는 객체를 생성하기 위한 함수로, new 키워드와 함께 호출된다. 이 함수 내에서 객체의 속성을 초기화하고, 메서드를 정의할 수 있다.

* 최근에는 ES6에서 도입된 클래스(class) 문법도 생성자 함수와 유사한 기능을 제공하므로,

	프로젝트나 개발 스타일에 따라 클래스를 사용하는 경우도 많다
```

```jsx
// 생성자 함수 정의
function Car(brand, model) {
  this.brand = brand
  this.model = model
}

// 생성자 함수를 통한 객체 생성
const myCar = new Car('Toyota', 'Camry')

// 생성된 객체 사용
console.log(myCar.brand) // 출력: Toyota
console.log(myCar.model) // 출력: Camry
```

## 프로토 타입을 상속받는 예제

```jsx
// 부모 생성자 함수
function Animal(name) {
  this.name = name
}

// 부모 생성자 함수의 프로토타입에 메서드 추가
Animal.prototype.introduce = function () {
  console.log(`안녕하세요, 나는 ${this.name}입니다.`)
}

// 자식 생성자 함수
function Dog(name, breed) {
  // 부모 생성자 호출 및 속성 상속
  Animal.call(this, name)
  this.breed = breed
}

// 프로토타입 체인을 통한 상속 설정
Dog.prototype = Object.create(Animal.prototype)

// 자식 생성자 함수의 프로토타입에 메서드 추가
Dog.prototype.bark = function () {
  console.log('멍멍!')
}

// 객체 생성
const myDog = new Dog('멍멍이', '진돗개')

// 부모 생성자의 메서드 호출
myDog.introduce() // 출력: 안녕하세요, 나는 멍멍이입니다.

// 자식 생성자의 메서드 호출
myDog.bark() // 출력: 멍멍!
```

```jsx
이 예제에서, Animal이라는 부모 생성자 함수와 Dog라는 자식 생성자 함수가 있다.

Dog 생성자 함수는 Animal 생성자 함수의 속성을 상속받고, Dog의 프로토타입은 Animal의 프로토타입을 상속받는다.

이렇게 함으로써 myDog 객체는 introduce와 bark라는 두 개의 메서드를 가지게 되어, 프로토타입 체인을 통한 상속이 이루어진다.
```

## **왜 팩토리 함수가 많이 사용되지 않을까?**

```jsx
**생성자 함수의 통일성**: 생성자 함수는 객체를 생성하는 데에 일관성 있는 방법을 제공한다.

new 키워드를 사용하여 객체를 생성하는 구조가 일관성 있고, 다양한 객체를 생성할 때에도 비슷한 문법을 사용할 수 있다.

**프로토타입 체인 활용**: 생성자 함수는 프로토타입을 활용하여 메서드를 공유할 수 있다.

이는 메모리를 효율적으로 사용하고, 유사한 객체 간에 메서드를 공유할 수 있도록 한다.

( 팩토리 함수의 경우에는 각 객체가 독립적으로 생성되기 때문에 프로토타입 체인이 유지되지 않는다.

프로토타입 체인은 생성자 함수와 new 키워드를 사용했을 때에만 적용되기 때문 )

**상속의 용이성**: 생성자 함수를 사용하면 상속을 쉽게 구현할 수 있다.

자식 객체가 부모 객체의 프로토타입을 상속받아 부모의 메서드 및 속성을 활용할 수 있다.
```

# JavaScript 클래스

```jsx
JavaScript 클래스는 객체 지향 프로그래밍(OOP)에서 클래스 기반의 문법을 도입하여 객체를 생성하고 구조화하는데 사용

ES6(ECMAScript 2015)부터 도입되었으며, 기존의 프로토타입 기반의 상속보다 간편하고 명확한 문법을 제공
```

## **기본 개념**

```jsx
**클래스 선언**:

class 키워드를 사용하여 클래스를 선언

**생성자 메서드**:

constructor 메서드는 객체가 생성될 때 자동으로 호출되는 특별한 메서드이다. 객체의 초기화를 담당한다

**메서드 정의**:

클래스 내부에서 메서드를 정의할 수 있다.

**상속**:

extends 키워드를 사용하여 다른 클래스를 상속할 수 있다.

**인스턴스 생성**:

new 키워드를 사용하여 클래스의 인스턴스를 생성한다.
```

```jsx
// 기본 클래스 정의
class Animal {
  // 생성자 메서드
  constructor(name) {
    this.name = name
  }

  // 메서드 정의
  speak() {
    console.log(`${this.name}이(가) 소리를 냅니다.`)
  }
}

// Animal 클래스를 상속받는 Dog 클래스 정의
class Dog extends Animal {
  // Dog 클래스의 생성자 메서드
  constructor(name, breed) {
```

```jsx
// Color 클래스 정의
class Color {
  // 생성자 메서드: r, g, b는 색상의 RGB 값, name은 색상의 이름
  constructor(r, g, b, name) {
    this.r = r
    this.g = g
    this.b = b
    this.name = name
    this.calcHSL() // HSL 값 계산
  }

  // RGB 값 반환
  innerRGB() {
    const { r, g, b } = this // 현재 객체
    return `${r}, ${g}, ${b}`
  }

  // RGB 형식의 문자열 반환
  rgb() {
    return `rgb(${this.innerRGB()})`
  }

  // RGBA 형식의 문자열 반환 (a는 투명도, 기본값은 1.0)
  rgba(a = 1.0) {
    return `rgba(${this.innerRGB()}, ${a})`
  }

  // HEX 형식의 문자열 반환
  hex() {
    const { r, g, b } = this
    return '#' + ((1 << 24) + (r << 16) + (g << 8) + b).toString(16).slice(1)
  }

  // HSL 형식의 문자열 반환
  hsl() {
    const { h, s, l } = this
    return `hsl(${h},${s}%, ${l}%)`
  }

  // 채도가 100%인 HSL 형식의 문자열 반환
  fulllySaturated() {
    const { h, l } = this
    return `hsl(${h},100%, ${l}%)`
  }

  // 현재 색상의 보색(HSL 기준으로 180도 회전) 반환
  opposite() {
    const { h, s, l } = this
    const newHue = (h + 180) % 360
    return `hsl(${newHue},${s}%, ${l}%)`
  }

  // RGB를 HSL로 변환하는 메서드
  calcHSL() {
    let { r, g, b } = this

    // RGB 값을 0~1 범위로 변환
    r /= 255
    g /= 255
    b /= 255

    // 최대, 최소값 찾기
    let cmin = Math.min(r, g, b),
      cmax = Math.max(r, g, b),
      delta = cmax - cmin,
      h = 0,
      s = 0,
      l = 0

    // 색상 계산
    if (delta == 0) h = 0
    else if (cmax == r) h = ((g - b) / delta) % 6
    else if (cmax == g) h = (b - r) / delta + 2
    else h = (r - g) / delta + 4

    h = Math.round(h * 60)

    // 음수인 색상을 양수로 변환
    if (h < 0) h += 360

    // 밝기 계산
    l = (cmax + cmin) / 2

    // 채도 계산
    s = delta == 0 ? 0 : delta / (1 - Math.abs(2 * l - 1))

    // 채도, 밝기를 0~100 범위로 변환
    s = +(s * 100).toFixed(1)
    l = +(l * 100).toFixed(1)

    // 객체의 속성으로 HSL 값 할당
    this.h = h
    this.s = s
    this.l = l
  }
}

// Color 클래스를 이용해 객체 생성
const red = new Color(255, 67, 89, 'tomato')
red.hsl() // HSL 형식의 문자열 반환
red.opposite() // 보색 반환
red.rgba(0.3) // 투명도가 있는 RGBA 형식의 문자열 반환

// 또 다른 Color 객체 생성
const white = new Color(255, 255, 255, 'white')
```
