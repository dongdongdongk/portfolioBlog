# 실행 클래스 어노테이션 추가

```java
어플리케이션 실행 클래스에 @SpringBootApplication 어노테이션을 추가 해준다.
```

```java
@SpringBootApplication
public class DeliveryApplication {

	public static void main(String[] args) {
		SpringApplication.run(DeliveryApplication.class, args);
	}

}
```
