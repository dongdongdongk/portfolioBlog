```jsx
SecureCRT에서 인코딩을 수정하는 방법은 다음과 같습니다:

세션 설정 변경 (특정 세션에만 적용):

해당 세션을 우클릭하고 'Properties' 선택
왼쪽 메뉴에서 'Terminal' 선택
'Emulation' 섹션에서 'Character encoding' 드롭다운 메뉴 클릭
'UTF-8' 또는 필요한 인코딩 선택 (한글의 경우 'EUC-KR'이나 'CP949'도 고려)
'OK' 클릭하여 저장

글로벌 설정 변경 (모든 새 세션에 적용):

'Options' 메뉴 > 'Session Options' 선택
왼쪽 메뉴에서 'Terminal' 선택
'Emulation' 섹션에서 'Character encoding' 드롭다운 메뉴 클릭
원하는 인코딩 선택
'OK' 클릭하여 저장

실시간 변경:

연결된 세션에서 'Terminal' 메뉴 > 'Character Encoding' 선택
원하는 인코딩 선택

고급 설정:

'Options' 메뉴 > 'Global Options' 선택
'Terminal' > 'Appearance' 선택
'Font' 섹션에서 유니코드를 지원하는 폰트 선택 (예: 'Consolas', 'Courier New')

로그 파일 인코딩 설정:

로깅을 사용하는 경우, 세션 속성의 'Log File' 섹션에서 로그 파일의 인코딩도 설정 가능

주의사항:

변경 후 세션을 재연결해야 할 수 있습니다.
서버 측 설정과 일치하는 인코딩을 선택해야 합니다.
한글 표시 문제가 있다면 'EUC-KR'이나 'CP949'를 시도해 보세요.

이러한 설정 변경 후에도 문제가 지속된다면, 서버 측 설정이나 로그 생성 방식을 확인해 볼 필요가 있습니다. 또한, 팀 내 다른 개발자들이 어떤 설정을 사용하고 있는지 확인하는 것도 도움이 될 수 있습니다.
```
