## Test Annotation

### 1. @Test

```jsx
Test할 메서드 선언부에 사용
```

### 2. @BeforeAll, @AfterAll

```jsx
메서드가 static 메서드여야 함

BeforeClass
해당 Testcase가 실행 하기전 딱 한번 실행

AfterClass
행당 Testcase가 Test를 모두 끝내고 종료하기전 딱 한번 실행
```

### 3. @BeforeEach, @AfterEach

```jsx
BeforeEach
각각의 Testcase 메서드가 실행 하기전 한번씩 실행

AfterClass
행각각의 Testcase 메서드가 실행 후 한번씩 실행
```
