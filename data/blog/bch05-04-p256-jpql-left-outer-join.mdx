### r.board = b ???

```java

r.board = b는 JPA에서 자동으로 관계를 이해하고 관련 엔터티의 기본 키(PK) 와 비교하는 부분이다.

여기서 Reply 엔터티의 board 속성과 Board 엔터티의 기본 키(PK)인 bno를 비교합니다.

JPQL에서는 이러한 연관 관계를 자동으로 인식하여 적절한 조인을 수행한다. ( @Many = r.board  To  One = Board 의 PK )

"LEFT OUTER JOIN Reply r ON r.board = b" 부분에서는 Reply 엔터티의 board 속성과 Board 엔터티의 기본 키가 자동으로 일치하여 조인된다.

이러한 비교를 통해 해당 기본 키에 관련된 댓글을 검색할 수 있도록 적절한 쿼리를 생성한다.

결과적으로 r.board = b는 Board 엔터티의 기본 키와 관련된 모든 댓글을 가져올 수 있게 된다.
```

```java
@Query(value ="SELECT b, w, count(r) " +
            " FROM Board b " +
            " LEFT JOIN b.writer w " +
            " LEFT JOIN Reply r ON r.board = b " +
            " GROUP BY b",
            countQuery ="SELECT count(b) FROM Board b")
    Page<Object[]> getBoardWithReplyCount(Pageable pageable);
```

```java
BoardRepository 에 JPQL 을 사용한 메서드를 작성해준다
```

```java
조금더 자세하게 설명하자면

@Query(value ="SELECT b, w, count(r) " +   // @Query(value = 사용자가 직접 JPQL 쿼리를 작성할 때 사용  ,  Board 엔티티 전체 + Board 의 writer 댓글수 count 이렇게 3가지 select
            " FROM Board b " +  // Board 엔티티를 기준으로 쿼리를 시작
            " LEFT JOIN b.writer w " +  // Board 엔티티와 writer 연관 관계 (Board 는 Member 을 연관관게로 물고있다)
            " LEFT JOIN Reply r ON r.board = b " +  // Board 의 bno , Reply 의 board 를 조인 (둘은 연관 관계가 없다)
            " GROUP BY b", // Board 엔티티를 기준으로 그룹화
            countQuery ="SELECT count(b) FROM Board b") // 페이징 처리를 위한 전체 레코드 수를 세는 쿼리
    Page<Object[]> getBoardWithReplyCount(Pageable pageable); // 페이징 처리된 결과를 받기 위해 Pageable을 파라미터로 받는다. 결과는 Object 배열의 리스트로, 각 배열에는 Board 엔티티, writer 연관 관계, 댓글 수 등이 포함된다.
```
