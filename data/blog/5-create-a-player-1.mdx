```jsx
이를 이해하기 위해, Phaser의 입력 처리(Input Handling), 물리 엔진(Physics), 속도(Velocity) 개념을 자세히 정리해보겠습니다.
```

## 1. **Phaser에서 키보드 입력 감지하기**

```jsx
게임에서 플레이어가 키보드를 눌렀을 때, 이를 감지하여 움직이게 해야 합니다.

Phaser에서는 this.input.keyboard.createCursorKeys()를 사용하여

기본적인 화살표 키(Arrow Keys) 입력을 감지할 수 있습니다.
```

### 📌 **키 입력 설정**

```jsx

```

```jsx
위 코드를 실행하면 this.cursors 객체가 생성되며, 이 안에는 left, right, up, down 등의 키가 자동으로 포함됩니다.
```

```jsx
const { left, right, up, down } = this.cursors
```

```jsx
이제 left.isDown 또는 right.isDown을 사용하면 해당 키가 눌렸는지 여부를 알 수 있습니다.
```

## 2. **Phaser의 `update()` 함수와 프레임 별 실행**

```jsx
게임의 동작은 초당 60번(60fps) 실행되는 update() 함수에서 처리됩니다.

즉, update() 함수에서 매 프레임마다 키 입력을 확인하고 플레이어의 속도를 변경하면,

자연스럽게 움직이는 효과를 만들 수 있습니다.
```

### 📌 **`update()`에서 키 입력 처리**

```jsx
update() {
    const { left, right } = this.cursors;

    if(left.isDown) {
        this.player.setVelocityX(-this.playerSpeed);  // 왼쪽 이동 (속도를 음수로 설정)
    } else if (right.isDown) {
        this.player.setVelocityX(this.playerSpeed);   // 오른쪽 이동 (속도를 양수로 설정)
    } else {
        this.player.setVelocityX(0);  // 키를 떼면 멈춤
    }
}
```

```jsx
이 코드는 왼쪽 화살표를 누르면 왼쪽(-방향)으로 이동하고,

오른쪽 화살표를 누르면 오른쪽(+방향)으로 이동하도록 만듭니다.

키를 떼면 속도가 0이 되어 플레이어가 멈추게 됩니다.
```

## 2. 리팩토링: 플레이어 클래스로 코드 개선


### 2-1. **플레이어 클래스 생성하기 (`Player.js`)**

```jsx
import Phaser from 'phaser'

class Player extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y) {
    super(scene, x, y, 'player') // 부모 클래스인 Sprite 초기화

    scene.add.existing(this) // 스프라이트를 씬에 추가
    scene.physics.add.existing(this) // 물리 엔진 적용
  }
}

export default Player
```

```jsx
1. 클래스 상속 (extends)

		class Player extends Phaser.Physics.Arcade.Sprite

		→ Player 클래스가 Phaser의 Sprite 기능을 물려받습니다.

		→ 이렇게 하면 스프라이트의 모든 기능을 그대로 사용할 수 있습니다.

2. 생성자 (constructor)

		constructor(scene, x, y)

		→ 플레이어를 생성할 때 필요한 값(씬, x좌표, y좌표)을 받습니다.

3. super()

		super(scene, x, y, "player");

		→ 부모 클래스(Sprite)의 생성자를 호출합니다.

		→ scene, x, y, "player"(이미지 키)를 전달하여 초기화합니다.

4. 씬에 추가 (add.existing)

		scene.add.existing(this)

		→ 만든 플레이어 객체를 Phaser의 씬에 추가합니다.

5. 물리 엔진 적용 (physics.add.existing)

		scene.physics.add.existing(this)

		→ 플레이어가 중력, 충돌 등 물리 효과를 가질 수 있도록 설정합니다.
```

## `preUpdate()`로 움직임 처리하기

```jsx
이제 플레이어의 움직임을 처리하는 부분입니다.
```

### 언제 어떤 걸 써야 할까?

```jsx
플레이어, 적 등 "개별 오브젝트"의 움직임 로직 → preUpdate() 사용

게임 전반적인 상태 관리(점수, 스테이지 관리 등) → update() 사용

애니메이션이 안 되거나 물리 처리가 이상하면 → super.preUpdate() 확인하기
```

```jsx
preUpdate() {
    const { left, right } = this.cursors;

    if (left.isDown) {
        this.setVelocityX(-this.playerSpeed);  // 왼쪽으로 이동
    } else if (right.isDown) {
        this.setVelocityX(this.playerSpeed);   // 오른쪽으로 이동
    } else {
        this.setVelocityX(0);                  // 멈추기
    }
}
```

```jsx
preUpdate()란?

		preUpdate()는 매 프레임마다(초당 60번) 자동으로 호출되는 함수입니다.

		여기서 플레이어의 움직임을 처리합니다.

속도 설정 (setVelocityX())

		this.setVelocityX(속도) → X축으로 움직임을 설정합니다.

		-this.playerSpeed → 왼쪽으로 이동

		this.playerSpeed → 오른쪽으로 이동

		0 → 정지

중요한 주의점:

		preUpdate()를 사용할 때는 항상 super.preUpdate(time, delta)를 호출해야 합니다.

		그래야 애니메이션이 정상적으로 작동합니다.
```

## 예제: 움직임 처리 비교

### (1) `update()` 사용 시 (씬 단위)

```jsx
class PlayScene extends Phaser.Scene {
  create() {
    this.player = new Player(this, 100, 100)
  }

  update() {
    this.player.move() // 씬의 update에서 플레이어 이동 처리
  }
}
```

```jsx
장점: 모든 게임 로직을 한 곳에서 관리하기 쉬움

단점: 플레이어 클래스가 아닌 씬에 로직이 집중됨 → 코드 분산 어려움
```

### (2) `preUpdate()` 사용 시 (플레이어 클래스 단위)

```jsx
class Player extends Phaser.Physics.Arcade.Sprite {
  preUpdate(time, delta) {
    super.preUpdate(time, delta) // ⭐ 필수
    this.move() // 자체적으로 움직임 처리
  }
}
```

```jsx
장점: 플레이어 관련 로직이 Player 클래스에 집중 → 더 깔끔한 구조

단점: 여러 개의 객체가 있을 경우 preUpdate()가 여러 번 호출되어 성능 이슈 가능성 (극단적인 경우)
```

### `super.preUpdate()`를 반드시 호출해야 하는 이유

```jsx
Phaser.Physics.Arcade.Sprite는 내부적으로 애니메이션, 물리 계산 등을 preUpdate()에서 처리합니다.

super.preUpdate()를 호출하지 않으면:

		애니메이션이 작동하지 않음

		충돌 처리 이상

		기타 Phaser의 내부 기능들이 비정상 작동
```

## 4. Play 씬과의 연결

```jsx
플레이어를 Play 씬에서 생성하고 관리합니다.
```

```jsx
import Phaser from 'phaser'
import Player from '../entities/Player'

class Play extends Phaser.Scene {
  constructor() {
    super('PlayScene')
  }

  create() {
    const map = this.createMap()
    const layers = this.createLayers(map)
    this.player = this.createPlayer()

    this.physics.add.collider(this.player, layers.platformsColliders)
  }

  createMap() {
    const map = this.make.tilemap({ key: 'map' })
    map.addTilesetImage('main_lev_build_1', 'tiles-1')
    return map
  }

  createLayers(map) {
    const tileset = map.getTileset('main_lev_build_1')
    const platformsColliders = map.createStaticLayer('platforms_colliders', tileset)
    platformsColliders.setCollisionByExclusion(-1, true)
    return { platformsColliders }
  }

  createPlayer() {
    return new Player(this, 100, 250) // 플레이어 생성
  }
}

export default Play
```

```jsx
플레이어 생성:

		this.player = this.createPlayer();


충돌 처리:

		this.physics.add.collider(this.player, layers.platformsColliders);

		→ 플레이어가 맵의 플랫폼과 충돌하도록 설정합니다.
```

```jsx
업데이트 함수 비우기:

update()는 더 이상 필요 없으므로 비워둡니다.

플레이어의 움직임은 Player 클래스의 preUpdate()에서 처리합니다.
```

## 1️⃣ **기존 구조와 문제점**

```jsx
기존에는 preUpdate() 함수를 사용하고 있었어.

preUpdate()는 스프라이트의 애니메이션을 업데이트할 때 주로 사용돼.

하지만 지금은 애니메이션이 없어서 이 함수를 사용하는 게 불필요했어.

그래서 애니메이션과 관련 없는 로직을 preUpdate()에 넣는 건 좋은 방법이 아니야.
```

## 2️⃣ **새로운 구조로 변경하기**

```jsx
preUpdate() 대신 직접 update() 함수를 만들어서 사용할 거야.

이렇게 하면 코드가 더 깔끔해지고, 나중에 애니메이션을 추가할 때 더 관리하기 쉬워져.
```

## 3️⃣ **핵심 개념: `initEvents()` 함수**

```jsx
initEvents()는 이벤트를 등록하는 역할을 해.

Phaser에서는 게임 루프가 돌아갈 때마다 update 이벤트를 발생시켜.

이 update 이벤트에 Player 클래스가 반응하도록 연결해주는 거야.
```

```jsx
initEvents() {
    this.scene.events.on(Phaser.Scenes.Events.UPDATE, this.update, this);
}
```

```jsx
this.scene.events.on(...): 이걸로 이벤트 리스너를 등록해.

Phaser.Scenes.Events.UPDATE: 이건 Phaser에서 제공하는 기본 update 이벤트야.

this.update: 이벤트가 발생하면 Player 클래스의 update() 함수가 호출돼.

this: 마지막 인자는 이벤트가 발생했을 때 참조할 컨텍스트야. 여기서는 Player 객체를 참조하도록 했어.
```

## 4️⃣ **`update()` 함수의 역할**

```jsx
update() {
    const { left, right } = this.cursors;
    if (left.isDown) {
        this.setVelocityX(-this.playerSpeed);
    } else if (right.isDown) {
        this.setVelocityX(this.playerSpeed);
    } else {
        this.setVelocityX(0);
    }
}
```

```jsx
역할:

		매 프레임마다 호출돼서 플레이어의 움직임을 처리해.

키보드 입력 감지:

		left.isDown: 왼쪽 화살표 키가 눌렸을 때.

		right.isDown: 오른쪽 화살표 키가 눌렸을 때.

속도 조절:

		왼쪽으로 이동: -this.playerSpeed

		오른쪽으로 이동: +this.playerSpeed

		아무 키도 안 눌렀을 땐 0으로 설정해서 멈춤.
```

## 5️⃣ **놓친 부분: `initEvents()` 호출하기**

```jsx
처음에는 initEvents()를 호출하지 않아서 이벤트가 등록되지 않았어.

그래서 플레이어가 움직이지 않았던 거야.

해결 방법: constructor에서 initEvents()를 호출하면 돼.
```

```jsx
constructor(scene, x, y) {
    super(scene, x, y, "player");

    scene.add.existing(this);
    scene.physics.add.existing(this);

    this.init();
    this.initEvents();  // 이 부분이 필수!
}
```

```jsx
이제 게임 루프가 돌 때마다 update()가 호출돼서 캐릭터가 잘 움직이게 됐어.
```

## 3. 애니메이션을 플레이어에 적용

### 1) 플레이어 클래스 생성

```jsx
Phaser에서 Player 클래스를 만들고 애니메이션을 적용합니다.
```

```jsx
import Phaser from 'phaser'
import initAnimations from './PlayerAnims'

class Player extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y) {
    super(scene, x, y, 'player')

    scene.add.existing(this)
    scene.physics.add.existing(this)

    this.init()
    this.initEvents()
  }

  init() {
    this.gravity = 500
    this.playerSpeed = 200

    this.body.setGravityY(500)
    this.setCollideWorldBounds(true)
    this.cursors = this.scene.input.keyboard.createCursorKeys()

    // 애니메이션 초기화
    initAnimations(this.scene.anims)
  }

  initEvents() {
    this.scene.events.on(Phaser.Scenes.Events.UPDATE, this.update, this)
  }

  update() {
    const { left, right } = this.cursors

    if (left.isDown) {
      this.setVelocityX(-this.playerSpeed)
      this.play('run', true) // 왼쪽 이동 시 run 애니메이션 실행
    } else if (right.isDown) {
      this.setVelocityX(this.playerSpeed)
      this.play('run', true) // 오른쪽 이동 시 run 애니메이션 실행
    } else {
      this.setVelocityX(0)
      this.play('idle', true) // 아무 키도 안 누르면 idle 애니메이션 실행
    }
  }
}

export default Player
```

```jsx
this.setVelocityX(-this.playerSpeed):

		→ 왼쪽으로 이동

this.setVelocityX(this.playerSpeed):

		→ 오른쪽으로 이동

this.play('run', true):

		→ 뛰는 애니메이션 실행

this.play('idle', true):

		→ 서 있는 애니메이션 실행
```

## 6. **점프 강도 조정**

```jsx
jumpSpeed를 playerSpeed * 1.5 등으로 조정하여 더 높은 점프 가능.

playerSpeed * 2 는 너무 강하기 때문에 적절한 값(예: *1.3 ~ 1.5)을 찾아 적용.
```

```jsx
this.jumpSpeed = -this.playerSpeed * 1.5
```

# { Phaser 3에서 더블 점프 구현하기 }

```jsx
이번 강의에서는 플레이어가 한 번만 점프하는 것이 아니라

공중에서 추가 점프(더블 점프)를 할 수 있도록 구현합니다.
```

## 1. 점프 관련 변수 설정

```jsx
점프를 구현하기 위해 먼저 몇 가지 변수를 설정합니다.
```

```jsx
this.jumpCount = 0 // 현재 점프 횟수
this.consecutiveJumps = 1 // 최대 연속 점프 가능 횟수
this.jumpSpeed = -250 // 점프 속도 (위로 올라가는 힘)
```

```jsx
jumpCount: 현재 몇 번 점프했는지를 저장하는 변수로, 기본값은 0입니다.

consecutiveJumps: 최대 연속 점프 가능 횟수로, 기본적으로 1로 설정하여 한 번 더 점프할 수 있도록 합니다.

jumpSpeed: 위로 이동하는 속도로, 음수 값이어야 위쪽으로 이동합니다.
```

## 2. 점프 로직 구현

```jsx
플레이어가 점프할 때 조건을 설정해 점프할 수 있는 상황을 결정합니다.
```

```jsx
if (isSpaceJustDown && (onFloor || this.jumpCount < this.consecutiveJumps)) {
  this.setVelocityY(this.jumpSpeed)
  this.jumpCount++
  this.play('jump', true)
}
```

```jsx
isSpaceJustDown: 스페이스 키가 눌렸을 때 한 번만 true를 반환하도록 함.

onFloor: 플레이어가 바닥에 있는지를 확인.

this.jumpCount < this.consecutiveJumps: 현재 점프 횟수가 연속 점프 가능 횟수보다 작은 경우 점프 가능.

점프 실행:

		setVelocityY(this.jumpSpeed)를 호출하여 플레이어가 위쪽으로 이동하도록 함.

		this.jumpCount++로 점프 횟수를 증가시킴.

		this.play('jump', true)를 호출하여 점프 애니메이션 실행.
```

## 3. 점프 횟수 초기화

```jsx
플레이어가 바닥에 닿으면 점프 횟수를 다시 0으로 초기화해야 다음 점프가 정상적으로 동작합니다.
```

```jsx
if (onFloor) {
  this.jumpCount = 0
}
```

```jsx
이렇게 하면 바닥에 닿을 때마다 jumpCount가 0으로 초기화되어 다시 두 번 점프할 수 있습니다.
```

## 4. `JustDown()`을 이용한 키 입력 처리

### 문제점

```jsx
강의에서는 단순히 space.isDown을 사용하면 점프가 여러 번 발생하는 문제를 설명합니다.
```

```jsx
const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space)
```

```jsx
space.isDown의 문제점:

		space.isDown을 사용하면 키를 누르는 동안 계속 true가 반환되어 점프가 여러 번 발생함.

		즉, 한 번만 눌러도 update()가 실행될 때마다 여러 번 호출될 가능성이 있음.

JustDown()의 해결책:

		JustDown(space)는 키를 처음 눌렀을 때 딱 한 번만 true를 반환.

		이후 계속 누르고 있어도 false를 반환하여 점프가 한 번만 실행됨.
```

## 5. 최종 코드 정리

```jsx
update() {
    const { left, right, space } = this.cursors;
    const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space);
    const onFloor = this.body.onFloor();

    if (left.isDown) {
        this.setVelocityX(-this.playerSpeed);
        this.play('run', true);
        this.setFlipX(true);
    } else if (right.isDown) {
        this.setVelocityX(this.playerSpeed);
        this.play('run', true);
        this.setFlipX(false);
    } else {
        this.setVelocityX(0);
        this.play('idle', true);
    }

    if ((isSpaceJustDown) && (onFloor || this.jumpCount < this.consecutiveJumps)) {
        this.setVelocityY(this.jumpSpeed);
        this.jumpCount++;
        this.play('jump', true);
    }

    if (onFloor) {
        this.jumpCount = 0;
    }
}
```

```jsx
✅ isSpaceJustDown을 사용해 한 번만 점프하도록 수정

✅ 점프 횟수 제한 (consecutiveJumps)을 추가하여 더블 점프 가능

✅ 바닥에 닿으면 (onFloor) jumpCount를 초기화
```
