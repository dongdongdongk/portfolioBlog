# { 언리얼 엔진에서 액터 위치 설정하기 }

## SetActorLocation 함수

**C++에서 액터의 위치를 변경하는 함수**

### 기본 문법

```cpp
SetActorLocation(FVector 위치);
```

## 사전 준비: 컴포넌트 추가

### 문제 상황

- 새로 만든 액터 클래스는 **Transform이 없음**
- Transform이 없으면 위치, 회전, 크기 설정 불가

### 해결 방법: 루트 컴포넌트 추가

### 1. 에디터에서 추가

```
아웃라이너에서 액터 선택
→ 디테일 패널 "Add Component" 버튼 (+)
→ "Cube" 선택 (임시 자리표시자)
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380616/notion-blog/_/_/_5_C_/_2_Obstacle_Assault_-_2/image.png)

### 2. 루트 컴포넌트란?

- 액터에 **처음 추가하는 컴포넌트**
- 액터의 **기준점(Transform)** 역할
- 모든 다른 컴포넌트는 루트를 기준으로 배치됨

### 큐브를 플랫폼처럼 만들기

```
Scale 조정:
- X: 3.0
- Y: 3.0
- Z: 0.15  (얇은 판 모양)
```

## SetActorLocation 사용법

### 기본 예제

```cpp
// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    Super::BeginPlay();

    // FVector로 새 위치 설정
    FVector NewLocation = FVector(-1110.0f, 610.0f, 440.0f);

    // 액터를 NewLocation으로 이동
    SetActorLocation(NewLocation);
}
```

### 단계별 설명

```cpp
// 1. 위치 벡터 생성
FVector TestVector = FVector(100.0f, 200.0f, 300.0f);
//                           ↑       ↑       ↑
//                           X       Y       Z

// 2. 액터 위치 설정
SetActorLocation(TestVector);
//  ↑ 함수 이름
//               ↑ FVector 인자
```

## 에디터에서 위치 복사하기

### 방법 1: 수동으로 복사

```
1. 액터를 원하는 위치로 이동
2. Location 값 확인
   X: -1110
   Y: 610
   Z: 440
3. 코드에 입력
```

### 방법 2: 위치 복사 기능 사용 (추천!)

```
1. 액터를 원하는 위치로 이동
2. Location 항목에서 우클릭
3. "Copy" 클릭
4. 코드에 붙여넣기 → 숫자만 추출
```

### 멤버 변수 사용 (더 좋은 방법!)

```cpp
// MovingPlatform.h
UCLASS()
class AMovingPlatform : public AActor
{
    GENERATED_BODY()

public:
    // 에디터에서 편집 가능한 목표 위치
    UPROPERTY(EditAnywhere, Category = "Movement")
    FVector TargetLocation = FVector(0.0f, 0.0f, 0.0f);

protected:
    virtual void BeginPlay() override;
};
```

```cpp
// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    Super::BeginPlay();

    // 멤버 변수 사용
    SetActorLocation(TargetLocation);

    UE_LOG(LogTemp, Warning, TEXT("목표 위치로 이동: X=%f, Y=%f, Z=%f"),
           TargetLocation.X, TargetLocation.Y, TargetLocation.Z);
}
```

## 멤버 변수 사용의 장점

### ✅ 코드 재컴파일 불필요

```cpp
// ❌ 로컬 변수: 위치 바꾸려면 코드 수정 필요
FVector TestVector = FVector(100.0f, 200.0f, 300.0f);
// → 값 바꾸려면 코드 수정 → 컴파일 → 재시작

// ✅ 멤버 변수: 에디터에서 바로 수정
UPROPERTY(EditAnywhere)
FVector TargetLocation;
// → 에디터에서 값만 바꾸면 끝!
```

## 에디터 워크플로우

### 1. 원하는 위치 찾기

```
뷰포트에서 액터를 원하는 위치로 이동
→ Transform > Location 확인
```

### 2. 위치 복사

```
Location 항목 우클릭 → Copy
또는
X, Y, Z 값 직접 확인
```

### 3. 멤버 변수에 붙여넣기

```
디테일 패널에서 TargetLocation 찾기
→ 벡터 위에서 우클릭 → Paste
```

### 4. 원위치로 되돌리기

```
액터를 원래 위치로 이동
(게임 시작 시 TargetLocation으로 텔레포트됨)
```

### 5. 테스트

```
게임 플레이 → 액터가 목표 위치로 이동 확인
```

```cpp
    APawn* PlayerPawn = GetWorld()->GetFirstPlayerController()->GetPawn();

    {
        // 플레이어 위치 가져오기
        FVector PlayerLocation = PlayerPawn->GetActorLocation();

        // 플레이어 위 100유닛에 배치

        SetActorLocation(TargetLocation);
    }
}
```

### 예제 3: 상대적 위치 이동

```cpp
void AMovingPlatform::BeginPlay()
{
    Super::BeginPlay();

    // 현재 위치 가져오기
    FVector CurrentLocation = GetActorLocation();

    // X축으로 500유닛 이동
    FVector NewLocation = CurrentLocation + FVector(500.0f, 0.0f, 0.0f);
    SetActorLocation(NewLocation);

    UE_LOG(LogTemp, Warning, TEXT("이동 전: %s"), *CurrentLocation.ToString());
    UE_LOG(LogTemp, Warning, TEXT("이동 후: %s"), *NewLocation.ToString());
}
```

- 🎮 **게임플레이 제어**: 액터를 원하는 위치로 이동

- ⚡ **텔레포트**: 순간 이동 구현

## 게임 루프 (Game Loop)

### 게임 루프란?

**게임이 실행되는 동안 계속 반복되는 사이클**

### 게임 루프의 3단계

```
┌─────────────────────────────┐
│   1. 입력 받기 (Input)       │
│   - 키보드, 마우스, 컨트롤러 │
└──────────┬──────────────────┘
           ↓
┌──────────────────────────────┐
│   2. 게임 상태 업데이트       │
│   - 변수 설정, 함수 호출      │
│   - 위치 변경, 충돌 처리      │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│   3. 렌더링 (Render)         │
│   - 그래픽을 화면에 표시      │
└──────────┬───────────────────┘
           ↓
           └─→ 다시 1번으로 (반복!)
```

### 플립북처럼 작동

```
프레임 1 → 프레임 2 → 프레임 3 → ...
(입력→업데이트→렌더링) 반복
```

## 프레임 (Frame)

### 프레임이란?

**게임 루프 한 사이클 = 1 프레임**

### FPS (Frames Per Second)

- **1초당 실행되는 프레임 수**
- 높을수록 부드러운 게임 플레이
- CPU/GPU 성능에 따라 달라짐

```
30 FPS = 1초에 30번 게임 루프 실행
60 FPS = 1초에 60번 게임 루프 실행
120 FPS = 1초에 120번 게임 루프 실행
```

## Tick 함수

### Tick이란?

**매 프레임마다 자동으로 호출되는 특수 함수**

### BeginPlay vs Tick

| 함수          | 호출 시점     | 호출 횟수          | 용도              |
| ------------- | ------------- | ------------------ | ----------------- |
| **BeginPlay** | 게임 시작 시  | **1번만**          | 초기 설정         |
| **Tick**      | 매 프레임마다 | **초당 60~120번+** | 지속적인 업데이트 |

### 시각화

```
게임 시작
    ↓
BeginPlay() ← 1번만 호출
    ↓
Tick() ← 프레임 1
    ↓
Tick() ← 프레임 2
    ↓
Tick() ← 프레임 3
    ↓
Tick() ← 프레임 4
    ↓
    ... (게임 종료까지 계속)
```

## 움직이는 플랫폼 만들기

### 문제: 같은 위치로 반복 설정

```cpp
void AMovingPlatform::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    // ❌ 매 프레임마다 같은 위치로 설정
    SetActorLocation(MyVector);
    // → 움직이지 않음! (항상 같은 곳)
}
```

### 해결: 위치 값을 증가시키기

```cpp
void AMovingPlatform::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    // 1. Z 값 증가
    MyVector.Z = MyVector.Z + 1.0f;

    // 2. 새 위치로 이동
    SetActorLocation(MyVector);
}
```

## 위치 증가 원리

### 작동 방식

```cpp
MyVector.Z = MyVector.Z + 1.0f;
```

### 단계별 설명

```
프레임 1:
  MyVector.Z = 10
  → 10 + 1 = 11
  → MyVector.Z = 11

프레임 2:
  MyVector.Z = 11
  → 11 + 1 = 12
  → MyVector.Z = 12

프레임 3:
  MyVector.Z = 12
  → 12 + 1 = 13
  → MyVector.Z = 13

... (계속 증가)
```

### 시각화

```
프레임마다 Z 위치 +1

Z=10 → Z=11 → Z=12 → Z=13 → ...
  ↑      ↑      ↑      ↑
위로   위로   위로   위로
```

## 좌표축 이해

### 언리얼 엔진 좌표계

```
        Z (위)
        ↑
        |
        |
        └─────→ X (앞/오른쪽)
       /
      /
     Y (옆)
```

### 방향 예시

- **X +** : 빨간 화살표 방향
- **Y +** : 초록 화살표 방향
- **Z +** : 파란 화살표 방향 (위로)

# { DeltaTime을 사용한 프레임 독립적 움직임 }

## 문제: 속도 문제 (Speed Problem)

### 현재 상황

```cpp
// Tick 함수 내부
CurrentLocation.X = CurrentLocation.X + 1;
```

- **빠른 컴퓨터** (100 FPS): 초당 100cm 이동
- **느린 컴퓨터** (30 FPS): 초당 30cm 이동
- 💥 **같은 게임이 컴퓨터마다 다르게 작동!**

---

## 해결책: DeltaTime

### DeltaTime이란?

> CPU가 마지막 프레임을 계산하는 데 걸린 시간(초 단위)

**게임 루프:**

1. 입력 받기
2. 게임 상태 업데이트
3. 그래픽 렌더링

이 전체 사이클이 한 프레임이고, 걸린 시간이 DeltaTime

---

## DeltaTime 작동 원리

### 컴퓨터 비교

| 컴퓨터 | FPS | DeltaTime |
| ------ | --- | --------- |
| 느림   | 10  | 0.1초     |
| 빠름   | 100 | 0.01초    |

**법칙:** 컴퓨터가 느릴수록 DeltaTime 커짐 ⬆️

---

### DeltaTime 없을 때

```
느린 컴퓨터: 10프레임 × 1 = 10cm/초
빠른 컴퓨터: 100프레임 × 1 = 100cm/초  ❌ 다름!
```

### DeltaTime 사용할 때

```
느린 컴퓨터: 10프레임 × (1 × 0.1) = 1cm/초
빠른 컴퓨터: 100프레임 × (1 × 0.01) = 1cm/초  ✅ 같음!
```

---

## 코드 구현

### 기본 공식

```cpp
void ATick(float DeltaTime) {
    // DeltaTime은 Tick 함수의 인자로 자동 제공됨

    CurrentLocation.X = CurrentLocation.X + (1 * DeltaTime);

    // 괄호로 명확하게 표시
}
```

### 실용적인 속도 설정

```cpp
// DeltaTime 사용 시 숫자가 매우 작아짐
CurrentLocation.X = CurrentLocation.X + (100 * DeltaTime);
// 100 = 초당 100cm 이동 (= 1m/초)
```

---

## 핵심 개념

### ⚠️ 중요한 변화

- **이전**: 1 입력 → 컴퓨터마다 다른 속도
- **이후**: 100 입력 → 초당 100cm로 통일

### 💡 생각 방식 전환

```
"프레임당 1씩" ❌
         ↓
"초당 100cm씩" ✅
```

# { 멤버 함수 (Member Function) }

## 멤버 함수란?

**클래스에 속하는 함수** = 클래스의 모든 기능에 접근 가능

```cpp
// 일반 함수 ❌
void Test() {
    GetActorLocation();  // 에러!
}

// 멤버 함수 ✅
void AMovingPlatform::MovePlatform() {
    GetActorLocation();  // OK!
}
```

## 멤버 함수 만드는 방법

### 1단계: 헤더 파일에 선언 (Declaration)

```cpp
// MovingPlatform.h

class AMovingPlatform : public AActor {
    GENERATED_BODY()

public:
    void BeginPlay() override;
    void Tick(float DeltaTime) override;

    void MovePlatform(float DeltaTime);  // 👈 선언 (세미콜론!)
};
```

### 2단계: CPP 파일에 정의 (Definition)

```cpp
// MovingPlatform.cpp

void AMovingPlatform::MovePlatform(float DeltaTime) {
//   ↑클래스명  ↑범위해상도연산자  ↑함수명

    // 함수 본문
    FVector CurrentLocation = GetActorLocation();
    CurrentLocation += PlatformVelocity * DeltaTime;
    SetActorLocation(CurrentLocation);
}
```

## 선언 vs 정의

| 구분     | 위치       | 형태                    | 역할               |
| -------- | ---------- | ----------------------- | ------------------ |
| **선언** | 헤더 (.h)  | `void Func();`          | "이런 함수 있어요" |
| **정의** | CPP (.cpp) | `void Class::Func() {}` | "실제 코드 구현"   |

```cpp
// 선언 - 세미콜론 O

// 정의 - 중괄호 O

    // 실제 코드
}
```

# { 클래스와 인스턴스 (Class & Instance) }

## 핵심 개념

### 클래스 (Class) = 레시피 📋

- 어떻게 만들지 설명하는 설계도
- 헤더(.h) + CPP(.cpp) 파일
- 변수와 함수의 구조 정의

### 인스턴스 (Instance) = 실제 요리 🍕

- 레시피로 만든 실제 게임 오브젝트
- 레벨에 배치된 각각의 액터
- 클래스를 기반으로 생성

```
클래스 = 붕어빵 틀 🔧
인스턴스 = 실제 붕어빵 🥐🥐🥐

하나의 틀(클래스)로
여러 개의 붕어빵(인스턴스) 생성!
```

4. **클래스 수정 = 강력함** (전체 업데이트)
5. **인스턴스 수정 = 안전함** (다른 것 안 깨짐)

## 구현 전략

### 필요한 것들

1. **시작 위치 (Start Location)** 📍
   - 게임 시작 시 플랫폼의 원래 위치
   - 돌아올 기준점
2. **이동 거리 (Distance Moved)** 📏
   - 시작 위치에서 얼마나 멀어졌는지
   - 실시간 추적
3. **최대 거리 (Max Distance)** - 다음 강의
   - 이동할 수 있는 최대 거리
   - 이 거리 도달 시 → 돌아오기

---

## 시각적 이해

```
시작 위치          현재 위치
    ↓                ↓
    [=================]
    ←  이동 거리 (Distance)  →

예: 300cm 이동 → 다시 돌아감
```

## 코드 구현

### 1단계: 시작 위치 멤버 변수 생성

### 헤더 파일 (.h)

```cpp
// MovingPlatform.h

class AMovingPlatform : public AActor {
    GENERATED_BODY()

public:
    // ... 기존 코드

private:
    // 시작 위치 저장
    FVector StartLocation;  // UPROPERTY 없음! (내부용)
};
```

**왜 UPROPERTY 없나요?**

- 에디터에서 수정할 필요 없음
- C++ 내부에서만 사용
- 자동으로 계산되는 값

---

### 2단계: BeginPlay에서 시작 위치 저장

### CPP 파일 (.cpp)

```cpp
void AMovingPlatform::BeginPlay() {
    Super::BeginPlay();

    // 게임 시작 시 현재 위치를 시작 위치로 저장
    StartLocation = GetActorLocation();
}
```

**시점:**

- 게임 시작 시 (또는 액터 스폰 시)
- 딱 1번만 실행
- 이후 변하지 않음

---

### 3단계: 이동 거리 계산

### FVector::Dist() 함수 사용

```cpp
// 두 점 사이의 거리 계산
float Distance = FVector::Dist(Point1, Point2);
```

**함수 설명:**

- **클래스 함수**: FVector 클래스에 속함
- **호출 방법**: `FVector::함수명` (범위 해상도 연산자)
- **매개변수**: 두 개의 FVector
- **반환값**: double (float으로 저장 가능)

---

### 4단계: 이동 거리 멤버 변수 생성

### 헤더 파일 (.h)

```cpp
class AMovingPlatform : public AActor {
public:
    // 에디터에서 확인용
    UPROPERTY(VisibleAnywhere)
    float DistanceMoved = 0.0f;  // 기본값 0

private:
    FVector StartLocation;
};
```

**VisibleAnywhere:**

- 에디터에서 **볼 수만** 있음
- 수정은 불가능
- 실시간으로 값 확인 가능 👁️

---

### 5단계: MovePlatform에서 거리 계산

### CPP 파일 (.cpp)

```cpp
void AMovingPlatform::MovePlatform(float DeltaTime) {
    // 1. 현재 위치 가져오기
    FVector CurrentLocation = GetActorLocation();

    // 2. 새 위치 계산
    CurrentLocation = CurrentLocation + (PlatformVelocity * DeltaTime);

    // 3. 위치 업데이트
    SetActorLocation(CurrentLocation);

    // 4. 이동 거리 계산 (새로 추가!)
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);
}
```

## 범위 해상도 연산자 `::` 두 번째 용도

### 용도 1: 멤버 함수 정의 (이미 배움)

```cpp
void AMovingPlatform::MovePlatform() {
    // 클래스명::함수명
}
```

### 용도 2: 클래스 함수 호출 (새로 배움)

```cpp
float Distance = FVector::Dist(A, B);
// 클래스명::함수명
```

**차이점:**

- 멤버 함수: 인스턴스에 속함
- 클래스 함수 (Static): 클래스 자체에 속함

## 코드 분석

### 전체 코드 정리

```cpp
// ========== MovingPlatform.h ==========
class AMovingPlatform : public AActor {
public:
    UPROPERTY(EditAnywhere)
    FVector PlatformVelocity = FVector(100, 0, 0);

    UPROPERTY(VisibleAnywhere)  // 👈 확인용
    float DistanceMoved = 0.0f;

private:
    FVector StartLocation;  // 👈 내부용
};

// ========== MovingPlatform.cpp ==========
void AMovingPlatform::BeginPlay() {
    Super::BeginPlay();
    StartLocation = GetActorLocation();  // 👈 시작 위치 저장
}

void AMovingPlatform::MovePlatform(float DeltaTime) {
    FVector CurrentLocation = GetActorLocation();
    CurrentLocation += PlatformVelocity * DeltaTime;
    SetActorLocation(CurrentLocation);

    // 👇 거리 계산 (핵심!)
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);
}
```

## 실습 문제 & 정답

### 문제

1. `StartLocation` 멤버 변수 추가
2. `BeginPlay`에서 초기화
3. `DistanceMoved` 멤버 변수 추가 (VisibleAnywhere)
4. `MovePlatform`에서 거리 계산

### 정답

```cpp
// 헤더
UPROPERTY(VisibleAnywhere)
float DistanceMoved = 0.0f;

FVector StartLocation;

// BeginPlay
void AMovingPlatform::BeginPlay() {

    StartLocation = GetActorLocation();
}

// MovePlatform
void AMovingPlatform::MovePlatform(float DeltaTime) {
    FVector CurrentLocation = GetActorLocation();
    CurrentLocation += PlatformVelocity * DeltaTime;
    SetActorLocation(CurrentLocation);

    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);
}
```

## 자주 하는 실수

### ❌ 실수 1: StartLocation 초기화 안 함

```cpp
// BeginPlay에서 설정 안 함
void AMovingPlatform::BeginPlay() {
    Super::BeginPlay();
    // StartLocation = GetActorLocation(); ← 없음!
}
// 결과: StartLocation이 (0,0,0)으로 잘못된 거리 계산
```

### ❌ 실수 2: 잘못된 위치에서 거리 계산

```cpp
// BeginPlay에서 계산 (틀림!)
void AMovingPlatform::BeginPlay() {
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);
    // 1번만 실행됨 → 항상 0
}

// MovePlatform에서 계산 (정답!)
void AMovingPlatform::MovePlatform(float DeltaTime) {
    // 매 프레임 실행 → 실시간 업데이트 ✅
}
```

### ❌ 실수 3: UPROPERTY 잘못 사용

```cpp
// StartLocation에 EditAnywhere (불필요!)
UPROPERTY(EditAnywhere)
FVector StartLocation;
// 자동 계산되는 값이므로 수동 수정 불필요
```

## 핵심 정리

### 거리 추적 3단계

```
1. 시작 위치 저장 (BeginPlay)
   StartLocation = GetActorLocation()

2. 매 프레임 이동 (Tick → MovePlatform)
   CurrentLocation += Velocity * DeltaTime

3. 거리 계산 (MovePlatform)
   DistanceMoved = Dist(Start, Current)
```

### 핵심 함수

```cpp
// 두 점 사이 거리 계산
FVector::Dist(Point1, Point2)
```
