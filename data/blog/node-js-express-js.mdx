# Node.js란?

```jsx
**Node.js 소개**

Node.js는 JavaScript용 호스트 환경 또는 런타임으로,

주로 서버 측 프로그래밍에 사용되는 기술이다.

JavaScript는 원래 브라우저에서 실행되는 언어이지만, Node.js를 사용하면 브라우저 밖에서도 JavaScript 코드를 실행할 수 있다.

이는 V8 엔진을 기반으로 하는 Chrome의 JavaScript 엔진을 사용하여 브라우저와 독립적으로 동작한다.

**Node.js의 역할**

Node.js는 브라우저 외부에서 JavaScript를 실행하는데 중점을 둔다.

브라우저에서의 JavaScript와는 달리 DOM과 상호 작용할 수 없으며,

대신 파일 시스템 작업과 같은 다양한 API를 사용할 수 있다.

Node.js는 주로 서버 측에서 실행되어 웹 서버를 구축하거나 데이터베이스와 통신하는 등의 작업에 활용된다.

**Node.js의 특징**

브라우저 외부 실행:

브라우저에서 동작하는 것이 아니라 서버 측에서 실행되기 때문에 브라우저 제약을 벗어난 작업을 수행할 수 있다.

V8 엔진:

Chrome의 JavaScript 엔진을 기반으로 하여 빠른 실행 속도를 제공한다.

서버 사이드 개발:

주로 서버 측 개발에 활용되며, PHP나 Java 등의 대안으로 사용될 수 있다.

파일 시스템 접근:

브라우저에서는 보안 문제로 파일 시스템 접근이 제한되지만, Node.js에서는 파일 시스템 작업이 가능하다.

Node.js의 활용

Node.js는 서버 측에서의 웹 개발, API 서버 개발, 데이터베이스와의 통신, 실시간 웹 소켓 통신 등 다양한 분야에서 사용된다.

이를 통해 비동기적이고 효율적인 서버 사이드 애플리케이션을 구축할 수 있다.

**결론**

Node.js는 브라우저 외부에서 JavaScript를 실행하고 서버 측에서 다양한 작업을 수행할 수 있는 강력한 도구로,

웹 개발자들에게 다양한 가능성을 제공한다. 이를 통해 브라우저와는 다른 환경에서 JavaScript를 적극적으로 활용할 수 있다.
```

# Node.js 시작하기


# **Express.js: Node.js를 위한 웹 프레임워크**

```jsx
**Express.js 소개:**

Express.js는 Node.js를 위한 웹 프레임워크로, Node.js로 웹 애플리케이션을 쉽게 구축할 수 있게 도와준다.

**Node.js의 한계 인식:**

Node.js만 사용하면 특정 작업을 수행하는 것이 번거로울 수 있다.

**Express.js의 역할:**

Express.js는 Node.js에서 특정 작업을 간편하게 수행할 수 있도록 도와주는 프레임워크이다.

**React와의 비교:**

React는 라이브러리이지만, Express.js는 웹 프레임워크이다.

둘 다 핵심 비즈니스 로직에 집중할 수 있도록 도와주는 역할을 한다.

**다른 프레임워크 및 라이브러리와의 유사성:**

Angular, Vue 등 다른 프레임워크나 라이브러리와도 비슷한 목적과 역할을 가지고 있다.

**프레임워크의 목적:**

Express.js의 목적은 다양한 유틸리티, 함수, 메서드를 제공하여 핵심 비즈니스 로직에 집중할 수 있도록 하고,

기본적인 작업을 단축하여 서버 사이드 코드로 웹 앱을 빌드하기 쉽게 만드는 것이다.

**Express.js의 특징:**

Express.js는 미들웨어 중심으로 동작합니다. 이에 대한 이해는 본 섹션이 진행되면서 더 명확해질 것이다.
```

# **미들웨어 (Middleware):**

```jsx
Express의 미들웨어는 클라이언트 요청과 서버 응답 사이에서 동작하는 함수이다.

app.use를 사용하여 등록하거나, 라우터에 미들웨어를 등록할 수 있다.

미들웨어는 req, res, next 파라미터를 가지며, next()를 호출하여 제어를 다음 미들웨어로 전달한다.
```

## 미들웨어 예제

```jsx
// app.js
const express = require('express')
const bodyParser = require('body-parser')

const app = express()
const port = 5000

// body-parser 미들웨어 사용
app.use(bodyParser.urlencoded({ extended: true }))

// 미들웨어 등록
app.use((req, res, next) => {
  console.log('MIDDLEWARE')
  next()
})

// 라우트 핸들러 등록
app.get('/', (req, res) => {
  res.send(
    '<form action="/" method="post"><input type="text" name="username" /><button type="submit">사용자 생성</button></form>'
  )
})

app.post('/', (req, res) => {
  if (req.body) {
    res.send(`<h1>${req.body.username}</h1>`)
  } else {
    next()
  }
})

// 서버 리스닝
app.listen(port, () => {
  console.log(`Server is running on port ${port}`)
})
```

## 미들웨어 실행 순서

```jsx
app.use((req, res, next) => {
  console.log('First Middleware')
  next()
})

app.use((req, res, next) => {
  console.log('Second Middleware')
  next()
})

app.get('/', (req, res) => {
  res.send('Hello, World!')
})
```

```jsx
이 경우, 클라이언트가 '/' 경로로 요청하면 첫 번째 미들웨어가 실행되어 'First Middleware'를 출력한 후 next()를 호출한다.

그러면 두 번째 미들웨어가 실행되어 'Second Middleware'를 출력하고,

마지막으로 라우트 핸들러인 app.get이 실행되어 'Hello, World!'를 응답으로 전송한다.

* 라우터 또한 미들웨어다
```

```jsx
**미들웨어 함수 동작:**

미들웨어 함수는 즉시 실행되지 않고, 요청이 서버에 도달할 때만 실행된다.

post, use, get 메서드를 사용하여 Express.js에 로직을 설정하고,

해당 요청이 설정한 기준을 충족할 때 함수가 실행된다.

**미들웨어 함수의 특징:**

미들웨어 함수는 설정된 요건을 충족하는 요청이 수신될 때 실행된다.

함수를 등록하고 해당 함수에 대한 참조를 메모리에 저장하며, 요청이 수신될 때에만 실행된다.

**Express.js 메서드 활용:**

Express.js 메서드를 사용하여 경로에 따라 적절한 미들웨어 함수를 실행하도록 설정한다.
```
