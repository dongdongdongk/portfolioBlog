# **정수형 (Integer) 자료형**

```jsx
정수형은 소수점이 없는 숫자를 말한다.

파이썬에서는 아주 큰 수나 아주 작은 수를 다룰 때도 별도의 타입 변환이나 선언 없이 사용할 수 있다.
```

```jsx
a = 123
b = -178
c = 0
```

## **부동 소수점 수 (Float)**

```jsx
부동 소수점 수는 소수점을 포함하는 숫자이다.

파이썬에서는 소수점을 사용하거나, e나 E를 사용한 지수 표현으로 부동 소수점 수를 표현할 수 있다.

* 일반적으로 그냥 소수를 직접 쓰면 된다

( 파이썬에서 소수점이 있는 숫자를 '부동 소수점 수'라고 함.

이런 숫자는 두 가지 방법으로 표현할 수 있다. 첫 번째는 우리가 흔히 사용하는 소수점을 직접 쓰는 거.

예를 들어, 3.14나 -2.5처럼요. 두 번째 방법은 e나 E를 사용한 지수 표현.

이 방법은 숫자가 아주 크거나 작을 때 유용 )
```

```jsx
a = 1.2
b = -3.45
c = 4.24E10  # 4.24 * 10^10
d = 4.24e-10  # 4.24 * 10^(-10)
```

## **복소수 (Complex)**

```jsx
복소수는 실수부와 허수부로 구성된 숫자이다.

파이썬에서 복소수는 j 또는 J를 사용해 표현한다.
```

```jsx
a = 1+2j
b = 3-4J
```

## **연산자**

```jsx
파이썬에서는 다음과 같은 수학적 연산자를 사용할 수 있다
```

```jsx
더하기: +

빼기: -

곱하기: *

나누기: /

나머지: %

거듭제곱: **

몫: //
```

```jsx
a = 10
b = 3

print(a + b)  # 결과: 13
print(a - b)  # 결과: 7
print(a * b)  # 결과: 30
print(a / b)  # 결과: 3.3333333333333335
print(a % b)  # 결과: 1
print(a ** b) # 결과: 1000
print(a // b) # 결과: 3
```

# **문자열(str) 자료형**

```jsx
파이썬에서 문자열(str)은 텍스트 데이터를 표현하는 데 사용되는 기본적인 자료형 중 하나이다.

문자열은 작은따옴표('), 큰따옴표(") 로 둘러싸여 표현된다.
```

```jsx
s1 = 'Hello'

s2 = "World"

s3 = '''This is a multi-line
string example.'''
s4 = """This is also a multi-line
string example."""
```

## **문자열 연산**

```jsx
파이썬에서는 문자열을 쉽게 조작할 수 있는 다양한 연산이 지원된다.
```

### **연결: 두 문자열을 `+` 연산자로 연결할 수 있다.**

```jsx
greeting = s1 + ", " + s2 + "!"

print(greeting)  # Output: Hello, World!
```

### **반복: 문자열을 `*` 연산자와 정수를 사용하여 반복할 수 있다.**

```jsx
echo = "Echo! " * 3

print(echo)  # Output: Echo! Echo! Echo!
```

### **인덱싱 및 슬라이싱: 문자열 내의 특정 문자에 접근하거나, 문자열의 일부를 추출할 수 있다.**

```jsx
print(s1[1])  # Output: e

print(s2[1:4])  # Output: orl     *시작인덱스 1 부터 인덱스 4를 만나면 종료 ( 4는 포함하지 않음 )

* 음수를 넣으면 뒤에서 부터 계산한다
```

### **여러 줄에 걸친 문자열**

```jsx
s = """This is another multi-line
string example. It also spans
multiple lines."""

* 이런식으로 하면 3줄로 출력된다 \n 도 사용가능

* 내부에 "" 를 넣고 싶다면 ' "하이 " ' 이런식으로 사용하면 내부에 사용 가능
```

```jsx
파이썬에서는 문자열을 표현할 때,

한 줄짜리 문자열 뿐만 아니라 여러 줄에 걸친 문자열을 표현할 수 있는 기능을 제공

삼중 따옴표('''' 또는 """)를 사용한다.

삼중 따옴표를 사용하면 문자열 내에서 엔터를 치며 여러 줄로 표현할 수 있고,

이를 통해 코드 내에서 문자열을 보기 좋게 정리할 수 있다.

또한, 문자열 안에 따옴표를 추가적으로 사용해야 할 때 유용하게 활용할 수 있다.
```

## **문자열 메서드**

```jsx
파이썬의 문자열 객체는 다양한 메서드를 제공하여 문자열을 쉽게 처리할 수 있게 한다.
```

### len(””)

```jsx
len() 함수는 문자열의 길이를 반환하는 파이썬 내장 함수이다.

문자열뿐만 아니라, 리스트, 튜플, 딕셔너리 등 다양한 컨테이너 타입의 요소 개수를 알아낼 때 사용할 수 있다.
```

```jsx
s = "Hello, World!"

print(len(s))  # 13
```

### strip(), lstrip(), rstrip()

```jsx
공백이나 지정된 문자를 문자열의 앞뒤에서 제거.

strip()은 양쪽 모두,

lstrip()은 왼쪽,

rstrip()은 오른쪽의 공백이나 문자를 제거.
```

```jsx
s = "   Hello, World!   "
print(s.strip())  # "Hello, World!"
print(s.lstrip())  # "Hello, World!   "
print(s.rstrip())  # "   Hello, World!"
```

### upper(), lower(), capitalize()

```jsx
문자열을 대문자나 소문자로 변환하거나, 첫 글자만 대문자로 만든다.
```

```jsx
s = "python"
print(s.upper())  # "PYTHON"
print(s.lower())  # "python"
print(s.capitalize())  # "Python"
```

### split(), join()

```jsx
split()은 문자열을 지정된 구분자로 나누어 리스트로 반환.

join()은 리스트의 원소를 하나의 문자열로 합친다.
```

```jsx
s = "a,b,c"
print(s.split(','))  # ['a', 'b', 'c']
print(' '.join(['Python', 'is', 'awesome']))  # "Python is awesome"
```
