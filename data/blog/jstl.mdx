## JSTL(JSP STANDARD Tag Library)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380885/notion-blog/_/_/JSP/_4/Untitled_7.png)

```html
예전에 배운 JSP 의 반복문의 불편함을 해결해주는 라이브러리 이다. 주로 사용하는 기능은 Core Tag
(다른건 다른곳에서 해결 가능) - 스크립 틀릿을 사용하지 않음 1) JSTL 태그 a. Core Tag : 변수관리,
제어문등을 제공 접두사(prefix, 태그명) : c b. Function Tag : 문자열 조작, 문자열 길이등 함수제공
접두사 : fn c. Formatting Tag : 숫자, 날짜, 통화단위 등을 지원 : fmt d. XML Tag : XML 관련 : x e.
SQL Tag : SQL 지원 : sql
```

### Core Tag 사용 순서

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380885/notion-blog/_/_/JSP/_4/Untitled_8.png)

```html
Core Tag 사용순서 1. 사용하려는 JSP page 마다 별로 선언부에 JSTL 라이브러리 선언 <%@ taglib
prefix="c" uri="http://java.sun.com/jsp/jstl/core" %> 2.<c:태그명
  items="${Collection의 속성명(배열,리스트)"
  var="DTO를 담을 변수명"
>
  ex<c:forEach items="${list}" var="dto">
    (Controller 의 이름이 items) var = 자유롭게

    <h3>${pageScope.dto.prodcutName}</h3>
    <h3>${dto.productJumsu}</h3>
    <!-- scope 명 생략가능 -->

    <c:/태그명> if : if문 forEach : 반복문 choose : 스위치문
  </c:forEach></c:태그명
>
```

### Ex 최종출력

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380885/notion-blog/_/_/JSP/_4/Untitled_9.png)

## JSTL-<c:choose>
