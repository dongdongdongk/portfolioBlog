# 언리얼 엔진 위젯 블루프린트 초보자용 완벽 가이드

이 강의는 **게임 화면에 UI를 표시하는 위젯 블루프린트**를 만드는 방법입니다. "3, 2, 1, Go!" 같은 텍스트를 화면에 띄우는 거죠!

---

## 🎨 1. 위젯 블루프린트란?

### 일반 블루프린트 vs 위젯 블루프린트

```
일반 블루프린트
  ↓
게임 속 3D 오브젝트 (캐릭터, 차량 등)

위젯 블루프린트
  ↓
화면에 표시되는 2D UI (메뉴, 텍스트, 버튼 등)
```

### 위젯의 예시

- 체력 바
- 점수 표시
- "승리!" / "패배!" 메시지
- 카운트다운 숫자 (3, 2, 1, Go!)
- 게임 메뉴

### 각 패널 설명

### 📋 Palette (팔레트) - 왼쪽 상단

```
위젯 재료 창고

- Text (텍스트)
- Button (버튼)
- Image (이미지)
- Progress Bar (진행 바)
- Slider (슬라이더)
등등...
```

### 🌲 Hierarchy (계층구조) - 왼쪽 하단

```
위젯들의 부모-자식 관계 표시

Canvas Panel (부모)
  ├─ Text Block (자식)
  └─ Button (자식)
```

### 🖼️ Viewport (뷰포트) - 중앙

```
실제 UI 디자인 작업 공간
WYSIWYG (What You See Is What You Get)
보이는 대로 만들어짐!
```

### ⚙️ Details (디테일) - 오른쪽

```
선택한 위젯의 속성 조정

- 위치 (Position)
- 크기 (Size)
- 색상 (Color)
- 폰트 (Font)
등등...
```

### 두 가지 탭

### Designer (디자이너)

```
UI를 시각적으로 디자인
드래그 앤 드롭으로 배치
← 주로 여기서 작업!
```

### Graph (그래프)

```
블루프린트 스크립팅
이벤트와 함수 작성
(이 강의에서는 사용 안 함)
```

## 🎯 4. 핵심 개념: Canvas Panel

```
❌ 잘못된 시도:

✅ 올바른 방법:
```

### Canvas Panel = 도화지

```
Canvas Panel
  ├─ 위젯들을 배치할 수 있는 공간
  ├─ 화면 전체를 차지
  └─ 모든 UI 요소의 부모 역할
```

## ⚙️ 6. Text Block 속성 설정

### 주요 속성 섹션

### Content (콘텐츠)

```cpp
Text: "Ready"  // 표시할 텍스트 내용
```

**변경 방법:**

1. Hierarchy에서 Text Block 선택
2. Details → Content → Text
3. "Ready" 입력

---

### Appearance (외관)

### Font (폰트)

```
Font Family: 폰트 종류 선택
Font Size: 48  // 글자 크기
```

**중요:**

```
Size (위젯 크기) ≠ Font Size (글자 크기)

Size: Text Block 박스의 크기
Font Size: 실제 글자의 크기
```

### Color (색상)

```
Color and Opacity: 텍스트 색상 변경
```

### Justification (정렬)

```
Align Text in Viewport:
- Left (왼쪽 정렬)
- Center (중앙 정렬)  ← 보통 이걸 사용
- Right (오른쪽 정렬)
```

---

### Layout (레이아웃)

### Position (위치)

```
Position X: 525  // 가로 위치 (픽셀)
Position Y: 332  // 세로 위치 (픽셀)
```

### Size (크기)

```
Size X: 200  // 박스 너비
Size Y: 50   // 박스 높이
```

**뷰포트에서 직접 조작:**

```
이동: 클릭 + 드래그
크기 조절: 모서리 핸들 드래그
```

## 🔗 7. Anchor (앵커) 시스템

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380637/notion-blog/_/_/_5_C_/_4_Battle_Blaster_-_8/image_3.png)

### 앵커란?

```
앵커 = 위젯의 기준점

위젯의 위치는 항상 앵커를 기준으로 계산됨
```

### 시각적 이해

```
화면
┌─────────────────────────┐
│ ⚓ ← 앵커 (기준점)        │
│  │                      │
│  └─→ 위젯               │
│     (앵커로부터 X픽셀,   │
│      Y픽셀 떨어진 위치)  │
└─────────────────────────┘
```

### 기본 앵커 위치

```
┌─────────────────────────┐
│ ⚓ Top-Left (기본값)      │
│                         │
│           ⚓ Center      │
│                         │
│                         │
│              ⚓ Bottom-Right
└─────────────────────────┘
```

## 🎯 9. 위젯을 화면 중앙에 배치하기

### 단계별 가이드

### 1단계: 앵커를 중앙으로

```
Details → Anchors → 프리셋 선택
┌──────────────┐
│  □  □  □    │
│  □  ■  □    │  ← 가운데 클릭
│  □  □  □    │
└──────────────┘
```

### 2단계: 위치 리셋

```
Position:
X: 0
Y: 0

결과: 위젯의 왼쪽 상단이 화면 중앙에
```

### 3단계: Alignment 조정

```
Alignment:
X: 0.5  // 위젯을 가로 중앙 정렬
Y: 0.5  // 위젯을 세로 중앙 정렬

최종 결과: 위젯의 중심이 화면 중앙에!
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380637/notion-blog/_/_/_5_C_/_4_Battle_Blaster_-_8/image_4.png)

### Alignment 값의 의미

```
Alignment X:
0.0 = 위젯의 왼쪽 끝을 기준점으로
0.5 = 위젯의 중앙을 기준점으로
1.0 = 위젯의 오른쪽 끝을 기준점으로

Alignment Y:
0.0 = 위젯의 위쪽 끝을 기준점으로
0.5 = 위젯의 중앙을 기준점으로
1.0 = 위젯의 아래쪽 끝을 기준점으로
```

## 🪟 11. 앵커의 반응형 기능

### 왜 앵커가 중요한가?

```
창 크기 조정 시:

앵커 없이:
- 위젯이 절대 위치에 고정
- 해상도 변경하면 위치 깨짐

앵커 사용:
- 앵커가 비율로 이동
- 위젯도 따라서 적절히 이동
- 어떤 해상도에서도 올바른 위치 유지!
```

### 실전 예시

```
1920x1080 화면:
┌────────────────────┐
│         ⚓          │
│       [위젯]       │
└────────────────────┘

1280x720 화면:
┌─────────────┐
│      ⚓      │
│    [위젯]   │  ← 여전히 중앙!
└─────────────┘
```

## 🎯 15. 자주 하는 실수와 해결

### 실수 1: Canvas 없이 위젯 추가

```
❌ Text Block을 바로 추가하려 함
✅ 먼저 Canvas Panel 생성 필수!
```

### 실수 2: Size와 Font Size 혼동

```
❌ Size를 키워도 글자가 안 커짐
✅ Font Size를 변경해야 글자 커짐
```

### 실수 3: 중앙 정렬 실패

```
❌ Position만 (0, 0)으로 설정
✅ Anchor + Position + Alignment 모두 설정!
```

### 실수 4: 위젯이 안 보임

```
원인:
- Canvas 밖에 배치
- 크기가 0
- 투명도가 0
- 눈 아이콘으로 숨김

해결:
- Hierarchy에서 위치 확인
- Size 확인
- Opacity 확인
- 눈 아이콘 확인
```

# { C++ 위젯 클래스 만들기 }

이 강의는 **위젯 블루프린트를 C++ 코드로 제어**하기 위한 클래스를 만드는 방법입니다. 게임 상황에 따라 화면 텍스트를 바꿀 수 있게 됩니다!

## 🎯 1. 왜 C++ 위젯 클래스가 필요한가?

### 문제 상황

```
위젯 블루프린트만 있으면:
- 화면에 "Ready" 텍스트 표시 ✅
- 하지만... 고정된 텍스트만 표시 가능 ❌
- 게임 상황에 따라 변경 불가 ❌

원하는 것:
- 카운트다운: "3" → "2" → "1" → "Go!"
- 게임 종료: "Victory!" 또는 "Defeat!"
- 점수 업데이트: "Score: 100" → "Score: 150"
```

### 해결책: C++ + 위젯 블루프린트

```
C++ 클래스 (로직)
    ↓
  연결
    ↓
위젯 블루프린트 (디자인)

C++에서 텍스트 변경 가능!
```

## 🔍 4. 변수 상세 분석

### (1) TSubclassOf<UScreenMessage>

```cpp
UPROPERTY(EditAnywhere)
TSubclassOf<UScreenMessage> ScreenMessageClass;
```

### TSubclassOf란?

```cpp
TSubclassOf<클래스명>

의미:
"이 클래스 또는 이 클래스의 자식 클래스만 할당 가능"

예시:
TSubclassOf<UScreenMessage>
→ UScreenMessage 클래스
→ 또는 UScreenMessage를 상속받은 클래스
→ BP_ScreenMessage (위젯 블루프린트) ✅
```

### 왜 필요한가?

```
C++ 코드에서는:
- 위젯 블루프린트에 직접 접근 불가
- 에디터에서 설정해야 함

TSubclassOf:
- 에디터에서 블루프린트를 선택할 수 있게 함
- 타입 안전성 보장 (엉뚱한 클래스 선택 방지)
```

### 시각적 비교

```
일반 포인터:
UScreenMessage* Widget;
→ 위젯 인스턴스(객체) 저장
→ 실제 위젯 자체

TSubclassOf:
TSubclassOf<UScreenMessage> WidgetClass;
→ 위젯 클래스(설계도) 저장
→ 위젯을 만들 수 있는 레시피
```

## 🤔 14. 자주 하는 질문

### Q1: CreateWidget이 nullptr을 반환해요!

**원인:**

```

```

### Q2: 위젯이 화면에 안 나타나요!

**체크리스트:**

```
□ CreateWidget 성공했나요?
□ AddToViewport 호출했나요?
□ SetVisibility(Visible) 상태인가요?
□ 텍스트 색상이 배경과 같은 색은 아닌가요?
```

### Q3: TSubclassOf가 뭔가요?

```
일반 포인터 vs TSubclassOf:

UScreenMessage* Widget;
→ 위젯 객체 저장 (인스턴스)

TSubclassOf<UScreenMessage> WidgetClass;
→ 위젯 클래스 저장 (설계도)
→ 에디터에서 블루프린트 선택 가능
```

### Q4: AddToViewport vs AddToPlayerScreen?

```
같은 기능!

AddToViewport():
- 표준 함수명
- UMG 공식 문서에 나옴

AddToPlayerScreen():
- 일부 버전에서 사용
- 내부적으로 같은 동작

둘 다 사용 가능!
```

## 🎨 1. 파티클 시스템이란?

### 시각적 효과의 종류

```
파티클 = 작은 입자들의 집합으로 만든 효과

- 폭발 💥
- 연기 💨
- 불꽃 ✨
- 물보라 💦
- 마법 효과 🔮
```

### 이 게임에서 사용할 3가지 효과

```
1. Death Effect (사망 효과)
   → 탱크/타워가 파괴될 때 폭발

2. Hit Effect (타격 효과)
   → 발사체가 뭔가에 부딪힐 때

3. Trail Effect (궤적 효과)
   → 발사체 뒤에 따라다니는 연기
```

## 🎯 6. Trail Particles 구현 (컴포넌트)

```cpp
{
    PrimaryActorTick.bCanEverTick = true;

    // 메쉬 생성
    ProjectileMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("ProjectileMesh"));
    SetRootComponent(ProjectileMesh);

    // 이동 컴포넌트
    ProjectileMovementComp = CreateDefaultSubobject<UProjectileMovementComponent>(TEXT("ProjectileMovementComp"));
```

```
    └─ TrailParticles (자식)

효과:
- ProjectileMesh가 이동하면

- 항상 발사체 뒤에 위치
```

```cpp
void AProjectile::OnHit(...)
{
    AActor* MyOwner = GetOwner();

    if (MyOwner)
    {
        if (OtherActor && (OtherActor != MyOwner) && (OtherActor != this))
        {
            // 데미지 적용
            UGameplayStatics::ApplyDamage(...);

            // Hit 파티클 스폰

            {

                    GetActorLocation(),   // 위치
                    GetActorRotation()    // 회전
                );
            }
        }
    }

    Destroy();  // 발사체 파괴
}
```

## 🔊 1. 사운드 효과란?

### 게임의 소리 종류

```cpp
void AProjectile::OnHit(
    UPrimitiveComponent* HitComponent,
    AActor* OtherActor,
    UPrimitiveComponent* OtherComp,
    FVector NormalImpulse,
    const FHitResult& Hit
)
{
    AActor* MyOwner = GetOwner();

    if (MyOwner)
    {
        if (OtherActor && (OtherActor != MyOwner) && (OtherActor != this))
        {
            // 데미지 적용
            UGameplayStatics::ApplyDamage(...);

            // Hit Particles 스폰
            if (HitParticles)
            {
                UNiagaraFunctionLibrary::SpawnSystemAtLocation(...);

            // Hit Sound 재생
            if (HitSound)
            {
                UGameplayStatics::PlaySoundAtLocation(
                    GetWorld(),           // 월드
                    HitSound,             // 충돌음
                    GetActorLocation()    // 충돌 위치
                );
            }
        }
    }

    Destroy();
}
```

```cpp
    GetWorld(),
    Sound,
    Location,
    Volume
);
```
