
```jsx
실행 파일 생성

pyinstaller --onefile OCR.py

* 이 명령어는 PyInstaller에게 모든 종속성을 단일 파일로 패키징하라고 지시합니다. --onefile 옵션은 모든 종속성을 하나의 파일에 포함시킵니다.

pyinstaller --onefile -w OCR.py

* 콘솔 없이 나오게 하기
```

```jsx
dist 내부에 있는 파일이 단일 실행 파일
```

```jsx
아이콘 지정: 실행 파일에 아이콘을 지정하려면 --icon 옵션을 사용할 수 있습니다. 예를 들어:

pyinstaller --onefile --icon=youricon.ico OCR.py
```
