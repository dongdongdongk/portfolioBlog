# 단축키

## 기본 도구 선택:

```jsx
기본적으로 이동 도구가 선택되어 있으며, 단축키는 'V'
```

## 화면에 맞추기

```jsx
	단축키: Shift + 1을 눌러 '화면에 맞추기' 기능을 사용할 수 있습니다.
```

## 눈금자 도구

```jsx
	눈금자 도구: Shift + R을 눌러 눈금자 도구를 켜고 끌 수 있습니다.
```

## 선 도구 선택

```jsx
단축키 L을 사용
```

## 타원 도구 선택

```jsx
타원 도구 선택: 도형 도구에서 타원을 선택하거나 단축키 O를 사용
```

## 스트로크 전환

```jsx
스트로크 전환: Shift + X를 눌러 채우기와 스트로크를 전환
```

## 펜 도구 선택

```jsx
펜 도구 선택: 그리기 도구에서 펜 도구를 선택하거나 단축키 P를 사용
```

## 모양 복사 및 뒤집기

```jsx
모양 복사 및 뒤집기: 옵션을 눌러 모양을 복사하고, Shift + H 를 눌러 가로로 뒤집습니다. Shift + V는 세로로 뒤집습니다.
```

## 연필 도구 선택

```jsx
연필 도구 선택: 연필 도구를 선택하거나 단축키 Shift + B를 사용
```
