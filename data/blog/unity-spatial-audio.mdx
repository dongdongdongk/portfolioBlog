## 1. Spatial Audio 개념 이해하기

- \*Spatial Audio(공간 오디오)\*\*란?
  - 게임 내 **소리의 위치, 거리, 방향, 반사, 차폐 효과** 등을 현실적으로 표현하는 기술입니다.
  - 리스너(플레이어의 귀)와 사운드 소스의 상대적 위치를 계산해 **3D 공간감**을 제공합니다.
- **핵심 구성 요소**
  - 🎧 **Listener(리스너)**:
    - 플레이어의 청취 위치를 의미합니다.
    - Unity에서는 주로 **플레이어 카메라**나 **캐릭터 오브젝트**에 부착합니다.
  - 🔊 **Emitter(방사체)**:
    - 사운드를 내는 오브젝트(예: 버튼, 스피커, 폭발물 등).
    - 소리의 위치, 방향, 감쇠(Attenuation)를 가집니다.
  - 🏠 **Room & Portal(공간과 포털)**:
    - 소리가 방 안에 갇히거나, 문을 통해 약하게 들리게 하는 구조를 표현합니다.
    - 예: 벽 너머에서 들리는 소리, 문틈으로 새는 소리 등.
  - 🌊 **Auxiliary Sends(보조 전송)**:
    - 리버브(잔향)나 환경음 같은 효과를 공간에 맞게 적용합니다.

## 2. Unity 프로젝트 만들기

### 🎯 목적

Wwise를 통합할 Unity 환경을 세팅합니다.

### 🧭 단계

1. **Unity 실행 → 새 프로젝트 생성**
   - 최신 버전의 Unity 사용을 권장합니다.
   - 예: “SpatialAudioTutorial” 이름으로 생성.
2. **Unity 닫기**
   - Wwise 통합 시 Unity를 닫은 상태여야 오류 없이 진행됩니다.
3. **Audiokinetic Launcher 실행**
   - 메뉴에서 `Unity 프로젝트 통합 (Integrate Wwise into Unity Project)` 선택.
   - 방금 만든 Unity 프로젝트 폴더를 지정.
4. **통합 완료**
   - 이제 Unity 프로젝트에 Wwise 관련 플러그인과 스크립트가 자동으로 추가됩니다.

## 3. Wwise 프로젝트 준비하기

### 🎯 목적

튜토리얼에서 사용할 **사운드, 이벤트, 사운드뱅크**를 생성합니다.

---

- **Launcher를 통해 Wwise 프로젝트 열기**
- **Actor-Mixer Hierarchy → Default Work Unit** 안에 새 **Sound SFX** 추가
- **사운드 파일 가져오기** (예: 버튼 클릭 사운드, 환경음 등)

---

### 2️⃣ Sound Property 설정

### 🎚 General Settings 탭

- **Use game-defined auxiliary sends**
  → ✔️ **활성화**
  → 게임 내에서 정의된 리버브나 공간 효과를 사운드가 받을 수 있도록 허용합니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380583/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image.png)

### 📍 Positioning 탭

- **Listener Relative Routing** → ✔️ 활성화
  → 리스너(플레이어) 기준으로 3D 공간 오디오 계산을 수행.
- **3D Spatialization** → `Position + Orientation` 선택
  → 위치뿐 아니라 방향성까지 포함한 공간적 소리 계산.
- **Attenuation(감쇠)** → 새로 추가
  → 사운드가 멀어질수록 볼륨이 점차 줄어드는 거리 기반 효과.
  - 예: Max Distance = 20m (적절한 범위 설정)

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380577/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image_1.png)

---

### 3️⃣ Event 만들기

- **Sound SFX 우클릭 → New Event → Play**
  - 해당 사운드를 재생할 이벤트 생성.
- **Event Editor**에서 이름 지정 (예: `Play_ButtonSound`)

---

### 4️⃣ SoundBank 생성

- 단축키 `F7` → **SoundBank 레이아웃**으로 이동
- 새 **SoundBank** 추가 (예: `SpatialAudio_Bank`)
- 방금 만든 **Event**를 이 SoundBank에 **드래그 앤 드롭**
- 프로젝트 저장 (Ctrl + S)

- **AkSpatialAudioListener** 컴포넌트 추가
  → 이때 자동으로 아래 컴포넌트들이 함께 추가됨:
  - **AkAudioListener**
  - **AkGameObj**
  - **AkRoomAwareObject**

### ⚙ 설정 정리

- **AkGameObj**
  - “Environment Aware” 체크 해제 → 환경에 의한 보조 이펙트 비활성화
  - “Use Default Listener” 활성화 → 기본 리스너로 설정

  - AkRoom 컴포넌트를 아직 사용하지 않기 때문에 나오는 메시지는 무시 가능.

### 3️⃣ 씬 만들기

- 예: `GameObject > 3D Object > Cylinder`
- 각 공간의 안팎에 하나씩 배치 (총 2개 버튼)

## 1. 개념 이해하기

### 🎧 1-1. 표면 리플렉터란?

- **Surface Reflector**는 **소리가 벽, 바닥, 천장 같은 표면에서 반사되는 효과**를 시뮬레이션하는 시스템입니다.
- 실제 공간에서 소리는 표면에 닿을 때 일부는 반사되고, 일부는 흡수됩니다.
  이 반사음을 시뮬레이션하면 **공간의 크기, 재질, 방향감**이 훨씬 현실적으로 느껴집니다.

---

### 🪞 1-2. Reflect 플러그인의 역할

- Wwise의 **Reflect 플러그인**은 **초기 반사음(Early Reflection)**을 계산하는 데 사용됩니다.
- 어떤 표면에 반사되는지, 반사각이 어떤지, 반사 후 감쇠 정도(attenuation)는 얼마인지 등을 자동으로 계산해줍니다.
- Reflect 플러그인을 사용하면:
  - 벽, 바닥, 천장과 같은 표면을 지정할 수 있고,
  - Acoustic Texture(음향 텍스처)에 따라 반사 특성이 달라집니다 (예: 금속, 나무, 천 등).

---

### 🧱 1-3. Acoustic Texture (음향 텍스처)

- Acoustic Texture는 **소리의 반사, 흡수, 투과 특성**을 표현하는 **소재 데이터**입니다.
- 예를 들어:
  - **Metal** → 강하게 반사, 거의 흡수 없음
  - **Carpet** → 반사 거의 없음, 흡수 강함
- 이 텍스처는 Wwise의 ShareSets 탭 > Virtual Acoustics 폴더 안에 있습니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380582/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image_7.png)

---

### 🌊 1-4. 반사의 순서 (Reflection Order)

- 반사는 **몇 번 튕길 것인지**를 의미합니다.
  - **1차 반사(1st order)**: 소리가 표면에 한 번 튕겨서 리스너에게 옴.
  - **2차 반사(2nd order)**: 두 번 튕긴 후 도달.
- Unity의 **AkWwiseInitializationSettings > Spatial Audio Settings**에서 Order를 설정할 수 있습니다.
  - 기본값: 1
  - 최대: 4

## 추천 순서:

### 1. **Physically-Based Early Reflection** ⭐ (가장 추천)

- **최신 방식**으로 물리 기반 음향 시뮬레이션
- 가장 현실적이고 정확한 초기 반사음
- **CPU 사용량**: 중간~높음
- **사용 케이스**: 고품질 음향이 중요한 프로젝트, PC/콘솔 게임

### 2. **Simplified Early Reflection**

- 성능과 품질의 균형
- **CPU 사용량**: 낮음~중간
- **사용 케이스**: 모바일 게임이나 성능이 중요한 프로젝트

### 3. **Legacy Early Reflection**

- 이전 버전과의 호환성을 위한 옵션
- **사용 케이스**: 기존 프로젝트를 유지해야 할 때만

### 4. **Room Auxiliary Bus**

- 단순한 룸 리버브 효과
- 초기 반사음보다는 전체적인 공간감
- **사용 케이스**: 간단한 공간 효과만 필요할 때

## 실전 추천:

- **PC/콘솔 게임** → **Physically-Based** 사용
- **모바일/VR 게임** → **Simplified** 사용
- **단순한 배경음악/효과음** → **Room** 사용

프로젝트가 Unity 기반이고 2025년 프로젝트이므로, **Physically-Based Early Reflection**을 선택하는 것을 추천합니다. 나중에 성능 문제가 생기면 Simplified로 변경할 수 있습니다.

### 🎛️ 2-3. 사운드에 Reflect 연결하기

## 3. B. Unity 프로젝트 설정

이제 Unity에서 **AkSurfaceReflector 컴포넌트**를 추가해 실제 반사 표면을 구현합니다.

---

### 🧱 3-1. AkSurfaceReflector의 개념

- **AkSurfaceReflector**는 Unity 내의 표면을 “소리가 반사되는 면”으로 정의하는 컴포넌트입니다.
- 해당 컴포넌트가 붙은 **메쉬 표면**이 Spatial Audio에 전달되어 Reflect 플러그인이 반사음을 계산합니다.

---

### 🧩 3-2. 표면 리플렉터 오브젝트 만들기

### 방법 1️⃣ 기존 메쉬에 AkSurfaceReflector 추가

- 예: 벽이나 바닥의 Mesh Renderer 오브젝트에 바로 붙이기
- 단, **삼각형이 너무 많을 경우** 게임 성능이 저하될 수 있음 → 단순한 충돌 메쉬 사용 권장

### 방법 2️⃣ 별도 큐브 생성 후 사용 (튜토리얼 기본 방식)

1. 메뉴에서 **GameObject > 3D Object > Cube** 생성
2. **Mesh Renderer 컴포넌트 제거**
   - 렌더링은 필요 없고, 충돌체만 남깁니다.
3. **Box Collider**의 **Is Trigger** 체크
4. **AkSurfaceReflector 컴포넌트 추가**
5. **Mesh 필드**는 `None`으로 둡니다. (MeshFilter의 메쉬를 그대로 사용)
6. **Acoustic Textures 배열**
   - 각 하위 메쉬에 적용할 텍스처 선택 (또는 `None` → 필터링 없는 반사)
7. **Transmission Loss Values**
   - 표면을 통과하는 소리의 손실 정도를 설정
   - 값이 높을수록 소리가 덜 통과함 (흡음율 증가)
8. **Enable Diffraction (회절)** 체크
   - 소리가 장애물 가장자리로 돌아나오는 효과 활성화
9. **Associated Room**은 `None`으로 둠
   - Room/Portal 시스템을 사용하지 않을 경우 기본값 유지

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380577/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image_12.png)

---

### ⚙️ 3-3. Spatial Audio 설정 확인

- 메뉴 경로: `AkWwiseInitializationSettings → Spatial Audio Settings`
- **Reflection Order** 기본값: `1`
  - 더 복잡한 반사를 원할 경우 `2~4`로 변경 가능

## 1. Room & Portal 개념 이해하기

### 🧩 Room (공간)

- **Room**은 “소리가 머무는 공간”을 의미합니다.
  예: 실내, 동굴, 교회, 복도 등.
- 각 Room에는 **리버브(Reverb)** 효과가 다르게 설정될 수 있습니다.
  → 작은 방은 잔향이 짧고, 성당은 잔향이 길죠.
- **AkRoom 컴포넌트**를 통해 Unity의 특정 영역(콜라이더) 안을 “하나의 공간”으로 정의합니다.

### 🚪 Portal (포털)

- **Portal**은 서로 다른 Room들을 연결하는 “문/통로”입니다.
  → 소리가 한 Room에서 다른 Room으로 전달될 때 통로 역할을 합니다.
- 예:
  - 실내(Room A) ↔ 실외(Room B)를 연결하는 문
  - 복도(Room B) ↔ 방(Room C)을 연결하는 문
- **AkRoomPortal 컴포넌트**로 정의되며,
  소리가 포털을 통과할 때 **전달(Transmission)** 과 **회절(Diffraction)** 효과가 적용됩니다.

### 🎧 Diffraction (회절)

- 소리가 **직접 보이지 않는 경로를 돌아 들어오는 현상**입니다.
  문 뒤에 있어도 소리가 살짝 들리는 이유가 이것입니다.

## 2. A. Wwise 프로젝트

### 🎛 1) Reverb 효과 및 Auxiliary Bus 추가

- 공간별 리버브를 다르게 적용하기 위해 **Auxiliary Bus(보조 버스)** 를 추가합니다.
- `Master Audio Bus` 우클릭 → `New Child > Presets > Room Auxiliary Bus`
- 예시:
  - 작은 방 → `Rooms/Room_Medium`
  - 큰 방 → `Cathedrals/Medium`

> 💡 “Aux Bus”는 소리를 보조 경로로 보내 리버브나 필터 등의 이펙트를 걸 수 있게 해주는 장치입니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380579/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image_20.png)

공간 프리셋을 사용하여 두 개의 Auxiliary Bus를 추가하세요.

1. **Master Audio Bus**를 우클릭하고 New Child > Presets으로 가서 Room Auxiliary Bus를 선택하세요
2. **Effects** 탭 아래에서 각 공간에 대해 효과를 각각 선택하세요. 예: 작은 공간에는 Rooms/Room_Medium, 큰 공간에는 Cathedrals/Medium 사용.

### 🎚 2) Sound Property 설정 (Diffraction & Transmission)

- Spatial Audio 튜토리얼 준비에서 만든 **사운드(Sound SFX)** 를 수정합니다.
- `Positioning` 탭에서
  ✅ **Enable Diffraction**
  ✅ **Enable Transmission**
  을 체크하세요.

> ✅ 회절(Diffraction): 벽 모서리를 돌아 들어오는 소리
>
> ✅ 전달(Transmission): 벽을 통과해 약하게 들리는 소리

### 📈 3) Diffraction 곡선 설정 (Environmental Curves)

- 메뉴: `Project > Project Settings > Environmental Curves`
- Wwise Unity Demo Scene 기준 예시:

| Curve               | Point 1 (X,Y) | Point 2 (X,Y) | Curve Type                     |
| ------------------- | ------------- | ------------- | ------------------------------ |
| Diffraction Volume  | (0, 0)        | (100, -3)     | Linear                         |
| Diffraction LPF     | (0, 0)        | (100, 60)     | Linear                         |
| Transmission Volume | (0, 0)        | (100, -12)    | Sine (Constant Power Fade In)  |
| Transmission LPF    | (0, 0)        | (100, 75)     | Sine (Constant Power Fade Out) |

> 🔊 Volume: 얼마나 크게 들리는가
>
> 🔊 **LPF (Low Pass Filter)**: 고음이 얼마나 깎이는가
>
> 이 곡선으로 “소리가 벽에 가려졌을 때 감쇠되는 방식”을 시각적으로 조정할 수 있습니다.

## 6. E. 포털과 리버브

### 🔁 Room Coupling (공간 연결)

- **포털을 통해 전달되는 소리도, 리스너가 있는 Room의 리버브를 반영**할 수 있습니다.
  → 예: 문틈 사이로 들리는 소리도 실내 잔향을 가집니다.
- 설정 방법:
  1. Room의 **Auxiliary Bus Property Editor** 열기
  2. `General Settings` 탭 → ✅ **Use game-defined auxiliary sends** 체크
  3. 이렇게 하면 한 Room의 리버브가 다른 Room으로 “전달”됩니다.
     ![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380581/notion-blog/_/WWISE/_/Unity_Spatial_Audio/image_30.png)

---

### 🎧 테스트

- 작은 Room에서 소리 재생
- 리스너를 큰 Room으로 이동
  → Voice Graph에서 작은 Room의 리버브가 큰 Room 리버브로 “넘어오는 것”을 확인 가능

## 7. F. 공간음 (Room Tone)

### 🌬 개념

- 각 공간에는 “특유의 배경음”이 있을 수 있습니다.
  예:
  - 에어컨 소리
  - 기계실의 진동음
  - 교회 내부의 웅웅거림
- 이를 Wwise에서는 **Room Tone**이라고 부릅니다.

---

### 🎧 구현 단계

### 1) Wwise 설정

1. 새로운 **Sound SFX** 생성 → 공간음으로 사용할 파일 지정
2. “Use game-defined auxiliary sends” 체크 (리버브로 보내기 위함)
3. SFX 우클릭 → `New Event > Play` → RoomTone 재생 이벤트 생성
4. 저장 후 SoundBank 생성

---

### 2) Unity 설정

1. 해당 Room 오브젝트(AkRoom)에 **Room Tone Event** 등록
2. `Aux Send Level` 조정 (공간 리버브 양 조절)
3. 이벤트 트리거 방식 선택 (OnEnable, OnStart 등)
4. 씬 실행 후 Wwise Authoring 연결

---

### 🧩 결과 확인

- 리스너가 공간 안에 있을 경우:
  → 공간음이 리스너 위치에서 들림
- 리스너가 다른 Room에 있을 경우:
  → 포털 위치에서 공간음이 전달되어 들림
- **3D Viewer**에서 리스너 이동에 따라 공간음 오브젝트가 Room 또는 Portal로 이동하는 걸 확인 가능

## 🧠 요약 정리

| 개념                | 역할          | 관련 컴포넌트             | 특징                       |
| ------------------- | ------------- | ------------------------- | -------------------------- |
| **Room**            | 공간 정의     | `AkRoom`                  | 리버브와 벽 통한 전달 제어 |
| **Portal**          | Room 간 연결  | `AkRoomPortal`            | 회절/전달 경로 계산        |
| **RoomAwareObject** | Room 인식     | 자동 또는 수동 추가       | 리스너/방사체 모두 필요    |
| **DebugDraw**       | 시각적 확인   | `AkSpatialAudioDebugDraw` | Diffraction 경로 표시      |
| **Room Coupling**   | 리버브 전송   | 설정 기반                 | 포털을 통해 리버브 전달    |
| **Room Tone**       | 공간의 배경음 | `Room Tone Event`         | 공간별 환경음 구현         |

---

이 튜토리얼을 마치면 🔊

- 서로 다른 방/실외 공간 간의 리버브 차이를 표현할 수 있고,
- 문틈 너머로 회절된 소리나 전달음을 들을 수 있으며,
- 공간마다 고유의 배경음을 설정해 **현실감 있는 사운드 공간**을 구현할 수 있습니다.
