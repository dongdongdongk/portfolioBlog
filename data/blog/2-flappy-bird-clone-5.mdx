## 4. **씬 순서 정리**

```jsx
Phaser는 등록된 씬의 순서에 따라 씬을 관리합니다. 만약 특정 씬이 다른 씬을 참조하거나 연결될 때,

그 씬이 먼저 등록되지 않았다면 에러가 발생하거나 원하는 씬으로 이동하지 않을 수 있습니다.
```

## Pause Scene 기능 소개

```jsx
Pause Scene은 게임이 진행 중일 때 일시정지 상태로 전환되는 화면입니다.

사용자는 두 가지 선택을 할 수 있습니다:

1. Continue: 게임을 계속 진행합니다.

2. Exit: 게임을 종료하고 메인 메뉴로 돌아갑니다.

```

### 1. 메뉴 이벤트 설정

```jsx
setupMenuEvents(menuItem) {
    const textGo = menuItem.textGo;
    textGo.setInteractive();

    // 마우스를 올렸을 때 메뉴 텍스트 색상 변경
    textGo.on('pointerover', () => {
        textGo.setStyle({fill: '#ff0'});
    });

    // 마우스를 내렸을 때 메뉴 텍스트 색상 복원
    textGo.on('pointerout', () => {
        textGo.setStyle({fill: '#fff'});
    });

    // 버튼 클릭 시 동작 설정
    textGo.on('pointerup', () => {
        if (menuItem.scene && menuItem.text === 'Continue') {
            // Continue 버튼 클릭 시
            this.scene.stop(); // Pause Scene 종료
            this.scene.resume(menuItem.scene); // Play Scene 재개
        } else {
            // Exit 버튼 클릭 시
            this.scene.stop('PlayScene'); // Play Scene 종료
            this.scene.start(menuItem.scene); // Menu Scene 시작
        }
    });
}

```

```jsx
2. Continue 버튼 동작 상세 설명

		1. this.scene.stop()

				현재 Pause Scene을 종료합니다.

				Pause Scene에 포함된 모든 요소(화면, 타이머 등)를 정리합니다.


		2. this.scene.resume(menuItem.scene)

				이전에 멈췄던 Play Scene을 다시 시작합니다.

				멈췄던 지점부터 물리 엔진과 업데이트 루프가 다시 동작합니다.


3. Exit 버튼 동작 상세 설명

		1. this.scene.stop('PlayScene')

				Play Scene을 종료합니다.

				Pause Scene도 자연스럽게 종료되며, 더 이상 동작하지 않습니다.


		2. this.scene.start(menuItem.scene)

				새로운 Menu Scene을 시작합니다.

				새 화면으로 전환되면서 이전 상태는 초기화됩니다.
```

# { 게임 일시정지 및 재개 기능 구현 }

```jsx
// import Phaser from "phaser";
import BaseScene from './BaseScene'

class PlayScene extends BaseScene {
  constructor(config) {
    super('PlayScene', config)

    this.bird = null // 플레이어가 조종할 새 객체
    this.pipes = null // 장애물로 사용될 파이프들

    // 파이프 간의 거리 관련 설정
    this.pipeHorizontalDistance = 0
    this.pipeVerticalDistanceRange = [150, 250]
    this.pipeHorizontalDistanceRange = [500, 550]
    this.flapVelocity = 300 // 새가 날갯짓할 때의 속도

    this.score = 0 // 점수 초기화
    this.scoreText = '' // 점수를 화면에 표시할 텍스트
  }

  create() {
    super.create() // 부모 클래스의 create() 메서드를 호출
    this.createBird() // 새를 생성
    this.createPipes() // 파이프를 생성
    this.handleInputs() // 사용자 입력 설정
    this.createScore() // 점수 표시 생성
    this.createColliders() // 충돌 감지 설정
    this.createPause() // 일시 정지 버튼 생성
    this.listenToEvents() // 이벤트 리스너 등록
  }

  listenToEvents() {
    // 1. pauseEvent가 이미 설정되어 있으면 이벤트 리스너를 다시 추가하지 않도록 함수 실행을 중단
    if (this.pauseEvent) {
      return // pauseEvent가 true이면 중복 실행 방지
    }

    // 2. 'resume' 이벤트에 대한 리스너를 등록
    this.pauseEvent = this.events.on('resume', () => {
      // 'resume' 이벤트 발생 시 실행할 콜백 함수

      // 3. 초기 카운트다운 시간 설정
      this.initialTime = 3

      // 4. 화면 중앙에 카운트다운 텍스트 추가
      //    화면 중심 좌표와 폰트 옵션을 사용하여 텍스트를 추가하고
      //    setOrigin(0.5)로 텍스트의 중심을 기준점으로 설정
      this.countDownText = this.add
        .text(...this.screenCenter, 'Fly in: ' + this.initialTime, this.fontOptions)
        .setOrigin(0.5)

      // 5. 카운트다운을 처리할 타이머 이벤트 생성
      this.timedEvent = this.time.addEvent({
        delay: 1000, // 1초(1000ms)마다 실행
        callback: this.countDown, // 1초마다 실행할 함수 (카운트다운 처리)
        callbackScope: this, // callback 내에서 'this'가 현재 객체(this)를 참조하도록 설정
        loop: true, // 타이머를 무한 반복하도록 설정
      })
    })
  }

  countDown() {
    this.initialTime-- // 카운트다운 숫자를 감소
    this.countDownText.setText('Fly in: ' + this.initialTime) // 텍스트 업데이트

    if (this.initialTime <= 0) {
      // 카운트다운이 끝나면
      this.countDownText.setText('') // 텍스트 지우기
      this.physics.resume() // 게임 물리 작동 재개
      this.timedEvent.remove() // 타이머 이벤트 제거
    }
  }

  createPause() {
    // 일시 정지 버튼 생성
    const pauseButton = this.add
      .image(this.config.width - 10, this.config.height - 10, 'pause') // 화면 오른쪽 하단
      .setInteractive() // 상호작용 가능하도록 설정
      .setScale(3) // 크기 조정
      .setOrigin(1) // 기준점을 오른쪽 아래로 설정

    pauseButton.on('pointerdown', () => {
      // 버튼 클릭 시 실행
      this.physics.pause() // 게임 물리 정지
      this.scene.pause() // 현재 씬 일시 정지
      this.scene.launch('PauseScene') // PauseScene 실행
    })
  }
}

export default PlayScene
```

## 일시정지 상태에서 게임 재개하기

### 1. 이벤트 리스너 등록 (`listenToEvents`)

```jsx
1. this.pauseEvent를 통한 중복 리스너 방지

		if (this.pauseEvent) 조건문을 사용해 리스너가 이미 등록되었는지 확인합니다.

		리스너가 이미 등록되어 있다면 함수가 즉시 종료되며, 중복 등록을 방지합니다.

2. resume 이벤트 리스너 등록

		this.events.on('resume', ...)을 통해 'resume' 이벤트 발생 시 실행될 콜백을 정의합니다.

		이 이벤트는 일반적으로 게임이 일시 중지 상태에서 다시 시작될 때 발생합니다.

3. 카운트다운 초기화

		this.initialTime을 3으로 설정하여 카운트다운의 시작 시간을 초기화합니다.

4. 카운트다운 텍스트 생성 및 화면 표시

		this.add.text 메서드로 카운트다운 메시지를 화면 중앙에 표시합니다.

		setOrigin(0.5)를 사용해 텍스트의 중심이 화면 중앙에 오도록 설정합니다.

5. 1초마다 실행되는 타이머 이벤트 추가

		this.time.addEvent를 통해 타이머 이벤트를 설정합니다.

		타이머는 1초(1000ms)마다 실행되며, 콜백 함수로 this.countDown을 호출합니다.

		loop: true로 설정되어 타이머가 계속 반복됩니다.
```

### `* resume` 이벤트는 물리 엔진의 `resume()`을 감지하지 않습니다.

```jsx
this.events.on('resume', () => {...});

씬이 재개될 때(this.scene.resume() 호출 시) 발생하는 resume 이벤트를 감지하는 코드입니다.

씬(Scene)의 상태를 일시정지에서 다시 재개할 때 resume 이벤트가 발생합니다.

여기서 중요한 점은, resume 이벤트는 this.scene.resume() 호출과 관련된 동작입니다.

* resume 이벤트는 씬(Scene)의 상태에 관련된 이벤트입니다. ( pauseScene 확인 )

	즉, 씬이 일시정지 상태에서 재개될 때 실행됩니다.

	이것은 물리 엔진의 resume 과 직접적인 연결이 없습니다.
```

### \* this.time.addEvent

```jsx
this.time.addEvent는 새 타이머 이벤트를 생성합니다.

즉, 일정 시간 간격마다 어떤 작업을 반복적으로 실행하도록 Phaser에 지시하는 코드입니다.
```

### `this.pauseEvent`를 활용하여 중복 리스너 등록 방지, 메모리 누수 및 예기치 않은 동작을 해결

```jsx
  listenToEvents() {
    if (this.pauseEvent) { return; }

    this.pauseEvent = this.events.on('resume', () => {
      this.initialTime = 3;
      this.countDownText = this.add.text(...this.screenCenter, 'Fly in: ' + this.initialTime, this.fontOptions).setOrigin(0.5);
      this.timedEvent = this.time.addEvent({
        delay: 1000,
        callback: this.countDown,
        callbackScope: this,
        loop: true
      })
    })
  }

이벤트 리스너를 중복 등록하게 되면, 동일한 이벤트가 발생할 때마다 리스너가 여러 번 실행됩니다. 예를 들어:

		1. 처음 게임을 정지했다가 재개할 때:

				listenToEvents 함수가 실행되고 'resume' 이벤트 리스너가 등록됩니다.

				이후 'resume' 이벤트가 발생하면, 리스너가 정상적으로 작동하며 타이머가 시작됩니다.


		2. 다시 정지하고 또 재개하면:

				listenToEvents 함수가 또 호출되고 새로운 리스너가 추가됩니다.

				이제 'resume' 이벤트가 발생할 때 리스너가 두 개 실행됩니다.

				이로 인해 타이머가 두 개 동시에 실행됩니다.


		3. 계속 정지와 재개를 반복하면:

				매번 새로운 리스너가 추가되어, 'resume' 이벤트 발생 시 실행되는 타이머가 점점 늘어납니다.

				결과적으로, 타이머가 여러 개 실행되면서 게임이 느려지거나 잘못 작동하게 됩니다.



this.pauseEvent로 해결 방법

		this.pauseEvent는 이러한 중복 등록을 막아주는 역할을 합니다.

		이미 'resume' 이벤트 리스너가 등록된 경우,

		listenToEvents 함수 실행을 멈추기 때문에 추가 리스너가 등록되지 않습니다.

```

## 2. 카운트다운 동작 처리 (`countDown`)

```jsx
역할:

		카운트다운 숫자를 1초마다 감소시키고, 0초가 되면 게임을 재개합니다.

구현 과정:

		1. this.initialTime 값을 감소시키고 화면에 표시합니다

				this.initialTime--;
				this.countDownText.setText('Fly in: ' + this.initialTime);


		2. 시간이 0초에 도달하면 다음 작업을 수행합니다:

				카운트다운 텍스트를 지웁니다.

						this.countDownText.setText('');

			  게임 물리 작동을 재개합니다

					  this.physics.resume();

				타이머 이벤트를 제거하여 불필요한 반복 실행을 방지합니다

						this.timedEvent.remove();
```

# **{ 점수(score)** 에 따라 난이도를 동적으로 변경 }

## 1. 난이도 시스템의 개념


## 3. 난이도 변경 함수 구현

```jsx

( 사실 씬을 초기화 하기 때문에 초기값 easy 가 있어 score 0 은 필요가 없음 )
```

```jsx
increaseDifficulty() {
    if (this.score === 0) {
        this.currentDifficulty = 'easy'; // 초반은 쉬움 난이도
    }
    if (this.score === 3) {
        this.currentDifficulty = 'normal'; // 점수 3에 도달하면 보통 난이도
    }
    if (this.score === 10) {
        this.currentDifficulty = 'hard'; // 점수 10에 도달하면 어려움 난이도
    }
}
```


## 1. 스프라이트 시트란?

```jsx
스프라이트 시트는 여러 애니메이션 프레임이 하나의 이미지에 모여 있는 큰 이미지 파일입니다.

각 프레임은 캐릭터나 오브젝트가 특정 상태(예: 대기, 비행)를 보여주는 한 장의 이미지입니다.

예:

		새가 날개를 내리고 있는 이미지

		새가 날개를 중간 정도로 든 이미지

		새가 날개를 완전히 올린 이미지

이러한 이미지가 순서대로 나열되어 있는 파일이 스프라이트 시트입니다.
```

## 2. 스프라이트 시트에서 프레임의 크기 계산

```jsx
스프라이트 시트를 사용할 때, 이미지의 각 프레임 크기를 알아야 합니다.

강의에서 제공된 새 스프라이트 시트(birdSprite.png)를 예로 들면:

1. 이미지 전체 크기:

		너비(Width): 128 픽셀

		높이(Height): 48 픽셀

2. 가로로 몇 개의 프레임이 있는지 계산:

		가로 프레임 개수: 8개

		따라서 각 프레임의 너비는 128 ÷ 8 = 16픽셀

3. 세로로 몇 개의 프레임이 있는지 계산:

		세로 프레임 개수: 3개

		따라서 각 프레임의 높이는 48 ÷ 3 = 16픽셀

결과적으로, 이 스프라이트 시트의 각 프레임 크기는 16픽셀 × 16픽셀입니다.
```

## 3. Phaser에서 스프라이트 시트 로드하기

```jsx
Phaser는 스프라이트 시트를 쉽게 처리할 수 있는 기능을 제공합니다.

```

```jsx
    });
```

## 4. 새 캐릭터 생성


```jsx
기본 프레임 속도: Phaser의 기본값은 초당 24프레임(24fps)입니다.

		예: 24개의 프레임으로 이루어진 애니메이션은 1초에 재생됩니다.
```

## 1. **새 캐릭터의 몸체 크기 조정**

```jsx
처음에는 새의 애니메이션이 끝난 후에도 새의 몸체 크기가 너무 커서 장애물(파이프)와 부딪히는 문제가 발생했습니다.

이유는 새의 날개가 애니메이션으로 움직이면서 실제 몸체보다 크고,

그 부분까지 충돌로 계산되었기 때문입니다.

이를 해결하기 위해, 새의 몸체 크기를 실제 새의 크기에 맞게 수동으로 조정합니다.
```

## 2. **디버깅 및 크기 수정 과정**

```jsx
index.js에서 디버깅을 활성화하여, 새의 몸체 크기와 실제 애니메이션의 크기를 시각적으로 확인했습니다.

이를 통해 새의 몸체가 너무 커서 파이프와 충돌하는 문제를 확인했습니다.

새의 몸체 크기를 setBodySize 함수를 사용하여 조정할 수 있습니다. 이 함수는 두 개의 파라미터,

즉 **너비(width)**와 **높이(height)**를 받습니다.

기본적으로 새의 몸체 크기와 애니메이션 크기가 같아서 충돌 문제가 발생했습니다.

몸체 크기를 변경하려면, 새의 너비는 그대로 두고,

높이만 수정하여 날개의 움직임이 몸체 크기에 영향을 주지 않도록 했습니다
```

## 3. **실제 코드 변경**

```jsx
createBird 함수 내에서 this.bird.setBodySize(this.bird.width, this.bird.height - 8)을

사용하여 몸체의 높이를 8 픽셀 줄였습니다.

이를 통해 새의 몸체가 더 작아지고, 파이프와 충돌하지 않게 되었습니다.

몸체 크기를 점진적으로 조정하면서, 새의 실제 크기에 맞는 적당한 값을 찾았습니다.
```

```jsx
  createBird() {
    this.bird = this.physics.add
      .sprite(this.config.startPosition.x, this.config.startPosition.y, "bird")
      .setFlipX(true)
      .setScale(3)
      .setOrigin(0);
    this.bird.setBodySize(this.bird.width, this.bird.height - 8);
    this.bird.body.gravity.y = 600;
    this.bird.setCollideWorldBounds(true);
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380496/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_5_-/image_6.png)

```jsx
checkFPS() {
    // 빈 텍스트를 화면에 추가합니다. (추가적으로 사용하지 않지만 초기화 목적일 수 있습니다.)
    // 위치: (x: 16, y: 16), 글자 크기: 16px, 색상: 흰색 (#FFF)
    this.add.text(16, 16, "", { fontSize: "16px", fill: "#FFF" });

    // FPS(초당 프레임 수)를 화면에 표시하기 위한 텍스트를 생성합니다.
    // 초기 텍스트는 "FPS: 0"으로 설정하고, 이후 실시간으로 업데이트됩니다.
    this.fpsText = this.add.text(16, 16, "FPS: 0", {
        fontSize: "16px", // 글자의 크기 (16px)
        fill: "#FFF",     // 글자의 색상 (흰색)
    });

    // Phaser의 `time.addEvent`를 사용하여 주기적으로 FPS 값을 업데이트하는 이벤트를 추가합니다.
    this.time.addEvent({
        delay: 100, // 100밀리초마다 이벤트를 실행합니다 (0.1초 간격).
        loop: true, // 이 이벤트는 반복 실행됩니다.
        callback: () => {
            // 게임 루프의 실제 FPS 값을 가져와 화면에 표시합니다.
            // `this.game.loop.actualFps`는 현재 프레임 속도를 나타냅니다.
            // Math.floor를 사용하여 소수점을 버리고 정수 형태로 표시합니다.
            this.fpsText.setText(`FPS: ${Math.floor(this.game.loop.actualFps)}`);
        },
    });
}

```

```jsx
이 코드에서 중요한 점은 fpsText가 이후에 업데이트되어 실시간으로

FPS 값을 사용자에게 보여준다는 점입니다.

이 기능은 게임 개발 중 성능을 확인하는 데 유용합니다.
```

```jsx
this.time.addEvent()

Phaser에서 일정 시간마다 실행할 작업(이벤트)을 등록하는 함수입니다.

주요 매개변수:

		delay: 이벤트가 실행되는 간격(밀리초 단위, 100ms = 0.1초).

		loop: true로 설정하면 이 이벤트는 계속 반복됩니다.

		callback: 실행할 작업을 정의한 함수입니다.


FPS 값을 업데이트하는 방식:

		this.game.loop.actualFps: Phaser에서 제공하는 속성으로, 현재 게임의 실제 FPS 값을 반환합니다.

		Math.floor(): FPS 값을 소수점 없이 정수로 표시하기 위해 사용합니다.

		setText(): 텍스트를 업데이트하는 함수로, "FPS: 숫자" 형식으로 화면에 표시됩니다.

실제 FPS 확인

		this.game.loop.actualFps는 현재 게임 루프의 초당 프레임 수를 측정한 값입니다.

		값이 높으면 게임이 원활히 실행 중임을 의미하며, 값이 낮으면 성능 문제를 의심할 수 있습니다.
```
