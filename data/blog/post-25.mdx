# 1. **스크립트란?**

```jsx
스크립트는 여러 명령어를 파일에 순서대로 작성해 놓은 프로그램입니다.

스크립트 파일을 실행하면 그 안에 있는 명령어들이 차례대로 자동으로 실행됩니다. 리눅스에서는 주로 Bash 스크립트를 작성합니다.
```

# 2. **스크립트 파일 만들기**

## 2.1. 파일 생성

```jsx
우선, 텍스트 파일을 하나 만들어서 그 안에 명령어를 작성하면 됩니다.

리눅스에서는 nano나 vi 같은 텍스트 편집기를 사용하여 파일을 만듭니다.

예를 들어, my_script.sh라는 이름의 스크립트를 만들어 보겠습니다:
```

```jsx
vi my_script.sh
```

## 2.2. 스크립트의 첫 줄: **Shebang**

```jsx
스크립트의 첫 줄은 항상 다음과 같이 시작합니다:

이 부분은 Shebang이라고 불리며,

이 스크립트를 Bash(리눅스에서 사용하는 명령어 해석기)로 실행하겠다는 의미입니다.
```

```jsx
#!/bin/bash
```

## 2.3. 명령어 작성

```jsx
그 아래에 실행하고 싶은 명령어들을 한 줄씩 추가하면 됩니다. 예를 들어,

디렉터리를 이동하고 파일의 내용을 확인하는 명령어들을 작성해 볼게요:
```

```jsx
#!/bin/bash

# 작업할 디렉토리로 이동
cd /home/user/myfolder

# 폴더 안의 파일 목록을 출력
ls

# 로그 파일의 내용을 실시간으로 확인
tail -f mylogfile.log
```

## 2.4. 파일 저장

```jsx
파일을 다 작성했으면 Ctrl + O (저장)하고 Ctrl + X (종료)하여 텍스트 편집기를 닫습니다

:wq 저장후 종료

:q! 강제 종료 ( 저장없이 )
```

# 3. **스크립트에 실행 권한 부여**

```jsx
스크립트 파일을 만들고 나면, 이 파일에 실행 권한을 주어야 합니다. 이를 위해 다음 명령어를 입력합니다:

이제 my_script.sh 파일은 실행할 수 있는 상태가 되었습니다.
```

```jsx
chmod +x my_script.sh
```

# 4. **스크립트 실행하기**

```jsx
이 명령어는 현재 디렉터리에서 my_script.sh라는 스크립트를 실행하라는 뜻입니다.

스크립트 실행 시, 스크립트에 작성된 명령어들이 차례대로 실행됩니다.
```

```jsx
./my_script.sh
```

# 5. **스크립트의 추가적인 기능들**

## 5.1. **주석**

```jsx
주석은 스크립트에 설명을 추가하는 방법입니다.

스크립트에 설명을 적어두면 나중에 다시 볼 때 이해하기 쉽습니다. **#**으로 시작하는 줄은 실행되지 않고 설명으로만 사용됩니다.
```

```jsx
#!/bin/bash

# 이 스크립트는 로그 파일을 모니터링하고 파일 목록을 출력합니다.

# 작업할 디렉토리로 이동
cd /home/user/myfolder

# 폴더 안의 파일 목록을 출력
ls

# 로그 파일의 내용을 실시간으로 확인
tail -f mylogfile.log
```

## 5.2. **변수**

```jsx
스크립트에서는 변수도 사용할 수 있습니다. 변수를 사용하면 값을 미리 저장해두고 나중에 여러 번 사용할 수 있습니다.

위에서 $DIR는 /home/user/myfolder라는 경로를 저장하는 변수입니다.
```

```jsx
#!/bin/bash

# 변수에 디렉토리 경로 저장
DIR="/home/user/myfolder"

# 변수에 저장한 디렉토리로 이동
cd $DIR

# 폴더 안의 파일 목록 출력
ls
```

## 5.3. **조건문**

```jsx
스크립트에서 특정 조건에 따라 명령어를 실행할 수도 있습니다.

if [ -d "/home/user/myfolder" ]; then: 폴더가 존재하는지 확인하는 조건문입니다.

else: 폴더가 존재하지 않을 경우의 동작을 정의합니다.
```

```jsx
#!/bin/bash

# 폴더가 존재하는지 확인하고, 존재하면 이동
if [ -d "/home/user/myfolder" ]; then
  cd /home/user/myfolder
  echo "폴더로 이동했습니다."
else
  echo "폴더가 존재하지 않습니다."
fi
```

# 6. **실제 예제: 권한 변경 및 파일 열기 스크립트**

```jsx
다음은 자주 사용하는 폴더의 권한을 변경하고 파일을 여는 스크립트 예시입니다:
```

```jsx
#!/bin/bash

# 권한을 변경할 폴더 경로
TARGET_DIR="/path/to/your/folder"

# 폴더의 소유권을 fds:fds로 변경
sudo chown -R fds:fds $TARGET_DIR

# 폴더로 이동
cd $TARGET_DIR

# 로그 파일을 실시간으로 모니터링
tail -f log.txt
```
