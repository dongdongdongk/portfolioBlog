```jsx
이 강의에서는 CSS 클래스 선택자에 대해 설명하면서, 여러 클래스를 적용하고 결합하는 방법을 살펴봅니다.
```

## 1. CSS 클래스 선택자의 활용

```jsx
재사용 가능한 규칙 정의: CSS 클래스는 특정 스타일 규칙을 정의하고, 이를 여러 HTML 요소에 적용하여 코드의 재사용성을 높입니다.
```

## 2. 여러 개의 클래스 적용

```jsx
한 요소에 여러 클래스 적용:

	HTML 요소는 공백으로 구분된 여러 개의 클래스를 가질 수 있습니다. 예를 들어,

	<section class="main-section highlighted">처럼 main-section과 highlighted 두 클래스를 적용할 수 있습니다.

독립적 적용:

	각 클래스는 서로 독립적으로 적용됩니다. 이는 같은 요소에 적용된 여러 클래스가 각각의 스타일을 독립적으로 적용한다는 것을 의미합니다.
```

## 3. 클래스의 명시도와 규칙 순서

```jsx
명시도:

	여러 클래스가 동일한 CSS 속성을 정의할 때, 더 구체적인 선택자가 우선 적용됩니다.

	예를 들어, a.active 선택자는 단순한 a 선택자보다 더 구체적이므로 우선 적용됩니다.

규칙 순서:

	CSS 파일에서 나중에 정의된 스타일이 우선 적용됩니다. 예를 들어, highlighted 클래스가 border 속성을 설정하고,

	나중에 정의된 main-section 클래스가 동일한 속성을 설정하면, 나중에 정의된 규칙이 우선됩니다.
```

## 4. 결합된 선택자

```jsx
선택자 결합:

	선택자를 결합하여 특정 조건에 맞는 요소를 보다 구체적으로 지정할 수 있습니다.

	예를 들어, a.active 선택자는 a 태그 중에서 active 클래스를 가진 요소만을 선택합니다.

결합자의 사용:

	결합자는 두 선택자 사이에 공백, 더하기(+) 등의 문자가 없이 붙어서 사용됩니다.

	예를 들어, a.active는 active 클래스를 가진 a 태그를 선택하며, 이 경우에는 결합자가 없는 결합된 선택자입니다.
```

# { 클래스 vs ID }

```jsx
이번 강의에서는 CSS 클래스 선택자와 ID 선택자의 차이점, 그리고 언제 어떤 선택자를 사용하는 것이 적절한지에 대해 설명합니다.

* 주로 ID 보다는 CSS 를 많이 사용한
```

## 1. CSS 클래스 선택자와 ID 선택자의 차이점

```jsx
클래스 선택자:

	정의: 클래스 선택자는 점(.) 기호로 시작합니다. 예: .classname

	특징: 재사용이 가능하며, 여러 HTML 요소에 동일한 클래스를 적용할 수 있습니다.

	사용 예시: 여러 요소에 동일한 스타일을 적용하고 싶을 때 적합합니다.

ID 선택자:

	정의: ID 선택자는 해시(#) 기호로 시작합니다. 예: #idname

	특징: 페이지에서 한 번만 사용되며, 특정 HTML 요소에만 스타일을 적용할 수 있습니다.

	사용 예시: 페이지에서 유일한 요소에 스타일을 적용하거나, JavaScript에서 요소를 참조할 때 사용됩니다.
```

## 2. 언제 클래스를 사용하고, 언제 ID를 사용할까요?

```jsx
클래스 선택자의 사용:

	재사용성: 클래스 선택자는 동일한 스타일을 여러 요소에 적용할 때 유리합니다.

	CSS와의 강력한 연결: 클래스는 스타일링 목적으로 사용되는 경우가 많아, CSS에서 가장 많이 사용되는 선택자입니다.

	태그 선택자와의 비교: 태그 선택자는 특정 태그의 모든 요소에 스타일을 적용하기 때문에 예상치 못한 곳에 영향을 줄 수 있습니다.

											반면, 클래스 선택자는 특정 요소에만 스타일을 적용하므로 더 세밀하게 제어할 수 있습니다.


ID 선택자의 사용:

	유일성: ID는 페이지에서 유일한 요소에 스타일을 적용할 때 사용합니다.

	JavaScript와의 연동: ID는 JavaScript에서 요소를 특정할 때 자주 사용됩니다.

	스타일 적용: 스타일링 목적으로 ID를 사용하는 것은 권장되지 않지만, 꼭 필요한 경우에는 사용할 수 있습니다.

	HTML 내장 기능: ID는 CSS와는 별도로, HTML에서 특정 섹션으로 링크를 걸거나 페이지 내에서 위치를 이동할 때 유용합니다.
```

# { !important 사용법 (권장하지 않음) }

## 1. **!important란?**

```jsx
!important는 특정 CSS 스타일을 강제로 적용해 다른 규칙을 덮어쓰게 합니다.
```

```jsx
.main-section {
    border: 1px solid #ccc;
}

.highlighted {
    border: 2px solid #fa923f !important;
    height: 200px;
}
```

```jsx
여기서 .highlighted 클래스의 border는 !important 덕분에 항상 적용됩니다.
```

## 3. **주의사항**

```jsx
남용 금지: 너무 많이 사용하면 코드가 복잡해지고 관리하기 어려워집니다.

적절한 사용: 꼭 필요한 경우에만 사용하세요, 예를 들어 외부 라이브러리의 스타일을 덮어쓸 때.
```

# { CSS와 브라우저 지원 }

## 1. **브라우저 지원의 중요성**

```jsx
모든 CSS 기능이 모든 브라우저에서 지원되지 않을 수 있으므로, 브라우저 지원 여부를 확인하는 것은 매우 중요합니다.

특정 CSS 기능이 목표로 하는 브라우저에서 지원되지 않는 경우, 해당 기능을 사용할 수 없기 때문입니다.
```

## 2. **지원 여부 확인 방법**

```jsx
MDN Web Docs: 특정 CSS 프로퍼티나 선택자 페이지 하단에서 주요 브라우저의 지원 상태를 확인할 수 있습니다.

	데스크톱과 모바일 브라우저로 구분되어 있으며, 어느 버전부터 지원되는지도 표시됩니다.

CanIUse.com: 특정 기능을 검색하면 브라우저별 지원 상태와 함께 시장 점유율 정보를 제공합니다.

	기능을 사용했을 때 전체 시장에서 얼마나 많은 사용자가 접근 가능한지 확인할 수 있습니다.
```

## 1. **HTML 구조**


```jsx

      </ul>

        <button>CHOOSE PLAN</button>
      </div>
    </article>
    <!-- 다른 요금제 articles도 동일한 구조 -->
  </div>
  <p>Make sure you get the most for your money!</p>

```

## 2. **CSS 스타일링**

```jsx
HTML 구조를 기반으로, CSS 파일에서 각 요금제(article 요소)에 스타일을 지정합니다.
```

```jsx
.plan {
    background: #d5ffdc; /* 연녹색 배경 */
    text-align: center; /* 텍스트 중앙 정렬 */
    padding: 16px; /* 안쪽 여백 */
    margin: 8px; /* 바깥 여백 */
    display: inline-block; /* 같은 열에 배치 */
    width: 30%; /* 너비를 30%로 제한 */
    vertical-align: middle; /* 수직 정렬 */
}
```

```jsx
배경 색상: 요금제 섹션 배경을 연녹색으로 설정합니다.

텍스트 중앙 정렬: text-align: center; 프로퍼티를 사용해 모든 텍스트를 중앙으로 정렬합니다.

Padding과 Margin: padding과 margin을 사용해 요소 간의 공간을 적절하게 조절합니다.

인라인 블록 배치: display: inline-block;을 사용해 각 요금제를 한 줄에 정렬합니다.

* width: 30%;는 각 요금제(article 요소)가 페이지 전체 너비의 30%만 차지하도록 하여,

	세 개의 요금제를 한 줄에 균형 있게 배치하기 위해 사용됩니다.

	이는 레이아웃을 깔끔하게 유지하고, 다양한 화면 크기에서도 디자인이 잘 유지되도록 도와줍니다.
```

## 2. **CSS 스타일링**

```jsx
key-feature__list 클래스:

	목록 스타일을 제거하기 위해 list-style: none;, margin: 0;, padding: 0;를 설정했습니다.

	텍스트를 중앙 정렬하기 위해 text-align: center;를 적용했습니다.

key-feature 클래스:

	목록 항목을 한 줄에 표시하기 위해 display: inline-block;과 width: 30%;를 설정했습니다.

	텍스트를 상단 정렬하기 위해 vertical-align: top;을 적용했습니다.

key-feature__description 클래스:

	본문 텍스트를 중앙 정렬하고, 글자 색을 흰색으로 변경했습니다.

	폰트 굵기를 굵게(font-weight: bold;) 하고, 폰트 크기를 20px로 지정했습니다.

key-feature__image 클래스:

	이미지를 넣을 컨테이너를 생성하고, 배경색을 #ffcede로 설정했습니다.

	컨테이너 크기를 width: 128px;와 height: 128px;로 설정해 원형으로 만들고, border-radius: 50%;로 완전한 원을 만들었습니다.

	원을 중앙 정렬하기 위해 margin: auto;를 적용했습니다.



	* border-radius: 50%;: 사각형의 각 모서리를 50%만큼 둥글게 만들어 원형으로 변환합니다.

		이 경우, border-radius를 50%로 설정하면 원의 반지름이 전체 크기의 절반이 되므로, 완벽한 원이 만들어집니다.


	* margin: auto;는 주로 블록 요소에 사용되며, 부모 컨테이너 안에서 요소를 가로축(X축) 방향으로 중앙에 배치합니다.

		부모 요소의 width가 명시적으로 설정되어 있어야 하고, 정렬할 자식 요소의 width가 부모 요소보다 작아야 효과적입니다.
```

```css
푸터는 웹사이트의 하단에 위치하며, 주로 내비게이션 링크나 저작권 정보를 포함합니다.
```

## 1. 푸터 추가하기

```css
먼저, HTML 파일에 푸터 요소를 추가합니다.

여기에는 비정렬 목록(<ul>)과 그 안에 내비게이션 링크를 포함한 목록 항목(<li>)이 들어갑니다.
```

```css
<footer class="main-footer">
```

## 2. 푸터 스타일링하기

```css
이제 푸터에 스타일을 적용합니다. 푸터는 헤더와 유사하게 스타일을 설정합니다.

강의에서는 main-footer라는 클래스를 사용해 스타일을 지정합니다.

이를 통해 푸터의 배경색, 텍스트 색상, 여백, 패딩 등을 설정합니다.
```

```css
.main-footer {
  background: black;
  padding: 32px;
  margin-top: 48px;
}
```

```css
background: black;: 푸터의 배경색을 검정색으로 설정합니다.

padding: 32px;: 푸터 내부에 32px의 패딩을 추가합니다.

margin-top: 48px;: 푸터 상단에 48px의 여백을 추가하여 본문과의 간격을 둡니다.
```

## 3. 푸터의 링크 스타일링

```css
푸터에 포함된 비정렬 목록(<ul>)과 목록 항목(<li>)을 스타일링합니다.

이를 통해 푸터 내의 링크를 중앙에 정렬하고, 기본 목록 스타일을 제거합니다.
```

```css
.main-footer__links {
  list-style: none;
  margin: 0;
  padding: 0;
  text-align: center;
}

  margin: 16px;
}
```

```css
list-style: none;: 목록의 기본 불릿 포인트를 제거합니다.

text-align: center;: 목록을 중앙에 정렬합니다.

display: inline-block;: 목록 항목을 인라인 블록으로 설정하여 한 줄에 표시되도록 합니다.

margin: 16px;: 목록 항목 사이에 16px의 간격을 둡니다.
```

```css

text-decoration: none;: 링크의 기본 밑줄을 제거합니다.

color: #ccc; (hover 및 active 상태): 링크에 마우스를 올리거나 클릭할 때 텍스트 색상을 밝은 회색(#ccc)으로 변경합니다.
```

## 푸터의 링크 텍스트 스타일을 따로 설정해야 하는 이유 ?

```css
푸터의 링크 텍스트 스타일을 따로 설정해야 하는 이유는 CSS의 상속과 우선순위 개념 때문입니다.
```

```css
모든 브라우저는 HTML 요소에 대해 기본 스타일을 가지고 있습니다.

예를 들어, a 태그는 기본적으로 파란색 텍스트와 밑줄로 표시됩니다.

이러한 기본 스타일은 부모 요소로부터의 스타일 상속보다 우선순위가 높습니다.

따라서, 푸터의 color: white; 설정이 부모 요소(main-footer)에서 a 태그로 상속되더라도,

브라우저는 기본 스타일(파란색)을 적용하기 때문에 상속된 스타일이 무시됩니다.
```

# { 패키지에 ‘float(플로팅)’ 프로퍼티 추가하기 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381555/notion-blog/_/_/CSS/_CSS_/_4_5_CSS_/image_16.png)

## 1. **float 속성의 의미**

```jsx
float는 HTML 요소를 왼쪽(left) 또는 **오른쪽(right)**으로 배치하여 기본 흐름에서 벗어나게 하는 속성입니다.

예를 들어, 이미지를 텍스트의 왼쪽이나 오른쪽에 배치하고 텍스트가 그 주위를 감싸게 할 때 사용합니다.

그러나 이 속성은 문서 레이아웃의 배치 문제를 일으킬 수 있습니다.

주로 Flexbox와 같은 더 나은 레이아웃 도구가 있어서 요즘은 많이 사용되지 않아요.
```

## 2. **예제 1: float을 사용한 요소 배치**

```
<style>
  #free {
    float: right;
    border-left: 4px solid darkgreen;
    text-align: right;
  }
</style>

<section id="free">
  <h2>프리 요금제</h2>
  <p>이용료: 무료</p>
</section>
```

```jsx
이 예제에서, #free는 float: right 속성을 사용해 페이지의 오른쪽으로 이동합니다.

그러나 이로 인해 문서 레이아웃에서 흐름이 깨지며, 뒤에 있는 다른 요소들이 예상치 못한 방식으로 배치될 수 있습니다.
```

## 3. **float 문제 해결: clearfix 사용**

```jsx
float로 인해 요소들이 예상과 다르게 배치될 수 있는데, 이를 해결하기 위해 clearfix라는 방법을 사용합니다.

float 속성이 적용된 요소 뒤에 clear 속성을 가진 요소를 추가하여 float의 영향을 제거할 수 있습니다.
```

```jsx
<style>
  .clearfix {
    clear: both;
  }
</style>

<section id="free">
  <h2>프리 요금제</h2>
  <p>이용료: 무료</p>
</section>

<div class="clearfix"></div>
```

```jsx
이 코드에서 clear: both를 사용해 float의 영향을 받지 않도록 처리합니다. 이 방법을 통해 페이지 레이아웃이 정상적으로 돌아옵니다.
```

# **블록 레벨 요소**와 **인라인 요소**의 차이

## 블록 레벨 요소

```jsx
페이지에서 블록으로 렌더링되며, 가능한 모든 수평 공간을 차지합니다.

예시: <div>, <section>, <article>, <nav>, <h1>, <p> 등.

margin-top과 margin-bottom을 설정하면 서로 다른 라인에 렌더링됩니다.
```

## 인라인 요소

```jsx
콘텐츠가 들어가는 공간만 차지하며, 같은 라인에 여러 인라인 요소가 들어갈 수 있습니다.

예시: <a>, <span>, <img> 등.

상하 바깥쪽 여백과 안쪽 여백은 요소에 영향을 미치지 않으며, 너비와 높이도 설정할 수 없습니다.
```

## **`inline-block`**:

```jsx
블록 레벨 요소와 인라인 요소의 동작을 모두 결합하고 싶을 때 사용합니다.

이 속성을 사용하면 인라인 요소가 블록처럼 안쪽 여백, 바깥쪽 여백을 가지면서도 인라인처럼 동작합니다.
```
