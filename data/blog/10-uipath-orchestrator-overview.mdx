# **UiPath Orchestrator와 연결하기**

## **개념 설명**

```python
UiPath Orchestrator는 RPA(로보틱 프로세스 자동화) 봇을 관리, 배포, 모니터링하는 중앙 플랫폼이다.

Orchestrator에 연결하면 봇을 클라우드에서 게시하고, 웹사이트의 버튼 클릭이나 다른 이벤트를 통해 트리거할 수 있다.
```

## **UiPath Assistant 열기**:

```python
작업 표시줄에서 "UiPath Assistant"를 검색하여 앱을 실행한다.

작업 트레이의 하단에서 UiPath Assistant 아이콘을 클릭하여 앱을 연다.
```

## **Orchestrator 연결 상태 확인**:

```python
UiPath Assistant의 상단에 녹색 점이 나타나면 Orchestrator와 연결된 상태를 의미한다.
```

# 무인 라이선스에 연결하기

## **개념 설명:**

```python
**무인 라이선스(Unattended License)**는 사람이 개입하지 않아도 봇이 자동으로 실행될 수 있도록 설정하는 라이선스이다.

무인 라이선스를 설정하면 Orchestrator에서 봇을 직접 실행하고 트리거할 수 있다.
```

## **기존 로그인에서 로그아웃**:

```python
브라우저를 열고 UiPath Orchestrator에서 로그아웃

로그아웃 후 브라우저의 히스토리와 쿠키를 삭제
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380807/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_10_UiPath_Orchestrator_Overview/Untitled_5.png)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380807/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_10_UiPath_Orchestrator_Overview/Untitled_6.png)

```python
Orchestrator 서비스로 이동

테넌트를 생성하지 않았다면 "Tenant 추가하기"를 클릭하여 새 테넌트를 생성
```

## **프로세스 시작하기**

```python
프로세스 선택:

위의 화면에서 재생 버튼을 클릭

컴퓨터를 선택. (기본값으로 생성된 워크스페이스 머신)

무인 로봇 권한 확인:

"현재 폴더에는 무인 로봇 권한을 가진 사용자가 없습니다"라는 메시지가 표시되면, 라이선스가 없다는 의미

무인 로봇 권한을 얻기 위해서는 Orchestrator에서 라이선스를 설정해야 한다
```

```python
Tenant 및 Personal Workspace 이동:

'Robots'를 클릭하여 로봇 목록을 확인

로컬 사용자로 구성된 'dongk'라는 로봇이 보인다 로봇 유형은 'Attended' (수동)이다.
```

## **로봇 유형 추가**

```python
로봇 유형 추가:

'Tenant' 탭으로 돌아가서 'Machines'을 클릭

기본 생성된 워크스페이스 머신을 확인

나중에 추가할 수 있도록 'Folder' 버튼을 클릭하여 폴더 설정으로 이동
```

## **사용자 및 컴퓨터 할당**

```python
새 폴더 생성:

'Create Folder' 버튼을 클릭하여 새 폴더를 생성 예: "My First Folder".

설명을 입력 예: "For testing and training purposes".

'Tenant Package Feed'를 기본값으로 둠

'Create' 버튼을 클릭하여 폴더를 생성
```
