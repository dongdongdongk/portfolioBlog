## 💻 Step 2: C++ 변수 생성

### 2-1: Header 파일

**HUDWidget.h:**

```cpp
#pragma once

#include "CoreMinimal.h"
#include "Blueprint/UserWidget.h"
#include "Components/ProgressBar.h"  // 👈 Include 추가!
#include "HUDWidget.generated.h"

UCLASS()
class SHOOTERSAM_API UHUDWidget : public UUserWidget
{
    GENERATED_BODY()

public:
    // ===== Progress Bar 변수 =====
    UPROPERTY(EditAnywhere, meta = (BindWidget))
    UProgressBar* HealthBar;

    // ===== 업데이트 함수 =====
    void SetHealthBarPercent(float NewPercent);
};
```

---

### UPROPERTY 설명

**EditAnywhere:**

```
에디터에서 편집 가능
→ 하지만 자동 바인딩됨
```

**meta = (BindWidget):**

```
위젯 블루프린트와 자동 연결
  ↓
이름이 같으면:
  HealthBar (C++) ↔ HealthBar (블루프린트)
  → 자동 바인딩!
```

---

### BindWidget vs BindWidgetOptional

**BindWidget (필수):**

```cpp
meta = (BindWidget)
```

**효과:**

```
블루프린트에 해당 이름 없으면:
  → 에러! ❌
  → 컴파일 안 됨

강제성:
  → 반드시 있어야 함
```

---

**BindWidgetOptional (선택):**

```cpp
meta = (BindWidgetOptional)
```

**효과:**

```
블루프린트에 해당 이름 없어도:
  → OK! ✅
  → 그냥 nullptr

유연성:
  → 있으면 쓰고 없으면 말고
```

---

**우리는 BindWidgetOptional 사용!**

```cpp
UPROPERTY(EditAnywhere, meta = (BindWidgetOptional))
UProgressBar* HealthBar;
```

**이유:**

```
더 안전함
→ 이름 틀려도 크래시 안 남
→ 유연함
```

### 함수 분석

**범위 체크:**


```
  ↓
1.5 같은 값 넣으면:
  → 이상하게 표시됨

-0.5 같은 값:
  → 말이 안 됨

범위 체크:
  → 안전! ✅
```

**SetPercent:**

```cpp

```

**동작:**


## 🎮 Step 3: Player Controller 수정

### 3-1: HUDWidget Public으로

**ShooterSamPlayerController.h:**

```cpp
class SHOOTERSAM_API AShooterSamPlayerController : public APlayerController
{
    GENERATED_BODY()

protected:
    // ...

public:  // 👈 Public으로 변경!
    // ===== HUD 위젯 =====
    UPROPERTY(EditDefaultsOnly)
    TSubclassOf<UHUDWidget> HUDWidgetClass;

    UHUDWidget* HUDWidget;  // 👈 접근 가능하게!
};
```

**왜 Public?**

```
기존 (Protected):
  외부에서 접근 불가
  → Character가 HUDWidget 못 씀

변경 (Public):
  외부에서 접근 가능
  → Character가 HUDWidget 사용 가능! ✅
```

```cpp
#include "ShooterSamPlayerController.h"  // 👈 Include 추가
```

---

**ShooterSamCharacter.cpp:**

```cpp
void AShooterSamCharacter::UpdateHUD()
{
    // ===== 1. Player Controller 가져오기 =====
    AShooterSamPlayerController* PlayerController =
        Cast<AShooterSamPlayerController>(GetController());

    // ===== 2. 유효성 확인 =====
    if (PlayerController)
    {
        // ===== 3. 퍼센트 계산 =====
        float NewPercent = Health / MaxHealth;

        // ===== 4. 음수 방지 =====
        if (NewPercent < 0.0f)
        {
            NewPercent = 0.0f;
        }

        // ===== 5. HUD 업데이트 =====
        PlayerController->HUDWidget->SetHealthBarPercent(NewPercent);
    }
}
```

---

### 코드 완전 분해

**1. GetController()**

```cpp
GetController()
```

**동작:**

```
Character의 함수
  ↓
이 Character를 조종하는 Controller 반환
  ↓
AController* 타입
```

---

**2. Cast**

```cpp
Cast<AShooterSamPlayerController>(GetController())
```

**왜?**

```
GetController() 반환:
  AController* (부모 타입)

우리가 원하는 것:
  AShooterSamPlayerController* (자식)
  → HUDWidget 변수 있음!

Cast 필요!
```

---

**3. 퍼센트 계산**

```cpp
float NewPercent = Health / MaxHealth;
```

**예시:**

```
Health = 100, MaxHealth = 100
  → 100 / 100 = 1.0 (100%)

Health = 50, MaxHealth = 100
  → 50 / 100 = 0.5 (50%)

Health = 25, MaxHealth = 100
  → 25 / 100 = 0.25 (25%)

Health = 0, MaxHealth = 100
  → 0 / 100 = 0.0 (0%)
```

---

**4. 음수 방지**

```cpp
if (NewPercent < 0.0f)
{
    NewPercent = 0.0f;
}
```

**왜 필요?**

```
사망 시:
  Health = 0
  DetachFromControllerPendingDestroy()

UpdateHUD 호출 시:
  GetController() = nullptr
  → 에러 가능

또는:
  Health가 음수가 될 수도
  → 0.0으로 보정
```

---

**5. HUD 업데이트**

```cpp
PlayerController->HUDWidget->SetHealthBarPercent(NewPercent);
```

**체이닝:**

```
PlayerController:
  AShooterSamPlayerController*
  ↓
HUDWidget:
  UHUDWidget*
  ↓
SetHealthBarPercent(NewPercent):
  void 함수
  → HealthBar->SetPercent() 호출
```

### 4-2: 호출 위치

**BeginPlay:**

```cpp
void AShooterSamCharacter::BeginPlay()
{
    Super::BeginPlay();

    OnTakeAnyDamage.AddDynamic(this, &AShooterSamCharacter::OnDamageTaken);
    Health = MaxHealth;

    // ===== 초기 HUD 설정 =====
    UpdateHUD();  // 👈 여기!

    // Gun 설정...
}
```

**왜?**

```
게임 시작 시:
  체력 바가 비어있을 수도
  → 잘못된 표시

UpdateHUD() 호출:
  → 100% 표시
  → 정확함! ✅
```

---

**OnDamageTaken:**

```cpp
void AShooterSamCharacter::OnDamageTaken(...)
{
    if (!IsAlive) return;

    if (IsAlive)
    {
        Health -= Damage;

        // ===== 데미지 받을 때마다 업데이트 =====
        UpdateHUD();  // 👈 여기!

        if (Health <= 0.0f)
        {
            IsAlive = false;
            Health = 0.0f;
            GetCapsuleComponent()->SetCollisionEnabled(ECollisionEnabled::NoCollision);
            DetachFromControllerPendingDestroy();
        }
    }
}
```

**왜 여기?**

```
UpdateHUD 위치:
  Health -= Damage 직후 ✅

사망 체크 전:
  → Health 값 정확

사망 체크 후는?
  → Health = 0.0 강제 설정
  → 괜찮음!

DetachFromController 전:
  → Controller 아직 있음
  → UpdateHUD 정상 작동
```

### Random 노드 설정

**Randomize Without Replacement:**

```
체크 ON (기본):
  모든 사운드를 한 번씩 재생
  → 반복 안 됨
  → 다양함!

  예: 1→3→5→2→4→6 (순서는 랜덤)
       다시 1→5→3...

체크 OFF:
  완전 랜덤
  → 같은 소리 연속 가능
  → 1→1→1 가능
```

**추천: ON 유지 ✅**
