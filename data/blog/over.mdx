# **OVER절이란?**

```sql
누적이라던가, 순위, 퍼센테이지, 평균, 총합 등 데이터를 통계나 집계할 때

"단일함수랑 집계함수랑 같이 올 수 없기 때문에", 서브쿼리를 사용하게 된다

특히 다수의 집계결과가 필요할 때 여러 서브쿼리와 그룹바이로 인해 쿼리가 지저분해진다

이를 마법처럼 간단하게 만들어주는 절이 OVER절
```

```sql
주의할점은 집계함수는 단일함수, 집계되지 않은 컬럼과 같이 사용할 수 없다

총합이랑 평균이 필요한데 위처럼 간단하게 작성하는건 불가능하다.

결국 서브쿼리로 평균과 합계 데이터를 뽑아줘야 하는 것
```

```sql
SELECT
	EMPLOYEE_ID 직원번호,
	SALARY 연봉,
	ROUND((
		SELECT AVG(SALARY)
		FROM EMPLOYEES
	)) AS 직원평균연봉,
	(
		SELECT SUM(SALARY)
		FROM EMPLOYEES
	) AS 전체연봉
FROM EMPLOYEES
```

```sql
서브쿼리가 SELECT절에 두개나 들어가 복잡하게 작성
```

```sql
SELECT EMPLOYEE_ID 직원번호,
		SALARY 연봉,
		ROUND(AVG(SALARY) OVER()) 직원평균연봉,
		SUM(SALARY) OVER() 전체연봉
FROM EMPLOYEES
```

```sql
over절을 사용하면 매번 서브쿼리를 만들 필요 없이 간단하게 줄일 수 있다
```

```sql
OVER는 서브쿼리뿐만 아니라 GROUP BY, ORDER BY 가 복잡하게 섞인 쿼리도 간단하게 표현할 수 있게 해준다.

또 RANK(), DENSE_RANK() 등 다양한 집계함수를 지원해줘서 편리하게 데이터를 표현할 수 있다.
```

# **OVER절 문법/사용법**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380958/notion-blog/_/Database/SQL_/_/_OVER/Untitled_3.png)

```sql
집계함수(또는 분석함수)는 count, sum, avg말고도 종류가 매우 많다

SUM(SCORE) OVER() 하면 전체 점수의 합계

AVG(SCORE) OVER()하면 평균 점수가
```

## 주의점

```sql
OVER절은 FROM, WHERE, GROUP BY, HAVING절 이후에 계산
```

```sql
SELECT EMPLOYEE_ID, count(*) OVER() 직원수, sum(SALARY) over() 총연봉
FROM EMPLOYEES e
WHERE JOB_ID = 'IT_PROG'
```

```sql
위와 같이 코드를 짠다면, 직업이 IT_PROG인 직원이라는 전제가 먼저 깔린다.

즉 전체직원수가 아닌 IT_PROG직원수가 되고, 전체연봉이 아닌 IT_PROG 연봉의 총합이 결과가 된다
```

# **OVER절 괄호안의 구문**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380959/notion-blog/_/Database/SQL_/_/_OVER/Untitled_5.png)

```sql
'OVER()' 이렇게 괄호안에 아무것도 없이 사용할 수도 있지만,

OVER(PARTITION BY 컬럼) 이런식으로 괄호안에 조건을 주기위한 절을 추가로 더할 수 있다
```

```sql
* PARITION BY는 GROUP BY를 OVER절에서 사용하고 싶을 때

* ORDER BY는 말그대로 정렬조건을 주고 싶을 때

* 세부분할기준(windowing clause)은 이 외에 추가적인 분할조건을 주고 싶을 떄 사용합니다.
```

```sql
예를 들어 SUM(salary) OVER()하면 전체연봉인대

SUM(SALARY) OVER(PARITION BY JOB_ID) 하면 JOB_ID별 연봉총합이 되는것
```

```sql
--##### OVER절 없이 #####
SELECT e1.EMPLOYEE_ID , e1.JOB_ID,
	 (
	 	SELECT SUM(SALARY)
	 	FROM EMPLOYEES
	 ) 전체총합, 직무별총합
FROM EMPLOYEES e1,
	(
		SELECT JOB_ID, SUM(SALARY) AS 직무별총합
		FROM EMPLOYEES
		GROUP BY JOB_ID
		ORDER BY JOB_ID
	) e2
WHERE  e1.JOB_ID  = e2.JOB_ID;

--##### OVER절 사용! #####
SELECT EMPLOYEE_ID, JOB_ID ,
		SUM(SALARY) OVER() 전체총합,
		SUM(SALARY) OVER(PARTITION BY JOB_ID ORDER BY JOB_ID) 직무별총합
FROM EMPLOYEES e ;
```
