
# 동적 vs 약형 언어

![Untitled](<%EC%84%B9%EC%85%981(%EA%B0%9C%EC%9A%94)/Untitled%201.png>)

```java
동적 해석형 (Dynamic, interpreted Programming Language)

미리 컴파일 되지 않았음을 의미한다.

예를 들어 다른 C++ , C 같은 언어는 개발중 또는 개발 후에 컴파일 된다. (최종 사용자와 공유하기 전)

또한 런타임에 해석,분석 되어 코드는 변경 될 수 있다 ( 예를 들어 데이터의 타입이 동적으로 변경 될 수 있다 (처음에는 스트링 이였다가 나중에는 숫자 등등))

약형 언어 (Weakly Typed Programming Language)

자바스크립트는 전송 중 컴파일된다. 즉, 코드가 런타임에 평가되고 실행된다. 코드가 런타임에 변경될 수 있음을 의미한다.

정수형 변수를 할당한 변수에 문자열을 재할당한다던지... 등의 작업을 수행할 수 있다. 이는 다른 언어에서는 할 수 없는 작업이다.

사실 자바스크립트는 변수를 선언할 때 let이나 var 등을 쓰기 때문에 변수형이라는게 딱히 없긴 하다. 하지만 이는 단점이 될 수도 있다. 이는 TypeScript의 등장으로 보완된다.
```
