# 인수 패널 ( Arguments Panel )

```python
인수(argument)는 프로그래밍에서 함수나 메소드에 전달되는 값

함수나 메소드를 호출할 때 전달하는 값으로, 해당 함수나 메소드에서 처리하고자 하는 작업에 필요한 데이터를 제공

변수와 인수의 가장 큰 차이점은 인수는 시스템 간의 데이터를 전달하는 데 사용된다는 것

예를 들어 예를 들어 한 xaml 파일의 데이터를 다른 것으로 전달하고 싶다면 인수를 사용해야 한다

데이터를 API에 전달하려면 인수를 사용해야 한다

경로 orchestrator를 입력으로 넘기고 싶다면 인수를 사용해야 한다

데이터가 서로 다른 시스템으로 전달될 때는 인수를 사용하게 된다

같은 워크플로나 같은 xaml 파일로 데이터를 전달할 때는 변수를 사용한다

요약하면

인수는 방향이 있고 변수는 없는 것
```
