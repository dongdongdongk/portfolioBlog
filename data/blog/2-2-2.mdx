# Virtual Box란?

## 1. Oracle VirtualBox 소개

```jsx
Oracle VirtualBox란 무엇인가?

VirtualBox 정의:

VirtualBox는 Oracle Corporation에서 개발 중인 무료 및 오픈 소스 하이퍼바이저이다.

* 하이퍼바이저(Hypervisor)는 가상 머신을 만들고 관리하는 소프트웨어 아주 쉽게 설명하자면,

	컴퓨터에서 여러 운영체제를 동시에 실행할 수 있게 해주는 "가상 컴퓨터 관리자"라고 생각

지원 플랫폼:

Intel 또는 AMD 기반의 컴퓨터에서 실행되며, Windows, Mac, Linux, Solaris 등 다양한 운영체제를 지원한다.
```

## 2. VirtualBox의 필요성

```jsx
CentOS 설치 방법

	CentOS Linux 운영체제를 컴퓨터에 설치해야 하는데, 두 가지 방법이 있다:

		1. 기존 운영체제를 제거하고 CentOS를 설치.

		2. 기존 Windows 또는 Mac 운영체제 위에 VirtualBox를 설치하고, 그 위에 CentOS를 설치.


		* CentOS : 주로 서버 환경에서 사용되는 오픈 소스 Linux 배포판

			CentOS는 Red Hat Enterprise Linux(RHEL)의 소스 코드를 기반으로 만들어졌으며, 안정성과 보안성, 그리고 장기간 지원이 특징

기존 운영체제 유지

	VirtualBox를 사용하면 기존 운영체제를 유지하면서 CentOS를 설치할 수 있다.

	기존 데이터나 설정을 잃지 않고 새로운 운영체제를 실행할 수 있는 방법을 제공한다.
```

## 3. VirtualBox의 기능

```jsx
다중 운영체제 실행

	하이퍼바이저 역할: VirtualBox는 하드웨어 자원을 가상화하여 여러 운영체제를 동시에 실행할 수 있게 합니다.

	확장된 기능: 기존 컴퓨터의 기능을 확장하여 동일한 하드웨어에서 여러 운영체제를 실행할 수 있습니다.

설치 및 사용

	설치 방법: VirtualBox는 일반 소프트웨어처럼 설치가 간단합니다. 기존 운영체제 위에 설치됩니다.

	운영체제 설치: VirtualBox 설치 후, CentOS를 비롯한 다양한 운영체제를 설치할 수 있습니다.

	예: Windows, Mac, Linux 등.
```

## 4. VirtualBox의 작동 원리

```jsx
구조

하드웨어 계층: 기본적으로 컴퓨터의 하드웨어가 존재한다.

기존 운영체제: 하드웨어 위에 설치된 기본 운영체제 (Windows 또는 Mac).

VirtualBox 설치: 기존 운영체제 위에 VirtualBox를 설치.

다중 운영체제: VirtualBox를 통해 여러 운영체제(CentOS, Windows, Mac 등)를 가상 머신으로 설치하고 실행.
```

# { 리눅스를 설치하는 다양한 방법 }

## 1: 운영체제 설치 방법 개요

```java
1. CD 또는 DVD를 사용한 설치

2. ISO 이미지를 사용한 설치

3. 네트워크 부팅을 통한 설치
```

## 2: CD 또는 DVD를 사용한 설치

```java
운영체제를 CD나 DVD를 사용하여 설치하는 방법입니다. 이 방법은 다음과 같은 절차를 따른다:

CD/DVD 준비: Linux, Windows 또는 Mac과 같은 운영체제가 담긴 CD나 DVD를 준비한다.

드라이브 열기: 서버, 노트북, 워크스테이션 등 컴퓨터의 CD/DVD 드라이브를 연다.

CD/DVD 삽입: CD나 DVD를 드라이브에 삽입한다.

부팅: CD나 DVD에서 부팅한다.

설치 프로그램 시작: CD나 DVD가 인식되면 설치 프로그램이 자동으로 시작된다.

이 방법은 가장 일반적인 방법으로, 다양한 유형의 컴퓨터에서 사용될 수 있습니다.
```

## 3: ISO 이미지를 사용한 설치

```java
ISO 이미지를 사용하여 운영체제를 설치하는 방법입니다. 이 방법은 다음과 같은 절차를 따른다:

1. ISO 이미지 다운로드: 운영체제의 ISO 이미지를 해당 벤더의 웹사이트에서 다운로드한다.

	 예를 들어, Red Hat, CentOS 또는 Windows의 ISO 이미지를 다운로드합니다.

2. 가상 디스크에 ISO 이미지 연결: ISO 이미지를 컴퓨터의 가상 디스크에 연결한다. 이를 위해 각 제조사마다 다른 콘솔 접근 방법을 사용한다.

	Dell: iDRAC

	HP: iLO

	기타: 다른 콘솔 접근 방법

3. 콘솔 접근: 콘솔을 통해 ISO 이미지를 가상 디스크에 연결한다.

4. 설치 시작: 가상 디스크로부터 부팅하여 설치를 시작한다.
```

## 4: 네트워크 부팅을 통한 설치

```java
대규모 조직에서 네트워크를 통해 다수의 컴퓨터에 운영체제를 설치하는 방법이다.

1. 네트워크 부팅 설정: 설치할 컴퓨터에 네트워크 부팅을 설정한다.

2. 특정 IP 및 폴더 지정: 컴퓨터에 특정 IP 주소와 공유 서버의 특정 폴더를 지정한다. 공유 서버는 NFS 서버나 Samba 서버일 수 있다.

3. 네트워크 부팅: 컴퓨터를 네트워크를 통해 부팅하여 지정된 폴더에서 운영체제를 설치한다.

이 방법은 하루에 수백 대의 컴퓨터에 운영체제를 설치해야 하는 큰 조직에서 주로 사용된다.
```

# { Linux에서 사용되는 키보드 키 }

```jsx
1. 서론
	강의 소개: 리눅스에서 사용되는 키보드 키에 대한 강의입니다.

	대상: IT에 처음 입문하는 사람들을 위한 내용입니다. 기존에 키보드 키에 대한 기본 지식이 있는 경우,

	이 강의를 건너뛰고 다음 강의로 넘어가도 됩니다.

	목표: 키의 접근 방법과 발음을 이해하고, 리눅스에서의 활용법을 배우는 것입니다.

2. 주요 키 설명

	2.1. Escape 키

		기능: VI 에디터에서 편집 모드에서 벗어나거나 다른 작업을 중단할 때 사용합니다.

		발음: 'Escape'로 발음하며, 'Esc'라고도 표기됩니다.

	2.2. Tilde (~) 키

		위치: Escape 키 바로 아래에 위치합니다.

		기능: cd ~ 명령어를 사용하여 사용자 홈 디렉토리로 이동할 때 사용합니다.

		발음: 'Tilde'로 발음합니다.

	2.3. Backtick (`) 키

		위치: Tilde (~) 키 바로 아래에 위치합니다.

		기능: Backtick은 단일 따옴표나 쉼표와 혼동되지 않도록 주의합니다. 특정 스크립트나 명령어에서 사용됩니다.

		발음: 'Backtick'으로 발음합니다.

	2.4. Exclamation Point (!) 키

		위치: 숫자 1 키 위에 위치합니다.

		기능: 강조의 의미를 갖으며, 리눅스에서는 'bang'이라고도 불립니다.

		발음: 'Exclamation Point' 또는 'Bang'으로 발음합니다.

	2.5. At Sign (@) 키

		위치: 숫자 2 키 위에 위치합니다.

		기능: 이메일 주소에서 사용되며, 도메인과 사용자 이름을 구분하는 데 사용됩니다.

		발음: 'At Sign'으로 발음합니다.

	2.6. Pound Sign (#) 키

		위치: 숫자 3 키 위에 위치합니다.

		기능: 스크립트나 설정 파일에서 주석을 추가하는 데 사용됩니다. 해시태그로도 알려져 있습니다.

		발음: 'Pound Sign' 또는 'Hashtag'으로 발음합니다.

	2.7. Dollar Sign ($) 키

		위치: 숫자 4 키 위에 위치합니다.

		기능: 변수 정의에 사용됩니다.

		발음: 'Dollar Sign'으로 발음합니다.

	2.8. Percent Sign (%) 키

		위치: 숫자 5 키 위에 위치합니다.

		기능: 퍼센트 값을 나타내며, 스크립트에서 사용될 수 있습니다.

		발음: 'Percent Sign'으로 발음합니다.

	2.9. Caret (^) 키

		위치: 숫자 6 키 위에 위치합니다.

		기능: 문자열의 시작을 나타내는 데 사용됩니다. LSS 명령어에서 패턴 매칭에 사용됩니다.

		발음: 'Caret'으로 발음합니다.

	2.10. Ampersand (&) 키

		위치: 숫자 7 키 위에 위치합니다.

		기능: 프로세스를 백그라운드에서 실행할 때 사용됩니다.

		발음: 'Ampersand' 또는 'And Sign'으로 발음합니다.

	2.11. Asterisk (*) 키

		위치: 숫자 8 키 위에 위치합니다.

		기능: 자주 'Star'로 발음되며, 와일드카드 문자로 사용될 수 있습니다.

		발음: 'Asterisk' 또는 'Star'로 발음합니다.

	2.12. Open Parenthesis (() 키

		위치: 숫자 9 키 위에 위치합니다.

		기능: 괄호를 열 때 사용됩니다.

		발음: 'Open Parenthesis'로 발음합니다.

	2.13. Close Parenthesis ()) 키

		위치: 숫자 0 키 위에 위치합니다.

		기능: 괄호를 닫을 때 사용됩니다.

		발음: 'Close Parenthesis'로 발음합니다.

	2.14. Hyphen (-) 키

		위치: 숫자 0 키 바로 오른쪽에 위치합니다.

		기능: 옵션이나 대시를 입력할 때 사용됩니다. 하이픈은 대시와 같은 기능을 합니다.

		발음: 'Hyphen' 또는 'Dash'로 발음합니다.

	2.15. Equals (=) 키

		위치: 하이픈 (-) 키 위에 위치합니다.

		기능: 수학적 수식을 작성하거나 프로그래밍에서 값을 정의할 때 사용됩니다.

		발음: 'Equals'로 발음합니다.

	2.16. Tab 키

		기능: 탭 공간을 입력할 때 사용됩니다.

		발음: 'Tab'으로 발음합니다.

	2.17. Curly Braces ({}) 키

		위치: 탭 키 오른쪽에 위치합니다.

		기능: 코드 블록을 정의할 때 사용됩니다.

		발음: 'Curly Braces'로 발음합니다.

	2.18. Brackets ([]) 키

		위치: Curly Braces 키 옆에 위치합니다.

		기능: 배열이나 인덱스 등을 정의할 때 사용됩니다.

		발음: 'Brackets'로 발음합니다.

	2.19. Enter 키

		기능: 명령어나 입력을 실행할 때 사용됩니다. 때때로 'Carriage Return'으로도 불립니다.

		발음: 'Enter' 또는 'Carriage Return'으로 발음합니다.

	2.20. Colon (:) 및 Semicolon (;) 키

		위치: Enter 키 오른쪽에 위치합니다.

		기능: 스크립트나 편집기에서 명령어를 구분하거나, 중요한 정보를 구분할 때 사용됩니다.

		발음: 'Colon'과 'Semicolon'으로 발음합니다.

	2.21. Double Quote (") 및 Single Quote (') 키

		위치: Colons과 Semicolons 키 옆에 위치합니다.

		기능: 문자열을 정의하거나 문자를 감쌀 때 사용됩니다.

		발음: 'Double Quote' 및 'Single Quote'으로 발음합니다.

	2.22. Pipe (|) 키

		위치: Backslash 키 바로 위에 위치합니다.

		기능: 명령어의 출력을 다른 명령어의 입력으로 전달할 때 사용됩니다.

		발음: 'Pipe'로 발음합니다.

	2.23. Backslash () 및 Forward Slash (/) 키

		위치: Pipe 키 바로 아래에 위치합니다.

		기능: Backslash는 Windows에서 경로를 구분할 때 사용되고, Forward Slash는 리눅스에서 경로를 구분할 때 사용됩니다.

		발음: 'Backslash'와 'Forward Slash'로 발음합니다.

	2.24. Less Than (<) 및 Greater Than (>) 키

		위치: 키보드의 오른쪽에 위치합니다.

		기능: 입력 및 출력을 리디렉션할 때 사용됩니다. 두 개의 기호를 사용하여 파일에 데이터를 추가하거나 덮어쓸 수 있습니다.

		발음: 'Less Than' 및 'Greater Than'으로 발음합니다.

	2.25. Question Mark (?) 키

		위치: Greater Than 키 바로 아래에 위치합니다.

		기능: 질문이나 조건을 정의할 때 사용됩니다.

		발음: 'Question Mark'로 발음합니다.
```
