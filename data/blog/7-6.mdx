# { 배경 이미지 스타일링 이해하기: 이미지 크기와 위치 조정 }

```jsx
웹 페이지의 배경 이미지를 효과적으로 조정하는 방법을 살펴봅니다.

배경 이미지는 페이지의 분위기를 좌우하는 중요한 요소인데요,

CSS의 background 프로퍼티를 사용해 이미지의 크기와 위치를 조정하는 다양한 방법을 알아보겠습니다.
```

## 1. **배경 이미지 설정하기**

```jsx
기본 설정:

배경 이미지를 설정하려면 background-image: url("이미지 경로")를 사용합니다.
```

## 2. **이미지 크기 조정**

```jsx
픽셀 단위 크기 조정:

	background-size: 100px와 같이 설정하면, 이미지가 지정된 크기(너비)로 반복됩니다.

반복 제어:

	background-repeat를 통해 이미지의 반복을 제어할 수 있습니다. 예를 들어, no-repeat로 설정하면 이미지가 반복되지 않고 한 번만 나타납니다.

비율 유지 크기 조정:

	너비와 높이를 각각 설정할 수 있으며, 비율을 유지하려면 background-size: auto를 사용합니다.
```

## 3. **커버와 컨테인 설정**

```jsx
cover:

	background-size: cover는 이미지가 컨테이너를 완전히 채우도록 크기를 조정합니다.

	컨테이너에 맞춰 이미지가 잘리더라도 여백 없이 채워집니다.

contain:

	background-size: contain은 이미지 전체가 컨테이너 안에 맞게 조정됩니다.

	이미지가 잘리지 않지만, 컨테이너에 여백이 남을 수 있습니다.
```

## 실습 예제

```jsx
body {
    background-image: url("freedom.jpg");
    background-size: cover;
    background-position: bottom;
    background-repeat: no-repeat;
}
```

```jsx
이 코드는 배경 이미지가 페이지를 가득 채우며, 이미지의 아래쪽이 강조되어 보이도록 설정한 예제입니다.

background-size: cover로 이미지가 컨테이너를 채우게 하고, background-position: bottom으로 이미지의 하단을 보여주도록 했습니다.
```

# { Background-Origin과 Background-Clip의 차이 이해하기: 테두리와 이미지 자르기 }

```jsx
background-origin과 background-clip 프로퍼티를 다룹니다.

이 프로퍼티들은 배경 이미지가 컨테이너의 어느 부분에 맞춰지고, 어디까지 표시될지를 제어합니다.

이를 이해하기 위해 임시 테두리를 추가하고, 다양한 설정을 실습해 보겠습니다.
```

## 1. **Background-Origin과 임시 테두리 설정**

### **임시 테두리 추가**:

```jsx
border: 5px dashed red;
```

```jsx
이 코드는 배경 이미지에 5px의 빨간색 파선 테두리를 추가합니다.

테두리가 생긴 후 배경 이미지가 테두리와 어떻게 상호작용하는지 확인할 수 있습니다.
```

### **Background-Origin 기본값**:

```jsx
기본적으로 background-origin은 padding-box로 설정되어 있습니다.

이는 배경 이미지가 컨테이너의 안쪽 여백을 포함하지만, 테두리 뒤에 위치하지 않음을 의미합니다.
```

### **Content-Box로 설정**:

```jsx
background-origin: content-box;
```

```jsx
이미지를 컨테이너의 콘텐츠 영역에 맞추어 배치하며,

안쪽 여백과 테두리는 포함하지 않습니다. 테두리 안쪽에 여백이 생기는 것을 볼 수 있습니다.
```

### **Border-Box로 설정**:

```jsx
background-origin: border-box;
```

```jsx
배경 이미지가 테두리 뒤로 확장되어 컨테이너 전체에 맞춰지며, 테두리를 포함한 영역에 배치됩니다.
```

## 2. **Background-Clip의 역할**

```jsx
Background-Clip 설명: background-clip은 배경 이미지가 어디까지 표시될지를 정의합니다.

배경 이미지가 어느 부분에서 잘릴지를 결정합니다.
```

### Border-Box로 설정

```jsx
background-clip: border-box;
```

```jsx
이미지가 테두리 뒤에서 잘리며, 테두리와 함께 표시됩니다.
```

### **Padding-Box로 설정**:

```jsx
background-clip: padding-box;
```

```jsx
테두리 뒤에서 이미지가 잘리며, 테두리 안쪽의 여백에 따라 이미지가 제한됩니다. 이미지가 테두리와 접촉하지 않게 됩니다.
```

### **Content-Box로 설정**:

```jsx
background-clip: content-box;
```

```jsx
배경 이미지가 컨텐츠 영역까지만 표시되며, 안쪽 여백에 맞춰 잘립니다. 이미지 주변에 여백이 생깁니다
```

## 3. **Background-Attachment: 이미지 스크롤 설정**

```jsx
Background-Attachment 설명: background-attachment는 배경 이미지가 스크롤과 함께 움직이는지 여부를 설정합니다.
```

### **Fixed 설정**:

```jsx
background-attachment: fixed;
```

```jsx
배경 이미지가 뷰포트에 고정되어, 페이지가 스크롤되어도 이미지가 고정됩니다.
```

### **Scroll 설정**:

```jsx
background-attachment: scroll;
```

```jsx
이미지가 컨테이너 내에서 스크롤됩니다.
```

### **Local 설정**:

```jsx
background-attachment: local;
```

```jsx
이미지가 컨테이너의 콘텐츠와 함께 스크롤됩니다.
```

## 4. **모든 프로퍼티를 축약형으로 사용하기**

## **전체 축약형 사용**:

```jsx
모든 background 하위 프로퍼티를 하나의 축약형으로 결합할 수 있습니다.
```

```jsx
background: url("freedom.jpg") no-repeat fixed center/cover border-box border-box;
```

```jsx
이 코드는 이미지를 뷰포트에 고정시키고, 테두리와 여백을 포함해 배치합니다.
```

### CSS에서 이미지 크기 조정

```jsx
shared.css 파일을 열고, .main-header__brand 클래스에 대한 스타일을 확인합니다.
```

## 컨테이너와 이미지의 상호작용

### 컨테이너와 이미지의 관계

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381562/notion-blog/_/_/CSS/_CSS_/_7_/image_3.png)

```jsx
이미지 태그 <img>는 기본적으로 자체의 크기를 유지하며, 주변 요소의 크기에 영향을 받지 않습니다.

이미지가 포함된 <a> 태그는 인라인 요소이기 때문에, 높이와 너비의 설정이 제대로 적용되지 않을 수 있습니다.

<a> 태그를 인라인 블록(inline-block)으로 변경하여 컨테이너의 크기를 설정할 수 있습니다:
```

```jsx
.main-header__brand {
    display: inline-block;
    height: 22px;
}
```

```jsx
이후 이미지의 높이와 너비를 100%로 설정하면, 이미지가 컨테이너의 크기에 맞춰 조정됩니다:
```

```jsx
.main-header__brand img {
    height: 100%;
    width: auto; /* 너비는 자동으로 비율에 맞게 */
}
```

## 편법으로 이미지 위치 조정하기

```jsx
때로는 이미지의 위치를 더 세밀하게 조정하고 싶을 때가 있습니다. 이때 margin이나 padding을 음수로 설정하는 방법을 사용할 수 있습니다.

예를 들어, 이미지의 위치를 살짝 위로 이동시키고 싶다면 다음과 같이 설정할 수 있습니다

이렇게 하면 이미지가 약간 위로 이동하게 됩니다.
```

```jsx
.main-header__brand img {
    margin-top: -5px;
}
```

## 이미지 스타일링

```jsx
HTML 구조:

	testimonial__image-container라는 컨테이너 안에 testimonial__image 클래스가 적용된 이미지 태그가 있음.

CSS 작성:

	testimonial__image-container와 testimonial__image 클래스에 스타일을 추가하여 이미지를 조절.

	testimonial__image-container의 너비를 65%로 설정하고, 이미지는 컨테이너 너비의 100%를 차지하도록 설정.

	두 요소의 display를 inline-block으로 설정해 텍스트와 이미지를 한 줄로 배치.
```

```jsx
.testimonial__image-container {
    width: 65%;
    display: inline-block;
    vertical-align: middle;
    box-shadow: 3px 3px 5px 3px rgba(0, 0, 0, 0.3);
}

.testimonial__image {
    width: 100%;
    vertical-align: top;
}
```

```jsx
.testimonial__info {
    text-align: right;

    width: 30%;
}
```

# 선형 그러데이션(CSS Linear Gradients)

```jsx
CSS에서 선형 그러데이션은 색상이 한 점에서 다른 점으로 자연스럽게 변환되는 효과를 만들 수 있는 기능입니다.

이 기능을 사용하면 웹 페이지의 배경을 단순한 색상 대신 더 다양한 색상 변환으로 꾸밀 수 있습니다.
```

## 1. 기본 선형 그러데이션

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381562/notion-blog/_/_/CSS/_CSS_/_7_/image_6.png)

```jsx
/* main.css */
background-image: linear-gradient(red, blue);
```

```jsx
위 코드는 빨간색에서 파란색으로 변환되는 기본적인 선형 그러데이션을 생성합니다.

기본적으로 색상 변환은 위에서 아래로 수직 방향으로 이루어집니다.
```

## 2. 방향 지정

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381562/notion-blog/_/_/CSS/_CSS_/_7_/image_7.png)

```jsx
선형 그러데이션의 방향을 지정할 수 있습니다.

방향을 지정하려면 첫 번째 인수로 방향 값을 넣으면 됩니다.
```

```jsx
/* 위에서 아래로 (기본값) */
background-image: linear-gradient(to bottom, red, blue);

/* 왼쪽 상단에서 오른쪽 하단으로 */
background-image: linear-gradient(to right bottom, red, blue);

/* 각도를 이용해 방향 지정 */
background-image: linear-gradient(45deg, red, blue);
```

```jsx
to bottom: 위에서 아래로 (기본값)

to right bottom: 오른쪽 하단을 향해 사선으로 변환

45deg: 45도 각도로 변환
```

## 3. 여러 색상 사용

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381563/notion-blog/_/_/CSS/_CSS_/_7_/image_8.png)

```jsx
선형 그러데이션에는 두 가지 색상뿐 아니라 여러 색상을 사용할 수 있습니다.
```

```jsx
background-image: linear-gradient(red, green, blue, yellow);
```

```jsx
위 코드는 빨간색에서 시작해 녹색, 파란색, 노란색으로 변환되는 그러데이션을 만듭니다.
```

## 4. 위치 지정

```jsx
색상이 어디서 시작하고 끝날지 세밀하게 지정할 수도 있습니다. 각 색상에 비율(%)을 지정하면 됩니다.
```

```jsx
background-image: linear-gradient(red 20%, green 50%, blue 80%);
```

```jsx
위 코드에서는 빨간색이 20%까지, 녹색이 50%까지, 파란색이 80%까지 차지하며 그다음 색으로 자연스럽게 변환됩니다.
```

## 5. 투명도 적용

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381563/notion-blog/_/_/CSS/_CSS_/_7_/image_9.png)

```jsx
선형 그러데이션에서 색상에 투명도를 적용할 수 있습니다. 이를 통해 배경 이미지가 드러나는 효과를 줄 수 있습니다.
```

```jsx
/* 투명도 적용 */
background-image: linear-gradient(red, transparent);
```

```jsx
위 코드는 빨간색에서 투명해지며 배경이 보이는 그러데이션을 만듭니다.
```

# { 원형 그러데이션(CSS Radial Gradients) }

```jsx
CSS에서 원형 그러데이션은 중심에서 시작하여 주변으로 퍼져나가는 색상 변환 효과를 만들어줍니다.
```

## 1. 기본 원형 그러데이션

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381561/notion-blog/_/_/CSS/_CSS_/_7_/image_10.png)

```jsx
/* main.css */
background-image: radial-gradient(red, blue);
```

## 2. 원형 그러데이션 만들기

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381561/notion-blog/_/_/CSS/_CSS_/_7_/image_11.png)

```jsx
타원형 대신 원형으로 만들려면 circle을 첫 번째 인수로 추가합니다.
```

```jsx
background-image: radial-gradient(circle, red, blue);
```

## 3. 시작 위치 지정

```jsx
원형 그러데이션의 중심 위치를 변경할 수 있습니다. at 키워드를 사용하여 위치를 설정합니다.
```

```jsx
/* 중앙이 상단에 위치 */
background-image: radial-gradient(circle, red, blue at top);

/* 왼쪽 상단에 위치 */
background-image: radial-gradient(circle, red, blue at top left);

/* 커스텀 위치 지정 (왼쪽에서 20%, 위에서 50%) */
background-image: radial-gradient(circle, red, blue at 20% 50%);
```

## 4. 크기 조절

```jsx
circle 뒤에 크기를 지정해 원의 크기를 조절할 수 있습니다. 타원형의 경우 너비와 높이를 각각 지정할 수 있습니다.
```

```jsx
/* 원형의 크기 지정 */
background-image: radial-gradient(circle 20px, red, blue);

/* 타원형의 크기 지정 */
background-image: radial-gradient(ellipse 50px 100px, red, blue);
```

## 5. 키워드를 통한 크기 조절


# { 다중 배경 이미지 및 선형 그러데이션 }

```jsx
CSS에서는 하나의 요소에 여러 배경 이미지를 설정할 수 있으며, 이때 배경 이미지와 그러데이션을 겹쳐서 적용할 수 있습니다.
```

## 1. 다중 배경 이미지 및 색상 설정

```jsx
하나의 요소에 여러 배경을 설정할 때, 각 배경은 쉼표(,)로 구분됩니다.

가장 위에 있는 배경이 우선적으로 표시되며, 아래에 있는 배경은 위의 배경이 투명한 부분을 통해 보이게 됩니다.
```

```jsx
/* main.css */
background:
  linear-gradient(rgba(80, 68, 18, 0.6), transparent 10%),
  url('background-image.jpg'),
  red;
```

```jsx
linear-gradient: 배경 이미지 위에 덮을 그러데이션입니다. 이 경우 밝고 투명한 회색에서 완전히 투명한 색으로 전환됩니다.

url('background-image.jpg'): 실제 배경 이미지입니다.

red: 이미지가 로딩되지 않을 때 사용될 대체 배경색입니다.
```

## 2. 여러 배경을 위한 속성 설정

```jsx
각 배경 이미지는 고유의 속성(Property)을 가질 수 있습니다. 예를 들어,

배경 위치, 배경 크기 등을 각 배경 이미지에 개별적으로 지정할 수 있습니다.
```

```jsx
background:
  linear-gradient(rgba(80, 68, 18, 0.6), transparent 10%) no-repeat center center,
  url('background-image.jpg') no-repeat center center/cover,
  red;
```

```jsx
no-repeat: 배경이 반복되지 않도록 설정합니다.
center center: 배경 이미지를 중앙에 배치합니다.
/cover: 배경 이미지가 요소를 덮도록 크기를 조정합니다.
```

## 3. 투명도를 활용한 배경 스태킹

```jsx
배경 이미지 또는 그러데이션의 투명도를 조정하여 아래 배경이 보이도록 할 수 있습니다.
```

```jsx
background:
  linear-gradient(rgba(80, 68, 18, 0.6), transparent 10%),
  url('background-image.jpg') no-repeat center center/cover,
  red;
```

```jsx
이 코드에서 상단의 선형 그러데이션이 약간의 투명도를 가지고 있기 때문에,

하단의 배경 이미지가 함께 보이게 됩니다. 가장 아래의 red 색상은 대체 색상으로,

이미지가 로딩되지 않을 경우 표시됩니다.
```

# { 필터(Filter) 프로퍼티 }

## 1. **필터란?**

```jsx
필터는 CSS에서 요소의 외양을 변경하는 데 사용되는 프로퍼티입니다.

이미지를 흐리게 하거나, 회색 톤으로 만들거나, 색상을 반전시키는 등의 다양한 효과를 적용할 수 있습니다.
```

## 2. **필터 적용 방법**

```jsx
필터는 CSS의 filter 프로퍼티를 사용해 적용할 수 있습니다. 예를 들어,

배경 이미지를 회색 톤으로 바꾸려면 grayscale 필터를 사용할 수 있습니다.
```

```jsx
/* packages.css */
.background {
    filter: grayscale(40%);
}
```

```jsx
grayscale(40%): 이미지의 색상을 40% 회색 톤으로 만듭니다.

blur(px): 이미지를 흐리게 만듭니다.

brightness(%), contrast(%), invert(%), opacity(%): 밝기, 대비, 색상 반전, 투명도 등을 조절할 수 있습니다.
```
