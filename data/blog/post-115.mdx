## **React에서의 Key 속성 및 Eslint 경고 해결**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_3.png)

### **Key 속성의 필요성**

```jsx
map 함수를 사용하여 배열의 각 요소를 순회할 때, **React는 각 요소에 고유한 식별자인 key 속성이 필요함**.

key 속성을 통해 React는 요소의 변경, 추가, 삭제를 효율적으로 추적할 수 있음.

이를 통해 React는 업데이트 시 변경된 부분만을 감지하여 최적화된 렌더링을 수행.
```

### **Eslint 경고 및 브라우저 오류**

```jsx
Eslint 및 브라우저 콘솔에서 "key" 속성이 없다는 경고가 발생

브라우저에서는 각 리스트의 자식 요소에 대해 고유한 "key" 속성이 필요하다는 오류 메시지 표시.

이러한 오류는 현재 예제에서는 렌더링에는 지장이 없지만, 추후 순서 변경이나 동적인 요소 추가/제거 시 문제 발생 가능.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_4.png)

```jsx
고유 식별자로 사용 할 id 를 추가해준다

( 모든 데이터 베이스는 고유 식별자가 존재한다 지금은 임시로 하기 때문에 이게 없었다 )

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381426/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_5.png)

	고유한 값이기만 하면 된다
```

## 항목을 나누는 예제

```jsx
**App 컴포넌트**:

전체 애플리케이션을 나타낸다.

쇼핑 아이템 목록을 가지고 있다.

<ShoppingList /> 컴포넌트에 쇼핑 아이템 목록을 전달한다.

**ShoppingList 컴포넌트**:

쇼핑 아이템 목록을 나타내며, 각 아이템을 <ShoppingListItem />으로 매핑한다.

각각의 아이템은 고유한 키와 함께 <ShoppingListItem /> 컴포넌트로 전달된다.

**ShoppingListItem 컴포넌트**:

각 쇼핑 아이템을 나타낸다.

전달받은 프로퍼티를 이용하여 스타일을 동적으로 설정하고, 해당 아이템을 렌더링한다.
```

```jsx
// App.jsx

import React, { useState } from 'react'
import ShoppingList from './components/ShoppingList'

function App() {
  const [shoppingItems, setShoppingItems] = useState([
    { id: 1, item: 'Eggs', quantity: 12, completed: false },
    { id: 2, item: 'Milk', quantity: 1, completed: true },
    // Additional shopping items...
  ])

  return (
    <div>
      <h1>Shopping List</h1>
      <ShoppingList items={shoppingItems} />
    </div>
  )
}

export default App
```

```jsx
// ShoppingList.jsx

import React from 'react'
import ShoppingListItem from './ShoppingListItem'

function ShoppingList({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <ShoppingListItem key={item.id} {...item} /> // 스프레드를 사용해서 코드를 짧게 만들어줌
      ))}
    </ul>
  )
}

export default ShoppingList
```

```jsx
// ShoppingListItem.jsx

import React from 'react'

function ShoppingListItem({ item, quantity, completed }) {
  const style = {
    color: completed ? 'gray' : 'red',
    textDecoration: completed ? 'line-through' : 'none',
  }

  return (
    <li style={style}>
      {item} - {quantity}
    </li>
  )
}

export default ShoppingListItem
```

```jsx
* Property 컴포넌트에게 p 객체의 속성들을 전달하고 있다

* {...p} p 객체의 모든 속성을 Property 컴포넌트로 전달 ex) { id: 129031, name: "Desert Yurt", rating: 4.9, price: 150 }

* React에서는 주로 배열을 순회하면서 컴포넌트를 생성하거나, 배열의 각 요소에 변형을 가할 때 map 함수를 사용 ( 즉 배열을 순회하면서 Property 를

	return 하면서 Property.jsx 를 컴포넌트 생성
```

```jsx
import Property from './Property'
import './PropertyList.css'
export default function PropertyList({ properties }) {
  return (
    <div className="PropertyList">
      {properties.map((p) => {
        return <Property {...p} key={p.id} />
      })}
    </div>
  )
}
```
