# { 소켓(Socket) - 메시 위치 지정 }

## 🎯 목표

```
드론이 총을 쏘게 하기
  ↓
총알이 어디서 나와야 하나?
  ↓
소총 앞 정확한 위치 필요!
  ↓
Socket 사용!
```

---

## 📍 Socket이란?

### 개념

```
메시의 특정 위치에 이름표 붙이기
  ↓
나중에 그 위치 쉽게 찾기
  ↓
"여기서 총알 나와!"
```

### 비유

```
메시 = 집
Socket = 대문 표지판
  ↓
"대문 위치가 어디죠?"
"Rifle_L 소켓 보세요!"
```

## 🔄 Socket 방향

### Forward 방향 확인

### 중요!

```
Socket의 Forward (전방)
  ↓
발사체가 나갈 방향!
  ↓
반드시 앞을 향해야 함
```

### 확인 방법

```
Socket 선택
  ↓
빨간 화살표 = Forward
파란 화살표 = Up
초록 화살표 = Right
  ↓
빨간 화살표가 앞으로!
```

## ✨ 밝기 증폭

### 문제

```

  ↓

  ↓

```

### Multiply 노드

### 추가

```

  ↓
"*" 입력
  ↓
[Multiply]
```

### 값 설정

```
[Multiply]
  ├─ A: RGB 색상
  └─ B: 20 (스칼라)
      ↓
색상 × 20 = 매우 밝음!
```

### 더 밝게

```
값 조정:
  ├─ 20: 약간 밝음
  ├─ 50: 밝음
  ├─ 100: 매우 밝음
  └─ 120: 엄청 밝음!
```

### 연결

```
[Constant3Vector]
  ↓
[× 120]
  ↓
Emissive Color
```
