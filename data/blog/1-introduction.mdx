# 1. **렌더 파이프라인 개념 이해**

Unity는 장면을 렌더링할 때 **렌더 파이프라인(Render Pipeline)** 이라는 시스템을 사용한다.

현재 선택할 수 있는 3가지 종류가 있다.

---

## 🔶 **1) Built-in Render Pipeline (레거시)**

- Unity가 처음 만들어진 시점부터 존재한 **가장 오래된 파이프라인**
- 기본적인 기능은 모두 있음
- 하지만 **유지보수가 끝난 레거시 옵션**임
- 요즘은 사용하지 않는 것이 권장됨
- **특수한 상황**에서만 선택 (예: 올드 프로젝트를 반드시 유지해야 할 때)

---

## 🔷 **2) Universal Render Pipeline (URP)**

- 이름 그대로 “Universal”, 즉 **모든 플랫폼에서 동작하도록 설계됨**
- 모바일, PC, 웹, 닌텐도 스위치, PS 등 대부분의 장치에서 구동 가능
- 확장성, 사용성, 퍼포먼스 모두 균형 잡힘
- 난이도: ★★★☆☆ (적당히 쉬움)

➡️ **강의에서 추천하는 선택**

**URP가 기본 선택.**

특히 강의자처럼 PC 게임을 만들어도 URP를 사용하는 것을 추천.

---

## 🔳 **3) HDRP (High Definition Render Pipeline)**

- 고사양 PC, 차세대 콘솔을 위한 **초고화질 렌더 파이프라인**
- 시네마틱 그래픽, 고급 조명 옵션, 복잡한 머티리얼 등이 가능
- 난이도: ★★★★★ (복잡함)

➡️ **언제 사용?**

- "최고 화질"이 절대적으로 중요할 때만 사용
- 실사급 그래픽, AAA 스타일 프로젝트

---

## ✅ 결론

| 목적                    | 추천 파이프라인 |
| ----------------------- | --------------- |
| 모바일/PC/웹 전용       | **URP**         |
| 인디 게임, 프로토타입   | **URP**         |
| 하이엔드 PC 그래픽      | **HDRP**        |
| 오래된 구 프로젝트 유지 | Built-in        |

강의에서는 **URP를 선택**한다.

# 3. **Quality Level과 URP Asset 관계**

Unity는 기본적으로 3개의 품질 옵션을 제공한다:

- **High Fidelity**
- **Balanced**
- **Performance**

각 품질 레벨마다 **별도의 URP Asset 을 연결할 수 있다**.

---

## 🔍 확인 방법

경로

**Edit → Project Settings → Quality**

여기서 각 Quality Level을 클릭하면

→ 오른쪽에 **Render Pipeline Asset** 항목이 보임.

강의자 설정

- 에디터에서는 **High Fidelity**를 사용
- 이유: 에디터에서 가장 높은 퀄리티로 보이기 때문
- 플레이 빌드 시에는 각 플랫폼에 맞게 선택 가능

# 1. 포스트 프로세싱 개념 이해하기

### ✔ 무엇인가?

- **렌더링이 끝난 화면 위에 마지막으로 효과를 덧입히는 작업**
  (카메라 필터처럼 생각하면 됨)
- 색 보정, Bloom(빛 번짐), Vignette(가장자리 어둡게), 톤 매핑 등 다양한 효과를 합성하여 비주얼을 고급스럽게 만듦.

### ✔ 왜 쓰는가?

- 개발 초기에 꼭 필요한 건 아님 → 메카닉을 먼저 만드는 게 우선
- 하지만 **비주얼이 좋으면 개발 의욕이 상승**하고,
  강의는 시각적 이해를 돕기 위해 초반부터 적용함.

# 2. Global Volume 설정하기

씬을 열면 **기본적으로 Global Volume 오브젝트가 존재함**.

### ✔ Volume의 두 가지 모드

| Mode       | 설명                             |
| ---------- | -------------------------------- |
| **Global** | **전체 월드에 항상 적용됨**      |
| Local      | 특정 Collider 영역 안에서만 적용 |

→ 강의에서는 **전체 적용이 목적 → Global 사용**

### ✔ 주요 필드

- **Weight** : 효과의 전체 강도(0 = 완전 끔, 1 = 100%)
- **Priority** : 여러 Volume이 겹칠 때 우선순위
- **Profile** : 실제 효과들이 들어 있는 설정 파일

# 4. Tone Mapping 적용하기

### ✔ 개념

- **눈으로 보는 실제 밝기를 화면에 맞게 재해석하는 과정**
- 색 보정의 기초 단계.

### ✔ 설정 방법

1. Global Volume → **Add Override**
2. **Post-processing / Tone Mapping** 선택
3. 체크박스로 활성화
4. **Mode → Neutral** 설정

### ✔ Neutral을 쓰는 이유

- 보다 정확한 기본 색을 유지
- 채도가 과하게 변형되지 않음

### ✔ Scene View에서 효과가 안 보일 때

우측 상단 **Effects(✨)** 버튼을 켜야함

- 이 버튼이 꺼져 있으면 **아무 효과도 보이지 않음**

---

# 5. Color Adjustments 적용하기

### ✔ 목적

색감을 더 생동하게 만들기 위해 사용.

### ✔ 추가하기

Add Override → Post Processing → **Color Adjustments**

### ✔ 사용한 옵션

| 옵션           | 설명                                     |
| -------------- | ---------------------------------------- |
| **Saturation** | 색의 강도를 조절 (0=흑백, 높을수록 강렬) |
| **Contrast**   | 어두운 부분과 밝은 부분의 차이 증가      |

### ✔ 강의 설정값

- Saturation: **약 +46**
- Contrast: **약 +37**

효과: 색감이 살아나고 게임 화면이 선명하게 보임.

---

# 6. Directional Light 조정하기

Tone Mapping + Color Adjustments 적용 후

빛이 너무 강해 보이므로 Directional Light 세팅을 변경.

### ✔ 설정

- **Intensity = 1**
- **Color Temperature = 5000K**
  - 기본값 그대로: 자연광 느낌 유지

빛의 온도는 취향에 따라 조절 가능

(낮은 값 = 따뜻한 느낌 / 높은 값 = 차가운 느낌)

# 7. Bloom(빛 번짐) 적용하기

Bloom은 강한 밝기가 주변으로 번져 보이게 하는 효과.

### ✔ 사용 이유

- 이후 만들 “발광 총알, 폭발 이펙트”에 필수
- 화면 전체 분위기도 부드럽게 만듦

### ✔ 추가하기

Add Override → Post Processing → **Bloom**

### ✔ 활성화해야 하는 옵션

| 옵션          | 설명                           |
| ------------- | ------------------------------ |
| **Threshold** | 이 값을 넘는 밝기만 Bloom 발생 |
| **Intensity** | Bloom의 강도                   |

### ✔ 실험

- Threshold < 1 → 거의 모든 오브젝트가 빛나듯 보임
- Threshold = 1 / Intensity = 1 → 현실적인 Bloom

강의는 **현실적인 느낌**을 위해 둘 다 약 **1**로 설정.

---

# 9. 카메라 Post-processing 활성화

카메라에서도 Post-processing을 켜야 실제 게임 화면에 반영됨.

→ **Post Processing = Enabled**

# 10. Vignette(비네팅) 적용하기

화면 가장자리에 어둡게 그라데이션을 넣는 효과.

### ✔ 용도

- 화면에 집중감을 주고
- 영화적인 느낌을 강화함

### ✔ 설정

Add Override → Post Processing → **Vignette**

### ✔ 사용한 옵션

| 옵션          | 설명                 |
| ------------- | -------------------- |
| **Intensity** | 가장자리 어두운 정도 |

강의 설정:

- **Intensity = 약 0.45**
  → 너무 강하지 않은 “적당히 영화 같은” 분위기

# 11. Anti-Aliasing(계단 현상 제거)

Unity URP는 **카메라 설정** + **URP Asset 설정**

두 군데에서 Anti-aliasing 설정이 가능함.

---

## ✔ 1) 카메라 Anti-Aliasing

Main Camera → Rendering → **Anti-Aliasing**

| 모드     | 설명                 |
| -------- | -------------------- |
| **FXAA** | 속도 빠름, 품질 낮음 |
| **SMAA** | 중간 품질            |
| **None** | 끔                   |

강의에서는 **카메라에서는 OFF (None)**

→ 대신 URP Asset의 MSAA를 사용하기 때문.

---

## ✔ 2) URP Asset Anti-Aliasing (MSAA)

Project → URP High Fidelity Asset → Inspector

| 옵션        | 설명                 |
| ----------- | -------------------- |
| **MSAA 4×** | 가장 선명하고 고품질 |
| Disabled    | 완전 비활성화        |

High Fidelity Quality는 기본적으로 4× 활성화

Balanced / Performance는 비활성화 상태.

### ✔ 효과 예시

- MSAA OFF → 픽셀 아트처럼 계단이 선명
- MSAA 4× → 부드러운 에지(가장자리)

# 12. Screen Space Ambient Occlusion(SSAO)

SSAO는 **오브젝트가 교차하는 부분에 미세한 그림자를 추가해 입체감을 높이는 효과**.

### ✔ 위치

Renderer Asset → Inspector → **Renderer Features**

기본적으로 **SSAO가 추가되어 있음.**

### ✔ 효과

- 발 아래, 벽 모서리, 관절 사이에 미세한 그림자
- 켜고 끄면 캐릭터가 “떠 있는 느낌”과 “접지된 느낌” 차이가 큼

### ✔ 강의 설정

- **Intensity ≈ 3**
- **Radius ≈ 0.15**

카메라가 멀리서 내려다보는 탑다운 게임이므로

미세하게 보이도록 강하게 적용함.
