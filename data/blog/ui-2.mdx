# Rating 컴포넌트 만들기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381431/notion-blog/_/The_Web_Developer_2022/REACT/_UI/Untitled_8.png)

```jsx
import Rating from '@mui/material/Rating'
import { useState } from 'react'
function RatingDemo() {
  const [score, setScore] = useState(3)
  return (
    <div>
      <h1>RatingDemo. Current Score : {score}</h1>
      <Rating
        name="simple-controlled"
        value={score}
        onChange={(event, newValue) => {
          setScore(newValue)
        }}
      />
    </div>
  )
}

export default RatingDemo
```

```jsx
이 컴포넌트는 State 를 사용한다 레이팅의 값이 변하면 score 의 값이 변하도록 설정하였다

컴포넌트가 변경되면 이 State 를 업데이트하는 것 ( 함수형 업데이트를 사용했다 )

( 첫 번째 인수는 이벤트 객체이고, 두 번째 인수는 이벤트 핸들러 함수 )

배후의 로직에서는 onClick이 DOM 요소에 연결되어 있다

하지만 코드 작성 시에는 간편하게 Rating 컴포넌트에 onChange 콜백만 추가하면 된다
```

# 폼과 슬라이더 만들기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381431/notion-blog/_/The_Web_Developer_2022/REACT/_UI/Untitled_9.png)

```jsx
import TextField from '@mui/material/TextField'
import Slider from '@mui/material/Slider'
import { useState } from 'react'
function FormDemo() {
  const [name, setName] = useState()
  const [volume, setVolume] = useState(50)
  const updateName = (e) => {
    setName(e.target.value)
  }
  const volumeChange = (e, newVal) => {
    setVolume(newVal)
  }
  return (
    <div>
      <h1>Name is : {name}</h1>
      <TextField
        id="outlined-basic"
        label="Outlined"
        variant="outlined"
        placeholder="name"
        value={name}
        onChange={updateName}
      />
      <h2>Volume : {volume}</h2>
      <Slider aria-label="Volume" value={volume} onChange={volumeChange} />
    </div>
  )
}

export default FormDemo
```

```jsx
폼과 슬라이더를 만들어본다

슬라이더와 필드를 사용하게 import 를 해주고

useState를 사용하여 컴포넌트의 상태를 정의한다

볼륨을 변경하는 함수와 사용자의 이름을 업데이트하는 함수를 정의한다

( 컴포넌트가 받는 값은 공식 문서에서 어떻게 받고 사용하는지 확인할것 )

```

# SX 프로퍼티와 커스텀 스타일

```jsx
sx는 머티리얼 UI에서 스타일을 적용하는 데 사용되는 특별한 프로퍼티이다.

JSX에서 sx={{}}와 같이 사용되며, 이 안에 객체 형태로 스타일 속성들을 정의한다.

일반적인 CSS와는 약간 다르게 값을 지정할 수 있는데, 예를 들어, 단위 없이 간단한 값을 사용할 수 있다. ex) p : 3 (패딩임)

내부에서는 이 값을 픽셀 등의 단위로 변환하여 적용하므로 편리하게 사용할 수 있다.

( 컴포넌트의 위치 크기 등을 조절하는 부트스트랩의 레이아웃 기능 + css 같은 느낌이라고 보면 될거같다 )
```

## **Box 컴포넌트 소개**

```jsx
Box는 머티리얼 UI에서 주로 CSS 유틸리티에 사용되는 래퍼 컴포넌트이다.

일반적으로 다른 컴포넌트들을 감싸는 용도로 사용되며, 주로 레이아웃에서 활용된다.

예를 들어, 내비게이션 바나 앱 바에서 주로 사용되며, 커스텀 스타일을 적용할 때 흔히 볼 수 있다.
```

## **Box 컴포넌트에서의 sx 사용 예시:**

```jsx
예를 들어, <Box sx={{ width: 300, border: '1px solid red', p: 2 }}>컨텐츠</Box>와 같이 사용할 수 있다.

width는 폭을 나타내며, border는 테두리를 지정하고, p는 안쪽 여백을 나타낸다.

단위 없이 값을 직접 사용하여 간결하게 스타일을 지정할 수 있다.

다양한 스타일 속성들을 sx 프로퍼티 안에 넣어서 사용할 수 있다.

<Box sx={{ border: '1px solid red', p: 2, '&:hover': { backgroundColor: 'lightgray' } }}>컨텐츠</Box>
```

```jsx
원래 있던 <div> 를 삭제하고 <Box> 로 교체하였다
```

```jsx
  )
}

export default FormDemo
```
