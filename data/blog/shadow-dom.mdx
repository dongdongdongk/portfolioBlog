# { Shadow DOM이란? }

```jsx
Shadow DOM은 HTML의 캡슐화된 DOM 트리입니다. 이것은 일반 DOM과 분리되어 있으며,

외부의 스타일(CSS)이나 JavaScript가 Shadow DOM 내부에 영향을 주지 못하게 하는 독립적인 환경을 제공합니다.

Shadow DOM은 웹 컴포넌트(Web Components) 기술의 핵심 중 하나로, 재사용 가능한 UI 컴포넌트를 만드는 데 사용됩니다.
```

# 왜 Shadow DOM을 사용할까?

```jsx
캡슐화:

		Shadow DOM 내부의 스타일은 외부로부터 영향을 받지 않고,

		반대로 외부 스타일도 내부에 영향을 미치지 않습니다.

		예를 들어, 글로벌 CSS가 전체 페이지의 요소에 영향을 미치더라도 Shadow DOM 내부는 영향을 받지 않습니다.

재사용성:

		독립적인 컴포넌트를 만들어 다른 프로젝트에서도 쉽게 재사용할 수 있습니다.

DOM 클러터 방지:

		Shadow DOM은 일반 DOM과 분리되어 있어, HTML 구조가 깔끔해집니다.
```
