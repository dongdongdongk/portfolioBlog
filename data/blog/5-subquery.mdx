```sql
- Query(SQL)문 내에 또 다른 Query(SQL)문
- 메인Query문에서 사용할 값을 조회할 목적으로 사용
- 서브쿼리는 시작과 끝부분을 ( SubQuery문 ) 감 쌈
- 서브쿼리는 갯수는 제한이 없음
- 사용 위치
	SELECT   서브쿼리
  FROM     서브쿼리
	WHERE    서브쿼리
	GROUP BY 서브쿼리

	INSERT, UPDATE, DELETE , CREATE

**SubQuery의 결과물의 갯수에 따라 분류**

1. 단일행(Single-row) 서브쿼리
	- Subquery의 결과물이 한개인 경우
	- 비교연산자의 뒤에서 단독 사용 경우 : >, >=, <. <=, =, != ...

	-- 사원 사원번호, 성, 이름, 월급 , 평균 급여보다 많이 받는 직원들
	SELECT EMPLOYEE_ID, LAST_NAME, FIRST_NAME, SALARY
	FROM EMPLOYEES
	WHERE SALARY > 6461;

	SELECT AVG(SALARY) FROM EMPLOYEES; -- 6461

	-> Subquery
	SELECT EMPLOYEE_ID, LAST_NAME, FIRST_NAME, SALARY
	FROM EMPLOYEES
	WHERE SALARY > (SELECT AVG(SALARY) FROM EMPLOYEES);

2. 다중행(Multi-row) 서브쿼리
	- SubQuery의 결과물이 여러개인 경우
	- 결과물이 여러개 이기 때문에 비교 연산자 불가능

	- IN, NOT IN, any, all, exists,

	1) all
			- and의 의미
			WHERE column명 > ALL(값1, 값2...)    : culumn의 값이 값1보다 크고 그리고, 값2보다 크고...
			WHERE SALARY > ALL (100, 200)       : 값들 중에서 최대값보다 큰것들
			WHERE SALARY < ALL (100, 200)       : 값들 중에서 최소값보다 작은것들

	2) any
			- or 의 의미
			WHERE column명 > ANY (값1, 값2...)    : culumn의 값이 값1보다 크거나, 값2보다 크거나...
			WHERE SALARY > ANY (100, 200)       : 값들 중에서 최소값보다 큰것들
			WHERE SALARY < ANY (100, 200)       : 값들 중에서 최대값보다 작은것들

	3) Exists
			- 대용량의 데이터에서 검색시 많이 사용
			WHERE EXISTS (서브쿼리)             : 서브쿼리에서 반환하는 행이 1개라도 있으면 true
			WHERE NOT EXISTS (서브쿼리)         : 서브쿼리에서 반환하는 행이 하나라도 없어야 true
```

- 서브쿼리 실습

  1. 사번이 198인 사원이 근무하는 부서가 있는 도시가 속해 있는 나라가 있는 대륙 정보

  2. LAST_NAME이 Khoo 인 사람의 근무하는 부서명

  3. 사원번호가 199번인 사원의 매니저가 근무하는 부서가 있는 나라명 출력

  4. 사원들 중에서 월급이 가장 적은 사원이 근무하는 도시명

  5. 부서명이 IT인 부서에 근무하는 사원들의 모든 정보 출력

  6. Employees 테이블에서 LAST_NAME이 Greenberg 사원보다 급여를 더 많이 받고 있는 사원들정보 출력

  7. 부서별 최소급여를 받고 있는 사원의 정보 출력

  8. 도시이름이 'S'로시작하는 지역에 근무하는 사원의 정보 출력

  9. 성이 Austin 사원의 매니저(상사)가 근무하는 부서의 평균 급여보다 부서평균이 더 큰 부서의 이름
