Application 개발할 때 표준 Naming Rule을 적용해서 개발자와 운영자가 코딩 및 분석하는데

쉽게 접근 할 수 있도록 표준 Naming Rule을 적용 한다

### 1. Package, Class, 변수, Method

```jsx
1. 기본 Camel case를 따름
2. 한글 사용은 금함
3. Class
		- 영문 대소문자를 혼용하지만, 첫글자는 반드시 대문자로 시작
		- 반드시 명사 형식을 사용
		- 테이블명(Member)+역할명
		- MemberDAO
4. 변수명
		- 영문 대소문자를 혼용하지만, 첫글자는 반드시 소문자로 시작
		- 반드시 명사 형식을 사용
5. Method
		- 영문 대소문자를 혼용하지만, 첫글자는 반드시 소문자로 시작
		- 반드시 동사 형식을 사용
		- DAO, Service, Controller
			-- 기능별로 메서드명을 동일하게
			-- Insert, Delete, Update를 사용하는 메서드는 set으로 시작
			-- Select를 사용하는 메서드는 get으로 시작
```

### 2. JSP와 폴더명

```jsx
1. 폴더명
	 - table명과 동일한 이름
2. JSP
	 - setXXX, getXXX 메서드의 set, get를 제외하고 첫글자를 소문자로 만든이름을
	 - jsp의 파일명으로 적용
```

### 3. 컬럼명, DTO의 Setter와 Getter의 이름, Parameter이름은 동일

### 4. Mapper

```jsx
- NAMESPACE 는 사용하려는 DAO의 풀패키지명.클래스명
- Mapper의 쿼리태그의 id값은 사용하려는 DAO의 메서드명과 동일하게
```
