음악대학에서 오케스트레이션, 미디, 사운드 디자인을 전공했으며, AAA 규모 게임사를 포함한 여러 회사에서 사운드 디자이너로 커리어를 쌓았습니다. 이후 개발 교육을 받고 SI 개발 실무 경험을 거쳐 현재는 개발과 사운드 양쪽을 아우르는 작업을 이어가고 있습니다.

금융감독원 플랫폼 전환, LG U+ 본인확인 시스템 개발·운영에 참여했으며, Unity로 1인 공포게임 「OverTime」을 제작하기도 했습니다. 사운드와 개발 양쪽을 모두 이해하고 구현할 수 있는 것이 강점입니다.

Wwise, FMOD를 활용한 인터랙티브 오디오 구현부터 React, Next.js 기반 풀스택 웹, Unity·Unreal 게임 개발까지 폭넓은 실무 경험을 보유하고 있습니다.

---

**경력**

AAA 규모 인하우스 사운드 디자이너

사운드팀 리드 · 팀 매니지먼트

SI 개발 및 시스템 운영

음악 프로덕션 · 레코딩 · 편곡

인디 게임 · 광고 · 애니메이션 · 영화 · 유아 콘텐츠 등 다수 외주

---

**Tech Stack**

Game : Unreal Engine, Unity, C#, C++

Audio : Cubase, Reaper, Wwise, FMOD, iZotope RX, FabFilter

Frontend : React, Next.js, TypeScript, JavaScript

Backend : Java, Spring Framework, Node.js

Database : MySQL, Oracle, MariaDB

DevOps : Linux, Bamboo CI/CD

---

**Equipments**

DAW : Cubase, Reaper, Logic Pro X

Audio Interface : Focusrite

Master Keyboard : Nektar Impact LX88+

Processing : iZotope RX, FabFilter Pro Bundle
