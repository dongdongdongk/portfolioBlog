# { 1. **타이포그래피 (Typography) }**

## 규칙:

```jsx
폰트 크기는 계층 구조를 나타내는 중요한 요소입니다. 헤딩, 본문, 작은 텍스트 등의 크기를 일관성 있게 유지합니다.

폰트 개수는 2-3개로 제한: 하나의 폰트를 헤딩에 사용하고, 본문과 부수적인 텍스트에 다른 폰트를 사용할 수 있습니다.

**라인 간격 (Line-height)**을 적절히 조정하여 읽기 편한 가독성을 유지합니다.
```

## 예시 수치:

```jsx
헤딩(H1): 32px ~ 40px

본문 텍스트: 16px ~ 18px (가장 많이 사용되는 크기)

라인 간격: 텍스트 크기의 1.5배가 적당 (16px 폰트라면 24px 라인 간격)
```

## 팁:

```jsx
Google Fonts에서 무료 폰트를 사용하고, 폰트 선택 시 가독성 좋은 서체를 사용하세요 (ex: 'Roboto', 'Open Sans').
```

# { 2. **색상 사용 (Color Usage) }**

## 규칙:

```jsx
3~4가지 색상을 기본으로 사용 (기본 색상, 보조 색상, 포인트 색상).

텍스트와 배경의 명도 대비를 충분히 확보하여 가독성을 높입니다. (텍스트와 배경의 대비 비율이 최소 4.5:1 이상이어야 함).

색상 선택 시, 사용자에게 불편함을 주지 않도록 색맹 모드를 고려하세요.
```

## 예시:

```jsx
배경색: #f0f0f0 (밝은 회색)

텍스트 색상: #333333 (짙은 회색)

포인트 색상: #ff6600 (강한 주황색)
```

## 팁:

```jsx
Coolors나 Adobe Color와 같은 색상 팔레트 생성기를 사용해 보세요. 미리 조화로운 색상 조합을 추천해줍니다.
```

# { 3. **레이아웃 (Layout) }**

## 규칙:

```jsx
Grid 시스템을 활용해 콘텐츠를 정렬합니다. 12 컬럼 그리드가 웹 디자인에서 많이 사용됩니다.

콘텐츠 간의 **여백 (Padding, Margin)**은 일정하게 유지합니다. 특히 요소 간의 여백을 일관성 있게 설정해 페이지가 균형 잡히도록 합니다.
```

## 예시 수치:

```jsx
그리드의 너비: 1170px (많이 사용하는 고정 레이아웃 너비)

요소 간 여백: 20px ~ 30px (각 요소 간 일정한 공간을 유지)

패딩 (내부 여백): 15px ~ 20px
```

## 팁:

```jsx
Flexbox와 CSS Grid를 이용하면 그리드 시스템을 쉽게 구현할 수 있습니다. 특히 모바일 반응형 디자인에 유리합니다.
```

# { 4. **반응형 디자인 (Responsive Design) }**

## 규칙:

```jsx
모바일 퍼스트 디자인: 모바일 화면을 우선으로 디자인하고, 데스크탑 화면에 맞게 확장해 나가는 방식이 좋습니다.

미디어 쿼리를 사용해 화면 크기에 따라 레이아웃이 변경되도록 설정합니다.

이미지를 자동으로 비율에 맞게 줄여주는 CSS 속성 (ex: max-width: 100%)을 사용하여 이미지가 화면을 넘치지 않게 만듭니다.
```

```jsx
/* 모바일 화면 (최대 768px) */
@media (max-width: 768px) {
  .container {
    padding: 10px;
  }
  .column {
    width: 100%;
  }
}

/* 데스크탑 화면 */
@media (min-width: 769px) {
  .container {
    padding: 20px;
  }
  .column {
    width: 50%;
  }
}
```

# { 5. **사용자 경험 (UX) }**

## 규칙:

```jsx
간결함이 중요합니다. 불필요한 요소를 제거하고 사용자가 중요한 정보에 집중할 수 있도록 구성합니다.

버튼은 사용자가 쉽게 클릭할 수 있는 크기로 만듭니다. 일반적으로 버튼의 높이는 최소 40px 이상이어야 하며, 충분한 여백을 줘서 눌렀을 때 편하게 느껴지도록 합니다.
```

## 팁:

```jsx
Micro-interactions (작은 애니메이션 효과)로 사용자가 상호작용할 때 피드백을 줍니다. 예를 들어,

버튼을 클릭하면 색상이 살짝 변하거나 그림자가 생기는 작은 변화만으로도 클릭감을 줍니다.
```

# { 6. **이미지 및 미디어 사용 }**

## 규칙:

```jsx
고해상도 이미지를 사용하되, 용량을 최소화하여 로딩 속도를 줄입니다. 이미지 압축 도구 (ex: TinyPNG)를 사용하세요.

이미지가 너무 커지지 않도록 max-width: 100%를 사용하여 가로폭에 맞게 자동 조정되도록 설정합니다.
```

## 팁:

```jsx
Unsplash나 Pexels 같은 무료 고화질 이미지 사이트에서 이미지 리소스를 가져옵니다.

너무 복잡한 이미지도 사용하는걸 피하자
```

# { 7. **아이콘 사용 }**

## 규칙:

```jsx
복잡한 이미지를 사용하는 것보다 아이콘을 사용하는 것이 더 직관적일 때가 많습니다.

특히 FontAwesome이나 Material Icons 같은 무료 아이콘 세트를 활용하세요.
```

## 팁:

```jsx
중요한 기능에 아이콘을 사용하되, 너무 많은 아이콘을 사용하면 오히려 혼란을 줄 수 있으니 주의하세요.
```

# { 8. **애니메이션 (Animation) }**

## 규칙:

```jsx
너무 많은 애니메이션은 오히려 사용자 경험을 해치므로, 중요한 부분에만 적용합니다.

지속 시간은 일반적으로 0.3초~0.5초 정도로 설정하여 너무 빠르거나 느리지 않게 적절히 조정합니다.
```

## 팁:

```jsx
CSS 트랜지션이나 AOS (Animate on Scroll) 라이브러리를 사용해 자연스러운 애니메이션을 구현하세요.
```

# { **여백(Whitespace)을 주는 방법 }**

```jsx
여백은 웹 디자인에서 매우 중요한 요소입니다. 요소들 사이에 적절한 여백을 주면,

디자인이 깔끔해지고 가독성이 높아집니다.

여백은 요소들이 서로 충돌하지 않도록 공간을 제공하고, 시각적으로 중요한 요소를 강조하는 데 도움을 줍니다.
```

```jsx
여백 종류:

		내부 여백(Padding): 요소 안쪽에 여백을 줘서, 콘텐츠와 요소의 경계 사이에 공간을 만듭니다.

		외부 여백(Margin): 요소 바깥쪽에 여백을 줘서, 다른 요소들과의 간격을 만듭니다.

기본 규칙:

		여백은 일관되게 주는 것이 중요합니다. 이를 통해 디자인이 통일된 느낌을 줍니다.

		모바일에서는 여백을 좀 더 크게 설정하는 것이 좋습니다.

		작은 화면에서는 요소들이 서로 너무 가까워지면 혼란스러워 보일 수 있기 때문입니다.

적절한 예시 수치:

		글자와 주변 요소의 간격: 16px ~ 24px

		제목과 본문 사이의 간격: 32px

		카드 형태의 요소 간 간격: 24px ~ 40px

		버튼의 Padding: 12px ~ 16px
```

## **요소 간의 간격**

```jsx
요소들 간의 간격은 너무 좁으면 답답해 보이고, 너무 넓으면 관련성을 잃습니다.

적절한 간격을 주는 것은 가독성을 높이고 사용자의 시선을 유도하는 데 매우 중요합니다.
```

```jsx
간격을 줄 때 기본 원칙:

		관련된 요소는 더 가깝게: 제목과 본문 같은 관련된 요소는 더 가까이 배치하고, 비슷하지 않은 요소는 더 넓은 간격을 줍니다.

		균형 잡힌 간격: 간격이 일관되게 적용되면 시각적으로 균형이 잡히고 깔끔해 보입니다.

예시:

		제목과 본문: 16px ~ 32px

		카드형 콘텐츠 사이: 24px ~ 40px

		버튼과 입력창 사이: 16px ~ 24px
```

# **{ 계층형 디자인으로 사용자 경험 개선 }**

```jsx
**계층 구조(Visual Hierarchy)**는 사용자가 어떤 정보를 먼저 보고, 어디에 집중해야 할지를 안내하는 중요한 디자인 요소입니다.

시각적 계층을 통해 정보를 쉽게 전달하고, 사용자의 시선을 자연스럽게 흐르게 할 수 있습니다.
```

```jsx
계층을 만드는 방법:

		글자 크기와 두께: 중요한 제목이나 텍스트는 크고 두껍게, 덜 중요한 정보는 작고 가볍게 표시합니다.

				H1(제목): 36px

				H2(소제목): 30px

				본문: 16px ~ 18px

색상 대비: 중요한 정보는 배경색과 강하게 대비되는 색을 사용해 강조합니다.

		예를 들어, 버튼에는 주목할 만한 색상을 사용하여 사용자가 쉽게 인식하게 합니다.

		회색은 덜 중요한 요소에, 밝은 색상은 강조가 필요한 요소에 사용합니다.

여백: 중요한 정보 주위에 충분한 여백을 줘서 돋보이게 합니다. 여백이 부족하면 정보가 혼잡해 보이고, 사용자가 집중하기 어려울 수 있습니다.

아이콘과 이미지: 시각적으로 중요한 정보는 아이콘이나 이미지를 활용해 사용자가 빠르게 이해할 수 있도록 도와줍니다.
```
