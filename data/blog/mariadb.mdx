# **Step4 :  DB 생성과 사용자 생성**

---

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380948/notion-blog/_/Database/MariaDB/MariaDB_/Untitled_8.png)

```jsx
MariaDB [(none)]> use DB명;                 // 사용할 DB선택

MariaDB[(none)]> create database DB이름;    // db생성

MariaDB[(none)]> show databases;           // DB 확인

// DB권한 설정 (당장 크게 필요한건 아니다)

> grant all privileges on db이름.* to 계정명@'%' identified by '비밀번호';

> grant all privileges on db이름.* to 계정명@'localhost' identified by '비밀번호';

계정명@'%' : 해당 계정이 모든 클라이언트에서 접근 가능하다.

계정명@'localhost' : 해당 계정이 localhost(본인 pc)에서만 접근 가능하다.
```

# **Step5 :  DB 스프링 연결**

```jsx
<dependency>
  <groupId>org.mariadb.jdbc</groupId>
  <artifactId>mariadb-java-client</artifactId>
  <version>2.7.2</version>
</dependency>

// 폼에 의존성을 추가해주고
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380946/notion-blog/_/Database/MariaDB/MariaDB_/Untitled_10.png)

```jsx
application.properties: 에 정보를 추가해준다

spring.datasource.url=jdbc:mariadb://localhost:3306/your_database_name
spring.datasource.username=your_username
spring.datasource.password=your_password
spring.datasource.driver-class-name=org.mariadb.jdbc.Driver
```
