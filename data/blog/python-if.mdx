```python
Python에서는 True, False 외에도 다른 값들이 참 또는 거짓으로 평가될 수 있다.

예를 들어, 비어 있지 않은 문자열이나 리스트는 True로, 빈 문자열이나 리스트는 False로 평가
```

# **기본 구조**

```python
if 조건:
    # 조건이 참일 때 실행될 코드
else:
    # 조건이 거짓일 때 실행될 코드
```

## **예제 1: 기본적인 if 문**

```python
age = 20

if age >= 18:
    print("성인입니다.")
else:
    print("미성년자입니다.")


* 이 예제에서는 age가 18 이상일 때 “성인입니다.”를 출력하고, 그렇지 않으면 “미성년자입니다.”를 출력
```

## **예제 2: elif 사용하기**

```python
score = 75

if score >= 90:
    print("A등급입니다.")
elif score >= 80:
    print("B등급입니다.")
elif score >= 70:
    print("C등급입니다.")
else:
    print("D등급입니다.")
```

## **예제 3: 중첩된 if 문**

```python
age = 25
is_student = False

if age < 26:
    if is_student:
        print("학생 할인이 적용됩니다.")
    else:
        print("학생이 아니지만, 연령 할인이 적용됩니다.")
else:
    print("할인이 적용되지 않습니다.")
```

```python
예제에서는 age가 26 미만일 경우 학생 여부를 추가로 검사하여,

학생이면 “학생 할인이 적용됩니다.”를, 학생이 아니면 “학생이 아니지만, 연령 할인이 적용됩니다.”를 출력.

그 외의 경우에는 “할인이 적용되지 않습니다.”를 출력
```

# **파이썬의 `and`, `or`, `not` 연산자**

```python
파이썬에서 논리 연산자 and, or, not은 조건문을 결합하는 데 사용
```

## **`and` 연산자 예제**

```python
이 예제에서 x > 4 and y < 10 조건은 x가 4보다 크고 y가 10보다 작을 때 True가 됩니다. 따라서 "두 조건 모두 만족"이 출력
```

```python
x = 5
y = 8

if x > 4 and y < 10:
    print("두 조건 모두 만족")
```

## **`or` 연산자 예제**

```python
이 예제에서 a < 5 or b > 10 조건은 a가 5보다 작거나 b가 10보다 클 때 True가 됩니다. 따라서 "적어도 하나의 조건 만족"이 출력
```

```python
a = 3
b = 12

if a < 5 or b > 10:
    print("적어도 하나의 조건 만족")
```

## **`not` 연산자 예제**

```python
이 예제에서 c는 False이다. not c는 c의 반대가 되므로, True가 된다. 따라서 "c가 False이므로 not 연산자로 True가 됩니다."가 출력
```

```python
c = False

if not c:
    print("c가 False이므로 not 연산자로 True가 됩니다.")
```

## **복합 예제**

```python
x = 5
y = 8

if not(x < 4 or y > 10):
    print("x가 4보다 작지 않거나 y가 10보다 크지 않습니다.")
```
