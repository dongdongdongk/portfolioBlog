# 인라인 이벤트(Inline Event)

```jsx
HTML 요소의 속성(attribute)으로 직접 이벤트 처리기를 지정하는 방식을 의미

 이는 요소 자체에 이벤트를 처리하는 JavaScript 코드를 포함하는 방식
```

```jsx
<button onclick="myFunction()">클릭하세요</button>
```

```jsx
장점:

간단하게 사용 가능하며, 빠르게 이벤트 처리를 설정할 수 있다.

단점:

코드와 마크업이 섞이기 때문에 유지보수가 어렵다.

여러 요소에 같은 이벤트를 적용하려면 중복 코드가 발생할 수 있다.

가독성이 떨어지고, 큰 프로젝트에서는 비추천된다.
```

## 권장하는 사용법

```jsx
일반적으로는 HTML과 JavaScript 코드를 분리하여 이벤트를 처리하는 방식이 권장
```

```jsx
<!-- HTML -->
<button id="myButton">클릭하세요</button>

<!-- JavaScript -->
<script>
  document.getElementById('myButton').addEventListener('click', function() {
    myFunction();
  });

  function myFunction() {
    // 원하는 동작 수행
    alert('버튼이 클릭되었습니다.');
  }
</script>
```

```jsx
JavaScript 코드에서 addEventListener를 사용하여 이벤트 처리기를 등록

이 방식을 통해 코드의 가독성이 향상되고, 유지보수가 쉬워짐
```

# **`addEventListener`**

```jsx
이 메서드를 사용하면 HTML 요소에 이벤트 리스너(이벤트 핸들러)를 추가할 수 있다.
```

## **`addEventListener` 메서드 구문**

```jsx
element.addEventListener(event, listener, options)
```

```jsx
element: 이벤트 리스너를 추가할 HTML 요소를 가리킴

event: 리스너가 반응할 이벤트 유형을 지정합니다. 예를 들어, "click", "mouseover", "keydown" 등이 있다

listener: 이벤트가 발생했을 때 실행될 콜백 함수(이벤트 핸들러)

options (선택 사항): 추가 설정을 지정하는 객체
```

```jsx
const myButton = document.getElementById('myButton')

function handleClick() {
  alert('버튼이 클릭되었습니다!')
}

// 클릭 이벤트에 대한 이벤트 리스너 등록
myButton.addEventListener('click', handleClick)
```

```jsx
modifyBtn.addEventListener('click', function () {
  if (!confirm('수정하시겠습니까?')) {
    return
  }
  actionForm.setAttribute('action', '/board/modify')
  actionForm.method = 'post'
  actionForm.submit()
})
```

# 키보드 이벤트

```jsx
키보드 이벤트는 사용자가 키보드를 사용할 때 발생하는 이벤트를 의미한다

주요 키보드 이벤트에는 keydown, keypress, 그리고 keyup이 있다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>키보드 이벤트 예제</title>
</head>
<body>

  <input type="text" id="textInput" placeholder="여기에 키를 눌러보세요">

  <script>
    const textInput = document.getElementById('textInput');

    // 키가 눌렸을 때
    textInput.addEventListener('keydown', function(event) {
      console.log(`키가 눌렸습니다. 눌린 키: ${event.key}`);
    });

    // 키가 떼어졌을 때
    textInput.addEventListener('keyup', function(event) {
      console.log(`키가 떼어졌습니다. 떼어진 키: ${event.key}`);
    });
  </script>

</body>
</html>
```

## **`key`**와 **`code`**

```jsx
키보드 이벤트에서 key와 code는 각각 눌린 키의 문자와 해당 키의 고유한 코드를 나타낸다

key: 알파벳 키, 숫자 키 등은 해당 문자나 숫자의 값을 갖습니다.

code: 키보드의 물리적인 위치를 나타내는 코드로, 키보드의 레이아웃에 상관없이 키의 실제 위치를 기준으로 함.

		  이것은 키보드의 레이아웃이 다른 언어로 설정되어 있을 때 유용
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>키보드 이벤트 - key와 code</title>
</head>
<body>

  <input type="text" id="myInput" placeholder="여기에 키를 눌러보세요">

  <script>
    const myInput = document.getElementById('myInput');

    myInput.addEventListener('keydown', handleKeyPress);

    function handleKeyPress(event) {
      const key = event.key;
      const code = event.code;

      // 입력한 키와 코드를 출력
      alert(`눌린 키: ${key}\n키 코드: ${code}`);
    }
  </script>

</body>
</html>
```

# **`input` 이벤트**

```jsx
사용자가 <input>, <textarea>, 또는 <select>와 같은 입력 요소에 값을 입력하거나 변경할 때 발생하는 이벤트

이 이벤트는 입력 요소의 값이 변경될 때마다 즉시 발생하며, 텍스트를 입력하거나 삭제하는 경우에도 반응
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>input 이벤트 예제</title>
</head>
<body>

  <label for="myInput">텍스트 입력:</label>
  <input type="text" id="myInput">

  <p id="output">입력된 텍스트: </p>

  <script>
    const myInput = document.getElementById('myInput');
    const output = document.getElementById('output');

    myInput.addEventListener('input', function() {
      // 입력된 텍스트를 출력 요소에 표시
      output.textContent = '입력된 텍스트: ' + myInput.value;
    });
  </script>

</body>
</html>
```

# **폼 이벤트(Form Events)**

```jsx
폼 이벤트는 HTML 폼 요소와 관련된 사용자 동작에 대응하여 발생하는 이벤트를 나타낸다

주요 폼 이벤트에는 submit, reset, 그리고 change가 있다
```

```jsx
**submit 이벤트**:

이 이벤트는 사용자가 폼을 제출할 때 발생

주로 폼 데이터를 서버로 전송하기 전에 유효성 검사 등의 작업을 수행하는 데 사용

**reset 이벤트**:

이 이벤트는 사용자가 폼을 초기 상태로 되돌릴 때 사용

주로 초기화 작업이 필요한 경우에 사용

**change 이벤트**:

이 이벤트는 폼 요소의 값이 변경될 때 발생

주로 텍스트 상자, 체크박스, 라디오 버튼 등의 값이 변경될 때 사용자에게 피드백을 제공하거나 특정 동작을 수행하는 데 사용
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>폼 이벤트 예제</title>
</head>
<body>

  <form id="myForm">
    <label for="username">사용자 이름:</label>
    <input type="text" id="username" name="username">
    <br>

    <label for="email">이메일:</label>
    <input type="email" id="email" name="email">
    <br>

    <label for="subscribe">구독 여부:</label>
    <input type="checkbox" id="subscribe" name="subscribe">
    <br>

    <input type="submit" value="제출">
    <input type="reset" value="초기화">
  </form>

  <script>
    const myForm = document.getElementById('myForm');

    // 제출 이벤트
    myForm.addEventListener('submit', function(event) {
      event.preventDefault();

      const usernameValue = document.getElementById('username').value;
      const emailValue = document.getElementById('email').value;
      const subscribeChecked = document.getElementById('subscribe').checked;

      console.log('--- 제출 이벤트 발생 ---');
      console.log(`사용자 이름: ${usernameValue}`);
      console.log(`이메일: ${emailValue}`);
      console.log(`구독 여부: ${subscribeChecked ? '예' : '아니오'}`);
    });

    // 초기화 이벤트
    myForm.addEventListener('reset', function() {
      console.log('--- 초기화 이벤트 발생 ---');
    });

    // 변경 이벤트
    myForm.addEventListener('change', function() {
      console.log('--- 변경 이벤트 발생 ---');
    });
  </script>

</body>
</html>
```

## **event.preventDefault()**

```jsx
이벤트가 발생했을 때 기본 동작을 취소하는 메서드

특히 폼 이벤트에서 주로 사용되며, 주로 폼 제출 시 새로고침을 막기 위해 사용 (새로고침 하면 로그등 모든게 사라지기 떄문)
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>폼 이벤트와 PreventDefault 예제</title>
</head>
<body>

  <form id="myForm">
    <label for="username">사용자 이름:</label>
    <input type="text" id="username" name="username">
    <br>
    <input type="submit" value="제출">
  </form>

  <script>
    const myForm = document.getElementById('myForm');

    myForm.addEventListener('submit', function(event) {
      // 폼 제출을 막음
      event.preventDefault();

      // 사용자 이름 입력란의 값을 얻음
      const usernameValue = document.getElementById('username').value;

      // 입력된 사용자 이름을 콘솔에 출력
      console.log(`사용자 이름: ${usernameValue}`);

      // 여기서 서버로 데이터를 전송하거나 다른 동작을 수행할 수 있음
    });
  </script>

</body>
</html>
```

# **이벤트 버블링**

```jsx
이벤트 버블링은 HTML 문서의 요소에서 발생한 이벤트가 해당 요소의 부모 요소로 전파되는 메커니즘을 의미한다

즉, 하위 요소에서 발생한 이벤트가 상위 요소로 계속해서 전파되는 것을 말합니다. ( 상위로 이벤트 리스너가 계속 터지는거 )
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>이벤트 버블링 예제</title>
  <style>
    div, section, body {
      padding: 20px;
      border: 1px solid #ccc;
      margin: 10px;
    }
  </style>
</head>
<body>

  <body id="parent">
    <section id="middle">
      <div id="innermost">
        <button id="myButton">버튼을 클릭하세요</button>
      </div>
    </section>
  </body>

  <script>
    const parent = document.getElementById('parent');
    const middle = document.getElementById('middle');
    const innermost = document.getElementById('innermost');
    const myButton = document.getElementById('myButton');

    parent.addEventListener('click', function() {
      console.log('부모(body) 요소가 클릭되었습니다.');
    });

    middle.addEventListener('click', function() {
      console.log('중간(section) 요소가 클릭되었습니다.');
    });

    innermost.addEventListener('click', function() {
      console.log('가장 안쪽(div) 요소가 클릭되었습니다.');
    });

    myButton.addEventListener('click', function() {
      console.log('버튼이 클릭되었습니다.');
    });
  </script>

</body>
</html>
```

```jsx
버튼이 클릭되었습니다.
가장 안쪽(div) 요소가 클릭되었습니다.
중간(section) 요소가 클릭되었습니다.
부모(body) 요소가 클릭되었습니다.
```

## **stopPropagation**

```jsx
이벤트의 버블링이나 캡처 단계에서의 이벤트 전파를 중단시키는 역할을

이 메서드를 호출하면 이벤트가 더 이상 상위(부모) 또는 하위(자식) 요소로 전파되지 않는다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>stopPropagation 예제</title>
  <style>
    div, section, body {
      padding: 20px;
      border: 1px solid #ccc;
      margin: 10px;
    }
  </style>
</head>
<body>

  <body id="parent">
    <section id="middle">
      <div id="innermost">
        <button id="myButton">버튼을 클릭하세요</button>
      </div>
    </section>
  </body>

  <script>
    const parent = document.getElementById('parent');
    const middle = document.getElementById('middle');
    const innermost = document.getElementById('innermost');
    const myButton = document.getElementById('myButton');

    parent.addEventListener('click', function() {
      console.log('부모(body) 요소가 클릭되었습니다.');
    });

    middle.addEventListener('click', function(event) {
      console.log('중간(section) 요소가 클릭되었습니다.');
      event.stopPropagation(); // 이벤트 전파 중단
    });

    innermost.addEventListener('click', function() {
      console.log('가장 안쪽(div) 요소가 클릭되었습니다.');
    });

    myButton.addEventListener('click', function() {
      console.log('버튼이 클릭되었습니다.');
    });
  </script>

</body>
</html>
```

```jsx
버튼이 클릭되었습니다.
가장 안쪽(div) 요소가 클릭되었습니다.
```

# **이벤트 위임(Event Delegation)**

```jsx
이벤트 위임은 여러 하위 요소에 대한 이벤트 리스너를 추가하는 대신,

하나의 상위 요소에 이벤트 리스너를 추가하여 이벤트를 처리하는 방법

이를 통해 코드가 더 간결해지고 효율적으로 이벤트를 관리할 수 있다.
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>이벤트 위임 예제</title>
</head>
<body>

  <ul id="myList">
    <li>항목 1</li>
    <li>항목 2</li>
    <li>항목 3</li>
    <li>항목 4</li>
    <li>항목 5</li>
  </ul>

  <script>
    const myList = document.getElementById('myList');

    // 상위 요소에 클릭 이벤트 리스너 추가
    myList.addEventListener('click', function(event) {
      // 클릭된 요소가 li인지 확인
      if (event.target.tagName === 'LI') {
        // 클릭된 li 요소의 텍스트를 콘솔에 출력
        console.log('클릭된 항목:', event.target.textContent);
      }
    });
  </script>

</body>
</html>
```
