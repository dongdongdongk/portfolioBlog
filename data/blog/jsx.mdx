# JSX 규칙

## 첫번째 ( 닫기 요소를 다룰 때는 / )

```jsx
이미지 태그나 줄바꿈(br) 태그, 입력 등 자체 닫기 요소를 다룰 때는HTML와는 달리 슬래시를 이용해 명시적으로 닫아야 한다

ex) <input type="text" />

( 슬래시를 통해 닫는 태그라는 걸 파악한다 그러니 슬래시가 없으면 다른 요소의 여는 태그라고 생각하는거 )
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381420/notion-blog/_/The_Web_Developer_2022/REACT/JSX_/Untitled_4.png)

## 두 번째 ( 컴포넌트가 반드시 하나의 요소만을 반환 )

```jsx
컴포넌트는 반드시 하나의 요소만을 반환해야 한다

예를 들어 컴포넌트인 LoginForm.js. 이 컴포넌트 내부에는 두 개의 요소,

즉 패스워드 입력 필드와 텍스트 입력 필드가 있을 것이다.

JSX에서는 컴포넌트가 하나의 최상위 요소만을 반환해야 하므로, 두 개의 요소를 직접 반환하면 오류가 발생한다

해결 방법 중 하나는 **두 요소를 감싸는 부모 요소를 만들어주는 것**이다.

예를 들어, <div>로 감싸면 된다.

또 다른 방법은 괄호를 사용하여 요소를 감싸는 것이다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381421/notion-blog/_/The_Web_Developer_2022/REACT/JSX_/Untitled_5.png)

### div 로 감싸기

```jsx
export default function LoginForm() {
  return (
    <div>
      <input type="password" />
      <input type="text" />
    </div>
  )
}
```

### 괄호를 사용하기

```jsx
export default function LoginForm() {
  return (
    <>
      <input type="password" />
      <input type="text" />
    </>
  )
}
```

```jsx
두 번째 방법에서는 빈 꺾쇠 괄호(<>와 </>)를 사용하여 요소를 감싸는데,

이를 Fragment라고 한다. Fragment를 사용하면 별도의 부모 요소를 만들지 않고 여러 요소를 그룹화할 수 있다

(아래에서 조금더 자세히 설명 )
```

# 리액트 프래그먼트

```jsx
리액트 컴포넌트는 JSX에서 하나의 요소만을 반환해야 하는 규칙이 있다.

때로는 간단하게 div나 기타 래퍼 요소로 내용을 감싸는 것으로 충분할 수 있다.

그러나 이렇게 하면 DOM이 원하지 않는 방식으로 지저분해질 수 있다.

예를 들어, LoginForm을 렌더링할 때마다 JSX 규칙을 충족시키기 위한 목적으로만 사용되는 div를 사용하는 것은 깔끔하지 않을 수 있다.

이렇게 하면 불필요한 div나 래퍼 요소로 문서가 지저분해질 수 있다.

이런 경우에는 실제로 문서에 나타나지 않으면서 JSX 규칙을 충족시키는 데 사용할 수 있는 React Fragment라는 것이 있다.

React Fragment는 빈 HTML이나 JSX 태그 집합으로, 내용이 없다.
```

```jsx
return (
  <>
    {' '}
    // 리액트 프래그 먼트
    <input type="password" />
    <input type="text" />
  </>
)
```
