### 파일명: `MeleeWeapon.js`

```jsx
import Phaser from 'phaser'

class MeleeWeapon extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, weaponName) {
    super(scene, x, y, weaponName)

    scene.add.existing(this)
    scene.physics.add.existing(this)

    this.damage = 15 // 공격력 설정
    this.attackSpeed = 1000 // 공격 속도 (1초)
    this.weaponName = weaponName
    this.wielder = null // 무기를 사용하는 캐릭터

    this.activateWeapon(false) // 처음에는 보이지 않도록 설정
  }

  // 무기 휘두르기
  swing(wielder) {
    this.wielder = wielder
    this.activateWeapon(true)
    this.body.reset(wielder.x, wielder.y) // 플레이어 위치에 무기 위치 설정
  }

  // 무기의 활성화 여부 설정
  activateWeapon(isActive) {
    this.setActive(isActive)
    this.setVisible(isActive)
  }
}

export default MeleeWeapon
```

```jsx
MeleeWeapon 클래스는 Phaser.Physics.Arcade.Sprite를 확장하여 만들었습니다.

swing(wielder): 무기를 휘두를 때 실행되며, 플레이어 위치에 무기를 배치합니다.

activateWeapon(isActive): 무기의 활성화 여부를 조절하여 보이거나 안 보이도록 합니다.
```

## **최종 코드**

```jsx
import Phaser from 'phaser'

class MeleeWeapon extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, weaponName) {
    super(scene, x, y, weaponName)

    scene.add.existing(this)
    scene.physics.add.existing(this)

    this.damage = 15
    this.attackSpeed = 1000
    this.weaponAnim = weaponName + '-swing'
    this.wielder = null

    this.setOrigin(0.5, 1)
    this.setDepth(10)
    this.activateWeapon(false)

    this.on('animationcomplete', (animation) => {
      if (animation.key === this.weaponAnim) {
        this.activateWeapon(false)
        this.body.reset(0, 0)
      }
    })
  }

  preUpdate(time, delta) {
    super.preUpdate(time, delta)
    if (!this.active) {
      return
    }

    if (this.wielder.lastDirection === Phaser.Physics.Arcade.FACING_RIGHT) {
      this.setFlipX(false)
      this.body.reset(this.wielder.x + 15, this.wielder.y)
    } else {
      this.setFlipX(true)
      this.body.reset(this.wielder.x - 15, this.wielder.y)
    }
  }

  swing(wielder) {
    this.wielder = wielder
    this.activateWeapon(true)
    this.anims.play(this.weaponAnim, true)
  }

  activateWeapon(isActive) {
    this.setActive(isActive)
    this.setVisible(isActive)
  }
}

export default MeleeWeapon
```

## \* `preUpdate()`와 `super.preUpdate()`가 필요한 이유

```jsx
우리는 MeleeWeapon 클래스를 만들어 플레이어가 검을 휘두를 수 있도록 하고 싶습니다.

검은 플레이어가 움직일 때 따라다녀야 하고, 공격할 때 애니메이션이 실행되어야 합니다.
```

### 1️⃣ `preUpdate()`는 왜 필요한가?

```jsx
💡 검이 플레이어를 따라다니도록 만들기 위해서!

문제:

		검은 플레이어가 휘두를 때만 나타나야 함.

		플레이어가 왼쪽으로 이동하면 검도 왼쪽으로 가야 함.

		플레이어가 오른쪽으로 이동하면 검도 오른쪽으로 가야 함.

		검이 플레이어의 위치를 따라오도록 매 프레임마다 위치를 업데이트해야 함!
```

### ✅ **해결책:**

```jsx
Phaser는 매 프레임마다 자동으로 실행되는 함수인 preUpdate()를 제공합니다.

우리는 preUpdate()를 사용해서 플레이어의 위치에 맞게 검의 위치를 업데이트할 수 있습니다!
```

```jsx
preUpdate(time, delta) {
    super.preUpdate(time, delta) // 부모 클래스의 기본 동작 유지 (중요!)

    if (!this.active) {
        return  // 검이 비활성화되면 아무것도 하지 않음
    }

    if (this.wielder.lastDirection === Phaser.Physics.Arcade.FACING_RIGHT) {
        this.setFlipX(false)  // 오른쪽을 보고 있으면 반전하지 않음
        this.body.reset(this.wielder.x + 15, this.wielder.y) // 검을 오른쪽에 배치
    } else {
        this.setFlipX(true)  // 왼쪽을 보고 있으면 검을 반전
        this.body.reset(this.wielder.x - 15, this.wielder.y) // 검을 왼쪽에 배치
    }
}
```

```jsx
📌 이제 검이 플레이어를 따라다니면서 자연스럽게 공격할 수 있게 됨!
```

### 2️⃣ `super.preUpdate(time, delta)`는 왜 필요한가?

```jsx
💡 Phaser의 기본적인 물리 처리 & 애니메이션 기능을 유지하려면 필요!

문제:

		preUpdate()를 오버라이드(덮어쓰기)하면 부모 클래스의 **기본 동작(애니메이션, 충돌 감지 등)**이 사라짐.

		즉, super.preUpdate(time, delta)를 호출하지 않으면 검이 충돌 처리를 하지 않고, 애니메이션도 제대로 실행되지 않음.

✅ 해결책:

		Phaser의 기본 동작을 유지하면서, 우리가 원하는 기능(검의 위치 변경)을 추가하려면

		uper.preUpdate(time, delta)를 호출해야 함.
```

```jsx
Phaser에는 update()와 preUpdate() 두 가지 업데이트 메서드가 있어요.

그렇다면 왜 update()가 아니라 preUpdate()를 쓰는 걸까요? 🤔
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380482/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_12_Melee_Weapon/image_2.png)

```jsx
Phaser는 게임 루프에서 업데이트 순서를 철저히 관리합니다.

💡 순서를 정리하면 다음과 같아요:

1️⃣ preUpdate() 실행 (객체의 위치, 상태 등을 먼저 업데이트!)
2️⃣ Phaser의 기본 업데이트 실행 (물리 엔진, 애니메이션, 충돌 감지 등)
3️⃣ update() 실행 (플레이어 입력 처리, 게임 로직 등)

✅ 검이 플레이어를 따라다녀야 해요!
✅ 하지만 충돌 감지보다 늦게 움직이면 버그가 생길 수 있어요!
```


## 문제 발생: `collider` 방식의 한계

```jsx
위의 코드대로 실행해 보면, 근접 공격이 제대로 감지되지 않는 문제가 발생합니다.

문제는 무기의 충돌 범위가 적의 충돌 범위 안에 있으면 충돌이 감지되지 않는다는 점입니다.

💡 해결책: collider 대신 overlap을 사용하여 "충돌"이 아니라 "겹침"을 감지하도록 수정합니다.
```

## `overlap` 방식으로 변경

### `addOverlap()` 함수 추가

```jsx
collidable.js
```

```jsx
export default {
  addColliders(otherGameObject, callback) {
    this.scene.physics.add.collider(this, otherGameObject, callback, null, this)
    return this
  },

  addOverlap(otherGameObject, callback) {
    // addOverlap() 함수 추가 겹침 overlap 두개가 겹쳐질 때 callback 함수 실행
    this.scene.physics.add.overlap(this, otherGameObject, callback, null, this)
    return this
  },

  bodyPositionDifferenceX: 0,
  prevRay: null,
  prevHasHit: null,

  raycast(body, layer, { raylength = 30, precision = 0, steepnes = 1 }) {
    const { x, y, width, halfHeight } = body
    // console.log("현재 감지 중인 레이어:", layer);

    this.bodyPositionDifferenceX += body.x - body.prev.x

    if (Math.abs(this.bodyPositionDifferenceX) <= precision && this.prevHasHit !== null) {
      return {
        ray: this.prevRay, // 이전 레이 값 그대로 반환
        hasHit: this.prevHasHit, // 이전 충돌 결과 그대로 반환
      }
    }

    const line = new Phaser.Geom.Line()
    let hasHit = false

    switch (body.facing) {
      case Phaser.Physics.Arcade.FACING_RIGHT: {
        line.x1 = x + width
        line.y1 = y + halfHeight
        line.x2 = line.x1 + raylength * steepnes
        line.y2 = line.y1 + raylength
        break
      }
      case Phaser.Physics.Arcade.FACING_LEFT: {
        line.x1 = x
        line.y1 = y + halfHeight
        line.x2 = line.x1 - raylength * steepnes
        line.y2 = line.y1 + raylength
        break
      }
    }

    const hits = layer.getTilesWithinShape(line)

    // console.log("감지된 타일:", hits);
    // console.log("타일 인덱스 값:", hits.map(hit => hit.index));
    if (hits.length > 0) {
      hasHit = this.prevHasHit = hits.some((hit) => hit.index !== -1)
      this.prevHasHit = null
    }

    this.prevRay = line
    this.bodyPositionDifferenceX = 0

    // console.log("레이케스트")
    return { ray: line, hasHit }
  },
}
```

## 3. 공격 속도 제한 로직 추가

```jsx
keydown-E 이벤트 핸들러 내부에서 이전 공격 시간 + 공격 속도(예: 1000ms) 가 현재 시간보다 크면 공격하지 않도록 합니다.
```

```jsx
this.scene.input.keyboard.on('keydown-E', () => {
  // 현재 시간이 마지막 공격 시간 + 공격 속도보다 작으면 공격 불가
  if (
    this.timeFromLastSwing &&
    this.timeFromLastSwing + this.meleeWeapon.attackSpeed > getTimestamp()
  ) {
    return // 공격 쿨다운 중이면 함수 종료
  }

  console.log('E key was pressed')
  this.play('throw', true)
  this.meleeWeapon.swing(this)

  // 현재 공격한 시간을 기록
  this.timeFromLastSwing = getTimestamp()
})
```

```jsx
}
```

## 동작 방식


```jsx
createEnemies(spawnLayer, platformsColliders) {
    // 적을 관리하는 그룹 객체 생성 (Enemies는 Phaser.Group을 확장한 클래스)
    const enemies = new Enemies(this);

    // enemies 그룹에서 적의 종류(Birdman, Snaky 등)를 가져옴
    const enemyTypes = enemies.getTypes(); // ENEMY_TYPES()에서 정의된 적 목록을 가져옴

    // 스폰 포인트 정보를 반복하여 각 위치에 적을 생성
    spawnLayer.objects.forEach((spawnPoint) => {
        /*
         * spawnPoint.type에는 맵에서 설정한 적의 타입이 들어 있음
         * 예를 들어, spawnPoint.type이 "Birdman"이면 enemyTypes["Birdman"]을 가져옴
         * 따라서 아래 코드는 적을 적절한 위치(x, y)에서 생성하는 역할을 함
         */
        const enemy = new enemyTypes[spawnPoint.type](this, spawnPoint.x, spawnPoint.y);

        // 적이 플랫폼과 충돌할 수 있도록 충돌 감지 설정
        enemy.setPlatformColliders(platformsColliders);

        // 생성된 적을 enemies 그룹에 추가하여 한 번에 관리할 수 있도록 함
        enemies.add(enemy);
    });

    // 생성된 모든 적을 포함하는 enemies 그룹을 반환
    return enemies;
}

```
