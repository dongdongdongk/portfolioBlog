# { Vue 앱 인스턴스 생성 및 연결하기 }

## Html 파일 작성

```jsx
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Vue Basics</title>
  <link
    href="https://fonts.googleapis.com/css2?family=Jost:wght@400;700&display=swap"
    rel="stylesheet"
  />
  <link rel="stylesheet" href="styles.css" />
  <script src="https://unpkg.com/vue@3/dist/vue.global.js" defer></script>
  <script src="app.js" defer></script>
</head>
<body>
  <header>
    <h1>Vue Course Goals</h1>
  </header>
  <section id="user-goal">
    <h2>My Course Goal</h2>
    <p></p>
  </section>
</body>
</html>
```

## JavaScript 파일 (`app.js`)

```jsx
Vue 애플리케이션 로직을 작성

Vue.createApp()을 사용하여 새로운 Vue 애플리케이션을 생성하고,

data() 메서드를 통해 데이터를 정의한 후, app.mount()를 사용하여 Vue 애플리케이션을 HTML 요소에 연결한다.
```

```jsx
const app = Vue.createApp({
  data() {
    return {
      courseGoal: '뷰를 마스터 하자!', // 애플리케이션의 데이터
    }
  },
})

app.mount('#user-goal') // Vue 애플리케이션을 특정 DOM 요소에 마운트
```

## 단계별 설명

### 1. Vue 애플리케이션 생성

```jsx
const app = Vue.createApp({
  data() {
    return {
      courseGoal: '뷰를 마스터 하자!',
    }
  },
})
```

```jsx
Vue.createApp():

새로운 Vue 애플리케이션을 생성한다.

data():

Vue 애플리케이션에서 사용할 데이터를 정의하는 메서드이다.

이 메서드는 객체를 반환하며, 반환된 객체의 속성들이 Vue 인스턴스의 반응형 데이터로 사용된다.
```

### 2. Vue 애플리케이션 마운트

```jsx
app.mount('#user-goal')
```

```jsx
app.mount():

Vue 애플리케이션을 특정 DOM 요소에 마운트한다. 여기서는 id가 user-goal인 요소에 마운트한다.
```

### 3. HTML 요소와 Vue 데이터 연결

```jsx
<section id="user-goal">
  <h2>My Course Goal</h2>
  <p>{{ courseGoal }}</p> <!-- Vue 데이터 표시 -->
</section>
```

```jsx
HTML 파일에서 Vue 애플리케이션의 데이터를 표시하도록 설정한다.

p 태그 안에 Vue의 템플릿 문법을 사용하여 데이터를 표시한다.

{{ courseGoal }}:

 Vue의 데이터 바인딩 문법을 사용하여 courseGoal 데이터를 HTML에 표시한다.
```

## Vue의 핵심 구문

### 1. 데이터 바인딩 (`{{ }}`)

```jsx
Vue의 데이터 바인딩을 사용하여 JavaScript 데이터를 HTML에 표시한다.

<p>{{ courseGoal }}</p>
```

### 2. 디렉티브 (`v-` 접두어)

```jsx
Vue 디렉티브를 사용하여 HTML 속성을 확장한다. 예를 들어 v-bind는 속성 바인딩, v-on은 이벤트 바인딩을 처리한다.
```

### 3. 메서드와 이벤트 처리

```jsx
Vue 애플리케이션에서 메서드를 정의하고, 이를 이벤트와 연결할 수 있다.

v-on:click="changeGoal": 버튼 클릭 이벤트와 changeGoal 메서드를 연결한다.
```

```jsx
const app = Vue.createApp({
  data() {
    return {
      courseGoal: '뷰를 마스터 하자!',
    }
  },
  methods: {
    changeGoal() {
      this.courseGoal = '새로운 목표 설정!'
    },
  },
})

app.mount('#user-goal')
```

```jsx
<button v-on:click="changeGoal">Change Goal</button>
```

```jsx
이는 전역 Vue 인스턴스 객체를 생성하고 data와 methods를 포함한 모든 데이터를 관리한다
```

## v-on

```jsx
v-on 디렉티브는 Vue.js에서 이벤트 리스너를 HTML 요소에 추가하는 데 사용된다.

JavaScript의 addEventListener와 같은 역할을 하지만, Vue를 사용하면 더 간편하게 구현할 수 있다.

<!-- v-on 디렉티브 사용 -->
<button v-on:click="methodName">Click me</button>

<!-- @ 기호 사용 -->
<button @click="methodName">Click me</button>

v-on 디렉티브를 사용하여 특정 이벤트가 발생할 때 실행할 메서드를 지정할 수 있다. 메서드는 Vue 인스턴스 내에 정의된다

* v-on 디렉티브는 @ 기호로 축약해서 사용할 수도 있다.
```

```jsx
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vue Basics</title>
    <link
      href="https://fonts.googleapis.com/css2?family=Jost:wght@400;700&display=swap"
      rel="stylesheet"
    />
    <link rel="stylesheet" href="styles.css" />
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script src="app.js" defer></script>
  </head>
  <body>
    <header>
      <h1>Vue Events</h1>
    </header>
    <section id="events">
      <h2>Events in Action</h2>
      <button v-on:click="counter++">Add</button>
      <button v-on:click="counter--">Reduce</button>
      <p>Result: {{ counter }}</p>
    </section>
  </body>
</html>

```

```jsx
v-on:click 을 사용해서 + - 를 하도록 한다

v-on:click 디렉티브를 사용하여 Add 버튼에 클릭 이벤트 리스너를 추가

counter++ 같은 인라인 메서드로 (++) counter 이라는 변수에 값이 변하게 가능하다
```

## Vue의 반응성

```jsx
Vue의 핵심 기능은 데이터가 변경될 때 자동으로 DOM을 업데이트하는 반응성이다.

counter 변수가 변경될 때마다, Vue는 이를 감지하고 DOM을 자동으로 업데이트하여 사용자에게 변경된 값을 보여준다.
```

```jsx
<input type="text" v-on:input="setName"> 와 출력 부분 <p>{{ name }}</p> 를 추가해준다

텍스트 상자의 입력 이벤트를 처리하기 위해 v-on 디렉티브를 사용하여 input 이벤트를 바인딩한다.

이 이벤트를 setName 메서드와 연결하여 사용자의 입력값으로 name 데이터를 업데이트 한다
```

```jsx
const app = Vue.createApp({
  data() {
    return {
      counter: 0,
      name: '',
    }
  },
  methods: {
    setName(event) {
      this.name = event.target.value
    },
    add(num) {
      this.counter = this.counter + num
    },
    reduce(num) {
      this.counter = this.counter - num
    },
  },
})

app.mount('#events')
```

```jsx
data 객체에 name 속성을 생성해준다

이제 setName 메서드를 Vue 인스턴스의 methods 섹션에 정의한다. 이 메서드는 이벤트 매개변수를 받아 입력 이벤트에 대한 정보를 처리 한다

		setName(event) {
      this.name = event.target.value;
    },


입력 이벤트가 발생할 때마다(즉, 사용자가 텍스트 상자에 무언가 입력할 때마다) setName 메서드가 호출된다.

이 메서드는 이벤트 객체를 받아 event.target을 통해 이벤트를 발생시킨 입력 요소에 접근한다.

event.target.value를 사용하여 입력 필드의 현재 값을 가져와 name 속성에 할당 한다
```

## 고급 사용법: 이벤트 객체 접근

```jsx
더 고급 시나리오에서는 이벤트 객체에 직접 접근하면서 추가 인수를 메서드에 전달해야 할 수 있다.

Vue는 $event라는 특별 변수를 제공하여 이러한 경우에 이벤트 객체를 참조할 수 있게 한다.
```

```jsx
예를 들어, 정적 인수를 이벤트 객체와 함께 전달하려면

<input type="text" v-on:input="setName('someArgument', $event)">

그리고 setName 메서드를 여러 인수를 처리하도록 업데이트한다
```

```jsx
methods: {
  setName(arg, event) {
    console.log(arg);  // 'someArgument'
    this.name = event.target.value;
  }
}
```

## 왜 setName 은 메서드 인데 () 가 없는가?

```jsx
<input type="text" v-on:input="setName">

setName 메서드가 호출될 때 ()가 없는 이유는 Vue.js의 이벤트 핸들러에서 메서드를 참조하기 위해서이다.

이벤트 핸들러에서 메서드를 참조할 때 ()를 사용하지 않으면, 해당 메서드가 이벤트가 발생할 때 실행된다.

()를 사용하면 메서드가 즉시 호출되기 때문에 이벤트가 발생할 때마다 호출되는 것이 아니라, Vue 인스턴스가 생성될 때 한 번 호출되고 끝난다.
```

# { 이벤트 수정자 알아보기 }

```jsx
Vue의 이벤트 수정자는 이벤트 처리의 동작을 간단하고 효율적으로 수정할 수 있는 기능을 제공한다.

기본 동작을 방지하고, 이벤트 전파를 멈추며, 이벤트가 발생하는 조건을 구체적으로 지정할 수 있다.

Vue의 이벤트 수정자를 사용하면 이벤트 처리가 간결하고 가독성이 좋아지며, 수동으로 이벤트 객체를 조작할 필요가 줄어든다.
```

```jsx
<!DOCTYPE html>
<html lang="en">
  <head>

    <script src="app.js" defer></script>
  </head>

    <header>

    </header>
    <section id="events">
      <h2>Events in Action</h2>

```

```jsx
const app = Vue.createApp({
  data() {
    return {
      counter: 0,
      name: '',
    }
  },
  methods: {
    submitForm(event) {
      event.preventDefault()
      alert('Submitted')
    },
    setName(event) {
      this.name = event.target.value
    },
    add(num) {
      this.counter = this.counter + num
    },
    reduce(num) {
      this.counter = this.counter - num
    },
  },
})

app.mount('#events')
```

```jsx
submit 을 하고 나면 새로고침으로 인해서 기존 데이터가 전부 날아가게 되기 때문에

event.preventDefault() 로 기본 폼 제출 방지를 해주고

			<form v-on:submit="submitForm">
        <input type="text">
        <button>Sign UP</button>
      </form>

폼에 v-on:submit 을 이용해서 제출하게 해줬다
```

## 두번째 방법 ( 이벤트 수정자 사용 )

```java
      <form v-on:submit.prevent="submitForm">
        <input type="text">
        <button>Sign UP</button>
      </form>
```

```java
.prevent는 기본 폼 제출 동작을 방지하는 이벤트 수정자이다.

이를 사용하면 event.preventDefault() 같은 코드 추가 없이 폼 제출을 막을 수 있다
```

## 예제: 수정자를 사용한 마우스 이벤트 처리

```java
  		<h2>Events in Action</h2>

```

```java
.right .left 를 사용하여 reduce(10) 메서드는 왼쪽 클릭에만 반응하도록 한다.
```

```jsx
<input type="text" v-on:input="setName" v-on:keyup.enter="confirmInput"/>

.enter는 Enter 키를 눌렀을 때만 confirmInput 메서드를 트리거하는 이벤트 수정자 이다
```

## 주요 이벤트 수정자 요약

```jsx
.prevent: 이벤트의 기본 동작을 방지합니다.

.stop: 이벤트가 DOM 트리 상위로 전파되는 것을 멈춥니다.

.capture: 이벤트 리스너를 캡처 단계에서 추가합니다.

.self: 이벤트 대상이 자신일 때만 이벤트를 트리거합니다.

.once: 이벤트가 최대 한 번만 트리거되도록 보장합니다.

마우스 버튼 수정자: .left, .right, .middle 등 특정 마우스 버튼에 반응하도록 합니다.

키보드 키 수정자: .enter, .ctrl, .shift, .alt, .meta 등 특정 키에 반응하도록 합니다.
```

```jsx
만약 처음 데이터를 받아오고 그 값을 계속 유지시키고 싶다면 ( 값이 변경되더라도 )

      <p v-once>Starting Counter: {{ counter }}</p>
      <p>Result: {{ counter }}</p>

위와 같이 v-once 로 값을 바꾼다면 초기 값을 받아오고 그 뒤 값이 바인딩 되어 변하더라도 변경되지 않는다
```
