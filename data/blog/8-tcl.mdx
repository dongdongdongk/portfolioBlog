```sql
TCL (Transaction Control Language)

1. Transaction
	- 데이터 처리의 한 단위
	- 여러개의 SQL문을 하나의 논리적인 작업 단위로 처리하는것
	- ALL OR NOTHING 개념

2. Transaction의 특징(ACID)
	1) 원자성 (Atomicity)
	- 모두 성공적으로 실행 하던지 전혀 실행되지 않은 상태로 남이 있던지

	2) 일관성 (Consistency)
	- 실행하기전 DB의 내용이 정상적이라면 실행 후에도 DB의 내용이 정상적이어야 함

	3) 고립성 (Isolation)
	- Transaction은 실행 중 다른 Transaction의 영향을 받아서는 안된다

	4) 지속성 (Durability)
	- Traction이 성공하면 DB의 내용은 영구적으로 저장

3. SQL문
	1) COMMIT
		- 저장하지 않은 정보를 저장하고 현재 Transaction을 종료

	2) ROLLBACK
		- 저장하지 않은 정보를 취소하고 현재 Transaction을 종료
		- 이전 COMMIT한 지점 까지 ROLLBACK

- JAVA에서는 AUTO COMMIT
- 한 TRANSACTION 단위 내에 INSERT, UPDATE, DELETE 두개 이상 존재 할 때 적용
```
