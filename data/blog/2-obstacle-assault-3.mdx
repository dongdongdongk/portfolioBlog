# { if 문으로 플랫폼 왕복 운동 만들기 }

## 목표

```
플랫폼 → → → (최대 거리) ← ← ← (왕복!)
```

---

## 비교 연산자

| 연산자 | 의미        | 예시              |
| ------ | ----------- | ----------------- |
| `==`   | 같음        | `5 == 10` → false |
| `!=`   | 같지 않음   | `5 != 10` → true  |
| `>`    | 큼          | `4 > 2` → true    |
| `<`    | 작음        | `4 < 2` → false   |
| `>=`   | 크거나 같음 | `10 >= 10` → true |
| `<=`   | 작거나 같음 | `3 <= 5` → true   |

---

## if 문 기본

```cpp
if (조건) {
    // true일 때 실행
} else {
    // false일 때 실행
}
```

## 구현

### 헤더 파일

```cpp
UPROPERTY(EditAnywhere)
float MoveDistance = 100.0f;  // 최대 이동 거리

UPROPERTY(VisibleAnywhere)
float DistanceMoved = 0.0f;  // 현재 이동 거리

FVector StartLocation;
```

### CPP 파일

```cpp
void AMovingPlatform::BeginPlay() {
    Super::BeginPlay();
    StartLocation = GetActorLocation();  // 시작점 저장
}

void AMovingPlatform::MovePlatform(float DeltaTime) {
    // 이동
    FVector CurrentLocation = GetActorLocation();
    CurrentLocation += PlatformVelocity * DeltaTime;
    SetActorLocation(CurrentLocation);

    // 거리 계산
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);

    // 왕복 체크
    if (DistanceMoved >= MoveDistance) {
        PlatformVelocity = -PlatformVelocity;  // 방향 반전
        StartLocation = CurrentLocation;        // 시작점 재설정
    }
}
```

StartLocation = CurrentLocation;

```

2. Velocity 반전 + StartLocation = (100, 0, 0)
   → 100cm 돌아옴 → CurrentLocation = (0, 0, 0)
   → DistanceMoved >= 100 ✅

3. Velocity 반전 + StartLocation = (0, 0, 0)
   → 반복...
```

# { 언리얼 엔진 - 플랫폼 이동 오버슈트 문제 해결 }

## 🎯 문제 상황

### 발생한 문제

- 플랫폼이 목표 지점을 **0.01cm씩 초과**하여 이동
- 작은 차이지만 시간이 지나면 **누적되어 경로가 왜곡**됨
- 잘못된 위치를 새로운 시작점으로 사용하여 오차가 계속 증가

### 문제의 원인

```cpp
// ❌ 기존 코드 (문제 있음)
if (DistanceMoved >= MoveDistance)
{
    StartLocation = GetActorLocation();  // 오버슈트된 위치를 사용
    PlatformVelocity = -PlatformVelocity;
}
```

---

## ✅ 해결 방법

### 1단계: 이동 방향 구하기

**정규화(Normalized) 벡터란?**

- 방향은 같지만 **길이가 1인 벡터**
- 속도의 크기는 무시하고 **방향만** 추출

```cpp
FVector MoveDirection = PlatformVelocity.GetSafeNormal();
```

### 2단계: 정확한 도착 지점 계산

**공식: 시작점 + (방향 × 거리)**

```cpp
FVector NewStartLocation = StartLocation + MoveDirection * MoveDistance;
```

**계산 과정:**

- `StartLocation`: 원래 출발점
- `MoveDirection`: 이동 방향 (정규화된 벡터)
- `MoveDistance`: 정확히 이동해야 할 거리
- 결과: 오버슈트 없는 정확한 도착점

### 3단계: 위치 보정 및 업데이트

```cpp
SetActorLocation(NewStartLocation);    // 정확한 위치로 보정
StartLocation = NewStartLocation;       // 새 시작점 저장
PlatformVelocity = -PlatformVelocity;  // 방향 반전
```

---

## 📝 최종 코드 분석

```cpp
void AMovingPlatform::MovePlatform(float DeltaTime)
{
    // 1. 현재 위치 업데이트
    FVector CurrentLocation = GetActorLocation();
    CurrentLocation = CurrentLocation + (PlatformVelocity * DeltaTime);
    SetActorLocation(CurrentLocation);

    // 2. 이동 거리 측정
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);

    // 3. 목표 거리 도달 시 방향 전환
    if (DistanceMoved >= MoveDistance)
    {
        // ✅ 정확한 방향 계산
        FVector MoveDirection = PlatformVelocity.GetSafeNormal();

        // ✅ 정확한 도착점 계산
        FVector NewStartLocation = StartLocation + MoveDirection * MoveDistance;

        // ✅ 위치 보정
        SetActorLocation(NewStartLocation);

        // ✅ 새 시작점 저장
        StartLocation = NewStartLocation;

        // ✅ 방향 반전 (마지막에 수행)
        PlatformVelocity = -PlatformVelocity;
    }
}
```

## 🔍 핵심 개념

### 점 연산자 (`.`) vs 범위 해상도 연산자 (`::`)

| 연산자 | 사용 대상                     | 예시                               |
| ------ | ----------------------------- | ---------------------------------- |
| `::`   | **클래스 함수** (정적 함수)   | `FVector::Dist(A, B)`              |
| `.`    | **인스턴스 함수** (멤버 함수) | `PlatformVelocity.GetSafeNormal()` |

**예시:**

```cpp
// 클래스 함수: 두 점 사이의 거리 계산
float Distance = FVector::Dist(PointA, PointB);

// 인스턴스 함수: 특정 벡터의 정규화
FVector Direction = MyVector.GetSafeNormal();
```

## 📊 수정 전/후 비교

### Before (수정 전)

```
실제 이동: 100.01cm → 오버슈트 0.01cm
다음 시작점: 100.01cm (잘못된 위치)
반복 후: 100.02cm, 100.03cm... (누적 오차)
```

### After (수정 후)

```
실제 이동: 100.01cm → 감지
정확한 위치로 보정: 100.00cm
다음 시작점: 100.00cm (정확한 위치)
반복 후: 항상 100.00cm (오차 없음)
```

## 💡 핵심 포인트

1. **정규화 벡터** - 방향만 추출하여 정확한 계산
2. **수학적 보정** - 오버슈트를 즉시 수정
3. **순서가 중요** - 위치 보정 → 시작점 저장 → 방향 반전
4. **방탄 코드** - 오차 누적 없이 영구적으로 정확한 이동

## 🎓 초보자 팁

- 벡터 수학을 완전히 이해하지 못해도 괜찮습니다
- 중요한 것: **정확한 도착점을 계산**하여 오차를 제거한다는 개념
- 이 패턴은 게임 개발에서 자주 사용되는 **위치 보정 기법**입니다

```csharp
void AMovingPlatform::MovePlatform(float DeltaTime)
{
    // 예시 값들
    FVector StartLocation = FVector(0.0f, 0.0f, 0.0f);
    FVector PlatformVelocity = FVector(300.0f, 400.0f, 0.0f);
    float MoveDistance = 1000.0f;  // 목표 이동 거리

    // 현재 위치 (오버슈트 발생)
    FVector CurrentLocation = FVector(601.0f, 801.0f, 0.0f);

    // 실제 이동한 거리
    DistanceMoved = FVector::Dist(StartLocation, CurrentLocation);
    // √(601² + 801²) = 1001.0f (1cm 오버슈트!)

    if (DistanceMoved >= MoveDistance)
    {
        // 1️⃣ 이동 방향 계산
        FVector MoveDirection = PlatformVelocity.GetSafeNormal();
        // 결과: (0.6f, 0.8f, 0.0f)

        // 2️⃣ 정확한 도착점 계산
        FVector NewStartLocation = StartLocation + MoveDirection * MoveDistance;

        // 계산 과정:
        // MoveDirection * MoveDistance
        // = (0.6f, 0.8f, 0.0f) × 1000.0f
        // = (600.0f, 800.0f, 0.0f)

        // StartLocation + 위의 결과
        // = (0.0f, 0.0f, 0.0f) + (600.0f, 800.0f, 0.0f)
        // = (600.0f, 800.0f, 0.0f) ✅ 정확한 위치!

        // 3️⃣ 위치 보정
        SetActorLocation(NewStartLocation);
        // (601, 801, 0) → (600, 800, 0) 으로 보정

        // 4️⃣ 새 시작점 저장
        StartLocation = NewStartLocation;
        // 다음 왕복의 시작점: (600, 800, 0)

        // 5️⃣ 방향 반전
        PlatformVelocity = -PlatformVelocity;
        // (300, 400, 0) → (-300, -400, 0)
    }
}
```

# { C++ 함수 반환값 (Return Values) 정리 }

## 기본 개념

모든 C++ 함수는 **하나의 값을 반환**할 수 있습니다. 반환 타입은 함수 이름 앞에 명시합니다.

```cpp
int MyFunction()  // int를 반환
{
    return 10;  // return 키워드로 값 반환
}
```

## 반환 타입의 종류

- **기본 타입**: `int`, `float`, `bool` 등
- **void**: 아무것도 반환하지 않음 (return 불필요)
- **구조체/클래스**: `FVector`, `FString` 등

```cpp
void NoReturn()        // 반환값 없음
{
    // return 생략 가능
}

float GetNumber()      // float 반환
{
    return 3.14f;      // 반드시 return 필요
}
```

## 반환값 사용하기

```cpp
// 1. 변수에 저장
int result = MyFunction();

// 2. 표현식에서 직접 사용
int value = MyFunction() * 2;

// 3. 함수 인자로 전달
UE_LOG(LogTemp, Warning, TEXT("%d"), MyFunction());
```

## 중요한 규칙

⚠️ **return 실행 시 함수 즉시 종료** - return 이후의 코드는 실행되지 않음

```cpp
int Test()
{
    return 40;
    UE_LOG(...);  // ❌ 실행되지 않음!
}
```

## 실전 예제 (MovingPlatform.cpp)

```cpp
// GetDistanceMoved 함수 - 이동 거리 계산하여 반환
float AMovingPlatform::GetDistanceMoved()
{
    return FVector::Dist(StartLocation, GetActorLocation());
}

// 반환값을 변수에 저장하여 사용
void AMovingPlatform::MovePlatform(float DeltaTime)
{
    DistanceMoved = GetDistanceMoved();  // 반환값 저장

    if (DistanceMoved >= MoveDistance)
    {
        // 방향 전환 로직
    }
    else
    {
        // 플랫폼 이동
    }
}
```

## 핵심 요약

1. 함수 이름 앞에 **반환 타입 지정** (예: `float GetDistance()`)
2. 함수 내부에서 **`return` 키워드로 값 반환**
3. `void`가 아닌 경우 **반드시 return 필요**
4. return 실행 시 **함수 즉시 종료**
5. 반환값은 변수 저장, 표현식 사용, 함수 인자 등 **어디서든 사용 가능**

# { C++ 플랫폼 회전 (Rotation) 정리 }

## 기본 개념

언리얼 엔진에서 **`AddActorLocalRotation()`** 함수를 사용하여 액터를 회전시킬 수 있습니다.

```cpp
void AMovingPlatform::RotatePlatform(float DeltaTime)
{
    FRotator RotationToAdd = RotationVelocity * DeltaTime;
    AddActorLocalRotation(RotationToAdd);
}
```

## FRotator 구조체

**FRotator**는 회전을 표현하는 구조체로, FVector와 유사하게 3개의 float 값을 가집니다.

```cpp
FRotator(Pitch, Yaw, Roll)
// Pitch (Y축): 위/아래 회전
// Yaw (Z축): 좌/우 회전
// Roll (X축): 좌우 기울기
```

### 헤더 파일에서 회전 속도 변수 선언

```cpp
UPROPERTY(EditAnywhere)
FRotator RotationVelocity;  // 에디터에서 편집 가능
```

## 프레임 독립성 (Frame Independence)

⚠️ **매 프레임마다 실행되는 연산은 DeltaTime을 곱해야 합니다**

```cpp
// ❌ 잘못된 방법 - 프레임 속도에 따라 회전 속도가 달라짐
AddActorLocalRotation(RotationVelocity);

// ✅ 올바른 방법 - 프레임 속도와 무관하게 일정한 속도
FRotator RotationToAdd = RotationVelocity * DeltaTime;
AddActorLocalRotation(RotationToAdd);
```

### DeltaTime을 사용하는 이유

- 고성능 PC (60fps): DeltaTime ≈ 0.016초
- 저성능 PC (30fps): DeltaTime ≈ 0.033초
- DeltaTime을 곱하면 **초당 회전량이 동일**하게 유지됨

## 회전 단위

- **도(Degree) 기준**: 90 = 초당 90도 회전
- **예시**: Z축 90 → 초당 90도 수평 회전 (파란 축)

```cpp
// 헤더 파일 선언
UPROPERTY(EditAnywhere)
FRotator RotationVelocity;

// 에디터에서 설정
RotationVelocity = (0, 0, 90)  // Z축 기준 초당 90도 회전
```

1. **콘텐츠 브라우저**에서 우클릭 → Blueprint Class

## 핵심 요약

1. **FRotator** 구조체로 회전 표현 (3개의 축)
2. **AddActorLocalRotation()** 함수로 회전 적용

6. Tick()에서 매 프레임 호출하여 부드러운 회전 구현

## 📚 핵심 개념 정리

### Component 계층구조

```
DefaultSceneRoot (루트)
└─ StaticMeshComponent (자식)
   └─ Mesh Asset
```

**루트의 위치** = 액터의 기준점 (피벗)

### Transform 3요소

- **Location**: 위치 (X, Y, Z)
- **Rotation**: 회전 (Roll, Pitch, Yaw)
- **Scale**: 크기 (X, Y, Z 배율)

### 블루프린트 vs 인스턴스

- **블루프린트 수정**: 모든 인스턴스에 영향
- **인스턴스 수정**: 해당 액터만 영향

💡 **실무 활용**: 블루프린트는 템플릿, 인스턴스는 개별 커스터마이징

## ⚙️ 주요 설정 항목

### 1. Walkable Floor Angle (보행 가능한 바닥 각도)

**용도**: 캐릭터가 걸을 수 있는 경사면의 최대 각도

```
기본값: 약 45도
권장값: 65도 (강 경사면에서 탈출 가능)
```

**실전 활용**:

- 강/계곡에 빠졌을 때 탈출 가능
- 가파른 경사로 설계 시 필수

---

### 2. Max Walk Speed (최대 걷기 속도)

**실제로는 달리기 속도를 제어**

```
기본값: 500
권장값: 600
테스트값: 2000 (매우 빠름, 다른 게임 스타일)
```

**영향**:

- 낮을수록: 신중한 플랫포머 게임
- 높을수록: 빠른 액션 게임

---

### 3. Jump Z Velocity (점프 속도)

**점프 높이를 결정**

```
기본값: 420
권장값: 500-600
테스트값: 2000 (달까지 점프)
```

⚠️ **주의**:

- 너무 높으면 공중 제어 어려움
- 레벨 디자인과 밀접한 관련

---

### 4. Gravity Scale (중력 스케일)

**떨어지는 속도 조절**

```
기본값: 1.0 (너무 떠 있는 느낌)
권장값: 1.3 (더 현실적인 낙하)
```

**효과**:

- 1.0 미만: 달 중력 느낌
- 1.0: 기본 (약간 붕 뜬 느낌)
- 1.3 이상: 현실적이고 타이트한 느낌

---

### 5. Air Control (공중 제어)

**점프 중 방향 전환 능력**

```
범위: 0.0 ~ 1.0
0.0: 점프 후 방향 전환 불가
1.0: 완전한 공중 제어 가능
```

**게임 스타일에 따라 조정**:

- 하드코어: 0.2~0.4
- 캐주얼: 0.6~0.8

## 🎯 패키징이란?

**패키징(Packaging)** = 게임을 실행 파일(.exe)로 만들어 다른 사람과 공유할 수 있게 만드는 과정

```
언리얼 프로젝트 → 패키징 → 독립 실행 파일
→ 친구/플레이어에게 배포 가능
```

---

## 📦 패키징 프로세스

### 1단계: 빌드 구성 선택

```
메뉴바 → Platforms → Windows → Build Configuration
```

### 빌드 구성 종류

| 구성            | 용도                      |
| --------------- | ------------------------- |
| **Development** | 개발/테스트용 (기본값)    |
| **Shipping**    | 최종 배포용 (최적화됨) ⭐ |

💡 **실전 팁**:

- 자체 테스트: Development
- 다른 사람에게 배포: **Shipping** 필수

---

### 2단계: 아키텍처 선택

```
Platforms → Windows → Architecture
```

**권장**: Project Default (그대로 두기)

---

### 3단계: 패키징 실행

```
Platforms → Windows → Package Project
```

### 저장 위치 선택

**옵션 1**: 프로젝트 외부

```
내문서/Builds/ObstacleAssault/
```

**옵션 2**: 프로젝트 내부

```
프로젝트폴더/Build/
```

💡 **팁**: 외부 폴더 추천 (프로젝트 폴더 용량 절약)

---

### 4단계: 패키징 대기

```
처음 패키징: 10~30분 소요 (프로젝트 크기에 따라)
이후 패키징: 5~10분 (증분 빌드)
```

⏰ **진행 상황**: 하단 출력 로그에서 확인 가능

---

## 📁 패키징 결과물 구조

```
Builds/
└─ Windows/           ← 이 폴더 전체를 배포
   ├─ ObstacleAssault.exe  ⭐ 게임 실행 파일
   ├─ Engine/
   ├─ ObstacleAssault/
   └─ 기타 필요한 파일들
```

⚠️ **중요**:

- **Windows 폴더 전체**를 배포해야 함
- .exe 파일만 보내면 작동 안 됨

## 🐛 문제 해결

### 패키징 실패

```
원인 1: 컴파일 오류
→ Visual Studio에서 빌드 에러 확인

원인 2: 에셋 참조 문제
→ Content Browser에서 깨진 참조 수정

원인 3: 플러그인 충돌
→ 불필요한 플러그인 비활성화
```

### 실행 파일이 안 열림

```
문제 1: 보안 경고
→ "추가 정보" → "실행" 클릭

문제 2: 파일 누락
→ Windows 폴더 전체 복사 확인

문제 3: DirectX 오류
→ DirectX 런타임 설치 필요
```

### 게임이 느리게 실행됨

```
원인: Development 빌드로 패키징
→ Shipping 빌드로 다시 패키징
```
