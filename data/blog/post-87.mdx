# 스코프

```jsx
"스코프(Scope)는 변수와 함수가 유효한 범위를 나타내는 중요한 개념"입니다.

JavaScript에서 스코프는 변수와 함수가 정의되고, 그들이 사용될 수 있는 범위를 결정합니다.

스코프는 코드 내에서 변수와 함수의 가시성과 접근성을 제어하는 역할을 합니다.

식별자 접근 규칙에 따른 유효 범위

* 스코프의 정의는 “식별자 접근 규칙에 따른 유효 범위”이다.

* 식별자(변수, 함수, 클래스)에 접근할 수 있는 범위가 존재한다.

* 범위는 중괄호(블록) 또는 함수에 의해 나눠진다.

* 그 범위를 스코프라고 부른다.

* 그래서 각각을 Block Scope와 Function Scope라고 부른다.
```

## 스코프의 종류

```jsx
1. "전역 스코프 (Global Scope)": 전역 스코프는 코드의 최상위 범위입니다.

전역 스코프에서 선언된 변수와 함수는 어디서든지 접근할 수 있습니다. 전역 스코프에서 선언된 변수는 전역 변수(global variable)로 알려져 있으며,

전역 스코프에서 선언된 함수는 전역 함수(global function)로 알려져 있습니다.

2. "지역(함수) 스코프 (Local Scope)": 지역 스코프는 함수 내부에서 선언된 변수와 함수가 해당 함수 내에서만 접근 가능한 범위입니다.

함수가 호출될 때마다 새로운 지역 스코프가 생성됩니다. 이것을 함수 스코프(function scope)라고도 부릅니다.

함수 내에서 선언된 변수는 해당 함수 내부에서만 유효하며, 함수 외부에서는 접근할 수 없습니다.

3. "블록 스코프 (Block Scope)": 블록 스코프는 블록({}) 내부에서 선언된 변수가 해당 블록 내에서만 접근 가능한 범위입니다.

ES6(ES2015)부터 let과 const 키워드로 선언된 변수는 블록 스코프를 갖습니다. 예를 들어, if, for, while 문 등의 블록 내에서 선언된 변수는 해당 블록 내에서만 유효하며 외부에서는 접근할 수 없습니다.

4. "렉시컬 스코프 (Function Scope and Lexical Scope)": JavaScript는 렉시컬 스코프(lexical scope)를 사용합니다.

이것은 함수가 정의된 위치에 따라 스코프가 결정된다는 의미입니다. 함수 스코프는 함수 내부에서 변수가 유효한 범위를 결정하고,

렉시컬 스코프는 변수의 유효 범위가 코드의 물리적 위치에 따라 결정됩니다. 이것은 함수가 어디에 선언되었는지에 따라 변수의 스코프가 결정된다는 것을 의미합니다.
```

## **스코프의 주요 규칙**

```jsx
1. 안쪽 스코프에서 바깥쪽 스코프로 접근할 수 있지만 반대는 불가능하다.

* 바깥쪽 스코프에서 선언한 식별자는 안쪽 스코프에서 사용 가능하다.

* 반면, 안쪽에서 선언한 식별자는 바깥쪽 스코프에서는 사용할 수 없다.

2. 스코프는 중첩이 가능하다.

* 스코프는 마치 중첩된 울타리와도 같다.

3. 전역 스코프와 지역 스코프

* 가장 바깥쪽의 스코프를 전역 스코프(Global Scope)라고 부른다.

* 전역이 아닌 다른 스코프는 전부 지역 스코프(Local Scope)이다.

4. 지역 변수는 전역 변수보다 우선순위가 더 높다.

* 전역 스코프에서 선언한 변수는 전역 변수이다.

* 지역 스코프에서 선언한 변수는 지역 변수이다.

* 지역 변수는 전역 변수보다 더 높은 우선순위를 가진다.
```

## 예제

```jsx
function outer() {
  var outerVar = "I'm in the outer function"

  function inner() {
    var innerVar = "I'm in the inner function"
    console.log(outerVar) // outerVar에 접근 가능
  }

  inner()
  console.log(innerVar) // 에러: innerVar는 outer 함수 밖에서는 접근 불가
}
```

```jsx
위의 코드에서 outerVar는 outer 함수 스코프 내에서 선언되었으므로 inner 함수에서도 접근할 수 있습니다.

그러나 innerVar는 inner 함수 스코프 내에서만 유효하기 때문에 outer 함수 외부에서 접근할 수 없습니다.

스코프는 변수와 함수의 가시성과 유효 범위를 관리하는 중요한 개념으로, 올바른 변수 및 함수 사용을 보장하기 위해 이해해야 합니다.
```

## **스코프와 var, let, const 키워드**

```jsx
const 키워드

유효 범위 : 블록 스코프 / 함수 스코프

값 재할당 : 불가능

재선언 : 불가능

let 키워드

유효 범위 : 블록 스코프 / 함수 스코프

값 재할당 : 가능

재선언 : 불가능

var 키워드

유효 범위 : 함수 스코프

값 재할당 : 가능

재선언 : 가능
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381265/notion-blog/_/JavaScript/JavaScript_/_/Untitled.png)

```jsx
for (let i = 0; i < 10; i++) {
  console.log(i)
}
// 전역스코프에서 선언한 변수 i 는 존재하지 않음으로 아래에서 ReferenceErrer을 일으킨다.
console.log(i) // ReferenceErrer
```

```jsx
블록 스코프 안에서 let과 const 키워드로 선언한 변수는 스코프 안에서만 참조 가능하다.

그런데 var 키워드로 선언한 변수는 블록 스코프를 무시하고 스코프 울타리 밖에서도 접근 가능하다. (var는 Only 함수 스코프만 따른다.)
```

### var 의 문제

```jsx
for (var i = 0; i < 10; i++) {
  console.log(i)
}
// var 키워드로 선언한 변수 i 는 지역 스코프에서 선언되었지만 모든 스코프에서 접근 가능하다.
console.log(i) // 9
```

```jsx
var 키워드로 선언한 변수는 only ‘함수 스코프’만을 따른다.

그래서 블록 단위로 스코프를 구분했을 때, 훨씬 더 예측 가능한 코드를 작성할 수 있으므로 let 키워드의 사용이 권장된다.
```

## **스코프와 관련해서 변수 선언시 주의점**

### **전역 객체(window)의 이해**

```jsx
* Window 객체는 only 브라우저에만 존재하는 객체이다.

* 브라우저의 창(window)를 의미하는 객체이다.

* 그런데 별개로 전역 영역을 담고 있기도하다.

* 그래서 함수 선언식으로 함수를 선언하거나 var 키워드로 변수를 선언하면 window 객체에 속해진다.
```

## **전역 변수는 최소화하기**

```jsx
* 가장 바깥 스코프에 정의한 변수가 전역 변수이다.

* 즉, 어디서든 접근이 가능하다.

* 전역 변수를 최소화 하면 side effect(의도하지 않은 로직에 의해 문제 발생)를 줄일 수 있다.

* 그런데 그러한 전역 변수를 심지어 var로 선언하는 경우 문제가 될 수 있다.

	1. 전역 변수는 어디서나 접근이 가능하다.
	2. var 키워드는 블록 스코프를 무시한다.
	3. 재선언과 재할당을 할 수 있다.
	4. 전역 변수를 var로 선언해서 브라우저의 내장 기능을 못하게 만들 수도 있다.
```

## **선언 없는 변수 할당 금지**

```jsx
* 선언 없이 변수를 할당하면 해당 변수는 var로 선언한 전역 변수 처럼 취급된다.

* 실수를 방지하기 위해 Strict Mode를 사용할 수 있다.

	1. Strict Mode는 브라우저가 보다 엄격하게 작동하도록 만들어준다.
	2. “선언 없는 변수 할당”의 경우도 에러로 판단해준다.
	3. 적용하려면, js 파일 상단에 ‘use strict’라고 입력하면된다. (따옴표 포함)
```

## 렉시컬 스코핑([**Lexical scoping)**](https://poiemaweb.com/js-scope#7-%EB%A0%89%EC%8B%9C%EC%BB%AC-%EC%8A%A4%EC%BD%94%ED%94%84)

```jsx
스코프는 함수를 호출할 때가 아니라 함수를 어디에 선언하였는지에 따라 결정된다.

이를 렉시컬 스코핑(Lexical scoping)라 한다. 위 예제의 함수 innerFunc는 함수 outerFunc의 내부에서 선언되었기 때문에 함수 innerFunc의 상위 스코프는 함수 outerFunc이다.

함수 innerFunc가 전역에 선언되었다면 함수 innerFunc의 상위 스코프는 전역 스코프가 된다.
```
