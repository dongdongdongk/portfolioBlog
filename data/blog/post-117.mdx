# 이번 파트의 내용

```jsx
이번 파트는 리액트의 새로운 기능이나 문법에 대한 내용은 없지만,

기존에 알고 있는 내용을 사용하여 어떻게 애플리케이션을 구성하고 상태를 관리하며,

프로퍼티를 전달하고 컴포넌트를 만들며, 이러한 다양한 도구들을 결합하여 큰 애플리케이션을 만드는 방법에 대해 알아본다.

이번 섹션에서는 컴포넌트 분해와 애플리케이션 설계를 중점적으로 다루며, 실전 예제로 "Lucky 7 Game"이라는 주사위 게임 컴포넌트를 만들어본다.
```

# 만들 앱의 규칙

```jsx
Lucky 7 Game 컴포넌트는 두 개의 6면 주사위를 굴려 합이 7이 되면 이기는 간단한 게임이다.

컴포넌트 안에서는 상태를 통해 주사위의 값을 관리하고, 렌더링 시 주사위의 합이 7이 되었는지 확인하여 결과를 표시한다.

"다시 굴리기" 버튼을 클릭하면 주사위를 다시 굴리고 새로운 결과를 보여준다.
```

# Lucky 7 게임을 개선을 위한 필요한 사항

```jsx
**게임 기능 확장**

럭키 7 이외에도 럭키 10, 럭키 11 등 다양한 목표 합을 플레이할 수 있도록 게임 기능 확장.

주사위 개수는 3개부터 10개까지 다양하게 설정 가능.

목표 점수는 99로 설정되며, 유연성 있게 변경 가능.

**컴포넌트 구성**

**게임 컴포넌트 (LuckyN)**: Lucky7이 아닌 일반적인 LuckyN, LuckyGame, LuckyDice 등의 게임을 나타냄.

**주사위 묶음을 렌더링하는 Dice 컴포넌트**: 여러 Die 컴포넌트로 구성됨.

**개별 주사위를 나타내는 Die 컴포넌트**: 주사위 값과 관련된 프레젠테이션 컴포넌트.

**게임 플레이 기능**

Dice 컴포넌트는 주사위 묶음을 렌더링하고, Die 컴포넌트들을 포함하여 화면에 표시.

주사위 값들의 합이 목표 점수와 일치할 경우 우승 알림 메시지를 표시.

주사위를 다시 굴릴 수 있는 버튼 기능 추가.

**상태 및 로직 컴포넌트**

LuckyN 컴포넌트에는 게임의 로직과 상태가 포함되어 있음.

Dice 컴포넌트는 프레젠테이션 컴포넌트로, 주로 화면 표시와 관련된 역할을 수행.

Die 컴포넌트는 주사위의 값과 관련된 프레젠테이션 컴포넌트로 상태가 없음.

**컴포넌트 재사용성**

LuckyN 컴포넌트는 게임의 로직을 담고 있으므로 여러 게임에서 재사용 가능.

Dice 컴포넌트는 주사위 묶음을 나타내며, 재사용 가능한 컴포넌트로 설계.

Die 컴포넌트는 주사위의 개별 값에 대한 프레젠테이션 역할을 수행하며, 여러 Dice 컴포넌트에서 재사용 가능.

**프레젠테이션 및 로직 컴포넌트 분리**

Dice 컴포넌트는 주로 UI 표시에 관련된 로직이 없이, Die 컴포넌트를 렌더링하는 역할 수행.

Die 컴포넌트는 주사위 값과 관련된 프레젠테이션만 처리하고 로직은 LuckyN 컴포넌트에서 담당.

**상태 관리 및 데이터 전달**

LuckyN 컴포넌트에 게임 상태가 저장되어 있으며, 주사위 값과 목표 점수 등을 관리.

주사위 값의 합이 목표 점수와 비교하여 게임 결과를 결정하는 로직이 LuckyN 컴포넌트에 존재.

리액트에서 상태는 필요한 만큼 위로 올리되, 더 이상은 상태를 올리지 않는 원칙을 적용.

**컴포넌트 유형 구분**

**바보 컴포넌트 (프레젠테이션 컴포넌트)**: 주로 상태가 없이 UI 표시에 관련된 역할을 하는 컴포넌트.

**로직 컴포넌트**: 게임의 로직이나 상태를 관리하는 컴포넌트로, LuckyN이 해당되며 상태를 갖고 있음.

각 컴포넌트의 역할을 구분하여 개발 및 유지보수 용이성을 고려.

**컴포넌트 재사용 및 확장성**

주사위 개수, 목표 점수 등의 설정은 LuckyN 컴포넌트에서 처리되어 유연성과 재사용성 확보.

다양한 게임 시나리오에서 해당 컴포넌트를 재사용할 수 있도록 설계.

게임 규칙이나 UI 요소의 변경에도 쉽게 대응 가능한 확장성 고려.
```

# 리액트에서 컴포넌트를 설계할 때 지켜야 할 규칙과 주의사항

```jsx
**컴포넌트 분리**:

각 컴포넌트는 단일 책임 원칙을 따라야 하며, 한 가지 역할을 수행하도록 설계.

**상태의 최상위 유지**:

상태는 필요한 만큼 위로 올려야 하지만, 최상위에서 너무 많은 상태를 관리하지 않도록 주의.

**무상태 프레젠테이션 컴포넌트**:

주로 상태가 없이 UI 표시에 관련된 역할을 하는 컴포넌트. 무상태로 설계하여 재사용성을 높이고 유지보수를 용이하게 함.

**로직 컴포넌트**:

게임의 로직이나 상태를 관리하는 컴포넌트

상태 및 게임 로직과 같은 비즈니스 로직은 별도의 컴포넌트에서 관리하여 컴포넌트를 단순화하고 유지보수성을 강화.

**프레젠테이션 및 로직의 분리**:

UI 표시와 관련된 로직과 상태를 프레젠테이션 컴포넌트에, 비즈니스 로직을 로직 컴포넌트에 위치시켜 역할을 분리.

**컴포넌트 재사용성**:

가능한 한 컴포넌트를 재사용 가능한 단위로 설계하여 다양한 환경에서 활용.

**상태 및 프로퍼티의 적절한 활용**:

상태는 컴포넌트 내에서 변경되어야 하는 값에만 사용하며, 나머지는 프로퍼티로 전달하여 유연성을 확보.

**구조적 설계**:

컴포넌트 계층 구조를 구성할 때 구조적이고 명확한 계층 구조를 유지하여 가독성을 향상.

**단일 책임 원칙**:

각 컴포넌트는 한 가지 일만 수행하도록 설계하여 코드의 간결성과 유지보수성을 높임.

**상태 전달의 한계**:

최대한 위로 상태를 전달하되, 최상위에서 너무 많은 상태를 관리하지 않도록 주의.

**유연성과 확장성**:

컴포넌트를 설계할 때 다양한 환경에서 유연하게 대처할 수 있도록 설계하고, 나중에의 확장성을 고려.

**리액트 원칙 준수**:

리액트의 주요 원칙을 따르며, 컴포넌트 기반 아키텍처의 이점을 최대한 활용.
```

```jsx
Die 컴포넌트에는 단순한 <div>가 포함되며, 값을 프로퍼티로 받아 렌더링함.
```

## **Dice 컴포넌트**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_2.png)

```jsx
import Die from './Die'
import './Dice.css'
function Dice({ dice, color }) {
  return (
    <section className="Dice">
      {dice.map((v, i) => (
        <Die key={i} val={v} color={color} />
      ))}
    </section>
  )
}
export default Dice

// dice 에 넘어오는 배열 형태 ex) [3, 4, 2]; 주사위 3개
```

```jsx
주사위 묶음을 나타내며, 주사위 값을 배열로 받아 Die 컴포넌트를 반복 렌더링.

주사위 배열을 받아 각 Die 컴포넌트에 값을 전달하고, 각 Die 컴포넌트를 렌더링함.

각 Die에는 프로퍼티로 색상을 전달하고, Die 컴포넌트는 해당 색상을 배경색으로 사용함.

Dice 컴포넌트는 무상태의 프레젠테이션 컴포넌트로, 주어진 주사위 배열에 따라 Die 컴포넌트를 렌더링함.
```

```jsx
**컴포넌트 구분:**

Die 컴포넌트는 주사위 값 하나를 표현하며, Dice 컴포넌트는 주사위 묶음을 나타냄.

Die는 무상태 프레젠테이션 컴포넌트이며, Dice는 주어진 주사위 배열에 따라 여러 Die 컴포넌트를 렌더링하는 역할을 함.

Die와 Dice의 구분을 통해 각 컴포넌트가 단일 책임을 갖도록 함.

**재사용성과 확장성:**

Die와 Dice 컴포넌트를 구분하여 재사용성을 높이고, 각 컴포넌트가 독립적으로 사용될 수 있도록 함.

Dice 컴포넌트를 이용하면 주어진 주사위 배열에 따라 동적으로 Die 컴포넌트를 생성하고 렌더링할 수 있음.

색상 설정을 통해 각 주사위 묶음에 대한 스타일을 쉽게 변경할 수 있으며, 확장성을 고려함.

**컴포넌트 디자인 원칙:**

Die 컴포넌트는 주어진 값에 따라 렌더링하는 간단한 프레젠테이션 컴포넌트.

Dice 컴포넌트는 주사위 배열을 받아 Die 컴포넌트를 반복 렌더링하는 역할을 수행하는 프레젠테이션 컴포넌트.

단일 책임 원칙과 컴포넌트 분리를 고려하여 코드를 작성하고, 구조적인 설계를 통해 가독성을 향상시킴.
```

# LuckyN 컴포넌트

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_3.png)

```jsx
import { useState } from 'react'
import { getRolls } from './utils'
import Button from './Button'
import Dice from './Dice'
function LuckyN({ title = 'Dice Game', numDice = 2, winCheck }) {
  const [dice, setDice] = useState(getRolls(numDice))
  const isWinner = winCheck(dice)
  const roll = () => setDice(getRolls(numDice))
  return (
    <main className="LuckyN">
      <h1>
        {/* isWinner가 true 라면 "You Win" */}
        {title} {isWinner && 'You Win!'}
      </h1>
      <Dice dice={dice} />
      <Button clickFunc={roll} label="Re-Roll" />
    </main>
  )
}
export default LuckyN
```

```jsx
/*utils.js 파일*/

/** Gets random integer: [1..6]. */

function d6() {
  return Math.floor(Math.random() * 6) + 1
}

/** Get n rolls => [num, ...]. */

function getRolls(n) {
  return Array.from({ length: n }, () => d6()) // Array.from: 이 함수는 주어진 유사 배열 객체나 반복 가능한 객체로부터 새로운 배열을 생성 { length: n } 객체를 생성하여 배열의 길이를 n으로 설정하고, 배열의 각 요소에 대해 두 번째 인자로 전달된 콜백 함수를 실행하여 값을 할당
}

/** Get sum of nums. */

function sum(nums) {
  return nums.reduce((prev, cur) => prev + cur, 0)
}

export { d6, getRolls, sum }
```

```jsx
**LuckyN 컴포넌트 생성**

LuckyN 컴포넌트: 주사위 게임 로직을 처리하고 주사위를 렌더링.

numDice, goal 프로퍼티를 받아 초기 설정.

주사위의 합이 목표(goal)과 일치하면 우승.

**LuckyN 컴포넌트 상태 관리**

useState를 사용하여 LuckyN 컴포넌트의 상태를 관리.

getRolls 함수로 초기 주사위 배열 생성.

**게임 우승 로직 추가**

주사위 합(sum)이 목표(goal)과 일치하는지 확인하여 우승 여부 표시.

isWinner 변수를 사용하여 조건부 렌더링.

**주사위 재굴리기 기능 추가**

"Re-Roll Dice" 버튼을 추가하고 onClick 이벤트에 roll 함수 설정.

roll 함수에서 getRolls를 사용하여 새로운 주사위 배열 생성.

**컴포넌트 재사용성 향상**

Dice, Die 컴포넌트를 통해 재사용 가능한 컴포넌트 구조 구성.

LuckyN 컴포넌트의 목표(goal) 및 주사위 개수(numDice)를 프로퍼티로 전달하여 다양한 게임 설정 가능.

**다양한 게임 변종 생성**

LuckyN 컴포넌트의 numDice와 goal 프로퍼티를 조절하여 다양한 게임 설정 가능.

다양한 주사위 개수와 목표 합을 실험적으로 설정하여 게임 플레이.
```

## **승리 조건을 동적으로 변경하기:**

```jsx
함수를 Props로 전달하면 부모 컴포넌트에서 해당 함수를 동적으로 변경할 수 있다.

이는 게임 로직의 수정이나 다양한 승리 조건을 실험하는 데 용이하다.
```

```jsx
// 부모 컴포넌트에서 함수 정의 (App)
const lessThan4 = (dice) => dice.reduce((sum, value) => sum + value, 0) < 4

// LuckyN 컴포넌트에 전달
;<LuckyN winCheck={lessThan4} />
```

## **다른 게임 모드 구현:**

```jsx
다양한 게임 모드를 구현할 때, 각각의 게임 모드에 해당하는 함수를 정의하고 해당 함수를 Props로 전달할 수 있다.
```

```jsx
// 부모 컴포넌트에서(App) 함수 정의

// LuckyN 컴포넌트에 전달
```


## BoxGrid.jsx

```jsx
import Box from './Box'
import { useState } from 'react'
function BoxGrid() {
  const [boxes, setBoxes] = useState([false, false, true, false, true, false, false, false, false])
  const reset = () => {
    setBoxes([false, false, false, false, false, false, false, false, false])
  }

  const toggleBox = (idx) => {
    setBoxes((oldBoxes) => {
      return oldBoxes.map((value, i) => {
        if (i === idx) {
          return !value
        } else {
          return value
        }
      })
    })
  }
  return (
    <div className="BoxGrid">
      {boxes.map((b, idx) => (
        <Box key={idx} isActive={b} toggle={() => toggleBox(idx)} />
      ))}
      <button onClick={reset}>Reset</button>
    </div>
  )
}

export default BoxGrid
```
