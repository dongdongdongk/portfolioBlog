```jsx
“클로저는 내부함수가 외부함수의 맥락(context)에 접근할 수 있는 것을 가리킨다”

클로저란 함수 내부에서 사용되는 변수와 그 변수가 속한 함수의 범위(스코프) 간의 특별한 관계를 의미합니다.

예를 들어서, 함수 A 안에서 선언된 변수 X가 있다고 가정해 봅시다.

이때 함수 A 내부에서 정의한 다른 함수 B가 변수 X를 사용할 수 있고, 함수 B를 함수 A 외부에서 호출해도 변수 X를 사용할 수 있게 되는 것이 클로저입니다.

클로저는 변수 X와 함수 B 간의 관계를 유지하여 변수 X를 보존하고 재사용할 수 있게 합니다.
```

# **클로저 함수의 장점 (활용)**

## 장점1. 데이터를 보존할 수 있다.

```jsx
클로저 함수는 외부 함수의 실행이 끝나더라도 외부 함수 내 변수를 사용할 수 있습니다. 이는 데이터를 보존하고 나중에 사용할 수 있는 기능을 제공합니다.
```

```jsx
function counter() {
  var count = 0

  return function () {
    count++
    console.log(count)
  }
}

var increment = counter()
increment() // 출력: 1
increment() // 출력: 2

//위 예제에서 counter 함수는 클로저를 반환합니다. 클로저 내부의 함수는 외부 함수인 counter의 count 변수에 접근하여 값을 증가시키고 보존합니다.
```

## 장점2. 정보의 접근 제한 (캡슐화)

```jsx
클로저를 사용하면 정보를 외부에서 직접 접근하지 못하게 할 수 있습니다. 이것을 캡슐화라고 합니다.
```

```jsx
function createPerson(name) {
  var age = 0

  return {
    getName: function () {
      return name
    },
    getAge: function () {
      return age
    },
    setAge: function (newAge) {
      if (newAge >= 0) {
        age = newAge
      }
    },
  }
}

var person = createPerson('John')
console.log(person.getName()) // 출력: "John"
console.log(person.getAge()) // 출력: 0
person.setAge(30)
console.log(person.getAge()) // 출력: 30

// 위 예제에서 createPerson 함수는 클로저를 사용하여 name과 age 변수를 캡슐화합니다. 외부에서 직접 접근할 수 없으며, getAge와 setAge 메서드를 통해 제어할 수 있습니다.
```

## 장점3. 모듈화에 유리하다.

```jsx
클로저를 사용하면 데이터와 메소드를 묶어서 모듈화할 수 있습니다. 이는 코드의 구조화와 재사용성을 높이는 데 도움이 됩니다.
```

```jsx
function calculator() {
  var result = 0

  return {
    add: function (x) {
      result += x
    },
    subtract: function (x) {
      result -= x
    },
    getResult: function () {
      return result
    },
  }
}

var calc = calculator()
calc.add(5)
calc.subtract(2)
console.log(calc.getResult()) // 출력: 3

// 위 예제에서 calculator 함수는 클로저를 사용하여 계산기 모듈을 생성합니다. 모듈은 add, subtract, getResult 메서드로 구성되어 있으며,

// 각각의 모듈은 독립적으로 데이터를 관리하고 동작합니다. 이렇게 모듈화된 코드는 다른 부분에서 재사용하기 용이합니다.
```

# 클로저 예제

```jsx
// 클로저를 만드는 형태 1. - 중첩함수
function outerFn() {
  let x = 10
  return function innerFn(y) {
    // innerFn 함수는 클로저다.
    return (x = x + y)
  }
}
let a = outerFn() // 외부함수 호출은 한번만. 이제 a 변수는 innerFn 함수를 참조한다.
a(5) // 15;
a(5) // 20;
a(5) // 25;
```

```jsx
// 클로저를 만드는 형태 2. - 전역에 선언한 변수를 박스 안에서 함수로 정의하고 전역에서 호출
let globalFunc
{
  let x = 10
  globalFunc = function (y) {
    // globalFunc 함수는 클로저다.
    return (x = x + y)
  }
}
globalFunc(5) // 15;
globalFunc(5) // 20;
globalFunc(5) // 25;
```
