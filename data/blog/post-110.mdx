# 리액트 소개

```jsx
리액트(React)는 프런트엔드 라이브러리로, 사용자 인터페이스를 만들기 위한 도구 이다

리액트는 가벼운 프레임워크가 아니라 라이브러리로 분류되기도 한다

리액트의 강점 중 하나는 컴포넌트를 재사용하고 조합하여 복잡한 사용자 인터페이스를 구축할 수 있다는 점이다.

이는 작은 모듈들을 조립하여 전체 애플리케이션을 만들어나가는 개념
```

## 컴포넌트

```jsx
컴포넌트(Component)는 리액트에서 핵심적인 개념 중 하나로,

사용자 인터페이스를 구축하기 위한 독립적인 모듈이다.

각 컴포넌트는 화면에 표시되는 부분과 그에 대한 로직을 포함하고 있다.

이로써 작은 기능을 갖는 컴포넌트들을 조합하여 큰 프런트엔드를 구축할 수 있다.

간단한 예로, '이용객 선택 버튼'이라는 컴포넌트를 생각해보자

이 컴포넌트에는 사용자가 선택한 이용객의 수를 표시하고, 늘리거나 줄일 수 있는 버튼이 있다.

이 컴포넌트는 단순한 카운터 기능을 수행하며, 이를 여러 번 재사용하여 화면을 구성할 수 있다.

React 컴포넌트는 PascalCase로 작성되어야 한다.

따라서

예를들어 home 컴포넌트의 이름을 대문자로 시작하는       Home        PascalCase로 수정해야한다
```

# JSX

```jsx
JSX(JavaScript XML)는 리액트에서 사용되는 문법 확장으로,

JavaScript 코드 내에서 XML 또는 HTML과 유사한 구문을 사용할 수 있게 해주는 것이다.

JSX는 리액트 컴포넌트에서 사용자 인터페이스를 표현하는 데 주로 활용된다.

간단하게 말하면, JSX는 JavaScript 안에서 HTML 형식으로 코드를 작성할 수 있게 해주어,

리액트 애플리케이션의 가독성을 높이고 작성하기 쉽게 만들어준다.

* 엄연히 자바스크립트와는 다르기 때문에 진짜 자바스크립트로 변환하는 과정이 필요하다

	**babel**이 JSX 변환을 처리한다 바벨이 하는 일은 자바스크립트가 지원하지 않는 문법으로 작성된 코드를 진짜 자바스크립트로

  변환한다
```

```jsx
<div>
  <h1>Hello, World!</h1>
  <p>This is a paragraph.</p>
</div>

* JSX 변환--------------------------------------

const element = (
  <div>
    <h1>Hello, World!</h1>
    <p>This is a paragraph.</p>
  </div>
);
```

## JSX 특징

### **JavaScript 표현식 삽입**

```jsx
JSX 내에서 중괄호 {}를 사용하여 JavaScript 표현식을 삽입할 수 있다.

이를 통해 동적인 내용을 표현할 수 있다.
```

```jsx
const name = 'John'
const element = <p>Hello, {name}!</p>
```

### **HTML과 유사한 구조**

```jsx
JSX는 HTML과 유사한 문법을 사용하기 때문에, HTML 태그와 속성을 그대로 활용할 수 있다.
```

### **컴포넌트 표현**

```jsx
JSX는 리액트 컴포넌트를 표현하는 데에도 사용된다.

컴포넌트는 JSX로 작성되며, 다른 컴포넌트를 조합하여 더 복잡한 UI를 생성할 수 있다.
```

```jsx
function Welcome(props) {
  return <p>Hello, {props.name}!</p>
}

const element = <Welcome name="John" />
```
