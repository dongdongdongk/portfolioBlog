# { Sass와 Scss란? }

## 1. **SASS와 SCSS란?**

```jsx
SASS: '문법적으로 끝내주는 스타일 시트(Syntactically Awesome Stylesheet)'의 약자.

SCSS: SASS의 구문 중 하나로, CSS와 매우 유사한 형식을 사용.

차이점: 둘은 본질적으로 동일하지만, 구문(Syntax)이 약간 다름.

		SCSS는 CSS처럼 중괄호 {}와 세미콜론 ;을 사용.

		SASS는 더 간결한 스타일로, 중괄호나 세미콜론 없이 공백과 들여쓰기를 사용.
```

## 2. **SASS와 SCSS의 필요성**

```jsx
CSS 확장: SASS는 CSS 규칙을 확장해 더 효율적으로 코딩할 수 있게 돕는다.

컴파일 과정: 브라우저는 SASS를 직접 이해하지 못하므로, SASS 코드를 CSS로 컴파일해야 함.

장점: 개발 단계에서 시간을 절약하고, 코드 유지와 수정이 쉬워지며, 재사용 가능한 코드를 작성 가능.
```

## 3. **SASS의 주요 기능**

```jsx
중첩(Nesting): 선택자(Selectors)를 중첩해 구조화된 스타일을 만들 수 있음.

상속(Inheritance): 기존 스타일 규칙을 상속받아 반복되는 코드를 줄일 수 있음.

믹스인(Mixins): 재사용 가능한 코드 블록을 정의해 필요할 때마다 호출 가능.

변수(Variables): 자주 사용하는 값(색상, 폰트 크기 등)을 변수로 저장해 필요 시 쉽게 변경 가능.

분할 파일(Partials): CSS 코드를 여러 파일로 나누어 관리하고, 필요한 파일만 불러와서 사용할 수 있음.

헬퍼 함수(Helper Functions): 색상 조정 등의 작업을 돕는 함수 제공.

조건문 및 반복문: 특정 상황에 따라 스타일을 다르게 적용하거나 반복적인 코드를 처리할 수 있음.
```

## 1. **SASS 파일 생성 및 기본 설정**

```jsx

SASS는 세미콜론과 중괄호 없이 들여쓰기로 프로퍼티를 구분합니다.
```

## 2. **SASS와 SCSS의 차이**

```jsx
SASS: 세미콜론과 중괄호 없이 간결한 문법을 사용.

SCSS: CSS와 유사한 문법으로, 세미콜론과 중괄호를 사용. SASS와 동일한 기능을 제공하지만 문법 차이만 존재.
```

## 1. **목록(List) 변수**

```jsx
목록 변수는 여러 값을 공백이나 쉼표로 구분하여 저장할 수 있습니다.

예를 들어, box-shadow처럼 여러 값이 필요한 CSS 속성에 적합합니다.
```

```jsx
$box-shadow: 0.2rem 0.2rem 0.1rem #ccc;

.sass-box {
  box-shadow: $box-shadow;
}
```

```jsx
$border-default: 0.05rem solid #521751;

.sass-border {
  border: $border-default;
}
```

## 2. **맵(Map) 변수**

```jsx
맵 변수는 키-값 쌍을 저장하는데, 이 방식으로 변수를 그룹화하고 체계적으로 관리할 수 있습니다.

맵 변수는 Sass의 map-get 함수를 사용하여 값을 추출합니다.
```

```jsx
$colors: (
  main: #521751,
  secondary: #fa923f
);

$border-default: 0.05rem solid map-get($colors, main);

.sass-border {
  border: $border-default;
}

.sass-background {
  background-color: map-get($colors, secondary);
}
```

```jsx
* 맵(Map) 변수는 여러 색상을 그룹화하여 관리할 수 있습니다.

	예를 들어, $colors 맵은 main과 secondary 색상을 저장하고, map-get($colors, main)을 통해 색상을 불러올 수 있습니다
```

# { Sass 내장 함수 활용하기 }

```jsx
Sass는 다양한 내장 함수를 제공하여 색상 조정, 투명도 관리 등 CSS 코드를 더욱 효율적으로 작성할 수 있도록 돕습니다.

내장 함수는 복잡한 계산을 간단하게 해결해 주기 때문에 Sass에서 중요한 기능 중 하나입니다.
```

## `lighten()` 함수

```jsx
lighten() 함수는 주어진 색상을 더 밝게 만들어줍니다.

첫 번째 인수는 색상, 두 번째 인수는 밝기의 비율(0~100%)입니다.
```

```jsx
.sass-introduction {
  background-color: lighten(map-get($colors, main), 72%);
}
```

```jsx
* 위 코드에서 **map-get()**을 사용해 main 색상을 가져오고, **lighten()**을 사용해 그 색상을 72% 밝게 만들었습니다.

이처럼 주 색상을 바꿀 때 자동으로 밝은 버전도 변경되게 할 수 있습니다.
```

## 다양한 내장 함수

```jsx
Sass는 lighten() 외에도 다양한 내장 함수를 제공합니다. 예를 들어:

		darken(): 색상을 어둡게 만들기.

		transparentize(): 색상의 투명도를 높이기.

* 공식 문서를 참고하도록
```

# { Sass에서 사칙연산 활용하기 }

```jsx
Sass는 CSS에 없는 사칙연산 기능을 제공하여, 크기나 간격 등 값을 동적으로 계산할 수 있습니다.

이는 변수 재사용뿐만 아니라 값 간의 연산을 가능하게 해줍니다. 다음은 강의에서 다룬 핵심 내용입니다.
```

## 1. **사칙연산 적용하기**

```jsx
Sass에서는 곱하기, 나누기, 더하기, 빼기와 같은 사칙연산을 사용할 수 있습니다.

		예를 들어, size-default 변수가 1rem이라면 size-default * 3을 적용하여 3rem을 만들 수 있습니다.

		Sass는 연산 결과를 자동으로 계산하여 CSS 파일에 반영합니다.
```

```jsx
$size-default: 1rem;
$size-tiny: 0.2rem;

.container {
  padding: $size-default * 3; // 결과: 3rem
  margin: $size-default * 2;  // 결과: 2rem
}

.sass-introduction {
  box-shadow: 0.2rem 0.2rem ($size-tiny / 2); // 결과: 0.1rem
}
```

# { Sass: Better Import와 Partials 활용하기 }

## 1. **@import와 CSS 파일 가져오기**

```jsx
.scss 또는 .sass 파일에서 @import를 사용해 CSS 파일을 가져오면,

Sass는 기존 CSS처럼 작동합니다. CSS 파일은 컴파일된 CSS 파일에 그대로 유지됩니다.

예를 들어, main.scss 파일에서 typography.css 파일을 가져오면,

개발자 도구에서 해당 CSS 파일이 별도의 HTTP 요청으로 로드됩니다.
```

## 다중 파일 가져오기

```jsx
@import 문을 사용하여 여러 .scss 파일을 하나의 파일에 가져와서, 최종적으로 하나의 큰 CSS 파일을 생성합니다.

이를 통해 개발 단계에서는 코드를 분할해 작업하고, 최종적으로는 하나의 CSS 파일로 HTTP 요청을 최소화할 수 있습니다.
```

```jsx
// main.scss
@import 'variables';
@import 'typography';
```

## Sass의 컴파일 과정

```jsx
Sass는 @import 문을 통해 가져온 분할 파일과 다른 .scss 파일을 하나의 CSS 파일로 컴파일합니다.

개발자 도구에서 확인할 때, 더 이상 가져온 파일들이 별도의 요청을 하지 않고 하나의 CSS 파일에 병합됩니다.

이로 인해 HTTP 요청 수가 줄어들고, 성능 최적화에도 도움이 됩니다.
```

# { Sass에서의 상속(Inheritance) }

```jsx
상속은 Sass에서 공통 규칙을 여러 선택자에서 쉽게 재사용할 수 있도록 돕는 강력한 기능입니다.

이를 통해 코드의 중복을 줄이고 유지보수를 쉽게 할 수 있습니다. 상속은 @extend 지시자를 사용하여 구현됩니다.
```

## 상속 전 코드

```jsx
.sass-introduction {
  border: 1px solid black;
  background-color: lightgray;
  padding: 20px;
  text-align: center;
  width: 80%;
  box-sizing: border-box;
  box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.1);
}

.sass-details {
  border: 1px solid black;
  background-color: lightgray;
  padding: 20px;
  text-align: center;
  width: 80%;
  box-sizing: border-box;
  margin: 20px 0;
}

@media (max-width: 768px) {
  .sass-introduction {
    width: 100%;
  }
  .sass-details {
    width: 100%;
  }
}
```

```jsx
문제점

.sass-introduction과 .sass-details는 많은 공통 속성을 갖고 있습니다.

이 속성들을 중복 작성해야 하는 불편함이 있습니다.

```

## 상속 후 코드

### Step 1: 공통 속성을 새로운 클래스에 모으기

```jsx
.sass-section {
  border: 1px solid black;
  background-color: lightgray;
  padding: 20px;
  text-align: center;
  width: 80%;
  box-sizing: border-box;
}

@media (max-width: 768px) {
  .sass-section {
    width: 100%;
  }
}
```

### Step 2: 개별 클래스에서 상속 사용

```jsx
.sass-introduction {
  @extend .sass-section;
  box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.1);
}

.sass-details {
  @extend .sass-section;
  margin: 20px 0;
}
```

```jsx
.sass-section 클래스에 공통 스타일을 모았습니다.

@extend 지시자를 사용해 **.sass-introduction**과 **.sass-details**에서 공통 스타일을 상속받습니다.

각 클래스는 자신만의 고유 속성(box-shadow, margin)만을 따로 정의합니다.

미디어 쿼리도 공통 부분은 .sass-section에 넣어줍니다.

* 원래 사용하면 한 클래스에 묶어두고 html 에서 사용하는 방법도 있지만 이는 html 에 클래스 양을 증가시키기 때문에

	이 방법이 더 좋다
```

# { Sass의 믹스인(Mixin) }

```jsx
*믹스인(Mixin)**은 재사용 가능한 코드 조각을 만들어서 코드의 중복을 줄이고

유지보수를 쉽게 할 수 있도록 도와주는 Sass의 강력한 기능입니다.

주로 반복적으로 사용되는 스타일을 믹스인으로 만들어 여러 곳에서 간편하게 사용할 수 있습니다.
```

## 믹스인 기본 사용 예제

## 예시 1: 벤더 접두어를 사용하는 `display: flex` 믹스인

### 사용전

```jsx
.container {
  display: -webkit-flex;
  display: -ms-flexbox;
  display: flex;
}

.documentation-links {
  display: -webkit-flex;
  display: -ms-flexbox;
  display: flex;
}

* 동일한 코드가 여러 곳에서 반복됨.
```

### 믹스인으로 코드 간소화:

### Step 1: `@mixin`을 사용해 벤더 접두어가 포함된 `display: flex`를 정의

```jsx
@mixin display-flex {
  display: -webkit-flex;
  display: -ms-flexbox;
  display: flex;
}
```

### Step 2: `@include`로 믹스인 사용

```jsx
.container {
  @include display-flex;
}

.documentation-links {
  @include display-flex;
}
```

## 인수를 받는 믹스인

```jsx
믹스인은 **인수(Arguments)**를 받을 수 있어 동적으로 값을 조정할 수 있습니다.
```

### **Step 1: 기본 미디어 쿼리 믹스인 작성**

```
@mixin media-min-width($width) {
  @media (min-width: $width) {
    @content;
  }
}
```

```jsx
@mixin:

		재사용할 코드를 정의하는 지시어입니다.

media-min-width($width):

		$width는 사용자가 나중에 값을 넘겨줄 변수입니다. 이 값은 min-width 미디어 쿼리에 사용됩니다.

@media (min-width: $width):

		실제로 미디어 쿼리를 생성할 때, $width에 사용자가 넘겨준 값이 들어갑니다.

		예를 들어, 40rem을 넘기면 @media (min-width: 40rem)처럼 작동합니다.

@content:

		이 부분은 믹스인을 사용할 때 그 안에 작성하는 스타일 블록이 동적으로 삽입되는 위치입니다.
```

### Step 2: 믹스인 호출 시 인수 전달

```jsx
.container {
  @include media-min-width(40rem) {
    font-size: 1.5rem;
  }
}

.documentation-links {
  @include media-min-width(40rem) {
    font-size: 1.2rem;
  }
}
```

```jsx
@include media-min-width(40rem):

		40rem을 인수로 전달하여 @media (min-width: 40rem) 미디어 쿼리를 생성합니다.

{ font-size: 1.5rem; }:

		미디어 쿼리 안에서 적용될 스타일을 작성합니다. 이 부분이 @content 자리에 동적으로 들어갑니다.

		* 한마디로 이 부분은 그대로 들어간다는거
```

# { 앰퍼샌드(`&`) 연산자 }

```jsx
앰퍼샌드(&)는 현재 선택자에 대해 추가적인 상태를 표현하거나, 선택자 자체를 연결할 때 사용합니다.

의사 선택자(pseudo-selector)와 같은 특정 상태를 중첩하여 작성할 수 있습니다.
```

```jsx
.documentation-links {
  color: blue;

  &:hover {
    color: darkblue;
  }

  &:active {
    color: red;
  }
}
```
