# 기본 명령어

```jsx
파일 및 디렉터리 관리

ls: 디렉터리 목록을 표시 // ls -l

cd: 디렉터리 변경 // cd /home/user/Documents

pwd: 현재 작업 디렉터리 경로 표시 // pwd

mkdir: 새 디렉터리 생성 // mkdir new_folder

rmdir: 비어있는 디렉터리 삭제 // rmdir empty_folder

rm: 파일 및 디렉터리 삭제 (rm -r은 디렉터리를 재귀적으로 삭제) // rm file.txt // rm -r folder_to_delete

cp: 파일 및 디렉터리 복사 // cp source.txt destination.txt // cp -r source_folder destination_folder

mv: 파일 및 디렉터리 이동 또는 이름 변경 // mv oldname.txt newname.txt // mv file.txt /new/location/

touch: 빈 파일 생성 또는 파일의 접근 시간을 업데이트 // touch newfile.txt

find: 파일 및 디렉터리를 검색 // find /home/user -name "*.txt"

파일 내용 조회 및 조작

cat: 파일 내용 출력 // cat file.txt

more, less: 파일 내용 페이지 단위로 출력 // less file.txt

head: 파일의 처음 몇 줄 출력 // head -n 10 file.txt

tail: 파일의 마지막 몇 줄 출력 (tail -f은 실시간으로 파일 변경 사항 출력) // tail -n 10 file.txt // tail -f logfile.txt

grep: 텍스트 검색 // grep "search_term" file.txt

awk: 텍스트 패턴 검색 및 처리 // awk '{print $1}' file.txt

sed: 스트림 편집기, 텍스트 변환 // sed 's/old/new/g' file.txt

파일 권한 관리

chmod: 파일 권한 변경 // chmod 755 script.sh

chown: 파일 소유자 변경 // chown user:group file.txt

chgrp: 파일 그룹 변경 // chgrp newgroup file.txt

시스템 정보 조회

uname: 시스템 정보 표시 // uname -a

df: 디스크 사용량 표시 // df -h

du: 디스크 사용량 측정 // du -sh /home/user

top: 실시간 시스템 상태 및 프로세스 표시 // top

ps: 현재 실행 중인 프로세스 표시 // ps aux

free: 메모리 사용량 표시 // free -h

uptime: 시스템 가동 시간 표시 // uptime

네트워크 관련

ping: 네트워크 연결 확인 // ping google.com

ifconfig 또는 ip: 네트워크 인터페이스 설정 및 표시 // ifconfig  // ip addr show

netstat: 네트워크 연결 및 포트 정보 표시 // netstat -tuln

ssh: 원격 서버 접속 // ssh user@remote_server

scp: 원격 서버 간 파일 복사 // scp localfile.txt user@remote_server:/remote/path/

wget, curl: 웹에서 파일 다운로드 // wget http://example.com/file.zip // curl -O http://example.com/file.zip

패키지 관리

apt-get, apt, dpkg: Debian 계열의 패키지 관리 // sudo apt-get update // sudo apt-get install package_name

yum, dnf, rpm: Red Hat 계열의 패키지 관리
```
