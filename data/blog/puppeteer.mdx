# { Puppeteer 개념 & 시작하기 }

```jsx
Puppeteer는 Node.js 환경에서 Google Chrome 또는 Chromium 브라우저를 제어하는 라이브러리입니다.

브라우저를 프로그램적으로 제어하여 웹 스크래핑, 테스트 자동화, PDF 생성 등의 작업을 할 수 있습니다.
```

## 코드 분석과 문법 설명

### 1. **모듈 임포트**

```jsx
import puppeteer from 'puppeteer'
```

```jsx
Puppeteer는 Node.js 모듈이므로 import를 사용하여 불러옵니다.

import 문법은 ES6에서 등장한 모듈 시스템입니다.

Puppeteer를 설치하려면 npm install puppeteer 명령어를 사용해야 합니다.
```

### 2. **비동기 함수 실행**

```jsx
(async () => {
  ...
})();
```

```jsx
IIFE(Immediately Invoked Function Expression) 형식으로 작성된 비동기 함수입니다.

Puppeteer의 대부분 메서드는 Promise를 반환하므로, 비동기로 작성하고 await 키워드를 사용합니다.

async/await:

		async 함수는 항상 Promise를 반환합니다.

		await는 비동기 작업이 완료될 때까지 기다리게 합니다.
```

### 3. **브라우저 시작 및 페이지 생성**

```jsx
const browser = await puppeteer.launch()
const page = await browser.newPage()
```

```jsx
puppeteer.launch(): 브라우저를 새로 시작합니다.

		기본적으로 헤드리스(Headless) 모드로 실행됩니다. UI 없이 동작합니다.

		UI가 필요하면 { headless: false } 옵션을 추가하세요.

browser.newPage(): 새 브라우저 탭을 엽니다.
```

### 4. **페이지 이동**

```jsx
await page.goto('https://developer.chrome.com/')
```

```jsx
page.goto(url): 지정한 URL로 페이지를 이동합니다.

		페이지가 로드될 때까지 대기합니다.

		옵션으로 로드 방식이나 타임아웃을 설정할 수 있습니다.
```

### 5. **화면 크기 설정**

```jsx
await page.setViewport({ width: 1080, height: 1024 })
```

```jsx
setViewport(): 화면 크기와 해상도를 설정합니다.

			웹사이트가 반응형인 경우 특정 화면 크기로 테스트할 때 유용합니다.
```

### 6. **텍스트 입력**

```jsx
await page.type('.devsite-search-field', 'automate beyond recorder')
```

```jsx
page.type(selector, text): 선택한 입력 필드에 텍스트를 입력합니다.

		첫 번째 인수는 CSS 선택자(selector)입니다.

		두 번째 인수는 입력할 문자열입니다.
```

### 7. **요소 대기 및 클릭**

```jsx
const searchResultSelector = '.devsite-result-item-link'
await page.waitForSelector(searchResultSelector)
await page.click(searchResultSelector)
```

```jsx
waitForSelector(selector): 지정된 선택자가 DOM에 나타날 때까지 기다립니다.

		페이지 로딩 상태를 확인할 때 자주 사용됩니다.

page.click(selector): 선택한 요소를 클릭합니다.
```

### 8. **요소의 텍스트 추출**

```jsx
const textSelector = await page.waitForSelector('text/Customize and automate')
const fullTitle = await textSelector?.evaluate((el) => el.textContent)
```

```jsx
waitForSelector(): 특정 텍스트가 포함된 요소를 기다립니다.

		'text/...' 형식은 Puppeteer에서 텍스트를 기준으로 요소를 선택하는 방식입니다.

evaluate(): 선택한 요소에 대해 JavaScript 코드를 실행합니다.

		el.textContent는 HTML 요소의 텍스트 내용을 가져옵니다.
```

### 9. **브라우저 닫기**

```jsx
await browser.close()
```

```jsx
browser.close(): 모든 작업이 끝나면 브라우저를 종료합니다.
```

### 전체 코드

```jsx
// Puppeteer 라이브러리를 가져옵니다. Puppeteer는 Chrome 또는 Chromium 브라우저를 제어하기 위한 Node.js 라이브러리입니다.
import puppeteer from 'puppeteer'
;(async () => {
  // 브라우저를 실행합니다. puppeteer.launch()는 브라우저 인스턴스를 반환합니다.
  // 기본적으로 headless 모드(화면 없이 백그라운드 실행)로 브라우저가 실행됩니다.
  const browser = await puppeteer.launch()

  // 새 탭(페이지)을 엽니다. 브라우저 안에서 여러 개의 페이지를 열 수 있습니다.
  const page = await browser.newPage()

  // 지정된 URL로 페이지를 로드합니다.
  // puppeteer는 기본적으로 페이지가 로드될 때까지 기다리며, 추가 옵션을 통해 대기 조건을 설정할 수 있습니다.
  await page.goto('https://developer.chrome.com/')

  // 페이지의 뷰포트(화면 크기)를 설정합니다.
  // 이 설정은 반응형 웹사이트 테스트 또는 특정 해상도로 작업할 때 유용합니다.
  await page.setViewport({ width: 1080, height: 1024 })

  // 검색 상자(CSS 선택자를 통해 선택)를 찾아 'automate beyond recorder'라는 텍스트를 입력합니다.
  // 이 작업은 사용자가 키보드를 통해 텍스트를 입력하는 것과 동일하게 동작합니다.
  await page.type('.devsite-search-field', 'automate beyond recorder')

  // 검색 결과 중 첫 번째 링크를 클릭하기 위해 먼저 해당 요소가 로드될 때까지 기다립니다.
  const searchResultSelector = '.devsite-result-item-link' // CSS 선택자로 검색 결과 항목을 지정합니다.
  await page.waitForSelector(searchResultSelector) // 해당 요소가 DOM에 나타날 때까지 대기합니다.
  await page.click(searchResultSelector) // 요소를 클릭합니다.

  // 제목이 포함된 특정 텍스트를 찾습니다.
  // Puppeteer는 CSS 선택자뿐만 아니라 텍스트 기반 선택도 지원합니다.
  const textSelector = await page.waitForSelector('text/Customize and automate') // 텍스트 내용으로 요소를 선택합니다.

  // 찾은 요소에서 텍스트 내용을 추출합니다.
  // evaluate()는 선택한 요소에 대해 브라우저 환경에서 실행되는 JavaScript 코드를 실행합니다.
  // 여기서는 textContent를 사용하여 요소의 텍스트 값을 가져옵니다.
  const fullTitle = await textSelector?.evaluate((el) => el.textContent)

  // 추출한 텍스트를 콘솔에 출력합니다. 여기서 `fullTitle` 변수에 블로그 포스트의 제목이 저장됩니다.
  console.log('The title of this blog post is "%s".', fullTitle)

  // 작업이 끝났으므로 브라우저를 종료합니다.
  await browser.close()
})()
```

# { XPath를 사용하는 방법 }

```jsx
Puppeteer에서 XPath를 사용하는 경우, page.$x() 메서드는 항상 배열을 반환합니다.

이는 XPath 쿼리가 여러 요소와 일치할 수 있기 때문입니다.

배열에서 원하는 요소를 선택하여 작업해야 하며, 이 방식은 Puppeteer의 설계에 따른 것입니다.
```

## XPath란?

```jsx
XPath는 XML 및 HTML 문서에서 특정 요소와 속성을 트리 구조로 탐색하기 위한 쿼리 언어입니다.

Puppeteer에서는 XPath를 사용하여 HTML DOM 요소를 찾습니다.
```

## XPath 문법 요약

```jsx
XPath는 요소를 찾기 위한 다양한 문법을 제공합니다. 주요 기능을 아래에 정리했습니다.

1. 기본 문법
		//: 루트 노드에서 시작하거나 모든 위치에서 요소를 찾음.

				예: //div는 모든 div 요소를 찾음.

		/: 직계 자식을 찾음.

				예: /html/body/div는 html > body > div를 찾음.

		.//: 현재 요소의 하위 트리를 탐색.

				예: .//span은 현재 요소 내부의 모든 span 요소를 찾음.

2. 속성 선택

		[@속성명="값"]: 특정 속성값을 가진 요소를 찾음.

				예: //input[@type="text"]는 type="text"인 모든 <input>을 찾음.


		[contains(@속성명, "값")]: 속성값에 특정 문자열이 포함된 요소를 찾음.

				예: //div[contains(@class, "active")].

3. 텍스트 기반 선택

		[text()="값"]: 특정 텍스트와 일치하는 요소를 찾음.

				예: //button[text()="Submit"]는 Submit 텍스트를 가진 버튼.


		[contains(text(), "값")]: 텍스트에 특정 문자열이 포함된 요소를 찾음.

				예: //p[contains(text(), "Hello")].

4. 위치 기반 선택

		[index]: 특정 위치의 요소를 선택.

				예: (//div)[1]는 첫 번째 div를 선택.


		last(): 마지막 요소를 선택.

				예: (//li)[last()].

5. 논리 연산자

		and, or: 여러 조건을 결합.

				예: //input[@type="text" and @name="username"].
```

## Puppeteer에서 XPath 사용 예제

### 1. 단일 요소 클릭

```jsx
XPath는 배열을 반환하지만, 단일 요소를 대상으로 작업하려면 첫 번째 요소를 선택합니다:
```

```jsx
const [button] = await page.$x('//button[text()="Click Me"]')
if (button) {
  await button.click() // 요소 클릭
}
```

### 2. 여러 요소 반복 처리

```jsx
여러 요소를 대상으로 작업할 때는 배열을 순회합니다:
```

```jsx
const items = await page.$x('//div[@class="item"]')
for (const item of items) {
  const text = await item.evaluate((el) => el.textContent) // 텍스트 추출
  console.log('아이템 텍스트:', text)
}
```

### 3. 속성과 텍스트를 함께 사용

```jsx
속성 조건과 텍스트 조건을 조합하여 요소를 찾습니다:
```

```jsx
const [link] = await page.$x('//a[contains(@href, "example") and text()="Learn More"]')
if (link) {
  await link.click()
}
```

### 4. 하위 요소 탐색

```jsx
XPath로 찾은 부모 요소에서 다시 하위 요소를 찾을 수 있습니다:
```

```jsx
const [parent] = await page.$x('//div[@id="parent"]')
if (parent) {
  const [child] = await parent.$x('.//span[@class="child"]')
  if (child) {
    await child.click() // 하위 요소 클릭
  }
}
```

### 5. 요소의 속성 값 가져오기

```jsx
evaluate를 사용하여 요소의 속성을 가져옵니다:
```

```jsx
const [link] = await page.$x('//a[contains(@href, "example")]')
if (link) {
  const href = await link.evaluate((el) => el.getAttribute('href')) // href 속성 가져오기
  console.log('링크 URL:', href)
}
```

## XPath 디버깅 팁

### 1. Chrome 개발자 도구에서 XPath 테스트

```jsx
$x 명령 사용:

		콘솔에서 document.evaluate 대신 $x를 사용해 XPath 결과를 확인합니다.

		$x('//button[text()="Click Me"]')

결과가 반환되면 Puppeteer에서도 동일한 XPath를 사용할 수 있습니다.
```

### 2. XPath 디버깅 도구

```jsx
Browser DevTools:

		Elements 탭에서 Ctrl+F를 눌러 XPath를 테스트합니다.
```

## 주요 포인트

```jsx
1. Puppeteer의 page.$x()는 항상 배열을 반환합니다.

2. 배열에서 요소를 선택하거나 순회하며 작업합니다.

3. XPath는 텍스트, 속성, 위치 등을 조합하여 매우 유연한 선택이 가능합니다.

4. Puppeteer와 함께 사용할 때는 evaluate로 속성을 추출하거나 동작을 수행합니다.
```

```jsx
const puppeteer = require('puppeteer')

;(async () => {
  const browser = await puppeteer.launch({ headless: false })
  const page = await browser.newPage()

  // 특정 URL로 이동
  await page.goto('https://example.com')

  // XPath를 사용하여 요소 찾기
  const [element] = await page.$x('//button[text()="Click Me"]')
  if (element) {
    // 요소를 클릭
    await element.click()
    console.log('클릭 성공!')
  } else {
    console.log('요소를 찾을 수 없습니다.')
  }

  await browser.close()
})()
```
