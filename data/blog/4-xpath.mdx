# XPath Syntax, Functions and Operators

## **1. XPath 소개 및 개요**

### XPath란?

```python
XPath는 XML Path Language의 약자

XML 문서에서 노드를 선택하는 쿼리 언어이다.

HTML 페이지에서도 요소를 선택하는 데 사용할 수 있다.
```

### **CSS 선택자와의 비교**

```python
CSS 선택자(Cascading Style Sheet)는 HTML 웹 페이지의 스타일을 지정하는 언어이다.

XPath와 CSS 선택자는 문법에서 일부 유사점이 있지만, 본 과정에서는 주로 XPath를 사용하여 요소를 선택한다.

XPath는 단순하고 직관적이기 때문에 주로 사용된다.
```

## **2. XPath 기본 문법**

### **기본 선택 방법**

```python
XPath로 요소를 선택하는 가장 기본적인 방법은 // (더블 슬래시) 뒤에 요소 이름을 쓰는 것

예: HTML 페이지에서 모든 H1 요소를 선택하려면 //H1을 사용
```

## **3. 위치 기반 요소 선택**

```python
요소의 위치를 기반으로 선택하려면 대괄호 []를 사용한다

페이지에 두 개의 H1 태그가 있다고 가정하면, 첫 번째 H1 태그를 선택하려면 //H1[1]을 사용하고,

두 번째 H1 태그를 선택하려면 //H1[2]을 사용한다.
```

## **4. 속성 기반 요소 선택**

```python
속성을 기반으로 요소를 선택하려면 대괄호 [] 안에 속성 이름을 쓴다.

표준 XPath 표현식은 //로 시작하고 태그 이름 뒤에 대괄호와 @ 기호, 속성 이름을 쓴다.

그 다음에는 등호 =와 따옴표 "" 안에 속성 값을 쓴다.

class 속성이 header인 H1 태그를 선택하려면: //H1[@class="header"]
```

```python
<!DOCTYPE html>
<html>
<head>
    <title>Example Page</title>
</head>
<body>
    <h1 class="header">First Heading</h1>
    <h1 class="header">Second Heading</h1>
</body>
</html>
```

## **5. 함수 사용**

```python
특정 값을 찾기 위해 함수를 사용할 수 있다.

starts-with 함수는 텍스트의 시작 부분을 검색하고,

contains 함수는 요소 내부의 텍스트를 검색한다.
```

```python
<!DOCTYPE html>
<html>
<head>
    <title>Example Page</title>
</head>
<body>
    <h1 class="header">First Heading</h1>
    <h1 class="header-second">Second Heading</h1>
</body>
</html>
```

```python
contains 함수를 사용하여 header를 포함하는 class 속성의 H1 태그를 선택하려면: //H1[contains(@class, "header")]
```

## **6. 논리 연산자 사용**

```python
XPath 표현식에서 논리 연산자 and 또는 or을 사용할 수 있다.

연산자는 대괄호 [] 안에 넣고, 각 XPath 표현식에 괄호 ()를 포함해야 한다.
```

```python
<!DOCTYPE html>
<html>
<head>
    <title>Example Page</title>
</head>
<body>
    <h1 class="header">First Heading</h1>
    <h1 class="header-second" id="main">Second Heading</h1>
</body>
</html>
```

```python
class 속성이 header이거나 id 속성이 main인 H1 태그를 선택하려면: //H1[@class="header" or @id="main"]
```

## 추가 예제

### **상황:** 특정 부모 요소의 하위 요소들을 선택하고 싶을 때

```python
div 클래스가 container인 요소 내부의 모든 p 요소를 선택하려면: //div[@class="container"]/p

첫 번째 p 요소를 선택하려면: //div[@class="container"]/p[1]
```

### **상황:** 특정 텍스트를 포함한 요소를 선택하고 싶을 때

```python
Welcome 텍스트를 포함하는 모든 요소를 선택하려면: //*[contains(text(), "Welcome")]

Welcome 텍스트로 시작하는 모든 요소를 선택하려면: //*[starts-with(text(), "Welcome")]
```

### **상황:** 특정 속성 값을 포함하는 요소를 선택하고 싶을 때

```python
src 속성이 jpg로 끝나는 모든 img 요소를 선택하려면: //img[contains(@src, ".jpg")]

src 속성이 image로 시작하는 모든 img 요소를 선택하려면: //img[starts-with(@src, "image")]
```

### **상황:** 특정 부모 요소의 자식 요소를 선택하고 싶을 때

```python
모든 ul 요소의 li 자식 요소를 선택하려면: //ul/li

첫 번째 ol 요소의 첫 번째 li 자식 요소를 선택하려면: //ol/li[1]
```

### **상황:** 여러 조건을 만족하는 요소를 선택하고 싶을 때

```python
class가 content이고 id가 main-content인 요소를 선택하려면: //div[@class="content" and @id="main-content"]

class가 content이거나 id가 sidebar-content인 요소를 선택하려면: //div[@class="content" or @id="sidebar-content"]
```

### **상황:** 인덱스 범위 내의 요소들을 선택하고 싶을 때

```python
첫 번째부터 세 번째까지의 li 요소를 선택하려면: //ul/li[position() <= 3]

세 번째 이후의 li 요소를 선택하려면: //ul/li[position() > 3]
```

# XPath 의 특수문자 ( Special Characters and Syntax )

## **XPath의 특수 문자들**

### **1. 단일 슬래시 (`/`)**

```python
설명: 단일 슬래시는 왼쪽의 노드 집합에서 자식 노드를 선택
```

```python
<!DOCTYPE html>
<html>
<body>
    <div>
        <h1>Title</h1>
        <p>Paragraph</p>
    </div>
</body>
</html>
```

```python
//div/h1은 div의 자식인 h1 요소를 선택
```

### **2. 이중 슬래시 (`//`)**

```python
설명: 이중 슬래시는 문서 내의 어느 레벨에 있는 매칭 노드를 선택
```

```python
<!DOCTYPE html>
<html>
<body>
    <div>
        <h1>Title</h1>
        <p>Paragraph</p>
    </div>
</body>
</html>
```

```python
//h1은 문서 내의 모든 h1 요소를 선택
```

### **3. 텍스트 노드 (`text()`)**

```python
설명: 텍스트 노드를 선택
```

```python
<!DOCTYPE html>
<html>
<body>
    <h1>Title</h1>
</body>
</html>
```

```python
//h1/text()은 h1 요소의 텍스트를 선택합니다
```


```python

```

```python

<html>
<body>
    <div class="content">Content</div>
    <div class="footer">Footer</div>
</body>
</html>
```

```python
//div[@class="content" or @class="footer"]은 class 속성이 content 또는 footer인 모든 div 요소를 선택
```
