```jsx
1. 문법
선택자 {
	속성명 : 값;
	속성명 : 값2;
}

2. 선택자 (Selector)
	1) *                : 전체 선택자, 모든 Element를 선택
	2) 태그명           : 태그 선택자
	3) #id명            : Id 선택자
	4) .클래스명        : Class 선택자
	5) 선택자A > 선택자B : 자식 선택자, A선택요소의 직계자손 B
	6) 선택자A 선택자B   : 후손 선택자, A선택요소의 모든 B

3. 가상 클래스(:pseudo-class)
	1) 앵커(a) 가상 클래스
			a. a:link    : 아직 방문하지 않은 링크
			b. a:visited : 방문한 링크
			c. a:hover   : 마우스의 커서를 올렸을 때
			d. a:active  : 요소를 누르고 있을 때
			e. a:focus   : 포커스가 생겼을 때
			- hover, active, focus는 a 태그 뿐만 아니라 다른 태그에서도 사용가능

	2) 순서 가상 클래스
			a. :first-child      : 요소 들 중 첫번째 요소 선택
			b. :last-child       : 요소 들 중 마지막 요소 선택
			c. :nth-child(번호)   : 번호에 해당하는 요소 선택 , 시작번호는 1번
				 :nth-child(odd)   : 홀수
				 :nth-child(even)  : 짝수

	3) 타입 순서 가상 클래스
		a.  : nth-of-type(번호) : 같은 타입들 중 번호에 해당하는 요소 선택

4. 가상 요소
		- 이미지나, text, 그라데이션 추가 할 목적
		a.  ::before            : 선택한 요소 앞에 가상의 요소를 추가
		b.  ::after             : 선택한 요소 뒤에 가상의 요소를 추가
				p::before {
						content : "Text";
				}

				p::after {
						content : url("image 경로")
				}
```

### 4. display

```jsx

- 모든 태그는 display 속성을 가지고 있음

1. inline
	- 가로와 높이를 수치를 가지지 못함
	- 크기가 Contents의 내용의 크기 만큼 차지
	- Margin 적용 안됨

2. block
	- 가로 와 높이의 수치를 조정
	- 크기가 조정 가능하지만 가상의 크기가 있음
	- 가상의 크기는 브라우저의 전체 넓이와 같음

3. inline-block
	- inline의 특성과 block의 특성을 합친것
	- 가상의 넓이를 가지지 않음
	- width, height 사용 가능

4. none
	- 화면에 표시 되지 않음, 자리도 차지 하지 않음

```

### 11. Flex

```jsx
- Flex Box
- float 대신 layout 만들 때 사용

- flex 속성은 부모에 적용하는 속성, 자식에게 적용하는 속성
- 부모는 Container, 자식은 item 이라 함

1. Container
	 **1) display:flex(inline-flex)    : 자식 태그들을 flex로 적용**

	 **2) flex-direction               : item들의 배치 방향 지정**
			a. row                       : item들을 가로로 배치
			b. row-reverse               : item들을 역순으로 가로 배치
			c. column                    : item들을 세로로 배치
			b. column-reverse            : item들을 역순으로 세로 배치

	 **3) flex-wrap                    : item들을 Container가 한줄에 담을 수 있는 공간이 없을 때**
			a. nowrap                    : Container 바깥으로 표시
			b. wrap                      : 줄바꿈을 해서 Container 영역 내에서 밑으로 내려욤
			c. wrap-reverse              : 줄바꿈을 해서 Container 영역 내에서 역순으로 배치

	 **4) justify-content              : item들의 정렬(수평 정렬)**
			a. flex-start                : Row일 때는 왼쪽, Column일 때는 위에서 시작
			b. flex-end                  : Row일 때는 오른쪽, Column일 때는 바닥에서 시작
		  c. center                    : item들을 중앙 정렬
			d. space-between             : 양쪽 끝은 벽에 붙이고 item들 사이는 동일한 간격을 가짐
			e. space-around              : item들 사이에 균일한 간격을 각자 가지고 배치 양쪽 끝은 한번만 적용
			f. space-evenly              : item들과 양 끝에 동일한 간격을 적용

	 **5) align-items                  : item들을 정렬(수직 정렬)**
			a. stretch                   : item들의 높이가 수직 방향으로 늘어 남
			b. flex-start                : row일 때는 top기준 정렬, column일 left 기준 정렬
			c. flex-end                  : row일 때는 bottom기준 정렬, column일 right 기준 정렬
			d. center                    : 가운데 정렬
			e. baseline                  : 글자의 baseline 기준으로 정렬

	 **6) align-content                : item들이 2줄이상 배치 될때 수직방향 정렬**
			a, stretch                   : item의 높이가 수직방향으로 늘어남
			b. flex-start                : row일 때는 top기준 정렬, column일 left 기준 정렬
			c. flex-end                  : row일 때는 bottom기준 정렬, column일 right 기준 정렬
			d. center                    : 가운데 정렬
			e. space-between             : 양쪽 끝은 벽에 붙이고 item들 사이는 동일한 간격을 가짐
			f. space-around              : item들 사이에 균일한 간격을 각자 가지고 배치 양쪽 끝은 한번만 적용
			g. space-evenly              : item들과 양 끝에 동일한 간격을 적용

2. item

- item라도 자기 자신이 Container가 될 수 있음
```
