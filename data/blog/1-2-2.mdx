## **BeautifulSoup**

```python
장점:

쉬운 사용법: Python 초보자에게 적합한 간단한 문법.

간단한 설정: requests 라이브러리와 함께 사용하여 설치 및 설정이 간단.

HTML 및 XML 파싱: 정적 웹 페이지에서 데이터를 추출하는 데 효과적.

단점:

JavaScript 지원 부족: JavaScript를 통해 동적으로 생성되는 콘텐츠는 지원하지 않음.

속도: 비동기 처리를 지원하지 않아서 대규모 데이터 스크래핑에 비효율적.

적합한 상황:

정적 웹 페이지: JavaScript 없이 HTML만으로 구성된 웹 페이지.

소규모 프로젝트: 간단한 데이터 추출 작업.
```

## **Selenium**

```python
장점:

동적 콘텐츠 처리: JavaScript 기반의 동적 웹사이트에서도 동작.

사용의 용이성: 비교적 배우기 쉬우며, 웹 페이지 렌더링을 통해 정확한 데이터를 가져올 수 있음.

브라우저 자동화: 웹 애플리케이션의 테스트 자동화에도 사용 가능.

단점:

속도: 전체 웹 페이지를 로드하고 렌더링하므로 느림.

자원 소모: 메모리와 CPU 사용량이 많음.

적합한 상황:

동적 웹 페이지: JavaScript로 콘텐츠가 동적으로 로드되는 웹 페이지.

작은 규모의 데이터 수집: 성능이 크게 중요하지 않은 소규모 프로젝트.
```

## **Scrapy**

```python
장점:

고성능: 비동기 처리를 통해 빠르고 효율적으로 데이터를 수집.

강력한 기능: 데이터베이스 저장, 사용자 지정 파이프라인 등을 지원.

확장성: 대규모 프로젝트에 적합한 프레임워크.

단점:

복잡한 설정: 초기 설정과 학습 곡선이 상대적으로 높음.

추가적인 설정 필요: 동적 웹 페이지 스크래핑 시 Selenium과의 통합 필요.

적합한 상황:

대규모 프로젝트: 대량의 데이터를 빠르게 수집하고 효율적으로 처리해야 하는 경우.

복잡한 데이터 처리: 데이터 파이프라인 및 저장소와의 통합이 필요한 경우.
```

# 웹 스크래핑을 위한 Python 기본 사항

## **1. 리스트**

```python
리스트는 Python에서 여러 항목을 단일 변수에 저장할 수 있는 자료형입니다.
```

```python
# 주(State) 리스트 생성
states = ["California", "Texas", "Florida", "New York"]

# 리스트 출력
print(states)
```

## **2. 인덱싱**

```python
리스트의 각 항목은 인덱스를 가지고 있으며, 인덱스를 사용하여 항목에 접근할 수 있습니다. Python은 0 기반 인덱싱을 사용합니다.
```

```python
# 첫 번째 요소 출력
print(states[0])  # California

# 네 번째 요소 출력
print(states[3])  # New York

# 마지막 요소 출력 (음수 인덱스 사용)
print(states[-1])  # New York
```

## **3. for 루프**

```python
리스트의 각 항목을 반복(iterate)하여 작업을 수행할 수 있습니다.
```

```python
# 리스트의 각 요소를 반복하여 출력
for state in states:
    print(state)
```

## **4. if 문**

```python
조건문을 사용하여 특정 조건에 맞는 항목만 선택할 수 있습니다.
```

```python
# 리스트에서 특정 주만 출력
for state in states:
    if state == "Florida":
        print(state)  # Florida
```

## **5. 웹 스크래핑과 리스트의 활용**

```python
웹 스크래핑을 할 때, 긁어온 데이터를 리스트에 저장하고 반복문을 통해 데이터를 처리합니다.

예를 들어, 웹 페이지에서 여러 요소를 긁어온 후 해당 요소의 텍스트를 추출하는 경우입니다.
```

```python
# 웹 스크래핑으로 긁어온 데이터 (예시)
scraped_data = ["Element1", "Element2", "Element3"]

# 데이터 처리 예제
for element in scraped_data:
    # 각 요소의 텍스트를 추출 (가정)
    element_text = element  # 실제 스크래핑 코드에서는 element.text와 같은 방식으로 텍스트 추출
    print(element_text)
```

## Python에서 데이터를 파일로 내보내는 두 가지 방법

### **`with open as` 패턴을 사용한 데이터 내보내기**

```python
# 파일에 데이터를 쓰기
with open("test.txt", "w") as file:
    file.write("I have successfully scraped the data.")
```

```python
**with open as 패턴**

open 함수는 파일을 열 때 사용하는 함수

이 함수는 파일을 읽거나 쓰기 모드로 열 수 있으며, 파일 작업이 끝나면 파일을 닫아야 한다.

( with open as 패턴을 사용하면 자동으로 파일을 닫아주므로 파일 닫기를 명시적으로 작성할 필요가 없다. )

파일 모드 (mode)

파일 모드는 파일을 어떻게 열고 사용할지를 결정한다. 자주 사용하는 모드들은 다음과 같다:

'r': 읽기 전용 모드 (기본값). 파일이 존재해야 합니다.
'w': 쓰기 전용 모드. 파일이 존재하면 내용을 덮어쓰고, 존재하지 않으면 새로 생성합니다.
'a': 추가 모드. 파일이 존재하면 끝에 내용을 추가하고, 존재하지 않으면 새로 생성합니다.
'b': 바이너리 모드. 텍스트 파일이 아닌 파일을 처리할 때 사용합니다.
't': 텍스트 모드. 기본값입니다.
```

```python
예제: 텍스트 파일 쓰기

# 파일을 쓰기 모드로 열고, 파일 객체를 file이라는 이름으로 사용
with open("test.txt", "w") as file:
    # 파일에 문자열 쓰기
    file.write("I have successfully scraped the data.")


# open("test.txt", "w"):

# "test.txt": 파일 이름. 현재 작업 디렉토리에 생성됩니다.

# "w": 쓰기 모드로 파일을 엽니다. 파일이 존재하지 않으면 새로 생성하고, 존재하면 내용을 덮어씁니다.

# as file: file이라는 이름으로 파일 객체를 사용합니다. 이제 file을 통해 파일에 접근하고 조작할 수 있습니다.

# file.write("I have successfully scraped the data."):

# write 메서드를 사용해 파일에 문자열을 씁니다.

#with 블록을 벗어나면 파일이 자동으로 닫힙니다.

예제: 추가 모드로 파일에 데이터 추가하기

# 파일을 추가 모드로 열고, 파일 객체를 file이라는 이름으로 사용
with open("test.txt", "a") as file:
    # 파일 끝에 문자열 추가
    file.write("\nAdding another line to the file.")


예제: 파일 읽기 예제

# 파일을 읽기 모드로 열고, 파일 객체를 file이라는 이름으로 사용
with open("test.txt", "r") as file:
    # 파일 내용을 읽어와 출력
    content = file.read()
    print(content)
```

# **BeautifulSoup의 기본 개념** ( Beautiful Soup Basics )

## **BeautifulSoup 소개**

```python
BeautifulSoup은 웹 스크래핑에 사용되는 가장 쉬운 파이썬 라이브러리이다.

HTML 및 XML 파일에서 데이터를 추출할 수 있다.

그러나 BeautifulSoup을 사용하려면 requests 라이브러리와 같은 의존성이 필요하다.

이러한 의존성 때문에 프로젝트 간에 코드를 전송하는 것이 복잡할 수 있다.

그래서 큰 웹 스크래핑 프로젝트에서는 BeautifulSoup이 좋은 선택이 아닐 수 있다.
```

## **필수 라이브러리 가져오기**

```python
웹사이트를 BeautifulSoup으로 스크래핑하려면 먼저 두 가지 라이브러리를 가져와야 한다.

from bs4 import BeautifulSoup
import requests
```

## **웹사이트 스크래핑 단계**

### **1. 페이지 가져오기**

```python
페이지를 가져오려면 requests.get 메서드를 사용한다.

# 예제: Google 홈페이지 가져오기
result = requests.get("https://www.google.com")
```

### **2. 페이지 내용 가져오기**

```python
웹사이트의 HTML 코드를 가져오려면 result.text를 사용

# HTML 코드 가져오기
page_content = result.text
print(page_content)
```

### **3. Soup 객체 생성하기**

```python
BeautifulSoup을 사용하여 HTML 내용을 파싱하고 Soup 객체를 생성

# BeautifulSoup을 사용하여 HTML 내용을 파싱하고 Soup 객체 생성
soup = BeautifulSoup(page_content, 'lxml')
```

### **4. 요소 찾기**

```python
**ID로 요소 찾기**

특정 ID 값을 가진 요소를 찾기 위해 soup.find 메서드를 사용

# 예제: 특정 ID 값을 가진 요소 찾기
element_by_id = soup.find(id="example_id")

----------

**클래스 이름으로 요소 찾기**

특정 클래스 이름을 가진 요소를 찾기 위해 soup.find 메서드를 사용 첫 번째 인수는 태그 이름이고, 두 번째 인수는 클래스 이름

# 예제: 특정 클래스 이름을 가진 요소 찾기
element_by_class = soup.find('div', class_='example_class')

----------

**태그 이름으로 요소 찾기**

ID나 클래스 이름이 없는 요소도 태그 이름으로 찾을 수 있다.

# 예제: H1 태그를 가진 요소 찾기
h1_element = soup.find('h1')

```

### **5. 여러 요소 찾기**

```python
태그 이름으로 여러 요소를 찾기 위해 soup.find_all 메서드를 사용
```

```python
# 예제: 여러 H2 태그를 가진 요소 찾기
h2_elements = soup.find_all('h2')

# 찾은 요소를 리스트로 반환하고, 각 요소를 반복하여 작업
for element in h2_elements:
    print(element.text)
```

# 한 페이지 추출하기 ( How to Scrape a Single Page )

```python
한 페이지를 추출하는 예제를 최종적으로 만들어 봤다
```

```python
from bs4 import BeautifulSoup  # BeautifulSoup 라이브러리를 임포트하여 HTML 파싱 기능을 사용합니다.
import requests  # 웹사이트에 요청을 보내기 위해 requests 라이브러리를 임포트합니다.

# 타이타닉 영화 대본이 있는 웹사이트 URL을 변수에 저장합니다.
website = "https://subslikescript.com/movie/Titanic-120338"

# requests.get() 메서드를 사용하여 웹사이트에 HTTP GET 요청을 보냅니다.
result = requests.get(website)

# 웹사이트의 HTML 콘텐츠를 텍스트 형식으로 저장합니다.
content = result.text

# BeautifulSoup 객체를 생성하고 HTML 파서를 사용하여 HTML 콘텐츠를 파싱합니다.
soup = BeautifulSoup(content, 'lxml')

# HTML을 보기 좋게 출력할 수 있지만, 여기서는 주석 처리합니다.
# print(soup.prettify())

# 'article' 태그 중 클래스가 'main-article'인 첫 번째 요소를 찾아서 변수에 저장합니다.
box = soup.find('article', class_='main-article')

# 'box' 요소 내에서 첫 번째 'h1' 태그의 텍스트를 찾아서 변수에 저장합니다. 이는 영화의 제목입니다.
title = box.find('h1').get_text()

# 'box' 요소 내에서 클래스가 'full-script'인 'div' 태그의 텍스트를 찾아서 변수에 저장합니다.
# strip=True: 앞뒤의 공백을 제거합니다.
# separator=" ": 줄 바꿈을 공백으로 대체합니다.
transcript = box.find('div', class_='full-script').get_text(strip=True, separator=" ")

# 추출한 대본을 출력합니다.
print(transcript)

# 영화 제목을 파일 이름으로 사용하여 텍스트 파일을 쓰기 모드로 엽니다. UTF-8 인코딩을 사용합니다.
with open(f'{title}.txt', 'w', encoding='utf-8') as file:
    # 텍스트 파일에 대본을 씁니다.
    file.write(transcript)

```

## **soup.select_one('CSS 선택자') 을 사용하자**

```python
# find 방법
box_find = soup.find('article', class_='main-article')

# select_one 방법
box_select = soup.select_one('article.main-article')

위와 같은 방식으로 사용하기도 하지만

더 많이 사용되는 방식은 select_one 을 사용하는거다

soup.find는 더 단순한 구조나 특정 속성을 기반으로 검색할 때 유용하고

soup.select_one는 복잡한 CSS 선택자나 여러 조건을 조합하여 검색할 때 더 유용하다
```

## **strip=True**: 와 separator=" "

```python
**strip=True** 인수는 텍스트의 앞뒤에 있는 불필요한 공백을 제거한다. ( HTML 코드에는 종종 앞뒤에 공백이 포함되어 있다 )

**separator=' '** 인수는 줄 바꿈 문자('\n')를 공백으로 대체합니다. HTML 코드에서 여러 줄에 걸쳐 있는 텍스트를 한 줄로 정리할 때 유용

(데이터를 CSV 파일이나 데이터베이스에 저장할 때 줄 바꿈 문자가 포함된 텍스트는 처리가 복잡할 수 있다)
```

```python

    This is a new line of text.
    Another line.


변환

This is some text. This is a new line of text. Another line.
```
