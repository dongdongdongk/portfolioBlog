## CSS 박스 모델 이해

```css
박스 모델(Box Model):

	HTML의 모든 요소는 CSS에서 박스로 인식됩니다. 박스 모델은 요소의 콘텐츠,

	안쪽 여백(padding), 테두리(border), 바깥쪽 여백(margin)으로 구성됩니다.

콘텐츠(Content):

	요소 내부의 실제 내용이며, 파란색 영역으로 표시됩니다.

안쪽 여백(Padding):

	콘텐츠와 테두리 사이의 내부 공백입니다.

테두리(Border):

	요소를 감싸는 선으로, 안쪽 여백 바로 다음에 위치합니다.

바깥쪽 여백(Margin):

	요소와 다른 요소 사이의 외부 공백입니다. 이 공간은 요소의 일부가 아니며, 다른 요소와의 간격을 조정하는 역할을 합니다.
```

## 2. 여백 상쇄 (Margin Collapsing)

```css
여백 상쇄란?:

	두 요소가 인접해 있을 때, 서로의 바깥쪽 여백이 겹쳐지며 더 큰 여백 값만이 적용되는 현상을 말합니다.

	이는 CSS의 기본 동작 방식으로, 의도된 설계입니다.


예시:

	product-overview 섹션과 plans 섹션 내 h1 요소를 비교하여 여백 상쇄를 관찰했습니다.

	이 경우, 두 섹션 사이의 바깥쪽 여백이 상쇄되어 하나의 여백으로 통합되는 것을 볼 수 있습니다.


여백 상쇄 방지:

	여백 상쇄를 방지하려면 margin-top 또는 margin-bottom 속성을 조정하여 필요에 따라 개별 요소의 여백을 수동으로 설정해야 합니다.




* 상쇄가 크게 일어나는게 아니지만 그래도 정확하게 해주고 원인을 알고있자
```

## 여백 상쇄 추가 내용

```css
**여백 상쇄(Margin Collapsing)**는 CSS에서 발생하는 현상으로,

인접한 두 요소의 바깥쪽 여백이 합쳐져 더 큰 여백만이 적용되는 것입니다. 기본적인 사례는 다음과 같습니다:

인접 형제 요소:

	두 요소의 바깥쪽 여백이 겹쳐질 때, 더 큰 여백만 적용됩니다.

자식 요소가 있는 부모 요소:

	첫 번째 또는 마지막 자식 요소의 바깥쪽 여백이 부모 요소와 상쇄되어, 큰 여백이 부모 요소에 적용됩니다.

빈 요소:

	콘텐츠, 안쪽 여백, 테두리, 높이가 없는 요소의 상단과 하단 여백이 하나로 병합됩니다.

자세한 내용은 MDN 문서에서 확인할 수 있습니다.
```

## 1. Width 설정

```css
기본 설정:

	width를 100%로 설정하면 요소가 페이지의 전체 너비를 사용합니다.

	하지만 대부분의 블록 레벨 요소들은 기본적으로 100% 너비를 사용하므로, 눈에 보이는 차이는 없습니다.

비율 조정:

	width: 50%로 설정하면 해당 요소가 부모 요소의 절반 너비만 차지합니다.

절대값 설정: width:

	300px 등으로 절대값을 지정하면, 요소는 해당 픽셀 수만큼 너비를 가집니다.
```

## 2. Height 설정

```css
기본 동작:

	height를 100%로 설정해도 부모 요소의 크기에 따라 실제 높이가 결정됩니다.

	부모 요소가 높이를 지정하지 않으면 자식 요소의 높이는 최소화됩니다.

부모 요소 높이 설정:

	만약 자식 요소의 높이를 100%로 설정하려면, 부모 요소의 높이도 명시적으로 설정해야 합니다.

	예를 들어, main 요소의 높이를 500px로 지정하면 자식 요소들도 이에 맞춰 늘어납니다.

연쇄적 설정:

	최상위 html, body, 그리고 그 아래의 모든 부모 요소에 100% 높이를 설정하면 자식 요소의 높이도 100%로 적용됩니다.
```

```css
한마디로 쉽게 말하면 부모요서 html 요소를 100퍼센트로 해줘야 자식 요소의 높이도 100%로 적용된다

자식 요소는 부모 요소의 높이와 같아지려 합니다.

하지만 부모 요소가 높이를 정해주지 않으면 자식 요소의 높이는 제대로 적용되지 않아요.

그렇기 때문에 부모 요소가 100% 가 아니라면 자식 요소는 부모 요소에 맞춰서 조금만 늘어난다
```

# { 박스 모델과 `box-sizing` 이해하기 }

```css
width와 height는 기본적으로 콘텐츠만 설정합니다.

box-sizing: border-box를 사용하면 width와 height에 안쪽 여백과 테두리도 포함되어 박스 크기를 계산합니다.

이를 통해 박스 크기 계산이 더 직관적이고 예측 가능해집니다.
```

## 기본 동작

```css
**width와 height**는 기본적으로 콘텐츠 영역만 설정합니다. 즉, 안쪽 여백(padding)과 테두리(border)는 포함되지 않아요.

	예:

		width: 100%와 height: 522px는 콘텐츠의 너비와 높이를 설정합니다.

		여기에 안쪽 여백과 테두리가 추가로 더해져 실제 박스는 더 커질 수 있습니다.
```

## 박스 모델 예시

```css
만약 padding을 10px, border를 5px로 설정하고, margin을 10px로 설정하면:

	실제 박스 크기는:

		너비: width (100%) + padding (좌우 10px씩) + border (좌우 5px씩)

		높이: height (522px) + padding (위아래 10px씩) + border (위아래 5px씩)
```

## `box-sizing` 프로퍼티

```css
기본값 (content-box):

	width와 height는 콘텐츠만 설정합니다. 안쪽 여백과 테두리는 별도로 추가됩니다.

		이 경우 실제 박스 크기는 설정한 값보다 더 커질 수 있습니다.

border-box:

	width와 height에 안쪽 여백과 테두리가 포함됩니다.

	즉, 콘텐츠 영역, 안쪽 여백, 테두리까지 모두 포함된 박스 크기를 설정합니다. 바깥쪽 여백(margin)은 여전히 포함되지 않습니다.
```

## 적용 방법

```css
전체 페이지에 border-box 적용:

	모든 요소에 box-sizing: border-box를 적용하여, width와 height를 설정할 때 안쪽 여백과 테두리까지 포함하도록 합니다.

	이를 위해 * 선택자를 사용해 모든 요소에 적용합니다.

```

```css
* {
  box-sizing: border-box;
}
```

## 결과

```css
box-sizing: border-box를 사용하면:

	width와 height가 콘텐츠, 안쪽 여백, 테두리를 포함한 전체 박스 크기를 결정합니다.

	바깥쪽 여백(margin)은 여전히 별도로 적용됩니다.
```

# { 프로젝트에 헤더(header) 추가하기 }


### BEM 이란?

```css
Block (블록): 독립적인 구성 요소로, 예를 들어 header, button, menu 등이 블록입니다.

예시: .header, .button

Element (엘리먼트): 블록 내부의 구성 요소로, 블록의 일부이며 블록이 없으면 존재할 수 없습니다. 블록 이름과 두 개의 언더스코어(__)로 구분됩니다.

예시: .header__logo, .button__icon

Modifier (모디파이어): 블록이나 엘리먼트의 변형이나 상태를 정의합니다. 블록 또는 엘리먼트 이름 뒤에 두 개의 하이픈(--)을 붙여 사용합니다.

예시: .button--primary, .header__logo--large
```

## 2. **`display` 프로퍼티 활용**

```css
display 프로퍼티를 사용하여 요소의 표시 방식과 레이아웃을 조정할 수 있습니다.

블록과 인라인

	인라인 요소 (예: <a> 태그)는 필요한 너비만 차지하고, 수평으로 나란히 배치됩니다. 기본적으로는 display: inline입니다.

	블록 레벨 요소 (예: <li> 태그)는 전체 너비를 차지하며, 새 줄로 표시됩니다. 기본적으로는 display: block입니다.
```

```css
<a href="customers/index.html" style="display: block;">Customers</a>

이렇게 설정하면, a 태그가 블록 요소처럼 전체 너비를 차지하고, 다음 요소는 새 줄에서 렌더링됩니다.

<a href="customers/index.html" style="display: none;">Customers</a>

이렇게 설정하면, a 태그가 DOM에서 완전히 제거된 것처럼 보이지만, 실제로는 DOM 내에 존재하며 화면에 표시되지 않습니다.
```

### 인라인 블록

```css

  inline-block을 사용하면,
  인라인 요소처럼 나란히 배치되지만 블록 요소처럼 상하 여백과 패딩을 설정할 수 있습니다;
```

```css
.main-nav__item {
  display: inline-block; /* 나란히 배치되지만 상하 여백과 패딩을 설정할 수 있음 */
  margin-right: 16px; /* 항목 간 간격 추가 */
  padding: 10px; /* 안쪽 여백 추가 */
}
```

# { display: none (디스플레이: 없음)과 visibility: hidden (가시성: 숨김)의 차이 }

```css
display: none;

	요소를 문서 대열에서 제거합니다.

	요소는 보이지 않으며 공간도 차지하지 않습니다.

	DOM에서 제거되지 않지만, 화면에 표시되지 않고 공간을 차지하지 않습니다.

visibility: hidden;

	요소는 보이지 않지만 공간은 차지합니다.

	요소는 여전히 문서 대열에 존재하며, 다른 요소들이 그 공간을 차지하지 않습니다.

	DOM에서 제거되지 않으며, 숨겨진 상태로 남아있습니다.
```

## 문제:

```css
Header 안에 있는 브랜드 링크(div)와 내비게이션(nav)이 서로 다른 줄에 표시됩니다.

```

## 목표:

```css
이 두 요소를 같은 줄에 배치하려면 div와 nav를 인라인 블록 요소로 바꿔야 합니다.
```

```css
div 요소 선택 및 스타일 적용:

```

```css
}
```

### `nav` 요소 선택 및 스타일 적용:

```css
nav 요소 선택 및 스타일 적용:

	nav 요소에도 동일하게 display: inline-block;을 적용합니다.
```

```css
.main-nav {
  display: inline-block;
}

```

```css

  text-align: right;
  display: inline-block;
}
```

### 내비게이션의 너비 설정:

```css
nav의 너비를 헤더의 남은 너비로 설정합니다. 이때 CSS의 calc() 함수를 이용해 전체 너비에서 div 요소의 너비를 뺍니다.
```

```css
.main-nav {

}
```

### 안쪽 여백 및 바깥쪽 여백 제거:

```css
내비게이션 안의 ul 요소(main-nav__items)의 기본 안쪽 여백(padding)과 바깥쪽 여백(margin)을 제거합니다. 또한, 글머리 기호도 제거합니다.
```

```css
  padding: 0;
  margin: 0;
  list-style: none;
}
```

```css
의사 클래스를 사용하여 사용자와의 상호작용(마우스 오버, 클릭 등)에 따라 스타일을 동적으로 변경할 수 있게 되었습니다.
```

## 1. 의사 클래스(Pseudo-Class) 소개

```css
**의사 클래스(Pseudo-Class)**는 CSS에서 특정 요소의 특별한 상태를 스타일링할 때 사용합니다.

일반적인 HTML 요소를 선택한 다음, 특정 상태(예: 마우스를 올렸을 때, 클릭했을 때 등)를 지정해 스타일을 바꿀 수 있습니다.
```

## 2. 의사 클래스 사용법

```css
의사 클래스를 사용하기 위해 선택자 뒤에 콜론(:)을 붙이고 의사 클래스 이름을 추가합니다.

예를 들어, main-nav__item a 선택자에 :hover와 :active 의사 클래스를 추가하여 스타일을 지정할 수 있습니다.

a:hover: 마우스를 링크 위에 올렸을 때의 스타일을 지정합니다.

a:active: 링크를 클릭하여 활성 상태가 되었을 때의 스타일을 지정합니다.
```

```css
.main-nav_item a:hover {
  color: white;
}

.main-nav_item a:active {
  color: white;
}
```

# { 의사 클래스(Pseudo-Class)와 의사 요소(Pseudo-Element) 정리 }

## 1. 의사(Pseudo)란?

```css
"의사(Pseudo)"는 "가짜" 또는 "유사한"이라는 의미를 가지며, 실제 요소가 아닌 특정 조건이나 요소의 일부를 가리킬 때 사용됩니다.
```

## 2. 의사 클래스(Pseudo-Class)

```css
정의: 의사 클래스는 HTML 요소의 특정 상태를 스타일링할 때 사용합니다.

예를 들어, 마우스를 요소 위에 올렸을 때 또는 요소가 클릭되었을 때의 스타일을 지정할 수 있습니다.

구문: 콜론(:) 하나를 사용하여 정의합니다.

예시:

	:hover: 마우스를 요소 위에 올렸을 때 적용됩니다.

	:active: 요소가 클릭된 상태일 때 적용됩니다.

	:focus: 요소가 포커스를 받을 때 적용됩니다.

	:first-child: 형제 요소들 중 첫 번째 자식을 선택합니다.

```

```css
.main-nav__item a:hover {
  color: white;
}

.main-nav__item a:active {
  color: white;
}
```

## 3. 의사 요소(Pseudo-Element)

```css
정의: 의사 요소는 HTML 요소의 특정 부분을 스타일링할 때 사용합니다.

			예를 들어, 첫 글자나 첫 줄만 스타일링하거나 요소 앞이나 뒤에 콘텐츠를 삽입할 수 있습니다.

구문: 콜론 두 개(::)를 사용하여 정의합니다.

예시:

	::first-letter: 요소의 첫 글자에 스타일을 적용합니다.

	::before: 요소의 내용 앞에 가상 요소를 삽입합니다.

	::after: 요소의 내용 뒤에 가상 요소를 삽입합니다.
```

```css
p::first-letter {
  color: red;
  font-size: 20px;
}

.main-nav__item a::after {
  content: ' (Link)';
  color: red;
}
```

```css
::first-letter는 단락의 첫 글자만 스타일링할 때 사용됩니다.

::after는 링크 뒤에 "(Link)"라는 텍스트를 추가하고 그 텍스트를 빨간색으로 스타일링합니다.
```

## 4. 의사 클래스와 의사 요소의 차이점

```css
의사 클래스:

	요소의 "상태"를 기반으로 스타일을 적용합니다. 예를 들어, 마우스 오버 상태, 클릭 상태 등을 스타일링합니다.

의사 요소:

	요소의 "특정 부분"을 스타일링하거나 가상의 콘텐츠를 추가할 때 사용됩니다.

	예를 들어, 첫 글자, 첫 줄, 또는 요소 앞뒤에 가상 콘텐츠를 추가할 수 있습니다.
```

# { CTA 버튼 추가 및 스타일링하기 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381551/notion-blog/_/_/CSS/_CSS_/_3_CSS_/image_23.png)

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381552/notion-blog/_/_/CSS/_CSS_/_3_CSS_/image_24.png)

```css
비게이션 메뉴의 마지막 항목을 클릭 유도 버튼(CTA)으로 변환하여 다른 링크와 시각적으로 구별되는 스타일을 지정하는 방법을 배웠습니다.
```

## 1. **추가 클래스 설정 (BEM 명명법)**

```css
내비게이션 항목에 추가 클래스를 지정하여 특별한 스타일을 적용했습니다.

main-nav__item 클래스에 --cta라는 추가 클래스를 붙여서 main-nav__item--cta로 정의했습니다.

BEM 명명법에 따라 --cta는 해당 항목이 특별한 상태임을 나타냅니다.
```

## 2. **기본 스타일 덮어쓰기**

```css
새로운 스타일 규칙을 만들기 위해 main-nav__item--cta a 선택자를 사용했습니다.

다른 링크와 구별되는 스타일을 적용하기 위해 다음과 같은 스타일을 추가했습니다:

	텍스트 색상: 흰색 (color: white;)

	배경 색상: 붉은 색 (background-color: red;)

	안쪽 여백(padding): 위아래 8px, 좌우 16px (padding: 8px 16px;)

	모서리 둥글게 하기(border-radius): 8px (border-radius: 8px;)
```

## 3. **마우스 오버 및 클릭 효과**

```css
마우스 오버 및 클릭 시 스타일을 변경하기 위해 hover와 active 의사 클래스를 사용했습니다.

main-nav__item--cta a:hover와 main-nav__item--cta a:active 선택자를 사용하여 다음 스타일을 적용했습니다:

	텍스트 색상: 빨간색 (color: red;)

	배경 색상: 흰색 (background-color: white;)

	테두리 제거: 마우스 오버 시 테두리가 나타나지 않도록 테두리 할당을 제거했습니다.
```

## 4. **순서의 중요성**

```css
동일한 명시도를 가진 스타일 규칙에서 순서가 중요하므로, 파일에서 규칙을 작성하는 순서에 따라 스타일이 적용됩니다.
```
