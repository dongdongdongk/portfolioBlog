# 리액트 조건문

## **if-else 문을 사용한 조건부 렌더링**

```jsx
import React from 'react'

const ExampleComponent = ({ isLoggedIn }) => {
  let content

  if (isLoggedIn) {
    content = (
      <div>
        <h1>Welcome User</h1>
        <p>You are logged in. Enjoy your stay!</p>
      </div>
    )
  } else {
    content = (
      <div>
        <h1>Welcome Guest</h1>
        <p>Please log in to access the full content.</p>
      </div>
    )
  }

  return <div>{content}</div>
}

export default ExampleComponent
```

## **Ternary Operator를 사용한 조건부 렌더링 ( 삼항 연산자)**

```jsx
import React from 'react'

const ExampleComponent = ({ isLoggedIn }) => {
  return (
    <div>
      <h1>Welcome {isLoggedIn ? 'User' : 'Guest'}</h1>
      {isLoggedIn ? (
        <p>You are logged in. Enjoy your stay!</p>
      ) : (
        <p>Please log in to access the full content.</p>
      )}
    </div>
  )
}

export default ExampleComponent
```

```jsx
간단한 조건에는 ternary 연산자가 편리하며, 복잡한 조건이나 여러 조건이 필요한 경우 if-else 문을 사용할 수 있다.
```

# 동적 컴포넌트 스타일 추가

```jsx
스타일을 동적으로 변경 가능하게 코드를 작성해본다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381442/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_22.png)

```jsx
export default function DoubleDice() {
  const num1 = Math.floor(Math.random() * 3) + 1
  const num2 = Math.floor(Math.random() * 3) + 1
  const styles = { color: num1 === num2 ? 'green' : 'red' }
  return (
    <div className="DoubleDice" style={styles}>
      <h2>Double Dice</h2>
      {num1 === num2 && <h3>You win</h3>}
      <p>Num1 : {num1} </p>
      <p>Num2 : {num2} </p>
    </div>
  )
}
```

```jsx
styles 변수에 3항 연산자를 사용해서 동적이게 글자색을 선택하게 작성하였다

그리고 style 속성에 {styles} 를 넣어줬다
```

## **Heading 컴포넌트**

```jsx
**Heading.jsx 파일 생성**: 특정 색상과 텍스트를 받아와 헤딩을 렌더링하는 컴포넌트를 생성

**색상 및 텍스트 프로퍼티 사용**: 컴포넌트에 전달된 프로퍼티를 기반으로 동적으로 색상 및 텍스트를 변경할 수 있다.

**인라인 스타일**: 인라인으로 스타일을 지정하여 특정 컴포넌트에 동적 스타일을 적용

**프로퍼티로 스타일 제어**: 프로퍼티를 통해 사용자나 개발자가 스타일을 지정할 수 있도록 구현
```

// JSX 내부에서 동적으로 스타일 적용

# Map으로 배열 렌더링

```jsx
map 함수는 배열의 각 요소에 대해 주어진 함수를 호출하고 그 결과로 새로운 배열을 생성한다.
```

```jsx
import React from 'react'

const RenderArray = () => {
  const myArray = ['Item 1', 'Item 2', 'Item 3', 'Item 4']

  return (
    <div>
      <h1>Array Rendering with Map</h1>
      <ul>
        {myArray.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  )
}

export default RenderArray
```
