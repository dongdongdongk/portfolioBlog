```java
함수형 인터페이스란 1 개의 추상 메소드를 갖는 인터페이스를 말한다.

Java8 부터 인터페이스는 기본 구현체를 포함한 디폴트 메서드 (default method) 를 포함할 수 있다.

여러 개의 디폴트 메서드가 있더라도 추상 메서드가 오직 하나면 함수형 인터페이스이다.

자바의 람다 표현식은 함수형 인터페이스로만 사용 가능하다.
```

```java
@FunctionalInterface // 함수형 인터페이스임을 명시적으로 표시
interface Calculator {
    int calculate(int a, int b);

    // 디폴트 메서드
    default int add(int a, int b) {
        return a + b;
    }
}

public class FunctionalInterfaceExample {
    public static void main(String[] args) {
        // 람다 표현식을 사용하여 함수형 인터페이스 구현
        Calculator addition = (a, b) -> a + b;
        Calculator subtraction = (a, b) -> a - b;

        // 함수형 인터페이스의 추상 메서드 호출
        System.out.println("Addition: " + addition.calculate(5, 3));
        System.out.println("Subtraction: " + subtraction.calculate(5, 3));

        // 함수형 인터페이스의 디폴트 메서드 호출
        System.out.println("Default Method (Add): " + addition.add(5, 3));
    }
}
```

## **Functional Interface**

```java
함수형 인터페이스는 추상 메서드가 오직 하나인 인터페이스를 의미

추상 메서드가 하나라는 뜻은 default method 또는 static method 는 여러 개 존재해도 상관 없다는 뜻

그리고 @FunctionalInterface 어노테이션을 사용하는데, 이 어노테이션은 해당 인터페이스가 함수형 인터페이스 조건에 맞는지 검사해준다.

@FunctionalInterface 어노테이션이 없어도 함수형 인터페이스로 동작하고 사용하는 데 문제는 없지만, 인터페이스 검증과 유지보수를 위해 붙여주는 게 좋다.
```

## **1.1. Functional Interface 만들기**

```java
@FunctionalInterface
interface CustomInterface<T> {
    // abstract method 오직 하나
    T myCall();

    // default method 는 존재해도 상관없음
    default void printDefault() {
        System.out.println("Hello Default");
    }

    // static method 는 존재해도 상관없음
    static void printStatic() {
        System.out.println("Hello Static");
    }
}
```

```java
위 인터페이스는 함수형 인터페이스이다.

default method, static method 를 넣어도 문제 없다.

어차피 함수형 인터페이스 형식에 맞지 않는다면 @FunctionalInterface 에러를 띄워준다.
```

# **2. 자바에서 제공하는 함수형 인터페이스**

```java
자바에서는 다양한 함수형 인터페이스를 제공하지만, 자주 사용하고 있는 것들만 우선 정리해봤다.
```

## **2-1. Predicate**

```java
Predicate 는 인자 하나를 받아서 boolean 타입을 리턴한다.

람다식으로는 T -> boolean 로 쓴다.
```

```java
@FunctionalInterface
public interface Predicate<T> {
    boolean test(T t);
    ....
}
```

## **2-2. Supplier**

```java
Supplier 는 파라미터 없이 특정 객체를 리턴한다.

람다식으로는 () -> T 로 쓴다.
```

```java
@FunctionalInterface
public interface Supplier<T> {
    T get();
}
```

## **2-3. Function**

```java
Function은 객체를 파라미터로 받아서, 객체를 리턴한다.

람다식으로는 T -> R 로 쓴다.
```

```java
@FunctionalInterface
public interface Function<T, R> {
    R apply(T t);
}
```

```java
보통 정렬 관련 문제는 쿼리에서 대부분 정리해서 넘어오지만, 그렇지 못한 경우나 stream에서 중간 과정을 거쳤을 때, 정렬에 문제가 생겨서 재정렬이 필요할 때 자주 사용한다.
```

