
### format 설정

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381506/notion-blog/_/_/_/04_/Untitled_15.png)

```java
두번째 중요 속성인 format 을 설정해준다

format 의 설정을 어떻게 해야할지 모르겠을 때는 F1 을 눌러서 문자 또는 숫자를 어떻게 표현하는지 보고

맞춰서 적어주면 된다

현재는 문자 - 숫자 여서 @@### 이런식으로 표현했다

급여는 #,##0.00 로 표현했는데

#,### 이여야 하는데 이렇게 표현한 이유는 소수점 2자리까지 표현하고 만약 데이터가 없을때

null 이 뜨게 하지 않게 하기 위해서 #,#0 를해서 없다면 0을 출력하게 만든것이다 (기본값)
```
