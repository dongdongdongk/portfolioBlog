# { `bind`란? }

```jsx
bind는 함수의 this를 고정하는 방법이에요.

일반 함수(function)는 호출 방법에 따라 this가 달라질 수 있지만,

bind를 사용하면 this를 원하는 값으로 고정할 수 있어요!
```

## 예제 1: `this`가 바뀌는 문제

```jsx
class Example {
  constructor() {
    this.name = 'ChatGPT'
  }

  sayHello() {
    console.log('Hello, ' + this.name)
  }
}

const ex = new Example()
const hello = ex.sayHello // ❌ 함수만 따로 저장하면 `this`가 사라짐!
hello() // 🚨 오류! `this.name`이 undefined가 됨
```

### ❌ **왜 오류가 날까?**

```jsx
ex.sayHello()로 실행하면 this가 ex를 가리키지만,

const hello = ex.sayHello;로 함수만 저장하면 this가 원래 객체(ex)를 잃어버려요!

따라서 this.name을 찾을 수 없어서 오류 발생 🚨
```

## 해결 방법 1: `bind(this)` 사용하기

```jsx
const hello = ex.sayHello.bind(ex) // 🔥 `this`를 `ex`로 고정!
hello() // ✅ Hello, ChatGPT (this가 유지됨)
```

```jsx
bind(ex)를 사용하면 this가 항상 ex를 가리키도록 고정돼요!
```

## 해결 방법 2: 화살표 함수 사용하기 (`=>`)

```jsx
class Example {
  constructor() {
    this.name = 'ChatGPT'
  }

  sayHello = () => {
    // 🔥 화살표 함수 사용
    console.log('Hello, ' + this.name)
  }
}

const ex = new Example()
const hello = ex.sayHello
hello() // ✅ Hello, ChatGPT (this가 유지됨!)
```

```jsx
화살표 함수(=>)는 this를 자동으로 유지하기 때문에 bind(this)가 필요 없어요!
```
