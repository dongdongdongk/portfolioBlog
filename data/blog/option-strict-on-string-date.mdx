```jsx
get text 액티비티를 사용하고 변수의 데이터 타입을 변경하면 오류가 난다 무조건 get text 는 String 으로만 받아야 하는 문제가 있다

( 아래 사진을 보면 get text 를 int32 로 받으려고 하니까 Strict On 오류가 난다 )
```

```jsx
예를들어 DateTime 타입으로 저장하고 싶다면

일단 get text 액티비티로 String 으로 데이터를 가져온다

Assign 액티비티를 만들어주고

DateTimeInvoiceDate 를 DateTime 타입으로 만들어준다
```
