# { 텍스트 및 타이포그래피 이론 - 세리프 및 산세리프 서체 }

## 타이포그래피의 기본 개념

```jsx
타이포그래피는 텍스트를 시각적으로 매력적이고 읽기 쉽게 배열하는 예술이자 기술입니다.

이는 디자인에서 매우 중요한 요소로, 잘 배열된 타이포그래피는 독자의 주의를 끌고, 텍스트를 더 쉽게 이해할 수 있게 합니다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381603/notion-blog/_/_/_/_UI_UX_/_7_/Untitled.png)

```jsx
동일한 텍스트를 양쪽에 배치했을 때, 텍스트 계층 구조가 있는 오른쪽 기사가 더 읽기 쉽고 시각적으로 매력적입니다.
```

```jsx
타이포그래피의 중요성:

	사용자가 텍스트를 어떻게 인식하는지에 큰 영향을 미칩니다.

	텍스트의 가독성과 시각적 매력을 향상시킵니다.
```

## 서체와 폰트의 차이점

```jsx
**서체(Typeface)**는 문자의 디자인 특징을 가진 한 세트입니다. 서체의 예로는 Roberto, Monserrat, Nolito 및 Rubik이 있습니다.

**폰트(Font)**는 서체의 두께와 크기의 변화를 나타냅니다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381602/notion-blog/_/_/_/_UI_UX_/_7_/Untitled_2.png)

## 세리프와 산세리프

```jsx
세리프 서체(Serif Typeface):

	특징: 장식 획이 있는 서체.

	예시: Roboto Slab, Merryweather, Playfair, Lora, Crimson.

	용도: 주로 매체 출력물에 사용됨.

산세리프 서체(Sans-Serif Typeface):

	특징: 장식 획이 없는 서체.

	예시: Open Sans, Lato, Raleway, Work Sans, Karla.

	용도: 웹 또는 앱 디자인에 주로 사용됨.

조합 사용: 필요에 따라 세리프와 산세리프를 조합하여 사용할 수 있습니다. 예를 들어, 제목에는 세리프를, 본문에는 산세리프를 사용하는 것이 일반적입니다.

주의 사항: 여러 서체를 과도하게 사용하면 가독성을 떨어뜨리고 사용자 경험을 해칠 수 있으므로 단일 웹사이트에 여러 서체를 사용하지 않는 것이 좋습니다.

```

## 텍스트 속성 탐색

```jsx
서체 변경:

	텍스트 속성 패널에서 서체를 변경할 수 있습니다. 예: Poppins로 변경.

글꼴 두께 및 크기 변경:

	글꼴 두께를 레귤러에서 미디엄으로 변경하고, 글꼴 크기를 12에서 24로 변경합니다.

	글꼴 크기를 36으로 수동 설정할 수도 있습니다.

줄간격:

	여러 줄의 텍스트가 필요합니다. 예: 텍스트를 복사하여 네 줄로 만듭니다.

	줄간격 옵션으로 선 사이의 간격을 조절합니다. 기본값은 Auto입니다.

자간:

	문자 사이의 간격을 변경할 수 있습니다.

문단 간격:

	텍스트 레이어를 만들어 단락 간격을 조절합니다.
```

## 텍스트 정렬 및 방향

```jsx
텍스트 정렬:

	텍스트를 왼쪽, 가운데, 오른쪽으로 정렬할 수 있습니다.

세로 방향 정렬:

	텍스트 영역을 늘려 각 텍스트 크기를 24로 줄이고, 텍스트를 위쪽, 가운데, 아래쪽으로 정렬할 수 있습니다.
```

## 텍스트 영역 설정

```jsx
자동 넓이, 자동 높이, 사이즈 고정:

	자동 넓이: 텍스트 입력 시 텍스트 영역의 너비가 자동으로 늘어납니다.

	자동 높이: 텍스트 입력 시 텍스트 영역의 길이가 자동으로 늘어납니다.

	사이즈 고정: 텍스트 영역이 고정된 상태로 유지되며, 텍스트가 넘칠 수 있습니다.

텍스트 자르기:

	크기 조정을 고정 크기에서 자르기로 변경하여 텍스트를 텍스트 영역으로 제한할 수 있습니다.
```

## 고급 텍스트 속성

```jsx
텍스트 크기 및 정렬:

	'Hello World' 텍스트를 작성하고 크기를 24에서 36으로 변경합니다.

텍스트 데코레이션:

	텍스트에 밑줄을 긋거나 취소선을 표시할 수 있습니다.

	목록 스타일을 글머리 기호 목록이나 번호 목록으로 변경할 수 있습니다.

대소문자 변경:

	대문자, 소문자, 제목 케이스 등으로 텍스트를 변경할 수 있습니다.

사용자 정의 글꼴 너비:

	다른 서체 (예: Rubik)로 변경하고 글꼴 두께를 사용자 정의할 수 있습니다.
```
