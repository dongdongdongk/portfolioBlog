# **Repository를 확장하는 법**

```java
1. Querydsl을 사용하여 쿼리 메서드나 @Query로 처리하기 어려운 기능들을 따로 인터페이스로 정의한다.

2. 이 인터페이스를 구현하는 별도의 클래스를 생성한다. 이때, 부모 클래스로 QuerydslRepositorySupport를 사용한다.

	* QuerydslRepositorySupport는 Querydsl을 지원하는데 도움을 주는 클래스이다.

3. Q 도메인 클래스와 JPQLQuery를 활용하여 구현 클래스에서 인터페이스 함수를 구현한다.

	* Q 도메인 클래스는 Querydsl이 생성한 엔터티를 조회하는 데 사용되는 클래스이다.

	* JPQLQuery는 Querydsl이 제공하는 쿼리를 작성하고 실행하는 데 사용되는 인터페이스이다.

간단히 말하면, Querydsl을 이용하여 데이터베이스 조회와 관련된 복잡한 기능들을 따로 분리하고,

이를 구현하기 위해 QuerydslRepositorySupport를 상속받은 클래스를 사용하는 것이다.

이 클래스에서는 Querydsl의 Q 도메인 클래스와 JPQLQuery를 활용하여 원하는 쿼리를 작성하고 실행한다.
```

## tuple 은 부분적인 결과를 가져올 때 사용

```java
  	QBoard board = QBoard.board;
    QReply reply = QReply.reply;
    QMember member = QMember.member;

    JPQLQuery<Board> jpqlQuery = from(board);
    jpqlQuery.leftJoin(member).on(board.writer.eq(member));
    jpqlQuery.leftJoin(reply).on(reply.board.eq(board));

    JPQLQuery<Tuple> tuple = jpqlQuery.select(board, member.email, reply.count());
    tuple.groupBy(board);

    log.info("---------------------------");
    log.info(tuple);
    log.info("---------------------------");

    List<Tuple> result = tuple.fetch();

    log.info(result);
```

```java
Q 도메인 객체를 가져와주고 ( QReply reply = QReply.reply; 와 QMember member = QMember.member; )

left join 을 이용해서 member 와 reply 를 조인해준다

이후 select 를 해서 필요한 부분만 가져와서 결과를 출력할건데 이때 tuple 을 사용한다 (count 같은 집합 함수도 지원된다)

(member 의 email (작성자) reply 의 count 결과를 부분적으로 가져온다 이럴때 사용하는게 tuple)
```

## 검색어 조건 처리 (BooleanExpression)

```java
@Override
    public Page<Object[]> searchPage(String type, String keyword, Pageable pageable) {

        log.info("searchPage.............................");

        // 도메인 클래스들
        QBoard board = QBoard.board;
        QReply reply = QReply.reply;
        QMember member = QMember.member;

        //JPQL 쿼리 객체 생성
        JPQLQuery<Board> jpqlQuery = from(board);
        jpqlQuery.leftJoin(member).on(board.writer.eq(member));
        jpqlQuery.leftJoin(reply).on(reply.board.eq(board));

        //SELECT b, w, count(r) FROM Board b
        //LEFT JOIN b.writer w LEFT JOIN Reply r ON r.board = b

        // 부분적으로 필요하기 떄문에 tuple 사용
        JPQLQuery<Tuple> tuple = jpqlQuery.select(board, member, reply.count());

        //검색 조건을 추가하기 위해 BooleanBuilder 추가
        BooleanBuilder booleanBuilder = new BooleanBuilder();
        //검색 조건을 추가 ( 검색 조건이 없을때는 내용물을 만들필요가 없기 때문에 bno 0 보다 크다로 끝
        BooleanExpression expression = board.bno.gt(0L);

        booleanBuilder.and(expression);

        // 검색 조건이 있다면
        if(type != null){
            String[] typeArr = type.split(""); // typeArr 배열을 통해 이 조건을 각각의 문자로 분리 (tcw)

            //검색 조건을 작성하기
            //컨디션 빌더를 따로 만들어서 검색 조건을 추가해준다
            BooleanBuilder conditionBuilder = new BooleanBuilder(); // conditionBuilder는 JPQL의 WHERE 절에 들어갈 조건들을 OR로 연결하기 위한 빌더

            for (String t:typeArr) {
                switch (t){
                    case "t":
                        conditionBuilder.or(board.title.contains(keyword)); // 현재의 검색 조건이 "t"일 때, JPQL 쿼리에 제목에 특정 키워드를 포함하는 조건을 추가
                        break;
                    case "w":
                        conditionBuilder.or(member.email.contains(keyword));
                        break;
                    case "c":
                        conditionBuilder.or(board.content.contains(keyword));
                        break;
                }
            }
            // 결과를 booleanBuilder 에 추가
            booleanBuilder.and(conditionBuilder);
        }

        // where 조건에 완성된 booleanBuilder 추가
        tuple.where(booleanBuilder);

        // groupBy board 추가
        tuple.groupBy(board);

        //결과를 list 에 담는다
        List<Tuple> result = tuple.fetch();

        log.info("==={}===",result);

        return null;
    }
}
```
