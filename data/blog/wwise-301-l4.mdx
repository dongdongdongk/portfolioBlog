## 1. Wwise Event와 스크립트의 관계 이해하기

Unity에서 **Wwise Event**를 재생하려면 반드시 다음 두 가지가 필요합니다.

1. **어떤 Event를 재생할 것인가** — (예: Explosion, Pickup_Coin 등)
2. **어디(GameObject)에서 재생할 것인가** — (예: Player, Tree, Enemy 등)

이 정보를 코드로 제어하기 위해 Wwise는 **AK.Wwise.Event**라는 특별한 클래스 타입을 제공합니다.

즉, `AK.Wwise.Event` 타입의 변수를 스크립트에 선언하면, **Inspector에서 직접 Event를 지정**할 수 있게 됩니다.

---

## 2. 새 스크립트 생성하기

### 🎬 단계 요약

1. Unity 메뉴에서 `Audiokinetic > Certification > 301 > Lesson 4` 이동
2. `Posting Events using Wwise-Types` 씬 열기
3. **Hierarchy** 창에서 `Player` 오브젝트 선택
4. **Inspector → Add Component → New Script** 클릭
5. 스크립트 이름을 `PostWwiseEvent`로 지정하고 **Create and Add** 클릭

> 💡 스크립트 이름은 나중에 바꾸기 어렵기 때문에 정확히 입력하는 것이 중요합니다.

### ✅ 결과

Inspector에서 Player에 새 `PostWwiseEvent` 스크립트가 추가됩니다.

이 스크립트는 자동으로 `Assets` 폴더에도 저장되며, **더블 클릭하면 Visual Studio**에서 열립니다.

## 4. Wwise-Type Event 프로퍼티 선언하기

### 🧩 목표

Inspector에서 Wwise Event를 선택할 수 있도록,

`AK.Wwise.Event` 타입의 변수를 **public 프로퍼티**로 선언합니다.

### 🧠 개념 정리

C#에서 변수를 선언할 때 기본 구조는 다음과 같습니다:

```
[접근 한정자] [타입] [이름];
```

| 구성 요소   | 설명                                                      |
| ----------- | --------------------------------------------------------- |
| 접근 한정자 | 외부 접근 가능 여부를 결정 (`public`, `private` 등)       |
| 타입        | 변수의 데이터 형태 (`int`, `string`, `AK.Wwise.Event` 등) |
| 이름        | 변수명 (자유롭게 지정 가능, 예: `MyEvent`)                |

### ✏️ 실제 코드

```csharp
public class PostWwiseEvent : MonoBehaviour {
    public AK.Wwise.Event MyEvent;

    void Start () {

    }

    void Update () {

    }
}
```

> 🧩 public으로 지정했기 때문에 Unity Inspector에서 이 프로퍼티가 보이게 됩니다.
>
> **AK.Wwise.Event**는 Wwise가 제공하는 특별한 클래스 타입으로,
>
> Inspector에서 Wwise 프로젝트의 Event를 직접 선택할 수 있게 해줍니다.

### 🧠 참고

- AK.Wwise.Event 외에도
  - `AK.Wwise.RTPC` (실시간 파라미터 제어)
  - `AK.Wwise.State`, `AK.Wwise.Switch` 등 다양한 타입이 존재합니다.
- 즉, 사운드 시스템을 코드로 유연하게 제어하기 위한 인터페이스입니다.

## 6. Post() 함수로 Event 재생하기

### 🎬 개념 설명

Wwise Event를 실제로 재생하기 위해서는 `Post()` 함수를 호출해야 합니다.

형식:

```csharp
MyEvent.Post(GameObject);
```

- `MyEvent` → Inspector에서 지정한 Wwise Event
- `GameObject` → 이 이벤트를 재생할 대상 (예: Player 자신)

### 🧩 코드 구현

```csharp
using UnityEngine;

public class PostWwiseEvent : MonoBehaviour {
    public AK.Wwise.Event MyEvent;

    void Start() {
        MyEvent.Post(gameObject);
    }
}
```

### 🧠 작동 원리

- **Start()** 함수는 씬이 실행될 때 한 번 호출됩니다.
- 따라서 Play 버튼을 누르면 `MyEvent`에 지정된 **Rock_Destroy** Event가
  `Player` 오브젝트의 위치에서 재생됩니다.

### ✅ 테스트

1. Unity에서 **Play** 버튼 클릭
2. 씬이 실행되면 Rock_Destroy 사운드가 재생됩니다.

> 💡 Post() 함수는 스크립트가 붙은 오브젝트를 기준으로 소리가 재생됩니다.
>
> 즉, Player가 움직이면 그 위치에서 사운드가 들리게 됩니다.

## 1. 개념 이해하기

### 🎬 Animation Clip이란?

- Unity에서 **애니메이션 클립(Animation Clip)** 은 오브젝트의 움직임, 회전, 크기, 위치 등 **프로퍼티의 변화 시퀀스**를 담은 파일입니다.
- 외부 프로그램(Maya, 3ds Max 등)에서 만든 애니메이션을 Unity로 가져오거나, Unity 내에서 직접 수정할 수 있습니다.
- 예를 들어 Player 캐릭터는 Maya에서 모델링되고, **Move(이동)** 와 **Attack(공격)** 같은 행동 애니메이션이 정의되어 있습니다.

### 👣 Animation Event란?

- **Animation Event**는 **애니메이션의 특정 시점에 스크립트의 함수를 호출**할 수 있게 해주는 Unity 기능입니다.
- 예를 들어,
  - "발이 바닥에 닿는 시점" → `PlayFootstepSound()` 함수 호출
  - "공격 모션에서 팔을 휘두르는 시점" → `PlaySwingSound()` 함수 호출

이를 통해 **시각적인 움직임과 소리를 완벽히 동기화**할 수 있습니다.

## 4. Start 함수 수정하여 Animation Event로 전환하기

기존 스크립트는 아래와 같습니다 👇

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class PostWwiseEvent : MonoBehaviour {
    public AK.Wwise.Event MyEvent;

    // Use this for initialization
    void Start () {
        MyEvent.Post(gameObject);
    }
}
```

### ❗ 문제점

- `Start()` 함수는 Unity가 **씬이 로드될 때 자동으로 실행**합니다.
- 즉, 게임이 시작되면 발소리가 **계속 자동으로 재생**됩니다.

### ✅ 해결 방법

Animation Event에서 직접 호출할 수 있도록

함수 이름을 바꾸고, 접근 한정자를 `public`으로 설정해야 합니다.

---

### ✏️ 수정된 코드

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class PostWwiseEvent : MonoBehaviour {
    public AK.Wwise.Event MyEvent;

    // Animation Event로 호출할 함수
    public void PlayFootstepSound() {
        MyEvent.Post(gameObject);
    }
}

```

- 함수 이름을 `Start()` → `PlayFootstepSound()` 로 변경
- `public` 접근 한정자 추가 → Animation Event에서 접근 가능
- 이제 이 함수는 Unity가 자동으로 호출하지 않으며,
  Animation Event에서만 호출됩니다.

💾 저장 (Ctrl+S 또는 Cmd+S) 후 Unity로 돌아갑니다.

## 1. 개요 및 핵심 개념

- 이 섹션은 **보너스 강의**로, **Wwise 301 자격증 시험 범위에는 포함되지 않음.**
- 하지만 매우 흥미로운 고급 주제:
  → **“오디오 입력(마이크)”을 이용해 게임 속 이벤트를 트리거(발생)** 시키는 방법을 다룸.

### 🔑 핵심 개념 요약

| 구분                 | 설명                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| **기존 방식**        | Player의 행동(Ex. 발이 바닥에 닿을 때) → `Player_Footsteps` Event 게시         |
| **이번 방식**        | 마이크 입력 신호 → 특정 dB 이상일 때 → Player가 무기를 휘두름 등 이벤트 트리거 |
| **Audio Input 역할** | “음원(Source)” 대신 “마이크 입력”을 사용                                       |
| **핵심 목표**        | 마이크 신호가 -48dB를 초과할 때 **Player가 공격**하도록 구현                   |

---

## 2. 마이크 입력을 사용하는 이유

- **Wwise Audio Input**을 통해 마이크 신호를 Wwise 오브젝트에 전달할 수 있음.
- **Wwise Meter Effect 플러그인**으로 마이크 입력 신호의 **레벨(dB)** 을 측정 가능.
- 즉, 오디오의 “볼륨” 정보를 실시간으로 받아서 **게임의 메커니즘(공격, 점프 등)** 을 조종할 수 있음.

---

## 3. Unity에서 AkMicrophone 스크립트 추가하기

1. Unity 메뉴: `Audiokinetic > Certification > 301 > Lesson 4 > Posting Audio Input` 으로 이동.
2. **Hierarchy에서 Player 오브젝트 선택.**
3. **Inspector → Add Component → "AkMicrophone" 검색 → 추가.**

> 💡 AkMicrophone 스크립트는 Audiokinetic이 미리 제공한 것으로,
>
> 마이크 신호를 읽고 RTPC와 이벤트를 자동으로 연결할 수 있게 설계됨.

---

## 4. Wwise에서 Audio Input 음원 만들기

1. `Project Explorer > Audio > Actor-Mixer Hierarchy` 로 이동.
2. `Default Work Unit` 우클릭 → `New Child > Sound SFX` 선택.
3. 이름: **Microphone**

🎧 아직 음원이 연결되지 않았기 때문에 **빨간색**으로 표시됨.

이제 Wwise Audio Input을 추가해야 함.

1. **Contents 탭 → Add Source >> → Audio Input** 선택.
   - 이렇게 하면 **시스템의 마이크 입력**이 Wwise의 음원이 됨.
   - 마이크 볼륨이 작으면 여기서 **Input Gain**을 조절 가능.
2. **Transport Control**에서 ▶ 버튼을 눌러 입력 테스트 가능.
   - 소리가 들리면 정상 작동.
   - 단, 이 프로젝트에서는 “재생”이 아닌 “입력 감지”만 필요하므로 **출력을 뮤트**할 예정.

## 5. Microphone Audio Bus 생성 및 볼륨 조정

### 🎛 출력 경로 설정 과정

1. `Project Explorer > Master-Mixer Hierarchy > Master Audio Bus > Non-World Audio Bus`

   → 우클릭 → `New Child > Audio Bus`

2. 이름: **Microphone**
3. `Audio Bus`의 **General 탭 → Bus Volume = -96 dB** 로 설정

   → 완전히 음소거 상태로 만들어 **소리는 들리지 않지만** 입력은 처리되도록 함.

4. 이제 **Microphone Sound SFX의 Output Bus**를 방금 만든 **Microphone Audio Bus**로 지정:
   - `Sound Property Editor → General Settings 탭`
   - Output Bus 탐색 버튼 (…) 클릭 → `Microphone Audio Bus` 선택.

> 🔇 이렇게 하면 마이크 입력은 계속 들어오지만,
>
> 실제 오디오 출력은 완전히 꺼진 상태로 측정만 가능하게 됨.

## 6. Wwise Meter로 마이크 신호 측정하기

- **Wwise Meter Effect**는 마이크 입력의 볼륨(dB)을 측정하는 플러그인.
- 마이크 신호가 **얼마나 큰지(피크 값)** 실시간으로 감지해
  이를 **RTPC (Real-Time Parameter Control)** 로 전달함.

### 📌 설정 방법

1. `Effects 탭` → `+` 클릭
2. `Meter > Meters` 경로에서 `MicrophoneMeter` Effect ShareSet 선택
3. `Edit` 클릭 → `Wwise Meter Effect Editor` 열기

---

## 7. RTPC를 Wwise Meter에 연결하기

- **RTPC (Game Parameter)** 는 게임과 오디오 사이의 “데이터 교환 통로”.

🎯 목표:

Wwise Meter에서 측정한 볼륨 값을

`MicrophoneLevel` RTPC로 전달.

- Wwise Meter의 `Output Game Parameter` 를
  `MicrophoneLevel RTPC`로 연결.

> 📘 기본 Output Min 값은 -48 dB,
>
> 즉, 마이크 입력이 -48dB보다 크면 이벤트가 발생하게 됨.

## 8. Unity의 AkMicrophone 스크립트와 RTPC 연결

1. Unity로 돌아가 `AkMicrophone` 컴포넌트를 선택.
2. `Microphone Level RTPC Property Drawer` 항목을 찾기.
   - 이 프로퍼티는 마이크 입력 레벨과 연결됨.
   - `MicrophoneLevel` RTPC를 선택해야 함.
3. 선택 버튼 → `Generic > MicrophoneLevel` 선택.

> ⚠️ 만약 Enable_Microphone Event가 보이지 않는다면
>
> Unity의 Wwise Settings에서 **Wwise Project Path**를 올바르게 변경해야 함.

## 9. Wwise에서 Enable_Microphone Event 생성하기

1. `Project Explorer > Audio > Actor-Mixer Hierarchy`

   → `Microphone Sound SFX` 우클릭 → `New Event > Play`

2. 이름: **Enable_Microphone**
3. `Event Editor`에서 이름을 확인하고,

   **General SoundBank**에 자동으로 추가됨.

4. `Project > Save`

   → SoundBank Layout으로 전환 → `Generate All` 클릭

5. Unity로 돌아가

   `AkMicrophone` 컴포넌트의 `Microphone Event Property`에서

   `Events > Default Work Unit > Enable_Microphone` 선택.

## 10. Unity에서 OnMicrophoneAction() 설정하기

1. `AkMicrophone` 컴포넌트에서 ➕ 버튼 클릭.
2. `PlayerAttack` 컴포넌트를 **Object 필드**에 드래그.
3. 함수 선택 메뉴에서 `PlayerAttack > Swing()` 선택.

> 🎮 이렇게 설정하면
>
> 마이크 신호가 -48dB를 초과할 때
>
> `PlayerAttack` 스크립트의 `Swing()` 함수가 호출되어
>
> 플레이어가 **공격 모션**을 실행함.

## 13. 문제 해결 및 팁
