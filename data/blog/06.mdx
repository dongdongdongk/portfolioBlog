# 설치과정 & 서버의 통신포멧

```java
1. 투비소프트가 방문하여 Server(Was가 구성되어 있어야함) 에 X-API 모듈을 설치해줌

	*X-API (라이브러리 형태의 모듈)

2. Client 와 서버 간의 데이터 통신을 하는데 Format 이 필요한데 이 포맷이 Dataset Layout 이고 Dataset Layout 에 맞게 만들기 위해 도와주는것이 X-API 이다

3. 통신은 http 통신을 한다 통신할 때 n개의 Dataset과 n개의 Variable 를 주고받을 수 있다 여기서 클라이언트에서 서버로 데이터를 넘기는 부분을 **Input 또는 Input Dataset 이라고 한다**

4. 서버에서 클라이언트로 보내는것을 **output 또는 output Dataset 을 받는다** 고 한다

* 넥사크로에서는 transaction() 이라는 메소드 하나만 배우면 연동하는데 문제가 없다
```

# transaction

```java
Application 영역에 정의된 Dataset 의 데이터를 갱신하기 위한 서비스를 호출하고, 트랜잭션이 완료되면 콜백함수을 실행하는 메소드
```

### get post 설정해주기 (post 값에 스페이스가 들어가는 경우)

```java
예를들어 "http://demo.nexacro.com/edu/nexacro17/select_emp.jsp?arg1=1&arg2=2" 이런식으로 arg 변수를 전달한다고 하면 get 방식 이므로 보안에 좋지 못하다

이때 post 방식으로 데이터를 전달하기 위해 사용하는 부분이 아래 조회조건 설정 부분이다

Get 방식은 & 로 변수를 구분했지만 post 는 space 로 구분하는데 데이터에 공백이 들어갈 때 는 (ex arg1=1 arg2=2 3)

"arg=1 arg2=" + nexacro.wrapQuote("2 3") 이런식으로 변경해서 보내줘야 한다
```

```java
this.btn_retrieve_onclick = function(obj:nexacro.Button,e:nexacro.ClickEventInfo)
```

### 콜백 함수

```java
콜백 함수는 무조건 3개의 파라미터를 받는다

svcid = 트랜젝션에서 넘겨주는 첫번째 id (위의 예제 strSelect)

ecd = 에러코드

emsg = 에러 메세지
```

```java
this.btn_retrieve_onclick = function(obj:nexacro.Button,e:nexacro.ClickEventInfo)
{
	this.transaction(
	"strSelect", // 서비스 id (트랜젝션을 구분할 수 있는 id)
	"DataSrv::samplexml.jsp", // 서비스 url 내가 호출할 서비스 URL
	"", // 저장 기능 (없으면 "")
	"ds_emp=out_emp", // 조회 클라이언트에서 받을 데이터셋  = 서버에서 받을 데이터셋
	"arg=1 arg2=" + nexacro.wrapQuote("2 3"), // 조회 조건 get과 post 를 설정해주는 부분
	"fn_call" //문장의 끝을 알려주는 부분 콜백 함수를 호출해야 한다
	);
};

//콜백 함수 ( 조회 횟수, 성공 여부 전송 )
this.fn_call = function(svcid, ecd, emsg) //콜백 함수는 무조건 3개의 파라미터
{
	if(ecd >= 0){
		if(svcid == "strSelect")
		{
			alert(this.ds_emp.getRowCount() + '건 조회');
		}
	} else {
		alert("Error " + ecd + ":" + emsg);
	}
}
```

## 저장

```java
//저장

this.btn_save_onclick = function(obj:nexacro.Button,e:nexacro.ClickEventInfo)
{
	this.transaction(
	"strSave", // 서비스 id (트랜젝션을 구분할 수 있는 id)
	"SvcURL::save_emp.jsp", // 서비스 url 내가 호출할 서비스 URL
	"in_emp=ds_emp:U", // 저장 server ds = client ds (서버에서 받을 Dataset = 클라이언트에서 넘겨줄 Dataset) , :U 수정된 정보만 넘기기 :A 전부 넘기기
	"", // 조회(없으면 "")
	"arg=1 arg2=" + nexacro.wrapQuote("2 3"), // 조회 조건 get과 post 를 설정해주는 부분
	"fn_call" //문장의 끝을 알려주는 부분
	);
};
```

```java
:U 를 붙이면 수정된 정보만 넘기고

:A 를 사용하면 모든 정보를 넘긴다

기본적으로 :U 를 사용해서 성능을 향상 시켜야 한다

```
