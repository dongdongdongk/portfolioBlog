# show

```jsx
SHOW는 데이터베이스 목록이나, 테이블 목록 등 다양한 정보를 보기 원할 때 사용하는 명령어
```

```jsx
SHOW DATABASES;   데이터베이스 목록 (현재 계정이 접근 가능한 데이터베이스)

SHOW TABLES;  현재 데이터베이스에 테이블 목록

SHOW TABLES LIKE '키워드%';  현재 데이터베이스에서 조건이 맞는 테이블 목록

SHOW TABLES FROM 데이터베이스;  특정 데이터베이스에 테이블 목록

등등
```

# CREATE DATABASE

```jsx
데이터베이스를 생성하는 일반적인 명령어:

CREATE DATABASE <database_name>;

예시:

CREATE DATABASE soap_store;
```

# **다중 INSERT**

```sql
-- 단일 삽입(name과 age의 순서 변경):

INSERT INTO cats (age, name)
VALUES
  (2, 'Beth');

-- 다중 삽입:

INSERT INTO cats (name, age)
VALUES
  ('Meatball', 5),
  ('Turkey', 1),
  ('Potato Face', 15);
```

## INSERT 예제

```sql
--테이블 생성

CREATE TABLE people
  (
    first_name VARCHAR(20),
    last_name VARCHAR(20),
    age INT
  );

--단일 삽입
INSERT INTO people(first_name, last_name, age)
VALUES ('Tina', 'Belcher', 13);

INSERT INTO people(age, last_name, first_name)
VALUES (42, 'Belcher', 'Bob');

--다중 삽입

INSERT INTO people(first_name, last_name, age)
VALUES
    ('Linda', 'Belcher', 45),
    ('Phillip', 'Frond', 38),
    ('Calvin', 'Fischoeder', 70);
```

# **NULL과 NOT_NULL**

```sql
칼럼의 NOT NULL 제약조건을 추가하여 NULL을 입력하지 못하게 하거나, NULL을 허용하도록 함
```

## **NULL과 NOT_NULL예제**

```sql
CREATE TABLE cats2 (
    name VARCHAR(100) NOT NULL,
    age INT NOT NULL
);
```
