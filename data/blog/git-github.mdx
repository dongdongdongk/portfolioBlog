## 4. Local에서 Repository 생성 후 Remote로 push

```java
1. git-fork
	1) File -> init new Repository
	2) 탐색창 -> repository로 사용할 폴더(Java Project로 사용 할)를 생성 후 선택
	3) repository 폴더에 gitignore 파일 생성
	4) git-fork에서 gitignore파일을 stage로 이동 후 commit
	5) STS에서 Java project를 생성 프로젝트명은 Reository 이름과 동일 한 경로와 이름
	6) Git-hub에서 동일한 repository이름으로 새로운 repository 생성
	7) URL 주소 복사
	8) git-fork에서 remote 우클릭 하면 복사한 내용이 자동 저장 확인

```

## 5. Remote에서 Repository 생성 후 Local pull

```java
1) Git-hub에서 새로운 repository 생성
		a. repository 이름 입력
		b. public 선택
		c. Add .gitignore 파일 선택(option, 나중에 local에서 만들어 도 됨)
			 - java 입력 후 template 선택
		d. create repository 클릭

 2) gitignore 파일 수정
		a. gitignore 페이지에서 연필모양 클릭(수정)
		b. 내용 수정
		c. commit changes 에서 제목 입력 후 commit

 3) URL 복사
		a. Repository 첫 화면에서 code 클릭
		b. HTTPS URL 주소 복사

	4) git-fork
		 a. File -> clone
		 b. 복사한 URL을 Repository url에 입력
		 c. Parent folder는 workspace로 경로
		 d. Name 에 자동입력(Ropository 와 동일한 이름 입력)
		 e. clone 클릭

	5) STS
		 a. 프로젝트 생성
		 b. 프로젝트명은 Repository 이름과 동일하게
```

## 6. 작업 순서

```java
0. Git-fork에서 Pull 진행
1. STS 코딩 작업 후 저장
2. git-fork에서 원하는 파일을 stage로 이동
3. commit 제목을 입력하고 commit 버튼 클릭(Local에 저장)
4. push - Github에 upload
```

## 7. Delete

```java
1. Git-hub Repository 삭제
	- git-hub에서만 삭제 Local은 영향이 없음
	a. 삭제할 Git-hub에 Repository에서 Setting 이동
	b. 하단에 Danger Zone의 Delete repository
	c. 소유자이름/repository이름 입력하고 삭제

2. Local Git 삭제
	- git-hub와 프로젝트 파일에는 영향이 없음
	- git-fork에서만 안보이게 하는것, git 설정은 남아 있음
	- git 설정을 모두 지울려면 repository 폴더내의 .git 폴더를 삭제 해야 함

	a. git-fork에서 Repository Manager 열기
	b. 탭을 모두 닫거나 + 버튼 누루면 Repository Manager가 나옴
	c. 삭제할 repository명 우클릭 remove 선택

3. Java project 삭제
	a. sts에서 삭제할 프로젝트명 우클릭 -> delete
	b. 체크 박스에 체크를 해야 HDD에서도 완전 삭제
```

## 8. Git-hub에서 사용하던 Project(Repository) Clone

```java
  1) Git-hub에서 Repository URL 복사
		a. Repository 첫 화면에서 code 클릭
		b. HTTPS URL 주소 복사

	2) git-fork
		 a. File -> clone
		 b. 복사한 URL을 Repository url에 입력
		 c. Parent folder는 workspace로 경로
		 d. Name 에 자동입력(Ropository 와 동일한 이름 입력)
		 e. clone 클릭

	3) sts
		A. Git Project Import
		 a. file > import
		 b. Git > Project From Git(with Smart import)
		 c. Existing local repository > add > Clone한 project 폴더 선택
		 d. import할 Project 선택 > finish


	 B. General Project Import
		 a. file > import
		 b. General > Existing Project....
		 c. root directory > browser > workspace 폴더 선택
		 d. 사용할 Project를 체크 하고 Finish
```

### GitHub 협업

```jsx
Owner : Project 소유자(리더, 팀장...)
Cotributor(Collaborator) : 기여자, 협력자 (팀원,,,)

1. Owner Github에 Repository를 생성하고 Project(공통 설정)생성
2. Coutributor는 Owner의 Repository를 Fork
3. Contributor는 각각의 local에 Clone후 Project import
4. Owner와 Contributor는 각자 local에서 작업
5. Contributor는 작업을 끝낸(Test까지 완료)것을 Owner로 Pull Request
6. Owner는 체크 후 merge를 하거나 거절

-- 주의점
1. main branch에 직접 작성 X
2. main branch에 merge를 하기 전
	 a. Github에서 main이 변경되었는지 확인(synk 작업)
	 b. 변경이 있으면 local에서 main을 pull
	 c. branch를 merge
```
