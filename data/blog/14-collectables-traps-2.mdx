# { Phaser에서 객체의 속성 추출 및 적용 }

```jsx
이번 강의에서는 Phaser에서 객체(Object)의 속성을 추출하고 적용하는 방법을 배웁니다.

이전 강의에서 레이어의 속성(Properties) 을 다룬 것처럼, 이번에는 게임 오브젝트(예: 다이아몬드)에도 속성을 적용하는 방법을 설명합니다.
```

## 1. 객체의 속성이란?

```jsx
Phaser에서 게임 오브젝트는 추가적인 정보(속성, Properties)를 가질 수 있습니다.

예를 들어, 다이아몬드 아이템이 있을 때 각 다이아몬드마다 점수(Score)를 다르게 설정할 수 있습니다.
```

### ✅ 예제: Tiled 맵에서 다이아몬드에 점수 설정

```jsx
1. Tiled 에디터에서 다이아몬드 오브젝트를 선택합니다.

2. Properties(속성) 창에서 새로운 속성을 추가합니다.

		score 속성 추가 (값: 5)

		다른 다이아몬드의 score 속성 추가 (값: 10)

3. Integer(정수) 타입으로 설정합니다.

이제 Phaser에서 이 정보를 가져와 적용해 봅시다.
```

## 2. 객체의 속성 읽어오기

```jsx
Phaser에서 맵에 배치된 객체들의 속성을 읽고 활용하는 방법을 배워봅니다.

🔹 Collectables 클래스에서 속성 적용

		Collectables 클래스는 여러 개의 Collectable 객체(즉, 다이아몬드)를 관리합니다.

		mapProperties() 메서드를 이용하여 속성을 읽습니다.

		기본 점수(defaultScore)를 설정하고, 개별 오브젝트의 점수를 덮어씁니다.
```

```jsx
import Phaser from 'phaser'
import Collectable from '../collectables/Collectable'

class Collectables extends Phaser.Physics.Arcade.StaticGroup {
  constructor(scene) {
    super(scene.physics.world, scene)

    this.createFromConfig({
      classType: Collectable,
    })
  }

  addFromLayer(layer) {
    // 1. 레이어에서 기본 속성 추출 (예: 기본 점수)
    const { score: defaultScore, type } = this.mapProperties(layer.properties)

    // 2. 레이어의 모든 오브젝트를 순회하며 속성 적용
    layer.objects.forEach((collectable0) => {
      const collectable = this.get(collectable0.x, collectable0.y, type)

      // 3. 개별 오브젝트 속성 가져오기
      const props = this.mapProperties(collectable0.properties)

      // 4. 개별 속성이 있으면 적용, 없으면 기본 점수 사용
      collectable.score = props.score || defaultScore
    })

    // 디버깅 코드: 모든 다이아몬드의 점수를 확인
    const a = this.getChildren().map((diamond) => diamond.score)
    debugger
  }

  // 속성 리스트를 객체로 변환하는 함수
  mapProperties(propertiesList) {
    if (!propertiesList || propertiesList.length === 0) {
      return {} // 속성이 없으면 빈 객체 반환
    }
    return propertiesList.reduce((map, obj) => {
      map[obj.name] = obj.value
      return map
    }, {})
  }
}

export default Collectables
```

## 3. `Collectable` 클래스에서 속성 적용

```jsx
각 개별 Collectable(다이아몬드) 객체는 기본적으로 score 값을 1로 가지며,
```

```jsx
class Collectable extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key)

    scene.add.existing(this)

    this.score = 1 // 기본 점수 설정

    this.setOrigin(0, 1) // 좌측 하단을 기준으로 위치 설정

    // 부드러운 애니메이션 적용 (상하로 약간 움직이는 효과)
    scene.tweens.add({
      targets: this,
      y: this.y - 3,
      duration: Phaser.Math.Between(1500, 2500),
      repeat: -1,
      ease: 'Linear',
      yoyo: true,
    })
  }
}
```

## 3. `this`의 컨텍스트 문제 해결 ( `context`를 전달하여 `this` 유지하기 )

```jsx
addOverlap 또는 addCollider는 콜백 함수의

this가 자동으로 현재 씬이 아니라 콜백이 호출된 객체로 바뀌는 문제가 있습니다.

이를 해결하려면 컨텍스트를 명확히 지정해야 합니다.

이제 onCollect을 사용할 때 this 컨텍스트가 올바르게 유지되도록 설정합니다.

this.onCollect을 실행할 때 this가 **현재 씬(Scene)**이 되도록 this를 추가로 전달합니다.

이를 통해 onCollect 내부에서 this.score를 올바르게 참조할 수 있습니다.
```

### 코드 수정

```jsx
createPlayerColliders(player, { colliders }) {
    player
        .addColliders(colliders.platformsColliders)
        .addColliders(colliders.projectiles, this.onWeaponHit)
        .addOverlap(colliders.collectables, this.onCollect, this);  // 🎯 this(씬)를 컨텍스트로 전달
}
```

## `this` 컨텍스트 유지 문제 해결하기

```jsx
문제점:

this.score를 onCollect에서 사용하려 했지만, this가 기대한 컨텍스트(즉, 현재 씬)가 아님

this가 콜백 함수 내에서 달라질 수 있음
```

```jsx
해결 방법:

콜라이더와 오버랩 설정에서 context를 명시적으로 전달

콜백 함수가 this를 올바르게 참조하도록 보장
```

```jsx
export default {
  // 다른 게임 오브젝트와 충돌 감지를 추가하는 함수
  addColliders(otherGameObject, callback, context) {
    // 현재 객체(this)와 otherGameObject 간의 충돌 감지를 추가
    // 충돌 시 callback 함수가 실행됨
    // context를 지정하지 않으면 기본적으로 this(현재 객체)를 사용
    this.scene.physics.add.collider(this, otherGameObject, callback, null, context || this)

    // 메서드 체이닝을 위해 this(현재 객체) 반환
    return this
  },

  // 다른 게임 오브젝트와 겹침(overlap) 감지를 추가하는 함수
  addOverlap(otherGameObject, callback, context) {
    // 현재 객체(this)와 otherGameObject 간의 겹침(overlap) 감지를 추가
    // 겹칠 때 callback 함수가 실행됨
    // context를 지정하지 않으면 기본적으로 this(현재 객체)를 사용
    this.scene.physics.add.overlap(this, otherGameObject, callback, null, context || this)

    // 메서드 체이닝을 위해 this(현재 객체) 반환
    return this
  },
}
```

```jsx
context || this를 사용하여 콜백 함수가 실행될 때 this가 유지되도록 보장합니다.

context가 명시적으로 전달되지 않으면, 기본적으로 this(현재 객체)를 사용합니다.
```

## 1. HUD 개념 이해

```jsx

컨테이너를 사용하면 내부 요소들이 컨테이너를 따라 움직이므로, UI 요소를 쉽게 배치할 수 있다.
```

## 2. HUD 컨테이너 생성

### HUD 클래스 구현 (`Hud.js`)

```jsx
import Phaser from 'phaser' // Phaser 라이브러리 불러오기

// HUD (Head-Up Display) 클래스: 게임 화면 상단에 점수를 표시하는 UI 요소
class Hud extends Phaser.GameObjects.Container {
  /**
   * HUD 생성자
   * @param {Phaser.Scene} scene - HUD가 추가될 씬
   * @param {number} x - HUD의 초기 X 좌표 (사용하지 않음)
   * @param {number} y - HUD의 초기 Y 좌표 (사용하지 않음)
   */
  constructor(scene, x, y) {
    super(scene, x, y) // Phaser 컨테이너 객체 생성
    scene.add.existing(this) // 현재 씬(scene)에 이 컨테이너를 추가

    // 씬의 설정 정보에서 오른쪽 상단 좌표(rightTopCorner) 가져오기
    const { rightTopCorner } = scene.config

    // HUD 위치 조정: 화면 오른쪽 상단에서 약간 왼쪽(-50)과 아래(+5)로 이동
    this.setPosition(rightTopCorner.x - 50, rightTopCorner.y + 5)

    // HUD는 카메라 이동에 영향을 받지 않도록 설정 (고정 UI 역할)
    this.setScrollFactor(0)

    // HUD 내부에 점수 표시용 텍스트 요소 추가
    this.setupList()
  }

  /**
   * HUD 내부 UI 요소 설정 (점수 텍스트 추가)
   */
  setupList() {
    this.fontSize = 20 // 폰트 크기 설정

    // Phaser의 text 객체를 사용하여 점수 텍스트 생성
    const scoreBoard = this.scene.add.text(
      0, // 컨테이너 내부에서의 X 좌표 (기본값: 0, 컨테이너 기준)
      0, // 컨테이너 내부에서의 Y 좌표 (기본값: 0, 컨테이너 기준)
      '0', // 초기 점수 (기본값: 0)
      {
        fontSize: `${this.fontSize}px`, // 텍스트 크기 설정
        fill: '#fff', // 텍스트 색상 (흰색)
      }
    )

    // 생성한 점수 텍스트를 컨테이너에 추가
    this.add(scoreBoard)
  }
}

export default Hud // Hud 클래스를 외부에서 사용할 수 있도록 내보내기
```

```jsx
Hud 클래스는 Phaser.GameObjects.Container를 확장하여 사용.

rightTopCorner 좌표를 가져와 HUD 위치를 설정.

setScrollFactor(0)을 사용해 카메라 이동 시 HUD가 고정되도록 설정.

setupList()에서 점수 표시용 Text 객체를 생성하여 컨테이너에 추가.

```

## 설명

```jsx
1. Hud 클래스는 Phaser의 Container를 상속받아 UI 요소들을 그룹으로 관리하는 역할을 합니다.
```

```jsx
import Phaser from 'phaser'

// Phaser의 컨테이너 클래스를 상속받아 Hud(점수판 UI)를 생성하는 클래스
class Hud extends Phaser.GameObjects.Container {
  constructor(scene, x, y) {
    super(scene, x, y) // 부모 클래스(Container) 생성자 호출

    scene.add.existing(this) // 현재 컨테이너를 Phaser 씬에 추가

    // 게임 씬의 설정 값에서 우측 상단 모서리 위치를 가져옴

    // HUD의 초기 위치를 우측 상단 모서리 기준으로 설정
    this.setPosition(rightTopCorner.x - 75, rightTopCorner.y + 5)
    this.setScrollFactor(0) // 스크롤 시 HUD가 움직이지 않도록 고정

    this.setupList() // 점수판 리스트를 설정하는 함수 호출
  }

  setupList() {

    // 첫 번째 점수판: 기본 점수 0
```

# { 트랩 충돌 시 반동(bounce off) 수정하기 }

## 1. **문제점: 트랩 충돌 시 반동 방향이 잘못됨**

```jsx
현재 플레이어가 트랩과 충돌했을 때 반동하는

방식이 적과 무기와 충돌할 때의 방식과 동일하게 동작하고 있습니다.

하지만, 타일(tile)과 충돌하는 경우에는 다른 속성이 필요합니다.
```

## 2. **기존 코드의 문제점**

```jsx
1. 적(enemy)이나 무기(weapon)과 충돌할 때는 touching 속성을 사용하여 충돌 방향을 판별합니다.

2. 하지만, 타일(tile) 과 충돌할 때는 touching 속성이 아니라 blocked 속성을 사용해야 합니다.

3. 현재 코드에서는 이 차이를 고려하지 않아, 타일과 충돌할 때 반동이 올바르게 적용되지 않는 문제가 발생했습니다.
```

## 3. **수정 방법**

```jsx
1. bounceOff(source) 함수에서 소스(source)에 body가 있는지 확인합니다.

2. 만약 body가 존재한다면, 기존처럼 touching.right을 사용하여 반동합니다.

   body가 없다면 (즉, 타일과 충돌한 경우), blocked.right 속성을 사용하여 반동합니다.

3. 일정 시간 후 Y축 방향으로도 반동을 적용하여 트랩에서 튕겨 나가도록 설정합니다.
```

## `touching` vs `blocked` 차이점

```jsx
Phaser에서 객체가 다른 물체와 충돌할 때, 충돌이 감지되는 방식은 두 가지가 있습니다.

바로 touching 속성과 blocked 속성입니다.
```

### `touching` 속성 (Moving Object vs Moving Object)

```jsx
움직이는 객체끼리(Moving Objects) 충돌할 때 사용

예를 들어, 플레이어가 적(enemy)이나 무기(weapon)와 충돌할 때 사용됨.

충돌 후에도 상대 객체(예: 적, 무기)가 움직일 수 있음.

touching은 충돌한 순간에만 true가 되고, 그 이후에는 false로 초기화됨.
```

### `blocked` 속성 (Moving Object vs Static Object)

```jsx
움직이는 객체가 고정된 객체(Static Object)와 충돌할 때 사용

예를 들어, 플레이어가 벽이나 타일에 부딪힐 때 사용됨.

벽이나 타일은 움직이지 않지만, 플레이어는 멈추거나 반동(bounce)할 수 있음.

플레이어가 벽에 막혀서 더 이상 이동할 수 없을 때 해당 방향의 blocked 값이 true가 됨.
```

## 4. **수정된 코드 설명**

```jsx
bounceOff(source) {
    if (source.body) {
        // 적(enemy)이나 무기(weapon)와 충돌한 경우 -> touching 사용
        this.body.touching.right
            ? this.setVelocity(-this.bounceVelocity, -this.bounceVelocity) // 왼쪽으로 튕김
            : this.setVelocity(this.bounceVelocity, -this.bounceVelocity);  // 오른쪽으로 튕김
    } else {
        // 타일(tile)과 충돌한 경우 -> blocked 사용
        this.body.blocked.right
            ? this.setVelocity(-this.bounceVelocity, -this.bounceVelocity)
            : this.setVelocity(this.bounceVelocity, -this.bounceVelocity);
    }

    // 일정 시간 후 Y축 방향 반동 추가
    setTimeout(() => this.setVelocityY(-this.bounceVelocity), 0);
}

```
