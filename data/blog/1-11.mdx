# 1. 프로젝트 개요

## 목적

```csharp
* 간단한 심리테스트와 짧은 미니게임을 통해 사용자 참여 유도

* 친구 초대·대결·협동 요소를 통한 자발적 바이럴 유도

* 한 포털 안에서 다양한 콘텐츠를 제공하여 SEO + SNS 유입 극대화

* 결과적으로 광고·부분 유료화·브랜드 제휴로 수익화
```

# 2. 핵심 기능

## 심리테스트 플랫폼

```csharp
* 간단한 질문형 테스트 (성향, 성격, 연애, MBTI 등)

* 결과 페이지에서 SNS 공유 버튼 (카카오톡, 트위터, 인스타 등) 제공

* “OO 결과 보기” 버튼 클릭 시 광고 삽입 이후 추가적인 소액 결제 옵션
```

## 미니게임 플랫폼

```csharp
* Unity 기반의 웹 미니게임 (1분 내외)

* PC & 모바일 모두 대응하는 반응형 게임 UI

* 인기 게임 순위, 최신 게임 필터링 기능
```

## 미니 게임 종류 ( 멀티 플레이 )

### 1:1 대결 모드

```csharp
* 실시간 반응속도 게임, 퀴즈 대결 등

* 공유 링크로 친구 초대 → 승패 결과 자동 공유

* 승리 시 순위 랭킹 반영
```

### 협동 모드

```csharp
* 제한 시간 내 두 명이 함께 푸는 퍼즐/미션

* 완수 시 협동 결과 카드 생성 → 공유 유도 ( 심리 테스트와 비슷한 결과 카드 누구와 궁합이 몇퍼센트 )
```

# 4. 기술 스택

```csharp
✅ 프론트엔드

		React 기반 SPA로 개발

		SEO 보완을 위해 React Helmet을 사용하여 메타태그 동적 생성

		Prerender.io 등을 활용해 검색 엔진용 정적 HTML 사전 생성

		OG 이미지 및 SNS 공유 최적화를 위한 태그 구성

✅ 백엔드

		Node.js + Express

		RESTful API 서버 구성

		실시간 기능을 위한 Socket.IO 연동 (게임 대결, 협력 등)

✅ 게임

		Unity WebGL로 개발하여 브라우저 기반 플레이 지원

		멀티플레이 기능은 Mirror 또는 Photon을 사용해 구현 ( 오픈소스 Unity용 멀티플레이 네트워킹 프레임워크 )

		모바일 및 데스크탑 환경 모두에서 실행 가능한 반응형 설계

✅ 실시간 통신

		Socket.IO를 통해 사용자 간 실시간 연결

		1:1 대결, 협동 모드 등 동기화 및 실시간 데이터 송수신 담당

✅ 데이터베이스

		Firebase Authentication: 간단한 로그인 및 유저 관리 ( Google에서 제공하는 사용자 인증 서비스 )

		Supabase 또는 MongoDB Atlas: 게임 기록, 테스트 결과 등 저장 ( "오픈소스 Firebase"라고 불리는 백엔드 플랫폼 )

		확장성과 실시간 동기화에 유리한 구조

✅ 배포/호스팅

		Vercel: React 프론트엔드 배포

		Firebase Hosting: Unity 게임 및 정적 파일 배포 (CDN 제공)

		( 정적 파일(예: 게임, 이미지, HTML 등)을 인터넷에 배포할 수 있게 해주는 클라우드 서비스 )

✅ 분석 도구

		Google Analytics: 사용자 트래픽 분석

		Facebook Pixel: 리타겟팅 광고 설정

		Naver Search Advisor: 국내 검색엔진 등록 및 유입 분석

✅ 광고 수익화

		Google AdSense 및 Kakao AdFit

		테스트 결과 페이지, 게임 종료 시 광고 삽입

		보상형 광고(예: 영상 보기 후 다시하기 기회 제공)도 적용 가능

✅ 결제 시스템

		Toss Payments 또는 Iamport 등등

		프리미엄 테스트 결과, 유료 아이템, 꾸미기 기능 등 결제 연동 가능

		국내 사용자를 위한 간편결제 UI 제공
```

# 5. 수익 모델

```csharp
✅ 광고 수익

		Google AdSense, Kakao AdFit을 통한 배너 광고 및 인피드 광고

		테스트 결과 페이지, 게임 종료 화면 등에 자연스럽게 배치

		보상형 광고도 도입 가능 (예: 광고 시청 후 테스트 결과 보기 or 게임 다시 도전)

✅ 프리미엄 콘텐츠

		테스트 결과 일부 잠금 후 소액 결제로 해제 가능 (ex. 연애 유형 상세 분석 등)

		간편결제 시스템 연동 (Toss, Iamport 등)

✅ 제휴 마케팅

		브랜드와 협업하여 콜라보 심리테스트 또는 전용 미니게임 제작

		예시: “스타벅스 유형 테스트”, “카카오프렌즈와 궁합 맞춰보기”

		기업 측 트래픽 유입 + 사용자 경험 결합으로 마케팅 효과 극대화

✅ 데이터 기반 수익

		사용자 성향 데이터를 익명화 처리하여 통계적 인사이트 제공

		특정 연령대의 테스트 결과 분석 리포트를 B2B 형태로 판매

		모든 데이터는 선택형 동의 기반으로 수집 및 활용 (개인정보 보호 법규 준수)
```

# 6. 콘텐츠 예시

## 심리테스트 아이디어

```csharp
"나의 연애 스타일은?"

"나는 어떤 동물과 닮았을까?"

"MBTI와 다른 나만의 성격 유형"

"스트레스 받을 때 나는?"

"직장에서 나는 어떤 타입?"

"나의 숨겨진 욕망 테스트"

"나는 어떤 전생의 인물이었을까?"

"친구가 보는 내 이미지는?"

"이상형 월드컵 결과로 보는 연애 유형"

"먹는 취향으로 알아보는 성격"
```

## 미니게임 아이디어

```csharp
"반응속도 테스트" – 클릭 타이밍 정확도

"기억력 순서 게임" – 제시된 순서대로 기억해 클릭

"타이밍 점프" – 정확한 타이밍으로 캐릭터 점프

"랜덤 단어 맞추기" – 제한 시간 내 정답 추리

"캐릭터 날리기" – 각도와 세기로 가장 멀리 보내기

"눈치 게임" – 적절한 타이밍에 멈추기 or 누르기

술게임 등등 기존의 단순하고 익숙한 게임에서 아이디어를 얻기
```

## 대결형 게임 아이디어 (1:1)

```csharp
"누가 더 빨리 누를까?" – 반응속도 대결

"1초 타이머 게임" – 정확히 1초를 누가 더 가깝게 누르나

"기억력 대결" – 더 긴 패턴을 기억하는 사람이 승리

"타이핑 배틀" – 제시된 문장을 누가 더 빨리 타이핑하나

"숨은그림찾기 대결" – 시간 안에 더 많이 찾기
```

## 협동형 게임 아이디어 (2인 플레이)

```csharp
"기억력 퍼즐 맞추기" – 번갈아가며 기억한 위치 클릭

"타이밍 미션 성공시키기" – 동시에 버튼 누르기, 타이밍 맞추기

"랜덤 퀴즈 연속 정답" – 둘이 번갈아 문제 풀기

"조립 협력 게임" – 각자 부품을 정확히 조립

"숫자 합 맞추기" – 서로 다른 숫자를 더해 정답 맞추기

"심리 테스트 결과 싱크 맞추기" – 각자 고른 답이 얼마나 일치하는지 확인

"방탈출 미션 (초간단형)" – 제한 시간 안에 단서 클릭, 간단 퀴즈 풀기
```
