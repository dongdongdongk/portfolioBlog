### 왜 분리하나요?

**LastKnownPlayerLocation 특성:**

```
언제 업데이트?
  → Chase 중에만!
  → Investigate나 Return 중엔 의미 없음

  → Chase = 플레이어 보는 중
  → 보는 동안만 위치 알 수 있음
  → 당연히 Chase에서만 업데이트!
```

**위치 비교:**

```
Selector
  [PlayerLocationIfSeen]
  ├─ Chase
  │   [PlayerLocation] ← 여기!
  │   └─ Move To
  ├─ Investigate
  └─ Return
```

### 2-2: TickNode 구현

**전체 코드:**

```cpp
void UBTService_PlayerLocation::TickNode(
    UBehaviorTreeComponent& OwnerComp,
    uint8* NodeMemory,
    float DeltaSeconds
)
{
    // ===== 1. Super 호출 =====
    Super::TickNode(OwnerComp, NodeMemory, DeltaSeconds);

    // ===== 2. Player Pawn 가져오기 =====
    APawn* PlayerPawn = UGameplayStatics::GetPlayerPawn(GetWorld(), 0);

    // ===== 3. Blackboard 가져오기 =====
    UBlackboardComponent* Blackboard = OwnerComp.GetBlackboardComponent();

    // ===== 4. 유효성 확인 후 설정 =====
    if (PlayerPawn && Blackboard)
    {
        Blackboard->SetValueAsVector(
            GetSelectedBlackboardKey(),
            PlayerPawn->GetActorLocation()
        );
    }
}
```

## 🔍 코드 상세 분석

### GetPlayerPawn vs AI Controller

**이전 방식 (PlayerLocationIfSeen):**

```cpp
// AI Controller 통해서
AShooterAI* OwnerController = Cast<AShooterAI>(OwnerComp.GetAIOwner());
AShooterSamCharacter* Player = OwnerController->PlayerCharacter;
```

**새 방식 (PlayerLocation):**

```cpp
// GameplayStatics 직접 사용
APawn* PlayerPawn = UGameplayStatics::GetPlayerPawn(GetWorld(), 0);
```

---

**GetPlayerPawn 함수:**

```cpp
static APawn* GetPlayerPawn(
    const UObject* WorldContextObject,
    int32 PlayerIndex
)
```

**파라미터:**

**1. WorldContextObject**

```cpp
GetWorld()
```

- 현재 월드 객체
- Service도 UObject 상속
- GetWorld() 사용 가능!

**2. PlayerIndex**

```
0: 첫 번째 플레이어
1: 두 번째 플레이어 (멀티플레이어)
...

대부분 0 사용!
```

---

**반환값: APawn\***

```cpp
APawn* PlayerPawn
```

**왜 APawn?**

```
모든 플레이어는 Pawn
  ↓
Character도 Pawn 상속
  ↓
GetActorLocation() 사용 가능
  ↓
위치만 필요하니 Cast 불필요!
```

---

### GetBlackboardComponent

**이전 방식:**

```cpp
// AI Controller 통해서
AShooterAI* OwnerController = ...;
UBlackboardComponent* Blackboard = OwnerController->GetBlackboardComponent();
```

**새 방식:**

```cpp
// OwnerComp에서 직접
UBlackboardComponent* Blackboard = OwnerComp.GetBlackboardComponent();
```

**왜 간단?**

```
OwnerComp (참조):
  BehaviorTreeComponent
  ↓
BT는 항상 Blackboard 가짐
  ↓
직접 가져오기 가능!
  ↓
AI Controller 거칠 필요 없음
```

---

### 유효성 확인

```cpp
if (PlayerPawn && Blackboard)
{
    // 설정
}
```

**왜 2개만 확인?**

**PlayerPawn:**

```
GetPlayerPawn 실패 가능
→ nullptr 반환 가능
```

**Blackboard:**

```
GetBlackboardComponent 실패 가능
→ nullptr 반환 가능
```

**AI Controller는?**

```
확인 안 해도 됨!
→ 이번엔 안 씀
```

---

### 위치 설정

```cpp
Blackboard->SetValueAsVector(

**GetSelectedBlackboardKey():**

```
에디터에서 선택한 Key

```

**PlayerPawn->GetActorLocation():**

```
플레이어 현재 위치
  ↓
FVector (X, Y, Z)
```

### ExecuteTask란?

**Service의 TickNode vs Task의 ExecuteTask**

**TickNode (Service):**

```

## 💡 실전 팁

### ExecuteTask vs TickNode

**단순 작업:**

```cpp
// ExecuteTask 사용
EBTNodeResult::Type ExecuteTask(...)
{
    DoSomething();  // 한 번만
    return Succeeded;
}
```

**복잡한 작업:**

```cpp
// TickTask 사용 (고급)
void TickTask(...)
{
    // 매 프레임 체크
    if (Complete)
    {
        FinishExecute(Succeeded);
    }
}
```

---

### 반환값 선택

**성공/실패만:**

```cpp
// 대부분의 경우
if (Success)
    return Succeeded;
else
    return Failed;
```

**여러 프레임:**

```cpp
// 복잡한 경우
StartTask();
return InProgress;
// TickTask에서 나중에 완료
```

## 💀 Step 4: 사망 처리

### DetachFromControllerPendingDestroy

**ShooterSamCharacter.cpp:**

```cpp
void AShooterSamCharacter::OnDamageTaken(...)
{
    if (!IsAlive) return;

    if (IsAlive)
    {
        Health -= Damage;

        if (Health <= 0.0f)
        {
            IsAlive = false;
            Health = 0.0f;

            // 충돌 끄기
            GetCapsuleComponent()->SetCollisionEnabled(ECollisionEnabled::NoCollision);

            // ===== 컨트롤러 분리 =====
            DetachFromControllerPendingDestroy();
        }
    }
}
```

---

**DetachFromControllerPendingDestroy란?**

**효과:**

```
캐릭터 ← Controller 연결 끊기
  ↓
더 이상 입력 안 받음
  ↓
카메라 제어 안 됨
  ↓
사망 상태!
```

**왜 필요?**

**분리 안 하면:**

```
사망 후에도:
  - 마우스로 카메라 회전 가능
  - WASD 입력 받음 (움직이진 않지만)
  - 이상함!
```

**분리하면:**

```
사망 후:
  - 입력 전부 무시
  - 완전한 사망 상태
  - 자연스러움! ✅
```
