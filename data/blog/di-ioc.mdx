## 객체 생성

```jsx
1. Annotation
	 @Controller      : 객체 생성, Constroller 역할
	 @Service         : 객체 생성, Service 역할
	 @Repository      : 객체 생성, DAO 역할
	 @Mapper          : 객체 생성, DAO 역할(Interface)

	 @ExceptionHandler
	 @ControllerAdvice:

	 @RestController  : 모든 메서드에 @Responsebody가 있다면 해당 Controller 를
	                    RestController Annotation으로 바꾸고 	@Responsebody를 생략

	 @ResponseBody    : 응답을 JSON 변경해서 내보냄
	 @RequestBody     : 요청 파라미터를 JSON으로 받음

	 @RequestParam    : 파라미터의 이름과 매개변수명이 일치하지 않을때나, 기본값,
										  또는 필수 여부 지정
											setAdd(@RequestParam(value="n", defaultValue="1", required=fasle) int num)

	 @ModelAttribute  :

	 @GetMapping
	 @PostMapping
	 @RequestMapping

	 @Value           : properties파일의 내용을 java에서 사용
	 @PathVariable    : URL의 일부분을 Data로 사용
			@GetMapping("/fileDown/{p}") //RestFul, RestAPI
			public ModelAndView fileDown(@PathVariable(name = "p") String path,

	 --
	 @Configuration   : 객체 생성, 설정 파일역할

```
