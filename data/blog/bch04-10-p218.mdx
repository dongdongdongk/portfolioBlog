```java
여기서는 한꺼번에 두가지 빌더를 사용한다 타입 정보 & 검색 조건 그리고 BooleanBuilder 을 리턴 해준다
```

```java
 private BooleanBuilder getSearch(PageRequestDTO requestDTO) {

        String type = requestDTO.getType(); // 타입 정보 얻어오기 (제목,작성자,내용)

        BooleanBuilder booleanBuilder = new BooleanBuilder(); // 불리언 빌더 생성

        if(type == null || type.trim().length() == 0) { // 검색 조건이 없는 경우 끝
            return booleanBuilder;
        }

        QGuestbook qGuestbook = QGuestbook.guestbook; // Q도메인 객체

        String keyword = requestDTO.getKeyword(); // 키워드 받아오기

        BooleanExpression expression = qGuestbook.gno.gt(0L); // gno > 0 조건만 생성

        booleanBuilder.and(expression); // booleanBuilder 에 조건 추가

        // 검색 조건 작성하기
        BooleanBuilder conditionBuilder = new BooleanBuilder();

        if (type.contains("t")) {
            conditionBuilder.or(qGuestbook.title.contains(keyword)); // or or 로 계속 추가중
        }
        if (type.contains("c")) {
            conditionBuilder.or(qGuestbook.content.contains(keyword));
        }
        if (type.contains("w")) {
            conditionBuilder.or(qGuestbook.writer.contains(keyword));
        }

        // 모든 조건 통합
        booleanBuilder.and(conditionBuilder);

        return booleanBuilder;
    }
```

## js 를 수정해서 form 에 type, keyword 값 보내주기

```java
<script th:inline="javascript">
      const removeBtn = document.querySelector(".removeBtn");
      const actionForm = document.querySelector("form");
      const modifyBtn = document.querySelector(".modifyBtn");
      const pageInfo = document.querySelector("input[name='page']");
      const typeInfo = document.querySelector("input[name='type']");
      const keywordInfo = document.querySelector("input[name='keyword']");
      const listBtn = document.querySelector(".listBtn");
      removeBtn.addEventListener('click', function (){
        actionForm.setAttribute("action","/guestbook/remove")
        actionForm.method = "post";
        actionForm.submit();
      });

      modifyBtn.addEventListener('click', function (){
        if(!confirm("수정하시겠습니까?")){
          return;
        }
        actionForm.setAttribute("action", "/guestbook/modify")
        actionForm.method = "post"
        actionForm.submit();
      });

      listBtn.addEventListener("click", function (){
        actionForm.innerHTML=""; //form 태그의 내용 삭제
        actionForm.append(pageInfo); // 목록에 필요한 페이지 값 추가
        actionForm.append(typeInfo); // 목록에 필요한 타입 값 추가
        actionForm.append(keywordInfo); // 목록에 필요한 키워드 값 추가
        actionForm.setAttribute("action", "/guestbook/list")
        actionForm.method = "get";
        actionForm.submit();
      });

    </script>
```
