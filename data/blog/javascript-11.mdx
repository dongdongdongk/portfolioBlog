## Truthy , False-y 값

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381368/notion-blog/_/The_Web_Developer_2022/JavaScript/Javascript_/Untitled_2.png)

```java
자바스크립트에서 Truthy와 Falsy는 '참 같은 값'과 '거짓 같은 값'을 뜻함.

이 값들은 자바스크립트에서 조건문과 반복문 등

boolean값이 필요한 곳에서 각각 true와 false로 평가됨.
```

```java
Truthy

1. true: 불리언 값 true
2. 숫자: 0이 아닌 모든 숫자 (양수, 음수, 소수 등)
3. 문자열: 비어 있지 않은 모든 문자열
4. 객체: 비어 있지 않은 모든 객체 (배열, 함수 등)
5. 배열: 비어 있지 않은 모든 배열
6. 함수: 비어 있지 않은 모든 함수
7. 정규 표현식: 유효한 정규 표현식 객체

Falsy

1. false: 불리언 값 false
2. 0: 숫자 0
3. NaN: 숫자가 아닌 값
4. null: 값이 없음을 나타내는 특별한 값
5. undefined: 값이 할당되지 않음을 나타내는 특별한 값
6. 빈 문자열: ""
7. null 또는 undefined로 평가되는 변수 또는 표현식

* Truthy 값은 조건문에서 if, while, for 등의 논리적 판단에 사용될 때 true로 평가되며,

Falsy 값은 false로 평가됨. 이러한 개념은 조건식을 평가하거나 변수의 유효성을 확인하는 등의

상황에서 유용하게 사용될 수 있다.
```
