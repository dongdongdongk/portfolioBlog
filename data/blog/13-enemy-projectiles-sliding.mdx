```jsx
이 강의에서는 Phaser를 활용하여 적(Enemy)의 투사체(Projectile)와 플레이어 간의 충돌을 구현하는 방법을 다룹니다.
```

## 1. **적의 투사체 그룹 생성하기**

```jsx
적들은 특정한 경우에만 투사체(Projectile)를 발사할 수 있습니다.

따라서, 모든 적이 투사체를 가지고 있는 것은 아니므로,

우리는 투사체를 가진 적들만을 따로 모아 그룹으로 관리해야 합니다.

우선, 적들의 그룹을 관리하는 Enemies.js 파일에서 투사체를 가져오는 메서드를 추가합니다.
```

### `getProjectiles()` 메서드

```jsx
getProjectiles() {
    // 새로운 그룹 생성 (투사체들을 담을 그룹)
    const projectiles = new Phaser.GameObjects.Group(this.scene);

    // 그룹에 속한 모든 적을 가져온 후 반복문 실행
    this.getChildren().forEach(enemy => {
        // 해당 적이 투사체를 가지고 있다면 그룹에 추가
        if (enemy.projectiles) {
            projectiles.addMultiple(enemy.projectiles.getChildren());
        }
    });

    return projectiles;
}
```

```jsx
this.getChildren() → 현재 적 그룹에 포함된 모든 적 객체를 가져옴

enemy.projectiles 확인 → 특정 적이 투사체를 가지고 있는지 확인

projectiles.addMultiple(enemy.projectiles.getChildren()) → 적이 가진 투사체들을 새로운 그룹에 추가
```

## 2. **플레이어와 적의 투사체 충돌 감지**

```jsx
위에서 만든 getProjectiles() 메서드를 이용하여, 플레이어와 적의 투사체 간 충돌을 감지하는 코드를 작성합니다.

이 코드는 Play.js에서 작성됩니다.
```

### `createPlayerColliders()` 메서드 수정

```jsx
createPlayerColliders(player, { colliders }) {
    player
        .addColliders(colliders.platformsColliders) // 플랫폼과의 충돌
        .addColliders(colliders.projectiles, this.onWeaponHit); // 적 투사체와 충돌
}
```

```jsx
colliders.platformsColliders → 플레이어가 플랫폼과 충돌 가능하도록 설정

colliders.projectiles → 적의 투사체와 충돌 시 onWeaponHit() 함수 실행
```

```jsx
class Play extends Phaser.Scene {
  constructor(config) {
    super('PlayScene')
    this.config = config
  }

  create() {
    const map = this.createMap()
    const layers = this.createLayers(map)
    const playerZones = this.getPlayerZones(layers.playerZones)
    const player = this.createPlayer(playerZones.start)

    const enemies = this.createEnemies(layers.enemySpawns, layers.platformsColliders)

    this.createPlayerColliders(player, {
      // 플레이어와 충돌할 여러 객체들을 등록
      colliders: {
        platformsColliders: layers.platformsColliders,
        projectiles: enemies.getProjectiles(),
      },
    })

    this.createEnemyColliders(enemies, {
      colliders: {
        platformsColliders: layers.platformsColliders,
        player,
      },
    })

    this.createEndOfLevel(playerZones.end, player)
    this.setupFollowupCameraOn(player)
    initAnims(this.anims)
  }

  createPlayerColliders(player, { colliders }) {
    // 플레이어와 충돌체들 간의 충돌 처리를 등록
    player
      .addColliders(colliders.platformsColliders) // 플랫폼 충돌 추가  addColliders = 플레이어 객체에 충돌체를 추가하는 역할
      .addColliders(colliders.projectiles, this.onWeaponHit) // 적의 투사체와 충돌 추가, 충돌 시 `onWeaponHit` 함수 실행
  }

  onWeaponHit(entity, source) {
    entity.takesHit(source)
  }
}
```

### `onWeaponHit()` 메서드


```jsx

즉, 적의 투사체가 플레이어와 충돌하면 takesHit() 메서드가 실행되어 플레이어가 피해를 입게 됩니다.
```

# { 플레이어 피격 기능 개선 정리 }

```jsx
이번 강의에서는 플레이어가 적의 발사체에 맞았을 때의 동작을 개선합니다.

현재는 플레이어가 피격되었을 때 발사체가 그대로 남아 있고,

속도가 감소하는 문제가 있습니다. 이를 해결하기 위해, 적과 동일한 방식으로 피격을 처리하도록 개선합니다.
```

## 1. 기존 문제점

```jsx
플레이어가 적의 발사체(Projectile)에 맞아도 발사체가 사라지지 않고 남아 있음.

발사체의 속도가 줄어들어 비정상적인 동작이 발생함.
```

## 2. 해결 방법

### 1) `takesHit` 메서드 수정

```jsx
takesHit 함수에서 발사체를 삭제하도록 수정합니다.

기존 코드에서는 initiator라는 변수를 사용하여 공격자를 정의했지만,

다양한 공격 요소(발사체, 함정 등)를 고려하여 source라는 보다 일반적인 이름으로 변경합니다.
```

### 2) 코드 수정

### 변경 전

```jsx
takesHit(initiator) {
    if (this.hasBeenHit) {
        return;
    }
    console.log("player got hit");
    this.hasBeenHit = true;
    this.bounceOff();
    const hitAim = this.playDamageTween();

    this.health -= initiator.damage;
    this.hp.decrease(this.health);

    this.scene.time.delayedCall(800, () => {
        this.hasBeenHit = false;
        hitAim.stop();
        this.clearTint();
    });
}

```

### 변경 후

```jsx
takesHit(source) {
    if (this.hasBeenHit) {
        return;
    }
    console.log("player got hit");
    this.hasBeenHit = true;
    this.bounceOff();
    const hitAim = this.playDamageTween();

    this.health -= source.damage;
    this.hp.decrease(this.health);

    // 공격을 가한 오브젝트의 `deliversHit` 메서드 호출 (예: 발사체 삭제)
    source.deliversHit && source.deliversHit(this); // 추가

    this.scene.time.delayedCall(800, () => {
        this.hasBeenHit = false;
        hitAim.stop();
        this.clearTint();
    });
}

```

### `source`란 무엇인가?

```jsx
source는 플레이어에게 피해를 준 오브젝트를 의미합니다.

예를 들어, 적이 발사한 발사체(Projectile)가 source가 될 수 있습니다.

source.deliversHit(this);는 공격이 성공적으로 맞았을 때, 해당 source가 수행해야 하는 동작을 실행합니다.
```

### Projectile 클래스 내 `deliversHit` 메서드

```jsx
deliversHit(target) {
    this.activateProjectile(false);  // 발사체 비활성화 (화면에서 숨김)
    this.traveledDistance = 0;       // 이동 거리 초기화
    const impactPosition = { x: this.x, y: this.y }; // 충돌 위치 저장
    this.body.reset(0, 0);           // 물리 엔진에서 초기화
    this.effectManager.playEffectOn('hit-effect', target, impactPosition); // 타격 효과 재생
}
```

### `source.deliversHit(this);`가 실행되면 무슨 일이 일어나는가?

```jsx
플레이어(Player) 입장에서

		takesHit(source) 메서드 실행

		플레이어의 체력이 감소하고 피격 애니메이션이 재생됨

		source.deliversHit(this); 호출 → Projectile.deliversHit(this) 실행

발사체(Projectile) 입장에서

		activateProjectile(false); 실행 → 발사체가 화면에서 사라짐

		this.traveledDistance = 0; → 이동 거리 초기화

		this.body.reset(0, 0); → 발사체의 위치를 초기화하여 게임 화면에서 제거

		playEffectOn('hit-effect', target, impactPosition); 실행 → 피격 효과를 표시
```

## `source`가 항상 `Projectile`이 아닐 수도 있다! ( 오류 )

```jsx
적의 투사체에 맞으면 충돌이 발생하는데 적과 직접 충돌하면 source 가 뭔지 찾을 수 없다면 오류가 발생하였고 아래 코드로 수정하여

문제를 해결하였다
```

```jsx
source.deliversHit && source.deliversHit(this)
```

```jsx
takesHit(source)가 호출될 때, source는 적(enemy) 또는 투사체(projectile)일 수 있습니다.

		투사체(Projectile): source.deliversHit(this); 실행 가능

		적(Enemy)과 직접 충돌: source.deliversHit가 없으므로 오류 발생 가능성 있음
```

### (예제 1) 적이 플레이어와 충돌하는 경우 (`source.deliversHit` 없음)

```jsx
// 적이 플레이어를 직접 공격할 경우
player.takesHit(enemy) // enemy 객체에는 deliversHit()가 없음!
```

```jsx
→ enemy.deliversHit(this); 를 실행하려고 하면 오류 발생 🚨

하지만 && 연산자를 사용하면 문제 없이 넘어감.
```

### (예제 2) 투사체가 플레이어를 명중한 경우 (`source.deliversHit` 있음)

```jsx
// 발사체가 플레이어를 명중할 경우
player.takesHit(projectile) // projectile 객체에는 deliversHit()가 있음!
```

```jsx
→ projectile.deliversHit(this); 실행됨
```

## 슬라이딩 기능 구현

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380485/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_13_Enemy_Projectiles_Sliding/image_2.png)

### 1) **플레이어의 `update()` 함수 수정**

```jsx
아래(↓) 키가 눌렸을 때 플레이어의 크기를 줄이고, 슬라이드 애니메이션을 실행하도록 설정한다.
```

```jsx
// 키보드 입력에서 특정 키(←, →, Space, ↓)를 가져옴
const { left, right, space, down } = this.cursors

// Space(점프) 키가 "딱 한 번" 눌렸는지 확인 (누른 순간만 true)
const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space)

// 플레이어가 바닥에 있는지 여부를 확인
const onFloor = this.body.onFloor()

if (down.isDown && onFloor) {
  // ↓(아래 방향키)가 눌렸고, 바닥에 있을 때만 실행
  // 플레이어의 충돌 판정 크기를 절반으로 줄임 (높이를 반으로 감소)
  this.body.setSize(this.width, this.height / 2)

  // 캐릭터의 충돌 판정 위치를 아래로 이동 (몸이 작아지므로 위치 조정)
  this.setOffset(0, this.height / 2)

  // 좌우 움직임을 멈춤 (슬라이딩 상태에서는 이동 불가)
  this.setVelocityX(0)
} else {
  // ↓ 키를 떼거나, 공중에 있을 때 실행
  // 충돌 판정 크기를 원래 크기로 되돌림 (높이를 38로 설정)
  this.body.setSize(this.width, 38)

  // 충돌 판정 위치를 원래대로 복구
  this.setOffset(0, 0)
}
```

## 버그 수정 (크기가 점점 줄어드는 문제)

```jsx
업데이트 함수가 매 프레임 호출되면서 몸 크기가 계속 줄어드는 문제가 발생한다.
```

### **수정 방법**:

```jsx
this.body.halfHeight를 사용하지 않고 **기본 높이 값(38px)**을 직접 설정
```

```jsx
if (down.isDown && onFloor) {
  this.body.setSize(this.width, 19) // 절반 크기 (38 / 2)
  this.setOffset(0, 19)
} else {
  this.body.setSize(this.width, 38) // 원래 크기로 복구
  this.setOffset(0, 0)
}
```

### 문제의 원리

```jsx
현재 코드에서 **this.body.setSize(this.width, this.height / 2)**를 사용하고 있습니다.

이 코드에서는 this.height가 매 프레임마다 업데이트되며,

그 값이 점점 줄어들기 때문에 몸의 크기도 계속 줄어드는 문제가 발생합니다.

왜냐하면 this.height는 원래 플레이어의 크기를 나타내고, 이 값을 기반으로 setSize()를 호출하므로 그 값이 계속 바뀌게 됩니다.
```

# { Phaser 게임 개발 - 플레이어 슬라이딩 기능 개선 }

```jsx
이번 강의에서는 플레이어의 슬라이딩 기능을 개선하는 작업을 진행했습니다.

기존에는 keydown-DOWN과 keyup-DOWN 이벤트를 handleMovement() 함수 내에서 직접 처리했지만,

더 깔끔하고 유지보수하기 쉽게 별도의 함수로 분리했습니다.
```

## 1. 슬라이딩 기능을 별도 함수로 분리

```jsx
기존에는 따로 슬라이딩을 처리했지만,

handleMovements() 함수를 새로 만들어 슬라이딩 동작을 분리했습니다.
```

```jsx
handleMovements() {
    this.scene.input.keyboard.on("keydown-DOWN", () => {
        if (!this.body.onFloor()) {
            return; // 공중에서는 슬라이딩 금지
        }
        this.body.setSize(this.width, this.height / 2);
        this.setOffset(0, this.height / 2);
        this.setVelocityX(0);
        this.play("slide", true);
        this.isSliding = true;
    });

    this.scene.input.keyboard.on("keyup-DOWN", () => {
        this.body.setSize(this.width, 38);
        this.setOffset(0, 0);
        this.isSliding = false;
    });
}

```

```jsx
슬라이딩이 독립적인 함수로 관리되어 코드가 더 깔끔해집니다.

keydown-DOWN과 keyup-DOWN 이벤트가 따로 관리되어 가독성이 좋아집니다.

공중에서는 슬라이딩이 불가능하도록 처리할 수도 있습니다.
```

## 2. 슬라이딩 중에는 다른 동작을 하지 않도록 설정

```jsx
업데이트 로직(update())에서 슬라이딩 중이면 다른 동작을 하지 않도록 했습니다.
```

```jsx
update() {
    if (this.hasBeenHit || this.isSliding) {
        return; // 피격 상태이거나 슬라이딩 중이면 다른 동작 X
    }

    const { left, right, space } = this.cursors;
    const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space);
    const onFloor = this.body.onFloor();

    if (left.isDown) {
        this.setVelocityX(-this.playerSpeed);
        this.setFlipX(true);
    } else if (right.isDown) {
        this.setVelocityX(this.playerSpeed);
        this.setFlipX(false);
    } else {
        this.setVelocityX(0);
    }

    if (isSpaceJustDown && (onFloor || this.jumpCount < this.consecutiveJumps)) {
        this.setVelocityY(this.jumpSpeed);
        this.jumpCount++;
    }

    if (onFloor) {
        this.jumpCount = 0;
    }

    if (this.isPlayingAnims("throw") || this.isPlayingAnims("slide")) {
        return;
    }

    onFloor
        ? this.body.velocity.x !== 0
            ? this.play("run", true)
            : this.play("idle", true)
        : this.play("jump", true);
}

```

```jsx
isSliding이 true일 때 플레이어의 이동, 점프, 공격 등의 행동이 멈춤

슬라이딩이 끝날 때까지 다른 애니메이션(걷기, 점프 등)이 실행되지 않음
```

## 3. 공중에서도 슬라이딩할 수 있도록 설정 (옵션)

```jsx
슬라이딩을 공중에서 할지 말지 선택 가능하도록 했습니다.
```

```jsx
this.scene.input.keyboard.on('keydown-DOWN', () => {
  if (!this.body.onFloor()) {
    return // 주석 처리하면 공중 슬라이딩 가능
  }
})
```

```jsx
만약 공중에서도 슬라이딩을 허용하고 싶다면,

위의 if (!this.body.onFloor()) return; 줄을 주석 처리하면 됨.

기본적으로는 바닥에서만 슬라이딩 가능하도록 설정.
```
