실시간으로 청소부 상태를 변경하는 기능을 만든다

## 1.Mapper 생성

```
오늘 청소를 하는 청소부 번호, 방번호, 방상태 를 가져오는 getRequestClean 를 작성해줬다.


```

### Mapper

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381059/notion-blog/_/_/Spring_/_/Untitled_1.png)

```java
<select id="getRequestClean" parameterType="ReservedVO" resultMap="getRequestCleanResult">
   SELECT DISTINCT C.SCHEDULENUMBER, R.ROOMNUMBER, ROOMSTATUS                                      // CALENDER' 테이블에서 'SCHEDULENUMBER', 'RESERVED' 테이블에서 'ROOMNUMBER', 두 테이블 중 하나에서 'ROOMSTATUS'를 선택
   FROM RESERVED R                                                                                 // 테이블이 조인되는 방식을 지정
   JOIN CALENDER C ON R.ROOMSTATUS = '청소요청' OR ROOMSTATUS = '청소중'                             // 조인 조건은 테이블의 'ROOMSTATUS'가 '청소 요청' 또는 '청소 진행 중'일 때 조인을 수행 (on 은 조인의 조건을 지정하는것)
	 WHERE CURRENT_DATE() BETWEEN C.SCHEDULESTARTDATE AND C.SCHEDULEENDDATE                          // 현재 날짜(CURRENT_DATE())가 CALENDER 테이블의 SCHEDULESTARTDATE 및 SCHEDULEENDDATE 열 사이에 있는지 확인
</select>
```

### resultMap

```java
조인을 사용해서 두개의 VO 를 합쳐서 사용하기 위해서 만들어 준다
```

```java
<resultMap type="CalenderVO" id="getRequestCleanResult">
        <id column="scheduleNumber" property="scheduleNumber"/>                                       // id 는 pk (이는 관행일 뿐이고 꼭 지켜야 하는건 아니다 꼭  scheduleNumber 가 되야하는건 아님)
        <result column="scheduleEnddate" property="scheduleEnddate"/>
        <result column="scheduleStartdate" property="scheduleStartdate"/>

        <collection property="reservedVOS" javaType="List" ofType="ReservedVO">                      // CalenderVO" 개체에서 "reservedVOS"라는 컬렉션 속성을 정의(CalenderVO 내부에 private List<ReservedVO> reservedVOS; 를 만들어 줘야함)  (collection 은 1:N 관계일때 사용) ( "CalenderVO" 에 "ReservedVO" 개체 모음이 포함되어 있음을 나타냄)
            <id column="reservationNum" property="reservationNum"/>
            <result column="reservationDate" property="reservationDate"/>
            <result column="roomNumber" property="roomNumber"/>
            <result column="roomType" property="roomType"/>
            <result column="roomStatus" property="roomStatus"/>
        </collection>
    </resultMap>
```

## 3.자바스크립트 작성

```java
onclick 을 사용할 함수를 작성해주고 Ajax 사용 + 몇초마다  새로고침(실시간을 위해서)
```

```java
$(document).ready(function() {
    // #insertSchedule 폼의 버튼 눌렀을 때 이벤트
    updateCardContainer();
});

function updateCardContainer() {                                                    //메인 jsp 에 분리해놓은 위의 jsp 를 넣어주기 위한 Ajax
    $.ajax({
        url: '/clean/cleanCheckList',
        method: 'GET',
        success: function (checkList) {

            $('#checkList').html(checkList);                                       // id 속성 "checkList"가 있는 요소의 HTML 콘텐츠를 업데이트, html() 함수는 요소의 내용을 checkList 변수의 값으로 가짐
        },
        error: function (error) {
            console.error('Error:', error);
        }
    });
}

setInterval(updateCardContainer, 3000);                                            // 3초마다 리셋 해주는 함수

function CleaningInProgress(roomNumber) {

    $.ajax({
        url:'/clean/updateCleaningInProgress',
        method: 'POST',
        data: {
            roomNumber: roomNumber,
        },
        success: function(response) {
            // Handle the success response
            console.log('Cleaning request sent');
        },
        error: function(error) {
            // Handle the error
            console.error('');
            alert("청소를 시작합니다.")
        }
    });
}

function CleaningComplete(roomNumber) {
    $.ajax({
        url: '/clean/cleaningComplete',
        method: 'POST',
        data: {
            roomNumber: roomNumber,
        },
        success: function(response) {
            // Handle the success response
            console.log('변경완료(재실)');
            alert("청소를 완료합니다.")
        },
        error: function(error) {
            // Handle the error
            console.error('An error occurred while marking the cleaning as complete');
            alert("청소를 완료합니다.")
        }
    });
}
```

# 청소부 상태 청소 중 변경하기

## 1.청소부 상태 변경 할 Mapper 만들기

```java
DB의 청소요청 을 청소중 으로 변경하여 jsp 에서 if 를 써서 다른 ui 로 출력되게 할 예정이다
```

### Mapper

```java
		<update id="updateCleaningInProgress" parameterType="ReservedVO">
        UPDATE RESERVED
        SET ROOMSTATUS = '청소중'
        WHERE ROOMNUMBER = #{roomNumber}
        AND ROOMSTATUS = '청소요청'
    </update>
```

### DAO

```java
public int updateCleaningInProgress(ReservedVO reservedVO) throws Exception;
```

### Service

```java
		public int updateCleaningInProgress(ReservedVO reservedVO) throws Exception{
        return cleanDAO.updateCleaningInProgress(reservedVO);
    }
```

### Controller

```java
		@ResponseBody
    @PostMapping ("/updateCleaningInProgress")
    public ModelAndView updateCleaningInProgress(ReservedVO reservedVO) throws Exception{
        ModelAndView mv = new ModelAndView();
        int result = cleanService.updateCleaningInProgress(reservedVO);
        return mv;
    }
```
