## 💡 왜 Timeline인가?

### 현재 상황

```
구체가 계속 존재
  ↓
영원히 날아다님
  ↓
게임이 너무 쉬움
```

### 목표

```
일정 시간 후 사라짐
  ↓
플레이어가 빨리 찾아야 함
  ↓
긴장감 증가
```

### Interpolation vs Timeline

**Interpolation (보간)**

```
Event Tick에서 매 프레임 계산
  ├─ Alpha 값 수동 관리
  ├─ 코드 복잡
  └─ Tick 계속 사용

단점:
  매 프레임 계속 실행
  ↓
타임라인 끝나도 계속 체크
```

**Timeline**

```
자체적으로 시간 관리
  ├─ Curve로 값 정의
  ├─ 시각적 편집
  └─ 재생 중에만 업데이트

장점:
  필요할 때만 실행
  ↓
타임라인 끝나면 자동 중지
  ↓
효율적!
```

## ⏰ Timer vs Timeline 차이

### 혼동하기 쉬운 개념

**Timer (타이머)**

```
일정 시간 후 1회 실행
  ├─ 알람 같은 것
  ├─ 시간 경과 후 이벤트 발생
  └─ 예: 2초 후 시작

용도: "언제" 실행할지
```

**Timeline (타임라인)**

```
시간에 따른 값 변화
  ├─ 애니메이션 커브
  ├─ 매 프레임 값 출력
  └─ 예: 0.5초 동안 1→0

용도: "어떻게" 변할지
```

### 함께 사용하는 방법

```
Timer: 2초 후 Timeline 시작
  ↓
Timeline: 0.5초 동안 Scale 1→0
  ↓
결과: 2초 후 0.5초 동안 축소
```

## 🔌 Timeline 출력 핀 이해

### Timeline 노드 구조

```
Wink Out Timeline
  ├─ Inputs (입력)
  │   ├─ Play: 재생 시작
  │   ├─ Stop: 중지
  │   ├─ Reverse: 역재생
  │   └─ ...
  │
  └─ Outputs (출력)
      ├─ Update: 매 프레임 실행
      ├─ Finished: 완료 시 1회 실행
      └─ Scale: Float 값 출력
```

### Update 출력

```
타임라인 재생 중
  ↓
매 프레임마다 실행
  ↓
Event Tick처럼 작동
  (단, 타임라인 재생 중에만!)
```

**비유**

```
Event Tick: 항상 켜진 전등
Timeline Update: 필요할 때만 켜는 전등
```

### Finished 출력

```
타임라인 완료 시
  ↓
1회만 실행
  ↓
정리 작업용
```

### Scale 출력 (Float)

```
Curve의 현재 값
  ├─ 시작: 1.0
  ├─ 중간: 0.5
  └─ 끝: 0.0

매 프레임 업데이트됨
```

## 🎯 Scale 적용 구현

### 1. Set World Scale 3D 이해

```
Actor의 크기 조정
  ├─ X: 가로 크기
  ├─ Y: 세로 크기
  └─ Z: 높이

Vector (X, Y, Z) 필요
```

### 2. Sphere_Mesh 스케일 확인

```
Viewport
  ↓
Sphere_Mesh 선택
  ↓
Details Panel → Transform
  ↓
Scale
  ├─ X: 1.0
  ├─ Y: 1.0
  └─ Z: 1.0
```

**의미**

```
(1, 1, 1) = 정상 크기
(2, 2, 2) = 2배 크기
(0.5, 0.5, 0.5) = 절반 크기
(0, 0, 0) = 보이지 않음

```

### 3. 균일한 스케일 적용

**왜 X, Y, Z 모두 같은 값인가?**

```
X만 작으면: 가로로 납작
Y만 작으면: 세로로 납작
Z만 작으면: 높이가 낮음

X=Y=Z: 구체 모양 유지하며 축소
```

### 4. Make Vector 노드

```
Timeline Update
  ↓
Make Vector
  ├─ X: Scale (Timeline 출력)
  ├─ Y: Scale (Timeline 출력)
  └─ Z: Scale (Timeline 출력)
  ↓
Set World Scale 3D
  └─ Sphere_Mesh
```

**흐름**

```
Timeline에서 Scale 값 (0.8) 출력
  ↓
Make Vector (0.8, 0.8, 0.8)
  ↓
Set World Scale 3D
  ↓
구체 크기 = 80%
```

### 5. 대안: Split Struct Pin

```
Set World Scale 3D 노드
  ↓
New Scale 핀 우클릭
  ↓
Split Struct Pin
  ↓
X, Y, Z 개별 입력 표시
  ↓
각각에 Scale 연결
```

**Make Vector vs Split Pin**

```
Make Vector:
  ├─ 명시적
  └─ 값 생성 과정 보임

Split Pin:
  ├─ 간결
  └─ 직접 연결

둘 다 동일한 결과!
```

## 💥 Actor 파괴

### 타임라인 완료 후 정리

```
Timeline Finished
  ↓
Destroy Actor
  └─ Target: Self
```

**왜 파괴해야 하나?**

```
Scale (0, 0, 0) = 보이지 않음
  but
Actor는 여전히 존재
  ├─ 메모리 차지
  ├─ CPU 사용
  └─ 충돌 감지 계속

파괴하면:
  완전히 제거
  ↓
리소스 해방
```

### 확인 방법

```
Play
  ↓
ESC (일시정지)
  ↓
Outliner 확인
  ↓
축소 전: BP_Small_Sphere 있음
축소 후: 사라짐 ✓
```

## 🧹 코드 정리

### 문제: 함수로 축소 불가

```
Timeline 포함 노드들 선택
  ↓
우클릭 → Collapse to Function
  ↓
❌ 에러 발생
```

**에러 메시지**

```
"Wink Out Timeline cannot be placed
in a function graph"

타임라인을 함수에 넣을 수 없음
```

### 왜 안 되나?

```
함수의 특성:
  ├─ 호출 즉시 완료
  ├─ 모든 것이 즉시 실행
  └─ 시간 개념 없음

Timeline의 특성:
  ├─ 시간에 걸쳐 실행
  ├─ 매 프레임 업데이트
  └─ 완료까지 대기

→ 근본적으로 충돌!
```

**함수에 넣을 수 없는 것들**

```
❌ Timeline
❌ Delay
❌ Set Timer
❌ 시간 관련 모든 것

이유: 함수는 즉시 완료되어야 함
```

### 해결: 부분만 함수화

```
Set World Scale 3D 부분만
  ↓
함수로 축소 가능
```

**문제**

```
Scale 출력
  ↓

```

**해결**


**함수 축소 시**

```

  ↓
```

## ⚙️ Timeline 길이 변경

### 변경이 필요한 두 곳

**1. Key의 Time**

```
마지막 Key 선택
  ↓
Time: 0.25 (변경)
```

**2. Timeline Length**

```
Timeline 상단
  ↓
Length: 0.25 (변경)
```

**둘 다 변경해야 하는 이유**

```
Key Time만 변경:
  Timeline은 0.5초까지 재생
  ↓
  0.25초 이후는 값 0 유지

Timeline Length만 변경:
  Key는 0.5초에 있음
  ↓
  Timeline이 0.25초에 끝남
  ↓
  값이 1에서 중간까지만 변화

결과: 둘 다 일치해야 함!
```

### 예시: 0.25초로 변경

```
1. 마지막 Key
   Time: 0.5 → 0.25

2. Timeline Length
   Length: 0.5 → 0.25

3. Fit Horizontally
   화면에 맞춤

결과:
  더 빠른 축소 (0.25초)
```

## 💡 핵심 개념 정리

### Timeline의 장점

```
1. 시각적 편집
   Curve로 직관적

2. 효율적 실행
   필요할 때만 Update

3. 자동 완료 감지
   Finished 핀으로 정리

4. 재사용 가능
   Play, Stop, Reverse
```

### Float Curve

```
시간에 따른 값 변화 정의
  ├─ Key로 제어점 설정
  ├─ Interpolation 타입 선택
  └─ 복잡한 애니메이션 가능
```

### Timer + Timeline 조합

```
Timer: "언제" 시작
Timeline: "어떻게" 변화
  ↓
시간차 애니메이션 구현
```

## ⚠️ 주의사항

### 1. Timeline과 함수

```
❌ Timeline 자체는 함수에 못 넣음
✓ Timeline이 호출하는 노드는 가능
```

### 2. Key와 Length 일치

```
마지막 Key Time = Timeline Length
```

## 🔍 Context Sensitive 검색 이해

### 개념

**Context Sensitive란?**

```
선택한 객체에 따라
  ↓
관련된 것만 검색
  ↓
필터링된 결과
```

### 동작 방식

**케이스 1: 우클릭 검색**

```
빈 공간에서 우클릭
  ↓
Context Sensitive: ✓
  ↓
모든 노드 검색 가능
  ↓
"Timeline" 검색 → 찾아짐 ✓
```

**케이스 2: 핀에서 드래그**

```
Sphere_Mesh 핀 드래그
  ↓
Context Sensitive: ✓
  ↓
Static Mesh 관련만 검색
  ↓
"Timeline" 검색 → 안 보임 ✗
```

### 왜 Timeline이 안 보이나?

```
Timeline은 범용 유틸리티
  ├─ 특정 객체와 무관
  └─ 엔진 기본 기능

Sphere_Mesh의 Context
  ├─ Set World Scale 3D ✓
  ├─ Get Bounds ✓
  └─ Timeline ✗ (관련 없음)
```

### 해결 방법

**방법 1: Context Sensitive 끄기**

```
검색창 체크박스
  ↓
Context Sensitive: ✗
  ↓
전체 엔진 검색
  ↓
모든 노드 표시
```

**방법 2: 빈 곳에서 검색**

```
핀에서 드래그 안 함
  ↓
빈 공간 우클릭
  ↓
자동으로 전체 검색
```

**방법 3: Custom Event에서 드래그**

```
Wink In 출력 핀 드래그
  ↓
Context Sensitive: ✓
  ↓
Timeline 검색 가능 ✓
```

### 유용한 이유

```
Context Sensitive 켜짐 (기본)
  ├─ 관련 노드만 표시
  ├─ 검색 결과 간결
  └─ 실수 방지

  ├─ 모든 노드 접근
```

## 📊 Vector Track 이해

### Float Track vs Vector Track

**Float Track**

```
단일 값
  ├─ Scale (1개 값)
  ├─ Alpha
  └─ Speed

1차원 애니메이션
```

**Vector Track**

```
3개 값 (X, Y, Z)
  ├─ Scale (3축)
  ├─ Location
  └─ Color (RGB)

3차원 애니메이션
```

### Vector Track 생성

```
Wink In Timeline 더블클릭
  ↓
+ Track 버튼
  ↓
Add Vector Track
  ↓
이름: Scale
```

**Event Graph 확인**

```
Wink In Timeline
  └─ Scale (노란색 핀)
      ↓
      Vector 타입!

cf. Wink Out Timeline
  └─ Scale (녹색 핀)
      ↓
      Float 타입
```

```
감쇠 진동 = Damped Oscillation
  ├─ 진폭이 점점 감소

  └─ 최종값에 수렴
```

```
    2.0 ← 오버슈트 (큼)
     ↗
    1.5 ← 언더슈트
     ↗
    1.1 ← 오버슈트 (작음)
     ↗
    0.95 ← 언더슈트
     ↗
    1.0 ← 최종 안정
```

### 1. 랜덤 방향 벡터

```
Random Rotator
  ↓

  └─ (Rotation → Vector)
```

**Get Forward Vector 이해**

```
≠ Get Actor Forward Vector
  (Actor의 Forward)

= 수학 함수
  Rotator 입력
  ↓
  Vector 출력
```

**Random Rotator의 결과**

```
Yaw: -180 ~ 180 (랜덤)
Pitch: -180 ~ 180 (랜덤)
Roll: -180 ~ 180 (랜덤)
  ↓
Get Forward Vector
  ↓
3D 공간의 랜덤 방향

* Random Rotator는 "어느 방향을 향하고 있다"는 각도 정보일 뿐이라서, 이걸로 실제 위치를 계산할 수 없어요. Get Forward Vector는 그 각도가 가리키는 방향을 (X, Y, Z) 벡터로 변환해주는 거예요. 예를 들어 "북동쪽 45도"라는 각도를 (0.7, 0.7, 0)이라는 방향 벡터로 바꿔주면, 여기에 거리(100)를 곱해서 (70, 70, 0)이라는 실제 위치를 계산할 수 있죠 - 즉 각도를 계산 가능한 방향 벡터로 변환하기 위해 사용한 겁니다!
```

### Pure Function이란?

**일반 Function vs Pure Function**

```
일반 Function:
  ├─ 실행 핀 있음 (흰색)
  ├─ 순서대로 실행
  └─ 부작용 가능

Pure Function:
  ├─ 실행 핀 없음
  ├─ 순서 무관
  ├─ 입력 → 출력만
  └─ 부작용 없음
```

**비유**

```
일반 Function = 레시피 단계
  1번 먼저, 2번 다음...

Pure Function = 계산기
  입력만 주면 결과 나옴
  순서 상관없음
```
