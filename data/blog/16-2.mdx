![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380972/notion-blog/_/JAVA/_/16_/Untitled_1.png)

### 2.이항 연산자

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380972/notion-blog/_/JAVA/_/16_/Untitled_10.png)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380973/notion-blog/_/JAVA/_/16_/Untitled_11.png)

- 예를 들어 v1 = 5이고 v2 = 2 이면 v1 % v2 의 result5 값은 (5/2 하고) 나머지 1 이 된다.
- v1 / v2 의 경우 정수 / 정수 는 정수기 때문에 (double) 을 v1 에 붙여주어 실수로 만들어 준다.

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380973/notion-blog/_/JAVA/_/16_/Untitled_12.png)

- ‘A’ + 1 은 유니코드66 + 1 의 유니코드 + 정수 리터럴 이기 때문에 컴파일러 에서 연산을 진행
- 그러나 c2 + 1 은 변수 가 들어가기 때문에 JVM 에서 연산을 수행하기 때문에 오류가 난다.
- char + 정수(int) 는 int 타입으로 강제 변환 되기 때문에 int c3 로 수정 해줘야 한다.

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380973/notion-blog/_/JAVA/_/16_/Untitled_13.png)

- 문자열 과 연산 결과는 문자열 이기 때문에 이후의 연산도 문자열로 합쳐진다.
- 앞에 먼저 연산을 진행하고 문자열과 합해지면 결과는 달라진다.
