}

export default function Clicker() {

    <div>
      <p>Click Button</p>
      <button onClick={handClick}>Click</button>
    </div>
  )
}

# Form 이벤트 만들기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled_3.png)

```jsx
폼을 전송하는 이벤트를 만들어 본다

SPA 는 페이지가 새로고침 되는걸 피해야 한다

.preventDefault 를 사용해서 submit 되어 페이지가 새로고침 되는걸

막아야 한다

기존과 마찬가지로 evt 변수에 들어가는건 이벤트 객체의 정보
```

```jsx
function handleFormSubmit(evt) {
  evt.preventDefault()
  console.log('SUBMITTED THE FORM')
}

export default function Form() {
  return (
    <form onSubmit={handleFormSubmit}>
      <button>Submit</button>
    </form>
  )
}
```
