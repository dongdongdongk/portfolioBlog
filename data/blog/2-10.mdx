# { "API 개발을 위한 필수 도구 소개: Node.js, MongoDB, Redis, Terraform 등” }

```jsx
강의에서 다루는 핵심적인 도구들은 다음과 같습니다.
```

```jsx
Node.js:

		백엔드 코드를 TypeScript로 작성하겠지만, 이는 Node.js 자바스크립트 런타임 위에서 동작합니다.

		강사는 최신 장기 지원(LTS) 버전을 사용할 것을 권장합니다.

MongoDB:

		데이터를 저장할 주요 데이터베이스로 사용됩니다.

		MongoDB는 NoSQL 데이터베이스로, 여기서 모든 데이터를 저장할 것입니다.

Redis:

		주로 인메모리 캐시로 사용되며, 메시지 브로커와 데이터베이스 역할도 할 수 있습니다.

		Redis 기반의 간단한 메시지 큐를 설정해 데이터를 MongoDB로 전달할 때 사용합니다.

Terraform:

		인프라를 코드로 설정하는 도구입니다.

		Terraform을 사용해 인프라를 자동으로 프로비저닝하고 설정할 예정입니다.

CircleCI:

		CI/CD 파이프라인 도구로, 코드 배포 자동화를 위해 사용합니다.

		Jenkins나 GitLab 같은 도구 대신 CircleCI를 선택한 이유는 설정과 사용이 간편하기 때문입니다.

Git 및 GitHub:

		버전 관리 도구인 Git과 코드를 저장할 GitHub를 사용합니다.

		GitHub에서 코드를 관리하고 CircleCI와 연동해 배포 작업을 자동화합니다.

AWS:

		클라우드 인프라로 AWS를 사용하여 EC2 인스턴스,

		VPC, 오토 스케일링 그룹, Route 53 등의 서비스를 설정하고 관리합니다.
```
