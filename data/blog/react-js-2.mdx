# **React.js란 무엇인가**

```jsx
React.js는 Facebook에서 개발한 JavaScript 라이브러리로,

사용자 인터페이스를 만들기 위해 사용된다.

주로 싱글 페이지 애플리케이션(SPA) 개발에 적합하며,

가상 DOM을 활용하여 효율적인 UI 업데이트를 가능하게 한다.

React는 컴포넌트 기반 아키텍처를 기반으로 하며, 각 컴포넌트는 독립적으로 관리되고 재사용된다.
```

```jsx
**React.js는 라이브러리인가요, 프레임워크인가요?**

React.js는 라이브러리입니다. 기본적으로는 뷰(View)를 담당하고 있으며, 다른 라이브러리나 프레임워크와 쉽게 통합될 수 있다.

하지만 생태계가 커져가면서 React를 사용하는 개발자들이 프레임워크처럼 활용하는 경우도 많아졌다.

**React의 작동 방식은 어떤가요**?

React는 가상 DOM(Virtual DOM)을 사용하여 효율적으로 UI를 업데이트한다.

상태 변화가 일어나면 React는 가상 DOM을 통해 실제 DOM과 비교하고 변경된 부분만을 업데이트한다.

이러한 방식으로 빠른 렌더링을 실현하며, 컴포넌트의 재사용성과 모듈화를 통한 유지보수성을 높인다.

**React의 핵심 개념은 무엇인가요?**

React의 핵심은 컴포넌트이다. 컴포넌트는 UI를 작은 단위로 나누어 관리하는데,

각 컴포넌트는 상태(state)와 속성(props)을 가질 수 있다.

이러한 컴포넌트를 조합하여 사용자 인터페이스를 구성하고, 각각의 컴포넌트는 독립적으로 테스트하거나 재사용할 수 있다.

**컴포넌트를 통한 사용자 인터페이스 구성 방법은 어떤가요?**

React에서는 JSX(JavaScript XML) 문법을 사용하여 컴포넌트를 정의하고 조합한다.

JSX는 JavaScript의 확장 문법으로, XML과 유사한 구조를 가지고 있어 가독성이 높다.

각 컴포넌트는 render 메서드를 통해 어떻게 UI를 표현할지를 정의하며, 이를 조합하여 전체 애플리케이션을 구성한다.

**React.js의 장점은 무엇인가요?**

React는 선언적인 프로그래밍 스타일을 채택하여 코드의 가독성을 높인다.

컴포넌트 기반 아키텍처는 재사용성이 뛰어나며, 개발자가 유지보수 및 확장을 쉽게 할 수 있게 한다.

가상 DOM을 활용하여 효율적인 렌더링을 지원하므로 빠른 UI 업데이트가 가능하다.
```

## **App 컴포넌트 예제:**

```jsx

```

```jsx
App.js 파일에서 정의된 App 컴포넌트는 함수 컴포넌트로, JSX를 반환한다. 이 컴포넌트는 다른 파일에서 불러와 사용된다.
```

## **React.createElement 메서드 예제:**

```jsx

```

```jsx
JSX 코드는 위와 같이 React.createElement로 변환된다.

첫 번째 인자는 요소의 타입, 두 번째 인자는 프로퍼티(속성), 세 번째 인자는 자식 요소이다.
```

## **JSX 구문의 편리성 예제:**

```jsx
// JSX 중첩 구문
const element = (
  <div>
    <h1>안녕, 난 React야!</h1>
    <p>JSX 구문은 편리하다!</p>
  </div>
)

// React.createElement로 변환된 코드
const element = React.createElement(
  'div',
  null,
  React.createElement('h1', null, '안녕, 난 React야!'),
  React.createElement('p', null, 'JSX 구문은 편리하다!')
)
```

```jsx
JSX를 사용하면 중첩된 구조를 표현할 때 가독성이 좋아지고 코드 작성이 간편해진다.
```

# 데이터 목록 렌더링하기

```jsx
import React from 'react'
import './GoalList.css'

const GoalList = (props) => {
  console.log(props.goals)
  return (
    <ul className="goal-list">
      {props.goals.map((goal) => {
        return <li key={goal.id}>{goal.text}</li>
      })}
    </ul>
  )
}
export default GoalList
```

```jsx
**1. 데이터 배열을 JSX 요소로 출력하기**

JavaScript 객체 배열을 JSX로 출력하려면 배열을 매핑해서 JSX 요소 배열로 만들어야 한다.

JSX는 JavaScript 표현식을 사용하므로 중괄호 {}를 활용한다.

**2. 동적 데이터 출력**

목표(Goal) 데이터 배열을 동적으로 출력하기 위해서는 map() 메서드를 사용한다.

map()은 각 배열 요소에 대해 주어진 함수를 실행하고, 새로운 배열을 반환한다.

**3. 고유 키 프로퍼티 추가**

React에서는 렌더링 효율성을 위해 고유 키 프로퍼티를 요구한다.

각 목표에 대한 li 요소에 고유한 키를 추가하여 React가 효율적으로 렌더링할 수 있도록 한다.

* 일반 반복문이 불가능한 이유는 배열이 아니라 자바스크립트 객체여서 이다
```

# 자식 컴포넌트에서 부모 컴포넌트로 값 보내기

```jsx
import React from 'react'
import './App.css'
import GoalList from './components/GoalList/GoalList'
import NewGoal from './components/NewGoal/NewGoal'

const courseGaols = [
  { id: 'cg1', text: 'Finish the Course1111111111111' },
  { id: 'cg2', text: 'Finish the Course2222222222222' },
  { id: 'cg3', text: 'Finish the Course3333333333333' },
]

const addNewHandler = (newGoal) => {
  courseGaols.push(newGoal)
  console.log(courseGaols)
}

function App() {
  return (
    <div className="course-goals">
      <h2>Course Goals</h2>
      <NewGoal onAddGoal={addNewHandler} />
      <GoalList goals={courseGaols} />
    </div>
  )
}

export default App
```

```jsx
import React from 'react'
import './NewGoal.css'
const NewGoal = (props) => {
  const addGoalHandler = (event) => {
    event.preventDefault()

    const newGoal = {
      id: Math.random().toString(),
      text: 'My Text',
    }
    props.onAddGoal(newGoal)
  }
  return (
    <form className="new-goal" onSubmit={addGoalHandler}>
      <input type="text" />
      <button type="submit">AddGoal</button>
    </form>
  )
}

export default NewGoal
```

```jsx
**상위 컴포넌트 (App)에서 하위 컴포넌트 (NewGoal)로 값 전달:**

App 컴포넌트에서 NewGoal 컴포넌트로 값이 전달되는 부분은 다음과 같다.

<NewGoal onAddGoal={addNewHandler} />

여기서 onAddGoal은 NewGoal 컴포넌트의 프로퍼티로 설정되어, addNewHandler 함수가 전달된다.

**하위 컴포넌트 (NewGoal)에서 상위 컴포넌트 (App)로 값 전달:**

NewGoal 컴포넌트 내부에서 이 프로퍼티를 활용하여 이벤트 핸들러를 호출하는 부분은 다음과 같다.

const addGoalHandler = (event) => {
    event.preventDefault();
    const newGoal = {
        id: Math.random().toString(),
        text: 'My Text'
    }
    props.onAddGoal(newGoal);
}

여기서 props.onAddGoal은 상위 컴포넌트인 App 컴포넌트에서 전달한 함수(addNewHandler)를 가리키고,

이를 호출하면서 새로운 newGoal 를 전달한다.

**상위 컴포넌트 (App)에서 전달한 함수 (addNewHandler)의 동작:**

App 컴포넌트에서 addNewHandler 함수는 다음과 같이 정의되어 있다.

const addNewHandler = (newGoal) => {
    courseGaols.push(newGoal);
    console.log(courseGaols);
}

여기서 새로운 목표(newGoal)을 받아서 courseGaols 배열에 추가하고, 추가된 배열을 콘솔에 출력한다.

*** 결과적인 동작:**

사용자가 NewGoal 컴포넌트에서 폼을 제출하면 addGoalHandler 함수가 호출된다.

이때, props.onAddGoal(newGoal)을 통해 App 컴포넌트로 새로운 newGoal 가 전달된다.

App 컴포넌트의 addNewHandler 함수에서는 전달받은 목표를 배열에 추가하고, 배열을 콘솔에 출력한다.

따라서 NewGoal 컴포넌트에서 추가된 목표가 상위 컴포넌트인 App 컴포넌트로 전달되어 처리된다.

* 간단히 설명하면, 상위 컴포넌트에서 정의한 함수를 하위 컴포넌트로 전달하고, 하위 컴포넌트에서 그 함수를 호출하여 값을 상위 컴포넌트로 보내는 것
```

# "상태" 활용하기

```jsx
import React, { useState } from 'react'
import './App.css'
import GoalList from './components/GoalList/GoalList'
import NewGoal from './components/NewGoal/NewGoal'

// 함수형 컴포넌트인 App 선언
const App = () => {
  // useState 훅을 사용하여 courseGoals 상태와 해당 상태를 업데이트하는 setCourseGoals 함수를 선언
  const [courseGoals, setCourseGoals] = useState([
    { id: 'cg1', text: 'Finish the Course1111111111111' },
    { id: 'cg2', text: 'Finish the Course2222222222222' },
    { id: 'cg3', text: 'Finish the Course3333333333333' },
  ])

  // 새 목표를 추가하는 핸들러 함수인 addNewHandler 선언
  const addNewHandler = (newGoal) => {
    // setCourseGoals 함수를 사용하여 기존의 courseGoals 배열에 새 목표(newGoal)를 추가하여 업데이트
    setCourseGoals(courseGoals.concat(newGoal)) // .concat 두 개 이상의 배열을 병합하는 데 사용
  }

  // JSX로 구성된 App 컴포넌트의 반환 값
  return (
    <div className="course-goals">
      {/* 헤딩 태그를 이용해 코스 목표를 표시하는 섹션 제목 */}
      <h2>Course Goals</h2>

      {/* NewGoal 컴포넌트를 렌더링하고, 새 목표 추가 핸들러를 props로 전달 */}
      <NewGoal onAddGoal={addNewHandler} />

      {/* GoalList 컴포넌트를 렌더링하고, 현재의 courseGoals 배열을 goals props로 전달 */}
      <GoalList goals={courseGoals} />
    </div>
  )
}

// App 컴포넌트를 외부로 내보내기
export default App
```

```jsx
React는 데이터의 변경을 자동으로 감지하지 않기 때문에, 변경이 발생할 때마다 React에게 언제 다시 렌더링해야 하는지 알려주어야 한다.

상태(state)는 React에서 이를 관리하기 위한 중요한 개념으로,

useState 훅을 사용하여 함수형 컴포넌트 내에서 상태를 선언하고 업데이트할 수 있다.

useState()는 항상 두 개의 요소를 가진 배열을 반환한다. 첫 번째 요소는 현재 상태를 나타내며,

두 번째 요소는 상태를 업데이트하는 함수이다.
```

## 향상된 업데이트 방법

```jsx
// setCourseGoals(courseGoals.concat(newGoal));

// 향상된 상태 업데이트 방법
setCourseGoals((prevCourseGoals) => prevCourseGoals.concat(newGoal))
```

```jsx
상태(State):

React에서 중요한 개념으로, 함수형 컴포넌트에서는 useState를 사용하여 상태를 관리한다.

상태는 배열이 아니어도 되며 텍스트, 숫자, 객체, 배열, 불리언 값 등 다양한 형태가 가능하다.

useState의 반환 값:

useState는 항상 두 개의 요소가 있는 배열을 반환한다.

첫 번째 요소는 최신 상태 스냅샷이고, 두 번째 요소는 해당 상태를 업데이트하는 함수이다.

상태 업데이트와 렌더링:

상태를 업데이트할 때 React는 두 가지 작업을 수행한다.

먼저 내부 상태 데이터를 업데이트하고, 그 다음에는 컴포넌트 전체를 함수로 다시 호출하여 JSX 코드를 다시 렌더링한다.

React는 DOM 전체를 다시 렌더링하지 않고 필요한 부분만 업데이트한다.

모범 사례:

상태를 업데이트하는 방법 중 첫 번째 방법은 대부분의 경우에 잘 작동하지만,

두 번째 방법을 사용하면 React가 예약된 방식으로 상태 업데이트를 처리하여 렌더링이 지연되더라도 순서가 보장된다.

함수를 사용하여 이전 상태를 받고 새로운 상태를 반환하는 방식이 더 안전하다

함수형 업데이트:

setCourseGoals 함수를 사용할 때 상태 데이터를 직접 전달하는 대신 함수를 전달하여 업데이트하는 방법

이 방법은 최신 상태가 이전 상태에 의존할 때 더 안전하게 상태를 업데이트할 수 있다.

지연된 업데이트:

React는 상태 업데이트를 즉시 적용하는 것이 아니라 예약하여 진행하기 때문에 지연될 수 있으며,

이는 여러 작업이 동시에 진행 중인 경우에 유용하다. 함수형 업데이트를 사용하면 React가 순서를 보장하여 업데이트를 처리한다.

```

# 사용자 입력 가져오기(양방향 바인딩)

```jsx
import React, { useState } from 'react'
import './NewGoal.css'

// NewGoal 컴포넌트 선언
const NewGoal = (props) => {
  // useState를 사용하여 enteredText 상태와 해당 상태를 업데이트하는 setEnteredText 함수를 선언
  const [enteredText, setEnteredText] = useState('')

  // addGoalHandler 함수 선언
  const addGoalHandler = (event) => {
    event.preventDefault() // 폼 제출 시 기본 동작 방지

    // 새로운 목표(newGoal) 객체 생성
    const newGoal = {
      id: Math.random().toString(), // 무작위 고유 id 생성
      text: enteredText, // 입력된 텍스트를 목표 객체의 text 속성에 할당
    }

    setEnteredText('') // 입력 상자 비우기
    props.onAddGoal(newGoal) // 부모 컴포넌트로부터 전달받은 onAddGoal 콜백 함수 호출
  }

  // textChangeHandler 함수 선언
  const textChangeHandler = (event) => {
    setEnteredText(event.target.value) // 입력 상자의 값이 변경될 때마다 enteredText 상태 업데이트
  }

  // JSX 반환
  return (
    <form className="new-goal" onSubmit={addGoalHandler}>
      {/* 입력 상자 및 버튼을 포함한 폼 */}
      <input type="text" value={enteredText} onChange={textChangeHandler} />
      <button type="submit">AddGoal</button>
    </form>
  )
}

export default NewGoal // NewGoal 컴포넌트를 내보냄
```

```jsx
이제 사용자가 입력한 값을 부모 컴포넌트에 보내서 실제로 입력하게 해준다
```
