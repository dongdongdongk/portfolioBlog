```python
파이썬(Python)에서 리스트(list)는 여러 값을 순서대로 저장하는 데 사용되는 자료형이다.

리스트는 대괄호 [] 안에 값을 넣어 생성하며, 값들은 쉼표 , 로 구분된다.

리스트 안에는 어떠한 자료형도 포함될 수 있으며, 리스트 안에 또 다른 리스트를 넣는 것도 가능하다.
```

# **리스트 생성하기**

```python
my_list = [1, 2, 3]
print(my_list)  # 출력: [1, 2, 3]

mixed_list = [1, "Hello", 3.14]
print(mixed_list)  # 출력: [1, 'Hello', 3.14]
```

# **리스트 인덱싱(indexing)**

```python
리스트의 특정 위치에 있는 값에 접근하려면 인덱스를 사용
```

```python
my_list = ['a', 'b', 'c', 'd']
print(my_list[0])  # 출력: 'a'
print(my_list[3])  # 출력: 'd'
```

```python
음수 인덱스를 사용하면 리스트의 끝에서부터 역순으로 접근할 수 있다.
```

```python
print(my_list[-1])  # 출력: 'd'
print(my_list[-2])  # 출력: 'c'
```

# **리스트 슬라이싱(slicing)**

```python
리스트에서 여러 항목을 한 번에 가져오려면 슬라이싱을 사용한다.
```

```python
print(my_list[1:3])  # 출력: ['b', 'c']
```

```python
시작 인덱스를 생략하면 리스트의 처음부터, 끝 인덱스를 생략하면 리스트의 끝까지 포함된다.
```

```python
print(my_list[:2])  # 출력: ['a', 'b']
print(my_list[2:])  # 출력: ['c', 'd']
```

# **리스트 수정하기**

```python
리스트의 값을 변경하거나 항목을 추가 및 삭제할 수 있다.
```

```python
my_list[1] = 'z'
print(my_list)  # 출력: ['a', 'z', 'c', 'd']

# 리스트에 항목 추가
my_list.append('e')
print(my_list)  # 출력: ['a', 'z', 'c', 'd', 'e']

# 리스트에서 항목 삭제
del my_list[1]
print(my_list)  # 출력: ['a', 'c', 'd', 'e']
```

# **리스트 관련 메서드**

```python
리스트는 데이터를 다루기 위한 다양한 메서드(method)를 제공
```

```python
append(x): 리스트의 끝에 항목 x를 추가합니다.

remove(x): 리스트에서 첫 번째로 나오는 x를 삭제합니다.

sort(): 리스트의 항목을 정렬합니다.   * sort(reverse=True) 하면 반대로 정렬

reverse(): 리스트의 항목 순서를 역순으로 뒤집습니다.

count(x): x가 몇개가 있는지

index(x): x 가 몇번째에 있는지
```

```python
numbers = [3, 1, 4, 1, 5, 9, 2]
numbers.sort()
print(numbers)  # 출력: [1, 1, 2, 3, 4, 5, 9]

numbers.reverse()
print(numbers)  # 출력: [9, 5, 4, 3, 2, 1, 1]
```
