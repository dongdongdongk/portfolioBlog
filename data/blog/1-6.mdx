## 📚 상속(Inheritance) 개념 ⭐

### Actor와 Pawn의 관계

### 계층 구조

```
Actor (부모)
  ↓ 상속
Pawn (자식)
  ↓ 추가 기능:
  └─ 조종 가능 (Possess)
```

### 관계

```
Pawn은 Actor다 ✅
  (Pawn은 Actor의 특수한 버전)

Actor는 Pawn이 아니다 ❌
  (일반 Actor는 조종 불가)
```

### 비유

```
동물 (Actor)
  └─ 개 (Pawn)

"개는 동물이다" ✅
"동물은 개다" ❌
```

# { 보간(Interpolation) - 부드러운 회전 }

## 🎯 현재 문제

  ↓

## ⏱️ Delay 노드로 테스트

### 목적

```
회전이 일어나는 순간을
명확하게 보기 위해!
```

### Delay 노드

### 찾기

```
우클릭 → "delay"
  ↓
[Delay]
  ├─ Duration: 2.0 (초)
  ├─ 실행 입력 ▶
  └─ 실행 출력 ▶ (지연 후)
```

### 작동 방식

```
실행 흐름이 멈춤
  ↓
Duration 시간만큼 대기
  ↓
이후 계속 진행
```

### 연결

```
Event BeginPlay
  ↓
[Delay] 2초
  ↓
[Get All Actors Of Class]
  ↓
나머지 코드...
```

---

## ⚠️ 문제 발생!

### 에러 상황

```
▶ 재생
  ↓
2초 동안 많은 에러!
  ↓
Message Log:
"Accessed None trying to read property TargetPawn"
```

### 왜?

```
Delay 2초 동안
  ↓
TargetPawn이 아직 설정 안 됨
  (비어있음 = None)
  ↓
Event Tick은 계속 실행 중
  ↓
비어있는 변수 사용 시도 ❌
```

### 시간선

```
0초: Event Tick 시작
     └─ TargetPawn = None ❌

2초: TargetPawn 설정됨 ✅
     └─ 이제 사용 가능

0~2초 사이: 계속 에러!
```

## 🔧 RInterp To 노드 구조

### 입력

```
[RInterp To]
  ├─ Current (현재 회전)
  ├─ Target (목표 회전)
  ├─ Delta Time (델타 시간)
  ├─ Interp Speed (보간 속도)
  └─ Return Value (결과 회전)
```

### 각 입력 설명

### Current

```
현재 드론의 회전
  ↓
이 프레임의 시작 회전
```

### Target

```
최종 목표 회전
  ↓
드론이 가고 싶은 회전
```

### Delta Time

```
프레임 사이 시간
  ↓
프레임 속도 독립성!
```

### Interp Speed

```
얼마나 빠르게 회전할까?
  ├─ 작은 값: 천천히
  └─ 큰 값: 빠르게
```

### Return Value

```
이번 프레임의 새 회전
  ↓
목표에 조금 더 가까워짐!
```

## 📐 작동 원리

### 개념

```
목표까지 한 번에 가지 않음!
  ↓
매 프레임마다 조금씩 이동
  ↓
부드러운 전환!
```

### 시각화

```
Frame 1: 현재 0°  → 결과 10°
Frame 2: 현재 10° → 결과 19°
Frame 3: 현재 19° → 결과 27°
...
Frame N: 목표 90° 도달!
```

### Interp Speed 효과

### Speed = 2 (느림)

```
0° → 2° → 4° → 6° → ...
  ↓
천천히 회전
```

### Speed = 8 (빠름)

```
0° → 8° → 15° → 21° → ...
  ↓
빠르게 회전
```
