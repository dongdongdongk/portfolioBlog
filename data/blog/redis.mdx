# Redis 개념

```jsx
레디스(Redis)는 인메모리 데이터 저장소로, 매우 빠른 속도로 데이터를 저장하고 검색할 수 있다.

다양한 데이터 구조를 지원하며, 주로 캐싱, 세션 저장소, 메시지 브로커 등으로 사용
```

# 레디스의 주요 특징

```jsx
1. 인메모리 데이터 저장소:

모든 데이터를 메모리에 저장하여 매우 빠른 읽기/쓰기 성능을 제공한다.

2. 다양한 데이터 구조 지원:

문자열, 리스트, 해시, 셋, 정렬된 셋, 비트맵, 하이퍼로그로그 등을 지원한다.

3. 데이터 지속성:

메모리 기반이지만, RDB 스냅샷과 AOF(Append Only File)를 통해 데이터를 디스크에 저장할 수 있다.

* 레디스는 메모리 기반 데이터베이스로, 데이터를 메모리에 저장하여 빠른 속도를 제공한다. 그러나 데이터의 지속성을 보장하기 위해 두 가지 방법을 제공
( 데이터가 계속 다음번에도 지속될 수 있도록 )


	1. RDB 스냅샷: 주기적으로 데이터의 스냅샷을 디스크에 저장하여 백업하고, 시스템 장애 시 데이터를 복구하는 방식

	일반적으로 스냅샷 파일은 작고 빠르게 백업 및 복구할 수 있어서 초기 데이터 복원이 빠르다.

	하지만 주기적인 스냅샷 간격에 따라 데이터 손실 가능성이 존재



	2. AOF (Append Only File): 모든 데이터 변경 명령어를 로그로 기록하여 디스크에 지속적으로 저장다.

	재시작 시 이 로그를 재실행하여 데이터를 복원한다.

	변경 사항을 모두 기록하기 때문에 복구 시에 데이터 손실이 적지만, 파일 크기가 커질 수 있고 재시작 시 AOF 파일을 모두 처리해야 하므로

	부팅 시간이 오래 걸릴 수 있다.

4. 고급 기능:

Pub/Sub 메시징, Lua 스크립트 실행, 트랜잭션, 지오스페이셜 인덱스와 쿼리 등을 지원한다.
```

# 사용 예시

```jsx
데이터 조회:

1. 클라이언트가 GET http://localhost:8080/data/123 요청을 보낸다.

2. 처음 요청 시에는 서비스 메서드가 호출되고, 데이터가 생성된다.

3. 생성된 데이터는 레디스에 캐싱된다.

4. 이후 동일한 요청이 오면 서비스 메서드가 호출되지 않고, 레디스 캐시에서 데이터를 반환다.
```

# 웹 브라우저의 페이지 캐싱 & 서버 측 데이터 캐싱

```jsx
캐싱은 데이터를 저장해 두었다가 필요할 때 다시 사용하는 기술이다.

여기서 데이터는 다양한 형태가 될 수 있다:

웹 페이지의 HTML, CSS, JavaScript 파일, 이미지, API 응답 데이터 등 모든 종류의 정보를 포함다.

캐싱은 주로 빠른 접근 속도와 성능 최적화를 목적으로 사용
```

## 웹 브라우저의 페이지 캐싱

```jsx
웹 브라우저는 방문한 웹 페이지의 자원을 로컬에 저장하여 다음에 같은 페이지를 요청할 때 다시 서버에서 받아오지 않고,

로컬 저장소에서 가져와 보여준다.

이 과정에서 네트워크 대역폭을 절약하고 페이지 로딩 속도를 향상시킬 수 있다.

예를 들어, 이미지나 스타일 시트 같은 정적 파일들은 웹 브라우저에 의해 캐싱다.
```

## 서버 측 데이터 캐싱

```jsx
서버 측에서는 다양한 데이터를 캐싱하여 성능을 개선할 수 있다.

예를 들어, 데이터베이스 쿼리 결과나 외부 API 호출 결과를 캐싱하여 매번 동일한 데이터를 다시 계산하지 않고 캐시에서 바로 제공할 수 있다.

이는 서버의 부하를 줄이고 응답 시간을 단축시키는 데 도움이 다.
```

# 데이터 캐싱의 장점

```jsx
1. 성능 향상:

캐싱된 데이터를 사용하면 데이터를 다시 계산할 필요 없이 빠르게 접근할 수 있다.

2. 네트워크 대역폭 절약:

데이터를 로컬에서 가져오므로 네트워크 대역폭을 절약할 수 있다.

3. 서버 부하 감소:

캐시된 데이터를 사용하면 서버의 부하를 줄일 수 있다.
```

# 웹 브라우저 캐싱과 서버 측 데이터 캐싱의 차이

```jsx
웹 브라우저 캐싱:

클라이언트(브라우저)에서 이루어지며, 정적 파일(이미지, 스타일 시트 등)을 저장하여 재사용한다.

사용자 경험을 향상시키고 네트워크 요청을 줄이는 데 주로 사용다.

서버 측 데이터 캐싱:

서버에서 이루어지며, 동적으로 생성되는 데이터나 외부 데이터를 캐시하여 서버 응답 속도를 개선한다.

데이터베이스 쿼리 결과, API 호출 결과 등을 저장하여 매번 요청할 때마다 데이터베이스나 외부 서버에 접근하는 것을 방지다.
```
