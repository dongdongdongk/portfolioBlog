# { 적 플레이어 충돌 시 반동 효과 (Bounce Off) 구현 }

```jsx
이 강의에서는 플레이어가 적과 충돌했을 때 반동하는 기능을 추가하는 방법을 설명합니다.

1. 플레이어가 적과 충돌하면 반동한다.

2. 충돌 방향에 따라 반동 방향이 결정된다.

3. 충돌 후 일정 시간 동안 플레이어의 조작이 제한된다.
```

## 1. 충돌 상태를 저장하는 변수 추가

```jsx
먼저 Player 클래스에서 충돌 여부를 확인할 변수를 추가합니다.
```

```jsx
init() {
    this.hasBeenHit = false;  // 플레이어가 적에게 맞았는지 여부
    this.bounceVelocity = 250; // 반동할 때 적용할 속도
}
```

```jsx
hasBeenHit: 기본적으로 false이며, 적과 충돌하면 true로 변경됩니다.

bounceVelocity: 충돌 시 반동의 세기를 조절하는 값입니다.
```

## 2. 충돌 시 반동하는 기능 추가

```jsx
적과 충돌하면 플레이어가 반동하도록 bounceOff() 함수를 만듭니다.
```

```jsx
bounceOff() {
    this.body.touching.right ?
        this.setVelocity(-this.bounceVelocity, -this.bounceVelocity) :
        this.setVelocity(this.bounceVelocity, -this.bounceVelocity);
}
```

```jsx
this.body.touching.right:

참 (true): 플레이어가 적의 오른쪽에 부딪혔다면 왼쪽(-x 방향)으로 튕깁니다.

거짓 (false): 플레이어가 적의 왼쪽에 부딪혔다면 오른쪽(+x 방향)으로 튕깁니다.

setVelocity(x, y): X축과 Y축 속도를 설정해 반동하도록 만듭니다.
```

### `setVelocity()`는 즉각적인 속도 변경을 의미

```jsx
Phaser의 setVelocity(x, y) 메서드는 물체의 속도를 즉시 변경합니다.

이때 적용된 속도는 한 프레임 동안 유지되며,

중력이나 다른 힘(예: 바닥과의 충돌)에 의해 계속 변경될 수 있습니다.
```

```jsx
this.setVelocity(-this.bounceVelocity, -this.bounceVelocity)
```

```jsx
위 코드를 실행하면:

x 속도: -this.bounceVelocity → 왼쪽으로 튕김

y 속도: -this.bounceVelocity → 위쪽으로 튕김

즉, 적과 충돌하면 순간적으로 왼쪽 위 방향으로 속도가 설정되며,

이후 중력에 의해 점점 아래로 떨어지게 됩니다.

ex) setVelocity(-250, -250)
```

## 3. 플레이어가 적에게 맞았을 때 처리

```jsx
플레이어가 적과 충돌했을 때 takesHit() 함수가 실행됩니다.
```

```jsx
takesHit(initiator) {
    this.body.checkCollision.none = true; // 일시적으로 충돌 비활성화
    this.hasBeenHit = true;  // 충돌 상태로 변경
    this.bounceOff();  // 반동 효과 적용
}
```

```jsx
this.body.checkCollision.none = true: 일시적으로 충돌 판정을 없애서 반동이 자연스럽게 이루어지도록 합니다.

this.hasBeenHit = true: 플레이어가 충돌했다는 상태를 저장합니다.

this.bounceOff(): 위에서 만든 bounceOff() 함수를 실행해 반동합니다.
```

## 4. 충돌 후 일정 시간 동안 조작 불가능하도록 설정

```jsx
플레이어가 적과 충돌한 후 일정 시간 동안 조작할 수 없게 만듭니다.
```

```jsx
update() {
    if (this.hasBeenHit) {
        return; // 충돌 중이라면 아무 동작도 하지 않음
    }
}
```

```jsx
if (this.hasBeenHit) return;: 플레이어가 충돌 상태(hasBeenHit = true)이면 조작을 제한합니다.
```

## 5. 문제 해결: Y축 반동이 작동하지 않는 이유

```jsx
처음에는 플레이어가 Y축 방향으로 튕기지 않는 문제가 있었습니다.

그 이유는 적이 immovable 속성을 가지고 있기 때문입니다.
```

```jsx
this.setImmovable(true)
```

```jsx
적이 immovable이기 때문에, 충돌 시 속도 변화가 적용되지 않았습니다.

이를 해결하기 위해 충돌 순간에 플레이어의 충돌 판정을 비활성화했습니다.
```

```jsx
this.body.checkCollision.none = true
```

```jsx
이렇게 하면 플레이어가 적과 충돌한 후 충돌 판정이 해제되면서 반동이 자연스럽게 적용됩니다.
```

### 충돌 판정을 비활성화하는 코드 (`checkCollision.none = true`)의 역할( 없어도 동작함 )

```jsx
이 코드는 충돌 판정을 비활성화하여 적과의 추가적인 충돌을 방지하는 역할을 합니다.

하지만 이 코드가 없어도 정상적으로 반동하는

이유는 충돌 처리 후에도 속도(velocity)가 유지되기 때문입니다.
```

```jsx
(1) checkCollision.none = true가 있을 때

		플레이어가 적과 충돌 → setVelocity()로 반동 → 이후 적과의 추가 충돌이 없음

		자연스럽게 공중에서 튕겨 나가며 움직임

(2) checkCollision.none = true가 없을 때

		플레이어가 적과 충돌 → setVelocity()로 반동 → 적과 추가적인 충돌이 발생할 수 있음

		만약 적과 다시 충돌하면 새로운 충돌 처리가 될 수도 있음 (이 부분은 상황에 따라 다름)

		즉, 이 코드가 없어도 속도가 변경되었기 때문에 플레이어는 정상적으로 튕겨 나갑니다.

		하지만 추가 충돌을 방지하고 싶다면 이 코드를 유지하는 것이 좋습니다.
```

# { 플레이어가 적에게 맞았을 때 튕겨나가는 기능 수정하기 }

```jsx
이 강의에서는 플레이어가 적에게 맞았을 때 튕겨나가는(bounce off) 기능을 개선합니다.

기존에는 플레이어가 맞았을 때 X축과 Y축 모두에서 속도가 변했지만,

이번에는 X축 방향만 속도를 변경하고, Y축 방향의 속도 변화는 약간의 딜레이를 줍니다.
```

## `bounceOff` 함수 수정하기

```jsx
기존 bounceOff 함수에서는 X축과 Y축 방향 속도를 동시에 변경했습니다.

이를 개선하여 X축 속도만 즉시 변경하고,

Y축 속도는 약간의 딜레이를 주어 실행하도록 합니다.
```

### 수정 전 코드

```jsx
bounceOff() {
    this.body.touching.right ?
        this.setVelocity(-this.bounceVelocity, -this.bounceVelocity) :
        this.setVelocity(this.bounceVelocity, -this.bounceVelocity);

    setTimeout(() => this.setVelocityY(-this.bounceVelocity), 0)
}
```

```jsx
위 코드에서는 this.setVelocity를 사용하여 X축과 Y축 속도를 한 번에 변경합니다.
```

### 수정 후 코드

```jsx
bounceOff() {
    // X축 방향 속도만 즉시 변경
    this.body.touching.right ?
        this.setVelocityX(-this.bounceVelocity) :
        this.setVelocityX(this.bounceVelocity);

    // 약간의 딜레이 후 Y축 속도 변경
    setTimeout(() => {
        this.setVelocityY(-this.bounceVelocity);
    }, 0);
}
```

```jsx
X축(setVelocityX) 속도만 즉시 변경

Y축(setVelocityY) 속도 변경을 setTimeout을 사용하여 지연 실행

이렇게 하면 플레이어가 적과 충돌할 때 더 자연스럽게 튕겨나가도록 보정할 수 있습니다.
```

## 연속 충돌 방지 (`takesHit` 함수 수정)

```jsx
현재 플레이어는 적에게 맞으면 즉시 다시 맞을 수 있는 상태가 됩니다.

이를 방지하기 위해 일정 시간 동안 추가 충돌을 무시하도록 설정합니다.
```

### 수정 전 코드

```jsx
takesHit(initiator) {
    if(this.hasBeenHit) {
        return;
    }
    console.log("player got hit")
    this.hasBeenHit = true;
    this.bounceOff();
}
```

```jsx
플레이어가 맞으면 즉시 hasBeenHit = true;로 설정되지만, 일정 시간 후 다시 맞을 수 있음.
```

### 수정 후 코드

```jsx
takesHit(initiator) {
    if (this.hasBeenHit) {
        return;
    }

    console.log("player got hit");
    this.hasBeenHit = true;
    this.bounceOff();

    // 일정 시간(1초) 후 다시 피격 가능하도록 설정
    this.scene.time.delayedCall(1000, () => {
        this.hasBeenHit = false;
    });
}
```

```jsx
this.hasBeenHit = true; 상태를 일정 시간(1초) 동안 유지

delayedCall(1000, () => { this.hasBeenHit = false; })를 사용해

1초 후 다시 공격을 받을 수 있도록 설정

이렇게 하면 플레이어가 맞은 후 일정 시간 동안 연속으로 공격받지 않도록 방지할 수 있습니다.
```

# { Phaser 3 - 플레이어 피격 후 컨트롤 복구 기능 추가 }

```jsx
플레이어가 적에게 피격되었을 때 일시적으로 조작이 불가능한 문제가 있습니다.

이 문제를 해결하기 위해 일정 시간이 지난 후 다시 조작할 수 있도록 수정합니다.
```

## 🛑 현재 코드의 문제점

```jsx
update() {
    if (this.hasBeenHit) {
        return;
    }
    // 플레이어 조작 코드...
}
```

```jsx
hasBeenHit이 true일 때 update() 함수가 바로 return 되므로 플레이어를 조작할 수 없음

즉, 피격 후 일정 시간이 지나도 조작이 불가능한 상태가 유지됨
```

## 해결 방법

```jsx
1. takesHit() 함수에서 hasBeenHit = true로 설정

2. this.bounceOff() 함수 호출 (플레이어가 튕겨나가는 효과)

3. 시간 이벤트 (this.scene.time.addEvent)를 추가하여 일정 시간 후 hasBeenHit을 false로 변경

	 1초 후(1000ms) 다시 조작 가능하도록 설정
```

## 코드 수정

```jsx
takesHit(initiator) {
    if (this.hasBeenHit) {
        return;
    }

    console.log("player got hit");
    this.hasBeenHit = true;  // 플레이어가 피격 상태가 됨
    this.bounceOff();  // 튕겨나가는 동작 수행

    // 일정 시간 후 다시 컨트롤 가능하도록 설정
    this.scene.time.addEvent({
        delay: 1000,  // 1초 후 실행
        callback: () => {
            this.hasBeenHit = false;  // 다시 조작 가능하도록 변경
        },
        loop: false  // 반복 실행 X (한 번만 실행)
    });
}

```

```jsx
적에게 맞으면 hasBeenHit = true로 설정되어 일시적으로 조작 불가능

1초 후(1000ms) hasBeenHit = false가 되어 다시 조작 가능

1초 동안은 추가 피격을 당하지 않도록 무적 상태가 됨

조작이 부드럽게 복구됨
```

# { 플레이어 피격 애니메이션 구현 }

```jsx
이번 강의에서는 적에게 피격되었을 때 플레이어에게 간단한 애니메이션을 적용하는 방법을 배웁니다.

트윈 애니메이션(Tween)을 사용하여 피격 시 색상을 변경하는 효과를 구현합니다.
```

## 1. 트윈 애니메이션(Tween) 개요

```jsx
트윈(Tween)이란 스프라이트 및 게임 오브젝트에서 수행할 수 있는 다양한 애니메이션 효과를 의미합니다.

특정 속성을 일정한 간격으로 변경하는 방식으로 애니메이션을 만듭니다.

이번 강의에서는 피격 시 색상을 변경하는 트윈 애니메이션을 구현합니다.
```

## 2. `playDamageTween()` 함수 구현

```jsx
플레이어가 피격될 때 색상을 변경하는 애니메이션을 적용합니다.
```

```jsx
playDamageTween() {
    return this.scene.tweens.add({
        targets: this, // 대상: 플레이어 스프라이트
        duration: 50, // 애니메이션 지속 시간 (50ms)
        repeat: -1, // 무한 반복 (피격 후 무적 시간 동안 반복)
        tint: 0xff0000, // 빨간색으로 색상 변경
        yoyo: true, // 색상이 원래대로 돌아오는 효과
    });
}
```

## 3. `takesHit(initiator)` 함수 구현

```jsx
플레이어가 적에게 피격될 때 실행되는 함수입니다.
```

```jsx
takesHit(initiator) {
    if (this.hasBeenHit) {
        return;
    }
    console.log("player got hit");
    this.hasBeenHit = true; // 피격 상태 설정
    this.bounceOff(); // 플레이어를 튕겨나가게 함
    const hitAnim = this.playDamageTween(); // 피격 애니메이션 실행

    // 일정 시간(800ms) 후 무적 상태 해제 및 애니메이션 중지
    this.scene.time.delayedCall(800, () => {
        this.hasBeenHit = false; // 다시 피격 가능하도록 설정
        hitAnim.stop(); // 애니메이션 중지
        this.clearTint(); // 색상 초기화
    });
}
```

## 4. `bounceOff()` 함수 구현

```jsx
플레이어가 피격되었을 때 적과 반대 방향으로 튕겨나가는 효과를 구현합니다.
```

```jsx
bounceOff() {
    this.body.touching.right
        ? this.setVelocity(-this.bounceVelocity, -this.bounceVelocity)
        : this.setVelocity(this.bounceVelocity, -this.bounceVelocity);

    setTimeout(() => this.setVelocityY(-this.bounceVelocity), 0);
}
```
