# `::before`와 `::after`

```scss
CSS에서 가상 요소를 추가하는 데 사용됩니다. 이 두 가지 요소는 HTML 문서에 실제로 추가되지 않지만,

CSS로 스타일을 적용하여 화면에 표시할 수 있습니다. 두 가상 요소 모두 디자인과 레이아웃을 더 세밀하게 조정하는 데 유용합니다.
```

## 1. 기본 개념

```scss
**::before와 ::after**는 각각 선택한 HTML 요소의 앞과 뒤에 내용(content)을 추가하는 데 사용됩니다.

::before: 선택한 요소의 앞에 내용을 추가합니다.

::after: 선택한 요소의 뒤에 내용을 추가합니다.
```

## 2. 사용법

```scss
content: 이 속성은 ::before와 ::after 요소의 기본 요소입니다. 내용이 없으면 요소가 화면에 나타나지 않습니다.

position: absolute, relative, fixed 등 위치를 설정합니다.

display: 요소를 어떻게 표시할지 결정합니다. block, inline, inline-block 등을 사용합니다.
```

```scss
/* ::before */
.selector::before {
  content: '텍스트'; /* 또는 "" 빈 문자열, 아이콘 코드 등 */
  /* 스타일 속성들 */
}

/* ::after */
.selector::after {
  content: '텍스트'; /* 또는 "" 빈 문자열, 아이콘 코드 등 */
  /* 스타일 속성들 */
}
```

## 3. 사용 예제

```scss
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>::before and ::after Example</title>
    <style>
        .box {
            position: relative;
            padding: 20px;
            border: 2px solid #333;
            margin: 20px;
            background-color: #f0f0f0;
        }

        .box::before {
            content: "★"; /* 별 아이콘 */
            color: gold;
            font-size: 24px;
            position: absolute;
            top: 10px;
            left: 10px;
        }

        .box::after {
            content: "☆"; /* 비어있는 별 아이콘 */
            color: silver;
            font-size: 24px;
            position: absolute;
            bottom: 10px;
            right: 10px;
        }
    </style>
</head>
<body>
    <div class="box">이 박스의 앞과 뒤에 아이콘이 추가됩니다.</div>
</body>
</html>
```

```scss
::before: .box 요소의 앞에 금색 별(★)이 추가됩니다.

::after: .box 요소의 뒤에 은색 별(☆)이 추가됩니다.
```

## 4. 활용 예제

### 1. **아이콘 추가하기**

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381564/notion-blog/_/_/CSS/_/before_after/image.png)

```scss
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Icon Example</title>
    <style>
        .icon-button {
            position: relative;
            padding: 10px 20px;
            background-color: #007bff;
            color: white;
            border: none;
            cursor: pointer;
        }

        .icon-button::before {
            content: "🔍"; /* 검색 아이콘 */
            font-size: 20px;
            position: absolute;
            left: 10px;
            top: 50%;
            transform: translateY(-50%);
        }
    </style>
</head>
<body>
    <button class="icon-button">Search</button>
</body>
</html>

```

```scss
::before: 버튼의 왼쪽에 검색 아이콘이 추가됩니다.;
```

### \*개인적으로는 flex 가 더 효율적이다

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381564/notion-blog/_/_/CSS/_/before_after/image_1.png)

```scss
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox Icon Button Example</title>
    <style>
        .icon-button {
            display: flex; /* Flexbox를 사용 */
            align-items: center; /* 아이템들을 수직 중앙 정렬 */
            padding: 10px 20px;
            background-color: #007bff;
            color: white;
            border: none;
            cursor: pointer;
            font-size: 16px;
            border-radius: 5px; /* 모서리 둥글게 */
            gap: 10px; /* 아이콘과 텍스트 사이의 간격 */
        }

        .icon-button .icon {
            font-size: 20px; /* 아이콘의 크기 설정 */
        }
    </style>
</head>
<body>
    <button class="icon-button">
        <span class="icon">🔍</span> <!-- 아이콘 -->
        <span class="text">Search</span> <!-- 텍스트 -->
    </button>
</body>
</html>

```
