# { 화면의 상단과 하단 경계와 충돌 감지 }

```jsx
문제 상황:

		현재 새(bird)가 화면 상단을 벗어나거나 바닥으로 떨어질 경우, 게임이 충돌로 간주되지 않고 계속 실행됩니다.

		이를 해결하기 위해 상단과 하단 경계에서 충돌을 감지하도록 설정합니다.
```

## 1단계: 새가 화면 경계와 충돌하도록 설정하기

```jsx
Phaser의 setCollideWorldBounds(true) 사용

1. setCollideWorldBounds 메서드를 사용하면 객체가 화면 경계를 벗어나지 못하도록 제한할 수 있습니다.

2. 코드 수정: 새를 생성하는 createBird 함수에서 새에 대해 이 설정을 추가합니다.

setCollideWorldBounds(true)는 화면의 네 가지 경계(상, 하, 좌, 우)를 기본적으로 충돌 대상으로 설정합니다.

따라서 별도로 상단 경계 충돌을 설정할 필요 없이, 이 메서드 하나로 상단과 하단 모두에서 충돌 처리가 가능합니다.
```

```jsx
createBird() {
    this.bird = this.physics.add
      .sprite(this.config.startPosition.x, this.config.startPosition.y, "bird")
      .setOrigin(0);
    this.bird.body.gravity.y = 400;
    this.bird.setCollideWorldBounds(true); // 화면 경계와 충돌하도록 설정
}

```

## 2단계: 충돌 시 게임 중단 처리

```jsx
기존 충돌 감지 방식의 문제:

		기존에는 새의 y 좌표만 확인하여 충돌 여부를 판단했습니다.

		이 방식은 상단 경계에서는 잘 작동했지만,

		하단에서는 새의 이미지가 화면에 남아 있는 경우 제대로 작동하지 않았습니다.
```

```jsx
if (this.bird.y > this.config.height || this.bird.y < 0) {
  this.gameOver()
}
```

```jsx
새의 전체 영역을 감지하도록 개선:

		Phaser에서 getBounds() 메서드를 사용하면 객체의 경계를 정확히 확인할 수 있습니다.

		이를 이용해 새의 아래쪽(bottom) 경계가 화면 하단을 벗어났는지 감지합니다.
```

```jsx
checkGameStatus() {
    if (this.bird.getBounds().bottom >= this.config.height || this.bird.y <= 0) {
        this.gameOver();
    }
}
```

```jsx
getBounds().bottom: 새의 이미지 아래쪽 경계의 위치를 가져옵니다.

this.config.height: 화면의 높이를 나타냅니다.

따라서, 새의 아래쪽 경계가 화면 높이보다 크면(즉, 새가 바닥을 넘어가면) 게임이 멈춥니
```

## getBounds() ?

```jsx
1. this.bird.getBounds() 사용:

		새 객체의 경계(boundaries) 정보를 가져옵니다.

		이 객체는 top, bottom, left, right 속성을 제공하며,

		각각 새의 위쪽, 아래쪽, 왼쪽, 오른쪽 경계 좌표를 나타냅니다.

2. birdBounds.top <= 0:

		새의 위쪽 경계가 화면 위쪽(0 위치)을 넘어가면 충돌로 간주합니다.

3. birdBounds.bottom >= this.config.height:

		새의 아래쪽 경계가 화면의 하단 경계(화면 높이, this.config.height)를 넘어가면 충돌로 간주합니다.
```

### 왜 `getBounds()`를 사용하는가?

```jsx
정확한 충돌 처리:

		새의 y 좌표는 이미지의 기준점(예: setOrigin(0))에 따라 바뀔 수 있습니다.

		하지만 getBounds()는 이미지의 실제 크기와 위치를 기준으로 충돌을 판단합니다.

코드 가독성 향상:

		birdBounds.top과 birdBounds.bottom으로 충돌 조건을 명확히 기술할 수 있습니다.

```

```jsx
checkGameStatus() {
    const birdBounds = this.bird.getBounds(); // 새의 현재 경계를 가져옴
    if (birdBounds.bottom >= this.config.height || birdBounds.top <= 0) {
        this.gameOver(); // 게임 종료 처리
    }
}
```

## 1. `this.time.addEvent`를 사용한 지연 처리

```jsx
Phaser에서는 this.time.addEvent를 사용해 특정 시간이 지난 후에 실행될 이벤트를 설정할 수 있습니다.

이 함수는 우리가 원하는 시간만큼의 **지연(delay)**을 설정하고, 지연 후 실행할 콜백(callback) 함수를 등록할 수 있습니다.

3개의 매개변수

		얼마나 기다릴지 (delay)

		지연 후 실행할 작업 (callback)

		반복 실행할지 (loop)
```

```jsx
this.time.addEvent({
  delay: 1000, // 1초 (1000밀리초)
  callback: () => {
    this.scene.restart() // 1초 후에 현재 씬(Scene)을 재시작
  },
  loop: false, // 무한 반복하지 않도록 설정
})
```

## 1. **점수 관련 변수 초기화**

```jsx
**점수(score)와 점수 텍스트(scoreText)**를 관리하기 위한 변수를 클래스의 생성자에 추가합니다.
```

## 2. **점수 표시 함수 작성**

```jsx
화면에 점수를 표시하기 위해 createScore라는 함수를 작성합니다.

이 함수는 게임 시작 시 호출되며, 점수를 0으로 초기화하고 화면에 점수 텍스트를 표시합니다.
```

```jsx
createScore() {
  this.score = 0; // 점수 초기화
  this.scoreText = this.add.text(16, 16, `Score: ${0}`, {
    fontSize: '32px',
    fill: '#000' // 검정색 텍스트
  });
}
```

```jsx
16, 16: 텍스트가 화면 왼쪽 위 (x=16, y=16) 위치에 나타납니다.

fontSize와 fill: 텍스트의 크기와 색상을 설정합니다.
```

## 3. **점수 증가 함수 작성**

```jsx
점수를 증가시키는 increaseScore 함수를 작성합니다.

점수를 1씩 증가시키고, 업데이트된 점수를 화면에 표시합니다.
```

```jsx
increaseScore() {
  this.score++; // 점수 1 증가
  this.scoreText.setText(`Score: ${this.score}`); // 업데이트된 점수 화면에 반영
}
```

## 4. **파이프를 넘어갈 때 점수 증가**

```jsx
새가 파이프를 넘을 때 점수를 증가시켜야 합니다.

이 작업은 파이프를 "재활용(recycle)"할 때 수행됩니다.

recyclePipes 함수에서 파이프가 화면 왼쪽을 벗어날 때 점수를 증가시킵니다.
```

```jsx
recyclePipes() {
  // 화면 왼쪽을 벗어난 파이프들을 임시로 저장할 배열
  const tempPipes = [];

  // 모든 파이프 그룹의 자식 객체를 순회
  this.pipes.getChildren().forEach((pipe) => {
    // 파이프의 오른쪽 끝이 화면의 왼쪽 경계를 벗어났는지 확인
    if (pipe.getBounds().right <= 0) {
      // 조건을 만족하는 파이프를 임시 배열에 추가
      tempPipes.push(pipe);

      // 상단 파이프와 하단 파이프가 모두 배열에 추가되었는지 확인
      if (tempPipes.length === 2) {
        // 두 개의 파이프를 재배치
        this.placePipe(...tempPipes);

        // 새가 이 파이프를 통과했으므로 점수를 증가
        this.increaseScore();
      }
    }
  });
}
```

# { Phaser로 게임에 점수 기능 추가하기 }

```jsx
게임 플레이 중 현재 점수와 최고 점수를 화면에 표시합니다.

점수가 오를 때마다 이를 업데이트하고, 게임 종료 시 최고 점수와 비교해 갱신합니다.
```

## 1. 현재 점수와 최고 점수 표시하기

```jsx
createScore() 함수 작성:

		현재 점수를 0으로 초기화하고 화면에 표시합니다.

		로컬 스토리지에서 최고 점수를 불러옵니다. 만약 최고 점수가 없으면 0으로 초기화합니다.

		add.text를 사용해 점수를 화면 좌측 상단에 표시합니다.
```

```jsx
createScore() {
    this.score = 0; // 현재 점수 초기화
    const bestScore = localStorage.getItem('bestScore'); // 로컬 스토리지에서 최고 점수 가져오기
    this.scoreText = this.add.text(16, 16, `Score:${0}`, { fontSize: '32px', fill: '#000' });
    this.add.text(16, 52, `Best Score: ${bestScore || 0}`, { fontSize: '18px', fill: '#000' }); // 최고 점수 표시
}
```

## 2. 점수 증가 기능

```jsx
increaseScore() 함수 작성:

		파이프를 통과할 때 점수를 1 증가시키고, 현재 점수를 화면에 업데이트합니다.
```

```jsx
increaseScore() {
    this.score++;
    this.scoreText.setText(`Score:${this.score}`); // 점수 업데이트
}
```

## 3. 최고 점수 저장하기

```jsx
로컬 스토리지 활용:

		localStorage.setItem()을 사용하여 최고 점수를 저장합니다.

saveBestScore() 함수 작성:

		현재 점수와 최고 점수를 비교하여 더 높은 점수를 로컬 스토리지에 저장합니다.
```

```jsx
saveBestScore() {
    const bestScoreText = localStorage.getItem('bestScore'); // 현재 최고 점수 불러오기
    const bestScore = bestScoreText ? parseInt(bestScoreText, 10) : 0; // 숫자로 변환
    if (!bestScore || this.score > bestScore) { // 최고 점수 갱신 조건
        localStorage.setItem('bestScore', this.score); // 로컬 스토리지에 저장
    }
}
```

## 4. 점수 갱신 시 최고 점수도 갱신하기

```jsx
recyclePipes() 함수 수정:

		파이프를 재배치할 때 점수를 증가시키고, 최고 점수도 저장합니다.
```

```jsx
recyclePipes() {
    const tempPipes = [];
    this.pipes.getChildren().forEach((pipe) => {
        if (pipe.getBounds().right <= 0) {
            tempPipes.push(pipe);
            if (tempPipes.length === 2) {
                this.placePipe(...tempPipes); // 파이프 재배치
                this.increaseScore(); // 점수 증가
                this.saveBestScore(); // 최고 점수 저장
            }
        }
    });
}

```

## 5. 게임 종료 시 최고 점수 갱신

```jsx
gameOver() 함수 수정:

		게임이 종료되면 현재 점수를 로컬 스토리지의 최고 점수와 비교하고, 갱신 후 게임을 재시작합니다.
```

```jsx
gameOver() {
    this.physics.pause();
    this.bird.setTint(0xEE4824); // 게임 종료 시 효과
    this.saveBestScore(); // 최고 점수 갱신

    this.time.addEvent({
        delay: 1000,
        callback: () => {
            this.scene.restart(); // 게임 재시작
        },
        loop: false
    });
}
```

## 3. **일시정지 버튼 생성 (create)**

```jsx
이제 버튼을 화면에 추가합니다. create 함수 안에서

createPause라는 새로운 함수를 호출하고, 해당 함수에서 버튼을 생성합니다.
```

```jsx
createPause() {
  this.add.image(
    this.config.width - 10, // 화면 전체 너비에서 10픽셀 뺀 값
    this.config.height - 10, // 화면 전체 높이에서 10픽셀 뺀 값
    "pause" // 미리 로드한 "pause" 이미지 키
  )
  .setOrigin(1) // 버튼의 기준점을 오른쪽 아래 코너로 설정
  .setScale(3); // 버튼 크기를 3배로 확대
}
```

```jsx
this.add.image(x, y, key): 주어진 좌표 (x, y)에 이미지를 추가합니다.

setOrigin(1): 버튼의 기준점을 오른쪽 아래(이미지의 끝)로 설정합니다.

setScale(3): 버튼 이미지를 3배로 확대하여 화면에서 더 잘 보이도록 만듭니다.
```

## **Physics와 Scene 일시정지**

```jsx
알림 대신 게임을 일시정지하는 기능을 추가합니다.

Physics 엔진과 Scene을 개별적으로 정지합니다.

		this.scene.pause() : 현재 Scene의 업데이트 단계 정지
```

## 최종 코드 예제:

```jsx
createPause() {
  const pauseButton = this.add.image(this.config.width - 10, this.config.height - 10, 'pause')
    .setInteractive()
    .setScale(3)
    .setOrigin(1);

  pauseButton.on('pointerdown', () => {
    this.physics.pause(); // 물리 엔진 정지
    this.scene.pause();   // Scene 업데이트 단계 정지
  });
}
```

```jsx
setInteractive(): 버튼을 클릭 가능한 상태로 만듭니다.

on('pointerdown', callback): 버튼 클릭 시 실행할 동작을 정의합니다.

this.physics.pause()와 this.scene.pause(): 각각 물리 엔진과 Scene을 일시정지합니다.
```

### `.setInteractive()` 상세 설명

```jsx
.setInteractive()는 Phaser에서 게임 오브젝트를 **사용자 입력

(예: 클릭, 터치, 마우스 오버 등)**에 반응하도록 설정하는 메서드입니다.

이 메서드를 호출하지 않으면 오브젝트는 사용자의 입력 이벤트를 처리할 수 없습니다.

		기본적으로 오브젝트의 크기를 입력 영역으로 사용

		사용자 정의 입력 영역 설정 가능

		다양한 포인터 이벤트(pointerdown, pointerup, pointerover 등)와 연결 가능
```

# { 메뉴 화면 만들기 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380494/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_4_-/image_2.png)

## 1. **BaseScene 클래스 개요**

```jsx
BaseScene은 다른 장면(Scene)들이 상속받을 수 있는 기반 클래스입니다.

공통 기능을 정의하고, 이를 자식 클래스에서 재사용할 수 있도록 설계되었습니다.
```

### 주요 속성

```jsx
config: 장면의 설정 정보를 담는 객체로, 화면의 크기(width, height) 등이 포함됩니다.

fontSize, lineHeight, fontOptions: 텍스트의 크기, 줄 간격, 스타일을 정의하는 속성입니다.

screenCenter: 화면의 중심 좌표를 [x, y] 배열 형태로 저장합니다.
```

### 주요 메서드

```jsx
create()

		배경 이미지를 화면에 추가합니다.


createMenu(menu)

		화면에 메뉴를 표시하는 기능입니다.

		메뉴 항목의 위치를 동적으로 계산하고, 순서에 따라 줄 간격(lineHeight)을 조정하여 배치합니다.
```

```jsx
import Phaser from 'phaser' // Phaser.js 라이브러리 가져오기

// BaseScene 클래스: 모든 Scene(장면)의 기본이 되는 클래스
class BaseScene extends Phaser.Scene {
  // 생성자: BaseScene의 인스턴스를 초기화
  constructor(key, config) {
    super(key) // Phaser.Scene의 생성자 호출 (Scene의 키값 설정)
    this.config = config // 화면 크기 등의 설정 정보 저장
    this.fontSize = 34 // 기본 글꼴 크기 설정
    this.lineHeight = 42 // 메뉴 항목 간의 줄 간격 설정
    // 글꼴 스타일 옵션 (크기와 색상)
    this.fontOptions = { fontSize: `${this.fontSize}px`, fill: '#CD00FF' }
    // 화면의 중심 좌표 계산 (화면 너비와 높이를 반으로 나눔)
    this.screenCenter = [config.width / 2, config.height / 2]
  }

  // create(): 장면이 생성될 때 실행되는 메서드
  create() {
    // 화면에 배경 이미지 추가 (0, 0 좌표에서 시작)
    // setOrigin(0)으로 이미지의 기준점을 좌상단으로 설정
    this.add.image(0, 0, 'sky').setOrigin(0)
  }

  // createMenu(menu): 화면에 메뉴를 생성하는 메서드
  createMenu(menu) {
    let lastMenuPositionY = 0 // 메뉴 항목 간의 y축 위치 간격 초기화

    // 메뉴 배열의 각 항목을 반복 처리
    menu.forEach((menuItem) => {
      // 현재 항목의 위치 계산 (화면 중심 + 이전 항목의 y 간격)
      const menuPosition = [
        this.screenCenter[0], // x 좌표: 화면 중심 x
        this.screenCenter[1] + lastMenuPositionY, // y 좌표: 화면 중심 y + 간격
      ]
      // 텍스트 추가: 화면에 메뉴 이름 표시
      this.add.text(...menuPosition, menuItem.text, this.fontOptions).setOrigin(0.5, 1) // 텍스트의 기준점을 중앙 하단으로 설정
      lastMenuPositionY += this.lineHeight // 다음 항목의 y 간격 업데이트
    })
  }
}

export default BaseScene // BaseScene 클래스를 외부에서 사용할 수 있도록 내보내기
```

### **메뉴 표시 로직**

```jsx
createMenu() 메서드에서 메뉴 항목을 화면에 배치하는 과정을 살펴봅니다.
```

```jsx
1) 화면 중심 계산

		화면 중심을 나타내는 screenCenter 속성을 정의합니다.

		this.screenCenter = [config.width / 2, config.height / 2];


2) 메뉴 항목 반복 처리

		menu 배열을 순회하며 각 항목의 텍스트를 화면에 추가합니다

		menu.forEach(menuItem => {
    const menuPosition = [
        this.screenCenter[0],
        this.screenCenter[1] + lastMenuPositionY
    ];
    this.add.text(...menuPosition, menuItem.text, this.fontOptions)
        .setOrigin(0.5, 1);
    lastMenuPositionY += this.lineHeight;
		});


		menuPosition: 메뉴 항목의 x, y 좌표를 계산합니다.

		lastMenuPositionY: 항목 간의 간격을 조정합니다.

		setOrigin(0.5, 1): 텍스트의 기준점을 설정하여 항목을 정렬합니다.

```

# { 마우스 오버 시 텍스트 색상 변경 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380495/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_4_-/image_3.png)

```jsx
텍스트에 마우스를 올렸을 때 텍스트 색상이 노란색으로 바뀌고,

마우스를 떼면 흰색으로 돌아오도록 설정합니다.
```

```jsx
1. 텍스트 객체를 인터랙티브로 만들기

		각 메뉴 텍스트를 클릭하거나 이벤트를 받을 수 있도록 setInteractive() 메서드를 호출합니다.

		textGo.setInteractive();



2. 마우스 오버 이벤트 추가하기

		pointerover 이벤트를 사용하여 마우스가 텍스트 위에 올려졌을 때의 동작을 설정합니다.

		setStyle() 메서드를 사용해 텍스트 색상을 노란색('#ff0')으로 변경합니다.

				textGo.on('pointerover', () => {
				   textGo.setStyle({ fill: '#ff0' });
				});


3. 마우스 아웃 이벤트 추가하기

		pointerout 이벤트를 사용하여 마우스가 텍스트에서 벗어났을 때의 동작을 설정합니다.

		다시 흰색('#fff')으로 색상을 변경합니다.

				textGo.on('pointerout', () => {
				    textGo.setStyle({ fill: '#fff' });
				});
```

## **콜백 함수로 이벤트 연결하기**

```jsx
각 메뉴 항목에 이벤트를 쉽게 추가하기 위해,

이벤트를 처리하는 함수 setupMenuEvents()를 생성합니다.

이 함수는 각 텍스트(GameObject)에 대해 마우스 오버와 마우스 아웃 이벤트를 연결합니다.
```

```jsx
setupMenuEvents(menuItem) {
    const textGo = menuItem.textGo; // 메뉴 항목의 텍스트 객체
    textGo.setInteractive(); // 텍스트를 인터랙티브하게 설정
    textGo.on('pointerover', () => {
        textGo.setStyle({ fill: '#ff0' }); // 마우스 오버 시 색상 변경
    });
    textGo.on('pointerout', () => {
        textGo.setStyle({ fill: '#fff' }); // 마우스 아웃 시 색상 복원
    });
}
```

## 이벤트 설정 시 `this` 컨텍스트 문제 해결

```jsx
콜백 함수 안에서 this가 undefined가 될 수 있습니다.

이를 해결하기 위해 두 가지 방법 중 하나를 사용할 수 있습니다:
```

```jsx
화살표 함수 사용하기

		화살표 함수는 this 컨텍스트를 바깥 컨텍스트로 유지합니다.

		this.createMenu(this.menu, (menuItem) => this.setupMenuEvents(menuItem));
```

```jsx

		함수 호출 시 this를 명시적으로 바인딩합니다.

		this.createMenu(this.menu, this.setupMenuEvents.bind(this));
```

# { 알맞은 화면으로 이동하기 }

```jsx
// Phaser 라이브러리 및 BaseScene을 가져옵니다.
import BaseScene from './BaseScene'

// MenuScene 클래스를 정의하며 BaseScene을 상속받습니다.
class MenuScene extends BaseScene {
  constructor(config) {
    // 부모 클래스의 생성자를 호출하고 'MenuScene' 이름과 설정(config)을 전달합니다.
    super('MenuScene', config)

    // 메뉴 항목을 정의합니다. 각각의 항목은 연결된 scene 이름과 표시할 텍스트로 구성됩니다.
    this.menu = [
      { scene: 'PlayScene', text: 'Play' }, // Play 버튼: 'PlayScene'으로 이동
      { scene: 'ScoreScene', text: 'Score' }, // Score 버튼: 'ScoreScene'으로 이동
      { scene: null, text: 'Exit' }, // Exit 버튼: 게임 종료
    ]
  }

  create() {
    // BaseScene의 create 메서드를 호출하여 기본 설정을 초기화합니다.
    super.create()

    // 메뉴를 생성하고 각 메뉴 항목에 이벤트를 설정합니다.
    this.createMenu(this.menu, (menuItem) => this.setupMenuEvents(menuItem))
  }

  setupMenuEvents(menuItem) {
    const textGo = menuItem.textGo // 메뉴 항목의 텍스트 객체를 가져옵니다.

    // 텍스트 객체를 상호작용 가능하게 설정합니다.
    textGo.setInteractive()

    // 마우스를 메뉴 항목 위에 올릴 때 텍스트 색상을 노란색(#ff0)으로 변경합니다.
    textGo.on('pointerover', () => {
      textGo.setStyle({ fill: '#ff0' })
    })

    // 마우스를 메뉴 항목에서 벗어날 때 텍스트 색상을 흰색(#fff)으로 변경합니다.
    textGo.on('pointerout', () => {
      textGo.setStyle({ fill: '#fff' })
    })

    // 메뉴 항목을 클릭하고 마우스를 뗄 때 실행됩니다.
    textGo.on('pointerup', () => {
      // 메뉴 항목에 scene이 설정되어 있다면 해당 scene으로 이동합니다.
      if (menuItem.scene) {
        this.scene.start(menuItem.scene)
      }

      // 메뉴 항목의 텍스트가 'Exit'인 경우 게임을 종료합니다.
      if (menuItem.text === 'Exit') {
        this.game.destroy(true) // true는 캔버스를 제거하는 옵션입니다.
      }
    })
  }
}

export default MenuScene
```

```jsx
import BaseScene from './BaseScene'

// ScoreScene 클래스 정의
class ScoreScene extends BaseScene {
  // 생성자: 씬 이름과 설정 값을 전달합니다.
  constructor(config) {
    super('ScoreScene', config) // 부모 클래스의 생성자를 호출합니다.
  }

  // create() 메서드: 씬이 생성될 때 실행되는 메서드입니다.

    // 화면 중앙에 최고 점수를 표시합니다.
    // this.screenCenter는 화면 중앙의 x, y 좌표입니다. (BaseScene에서 정의됨)
    // this.fontOptions는 텍스트 스타일입니다. (BaseScene에서 정의됨)
    this.add
      .text(
        ...this.screenCenter, // 중앙 위치
        `Best Score: ${bestScore || 0}`, // 최고 점수 표시, 없으면 0
        this.fontOptions // 텍스트 스타일 베이스 씬에 있다
      )
      .setOrigin(0.5) // 텍스트를 중앙 정렬합니다.
```
