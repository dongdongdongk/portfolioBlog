```jsx

2. 프로젝트 이름, 프로젝트 유형(JavaScript 선택) 등을 설정.

3. 의존성 설치: npm install.

4. 개발 서버 실행: npm run dev
```

## **로컬 실행 및 확인**

```jsx
프로젝트 루트 디렉토리에서 npm install 명령어를 실행하여 의존성 설치.

npm run dev 명령어를 사용하여 로컬 개발 서버 실행.

브라우저에서 http://localhost:3000 열어 로컬 실행 확인.
```

## **기타 파일 및 폴더 설명**

```jsx
index.html: standalone 파일로, CodeSandbox의 public 디렉토리와 유사한 역할 수행.

main.jsx: App 컴포넌트를 root div에 렌더링하는 파일.

index.css: 전체 웹 사이트에 일반적으로 적용되는 스타일 지정. (중요도가 높은 일반적인 스타일은 모두 여기 컴포넌트에 특정적인건 컴포넌트.css에)

App.css: App 컴포넌트에 대한 사전 작성된 스타일 파일.
```

## **설정 및 자동화**

```jsx
node_modules :

ESLint 구성 및 프로젝트에 필요한 모든 의존성이 미리 구성됨.

개발 서버, Babel 구성, JSX 변환, 번들링 등의 작업이 자동으로 수행.
```
