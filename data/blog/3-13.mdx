# { 색상 이론 및 색상 조화 설명 (예시 포함) }

```jsx
색 이론을 이해하면 왜 특정 색상 조합이 눈에 더 즐겁게 보이는지, 어떻게 색상을 조화롭게 사용할 수 있는지 알 수 있습니다.
```

## 색 이론 기초

```jsx
색상환(Color Wheel)

	색상 간의 관계를 보여줍니다.

	아이작 뉴턴 경이 발명한 것으로, 색상 스펙트럼을 원에 매핑한 것입니다.

	원색(Primary Colors): 빨간색, 노란색, 파란색

	2차색(Secondary Colors): 원색을 섞어 만든 색 (예: 노란색 + 파란색 = 초록색)

	3차색(Tertiary Colors): 원색과 2차색을 섞어 만든 색 (예: 노란색 + 초록색 = 연두색)

색상 모델(Color Models)

	가산혼합(Additive Mixing): 빛을 사용하여 색을 만드는 방법 (예: RGB - Red, Green, Blue)

	감산혼합(Subtractive Mixing): 잉크나 페인트를 사용하여 색을 만드는 방법 (예: CMYK - Cyan, Magenta, Yellow, Key/Black)

색상 조화(Color Harmony)

	보색(Complementary): 색상환에서 서로 반대되는 색상

	분할 보색(Split-Complementary): 하나의 주요 색상과 그 색상의 양옆에 있는 색상

	유사색(Analogous): 색상환에서 나란히 있는 세 가지 색상

	트리아딕(Triadic): 색상환에서 등변 삼각형을 이루는 세 가지 색상

	테트라딕(Tetradic): 색상환에서 직사각형을 이루는 네 가지 색상

	단색(Monochromatic): 한 가지 색상에 명도(밝기)와 채도(강도)를 다르게 한 색상
```

## 색상 속성

```jsx
휴(Hue): 순수한 색상 (예: 빨간색, 파란색)

틴트(Tint): 휴에 흰색을 섞은 색상

톤(Tone): 휴에 회색을 섞은 색상

쉐이드(Shade): 휴에 검은색을 섞은 색상
```

색상환에서 서로 옆에 있는 색상들을 사용해 조화를 이룹니다. 예를 들어, 파란색, 파란-녹색, 녹색.
