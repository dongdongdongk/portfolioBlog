- public 은 class 를 같은 패키지 내에서만 사용할 것인지 다른 패키지 내에서도 사용할 수 있도록 할 것인지 결정한다.

```java
public class A {     //외부에서 사용 가능
}

class B {            //와부에서 사용 불가
}

// 다른 패키지 에서 public class 를 사용할 때 는 import 문을 작성해 줘야한다.
// 이때 ctrl + shift + o 를 해주면 자동으로 import 문을 작성해 준다.
```

![Untitled](<38%20%ED%8C%A8%ED%82%A4%EC%A7%80%EC%99%80%20%EC%A0%91%EA%B7%BC%20%EC%A0%9C%ED%95%9C%EC%9E%90(2)/Untitled%202.png>)

```java
**생성자 접근 제한**

public class ClassName {

public ClassName(...) {...} // 이 생성자를 어디서든 호출할수 있다는 것이다.(new 연산자 객체를
                            // 어디서든 만들수 있다.)

protected ClassName(...) {...} // 상수를 배워야 설명 가능

ClassName(...) {...}    // 같은 패키지에 소속 되어야 생성 가능하다.

private ClassName(...) {...} // 클래스 내부 에서만 사용할수 있다.( 이 클래스 내부에서만 생성자
														 // 를 사용하여 객체를 생성할수 있다.)

```
