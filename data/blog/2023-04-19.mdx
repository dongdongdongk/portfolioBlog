- 로그설정 상세

  ## Log 설정 항목

  ```xml
  **Appender**
  이벤트 마다 로그를 기록하는 기능을 처리하는 객체
  로그이 출력위치, 출력 형식등을 설정

  1. ConsoleAppender
  	 - 로그를 콘솔에 출력
  2. FileAppender
  	 - 로그를 지정 파일에 기록
  3. RollingFileAppender
  	- FileAppender을 상속. 날짜와 용량등을 설정해서 패턴에 따라 로그가 각기 다른파일에 기록되게 할 수 있음.
  	- rollover는 다음 파일로 이동하는 행위로 한 로그 파일에 무한정 기록할 수 없으니 특정 기준에 따라 기록하는 파일 대상을 바꿔주는 것

  	1) RollingPolicy    : rollover에 필요한 action을 설정한다. (ex. TimeBasedPolicy, SizeAndTimeBasedRollingPolicy 등)
  			a. TimeBasedPolicy, SizeAndTimeBasedRollingPolicy
  				 - TimeBasedPolicy는 시간을 기준으로 rollover를 설정
  				 - SizeAndTimeBasedRollingPolicy 시간에다가 파일 크기까지 고려하여 rollover를 설정
  				 * fileNamePattern
  					 - 아카이브 될 로그 파일의 패턴을 정의한다.
  					 - %d 문자를 이용해 파일의 적절한 부분을 dateTime 패턴으로 바꿔준다.
  					 - default(%d)는 yyyy-mm-dd로 매일 자정 새로운 로그 파일로 rollover 한다.
  				 * maxHistory
  					 - 아카이브에 저장할 로그 파일 개수를 지정한다.
  					 - fileNamePattern에 명시된 dateTime 패턴의 최소 단위에 따라 rollover 단위가 달라진다.
  				 * totalSizeCap
  					 - 로그 파일 아카이브 저장소 최대 크기를 지정한다. 이를 초과하면 가장 오래된 파일이 삭제된다.
  				 * cleanHistoryOnStart
  					- true로 설정하면 앱을 시작하면 아카이브된 로그 파일을 모두 삭제한다. default는 false이다.


  	2) TriggeringPolicy : rollover가 발생하는 기준(정책)을 설정한다.

  4. Loback-classic 모듈의 Appender (SSLSocketAppender, SMTPAppender, DBAppender 등)을 사용하여 로그를 원격위치에 기록 가능

  **Logger**
  실제 로그 기능을 수행하는 객체
  각 Logger 마다 name을 통해 구분
  최상위 로거인 Root Logger를 설정하면 계층적으로 활용 가능

  **Pattern**
  	1. %-5level           : 로그 레벨, -5는 출력의 고정폭 값(5글자이하라도 5칸 차지 줄맞추기 위한 용도) (INFO, ERROR, DEBUG , 기타 등등이다.)
    2. %d{날짜 형식 포맷} : 로그 기록시간 %d{yyyy-MM-dd HH:mm:ss}
  	3. %thread            : 현재 Thread 명
  	4. %F                 : 로깅을 발생시킨 파일 명
  	5. %M                 : 로깅을 발생시킨 메소드 명
  	6. %logger{length}    : Logger name을 축약할 수 있다. length는 최대 자릿수이다 (0 = 무제한)
  	7. %line              : 로깅이 발생된 라인 넘버
  	8. %msg               : 로그 메시지
  	9. %n                 : 줄바꿈(new line)

  **Color**
  로그 기록 출력시 색상 적용(공식 문서 확인)
  %clr(pattern){color}로 사용

  Springboot에서 제공하는 로그 Color 참조
  https://github.com/spring-projects/spring-boot/blob/main/spring-boot-project/spring-boot/src/main/resources/org/springframework/boot/logging/logback/defaults.xml
  ======================================================================================

  <configuration>
  		<!-- 다른 설정 파일 불러오기 가능 -->
  		<include resource="org/springframework/boot/logging/logback/console-appender.xml" />

  		<!------------------------------------  **Property 설정**  ----------------------------------------------------->
  		<!-- peroperty : 변수 같은 개념 사용하는 곳에서 ${perperty의 name값} 으로 사용 -->
  		<!-- log 기록 절대 위치 설정 -->
      <property name="LOGS_ABSOLUTE_PATH" value="./logs" />
  		<!-- CONSOLE에 출력시 format 형식을 지정-->
      <property name="CONSOLE_LOG_PATTERN"
                value="[%d{yyyy-MM-dd HH:mm:ss}:%-3relative]  %clr(%-5level) %clr(${PID:-}){magenta} %clr(---){faint} %clr([%15.15thread]){faint} %clr(%-40.40logger{36}){cyan} %clr(:){faint} %msg%n"/>
      <!-- File에 출력시 format 형식을 지정-->
  		<property name="FILE_LOG_PATTERN"
                value="[%d{yyyy-MM-dd HH:mm:ss}:%-3relative] %-5level ${PID:-} --- [%15.15thread] %-40.40logger{36} : %msg%n"/>

  		<!------------------------------------  **Appender 설정**  ----------------------------------------------------->
  		<!-- Console Appender -->
      <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender">
  				<!-- encoder : 출력 format 형식을 지정 -->
          <encoder>
              <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
          </encoder>
      </appender>

  		<!-- 파일(FILE) Appender -->
      <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
          <!-- log 기록할 파일 위치 설정 -->
          <file>${LOGS_ABSOLUTE_PATH}/logback.log</file>
          <!-- 출력 format 형식을 지정 -->
          <encoder>
              <pattern>${FILE_LOG_PATTERN}</pattern>
          </encoder>
          <!-- TimeBasedRollingPolicy 사용한다면 -->
  				<rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
              <!-- daily rollover -->
              <fileNamePattern>logFile.%d{yyyy-MM-dd}.log</fileNamePattern>
              <!-- keep 30 days' worth of history capped at 3GB total size -->
              <maxHistory>30</maxHistory>
              <totalSizeCap>3GB</totalSizeCap>
          </rollingPolicy>
  				<!-- SizeAndTimeBasedRollingPolicy 사용한다면 -->
  				<rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">
              <fileNamePattern>${LOG_FILE}.%d{yyyy-MM-dd}.%i.gz</fileNamePattern>
              <maxFileSize>${LOG_FILE_MAX_SIZE:-10MB}</maxFileSize>
              <maxHistory>${LOG_FILE_MAX_HISTORY:-0}</maxHistory>
          </rollingPolicy>

      </appender>

  		<!------------------------------------  **Logger 설정**  ----------------------------------------------------->
  		<!-- 특정 클래스별로 Logger 지정 -->
  		<!-- SomeService는 INFO일때 Log 생성 -->
      <logger name="com.iu.service.SomeService" level="INFO"/>

  		<!-- log 레벨 설정 (org.springframework.web=debug)-->
      <logger name="org.springframework.web" level="debug">
          <appender-ref ref="FILE" />
      </logger>

  		<!------------------------------------  **Root(전역) 설정**  ----------------------------------------------------->
  		<!-- 전역 설정 Warn 이상일 때 Log 생성 (logging.level.root=info) -->
      <root level="warn">
  		<!-- 참조할 appender 설정 - STDOUT -->
          <appender-ref ref="STDOUT"/>
      </root>
  </configuration>

  ```

  ```java
  import org.slf4j.Logger;
  import org.slf4j.LoggerFactory;

  public class MyClass {
      private static final Logger logger = LoggerFactory.getLogger(MyClass.class);

      public void myMethod() {
          logger.debug("debug level message");
          logger.info("info level message");
          logger.warn("warn level message");
          logger.error("error level message");
      }
  }

  *******

  1. LoggerFactory.getLogger() 메서드를 사용하여 로거 객체를 생성하고,

  2. logger.debug(), logger.info(), logger.warn(), logger.error() 메서드를 사용하여 각각의 로그 레벨에 맞는 로그를 출력
  ```

  ```java
  @RestController
  @RequestMapping("/api")
  public class MyController {

      private static final Logger logger = LoggerFactory.getLogger(MyController.class);

      @GetMapping("/greeting")
      public String greeting(@RequestParam(name = "name", defaultValue = "World") String name) {
          logger.info("Received greeting request for {}", name);
          return "Hello, " + name + "!";
      }

      @PostMapping("/calculate")
      public int calculate(@RequestParam(name = "a") int a, @RequestParam(name = "b") int b) {
          logger.debug("Received calculate request with a={}, b={}", a, b);
          int result = a + b;
          logger.debug("Result of calculation: {}", result);
          return result;
      }
  }

  ******

  1. @RestController 애노테이션으로 HTTP 요청을 처리하는 컨트롤러를 정의

  2. 컨트롤러 내부에서는 LoggerFactory.getLogger() 메서드를 사용하여 로거 객체를 생성하고, 각각의 요청 처리 메서드에서 로그를 출력

  3. greeting() 메서드에서는 @RequestParam 애노테이션으로 전달받은 파라미터 값을 로그에 출력하고, calculate() 메서드에서는 계산 결과를 로그에 출력
  ```
