## 2.Test클래스 만들기

```java
테스트를 위한 클래스를 만드는 폴더다

여기서 JUnit Test Case 를 만들어준다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380892/notion-blog/_/_/JSP/_6/Untitled_4.png)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380892/notion-blog/_/_/JSP/_6/Untitled_5.png)

```java

@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations = {"file:src/main/webapp/WEB-INF/spring/**/*-context.xml"})
public abstract class MyTestCase {
}

@RunWith : 누구랑 실행할거냐 설치한 SpringJUnit4ClassRunner.class 와 함께 실하겠다 적어준다

@ContextConfiguration : 설정파일이 어디있냐  context 설정 파일의 위치를 알려달라

(locations = {"file:src/main/webapp/WEB-INF/spring/**/*-context.xml"})

/*-context : context 로 끝나는 모든파일

/** : Spring 폴더 밑에 폴더가 있어도 괜찮고 없어도 괜찮다 (하위 모든 폴더 )

이는 다른 클래스 만들때 상속해주기 위한 추상클래스로 활용된다

public abstract class MyTestCase { } 로 추상 클래스를 만들어 준다.

```
