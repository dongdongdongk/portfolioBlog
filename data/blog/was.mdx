## 외부 폴더 만들기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381521/notion-blog/_/_/_WAS_/Untitled_3.png)

```html
원하는 곳에 폴더를 만들어준다 나는 경로를 C:\text\Build\Hello 로 만들었다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381521/notion-blog/_/_/_WAS_/Untitled_4.png)

```html
C:\Program Files\Apache Software Foundation\Tomcat 8.5\conf\Catalina\localhost 여기로 이동한 뒤 XML
파일을 추가해준다
```

```html
<Context path="/Hello" docBase="C:\text\Build\Hello" debug="0" prvileged="true" reloadable="true">
  <Logger
    className="org.apache.catalina.logger.FileLogger"
    directory="logs"
    prefix="localhost_log."
    suffix=".txt"
    timestame="true"
  />
</Context>

docBase="C:\text\Build\Hello" 이부분이 아까 만든 폴더의 경로가 되어야 한다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381521/notion-blog/_/_/_WAS_/Untitled_5.png)

```html
경로를 지금 사용하는 폴더로 바꿔준다
```
