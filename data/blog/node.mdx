# **Node.js 소개 및 사용 이유**

```jsx
Node.js는 JavaScript를 실행하는 런타임 환경으로,

브라우저 외부에서도 JavaScript 코드를 실행할 수 있게 해주는 도구입이다.

이는 브라우저에서만 사용되던 JavaScript를 서버 측에서도 활용할 수 있게 한 혁신적인 기술이다.
```

# **Node.js 특징**

```jsx
**JavaScript 사용**: 브라우저 외부에서도 JavaScript를 사용할 수 있어 개발자에게 익숙한 언어를 활용할 수 있다.

**서버 측 개발**: Node.js를 사용하면 서버 측에서 JavaScript 코드를 실행할 수 있어 서버 개발이 더 효율적으로 이루어진다.

**확장성**: 이벤트 기반, 비동기 프로그래밍을 지원하여 높은 확장성을 제공한다.

**강력한 커뮤니티**: Node.js는 강력한 커뮤니티를 가지고 있어 다양한 패키지와 도구를 활용할 수 있다.
```

# **Node.js 사용 예**

```jsx
**웹 서버 구축**: Node.js를 사용하여 간단하고 빠른 웹 서버를 만들 수 있다.

**API 서버**: RESTful API를 개발하고 관리할 때 Node.js가 효과적으로 사용된다.

**실시간 어플리케이션**: 채팅 애플리케이션, 실시간 알림 등의 기능을 구현할 때 사용된다.

**도구 및 자동화 스크립트**: JavaScript를 사용하여 다양한 도구와 자동화 스크립트를 개발할 수 있다.
```

```jsx
Node REPL은 Node.js의 REPL(Read-Eval-Print Loop) 환경을 나타낸다.

REPL은 사용자와 상호 작용하면서 JavaScript 코드를 입력하고 실행하며 결과를 즉시 피드백하는 환경을 제공한다

Node REPL은 단순한 수학 계산뿐만 아니라 변수 선언, 함수 정의, 모듈 호출 등과 같은 JavaScript의 다양한 기능을 지원한다.

사용자는 REPL을 통해 코드를 작성하고 테스트하며 더 나은 이해와 디버깅을 할 수 있다.

또한 REPL은 자동 완성 기능도 지원하여 사용자가 코드를 빠르게 작성할 수 있도록 도와준다.

Tab 키를 사용하여 가능한 명령어나 변수 이름을 자동으로 완성할 수 있다.

간단한 코드 조각이나 JavaScript의 작은 부분을 빠르게 테스트하고 실험할 때 특히 유용한 REPL은

Node.js를 학습하고 익히는 데 도움이 되는 도구 중 하나이다.

( 브라우저의 개발자 도구에 입력하는걸 상상하면 된다 )

( 그러나 차이점은 브라우저에 있는 document 나 window 가 없고 node 만의 기능이 추가되어 있다 (파일조작 등등)
```

# **`fs`** 모듈

```jsx
Node에서는 파일 시스템 작업을 수행하는데에도 다양한 내장 메서드가 제공된다.

예를 들어, fs 모듈은 파일을 생성, 읽기, 추가하기, 디렉토리 생성 등 다양한 작업을 할 수 있는 메서드를 제공
```

## Node 스크립트를 통해 폴더를 생성하고 파일을 만드는 과정

```jsx
const fs = require('fs')

// 명령줄에서 전달된 폴더명을 가져옴 (디폴트는 'Project')
const folderName = process.argv[2] || 'Project'

try {
  // 폴더 생성 (동기 방식)
  fs.mkdirSync(folderName) // 동기적으로 폴더 생성
  console.log(`Folder '${folderName}' created.`)

  // 세 개의 파일 생성 (동기 방식)
  fs.writeFileSync(`${folderName}/index.html`, '') // 폴더명 / 가 내부에 파일을 넣는다는것
  fs.writeFileSync(`${folderName}/app.js`, '')
  fs.writeFileSync(`${folderName}/style.css`, '')

  console.log('Three files created in the folder.')
} catch (err) {
  console.error('SOMETHING WENT WRONG!!!', err)
}
```

```jsx
이런식으로 폴더를 생성하고 할때는 비동기 보다는 동기 방식이 좋다

( 폴더가 생성되지 않았는데 아래 코드가 실행될수도 있기 때문에 )
```
