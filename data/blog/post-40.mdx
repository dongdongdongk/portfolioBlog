## CRUD

```sql

Create : INSERT
READ   : SELECT
UPDATE : UPDATE
DELETE : DELETE
```

```sql
- Table의 데이터를 조회(Read)
- SELECT의 결과물은 ResultSet에 보관
- ResultSet의 결과물을 보여주는 화면을 View라고 함

실행 순서(읽는 순서)
FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY
```

```sql
**SELECT**
1.DISTINCT(중복제거)  :  컬럼 중복제거
SELECT DISTINCT 컬럼 FROM 테이블;

2.AS(별칭) : 컬럼을 합쳐 별칭생성
SELECT 컬럼, 컬럼 ,컬럼*12 AS 별칭

3.||’문자열’||(연결 연산자)  :
SELECT STATE_PROVINCE || '의 도시명은' || CITY

**WHERE**
1.<,>,= (비교연산자)  :
WHERE 컬럼 = 90;

2.AND,OR (논리 연산자)  :
WHERE 컬럼 =60 OR 컬럼 = 100;

3.IS NULL (NULL 연산자) :
WHERE 컬럼 IS NULL;

4.BETWEEN(AND)  :
WHERE 컬럼 BETWEEN 8000 AND 15000;

5.IN(OR) :
WHERE 컬럼 IN (60,100);

6.LIKE : 특정 문자열에 일치하는 데이터를 조회
WHERE LAST_NAME LIKE '%k%';

**GROUP BY :** GROUP BY 그룹으로 묶을 컬럼명

**HAVING :** GROUP BY 그룹의 조건

**Order By :** Table에 Data 조회할때 순서를 지정하고 싶을 때 사용
오름차순 : asc   내림차순 : desc
****ORDER BY 컬럼명 DESC

**INSERT :** DB에 새로운 데이터를 추가
****INSERT INTO 테이블명 (컬럼1, 컬럼2,...) values(값1, 값2,...)

**UPDATE :** Table에 있는 컬럼의 값을 수정 할 때
****UPDATE 테이블명 SET 수정할컬럼명1=수정할값1, 수정할컬럼명2=수정할값

**DELETE :** Table에 있는 ROW를 삭제
****DELETE 테이블명

**Function----------------------------------------------------------------**

**DUAL :** 단순한 계산 결과물을 조회 하거나 테이블이 없을 때
**SELECT 10/5 FROM DUAL;**

1. 그룹함수(Group Function)
SELECT SUM(컬럼명) FROM 테이블; ****

1) SUM(컬럼명)          : 해당 컬럼의 총합을 계산, NULL은 제외
2) AVG(컬럼명)          : 해당 컬럼의 평균을 계산, NULL은 제외
3) COUNT(컬럼명)        : 해당 컬럼의 ROW의 총 갯수를 계산, NULL은 제외
4) MAX(컬럼명)          : 해당 컬럼에서 최대값(제일 큰 값)을 조회, NULL은 제외
5) MIN(컬럼명)          : 해당 컬럼에서 최소값(제일 작은값)을 조회, NULL은 제외

2. 단일함수(Single Function)

**SubQuery**
```

## 기본문법

## 1.SELECT

```sql
1. 기본 문법

SELECT     [DISTINCT] *(모든 컬럼), 컬럼명, 계산식, 함수 호출, 별칭(Alias)
FROM       테이블명
[WHERE]    조건식 **(사용빈도 높음)**
[GROUP BY] 그룹으로 묶을 컬럼명
[HAVING]   그룹의 조건식
[ORDER BY] 컬럼명 정렬방식

**문법 :**

--WHERE
--부서번호(DEPARTMENT_ID 가 90인것만 조회
SELECT FIRST_NAME, SALARY, DEPARTMENT_ID
FROM EMPLOYEES
WHERE DEPARTMENT_ID = 90;
```

### SELECT-DISTINCT(중복제거)

```sql
1) DISTINCT
	- 중복제거
	- DISTINCT 컬럼명
	- SELECT 절에서 딱 한번만 사용가능

**문법 :**

-- tCity 테이블에서 region컬럼에 대해 중복 제거하여 출력
SELECT DISTINCT region FROM tCity;

-- tCity 테이블에서 region, name 컬럼 합쳐서 중복인 행을 제거합니다.
SELECT DISTINCT region, name FROM tCity;

--중복제거
--DISTINCT
--DISTINCT 는 SELECT 안에 딱 하나만 존재가능
--SELECT 의 결과는 완전한 사각형의 모습을 갖춰야함 100:100
SELECT DISTINCT DEPARTMENT_ID --, EMPLOYEE_ID 12:104개(x)
FROM EMPLOYEES;
```

### SELECT-AS(별칭)

```sql
2) 별칭 (Alias)
	- 조회 결과의 컬럼명 또는 계산식, 함수결과를 대신해서 출력할 컬럼명
	- 별칭의 글자사이에 공백이나 기호문자가 포함 될때는 쌍따옴표로 감쌈
	- 테이블명도 별칭 가능

	a. 컬럼명(계산식, 함수호출) AS 별칭
	b. 컬럼명(계산식, 함수호출) 별칭
	c. 테이블명 별칭

**문법:**

--사운의 성, 이름, 월급, 입사일
--뛰어쓰기 다음 별칭 or AS 별칭 (한글도가능)
--뛰어쓰기 꼭 해야겠다 하면 "" 사이에 적기 (사용빈도 많지x)
SELECT FIRST_NAME, LAST_NAME,SALARY*12 AS YEAR_SALARY, (SALARY*12)-5000 AS SAL, HIRE_DATE, HIRE_DATE 입사날짜
FROM EMPLOYEES;
```

### SELECT-||’문자열’||(연결 연산자)

```sql
3) 연결 연산자
	- 조회 결과를 문장 형식으로 보고 싶을 때 많이 사용
	- 컬럼명 || '문자열' || 컬럼명 || '문자열'
	- "a"+"b" => "ab"

**문법 :**

--문자열을 추가하기 || '문자열' ||   (사용빈도 낮음)
SELECT STATE_PROVINCE || '의 도시명은' || CITY
FROM LOCATIONS;
```

### WHERE-<,>,= (비교연산자)

```sql
1) 비교연산자
			>, <, >=, <= , =, != ( !=랑같음 ^=, <> )

**문법 :**

--WHERE
--부서번호(DEPARTMENT_ID 가 90인것만 조회
SELECT FIRST_NAME, SALARY, DEPARTMENT_ID
FROM EMPLOYEES
WHERE DEPARTMENT_ID = 90;

--사원의 정보, 사원의ID, JOB ID(직급), 입사일, 월글
--월급이 8000 이상이고 DEPARTMENT ID 100
--다른 컬럼은 BETWEEN 사용불가
SELECT EMPLOYEE_ID, JOB_ID, HIRE_DATE, SALARY, DEPARTMENT_ID
FROM EMPLOYEES
WHERE SALARY >= 8000 AND DEPARTMENT_ID = 100;
```

### WHERE-AND,OR (논리 연산자)

```sql
2) 논리연산자
			and ,  or

**문법:**

--사원의 모든정보
--급여가 8000이상 15000이하인 사원만
SELECT *
FROM EMPLOYEES
WHERE SALARY >= 8000 AND SALARY <= 15000;
```

### WHERE-IS NULL (NULL 연산자)

```sql
3) NULL 연산자
			- 알수없는 DATA, 무한대
			- 0 이 X, 비어있다 X
			- null+3 => null
		a. IS NULL     : 컬럼명 IS NULL    // null 값이 있는 행을보여줌
		b. IS NOT NULL : 컬럼명 IS NOT NULL  //  null 값이 없는 행을 보여줌

**문법 :**

-- NULL은 알수없는 DATA 0이아님
SELECT *
FROM EMPLOYEES
WHERE COMMISSION_PCT IS NULL;

-- NULL이 아닌
SELECT *
FROM EMPLOYEES
WHERE COMMISSION_PCT IS NOT NULL;

```

### WHERE-BETWEEN(AND)

```sql
4) BETWEEN (and)
			- WHERE A >= 10 and A<=100
			- WHERE 컬럼명 between 작은값 and 큰값
			- WHERE A between 10 and 100
			- WHERE A NOT BETWEEN 10 and 100

			- WHERE A>=10 and B<=100 => 컬럼이 2개이상은 between으로 표현 할 수 없음

**문법 :**

--BETWEEN
--자동으로 이상 이하설정
--and 의 개념
--NOT 사용가능 NOT BETWEEN
SELECT  *
FROM EMPLOYEES
WHERE SALARY BETWEEN 8000 AND 15000;
```

### WHERE-IN(OR)

```sql
5) IN (OR)
			- WHERE A = 10 or A = 20
			- WHERE 컬럼명 IN (값1, 값2,...)
			- WHERE A IN (10, 20)
			- WHERE A NOT IN (10, 20)

IN 연산자의 장점

-  목록에 넣을 값이 여러 개일때, IN 연산자가 보다 쓰기도 쉽고, 이해하기도 쉽다.

-  IN을 사용하면 평가 순서를 보다 쉽게 관리 할 수 있고, 연산자 수도 줄어든다.

-  IN 연산자가 OR 연산자보다 실행 속도가 빠르다.

-  IN의 가장 큰 장점은 IN 연산자에 다른 SELECT 문을 넣을 수 있다.

-  동적인 WHERE 절을 만들때 더 크게 활용 된다.

예제 **:**

--SELECT 문 IN에 넣기 (값이 여러개)
****SELECT *
  FROM TABLE
 WHERE COLUMN IN (SELECT COLUMN1
                    FROM TABLE2)

****--사원의 모든정보
--부서번호가 60,100인 사원들
SELECT  *
FROM EMPLOYEES
WHERE DEPARTMENT_ID =60 OR DEPARTMENT_ID = 100;

--사원의 모든정보
--IN() 를 사용해서 위 식을 간소화 가능
SELECT  *
FROM EMPLOYEES
WHERE DEPARTMENT_ID IN (60,100);
```

### WHERE-LIKE

```sql
6) LIKE
		- 특정 문자열에 일치하는 데이터를 조회
		- WHERE 컬럼명 LIKE 검색어

		a.  '_'     : 글자수 1개, 어떤 글자든 상관 없음

				WHERE 컬럼명 LIKE '_K'    : 총 2글자중에서 K로 끝나는 것들
				WHERE 컬럼명 LIKE '_K_'   : 총 3글자중 중간에 K가 있는것들
				WHERE 컬럼명 LIKE 'K_ _'  : 총 3글자중에서 K로 시작하는 것들

				ex)JUMIN : 941225-1234567
			  ex) 1900년대에 태어난 여성만 검색
				ex) WHERE JUMIN LIKE '______-2______'

		b.  '%'     : 글자수 0개 이상, 어떤 글자든 상관 없음 **(언더바 보다 많이사용)**
				WHERE 컬럼명 LIKE '%K'     : 글자수 상관X , 뭐로 시작하든 K로 끝나는 것들
				WHERE 컬럼명 LIKE '%K%'    : 글자수 상관X , K가 포함되어 있는 모든 것들
				WHERE 컬럼명 LIKE 'K%'     : 글자수 상관X, K로 시작하는 모든 것들
        WHERE 컬럼명 LIKE '%%'     : 글자수 상관X, 모든것

		c. ESCAPE 옵션
				- %, _ 를 문자열에 포함해서 검색하고 싶을 때

				WHERE 컬럼명 LIKE '%#%%' ESCAPE '#'
				WHERE 컬럼명 LIKE '%$%%' ESCAPE '$'

예제 **:**

SELECT *
FROM EMPLOYEES
WHERE LAST_NAME LIKE '%k%';
```

```sql
--사원의 모든정보
--LAST NAME 이 Austin 인사람
```

## 3. GROUP BY

```sql
3. GROUP BY
		- GROUP BY 그룹으로 묶을 컬럼명

4. HAVING
		- 그룹의 조건

SELECT DEPARTMENT_ID, SUM(SALARY)   -- 5
FROM EMPLOYEES						          -- 1
WHERE DEPARTMENT_ID >=50			      -- 2
GROUP BY DEPARTMENT_ID				      -- 3
HAVING SUM(SALARY)>=50000			      -- 4
ORDER BY SUM(SALARY) DESC;	        -- 6

**예제 :**
-- 평균 급여, 큰 부서금액
-- 평균 급여 1000 이상
SELECT DEPARTMENT_ID, AVG(SALARY), MAX(SALARY), MIN(SALARY)
FROM EMPLOYEES
WHERE MANAGER_ID IS NOT NULL
-- 그룹으로 묶을때
GROUP BY DEPARTMENT_ID
--그룹에 조건을 줄때
HAVING AVG(SALARY) >10000
ORDER BY 2 DESC;
```

## 4. HAVING

```sql
4. HAVING
		- 그룹의 조건

SELECT DEPARTMENT_ID, SUM(SALARY)   -- 5
FROM EMPLOYEES						          -- 1
WHERE DEPARTMENT_ID >=50			      -- 2
GROUP BY DEPARTMENT_ID				      -- 3
HAVING SUM(SALARY)>=50000			      -- 4
ORDER BY SUM(SALARY) DESC;	        -- 6

**예제 :**
--메니저별 사원수
SELECT MANAGER_ID ,COUNT(EMPLOYEE_ID)
FROM EMPLOYEES
--WHERE MANAGER_ID IS NOT NULL
GROUP BY MANAGER_ID
HAVING MANAGER_ID IS NOT NULL;
```

## 5. Order By

```sql
5. Order By
	- Table에 Data는 순서대로 저장 되지 않음
	- 조회할때 순서를 지정하고 싶을 때 사용

	1) 정렬방식
		a. 오름차순 : asc      - 작은것부터 큰것
		b. 내림차순 : desc     - 큰것부터 작은것

	2) 문법
		- ORDER BY 컬럼명 정렬방식
		- ORDER BY 컬럼의Index번호 정렬방식

		- ORDER BY 컬럼명1 정렬방식, 컬럼명2 정렬방식,...
		- ORDER BY 컬럼의Index번호 정렬방식, 컬럼의Index번호 정렬방식
			-- 컬럼명(Index번호)1로 정렬하고, 동등한 값이 있는 row들은 컬럼명(Index번호)2로 다시 정렬

**예제**

	**--사원의 급여순으로 출력
--내림차순
SELECT LAST_NAME , SALARY
FROM EMPLOYEES
ORDER BY SALARY DESC;

--사원의 급여순으로 출력
--내림차순
--SALARY 로 정렬 LAST_NAME으로 또 정렬가능
SELECT LAST_NAME , SALARY
FROM EMPLOYEES
ORDER BY SALARY DESC, LAST_NAME ASC;

--사원의 급여순으로 출력
--내림차순
--숫자를 이용해서 출력가능(SELECT 의 컬럼 1,2)
SELECT LAST_NAME , SALARY
FROM EMPLOYEES
ORDER BY 2 DESC;

--LAST_NAME 기준 오름차순
SELECT LAST_NAME , SALARY
FROM EMPLOYEES
ORDER BY LAST_NAME  ASC;

--사원 모든 정보
--입사순
SELECT *
FROM EMPLOYEES
ORDER BY HIRE_DATE ASC;**
```

## 6. INSERT

```java
- INSERT, UPDATE, DELETE는 Query의 결과로 성공한 ROW 갯수 만큼 숫자가 리턴.
- 0이면 실패, 1이상 양의 정수는 성공

- DB에 새로운 데이터를 추가

1. 컬럼을 나열 하는 방식
INSERT INTO 테이블명 (컬럼명1, 컬럼명2,...)
VALUES (값1, 값2,...)

- 테이블의 컬럼순서와 달라도 상관 없음
- 단, 선언한 컬럼명의 순서와 값의 순서는 일치
- NULL이 허용된 컬럼에 NULL을 INSERT 할 때 컬럼명을 생략 하고 INSERT

2. 컬럼을 생략 하는 방식
INSERT INTO 테이블명
VALUES (값1, 값2,...)

- value는 테이블의 컬럼의 순서와 일치시켜야 하고, 갯수도 같아야 함

3. INSERT 의 VALUES에 SubQuery를 이용해서 데이터를 입력 할 수 있다.

**예제

-- 1. INSERT INTO 테이블명 (컬럼1, 컬럼2,...) values(값1, 값2,...)
SELECT * FROM REGIONS
ORDER BY REGION_ID ASC;

INSERT INTO REGIONS (REGION_ID, REGION_NAME)
VALUES (5,'Test');

INSERT  INTO REGIONS (REGION_NAME, REGION_ID)
VALUES ('Test2', 6);

INSERT  INTO REGIONS  (REGION_ID, REGION_NAME)
VALUES (7, null);

INSERT  INTO REGIONS  (REGION_ID)
VALUES (8);

-- 갯수를 맞춰야 함 error
--INSERT INTO REGIONS  (REGION_ID, REGION_NAME)
--VALUES (9);

--INSERT  INTO REGIONS  (REGION_ID, REGION_NAME)
--VALUES (NULL< NULL);

--컬럼 생략 방식
--value 는 테이블 순서 숫자 일치 시켜야함
INSERT  INTO REGIONS
VALUES(9, 'Test3');

INSERT  INTO REGIONS
VALUES(10, null);

--Error 값의 개수를 맞춰줘야함
--INSERT  INTO REGIONS
--VALUES (11)**
```

## UPDATE

```java
- Table에 있는 컬럼의 값을 수정 할 때

1. 문법
UPDATE 테이블명 SET 수정할컬럼명1=수정할값1, 수정할컬럼명2=수정할값, ...             : 테이블의 모든 ROW가 수정
UPDATE 테이블명 SET 수정할컬럼명1=수정할값1, 수정할컬럼명2=수정할값, ... WHERE 조건식 : 특정한 ROW 수정

**예제
--------------------------UPDATE-----------------------------------------
SELECT * FROM DEPARTMENTS;
UPDATE DEPARTMENTS SET MANAGER_ID = 200 WHERE DEPARTMENT_ID = 120;
ROLLBACK;

UPDATE DEPARTMENTS SET DEPARTMENT_NAME = 'ITTest', MANAGER_ID = NULL
WHERE DEPARTMENT_ID = 280;
COMMIT;

SELECT * FROM EMPLOYEES;

UPDATE EMPLOYEES SET JOB_ID = 'AD_PRES', EMAIL = 'SKING'
WHERE EMPLOYEE_ID = 100;**
```

## DELETE

```java
- Table에 있는 ROW를 삭제

DELETE 테이블명              : Table의 모든 ROW 삭제
DELETE 테이블명 WHERE 조건식 : 특정한 ROW 삭제

- MYSQL 같은 경우
- DELETE FROM 테이블명 WHERE 조건식

**예제
```

### 1. 그룹함수(Group Function)

```java
- 컬럼의 값이 여러개라도 결과는 한개 리턴하는 함수
- 컬럼의 값(row)이 20개라도 결과는 1개
- 모든 그룹함수는 NULL값을 무시(제외)

1) SUM(컬럼명)          : 해당 컬럼의 총합을 계산, NULL은 제외
2) AVG(컬럼명)          : 해당 컬럼의 평균을 계산, NULL은 제외
3) COUNT(컬럼명)        : 해당 컬럼의 ROW의 총 갯수를 계산, NULL은 제외
4) MAX(컬럼명)          : 해당 컬럼에서 최대값(제일 큰 값)을 조회, NULL은 제외
5) MIN(컬럼명)          : 해당 컬럼에서 최소값(제일 작은값)을 조회, NULL은 제외

**예시

---SUM

SELECT SUM(SALARY) FROM EMPLOYEES;

--합, 평균
SELECT  SUM(SALARY), AVG(SALARY) FROM EMPLOYEES;

-- 카운트
SELECT COUNT(EMPLOYEE_ID) FROM EMPLOYEES;

--합, 평균, 카운트 (null 값들은 다 제외)
SELECT SUM(COMMISSION_PCT),AVG(COMMISSION_PCT), COUNT(COMMISSION_PCT) FROM EMPLOYEES;

--null 값까지 포함
SELECT SUM(COMMISSION_PCT)/COUNT(EMPLOYEE_ID)  FROM EMPLOYEES;**
```

### 2. 단일함수(Single Function)

```java
- 컬럼에 값을 각각 한개씩 처리해서 각각의 결과를 리턴하는 함수
- 컬럼의 값(row)이 20개라면 결과도 20개
- 숫자 함수, 문자열 함수, 날짜 함수, NULL 함수

1. NULL 함수
	1) NVL(컬럼명, 변경할 값)
		- 컬럼들의 값중에서 NULL인것들을 변경할 값으로 변경
	2) NVL2(컬럼명, 변경할값1, 변경할값2)
		- 컬럼들의 값중에서 NULL이 아니면 변경값1로 변경하고, NULL이면 변경값2로 변경

**예시

SELECT DEPARTMENT_NAME , NVL(MANAGER_ID, 200)
FROM DEPARTMENTS;

SELECT SUM(COMMISSION_PCT)/COUNT(EMPLOYEE_ID),  AVG(COMMISSION_PCT)
FROM EMPLOYEES;

--NULL 함수
--NULL값을 0으로 변경, 평균값 똑같이 만들기
SELECT SUM(COMMISSION_PCT)/COUNT(EMPLOYEE_ID), AVG(NVL(COMMISSION_PCT,0))
FROM EMPLOYEES;

--MANAGER_ID 가 NULL 이면 100 아니라면 200
SELECT DEPARTMENT_NAME , NVL2(MANAGER_ID,100, 200)
FROM DEPARTMENTS;**

2. 숫자 처리 함수
	1) ABS(컬럼명 또는 숫자)     : 절대값 리턴
	2) FLOOR(컬럼명 또는 숫자)   : 소숫점 아래 값을 버림
	3) ROUND(컬럼명 또는 숫자, [반올림할 자릿수])
		- 지정한 자리 까지 반올림 (0이면 소숫점 첫째자리, 1이면 둘째 자리)
		- 음수를 지정하면 정수부에 해당
	4) TRUNC(컬럼명 또는 숫자, [적용할 자릿수])
		- 지정한 자리 이하의 값은 버림
		- 음수를 지정하면 정수부에 해당
	5) MOD(컬럼명 또는 숫자, 나눌 수) : 나머지 구하기

**예시

-- 숫자함수
SELECT  ABS(-2.3) FROM DUAL;
SELECT  FLOOR(3.123) FROM DUAL;
SELECT  ROUND(3.723, 1) FROM DUAL;**

3. 문자열 처리 함수
	1) UPPER(컬럼명 또는 문자열)     : 대문자로 변경
	2) LOWER(컬럼명 또는 문자열)     : 소문자로 변경
	3) INITCAP(컬럼명 또는 문자열)   : 첫글자만 대문자로 변경
	4) LENGTH(컬럼명 또는 문자열)    : 글자의 갯수 조회
	5) LENGTHB(컬럼명 또는 문자열)   : 문자열 총 Byte 크기를 조회
	6) SUBSTR(컬럼명 또는 문자열, 시작번호, 글자 갯수)
			- 문자열에서 일부분 파싱(Java의 subString())
			- 시작번호는 1번 부터
			- 시작번호가 음수이면 뒤에서 부터의 위치
	7) SUBSTRB(컬럼명 또는 문자열, 바이트크기로 봤을 때의 위치, 추출할 바이트 크기)
	8) RPAD/LPAD(컬럼명 또는 문자열, 표현할 너비, 채울문자)
		-- RPAD  : 오른쪽을 채울문자로 채움
		-- LPAD  : 왼쪽을 채울문자로 채움
	9) TRIM([제거할문자] from 컬럼명 또는 문자열)
		- 제거할 문자가 없으면 기본은 공백 문자( ' ' )
		- 앞 뒤 제거
	10) LTRIM/RTRIM(컬럼명 또는 문자열, 제거할 문자)
	11) REPLACE(컬럼명 또는 문자열, 'Old Char', 'New Char')
		- 문자열에 있는 Old Char(문자)를 New Char(문자)로 변경

**예시

--문자 함수
SELECT DEPARTMENT_ID , UPPER(DEPARTMENT_NAME)
FROM  DEPARTMENTS;

SELECT RPAD('abc', 10, '!') FROM DUAL;
SELECT LPAD('abc', 10, '%') FROM DUAL;**

4. 날짜 처리 함수
	- 날짜는 연산이 가능
	- 날짜 + 숫자의 결과는 날짜 데이터 타입
	- 날짜 + 연산은 며칠 뒤를 의미
	- 날짜 - 연산은 며칠 전을 의미

	1) 현재(오늘) 날짜 조회 함수
		a. SYSDATE
		b. SYSTIMESTAMP
		c. CURRENT_DATE
		d. CURRENT_TIMESTAMP

	2) ADD_MONTHS(컬럼명 또는 날짜데이터, 추가할 개월수)
		- 날짜에 개월수가 추가된 날짜가 리턴
	3) MONTHS_BETWEEN(컬럼명 또는 날짜데이터 A, 컬럼명 또는 날짜데이터 B)
		- A와 B사이의 개월 수
	4) NEXT_DAY(컬럼명 또는 날짜데이터, '요일 이름')
		- 날짜에 지정한 요일에 가장 가까운 날짜를 리턴
		- KOR 버전이면 한글로 요일 이름을 지정 ('일요일' 또는 '일')
		- ENG 버전이면 영어로 요일 이름을 지정 ('SUNDAY' 또는 'SUN')
		- 요일 이름 대신 숫자 가능
		- 1-일요일, 2-월요일 ,... 7-토요일
	5) LAST_DAY(컬럼명 또는 날짜데이터)
		- 날짜가 있는 해당 월의 마지막 날짜를 리턴

	6) EXTRACT(추출할 정보 FROM 컬럼명 또는 날짜데이터) AS 별칭
		- 날짜에서 년, 월, 일, 시, 분, 초 등의 특정 정보를 추출
		- YEAR, MONTH, DAY, HOUR, MINUTE, SECOND...

		- SELECT EXTRACT (MINUTE FROM SYSTIMESTAMP) AS MINUTE FROM DUAL;

5. 형변환 함수
		숫자 <--> 문자열 <--> 날짜

	1) TO_CHAR(숫자 또는 날짜, '포맷문자열')
```

# SubQuery

```java
- Query(SQL)문 내에 또 다른 Query(SQL)문
- 메인Query문에서 사용할 값을 조회할 목적으로 사용
- 서브쿼리는 시작과 끝부분을 ( SubQuery문 ) 감 쌈
- 서브쿼리는 갯수는 제한이 없음
- 사용 위치
	SELECT   서브쿼리
  FROM     서브쿼리
	WHERE    서브쿼리
	GROUP BY 서브쿼리

	INSERT, UPDATE, DELETE , CREATE

**SubQuery의 결과물의 갯수에 따라 분류**

1. **단일행(Single-row) 서브쿼리**
	- Subquery의 결과물이 한개인 경우
	- 비교연산자의 뒤에서 단독 사용 경우 : >, >=, <. <=, =, != ...

	-- 사원 사원번호, 성, 이름, 월급 , 평균 급여보다 많이 받는 직원들
	SELECT EMPLOYEE_ID, LAST_NAME, FIRST_NAME, SALARY
	FROM EMPLOYEES
	WHERE SALARY > 6461;

	SELECT AVG(SALARY) FROM EMPLOYEES; -- 6461

	-> Subquery
	SELECT EMPLOYEE_ID, LAST_NAME, FIRST_NAME, SALARY
	FROM EMPLOYEES
	WHERE SALARY > (SELECT AVG(SALARY) FROM EMPLOYEES);

**예시

---사원들의 정보 평균 급여보다 많이 받는 사원들의 정보 (서브쿼리)
SELECT *
FROM EMPLOYEES
WHERE SALARY > (SELECT AVG(SALARY) FROM EMPLOYEES);

======================================================================================

---First_name lex 의 관리자의 First_name
SELECT FIRST_NAME
FROM EMPLOYEES
WHERE EMPLOYEE_ID =
	(
		SELECT MANAGER_ID
		FROM EMPLOYEES
		WHERE FIRST_NAME = 'Lex'
	);

======================================================================================
-- 사원들 중에서 급여를 제일 많이 받는 사원과
-- 같은 부서에 근무하는 사원들의 평균급여
SELECT AVG(SALARY)
FROM EMPLOYEES
WHERE DEPARTMENT_ID =
	(
		SELECT DEPARTMENT_ID
		FROM EMPLOYEES
		WHERE SALARY = (SELECT MAX(SALARY)FROM EMPLOYEES)
	);

======================================================================================**

2. 다중행(Multi-row) 서브쿼리
	- SubQuery의 결과물이 여러개인 경우
	- 결과물이 여러개 이기 때문에 비교 연산자 불가능

	- IN, NOT IN, any, all, exists,

	1) all
			- and의 의미
			WHERE column명 > ALL(값1, 값2...)    : culumn의 값이 값1보다 크고 그리고, 값2보다 크고...
			WHERE SALARY > ALL (100, 200)       : 값들 중에서 최대값보다 큰것들
			WHERE SALARY < ALL (100, 200)       : 값들 중에서 최소값보다 작은것들

	2) any
			- or 의 의미
			WHERE column명 > ANY (값1, 값2...)    : culumn의 값이 값1보다 크거나, 값2보다 크거나...
			WHERE SALARY > ANY (100, 200)       : 값들 중에서 최소값보다 큰것들
			WHERE SALARY < ANY (100, 200)       : 값들 중에서 최대값보다 작은것들

	3) Exists
			- 대용량의 데이터에서 검색시 많이 사용
			WHERE EXISTS (서브쿼리)             : 서브쿼리에서 반환하는 행이 1개라도 있으면 true
			WHERE NOT EXISTS (서브쿼리)         : 서브쿼리에서 반환하는 행이 하나라도 없어야 true
```
