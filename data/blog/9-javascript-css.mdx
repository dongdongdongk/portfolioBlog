# { 모달 추가하기 }

## **백드롭과 모달 추가**:

```css
페이지에 백드롭(.backdrop)과 모달(.modal)을 추가합니다. 백드롭은 모달 뒤에 나타나는 반투명한 배경입니다.

모달 HTML 코드는 div.modal로 구성되어 있으며, h1 태그와 두 개의 버튼으로 이루어져 있습니다.
```

```css
    <div class="modal">
        <h1 class="modal__title">Do you want to continue?</h1>
        <div class="modal__actions">
            <a href="start-hosting/index.html" class="modal__action">Yes!</a>
            <button class="modal__action modal__action--negative" type="button">No!</button>
        </div>
    </div>
```

## **CSS 스타일링**:

```css
CSS 파일을 열어 모달을 스타일링하는 코드를 추가합니다. 주요 스타일 속성:

		position: fixed;로 페이지의 고정 위치에 배치.

		z-index를 설정하여 모달이 백드롭보다 앞에 위치하도록 합니다 (.modal의 z-index는 200, .backdrop의 z-index는 100).

		기타 스타일로 배경 색, 그림자, 테두리, 패딩 등을 설정합니다.
```

```css
.modal {
  position: fixed;
  display: none;
  z-index: 200;
  top: 20%;
  left: 30%;
  width: 40%;
  background: white;
  padding: 1rem;
  border: 1px solid #ccc;
  box-shadow: 1px 1px 1px rgba(0, 0, 0, 0.5);
}

.modal__title {
  text-align: center;
  margin: 0 0 1rem 0;
}

.modal__actions {
  text-align: center;
}

.modal__action {
  border: 1px solid #0e4f1f;
  background: #0e4f1f;
  text-decoration: none;
  color: white;
  font: inherit;
  padding: 0.5rem 1rem;
  cursor: pointer;
}

.modal__action:hover,
.modal__action:active {
  background: #2ddf5c;
  border-color: #2ddf5c;
}

.modal__action--negative {
  background: red;
  border-color: red;
}

.modal__action--negative:hover,
.modal__action--negative:active {
  background: #ff5454;
  border-color: #ff5454;
}
```

# { JavaScript를 사용한 스타일 선택 및 조정하기 }

## **JavaScript 활용 이유**:

```css
JavaScript는 페이지 로드 후 실행되며 HTML과 CSS를 동적으로 변경할 수 있습니다.
```

## **JavaScript 파일 생성 및 추가**:

```css
프로젝트 폴더에 shared.js 파일을 생성합니다.

index.html의 <body> 태그 끝에 <script src="shared.js"></script>를 추가합니다.
```

## **JavaScript로 요소 선택**:

```css
JavaScript에서 HTML 요소(DOM 요소)를 선택하려면 document.querySelector() 메서드를 사용합니다.

예: const backdrop = document.querySelector('.backdrop');

querySelector는 첫 번째 일치 요소를 선택하고, querySelectorAll은 모든 일치 요소를 배열 형태로 반환합니다.
```

## **스타일 변경**:

```css
선택한 요소의 스타일을 변경하려면 element.style을 사용합니다.

예: backdrop.style.display = 'block';는 백드롭의 display 속성을 block으로 변경하여 화면에 보이게 합니다.
```

## **인라인 스타일과 CSS 스타일 차이**:

```css
element.style은 인라인 스타일을 설정하며, 이는 외부 CSS 스타일을 덮어씁니다.

JavaScript로 스타일을 변경하면, 인라인 스타일이 추가됩니다.
```

# { 이벤트 리스너 추가하기 }

## **요소 선택**:

```css

```

## **이벤트 리스너 추가**:

```css
버튼 클릭 시 특정 작업을 수행하기 위해 각 버튼에 이벤트 리스너를 추가합니다.

addEventListener 메서드를 사용하여 버튼이 클릭될 때마다 모달과 백드롭이 표시되도록 합니다.
```

```css
for (let i = 0; i < selectPlanButton.length; i++) {
    selectPlanButton[i].addEventListener('click', function() {
        modal.style.display = 'block';
        backdrop.style.display = 'block';
    });
}
```

## **이벤트 리스너와 익명 함수**:

### 1. 이벤트 리스너 (Event Listener)

```css
이벤트 리스너는 특정 이벤트가 발생할 때 실행될 함수를 등록하는 메서드입니다.

웹 페이지에서 사용자가 어떤 작업을 할 때(예: 클릭, 키보드 입력, 마우스 이동 등)

이 작업을 감지하고 미리 정의된 코드를 실행하기 위해 사용합니다.
```

### `addEventListener` 메서드

```css
addEventListener 메서드는 DOM 요소에 이벤트 리스너를 추가할 때 사용합니다. 이 메서드는 두 개의 주요 인수를 받습니다:

이벤트 타입 (Event Type):

어떤 이벤트가 발생할 때 리스너를 실행할지 정의합니다. 예를 들어, 'click'은 클릭 이벤트를 의미합니다.

콜백 함수 (Callback Function):

이벤트가 발생했을 때 실행될 함수입니다. 이 함수는 이벤트가 발생할 때마다 호출됩니다.
```

```css
element.addEventListener('event', function);
```

### 2. 익명 함수 (Anonymous Function)

```css
익명 함수는 이름이 없는 함수입니다. 일반적으로 일회성으로 사용되거나 특정 위치에서만 사용될 때 정의합니다.

익명 함수는 다른 함수의 인수로 전달되거나 즉시 실행할 필요가 있을 때 유용합니다.
```

```css
익명 함수의 사용 예

addEventListener에서 익명 함수를 사용하면 특정 이벤트가 발생할 때 실행할 코드를 직접 정의할 수 있습니다.

이는 코드의 가독성을 높이고 특정 이벤트와 관련된 동작을 하나의 명확한 블록으로 그룹화하는 데 도움이 됩니다.
```

```css
// 선택된 버튼에 이벤트 리스너를 추가합니다
selectPlanButton[i].addEventListener('click', function() {
    modal.style.display = 'block';  // 모달을 표시합니다
    backdrop.style.display = 'block';  // 백드롭을 표시합니다
});
```

## 기본 설정:

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381564/notion-blog/_/_/CSS/_CSS_/_9_JavaScript_CSS_/image_4.png)

```css
HTML 요소 중 햄버거 버튼(.toggle-button)과 사이드 내비게이션 메뉴(.mobile-nav)를 자바스크립트에서 선택해야 합니다.

document.querySelector를 사용하여 요소를 선택하고, 변수 toggleButton과 mobileNav에 각각 저장합니다.
```

```jsx
let backdrop = document.querySelector('.backdrop')
let modal = document.querySelector('.modal')
let selectPlanButton = document.querySelectorAll('.plan button')
let toggleButton = document.querySelector('.toggle-button')
let mobileNav = document.querySelector('.mobile-nav')
let modalNoButton = document.querySelector('.modal__action--negative')

for (let i = 0; i < selectPlanButton.length; i++) {
  selectPlanButton[i].addEventListener('click', function () {
    modal.style.display = 'block'
    backdrop.style.display = 'block'
  })
}

backdrop.addEventListener('click', function () {
  mobileNav.style.display = 'none'
  closeModal()
})

modalNoButton.addEventListener('click', closeModal)

function closeModal() {
  backdrop.style.display = 'none'
  modal.style.display = 'none'
}

toggleButton.addEventListener('click', function () {
  mobileNav.style.display = 'block'
  backdrop.style.display = 'block'
})
```

## 모달 및 백드롭에 클래스 추가

```jsx
모달 창과 백드롭에 open 클래스를 추가하여 표시되도록 설정합니다.

( 삭제 또한 같은 방식으로 )
```

```jsx
let backdrop = document.querySelector('.backdrop')
let modal = document.querySelector('.modal')
let selectPlanButton = document.querySelectorAll('.plan button')
let toggleButton = document.querySelector('.toggle-button')
let mobileNav = document.querySelector('.mobile-nav')
let modalNoButton = document.querySelector('.modal__action--negative')

// 모달 열기
for (let i = 0; i < selectPlanButton.length; i++) {
  selectPlanButton[i].addEventListener('click', function () {
    modal.classList.add('open')
    backdrop.classList.add('open')
  })
}

// 모달과 백드롭 닫기
function closeModal() {
  modal.classList.remove('open')
  backdrop.classList.remove('open')
}

// 백드롭 클릭 시
backdrop.addEventListener('click', function () {
  mobileNav.classList.remove('open') // 모바일 네비게이션 닫기
  closeModal() // 모달 닫기
})

// 모달 닫기 버튼 클릭 시
modalNoButton.addEventListener('click', closeModal)

// 모바일 네비게이션 열기
toggleButton.addEventListener('click', function () {
  mobileNav.classList.add('open')
  backdrop.classList.add('open')
})
```
