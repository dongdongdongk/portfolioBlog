## 타깃 내부에서 요소들을 식별하는 세가지 방법

```python
**엄격한 선택기**

엄격한 선택기는 모든 선택기 속성에 정확히 일치하는 단일 요소를

반환해야만 작동하며 고정 장치 ( 앵커 ) 도 필요 없다 ( 크게 추천하는 방법은 아니다 하지만 속도는 가장 빠르다 )

**퍼지 선택기**

퍼지 선택기는 퍼지 선택기에 있는 속성과 유사한 속성을 가진 여러 앨리먼트를 반환한다 유사도는 슬라이더를 사용하여 조절이 가능하고 일반적으로

앵커가 필요하다

( 퍼지 선택기의 더블 링 표시는 대상을 정확하게 식별했다는 걸 보여준다 )

눈 모양의 버튼을 누른다면 화면에 선택기와 일치하는 모든 요소가 나타난다 퍼지 셀렉터는 모든 필드를 동일하게 식별하지만 성공적으로 타깃을

식별할 수 있는 이유는 앵커가있어서 찾는걸 도와주기 때문이다 ( 코드를 보면 onname 이라는 속성이 그 부분이다 )

**이미지 선택기**

다른 선택기가 식별에 실패하면 이미지를 사용
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380825/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_4_Robot_2_Data_Capturing/Untitled_31.png)

```python

가시성 검사 - UI 요소가 표시되는지 여부를 확인. 드롭다운 메뉴에서 세 가지 옵션 중 하나를 선택할 수 있다

**대화형( 퍼지 선택기의 경우 )**

기본 옵션입니다. 페이지 스크롤 및 다른 앱의 방해나 애플리케이션이 최소화된다는 사실을 무시하고

요소가 잠재적으로 표시되는지 확인한다.

이 검사는 DOM에 존재하지만 숨겨져 있는 보이지 않는 요소를 대상으로 하지 않는지 확인하려고 할 때 유용하다.

**전체 표시 가능**

UI 요소가 표시되는지 여부를 확인한다

**없음**

가시성을 확인하지 않는다.

**응답형 웹 사이트**

특정 웹사이트에서 줌인이나 줌아웃을 하면 앵커의 위치가 왼쪽에서 위로 움직이는 등 ui 의 변화로 인해 작동하지 않는다

하지만 이걸 확인하면 앵커가 타깃의 위로 이동되어도 UI 요소를 찾을 수 있다
```
