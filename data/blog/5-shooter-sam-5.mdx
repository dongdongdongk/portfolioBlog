# { 총을 손에 붙이기 }

## 🎯 이번에 할 것

바닥에 있던 총을 **캐릭터 손에 딱 붙여서** 들고 있게 만듭니다!

```
Before: 총이 바닥에 떨어져 있음 (0, 0, 0)
After: 총이 손에 딱 붙어서 따라다님 ✨
```

---

## 🧩 전체 과정 (큰 그림)

```
1. 캐릭터 메시의 기본 무기 숨기기
2. 스켈레톤에 소켓(Socket) 만들기
3. 총을 소켓에 붙이기
4. 위치 미세 조정
```

**비유:**

- 소켓 = 손에 붙은 자석
- 총 = 자석에 달라붙는 물건
- 손이 움직이면 총도 자동으로 따라감!

---

## 📝 Step 1: 기본 무기 숨기기

### 문제 상황

캐릭터 메시에 이미 총이 그려져 있어요!

```
캐릭터 메시
  └─ weapon_r (무기 뼈대)
      └─ 그려진 총 👈 이게 보임
```

우리가 만든 총을 들게 하려면 **이 기본 무기를 숨겨야** 합니다.

### 보너스: Enum(열거형) 설명

**EPhysBodyOp가 뭔가요?**

```cpp
enum class EPhysBodyOp
{
    PBO_None = 0,      // 아무것도 안 함
    PBO_Term = 1,      // 종료
    PBO_MAX = 2        // 최대값
};
```

**Enum = 미리 정의된 선택지들**

**비유:**

```
메뉴판 같은 것:
- 작은 사이즈
- 중간 사이즈
- 큰 사이즈

대신 0, 1, 2 숫자 쓰는 것보다 의미가 명확!
```

**사용 방법:**

```cpp
// Enum 타입::값
EPhysBodyOp::PBO_None

// 범위 확인 연산자 (::) 사용
```

**다른 예시:**

```cpp
ETriggerEvent::Started    // 입력 시작
ETriggerEvent::Triggered  // 입력 중
ETriggerEvent::Completed  // 입력 끝
```

## 🔌 Step 2: 소켓(Socket) 만들기

### Socket이 뭔가요?

**Socket = 뼈대에 물건을 붙일 수 있는 지점**

```
손 뼈대 (weapon_r)
  └─ Socket (WeaponSocket) 👈 여기에 총 붙일 거예요
      └─ 총이 딱 달라붙음!
```

**비유:**

- 뼈대 = 막대기
- 소켓 = 막대기에 붙은 자석
- 총 = 자석에 달라붙는 물건

손이 움직이면 → 뼈대 움직임 → 소켓 움직임 → 총 따라감!

## 🔗 Step 3: 총을 소켓에 붙이기

### 3-1: AttachToComponent 사용

**ShooterSamCharacter.cpp - BeginPlay:**

```cpp
void AShooterSamCharacter::BeginPlay()
{
    Super::BeginPlay();

    // 기본 무기 숨기기
    GetMesh()->HideBoneByName("weapon_r", EPhysBodyOp::PBO_None);

    // 총 생성
    Gun = GetWorld()->SpawnActor<AGun>(GunClass);

    if (Gun)
    {
        Gun->SetOwner(this);

        // ===== 총을 손에 붙이기! =====
        Gun->AttachToComponent(
            GetMesh(),                                    // 어디에?
            FAttachmentTransformRules::KeepRelativeTransform,  // 어떻게?
            TEXT("WeaponSocket")                          // 어느 소켓?
        );
    }
}
```

---

### 3-2: 코드 완벽 이해하기

**파라미터 1: GetMesh()**

```cpp
GetMesh()
```

- 캐릭터의 스켈레탈 메시
- 여기에 소켓이 있음

---

**파라미터 2: FAttachmentTransformRules**

```cpp
FAttachmentTransformRules::KeepRelativeTransform
```

**Transform Rules = 붙일 때 위치/회전 규칙**

**종류:**

**1. KeepRelativeTransform** (우리가 사용)

```
로컬 좌표 유지
총의 (0, 0, 0) → 소켓의 (0, 0, 0)

비유:
손에 딱 맞춰서 붙이기
```

**2. KeepWorldTransform**

```
월드 좌표 유지
총이 있던 월드 위치 그대로

비유:
총이 바닥에 있었으면 바닥에 그대로
(손에 안 붙음!)
```

**3. SnapToTargetXXX**

```
대상에 딱 맞춰서 스냅
크기도 조정
```

**우리가 KeepRelativeTransform 쓰는 이유:**

```
총을 (0, 0, 0) 로컬 위치에 배치
→ 소켓 위치에 딱 맞춰짐
→ 손과 함께 움직임 ✨
```

---

**파라미터 3: 소켓 이름**

```cpp
TEXT("WeaponSocket")
```

- 방금 만든 소켓 이름
- 정확히 일치해야 함!

---

### SetupAttachment vs AttachToComponent

**SetupAttachment (생성자에서)**

```cpp
// 컴포넌트 생성할 때
Mesh->SetupAttachment(SceneRoot);
```

- 블루프린트가 만들어질 때 연결
- 정적인 구조

**AttachToComponent (런타임에서)**

```cpp
// 게임 중에 붙이기
Gun->AttachToComponent(GetMesh(), ...);
```

- 게임이 실행되는 중에 연결
- 동적으로 붙였다 뗐다 가능

**비유:**

- SetupAttachment = 공장에서 조립
- AttachToComponent = 사용자가 장착

### SceneRoot를 만든 이유!

**이제 이해되죠?**

```
SceneRoot (소켓에 붙음, 위치 고정)
  └─ Mesh (위치 조정 가능!)
```

**만약 Mesh가 바로 루트였다면:**

```
Mesh (소켓에 붙음)
  └─ 위치 조정하면 소켓에서 떨어짐 ❌
```

**SceneRoot 덕분에:**

```
SceneRoot는 소켓에 딱 붙어있고
Mesh만 상대적으로 이동 가능! ✅
```

## 🤔 왜 시점이 필요한가요?

### 총 쏘기의 원리

**두 가지 방법:**

**방법 1: 실제 총알 발사 (Projectile)**

```
총 → 총알 오브젝트 생성 → 물리로 날아감
```

- 현실적이지만 느림
- 총알이 너무 빨라서 어차피 안 보임
- 불필요하게 복잡

**방법 2: Line Trace (우리가 사용할 방법)** ✅

```
시작점 → 끝점까지 선 그리기 → 맞은 거 감지
```

- 빠르고 효율적
- 총알이 빛의 속도로 이동
- 대부분의 슈팅 게임이 사용

**비유:**

```
방법 1 = 진짜 종이비행기 날리기
방법 2 = 레이저 포인터 쏘기 (즉시 도달!)
```

## 📝 Step 1: Controller 변수 추가

### Controller가 뭔가요?

**Controller = 캐릭터를 조종하는 두뇌**

```
Controller
    ↓
  캐릭터
    ↓
  움직임/회전
```

**종류:**

- **PlayerController**: 사람이 조종
- **AIController**: 컴퓨터가 조종

**왜 필요한가요?**

```
Controller가 카메라 시점 정보를 가지고 있음!
→ Controller에게 물어봐야 함
```

---

### 1-1: Gun 클래스에 Controller 변수 추가

**Gun.h:**

```cpp
UCLASS()
class SHOOTERSAM_API AGun : public AActor
```

### 코드 완벽 이해하기

**Step 1: 변수 선언**

```cpp
FVector ViewpointLocation;
FRotator ViewpointRotation;
```

**FVector = 3D 위치**

```cpp
FVector(X, Y, Z)
예: (100, 200, 300)
```

**FRotator = 3D 회전**

```cpp
FRotator(Pitch, Yaw, Roll)
- Pitch: 위/아래 (고개 끄덕임)
- Yaw: 좌/우 (고개 좌우)
- Roll: 기울기 (고개 갸우뚱)
```

---

**Step 2: GetPlayerViewPoint 호출**

```cpp
OwnerController->GetPlayerViewPoint(ViewpointLocation, ViewpointRotation);
```

**이 함수의 특별한 점:**

**참조(Reference) 매개변수 사용!**

```cpp
// 일반 함수:
int GetNumber()
{
    return 5;  // 하나만 반환
}

// GetPlayerViewPoint:
void GetPlayerViewPoint(FVector& Location, FRotator& Rotation)
{
    Location = 카메라위치;   // 두 개 다 수정!
    Rotation = 카메라회전;
}
```

**참조(&)의 의미:**

```
값 복사 X
원본 변수 직접 수정 O
```

**비유:**

```
일반 매개변수 = 복사본 주기
  함수(복사본);
  복사본만 바뀜, 원본은 그대로

참조 매개변수 = 원본 주기
  함수(원본&);
  원본이 바뀜!
```

**그림으로 이해:**

```cpp
FVector ViewpointLocation;  // 빈 상자
FRotator ViewpointRotation; // 빈 상자

GetPlayerViewPoint(ViewpointLocation, ViewpointRotation);
// 함수가 상자 안을 채워줌!

// 이제 사용 가능:
ViewpointLocation   // (100, 50, 200)
ViewpointRotation   // (0, 90, 0)
```

## 🤔 Line Trace가 뭔가요?

### Line Trace = 보이지 않는 레이저

**개념:**

```
시작점 ━━━━━━━━━━━━━━→ 끝점
        (보이지 않는 선)

선이 뭔가 맞으면?
→ 충돌 정보 반환!
```

**비유:**

```
레이저 포인터를 쏘는 것과 같음
- 즉시 도달 (빛의 속도)
- 중간 과정 없음
- 맞은 곳 감지
```

---

### Shape Trace vs Line Trace

**Shape Trace (이전에 배운 것):**

```
     ●  ← 구 모양이 날아감
    ◯
   ◯
  ◯
 ●
```

**Line Trace (이번에 배울 것):**

```
━━━━━━━━━━→  ← 선이 즉시 도달
```

**차이점:**

- Shape Trace: 모양이 있음, 두께가 있음
- Line Trace: 선만, 두께 없음, 더 빠름

---

## 📐 Line Trace의 구성 요소

### 필요한 것들

```
1. 시작점 (Start)
   → ViewpointLocation (카메라 위치)

2. 끝점 (End)
   → 시작점 + 방향 × 거리

3. 추적 채널 (Trace Channel)
   → 어떤 물체를 감지할지

4. 무시 목록 (Ignore List)
   → 무시할 액터들
```

### 끝점 계산 완벽 이해

**수식:**

```cpp

```

**부분별로 쪼개기:**

**1. ViewpointLocation (시작점)**

```cpp

```

- 카메라 위치
- 3D 좌표

**2. ViewpointRotation.Vector() (방향)**

```cpp
ViewpointRotation.Vector()  // 예: (1, 0, 0)
```

- 회전을 방향 벡터로 변환
- 길이가 1인 단위 벡터

**회전 → 벡터 변환:**

```
회전 (Pitch:0, Yaw:90, Roll:0)
  ↓ .Vector()
방향 벡터 (0, 1, 0)  // 오른쪽 방향
```

**3. \* MaxRange (거리 곱하기)**

```cpp
방향벡터 * 10000
예: (1, 0, 0) * 10000 = (10000, 0, 0)
```

- 방향에 거리를 곱함
- 최종 벡터 길이 = MaxRange

**4. + 시작점 (최종 위치)**

```cpp
(100, 200, 300) + (10000, 0, 0) = (10100, 200, 300)
```

- 시작점에서 방향으로 이동한 위치

---

### 시각적 이해

```
시작점: (0, 0, 0)
방향: 앞쪽 (1, 0, 0)
거리: 10000

계산:
(0,0,0) + (1,0,0) × 10000
= (0,0,0) + (10000,0,0)
= (10000, 0, 0)

그림:
시작 ━━━━━━━━━━→ 끝
(0,0,0)      (10000,0,0)
```

**4. HitResult.ImpactNormal.Rotation()**

```cpp
HitResult.ImpactNormal.Rotation()
```

**분해해서 이해:**

```cpp
HitResult.ImpactNormal
```

- 맞은 표면의 **법선 벡터**
- 표면에 수직인 방향

**법선 벡터가 뭔가요?**

```
벽 면
  ↑  ← 법선 (표면에 수직)
  |
━━━━━
```

```cpp
.Rotation()
```

- 벡터를 회전으로 변환
- 파티클이 표면 쪽을 향하게

**왜 필요한가요?**

```
벽에 맞으면:
  파티클이 벽 쪽 향함 ✅
  (벽 안쪽으로 안 들어감)

바닥에 맞으면:
  파티클이 위쪽 향함 ✅
  (바닥 아래로 안 들어감)
```

**시각적으로:**

```
총알 →  | 벽
       💥 ← 파티클 (표면 방향)
```

---

### 잘못된 코드 (강의의 실수)

**강의 코드:**

```cpp
HitResult.ImpactPoint.Rotation()  // ❌ 틀림!
```

**문제:**

```
ImpactPoint = FVector (위치)
→ 위치에는 .Rotation() 함수 없음!
→ 컴파일 에러!
```

**올바른 코드:**

```cpp
HitResult.ImpactNormal.Rotation()  // ✅ 맞음!
```
