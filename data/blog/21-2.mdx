- String 변수에 문자열 리터럴을 대입할 경우 String 객체로 생성되고 변수가 String 객체를 참조 한다.
- 문자열 리터럴이 동일한 경우 같은 번지를 가지고 결과 적으로 동일한 String 객체를 공유한다.

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%201.png>)

- new 를 사용하면 힙 영역에 새로운 객체를 생성하여 스택 영역에서 참조 하도록 한다.
- 고로 같은 문자 리터럴 을 가지고 있어도 객체를 비교했을 때 new 를 사용했다면 false 가 나온다.

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%202.png>)

- 문자열 비교는 == 은 잘 쓰지 않고 equals() 메소드를 사용한다
- 이는 스택에 저장된 번지를 비교 하는 것이 아닌 객체에 저장된 문자열을 비교하는 것이기 때문에 다른 번지에 다른 객체에 저장 되었어도 문자열이 같다면 true 가 나온다.

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%203.png>)

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%204.png>)

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%205.png>)

- String 변수에 null 을 입력하여 참조하는 객체가 없음으로 만들 수 있다.
- 여기서 참조 하던 객체가 있었는데 null 을 사용하여 참조 번지를 없에면 참조 번지를 잃은 String 객체는 쓰레기 수집기(Garbage Collector) 를 통해 메모리 에서 자동 제거 된다.(자바의 기능)

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%206.png>)

- 자바는 자동으로 메모리가 부족하거나 cpu가 한가할 때 쓰레기 객체를 메모리 에서 수거한다. 이러한 특징으로 객체를 메모리 에서 제거하고 싶으면 null 을 이용하여 참조 연결을 끊어주면 된다.

![Untitled](<21%20%EC%9E%90%EB%B0%94%20%EC%B0%B8%EC%A1%B0%20%ED%83%80%EC%9E%85%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EB%B3%80%EC%88%98(2)/Untitled%207.png>)

- 변수에 객체의 번지 저장 이란 말은 객체를 참조한다는 말과 동일하다.
- 메소드 영역에는 주로 코드
- 힙 영역에는 객체
- 스택 영역에는 변수가 저장 (메소드 호출이 끝나면 제거)
- heap 영역에 만들어 지는 변수는 자동으로 초기화가 진행된다.
  로컬 변수는 개발자가 꼭 초기화를 시켜줘야 한다.
