## user.js 컨트롤러

```jsx
const express = require('express')
const path = require('path')
const router = express.Router()
const { upload } = require('../multer')
const User = require('../model/user')
const fs = require('fs')
const ErrorHandler = require('../util/ErrorHandler')

// "/create-user" 엔드포인트에 대한 POST 요청을 처리하는 라우터 핸들러
router.post('/create-user', upload.single('file'), async (req, res, next) => {
  // 요청에서 필요한 데이터 추출
  const { name, email, password } = req.body

  // 이메일을 통해 이미 등록된 사용자인지 확인
  const userEmail = await User.findOne({ email })

  // 이미 등록된 사용자인 경우 에러 응답과 함께 파일 삭제 처리
  if (userEmail) {
    // 업로드된 파일의 이름을 추출하고 해당 파일 경로 생성
    const filename = req.file.filename
    const filePath = `uploads/${filename}`

    // fs.unlink를 사용하여 파일 삭제 시도
    fs.unlink(filePath, (err) => {
      if (err) {
        console.log(err)
        res.status(500).json({ message: '파일 삭제 실패' })
      } else {
        res.json({ message: '파일 삭제 성공' })
      }
    })

    // 사용자가 이미 존재함을 나타내는 에러 응답 반환
    return next(new ErrorHandler('유저가 이미 존재합니다', 400))
  }

  // 사용자가 존재하지 않는 경우, 파일의 이름을 경로로 변환
  const filename = req.file.filename
  const fileUrl = path.join(filename)

  // 새로운 사용자 객체 생성
  const user = {
    name: name,
    email: email,
    password: password,
    avatar: fileUrl,
  }

  // 새로운 사용자 등록
  const newUser = await User.create(user)

  // 성공적인 응답 반환
  res.status(201).json({
    success: true,
    newUser,
  })
})

// 라우터 객체 내보내기
module.exports = router
```

```jsx
라우터 원리 설명

Express 애플리케이션에서 app.use("/api/v2/user", user)라고 설정한 부분은

라우터 미들웨어를 사용하여 경로(/api/v2/user)에 대한 모든 요청을 user 라우터로 전달하는 역할을 한다.

간단히 말하면, 이 설정은 "/api/v2/user"로 시작하는 모든 URL에 대해 user 라우터로 요청을 전달한다.

즉, 클라이언트가 "/api/v2/user"로 시작하는 요청을 보내면 해당 요청은 user 라우터에서 처리된다.

실제로 user 라우터는 "/create-user" 경로에 대한 POST 요청을 처리하는 로직을 가지고 있다.

따라서 클라이언트에서 Axios를 사용하여 "http://localhost:5000/api/v2/user/create-user"에 POST 요청을 보내면,

Express 애플리케이션은 이 요청을 user 라우터의 "/create-user" 핸들러로 라우팅하게 된다.

요약하면, Express의 라우터 미들웨어를 사용하여 경로에 따라 요청을 분기 처리하고,

위에서 설정한 app.use("/api/v2/user", user)는 "/api/v2/user"로 시작하는 경로에 대해 user 라우터로 요청을 전달하는 역할을 한다.
```

이미지 미표시 문제 해결: 백엔드에서 정적 파일 서빙 설정

기존에 올바른 URL을 사용했음에도 불구하고 이미지가 표시되지 않는 문제 발생

서버 사이드에서 정적 파일 서빙이 필요한 상황

**정적 파일 서빙을 위한 express.static 미들웨어 추가**

const fs = require('fs');
const path = require('path');

app.use('/uploads/images', express.static(path.join('uploads','images')));

백엔드 코드에 express.static 미들웨어를 추가하여 정적 파일 서빙 설정

/uploads/images로 시작하는 URL에 대한 요청을 해당 폴더의 파일로 서빙하도록 설정

path 모듈을 사용하여 폴더 경로를 생성하여 express.static에 전달

path.join() 은 자동으로 / 를 붙여서 생성 uploads/images

    * express.static 미들웨어의 역할:

    express.static은 Express에서 정적 파일을 제공하기 위한 빌트인 미들웨어이다.

    클라이언트에게 서버의 특정 디렉토리 안에 있는 파일을 직접 제공할 때 사용된다.

    파일 서빙을 위해 사용자의 브라우저가 서버에 파일을 직접 요청할 수 있도록 허용한다.

    * path 모듈을 사용한 폴더 경로 생성:

    path 모듈은 파일 및 디렉토리 경로를 조작하기 위한 유틸리티를 제공한다.

    path.join() 메서드를 사용하여 현재 디렉토리(__dirname)에 uploads/images를 합쳐서 절대 경로를 생성한다.

    ( 다른 파일들은 모두 잠겨 있지만 이 폴더에 있는 파일들은 요청과 함께 반환 )

    ( app.use('/uploads/images', express.static(path.join('uploads','images'))); )

**서버 사이드 동작 원리 이해**

Node/Express에서 파일은 미들웨어를 통해 제어됨

서버 외부에서 직접 파일 액세스 불가능

미들웨어를 통해 처리된 요청만이 서버에서 처리됨

    * 파일은 미들웨어를 통해 제어:

    클라이언트가 서버에 파일을 요청할 때, 미들웨어를 통해 해당 파일에 대한 처리를 수행할 수 있다.

    서버에 저장된 파일을 직접 노출하지 않고, 미들웨어를 사용하여 파일을 읽거나 변형하여 클라이언트에게 전달할 수 있다.

    이는 보안 및 접근 제어를 강화하고, 파일에 대한 직접적인 액세스를 방지하는데 도움이 된다. ( 주소를 입력해서 파일에 접근하는걸 방지 )


    * 서버 외부에서 직접 파일 액세스 불가능:

    서버에서 파일에 대한 처리는 미들웨어를 통해서만 이루어진다.

    서버의 파일 시스템에 직접적인 액세스를 할 수 없도록 보안을 강화한다.

    미들웨어를 통해 요청된 파일에 대한 적절한 권한 및 검증 절차를 수행할 수 있다.


    * 미들웨어를 통해 처리된 요청만이 서버에서 처리됨:

    클라이언트가 보낸 모든 요청은 Express 애플리케이션 내의 미들웨어를 통과한다.

    특정 미들웨어에서 요청에 대한 처리가 이루어지면, 그 이후의 미들웨어나 라우팅 핸들러로 전달된다.

    따라서 미들웨어를 통과하지 않은 요청은 서버에서 처리되지 않고, 특정 미들웨어에서 처리된 요청만이 서버의 로직에 의해 처리된다.

    ( 현재 파일에 접근 불가능 한것도 uploads/images 이런 라우터가 없다 )

## 회원가입 (프론트)

```jsx
// Signup.jsx

// Signup.jsx

import React, { useState } from 'react'
import { AiOutlineEye, AiOutlineEyeInvisible } from 'react-icons/ai'
import { FiFilePlus } from 'react-icons/fi'
import styles from '../../styles/styles.js'
import { Link } from 'react-router-dom'
import axios from 'axios'

const Signup = () => {
  // 상태 변수들을 정의합니다.
  const [email, setEmail] = useState('')
  const [name, setName] = useState('')
  const [password, setPassword] = useState('')
  const [visible, setVisible] = useState(false)
  const [avatar, setAvatar] = useState(null)

  // 폼을 제출할 때 실행되는 함수입니다.
  const handleSubmit = async (e) => {
    e.preventDefault()

    // HTTP 요청 헤더 설정
    const config = { headers: { 'Content-Type': 'multipart/form-data' } }

    // FormData 객체 생성
    const newForm = new FormData()
    newForm.append('file', avatar)
    newForm.append('name', name)
    newForm.append('email', email)
    newForm.append('password', password)

    // 사용자 정보를 서버로 전송하는 POST 요청
    axios
      .post('http://localhost:5000/api/v2/user/create-user', newForm, config)
      .then((res) => {
        console.log(res) // 성공 시 응답 로그 출력
      })
      .catch((error) => {
        console.log(error) // 실패 시 에러 로그 출력
      })
  }

  // 파일 입력이 변경될 때 실행되는 함수
  const handlerFileInputChange = (e) => {
    const file = e.target.files[0]
    setAvatar(file)
  }

  // JSX를 반환하여 화면을 구성합니다.
  return (
    <div className="flex min-h-screen flex-col justify-center bg-gray-50 py-12 sm:px-6 lg:px-8">
      <div className="sm:mx-auto sm:w-full sm:max-w-md">
        <h2 className="mt-6 text-center text-3xl font-extrabold text-gray-900">회원가입</h2>
        <div className="mt-8 sm:mx-auto sm:w-full sm:max-w-md">
          <div className="bg-white px-4 py-8 shadow sm:rounded-lg sm:px-10">
            {/* 폼 요소 시작 */}
            <form className="space-y-6" onSubmit={handleSubmit}>
              {/* 이름 입력란 */}
              <div>
                <label htmlFor="email" className="block text-sm font-medium text-gray-700">
                  이름
                </label>
                <div className="mt-1">
                  <input
                    type="text"
                    name="name"
                    required
                    value={name}
                    onChange={(e) => setName(e.target.value)}
                    className="block w-full appearance-none rounded-md border border-gray-300 px-3 py-2 placeholder-gray-400 shadow-sm focus:border-blue-500 focus:ring-blue-500 focus:outline-none sm:text-sm"
                  />
                </div>
              </div>
              {/* 아이디(이메일) 입력란 */}
              <div>
                <label htmlFor="email" className="block text-sm font-medium text-gray-700">
                  아이디
                </label>
                <div className="mt-1">
                  <input
                    type="email"
                    name="email"
                    required
                    value={email}
                    onChange={(e) => setEmail(e.target.value)}
                    className="block w-full appearance-none rounded-md border border-gray-300 px-3 py-2 placeholder-gray-400 shadow-sm focus:border-blue-500 focus:ring-blue-500 focus:outline-none sm:text-sm"
                  />
                </div>
              </div>
              {/* 비밀번호 입력란 */}
              <div>
                <label htmlFor="password" className="block text-sm font-medium text-gray-700">
                  비밀번호
                </label>
                <div className="relative mt-1">
                  <input
                    type={visible ? 'text' : 'password'}
                    name="password"
                    required
                    value={password}
                    onChange={(e) => setPassword(e.target.value)}
                    className="block w-full appearance-none rounded-md border border-gray-300 px-3 py-2 placeholder-gray-400 shadow-sm focus:border-blue-500 focus:ring-blue-500 focus:outline-none sm:text-sm"
                  />
                  {/* 비밀번호 가리기/보이기 아이콘 */}
                  {visible ? (
                    <AiOutlineEye
                      className="absolute top-2 right-2 cursor-pointer"
                      size={25}
                      onClick={() => setVisible(false)}
                    />
                  ) : (
                    <AiOutlineEyeInvisible
                      className="absolute top-2 right-2 cursor-pointer"
                      size={25}
                      onClick={() => setVisible(true)}
                    />
                  )}
                </div>
              </div>
              {/* 파일 업로드 입력란 */}
              <div>
                <label htmlFor="avatar" className="block text-sm font-medium text-gray-700"></label>
                <div className="mt-2 flex items-center">
                  {/* 이미지 미리보기 */}
                  <span className="inline-block h-8 w-8 overflow-hidden rounded-none">
                    {avatar ? (
                      <img
                        src={URL.createObjectURL(avatar)}
                        alt="avatar"
                        className="h-full w-full rounded-full object-cover"
                      />
                    ) : (
                      <FiFilePlus className="h-8 w-8" />
                    )}
                  </span>
                  {/* 파일 업로드 버튼 */}
                  <label
                    htmlFor="file-input"
                    className="ml-5 flex items-center justify-center rounded-md border border-gray-300 bg-white px-4 py-2 text-sm font-medium text-gray-700 shadow-sm hover:bg-gray-50"
                  >
                    <span>Upload a file</span>
                    <input
                      type="file"
                      name="avatar"
                      id="file-input"
                      accept=".jpg,.jpeg,.png"
                      onChange={handlerFileInputChange}
                      className="sr-only"
                    />
                  </label>
                </div>
              </div>
              {/* 제출 버튼 */}
              <div>
                <button
                  type="submit"
                  className="group relative flex h-[40px] w-full justify-center rounded-md border border-transparent bg-blue-600 px-4 py-2 text-sm font-medium text-white hover:bg-blue-700"
                >
                  Submit
                </button>
              </div>
              {/* 로그인 링크 */}
              <div className={`${styles.noramlFlex} w-full`}>
                <h4>이미 회원이십니까?</h4>
                <Link to="/login" className="pl-2 text-blue-600">
                  로그인
                </Link>
              </div>
            </form>
            {/* 폼 요소 종료 */}
          </div>
        </div>
      </div>
    </div>
  )
}

export default Signup
```

```jsx
axios.post('http://localhost:5000/api/v2/user/create-user', newForm, config):

Axios를 사용하여 POST 요청을 보낸다.

첫 번째 인자로는 요청을 보낼 URL을 지정한다. 여기서는 http://localhost:5000/api/v2/user/create-user로 설정되어 있다.

두 번째 인자로는 서버로 보낼 데이터를 담은 newForm을 전달한다.

세 번째 인자로는 요청 헤더를 설정하는데, config 객체를 사용한다.

이 객체에는 "Content-Type": "multipart/form-data"로 설정된 헤더가 포함되어 있다.

----------------------------------------------------------------------------------------------

const handlerFileInputChange = (e) => {:

handlerFileInputChange라는 함수를 정의합니다. 이 함수는 파일 입력이 변경되었을 때 호출된다.
```

```jsx
const sendMail = async (options) => {
  // nodemailer를 사용하여 전송 객체 생성
  const transporter = nodemailer.createTransport({
    host: process.env.SMPT_HOST, // SMTP 호스트 주소
    port: process.env.SMPT_PORT, // SMTP 포트 번호
    service: process.env.SMPT_SERVICE, // 사용할 서비스 (선택적)
    auth: {
      user: process.env.SMPT_MAIL, // 발신자 이메일 주소
      pass: process.env.SMPT_PASSWORD, // 발신자 이메일 비밀번호
    },
  })

  // 이메일 전송에 사용될 옵션 설정
  const mailOptions = {
    from: process.env.SMPT_MAIL, // 발신자 이메일 주소
    to: options.email, // 수신자 이메일 주소
    subject: options.subject, // 이메일 제목
    text: options.message, // 이메일 본문
  }

  // transporter 객체를 사용하여 이메일 전송
  await transporter.sendMail(mailOptions)
}
```

```jsx
const sendToken = (user, statusCode, res) => {
  // 사용자 객체로부터 JWT 토큰 생성
  const token = user.getJwtToken()

  // 쿠키 설정을 위한 옵션
  const options = {
    expires: new Date(Date.now() + 90 * 24 * 60 * 60 * 1000), // 쿠키 만료 날짜 설정 (현재로부터 90일)
    httpOnly: true, // 클라이언트 측에서 쿠키를 읽을 수 없도록 설정

  }

  // 응답 객체에 상태 코드와 함께 토큰을 쿠키로 전송
  res.status(statusCode).cookie('token', token, options).json({
    success: true,
    user,
    token,
  })
}
```

## auth.js

```jsx
const ErrorHandler = require('../util/ErrorHandler')
const catchAsyncErrors = require('./catchAsyncErrors')
const jwt = require('jsonwebtoken')
const User = require('../model/user')

exports.isAuthenticated = catchAsyncErrors(async (req, res, next) => {
  const { token } = req.cookies

  if (!token) {
    return next(new ErrorHandler('로그인 후 진행해 주세요', 401))
  }

  const decoded = jwt.verify(token, process.env.JWT_SECRET_KEY)

  req.user = await User.findById(decoded.id)

  next()
})
```

### userReducer.js 작성

```jsx
// createSlice는 Redux 슬라이스를 생성하는 함수로, 초기 상태와 각 액션에 대한 리듀서를 자동으로 생성합니다.
// userSlice는 'user'라는 이름의 Redux 슬라이스를 생성합니다.

// loadUser와 clearErrors 액션 생성자 함수를 임포트합니다. 이들은 userAction 파일에서 정의된 것이어야 합니다.
import { createSlice } from '@reduxjs/toolkit'
import { loadUser, clearErrors } from './userAction'

// userSlice를 생성합니다.
const userSlice = createSlice({
  // 슬라이스의 이름을 정의합니다.
  name: 'user',
  // 초기 상태를 정의합니다.
  initialState: {
    isAuthenticated: false,
    loading: false,
    user: null,
    error: null,
  },
  // extraReducers를 사용하여 비동기 액션에 대한 추가적인 리듀서를 정의합니다.
  extraReducers: (builder) => {
    builder
      // loadUser 액션이 pending 상태일 때의 리듀서를 정의합니다.
      .addCase(loadUser.pending, (state) => {
        state.loading = true // 로딩 상태를 true로 설정하여 로딩 중임을 나타냅니다.
      })
      // loadUser 액션이 fulfilled 상태일 때의 리듀서를 정의합니다.
      .addCase(loadUser.fulfilled, (state, action) => {
        state.isAuthenticated = true // 인증 상태를 true로 설정합니다.
        state.loading = false // 로딩 상태를 false로 설정하여 로딩이 완료되었음을 나타냅니다.
        state.user = action.payload // API에서 받아온 사용자 정보를 저장합니다.
      })
      // loadUser 액션이 rejected 상태일 때의 리듀서를 정의합니다.
      .addCase(loadUser.rejected, (state, action) => {
        state.loading = false // 로딩 상태를 false로 설정하여 로딩이 완료되었음을 나타냅니다.
        state.error = action.error.message // 오류 메시지를 저장합니다.
        state.isAuthenticated = false // 인증 상태를 false로 설정합니다.
      })
      // clearErrors 액션이 fulfilled 상태일 때의 리듀서를 정의합니다.
      .addCase(clearErrors.fulfilled, (state) => {
        state.error = null // 오류 상태를 초기화하여 오류가 없음을 나타냅니다.
      })
  },
})

// 생성된 userSlice의 리듀서를 내보냅니다.
export default userSlice.reducer
```

```jsx
비동기로 loadUser을 호출해서 3단계 pending, fulfilled, rejected 마다 action 을 설정해준다

성공하면 인증 상태를 ture 로

받아온 user 값을 상태 user 에 저장한다
```
