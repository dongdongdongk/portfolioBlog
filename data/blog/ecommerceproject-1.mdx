```jsx
Tailwind CSS의 구성 파일(tailwind.config.js)로, Tailwind CSS를 프로젝트에 통합하고 사용자 정의 설정을 지정하는 역할

content 속성:

content: ["./src/**/*.{html,js,jsx}"],

이 속성은 Tailwind가 클래스를 추출하고 처리할 파일을 지정한다.

현재 프로젝트에서는 ./src 디렉토리 안에 있는 HTML, JS, JSX 확장자를 가진 모든 파일을 대상으로 설정되어 있다.

mode 속성:

mode: "jit",

JIT(J ust-In-Time) 모드는 Tailwind의 최신 버전에서 도입된 모드로,

필요한 클래스만 동적으로 생성하여 성능을 향상시킨다.

이 모드를 사용하면 컴파일 시간이 줄어들고, 개발 환경에서의 즉각적인 반영이 가능하다.

theme 속성:

theme: {
  fontFamily: {
    Roboto: ["Roboto", "sans-serif"],
    Poppins: ['Poppins', "sans-serif"],
  },
  extend: {
    screens: {
      "1000px": "1050px",
      "1100px": "1110px",
      "800px": "800px",
      "1300px": "1300px",
      "400px":"400px"
    },
  },
},
theme 속성은 프로젝트의 디자인과 레이아웃을 조절하는 데 사용된다.

fontFamily는 사용자 지정 폰트를 정의하는 부분으로, Roboto와 Poppins 폰트를 사용하도록 지정되어 있다.

extend는 기본 Tailwind 클래스를 확장하고 새로운 클래스를 추가하는 데 사용된다.

여기에서는 사용자 지정 스크린 사이즈를 추가로 정의하고 있다.

plugins 속성:

plugins: [],

plugins 속성은 Tailwind에 추가적인 플러그인을 사용하거나 설정하는 데 사용된다.

현재는 비어 있어서 특별한 플러그인을 사용하지 않고 있다.

이 구성 파일은 Tailwind CSS를 프로젝트에 통합하고,

사용자 지정 클래스 및 확장된 설정을 적용하기 위한 것이다.

프로젝트의 디자인 및 레이아웃을 효과적으로 관리하고 개발 시간을 단축하기 위해 사용된다.
```

```jsx
가령, 사용자가 로그인 페이지로 이동하려면, Routers.js 파일에서 Login 컴포넌트를 가져와서 해당 페이지를 라우터에 등록할 것이다.

예를 들면, 다음과 같이 라우터를 설정할 수 있다:
```

```jsx
// Routers.js 파일

import React from 'react'
import { BrowserRouter as Router, Route, Switch } from 'react-router-dom'
import { Login } from './path-to-your-components' // 실제 경로에 따라 수정

const Routers = () => {
  return (
    <Router>
      <Switch>
        <Route path="/login" component={Login} />
        {/* 다른 페이지에 대한 라우팅 정보 추가 */}
      </Switch>
    </Router>
  )
}

export default Routers
```

```jsx
위 예제에서 /login 경로로 이동하면 Login 컴포넌트가 렌더링된다.

이것은 사용자가 애플리케이션 내에서 다른 페이지로 이동할 때 해당 페이지의 컴포넌트를 로드하도록 도와주는 일반적인 라우팅 구성이다.
```

```jsx
import React, { useState } from 'react'
import { AiOutlineEye, AiOutlineEyeInvisible } from 'react-icons/ai'
import styles from '../styles/styles.js' // 스타일 모듈을 불러옵니다.
import { Link } from 'react-router-dom'

const Login = () => {
  const [email, setEmail] = useState('') // 이메일을 위한 상태 변수
  const [password, setPassword] = useState('') // 비밀번호를 위한 상태 변수
  const [visible, setVisible] = useState(false) // 비밀번호 보이기/가리기를 관리하는 상태 변수

  return (
    <div className="flex min-h-screen flex-col justify-center bg-gray-50 py-12 sm:px-6 lg:px-8">
      <div className="sm:mx-auto sm:w-full sm:max-w-md">
        <h2 className="mt-6 text-center text-3xl font-extrabold text-gray-900">
          Login to your account
        </h2>
        <div className="mt-8 sm:mx-auto sm:w-full sm:max-w-md">
          <div className="bg-white px-4 py-8 shadow sm:rounded-lg sm:px-10">
            <form className="space-y-6">
              {/* 이메일 입력란 */}
              <div>
                <label htmlFor="email" className="block text-sm font-medium text-gray-700">
                  아이디
                </label>
                <div className="mt-1">
                  <input
                    type="email"
                    name="email"
                    required
                    value={email}
                    onChange={(e) => setEmail(e.target.value)}
                    className="block w-full appearance-none rounded-md border border-gray-300 px-3 py-2 placeholder-gray-400 shadow-sm focus:border-blue-500 focus:ring-blue-500 focus:outline-none sm:text-sm"
                  />
                </div>
              </div>
              {/* 비밀번호 입력란 */}
              <div>
                <label htmlFor="password" className="block text-sm font-medium text-gray-700">
                  비밀번호
                </label>
                <div className="relative mt-1">
                  <input
                    type={visible ? 'text' : 'password'}
                    name="password"
                    required
                    value={password}
                    onChange={(e) => setPassword(e.target.value)}
                    className="block w-full appearance-none rounded-md border border-gray-300 px-3 py-2 placeholder-gray-400 shadow-sm focus:border-blue-500 focus:ring-blue-500 focus:outline-none sm:text-sm"
                  />
                  {/* 비밀번호 보이기/가리기 아이콘 */}
                  {visible ? (
                    <AiOutlineEye
                      className="absolute top-2 right-2 cursor-pointer"
                      size={25}
                      onClick={() => setVisible(false)}
                    />
                  ) : (
                    <AiOutlineEyeInvisible
                      className="absolute top-2 right-2 cursor-pointer"
                      size={25}
                      onClick={() => setVisible(true)}
                    />
                  )}
                </div>
              </div>
              {/* 기억하기 체크박스와 비밀번호 찾기 링크 */}
              <div className={`${styles.noramlFlex} justify-between`}>
                <div className={`${styles.noramlFlex}`}>
                  <input
                    type="checkbox"
                    name="remember-me"
                    id="remember-me"
                    className="h-4 w-4 rounded border-gray-300 text-blue-600 focus:ring-blue-50"
                  />
                  <label htmlFor="remember" className="ml-2 block text-sm text-gray-900">
                    Remember me
                  </label>
                </div>
                <div className="text-sm">
                  <a
                    href=".forgot-password"
                    className="font-medium text-blue-600 hover:text-blue-500"
                  >
                    Forgot your password?
                  </a>
                </div>
              </div>
              {/* 제출 버튼 */}
              <div>
                <button
                  type="submit"
                  className="group relative flex h-[40px] w-full justify-center rounded-md border border-transparent bg-blue-600 px-4 py-2 text-sm font-medium text-white hover:bg-blue-700"
                >
                  Submit
                </button>
              </div>
              {/* 회원가입 링크 */}
              <div className={`${styles.noramlFlex} w-full`}>
                <h4>회원이 아니십니까?</h4>
                <Link to="/sign-up" className="pl-2 text-blue-600">
                  회원가입
                </Link>
              </div>
            </form>
          </div>
        </div>
      </div>
    </div>
  )
}

export default Login
```

```jsx
상태 변수 설정:

useState 훅을 사용하여 이메일, 비밀번호 및 비밀번호 가시성을 관리하는 상태 변수들을 초기화한다.

UI 구성:

Flex 및 Grid를 사용하여 화면을 세로 중앙 정렬하고, 폭을 조절한다.

그리고 각 요소들에 대한 스타일을 지정하는데 Tailwind CSS 클래스들을 사용한다.

이메일 및 비밀번호 입력란:

이메일과 비밀번호를 입력받는 두 개의 입력란을 구성하고, 입력값을 상태 변수에 업데이트하는 onChange 이벤트를 처리한다.

기억하기 체크박스와 비밀번호 찾기 링크:

코드는 주로 Tailwind CSS를 이용하여 스타일이 적용되어 있으며,

비밀번호 가리기/보이기 기능은 React Icons의 AiOutlineEye와 AiOutlineEyeInvisible를 활용하고 있다.

또한, React Router의 Link 컴포넌트를 사용하여 회원가입 페이지로 이동할 수 있는 링크를 구현하였다.
```

## Tailwind CSS 클래스들에 대한 설명

```jsx
min-h-screen:

최소 높이를 화면의 높이로 설정하여 전체 화면을 차지합니다.

bg-gray-50:

배경색을 밝은 회색으로 설정합니다.

flex flex-col justify-center:

수직 방향으로 아이템을 정렬하고, 아이템을 수직 중앙으로 정렬합니다.

py-12 sm:px-6 lg:px-8:

위아래로 여백을 주고, 화면의 너비에 따라 좌우 여백을 조정합니다.

sm:mx-auto sm:w-full sm:max-w-md:

작은 화면에서 가운데 정렬하고, 너비를 전체 화면으로 설정하며, 최대 너비를 지정합니다.

mt-6 text-center text-3xl font-extrabold text-gray-900: 위쪽 여백을 주고, 텍스트를 중앙 정렬하며, 글꼴 크기를 크게,

글자 두껍게, 색상을 짙은 검정으로 설정합니다.

bg-white py-8 px-4 shadow sm:rounded-lg sm:px-10: 배경을 흰색으로 설정하고,

위아래 여백을 주며, 그림자를 추가하고, 작은 화면에서 둥근 모서리를 적용합니다.

block text-sm font-medium text-gray-700: 블록 레벨 요소로 설정하고, 글자 크기를 작게, 글꼴을 중간 두껍게, 색상을 회색으로 설정합니다.

appearance-none block w-full px-3 py-2 border border-gray-300 rounded-md shadow-sm placeholder-gray-400 focus:outline-none focus:ring-blue-500 focus:border-blue-500 sm:text-sm:

외관을 무시하고, 블록 레벨 요소로 설정하고, 전체 너비를 차지하며, 여백 및 테두리를 설정하며, 그림자와 플레이스홀더 스타일, 포커스 시 스타일을 추가합니다.

h-4 w-4 text-blue-600 focus:ring-blue-50 border-gray-300 rounded:

높이와 너비를 설정하고, 글자 색상을 파란색으로, 포커스 시 스타일을 추가합니다.

cursor-pointer:

포인터 커서를 사용하여 마우스 오버 시 상호 작용이 가능하도록 합니다.

group relative w-full h-[40px] flex justify-center py-2 px-4 border border-transparent text-sm font-medium rounded-md text-white bg-blue-600 hover:bg-blue-700:

그룹을 형성하고, 전체 너비를 차지하며, 높이와 여백을 설정하며, 텍스트 스타일과 배경색 및 호버 시 스타일을 지정합니다.

text-blue-600 hover:text-blue-500:

텍스트 색상을 파란색으로 설정하고, 호버 시 텍스트 색상을 진한 파란색으로 변경합니다.

pl-2:
```

### ErrorHandler 클래스를 정의

```jsx
class ErrorHandler extends Error {
  constructor(message, statusCode) {
    super(message)
    this.statusCode = statusCode

    Error.captureStackTrace(this, this.constructor)
  }
}

module.exports = ErrorHandler
```

```jsx
ErrorHandler 클래스를 정의하고 있다. 주로 Express 애플리케이션에서 에러 핸들링을 통합하는 데 사용된다.

class ErrorHandler extends Error {:

ErrorHandler 클래스를 정의하며,

기본적으로 JavaScript의 내장 Error 클래스를 확장한다. 이를 통해 ErrorHandler 클래스는 에러 객체로 사용될 수 있게 된다.

constructor(message, statusCode) {:

클래스의 생성자 메서드를 정의한다. 이 메서드는 message와 statusCode라는 두 개의 매개변수를 받는다.

super(message);:

부모 클래스인 Error 클래스의 생성자를 호출하며, 에러 객체의 메시지를 설정한다.

this.statusCode = statusCode:

클래스의 인스턴스 속성으로 statusCode를 설정한다. 이 속성은 해당 에러의 HTTP 상태 코드를 나타낸다.

Error.captureStackTrace(this, this.constructor):

스택 트레이스를 캡처한다.

이를 통해 에러 객체가 생성된 위치를 추적할 수 있게 된다.

두 번째 인자로 this.constructor를 전달하여 현재 클래스의 생성자 함수를 사용하도록 한다.

module.exports = ErrorHandler;:

ErrorHandler 클래스를 모듈로 내보낸다. 이렇게 정의된 클래스는 다른 파일에서 require하여 사용할 수 있다.

이 ErrorHandler 클래스를 사용하면 애플리케이션에서 발생하는 다양한 에러에 대한 통일된 형태의 에러 객체를 생성할 수 있다.

이러한 통일된 형태의 에러 객체를 사용하면 미들웨어에서 효과적으로 에러를 처리하고 클라이언트에게 적절한 응답을 전달할 수 있다.
```

### 전역 에러 처리

```jsx
const ErrorHandler = require('../util/ErrorHandler')

// 에러 핸들러 미들웨어
module.exports = (err, req, res, next) => {
  // 기본적으로 서버 오류로 설정
  err.statusCode = err.statusCode || 500
  err.message = err.message || '서버 오류'

  // CastError: 잘못된 자료형으로 인한 오류 처리
  if (err.name === 'CastError') {
    const message = `해당 ID의 리소스를 찾을 수 없습니다. 잘못된 ${err.path}`
    err = new ErrorHandler(message, 400)
  }

  // Duplicate key error (MongoDB에서 고유 인덱스 위반)
  if (err.code === 11000) {
    const message = `${Object.keys(err.keyValue)} 중복된 값이 이미 존재합니다.`
    err = new ErrorHandler(message, 400)
  }

  // JsonWebTokenError: 유효하지 않은 토큰 오류 처리
  if (err.name === 'JsonWebTokenError') {
    const message = '유효하지 않은 토큰입니다.'
    err = new ErrorHandler(message, 400)
  }

  // TokenExpiredError: 토큰 만료 오류 처리
  if (err.name === 'TokenExpiredError') {
    const message = '토큰이 만료되었습니다.'
    err = new ErrorHandler(message, 400)
  }

  // 클라이언트에게 오류 응답 전송
  res.status(err.statusCode).json({
    success: false,
    message: err.message,
  })
}
```

## **catchAsyncErrors 작성 ( 비동기 함수 에러 처리 )**

```jsx
module.exports = (theFunc) => (req, res, next) => {
  Promise.resolve(theFunc(req, res, next)).catch(next)
}
```

```jsx
이 코드는 Express 애플리케이션에서 비동기 함수의 에러 처리를 간편하게 처리하기 위한 미들웨어 함수를 정의하고 있다.

주로 비동기 함수에서 발생하는 에러를 효과적으로 처리하고 에러를 다음 미들웨어로 전달하기 위해 사용된다.

module.exports = (theFunc) => (req, res, next) => {:

이 모듈은 함수를 익명으로 내보낸다. 이 함수는 미들웨어를 반환하는 함수이다. 외부 함수에서는 실행될 비동기 함수(theFunc)를 전달는다.

Promise.resolve(theFunc(req, res, next)).catch(next);:

Promise.resolve:

주어진 값을 Promise로 래핑합니다. 이 부분에서는 theFunc(req, res, next)를 실행한 결과를 Promise로 감싸서 반환한다.

* Promise.resolve(value)에서 resolve는 Promise를 성공적으로 이행시키는 역할을 합니다. 주어진 value를 갖는 Promise를 반환

.catch(next):

앞서 반환된 Promise가 reject(에러가 발생)되면, next 함수를 호출하여 Express의 에러 핸들러로 에러를 전달한다.

이를 통해 다음에 등록된 에러 핸들러가 실행되도록 한다.

동작 설명:

외부 함수에 전달된 theFunc은 비동기 함수로 가정되며, 이 함수는 Express의 미들웨어 함수처럼 req, res, next 매개변수를 받는다.

해당 함수를 실행하고 반환된 결과를 Promise로 감싸서 .catch(next)를 통해 에러 처리한다.

만약 theFunc 함수에서 에러가 발생하면 해당 에러는 catch 블록으로 전달되고, 이후에 등록된 Express의 에러 핸들러로 전달된다.

이렇게 구현된 미들웨어를 사용하면 비동기 함수에서 발생하는 에러를 효과적으로 처리할 수 있다.

또한, 이를 통해 에러 처리 코드를 중복해서 작성하지 않고 간결하게 유지할 수 있다.
```

```jsx
// multer 모듈을 가져옵니다.
const multer = require('multer')

// multer.diskStorage를 사용하여 디스크 스토리지 엔진을 설정합니다.
const storage = multer.diskStorage({
  // 파일이 저장될 목적지를 설정합니다.
  destination: function (req, file, cb) {
    // cb는 콜백 함수로, 첫 번째 인자는 에러를 나타냅니다 (에러가 없다면 null),
    // 두 번째 인자는 실제 저장 경로입니다.
    cb(null, 'uploads/') // "uploads/" 폴더에 파일을 저장합니다.
  },
  // 파일의 이름을 설정합니다.
  filename: function (req, file, cb) {
    // 파일 이름에 유니크한 접미사를 추가하여 중복을 방지합니다.
    const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1e9)

    // 파일의 확장자를 추출합니다.
    const filename = file.originalname.split('.')[0]

    // 콜백 함수에는 에러 (에러가 없다면 null)와 최종적으로 설정된 파일 이름을 전달합니다.
    cb(null, filename + '-' + uniqueSuffix + '.png')
  },
})

// multer 모듈을 사용하여 업로드 미들웨어를 생성합니다.
exports.upload = multer({ storage: storage })
```

```jsx
multer 모듈을 가져온다. 이 모듈은 Express 애플리케이션에서 파일 업로드를 쉽게 처리할 수 있도록 도와주는 미들웨어이다.

multer.diskStorage를 사용하여 파일의 저장 경로(destination)와 파일의 이름(filename)을 설정한다.

destination: 업로드된 파일이 저장될 폴더를 설정한다. 여기서는 "uploads/" 폴더를 사용한다

filename: 업로드된 파일의 이름을 설정한다. 고유한 접미사를 생성하고, 파일의 원래 이름과 조합하여 최종 파일 이름을 설정한다.

exports.upload를 통해 multer를 이용한 파일 업로드를 처리하는 미들웨어를 생성한다.

storage에는 위에서 설정한 diskStorage를 사용한다. 파일 업로드를 위한 설정이 담긴 객체이다.

* diskStorage는 Multer에서 제공하는 파일 저장 방식 중 하나로, 업로드된 파일을 디스크에 저장하는 방식을 말한다.

즉, destination과 filename을 설정하여 파일이 저장될 경로와 파일의 이름을 지정하는 역할
```
