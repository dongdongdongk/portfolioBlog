```java
// 메소드 오버라이딩 이란 자식 클래스에서 부모에게 상속 받은 메소드를 덮어쓰는것(재정의)

class Parent {
	void method1() { 실행코드 }
	void method2() { 실행코드 }
}

class child extends Parent {
	void method2() { 실행코드 }  // 자식 클래스에서 부모 method2 를 다시 재정의 했다.
	void method3() { 실행코드 }
}

//결과적으로 실행클래스 에서 호출하면

class ChildExample {
	pubclic static void main(String[] args) {

		Child child = new Child();

		child.method1();

		child.method2();         // 재정의된 메소드 호출

    child.method3();
	}
}
```

메소드 재정의 방법

- 부모 메소드와 동일한 이름 &타입을 가져야 함
- 접근 제한을 더 강하게 재정의 할 수 없음 (ex) public 에서 private )(더 약하게는 가능
- 새로운 예외 throws 할 수 없음 ( 뒤에 가서 설명)

```java
	class Parent {
		void method1() { 실행내용 }
		void method2() { 실행내용 }
	}


	// 자식 class에서 부모 메소드 호출

	class Child extends parent {
		void method2() { 실행내용 } // 재정의
		void method3() {
			method2(); //재정의 한걸 호출
			super.method2(); //부모 메소드(원본 메소드) 를 호출
	}
}
```

```java
문법 : public final class 클래스 { 실행내용 }

			 public final 리턴타입 메소드(매개변수, ..) { 실행내용 }
```

fianl 키워드를 사용하면 최종 상태로 수정될 수 없음을 의미한다.

final 클래스는 부모 클래스가 될 수 없어 자식 클래스를 만들수 없다.

부모 클래스에 선언된 final 메소드는 자식 클래스 에서 재정의 할 수 없다.

```java
상속 : 	public class B extends A { 실행내용 }  // 자식 클래스가 부모 클래스의 필드와 메서드를
                                              // 사용할 수 있게 해준다.
```

```java
메소드 재정의 : 부모 클래스의 메소드를 자식 클래스에서 다시 정의 하는것 (복붙 실행내용or 값 수정)
               (부모 메소드와 동일한 이름 &타입을 가져야 함)
```

```java
final 클래스 : final 클래스는 부모 클래스로 사용할수 없다. (상속 불가)
```

```java
final 메소드 : 자식 클래스에서 재정의 할 수 없는 메소드이다 .
```
