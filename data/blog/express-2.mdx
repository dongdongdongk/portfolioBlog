# Express 개요

```jsx
Express는 Node 패키지와 비슷하지만 더 많은 기능을 제공하는 웹 애플리케이션 개발을 위한 프레임워크이다.( Node.js를 위한 간결한 프레임워크 )

이 프레임워크는 웹 애플리케이션 서버를 만들고 실행하는 데 도움이 되며 API 생성과 같은 다양한 작업에도 활용된다.
```

## Express의 주요 기능

```jsx
* 서버에서 들어오는 요청 수락 및 처리

* HTTP 요청의 텍스트 정보를 해석하여 객체로 변환

* 요청에 따라 코드를 실행하도록 설정

* 응답 형식 및 상태 코드 설정

* 클라이언트에 응답 반환
```

## 프레임워크와 라이브러리

```jsx
프레임워크는 라이브러리와 목적 및 제어 방식에서 차이가 있다.

**라이브러리**는 필요할 때 수동으로 호출하여 사용할 수 있는 독립적인 코드 모음이다.

예를 들어, 특정 기능을 제공하는 라이브러리를 사용하려면 해당 라이브러리를 코드에 추가하고 필요한 시점에 호출하면 된다.

개발자는 라이브러리의 일부를 선택적으로 사용하거나 전혀 사용하지 않을 수 있다.

**프레임워크**는 애플리케이션의 구조와 동작 방식을 정의한다.

프레임워크는 개발자에게 제어의 역전(IOC)을 제공하며, 개발자는 프레임워크가 제공하는 규칙과 패턴에 따라 코드를 작성해야 한다.

프레임워크는 일반적으로 특정한 목적을 갖고 있으며, 개발자는 그 목적을 달성하기 위해 프레임워크가 제시하는 방법에 따라 코드를 작성한다.

프레임워크의 목적은 개발자가 일정한 구조 안에서 작업하고,

프레임워크가 제어하는 방식에 따라 개발자의 코드를 통합하는 것이다.

이는 개발자에게 일종의 가이드라인을 제공하며, 애플리케이션의 특정 부분에 대한 제어를 프레임워크에게 넘기게 된다. ( 제어의 역전 )

이러한 특성으로 인해 프레임워크는 높은 수준의 추상화를 제공하면서도 개발자에게 작업의 일부를 위임한다.
```

# 요청 및 응답 객체

## **서버 실행 및 요청 처리**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381374/notion-blog/_/The_Web_Developer_2022/node_js/Express_/Untitled_3.png)

```jsx
서버를 실행하면 요청이 서버에 도착하고 응답할 내용이 없어 브라우저는 계속 무한 로딩 상태에 있다.

Express 애플리케이션은 요청 처리를 위해 두 개의 중요한 객체를 사용한다: req (요청 객체)와 res (응답 객체).
```

## **요청 객체 (`req`) 살펴보기**

```jsx
app.use의 콜백 함수에 전달되는 req 객체는 들어오는 HTTP 요청을 나타낸다.

객체에는 다양한 속성이 있으며, 예를 들어 rawHeaders, headers, method, url 등이 있다.

Express는 HTTP 요청 정보를 자동으로 파싱하여 JavaScript 객체로 만들어 콜백 함수에 전달한다.

( .JSON 으로 JSON 응답을 javaScript 로 만들어 줄 필요없다 )
```

## **응답 객체 (`res`) 및 `res.send` 메서드 활용**

```jsx
res 객체는 응답 생성을 위한 여러 메서드를 제공한다. 여기서는 res.send 메서드를 사용한다.

res.send는 HTTP 응답을 보내며, 자동으로 HTTP 응답 헤더를 설정한다.

다양한 데이터 타입을 응답으로 사용할 수 있으며, 문자열, JavaScript 객체, HTML 등을 응답으로 전송할 수 있다.
```

## **JSON 응답 및 HTML 응답**

```jsx
res.send에 문자열, JavaScript 객체, HTML을 전달하여 각각의 다양한 형식의 응답을 생성한다.

JSON 응답은 객체를 전송하고, HTML 응답은 HTML 문자열을 전송한다.

응답의 콘텐츠 타입은 Express가 자동으로 설정하며, JSON인 경우 application/json으로 설정된다
```

# Express 라우팅 기초

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381374/notion-blog/_/The_Web_Developer_2022/node_js/Express_/Untitled_4.png)

## **라우팅 소개**

```jsx
라우팅은 Express에서 서버에 요청된 경로에 따라 응답을 제공하는 개념
```

## **Express 메서드**

```jsx
Express 앱에서는 app 객체의 여러 메서드를 사용하여 라우트를 정의할 수 있다.

Express에서는 HTTP 동사(get, post, put, delete 등)에 따라 다른 메서드를 사용하여 라우트를 정의한다

app.get(path, callback): Get 요청에 대한 라우트를 정의한다.

app.post(path, callback): Post 요청에 대한 라우트를 정의한다.
```

## **다양한 응답**

```jsx
서로 다른 경로에 대해 다양한 응답을 추가하여 요청에 따라 다르게 응답할 수 있다.

res.send 메서드를 통해 다양한 형태의 응답을 보낼 수 있다 ( html, json, text 등등 )

예를 들어, /cats에 대한 Get 요청에는 "MEOW!!"를 응답하고,

Post 요청에는 "POST REQUEST TO /cats!!!! THIS IS DIFFERENT THAN A GET REQUEST!"를 응답한다.
```

## **에러 핸들링**

```jsx
라우트가 없는 경로에 대한 요청에 대비하여 에러 핸들링을 추가할 수 있다.

* 를 사용하여 모든 경로에 대한 일반적인 응답을 정의하고, 순서에 주의하여 제대로 동작하도록 한다.

( 맨 아래에 넣어줘야 한다 )
```

# Express 경로 매개 변수

```jsx
Express에서 경로 매개변수를 사용하여 동적인 라우팅을 구현하는 방법을 살펴보자

정확하게 매치되는 라우트뿐만 아니라, 패턴을 가진 동적인 라우트를 처리하기 위해 경로 매개 변수를 사용한다
```

## **경로 매개변수의 필요성**

```jsx
Reddit의 서브레딧(Subreddit)이나 게시물의 URL과 같이 정적인 경로뿐만 아니라 동적인 요청에 대응하기 위해 경로 매개변수를 사용한다

ex) https://www.reddit.com/r/Worldbox/

Worldbox 부분이 서브레딧 이름인데 이부분이 경로 매개변수가 필요한 부분
```

## **라우트에 경로 매개변수 추가**

```jsx
app.get('/r/:subreddit', ...)와 같이 :subreddit과 같은 표현을 사용하여 경로 매개변수를 정의했다

**: 단어** 이렇게 사용한다

/r/ 까지는 같고 그 뒤로는 어떤 단어가 와도 매칭된다
```

# 쿼리 문자열 작업하기

```jsx
URL의 일부로Express 앱에서의 쿼리 스트링(Query String)은 클라이언트에서 서버로 전달되는 URL 파라미터로,

키-값 쌍의 형태로 정보를 전달한다. Express에서는 이러한 쿼리 스트링을 쉽게 다룰 수 있는 기능을 제공한다.
```

## **Express에서의 쿼리 스트링 처리**

```jsx
Express 앱에서는 라우트를 정의할 때( 클라이언트가 해당 경로로 요청을 보낼 때 실행될 코드 ) 쿼리 스트링이 추가되는 것이 아니라,

Express가 자동으로 생성한 req 객체 내에 query 속성이 생성된다.

req.query를 통해 클라이언트에서 전달된 쿼리 스트링의 키-값 쌍을 쉽게 추출할 수 있다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381372/notion-blog/_/The_Web_Developer_2022/node_js/Express_/Untitled_11.png)

```jsx
app.get('/search', (req, res) => {
  const { q } = req.query
  if (!q) {
    res.send('쿼리가 없습니다.')
  }
  res.send(`<h1>쿼리 결과는 : ${q} </h1>`)
})
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381373/notion-blog/_/The_Web_Developer_2022/node_js/Express_/Untitled_12.png)

### 여러개의 쿼리 스트링 값 받기

```jsx
동시에 여러개의 값을 받으려면 어떻게 해야하는지 알아본다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381373/notion-blog/_/The_Web_Developer_2022/node_js/Express_/Untitled_13.png)

```jsx
app.get('/search', (req, res) => {
  const { q, color } = req.query
  if (!q) {
    res.send('q 가 없습니다.')

    res.send('color 가 없습니다.')
  }
  res.send(`<h1>쿼리 결과는 : ${q} color 는 : ${color} </h1>`)
})
```
