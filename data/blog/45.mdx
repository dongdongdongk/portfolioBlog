## **추상,실체 클래스**

- 실체 클래스(객체 생성용 클래스) 들이 가지고 있는 공통적 특성(필드, 메소드)을 추출하여 만든 클래스

- 추상 클래스와 실체 클래스는 부모, 자식의 상속 관계를 가진다.

```java
Bird.class   // 실체 클래스
Insect.class
Fish.class
// 이러한 클래스들의 공통 필드와 메소드를 모아 추출하여 새로운 클래스를 만든다.

Animal.class // 추상 클래스
             // 이때 추상 클래스가 부모 클래스 실체 클래스가 자식 클래스


// 다이어 그램이 상속을 하는 상위 클래스 방향으로 화살표 되어있다고 헷갈리지 말자
// 상속 받는쪽이 상속 하는쪽을 가르키는컷
// 부모 Animal 의 공통 메소드와 필드를 자식 클래스들에게 상속 하는것
```

## **추상 클래스**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381027/notion-blog/_/JAVA/_/45_/Untitled_1.png)

- 일반적으론 추상 클래스 먼저 제작한 뒤 실체 클래스를 제작한다. (공통 부분 예측하여 제작)
- 추상 클래스는 객체 생성용이 아니다.
- 이렇게 하면 실체 클래스의 공통된 내용을 물려받고 다른 점만 선언하면 되므로 시간 절약
- 설계 규격 (추상 클래스) 으로 자동차 타이어를 설계하고 실제로 장착 되는건 실체 클래스

## **추상 클래스 선언**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381028/notion-blog/_/JAVA/_/45_/Untitled_2.png)

```java
문법 : public abstract class 클래스 {
				 //필드
	       //생성자
         //메소드
			 }
```

- 이런 종류의 클래스는 상속을 통해서만 사용해야 한다.(직접 객체를 생성x, new 클래스 사용x)
- new 생성자를 사용 못하는데 생성자가 있는 이유는?
- 자식 객체가 만들어질 때 부모 객체도 자동으로 만들어진다(객체로 만들어 지기 위해선 생성자 필요)(super(매개변수) 형태로 추상 클래스의 생성자 호출)

## 추상 메소드

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381029/notion-blog/_/JAVA/_/45_/Untitled_7.png)

```java
문법 : public abstract 리턴타입 메소드이름(매개변수,...);

       public abstract void sound();

       // 특이한 점은 {} 가 없는 메소드 라는 것 이다.
```

- 개와 고양이 공통점으로 소리가 있다. 그러나 어떤 소리가 들어가야 할지 명확하게 알 수 없으므로 메소드 선언만 통일하고 내용은 실체 클래스 마다 다르게 채워준다.

- 하위 클래스는 반드시 재정의 해서 실행 내용을 채워줘야 한다.
