## 1. 트레이 아이콘 준비 및 추가

```jsx
16x16 크기의 tray_icon.png 파일을 프로젝트 내 assets/icons 폴더에 배치

path 모듈을 사용하여 아이콘 경로 설정

new Tray(iconPath)를 사용하여 트레이 아이콘 생성
```

```jsx
const path = require('path')
const { app, BrowserWindow, Tray } = require('electron')

let mainWindow
let tray

function createMainWindow() {
  mainWindow = new BrowserWindow({
    width: 700,
    height: 500,
    icon: path.join(__dirname, 'assets', 'icons', 'icon.png'),
    resizable: false,
    show: false, // 앱 실행 시 창을 숨김 상태로 시작
    opacity: 0.9, // 창을 약간 투명하게 설정
    webPreferences: {
      nodeIntegration: false,
      contextIsolation: true,
    },
  })

  mainWindow.loadFile('./app/index.html')
}

app.on('ready', () => {
  createMainWindow()

  // 트레이 아이콘 추가
  const iconPath = path.join(__dirname, 'assets', 'icons', 'tray_icon.png')
  tray = new Tray(iconPath)

  // 트레이 아이콘 클릭 이벤트
  tray.on('click', () => {
    if (mainWindow.isVisible()) {
      mainWindow.hide()
    } else {
      mainWindow.show()
    }
  })
})
```

```jsx

tray.on('right-click', () => {

    {
```

```jsx
app.isQuitting이 true가 아닐 경우 창을 숨기고 종료를 방지.

* 이 코드에서는 return true;가 사실상 필요하지 않습니다.

	Electron의 close 이벤트 핸들러에서 return 값은 사용되지 않기 때문입니다.
```

```jsx
mainWindow.on('close', (e) => {
  if (!app.isQuitting) {
    e.preventDefault()
    mainWindow.hide()
  }
  return true
})
```

## 1. **메뉴에서 클릭 이벤트가 발생**

```jsx
메인 프로세스에서는 View 메뉴 항목에 Toggle Navigation 항목이 있습니다.

사용자가 이 메뉴 항목을 클릭하면, 아래 코드에 의해 nav:toggle 이벤트가 렌더러 프로세스에 전송됩니다.
```

```jsx
{
  label: 'Toggle Navigation',
  click: () => mainWindow.webContents.send('nav:toggle')  // 클릭하면 이벤트 전송
}
```

```jsx
mainWindow.webContents.send('nav:toggle'): 이 부분이 렌더러 프로세스에 nav:toggle이라는 이벤트를 전송하는 역할을 합니다.

즉, 메뉴에서 "Toggle Navigation"을 클릭하면 nav:toggle 이벤트가 렌더러로 전달됩니다.
```

## 2. 프리로드로 이벤트 전달

```jsx
const { contextBridge, ipcRenderer } = require('electron')

contextBridge.exposeInMainWorld('electron', {
  getComInfo: () => ipcRenderer.invoke('getComInfo'),
  getCpuUsage: () => ipcRenderer.invoke('getCpuUsage'),
  getUptime: () => ipcRenderer.invoke('getUptime'),

  // 이벤트 리스너 추가 (렌더러에서 `on` 메서드 사용 가능)
  on: (channel, callback) => {
    ipcRenderer.on(channel, (event, data) => callback(data))
  },

  send: (channel, data) => {
    ipcRenderer.send(channel, data)
  },
})
```

```jsx
on:

		on 메서드는 메인 프로세스에서 보내는 이벤트를 렌더러 프로세스에서 처리할 수 있게 해줍니다.

		ipcRenderer.on(channel, callback)을 사용하여 메인 프로세스에서 전송한 이벤트를 수신하고,

		callback(data)로 데이터를 렌더러 프로세스로 전달합니다.

send:

		send 메서드는 렌더러 프로세스에서 메인 프로세스로 데이터를 보낼 때 사용됩니다.

		ipcRenderer.send(channel, data)를 호출하여 메인 프로세스로 메시지를 보냅니다.
```

## 2. **렌더러에서 이벤트를 수신**

```jsx
렌더러 프로세스에서는 preload.js 또는 renderer.js에서 nav:toggle 이벤트를 받고 처리합니다.

이때 중요한 부분은 **window.electron.on('nav:toggle', ...)**입니다.

이렇게 하면 메인 프로세스에서 보내는 nav:toggle 이벤트를 렌더러가 수신할 수 있게 됩니다
```

```jsx
window.electron.on('nav:toggle', () => {
  let nav = document.getElementById('nav') // 'nav' 요소 찾기
  if (nav) {
    nav.classList.toggle('hide') // 'hide' 클래스를 토글해서 숨기거나 보이게 하기
  }
})
```

## `AppTray.js` 파일 생성하여 트레이 관련 코드 분리

```jsx
트레이 관련 코드만 따로 관리할 수 있도록 AppTray.js 클래스를 생성
```

```jsx
const { app, Menu, Tray } = require('electron')

class AppTray extends Tray {
  constructor(icon, mainWindow) {
    super(icon)
    this.mainWindow = mainWindow

    this.setToolTip('SysTop')

    // ✅ 화살표 함수 사용 → this 유지됨
    this.on('click', this.onClick)
    this.on('right-click', this.onRightClick)
  }

  onClick = () => {
    if (this.mainWindow.isVisible()) {
      this.mainWindow.hide()
    } else {
      this.mainWindow.show()
    }
  }

  onRightClick = () => {
    const contextMenu = Menu.buildFromTemplate([
      {
        label: 'Quit',
        click: () => {
          app.isQuitting = true
          app.quit()
        },
      },
    ])
    this.popUpContextMenu(contextMenu)
  }
}

module.exports = AppTray
```

```jsx
Tray 클래스를 상속받아 AppTray 클래스를 생성

onClick과 onRightClick을 메서드로 따로 분리

화살표 함수(=>) 사용하여 자동으로 this 유지

setToolTip()을 사용하여 툴팁 설정
```
