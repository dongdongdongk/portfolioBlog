# 스프레드(Spread) 및 레스트(Rest) 연산자

## 레스트 연산자 (Rest)

```java
JavaScript의 Rest 연산자(...)는 함수의 매개변수로 사용되며 가변 인자(variable arguments)(길이가 일정하지 않은 배열)

를 다루는데 도움을 주는 기능이다.

Rest 연산자를 사용하면 함수에 전달된 인자들을 배열로 쉽게 다룰 수 있다.

( 받은 매개변수를 배열로 만들어줌 )

요약하면 인수 목록이나 함수에서 여러 인수를 하나의 배열로 묶는데 사용하는것
```

```java
// 변수 길이 인자를 받는 함수
function addNumbers(...numbers) {
  let sum = 0;

  // 모든 인자를 더함
  for (let number of numbers) {
    sum += number;
  }

  return sum;
}

// 다양한 개수의 인자 전달하여 함수 호출
const result1 = addNumbers(1, 2, 3);
const result2 = addNumbers(1, 2, 3, 4, 5);

console.log(result1); // 출력: 6
console.log(result2); // 출력: 15
```

```java
배열에 새로운 값을 추가할 때마다 기존의 배열을 편집하는것이 아니라

기존값과 새로운 값이 포함된 새로운 배열을 만들고 싶다면 ?

이는 불변셩이라 불리며 꽤 자주 등장하는 패턴이다

( 기존의 값을 절대 편집하지 않고 사본에 변경된 값을 더한 배열로 대체하는 방식 )

( 복사해서 편집함으로서 오류를 피할 수 있고 기존 객체를 편집하지 않음으로써 코드를 읽어올 수 없게 되는일을 방지 )
```

## 스프레드(Spread) 연산자

```java
스프레드 연산자란 무엇인가?

배열이나 객체 등의 요소를 펼쳐서 각각 개별적인 요소로 만드는 연산자

예시로 설명:

배열을 복사하거나, 새로운 배열을 만들 때, 또는 함수의 인자로 배열을 전달할 때 스프레드 연산자를 사용할 수 있다.

요약하자면 배열이나 객체에서 원소나 속성을 추출하는데 사용
```

```java
// 배열의 요소를 펼쳐서 새로운 배열 만들기
const originalArray = [1, 2, 3];
const newArray = [...originalArray, 4, 5]; // originalArray의 모든 요소를 펼쳐서 newArray에 새로운 배열로 만드는 것 [1, 2, 3] 이 1, 2, 3 으로 펼쳐지는것

console.log(newArray);
// 출력: [1, 2, 3, 4, 5]

// 함수에 배열을 전달하여 사용하기
function sumNumbers(x, y, z) {
  return x + y + z;
}

const numbers = [1, 2, 3];

const result = sumNumbers(...numbers);

console.log(result); // x y z 에 1, 2, 3 이 들어감
// 출력: 6
```

## … 연산자

```java
... 연산자는 사용되는 맥락에 따라 정의가 달라지며, "Rest"와 "Spread" 두 가지 역할을 수행한다.

Rest (나머지):

함수의 매개변수에서 사용될 때, ... 연산자는 "Rest"로 불리며, 나머지 인자들을 배열로 수집한다.

예를 들어, function example(a, b, ...rest)와 같이 사용될 때 rest는 남은 모든 인자를 배열로 받는다.

Spread (펼치기):

배열이나 객체에서 사용될 때, ... 연산자는 "Spread"로 불리며, 해당 요소들을 펼쳐서 개별적인 요소로 분리한다.

예를 들어, const newArray = [...originalArray]와 같이 사용될 때 newArray는 originalArray의 모든 요소를 펼쳐서 새로운 배열로 만든다.

이처럼 ... 연산자는 함수의 매개변수에서는 나머지 요소를 수집하고, 배열이나 객체에서는 요소를 펼쳐서 다루는 다양한 역할을 수행합니다.
```

# Destructuring

```java
해체 할당(Destructuring assignment)은 배열이나 객체의 값을 추출하여 변수에 할당하는 문법
```

## **배열 해체 할당**

```java
// 배열 해체 할당
const numbers = [1, 2, 3];

// 기존 방식
const firstNumber = numbers[0];
const secondNumber = numbers[1];

// 해체 할당 사용
const [first, second, kimkim] = numbers;

console.log(first);  // 출력: 1
console.log(second); // 출력: 2
console.log(kimkim); // 출력: 3
```

```java
const [first, second, kimkim] = numbers;는

numbers 배열의 첫 번째 요소를 first 변수에, 두 번째 요소를 second 변수에 할당 세번째는 kimkim

( 인덱스 기반으로 [0 , 1, 2] 이렇게 지정된다
```

## **객체 해체 할당:**

```java
// 객체 해체 할당
const person = { name: 'John', age: 30 };

// 기존 방식
const personName = person.name;
const personAge = person.age;

// 해체 할당 사용
const { name, age } = person;

console.log(name); // 출력: 'John'
console.log(age);  // 출력: 30
```

```java
의 예제에서 const { name, age } = person;은 person 객체의 name 속성을 name 변수에, age 속성을 age 변수에 할당

( 새로운 name age 라는 변수가 생겨났다 )
```

# **템플릿 리터럴**

```jsx
문자열을 작성하는 다른 방법

큰따옴표나 작은따옴표를 사용해

'A String'

혹은

"Another string"

와 같은 방식으로 표현하거나,

백틱(`)을 사용해

`Another way of writing strings`

와 같은 방식으로 표현
```

## 왜 이런식으로 사용하는가?

```jsx
이 구문을 사용하면, 문자열에 다양하게 데이터를 추가할 수 있다. 아래 예시를 확인하자

기존의 문자열 결합 방식보다 짧고 읽기 쉽다.
```

```jsx
* 기존 문자열

const name = "Max";
const age = 29;
console.log("My name is " + name + " and I am " + age + " years old.");

* 템플릿 리터럴

const name = "Max";
const age = 29;
console.log(`My name is ${name} and I am ${age} years old.`);

```
