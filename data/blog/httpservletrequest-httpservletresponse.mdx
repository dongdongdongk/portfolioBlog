```java
웹 브라우저에서 URL을 입력하고 엔터를 치면 웹 애플리케이션 서버(WAS)에 요청이 전송됩니다.

이 요청은 클라이언트(브라우저)가 웹 서버와 통신하고 실제로 웹 애플리케이션 서버(WAS)에서 실행됩니다. 요청 및 처리 과정은 다음과 같습니다:

1. 웹 브라우저에서 URL 입력 및 엔터:

	* 사용자가 웹 브라우저의 주소 표시줄에 URL을 입력하고 엔터를 누릅니다. 이 URL은 웹 애플리케이션 서버(WAS)에 도달하려고 합니다.


2. 도메인과 포트 번호를 이용한 서버 접속:

	* URL에서 도메인(예: www.example.com) 및 포트 번호(기본적으로 80번 포트)를 사용하여 웹 서버에 연결합니다.

3. 요청 정보 생성:

	* 클라이언트(브라우저)는 요청 정보를 생성하여 서버에 보냅니다. 이 정보에는 요청한 리소스(패스 정보), HTTP 메소드(GET, POST, 등), 헤더, 쿠키 및 기타 클라이언트 정보가 포함됩니다.

4. HttpServletRequest 및 HttpServletResponse 객체 생성:

	* 웹 애플리케이션 서버(WAS)는 클라이언트의 요청을 받고 HttpServletRequest 및 HttpServletResponse 객체를 생성합니다. 이러한 객체는 서블릿 컨테이너에 의해 관리됩니다.

5. 서블릿 매핑:

	* 클라이언트의 요청 정보에 있는 패스(URI)를 기반으로 서블릿 매핑을 수행합니다. 즉, 요청이 어떤 서블릿과 연결되어야 하는지 결정합니다.

6. 서블릿 호출:

	* 서블릿 매핑 결과, 해당 서블릿이 실행되고 요청 정보 및 HttpServletRequest 객체가 해당 서블릿으로 전달됩니다.

7. 서블릿 처리:

	* 서블릿은 클라이언트로부터 받은 요청 정보를 처리하고, 필요한 경우 데이터베이스 쿼리, 파일 업로드, 비즈니스 로직 실행 등을 수행합니다.

8. 응답 생성:

	* 서블릿은 HttpServletResponse 객체를 사용하여 클라이언트에 응답을 생성합니다. 이 응답에는 헤더 정보, 쿠키, HTML, JSON 또는 다른 데이터가 포함될 수 있습니다.

9. 응답 전송:

	* 생성된 응답은 WAS를 통해 웹 서버를 거쳐 클라이언트로 전송됩니다. 클라이언트는 이 응답을 받아 화면에 결과를 표시하거나 다운로드할 수 있습니다.

이러한 과정을 통해 클라이언트의 요청이 웹 애플리케이션 서버(WAS)에 도달하고, 서블릿을 통해 처리되어 응답이 클라이언트에게 전달됩니다.

이것은 웹 애플리케이션의 기본 동작 방식을 설명한 것이며, 실제 구현은 웹 서버와 WAS 설정, 서블릿 프로그래밍, 데이터베이스 연동, 클라이언트-서버 통신 등 다양한 요소가 포함됩니다.
```

# 언제 사용하는가?

```java
실제로 그렇게 많이 사용하는건 아니다 세션 쿠키 정도?

1. 파일 업로드 처리를 직접 제어할 때:

파일 업로드 처리를 직접 제어하려는 경우, HttpServletRequest를 사용하여 클라이언트로부터 업로드된 파일의 내용과 속성을 직접 추출하고 처리할 수 있습니다.

이것은 Spring의 MultipartFile 또는 Java Servlet 3.0 이후의 Part API를 사용하지 않고, 파일 업로드를 직접 구현하려는 경우에 해당합니다.

2. HTTP 요청의 헤더 정보에 접근할 때:

HttpServletRequest를 사용하여 HTTP 요청의 헤더 정보를 확인하고 이를 기반으로 특정 작업을 수행하는 경우에 유용합니다.

예를 들어, 사용자의 User-Agent 헤더를 읽어 브라우저 또는 플랫폼에 따라 다른 동작을 수행할 수 있습니다.

3. 세션 관리 및 세션 속성에 접근할 때: 세션 관리와 세션 속성에 접근하려는 경우 HttpServletRequest를 사용합니다.

세션 관리는 로그인 상태 유지, 장바구니 구현, 사용자 상태 추적 등 다양한 웹 애플리케이션 요구 사항에서 중요합니다.

4. 요청 매개변수에 직접 접근할 때: HttpServletRequest를 사용하여 요청 매개변수 (HTTP 요청 URL의 쿼리 문자열 또는 POST 데이터)에 직접 접근할 수 있습니다.

이를 통해 클라이언트가 제출한 데이터를 처리하거나 검증할 수 있습니다.

5. 다양한 HTTP 메서드 처리: HttpServletRequest를 사용하면 GET, POST, PUT, DELETE와 같은 다양한 HTTP 메서드를 처리하거나 구분하는 데 도움이 됩니다.
```

```java
@Controller
public class UserProfileController {

    @GetMapping("/userProfileInput")
    public String userProfileInput() {
        return "userProfileInput"; // 사용자 입력 페이지로 이동
    }

    @PostMapping("/userProfile")
    public String saveUserProfile(HttpServletRequest request, Model model) {
        String name = request.getParameter("name");
        String id = request.getParameter("id");

        // 세션에 사용자 정보 저장
        HttpSession session = request.getSession();
        User user = new User(name, id);
        session.setAttribute("user", user);

        model.addAttribute("message", "User profile saved!");
        return "userProfileInput"; // 사용자 입력 페이지로 리다이렉트
    }
}
```

```java
@Controller
public class CartController {

    @RequestMapping("/cart")  // 입력 페이지로 이동
    public String showCart(Model model, HttpSession session) {
        model.addAttribute("cart", session.getAttribute("cart"));
        return "cart";
    }

    @PostMapping("/addToCart")
    public String addToCart(HttpServletRequest request, HttpSession session) {
        String product = request.getParameter("product");
        String cartItem = "Added to Cart: " + product;

        // 세션에서 장바구니 목록을 가져와서 제품 추가
        List<String> cart = (List<String>) session.getAttribute("cart");
        if (cart == null) {
            cart = new ArrayList<>();
        }
        cart.add(cartItem);
        session.setAttribute("cart", cart);

        return "redirect:/cart";
    }
}
```

### 쿠키 처리

```java
<!DOCTYPE html>
<html>
<head>
    <title>Set Cookie</title>
</head>
<body>
    <h1>Set Cookie</h1>
    <form action="/your-web-app-context/setCookie" method="get">
        <label for="username">Enter Your Username:</label>
        <input type="text" name="username" id="username" required>
        <button type="submit">Set Cookie</button>
    </form>
</body>
</html>
```

```java
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;

import javax.servlet.http.Cookie;
import javax.servlet.http.HttpServletResponse;

@Controller
public class CookieController {

    @GetMapping("/setCookie")
    public String setCookie(@RequestParam String username, HttpServletResponse response) {
        // 클라이언트에 username 쿠키 설정
        Cookie cookie = new Cookie("username", username);
        cookie.setMaxAge(3600); // 쿠키의 유효 기간 설정 (초 단위)
        response.addCookie(cookie);
        return "redirect:/readCookie";
    }
}
```
