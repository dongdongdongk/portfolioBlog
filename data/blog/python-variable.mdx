# **변수의 기본**

```jsx
파이썬에서 변수를 만들 때는 특별한 선언이 필요 없다. 변수에 값을 할당(대입)하는 순간, 해당 변수가 자동으로 생성된다.
```

```python
# 변수의 선언 및 할당
name = "John"
age = 30

# 변수의 사용
print(name)  # John 출력
print(age)  # 30 출력
```

# **변수의 동적 타이핑**

```jsx
파이썬은 동적 타이핑(dynamic typing) 언어이다.

이는 변수의 데이터 타입을 실행 시간(runtime)에 결정한다는 의미로, 같은 변수에 다른 타입의 데이터를 재할당할 수 있다.

* 파이썬은 상수라는 개념이 없다
```

```python
x = 10      # x는 정수(integer)
print(x)
x = "Hello"  # x는 이제 문자열(string)
print(x)
```

# **여러 변수에 값 할당하기**

```python
파이썬에서는 한 줄에 여러 변수에 값을 할당할 수 있다. 이는 코드를 더 간결하게 만들어 준다.
```

```python
# 한 줄에 여러 변수에 값 할당하기
a, b, c = 5, 10, 15

print(a)  # 5 출력
print(b)  # 10 출력
print(c)  # 15 출력
```

# **`%s` 사용**

```python
Python에서 %s는 문자열 형식 지정자로 사용된다.

%s를 사용하면 문자열 내에서 변수의 값을 문자열 형태로 삽입할 수 있다.

이 방법은 Python의 오래된 스타일의 문자열 포맷팅 중 하나로, Python 3.6 이상에서는 f-strings를 사용하는 것이 더 선호
```

## **예제 1: 하나의 값 삽입하기**

```python
name = "뤼튼"
greeting = "안녕하세요, %s님." % name
print(greeting)

출력 : 안녕하세요, 뤼튼님.
```

## **예제 2: 여러 값 삽입하기**

```python
name = "뤼튼"
age = 30
message = "%s님의 나이는 %s살입니다." % (name, age)
print(message)

출력 : 뤼튼님의 나이는 30살입니다.
```

## **예제 3: 사전(Dictionary)을 사용하는 경우**

```python
person_info = {"name": "뤼튼", "age": 30}
message = "%(name)s님의 나이는 %(age)s살입니다." % person_info
print(message)

출력 : 뤼튼님의 나이는 30살입니다.
```

# **f-strings 를 사용**

```python
Python 3.6 이상에서는 f-strings, 공식적으로는 Formatted String Literals라고 불리는,

문자열 포매팅 방법을 도입하여 문자열 내에서 변수의 값을 보다 쉽게 삽입할 수 있게 되었다.
```

## **f-strings 사용 방법**

```python
f-strings 사용 방법:

1. 문자열의 시작을 f나 F로 표시한다.

2. 문자열 내에서 중괄호 {}를 사용하여 변수명이나 표현식을 감싸 넣는다.

3. Python이 실행 시점에 해당 변수의 값을 문자열에 삽입한다.
```

## **단일 변수 삽입**

```python
name = "뤼튼"
greeting = f"안녕하세요, {name}님."
print(greeting)

출력 : 안녕하세요, 뤼튼님.
```

## **여러 변수 및 표현식 사용**

```python
name = "뤼튼"
age = 30
message = f"{name}님의 나이는 {age}살입니다. 10년 후면 {age + 10}살이 되겠군요."
print(message)

출력 : 뤼튼님의 나이는 30살입니다. 10년 후면 40살이 되겠군요.
```

## **딕셔너리 사용**

```python
person_info = {"name": "뤼튼", "age": 30}
message = f"{person_info['name']}님의 나이는 {person_info['age']}살입니다."
print(message)

출력 : 뤼튼님의 나이는 30살입니다.
```

## **포매팅 옵션 사용**

```python
-strings는 또한 다양한 포매팅 옵션을 제공한다.

예를 들어, 소수점 이하 숫자를 제한하거나, 값을 퍼센트로 표시하거나, 패딩을 추가하는 것 등이 가능하다.
```

```python
number = 3.14159
print(f"파이의 값은 {number:.2f}입니다.")

출력 : 파이의 값은 3.14입니다.
```
