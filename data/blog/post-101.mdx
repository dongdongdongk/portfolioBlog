# JavaScript 객체(object)

```jsx
키-값 쌍 또는 프로퍼티라는 걸 이용해서 데이터를 저장

객체는 이 쌍들의 집합
```

### 프로퍼티

```jsx
프로퍼티(property)는 두 개의 정보가 모인 건데

키(key)와 값(value)로 구성된다
```

# **객체 리터럴의 기본 구조**

```jsx
객체 리터럴은 중괄호 {}를 사용하여 정의된다.
```

```jsx
const person = {
  name: 'John',
  age: 30,
  gender: 'male',
}
```

```jsx
위 예제에서 person은 객체를 나타냅니다.

객체는 name, age, gender와 같은 속성들을 가지고 있습니다.
```

## **속성과 값**

```jsx
객체 내의 각 속성은 콜론(:)으로 구분된 이름과 값의 쌍으로 정의된다
```

```jsx
const person = {
  name: 'John',
  age: 30,
  gender: 'male',
}
```

## **다양한 데이터 유형**

```jsx
객체 리터럴 내의 값은 문자열, 숫자, 불리언, 배열, 다른 객체 등 다양한 데이터 유형일 수 있다.
```

```jsx
const car = {
  brand: 'Toyota',
  model: 'Camry',
  year: 2022,
  features: ['automatic transmission', 'power windows'],
  owner: {
    name: 'Alice',
    age: 28
  }
};

* features는 배열이고, owner는 다른 객체
```

## **메서드 추가**

```jsx
객체 리터럴 내에 함수를 포함하여 메서드를 추가할 수 있다
```

```jsx
const calculator = {
  add: function (a, b) {
    return a + b
  },
  subtract: function (a, b) {
    return a - b
  },
}
```

## **속성 접근**

```jsx
객체의 속성에 접근할 때는 마침표(.)를 사용
```

```jsx
console.log(person.name); // 출력: 'John'
console.log(car.features[0]); // 출력: 'automatic transmission'

* person 객체의 name 속성과 car 객체의 features 배열의 첫 번째 요소에 접근하는 예제
```

### 대괄호 표기법[]

```jsx
대괄호 안에 객체의 속성 이름을 넣어서 값을 가져올 수 있다.

이 방법은 속성의 이름이 변수에 저장되어 동적으로 속성에 접근할 때 유용하다.

대부분의 경우에는 점 표기법(.)을 사용하는 것이 더 직관적이지만, 특정 상황에서는 대괄호 표기법이 더 유용할 수 있다.
```

예제

```jsx
* 사용자 입력 처리

const userInput = 'brand';
const car = {
  brand: 'Toyota',
  model: 'Camry',
  year: 2022
};

// 대괄호 표기법을 사용하여 동적으로 사용자가 입력한 속성에 접근
const userSelectedValue = car[userInput];
console.log(userSelectedValue); // 출력: 'Toyota'

----------------------------------------------------------------------

* 동적 속성 생성

const propertyName = 'color';
const car = {
  brand: 'Toyota',
  model: 'Camry',
  year: 2022
};

const propertyValue = 'Blue';

// 대괄호 표기법을 사용하여 동적으로 속성 추가
car[propertyName] = propertyValue;
console.log(car); // 출력: { brand: 'Toyota', model: 'Camry', year: 2022, color: 'Blue' }

----------------------------------------------------------------------

* API 응답 처리

const apiResponse = {
  data: {
    user: {
      name: 'Alice',
      age: 28
    },
    status: 'success'
  }
};

const userPropertyName = 'name';

// 대괄호 표기법을 사용하여 중첩된 객체의 속성에 접근
const userName = apiResponse.data.user[userPropertyName];
console.log(userName); // 출력: 'Alice'

----------------------------------------------------------------------

* 다국어 지원

const language = 'ko';
const translations = {
  en: 'Hello!',
  ko: '안녕하세요!'
};

// 대괄호 표기법을 사용하여 동적으로 다국어 지원
const greeting = translations[language];
console.log(greeting); // 출력: '안녕하세요!'
```

## **객체 확장**

```jsx
객체 리터럴은 생성된 이후에도 속성을 추가하거나 수정할 수 있다
```

```jsx
person.job = 'Engineer';

* person 객체에 job 속성을 추가하는 예제
```

# 객체 네스트 (객체 중첩)

```jsx
객체 중첩을 효과적으로 활용하면 복잡한 데이터 구조를 쉽게 관리할 수 있다
```

```jsx
// 객체 생성
var person = {
  name: 'John',
  age: 30,
  address: {
    city: 'Seoul',
    street: '123 Main Street',
  },
  hobbies: ['reading', 'coding', 'traveling'],
}

// 객체 속성에 접근
console.log(person.name) // "John"
console.log(person.address.city) // "Seoul"
console.log(person.hobbies[1]) // "coding"
```

```jsx
* 객체 내부의 객체: 객체 내부에 다른 객체를 중첩할 수 있다. 위의 예제에서 address 속성이 그런 예다.

* 배열을 값으로 가지는 속성: 객체는 배열을 값으로 가질 수도 있다. hobbies 속성은 배열을 값으로 가지고 있다.

* 속성에 접근: 중첩된 객체 또는 배열의 속성에 접근할 때는 점(.) 또는 대괄호([])를 사용한다.

* 동적으로 속성 추가: 객체는 동적으로 속성을 추가할 수 있다. 예를 들어, person.gender = "Male";와 같이 속성을 추가할 수 있다.

* 중첩된 객체의 속성 변경: 중첩된 객체의 속성은 동일한 방식으로 변경할 수 있다.

	예를 들어, person.address.city = "Busan";와 같이 변경할 수 있다.
```
