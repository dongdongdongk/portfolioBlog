# 쿼리

쿼리는 말 그대로 뭔가를 물어보는 것. 여기서는 데이터베이스에게 무언가를 부탁하거나, 정보를 찾아오는 데 사용. SQL이라는 언어를 주로 씀. 그런데 SQL은 데이터베이스와 친한 언어지만, 객체랑은 친하지 않다. 그래서 자바 같은 객체 지향 언어에서는 좀 어색하게 느껴질 수 있다.(쿼리는 데이터베이스에게 문의하는 언어)

# JPQL (Java Persistence Query Language):

자바에서 데이터베이스랑 소통하기 위한 언어 일종의 중간 언어라고 생각할것. 쿼리를 쓸 때 테이블이 아니라 자바 객체를 대상으로 함. 그래서 객체지향적으로 편하게 쓸 수 있다. 예를 들면, "이런 객체들 중에서 이런 조건에 맞는 거 찾아와줘" 식으로 부탁할 수 있다.(JPQL은 자바에서 편하게 쿼리를 쓰기 위한 언어)

# 쿼리 DSL (Query DSL):

이건 마치 자바 코드처럼 생겼다. 자바 코드 안에다가 데이터베이스에게 하는 요청을 코드로 쓰는 것. 그래서 쿼리를 자바 코드로 편하게 작성할 수 있게 해주는 도구 같은 거다. 자바 코드에 쿼리를 써서, 코드 자체로 데이터베이스에게 무엇을 해달라고 요청하는 거.(쿼리 DSL은 자바 코드 안에서 쿼리를 작성할 수 있게 도와주는 도구)

# 쿼리 메서드

쿼리 메서드는 메서드의 이름을 기반으로 데이터베이스 쿼리를 생성해준다. 메서드 이름에 따라 Spring Data JPA가 자동으로 쿼리를 만들어주기 때문에 별도의 JPQL이나 SQL을 작성하지 않아도 됀다.(복잡한 쿼리나 특별한 조인이 필요한 경우에는 JPQL이나 네이티브 쿼리를 사용해야 할 수도 있다)

# 스프링 데이터 JPA

자바 어플리케이션에서 데이터베이스와 소통하기를 도와주는 도구. 여기서 JPA는 데이터베이스와 자바 객체 사이의 다리 역할을 하는데, 스프링 데이터 JPA는 이를 더 쉽게 사용할 수 있게 도와준다

(스프링 프레임워크에서 제공하는 모듈 중 하나로, Java Persistence API (JPA)를 기반으로 하는 데이터 액세스를 지원하는 도구)

## JPA(Java Persistence API)

JPA는 자바에서 관계형 데이터베이스와 상호작용하기 위한 표준 인터페이스를 제공한다.객체와 관계형 데이터베이스 간의 매핑을 담당하며, 엔터티 객체를 데이터베이스에 저장하고 조회하는 등의 작업을 지원한다.

## 스프링 데이터 JPA

스프링 데이터 JPA는 스프링 프레임워크에서 JPA를 더 쉽게 사용할 수 있도록 도와주는 모듈이다.주로 Repository 인터페이스를 정의하면, 스프링 데이터 JPA가 해당 인터페이스의 구현체를 자동으로 생성하여 데이터베이스 액세스를 지원한다.

## Repository 인터페이스

Repository 인터페이스는 JPA 엔터티와 관련된 데이터베이스 조작을 위한 메서드를 정의한다.스프링 데이터 JPA는 이 인터페이스를 분석하여 자동으로 쿼리 메서드를 생성하여 제공한다.

## 자동 구현체 생성

Repository 인터페이스를 정의하면, 스프링 데이터 JPA가 이를 분석하여 자동으로 해당 Repository의 구현체를 생성한다.구현체는 JPA를 사용하여 데이터베이스 액세스를 수행하며, CRUD (Create, Read, Update, Delete) 작업을 지원한다.

## 쿼리 메서드

Repository 인터페이스에서는 쿼리 메서드를 정의할 수 있다. 이 메서드의 이름을 통해 스프링 데이터 JPA가 자동으로 데이터베이스 쿼리를 생성한다.메서드 이름에 따라 조회, 수정, 삭제 등 다양한 작업을 할 수 있다
