## 🔄 Selector 노드란?

### Sequence vs Selector

**Sequence (AND):**

```
모두 성공해야 성공
  1 성공 → 2 성공 → 3 성공 → 성공 ✅
  1 성공 → 2 실패 → 중단 ❌
```

**Selector (OR):**

```
하나만 성공하면 성공
  1 실패 → 2 성공 → 성공 ✅ (멈춤)
  1 성공 → 성공 ✅ (2, 3 안 봄)
```

---

### Selector 실행 규칙

**1. 왼쪽에서 오른쪽으로**

```
Selector
  ├─ 1️⃣ 첫 번째
  ├─ 2️⃣ 두 번째
  └─ 3️⃣ 세 번째
```

**2. 성공하면 중단**

```
1️⃣ 실패 ❌ → 다음으로
2️⃣ 성공 ✅ → 멈춤! (3번 안 봄)
```

**3. 모두 실패하면 실패**

```
1️⃣ 실패 ❌
2️⃣ 실패 ❌
3️⃣ 실패 ❌
  ↓
Selector 실패 ❌
```


## 🔍 Key Query 옵션

### Is Set vs Is Not Set

**Is Set (설정됨):**

```cpp

    // 실행

```

```
4. 없으면 추가!
```

## 🤔 왜 Service가 필요한가요?

## 🎨 Service란?

### Service = 자동 실행 기능

**비유:**

```
배경에서 돌아가는 프로그램
  ↓
계속 체크하면서
  ↓
필요할 때 업데이트

예: 시계 앱
  → 1초마다 시간 업데이트
```

---

### Decorator vs Service

**Decorator (조건):**

```
한 번 체크
  ↓
통과/차단 결정
  ↓
끝

예: "출입증 있나요?"
  → 한 번 확인하고 끝
```

**Service (반복 작업):**

```
계속 실행
  ↓
주기적으로 반복
  ↓
무한 반복

예: "체온 계속 재기"
  → 10초마다 계속 측정
```

```cpp
    UBehaviorTreeComponent& OwnerComp,
    uint8* NodeMemory,
    float DeltaSeconds
```

```cpp
            OwnerController->ClearFocus(EAIFocusPriority::Gameplay);
        }
```
```cpp
    }
}
```

## ⚡ Observer Aborts (중단 설정)

### 문제 상황

**게임 시작 시:**

```
1. Service 시작
2. PlayerLocation 아직 설정 안 됨
3. Selector 실행
   ├─ Chase → PlayerLocation 없음 → 건너뛰기
   ├─ Investigate → 실행
   └─ Return

4. Investigate 끝날 때까지 기다림
5. 그 후에야 Chase 확인
```

**문제:**

```
Investigate 중 플레이어 발견해도
→ Investigate 끝날 때까지 기다림
→ 반응 느림! ❌
```

---

### 해결: Observer Aborts

**Chase Decorator 설정:**

```
1. Chase의 Decorator 선택
2. Details 패널
3. Observer Aborts:
   ☑ Self
   ☑ Lower Priority
```

---

**Self (자기 중단):**

```
Chase 실행 중:
  PlayerLocation 해제되면
  → 즉시 Chase 중단! ❌
  → Investigate로 전환
```

**Lower Priority (낮은 우선순위 중단):**

```
Investigate/Return 실행 중:
  PlayerLocation 설정되면
  → 즉시 Investigate/Return 중단! ❌
  → Chase로 전환! ✅
```
