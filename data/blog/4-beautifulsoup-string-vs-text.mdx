# 텍스트를 가져오는 string과 text의 차이점 완벽 이해

```python
뷰티풀 숲(Beautiful Soup)에서 .text와 .string은 각각 다른 의미를 갖는다.
```

## .text

```python
.text: BeautifulSoup에서 .text 속성은 특정 태그에 포함된 모든 텍스트 내용을 반환한다.

즉, 해당 태그 안에 있는 모든 텍스트를 하나의 문자열로 반환한다.

이 문자열은 태그 안의 모든 텍스트를 포함하며, 하위 태그의 텍스트도 포함될 수 있다.

ex) 만약 html 태그에 엔터가 있거나 띄어쓰기가 있으면 그걸 전부 인식해서 빈칸을 만들어 버린다

html = "<p>This is <strong>bold </strong> text.</p>"
```

## .string

```python
.string: .string은 특정 태그 안에 있는 첫 번째 문자열을 반환한다.

하지만 이 속성은 모든 태그에서 사용할 수 있는 것은 아니며,

텍스트가 아닌 경우에는 None을 반환한다. 따라서 .string은 해당 태그 안의 첫 번째 문자열만을 반환하는 반면,

.text는 해당 태그 안의 모든 텍스트를 하나의 문자열로 반환한다.

ex) 만약 중간에 띄어쓰기가 있거나 하면 string 은 텍스트를 인식하지 못한다

html = """<a class="logo_naver"> <span class="blind"> 네이버 </span></a>

현재 <span> 앞에 공간이 생겼기 때문에 이제 <a> 태그의 클래스를 선택해서는 잡아내지 못하게 된다 그렇기 때문에 <span> 의 클래스를 잡아서 string을

쓰는것이 좋다
```

```python
정리하자면 string 은 우리가 가져오고자 하는 텍스트에 최대한 접근해서 가져오는 것

정확하게 사용하자면 string 두루뭉실하게 사용하자면 text ( 물론 text 도 최대한 접근하게 좋다 )
```

## 예제

```python
from bs4 import BeautifulSoup

html = "<p>This is <strong>bold</strong> text.</p>"
soup = BeautifulSoup(html, "html.parser")
p_tag = soup.find("p")

print(p_tag.text)    # 출력: This is bold text.
print(p_tag.string)  # 출력: None
```
