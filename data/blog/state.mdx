```jsx
리액트(State)는 React 컴포넌트의 상태를 관리하는 데 사용되는 기능이다.

상태(state)는 컴포넌트 내에서 동적인 데이터를 다루기 위해 사용된다. ( ex) 클릭하면 카운트가 올라가는 기능에서 계속 변하는 숫자 )

React 컴포넌트는 상태의 변경을 감지하고 자동으로 UI를 업데이트한다.
```

## **리액트 State의 특징**

```jsx
**컴포넌트 내에서 관리**:

State는 컴포넌트 내부에서 관리되며, 해당 컴포넌트에서만 접근이 가능하다.

**가변성(mutable)**:

State는 직접 수정이 불가능하고, setState 함수를 통해 업데이트된다.

**비동기적 업데이트**:

setState는 비동기적으로 동작하며, React가 여러 setState 호출을 하나로 묶어서 처리한다.
```

## **`useState`** 훅

```jsx
React에서 상태(state)를 사용할 수 있게 해주는 특별한 함수 ( 리액트에는 20 가지 정도의 여러 훅이 있다 )

( 훅 = 함수형 컴포넌트에서 더 많은 기능을 사용할 수 있게 해주는 것 )

함수형 컴포넌트에서 상태를 다룰 수 있도록 도와주는 훅 중 하나로,

기존의 클래스형 컴포넌트에서 사용되던 this.state와 this.setState와 유사한 역할을 한다.
```

### **`useState`의 기본 사용법**

```jsx
mport React, { useState } from 'react';

function ExampleComponent() {
  // useState 훅을 사용하여 상태를 정의하고 초기값을 전달합니다.
  const [state, setState] = useState(initialState);

  // state: 현재 상태의 값
  // setState: 상태를 업데이트하는 함수
	// [dong, minmin] = useState() 이렇게 되도 상관없다 배열의 첫번째 두번째 이것만 중요

  // 이후에 state와 setState를 사용하여 상태를 읽고 업데이트할 수 있습니다.
}

* 쉽게 말하면

useState = 초기값 ( 카운터로 치면 0 )

state = 현재 값 ( 현재 카운터 된 번호 )

setState = 다음번에 올 번호 ( 카운트 번호를 눌렀을 때 업데이트 될 +1 된 숫자 )
```

## **리액트 State 사용 예제**

```jsx
import React, { useState } from 'react'

function Counter() {
  // useState 훅을 사용하여 초기 상태와 상태를 업데이트할 함수를 생성
  const [count, setCount] = useState(0)

  // 상태를 업데이트하는 이벤트 핸들러 함수
  const handleIncrement = () => {
    // setCount 함수를 사용하여 상태를 업데이트
    setCount(count + 1)
  }

  const handleDecrement = () => {
    setCount(count - 1)
  }

  return (
    <div>
      <h2>Counter: {count}</h2>
      <button onClick={handleIncrement}>Increment</button>
      <button onClick={handleDecrement}>Decrement</button>
    </div>
  )
}

export default Counter
```

```jsx
위의 예제에서 useState 훅을 사용하여 count라는 상태와 이를 업데이트할 수 있는 setCount 함수를 생성

handleIncrement과 handleDecrement 함수에서는 setCount 함수를 사용하여 상태를 업데이트하고 있다

이로써 컴포넌트는 상태가 변경될 때마다 리렌더링되어 변경된 상태를 화면에 반영한다.
```

```jsx
import { useState } from 'react'
import './Toggler.css'
export default function TogglerCounter() {
  const [isHappy, setIsHappy] = useState(true)
  const [count, setCount] = useState(0)
  const toggleIsHappy = () => setIsHappy(!isHappy)
  const increment = () => setCount(count + 1)
  return (
    <>
      <p className="Toggler" onClick={toggleIsHappy}>
        {isHappy ? '😁' : '😢'}
      </p>

      <button onClick={increment}>+</button>
      <p>{count}</p>
    </>
  )
}
```

```jsx
한번에 두개의 useState 도 사용 가능하다

const [count, setCount] = useState(0); 이렇게 또다른 useState 배열을 선언해주고

const increment = () => setCount(count + 1); 숫자가 올라가는 함수를 선언해주고

한번에 두개의 요소를 보내는게 불가능하니 <> </> 를 사용해서 묶어서 보내준다
```

# useState()와 렌더링 순서

## **컴포넌트의 렌더링 순서**

```jsx
컴포넌트는 처음에 렌더링될 때 함수 전체가 실행된다.

이때 useState 훅은 최초 렌더링 시에만 초기값을 이용하여 새로운 상태를 생성한다
```

## state **업데이트 및 렌더링**

```jsx
상태를 업데이트할 때마다 컴포넌트 전체가 다시 실행되고, 새로운 상태가 반영된다

예를 들어, setNum 함수를 호출하여 num 상태를 업데이트하면 전체 컴포넌트가 재실행된다
```

## **함수 컴포넌트의 특징**

```jsx
함수 컴포넌트는 처음에 한 번 실행되며, 그 이후 상태 변경이 있을 때만 다시 실행된다.

useState 훅은 이러한 동작을 지원하며, 최초 렌더링 시에만 초기값을 사용한다.
```

## **상태 업데이트 이후의 동작**

```jsx
상태를 업데이트한 후에는 해당 컴포넌트가 다시 렌더링되어야 새로운 상태가 화면에 반영된다.

상태 업데이트는 비동기적으로 이루어지며, 업데이트된 상태는 다음 렌더링에서 반영된다.
```

## **클로저 및 함수 컴포넌트의 최적화**

```jsx
리액트는 함수 컴포넌트를 최적화하여 상태 값의 변화가 있을 때만 재렌더링되도록 한다.

함수 컴포넌트의 클로저(Closure)를 활용하여 상태 값을 적절히 관리하며, 상태의 업데이트는 최소한으로 제한된다.
```

```jsx
import { useState } from 'react'
import './ColorBox.css'

// 배열에서 무작위로 요소를 선택하는 randomChoice 함수를 정의
// arr 배열의 길이를 이용하여 무작위 인덱스(idx)를 생성하고, 해당 인덱스에 해당하는 배열 요소(색상하나)를 반환
function randomChoice(arr) {
  const idx = Math.floor(Math.random() * arr.length)
  return arr[idx]
}

// ColorBox라는 함수 컴포넌트를 정의한다. 이 컴포넌트는 colors라는 prop을 받아오고, 이 prop은 가능한 색상을 나타내는 배열
// useState 훅을 사용하여 color라는 상태를 관리, 초기값은 randomChoice(colors), changeColor 함수는 호출될 때마다 colors 배열에서 무작위로 선택된 색으로 상태를 업데이트
function ColorBox({ colors }) {
  const [color, setColor] = useState(randomChoice(colors))
  const changeColor = () => {
    const randomColor = randomChoice(colors)
    setColor(randomColor)
  }
  // 클릭 이벤트가 발생하면 changeColor 함수가 호출, style 속성을 사용하여 배경색을 현재 color 상태로 설정
  return <div className="ColorBox" onClick={changeColor} style={{ backgroundColor: color }}></div>
}

export default ColorBox
```
