# { 🎧 레벨 전용 SoundBank 만들기 }

**(Wwise Module 18 - Creating Level-Specific SoundBanks)**

이번 단원에서는 **특정 레벨에서만 사용되는 사운드를 별도로 관리하기 위한 전용 SoundBank**를 만드는 방법을 배웁니다.

이를 통해 **게임 메모리를 효율적으로 관리**하고, 불필요한 오디오 자원이 **불필요하게 로드되지 않도록** 합니다.

## 1️⃣ SoundBank의 개념 이해하기

- **SoundBank**란 Wwise에서 **사운드 데이터를 묶어서 관리하고, 게임 실행 시 메모리에 로드하는 단위**입니다.
- 하나의 게임에는 여러 개의 SoundBank가 존재할 수 있으며, 각 SoundBank는 다음을 포함할 수 있습니다.
  - Event (사운드 트리거 명령)
  - Actor-Mixer 오브젝트 (사운드 자원)
  - Bus (믹싱 구조)
  - Effect (효과)

🎯 **핵심 역할:**

게임 내에서 특정 구간이나 상황에서 필요한 오디오만 **부분적으로 로드/언로드하여 메모리 절약**.

---

## 2️⃣ 레벨 전용 SoundBank의 필요성

대부분의 게임은 **여러 개의 레벨(stage, map)** 로 구성되어 있으며,

각 레벨은 서로 다른 배경음, 환경음, 음성 파일 등을 가집니다.

예시:

- `dcp_the_core` 레벨 → 화산 지역, 불꽃, 폭발음, 열기 효과음
- `forest_village` 레벨 → 새소리, 바람소리, 잎사귀 흔들림

이처럼 **특정 레벨에서만 재생되는 사운드**가 있을 경우,

그 사운드를 **전용 SoundBank**로 분리해야 합니다.

> 💡 이유:
>
> - 불필요한 사운드를 미리 메모리에 올리지 않음 → **RAM 절약**
> - 레벨 진입 시에만 해당 사운드 로드 → **로딩 효율 향상**
> - 대규모 프로젝트에서 **사운드 관리 체계화** 가능

---

### 🔍 예시 상황

- 프로젝트에 **“Map Voices”** 라는 Actor-Mixer 오브젝트가 존재함.
- 이 오브젝트는 **Cube의 `dcp_the_core` 레벨**에서만 들을 수 있는 음성들을 포함함.
- 따라서 `Map Voices` 관련 사운드는 **그 레벨 전용 SoundBank**로 따로 분리해야 함.

## 3️⃣ SoundBank Manager 열기

1. **Wwise 실행** 후 프로젝트 파일을 엽니다.
   - `Module 18` 프로젝트를 열었는지 반드시 확인합니다.
2. **상단 메뉴 바**에서

   `Layouts > SoundBank` (단축키 **F7**) 을 클릭합니다.

3. 화면 오른쪽 상단에 **SoundBank Manager** 창이 표시됩니다.
   - 이곳에서 SoundBank의 생성, 관리, 빌드(Generate) 작업을 수행합니다.

## 4️⃣ 새로운 SoundBank 생성하기

1. **SoundBank Manager** 창에서

   `Default Work Unit` 을 펼칩니다.

   → 이미 **1단원: 적막에서 소리까지** 에서 만든

   `Main` SoundBank 가 존재하는 것을 확인할 수 있습니다.

2. **“Create new User-Defined SoundBank”** 버튼을 클릭합니다.

   > 📌 위치: SoundBank Manager 상단의 + 아이콘 또는 “New” 버튼

3. **대화 상자(Dialog)** 가 열리면 다음과 같이 입력합니다.
   - **Name:** `DCP_the_core`
   - **OK** 클릭
4. 새로 만든 SoundBank가 **Main SoundBank**와 함께

   목록에 표시됩니다.

> ⚠️ 중요:
>
> Cube 게임의 코드에서는 `DCP_the_core` 라는 이름으로 SoundBank를 찾도록 되어 있습니다.
>
> 따라서 **정확한 이름으로 생성해야** 사운드가 정상적으로 로드됩니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380553/notion-blog/_/WWISE/Wwise_/18_SoundBank_/image_1.png)

## 5️⃣ 플랫폼 설정 확인하기

SoundBank는 **플랫폼(Windows, Mac, Console 등)** 별로

빌드 환경이 다를 수 있습니다.

1. **툴바 왼쪽 상단**에 있는 **Platform Selector** 를 확인합니다.
2. 현재 작업 중인 플랫폼(예: `Windows`)이 올바르게 선택되어 있는지 확인합니다.
   - 선택된 플랫폼은 SoundBank Manager의 상단에도 표시됩니다.

> 🎯 이유:
>
> 플랫폼별로 경로, 파일 포맷(WAV/ADPCM), 압축 옵션이 달라질 수 있기 때문입니다.

**Map Voices 오브젝트를 추가하고 SoundBank를 실제로 빌드(Generate)** 하게 됩니다.

# { 🎧 SoundBank에 Event 추가하기 }

## 🚀 전체 요약

이번 강의에서는 **게임의 각 레벨이나 상황에 맞게 필요한 사운드(Event)를 SoundBank에 추가하는 방법**을 배웁니다.

특히 “DCP_the_core”라는 레벨에만 사용되는 이벤트들을 **레벨 전용 SoundBank(DCP_the_core SoundBank)** 에 넣고,

나머지 공용 이벤트들을 **Main SoundBank** 에 넣는 방식으로 구성합니다.

이 과정을 통해 **사운드 데이터를 효율적으로 관리**하고, **메모리 최적화**를 달성할 수 있습니다.

## 1. 🎼 SoundBank와 Event의 개념 이해하기

- **SoundBank란?**
  - 게임 실행 시 **메모리에 로드되는 사운드 묶음**입니다.
  - 여러 개의 SoundBank를 만들어 **레벨별, 상황별로 필요한 사운드만 로드**하도록 하면 메모리 낭비를 막을 수 있습니다.
  - 예:
    - `Main SoundBank`: 게임 전반에서 쓰이는 공용 사운드
    - `DCP_the_core SoundBank`: 특정 레벨(`dcp_the_core`)에서만 쓰이는 사운드
- **Event란?**
  - 게임 코드나 엔진에서 특정 행동을 트리거할 때 사용하는 **사운드 실행 명령**입니다.
  - 예: `"Player_Jump"` Event → 플레이어 점프 시 재생되는 사운드.
  - Event를 SoundBank에 추가해야만 **빌드 시 관련 오디오 리소스가 포함되어 게임에서 재생 가능**해집니다.

---

## 2. 🔍 레벨 전용 Event 찾기 (“DCP” 접두사)

- 강의에서 사용된 예시 레벨 이름: `dcp_the_core`
- 이 레벨과 관련된 모든 Event의 이름은 **‘DCP’로 시작**합니다.
  - 예:
    - `DCP_Door_Open`
    - `DCP_Alarm_Loop`
    - `DCP_Boss_Intro`

➡️ 이렇게 이름 패턴이 통일되어 있으면 **검색으로 한 번에 선택**하기 쉽습니다.

---

## 3. 🎚️ DCP_the_core SoundBank에 Event 추가하기

### 단계별 과정

1. **SoundBank Manager 열기**
   - Wwise 상단 메뉴에서 `SoundBank Manager`를 엽니다.
   - 왼쪽 목록에서 `DCP_the_core` SoundBank를 클릭합니다.
2. **Event Viewer 열기 및 필터링**
   - 하단의 **Event Viewer**(이벤트 목록 창)에서 검색창에 **“DCP”** 입력.
   - 이름이 `DCP`로 시작하는 모든 Event가 필터링되어 표시됩니다.
3. **모든 DCP 관련 Event 선택하기**
   - 첫 번째 Event를 클릭한 뒤,
   - **Shift 키**를 누른 상태로 마지막 Event를 클릭 → 중간의 모든 Event가 한 번에 선택됩니다.

   💡 **Tip:**
   - 이 방법은 연속으로 나열된 여러 Event를 빠르게 선택할 때 유용합니다.
   - 여러 개를 개별적으로 선택하려면 `Ctrl + 클릭`도 가능합니다.

4. **드래그로 추가하기**
   - 선택된 모든 Event를 마우스로 **DCP_the_core SoundBank로 드래그**합니다.
5. **결과 확인**
   - 우측 하단의 **SoundBank Editor 뷰**로 이동합니다.
   - 방금 추가한 모든 Event가 **DCP_the_core SoundBank 목록에 표시**됩니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380553/notion-blog/_/WWISE/Wwise_/18_SoundBank_/image_3.png)

## 4. 🧰 Main SoundBank에 나머지 Event 추가하기

이제 프로젝트의 **나머지 Event들(즉, DCP로 시작하지 않는 것들)** 을 **Main SoundBank** 에 추가합니다.

### 단계별 과정

1. **Event Viewer에서 나머지 Event 선택**
   - 필터링을 해제하고 전체 Event를 표시한 다음,
   - ‘DCP’로 시작하지 않는 나머지 모든 Event를 선택합니다.
   - Event 목록이 길다면 **아래로 스크롤하면서 빠짐없이 선택**합니다.
2. **Main SoundBank로 드래그**
   - 선택된 Event들을 **Main SoundBank** 로 드래그합니다.
3. **추가 완료 확인**
   - 이제 프로젝트의 모든 Event가
     - `DCP_the_core` SoundBank
     - `Main` SoundBank
       중 하나에 포함되어 있습니다.

---

## 5. ⚙️ 중복 추가 방지와 확인 사항

- **중복 추가는 자동 방지됨**
  - 예: 이전에 `Fire_IceGem_Player` Event를 Main SoundBank에 추가했더라도
    → 다시 추가할 경우 **중복 저장되지 않습니다.**
- **Data Size(데이터 크기)는 아직 0으로 표시됨**
  - 이유: 아직 SoundBank를 “생성(Build)”하지 않았기 때문입니다.
  - 실제 파일 크기와 데이터는 **SoundBank를 빌드할 때 계산**됩니다.

## 🎯 핵심 정리

| 구분                       | 역할                       | 포함되는 Event                    |
| -------------------------- | -------------------------- | --------------------------------- |
| **Main SoundBank**         | 공용 사운드 관리           | 전체 레벨에서 사용하는 일반 Event |
| **DCP_the_core SoundBank** | 특정 레벨 전용 사운드 관리 | `DCP`로 시작하는 Event            |

💡 **결과적으로**

이 과정을 통해 프로젝트의 모든 Event가 올바른 SoundBank에 배치되고,

레벨별로 필요한 사운드만 로드되는 구조가 완성됩니다.

이는 **메모리 효율성 향상, 로딩 속도 개선, 유지보수성 향상**으로 이어집니다.

# { 🎧 SoundBank 생성하기 }

이 단원에서는 Cube 게임의 각 레벨에 필요한 **사운드를 효율적으로 관리하기 위해 SoundBank를 생성하고 구성하는 방법**을 배웁니다.

SoundBank는 Wwise에서 **게임에 필요한 사운드 데이터(Event, 오디오 파일 등)** 를 실제 실행 환경(게임)에 맞게 **패키징하는 핵심 시스템**입니다.

## 1. SoundBank 개념 이해하기

- **SoundBank란?**
  - 게임 실행 시 필요한 **모든 오디오 관련 데이터(Event, Sound, Effect 등)** 를 하나로 묶은 **사운드 패키지 파일**입니다.
  - 게임은 실행 중에 Wwise 프로젝트 전체를 로드하지 않고, **SoundBank 파일만 읽어들여 사운드를 재생**합니다.
  - 이렇게 하면 **메모리 사용량과 로딩 시간을 효율적으로 관리**할 수 있습니다.
- **왜 여러 개의 SoundBank를 쓰는가?**
  - 게임의 각 **레벨, 구역, 캐릭터, 상황(State)** 에 따라 필요한 사운드가 다르기 때문입니다.
  - 예를 들어,
    - `Main SoundBank`: 전체 공통 사운드 (UI, 배경음, 효과음 등)
    - `dcp_the_core SoundBank`: 특정 레벨에서만 사용하는 사운드(Event)

---

## 2. SoundBank 생성 준비하기

### 🎛 SoundBank Manager 열기

- **Wwise 상단 메뉴 → Layouts → SoundBank** 를 통해 SoundBank Manager 창을 엽니다.
- SoundBank Manager는 **각 플랫폼(Windows, Mac, PS, Xbox 등)** 과 **언어별(English, Korean 등)** 로 사운드 데이터를 관리할 수 있게 해줍니다.

---

### 🗂 SoundBank 선택하기

- **Default Work Unit**을 선택합니다.
  - Work Unit은 Wwise 프로젝트의 논리적 단위로, 관련 SoundBank를 묶어 관리할 수 있습니다.
- **두 개의 SoundBank 선택:**
  1. `Main` SoundBank
  2. `dcp_the_core` SoundBank

이 두 SoundBank는 이전 단계에서 각각

- 공통 이벤트용(Main)
- 레벨 전용 이벤트용(dcp_the_core)
  으로 설정된 것입니다.

---

### 💻 플랫폼 및 언어 선택

- 사용하는 운영체제에 따라 선택:
  - Windows 사용자는 **Windows**
  - Mac 사용자는 **Mac**
- 그 다음 언어를 **English (US)** 로 선택합니다.

> 📝 Note
>
> - Wwise는 다국어 음성을 지원하지만,
>   이번 프로젝트에서는 영어만 사용합니다.

---

## 3. SoundBank 생성(Generate) 과정 이해하기

### ⚙️ SoundBank 생성 시작

- SoundBank Manager 오른쪽 상단의 **[Generate Checked]** 버튼을 클릭합니다.

→ 선택한 SoundBank들이 실제 파일로 변환되는 과정이 시작됩니다.

---

### 💡 Generate All vs Generate Checked

- **Generate All**
  - 모든 플랫폼과 언어의 SoundBank를 한 번에 생성합니다.
  - 시간이 오래 걸리므로, 현재 작업 중인 플랫폼만 필요할 때는 비효율적입니다.
- **Generate Checked**
  - 현재 선택한 플랫폼(예: Windows)과 언어(예: English)에 대해서만 생성합니다.
  - 대부분의 실습이나 테스트에서는 이 옵션을 사용합니다.

---

### 🔄 Generating SoundBanks 대화상자

- 이 창에서는 Wwise가 SoundBank를 생성하는 **실시간 처리 과정을 시각적으로 보여줍니다.**
  - Event와 연결된 모든 오디오 애셋을 찾고
  - 각 애셋을 게임이 읽을 수 있는 형식으로 변환
  - 해당 데이터를 SoundBank 파일로 묶어 저장

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380554/notion-blog/_/WWISE/Wwise_/18_SoundBank_/image_5.png)

---

### 📁 저장 위치

- SoundBank는 자동으로 **게임에서 사용하는 폴더** (예: `\GeneratedSoundBanks\Windows`) 에 저장됩니다.
- 이 폴더는 **Cube 게임 실행 시 Wwise 사운드를 불러오는 경로**로 연결됩니다.

---

### ✅ 완료 후

- 변환이 끝나면 대화상자 하단의 **[Close]** 버튼을 클릭해 닫습니다.

## 4. 생성된 사운드 테스트하기

이제 SoundBank가 성공적으로 만들어졌는지 직접 테스트합니다.

### 🎧 Event 재생 테스트

1. **Event Viewer**를 엽니다.
2. `DCP_Signal02` Event를 선택합니다.
3. **스페이스 바(Space)** 를 눌러 재생합니다.

> 💡 팁
>
> DCP로 시작하는 다른 Event들도 재생해보세요.
>
> 이들은 모두 `dcp_the_core` SoundBank에 포함되어 있습니다.

---

### 🕹 Cube 게임 내 테스트

1. Cube 실행 → `Esc` 키를 눌러 메뉴를 엽니다.
2. 방향키를 이용해 다음 순서로 이동합니다:
   - **single player → start SP map → map dcp_the_core → Enter**
3. `dcp_the_core` 레벨이 로드됩니다.
4. 앞으로 이동하다가 **오른쪽 건물 안으로 들어가면**,

   문턱을 넘는 순간 `DCP_Signal02` 사운드가 재생됩니다.

> 🔊 이 소리가 들린다면,
>
> `dcp_the_core SoundBank`가 **정상적으로 로드되어 작동 중**임을 의미합니다.
