# **Redirect URI**

```jsx
프론트 localhost:3000에서 카카오 버튼을 클릭하면서 요청을 하는 거니 프론트 측 도메인과 code를 받을 path를 적으면 된다.

물론 아래처럼 /auth로 하게 되면 auth? code='인가코드'가 나오는 거고 localhost:3000으로 설정하시면 localhost:3000/? code='인가코드'로 나오게 된다.

개발 나름이겠지만 기본 '/'에서 하고 싶은 사람도 있고, 다른 페이지에서 인가코드를 받아서 처리하고 싶은 사람도 있다.

개발 방향에 따라서 설정하면 된다, 그리고 백엔드 도메인을 적는 게 아니다

*  쉽게 말하면 Redirect URI는 사용자가 로그인을 완료한 후에 돌아갈 주소를 나타낸다.

	 예를 들어, 사용자가 웹 페이지의 로그인 버튼을 누르고 로그인을 완료하면, 다시 그 웹 페이지로 돌아가야 한다.

	 이 때 Redirect URI를 설정하면 로그인 후에 자동으로 해당 웹 페이지로 이동하게 된다.
```

# **REST API 방식 컴포넌트 구현**

```jsx
카카오 개발자 - 앱 키 - REST API 키로 구현

위에서 설정한 내용으로 client_id에는 REST API와 redirect_uri에는 RedirectURI를 입력

https://kauth.kakao.com/oauth/authorize?client_id=${Rest_api_key}&
redirect_uri=${redirect_uri}&response_type=code

```

```jsx
const KakaoLogin = () => {
  const Rest_api_key = 'REST API KEY' //REST API KEY ( 내 Rest API KEY )
  const redirect_uri = 'http://localhost:3000/auth' //Redirect URI ( 아까 설정해둔거 )
  // oauth 요청 URL
  const kakaoURL = `https://kauth.kakao.com/oauth/authorize?client_id=${Rest_api_key}&redirect_uri=${redirect_uri}&response_type=code`
  const handleLogin = () => {
    window.location.href = kakaoURL
  }
  return (
    <>
      <button onClick={handleLogin}>카카오 로그인</button>
    </>
  )
}

export default KakaoLogin
```

# 인가 코드 추출

```jsx
인가코드 추출 방법은 new URL()을 사용하여 추출하면 된다

const code = new URL(window.location.href).searchParams.get("code");

window.location.href: 현재 페이지의 URL을 나타내는 JavaScript의 내장 객체이다. 이를 통해 현재 페이지의 URL을 가져올 수 있다.

new URL(window.location.href): window.location.href에서 가져온 URL 문자열을 사용하여 새로운 URL 객체를 생성한다. 이 객체를 사용하면 URL을 구문 분석하고 필요한 정보를 추출할 수 있다.

.searchParams: URL의 쿼리 문자열 부분을 나타내는 URLSearchParams 객체에 접근한다. 이를 통해 쿼리 매개변수를 추출할 수 있다.

.get("code"): URLSearchParams 객체의 get 메서드를 사용하여 특정 쿼리 매개변수의 값을 가져온다. 여기서 "code"는 쿼리 문자열에서 추출하려는 매개변수 이름이다.

따라서 위의 코드는 현재 페이지의 URL에서 "code"라는 이름의 쿼리 매개변수의 값을 추출하여 code 변수에 할당한다. 이를 통해 페이지 URL에서 "code" 매개변수의 값을 가져올 수 있다
```

```jsx
여기까지 프론트에서 처리할 과정은 끝났다.
```

# 인가 코드 서버로 전달하기

```jsx
이제 받아온 인가 코드를 서버로 전달해야 하는데

위의 주소 /Auth 로 이동하는 라우터를 App.js 에 작성해주고

아래와 같이 컴포넌트를 만들어서 이동하도록 해준다

아래 컴포넌트는 받아온 인가코드를 추출해서 서버에 post 로 요청을 보내준다

( 이후 서버에서 토큰을 받아오면서 응답이 성공하면 / 로 이동하게 한다
```

```jsx
import React, { useEffect } from 'react'
import { useLocation } from 'react-router-dom'
import { toast } from 'react-toastify'
import Loader from '../Layout/Loader'
import axios from 'axios'

const AuthCallback = () => {
  const location = useLocation()

  useEffect(() => {
    const urlParams = new URLSearchParams(location.search)
    const authorizationCode = urlParams.get('code')

    const sendDataToServer = async () => {
      try {
        const response = await axios.post(
          process.env.REACT_APP_BACKEND_URL + `/auth/kakao`,
          { code: authorizationCode },
          { withCredentials: true }
        )
        console.log('받아온 유저 정보', response.data)
        window.location.replace('/')
        toast.success('로그인 성공!')
      } catch (error) {
        console.error(error)
      }
    }

    sendDataToServer() // 함수 호출하여 서버로 데이터 전송
  }, [location.search])

  return (
    <div>
      <Loader />
    </div>
  )
}

export default AuthCallback
```

# auth 컨트롤러 작성

```jsx
위의 프론트에서 인가 코드를 받아서 서버의 아래 라우터로 전달해준다

그럼 서버는 이 인가 코드를 받아서 카카오로 액세스 토큰을 요청하고 토큰 결과를 받아오게 된다 ( kakaoToken )

( "https://kauth.kakao.com/oauth/token", 이 주소가 카카오 서버에서 인가 코드를 통해서 토큰을 받아오는 주소이다 )

그럼 받아온 토큰을 이용해서 카카오 서버에 사용자 정보를 요청하고 사용자 프로필 정보를 받아온다

( https://kapi.kakao.com/v2/user/me 이 주소가 토큰을 이용해서 사용자 정보를 받아오는 카카오 서버이다 )

이후 카카오 서버에서 받아온 email 을 기반으로 사용자가 있는지 확인하고 사용자가 있다면 사용자 정보 저장은 건너뛰고 엑세스 토큰을 발행해주고

사용자가 없다면 사용자 정보를 저장하고 엑세스 토큰을 발급해준다
```

```jsx
const express = require('express')
const router = express.Router()
const axios = require('axios')
const User = require('../model/user')
const sendToken = require('../util/jwtToken')

// 카카오 토큰 요청 및 사용자 정보 조회 핸들러
router.post('/kakao', async (req, res, next) => {
  const { code } = req.body // 프론트엔드에서 받은 인가 코드
  const restApiKey = '965a71a94f58405c10e1712ce59b83bd' // 카카오 앱의 REST API 키

  const data = {
    grant_type: 'authorization_code',
    client_id: restApiKey,
    code,
  }
  ㅋ
  // 헤더 설정
  const header = {
    'Content-Type': 'application/x-www-form-urlencoded;charset=utf-8',
    Authorization: 'Bearer ',
  }

  // grant_type=authorization_code&client_id=your_client_id&code=authorization_code_here
  // 위와 같이 문자열 형태로 구성하기 위해
  const queryString = Object.keys(data)
    .map((k) => encodeURIComponent(k) + '=' + encodeURIComponent(data[k]))
    .join('&')

  try {
    const kakaoToken = await axios.post('https://kauth.kakao.com/oauth/token', queryString, {
      headers: header,
    })

    console.log(kakaoToken)

    // 카카오 토큰을 사용하여 사용자 정보 조회
    const getUserInfo = async (accessToken) => {
      const header = {
        Authorization: `Bearer ${accessToken}`,
      }

      const get = await axios.get('https://kapi.kakao.com/v2/user/me', {
        headers: header,
      })
      const result = get.data
      console.log('카카오 사용자 정보 결과', result)

      return {
        id: result.id,
        nickname: result.kakao_account.profile.nickname,
        email: result.kakao_account.email,
        avatar: result.kakao_account.profile.profile_image_url,
      }
    }

    // 임시 비밀번호 생성 함수
    function generateRandomPassword() {
      const length = 10 // 비밀번호 길이
      const charset = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789' // 사용할 문자셋
      let password = ''
      for (let i = 0; i < length; i++) {
        const randomIndex = Math.floor(Math.random() * charset.length)
        password += charset[randomIndex]
      }
      return password
    }

    // 토큰 정보와 사용자 정보를 합쳐서 클라이언트에게 응답
    const userInfo = await getUserInfo(kakaoToken.data.access_token)

    // 사용자 이메일을 통해 데이터베이스에서 사용자 조회
    let user = await User.findOne({ email: userInfo.email })

    // 사용자가 데이터베이스에 존재하지 않으면 새로운 사용자로 저장
    if (!user) {
      user = new User({
        name: userInfo.nickname,
        email: userInfo.email,
        password: generateRandomPassword(),
      })
      await user.save()
    }

    // 클라이언트에게 응답 ( 토큰 발급해주기 )
    sendToken(user, 201, res)
  } catch (error) {
    console.error(error)
    res.status(500).json({ error: 'Internal server error' }) // 에러 발생 시 클라이언트에게 에러 전송
  }
})

module.exports = router
```
