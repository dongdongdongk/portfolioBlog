# for in 과 for of

```jsx
for...in은 주로 객체의 속성을 순회할 때 사용하고, for...of은 주로 배열이나 iterable 객체의 요소를 순회할 때 사용

( 요즘은 거진 for of 만 쓰인다 )

* iterable : 여러 값을 가진 객체 중에서 하나씩 값을 꺼내어 처리할 수 있는 객체를 의미 ( 객체는 iterable 이 아님 예를들어 문자열, 배열 )
```

# for in

```jsx
* for...in 반복문은 객체의 속성을 열거할 때 사용

* 이 반복문은 객체의 프로퍼티를 열거하면서 반복한다.
```

## 예제

### **객체의 속성 출력**

```jsx
const person = {
  name: "John",
  age: 30,
  city: "Seoul",
};

for (const key in person) {
  console.log(key + ": " + person[key]);
}

* 결과

name: John
age: 30
city: Seoul
```

```jsx
for...in 반복문은 객체 person의 속성을 모두 순회

key 변수에는 각 속성의 키가 할당되고, person[key]를 통해 각 속성의 값을 출력
```

### **배열의 인덱스 출력**

```jsx
const colors = ["red", "green", "blue"];

for (const index in colors) {
  console.log("인덱스: " + index + ", 값: " + colors[index]);
}

 * 결과

인덱스: 0, 값: red
인덱스: 1, 값: green
인덱스: 2, 값: blue
```

```jsx
for...in 반복문은 배열 colors의 인덱스를 순회

각 인덱스에 해당하는 배열의 값을 출력
```

### **문자열의 글자 수 출력**

```jsx
const sentence = "안녕하세요";

for (const index in sentence) {
  console.log("인덱스: " + index + ", 글자: " + sentence[index]);
}

* 결과

인덱스: 0, 글자: 안
인덱스: 1, 글자: 녕
인덱스: 2, 글자: 하
인덱스: 3, 글자: 세
인덱스: 4, 글자: 요
```

```jsx
for...in 반복문을 사용하여 문자열 sentence의 각 글자를 순회

각 인덱스에 해당하는 문자를 출력
```

# for of

```jsx
* for...of 반복문은 반복 가능한(iterable) 객체를 순회할 때 사용

* 주로 배열이나 문자열과 같은 iterable 객체에서 사용
```

### **배열의 요소 출력**

```jsx
const colors = ["red", "green", "blue"];

for (const color of colors) {
  console.log(color);
}

* 결과

red
green
blue
```

```jsx
for...of 반복문은 배열 colors의 각 요소를 직접 순회

각 루프에서 color 변수에는 배열의 현재 요소가 할당되고, 이를 출력
```

### **문자열의 글자 출력**

```jsx
const sentence = "안녕하세요";

for (const char of sentence) {
  console.log(char);
}

* 결과

안
녕
하
세
요
```

```jsx
for...of 반복문은 문자열 sentence의 각 글자를 직접 순회

각 루프에서 char 변수에는 문자열의 현재 글자가 할당되고, 이를 출력
```

### **Map 객체의 값 출력**

```jsx
const myMap = new Map();
myMap.set("one", 1);
myMap.set("two", 2);
myMap.set("three", 3);

for (const [key, value] of myMap) {
  console.log(key + ": " + value);
}

* 결과

one: 1
two: 2
three: 3
```

```jsx
for...of 반복문은 Map 객체 myMap의 각 항목을 순회

각 루프에서 배열 디스트럭처링을 사용하여 key와 value에 각각 키와 값이 할당되고, 이를 출력
```

### Object.values()로 객체의 값들 배열로 얻기

```jsx
const person = {
  name: "John",
  age: 30,
  city: "Seoul",
};

// Object.values()를 사용하여 객체의 값들을 배열로 얻기
const valuesArray = Object.values(person);

// for...of를 사용하여 배열의 각 값을 순회하면서 출력
for (const value of valuesArray) {
  console.log(value);
}

* 결과

John
30
Seoul
```

```jsx
이 예제에서 Object.values(person)는 person 객체의 값들을 배열로 반환

그리고 for...of 반복문을 사용하여 이 배열의 각 값을 순회하면서 출력
```
