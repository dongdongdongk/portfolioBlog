## 🔑 해결책: Delta Time

### Delta Time이란?

```
Delta Seconds (Delta Time)
  = 이전 프레임 이후 경과 시간
  ↓
프레임 사이의 시간!
```

### 작동 원리

```
고 FPS (빠름):
  └─ Delta Time: 작음 (0.008초)

저 FPS (느림):
  └─ Delta Time: 큼 (0.033초)
```

---

## 💡 Delta Time 적용

### 공식

```
이동량 = 방향 × 속도 × Delta Time
  ↓
프레임 속도 보정!
```

### 왜 작동하나?

### 시나리오 1: 고 FPS

```
속도: 100 유닛/초
Delta: 0.008초
  ↓
이동: 100 × 0.008 = 0.8 유닛
  ↓
1초에 125번 실행
  ↓
총: 0.8 × 125 = 100 유닛/초 ✅
```

### 시나리오 2: 저 FPS

```
속도: 100 유닛/초
Delta: 0.033초
  ↓
이동: 100 × 0.033 = 3.3 유닛
  ↓
1초에 30번 실행
  ↓
총: 3.3 × 30 = 100 유닛/초 ✅
```

## 📐 수학적 이해

### 공식 정리

```
이동 거리 = 속도 × 시간
  ↓
Distance = Speed × Time
  ↓
Delta Location = Speed × Delta Time
```

### 예시

```
속도: 100 유닛/초
시간: 0.016초 (60 FPS)
  ↓
이동: 100 × 0.016 = 1.6 유닛
```

# { Rotator - 회전 정보 저장 }

## 🎯 Rotator란?

```
Vector = 위치/방향
Rotator = 회전
  ↓
3가지 회전 정보 저장:
  ├─ Roll (굴림)
  ├─ Pitch (피치)
  └─ Yaw (요)
```

---

## ✈️ 비행기로 이해하기

### 비행기의 로컬 축

```
       ↑ Z (위)
       |
       |
  ←────●────→ Y (오른쪽)
      /
     / X (앞)
    ↙

X축: Forward (앞)
Y축: Right (오른쪽)
Z축: Up (위)
```

---

## 🔄 3가지 회전

### 1️⃣ Yaw (요) - Z축 회전

### 평면도 (위에서 봄)

```
    위에서 본 모습
        ↑ X
        |
    ←───●───→ Y
        |
      (Z축 보임)

Z축 중심으로 회전
  ↓
좌우로 회전! ◀▶
```

### 예시

```
비행기: 좌우로 방향 전환
사람: 고개 좌우로 흔들기 (No!)
  ↓
"아니요" 하는 동작
```

---

### 2️⃣ Pitch (피치) - Y축 회전

### 측면도 (옆에서 봄)

```
    옆에서 본 모습
        ↑ Z
       /
      /
     ●────→ X
     |
   (Y축 보임)

Y축 중심으로 회전
  ↓
위아래로 회전! ▲▼
```

### 예시

```
비행기: 기수 위아래로 기울임
사람: 고개 위아래로 끄덕임 (Yes!)
  ↓
"네" 하는 동작
```

---

### 3️⃣ Roll (롤) - X축 회전

### 정면도 (앞에서 봄)

```
    앞에서 본 모습
        ↑ Z
        |
    ←───●───→ Y
      (X축 보임)

X축 중심으로 회전
  ↓
좌우로 기울기! ↶↷
```

### 예시

```
비행기: 좌우로 기울임 (배럴롤)
사람: 고개 좌우로 갸우뚱
  ↓
"잘 모르겠어요" 하는 동작
```

---

## 📊 회전 요약표

```
┌──────┬────────┬────────┬────────────┐
│ 이름 │   축   │  동작  │    예시    │
├──────┼────────┼────────┼────────────┤
│ Yaw  │ Z축 ↕  │ 좌우   │ 고개 No    │
│Pitch │ Y축 ←→ │ 위아래 │ 고개 Yes   │
│ Roll │ X축 ⊙  │ 기울기 │ 갸우뚱     │
└──────┴────────┴────────┴────────────┘
```

## 🧭 각 축 중심 회전 이해

### Yaw (Z축)

```
Z축을 중심으로 빙글빙글
  ↓
    ⟲
   ╱│╲
  ╱ │ ╲
 ╱  Z  ╲

수평 회전!
```

### Pitch (Y축)

```
Y축을 중심으로 앞뒤
  ↓
    ⤴
    |
  ──●──
    |
    ⤵

상하 회전!
```

### Roll (X축)

```
X축을 중심으로 굴림
  ↓
    ↶
  ──●──→
    ↷

측면 회전!
```

## 📐 Rotator 구조

### 데이터 타입

```
Rotator = (Roll, Pitch, Yaw)
  ├─ Roll: X축 회전 (도)
  ├─ Pitch: Y축 회전 (도)
  └─ Yaw: Z축 회전 (도)
```

### 단위

```
각도 = Degrees (도)
  ├─ 0° ~ 360°
  └─ 음수도 가능
```

  Rotator = (0, 0, 45)

## 🎯 Vector vs Rotator

```
Vector (노란색):
  ├─ X, Y, Z (위치/방향)
  ├─ 크기 있음
  └─ 정규화 가능

Rotator (파란색):
  ├─ Roll, Pitch, Yaw (회전)
  ├─ 각도 (도)
  └─ -180° ~ 180°
```

## ⚠️ 자주 하는 실수

### 실수 1: Component에 World 노드

```
[DronMesh] → [Add Actor World Rotation]
  ↓
타입 불일치! ❌
```

### 해결

```
[DronMesh] → [Add Local Rotation]
  ↓
타입 맞음! ✅
```

### 실수 2: Component 이동 vs Actor 이동

```
Details에서 Component 선택 이동
  ↓
Actor 안 움직임!
Component만 Offset!
```

### 주의

```
Actor 이동:
  └─ Outliner에서 선택

Component 이동:
  └─ Details → Components 선택
```
