## TabPage 속성(preload)을 이용한 로딩 undefind 해결하기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381504/notion-blog/_/_/_/03_/Untitled_30.png)

```java
탭은 사용할 때 url 을 불러와서 로딩하는 방식을 쓴다 ( 효율적 )

그러나 로딩 속도가 느려 undefind 가 뜨는 경우가 있다

이럴때 tab 속성에서 preload 를 true 로 해주면 이 문제를 해결 가능하다 (true 로 바꿀시 tab페이지 를 모두 불러와야 로딩이 끝나기 때문에 undefind 가 뜨지 않는다)

(로딩 속도에 문제를 줄 수 있기 때문에 preload 는 기본 false 로 두도록 하자)
```
