# { Next.js와 React 폴더 구조, 서버 액션, formAction의 차이 }

## 1. 서버 액션이란 무엇인가?

```jsx
✅ 정의 (쉽게)

		서버 액션(Server Actions) 은 React와 Next.js에서 지원하는 기능으로,

				서버에서 실행되는 함수를 정의하고

				그 함수를 폼(form) 제출 또는 클라이언트 요청과 연결할 수 있는 기능입니다.

✅ 무엇이 다른가?

		전통적으로:

				클라이언트에서 form 데이터를 받아서

				fetch나 axios로 API 라우트(예: /api/posts)에 POST 요청을 보내고

				서버에서 처리하는 과정을 거쳤습니다.


		서버 액션을 사용하면:

				클라이언트에서 API 요청을 작성하지 않아도

				form action으로 직접 서버에서 실행될 함수를 지정할 수 있습니다.

				Next.js가 이 과정을 자동으로 처리하여 코드를 간결하게 만듭니다.

✅ 결론적으로

		서버 액션 = 서버에서 실행할 수 있는 함수를 클라이언트의 form action으로 직접 연결하는 기술
```

## 2. Next.js에서 서버 액션 사용 예제

```jsx
아래 코드는 app/new-post/page.js 파일의 예시로,

		1. 폼 제출 시 createPost 함수가 서버에서 실행되도록 작성했습니다.

		2. 모든 코드에 상세 주석을 달았습니다.
```

```jsx
// Next.js의 페이지 컴포넌트입니다.
export default function NewPostPage() {
  // createPost 함수는 서버에서 실행됩니다.
  // async function 앞에 'use server' 지시어를 추가하면
  // 이 함수가 클라이언트가 아닌 서버에서 실행됩니다.
  async function createPost(formData) {
    'use server' // ✅ 이 지시어가 있으면 Next.js가 서버 액션으로 처리합니다.

    // formData.get('name')으로 각 입력값을 가져옵니다.
    const title = formData.get('title')
    const image = formData.get('image')
    const content = formData.get('content')

    // 콘솔에 출력해보면 서버 터미널에 표시됩니다.
    console.log('서버에서 실행됨:', title, image, content)

    // 여기서 데이터베이스에 저장하거나
    // 외부 API에 전송하거나
    // 파일을 업로드하는 로직을 작성할 수 있습니다.
    //
    // 예:
    // await db.posts.create({ title, image, content });
  }

  // 페이지 JSX를 반환합니다.
  return (
    <>
      <h1>Create a new post</h1>

      {/* 
        form의 action 속성에 createPost 함수를 전달합니다.
        서버 액션 기능 덕분에, 이 함수가 서버에서 실행됩니다.
      */}
      <form action={createPost}>
        {/* 제목 입력 */}
        <p className="form-control">
          <label htmlFor="title">Title</label>
          <input type="text" id="title" name="title" />
        </p>

        {/* 이미지 업로드 입력 */}
        <p className="form-control">
          <label htmlFor="image">Image</label>
          <input type="file" accept="image/png, image/jpeg" id="image" name="image" />
        </p>

        {/* 콘텐츠 입력 */}
        <p className="form-control">
          <label htmlFor="content">Content</label>
          <textarea id="content" name="content" rows="5" />
        </p>

        {/* 제출 및 리셋 버튼 */}
        <p className="form-actions">
          <button type="reset">Reset</button>
          <button type="submit">Create Post</button>
        </p>
      </form>
    </>
  )
}
```

## 3. 주요 정리

```jsx
✅ 서버 액션을 위한 조건

		'use server' 지시어를 함수 맨 위에 작성해야 합니다.

		app router (app 디렉토리 기반) 에서만 작동합니다.

		클라이언트 측의 fetch 없이도 서버에서 실행됩니다.

✅ form action에 함수를 넣으면

		Next.js는 자동으로

				브라우저의 기본 제출 동작을 방지하고

				해당 함수를 서버에서 실행되도록 처리합니다.

✅ 이미지 업로드의 경우

		input type="file" 로 업로드한 파일은

				formData.get('image')에서 File 객체로 얻어집니다.

		S3, Firebase Storage, Supabase Storage 등에 업로드하는 로직을 추가하면 됩니다.


✅ formAction vs 서버 액션
```

| 구분              | formAction                    | 서버 액션                   |
| ----------------- | ----------------------------- | --------------------------- |
| 실행 위치         | 클라이언트                    | 서버                        |
| 기능              | 클라이언트에서 함수 실행      | 서버에서 함수 실행          |
| Next.js 필요 여부 | React 자체 기능 (아직 실험적) | Next.js에서 unlock되어 작동 |
| 예                | formAction={myClientFunction} | action={myServerFunction}   |

## 4. 서버 액션의 장점

```jsx
1. API 라우트를 별도로 만들지 않아도 된다.

2. 클라이언트 fetch 코드가 필요 없다.

3. 서버에서 바로 DB 처리 가능하다.

4. 코드가 간결해지고 유지보수가 쉬워진다.
```
