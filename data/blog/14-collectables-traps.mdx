## 3️⃣ **Collectables 객체 생성 및 게임에 추가**

### 📌 **Collectables를 Phaser의 그룹(Group)으로 관리**

```jsx
수집 아이템을 Static Group으로 만들어 배치합니다.
```

```jsx
createCollectables(collectableLayer) {
    // 물리 엔진을 사용하여 정적인(움직이지 않는) 그룹을 생성합니다.
    const collectables = this.physics.add.staticGroup();

    // `collectableLayer`는 타일맵(Tiled)에서 가져온 'collectables' 레이어입니다.
    // 이 레이어에 있는 모든 오브젝트를 반복문을 통해 순회합니다.
    collectableLayer.objects.forEach(collectable => {
        // `collectables.get(x, y, 'diamond')`
        // - `get` 메서드는 그룹에서 기존의 비활성화된 오브젝트를 찾거나, 없으면 새로 생성합니다.
        // - X, Y 좌표를 설정하여 다이아몬드 이미지를 해당 위치에 배치합니다.
        // - 'diamond'는 사전에 로드된 이미지의 키(key)입니다.
        collectables.get(collectable.x, collectable.y, 'diamond')
            .setDepth(-1); // 깊이(Depth)를 설정하여 플레이어보다 뒤쪽에 배치되도록 합니다.
    });

    // 생성된 collectables 그룹을 반환하여 나중에 게임에서 사용할 수 있도록 합니다.
    return collectables;
}

```

```jsx
📌 작동 방식:

1. this.physics.add.staticGroup() → 정적인 그룹(Static Group)을 생성

2. 각 collectable을 가져와 그룹에 추가

		collectables.get(collectable.x, collectable.y, 'diamond')

		setDepth(-1) → 배경보다 뒤쪽에 배치

💡 핵심 개념:

		Static Group: 움직이지 않는 물체를 배치하는 데 사용 (플레이어와 충돌 가능)

		setDepth(-1): 다이아몬드를 플레이어보다 뒤에 배치
```

```jsx
get 메서드
```

## 플레이어와 수집품의 충돌 감지

```jsx
이제 플레이어가 수집품을 획득하도록 설정해야 합니다.

Phaser에서는 overlap을 사용하여 두 개체가 겹칠 때 특정 동작을 실행할 수 있어요.
```

```jsx
// createPlayerColliders 함수는 플레이어와 다양한 객체들 간의 충돌 및 겹침을 처리하는 함수입니다.
createPlayerColliders(player, { colliders }) {
    // 플레이어와 플랫폼 충돌 처리
    player
        // 플랫폼과 충돌을 처리합니다. (플랫폼에서 떨어지지 않도록 하고, 플레이어가 땅 위에 있을 수 있게 만듭니다)
        .addColliders(colliders.platformsColliders)

        // 적의 총알과 충돌할 때, 총알이 플레이어에 닿으면 onWeaponHit 함수를 실행합니다.
        .addColliders(colliders.projectiles, this.onWeaponHit)

        // 수집품과 겹칠 때 onCollect 함수를 실행하여 수집품을 획득할 수 있도록 합니다.
        .addOverlap(colliders.collectables, this.onCollect);
}
```

```jsx
addColliders(colliders.platformsColliders) : 플레이어가 플랫폼과 충돌하도록 설정

addColliders(colliders.projectiles, this.onWeaponHit) : 적의 공격을 플레이어가 맞으면 onWeaponHit 함수 실행

addOverlap(colliders.collectables, this.onCollect) : 플레이어가 수집품과 겹치면 onCollect 함수 실행
```

## 4. 애니메이션이 적용되지 않는 문제 해결

```jsx
문제 발생 원인

		우리는 createCollectables 함수에서 다이아몬드(diamond)를 생성한 후,

		playAnimation('diamond-shine')을 호출하여 애니메이션을 적용하려고 했습니다.

		하지만 실행해보니 애니메이션이 적용되지 않는 문제가 발생했습니다.

		이유는 애니메이션이 아직 등록되지 않았기 때문입니다.

		즉,

		createCollectables 함수가 실행될 때 다이아몬드가 먼저 생성됩니다.

		하지만 애니메이션(diamond-shine)은 아직 존재하지 않음

		따라서 "Missing animation diamond-shine" 오류 발생

정리

		애니메이션을 적용하려면 먼저 등록한 후 객체를 생성해야 한다.

		initAnims(this.anims);를 createCollectables를 호출하기 전에 실행하면 해결됨.

		순서를 올바르게 설정하면 diamond-shine 애니메이션이 정상적으로 적용됨. 🚀
```

```jsx
create() {
    const map = this.createMap();
    initAnims(this.anims);  // 애니메이션을 먼저 초기화
    const layers = this.createLayers(map);
    const playerZones = this.getPlayerZones(layers.playerZones);
    const player = this.createPlayer(playerZones.start);
    const enemies = this.createEnemies(layers.enemySpawns, layers.platformsColliders);
    const collectables = this.createCollectables(layers.collectables);
}
```

## 1. Collectible을 별도의 파일로 분리하기

```jsx
Collectible을 관리하기 위해 collectables/Collectable.js 파일을 새로 만들고,

Phaser의 Arcade.Sprite를 확장하여 클래스를 생성합니다.
```

```jsx
import Phaser from 'phaser'

class Collectable extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key) // Phaser의 Sprite 클래스를 상속

    scene.add.existing(this) // 현재 씬에 이 Collectible(스프라이트)을 추가

    this.score = 1 // 기본 점수는 1점으로 설정

    // Tween 애니메이션 추가
    scene.tweens.add({
      targets: this, // 애니메이션을 적용할 대상 (Collectable)
      y: this.y - 3, // Y축으로 3픽셀 위로 이동
      duration: Phaser.Math.Between(1500, 2500), // 1.5초 ~ 2.5초 랜덤 지속 시간
      repeat: -1, // 무한 반복
      ease: 'Linear', // 속도 일정하게 유지
      yoyo: true, // 위로 갔다가 다시 아래로 돌아오는 효과
    })
  }
}

export default Collectable
```

## 2. Tween 애니메이션을 적용하는 방식

```jsx
Tween을 사용하여 Collectible이 부드럽게 위아래로 움직이는 효과를 줍니다.

💡 Tween이란? Phaser에서 객체를 특정 방향으로 이동시키거나 변화를 줄 때 사용하는 애니메이션 기능입니다.
```

### 🚀 Tween의 주요 설정값

### 애니메이션 동작 방식

```jsx
1. Collectible이 기본 위치에서 Y축으로 3픽셀 위로 이동

2. 랜덤한 시간(1.5초 ~ 2.5초) 동안 이동

3. yoyo 옵션이 활성화되어 다시 원래 위치로 돌아옴

4. 무한 반복 (-1 설정으로 반복)

5. 각 Collectible마다 이동 속도가 다르게 설정됨 → 자연스럽게 떠 있는 효과 생성
```

### Collectible을 생성하는 함수 추가

```jsx
아래 코드에서 createCollectables 함수는 게임의 특정 위치에 Collectible을 배치하고, 그룹화하여 관리합니다.
```

```jsx
createCollectables(collectableLayer) {
    // 정적인(움직이지 않는) 그룹을 생성하고, 깊이(depth)를 -1로 설정하여 배경보다 앞에 오도록 함
    const collectables = this.physics.add.staticGroup().setDepth(-1);

    // collectableLayer에 정의된 모든 수집 아이템(예: 다이아몬드)을 하나씩 처리
    collectableLayer.objects.forEach(collectable => {
        // Collectable 클래스를 사용하여 새로운 수집 아이템을 생성하고 그룹에 추가
        collectables.add(new Collectable(this, collectable.x, collectable.y, 'diamond'));
    });

    // 그룹 내 모든 수집 아이템에 'diamond-shine' 애니메이션을 적용하여 반짝이는 효과 추가
    collectables.playAnimation('diamond-shine');

    // 생성된 수집 아이템 그룹을 반환하여 다른 곳에서도 사용할 수 있도록 함
    return collectables;
}

```

```jsx
1. staticGroup()을 이용해 Collectible 그룹을 생성

2. collectableLayer.objects.forEach(...)

→ collectableLayer에 있는 모든 오브젝트를 반복하며, 각 위치에 Collectible을 추가
```

### Collectables.js

```jsx
// Phaser 모듈을 가져옴 (게임 개발을 위한 라이브러리)
import Phaser from 'phaser'

// Collectable 클래스를 가져옴 (수집 가능한 아이템을 나타내는 클래스)
import Collectable from '../collectables/Collectable'

/**
 * Collectables 그룹 클래스 (Phaser의 StaticGroup을 상속받음)
 * - 여러 개의 Collectable 객체를 관리하는 그룹
 * - StaticGroup은 물리 엔진을 사용하지만, 움직이지 않는(static) 객체들을 위한 그룹
 */
class Collectables extends Phaser.Physics.Arcade.StaticGroup {
  /**
   * 생성자(Constructor)
   * @param {Phaser.Scene} scene - Collectables 그룹을 생성할 씬(Scene)
   */
  constructor(scene) {
    // 부모 클래스(StaticGroup)의 생성자 호출
    // scene.physics.world → 현재 씬의 물리(world) 시스템을 가져옴
    // scene → Collectables 그룹이 속할 씬
    super(scene.physics.world, scene)

    // 그룹의 설정을 지정하는 메서드
    this.createFromConfig({
      classType: Collectable, // 그룹 내에서 생성될 객체의 클래스 타입을 Collectable로 지정
    })
  }
}

// Collectables 클래스를 내보내서 다른 파일에서 사용할 수 있도록 함
export default Collectables
```

```jsx
createFromConfig() 메서드를 사용하여 Collectable 클래스 타입을 설정하면,

get() 호출 시 자동으로 Collectable 인스턴스가 생성됨.

이렇게 하면 PlayScene에서 직접 new Collectable()을 호출할 필요가 없음.
```

## 1. Collectables 그룹에서 Layer 속성 추출

### 기존 문제점

```jsx
Collectables 그룹에서 Collectable 객체를 추가할 때, 개별 객체의 속성을 고려하지 않음.

Layer 전체에 적용되는 속성(예: 기본 점수)을 객체에 반영할 수 있도록 개선 필요.
```

### 해결 방법

```jsx
Layer 전체의 속성을 하나의 객체(Map)로 변환하여 다루기 쉽게 만든다.

속성을 key-value 형태로 변환하여 프로그래밍적으로 접근 가능하게 한다.
```

## 1.1 Layer 속성을 객체(Map) 형태로 변환

```jsx
1️⃣ mapProperties() 함수 추가

Layer의 속성 배열을 { 속성이름: 값 } 형태의 객체로 변환하는 함수.
```

```jsx
mapProperties(propertiesList) {
    // 만약 propertiesList가 존재하지 않거나, 빈 배열이라면 undefined를 반환하고 종료
    if (!propertiesList || propertiesList.length === 0) {
        return;
    }

    // propertiesList 배열을 객체(Map) 형태로 변환
    return propertiesList.reduce((map, obj) => {
        // 각 속성 객체(obj)의 name을 key로, value를 value로 저장
        map[obj.name] = obj.value;
        return map; // 변환된 객체(Map)를 다음 순회에서도 유지
    }, {}); // 초기값은 빈 객체 {}
}
```

```jsx
reduce()를 활용한 변환 과정

		propertiesList는 배열 형태이며, 각 요소는 { name: "속성이름", type: "타입", value: 값 } 구조.

		reduce()를 사용하여 { 속성이름: 값 } 형태의 객체(Map)으로 변환.
```

### 예제 변환 과정

```jsx
;[
  { name: 'score', type: 'int', value: 1 },
  { name: 'type', type: 'string', value: 'diamond' },
]
```

```jsx
⬇ 변환 후

{
    "score": 1,
    "type": "diamond"
}
```

### 2️⃣ `addFromLayer()` 함수 수정

```jsx
addFromLayer(layer) {
    // layer의 properties(속성 리스트)를 객체(Map) 형태로 변환
    const properties = this.mapProperties(layer.properties);

    // layer의 objects(객체 리스트)를 하나씩 순회하며 처리
    layer.objects.forEach(collectable => {
        // collectable 객체의 (x, y) 좌표에 properties.type 타입의 객체를 추가
        this.get(collectable.x, collectable.y, properties.type);
    });
}
```
