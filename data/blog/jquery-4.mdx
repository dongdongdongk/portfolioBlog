## 1. jQuery란?

jQuery는 JavaScript를 더 쉽고 짧게 쓸 수 있게 해주는 라이브러리입니다.

| 순수 JavaScript                         | jQuery                |
| --------------------------------------- | --------------------- |
| `document.getElementById('btn')`        | `$('#btn')`           |
| `element.addEventListener('click', fn)` | `$('#btn').click(fn)` |

**장점**

- 코드가 훨씬 짧아진다
- 크로스 브라우저 호환성 자동 처리
- DOM 조작, 이벤트, Ajax가 쉬워진다

## 3. 기본 문법 구조

```jsx
// 핵심 패턴: $(선택자).동작();
$('#myId').hide()
$('.myClass').css('color', 'red')
```

### 문서 로드 후 실행 (필수 습관)

```jsx
// DOM이 준비된 후 코드를 실행 — 항상 이 안에 코드를 작성
$(document).ready(function () {
  // 여기에 코드 작성
  console.log('DOM 준비 완료!')
})

// 단축형 (더 많이 사용)
$(function () {
  console.log('DOM 준비 완료!')
})
```

> ⚠️ **주의**: `$(document).ready()` 없이 작성하면 HTML이 로드되기 전에 스크립트가 실행되어 오류가 생길 수 있습니다.

## 4. 선택자 (Selector)

HTML 요소를 가져오는 방법입니다. CSS 선택자와 거의 동일합니다.

### 기본 선택자

```jsx
$('p') // 모든 <p> 태그
$('#header') // id="header" 인 요소 (하나)
$('.btn') // class="btn" 인 모든 요소
$('*') // 모든 요소
```

### 복합 선택자

```jsx
$('div p') // div 안의 모든 p
$('div > p') // div 바로 아래의 p (직계 자식)
$('div, span') // div와 span 모두
$('#form input') // #form 안의 모든 input
```

### 속성 선택자

```jsx
$('input[type="text"]') // type이 text인 input
$('a[href^="https"]') // href가 https로 시작하는 a
$('a[href$=".pdf"]') // href가 .pdf로 끝나는 a
$('input[name="email"]') // name이 email인 input
```

### 위치/필터 선택자

```jsx
$('li:first') // 첫 번째 li
$('li:last') // 마지막 li
$('li:eq(2)') // 인덱스 2번 (3번째) li
$('li:even') // 짝수 번째 li (0, 2, 4...)
$('li:odd') // 홀수 번째 li (1, 3, 5...)
$('tr:nth-child(2)') // 2번째 tr
$('input:checked') // 체크된 input
$('input:disabled') // 비활성화된 input
$(':visible') // 현재 보이는 요소
$(':hidden') // 숨겨진 요소
```

### 선택자 예제

```html
<ul id="menu">
  <li class="item active">홈</li>
  <li class="item">소개</li>
  <li class="item">연락처</li>
</ul>
```

```jsx
$('#menu li') // ul#menu 안의 모든 li → 3개
$('.item.active') // class가 item이면서 active인 것 → 1개
$('#menu li:first') // 첫 번째 li → "홈"
$('#menu li').length // li 개수 → 3
```

## 5. DOM 조작

### 콘텐츠 읽기 / 쓰기

```jsx
// HTML 내용
$('#box').html() // 현재 HTML 읽기
$('#box').html('<b>새 내용</b>') // HTML 쓰기

// 텍스트 내용 (태그 제외)
$('#box').text() // 텍스트 읽기
$('#box').text('새 텍스트') // 텍스트 쓰기

// input 값
$('input').val() // 값 읽기
$('input').val('새 값') // 값 쓰기
```

### 속성(Attribute) 다루기

```jsx
// 속성 읽기/쓰기
$('img').attr('src') // src 값 읽기
$('img').attr('src', '/new-image.png') // src 값 쓰기
$('img').attr('alt', '이미지 설명') // alt 속성 추가
$('a').removeAttr('target') // 속성 제거

// data- 속성 (HTML5)
$('#item').data('id') // data-id 읽기
$('#item').data('id', '123') // data-id 쓰기
```

### 요소 추가/삽입

```jsx
$('#list').append('<li>끝에 추가</li>') // 마지막 자식으로 추가
$('#list').prepend('<li>앞에 추가</li>') // 첫 번째 자식으로 추가
$('#list').before('<p>list 앞에 삽입</p>') // 형제로 앞에 삽입
$('#list').after('<p>list 뒤에 삽입</p>') // 형제로 뒤에 삽입
```

### 요소 제거/복제

```jsx
$('#item').remove() // 요소 삭제 (이벤트도 함께 삭제)
$('#item').detach() // 요소 분리 (이벤트 유지 — 나중에 다시 붙일 때)
$('#item').empty() // 자식 요소만 삭제 (자신은 유지)
$('#item').clone() // 복제 (이벤트 미포함)
$('#item').clone(true) // 복제 (이벤트 포함)
```

### 탐색 (Traversal)

```jsx
$('#item').parent() // 바로 위 부모
$('#item').parents('div') // 모든 조상 중 div
$('#item').children() // 직계 자식 전체
$('#item').children('.active') // 직계 자식 중 .active
$('#item').find('span') // 자손 중 span 전체
$('#item').siblings() // 형제 요소 전체
$('#item').next() // 바로 다음 형제
$('#item').prev() // 바로 이전 형제
$('#item').closest('.box') // 가장 가까운 조상 .box
```

### 필터링

```jsx
$('li').first() // 첫 번째
$('li').last() // 마지막
$('li').eq(1) // 인덱스 1번
$('li').filter('.active') // .active 클래스만
$('li').not('.disabled') // .disabled 제외
```

## 6. 이벤트 처리

### 기본 이벤트 등록

```jsx
// on() 방식 — 가장 권장
$('#btn').on('click', function () {
  alert('클릭!')
})

// 단축형
$('#btn').click(function () {
  alert('클릭!')
})
```

### 자주 쓰는 이벤트 목록

```jsx
$('#btn').click(fn) // 마우스 클릭
$('#btn').dblclick(fn) // 더블 클릭
$('#input').focus(fn) // 포커스 진입
$('#input').blur(fn) // 포커스 해제
$('#input').change(fn) // 값 변경 (input, select)
$('#input').keyup(fn) // 키 뗄 때
$('#input').keydown(fn) // 키 누를 때
$('#div').mouseenter(fn) // 마우스 진입
$('#div').mouseleave(fn) // 마우스 이탈
$('#div').hover(fnIn, fnOut) // mouseenter + mouseleave
$(window).resize(fn) // 창 크기 변경
$(window).scroll(fn) // 스크롤
$(document).ready(fn) // DOM 로드 완료
```

### this 활용

```jsx
// 이벤트 안에서 this = 이벤트가 발생한 요소
$('.btn').click(function () {
  $(this).addClass('active') // 클릭된 버튼에만 적용
  $(this).text('클릭됨')
})
```

### 동적 요소 이벤트 (중요!)

```jsx
// 나중에 추가된 요소에도 이벤트 적용하려면 부모에 위임
// 잘못된 방법: 나중에 추가된 .item에는 작동 안 함
$('.item').click(fn)

// 올바른 방법: 이미 있는 부모(#list)에 위임
$('#list').on('click', '.item', function () {
  console.log('동적 요소 클릭!')
})
```

### 이벤트 제거

```jsx
$('#btn').off('click') // 특정 이벤트 제거
$('#btn').off() // 모든 이벤트 제거
$('#btn').one('click', fn) // 한 번만 실행 후 자동 제거
```

### 이벤트 기본 동작 막기

```jsx
$('a').click(function (e) {
  e.preventDefault() // 링크 이동 막기
  e.stopPropagation() // 이벤트 버블링 막기
})

$('form').submit(function (e) {
  e.preventDefault() // 폼 제출 막기
  // 유효성 검사 후 수동으로 submit
})
```

## 9. Ajax 통신

서버에서 데이터를 비동기로 가져올 때 사용합니다.

### $.ajax() — 가장 상세한 제어

```jsx
$.ajax({
  url: '/api/users', // 요청 URL
  type: 'GET', // 'GET', 'POST', 'PUT', 'DELETE'
  data: { page: 1, limit: 10 }, // 전송할 데이터
  dataType: 'json', // 응답 타입
  success: function (response) {
    console.log('성공:', response)
  },
  error: function (xhr, status, error) {
    console.error('실패:', error)
  },
  complete: function () {
    console.log('성공/실패 상관없이 항상 실행')
  },
})
```

### $.get() / $.post() — 단축형

```jsx
// GET 요청
$.get('/api/users', { page: 1 }, function (data) {
  console.log(data)
})

// POST 요청
$.post('/api/login', { id: 'test', pw: '1234' }, function (data) {
  console.log(data)
})
```

### $.getJSON() — JSON 전용 단축형

```jsx
$.getJSON('/api/products', function (data) {
  data.forEach(function (item) {
    $('#list').append('<li>' + item.name + '</li>')
  })
})
```

### 최신 방식: Promise 체이닝

```jsx
$.ajax({
  url: '/api/users',
  type: 'GET',
  dataType: 'json',
})
  .done(function (data) {
    console.log('성공:', data)
  })
  .fail(function (xhr) {
    console.error('실패:', xhr.status)
  })
  .always(function () {
    $('#loading').hide()
  })
```

### Ajax 실무 예제: 상품 목록 불러오기

```jsx
function loadProducts() {
  $('#loading').show()

  $.ajax({
    url: '/api/products',
    type: 'GET',
    dataType: 'json',
    success: function (products) {
      var html = ''
      $.each(products, function (i, item) {
        html += '<div class="product">'
        html += '  <h3>' + item.name + '</h3>'
        html += '  <p>' + item.price + '원</p>'
        html += '</div>'
      })
      $('#product-list').html(html)
    },
    error: function () {
      alert('데이터를 불러오지 못했습니다.')
    },
    complete: function () {
      $('#loading').hide()
    },
  })
}
```

## 10. 폼 처리

### 값 읽기

```jsx
$('input[type="text"]').val() // 텍스트 입력값
$('input[type="checkbox"]').is(':checked') // 체크 여부 → true/false
$('input[type="radio"]:checked').val() // 선택된 라디오 값
$('select').val() // 선택된 option 값
$('textarea').val() // textarea 값
```

### 폼 전체 직렬화

```jsx
// 폼 데이터를 쿼리 문자열로
$('#myForm').serialize()
// → "name=홍길동&email=test@test.com"

// 배열 형태로
$('#myForm').serializeArray()
// → [{name: 'name', value: '홍길동'}, ...]
```

### 유효성 검사 예제

```jsx
$('#myForm').on('submit', function (e) {
  e.preventDefault()

  var name = $('#name').val().trim()
  var email = $('#email').val().trim()

  if (name === '') {
    alert('이름을 입력해주세요.')
    $('#name').focus()
    return
  }

  if (email === '' || !email.includes('@')) {
    alert('올바른 이메일을 입력해주세요.')
    $('#email').focus()
    return
  }

  // 검사 통과 → Ajax 전송
  $.post('/api/submit', $(this).serialize(), function (res) {
    alert('제출 완료!')
  })
})
```

## 11. 유용한 유틸리티

### 반복: $.each()

```jsx
// 배열 반복
var arr = ['사과', '배', '포도']
$.each(arr, function (index, value) {
  console.log(index, value) // 0 사과, 1 배, 2 포도
})

// 객체 반복
var obj = { name: '홍길동', age: 30 }
$.each(obj, function (key, value) {
  console.log(key, value) // name 홍길동, age 30
})

// jQuery 요소 반복
$('li').each(function (i) {
  console.log(i, $(this).text())
})
```

### 배열 유틸리티

```jsx
// 배열 필터링
var evens = $.grep([1, 2, 3, 4, 5], function (n) {
  return n % 2 === 0 // → [2, 4]
})

// 배열 변환 (map)
var doubled = $.map([1, 2, 3], function (n) {
  return n * 2 // → [2, 4, 6]
})

// 값이 배열에 있는지 확인
$.inArray('포도', ['사과', '배', '포도']) // → 2 (없으면 -1)
```

### 예제 1: 탭 메뉴

```html
<div class="tabs">
  <ul class="tab-menu">
    <li data-tab="tab1" class="active">탭1</li>
    <li data-tab="tab2">탭2</li>
    <li data-tab="tab3">탭3</li>
  </ul>
  <div class="tab-content" id="tab1">탭1 내용</div>
  <div class="tab-content" id="tab2" style="display:none">탭2 내용</div>
  <div class="tab-content" id="tab3" style="display:none">탭3 내용</div>
</div>
```

```jsx
$(function () {
  $('.tab-menu li').click(function () {
    var tabId = $(this).data('tab')

    // 메뉴 active 처리
    $('.tab-menu li').removeClass('active')
    $(this).addClass('active')

    // 콘텐츠 전환
    $('.tab-content').hide()
    $('#' + tabId).show()
  })
})
```

### 예제 2: 아코디언 (접기/펼치기)

```html
<div class="accordion">
  <div class="acc-item">
    <div class="acc-header">질문 1 <span>▼</span></div>
    <div class="acc-body" style="display:none">답변 1 내용...</div>
  </div>
  <div class="acc-item">
    <div class="acc-header">질문 2 <span>▼</span></div>
    <div class="acc-body" style="display:none">답변 2 내용...</div>
  </div>
</div>
```

```jsx
$(function () {
  $('.acc-header').click(function () {
    var $body = $(this).next('.acc-body')

    // 다른 항목 닫기
    $('.acc-body').not($body).slideUp(200)
    $('.acc-header span').not($(this).find('span')).text('▼')

    // 현재 항목 토글
    $body.slideToggle(200)
    $(this)
      .find('span')
      .text($body.is(':visible') ? '▲' : '▼')
  })
})
```

### 예제 3: 검색 자동완성 (Ajax)

```html
<input type="text" id="search" placeholder="검색어 입력" />
<ul id="autocomplete-list"></ul>
```

```jsx
$(function () {
  var timer

  $('#search').keyup(function () {
    var keyword = $(this).val().trim()

    clearTimeout(timer) // 타이핑 중 중복 요청 방지

    if (keyword.length < 2) {
      $('#autocomplete-list').empty().hide()
      return
    }

    timer = setTimeout(function () {
      $.get('/api/search', { q: keyword }, function (results) {
        var html = ''
        $.each(results, function (i, item) {
          html += '<li class="autocomplete-item">' + item.name + '</li>'
        })
        $('#autocomplete-list').html(html).show()
      })
    }, 300) // 300ms 대기 후 요청
  })

  // 목록 클릭 시 입력창에 값 넣기
  $(document).on('click', '.autocomplete-item', function () {
    $('#search').val($(this).text())
    $('#autocomplete-list').empty().hide()
  })

  // 다른 곳 클릭 시 목록 닫기
  $(document).click(function (e) {
    if (!$(e.target).closest('#search, #autocomplete-list').length) {
      $('#autocomplete-list').empty().hide()
    }
  })
})
```

### 예제 4: 무한 스크롤

```jsx
$(function () {
  var page = 1
  var loading = false

  $(window).scroll(function () {
    var scrollBottom = $(document).height() - $(window).scrollTop() - $(window).height()

    if (scrollBottom < 100 && !loading) {
      loading = true
      page++

      $.get('/api/posts', { page: page }, function (data) {
        if (data.length === 0) {
          $(window).off('scroll') // 더 이상 데이터 없으면 해제
          return
        }
        $.each(data, function (i, post) {
          $('#post-list').append('<div class="post">' + post.title + '</div>')
        })
        loading = false
      })
    }
  })
})
```

### 예제 5: 모달 팝업

```html
<button id="open-modal">팝업 열기</button>

<div id="modal" style="display:none">
  <div class="modal-overlay"></div>
  <div class="modal-content">
    <button class="modal-close">✕</button>
    <h2>모달 제목</h2>
    <p>모달 내용...</p>
  </div>
</div>
```

```jsx
$(function () {
  // 열기
  $('#open-modal').click(function () {
    $('#modal').fadeIn(200)
    $('body').css('overflow', 'hidden') // 배경 스크롤 막기
  })

  // 닫기 (버튼 또는 오버레이 클릭)
  $('.modal-close, .modal-overlay').click(function () {
    $('#modal').fadeOut(200)
    $('body').css('overflow', '')
  })

  // ESC 키로 닫기
  $(document).keydown(function (e) {
    if (e.key === 'Escape') {
      $('#modal').fadeOut(200)
      $('body').css('overflow', '')
    }
  })
})
```

### 예제 6: 테이블 행 추가/삭제

```html
<table id="data-table">
  <thead>
    <tr>
      <th>이름</th>
      <th>나이</th>
      <th>삭제</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>홍길동</td>
      <td>30</td>
      <td><button class="del-btn">삭제</button></td>
    </tr>
  </tbody>
</table>
<button id="add-row">행 추가</button>
```

```jsx
$(function () {
  // 행 추가
  $('#add-row').click(function () {
    var newRow = '<tr><td>새이름</td><td>25</td><td><button class="del-btn">삭제</button></td></tr>'
    $('#data-table tbody').append(newRow)
  })

  // 행 삭제 (동적 요소 이벤트 위임)
  $('#data-table').on('click', '.del-btn', function () {
    if (confirm('삭제하시겠습니까?')) {
      $(this)
        .closest('tr')
        .fadeOut(200, function () {
          $(this).remove()
        })
    }
  })
})
```

| 작업               | 코드                                                   |
| ------------------ | ------------------------------------------------------ |
| 요소 숨기기/보이기 | `$('#el').hide()` / `$('#el').show()`                  |
| 클래스 토글        | `$('#el').toggleClass('active')`                       |
| 텍스트 변경        | `$('#el').text('새 텍스트')`                           |
| HTML 변경          | `$('#el').html('<b>내용</b>')`                         |
| input 값 읽기      | `$('input').val()`                                     |
| 이벤트 등록        | `$('#btn').on('click', fn)`                            |
| Ajax GET           | `$.get(url, data, callback)`                           |
| Ajax POST          | `$.post(url, data, callback)`                          |
| 반복               | `$('li').each(fn)`                                     |
| 요소 추가          | `$('#list').append('<li>...</li>')`                    |
| 요소 삭제          | `$('#el').remove()`                                    |
| 속성 읽기/쓰기     | `$('#el').attr('src')` / `$('#el').attr('src', 'url')` |
| 스타일 변경        | `$('#el').css('color', 'red')`                         |
| 애니메이션         | `$('#el').animate({ width: '200px' }, 300)`            |
