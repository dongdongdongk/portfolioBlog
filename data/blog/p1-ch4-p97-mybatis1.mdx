## XML Mapper + Mapper 인터페이스

```java
실제로 어노테이션을 이용해서 위의 예시처럼 (@Select)  sql문을 사용하면 코드가 복잡해지고 효율적이지 못하다 (동적인 sql 생성도 불가)

이 상황을 해결하기 위해 XML Mapper + Mapper 인터페이스를 사용한다
```

```java
인터페이스에 새로운 메서드를 추가한다
```

```java
//TimeMapper 인터페이스

package org.zerock.mapper;

import org.apache.ibatis.annotations.Select;

//org.zerock.mapper.TimeMapper.getTime2 -> 메서드 경로 풀 네임

public interface TimeMapper {
	//; 없어야 한다
	@Select("select sysdate from dual")
	String getTime();

	String getTime2();
}
```

```java
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="org.zerock.mapper.TimeMapper">

	<select id="getTime2" resultType="string">
		SELECT SYSDATE
	  	  FROM DUAL
	</select>

</mapper>
```
