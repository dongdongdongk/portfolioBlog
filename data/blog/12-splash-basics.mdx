# Introduction to Splash

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380910/notion-blog/_/_/Python_Selenium_Scrapy_ChatGPT_Prize/_12_Splash_Basics/Untitled_3.png)

```python
이 코드는 Splash 스크립트로, 웹 페이지를 로드하고 해당 페이지의 스크린샷을 반환하는 간단한 작업을 수행
```

```python
#main 함수 정의: 이 함수는 Splash에서 실행되는 스크립트의 진입점입니다.
#splash와 args를 인수로 받습니다.
function main(splash, args)

  #args 테이블에서 url 값을 추출하여 url 변수에 할당합니다.
  #이는 스크립트가 로드할 웹 페이지의 URL입니다.
  url = args.url

  #splash 인스턴스의 go 메서드를 호출하여 지정된 url로 이동합니다.
  #이 메서드는 페이지가 로드될 때까지 기다립니다.
  splash:go(url)

  #현재 로드된 페이지의 스크린샷을 PNG 형식으로 반환합니다.
  #이 이미지는 호출자에게 반환됩니다.
  return splash:png()
end
```

```python
function main(splash, args)

function main(splash, args):

이 줄은 main이라는 함수를 정의한다. 이 함수는 Splash에서 실행되는 스크립트의 진입점이다. splash와 args는 함수의 인수이다.

	splash:

	Splash 인스턴스를 나타내며, 다양한 메서드를 사용하여 웹 페이지를 로드하고 상호작용할 수 있다.


	args:

	호출 시 전달되는 인수들을 포함하는 테이블이다. 여기에는 URL과 같은 정보가 포함될 수 있다.
```

```python
url = args.url

url = args.url:

args 테이블에서 url 값을 추출하여 url 변수에 할당한다. 이는 스크립트가 로드할 웹 페이지의 URL이다.
```

```python
splash:go(url)

splash:go(url):

Splash 인스턴스의 go 메서드를 호출하여 지정된 url로 이동한다. 이는 웹 브라우저에서 해당 URL을 여는 것과 유사하다.

	splash:go:

	지정된 URL로 이동하는 Splash의 메서드이다. 이 메서드는 페이지가 로드될 때까지 기다린다.
```

```python
return splash:png()

return splash:png():

현재 로드된 페이지의 스크린샷을 PNG 형식으로 반환한다. 이 이미지는 호출자에게 반환된다.

	splash:png:

	현재 페이지의 스크린샷을 PNG 이미지 형식으로 캡처하는 메서드이다
```

```python
전체적인 흐름

함수 정의: main 함수를 정의하고, splash와 args 인수를 받는다.

URL 추출: args 테이블에서 url 값을 추출한다.

페이지 로드: splash:go 메서드를 사용하여 지정된 URL로 이동한다.

스크린샷 반환: splash:png 메서드를 호출하여 페이지의 스크린샷을 캡처하고 반환한다
```

### assert 사용으로 디버깅 하기

```python
assert 함수는 조건이 참인지 검사하고, 만약 거짓이면 오류를 발생시키는 역할을 한다.

주로 디버깅 목적으로 사용되며, 코드의 예상 동작을 보장하기 위해 조건을 검증하는 데 사용된다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380910/notion-blog/_/_/Python_Selenium_Scrapy_ChatGPT_Prize/_12_Splash_Basics/Untitled_6.png)

```python
assert(splash:go(url))는 페이지 로드가 성공적으로 완료되지 않으면 스크립트를 중단시키고 오류를 보고한다.

이렇게 하면 웹 페이지가 제대로 로드되지 않았을 때 이후의 스크린샷이나 HTML 추출 작업이 수행되지 않도록 보장할 수 있다.
```

# 스플레쉬 웹사이트 요소 찾기 ( How to Find Elements with Splash )

```python
스플레쉬를 사용해서

버튼에 텍스트를 입력하고 서치 버튼을 클릭하도록 해본다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380911/notion-blog/_/_/Python_Selenium_Scrapy_ChatGPT_Prize/_12_Splash_Basics/Untitled_8.png)

```python
function main(splash, args)
  # args에서 URL을 가져옵니다.
  url = args.url

  # 주어진 URL로 이동을 시도하고, 실패 시 오류를 발생시킵니다.
  assert(splash:go(url))

  # 페이지가 로드될 시간을 2초 동안 기다립니다.
  assert(splash:wait(2))

  # 검색 입력 상자를 선택하고, 실패 시 오류를 발생시킵니다.
  input_box = assert(splash:select("#twotabsearchtextbox"))

  # 선택된 입력 상자에 포커스를 맞춥니다.
  input_box:focus()

  # 입력 상자에 "books" 텍스트를 입력합니다.
  input_box:send_text("books")

  # JavaScript가 실행된 후 페이지가 업데이트될 시간을 1초 동안 기다립니다.
  assert(splash:wait(1))

  # 검색 버튼을 선택하고, 실패 시 오류를 발생시킵니다.
  button = assert(splash:select("#nav-search-submit-button"))

  # 선택된 버튼을 클릭합니다.
  button:mouse_click()

  # 검색 결과 페이지가 로드될 시간을 5초 동안 기다립니다.
  assert(splash:wait(5))

  # 페이지의 스크린샷을 PNG 형식으로 캡처하여 반환합니다.
  # 페이지의 HTML을 반환합니다.
  return {
    png = splash:png(),
    html = splash:html()
  }
end
```

```python
스플레쉬는 CSS 선택자를 사용하여 요소를 선택한다. XPath는 사용할 수 없다
```
