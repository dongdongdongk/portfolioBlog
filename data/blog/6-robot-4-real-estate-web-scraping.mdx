# 인풋 모드 심화 설명 ( Using Input Modes )

```python
입력 모드는 모든 UI 액티비티에서 사용할 수 있다.

예를 들어 Application/Browser activity나 Click activity에서 사용 가능

Simulate (시뮬레이션): 백 그라운드

접근성 API를 이용해 작업을 시뮬레이션한다.

가장 신뢰도가 높다.

Chrome API: 백 그라운드

백그라운드에서 실행되고 디버거 API를 이용해 액션을 수행한다.

시뮬레이션이 안 될 때 두 번째로 좋은 옵션이다.

Window Messages: 백 그라운드

Wind32 메시지를 통해 마우스와 키보드 입력을 보낸다.

백그라운드에서 실행된다.

Hardware Events: 프론트 그라운드

하드웨어 드라이버를 이용해 액션을 수행한다.

전경에서 실행된다.

가장 신뢰도가 낮지만, 항상 성공적이다.
```
