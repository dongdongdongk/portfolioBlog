## 1. 지형에 나무 추가 개념

- **Terrain(지형)** 컴포넌트에는 **나무(Trees) 페인트 툴**이 있음.
- 여기서 나무뿐 아니라 **아무 GameObject Prefab**도 등록해서 지형에 배치 가능.
  - 예: 바위, 덤불, 심지어 엉뚱한 오브젝트까지.
- 하지만 환경 표현 목적상 **나무 prefab**을 주로 사용.

---

## 2. 나무 에셋 다운로드 및 가져오기

- **Unity Asset Store → 무료 나무 에셋 검색**
- 강의에서는 두 가지 예시 사용:
  1. **URP Tree Models** → 기본적으로 잘 작동 (LOD 포함).
  2. **Mobile Trees** → 일부 문제가 있어 직접 수정 필요.
- 가져오기 절차:
  1. Asset Store에서 다운로드.
  2. `Package Manager → Open in Unity`로 가져오기.
  3. `Import` 시 **모든 항목 선택** 후 프로젝트에 추가.
  4. 정리: `Tree Packs` 폴더 만들어 `Third Party Assets`에 배치.

## 3. Terrain에 나무 배치하기

- `Terrain` 선택 → **Inspector > Paint Trees (세 번째 아이콘)**.
- **Edit Trees → Add Tree** 클릭 → Tree Prefab 드래그 앤 드롭.
- 브러시 옵션:
  - **Brush Size**: 한 번에 페인트할 영역 크기.
  - **Tree Density**: 나무 밀도.
    - 권장: **Density 낮게 + Brush 크게** 설정 → 자연스럽고 성능 안정적.

## 4. 나무 크기/스케일 조정

- 처음 추가 시 나무가 너무 작게 보일 수 있음.
- Prefab 선택 후 **Transform Scale** 수정:
  - 예: `(6,6,6)` → 현실적인 크기 확보.
- **Apply/Save** 해서 Terrain에서도 적용되도록 함.

## 5. LOD(Group) 개념과 문제 해결

- 많은 나무 Prefab은 **LOD Group** 컴포넌트를 가짐.
- **LOD (Level of Detail)**: 카메라 거리 따라 다른 Mesh로 교체 → 성능 최적화.
  - 가까울 때: 폴리곤 많은 디테일 모델.
  - 멀리 있을 때: 단순화된 저해상도 모델.
- 문제:
  - 카메라 움직일 때 나무가 **깜빡이거나 품질 변동** → 산만해 보임.
- 해결 방법:
  - 불필요한 LOD 단계 제거.
  - 항상 **하나의 LOD Mesh만 표시**하도록 수정.
  - 강의에서는 **가장 낮은 LOD Mesh만 유지**하도록 설정.

## 6. URP 호환되지 않는 재질 문제 해결

- 일부 에셋은 **핑크색(Material Missing)** 문제 발생.
  - 원인: **URP(Render Pipeline)**와 호환되지 않는 Shader 사용.
- 해결 방법: **Render Pipeline Converter** 활용.
  - 경로: `Window > Rendering > Render Pipeline Converter`.
  - `Built-in → URP`로 변환.
  - **Material Upgrade** 옵션만 체크.
  - 실행하면 대부분 자동 변환됨.
- 미처 변환 안 된 재질은 직접 **URP 호환 Shader** 지정 필요.

## 8. 여러 나무 추가 및 복사 활용

- Terrain에 여러 종류의 나무 등록 가능.

## 9. 나무 배치 시 발생하는 문제

- **깜빡임(Flickering)**
  - 원인: LOD 전환 / z-fighting(겹침).
- **그림자 안 보임**
  - 원인: 카메라 거리 제한 → 추후 **Shadow Distance** 세팅에서 해결.
- **너무 크게/작게 보임**
  - 원인: Scale 값 잘못 설정 → Prefab 수정 필요.

## 1. 그림자 렌더링 거리 조정하기

### 🔎 개념

- **그림자 거리(Shadow Distance)**: 카메라와 얼마나 멀리 떨어진 그림자까지 보이게 할지 결정.
- 기본값이 너무 짧으면, 가까이에서만 그림자가 보이고 멀리서는 사라져 부자연스럽게 보임.

### ⚙️ 설정 방법

1. **Edit → Project Settings → Quality 탭** 으로 이동.
2. `Rendering` → **Render Pipeline Asset** 확인.
   - 현재 사용하는 Render Pipeline Asset을 선택.
3. Inspector 하단의 **Shadows** 드롭다운에서 **Max Distance** 조정.
   - 예시: `700` (지형 블록 단위와 동일 → 플레이어가 보는 대부분 장면에서 그림자가 보임).

## 2. 광원(Directional Light) 세팅하기

### 🔎 개념

- **Directional Light**는 태양광처럼 장면 전체에 일정하게 비추는 빛.
- 위치는 중요하지 않고, **회전(Rotation)** 방향이 실제 그림자의 방향을 결정함.

### ⚙️ 주요 설정

1. **기존 Directional Light** 선택 후 Inspector에서:
   - **Shadows → Strength** : 그림자 농도.
     - 기본값이 강하면 너무 진해 보임 → `0.7` 정도로 부드럽게 조정.
2. **보조 광원 추가**:
   - Hierarchy → `Light → Directional Light` 생성.
   - 이름: _Fill Light(보조 조명)_.
   - 기존 광원과 **살짝 다른 회전**으로 조정 → 그림자 대비 완화 + 볼륨감 증가.
3. **색 온도 & 필터 색상 조정**:
   - 광원 Inspector → Color 옵션에서 모드 변경: `Color` → `Filter & Temperature`.
   - 주광(Main Light): 따뜻한 주황빛(약간 어둡게).
   - 보조광(Fill Light): 차가운 푸른빛.
   - → 두 조명을 대비시켜 은하나 행성의 불길한 느낌을 연출.

## 3. 조명 창(Lighting Window)과 안개 설정하기

### 🔎 개념

- **Lighting Window**: 장면(Scene)의 전체적인 환경광, 하늘(Skybox), 안개(Fog) 등을 제어.
- **Fog(안개)**: 먼 거리를 흐리게 처리하여 깊이감과 분위기 연출.

### ⚙️ 설정 방법

1. 상단 메뉴: **Window → Rendering → Lighting** → Inspector 옆에 도킹.
2. `Environment 탭` → **Fog 활성화**.
   - Scene 뷰에서는 잘 안 보일 수 있음 → Game 뷰에서 확인 권장.
3. **Fog Mode**:
   - `Linear` (선형) 모드 선택 → 시작 지점부터 끝 지점까지 서서히 짙어짐.
4. **Start / End 값**:
   - Start: 카메라와 얼마나 가까운 곳에서 안개가 시작되는지.
   - End: 얼마나 멀리까지 안개가 퍼지는지.
   - 예시: Start `400` → 부드러운 전환.
   - 두 값 차이가 클수록 페이드가 천천히 진행 (안개가 옅게 보임).
5. **Fog Color**: 전체 톤과 맞추어 어두운 파란색 설정 → 미지의 행성 같은 분위기.

## 4. 카메라 렌더링 및 포스트 프로세싱 설정

### 🔎 개념

- **Post-Processing**: Bloom, 색 보정, 대비, 필름 효과 등 다양한 시각 효과를 카메라에 적용.
- 켜져 있어야 후처리 효과들이 반영됨.

### ⚙️ 설정 방법

1. `Hierarchy → Main Camera` 선택.
2. Inspector → **Rendering** 드롭다운 확인.
3. `Post Processing` 옵션이 켜져 있는지 확인.
   - 꺼져 있으면 효과가 적용되지 않음.

## 5. 안티앨리어싱(Anti-Aliasing) 적용하기

### 🔎 개념

- **안티앨리어싱**: 오브젝트의 경계선이 톱니처럼 보이는 계단 현상을 부드럽게 보정.
- Low Poly 스타일에도 적용하면 외관이 크게 개선됨.

### ⚙️ 설정 방법

1. Main Camera Inspector → **Anti-aliasing 옵션** 선택.
2. 주요 모드:
   - **FXAA**: 빠르지만 저품질.
   - **SMAA**: 균형형.
   - **TAA (Temporal Anti-Aliasing)**: 가장 부드럽고 고품질.
3. 강의에서는 **TAA 선택**.
   - `Quality: Very High`
   - `Contrast Adaptive: Medium` (중간값 → 흐릿함 방지).
4. 비교를 위해 Anti-Aliasing을 껐다 켰다 하면서 차이를 확인 가능.

## 1. Skybox 개념 이해하기

- **Skybox** : 게임 월드의 하늘과 배경을 표현하는 큐브 형태의 재질.
  → 실제로는 거대한 정육면체 안에 들어 있는 것처럼 작동하며, 여섯 면(앞/뒤/좌/우/위/아래)에 텍스처가 입혀져 있음.
- **적용 위치** : Lighting(조명) → Environment(환경) → **Skybox Material** 설정에서 지정 가능.

---

## 2. 새 Skybox Material 만들기

1. **Assets 폴더 → Material 폴더** 이동.
2. **마우스 오른쪽 클릭 → Create → Material** 선택.
3. 이름을 `"Skybox"` 로 지정.
4. **Inspector 창 → Shader 변경** :
   - 기본 Shader 대신 **Skybox** 계열 Shader 선택.
   - 범용 렌더 파이프라인(URP)을 사용 중이어도, 일반적인 Skybox Shader는 정상 작동함.

---

## 3. Skybox 색상 직접 커스터마이징하기

- 새로 만든 Skybox Material을 씬에 적용.
- 처음엔 눈에 띄는 변화 없음 → 이제 색상을 변경.
  - **하늘 색상(Sky Tint)** : 어두운 파란색.
  - **지면 색상(Ground Color)** : 어두운 보라색.
- 결과 → 기본 Skybox가 아닌, 직접 지정한 **맞춤형 Skybox** 완성.

---

## 4. Asset Store에서 Skybox 다운로드 및 임포트하기

- 직접 제작한 단순 Skybox 외에도, **에셋 스토어에서 고품질 Skybox**를 다운로드 가능.
- 절차:
  1. Unity Asset Store 접속.
  2. "Skybox" 검색 → **가격 필터 = 무료(Free)** 설정.
  3. 검색 결과 : 무료 Skybox만 148개 이상 제공됨.
  4. 예시 : _Skybox Volume 2 – Nebula_
     - SF 스타일의 7가지 Skybox 옵션 포함.
     - 계정에 추가 후 Unity 패키지 매니저에서 다운로드 가능.
  5. 다운로드 완료 → **프로젝트 임포트**.
     - `Assets/ThirdParty/Skybox` 같은 전용 폴더에 정리 권장.

---

## 5. Skybox 적용 및 세부 조정하기

1. **Skybox Material 찾기**:
   - 예: `"Deep Space Green"` (성운 느낌의 초록빛 하늘).
2. **적용 방법**:
   - Material을 **Lighting → Environment → Skybox Material** 슬롯에 드래그.
3. **옵션 조정**:
   - **Tint(색조)** : 기본 색상 분위기 변경.
   - **Exposure(노출)** : 밝기/빛 반짝임 정도 조절 (밤하늘 느낌 가능).
   - **Rotation(회전)** : 0–360°로 회전시켜 배경의 방향을 원하는 각도로 조정 가능.

---

✅ **이번 강의 핵심 요약**

- Skybox는 씬의 **배경(하늘/지면)을 정의하는 큐브 재질**.
- 직접 **새 Material**을 만들어 색상 기반의 단순 Skybox를 만들 수 있음.
- 에셋 스토어에서 무료/유료 **고품질 Skybox**를 가져와 적용 가능.
- Skybox는 단순히 끼우는 것뿐만 아니라, **색조, 밝기(노출), 회전**까지 조절 가능.

## 1. 마스터 타임라인에서 플레이어 릭 위치 조정하기

- **목적**: 나무에 가려지지 않고, 후처리 효과를 카메라에서 잘 보도록 플레이어를 띄움.
- **단계**:
  1. **마스터 타임라인 선택 → 플레이어 탭 열기**
  2. 녹화 버튼 옆의 **곡선 버튼** 클릭 → 위치/회전 곡선 확인 가능
  3. **Y 위치 곡선 선택 후 F 키** → 키프레임만 화면에 포커스
  4. 모든 Y 키프레임 선택 → 위로 드래그 (Shift 누르면 수직만 이동 가능)
- **결과**: 플레이어 릭이 나무에서 완전히 떨어져 **우주선이 공중을 나는 연출** 가능.

## 4. 블룸(Bloom) 효과 조정하기

- **개념**: 밝은 부분 주위에 빛 번짐을 만들어, 광원과 발광 재질을 더 빛나게 보이도록 함.

## 6. 비네트(Vignette) 확인하기

## 7. 노출(Exposure) 조정하기

- **개념**: 장면 전체의 밝기를 제어.
- **설정 방법**:
  - `Post Exposure` 값 사용
  - 강의에서는 처음에 `1.1`을 입력했으나 너무 과했음 → 최종적으로 `0.1`로 조정
- **결과**: 씬이 과도하게 밝아지지 않고, 살짝만 빛이 보강됨.

## 8. 색수차(Chromatic Aberration) 효과 주기

- **개념**: 화면 가장자리에서 색이 살짝 분리되는 효과 → 초고속 이동, SF 느낌 강화.
- **설정 방법**:
  - `Intensity = 0.1 ~ 0.2` 사이 추천
  - 강의에서는 `0.14 → 0.1`로 최종 확정
- **결과**: 미세하게 색이 퍼져 우주 비행의 몰입감을 높임.

---

## 9. 포트레이트 카메라(Post Processing & Anti-Aliasing) 적용하기

- **문제**: 메인 카메라에는 후처리가 적용되지만, **포트레이트 카메라(인물 컷)**에는 적용되지 않음.
- **원인**: 개별 카메라 옵션에서 후처리가 꺼져 있었음.
- **해결 방법**:
  1. 두 포트레이트 카메라(Lieutenant Snippets, General Kier) 선택
  2. **Rendering → Post Processing** 체크
  3. **Anti-Aliasing → TAA**로 변경
- **결과**: 인물용 카메라에도 후처리 효과와 부드러운 엣지 처리가 적용됨.

## 1. 레이어와 레이어 마스크 개념 이해하기

- **레이어(Layer)** :
  - Scene 내 게임 오브젝트를 분리하고, 상호작용 방식을 정의하는 도구.
  - 충돌(Physics), Raycasting, 카메라 시야 제어 등에 사용됨.
- **레이어 마스크(Layer Mask)** :
  - 카메라나 Raycast가 어떤 레이어만 감지/표시할지 선택할 수 있는 필터.
- **사용 사례**
  1. **충돌**:
     - 예) 아군과 적의 총알이 같은 "입자 충돌"을 쓰더라도,
       → 아군 총알은 적만, 적 총알은 아군만 맞도록 레이어 분리.
  2. **Raycasting**:
     - 특정 오브젝트만 감지하도록 레이어 마스크 사용.
  3. **카메라 쿨링(Camera Culling)**:
     - 특정 카메라에만 특정 오브젝트 보이도록 설정 가능.

---

## 2. 카메라 쿨링(Camera Culling)과 활용 사례

- 카메라마다 **보여줄 대상**을 제어 가능.
- 특정 오브젝트를 **특정 카메라 전용**으로 표시 가능.
- 예시:
  - 메인 카메라는 전체 장면 표시.
  - 초상화(Portrait) 카메라는 캐릭터 초상 전용 볼륨 효과만 표시.

## 3. Global Volume과 Portrait Volume 설정하기

1. **Volumes라는 빈 게임 오브젝트 생성**
   - Scene에 두고, `(0,0,0)` 위치 초기화.
   - 관리하기 쉽도록 Global/Portrait 볼륨을 모두 이 안에 배치.
2. **Global Volume 생성**
   - Scene 전체에서 쓰이는 기본 후처리 프로파일(Global Volume).
3. **Portrait Volume 생성**

   - Volume 컴포넌트 추가.
   - **프로파일(Profile)** → 새로 생성.
   - 새 프로파일은 기본적으로 `Assets/Scene` 루트에 저장됨.
   - 관리 편의를 위해 `Assets/Settings` 폴더로 이동.

## 5. Portrait Volume에 후처리 효과 추가하기

- Portrait Volume은 Global Volume의 기본 설정을 **상속**받음.
- 따라서, 직접 **오버라이드(Override)** 를 추가해야 차이가 발생함.

### (예시) 필름 그레인 효과 추가하기

1. Portrait Volume 선택.
2. `Add Override → Post-processing → Film Grain`.
3. 옵션 조정:
   - **Type** : 켜기 (활성화).
   - **Intensity (강도)** : 5 (기본보다 눈에 띄게).
   - **Response** : 0.2 (입자 반응 약간 부드럽게).

👉 결과: Portrait 카메라에는 거친 필름 느낌의 노이즈가 적용됨.

### (예시) 색상 조정 효과 추가하기

1. Portrait Volume에 `Color Adjustments` 오버라이드 추가.
2. 설정:
   - **Saturation (채도)** : 감소 → 색 빠진 느낌.
   - **Contrast (대비)** : 감소 → 부드럽고 탁한 느낌.
     👉 마치 먼 우주에서 라디오 신호를 받는 듯한 분위기 연출.

## 6. Global Volume과 Portrait Volume의 관계

- **Global Volume** : 프로젝트 전반의 기본 후처리 프로파일.
- **Portrait Volume** : Global Volume의 설정을 상속받음.
- **규칙**: 동일한 오버라이드를 Portrait Volume에서 변경하면, Global Volume의 값을 **덮어씌움(Override)**.

- 📌 과제:

## 1. 씬 매니저(GameSceneManager) 준비하기

- 씬(Scene)을 다시 불러오는 기능을 **전담하는 클래스**를 만듭니다.
- 이름을 단순히 `SceneManager`라고 하면 Unity의 네임스페이스 `UnityEngine.SceneManagement.SceneManager`와 **충돌(conflict)** 하므로,
  `GameSceneManager`라는 이름으로 작성합니다.
- 구성 방식:
  1. **빈 GameObject 생성** → 이름을 `Game Scene Manager`로 설정.
  2. 새 **MonoBehaviour 스크립트** 생성 → `GameSceneManager.cs`.
  3. 해당 GameObject에 이 스크립트를 붙여서 관리.

---

## 2. CollisionHandler에서 충돌 처리하기

- `CollisionHandler`는 우주선에 붙어 있는 스크립트.
- `OnTriggerEnter(Collider other)`를 통해 충돌 이벤트를 감지합니다.
- 충돌 시 수행할 동작:
  1. **폭발 이펙트 생성** (`Instantiate(explosion, transform.position, Quaternion.identity)`).
  2. **우주선 오브젝트 파괴** (`Destroy(gameObject)`).
  3. **GameSceneManager의 ReloadLevel 실행**.
- `GameSceneManager`를 가져오기 위해:
  ```csharp
  private void Start()
  {
      gameSceneManager = FindFirstObjectByType<GameSceneManager>();
  }
  ```
  → 시작 시 계층 구조(Scene Hierarchy)에서 자동으로 매니저를 찾아 참조합니다.

---

## 3. SceneManager로 씬 다시 불러오기

- Unity의 내장 클래스: `UnityEngine.SceneManagement.SceneManager`
- 현재 씬의 인덱스를 얻고, 다시 불러올 수 있음.

```csharp
int currentSceneIndex = SceneManager.GetActiveScene().buildIndex;
SceneManager.LoadScene(currentSceneIndex);
```

- `GetActiveScene()` → 현재 활성화된 씬 정보 반환.
- `.buildIndex` → Build Settings에서 지정한 씬 번호.
- `LoadScene()` → 해당 번호의 씬을 다시 로드.

## 4. 코루틴 개념 이해하기

- **코루틴(Coroutine)**: Unity에서 시간 지연이나 반복 동작을 쉽게 처리할 수 있는 특별한 함수.
- 일반 함수는 `void`를 반환하지만, **코루틴은 `IEnumerator`를 반환**해야 함.
- 주요 특징:
  - `yield return null` → 다음 프레임까지 대기.
  - `yield return new WaitForSeconds(x)` → 지정한 초 동안 대기.
  - `yield return 다른 코루틴` → 다른 코루틴이 끝날 때까지 대기.
- 실행 방식:
  - 일반 함수처럼 직접 호출하지 않고,
    **`StartCoroutine(코루틴이름())`**으로 실행해야 함.

---

## 5. ReloadLevelRoutine 구현하기

### GameSceneManager.cs

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.SceneManagement;

public class GameSceneManager : MonoBehaviour
{
    public void ReloadLevel()
    {
        StartCoroutine(ReloadLevelRoutine());
    }

    IEnumerator ReloadLevelRoutine()
    {
        yield return new WaitForSeconds(1f); // 1초 지연
        int currentSceneIndex = SceneManager.GetActiveScene().buildIndex;
        SceneManager.LoadScene(currentSceneIndex); // 현재 씬 다시 로드
    }
}
```

- `ReloadLevel()` : 외부 클래스(CollisionHandler)에서 호출할 공개 메서드.
  내부적으로 `ReloadLevelRoutine()` 코루틴을 실행.
- `ReloadLevelRoutine()` : 실제 지연 후 씬을 재로드하는 로직 담당.

---

### CollisionHandler.cs

```csharp
using UnityEngine;

public class CollisionHandler : MonoBehaviour
{
    [SerializeField] GameObject explosion;
    GameSceneManager gameSceneManager;

    private void Start()
    {
        gameSceneManager = FindFirstObjectByType<GameSceneManager>();
    }

    void OnTriggerEnter(Collider other)
    {
        gameSceneManager.ReloadLevel(); // 씬 리로딩 시작
        Instantiate(explosion, transform.position, Quaternion.identity);
        Destroy(gameObject);
    }
}
```

## 1. 오디오 시스템 개념 이해하기

- \*Unity 오디오(Audio)\*\*는 크게 두 가지로 나눌 수 있습니다:
  1. **SFX (Sound Effect, 효과음)**

     → 짧고 즉각적인 소리 (예: 폭발음, 점프 소리, 버튼 클릭).

  2. **BGM (Background Music, 배경 음악)**

     → 게임 전반에 걸쳐 계속 재생되는 음악.

- **Audio Source 컴포넌트**
  - 실제로 소리를 출력하는 역할.
  - `Audio Clip`을 할당해야 소리를 재생할 수 있음.
  - 주요 옵션:
    - **Play On Awake**: 씬 시작과 동시에 자동 재생 여부.
    - **Loop**: 음악처럼 계속 반복할지 여부.
    - **Volume**: 출력 음량.
- **Audio Clip**
  - 실제 오디오 파일(예: .mp3, .wav).

## 2. SFX(효과음) 구현하기

우주선이 파괴될 때 폭발 효과와 함께 **폭발음(SFX)** 을 재생하는 과정을 구현합니다.

1. **Prefab 찾기**
   - `Assets/Prefabs/VFX` 폴더에서 `Destroyed VFX` 프리팹 선택.
   - 이 프리팹은 **우주선 폭발 시** 생성되는 이펙트.
2. **Audio Source 추가**
   - `Destroyed VFX` 프리팹에 `Audio Source` 컴포넌트 붙이기.
   - `Audio Clip` 필드에 **폭발음 파일(SFX Explosion)** 할당.
3. **설정**
   - **Play On Awake** ✅ (체크됨 → 프리팹이 생성될 때 즉시 재생).
   - **Loop** ❌ (반복 불필요).

➡️ 결과: 우주선이 폭발하면 폭발 이펙트와 동시에 SFX가 자동 재생됩니다.

---

## 3. 음악 플레이어 구현하기

게임 전체에 흐르는 **배경 음악(BGM)** 을 구현합니다.

1. **Hierarchy에 빈 오브젝트 생성**
   - 이름: `Music Player`
2. **Audio Source 컴포넌트 추가**
   - `Audio Clip` → **음악 파일** 할당.
   - `Loop` → ✅ 체크 (계속 반복 재생).
   - `Play On Awake` → ✅ 체크 (게임 시작 시 바로 재생).
   - `Volume` → 적절히 낮춤 (예: `0.11`)
3. **테스트**
   - 게임을 실행하면 배경 음악이 반복 재생됨.

⚠️ 문제점 발견:

씬이 다시 로드될 때마다 **음악이 중복 실행**되거나, **처음부터 다시 재생**되는 현상 발생.

→ 해결책 필요.

## 4. 씬 이동 시 음악 유지하기 (싱글톤 패턴 적용)

**문제**: 씬이 다시 로드될 때 `Music Player`가 새로 생성됨 → 음악이 겹치거나 리셋됨.

**해결**: 오직 하나의 `Music Player`만 존재하도록 만들기.

### 싱글톤 기본 원리

- **씬에 여러 개가 존재하면 안 된다.**
- 하나만 남기고 나머지는 제거.
- 선택된 `Music Player`는 **씬 전환 시 파괴되지 않고 유지**.

### 코드 구현

```csharp
using UnityEngine;

public class MusicPlayer : MonoBehaviour
{
    void Start()
    {
        // 현재 씬 안에 존재하는 MusicPlayer 개수를 센다
        int numOfMusicPlayers = FindObjectsByType<MusicPlayer>(FindObjectsSortMode.None).Length;

        if (numOfMusicPlayers > 1)
        {
            // 이미 다른 MusicPlayer가 있다면, 자기 자신을 제거
            Destroy(gameObject);
        }
        else
        {
            // 최초 MusicPlayer라면, 씬이 바뀌어도 유지
            DontDestroyOnLoad(gameObject);
        }
    }
}
```

### 동작 과정

1. 씬 시작 시 `FindObjectsByType`로 씬 안의 `MusicPlayer` 개수 확인.
2. 개수가 **2개 이상**이라면 → 현재 오브젝트 제거.
3. 개수가 **1개뿐**이라면 → `DontDestroyOnLoad` 호출, 씬 전환에도 유지.

➡️ 이렇게 하면 **게임 전반에서 음악이 끊기지 않고 자연스럽게 이어짐**.

## `* FindObjectsSortMode.None`

- 객체를 찾은 뒤 **정렬을 어떻게 할지** 지정하는 옵션.
- 선택지:
  - `None` → 정렬하지 않음 (가장 빠름).
  - `InstanceID` → Unity 내부 ID 순으로 정렬.
  - `TransformHierarchy` → 계층(Hierarchy) 순서대로 정렬.
  - `Scene` → 씬 순서대로 정렬.

---

✅ 이번 강의에서 배운 핵심

1. **SFX** → 프리팹에 `Audio Source` 붙여서 즉시 재생.
2. **BGM** → `Music Player` 오브젝트에 `Audio Source`로 재생.
3. **씬 전환 시 음악 유지** → 싱글톤 패턴 (`DontDestroyOnLoad + 중복 제거`).
