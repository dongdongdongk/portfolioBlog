# 프레젠테이션 컴포넌트 vs 스테이트풀 컴포넌트 ( **React 컴포넌트 유형 )**

```jsx
React에는 두 가지 주요 유형의 컴포넌트가 있다:

프레젠테이션 컴포넌트와 스테이트풀(stateful) 컴포넌트.

**프레젠테이션 컴포넌트**는 주로 콘텐츠를 출력하고 스타일 및 구조를 담당하는 단순한 컴포넌트로,

외부에서 데이터를 받아 화면에 표시한다.

**스테이트풀 컴포넌트**는 상태를 관리하고 자식 컴포넌트가 새 데이터를 받도록 조직하는 등 복잡한 로직을 처리한다.

* 일반적으로 데이터를 관리하고 가져오는 컴포넌트는 적고, 화면을 보여주는 역할을 하는 프레젠테이션 컴포넌트가 더 많다.
```

## **컴포넌트 설명 ( 예시 )**

```jsx
Card

컴포넌트는 프레젠테이션 컴포넌트의 예시로, 단순히 콘텐츠를 렌더링하고 스타일을 적용한다.

Avatar

컴포넌트와 UserItem 컴포넌트도 마찬가지로 간단한 프레젠테이션 컴포넌트이며, 외부에서 받은 데이터를 렌더링한다.

UsersList

컴포넌트는 렌더링 대상을 정하는 로직이 추가된 프레젠테이션 컴포넌트이다.

Users
```


# 포털 이해

```jsx
React Portal은 React 컴포넌트를 본래 렌더링되는 위치 외에서도 구현하거나 렌더링할 수 있게 해주는 기능이다.

Portal을 사용하는 이유

사이드 드로어와 같은 컴포넌트는 일반적으로 메인 내비게이션의 일부로 렌더링되어 메인 내비게이션과 함께 표시된다.

Portal을 사용하면 HTML 파일에서 새로운 렌더링 위치를 지정할 수 있으며,

예시로 Public 폴더의 index.html 파일에 새로운 div 태그를 추가하여 이를 구현하는 방법을 제시 해보겠다
```

## **Portal을 통한 렌더링 위치 설정**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381308/notion-blog/_/React_NodeJS_Express_MongoDB_-_MERN_/React_js_/Untitled_21.png)

```jsx
public 의  index.html 로 이동해서

<div id="drawer-hook"></div> 를 추가해줘 새로 렌더링 될 위치를 지정해준다 ( id 이름은 내가 정하기 나름 )

( 이부분에 사이드 드로어가 렌더링 될것이다 )

( HTML 파일에서 새로운 렌더링 위치를 정하기 위해, index.html 파일에 "drawer-hook"이라는 ID를 가진 div 태그를 추가하고,

이 위치에 사이드 드로어를 렌더링할 것을 명시 한다 )
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381309/notion-blog/_/React_NodeJS_Express_MongoDB_-_MERN_/React_js_/Untitled_22.png)

```jsx
import React from 'react'
import ReactDOM from 'react-dom'

import './SideDrawer.css'

const SideDrawer = (props) => {
  // 1. JSX로 사이드 드로어의 콘텐츠를 정의
  const content = <aside className="side-drawer">{props.children}</aside>

  // 2. 렌더링할 위치의 DOM 요소 선택
  const portalRoot = document.getElementById('drawer-hook')

  // 3. ReactDOM.createPortal을 사용하여 콘텐츠를 렌더링할 위치와 방법을 설정하고 반환
  return ReactDOM.createPortal(content, portalRoot)
}

export default SideDrawer
```

```jsx
위의 코드에서 content 상수에는 사이드 드로어의 JSX 콘텐츠가 저장되어 있다.

이는 일반적인 React 컴포넌트처럼 구성된 것이며, 사이드 드로어의 내용이 포함되어 있다.

그 다음, ReactDOM.createPortal 함수를 사용하여 이 콘텐츠를 선택한 위치에 렌더링한다.

portalRoot 상수에는 렌더링할 위치로 지정한 "drawer-hook"이라는 ID를 가진 div 태그가 저장되어 있다. ( 아까 index.html 에 사용 )

마지막으로, SideDrawer 컴포넌트는 이렇게 생성된 Portal을 반환한다.

이렇게 함으로써, React는 해당 콘텐츠를 portalRoot에 지정된 위치에 렌더링한다.

이를 통해, 일반적인 컴포넌트처럼 작성된 JSX를 원하는 다른 위치에 Portal을 통해 렌더링할 수 있게 된다.
```

## SideDrawer.jsx

```jsx
// React 및 ReactDOM 라이브러리를 import
import React from 'react'
import ReactDOM from 'react-dom'

// react-transition-group 라이브러리에서 CSSTransition 컴포넌트를 import
import { CSSTransition } from 'react-transition-group'

// SideDrawer.css 파일에서 스타일을 import
import './SideDrawer.css'

// SideDrawer 함수형 컴포넌트 정의
const SideDrawer = (props) => {
  // 1. JSX로 사이드 드로어의 콘텐츠를 정의
  const content = (
    <CSSTransition
      in={props.show} // 드로어의 표시 여부를 결정하는 props
      timeout={200} // 애니메이션 효과의 지속 시간 (200ms)
      classNames="slide-in-left" // 적용할 CSS 클래스 이름
      mountOnEnter // 드로어가 나타날 때 DOM에 추가
      unmountOnExit // 드로어가 사라질 때 DOM에서 제거
    >
      {/* aside 태그로 감싼 드로어 콘텐츠 */}
      <aside className="side-drawer">{props.children}</aside>
    </CSSTransition>
  )

  // 2. 렌더링할 위치의 DOM 요소 선택
  const portalRoot = document.getElementById('drawer-hook')

  // 3. ReactDOM.createPortal을 사용하여 콘텐츠를 렌더링할 위치와 방법을 설정하고 반환
  return ReactDOM.createPortal(content, portalRoot)
}

// SideDrawer 컴포넌트를 내보내기
export default SideDrawer
```

# 포털 ( **ReactDOM.createPortal )**

```jsx
React에서 ReactDOM.createPortal은 포털(Portal)을 생성하는 메서드이다.

포털은 React 트리의 일부가 아닌 다른 DOM 요소에 자식 요소를 렌더링할 수 있게 해준다.

일반적으로 Modal, Tooltip, Popover 등을 구현할 때 유용하게 사용된다.
```

## React트리란?

```jsx
React 트리는 React 앱의 구조를 나타내는 가상의 계층 구조라고 생각할 수 있다.

일반적으로 React 컴포넌트들은 부모-자식 관계를 가지며 트리 형태를 이루고 있다.

이 구조 안에서 각 컴포넌트는 부모 컴포넌트로부터 상태와 속성을 상속받아 렌더링되고, 이를 통해 화면이 구성된다.

포털은 이러한 React 트리의 일부가 아닌, 외부에 위치한 다른 HTML DOM 요소에 컴포넌트를 렌더링할 수 있게 해준다.

다시 말해, 포털은 React 트리 외부에 있는 특정 DOM 요소에 자식 요소를 렌더링하는 기능을 제공한다.

예를 들어, 모달 창을 생각해보자.

모달은 일반적으로 페이지의 특정 위치에 나타나야 하며,

이를 위해서는 React 트리 외부의 DOM 요소에 해당 모달 컴포넌트를 렌더링해야 한다.

포털을 사용하면 모달을 React 트리 밖에 있는 특정 DOM 요소에 부착할 수 있다.

간단히 말하면, 포털은 React의 트리 구조 밖에 있는 HTML 요소에 컴포넌트를 효과적으로 삽입할 수 있는 기능을 제공하여,

특정 UI 요소를 트리의 구조와는 독립적으로 처리할 수 있게 해준다.

* 한마디로 외부적인 요소 ( 모달, 툴팁 등등 외적 요소를 나타나게 할 때 사용하는것 )
```

## **왜 `createPortal`이 필요한가?**

```jsx
React 앱에서 UI는 일반적으로 하나의 루트 DOM 요소에서 시작한다.

하지만 때로는 모달 창과 같이 다른 DOM 요소에 렌더링해야 하는 경우가 있다.

createPortal은 이런 상황에서 도움이 된다.
```

## **요약**

```jsx
ReactDOM.createPortal은 React에서 포털을 생성하는 데 사용된다.

포털은 React 트리의 일부가 아닌 다른 DOM 요소에 자식을 렌더링할 수 있게 해준다.

주로 모달이나 팝오버 등을 다른 DOM 요소에 렌더링해야 할 때 활용된다.
```

## **예제를 통한 설명**

```jsx
아래의 예제에서는 Modal 컴포넌트를 사용하여 포털을 만드는 방법을 보여준다.
```

```jsx
import React from 'react'
import ReactDOM from 'react-dom'

// 함수형 컴포넌트 Modal 선언
const Modal = ({ children }) => {
  // modal-root라는 ID를 가진 DOM 요소를 찾아 modalRoot에 할당
  const modalRoot = document.getElementById('modal-root')

  // ReactDOM.createPortal을 사용하여 모달의 children을 modalRoot에 렌더링
  return ReactDOM.createPortal(children, modalRoot)
}

// 함수형 컴포넌트 App 선언
const App = () => {
  return (
    <div>
      <h1>My App</h1>
      {/* 모달은 다른 DOM 요소에 렌더링됩니다. */}
      <Modal>
        <p>This is a modal content!</p>
      </Modal>
    </div>
  )
}

// App 컴포넌트를 내보냄
export default App
```

```jsx
이 예제에서 Modal은 자식 컴포넌트를 받아 포털로 렌더링한다.

( {children}은 React 컴포넌트 내에서 렌더링된 자식 요소들을 나타내는 특별한 prop이다.

React에서 부모 컴포넌트가 자식 컴포넌트를 포함하고 있는 경우, 이 자식 컴포넌트들은 부모 컴포넌트의 children prop을 통해 전달된다. )

createPortal의 두 번째 매개변수는 포털로 사용할 DOM 요소이다.

이 경우에는 modal-root라는 ID를 가진 DOM 요소가 필요하다. ( index.html 에 넣어줘야 한다 )
```

### **ModalOverlay 컴포넌트 (부분 설명)**

```jsx
const ModalOverlay = (props) => {
  // 1. JSX로 모달의 내용을 정의합니다.
  const content = (
    <div className={`modal ${props.className}`} style={props.style}>
      {/* 1.1. 모달 헤더 부분을 생성합니다. */}
      <header className={`modal__header ${props.headerClass}`}>
        <h2>{props.header}</h2>
      </header>
      {/* 1.2. 모달 내용 부분을 생성합니다. */}
      <form
        onSubmit={
          // 1.2.1. onSubmit 함수가 주어졌다면 해당 함수를 실행하고,
          //        그렇지 않으면 기본 이벤트 동작을 방지하는 함수를 실행합니다.
          props.onSubmit ? props.onSubmit : (event) => event.preventDefault()
        }
      >
        <div className={`modal__content ${props.contentClass}`}>
          {/* 1.2.2. 모달 내용(children)을 동적으로 받아옵니다. */}
          {props.children}
        </div>
        {/* 1.3. 모달 푸터 부분을 생성합니다. */}
        <footer className={`modal__footer ${props.footerClass}`}>
          {/* 1.3.1. 모달 푸터(footer)를 동적으로 받아옵니다. */}
          {props.footer}
        </footer>
      </form>
    </div>
  )

  // 2. ReactDOM.createPortal을 사용하여 모달을 특정 DOM 요소에 렌더링합니다.
  //    (modal-hook이라는 ID를 가진 DOM 요소에 렌더링됩니다.)
  return ReactDOM.createPortal(content, document.getElementById('modal-hook'))
}
```

# 리액트 **Ref**

```jsx
React에서의 Ref 역할:

React는 일반적으로 데이터를 상태(state)와 속성(props)를 통해 관리한다.

그러나 때로는 직접 DOM에 접근하거나 다른 컴포넌트의 인스턴스를 얻어야 할 경우가 있다. 이때 Ref가 사용된다.

Ref는 React에서 사용되는 개념으로, 주로 DOM 요소나 클래스 컴포넌트에 접근하기 위한 방법을 제공한다.

React에서는 주로 선언적인 방식으로 상태와 UI를 관리하지만,

가끔씩은 선언적인 스타일을 벗어나 직접 DOM이나 다른 컴포넌트에 접근해야 하는 경우가 있다. 이때 Ref를 사용한다.

간단히 말하면, Ref는 React 컴포넌트 내에서 특정한 요소에 "참조"를 생성하는 객체이다.

이 참조를 사용하면 해당 요소에 직접적으로 접근하여 값을 읽거나 변경할 수 있다.

이것은 React의 주요 철학 중 하나인 "선언적인 프로그래밍"을 깨지 않으면서도 필요한 경우에만 "명령형 프로그래밍"을 허용한다.
```

```jsx
간단한 예를 들어보겠다.

만약 특정 input 요소에 포커스를 주고 싶다면, Ref를 사용하여 해당 요소에 접근할 수 있다.

이때 선언적인 방식으로는 힘들었던 작업을 Ref를 통해 쉽게 수행할 수 있다.

* 아래 코드의 주요 목적은 컴포넌트가 처음으로 렌더링될 때 input 요소에 자동으로 포커스를 주는 것
```

```jsx
import React, { useRef, useEffect } from 'react'

const MyComponent = () => {
  // Ref 생성
  const myInputRef = useRef()

  // 컴포넌트가 마운트될 때 실행되는 효과
  useEffect(() => {
    // Ref를 사용하여 input 요소에 포커스를 설정
    myInputRef.current.focus()
  }, [])

  // JSX에서 Ref를 할당
  return <input ref={myInputRef} />
}
```

```jsx
useRef 훅을 사용하여 myInputRef라는 Ref 객체를 생성

useEffect 훅을 사용하여 컴포넌트가 마운트될 때 실행되는 효과를 정의한다.

myInputRef.current를 사용하여 Ref가 현재 참조하는 DOM 요소에 직접적으로 접근한다.

( current는 useRef 객체의 속성 중 하나이다. useRef 객체는 .current라는 속성을 가지고 있으며,

이 속성은 useRef로 참조한 대상에 대한 실제 값 또는 DOM 요소를 가리킨다 )

current 속성은 이 객체가 현재 참조하고 있는 값을 나타냄 그렇기 때문에 현재는 input 을 가리킴

focus() 메서드를 호출하여 input 요소에 포커스를 설정한다

JSX에서 ref 속성을 사용하여 Ref를 input 요소에 할당한다.

이제 myInputRef.current를 통해 해당 input 요소에 접근할 수 있다.
```

## Ref 와 ReactDOM.createPortal 의 차이

```jsx
Ref는 React 컴포넌트 내에서 특정 DOM 요소에 직접 접근하기 위한 것이고,

ReactDOM.createPortal은 React 컴포넌트의 일부를 다른 DOM 요소로 렌더링하기 위한 것
```

## **Ref 사용 상황**

### **DOM 요소에 접근:**

```jsx
Ref를 사용하여 특정 DOM 요소에 직접적으로 접근할 수 있다. 예를 들어,

특정 input 요소에 포커스를 설정하거나 값을 가져오려는 경우 Ref를 사용할 수 있다.
```

```jsx
import React, { useRef, useEffect } from 'react'

const MyComponent = () => {
  const myInputRef = useRef()

  useEffect(() => {
    // 컴포넌트가 마운트되면 input 요소에 포커스를 설정합니다.
    myInputRef.current.focus()
  }, [])

  return <input ref={myInputRef} />
}
```

### **외부 라이브러리와 통합:**

```jsx
외부 라이브러리가 DOM 요소에 접근하려면 Ref를 활용할 수 있다.

예를 들어, D3.js, Chart.js와 같은 라이브러리와 통합할 때 사용할 수 있다.
```

```jsx
import React, { useRef, useEffect } from 'react'
import * as d3 from 'd3'

const D3Chart = () => {
  const chartRef = useRef()

  useEffect(() => {
    // D3를 사용하여 차트를 그리기 위해 chartRef를 활용합니다.
    const chart = d3.select(chartRef.current)
    // ... D3 로직 ...
  }, [])

  return <div ref={chartRef}></div>
}
```

### **컴포넌트 간 통신:**

```jsx
Ref를 사용하여 부모 컴포넌트에서 자식 컴포넌트로 데이터를 전달하거나

자식 컴포넌트에서 부모 컴포넌트의 메서드를 호출하는 등 컴포넌트 간의 통신에 활용할 수 있다.
```

```jsx
import React, { useRef } from 'react'
import ChildComponent from './ChildComponent'

const ParentComponent = () => {
  const childRef = useRef()

  const handleClick = () => {
    // 자식 컴포넌트의 메서드 호출
    childRef.current.doSomething()
  }

  return (
    <>
      <ChildComponent ref={childRef} />
      <button onClick={handleClick}>Call Child Method</button>
    </>
  )
}
```

### **애니메이션 및 DOM 조작:**

```jsx
Ref를 사용하여 애니메이션을 제어하거나 특정 DOM 조작을 수행할 수 있다.

예를 들어, 애니메이션 트리거 시점이나 특정 DOM 요소의 크기를 측정할 때 사용할 수 있다.
```

```jsx
import React, { useRef, useState, useEffect } from 'react'

const AnimatedComponent = () => {
  const boxRef = useRef()
  const [width, setWidth] = useState(0)

  useEffect(() => {
    // 컴포넌트가 마운트되면 boxRef의 너비를 측정하여 상태 업데이트
    setWidth(boxRef.current.offsetWidth)
  }, [])

  return (
    <div ref={boxRef} style={{ width: `${width}px`, transition: 'width 0.5s' }}>
      Animated Box
    </div>
  )
}
```
