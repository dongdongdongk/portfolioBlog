- 이미 개발된 클래스를 재 사용하여 새로운 클래스를 만들기에 중복되는 코드를 줄인다.
- 부모 클래스의 한번의 수정으로 모든 자손 클래스 수정이 가능하여 유지보수 시간을 줄일 수 있다.
- 우리가 프로그래밍 언어에서 서로간의 관계를 나타내기 위해 다이어그램을 많이 사용하는데 상속에는 화살표가 사용된다.
  화살표의 방향은 상속을 해주는 상위클래스 쪽으로 실선 화살표를 그려주고 있으며, 이는 상속관계를 의미한다.

```java
문법 : public class A {
				int field1;
				void method1() { 내용 }

			public class B extends A {         // extends A 를 통해 상속 받는다.
	      String field2;                   // 결과적으로 class A 의 field1 과 method1 사용가능
        void method2() { 내용 }          // 상속받을시 생성자는 제외하고 상속받는다.


*필드로 사용할지 상속으로 사용할지 결정하는법

상속(상속관계)
자식클래스 is a 부모클래스 ex)Car 가 Engine입니다. (x)

포함(필드로 선언)
자식클래스 has a 부모클래스 ex)Car 가 Engine을 가지고 있습니다. (o)

*상속이 여러개 필요할때는 비중이 높은걸 상속하고 나머지는 필드로
```

- 부모 없는 자식 없다.(자식 객체가 만들어질 때 부모 객체도 같이 생성된다.)
- 자식 객체가 생성될 때 부모 객체가 먼저 생성되고 그 다음 자식 객체가 생성된다.
- 생성자의 호출이 있어야 객체를 생성할 수 있다.

```java
 DmbCellPhone dmbCellPhone = new DmbCellPhone(); // 1.자식 클래스 호출

 public DmbCellPhone() { // 4.자식 생성자 생성
		super();  // 2. 상위의 라는 뜻으로 컴파일러가 자식의 생성자 첫 줄에 자동으로 넣어준다.
	 }          //   (부모 생성자 호출)

 public CellPhone() {  // 3.부모 생성자 생성

	 }

// 1 - 2 -3 - 4  순으로 진행
// 부모 생성자가 자동으로 먼저 만들어 지고 자식 생성자가 만들어진다.
// 호출은 자식이 먼저 되지만 생성은 부모가 먼저 생성된다.
```

```java
// 부모 생성자가 매개 변수가 있는 생성자가 있다면 명시적으로 자식 생성자의 부모 생성자 (super)
// 에 매개값 을 넣어줘야 한다
```
