```xml
1. 목록 보기
	 ls
	 ls -a  : 숨김파일 및 폴더 까지 보기
	 ls -l  : 자세히 보기
	 ls -al

2. 디렉토리 이동
	 cd ../   : 한단계 위로 이동
	 cd ./    : 현재 위치에서
	 cd 폴더명 : 해당 폴더로 이동

	 - Linux에서 최상위 폴더 /(root)

	cd ../app2
	cd /app2

3. 현재위치 확인
	pwd

4. 디렉토리(폴더) 생성
	mkdir 폴더명  : 현재 위치에서 폴더 생성

	mkdir ../app/test/
	mkdir /app/test/

5. 삭제
	1) 파일 삭제
		rm -f 파일명 : 현재 위치의 해당 파일 삭제
	  rm -f ../app/test.war
		rm -f /app/test.war
		-f : force

	2) 디렉토리(폴더) 삭제
	 rm -rf 디렉토리명 : 현재 위치의 해당 디렉토리삭제
	 rm -rf ../app/test/
	 rm -rf /app/test/

6. 복사
	 cp 파일명 목적지경로 : 현재위치의 파일을 해당경로 폴더에 복사 붙여넣기
	 cp test.war /app2/
	 cp /app/test.war /app2/

7. 파일 이동
	 mv 파일명 목적지경로 : 현재위치의 파일을 해당경로 폴더에 잘라내서 붙여넣기
	 mv test.war /app2/
	 mv /app/test.war /app2/

8. 현재 ip주소 확인
	 hostname -I
	 ifconfig

9. 권한변경
	 소유자 그룹 그외
	 rwx   rwx  rwx
	 r : read      4
	 w : write     2
	 x : execute   1

	rwxr-xr-x a.txt  755

	chmod 소유자 그룹 그외 파일이나폴더명
	chmod 777 test.txt

	chmod 777 ../app/test.txt
	chmod 777 /app/test.txt

```
