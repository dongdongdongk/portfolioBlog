# { "PLAYER_LOOSE" 이벤트 처리 }

## 1. EventEmitter 클래스

```jsx
Phaser.Events.EventEmitter를 상속받아 이벤트를 관리하는 클래스를 만들었다.

이벤트 시스템을 활용하면 게임 내에서

특정 상황이 발생했을 때(예: 플레이어가 체력이 0이 되어 패배함)

다른 곳에서 해당 이벤트를 감지하고 반응할 수 있다.
```

```jsx
import Phaser from 'phaser'

class EventEmitter extends Phaser.Events.EventEmitter {
  constructor() {
    super()
  }
}

export default new EventEmitter()
```

```jsx
Phaser.Events.EventEmitter 클래스를 상속받아 새로운 EventEmitter 클래스를 정의함.

생성자에서 super();를 호출하여 Phaser.Events.EventEmitter의 기능을 그대로 가져옴.

new EventEmitter()를 생성하여

이벤트 관리 객체를 export함 → 어디서든 이 객체를 불러와서 이벤트를 발생시키거나 감지할 수 있음.
```

## 2. 플레이어가 피격되는 로직 (`takesHit` 메서드)

```jsx
플레이어가 적의 공격을 받았을 때 체력이 줄어들고, 체력이 0이 되면 게임 오버 이벤트를 발생시킨다.
```

```jsx
takesHit(source) {
    if (this.hasBeenHit) {
        return;
    }

    this.health -= source.damage || source.properties.damage || 0;
    if(this.health <= 0) { // EventEmitter.emit("PLAYER_LOOSE")를 호출
        EventEmitter.emit("PLAYER_LOOSE");
        return;
    }

    console.log("player got hit");
    this.hasBeenHit = true;
    this.bounceOff(source);
    const hitAim = this.playDamageTween();

    this.hp.decrease(this.health);

    source.deliversHit && source.deliversHit(this);

    // 일정 시간(800ms) 후 다시 피격 가능하도록 설정
    this.scene.time.delayedCall(800, () => {
        this.hasBeenHit = false;
        hitAim.stop();
        this.clearTint();
    });
}

```

```jsx
체력이 0 이하가 되면 EventEmitter.emit("PLAYER_LOOSE")를 호출하여 "PLAYER_LOOSE" 이벤트 발생 → 게임이 종료됨.
```

### `emit`을 사용하는 이유

```jsx
1. 코드를 더 깔끔하게 관리 가능

		게임 내 여러 곳에서 "게임 오버" 이벤트를 감지할 수 있음.

		예를 들어, UI 업데이트, 배경음악 정지, 결과 창 표시 등을 한 곳에서 관리 가능.

2. 느슨한 결합 (Loose Coupling)

		플레이어가 죽었을 때,

		UI나 사운드 시스템과 직접적으로 연결할 필요 없이 "PLAYER_LOOSE" 이벤트만 발생시키면 됨.

		UI나 사운드 시스템은 "PLAYER_LOOSE" 이벤트를 감지해서 필요한 작업을 수행.
```

### `emit`과 `on`의 관계

```jsx
emit("이벤트_이름") → 이벤트 발생

on("이벤트_이름", 함수) → 이벤트 감지 후 실행할 함수 등록

1. 이벤트 발생 (emit)

		EventEmitter.emit("PLAYER_LOOSE");

				"PLAYER_LOOSE"라는 이벤트를 발생시킴.

				이 이벤트를 감지하는 코드가 있다면 실행됨.



2. 이벤트 감지 (on)

		EventEmitter.on("PLAYER_LOOSE", () => {
		    alert("You lost! Click OK to restart the game.");
		});


			"PLAYER_LOOSE" 이벤트가 발생하면 콜백 함수 실행.

		  이 경우, 게임 오버 메시지를 띄우는 alert 창이 나타남.
```

## `this.createGameEvents()`를 통해 이벤트 시스템을 초기화

```jsx
create() {
    this.score = 0;
    this.hud = new Hud(this, 0, 0).setDepth(1)

    const map = this.createMap();
    initAnims(this.anims);
    const layers = this.createLayers(map);
    const playerZones = this.getPlayerZones(layers.playerZones);
    const player = this.createPlayer(playerZones.start);

    const enemies = this.createEnemies(layers.enemySpawns, layers.platformsColliders);
    const collectables = this.createCollectables(layers.collectables);

    this.createPlayerColliders(player, {
        colliders: {
            platformsColliders: layers.platformsColliders,
            projectiles: enemies.getProjectiles(),
            collectables,
            traps: layers.traps,
        },
    });


    this.createEnemyColliders(enemies, {
        colliders: {
            platformsColliders: layers.platformsColliders,
            player,
        },
    });

    this.createGameEvents(); // 이벤트 시스템을 초기화
    this.createEndOfLevel(playerZones.end, player);
    this.setupFollowupCameraOn(player);
}
```

# { 게임 씬 재시작 오류 해결 및 최적화 }

## 1. **문제 발생: 씬을 재시작할 때 오류 발생**

```jsx
    createGameEvents() {
        EventEmitter.on("PLAYER_LOOSE", () => {
            console.log('player loose')
            this.scene.restart({gameStatus: 'PLAYER_LOOSE'});
        })
    }
```

### 오류 1: "Cannot read property 'onFloor' of undefined”

```jsx
현상:

		플레이어가 죽으면 씬을 재시작하는데,

		콘솔에서 "Cannot read property 'onFloor' of undefined" 오류가 발생합니다.

원인:

		씬이 재시작될 때 update 함수가 계속 실행되는데,

		이때 이미 플레이어 객체가 삭제되어 body가 존재하지 않음.
```

```jsx
해결 방법:

		update 함수에서 객체가 존재하는지 확인한 후 ( !this.body ) 로직을 실행하도록 변경.
```

```jsx
update() {
    if (this.hasBeenHit || this.isSliding || !this.body) {
        return;
    }
}
```

### 오류 2: "Cannot read property 'velocity' of undefined”

```jsx
현상:

		Snaky 적이 존재할 때 씬을 재시작하면 "Cannot read property 'velocity' of undefined" 오류 발생.

원인:

		적(Snaky) 객체가 이미 삭제되었음에도 불구하고, update 함수에서 body.velocity를 참조하려고 시도.


해결 방법:

		update 함수에서 객체가 활성 상태(active)인지 확인한 후 로직 실행. !this.active
```

```jsx
update(time, delta) {
    super.update(time, delta);
    if (!this.active) {
        return;
    }

    if (this.body.velocity.x > 0) {
        this.lastDirection = Phaser.Physics.Arcade.FACING_RIGHT;
    } else {
        this.lastDirection = Phaser.Physics.Arcade.FACING_LEFT;
    }
}
```

## 2. **게임 씬을 여러 번 재시작하면 실행 속도가 느려지는 문제**

### 현상: 게임을 계속 재시작하면 점점 느려짐

```jsx
원인:
씬이 재시작될 때마다 createGameEvents() 함수가 여러 번 실행되며 이벤트가 중복 등록됨.

예를 들어:

1번째 재시작 → 1번 실행

2번째 재시작 → 2번 실행

3번째 재시작 → 4번 실행

4번째 재시작 → 8번 실행

→ 계속 배수로 증가하여 성능 저하 발생.

1. 씬이 시작될 때 createGameEvents() 실행됨

		createGameEvents() 함수에서 "PLAYER_LOOSE" 이벤트를 감지하도록 설정함.

		처음 한 번 실행되므로 이벤트 리스너가 1개 등록됨.

2. 게임 오버 시 this.scene.restart() 실행됨

		씬이 재시작되면서 create() 함수가 다시 실행됨.

		그리고 createGameEvents()도 다시 실행됨.

		"PLAYER_LOOSE" 이벤트에 대한 새로운 리스너가 추가됨.

		기존 리스너는 삭제되지 않음.

		따라서 이제 이벤트가 2번 실행됨.

3. 재시작을 반복하면?

		씬이 재시작될 때마다 createGameEvents()가 실행됨.

		"PLAYER_LOOSE" 이벤트 리스너가 또 추가됨.

		기존 리스너들이 제거되지 않아서 중복 실행이 계속 늘어남.

		실행 횟수: 1 → 2 → 4 → 8 → 16 → 32 ... 이런 식으로 배수 증가.
```

### ✅ **해결 방법: 중복 이벤트 등록 방지**

```jsx
씬을 재시작할 때 createGameEvents()가 다시 실행되지 않도록

gameStatus를 체크하여 이미 구독된 이벤트라면 재등록하지 않음.
```

```jsx
create(gameStatus) {
    this.score = 0;
    this.hud = new Hud(this, 0, 0).setDepth(1);

    const map = this.createMap();
    initAnims(this.anims);
    const layers = this.createLayers(map);
    const playerZones = this.getPlayerZones(layers.playerZones);
    const player = this.createPlayer(playerZones.start);
    const enemies = this.createEnemies(layers.enemySpawns, layers.platformsColliders);
    const collectables = this.createCollectables(layers.collectables);

    this.createPlayerColliders(player, {
        colliders: {
            platformsColliders: layers.platformsColliders,
            projectiles: enemies.getProjectiles(),
            collectables,
            traps: layers.traps,
        },
    });

    this.createEnemyColliders(enemies, {
        colliders: {
            platformsColliders: layers.platformsColliders,
            player,
        },
    });

    this.createEndOfLevel(playerZones.end, player);
    this.setupFollowupCameraOn(player);

    // ⚠️ 게임이 재시작된 경우, 이벤트 중복 등록 방지
    if (gameStatus === "PLAYER_LOOSE") {
        return;
    }

    this.createGameEvents();
}

```

```jsx
gameStatus 를 매개변수로 받고 아래 if 에서 체크
```

# { 게임에서 화면 밖으로 떨어졌을 때 게임 재시작 구현 }

## 1. **게임 오버 조건 추가**

```jsx
플레이어가 화면 아래로 떨어지면 게임을 재시작하도록 update() 함수에서 조건을 추가합니다.
```

### 기존 `update()` 함수에서 추가된 부분

```jsx
if (this.getBounds().top > this.scene.config.height + 100) {
  EventEmitter.emit('PLAYER_LOOSE')
  return
}
```

```jsx
this.getBounds().top : 플레이어의 최상단 좌표를 가져옵니다.

this.scene.config.height + 100 : 화면 높이보다 100px 아래에 있을 경우 게임을 종료합니다.

EventEmitter.emit("PLAYER_LOOSE") : "PLAYER_LOOSE" 이벤트를 발생시켜 게임 재시작을 트리거합니다.

return; : 이후 코드를 실행하지 않도록 함수 종료.
```

## 2. **높이를 조정하여 자연스러운 게임 오버 처리**

```jsx
this.getBounds().top > this.scene.config.height + 100
```

```jsx
+100을 조정하여 플레이어가 완전히 화면 아래로 사라지고 나서 게임을 재시작할 수 있습니다.

+200으로 설정하면 더 오래 기다린 후 게임이 종료됩니다
```

## 3. **최종 코드**

```jsx
update() {
    if (this.hasBeenHit || this.isSliding || !this.body) {
        return;
    }

    // 화면 아래로 떨어지면 게임 오버 이벤트 발생
    if (this.getBounds().top > this.scene.config.height + 100) {
        EventEmitter.emit("PLAYER_LOOSE");
        return;
    }

    const { left, right, space } = this.cursors;
    const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space);
    const onFloor = this.body.onFloor();

    if (left.isDown) {
        this.lastDirection = Phaser.Physics.Arcade.FACING_LEFT;
        this.setVelocityX(-this.playerSpeed);
        this.setFlipX(true);
    } else if (right.isDown) {
        this.lastDirection = Phaser.Physics.Arcade.FACING_RIGHT;
        this.setVelocityX(this.playerSpeed);
        this.setFlipX(false);
    } else {
        this.setVelocityX(0);
    }

    if (isSpaceJustDown && (onFloor || this.jumpCount < this.consecutiveJumps)) {
        this.setVelocityY(this.jumpSpeed);
        this.jumpCount++;
    }

    if (onFloor) {
        this.jumpCount = 0;
    }

    if (this.isPlayingAnims("throw") || this.isPlayingAnims("slide")) {
        return;
    }

    onFloor
        ? this.body.velocity.x !== 0
            ? this.play("run", true)
            : this.play("idle", true)
        : this.play("jump", true);
}

```

### TileSprite란?

### 배경 생성 함수 (`createBG`)

```jsx
createBG(map) {
    // 1. "distance_bg"라는 이름의 오브젝트 레이어에서 첫 번째 오브젝트를 가져온다.
    //    Tiled에서 배경을 추가할 때 distance_bg 레이어에 배경 이미지를 오브젝트로 삽입했기 때문에
    //    해당 오브젝트의 위치와 크기를 가져와서 Phaser에서 배경으로 활용한다.
    const bgObject = map.getObjectLayer("distance_bg").objects[0];

    // 2. Phaser의 tileSprite를 이용하여 배경을 생성한다.
    //    tileSprite는 이미지가 반복되는 구조를 만들 수 있는 스프라이트 객체다.
    //    우리는 단순한 이미지가 아니라, 화면이 넓어질 때 계속 배경이 이어지는 효과를 원하므로 tileSprite를 사용한다.
    this.add.tileSprite(
        bgObject.x,  // 배경의 X 좌표 (Tiled에서 설정한 오브젝트의 X 위치)
        bgObject.y,  // 배경의 Y 좌표 (Tiled에서 설정한 오브젝트의 Y 위치)
        this.config.width,  // 배경의 가로 길이 (게임 화면의 전체 너비와 동일하게 설정)
        bgObject.height,  // 배경의 세로 길이 (Tiled에서 설정한 오브젝트의 높이)
        "bg-spikes-dark"  // 미리 로드된 배경 이미지의 키 (preload에서 설정한 키값)
    )
    .setOrigin(0, 1)   // 원점을 (0,1)로 설정하여 배경의 왼쪽 아래를 기준점으로 삼는다.
                       // 기본적으로 Phaser의 스프라이트 원점은 (0.5,0.5) 즉, 정중앙이므로
                       // 배경이 정확한 위치에 배치되도록 조정한다.

    .setDepth(-10)     // 배경이 맨 뒤쪽에 위치하도록 깊이 값을 -10으로 설정.
                       // Phaser에서는 Depth 값이 클수록 화면의 앞쪽에 배치되고, 작을수록 뒤쪽에 배치됨.
                       // 즉, 플레이어나 다른 오브젝트보다 배경이 뒤에 있도록 설정한다.

    .setScrollFactor(0, 1); // 배경의 스크롤 속도를 조정한다.
                            // X축(가로 방향) 스크롤은 0으로 설정하여 배경이 고정된 느낌을 주고,
                            // Y축(세로 방향) 스크롤은 1로 설정하여 카메라가 위아래로 움직일 때 배경도 같이 움직이도록 한다.
}

```

# { 패럴랙스(Parallax) 효과 구현하기 }

```jsx
이번 강의에서는 게임의 배경을 더 생동감 있게 보이도록 하는 패럴랙스 효과(Parallax Effect) 를 구현할 것입니다.

패럴랙스 효과는 배경이 플레이어보다 더 천천히 움직여서 깊이감을 주는 기술입니다.

이 기능을 추가하면 게임의 시각적 경험이 훨씬 더 풍부해질 것입니다.
```

## 1. 패럴랙스 효과란?

```jsx
패럴랙스 효과란, 카메라(또는 플레이어)가 이동할 때 배경이 다른 속도로 움직이도록 하는 기술 입니다.

일반적으로 전경(Foreground)은 빠르게, 배경(Background)은 느리게 움직이게 합니다.

이렇게 하면 원근감이 생기고 게임의 깊이감이 증가합니다.

예를 들어, 실제로 우리가 창밖을 보면서 움직일 때 가까운 사물은 빠르게 지나가고

먼 배경(하늘이나 산)은 천천히 움직이는 것과 같은 원리입니다.
```

## 2. 기존 코드에서 패럴랙스 효과 적용

```jsx
Phaser에서는 tileSprite를 사용하여 반복되는 배경을 쉽게 만들 수 있습니다.

우리는 update() 함수에서 tileSprite.tilePositionX 값을 조정하여 패럴랙스 효과를 적용할 것입니다.
```

## 3. 배경 이미지 생성하기 (`createBG` 함수)

```jsx
우선, 배경 이미지를 생성하는 함수를 살펴보겠습니다.
```

```jsx
createBG(map) {
    const bgObject = map.getObjectLayer("distance_bg").objects[0];

    // 가시 이미지 (Spikes Image) - 배경 중간 부분
    this.spikesImage = this.add.tileSprite(
        bgObject.x, bgObject.y,
        this.config.width, bgObject.height,
        "bg-spikes-dark"

    .setDepth(-10)     // 깊이 값 설정 (앞쪽 요소보다 뒤에 배치)
    .setScrollFactor(0, 1);  // 카메라 움직임에 영향을 주지 않음

    this.skyImage = this.add.tileSprite(
        0, 0,

        "sky-play"
    )
    .setOrigin(0, 0)   // 왼쪽 상단을 기준점으로 설정
    .setDepth(-11)     // 깊이 값 설정 (스파이크보다 더 뒤에 배치)
    .setScale(1.1)     // 이미지 크기 확대
```

## 4. 배경 이미지 움직이게 하기 (`update` 함수)

```jsx
배경을 움직이려면 update() 함수에서 tilePositionX 값을 조정해야 합니다.
```

```jsx
update() {
    // 스파이크 이미지의 X 좌표를 카메라 이동값 * 0.3 만큼 이동
    this.spikesImage.tilePositionX = this.cameras.main.scrollX * 0.3;

    // 하늘 이미지의 X 좌표를 카메라 이동값 * 0.1 만큼 이동
    this.skyImage.tilePositionX = this.cameras.main.scrollX * 0.1;
}
```

### tilePositionX란?

```jsx
tilePositionX는 배경 이미지가 얼마나 왼쪽 또는 오른쪽으로 이동하는지를 결정하는 값이야.

Phaser에서 tilePositionX를 변경하면 배경이 움직이는 것처럼 보이게 할 수 있어

즉

this.spikesImage.tilePositionX를 this.cameras.main.scrollX와 같게 하면 배경이 플레이어와 같은 속도로 움직여 패럴랙스 효과가 없어져.

하지만 this.cameras.main.scrollX * 0.3처럼 0.3을 곱해주면 배경이 30% 속도로 움직이면서 더

느리게 보여서 깊이감이 생겨! 숫자를 작게 할수록 배경이 더 천천히 움직여 멀리 있는 것처럼 보이게 만들 수 있어
```

### 어떻게 동작하나요?

```jsx
this.cameras.main.scrollX → 현재 카메라의 X 위치

이를 특정 배율(0.3 또는 0.1)로 곱해서 tilePositionX 값으로 설정

결과적으로, 카메라가 오른쪽으로 이동하면 배경도 천천히 오른쪽으로 이동하게 됨

이 코드는 플레이어가 움직일 때 배경이 자연스럽게 따라오도록 만드는 역할을 합니다.

this.cameras.main.scrollX는 카메라가 얼마나 이동했는지를 나타내는데,

이 값을 그대로 사용하면 배경이 플레이어와 같은 속도로 움직여서 입체감이 사라집니다.

그래서 배경마다 곱하는 숫자를 다르게 해서 이동 속도를 조절합니다.

예를 들어, this.spikesImage.tilePositionX = this.cameras.main.scrollX * 0.3;은

스파이크 배경이 카메라 이동 속도의 30% 속도로 움직이도록 해서 플레이어보다 천천히 움직이게 합니다.

마찬가지로 this.skyImage.tilePositionX = this.cameras.main.scrollX * 0.1;은 하늘 배경이 10% 속도로 더 천천히 움직이도록 해서

멀리 있는 배경처럼 보이게 합니다.

이렇게 하면 플레이어가 앞으로 갈 때 배경이 천천히 따라와서 깊이감 있는 화면 효과(패럴랙스 효과)가 만들어집니다!
```

## 5. 패럴랙스 효과가 적용되는 모습

```jsx
✅ 패럴랙스 없이 (잘못된 예)

만약 tilePositionX = this.cameras.main.scrollX; 처럼 그대로 적용하면 배경이 플레이어와 같은 속도로 이동합니다.

이 경우 배경과 플레이어가 따로 움직이는 효과가 전혀 없어집니다.

✅ 패럴랙스 적용 후 (올바른 예)

spikesImage.tilePositionX = this.cameras.main.scrollX * 0.3;

skyImage.tilePositionX = this.cameras.main.scrollX * 0.1;

이렇게 하면 배경이 느리게 이동하면서 자연스러운 깊이감이 생깁니다!
```
