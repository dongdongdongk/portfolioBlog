## Thymeleaf 사용 이유

```java
여러 기술중 Thymeleaf 을 사용하기로 결정한 이유는

* JSP 와 유사하게 ${} 을 별도 처리 없이 이용 가능하다

* Model 에 담긴 객체를 화면에서 JavaScript 로 처리하기 편리하다

* 연산이나 포맷과 관련된 기능을 추가적인 개발 없이 지원한다

* 개발 도구를 이용할 때 .html 파일로 생성하는데 문제가 없고 별도의 확장자를 이용하지 않는다.
```

```java
@Controller
@RequestMapping("/sample")
@Log4j2
public class SampleController {

    @GetMapping("/ex1")
    public void ex1() {
        log.info("ex1.....................");
    }

    @GetMapping({"/ex2"}) // 중괄호 {}를 사용하는 이유는 경로(path)를 배열 형태로 지정하여 여러 개의 경로를 한 번에 처리하기 위함 ex) @GetMapping({"/ex2", "/example2"})
    public void exModel(Model model) {
        List<SampleDTO> list = IntStream.rangeClosed(1,20).asLongStream().mapToObj(i -> {
            // IntStream.rangeClosed(1,20)는 1부터 20까지의 숫자를 생성하는 스트림을 생성
            // .asLongStream()은 이를 long 형식의 스트림으로 변환
            // .mapToObj(i -> { ... }) 스트림의 각 요소(숫자)를 사용하여 SampleDTO 객체를 생성하고 매핑합니다. 람다식을 사용하여 각 숫자를 입력으로 받아서 SampleDTO 객체를 생성합니다.
            // SampleDTO는 빌더 패턴을 사용하여 생성되며, sno, first, last, regTime 필드를 설정
           SampleDTO dto = SampleDTO.builder()
                   .sno(i)
                   .first("First.." + i)
                   .last("Last.." + i)
                   .regTime(LocalDateTime.now())
                   .build();
           return dto; // 만들어진 dto 전달
        }).collect(Collectors.toList());
        // .collect(Collectors.toList())는 이전 단계에서 생성된 SampleDTO 객체들을 리스트로 수집하는 부분입니다.
				// 즉, 스트림에서 생성된 모든 SampleDTO 객체들을 하나의 리스트로 모아줍니다.
        model.addAttribute("list",list);
    }
}
```

```java
@GetMapping({"/ex2"}) 의 value 속성값을 {} 로 처리하면 하나 이상의 URL 을 지정할 수 있다

(이는 나중에 Thymeleaf 실습을 위해서 URL 변경이 용이하게 하기 위해서 설정한거다)

* 위의 코드는 SampleDTO 타입의 객체를 20개 추가하고 Model에 담아서 전달했다.
```

## 제어문 처리

```java
Themeleaf 의 제어문 처리는

th:if ~ unless

등을 이용할 수 있고  삼항 연산자 스타일도 사용 가능하다
```

```java
th:if  /  th:unless

타임 리프는 조건이 맞지 않으면 태그 자체를 렌더링 하지 않는다. (렌더링 시 없애버림)

${...} 내부에 boolean 값을 넣으면 된다.

 true 면 출력 false 면 출력 x

th:if 는 ${} 가 참이면 출력

th:unless 는 ${} 가 거짓이면 출력
```

```java
예를 들어 sno 의 값이 5의 배수들만 출력하라는 지시가 있다면 다음과 같은 형태로 사용할 수 있다
```

### th:if 와 th:unless 를 사용하여 상황에 맞게 다른 내용 출력

```java
th:if 와 th:unless 를 사용하여 상황에 맞게 다른 내용을 출력하는 것이 가능해진다

다른 언어들은 if else 가 있지만 Thymeleaf 는 단독으로 처리 한다는 차이가 있다

예를 들어

"sno 가 5로 나눈 나머지가 0인 경우에는 sno 만을 출력하고 그렇지 않다면 SampleDTO 의 first 를 출력하라"

는 지시라면 다음과 같이 코드를 작성 가능하다
```

```java
<!DOCTYPE html>
<html lang="en" xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
    <ul>
        <li th:each="dto,state : ${list}">
            <span th:if="${dto.sno % 5 == 0}" th:text = "${'--------' + dto.sno}"></span> // 5의 배수면 -------------sno 출력
            <span th:unless="${dto.sno % 5 == 0}" th:text="${dto.first}"></span> // 5의 배수가 아니라면 first 출력
        </li>
    </ul>
</body>
</html>
```

## inline 속성

```java
서버에서 Thymeleaf를 사용하여 동적으로 생성된 데이터(웹 페이지가 실행될 때 서버에서 클라이언트(웹 브라우저)로 전송되는 데이터) 를 JavaScript 변수로 할당하여

클라이언트 측 스크립트에서 사용할 수 있도록 한다.

이것은 웹 페이지에서 서버 측 데이터를 JavaScript로 전달하고 처리하는데 유용한 방법이다.
```

```java
Thymeleaf 의 여러 속성 중에서 개발에 많이 도움되는 기능이 **inline** 속성이다

inline 속성은 주로 javaScript 처리에서 유용하다

thymeleaf는 기본적으로 HTML 에 맞춰 렌더링하는게 기본 값 쉽게 말해 평소 태그들은 <th:inline="html">인 느낌

그래서 이후에 <script></script>태그가 나올때, <script></script> 안에 있는 thymeleaf 문을 제대로 해석하지못함

그래서 <script th:inline="javascript"> 으로 선언해줘서 <script></script> 안에 있는 thymeleaf문을 제대로 읽을 수 있게 해줌

여기서 [[...]] =

은 HTML 텍스트로 출력되야하기에, thymeleaf가 렌더링 하면 안됨

그래서 <span th:inline="none"> 으로 읽지 못하게 하는것
```

```java
예제를 위해 SampleController 에 코드를 약간 추가한다
```

```java
@GetMapping({"/exInline"})
    public String exInline(RedirectAttributes redirectAttributes) {  // RedirectAttributes 객체를 파라미터로 받는다. 이 객체는 리다이렉트 시 데이터를 전달하는 데 사용
        log.info("exInline.........");

        SampleDTO dto = SampleDTO.builder()
                .sno(100L)
                .first("First..100")
                .last("Last...100")
                .regTime(LocalDateTime.now())
                .build();
        redirectAttributes.addFlashAttribute("result","success"); // 리다이렉트 시에 데이터를 전달하기 위해 "result"라는 속성 이름으로 "success"라는 값을 redirectAttributes에 추가. 이것은 리다이렉트 후에도 데이터를 유지하고, 다음 페이지에서 사용할 수 있도록 한다
        redirectAttributes.addFlashAttribute("dto", dto); // 동일한 방식으로 dto라는 이름으로 SampleDTO 객체를 redirectAttributes에 추가

        return "redirect:/sample/ex3"; //  /sample/ex3 경로로 리다이렉트
    }

@GetMapping("/ex3")
    public void ex3() {
        log.info("ex3");
    }
```

### th:block

