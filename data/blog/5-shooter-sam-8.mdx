## 🤖 AI Controller란?

### Controller의 종류

**게임 속 캐릭터는 누군가 조종해야 함!**

**1. Player Controller (플레이어 컨트롤러):**

```
플레이어 캐릭터 조종
→ 키보드/마우스 입력 받음
→ 사람이 조종
```

**2. AI Controller (AI 컨트롤러):**

```
적 캐릭터 조종
→ 코드로 동작 결정
→ 컴퓨터가 조종
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380662/notion-blog/_/_/_5_C_/_5_Shooter_Sam_-_8/image.png)

### 비유

```
플레이어 캐릭터 = 리모컨 자동차
  ↓
Player Controller = 리모컨 (사람이 조종)

적 캐릭터 = 자율주행 자동차
  ↓
AI Controller = 자율주행 시스템 (스스로 조종)
```

### Step 1: 플레이어 폰 찾기

```cpp
APawn* PlayerPawn = UGameplayStatics::GetPlayerPawn(GetWorld(), 0);
```

**분해해서 보기:**

**1. UGameplayStatics**

```cpp
UGameplayStatics::
```

- 게임플레이 유틸리티 클래스

---

**2. GetPlayerPawn**

```cpp
GetPlayerPawn(GetWorld(), 0)
```

- 플레이어 폰을 찾는 함수
- 2개 파라미터 필요

**파라미터 1: GetWorld()**

```cpp
GetWorld()
```

- 현재 게임 월드 반환
- "어느 월드에서 찾을까?"

**파라미터 2: 0**

```cpp
0
```

- 플레이어 인덱스
- 0 = 첫 번째 플레이어

**여러 플레이어가 있다면?**

```cpp
GetPlayerPawn(GetWorld(), 0);  // Player 1
GetPlayerPawn(GetWorld(), 1);  // Player 2
GetPlayerPawn(GetWorld(), 2);  // Player 3
```

---

**3. 반환값**

```cpp
APawn* PlayerPawn =
```

- APawn 포인터 반환
- 플레이어를 조종 중인 폰

**성공 시:**

```
PlayerPawn = 플레이어 캐릭터 주소
```

**실패 시:**

```
PlayerPawn = nullptr
(플레이어 없음)
```

---

### Step 2: 유효성 확인

```cpp
if (PlayerPawn)
```

**왜 체크하나요?**

```
만약 플레이어가 없다면?
→ PlayerPawn = nullptr
→ nullptr->함수() = 크래시! 💥

체크하면:
→ nullptr이면 if 블록 건너뜀
→ 안전! ✅
```

## 🎮 SetFocus 상세 설명

### 함수 시그니처

```cpp
void SetFocus(
    AActor* NewFocus,
    EAIFocusPriority::Type InPriority = EAIFocusPriority::Gameplay
);
```

---

### 파라미터 1: NewFocus

```cpp
AActor* NewFocus
```

- 쳐다볼 대상
- AActor 포인터

**예시:**

```cpp
SetFocus(PlayerPawn);     // 플레이어 쳐다보기
SetFocus(ImportantItem);  // 아이템 쳐다보기
SetFocus(Bomb);           // 폭탄 쳐다보기
```

---

### 파라미터 2: InPriority (우선순위)

```cpp
EAIFocusPriority::Type InPriority = EAIFocusPriority::Gameplay
```

**기본값이 있어서 생략 가능!**

**우선순위 종류:**

```cpp
EAIFocusPriority::Gameplay   // 가장 높음 (기본값)
EAIFocusPriority::Move       // 중간
EAIFocusPriority::Default    // 가장 낮음
```

---

### 우선순위가 왜 필요한가요?

**시나리오:**

```cpp
// 우선순위: Default
SetFocus(NormalEnemy, EAIFocusPriority::Default);
// "일반 적 쳐다봐"

// 우선순위: Gameplay (더 높음!)
SetFocus(DangerousEnemy, EAIFocusPriority::Gameplay);
// "위험한 적 쳐다봐!" ← 이게 우선!

// 결과: DangerousEnemy를 쳐다봄
```

**규칙:**

```
높은 우선순위가 낮은 우선순위 덮어씀
같은 우선순위면 최신 것 사용
```

---

### 우리 코드에서는?

```cpp
SetFocus(PlayerPawn);
// 기본값 사용: EAIFocusPriority::Gameplay
```

**완전히 쓰면:**

```cpp
SetFocus(PlayerPawn, EAIFocusPriority::Gameplay);
// 같은 의미!
```

## 🧹 ClearFocus

### 사용법

```cpp
void ClearFocus(EAIFocusPriority::Type InPriority);
```

**SetFocus의 반대!**

```cpp
// 플레이어 쳐다보기
SetFocus(PlayerPawn, EAIFocusPriority::Gameplay);

// 쳐다보기 중지
ClearFocus(EAIFocusPriority::Gameplay);
```

---

### 주의사항

**우선순위 맞춰야 함!**

```cpp
// ❌ 틀린 예
SetFocus(Player, EAIFocusPriority::Gameplay);
ClearFocus(EAIFocusPriority::Default);
// 안 꺼짐! (우선순위 다름)

// ✅ 올바른 예
SetFocus(Player, EAIFocusPriority::Gameplay);
ClearFocus(EAIFocusPriority::Gameplay);
// 꺼짐!
```

## 🗺️ Navigation Mesh (NavMesh)

### NavMesh가 뭔가요?

**NavMesh = AI가 걸어다닐 수 있는 영역을 표시한 메시**

**비유:**

```
건물 바닥 지도
  ├─ 초록색: 걸을 수 있음 ✅
  ├─ 빨간색: 계산 중 ⚠️
  └─ 없음: 못 감 ❌
```

**왜 필요한가요?**

```
AI가 어디로 갈 수 있는지 알아야 함
→ 벽 통과 X
→ 장애물 피해서 이동
→ NavMesh가 경로 알려줌
```

## 👁️ Line of Sight (시야)

### 시야가 뭔가요?

**Line of Sight = "볼 수 있나요?"**

```
AI ━━━━━━━→ Player
   (시야 확보) ✅

AI ━━━┃     Player
      벽 (가림)
   (시야 차단) ❌
```

**비유:**

```
숨바꼭질:
  - 술래가 날 보면 → 쫓아옴
  - 벽 뒤에 숨으면 → 못 찾음
```

---

### 현재 문제점

**지금 AI 동작:**

```
플레이어 추적
    ↓
벽 뒤로 숨음
    ↓
여전히 쫓아옴! ❌
(벽 돌아서 계속 옴)
```

**원하는 동작:**

```
플레이어 추적
    ↓
벽 뒤로 숨음
    ↓
멈춤! ✅
(못 보니까 안 쫓아옴)
```

---

## 💻 LineOfSightTo 함수

### 함수 설명

```cpp

    const AActor* Other,

    bool bAlternateChecks = false

```

**간단 사용:**

```cpp

```

---

### 반환값

```cpp

```

**어떻게 판단하나요?**

```

    ↓

    ↓

    Yes → true (볼 수 있음)
```

```cpp
{
    FVector ToPlayer = Player->GetActorLocation() - GetPawn()->GetActorLocation();
```
