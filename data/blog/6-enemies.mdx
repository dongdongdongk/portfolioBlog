## 3. Birdman 클래스 생성 (Birdman.js)

```jsx
Birdman이라는 적을 만들기 위해 클래스를 생성하고 기본 물리 설정을 적용합니다.
```

```jsx
import Phaser from 'phaser'
import collidable from '../mixins/collidable'

class Birdman extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y) {
    super(scene, x, y, 'birdman')

    scene.add.existing(this)
    scene.physics.add.existing(this)

    Object.assign(this, collidable)

    this.init()
  }

  init() {
    this.body.setGravityY(500) // 중력 적용 (아래로 떨어짐)
    this.setCollideWorldBounds(true) // 화면 밖으로 나가지 않도록 제한
    this.setOrigin(0.5, 1) // 적의 기준점을 설정 (중앙 하단)
  }
}

export default Birdman
```

```jsx
1. super(scene, x, y, "birdman")

		Birdman이라는 적을 생성하며, birdman은 Preload.js에서 불러온 스프라이트 시트 이름입니다.

2. scene.add.existing(this);

		현재 씬에 적을 추가합니다.

3. scene.physics.add.existing(this);

		물리 엔진을 적용하여 적이 중력을 받도록 설정합니다.

4. this.body.setGravityY(500);

		적이 자연스럽게 아래로 떨어지도록 중력 설정을 적용합니다.

5. this.setCollideWorldBounds(true);

		적이 화면 밖으로 나가지 않도록 제한합니다.
```

## 1. **적과 플레이어의 충돌 설정**

```jsx
🔹 개념

		현재 상태에서는 플레이어가 적과 충돌해도 아무런 반응이 없습니다.

		이를 해결하기 위해 콜라이더(Colliders) 를 설정해야 합니다.

🔹 방법

		scene.physics.add.collider(객체1, 객체2, 충돌 시 실행할 함수)

		이 기능을 사용하면 두 객체가 충돌했을 때 특정 동작을 실행할 수 있습니다.
```

```jsx
export default {
  addColliders(otherGameObject, callback) {
    this.scene.physics.add.collider(this, otherGameObject, callback, null, this)
    return this
  },
}
```

```jsx
위 코드에서 addColliders 함수는 현재 객체와 다른 게임 객체(otherGameObject)를 충돌 처리합니다.

그리고 return this; 를 추가하여 메서드 체이닝이 가능하도록 만들었습니다.

addColliders 함수의 역할

이 함수는 현재 객체(this)와 다른 게임 객체(otherGameObject)가 충돌하도록 설정하는 기능을 합니다.
```

### return this; 를 왜 쓰는 걸까?

```jsx
return this;를 사용하면 객체 자체를 반환하기 때문에,

여러 동작을 한 번에 연결해서 실행할 수 있어!
```

```jsx
만약 return this;가 없다면?

		birdman.addColliders(player);
		birdman.setVelocityX(100);
		birdman.setImmovable(true);

		이렇게 매번 birdman을 다시 적어야 해!

return this;가 있으면?

		birdman.addColliders(player)
		       .setVelocityX(100)
		       .setImmovable(true);

		한 줄로 쭉 이어서 깔끔하게 사용할 수 있어!
```

```jsx
예제 1: return this;가 없는 경우

class Character {
    setName(name) {
        this.name = name;
    }

    setPower(power) {
        this.power = power;
    }
}

const hero = new Character();
hero.setName("Superman");
hero.setPower(100);
console.log(hero);
// 결과: { name: "Superman", power: 100 }

setName()과 setPower()를 연속적으로 호출할 수 없어.

매번 hero.을 적어야 해!

```

```jsx
예제 2: return this;를 사용한 경우

class Character {
    setName(name) {
        this.name = name;
        return this;  // 현재 객체(Character 인스턴스)를 반환
    }

    setPower(power) {
        this.power = power;
        return this;  // 현재 객체를 반환
    }
}

const hero = new Character();
hero.setName("Superman").setPower(100); // 체이닝 가능!
console.log(hero);
// 결과: { name: "Superman", power: 100 }

여기서 return this;가 하는 역할!

setName() 실행 후 hero 객체 자체를 반환

그 반환된 객체에서 바로 setPower() 실행 가능

결국, 한 줄에 여러 동작을 깔끔하게 이어서 실행할 수 있어!

"객체 자체를 반환한다"는 건, 메서드를 호출한 그 객체를 그대로 돌려줘서,

그 객체에서 바로 다른 메서드를 실행할 수 있도록 하는 것!
```

## `createEnemyColliders(enemy, { colliders })` 함수

```jsx
이 함수는 적(enemy)과 다른 객체들(플랫폼, 플레이어) 사이의 충돌을 설정하는 역할을 해.

쉽게 말하면, 적이 플랫폼과 플레이어와 부딪히도록 하는 함수야.
```

```jsx
createEnemyColliders(enemy, { colliders }) {
    enemy
        .addColliders(colliders.platformsColliders)
        .addColliders(colliders.player);
}
```

```jsx
enemy: 충돌을 설정할 적 캐릭터

{ colliders }: 충돌할 대상들이 담긴 객체 (객체 구조 분해 할당 사용)

{ colliders }는 colliders 객체 하나만 전달받겠다는 의미야.

즉, colliders.platformsColliders와 colliders.player 같은 속성을 사용할 수 있어!
```

### \* `return`이 두 개처럼 보이는 이유?

```jsx
코드를 보면 return이 두 번 등장하는 것처럼 보이지만, 사실은 한 번만 작동
```

```jsx
* createEnemies() 코드 분석

spawnLayer.objects.map(...)

		spawnLayer.objects는 적 스폰 포인트들의 배열이야.

		.map(...)을 사용하면 각각의 스폰 포인트를 변환해서 새로운 배열을 만들 수 있어.

		예를 들어, spawnLayer.objects가 이렇게 생겼다고 해보자:
```

```jsx
;[
  { x: 100, y: 200 },
  { x: 300, y: 400 },
]
```

```jsx
.map(spawnPoint => { return new Birdman(...) })

		.map() 안에서 각각의 spawnPoint에 대해 new Birdman(...)을 생성하고 있어.

		그리고 return new Birdman(...)을 통해 배열의 각 요소가 Birdman 객체가 되도록 변환하는 거야.

💡 결과적으로 spawnLayer.objects의 각 요소가 Birdman 객체로 변환된 새로운 배열이 반환되는 거지!
```

```jsx
이제 return이 왜 두 개처럼 보이는지 정리해볼게.
```

### 3) 적과 플레이어 충돌 설정

```jsx
생성된 적이 플레이어 및 맵의 충돌 처리를 올바르게 하도록 설정해야 합니다.

1. 첫 번째 return → .map()이 만든 새로운 배열을 함수에서 반환하는 return

		return spawnLayer.objects.map(spawnPoint => { ... });

		→ createEnemies() 함수가 최종적으로 Birdman 객체들의 배열을 반환하도록 함.



2. 두 번째 return → .map() 안에서 개별 spawnPoint를 Birdman 객체로 변환하는 return

		return new Birdman(this, spawnPoint.x, spawnPoint.y);

		→ spawnPoint 하나를 Birdman 객체로 변환.



즉, return이 두 개가 아니라 map() 안에서 요소를 변환하는 return과

map()의 결과를 반환하는 return이 따로 있는 것이야!
```

```jsx
createEnemyColliders(enemies, { colliders }) {
    enemies.forEach(enemy => {
        enemy
        .addColliders(colliders.platformsColliders)  // 플랫폼과 충돌
        .addColliders(colliders.player);            // 플레이어와 충돌
    })
}
```

```jsx
1. enemies.forEach(enemy => {...}) → 생성된 모든 적 객체에 대해 충돌 설정 적용.

2. enemy.addColliders(colliders.platformsColliders) → 적이 바닥(플랫폼)과 충돌하도록 설정.

3. enemy.addColliders(colliders.player) → 적이 플레이어와 충돌할 수 있도록 설정.
```

```jsx
import Phaser from 'phaser'
import collidable from '../mixins/collidable'

class Enemy extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key)

    // 현재 씬(scene)에서 이 객체를 추가하고 물리 속성을 부여
    scene.add.existing(this)

  init() {
    this.body.setGravityY(500) // 적이 아래로 떨어지도록 중력 설정
    this.setCollideWorldBounds(true) // 월드 바깥으로 나가지 못하도록 설정
    this.setOrigin(0.5, 1) // 이미지의 기준점을 하단 중앙으로 설정
    this.setImmovable(true) // 적이 움직이지 않도록 설정
    this.setSize(20, 45) // 충돌 박스 크기 설정
    this.setOffset(7, 20) // 충돌 박스 위치 조정
  }
}
```

## 3. `PlayScene`에서 동적으로 적을 생성하도록 변경

```jsx
이제 PlayScene에서 적을 생성할 때 동적인 적 클래스를 로드할 수 있도록 변경합니다.
```

```jsx
import Phaser from 'phaser'
import { getEnemyTypes } from '../types'

class Play extends Phaser.Scene {
  constructor(config) {
    super('PlayScene')
    this.config = config
  }

  create() {
    const map = this.createMap()
    const layers = this.createLayers(map)
    const playerZones = this.getPlayerZones(layers.playerZones)
    const player = this.createPlayer(playerZones.start)
    const enemies = this.createEnemies(layers.enemySpawns) // 동적 적 생성

    this.createPlayerColliders(player, {
      colliders: {
        platformsColliders: layers.platformsColliders,
      },
    })

    this.createEnemyColliders(enemies, {
      colliders: {
        platformsColliders: layers.platformsColliders,
        player,
      },
    })

    this.createEndOfLevel(playerZones.end, player)
    this.setupFollowupCameraOn(player)
  }

  createEnemies(spawnLayer) {
    const enemyTypes = getEnemyTypes() // 적 타입을 가져온다

    return spawnLayer.objects
      .map((spawnPoint) => {
        const EnemyClass = enemyTypes[spawnPoint.type] // 타입에 맞는 클래스를 가져온다
        if (!EnemyClass) return null // 적 타입이 없으면 무시

        return new EnemyClass(this, spawnPoint.x, spawnPoint.y)
      })
      .filter((enemy) => enemy !== null) // 유효한 적만 리스트에 포함
  }
}

export default Play
```

### 적을 동적으로 생성하는 방식 개선

```jsx
적의 종류를 동적으로 관리하는 방식을 개선합니다.

getEnemyTypes() 함수를 호출하여 모든 적 타입을 가져온다.

spawnLayer.objects.map()을 사용해 각 스폰 지점의 적 타입에 맞는 클래스를 찾아 생성한다.

filter(enemy => enemy !== null)을 사용하여 유효한 적만 리스트에 포함한다.
```

```jsx
createEnemies(spawnLayer) {
    const enemies = new Enemies(this); // 적 그룹 생성
    const enemyTypes = enemies.getTypes(); // 적 타입 가져오기

    spawnLayer.objects.forEach(spawnPoint => {

}
```

```jsx
    this.setOrigin(0.5, 1)
    this.setImmovable(true) // 적이 움직여도 밀리지 않도록 설정
    this.setSize(20, 45) // 충돌 박스 크기 설정
    this.setOffset(7, 20) // 충돌 박스 위치 조정
  }

  initEvents() {
    this.scene.events.on(Phaser.Scenes.Events.UPDATE, this.update, this)
  }

  update(time, delta) {
    this.setVelocityX(-30) // 왼쪽으로 이동
  }
}

export default Enemy
```

```jsx
Enemy 클래스가 하는 일

		scene.add.existing(this), scene.physics.add.existing(this) → 씬에 적을 추가하고 물리 엔진 적용

		setGravityY(500) → 적에게 중력을 적용

		setCollideWorldBounds(true) → 적이 화면 밖으로 나가지 않도록 설정

		setVelocityX(-30) → 기본적으로 왼쪽으로 이동
```

### (2) `Birdman` 클래스 (Enemy를 상속받는 적)

```jsx
Birdman은 Enemy를 상속받아 추가적인 애니메이션 기능을 포함합니다.

super(scene, x, y, "birdman")을 호출하여 Enemy 클래스의 기본 기능을 상속받습니다.
```

### `Birdman` 클래스 코드

```jsx
import Enemy from './Enemy'
import initAnims from './anims/birdmanAnims'

class Birdman extends Enemy {
  constructor(scene, x, y) {
    super(scene, x, y, 'birdman') // Enemy 클래스 상속
    initAnims(scene.anims) // 애니메이션 초기화
  }

  update(time, delta) {
    super.update(time, delta) // 부모 클래스의 update 실행
    this.play('birdman-idle', true) // 애니메이션 재생
  }
}

export default Birdman
```

```jsx
Birdman 클래스가 하는 일

		super(scene, x, y, "birdman") → Enemy 클래스를 상속받아 기본 동작 유지

		initAnims(scene.anims) → 애니메이션을 초기화

		update(time, delta) → 부모의 update 실행 후 Birdman의 애니메이션을 실행
```

## 2. 애니메이션 설정

```jsx
적 캐릭터가 특정 동작(대기, 이동 등)을 할 때 적절한 애니메이션이 실행되도록 설정합니다.

애니메이션은 Phaser.Animations.AnimationManager를 사용하여 생성합니다.
```

### `birdmanAnims.js` (애니메이션 설정 파일)

```jsx
export default (anims) => {
  anims.create({
    key: 'birdman-idle', // 애니메이션 키값
    frames: anims.generateFrameNumbers('birdman', { start: 0, end: 12 }), // 0~12번 프레임 사용
    frameRate: 10, // 초당 프레임 속도
    repeat: -1, // 무한 반복
  })
}
```

```jsx
애니메이션 설정 과정

		key: 'birdman-idle' → 'birdman-idle'라는 애니메이션 키를 설정

		frames: anims.generateFrameNumbers('birdman', { start: 0, end: 12 }) → 'birdman'의 0~12 프레임을 애니메이션으로 사용

		frameRate: 10 → 초당 10프레임으로 재생

		repeat: -1 → 애니메이션을 무한 반복
```
