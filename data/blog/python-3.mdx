```python
함수는 특정 작업을 수행하는 코드 블록을 의미하며, 필요할 때마다 호출하여 사용할 수 있다.

함수를 만들 때에는 def 키워드를 사용하며, 함수의 이름과 필요한 매개변수를 정의한다.

함수가 필요한 작업을 수행한 뒤에는 결과값을 반환할 수도 있다. 이때 반환되는 값을 리턴값이라고 한다.
```

```python
def add_numbers(a, b):
    """두 수를 더하여 결과를 반환하는 함수"""
    result = a + b
    return result

# 함수 호출
result = add_numbers(3, 5)
print("결과:", result)
```
