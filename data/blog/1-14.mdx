### 3. JSP 연동

a. Market 설치

```jsx
1. STS -> Help -> Market place
2. find -> Eclipse web 검색
3. Eclipse Enterprise Java and Web,,, 설치
```

b. pom.xml

```jsx
1. Tomcat을 사용 하는 것처럼 라이브러리 추가

		<!-- https://mvnrepository.com/artifact/org.apache.tomcat.embed/tomcat-embed-jasper -->
		<dependency>
		    <groupId>org.apache.tomcat.embed</groupId>
		    <artifactId>tomcat-embed-jasper</artifactId>
		    <!-- 버전 삭제 -->
		</dependency>

2. JSTL 추가
		<!-- https://mvnrepository.com/artifact/javax.servlet/jstl -->
		<dependency>
		    <groupId>javax.servlet</groupId>
		    <artifactId>jstl</artifactId>
		     <!-- 버전 삭제, 에러 발생시 버전 적용 -->
				<version>1.2</version>
		</dependency>
```

c. application.properties

```jsx
spring.mvc.view.prefix=/WEB-INF/views/
spring.mvc.view.suffix=.jsp
```

d. 폴더 생성

```jsx
src -> main -> webapp 폴더 생성
src -> main -> webapp -> WEB-INF 폴더 생성
src -> main -> webapp -> WEB-INF -> views 폴더 생성
```

### 4. Encoding 설정

```jsx
1. windows > preferences > general > workspace > Default Encoding 을 UTF-8로 변경

2. windows > preferences > general > web browser > External 선택, Chrome 선택

3. windows > preferences > > web -> css -> Encoding 을 UTF-8로 변경

4. windows > preferences > > web -> html -> Encoding 을 UTF-8로 변경

5. windows > preferences > > web -> jsp -> Encoding 을 UTF-8로 변경

6. windows > preferences > general > content type > text 확장 > Java properties files 선택 > Default Encoding 을 UTF-8로 변경 후 update
```
