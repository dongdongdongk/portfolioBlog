```python
표준 라이브러리는 파이썬에 기본적으로 포함되어 있는 라이브러리들을 말한다.

이러한 표준 라이브러리는 파이썬 프로그래밍을 보다 쉽고 효율적으로 할 수 있도록 다양한 기능을 제공한다.

대부분의 표준 라이브러리는 파이썬 설치 시 함께 제공되므로 별도의 설치가 필요하지 않다.
```

# 모듈 사용하기

```python
모듈을 사용하려면 import 를 입력해서 모듈을 불러와야 한다

많이 사용하는 모듈을 알아보자
```

## **os 모듈 (운영체제 관련 작업)**

```python
os 모듈은 운영체제와 상호작용하기 위한 기능을 제공한다.

파일 및 디렉토리 관리, 환경 변수 액세스, 프로세스 관리 등의 기능을 포함하고 있다.
```

```python
import os

# 현재 디렉토리 출력
current_dir = os.getcwd()
print("현재 디렉토리:", current_dir)

# 디렉토리 생성
new_dir = "new_directory"
os.mkdir(new_dir)
print("새 디렉토리 생성:", new_dir)

# 파일 목록 출력
files = os.listdir()
print("파일 목록:", files)
```

## **datetime 모듈 (날짜와 시간 다루기)**

```python
import datetime

# 현재 날짜와 시간 출력
current_datetime = datetime.datetime.now()
print("현재 날짜와 시간:", current_datetime)

# 특정 날짜와 시간 생성
new_datetime = datetime.datetime(2024, 4, 30, 12, 30)
print("새로운 날짜와 시간:", new_datetime)

# 날짜 간의 차이 계산
delta = new_datetime - current_datetime
print("두 날짜의 차이:", delta)
```

## **random 모듈 (랜덤한 값 생성)**

```python
import random

# 1에서 10까지의 무작위 정수 생성
random_number = random.randint(1, 10)
print("무작위 정수:", random_number)

# 리스트의 요소 무작위 섞기
my_list = [1, 2, 3, 4, 5]
random.shuffle(my_list)
print("무작위 섞은 리스트:", my_list)

# 0에서 1 사이의 무작위 실수 생성
random_float = random.random()
print("무작위 실수:", random_float)
```

## **math 모듈 (수학 함수와 상수)**

```python
import math

# 원주율 값
pi = math.pi
print("원주율:", pi)

# 제곱근 계산
sqrt_value = math.sqrt(16)
print("제곱근:", sqrt_value)

# 삼각함수 계산
sin_value = math.sin(math.pi / 2)
print("사인 값:", sin_value)
```
