# 모델(Model)

```jsx
정의:

		모델은 데이터베이스와 직접 상호작용하는 객체입니다.

		데이터를 데이터베이스에 저장하거나 가져오거나 수정 및 삭제하는 역할을 담당합니다.

		데이터베이스에 정의된 구조(Schema)를 기반으로 동작합니다.

주요 역할:

		데이터의 CRUD(생성, 조회, 수정, 삭제) 작업을 처리.

		데이터를 특정 구조(Schema)에 따라 저장.

비유:

		모델은 데이터베이스의 일꾼입니다.

		데이터를 가져오거나 업데이트하고, 명령에 따라 데이터베이스와 통신하는 역할을 합니다.
```

```jsx
import mongoose from 'mongoose'

// Schema 정의
const UserSchema = new mongoose.Schema({
  username: { type: String, required: true },
  email: { type: String, required: true },
  password: { type: String, required: true },
  createdAt: { type: Date, default: Date.now },
})

// 모델 정의
const UserModel = mongoose.model('User', UserSchema)

// 모델 사용
;(async () => {
  const user = new UserModel({
    username: 'JaneDoe',
    email: 'jane@example.com',
    password: 'securepassword',
  })

  const savedUser = await user.save() // 데이터 저장
  console.log('Saved User:', savedUser)
})()
```

# 스키마(Schema)

```jsx
정의:

		데이터의 구조와 속성을 정의한 설계도입니다.

		각 필드(컬럼)의 이름, 데이터 타입, 제약 조건 등을 명시합니다.

		모델이 데이터베이스에 데이터를 저장하거나 가져올 때 사용하는 템플릿입니다.

주요 역할:

		데이터의 구조를 강제.

		데이터베이스에서 데이터가 어떻게 저장될지 결정.

비유:

		스키마는 데이터의 설계도입니다.

		건물을 짓기 전에 설계도가 필요한 것처럼, 데이터베이스에 데이터를 저장하기 전에 스키마가 필요합니다.
```

```jsx
import mongoose from 'mongoose'

const UserSchema = new mongoose.Schema({
  username: { type: String, required: true },
  email: { type: String, required: true },
  password: { type: String, required: true },
  createdAt: { type: Date, default: Date.now },
})
```

# 인터페이스(Interface)

```jsx
정의:

		데이터 구조를 정의하는 타입입니다.

		주로 TypeScript에서 사용되며, 코드에서 데이터의 형식을 명확히 합니다.

		실제 구현을 포함하지 않으며, 데이터가 가져야 할 속성과 타입만 명시합니다.

주요 역할:

		데이터 구조를 명확히 정의.

		타입 안정성을 제공하여 컴파일 시 오류를 방지.

비유:

		인터페이스는 데이터의 계약서입니다.

		어떤 데이터를 사용하려면 반드시 계약서에 적힌 대로 속성과 타입을 따라야 합니다.
```

```jsx
export interface IUser {
  username: string;        // 사용자 이름
  email: string;           // 이메일
  password: string;        // 비밀번호
  createdAt?: Date;        // 생성일 (선택적 속성)
}

```
