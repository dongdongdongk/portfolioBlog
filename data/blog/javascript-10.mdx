# 기본 매개 변수

```jsx
JavaScript에서는 함수의 매개변수에 기본값을 설정할 수 있는 기능이 있다.

이를 "기본 매개변수(Default Parameters)"라고 한다

함수를 정의할 때 매개변수에 기본값을 할당하여 해당 매개변수가 전달되지 않았을 때 사용되는 값을 설정할 수 있다.
```

## **기본 매개변수의 사용 예제**

```jsx
function greet(name = '손님', greeting = '안녕하세요') {
  console.log(`${greeting}, ${name}님!`)
}

greet() // 출력: 안녕하세요, 손님님!
greet('홍길동') // 출력: 안녕하세요, 홍길동님!
greet('아무개', '안녕') // 출력: 안녕, 아무개님!
```

```jsx
이 예제에서 greet 함수는 두 개의 매개변수 name과 greeting을 가지고 있다

각 매개변수에는 기본값이 할당되어 있다. 함수를 호출할 때 해당 매개변수를 전달하지 않으면 기본값이 사용된다
```

## **주의 사항**

### **매개변수의 순서에 주의**

```jsx
기본 매개변수는 함수의 매개변수 목록에서 마지막에 위치해야 한다. 그렇지 않으면 오류가 발생할 수 있다.
```

```jsx
// 올바른 사용
function example(a, b, c = 0) {
  // ...
}

// 오류 발생: 기본 매개변수는 매개변수 목록의 마지막에 위치해야 함
function example(a = 1, b, c) {
  // ...
}
```

### **기본값은 함수가 호출될 때마다 계산됨**

```jsx
기본 매개변수의 기본값은 함수가 정의될 때 한 번만 평가되기 때문에 동적인 값을 설정하는 데는 한계가 있다
```

```jsx
function getDefault() {
  console.log('기본값 계산')
  return 42
}

function example(a = getDefault()) {
  console.log(a)
}

example() // 출력: 기본값 계산, 42
example() // 출력: 기본값 계산, 42 (다시 계산되지 않음)
```

# JavaScript에서 스프레드

```jsx
배열이나 객체의 요소를 펼쳐서 개별 요소로 분해하거나 복사할 때 사용되는 편리한 문법이다.

스프레드 문법은 ... (세 점)으로 표현되며, 배열, 객체, 함수 호출 등에서 사용될 수 있다
```

## **배열에서의 스프레드 문법**

```jsx
const array1 = [1, 2, 3]
const array2 = [...array1, 4, 5, 6]

console.log(array2) // 출력: [1, 2, 3, 4, 5, 6]
```

```jsx
...array1은 배열 array1의 모든 요소를 펼쳐서 새로운 배열 array2에 포함시킨다.

이를 통해 두 배열을 합치거나 복사할 수 있다.
```

## **객체에서의 스프레드 문법**

```jsx
const obj1 = { a: 1, b: 2 }
const obj2 = { ...obj1, c: 3, d: 4 }

console.log(obj2)
// 출력: { a: 1, b: 2, c: 3, d: 4 }
```

```jsx
...obj1은 객체 obj1의 속성을 펼쳐서 새로운 객체 obj2에 포함시킨다.

새로운 속성을 추가하거나 기존 객체를 복사할 때 유용하다.
```

## **함수 호출에서의 스프레드 문법**

```jsx
function sum(a, b, c) {
  return a + b + c
}

const numbers = [1, 2, 3]
const result = sum(...numbers)

console.log(result) // 출력: 6
```

```jsx
함수 호출 시에도 스프레드 문법을 사용하여 배열의 요소를 함수의 매개변수로 전달할 수 있다.

위의 예제에서 sum(...numbers)은 sum(1, 2, 3)과 동일한 결과를 가져온다.
```

## **배열과 문자열에서의 스프레드 문법**

```jsx
const str = 'hello'
const chars = [...str]

console.log(chars) // 출력: ['h', 'e', 'l', 'l', 'o']
```

```jsx
스프레드 문법은 배열 또는 문자열의 각 요소를 펼쳐서 개별 요소로 만든다
```

# JavaScript에서 Rest

```jsx
JavaScript에서 Rest 문법은 스프레드 문법과 반대로,

함수의 매개변수나 배열 패턴에서 사용되어 여러 개의 인수나 요소를 하나의 변수로 묶을 때 사용된다

Rest 문법은 ... (세 점)으로 표현되며, 함수 선언 시나 배열 패턴에서 사용된다.

( Rest 문법은 동적으로 개수가 변할 수 있는 인수나 배열의 일부를 다룰 때 특히 유용하다 )
```

## **함수 매개변수에서의 Rest 문법**

```jsx
function sum(...numbers) {
  return numbers.reduce((acc, num) => acc + num, 0)
}

console.log(sum(1, 2, 3, 4, 5)) // 출력: 15
```

```jsx
함수의 매개변수에서 ...numbers는 전달된 모든 인수를 배열로 묶어준다.

위의 예제에서 sum 함수는 전달된 모든 인수를 합하여 반환
```

## **배열 패턴에서의 Rest 문법**

```jsx
const [first, second, ...rest] = [1, 2, 3, 4, 5]

console.log(first) // 출력: 1
console.log(second) // 출력: 2
console.log(rest) // 출력: [3, 4, 5]
```

```jsx
배열 패턴에서 ...rest는 남은 요소들을 배열로 묶어준다.

위의 예제에서 first와 second에는 배열의 처음 두 요소가 할당되고, 나머지 요소는 rest 배열에 할당된다.
```

## **객체에서의 Rest 문법**

```jsx
const { a, b, ...rest } = { a: 1, b: 2, c: 3, d: 4 }

console.log(a) // 출력: 1
console.log(b) // 출력: 2
console.log(rest) // 출력: { c: 3, d: 4 }
```

```jsx
객체에서도 Rest 문법을 사용할 수 있다. ...rest는 나머지 속성들을 객체로 묶어준다.

위의 예제에서 a와 b에는 객체의 처음 두 속성이 할당되고, 나머지 속성들은 rest 객체에 할당된다.
```

## Rest Spread 쉽게 구분하기

```jsx
**Rest**

함수 매개변수에서 사용될 때: function example(...rest) { /* ... */ }

배열 패턴에서 사용될 때: const [first, second, ...rest] = [1, 2, 3, 4, 5];

객체 분해 할당에서 사용될 때: const { a, b, ...rest } = { a: 1, b: 2, c: 3 };

**Spread**

배열 합치기에서 사용될 때: const array2 = [...array1, 4, 5, 6];

객체 병합에서 사용될 때: const obj2 = { ...obj1, c: 3, d: 4 };

함수 호출 인수에서 사용될 때: sum(...numbers);
```

# Destructuring

```java
해체 할당(Destructuring assignment)은 배열이나 객체의 값을 추출하여 변수에 할당하는 문법
```

## **배열 해체 할당**

```java
// 배열 해체 할당
const numbers = [1, 2, 3];

// 기존 방식
const firstNumber = numbers[0];
const secondNumber = numbers[1];

// 해체 할당 사용
const [first, second, kimkim] = numbers;

console.log(first);  // 출력: 1
console.log(second); // 출력: 2
console.log(kimkim); // 출력: 3
```

```java
const [first, second, kimkim] = numbers;는

numbers 배열의 첫 번째 요소를 first 변수에, 두 번째 요소를 second 변수에 할당 세번째는 kimkim

( 인덱스 기반으로 [0 , 1, 2] 이렇게 지정된다
```

## **객체 해체 할당:**

```java
// 객체 해체 할당
const person = { name: 'John', age: 30 };

// 기존 방식
const personName = person.name;
const personAge = person.age;

// 해체 할당 사용
const { name, age } = person;

console.log(name); // 출력: 'John'
console.log(age);  // 출력: 30
```

```java
의 예제에서 const { name, age } = person;은 person 객체의 name 속성을 name 변수에, age 속성을 age 변수에 할당

( 새로운 name age 라는 변수가 생겨났다 )
```

## **매개변수 분해 (Function Parameter Destructuring)**

```jsx
// 기존 방식
function getUserInfo(user) {
  const name = user.name
  const age = user.age
  const city = user.city

  console.log(name, age, city)
}

// 매개변수 분해를 사용한 방식
function getUserInfo({ name, age, city }) {
  console.log(name, age, city)
}

const userData = {
  name: 'John',
  age: 30,
  city: 'New York',
}

getUserInfo(userData)
// 출력: 'John' 30 'New York'
```

# Destructuring 디폴트(default) 값 설정해주기

```jsx
디폴트 값은 할당하려는 변수 뒤에 = 연산자를 사용하여 설정하면 된다.

만약 해당 속성이나 배열 요소가 정의되지 않았을 때 디폴트 값이 사용된다.
```

## **객체 비구조화 할당에서의 디폴트 값**

```jsx
const person = { name: 'John' }

// 디폴트 값을 설정하는 방법
const { name, age = 30 } = person

console.log(name) // 출력: 'John'
console.log(age) // 출력: 30
```

## **배열 비구조화 할당에서의 디폴트 값**

```jsx
const numbers = [1, 2]

// 디폴트 값을 설정하는 방법
const [a, b = 0] = numbers

console.log(a) // 출력: 1
console.log(b) // 출력: 2
```
