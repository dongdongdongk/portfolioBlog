## 그룹화(Grouping)**와 **프레임으로 묶기(Framing) 차이?

```tsx
그룹화:

	여러 요소를 단순히 하나로 묶어 정렬이나 이동을 편리하게 할 때 사용합니다.

	디자인 상에서 요소들을 함께 다루지만, 그룹 내 요소들은 독립적으로 남아 있습니다.

	단축키: Ctrl + G (Windows) / Cmd + G (Mac).

프레임으로 묶기:

	요소들을 하나의 레이아웃 컨테이너로 묶어 더 복잡한 구조를 만들고, 프레임 속성(패딩, 그리드 등)을 적용할 때 사용합니다.

	프레임 안의 요소들은 프레임의 영향을 받아 배치와 크기가 조정될 수 있습니다.

	단축키: Ctrl + Alt + G (Windows) / Cmd + Option + G (Mac).
```

```tsx
언제 사용하나?

	그룹화: 간단히 요소들을 묶어서 함께 이동하거나 정렬할 때.

	프레임으로 묶기: 반응형 레이아웃을 만들거나, 프레임의 속성을 활용해 요소들을 더 정교하게 배치할 때.
```

## \* SVG?

```jsx
SVG(Scalable Vector Graphics)는 벡터 기반의 그래픽 형식으로, 주로 웹 디자인과 사용자 인터페이스에서 많이 사용됩니다. 그 이유는 다음과 같습니다:
```

```jsx
해상도 독립성: SVG는 벡터 그래픽이기 때문에 어떤 크기로 확대하더라도 품질이 유지됩니다.

							이는 다양한 화면 해상도와 기기에서 선명하게 표시될 수 있음을 의미합니다.

파일 크기: 일반적으로 SVG 파일은 래스터 이미지 파일보다 크기가 작아 웹 페이지의 로딩 속도가 빨라질 수 있습니다.

편집 가능성: SVG 파일은 XML 형식으로 작성되어 있어, 코드로 직접 수정하거나 스타일을 변경할 수 있습니다.

						CSS와 JavaScript로 스타일을 조정하거나 애니메이션을 추가하는 것이 가능합니다.

기타 기능: SVG는 이미지 안에 텍스트, 링크, 그래디언트 등 다양한 기능을 내장할 수 있으며, 검색 엔진 최적화(SEO)에도 유리합니다.
```

2.1 카드 텍스트 추가

	단축키 및 작업:

		텍스트 도구 선택: T 키를 눌러 텍스트 박스를 생성하고 원하는 내용을 입력.

		텍스트 정렬: 텍스트를 선택한 후 Properties 패널에서 가로 및 세로 중앙 정렬 설정.

2.2 번호 매기기 생성

	작업 내용: 타원 도구를 사용하여 원을 만들고, 텍스트 도구로 번호를 추가한 후, 원과 텍스트를 중앙에 정렬하여 그룹화합니다.

	단축키 및 작업:

		타원 도구 선택: O 키를 눌러 원을 생성.

		그룹화: 여러 요소를 선택한 후 Command + G (Mac) 또는 Ctrl + G (Windows)로 그룹화.

		정렬: Properties 패널에서 가로 및 세로 중앙 정렬 설정.
