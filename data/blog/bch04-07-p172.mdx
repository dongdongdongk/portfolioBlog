# 화면에서 DTO 처리

```java
앞 강의에서데이터 베이스에서  넘어온 데이터를 엔티티 에서 DTO 로 변환하는 과정을 처리했다

화면에서 이 DTO 를 처리하려면 추가적으로 페이지 번호, 시작 페이지 번호 , 끝 페이지 번호 등 이런것들이 필요하다

Page<엔티티> 내부에는 페이지 처리에 필요한 많은 정보들이 존재하므로 이를 이용하도록 한다

PageResultDTO 에서는 페이지 구성에 필요한 정보들을 정의하고 이를 추출해서 사용한다

* 화면에서 시작 페이지 번호(start)

* 화면에서 끝 페이지 번호 (end)

* 이전/다음 이동 링크 여부(prev,next)

* 현재 페이지 번호 (page)
```

# 페이지 번호의 계산

```java
* 현재 페이지를 기준으로 화면에 출력 되어야 하는 마지막 페이지를 우선 처리

tempEnd = (int)(Math.ceil(페이지번호 / 10.0)) * 10;

// 예를 들어 현재 페이지가 13 이라고 치면 10으로 나누면 1.3 ceil 로 올림을 하면 2 x 10 하면 20  13페이지 경우는 화면에서 페이저가 20 까지 나와야한다

* 화면의 시작 페이지 번호는 tempEnd - 9로 처리

start = tempEnd - 9;

// 위에서 나온 20 에 - 9 를 하면 11 이다 이는 시작 페이지

* 실제 데이터가 부족한 경우를 위해 마지막 페이지 번호는 전체 데이터의 개수를 이용해서 다시 계산

totalPage = result.getTotalPages(); //result 는 Page<Guestbook>

end = totalPage > tempEnd ? tempEnd : totalPage;

// 만약 데이터 145개가 있다고 치면 15 페이지 까지 나와야지 20 페이지 까지 나오는게 아니다 (10개씩)

//Page<엔티티> 의 result.getTotalPages 를 이용해서 총 페이지를 구하고 (고맙게도 위의 145 예제에서 딱 15까지 나와준다)

// 예를들어 위의 13 페이지는 20까지 나와야 한다 totalPage 가 30 이라면 마지막 페이지는 20 이 되야하고 데이터가 적어 더 작은 4 라면 4가 나와야 한다

* 기타 필요한 이전 페이지 여부 / 다음 페이지 존재 여부 계산

prev = start > 1;

next = totalPage > tempEnd;

// 시작 페이지가 1보타 크면 이전 페이지로 가는 링크가 필요한거고

// totalEnd 가 20 이고 tempEnd 가 20 이면 다음으로 가는 링크가 필요 없다는 것 ( 더 뒷쪽 페이지 링크를 표시 할 필요가 없다 )
```

```java
package org.zerock.guestbook.dto;

import lombok.Data;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;

import java.util.List;
import java.util.Map;
import java.util.function.Function;
import java.util.stream.Collectors;
import java.util.stream.IntStream;

@Data
public class PageResultDTO<DTO, EN> {

    // DTO 리스트
    private List<DTO> dtoList;

    // 총 페이지 번호
    private int totalPage;

    // 현재 페이지 번호
    private int page;

    // 목록 사이즈
    private int size;

    // 시작 페이지 번호, 끝 페이지 번호
    private int start, end;

    // 이전, 다음
    private boolean prev, next;

    // 페이지 번호 목록
    private  List<Integer> pageList;

    // 생성자: Page<EN> 타입의 데이터와 매핑 함수(Function<EN, DTO>)를 받음
    public PageResultDTO(Page<EN> result, Function<EN, DTO> fn) {

        // result 내의 엔티티 데이터를 DTO로 변환하여 리스트로 저장
        dtoList = result.stream().map(fn).collect(Collectors.toList());
        // 총 페이지 수 설정
        totalPage = result.getTotalPages();
        // 페이지 번호 목록 생성
        makePageList(result.getPageable());

    }

    // 현재 페이지 정보를 기반으로 페이지 번호 목록 생성
    public void makePageList(Pageable pageable) {

        this.page = pageable.getPageNumber() + 1; // 0부터 시작하므로 1을 추가
        this.size = pageable.getPageSize();

        //temp end page
        int tempEnd = (int)(Math.ceil(page/10.0)) * 10;

        start = tempEnd - 9;

        prev = start > 1;

        end = totalPage > tempEnd ? tempEnd : totalPage;

        next = totalPage > tempEnd;

        // 페이지 번호 목록 생성 (start부터 end까지)
        pageList = IntStream.rangeClosed(start,end).boxed().collect(Collectors.toList());
        // boxed() 는 IntStream 을 Integer 로 변환하여 List<Integer> pageList 에 수집 가능하도록 래퍼 객체로 바꿔준다
    }
}
```

# PageResultDTO 작동 원리 ( Function<EN, DTO> )

```java
PageResultDTO 클래스의 생성자를 정의한 부분으로, Page 타입의 엔터티 데이터와 해당 엔터티를 DTO로 변환하는 함수(Function<EN, DTO> fn)를 받아와서 PageResultDTO 객체를 초기화하는 역할을 한다.
```

```java

// 생성자: Page<EN> 타입의 데이터와 매핑 함수(Function<EN, DTO>)를 받음
public PageResultDTO(Page<EN> result, Function<EN, DTO> fn) {

//생성자 정의: PageResultDTO 클래스의 생성자를 정의하고, Page 타입의 엔터티 데이터(result)와 해당 엔터티를 DTO로 변환하는 함수(Function<EN, DTO> fn)를 매개변수로 받는다.

// result에 있는 엔터티 데이터를 DTO로 변환하여 리스트에 저장
dtoList = result.stream().map(fn).collect(Collectors.toList());

//DTO 리스트 초기화: result에 있는 엔터티 데이터를 stream()을 통해 스트림으로 변환한다.

//map(fn)을 사용하여 각 엔터티를 DTO로 변환하고, collect(Collectors.toList())를 사용하여 DTO를 리스트에 저장한다. (fn 은 생성자 생성때 받아온 fn)

//따라서, dtoList에는 result에 있는 엔터티 데이터를 DTO로 변환한 리스트가 저장된다.

// 총 페이지 수 설정
totalPage = result.getTotalPages();

//총 페이지 수 설정: result.getTotalPages()를 통해 전체 페이지 수를 얻어와서 totalPage에 저장한다. 이 값은 나중에 페이지 목록을 생성할 때 사용된다.

// 페이지 번호 목록 생성
makePageList(result.getPageable());

//페이지 번호 목록 생성: makePageList 메서드를 호출하여 페이지 번호 목록을 생성한다.

//result.getPageable()을 통해 현재 페이지 정보를 얻어와서 makePageList 메서드에 전달한다.

//이렇게 하면 start, end, prev, next, 그리고 pageList 등의 필드가 초기화된다.

//총평하면, 이 생성자는 주어진 Page 객체에 대한 DTO 변환 및 필요한 페이지 정보를 초기화하여 PageResultDTO 객체를 생성한다.

//이를 통해 페이징된 데이터와 함께 필요한 페이지 정보를 한꺼번에 가공하여 사용할 수 있다.
```
