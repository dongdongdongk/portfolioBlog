클래스 를 사용하게 되면 클래스 로더에 의해 메소드 영역에 정적필드, 정적메소드 가 저장 된다.

```java
public class 클래스 {
	// 정적 필드
	static 타입 필드 [= 초기값];

	// 정적 메소드
	static 리 타입 메소드( 매개변수 선언) { 내용 }

// 정적 멤버를 선언 할 때는 앞에 static 을 붙여주면 된다.
```

![Untitled](<35%20%EC%9D%B8%EC%8A%A4%ED%84%B4%EC%8A%A4%20%EB%A9%A4%EB%B2%84%EC%99%80%20%EC%A0%95%EC%A0%81%20%EB%A9%A4%EB%B2%84(2)/Untitled%201.png>)

```java
클래스 이름과 함께 도트 연산자로 접근

클래스.필드; // 클래스에 접근해서 필드를 사용하라

클래스.메소드( 매개값) // 클래스에 접근해서 메소드를 실행 해라

public class Calculator {
	static double pi = 3.14159;  // static 이 붙으면 정적 멤버
	static int plus(int x, int y) {...}
	static int minus(int x, int y) {...}
}

// 메소드 호출
double result1 = 10 * 10 * Claculator.pi;
int result2 = Calculator.plus(10, 5);
int result3 = Calculator.minus(10, 5);

//Dot 연산자 (멤버 참조 연산자)
멤버 접근(액세스) 에 사용되는 연산자이다.

//인스턴스
설계도(class)를 바탕으로 소프트웨어 세계에 구현된 구체적인 실체
즉, 객체를 소프트웨어에 실체화 하면 그것을 ‘인스턴스’라고 부른다.
실체화된 인스턴스는 메모리에 할당된다.
```

```java
//인스턴스 멤버와 정적 멤버 선택 기준

public class Calculator {
	String color; // 객체마다 다를수 있는 필드값 인스턴스 필드 선언
                // (계산기 마다 색 다를수 있음)

static double pi = 3.14159; // 객체마다 다를 필요가없는값
                            // (계산기에서 사용하는 파이 값은 동일하다.)
}

//메소드

public class Calculator {
	String color;
// 인스턴스 필드

void setColor(String color) { this.color = color; }
 //메소드 블록에 인스턴스 필드 또는 인슨턴스 메소드를 사용할경우 인스턴스 메소드 선언
 //this 와 같은 객체 자신을 참조하는 키워드를 사용하면 인스턴스


static int plus(int x, int y) { return x + y; }
static int minus(int x, int y) { return x - y; }
//인스턴스 필드사용 x 매개변수 만으로 만들어진 메소드
//정적 메소드 사용
}
```

```java
public class ClassName {
//인스턴스 필드와 메소드
int field1;
void method1() {내용}

//정적 필득와 메소드
static int field2;
static void method2(){내용}

//정적 메소드
static void Method3 {
	this.field1 = 10; //this. 은 인스턴스 멤버에 접근하기 위해 사용하기 this. 사용불가
	this.method1();   //인스턴스 필드와 메소드 사용불가

	field2 = 10; (o) //사용가능
	method2();   (o)

//정적 메소드에서 인스턴스 멤버 사용하는 방법
//객체 생성후 참조 변수로 접근

static void Method3() {
	ClassName obj = new ClassName(); //객체를 생성후 인스턴스 필드, 메소드 사용
	obj.field1 = 10;
	obj.method1();
}
```
