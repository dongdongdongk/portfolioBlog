# { 프로토타입 기초 }

## 1. **프로토타입의 의미**

```jsx
프로토타입: 사용자가 디자인과 어떻게 상호작용할 수 있는지를 미리 살펴볼 수 있는 인터랙티브 플로우를 만듭니다.

목적: 정적인 디자인을 인터랙티브하고 동적인 디자인으로 전환하여 사용자 흐름을 시뮬레이션합니다.
```

## 2. **프로토타입의 구성 요소**

```jsx
핫스팟: 사용자 상호 작용이 이루어지는 디자인의 특정 지점입니다.

커넥션: 핫스팟과 데스티네이션을 연결하는 화살표입니다.

데스티네이션: 커넥션이 끝나는 지점, 즉 다음 단계입니다.
```

## 3. **프로토타입 설정 과정**

```jsx
새 디자인 파일 생성: 파일 이름을 "Prototype"으로 변경합니다.

프레임 설정:

	iPhone 크기의 프레임을 생성하고, 옵션(Option) 키를 길게 눌러 복사본을 만듭니다.

	첫 번째 프레임 이름은 "Hotspot", 두 번째 프레임 이름은 "Destination"으로 변경합니다.

플로우 시작점 설정:

	프로토타입 모드로 이동하여 Flow starting point를 설정합니다.

	핫스팟 프레임에 플로우 1이 추가됩니다.

커넥션 만들기:

	핫스팟 프레임에서 더하기 아이콘을 클릭하여 커넥션을 생성하고, 이를 데스티네이션 프레임에 연결합니다.

프로토타입 테스트:

	프로토타입 시작: 작은 플레이 아이콘을 클릭하여 시작합니다.

	화면 전환: 핫스팟 프레임에서 데스티네이션 프레임으로 전환되는 것을 확인합니다.

	애니메이션 다시 시작: R 키를 눌러 애니메이션을 다시 시작합니다.
```

## Mouse Enter 인터랙션

```tsx
설명: 커서가 특정 영역(핫스팟)에 들어갈 때 발생하는 인터랙션입니다.

중요 포인트:

	마우스 움직임 추적: 마우스와 함께 사용되며, 커서가 지정된 핫스팟에 들어갈 때 인터랙션이 발생합니다.

	핫스팟 설정: 원형 객체를 핫스팟으로 설정하여, 커서가 원 안쪽으로 들어가면 인터랙션이 발생하도록 설정.
```

## Mouse Leave 인터랙션

```tsx
설명: 커서가 특정 영역(핫스팟)에서 나갈 때 발생하는 인터랙션입니다.

중요 포인트:

	반대 동작: Mouse Enter와 반대 동작으로, 커서가 핫스팟을 떠날 때 인터랙션이 발생합니다.

	핫스팟 설정: 동일한 원형 객체를 사용하여, 커서가 원 밖으로 나가면 인터랙션이 발생하도록 설정.
```

## On Click과 On Tap 인터랙션의 차이점

```tsx

On Click vs On Tap

	설명: 모바일 앱에서는 주로 터치를 통해 상호작용하므로 On Click 대신 On Tap 인터랙션이 사용됩니다.

	중요 포인트:

		모바일 앱 디자인: 모바일 앱은 터치로 상호작용하기 때문에 On Click에 대해 신경 쓸 필요가 없습니다.

		데스크톱 웹사이트 디자인: 데스크톱에서 웹사이트에 접근할 때는 On Click 인터랙션이 발생합니다.

		모바일 및 태블릿: 동일한 웹사이트에 모바일이나 태블릿으로 접근하면 On Tap 인터랙션이 발생합니다.


		* 한마디로 디바이스를 휴대폰으로 하느냐 데스크탑으로 하느냐의 차이로 자동으로 변경된다
```

# { 내비게이트가 있는 동작 기본 설명 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381586/notion-blog/_/_/_/_UI_UX_/_13_/image_5.png)

## 1. **인터랙션의 기본 구조**

```jsx
인터랙션 3단계 프로세스:

	트리거(Trigger): 사용자 상호작용을 시작하는 요소.

	액션(Action): 사용자가 핫스팟과 상호작용할 때 일어나는 일.

	데스티네이션(Destination): 액션이 종료된 후 도달하는 지점.
```

## 2. **액션의 개요**

```jsx
액션의 의미: 사용자가 핫스팟과 상호작용할 때 발생하는 동작.

피그마의 8가지 액션:

	피그마는 다양한 사용 사례에 따라 8가지 액션을 제공합니다.

	각 액션은 특정 프로젝트 요구 사항에 따라 사용됩니다.
```

## Navigate to

```jsx
Navigate to 액션 설명:

	Navigate to는 한 프레임에서 다른 프레임으로 이동하는 액션입니다.

	사용자가 핫스팟을 탭할 때, 지정된 데스티네이션으로 이동합니다.
```

# 동작 뒤로 가기 및 오버레이 닫기 동작 설명

## 1. **강의 개요**

```jsx
목표: 모바일 앱 화면을 제작하고, Close Overlay와 Back 액션을 배우는 것.

프로젝트: 다운로드 버튼이 있는 앱 화면을 디자인.
```

## 2. **디자인 단계**

```jsx
새 디자인 파일 생성: 이름을 "App"으로 변경.

iPhone 프레임 설정: "Main Screen" 프레임 생성.

이미지와 아이콘 배치:

	Unsplash에서 꽃 이미지 추가.

	Feather Icons에서 다운로드 및 북마크 아이콘 추가.

텍스트 설정:

	"Flower" 텍스트 추가: 글꼴을 Rubik으로 변경하고, 세미볼드로 설정.

프레임 정렬: 아이콘과 텍스트를 프레임 내에 정렬하고 그룹화.
```

## 3. **Download Button Overlay 생성**

```jsx
프레임 추가: Download Button Overlay라는 이름의 프레임 생성.

버튼 디자인:

	"Download Now"와 "Cancel" 버튼 추가.

	Corner radius와 채우기 색상 설정.

버튼 정렬: 두 버튼을 Overlay 프레임 내에 정렬.
```

## 4. **프로토타입 연결 및 테스트**

```jsx
Open Overlay 액션:

	다운로드 아이콘을 클릭 시 Download Button Overlay가 열리도록 설정.

Navigate to 액션:

	"Download Now" 버튼 클릭 시 "Thanks For Downloading" 화면으로 이동하도록 설정.

Close Overlay 액션:

	"Cancel" 버튼 클릭 시 오버레이가 닫히도록 설정.
```
