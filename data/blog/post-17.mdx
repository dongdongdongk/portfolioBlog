```jsx
게시판 만들기

게시판은 글목록보기(list), 글상세보기(detail), 글쓰기(add), 글수정(update), 글삭제(delete) 기능이 있음

글쓰기는 로그인한 사용자만 가능,
글수정과 글삭제는 작성자만 가능

```

### 1. Table

```jsx
1. 테이블명은 Board
2. 컬럼의 구성은 글번호, 글제목, 글내용, 작성자, 작성날짜, 조회수로 구성
3. 글번호의 들어가는 번호는 Sequence 사용
4. Sequence의 이름은 BOARD_SEQ, 시작번호는 1, 증가번호는 1로 생성
```

### 2. 요청 URL과 JSP

```jsx
1. 글목록보기(list)
	URL       : /board/list.확장자    -- 확장자는 개발자 마음대로
	Method    : GET
	JSP       : /WEB-INF/views/board/list.jsp
	Parameter : 없음


2. 글상세보기(detail)
	URL       : /board/deatail.확장자    -- 확장자는 개발자 마음대로
	Method    : GET
	JSP       : /WEB-INF/views/board/detail.jsp
	Parameter : 글번호

3. 글작성(add)
	1) 글 작성 입력 페이지 요청
		URL       : /board/add.확장자    -- 확장자는 개발자 마음대로
		Method    : GET
		JSP       : /WEB-INF/views/board/add.jsp
		Parameter : 없음

	2) 입력한 글을 Table에 Insert 요청
		URL       : /board/add.확장자    -- 확장자는 개발자 마음대로
		Method    : POST
		JSP       : 없음, 단, 글목록보기로 이동
		Parameter : 글제목, 글내용, 작성자

4. 글수정(update)
	1) 글 수정 입력 페이지 요청
		URL       : /board/update.확장자    -- 확장자는 개발자 마음대로
		Method    : GET
		JSP       : /WEB-INF/views/board/update.jsp
		Parameter : 글번호

	2) 입력한 글을 Table에 update 요청
		URL       : /board/update.확장자    -- 확장자는 개발자 마음대로
		Method    : POST
		JSP       : 없음, 단, 글목록보기로 이동
		Parameter : 글제목, 글내용, 글번호

5. 글삭제(delete)
	URL       : /board/delete.확장자    -- 확장자는 개발자 마음대로
	Method    : GET
	JSP       : 없음, 단, 글목록보기로 이동
	Parameter : 글번호
```

### 3. Page 흐름

```jsx
1. 글 목록 보기
	- index(home)에서 글목록보기를 요청하는 링크을 만들고 클릭을 하면 글목록 보기 페이지로 이동
	- 글목록페이지는 글번호, 글제목, 작성자, 작성날짜, 조회수를 출력

2. 글 상세보기
	- 글목록에서 글제목을 클릭하면 글상세페이지로 이동
	- 글번호, 글제목, 작성자, 작성날짜, 조회수, 글내용 출력

3. 글 수정하기
	- 글상세페이지에서 글 수정을 클릭하면 수정입력 폼으로 이동
	- 수정입력 폼에서 수정 작성 후 글목록으로 이동

4. 글 삭제하기
	- 글상세페이지에서 글 삭제를 클릭하면 글 삭제 후 글목록으로 이동

5. 글 작성하기
	- 글목록에서 글작성링크를 만들어 링크를 클릭하면 글작성 입력 폼으로 이동
	- 글 입력 폼에서 글 작성후 글 목록으로 이동
	- 작성자, 제목, 내용을 입력
	- 단, 작성자는 로그인한 사용자의 ID가 자동 입력되어 있어야 하고, 수정 불가하여야 함


```
