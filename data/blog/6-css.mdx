# { 이론 - position(배치) 프로퍼티 이해하기 }

```jsx
HTML 요소의 배치(positioning)**에 관한 기본 개념과 방법을 설명하고 있습니다.
```

## 1. **기본 문서 대열 (Document Flow)**

```jsx
HTML의 블록 레벨 요소는 기본적으로 문서 대열을 따릅니다.

이들은 페이지에서 수평 공간을 모두 차지하며, 각 블록이 한 줄씩 쌓이게 됩니다.

이 경우, 모든 <div> 요소는 각각 한 줄씩 차지하게 됩니다.
```

```jsx
<div>첫 번째 블록</div>
<div>두 번째 블록</div>
<div>세 번째 블록</div>
```

## 2. **Position 프로퍼티의 기본값: `static`**

```jsx
모든 요소는 기본적으로 position: static;을 가지고 있습니다.

이는 요소가 기본 문서 대열에 따라 배치됨을 의미합니다.
```

```jsx
div {
  position: static;
}
```

## 3. **Position 프로퍼티로 위치 조정**

```jsx
position 프로퍼티를 사용해 기본 문서 대열에서 벗어나 특정 위치로 요소를 배치할 수 있습니다.

주요 값으로는 absolute, relative, fixed, sticky 등이 있습니다.
```

### absolute

```jsx
요소를 문서 대열에서 제거하고, 가장 가까운 상대 위치나 고정 위치의 부모 요소를 기준으로 배치합니다.

이 경우 .box 요소는 부모 요소의 위쪽에서 20px, 왼쪽에서 50px 떨어진 위치에 배치됩니다.
```

```jsx
.box {
  position: absolute;
  top: 20px;
  left: 50px;
}
```

### relative

```jsx
요소를 문서 대열에 그대로 두되, 기본 위치에서 상대적으로 이동시킵니다.

이 경우 .box 요소는 기존 위치에서 20px 아래로, 50px 오른쪽으로 이동합니다.
```

```jsx
.box {
  position: relative;
  top: 20px;
  left: 50px;
}
```

### fixed

```jsx
요소를 뷰포트(브라우저 창)를 기준으로 고정시킵니다. 스크롤을 하더라도 위치가 변하지 않습니다.

이 경우 .box 요소는 뷰포트의 오른쪽 아래에서 10px 떨어진 위치에 고정됩니다.
```

```jsx
.box {
  position: fixed;
  bottom: 10px;
  right: 10px;
}
```

## 3. **`fixed` 값의 사용**

```jsx
position: fixed;는 요소를 문서 대열에서 제거하고,

```

## 4. **배치 콘텍스트 및 문제 해결**

```jsx
fixed 값이 적용된 요소는 뷰포트를 기준으로 위치가 설정됩니다.

예제에서 top: 100px;을 top: 0;으로 변경하면, 요소가 브라우저 창의 가장 위에 위치하게 됩니다.

요소의 너비가 브라우저 창을 넘어가는 문제는 box-sizing: border-box;를 사용하여 해결할 수 있습니다.

이 값은 패딩과 테두리를 포함하여 너비를 계산하므로, 요소가 뷰포트를 초과하지 않게 합니다.
```

# { z-index 이해하기 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381559/notion-blog/_/_/CSS/_CSS_/_6_CSS_/image_5.png)

## 1. **z축과 z-index 개념**

```css
z축:

화면에서 요소를 좌우(x축)나 상하(y축) 외에 **앞뒤(z축)**로도 배치할 수 있는 개념입니다.

이를 통해 요소들이 서로 겹치는 상황을 제어할 수 있습니다.

z-index:

요소의 z축 위치를 조정하는 CSS 속성입니다.

이 속성의 값에 따라 요소가 앞이나 뒤에 위치하게 됩니다.
```

## 2. **기본 z-index 값과 적용**

```css
모든 요소의 기본 z-index 값은 auto이며, 이는 숫자로는 0과 같습니다. ( 기본 static 은 0 이니 -1 을 해야지 뒤로 간다는거 )

	position 속성이 설정되지 않은 요소에는 z-index가 적용되지 않으며,

	기본적으로 static인 요소는 z축에서의 위치를 변경할 수 없습니다.

position이 relative, absolute, fixed로 설정된 요소는 z-index 속성을 사용할 수 있습니다.
```

```css
.background {
  background: url('../packages/images/plans-background.jpg');
  width: 100%;
  height: 100%;
  position: fixed;
  z-index: -1;
}
```

## 4. 내비게이션 바와 z-index

```css
내비게이션 바가 배경 이미지 위에 표시되는 이유는 z-index와 HTML 문서의 순서 때문입니다.

HTML 파일에서 나중에 나오는 요소는 같은 z-index 값을 가질 때 더 앞에 위치하게 됩니다.
```


# { 상대적 배치(Relative Positioning) 이해와 활용 }

```css
상대적 배치(relative positioning)**를 활용하여 HTML 요소를 어떻게 조작할 수 있는지에 대해 학습했습니다.

이전에 고정 배치(fixed)와 절대적 배치(absolute positioning)를 다루었지만,

상대적 배치가 어떻게 다른지 이해하는 것이 중요합니다.
```

## 1. 상대적 배치의 기본 개념

```css
상대적 배치에서 position: relative를 사용하면 요소는 원래 위치에 그대로 유지됩니다.

그러나 추가로 top, left, right, bottom 속성을 이용해, 원래 위치를 기준으로 요소를 이동시킬 수 있습니다.

중요한 점은, 요소가 문서의 흐름에서 제외되지 않으며, 다른 요소와의 배치 관계는 그대로 유지된다는 것입니다.
```

## 2. 코드 예제

```css
<div class="parent">
    <div class="child-1">Navigation Bar</div>
</div>
```

```css
.child-1 {
  position: relative;
  top: 50px;
  left: 50px;
}
```

```css
이렇게 설정하면, child-1 요소는 원래 위치에서 아래로 50px, 왼쪽으로 50px 이동합니다.
```

## 3. 상대적 배치의 작동 원리

```css
고정 배치와 절대적 배치와 달리, 상대적 배치는 요소 자체를 기준으로 이동시킵니다.

요소는 문서 흐름에서 제거되지 않으므로, 이동된 공간은 그대로 차지하며 다른 요소와의 관계도 변경되지 않습니다.
```

## 5. 상대적 배치의 장단점

```css
장점:

	상대적 배치는 요소의 배치를 변경하면서도 문서 흐름을 유지할 수 있습니다. 특히, 작은 조정을 위해 사용됩니다.

단점:

	부모 요소의 경계를 벗어날 수 있어, 부모 요소 안에서 제한적인 배치가 필요할 때는 추가적인 조치가 필요합니다.
```

```css
이를 해결하는 방법을 학습했습니다. 상대적 배치는 유용하지만,

요소가 부모 요소의 경계를 벗어날 수 있어, 의도치 않은 결과를 초래할 수 있습니다.

이러한 문제를 피하기 위한 CSS 기법을 소개하겠습니다.
```

## 3. Body 요소에서의 오버플로우 문제

```css
때때로, body 요소를 부모 요소로 사용할 때, overflow: hidden 속성이 제대로 작동하지 않는 경우가 발생합니다.

이는 CSS의 기본 동작으로 인해 body 요소에 적용된 오버플로우가 html 요소로 전달되기 때문입니다.
```

```css
body {

}
```

# { Sticky 배치 개념 정리 }

```css
Sticky 배치는 상대적 배치와 고정 배치의 조합으로,

특정 스크롤 위치에 도달하면 요소가 뷰포트에 고정되는 기능을 제공합니다.
```

## 1. Sticky 배치 동작

```css
기본 상태: 상대적 배치처럼 동작하며, 문서 흐름에 영향을 주지 않습니다.

스크롤 시: 상단(top) 프로퍼티를 통해 지정된 거리만큼 스크롤되면 요소가 뷰포트에 고정됩니다.

부모 요소 끝에서 멈춤: 요소가 부모 요소의 경계를 벗어나면 고정 상태가 해제됩니다.
```

# { 스택 컨텍스트(Stacking Context) 개념 정리 }

```css
스택 컨텍스트는 HTML 요소들이 z축을 기준으로 쌓이는 방식을 정의하는 CSS 개념입니다.

각 요소는 특정한 규칙에 따라 스택 컨텍스트를 형성하며,

이 스택 컨텍스트는 그 요소의 자식 요소들이 어떻게 배치되고 겹쳐지는지를 결정합니다.
```

## 1. 기본 개념

```css
Z-index:

	요소들이 z축을 기준으로 쌓이는 순서를 정의하는 속성입니다. 값이 클수록 화면 상에서 위에 표시됩니다.

스택 컨텍스트 생성:

	특정 CSS 속성들(ex: position: fixed, z-index)이 적용된 요소는 새로운 스택 컨텍스트를 생성합니다.

	이 컨텍스트 내에서는 자식 요소들이 독립적으로 z축을 따라 쌓이지만, 부모 요소의 z-index가 이 자식 요소들의 최종 배치를 결정합니다.
```

### **HTML 구조**:

```css
navigation, headline, contact-us라는 세 개의 부모 요소가 있으며, 이들은 각각 고정된 위치(fixed)에 배치되어 있습니다.

headline 요소 내에 세 개의 자식 요소(image-1, image-2, image-3)가 포함되어 있습니다.
```

### **CSS 스타일**:

```css
navigation, headline, contact-us 요소들이 각각 서로 다른 z-index를 가지고 있습니다.

이는 이들이 화면 상에서 쌓이는 순서를 정의합니다.

image-1, image-2, image-3 자식 요소들도 z-index를 가지고 있으며,

이 값에 따라 부모 요소 내에서 쌓이는 순서가 결정됩니다.
```
