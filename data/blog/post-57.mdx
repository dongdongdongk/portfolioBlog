```java
message = "닉네임은 한글, 영어, 숫자만 4 ~10자리로 입력 가능합니다"

출력될 메세지 입력하는곳

regexp = "^01([0|1|6|7|8|9])-?([0-9]{3,4})-?([0-9]{4})$ "

패턴을 지정해 주는곳으로 분석하자면

^ : 문자열의 시작

01 : "01"로 시작해야 함

([0|1|6|7|8|9]) : 그 다음에는 0, 1, 6, 7, 8, 9 중 하나의 숫자가 있어야 합

-? : 다음 선택적으로 하이픈("-")이 있을 수 있음

([0-9]{3,4}) :  0-9 범위의 숫자가 3개 또는 4개 나옴

([0-9]{4}) : 0-9 범위의 숫자가 4개 나옴

$ : 문자열 종료

```

# 3.jsp에 메세지 보내줄 Controller 제작

```java
@GetMapping("userJoin")
    public ModelAndView setJoin(@ModelAttribute() UserVO userVO) throws Exception {
        ModelAndView mv = new ModelAndView();
        mv.setViewName("user/userJoin");
        return mv;
    }

    @PostMapping("userJoin")
    public ModelAndView setJoin(@Valid UserVO userVO, BindingResult bindingResult) throws Exception {            //@Valid 주석은 UserVO 개체에 대한 유효성 검사를 수행하는 데 사용됨. 정의된 유효성 검사 제약 조건에 따라 개체의 유효성을 검사
        ModelAndView mv = new ModelAndView();                                                                    //BindingResult 객체에는 유효성 검사를 하여 위반이 있으면 정보를 저장한다. 저장된 정보는 request 영역에 erorros라는 이름으로 저장된다.
        log.debug("Join");
        if(bindingResult.hasErrors()) {                                                                          //유효성 검사 오류가 있는지 확인
            List<FieldError>list = bindingResult.getFieldErrors();                                               //bindingResult 개체에서 모든 필드 오류를 검색하여 List<FieldError> 유형인 list변수에 할당
            Map<String, String> errorMsg = new HashMap<>();                                                      //오류 메시지를 저장할 맵을 생성
            for(int i=0;i<list.size();i++) {
                String field = list.get(i).getField();                                                           //list에서 인덱스 i에 있는 FieldError 객체의 필드 이름을 검색하고 field 변수에 할당
                String message = list.get(i).getDefaultMessage();                                                //list에서 인덱스 i에 있는 FieldError 개체의 기본 오류 메시지를 검색하고 message 에 할당

                System.out.println("필드 = " + field);
                System.out.println("메세지 = " + message);

                errorMsg.put(field,message);                                                                     //errorMsg 맵에 새로운 키-값(field(키),message(값)) 쌍을 추가
            }
            mv.addObject("errorMsg",errorMsg);
            mv.setViewName("user/userJoin");
            return mv;
        }
        int result = userService.setJoin(userVO);
        mv.setViewName("redirect:../");
        return mv;
    }
```
