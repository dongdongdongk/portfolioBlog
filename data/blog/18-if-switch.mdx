- 조건식이 여러개인 if 문에 사용
- if 가 ture 일 경우 if 의 내용을 실행하고 종료
- false 일 경우 else if 의 조건식을 확인하고 ture 일 경우 else if 의 내용 실행 false 일 경우 다른 else if 조건식 확인
- else if 는 개수 제한 없이 사용 가능
- else 는 어떠한 조건식도 충족 시키지 못했을 때 실행
