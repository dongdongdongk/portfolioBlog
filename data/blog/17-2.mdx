- && 둘다 ture 여야지 true (ture ture 여야지 ture다)
- || 둘중 하나만 true 면 true(false false 여야지 false 다)
- ^ 서로 달라야 ture 다.
- ! 피 연산자의 논리 값을 바꿈

![Untitled](<17%20%EC%97%B0%EC%82%B0%EC%9E%90%EC%9D%98%20%EC%A2%85%EB%A5%98(2)/Untitled%206.png>)

![Untitled](<17%20%EC%97%B0%EC%82%B0%EC%9E%90%EC%9D%98%20%EC%A2%85%EB%A5%98(2)/Untitled%207.png>)

- & 와 && (논리곱) 의 차이는 & 는 앞의 연산이 false 여도 뒤의 연산까지 진행 하는 것 이고(앞이 false 라면 어짜피 결과는 false 다) && 앞의 연산에서 이미 false 가 나온다면 뒤의 연산을 진행하지 않는 것 이다. (연산 속도의 차이가 생긴다)

- | 와 || 는 위와 같지만 둘중 하나만 ture 가 나오면 되므로 false 가 아닌 true 가 나오면 연산을 중지하고 결과를 도출한다. ( | 는 앞의 값에 관계없이 둘다 확인한다.)

![Untitled](<17%20%EC%97%B0%EC%82%B0%EC%9E%90%EC%9D%98%20%EC%A2%85%EB%A5%98(2)/Untitled%208.png>)

- 부호에 맞게 변수와 연산을 진행하고 그 수를 변수에 저장하라 이다.
- x += 2 의 경우 x 에 2를 더하고 저장하라 이다. ( x = x +2 )
- 변수 _= 변수 _ 피 연산자 이다.
- 아래 4가지의 대입 연산자는 실제 사용이 그렇게 많지 않다.
