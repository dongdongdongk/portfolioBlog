## 1. SoundSeed Impact란?

SoundSeed Impact는 **타격/충돌/충격 사운드에 특화된 합성(Synthesis) 기반 사운드 변형 플러그인**이다.

하나의 충격 사운드에서 **재질 감**, **크기**, **공명 정도**, **세기** 등을 **실시간으로 바꿔 무한한 변형을 생성할 수 있다.**

즉,

> “같은 금속 타격 소리를 게임 상황마다 다르게 들리게 하고 싶다”
>
> → 이걸 위해 만들어진 시스템.

---

## 2. 전체 워크플로우 개요

| 단계 | 설명                                                                                |
| ---- | ----------------------------------------------------------------------------------- |
| 1    | **SoundSeed Impact Modeler**에서 원본 타격 음을 분석한다.                           |
| 2    | 분석 결과 **Residual(잔류 잡음) WAV 파일** + **Resonance Model(.ssm)** 이 생성된다. |
| 3    | Wwise에 **Residual 파일**을 import하여 Sound Object를 만든다.                       |
| 4    | 그 Sound Object에 **SoundSeed Impact Effect Plugin**을 추가한다.                    |
| 5    | 플러그인 안에서 **.ssm 모델 데이터를 불러온다.**                                    |
| 6    | 조정 가능한 **변환(Transformation) 파라미터로 사운드를 변형한다.**                  |
| 7    | 필요하면 RTPC로 실시간 제어하여 게임 상황에 맞게 변형한다.                          |

---

## 3. Residual Sound & Model Data란 무엇인가

| 파일            | 내용                                                                                 | 역할                                             |
| --------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| Residual WAV    | 원본 소리에서 “공명(울림)”을 제거하고 남은 **잡음/충격 요소**만 남긴 소리            | 플레이할 실제 Audio                              |
| .SSM Model File | 사운드의 **공명(Resonance Mode) 데이터** → “어떤 재질이 어떻게 울리는가”에 대한 정보 | 플러그인이 Residual에 울림을 다시 합성할 때 사용 |

즉,

Residual = "딱!"

SSM = "띠이이잉…"

플러그인은 이 둘을 다시 합쳐 새로운 충격음을 만든다.

---

## 4. Wwise에서 SoundSeed Impact 적용 단계

1. **Residual WAV 파일을 Wwise에 드래그하여 Sound Object 생성**
2. Sound Object 선택 → **Effects 탭** 이동
3. **SoundSeed Impact** 플러그인 추가
4. 플러그인 창에서 `.ssm` 파일 **불러오기(Browse 또는 Drag & Drop)**

이제 재질 공명 데이터가 Residual 사운드에 합성되며

**사운드가 원래의 타격음 형태로 되살아난다.**

---

## 5. SoundSeed Impact 변환 파라미터 상세 설명

SoundSeed Impact는 공명 데이터를 **3가지 방식으로 변형할 수 있다.**

| 파라미터                 | 설명                                     | 청감 효과                                            |
| ------------------------ | ---------------------------------------- | ---------------------------------------------------- |
| **Frequency Stretching** | 공명 주파수 사이의 거리 비율을 확장/축소 | **사물의 크기 변화**처럼 들림 (큰 금속판 ↔ 작은 캔) |
| **Bandwidth Stretching** | 공명이 얼마나 넓게 지속되는가            | **울림(공명) 양 조절** (단단/건조 ↔ 울림이 길다)    |
| **Magnitude Scaling**    | 공명 모드 하나하나의 세기를 조정         | **충격 세기 · 타격 지점** 느낌 변화                  |

---

## 6. RTPC를 이용한 실시간 사운드 변형

각 파라미터는 RTPC에 연결할 수 있다.

→ 게임 상황에서 자동으로 사운드 변형 가능.

예시:

| 상황                              | 변경될 값                                    |
| --------------------------------- | -------------------------------------------- |
| 큰 몬스터가 무거운 무기 휘두를 때 | Frequency ↓ + Magnitude ↑ (크고 무거운 느낌) |
| 작은 캐릭터가 공격할 때           | Frequency ↑ + Magnitude ↓ (가벼운 금속 소리) |

---

## 7. Variation(랜덤 변형)으로 무한한 사운드 다양성 만들기

**Variation 슬라이더**는

재생될 때마다 **주파수/대역폭/크기 변형을 랜덤하게 살짝 변경한다.**

→ 같은 타격 소리를 재생할 때 **매번 다르게** 들리게 한다.

→ "기계적인 반복 음" 문제 해결.

---

## 8. Quality 슬라이더로 CPU 성능 제어

| 값   | CPU 사용량 | 효과                                                |
| ---- | ---------- | --------------------------------------------------- |
| High | 높음       | 공명 모드 많이 사용 → 사운드가 사실적으로 들림      |
| Low  | 낮음       | 공명 단순 처리 → 사운드가 덜 풍부하지만 성능 확보됨 |

게임 상황에 맞추어 RTPC로 자동 조절 가능.

예: 전투가 격해지면 성능 절약 위해 Low로 자동 전환.

---

## 9. 샘플 프로젝트 예시 사운드 유형

Wwise SoundSeed Sample 프로젝트에는 다음 예시가 포함됨:

- **Plastic Hits** → 크기 변형이 크게 느껴짐
- **Wood Bounce** → 탄성(반발력) 감이 표현됨
- **Metal Impact** → 공명량 변화가 매우 드라마틱함
- **Sword & Shield Clash** → Variation 적용하면 전투 느낌 강화됨
- **Punch / 몸 타격** → Magnitude가 타격 세기 표현에 중요

# ✅ 요약 (핵심 한 줄 정리)

> SoundSeed Impact는 Residual + Resonance Model을 실시간 합성하여
>
> 한 개의 충격 사운드 원본으로부터 **무한한 변형 타격 소리를 만드는 플러그인**이다.

## 🥊 왜 이런 플러그인이 필요할까?

게임에서 **타격음(충돌, 쇠 부딪힘, 나무 부딪힘, 주먹 등)** 은

같은 소리를 반복 재생하면 **바로 티가 난다.** (자연스럽지 않음)

예를 들어:

| 타격 상황                  | 결과                                       |
| -------------------------- | ------------------------------------------ |
| 칼로 10번 같은 몬스터 때림 | “챙! 챙! 챙! 챙! 챙!” → 플레이어 귀가 질림 |
| 공 튀는 소리 반복          | “톡, 톡, 톡” → 기계적, 현실감 떨어짐       |

그래서 우리는

> "같은 타격 소리여도, 매번 조금씩 다르게 들리면 좋다"

SoundSeed Impact는 바로 이것을 해결하는 툴이다.

**한 개의 타격 사운드를** → **무한히 변형해서 재생 가능**하게 만든다.

---

## 🔥 핵심 원리 한 줄 요약

타격음은 사실 **두 가지 소리의 합**이다.

| 구성 요소                          | 설명                             | 귀로 들리는 느낌      |
| ---------------------------------- | -------------------------------- | --------------------- |
| **Residual (잔향 없는 충격 소리)** | 순간적 **때리는/부딪히는** 소리  | “딱!”, “퍽!”, “쿵!”   |
| **Resonance (공명, 울림)**         | 재질과 크기 때문에 **남는 잔향** | “띤—” / “텅—” / “웅—” |

SoundSeed는 **이 둘을 분리해서 저장**하고,

Wwise에서 **다시 합쳐서 재생**하면서 여러 변형을 줄 수 있다.

---

## 🎨 비유해서 이해하기

| 비유                                       | 설명                             |
| ------------------------------------------ | -------------------------------- |
| Residual = 망치가 처음 맞닿는 “순간 충격”  | 소리에서 제일 짧고 거친 부분     |
| Resonance = 금속 또는 나무가 울리는 “여운” | 사운드의 질감, 재질, 크기를 결정 |

➡️ SoundSeed는 **여운(Resonance)** 을 마음대로 바꾸는 플러그인이다.

예:

- "작은 금속 캔" → **짧고 얇은 울림**
- "큰 철문" → **크고 깊은 울림**

즉, **같은 Residual**에 **다른 울림**을 붙이면 **다른 재질처럼 들린다.**

## 🛠 전체 과정 흐름 (완전히 이해되는 버전)

| 단계 | 하는 일                                      | 결과                           |
| ---- | -------------------------------------------- | ------------------------------ |
| 1    | SoundSeed Modeler에서 원본 타격음 분석       | 두 파일 생성됨                 |
| 2    | `Residual.wav` 를 Wwise에 가져옴             | “딱!” 같은 충격 소리 재생 가능 |
| 3    | SoundSeed Impact 플러그인을 이 사운드에 적용 | 잔향 합성 가능해짐             |
| 4    | `.ssm (모델 데이터)` 파일 불러오기           | 울림 정보 연결됨               |
| 5    | 플러그인에서 변형 파라미터 조정              | 재질 / 크기 / 세기 / 울림 변화 |
| 6    | 필요하면 RTPC로 실시간 제어                  | 상황에 따라 자동 사운드 변화   |

## 🎚 변형 파라미터 (실제로 어떻게 바뀌는가)

| 파라미터                               | 하는 역할                                      | 실제로 들리는 변화 예시                                         |
| -------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------- |
| **Frequency Stretching** (주파수 늘림) | 공명의 높낮이 조절 → **크기/질량** 변하는 느낌 | 🎛 ↑ → 작고 얇은 물체 느낌 🎛 ↓ → 크고 무거운 물체 느낌         |
| **Bandwidth Stretching** (대역폭 변화) | 울림이 얼마나 “퍼지냐” 조절                    | 🎛 ↑ → 댐핑 강함(딱딱, 건조) 🎛 ↓ → 울림 길어짐, 통 울리는 느낌 |
| **Magnitude Scaling** (세기 조절)      | 충격의 **강도 / 때린 위치** 느낌 변화          | 🎛 ↑ → 강하게 때린 느낌 🎛 ↓ → 약한 접촉 느낌                   |

**이 세 가지를 조합 → 무한한 타격음 변형 가능**

## 🎛 Variation (랜덤 변형) — 핵심 포인트

Variation 슬라이더는

> 매 재생마다 파라미터를 조금씩 랜덤으로 바꿔준다.

결과:

- 같은 소리라도 **매번 다르게**
- “게임 사운드가 살아있는 느낌” 생성

**턴제 RPG 주먹 소리, FPS 금속 충돌음, 무기 전투 사운드에서 매우 중요함**

## 🎮 샘플로 어떤 사운드를 만들 수 있는가?

# ✅ 최종 요약

> SoundSeed Impact는 충격 소리에서 울림을 분리하고,
>
> 그 울림을 **실시간으로 변형해서 붙이는 플러그인**이다.
>
> 그래서 **하나의 소스만으로도 무한한 충격 사운드 변형이 가능**하다.
