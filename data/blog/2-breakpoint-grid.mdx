## 프레임 생성 및 관리

```jsx
프레임 생성 및 관리

	프레임 생성: 프레임 도구를 선택하고 캔버스에서 클릭하여 프레임을 생성합니다.

	프레임 이동: 이동 도구를 사용하여 프레임을 이동할 수 있습니다.

	레이어 패널에서 프레임 확인: 생성된 프레임이 레이어 패널에 표시됩니다.

	프레임 이름 변경: 레이어 패널에서 프레임 이름을 더블 클릭하여 변경할 수 있습니다.

	디자인 파일 이름 변경: 캔버스 상단에서 파일 이름을 클릭하여 변경할 수 있습니다.
```

## 프레임의 개념

```jsx
프레임의 개념

	프레임의 역할: 프레임은 디자인의 기본 요소로, 모든 텍스트, 이미지, 아이콘 등이 프레임에 배치됩니다.

	부모-자식 관계: 프레임은 부모 객체로, 그 안에 배치된 모든 자식 객체를 제어하고 영향을 미칩니다.
```

## 프레임 속성

```jsx
위치 좌표 (X, Y)

	위치 지정: X와 Y 값을 사용하여 개체의 위치를 지정합니다.

	단축키: Shift + 1을 눌러 '화면에 맞추기' 기능을 사용할 수 있습니다.

	눈금자 도구: Shift + R을 눌러 눈금자 도구를 켜고 끌 수 있습니다.

크기 (너비, 높이)

	크기 조정: 너비와 높이 값을 수동으로 입력하여 크기를 변경할 수 있습니다.

	비율 고정: 컨스트레인트를 잠그면 비율을 유지하면서 크기를 조정할 수 있습니다.

회전

	회전 기능: 수동으로 회전하거나, Shift를 누른 상태에서 모서리를 클릭하고 돌려서 회전할 수 있습니다.

모서리 둥글기

	둥글기 설정: 모서리 둥글기 값을 입력하여 프레임 모서리를 둥글게 만들 수 있습니다.

	개별 모서리 설정: 각 모서리의 둥글기 값을 개별적으로 설정할 수 있습니다.

프레임 크기 변경

	Resize to fit 기능: 부모 프레임이 자식 프레임과 크기가 같아지도록 조정할 수 있습니다.

사전 기본 템플릿

	프레임 템플릿: 다양한 스크린 사이즈의 사전 기본 템플릿을 선택할 수 있습니다.
```

## 1. 그리드의 개념 및 중요성

```jsx
그리드란?

	콘텐츠를 효율적으로 구성하는 데 사용되는 구조.

그리드의 중요성

	정돈된 디자인을 가능하게 함.

	콘텐츠의 일관성을 유지함.

	디자인 요소의 정렬을 쉽게 함.
```

## 2. 그리드의 기본 용어

```jsx
행 그리드 (Row Grid): 수평선으로 나뉘어진 그리드.

열 그리드 (Column Grid): 수직선으로 나뉘어진 그리드.

모듈형 그리드 (Modular Grid): 행과 열이 겹쳐서 만들어진 그리드.

거터 (Gutter): 두 줄 사이의 공간.

마진 (Margin): 프레임의 가장자리.

모듈 (Module): 수평과 수직의 그리드가 겹쳐서 만들어진 공간.
```

## 3. 그리드의 종류

```jsx
원고 격자 그리드 (Manuscript Grid)

	많은 텍스트를 정렬할 때 사용.

컬럼 그리드 (Column Grid)

	모바일 및 앱 디자인에 자주 사용.

베이스라인 그리드 (Baseline Grid)

	텍스트를 정확하게 정렬할 때 사용.

모듈 그리드 (Modular Grid)

	행과 열이 교차하여 만들어진 공간에 객체를 배치.

계층적 그리드 (Hierarchical Grid)

	중요도에 따라 콘텐츠를 구성할 때 사용.
```

### 베이스라인 그리드 생성 방법

```jsx
베이스라인 그리드 생성 방법

	베이스라인 그리드는 텍스트를 정확하게 정렬하는 데 사용되며, 행을 이용하여 만들 수 있습니다.

단계별 가이드:

	새 프레임 생성

		Figma에서 F를 눌러 새 프레임 도구를 선택합니다.

		원하는 크기의 프레임을 생성합니다.

그리드 설정

	프레임을 선택한 상태에서 오른쪽 패널의 Layout Grid 섹션으로 이동합니다.

	+ 아이콘을 클릭하여 새로운 그리드를 추가합니다.

	기본 그리드가 추가됩니다.

그리드 타입 변경

	기본 그리드 설정에서 Grid 타입을 Rows로 변경합니다.

행 개수와 거터 설정

	Count를 적절한 값으로 설정합니다. 예를 들어, 50으로 설정하여 촘촘한 그리드를 만듭니다.

	Gutter를 0으로 설정합니다.

불투명도 조절

	그리드의 불투명도를 조절하여 가시성을 높입니다. 예를 들어, Opacity를 100%로 설정합니다.

	베이스라인 그리드 확인

이제 프레임 안에 촘촘한 행 그리드가 생성되어 텍스트를 정확하게 정렬할 수 있는 베이스라인 그리드가 완성되었습니다.
```

### 모듈 그리드 생성 방법

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381592/notion-blog/_/_/_/_UI_UX_/_2_Breakpoint_Grid/Untitled_12.png)

```jsx
모듈 그리드는 행과 열이 교차하여 생성된 공간에 객체를 배치하는 데 사용됩니다. 열 그리드와 행 그리드를 동시에 사용하여 만듭니다.

단계별 가이드:

새 프레임 생성

	Figma에서 F를 눌러 새 프레임 도구를 선택합니다.

	원하는 크기의 프레임을 생성합니다.


열 그리드 설정

프레임을 선택한 상태에서 오른쪽 패널의 Layout Grid 섹션으로 이동합니다.

+ 아이콘을 클릭하여 새로운 그리드를 추가합니다.

기본 그리드가 추가됩니다.

기본 그리드 설정에서 Grid 타입을 Columns로 변경합니다.

열 개수와 마진 설정

	Count를 적절한 값으로 설정합니다. 예를 들어, 6으로 설정하여 6개의 열을 만듭니다.

	Margin을 원하는 값으로 설정합니다. 예를 들어, 양쪽 마진을 100으로 설정합니다.

	Gutter 간격을 설정합니다. 예를 들어, 20으로 설정합니다.

	Type을 Stretch로 설정하여 열이 프레임 너비에 맞게 자동 조정되도록 합니다.


행 그리드 설정

	+ 아이콘을 클릭하여 새로운 그리드를 추가합니다.

	기본 그리드 설정에서 Grid 타입을 Rows로 변경합니다.

행 개수와 거터 설정

	Count를 적절한 값으로 설정합니다. 예를 들어, 6으로 설정하여 6개의 행을 만듭니다.

	Margin을 원하는 값으로 설정합니다. 예를 들어, 상하 마진을 100으로 설정합니다.

	Gutter 간격을 설정합니다. 예를 들어, 20으로 설정합니다.

	Type을 Stretch로 설정하여 행이 프레임 높이에 맞게 자동 조정되도록 합니다.

불투명도 조절

	열 그리드와 행 그리드의 불투명도를 적절히 조절하여 가시성을 높입니다. 예를 들어, Opacity를 10%로 설정합니다.

모듈 그리드 확인

	이제 프레임 안에 행과 열 그리드가 겹쳐져 모듈 그리드가 생성되었습니다. 이 모듈 그리드를 사용하여 객체를 정렬할 수 있습니다.
```

### 디바이스 브레이크포인트 소개

```jsx
일반적인 화면 크기

	모바일: 열 4개, 마진 16px or 20, 24, 거터 16px

	태블릿: 열 8개, 마진 24px, 거터 24px

	데스크탑: 열 6개 또는 12개, 마진 100px, 거터 20px

4의 배수 사용 이유

	모든 열의 개수가 4의 배수로 설정됩니다. 이는 화면을 균등하게 나누기 쉽기 때문입니다.
```
