```jsx
{
  "manifest_version": 3, // 사용 중인 Manifest 파일의 버전입니다. 현재 버전 3을 사용 중입니다.
  "name": "Translate Extension", // 확장 프로그램의 이름입니다.
  "version": "1.0", // 확장 프로그램의 버전입니다.

  "description": "Translate text using Google Translate API", // 확장 프로그램에 대한 설명입니다.
  "permissions": ["storage", "scripting"], // 확장 프로그램이 요구하는 권한입니다. 여기서는 로컬 스토리지와 스크립팅 기능에 대한 권한을 요청합니다.
  "host_permissions": [ // 확장 프로그램이 작동할 수 있는 웹사이트의 범위를 정의합니다.
    "*://*.googleapis.com/",
    "*://*.gstatic.com/",
    "http://*/*",
    "https://*/*"
  ],
  "content_scripts": [ // 웹 페이지에 삽입될 콘텐츠 스크립트에 대한 설정입니다.
    {
      "matches": ["<all_urls>"], // 모든 URL에 대해 적용됩니다.
      "js": ["content.js"], // 적용될 JavaScript 파일입니다.
      "run_at": "document_idle" // 문서 로딩이 완료된 후에 스크립트가 실행됩니다.
    }
  ],
  "action": { // 브라우저 툴바에 표시될 확장 프로그램 아이콘에 대한 설정입니다.
    "default_popup": "popup.html", // 클릭 시 표시될 팝업 페이지입니다.
    "default_icon": { // 아이콘의 사이즈별 경로입니다. 모든 사이즈에 같은 아이콘을 사용하고 있습니다.
      "16": "/images/icon16.png",
      "48": "/images/icon16.png",
      "128": "/images/icon16.png"
    }
  },
  "icons": { // 확장 프로그램 목록에서 표시될 아이콘에 대한 설정입니다.
    "16": "/images/icon16.png",
    "48": "/images/icon16.png",
    "128": "/images/icon16.png"
  },

  "background": { // 백그라운드 스크립트에 대한 설정입니다. 여기서는 서비스 워커를 사용합니다.
    "service_worker": "background.js"
  },
  "content_security_policy": { // 확장 프로그램의 콘텐츠 보안 정책입니다.
    "extension_pages": "script-src 'self'; object-src 'self'"
  }
}

```

```jsx
background.js 파일은 확장 프로그램의 백그라운드 스크립트로,

확장 프로그램의 생명주기 동안 지속적으로 실행되며,

이벤트 리스닝, 알림 전송, 복잡한 로직 처리 등 백그라운드에서 필요한 작업을 수행합니다.

예를 들어, 이 스크립트는 사용자가 특정 동작을 할 때마다 Google Translate API를 호출하여 텍스트를 번역하고 그 결과를 저장하는 역할을 할 수 있습니다. 또한, 팝업이나 콘텐츠 스크립트로부터 메시지를 받아 처리하는 중계자 역할을 하기도 합니다.
```
