# { 트랜지션 무브인 & 무브아웃 & 푸시 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381588/notion-blog/_/_/_/_UI_UX_/_14_Easing_curve/image_2.png)

## 1. **Move In 트랜지션**

```jsx
Move In 트랜지션: 데스티네이션 프레임이 원래 프레임 위로 슬라이드되는 애니메이션.

방향 선택:

	피그마에서 Move In 트랜지션을 선택하면, 프레임이 이동할 방향을 설정할 수 있는 4개의 화살표가 나타남.

	기본 방향은 왼쪽이며, 트리거를 누르면 데스티네이션 프레임이 왼쪽에서 들어옴.

	방향은 왼쪽, 오른쪽, 위, 아래로 선택 가능.

프로토타입 실행:

	방향을 변경하며, 데스티네이션 프레임이 설정한 방향으로 슬라이드되어 들어오는 것을 확인.
```

## 2. **Move Out 트랜지션**

```jsx
Move Out 트랜지션: Move In의 반대 개념으로, 핫스팟 프레임이 슬라이드되어 나가는 애니메이션.

차이점:

	Move In: 데스티네이션 프레임이 이동하여 들어옴.

	Move Out: 핫스팟 프레임이 이동하여 나감.

프로토타입 실행:

	트리거 시, 핫스팟 프레임이 설정된 방향으로 나가고, 데스티네이션 프레임은 고정된 상태로 유지됨.
```

## 3. **Push 트랜지션**

```jsx
Push 트랜지션: 원래 프레임이 데스티네이션 프레임에 의해 밀려나는 애니메이션.

사용 사례: 주로 스와이프 제스처를 복제하는 데 사용.

프로토타입 실행:

	트리거 시, 원래 프레임이 밀려나고, 데스티네이션 프레임이 자리 잡음.
```

# { 스마트 애니메이트 틱 (Smart Animate Tick) }

## 1. **스마트 애니메이션의 옵션: 일치하는 레이어 찾기**

```jsx
기능:

	이 옵션을 선택하면 두 개의 프레임 사이에서 동일한 이름을 가진 레이어를 자동으로 찾습니다.

	예를 들어, 두 프레임에 각각 "Ellipse 1"이라는 레이어가 있다면, 스마트 애니메이션은 이 두 레이어를 일치시켜 자연스러운 애니메이션 효과를 만듭니다.

사용 시 주의사항:

	이 옵션은 오직 일치하는 레이어에서만 작동합니다.

	Move In, Move Out 같은 다른 트랜지션에서는 이 옵션이 적용되지 않습니다.

실행:

	R을 눌러 애니메이션을 재생하면, 일치하는 레이어가 자연스럽게 변환되는 것을 볼 수 있습니다.
```

# { Bezier 곡선 기초 및 Linear Ease }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381589/notion-blog/_/_/_/_UI_UX_/_14_Easing_curve/image_4.png)

## 1. **완화 곡선(Easing Curves) 개념**

```jsx
정의: 완화 곡선은 시간에 따라 물체의 위치 변화를 결정하는 곡선으로, 주로 베지어 곡선을 사용합니다.

구성:

	X축: 시간(time)

	Y축: 위치(position)

역할: 물체의 움직임이 얼마나 자연스럽게 보일지를 결정하며, 애니메이션에서 중요한 역할을 합니다.
```

## 2. **Linear Ease**

```jsx
특징:

	물체가 일정한 속도로 움직이며, 속도가 시간에 따라 변하지 않습니다.

	1단위 거리를 1단위 시간에 이동하고, 2단위 거리를 2단위 시간에 이동하는 등 선형적으로 움직입니다.

	그래프: Linear Ease의 그래프는 직선으로 표현됩니다.

사용 예시:

	실생활에서는 거의 사용되지 않는 트랜지션입니다. 예를 들어, 문을 열고 닫을 때 속도가 일정하지 않으므로, 이 트랜지션은 부자연스러울 수 있습니다.

	디자인에서 실제로 사용하기보다는 트랜지션의 기본 개념을 이해하는 데 유용합니다.
```

# { Ease In & Out }

## 1. **Ease In 커브**:

```tsx
특징: 천천히 시작하여 끝에 도달할수록 가속하는 커브.

장점: 부드러운 전환을 제공함.

단점: 오브젝트가 느리게 느껴질 수 있음.

그래프 예시: 시작할 때는 3단위 시간에 1단위 거리를 이동하고, 끝에 도달하면 1단위 시간에 3단위 거리를 이동.

피그마 적용: Ease In으로 전환 후, 지속 시간을 1초로 설정하면, 오브젝트가 느리게 시작하고 끝에 도달할수록 속도가 빨라짐.
```

## 2. **Ease Out 커브**:

```tsx
특징: 빠르게 시작하지만 끝에 도달할수록 속도가 느려지는 커브.

그래프 예시: 시작할 때는 1단위 시간에 3단위 거리를 이동하고, 끝에 도달하면 3단위 시간에 1단위 거리를 이동.

피그마 적용: Ease Out으로 전환 후, 애니메이션이 빠르게 시작하고 끝에 도달할수록 속도가 느려짐.
```

## 3. **Ease In and Out 커브**:

```tsx
특징: 천천히 시작하고 중간에 가속되지만, 끝에 도달할수록 다시 속도가 느려지는 커브.

그래프 예시: 시작과 끝 부분에서 느리고, 중간에서 속도가 증가.

피그마 적용: Ease In and Out으로 전환 후, 오브젝트가 느리게 시작해 중간에 속도가 빨라지고, 끝에 도달할 때 다시 느려짐.

```

# { Ease In & Out Back }

## 1. Ease In Back 커브:

```tsx
특징: 물체가 움직이기 시작할 때 약간 뒤로 튕겨져 나가는 동작을 보이는 커브.

그래프 예시: 4단위 시간 동안 1단위만 이동하고, 3단위 시간에 X축을 넘어가며 뒤로 이동. 마지막에는 1단위 시간에 4단위 거리를 빠르게 이동.

피그마 적용: Ease In Back으로 전환 후, 애니메이션이 시작할 때 물체가 뒤로 튕겨졌다가 빠르게 목표 지점에 도달하는 것을 볼 수 있음.
```

## 2. Ease Out Back 커브:

```tsx
특징: 애니메이션이 빠르게 시작되고, 끝에 도달할 때 물체가 경로를 벗어나면서 뒤로 튕겨 나가는 동작을 보이는 커브.

그래프 예시: 시작할 때 1단위 시간에 4단위 거리를 이동하고, 끝에 도달할 때는 4단위 시간에 1단위 거리만 이동하며 경로를 벗어남.

피그마 적용: Ease Out Back으로 전환 후, 애니메이션이 빠르게 시작하고 끝에서는 경로를 벗어나 뒤로 튕겨 나가는 모습을 볼 수 있음.
```

## 3. Ease In 및 Out Back 곡선:

```tsx
특징: 천천히 시작해 중간에 가속되고, 끝에 갈수록 느려지며 양쪽 끝에서 뒤로 튕겨지는 동작을 보이는 커브.

그래프 예시: 양쪽 끝에서 일정한 경로를 벗어나며 바운스 애니메이션이 발생.

피그마 적용: Ease In and Out Back으로 전환 후, 시작과 끝에서 뒤로 튕겨지는 바운스 효과가 나타나며 중간에서는 가속.
```

## 4. 커스텀 곡선:

```tsx
설명: 사용자는 필요에 따라 직접 커스텀 곡선을 만들 수 있음.

예시: 핸들바를 조정해 원하는 대로 물체가 새로운 방향으로 멀리 이동하도록 설정 가능.
```

# { 컴포넌트 생성으로 모든 커브 설명 }

```tsx
8개의 완화 곡선을 복습하고, 실제 UI 요소인 토글 버튼을 생성하여 각 곡선이 어떻게 작동하는지 살펴보았습니다.
```

## 1. **UI 요소 생성**:

```tsx
iPhone 크기의 프레임을 사용하여 토글 버튼을 만듭니다.

직사각형 도구로 150 x 50 크기의 직사각형을 만들고, 코너 반경을 100으로 지정하여 둥근 버튼을 만듭니다.

타원 도구로 버튼 내부의 원을 만들고, 중앙에 배치합니다.

복사본을 만들어 원을 오른쪽으로 이동시키고, 직사각형의 색상을 파란색으로 변경합니다.
```

## 2. **프로토타입 설정**:

```tsx
프로토타입 모드로 전환하여, 첫 번째 상태에서 두 번째 상태로의 인터랙션을 설정합니다.

애니메이션 지속 시간을 1초(1000밀리초)로 설정하고, 처음에 Linear 완화 곡선을 사용합니다.
```

## 3. **완화 곡선 적용**

```tsx
Linear: 일정한 속도로 애니메이션이 진행됨.

Ease In: 천천히 시작하여 가속.

Ease Out: 빠르게 시작하여 점점 속도가 느려짐.

Ease In and Out: 천천히 시작하고, 중간에 가속되었다가 끝에서 다시 느려짐.

Ease In Back: 물체가 처음에 위치를 벗어나 뒤로 튕겨졌다가 가속되어 목적지에 도달.

Ease Out Back: 빠르게 시작하지만 끝에 도달할 때 위치를 벗어나 뒤로 튕겨짐.

Ease In and Out Back: 양쪽 끝에서 튕겨 나오는 바운스 효과가 나타남.
```
