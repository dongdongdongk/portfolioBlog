### Event 전달(위임)

```jsx
버블링 과 캡처링
default는 버블링

1. 버블링
	- 중접된 Element 들에서 같은 이벤트가 적용 되었을때
	- 자식 부터 실행하고 부모로 전파 되는것
	자식 엘리먼트에 이벤트가 발생하면 할당된 핸들러(callback)가 작동하고 부모의 핸들러가 작동
	addEventListener('이벤트명',function(){}, capture:false) - {capture:false} 대신에 false만 작성 가능

2. 캡처링
	- 중접된 Element 들에서 같은 이벤트가 적용 되었을때
	- 부모 부터 실행하고 자식으로 전파 되는것
	이벤트 전달이 버블링 반대
	addEventListener('이벤트명', 콜백함수, {capture:true}) - {capture:true} 대신에 true만 작성 가능

	3. 버블링, 캡처링 중단
	- 이벤트 전달을 중단 시키기
	- 꼭 필요한 경우를 제외하고 버블링 중단은 안하는 것을 권장
		1) event.stopPropagation();

		d2.addEventListener("click", function(event){
		    event.stopPropagation();
		    console.log("p click");
		}, false);

		2) event.stopImmediatePropagation();
		해당 Element에 있는 모든 이벤트 전달을 중단 할 때 사용

	4. Element가 가지고 있는 기본 동작(event, a, submit,,,)을 중단

		1) preventDefault()

		- Element가 가지고 있는 기본 동작(event, a, submit,,,)을 중단 시키는 메서드

		<a href="https://www.google.com" id="google">GOOGLE</a>

			const google = document.getElementById("google");

			google.addEventListener("click", function(event){
		    alert("Go Google");
		    event.preventDefault();
			});

		2) 콜백함수에서 false를 리턴

				google.addEventListener("click", function(event){
		    alert("Go Google");
		    return false;
			});


```
