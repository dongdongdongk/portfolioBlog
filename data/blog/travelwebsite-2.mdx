## 그라데이션 사용하기

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381574/notion-blog/_/_/CSS/_/TravelWebsite/TravelWebsite_-2-/image_4.png)

```jsx
이 background 속성은 두 가지 배경을 겹쳐서 사용하고 있습니다.

하나는 그라데이션(linear-gradient)이고, 다른 하나는 이미지(url)입니다.

이 두 개의 배경이 결합되어, 그라데이션이 위에, 이미지가 그 아래에 위치하게 됩니다.
```

```jsx
background: linear-gradient(to top, rgba(0, 0, 0, 0.73), rgba(0, 0, 0, 0.609)),
            url(../../assets/map.jpg);  /* 비디오 카드 배경 */

```

```jsx
linear-gradient(to top, rgba(0, 0, 0, 0.73), rgba(0, 0, 0, 0.609))
```

```jsx
이 부분은 그라데이션(점차 색이 변하는 효과)을 나타냅니다.

linear-gradient는 색이 선형으로 변하는 효과를 적용할 때 사용됩니다.

to top:

		그라데이션이 아래에서 위로(bottom-to-top) 진행된다는 뜻입니다. 색상이 아래에서 시작해서 위로 가면서 점차 변합니다.

rgba(0, 0, 0, 0.73):

		아래쪽 색은 검은색(RGB 값이 0, 0, 0)이며, 투명도(opacity)가 73%입니다. rgba는 Red, Green, Blue, 그리고 Alpha(투명도)를 의미합니다.

rgba(0, 0, 0, 0.609):

		위쪽으로 갈수록 검은색이 더 투명해지는(60.9% 투명) 색으로 변합니다.

즉, 이 linear-gradient는 아래는 진한 검은색, 위로 올라갈수록 점점 더 투명해지는 검은색의 그라데이션을 만든다고 보면 됩니다.

이 효과는 배경 이미지 위에 어두운 필터처럼 덮이는 역할을 합니다.
```

```jsx
url(../../assets/map.jpg)
```

```jsx
이 부분은 배경에 이미지를 넣는 역할을 합니다. url() 안에 이미지 파일의 경로가 들어가 있으며, map.jpg라는 이미지를 사용합니다.

두 배경이 겹쳐지는 원리

이 CSS에서는 그라데이션이 먼저 선언되고, 그 다음에 이미지가 선언되었기 때문에 그라데이션이 이미지 위에 표시됩니다.

그래서 사용자는 이미지 위에 살짝 어두운 투명한 레이어가 덧씌워진 것처럼 보이게 됩니다.
```

## 화살표 애니메이션의 원리

```jsx
화살표 아이콘이 "Read More" 텍스트 옆에 있으며, 이 화살표가 마우스를 올렸을 때 오른쪽으로 움직이는 애니메이션이 발생합니다.

이 원리를 간단히 설명하면, 아이콘의 위치를 마우스가 올려졌을 때 변경해 주는 방식입니다.

CSS에서는 transform 속성을 사용해 요소의 위치를 이동시킬 수 있습니다.

translateX(10px)는 X축(가로 방향)으로 10px 이동하는 의미입니다.

a:hover {
  color: var(--HoverColor); /* 호버 시 링크 텍스트 색상 변경 */

  .icon {
    transform: translateX(10px); /* 아이콘을 오른쪽으로 10px 이동 */
  }
}
```

## 확대되는 이미지의 원리

```jsx
이미지가 확대되는 것은 CSS의 transform 속성을 사용한 것입니다.

마우스를 이미지 위에 올리면, 이미지를 살짝 크게 보여주는 효과가 발생하는데,

이는 **이미지의 크기를 확대(scale)**하는 방식입니다.
```

```jsx
scale(1.1)은 이미지를 10% 더 크게 만든다는 의미입니다. 즉, 원래 크기보다 1.1배로 확대됩니다.

그리고 transition 속성은 이 확대 효과가 부드럽게 일어나도록 만듭니다.

.imgDiv:hover img {
  transform: scale(1.1); /* 이미지를 1.1배 확대 */
  transition: 3s ease; /* 3초 동안 부드럽게 확대 */
}
```
