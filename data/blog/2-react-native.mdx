# 📱 React Native 기초 완전 정리

> React를 알면 React Native는 금방 익힌다 — 다르지만 비슷하다!

---

## 🔄 React.js vs React Native — 핵심 차이

| React.js (웹) | React Native (모바일)   | 설명              |
| ------------- | ----------------------- | ----------------- |
| `<div>`       | `<View>`                | 레이아웃 컨테이너 |
| `<p>`, `<h1>` | `<Text>`                | 텍스트 표시       |
| `<img>`       | `<Image>`               | 이미지 표시       |
| `<button>`    | `<TouchableOpacity>`    | 버튼/클릭 요소    |
| `onClick`     | `onPress`               | 클릭/탭 이벤트    |
| CSS 파일      | StyleSheet / Nativewind | 스타일링          |

> ✅ JavaScript, JSX 문법은 **동일** — HTML 태그만 바뀐다고 생각하면 됩니다!

---

## 🧱 핵심 컴포넌트 총정리

---

### 1. `<Text>` — 텍스트 표시

웹의 `<p>`, `<h1>` 대신 React Native에서는 모든 텍스트에 `<Text>`를 씁니다.

```jsx
import { Text } from 'react-native'

export default function App() {
  return (
    <Text style={{ fontSize: 24, color: 'blue', fontWeight: 'bold' }}>
      안녕하세요, React Native!
    </Text>
  )
}
```

> 💡 `style` prop으로 CSS와 비슷하게 스타일을 줄 수 있습니다.

---

### 2. `<View>` — 레이아웃 컨테이너

웹의 `<div>`와 같은 역할. 다른 컴포넌트를 감싸는 박스입니다.

**기본적으로 Flexbox 레이아웃**이 적용됩니다.

```jsx
import { View, Text } from 'react-native'

export default function App() {
  return (
    <View style={{ flexDirection: 'row', justifyContent: 'center', alignItems: 'center' }}>
      <Text>왼쪽</Text>
      <Text>오른쪽</Text>
    </View>
  )
}
```

> 💡 `flexDirection`, `justifyContent`, `alignItems` — 웹 Flexbox와 동일한 속성을 씁니다.

---

### 3. 스타일링 방법 2가지

### 방법 1: StyleSheet (공식 방법)

```jsx
import { View, Text, StyleSheet } from 'react-native'

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>제목입니다</Text>
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
  },
  title: {
    fontSize: 20,
    color: 'black',
  },
})
```

> 💡 StyleSheet는 스타일을 한 객체에 모아두는 방식 — 큰 앱에서 **성능 최적화**에 유리합니다.

### 방법 2: Nativewind (Tailwind CSS 방식)

```jsx
import { View, Text } from 'react-native'

export default function App() {
  return (
    <View className="flex-1 items-center justify-center bg-white">
      <Text className="text-2xl font-bold text-blue-500">Tailwind처럼 쓰는 React Native!</Text>
    </View>
  )
}
```

> 💡 웹에서 Tailwind CSS를 써봤다면 바로 적응 가능. 요즘 점점 더 많이 씁니다.

---

### 4. 버튼/터치 관련 컴포넌트

### `<TouchableOpacity>` — 가장 많이 쓰는 버튼

누르면 **투명도**가 낮아지는 시각적 피드백을 줍니다.

```jsx
import { TouchableOpacity, Text } from 'react-native'

export default function App() {
  return (
    <TouchableOpacity
      onPress={() => alert('버튼 눌림!')}
      style={{ backgroundColor: 'blue', padding: 12, borderRadius: 8 }}
    >
      <Text style={{ color: 'white' }}>눌러보세요</Text>
    </TouchableOpacity>
  )
}
```

### `<TouchableHighlight>` — 눌렀을 때 배경색 변경

```jsx
import { TouchableHighlight, Text } from 'react-native'
;<TouchableHighlight
  onPress={() => console.log('눌림')}
  underlayColor="#DDDDDD" // 눌렸을 때 나타나는 색
>
  <Text>하이라이트 버튼</Text>
</TouchableHighlight>
```

### `<TouchableWithoutFeedback>` — 피드백 없는 터치

링크나 이미지처럼 **시각적 효과 없이** 탭만 감지할 때 사용합니다.

```jsx
import { TouchableWithoutFeedback, View, Text } from 'react-native'
;<TouchableWithoutFeedback onPress={() => console.log('탭됨')}>
  <View>
    <Text>효과 없는 버튼</Text>
  </View>
</TouchableWithoutFeedback>
```

### `<Button>` — 간단한 기본 버튼

빠르게 버튼이 필요할 때만 씁니다. 커스터마이징이 어렵습니다.

```jsx
import { Button } from 'react-native'
;<Button title="기본 버튼" color="blue" onPress={() => alert('눌림!')} />
```

> 💡 실무에서는 커스터마이징이 자유로운 `TouchableOpacity`를 훨씬 많이 씁니다.

---

### 5. `<FlatList>` — 긴 리스트 렌더링

웹의 `.map()`과 비슷하지만, **스크롤 최적화**가 자동으로 됩니다.

수백 개의 아이템이 있어도 화면에 보이는 것만 렌더링합니다.

```jsx
import { FlatList, Text, View } from 'react-native'

const movies = [
  { id: '1', title: '인터스텔라' },
  { id: '2', title: '기생충' },
  { id: '3', title: '어벤져스' },
]

export default function App() {
  return (
    <FlatList
      data={movies}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <View style={{ padding: 16 }}>
          <Text>{item.title}</Text>
        </View>
      )}
    />
  )
}
```

> 💡 **언제 FlatList vs map?**
>
> - 아이템이 많고 스크롤이 필요하면 → `FlatList`
> - 아이템이 적고 간단하면 → `.map()`

---

### 6. `<ScrollView>` — 스크롤 가능한 컨테이너

웹의 `overflow: scroll`과 같은 개념입니다.

```jsx
import { ScrollView, Text } from 'react-native'

export default function App() {
  return (
    <ScrollView>
      <Text style={{ fontSize: 18 }}>내용 1</Text>
      <Text style={{ fontSize: 18 }}>내용 2</Text>
      <Text style={{ fontSize: 18 }}>내용 3</Text>
      {/* 계속 이어지는 콘텐츠... */}
    </ScrollView>
  )
}
```

> ⚠️ 리스트가 매우 길면 `FlatList`를 쓰세요. ScrollView는 **모든 아이템을 한 번에 렌더링**해서 느려질 수 있습니다.

---

### 7. `<SafeAreaView>` — 안전 영역 확보

노치, 홈 인디케이터, 상태바에 **가리지 않도록** 콘텐츠를 보호합니다.

```jsx
import { SafeAreaView, Text } from 'react-native'

export default function App() {
  return (
    <SafeAreaView style={{ flex: 1 }}>
      <Text>노치에 안 가려요!</Text>
    </SafeAreaView>
  )
}
```

> 💡 더 정확한 처리가 필요하면 `react-native-safe-area-context` 패키지를 씁니다.

---

### 8. `<Image>` / `<ImageBackground>` — 이미지

```jsx
import { Image, ImageBackground, View, Text } from 'react-native';

// 일반 이미지
<Image
  source={{ uri: 'https://example.com/photo.jpg' }}
  style={{ width: 200, height: 200 }}
/>

// 배경 이미지 (위에 다른 컴포넌트를 올릴 수 있음)
<ImageBackground
  source={{ uri: 'https://example.com/bg.jpg' }}
  style={{ width: '100%', height: 300 }}
>
  <Text style={{ color: 'white', fontSize: 24 }}>배경 위 텍스트</Text>
</ImageBackground>
```

> ⚠️ SVG 파일은 기본 지원 안 됨 → `react-native-svg` 패키지 필요

### 9. `<Modal>` — 팝업 창

```jsx
import { Modal, View, Text, TouchableOpacity } from 'react-native'
import { useState } from 'react'

export default function App() {
  const [visible, setVisible] = useState(false)

  return (
    <View>
      <TouchableOpacity onPress={() => setVisible(true)}>
        <Text>모달 열기</Text>
      </TouchableOpacity>

      <Modal
        visible={visible}
        animationType="slide" // 'fade', 'slide', 'none'
        onRequestClose={() => setVisible(false)}
      >
        <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
          <Text>모달 내용입니다!</Text>
          <TouchableOpacity onPress={() => setVisible(false)}>
            <Text>닫기</Text>
          </TouchableOpacity>
        </View>
      </Modal>
    </View>
  )
}
```

### 10. `Alert` — 알림 다이얼로그

```jsx
import { Alert, TouchableOpacity, Text } from 'react-native'
;<TouchableOpacity
  onPress={() =>
    Alert.alert(
      '확인', // 제목
      '정말 삭제할까요?', // 내용
      [
        { text: '취소', onPress: () => console.log('취소') },
        { text: '확인', onPress: () => console.log('삭제!') },
      ]
    )
  }
>
  <Text>삭제</Text>
</TouchableOpacity>
```

### 11. `<Switch>` — 토글 스위치

```jsx
import { Switch, View, Text } from 'react-native'
import { useState } from 'react'

export default function App() {
  const [isOn, setIsOn] = useState(false)

  return (
    <View style={{ flexDirection: 'row', alignItems: 'center' }}>
      <Text>알림 설정</Text>
      <Switch
        value={isOn}
        onValueChange={(value) => setIsOn(value)}
        trackColor={{ false: '#ccc', true: '#4CAF50' }}
        thumbColor={isOn ? '#fff' : '#f4f3f4'}
      />
    </View>
  )
}
```

## 📊 컴포넌트 한눈에 비교

| 컴포넌트             | 웹 대응 요소              | 주요 용도             |
| -------------------- | ------------------------- | --------------------- |
| `View`               | `div`                     | 레이아웃 컨테이너     |
| `Text`               | `p`, `h1~h6`, `span`      | 텍스트 표시           |
| `Image`              | `img`                     | 이미지                |
| `ImageBackground`    | `background-image`        | 배경 이미지           |
| `TouchableOpacity`   | `button`                  | 버튼 (투명도 효과)    |
| `TouchableHighlight` | `button`                  | 버튼 (배경색 효과)    |
| `FlatList`           | `.map()`                  | 긴 리스트 렌더링      |
| `ScrollView`         | `overflow: scroll`        | 스크롤 영역           |
| `SafeAreaView`       | `padding-top`             | 노치/상태바 안전 영역 |
| `Modal`              | `<dialog>`                | 팝업 창               |
| `Alert`              | `alert()` / `confirm()`   | 알림 다이얼로그       |
| `Switch`             | `<input type="checkbox">` | 토글 스위치           |
| `ActivityIndicator`  | CSS 스피너                | 로딩 표시             |
| `StatusBar`          | 브라우저 없음             | 상단 상태바 스타일    |

---

## 🔑 핵심 요약

1. **JavaScript + JSX 문법은 React와 동일** — HTML 태그만 바뀐다
2. **`View` = div, `Text` = p/h태그** — 이 두 개만 알아도 기본 레이아웃 가능
3. **Flexbox가 기본** — `View`는 자동으로 Flexbox 적용됨
4. **버튼은 `TouchableOpacity`** — `Button`보다 커스터마이징이 쉬움
5. **긴 리스트는 `FlatList`** — `.map()`보다 성능이 훨씬 좋음
6. **`SafeAreaView`로 감싸기** — 노치 문제 자동 해결
