# useEffect 훅

```jsx
useEffect는 함수 컴포넌트에서 side effect(부수 효과)를 수행할 수 있게 해주는 React 훅 중 하나이다.

이 훅은 컴포넌트가 렌더링될 때마다 실행되거나, 특정 state나 prop이 변경될 때 특정 동작을 수행하는 데 사용된다.
```

## 사용 상황

```jsx
**데이터 가져오기 또는 구독 설정**:

외부 API에서 데이터를 가져오거나, WebSocket을 통해 실시간 데이터를 구독할 때 사용된다.

**수정된 DOM 요소에 대한 작업**:

컴포넌트가 렌더링된 후에 DOM에 직접 접근하여 조작해야 할 때 사용된다.

**타이머나 인터벌 설정**:

일정 시간 간격으로 실행되는 작업을 설정할 때 사용된다.

**컴포넌트의 라이프사이클 관리**:

클래스 컴포넌트의 라이프사이클 메서드와 유사하게, 컴포넌트가 마운트, 언마운트, 업데이트될 때 특정 동작을 수행하도록 설정할 수 있다.

**다른 상태나 프롭스의 변화에 대한 반응**:

특정 상태나 프롭스가 변경될 때 수행되어야 하는 작업을 설정할 수 있다.
```

## 기본 사용법

```jsx
* 기본 사용법

import React, { useEffect } from "react";

function MyComponent() {
    function myEffect() {
        // .... do something
    }

    useEffect(myEffect);

    //rest of component
}

*  한줄 사용법

import React, { useEffect } from "react";

function MyComponent() {
    useEffect(function myEffect() {
        // .... do something
    });

    //rest of component
}
```

## 예제 **Counter 컴포넌트**

```jsx
// counter.jsx

  }
```

## **설명: useEffect와 컴포넌트 렌더링**

```jsx
useEffect 후크를 추가하여 컴포넌트 안에 함수를 전달한다.

기본적인 예제로 MY EFFECT WAS CALLED!을 콘솔에 출력하는 함수 myEffect를 정의한다.

첫 렌더링 이후 useEffect에 전달된 함수가 실행되며 콘솔에 메시지가 출력된다.

버튼을 클릭할 때마다 컴포넌트가 다시 렌더링되며, 매 렌더링마다 useEffect에 전달된 함수가 실행된다.

**추가 설명**:

useEffect 함수 내부의 코드는 컴포넌트의 렌더링 이후에 실행되므로, 첫 렌더링 이후에 한 번 실행되는 것을 확인할 수 있다.

useEffect는 모든 렌더링 이후에 실행되기 때문에, 렌더링이 일어날 때마다 해당 함수가 호출된다.

useEffect는 주로 컴포넌트의 생명주기와 관련된 작업이나 사이드 이펙트를 다룰 때 사용된다.
```

# useEffect 아큐먼트 사용방법

```jsx
useEffect는 컴포넌트의 렌더링 이후에 특정 동작을 수행할 수 있도록 하는 리액트 후크이다.

의존성 배열을 사용하여 특정 조건에 따라 useEffect를 실행할 수 있다.

빈 배열을 사용하면 처음 마운트될 때만 실행되고, 의존성 배열이 없으면 렌더링될 때마다 실행된다.
```

```jsx
**useEffect(myCallbackFn);**

컴포넌트가 렌더링될 때마다 myCallbackFn 함수가 실행, 컴포넌트의 렌더링 후에 수행해야 하는 부가적인 작업을 처리할 때 유용

**useEffect(myCallbackFn,[productId, userId);**

useEffect에 의존성 배열(dependency array)을 추가한 예제이다. 의존성 배열은 useEffect가 실행되는 조건을 지정하는데 사용된다

예제는 [productId, userId]가 의존성 배열로 사용되었다. 이 의존성 배열에 포함된 값 중 하나라도 변경되면 myCallbackFn 함수가 실행된다

**useEffect(myCallbackFn, []);**

빈 배열을 사용하면 useEffect는 컴포넌트가 처음 마운트될 때만 실행되고, 이후의 렌더링에서는 실행되지 않는다
```

## 종속성 배열을 추가(useEffect(myCallbackFn,[productId, userId);)

```jsx
현재 상황에서는 입력을 하거나 카운트를 올리면 렌더링이 다시 일어나기 때문에 useEffect 가 호출되어 콘솔에 계속

"MY EFFECT WAS CALLED!" 가 출력된다
```

```jsx
import { useState, useEffect } from 'react'

function Counter() {
  const [count, setCount] = useState(0)
  const [name, setName] = useState('')
  useEffect(function myEffect() {
    console.log('MY EFFECT WAS CALLED!')
  })
  const increment = () => {
    setCount((c) => c + 1)
  }
  const handleChange = (e) => {
    setName(e.target.value)
  }

  return (
    <div>
      <h1>{count}</h1>
      <button onClick={increment}>+1</button>
      <p>Name : {name}</p>
      <input value={name} onChange={handleChange} type="text" />
    </div>
  )
}
export default Counter
```

## **비동기 함수와 useEffect의 상호 작용:**

```jsx
useEffect는 비동기 함수를 직접 사용할 수 없다.

따라서 useEffect 내에서 비동기 함수를 동기 함수로 래핑하고, 그 안에서 비동기 함수를 호출하는 방식으로 문제를 해결해야 한다.
```

### 예제

```jsx
useEffect(() => {
  const fetchData = async () => { // 동기 함수로 래핑하기 위해 async 키워드로 정의된 함수 내에서 호출하고, 그 결과를 반환
    // 비동기 함수를 동기 함수로 래핑
    const getInitialQuote = async () => {
      try {
        const response = await fetch('API_ENDPOINT');
        const data = await response.json();
        return { text: data.text, author: data.author };
      } catch (error) {
        console.error('Error fetching data:', error);
      }
    };

    // 동기 함수로 비동기 함수 호출
    const result = await getInitialQuote();
    setQuote(result);
  };

  // 첫 렌더링 이후 한 번만 실행
  fetchData();
}, []);

* 래핑 : JavaScript에서 비동기 코드를 동기식으로 처리할 수 있게 하는 기술
```

# **`useEffect`와 비동기 함수 처리:**

```jsx
useEffect의 콜백 함수는 비동기적인 함수를 직접적으로 받지 않는다

useEffect의 콜백 함수는 동기적이어야 하기 때문에 직접적인 비동기 함수 호출이 허용되지 않는다.

따라서 이 문제를 해결하기 위해 비동기 함수를 동기 함수로 감싸고, 그것을 useEffect 내에서 실행하는 방법을 사용한다. (래핑)
```

## **동기 함수 내에서의 비동기 함수 실행:**

```jsx
getInitialQuote라는 함수는 비동기 함수로, API에서 데이터를 가져오는 역할을 한다.

이 함수는 async/await를 사용하여 비동기적으로 데이터를 가져온다.
```

```jsx
const getInitialQuote = async () => {
  try {
    const response = await fetch('API_ENDPOINT')
    const data = await response.json()
    return { text: data.text, author: data.author }
  } catch (error) {
    console.error('Error fetching data:', error)
  }
}
```

## **비동기 함수를 동기 함수로 래핑:**

```jsx
비동기 함수를 동기 함수로 감싸기 위해, 함수 내에서 await를 사용하여 해당 비동기 함수가 완료될 때까지 기다리게 한다.

( 비동기 함수인 api 호출 함수에 await 를 붙여서 동기로 만드는거 )
```

```jsx
const fetchData = async () => {
  // 비동기 함수를 동기 함수로 래핑
  const result = await getInitialQuote()
  setQuote(result)
}
```

## **`useEffect` 내에서의 실행:**

```jsx
useEffect의 콜백 함수는 동기적이어야 하기 때문에,

비동기 함수를 동기 함수로 래핑한 fetchData 함수를 useEffect 내에서 실행한다.

또한, 두 번째 매개변수로 빈 배열을 전달하여 첫 로드 이후 한 번만 실행되도록 한다.
```

```jsx
useEffect(() => {
  // 첫 렌더링 이후 한 번만 실행
  fetchData()
}, [])
```

```jsx
이러한 방식으로 useEffect 내에서 비동기 함수를 동기 함수로 래핑하고 실행함으로써,

초기 렌더링 이후에만 한 번 호출되는 비동기 작업을 처리할 수 있다
```

# 로딩 기능 만들기

```jsx
화면에 컴포넌트가 나타날떄까지 로딩이라는 문자가 출력되게 만들어준다
```

```jsx
import { useState, useEffect } from 'react'
const RANDOM_QUOTE_URL = 'https://inspo-quotes-api.herokuapp.com/quotes/random'

export default function QuoteFetcherLoader() {
  const [quote, setQuote] = useState({ text: '', author: '' })
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    async function fetchQuote() {
      const response = await fetch(RANDOM_QUOTE_URL)
      const jsonResponse = await response.json()
      const randomQuote = jsonResponse.quote
      setQuote(randomQuote)
      setIsLoading(false)
    }
    fetchQuote()
  }, []) // 한번만 출력되게 []

  return (
    <div>
      <p className="Loader" style={{ opacity: isLoading ? 1 : 0 }}>
        {' '}
        // 천천히 생겨나고 사라지게 애니메이션을 줬다 Loading...
      </p>
      <h1>{quote.text}</h1>
      <h3>{quote.author}</h3>
    </div>
  )
}
```

```jsx
useState 훅을 사용하여 quote와 isLoading 상태를 정의한다.

useEffect 훅을 이용하여 컴포넌트가 마운트될 때 한 번만 실행되는 비동기 함수 fetchQuote를 정의한다.

fetchQuote 함수에서는 fetch 함수를 사용하여 RANDOM_QUOTE_URL에서 명언 데이터를 가져오고, 이를 JSON 형식으로 변환한다.

명언 데이터에서 랜덤 명언을 추출하고, setQuote를 통해 quote 상태를 업데이트한다.

로딩 상태를 나타내는 isLoading을 setIsLoading를 통해 false로 업데이트한다.

화면에는 isLoading 값에 따라 로딩 메시지의 투명도가 결정되도록 스타일을 조절한다.

화면에는 현재 명언의 텍스트와 저자를 출력한다.

즉, 이 컴포넌트는 컴포넌트가 처음 로드될 때 useEffect를 통해 명언을 비동기적으로 불러오고,

그 동안에는 로딩 메시지를 보여주게 된다. 명언 데이터가 성공적으로 불러와지면 로딩 메시지는 사라지고, 실제 명언이 출력된다.
```
