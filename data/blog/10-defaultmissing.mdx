**GITHUB Clone 등으로 import 했을 때 기본 폴더가 없는 경우 해결**

1. 프로젝트 생성시 기본 폴더에 Sample 파일을 미리 생성

- 처음 프로젝트 생성시 폴더 내부가 비어 있으면 github에 push 할때 안올라 가는 경우도 있음
- 처음 프로젝트 생성시 기본 폴더에 sample 파일을 생성하고 올리면 해결 가능

2 . import 시 폴더가 없을 때 해결

- 프로젝트 우클릭 → properties - java build path
