# 클릭으로 리스트 타입 변경하기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380945/notion-blog/_/_/_/Untitled.png)

```java
앨범 정보를 표시합니다. 오른쪽 버튼을 클릭하면 해당 앨범 수록곡을 표시합니다.

Radio 컴포넌트를 선택하면 bandexpandtype 속성값을 변경하고 Spin 컴포넌트의 숫자를 변경하면 bandindentsize 속성값으로 반영
```

## 핵심기능

### bandexpandtype

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380945/notion-blog/_/_/_/Untitled_1.png)

```java
Body 밴드 설정에서 expandbartype 속성값을 true로 지정한 경우 목록 오른쪽에 Detail 밴드 영역을 제어할 수 있는 버튼이 표시된다.

이때 Detail 밴드 영역을 어떻게 표시할지 bandexpandtype 속성에서 지정할 수 있다. 속성값을 "expand", "accordion"으로 설정한 경우 비슷하게 동작하는 것처럼 보이는데

"accordion"으로 설정한 경우에는 한번에 하나의 Detail 밴드만 표시한다.

예를 들어 첫 번째 아이템의 Detail 밴드가 열린 상태에서 두 번째 아이템의 Detail 밴드를 펼치면 첫 번째 아이템의 Detail 밴드는 자동으로 닫힌다.

```

### **bandindentsize**

```java
Detail 밴드가 펼쳐질 때 지정된 속성값만큼 왼쪽 여백이 생긴다.

bandexpandtype 속성값이 "popup"인 경우에는 ListView 컴포넌트의 영역을 벗어나 Detail 밴드가 표시될 수 있다.
```

## bandexpandtype 속성값 바꾸어보기

```java
예제에서 bandexpandtype 속성값을 바꾸어볼 수 있도록 Radio 컴포넌트에서 bandexpandtype 속성값을 설정할 수 있도록 합니다.

innerdataset 항목값으로 "expand", "accordion", "popup"을 설정하고 onitemchanged 이벤트 함수를 아래와 같이 작성합니다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381523/notion-blog/_/_/_/Untitled_14.png)

```java
this.Radio00_onitemchanged = function(obj:nexacro.Radio,e:nexacro.ItemChangeEventInfo)
{
	this.ListView00.set_bandexpandtype(e.postvalue);
};
```

```java

this.Spin00_onchanged = function(obj:nexacro.Spin,e:nexacro.ChangeEventInfo)
{
	this.ListView00.set_bandindentsize(e.postvalue);
};
```
