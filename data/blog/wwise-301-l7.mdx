## 1. 🎯 콜백 개념 이해하기

- **콜백(Callback)** :
  이름 그대로 “다시 호출되는 함수”입니다.
  즉, **Wwise에서 특정 이벤트가 발생했을 때 Unity 쪽으로 알려주는 기능**입니다.
- **콜백을 사용하는 이유**
  - 음악이 특정 시점(예: 마디, 박자, 비트)에 도달했을 때 무언가를 실행하고 싶을 때
  - 이벤트가 끝났을 때 다음 사운드나 애니메이션을 실행하고 싶을 때
  - 게임 속 오브젝트를 음악 리듬에 맞춰 움직이게 하고 싶을 때
- **예시 시나리오**
  - 음악의 마디마다 나무(Tree)가 위아래로 움직이게 하기
  - 적 캐릭터의 공격 타이밍을 음악 비트에 맞추기
  - 음악이 끝났을 때 자동으로 다음 트랙으로 전환

## 2. 🧩 Wwise-Type Event와 콜백의 차이

| 비교 항목   | **AkEvent / AkAmbient 컴포넌트**                    | **Wwise-Type Event (사용자 정의 스크립트)**             |
| ----------- | --------------------------------------------------- | ------------------------------------------------------- |
| 설정 방법   | 인스펙터에서 **Use Callbacks** 체크박스로 쉽게 설정 | 코드에서 직접 콜백 플래그와 함수 지정 필요              |
| 장점        | 빠르고 간단 (드래그앤드롭)                          | 세밀한 제어 가능, 확장성 높음                           |
| 단점        | 개별 오브젝트에만 적용                              | 직접 코드 작성 필요                                     |
| 적합한 상황 | 소수의 특정 오브젝트에 콜백 적용                    | 다양한 오브젝트 타입 / 게임 메커닉에서 재사용할 때 유리 |

> 즉, 단순한 테스트용이라면 AkEvent로 충분하지만,
>
> **여러 환경 객체나 시스템 레벨 동기화**를 하려면 Wwise-Type Event를 쓰는 게 낫습니다.

## 4. 🎼 Wwise-Type Event 선언 및 게시하기

1. 클래스 내부, 함수 바깥에 Wwise 이벤트를 선언합니다.

   ```csharp
   public AK.Wwise.Event MusicEvent;
   ```

   - **AK.Wwise.Event** : Unity에서 Wwise 이벤트를 코드로 다룰 수 있게 해주는 타입
   - **MusicEvent** : 인스펙터에 표시되는 이름 (Wwise Event를 드래그해 넣을 수 있음)

2. `Start()` 함수에서 이벤트를 게시(Post)합니다:

   ```csharp
   void Start() {
       MusicEvent.Post(gameObject);
   }
   ```

이렇게 하면 **게임 시작 시점(Start)** 에 **MusicEvent** 가 재생됩니다.

## 5. ⚙️ 콜백(Callback) 추가하기

이제 단순히 이벤트를 재생하는 것뿐만 아니라,

**“언제”** 콜백을 받을지도 지정해야 합니다.

### (1) 콜백 타입 지정하기

Post 함수의 두 번째 매개변수로 콜백 타입을 지정할 수 있습니다.

```csharp
MusicEvent.Post(gameObject, AkCallbackType.AK_MusicSyncBar);
```

- `AkCallbackType.AK_MusicSyncBar`
  → 음악의 **한 마디(Bar)** 가 끝날 때마다 콜백을 호출

> 💡 다른 콜백 타입 예시
>
> - `AK_EndOfEvent` → 이벤트 종료 시
> - `AK_MusicSyncBeat` → 매 비트마다
> - `AK_MusicSyncEntry` → 음악 시작 시

---

### (2) 타입 캐스팅 (Type Casting)

`Post()` 함수는 콜백 타입을 **`uint` 형식**으로 받아야 합니다.

즉, 다음과 같이 **(uint)** 를 붙여줍니다.

```csharp
MusicEvent.Post(gameObject, (uint)AkCallbackType.AK_MusicSyncBar);
```

---

### (3) 콜백 함수 추가하기

Post 함수가 콜백을 호출할 수 있으려면 **어떤 함수를 호출할지** 지정해야 합니다.

세 번째 인자로 함수를 추가합니다.

```csharp
MusicEvent.Post(gameObject, (uint)AkCallbackType.AK_MusicSyncBar, CallbackFunction);
```

## 6. 🧠 Callback Function 구성하기

Wwise가 호출할 함수는 반드시 **특정 매개변수 형태**를 가져야 합니다.

아래처럼 정의합니다:

```csharp
void CallbackFunction(object in_cookie, AkCallbackType in_type, object in_info) {
    GameManager.PushRhythmAction();
}
```

- **`object in_cookie`** : 이벤트 게시 시 함께 전달된 사용자 데이터 (일반적으로 null)
- **`AkCallbackType in_type`** : 어떤 콜백 타입으로 호출되었는지 알려줌 (예: MusicSyncBar)
- **`object in_info`** : 콜백에 대한 세부 정보 (예: 타이밍, 위치 등)

> 💬 지금은 MusicSyncBar 하나만 받기 때문에 세 매개변수는 실제 사용하지 않지만,
>
> Wwise SDK에서는 이를 통해 매우 정밀한 음악 제어가 가능합니다.

---

## ✅ 최종 코드

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

// 🎵 이 스크립트는 Wwise에서 "음악 이벤트"를 게시(post)하고,
// 음악이 한 마디(bar)에 도달할 때마다 콜백(callback) 함수를 실행하도록 설정합니다.
public class PostMusic : MonoBehaviour {

    // 🎧 ① Wwise 이벤트를 받을 변수 선언
    // Wwise의 Event 타입을 사용하여 Unity 인스펙터(Inspector)에서 이벤트를 연결할 수 있게 합니다.
    // 여기에는 "Region Music" 같은 음악 이벤트를 연결합니다.
    public AK.Wwise.Event MusicEvent;

    // ▶️ ② Start()는 Unity에서 오브젝트가 활성화될 때 자동으로 한 번 호출되는 함수입니다.
    void Start() {
        // 🎶 ③ Wwise 이벤트를 게시(Post)하는 부분입니다.
        // 'MusicEvent.Post()'는 실제로 Wwise에 이벤트를 보내서 음악을 재생하게 합니다.

        // 매개변수 설명:
        // 1️⃣ gameObject → 이 이벤트가 게시되는 Unity 오브젝트 (즉, 이 스크립트가 붙은 GameObject)
        // 2️⃣ (uint)AkCallbackType.AK_MusicSyncBar → 콜백이 언제 호출될지를 지정합니다.
        //     AK_MusicSyncBar는 "음악이 한 마디(bar)에 도달할 때"를 의미합니다.
        //     (uint)는 C#의 형 변환 연산자입니다.
        //     여기서 'AkCallbackType'이라는 enum(열거형)을 부호 없는 정수형(uint)으로 변환합니다.
        //
        //     🔹 uint란?
        //     → 'unsigned int'의 줄임말로, 음수(-)가 없는 정수형 데이터 타입입니다.
        //       즉, 0 이상만 표현할 수 있습니다.
        //       보통 C나 C#에서 외부 라이브러리(Wwise처럼!)와 통신할 때
        //       해당 라이브러리의 형식에 맞추기 위해 형 변환을 해주는 것입니다.
        //
        // 3️⃣ CallbackFunction → 실제 콜백이 발생할 때 실행할 함수 이름입니다.
        //
        // 즉, 아래 코드는 "이 오브젝트에서 음악을 재생하고,
        // 음악이 한 마디(bar)에 도달할 때마다 CallbackFunction()을 실행하라"는 뜻입니다.
        MusicEvent.Post(gameObject, (uint)AkCallbackType.AK_MusicSyncBar, CallbackFunction);
    }

    // 🎯 ④ 콜백 함수 정의
    // 위에서 지정한 CallbackFunction 이름과 동일해야 합니다!
    //
    // 매개변수 설명:
    // object in_cookie → Post() 호출 시 함께 전달되는 사용자 데이터 (여기선 사용 안 함)
    // AkCallbackType in_type → 어떤 종류의 콜백이 발생했는지 알려줍니다 (여기선 Bar Sync)
    // object in_info → 콜백과 관련된 추가 정보 (예: 시간, 위치 등)
    void CallbackFunction(object in_cookie, AkCallbackType in_type, object in_info) {

        // 🎬 ⑤ 음악이 한 마디(bar)에 도달할 때마다 호출될 동작을 작성하는 부분입니다.
        // 여기서는 GameManager의 PushRhythmAction() 함수를 호출합니다.
        // 즉, 음악이 한 박자 단위로 리듬에 맞춰 어떤 행동(예: 나무 움직이기)을 수행하도록 합니다.
        GameManager.PushRhythmAction();
    }
}

```

## 7. 🧩 GameManager와 RhythmActions 연동하기

- **GameManager** 는 **Singleton(싱글턴)** 으로 존재하는 오브젝트입니다.
  → 게임 전체에서 **하나만 존재**하고, **파괴되지 않음(DontDestroyOnLoad)**
- **RhythmActions** 스크립트는 각 오브젝트에 붙어 있으며,
  음악의 마디마다 움직이거나 스케일이 변하는 등의 행동을 수행합니다.
- `GameManager.PushRhythmAction()`
  → 씬 안의 **모든 RhythmActions** 컴포넌트를 찾아 호출해줍니다.
  → 덕분에 PostMusic의 Callback 하나만으로 모든 오브젝트가 반응하게 됩니다.

## 8. 🌲 RhythmActions 스크립트 적용하기

1. Hierarchy에서 `TrainingArea_` 로 시작하는 오브젝트 전부 선택
2. **Inspector → Add Component → RhythmActions** 검색 후 추가

이렇게 하면 선택한 모든 오브젝트가 음악의 마디에 맞춰 크기가 변하게 됩니다.

> ⚠️ 주의:
>
> - 일부 오브젝트는 _Static_ 상태일 수 있습니다.
>   - Static 체크박스를 해제해야 런타임에서 움직일 수 있습니다.
> - Music_Region 이벤트를 **MusicEvent** 프로퍼티에 연결해야 합니다.
>   - `Events > Music > General > Music_Region` 더블 클릭

## 9. 🧪 테스트 및 주의사항

- **Play 모드** 실행 후, 음악이 마디마다 나무가 커지면 성공 🎵
- 게임 오브젝트의 스케일 변화 정도는 RhythmActions 스크립트 내에서 조절 가능
- 더 많은 오브젝트에 추가해 실험해도 동일한 방식으로 동작

> ⚠️ Wwise Adventure Game 주의점
>
> - 음악 시스템이 **2부분으로 구성되어 있음**
> - 따라서 `AK_MusicSyncBar` 콜백이 **두 번씩 호출될 수 있음**
> - RhythmActions 스크립트에서 이 중복 호출을 처리하고 있음
