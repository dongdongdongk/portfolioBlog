# HTTP 요청에 대한 Get 및 Post

## **Get 요청**

```jsx
Get 요청을 정보를 가져올 때 쓴다

데이터는 쿼리 문자열에 포함되며, URL에서 데이터를 확인하고 Get 요청을 북마크할 수 있다.

URL의 최대 길이는 일반적으로 2,048자로 제한되며, 이는 Get 요청과 함께 보낼 수 있는 데이터의 한계를 의미한다.

데이터를 보내려면 HTML 폼을 사용하고, 폼의 method 속성을 Get으로 설정한다.

Get 요청은 주로 정보를 검색하거나 조회할 때 사용되며, 백엔드를 변경하지 않는다.

Get 요청은 데이터를 URL 쿼리 문자열로 보내기 때문에, 검색, 분류, 정렬 등에 사용된다.
```

## **Post 요청**

```jsx
Post 요청은 정보를 업로드하거나 전송하는 데 사용된다.

데이터는 일반적으로 쿼리 문자열이 아닌 요청의 본문(Body) 에 포함된다.

Post 요청은 중요한 데이터를 보낼 때 사용되며, 데이터를 URL의 쿼리 문자열에 포함시키지 않는다.

URL의 길이 제한이 없으므로 더 많은 데이터를 보낼 수 있으며, JSON 형식으로도 보낼 수 있다.

HTML 폼에서 method 속성을 Post로 설정하여 데이터를 보낼 수 있다.

Post 요청은 백엔드에서 생성, 편집 또는 업데이트와 같은 동작에 영향을 줄 수 있다.

Post 요청은 주로 계정 등록, 댓글 쓰기, 새로운 사진 또는 글 게시 등에 사용된다.
```

## **Undefined req.body 이슈**

```jsx
Post 요청을 받았을 때, req.body를 출력해보면 'undefined'가 나타난다.

이는 Express에서 기본적으로 req.body가 정의되어 있지 않기 때문이다.

req.body를 사용하려면 **express.json()** 또는 **express.urlencoded()**와 같은 body analysis 미들웨어를 사용해야 한다.
```

# REST

```jsx
REST는 주로 웹 서비스 및 API(Application Programming Interface)의 설계에 사용되며, 다른 시스템 간의 통신을 가능하게 한다
```

## **Stateless ( 무상태 통신 )**

```jsx
REST에서 클라이언트에서 서버로의 각 요청은 그 자체로 완전한 정보를 갖고 있어서

서버는 클라이언트의 이전 상태를 기억하지 않는다. 다시 말해,

서버는 클라이언트가 이전에 무엇을 요청했는지 또는 어떤 상태에 있었는지에 대해 알지 못하고, 각각의 새로운 요청을 독립적으로 처리한다

예: 클라이언트가 리소스에 대한 정보를 검색하려면 해당 요청에 필요한 모든 세부 정보가 포함되며, 서버는 요청된 데이터로 응답
```

## **리소스**

```jsx
리소스는 REST에서 주요 추상화로 ( 웹 서비스에서는 글, 이미지, 사용자 정보) 시스템의 엔터티나 개념을 나타낸다.

리소스는 URI(Uniform Resource Identifier)로 식별될 수 있다.

예: 블로깅 시스템에서는 기사, 댓글 및 작성자가 리소스가 될 수 있으며 다음과 같이 식별될 수 있다
/articles
/articles/123
/authors/456
```

## **HTTP 메서드**

```jsx
RESTful 서비스는 리소스에 대한 작업을 수행하기 위해 표준 HTTP 메서드(GET, POST, PUT, DELETE 등)를 사용한다.

GET /articles: 기사 목록을 검색합니다.
POST /articles: 새로운 기사를 작성합니다.
PUT /articles/123: ID가 123인 기사를 업데이트합니다.
DELETE /articles/123: ID가 123인 기사를 삭제합니다.
```

## 리소스의 다양한 형식

```jsx
리소스는 다양한 형식을 가질 수 있다(예: JSON, XML, HTML).

클라이언트와 서버는 리소스의 형식을 교환함으로써 통신한다.

예: 클라이언트가 JSON 형식으로 리소스를 요청할 수 있으며(Accept: application/json), 서버는 JSON 형식으로 데이터를 응답한다.
```

## **routes.js:**

```jsx
const data = require('./data')

module.exports = (app) => {
  // Read All
  app.get('/users', (req, res) => {
    res.json(data)
  })

  // Read One
  app.get('/users/:id', (req, res) => {
    const userId = parseInt(req.params.id)
    const user = data.find((u) => u.id === userId)

    if (user) {
      res.json(user)
    } else {
      res.status(404).send('User not found')
    }
  })

  // Create
  app.post('/users', (req, res) => {
    const newUser = req.body
    newUser.id = data.length + 1
    data.push(newUser)
    res.status(201).json(newUser)
  })

  // Update
  app.put('/users/:id', (req, res) => {
    const userId = parseInt(req.params.id)
    const updatedUser = req.body
    const index = data.findIndex((u) => u.id === userId)

    if (index !== -1) {
      data[index] = { ...data[index], ...updatedUser }
      res.json(data[index])
    } else {
      res.status(404).send('User not found')
    }
  })

  // Delete
  app.delete('/users/:id', (req, res) => {
    const userId = parseInt(req.params.id)
    const index = data.findIndex((u) => u.id === userId)

    if (index !== -1) {
      const deletedUser = data.splice(index, 1)
      res.json(deletedUser[0])
    } else {
      res.status(404).send('User not found')
    }
  })
}
```

import { useState, useEffect } from 'react'
import { useParams } from 'react-router-dom'
import axios from 'axios'
const Profile = () => {
  const params = useParams()
  const [profile, setProfile] = useState(null)

  useEffect(() => {
    const fetchProfile = async () => {
      try {
        const response = await axios.get(`http://localhost:4000/profile/${params.username}`)
        setProfile(response.data)
      } catch (error) {
        console.error('프로필 정보를 불러오는 데 실패했습니다.', error)
        setProfile(null)
      }
    }

    fetchProfile()

  return (
    <div>
      <h1>사용자 프로필</h1>
      {profile ? (
        <div>
          <h2>{profile.username}</h2>
          <p>{profile.comment}</p>
        </div>
      ) : (
        <p>존재하지 않는 프로필입니다.</p>
      )}
    </div>
  )
}

## 댓글 업데이트

```jsx
put 과 patch 가 있는데

put 은 전체 내용을 업데이트 하는 기능이고 ( 모두 다 수정된다 )

patch 는 부분적인 내용을 수정하는 기능이다

( post 의 경우에는 모든 내용 id 까지 다 들어간다 )

HTTP PATCH 메서드는(patch 에만 있다)

업데이트에 필요한 데이터를 페이로드(body)에 담아 전송한다. req.body.comment 를 보면 폼에서 보낸(새로 작성한) comment 를 받아와서

newCommentText 에 넣는것이다
```

```jsx
// 업데이트
app.patch('/profile/:id', (req, res) => {
  const { id } = req.params // url 에서 id 를 가져온 뒤
  const newCommentText = req.body.comment // req.body.comment 에 담긴 페이로드 가져오기
  const foundComment = comments.find((c) => c.id === id) // id 와 비교해서 같은 id 객체를 찾아와서 저장
  foundComment.comment = newCommentText // 찾아온 객체에서 comment 부분 newCommentText 로수정
  return res.send('UpdateSuccess')
})
```

    const comment = e.target.comment.value
    await axios.patch(`http://localhost:4000/profile/${params.id}`, { username, comment })
    // 추가가 성공하면 페이지를 리디렉션
    navigate('/')
  }
  // 인풋 값이 변경될 때 호출되는 함수
  const handleInputChange = (e) => {
    const { name, value } = e.target
    setProfile((prevProfile) => ({ ...prevProfile, [name]: value }))
  }
  useEffect(() => {
    const fetchProfile = async () => {
      try {
        const response = await axios.get(`http://localhost:4000/profile/${params.id}`)
        setProfile(response.data)
        console.log(response.data)
      } catch (error) {
        console.error('프로필 정보를 불러오는 데 실패했습니다.', error)
        setProfile(null)
      }
    }

    fetchProfile()
  }, [params.id])

  if (!profile) {
    return <p>Loading...</p>
  }
  return (
    <div>
      <h1>UpdateComment</h1>
      <Form onSubmit={onSubmitHandler}>
        <Form.Group className="mb-3" controlId="exampleForm.ControlInput1">
          <Form.Label>사용자 이름 </Form.Label>
          <Form.Control
            name="username"
            type="text"
            placeholder="사용자 이름"
            value={profile.username}
            onChange={handleInputChange}
          />
        </Form.Group>
        <Form.Group className="mb-3" controlId="exampleForm.ControlTextarea1">
          <Form.Label>댓글 내용</Form.Label>
          <Form.Control
            as="textarea"
            rows={3}
            name="comment"
            value={profile.comment}
            onChange={handleInputChange}
          />
        </Form.Group>
        <input type="submit" value="추가" />
      </Form>
      <Link to="/">홈으로</Link>
    </div>
  )
}
export default CommentUpdate
