# { 핵심 컴포넌트 & 컴포넌트 스타일링 살펴보기 }

## App.js 파일 구성

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381491/notion-blog/_/React_Native/React_Native_2024_/_2_React_Native_/Untitled.png)

```jsx
임포트(import)

	Expo 관련 패키지와 React Native 패키지에서 컴포넌트를 임포트합니다.

	View, Text, StyleSheet 객체 등을 React Native에서 불러옵니다.

함수 컴포넌트

	React 함수 컴포넌트를 사용합니다.

	이 강의에서는 함수 컴포넌트와 React 훅만 사용하고 클래스 컴포넌트는 사용하지 않습니다.

JSX 코드와 핵심 컴포넌트

	Text와 View는 JSX 코드에서 사용되는 React Native의 내장 컴포넌트입니다.

	React Native는 HTML 요소를 지원하지 않으며, 네이티브 기기에 맞는 컴포넌트로 변환합니다.
```

## React Native 컴포넌트

```jsx
핵심 컴포넌트

	React Native는 다양한 내장 컴포넌트를 제공합니다: Button, Image, Text, View, TextInput 등.

	이 핵심 컴포넌트를 조합해 사용자 인터페이스를 구축합니다.

공식 문서 참고

	React Native 공식 웹사이트의 Components 탭에서 다양한 가이드를 참고할 수 있습니다.

	제공되는 컴포넌트 리스트는 많지 않지만 핵심 컴포넌트를 이용해 다양한 UI를 만들 수 있습니다.
```

## 스타일링

```jsx
스타일 적용

	React Native에서는 CSS를 사용하지 않고 JavaScript에서 스타일링을 작성합니다.

	인라인 스타일(Inline Styles) 또는 StyleSheet 객체를 사용합니다.

CSS와의 차이점

	React Native는 전체 CSS 프로퍼티를 지원하지 않지만, 중요한 CSS 프로퍼티는 대부분 지원합니다.

	JavaScript 프로퍼티를 이용해 스타일을 설정합니다.
```

## App 컴포넌트

```jsx
App 컴포넌트의 역할

	App.js 파일 내의 App 컴포넌트는 루트 컴포넌트로써 모든 UI 요소와 컴포넌트가 이 아래에 위치합니다.

	Expo가 자동으로 App 컴포넌트를 루트 컴포넌트로 렌더링합니다.

UI 구조

	App 컴포넌트 내에서 다양한 커스텀 컴포넌트를 조합해 사용자 인터페이스를 구축합니다.

	StyleSheet 객체를 통해 스타일을 설정하고 컴포넌트에 적용합니다.
```

## 텍스트와 뷰 컴포넌트 이해하기

```jsx
Text 컴포넌트의 역할

	텍스트를 화면에 표시하는 컴포넌트

	React Native에서는 텍스트를 반드시 Text 컴포넌트로 감싸야 함

	하지 않을 시 오류 메시지: "텍스트 문자열은 Text 컴포넌트 안에서 렌더링 되어야 한다"

View 컴포넌트의 역할

	다른 컴포넌트를 담고 배치하는 컴포넌트

	텍스트를 직접 담을 수 없고, Text 컴포넌트를 사용해야 함

	웹의 div와 비슷 ( 겹쳐서 만드는것도 가능 )
```

## View와 Text의 차이점

```jsx
View

	다른 컴포넌트를 담는 컨테이너 역할

	복수의 자식 컴포넌트를 포함 가능

	스타일링 및 배치에 사용

Text

	텍스트를 표시하는 역할

	반드시 텍스트는 Text 컴포넌트로 감싸야 함
```

## React Native와 웹 개발의 차이점

```jsx
웹 개발

	div, section, article 등 다양한 컨테이너 사용 가능

	div 내에 텍스트를 직접 포함 가능

React Native

	View는 유일한 컨테이너 컴포넌트

	텍스트는 반드시 Text 컴포넌트로 감싸야 함
```

## 다른 코어 컴포넌트

```jsx
주요 코어 컴포넌트

	Image: 이미지 표시

	ScrollView: 스크롤 가능한 영역

	TextInput: 사용자 입력 텍스트

	Button: 클릭 가능한 버튼
```

```jsx
Button 컴포넌트를 import하여 사용

```

## 결론

```jsx
React Native의 Text와 View 컴포넌트는 각각 명확한 역할이 있음

Text 컴포넌트는 텍스트 표시, View 컴포넌트는 배치와 스타일링
```

## 📂 폴더 구조

```bash
MyApp/
 ├── App.js
 ├── package.json
 └── node_modules
```

## 🧠 개념

- `App.js`가 앱의 시작점
- 모든 화면, 네비게이션을 직접 설정
- React Navigation을 직접 설치해서 사용

---

## ✏️ 기본 예제

```jsx
// App.js

import React from 'react'
import { View, Text } from 'react-native'

export default function App() {
  return (
    <View>
      <Text>Hello World</Text>
    </View>
  )
}
```

👉 앱 실행하면 이 화면 하나만 나옴.

---

## 📌 여러 화면 만들려면?

직접 네비게이션 설정해야 함:

```jsx
import { NavigationContainer } from '@react-navigation/native'
import { createNativeStackNavigator } from '@react-navigation/native-stack'

const Stack = createNativeStackNavigator()

function HomeScreen() {
  return <Text>Home</Text>
}

function DetailScreen() {
  return <Text>Detail</Text>
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Detail" component={DetailScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  )
}
```

👉 전부 App.js 안에서 설정

# 🏠 첫 화면 만들기

```tsx
// app/index.tsx

import { View, Text } from 'react-native'

export default function Home() {
  return (
    <View>
      <Text>Hello World</Text>
    </View>
  )
}
```

👉 이게 자동으로 홈 화면이 됨.

---

# 📄 두 번째 화면 만들기

```tsx
// app/detail.tsx

import { View, Text } from 'react-native'

export default function Detail() {
  return (
    <View>
      <Text>Detail Screen</Text>
    </View>
  )
}
```

👉 파일만 만들면 자동으로 화면 추가됨.

# 🔀 네비게이션은 어디서 하냐?

👉 NavigationContainer 필요 없음

# { React Native 앱 스타일링하기 }

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381489/notion-blog/_/React_Native/React_Native_2024_/_2_React_Native_/Untitled_2.png)

## 스타일링 방법 개요

```jsx
인라인 스타일(Inline Style)

	스타일 객체를 직접 컴포넌트에 전달.

	간단한 스타일링에 적합하지만 재사용성 떨어짐.

StyleSheet 객체

	별도의 객체로 스타일을 정의하고 이를 컴포넌트에 적용.

	코드의 가독성 및 재사용성 높임.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381489/notion-blog/_/React_Native/React_Native_2024_/_2_React_Native_/Untitled_3.png)

## 인라인 스타일 예제

```jsx
스타일 프로퍼티 예시

	margin: 바깥쪽 여백. 숫자로 픽셀 단위 설정.

	borderWidth: 테두리 너비. 숫자로 픽셀 단위 설정.

	borderColor: 테두리 색상. 문자열로 색상 지정.

	padding: 안쪽 여백. 숫자로 픽셀 단위 설정.
```

## CSS와의 차이점

```jsx
차이점

	React Native는 CSS의 모든 기능을 지원하지 않음.

	CSS와 유사하지만 다른 프로퍼티 이름 사용.

	border 프로퍼티는 지원하지 않음.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381491/notion-blog/_/React_Native/React_Native_2024_/_2_React_Native_/Untitled_4.png)

```jsx
import { StatusBar } from 'expo-status-bar'
import { StyleSheet, Text, View, Button } from 'react-native'

export default function App() {
  return (
    <View style={styles.container}>
      <View>
        <Text style={styles.dummyText}>Another Text</Text>
        <Text style={styles.dummyText}>Hello World</Text>
        <Button title="TapMe" />
      </View>
      <StatusBar style="auto" />
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
  dummyText: {
    margin: 16,
    borderWidth: 6,
    borderColor: 'blue',
    padding: 16,
  },
})
```

## StyleSheet 객체 사용

```jsx
StyleSheet 객체 생성

import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  dummyText: {
    margin: 16,
    borderWidth: 2,
    borderColor: 'red',
    padding: 16,
  },
});
```

## StyleSheet 적용

```jsx
<Text style={styles.dummyText}>
  Hello World!
</Text>
<Text style={styles.dummyText}>
  Another piece of text!
</Text>
```

```jsx
StyleSheet 객체로 스타일을 정의하고 재사용 가능.

JSX 코드와 스타일 코드의 명확한 분리.
```

## 결론

```jsx
스타일링은 React Native에서 중요한 부분.

인라인 스타일과 StyleSheet 객체를 통해 스타일 적용 가능.

StyleSheet 객체를 사용하면 가독성과 재사용성 높아짐.
```
