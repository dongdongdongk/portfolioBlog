# **DNS (Domain Name System)** 개념

```jsx
DNS는 도메인 이름을 IP 주소로 변환해 주는 시스템입니다.

우리가 웹사이트에 접속할 때 도메인 이름(예: www.example.com)을 입력하면,

실제로는 해당 도메인의 IP 주소로 접속하는 것인데, 이때 DNS 서버가 도메인 이름을 IP 주소로 변환해 줍니다.

예를 들어, 61.101.247.200이라는 DNS 서버가 도메인 이름을 IP 주소로 변환해 주는 역할을 할 것입니다.
```

# resolv.conf 파일

```jsx
/etc/resolv.conf 파일은 리눅스 시스템에서 사용하는 DNS 서버를 설정하는 파일입니다.

이 파일에 DNS 서버 IP 주소를 추가하면, 해당 서버가 도메인 이름을 해석하는 데 사용됩니다.
```

```jsx
nameserver 61.101.247.200
```

```jsx
이 코드를 resolv.conf에 추가하면 시스템에서 DNS 요청을 할 때 61.101.247.200을 사용하여 도메인 이름을 해석하게 됩니다.
```

# nameserver 설정의 의미

```jsx
만약 당신이 www.google.com이라는 웹사이트에 가고 싶다면,

리눅스 시스템은 그 주소의 IP가 무엇인지 알아야 합니다.

그런데 당신의 컴퓨터는 그걸 직접 알지 못하죠. 그래서 DNS 서버에게 물어보는 것입니다.
```

# 과정 정리

```jsx
1. 웹 브라우저에 www.google.com을 입력함.

2. 리눅스 시스템이 /etc/resolv.conf에 설정된 DNS 서버(예: 61.101.247.200)에 물어봄.

3. DNS 서버가 www.google.com의 IP 주소를 알려줌 (예: 142.250.72.196).

4. 리눅스 시스템은 이 IP 주소를 통해 구글 웹사이트에 접속함.
```

# `/etc/hosts`와 `/etc/resolv.conf` 의 차이

## `/etc/hosts`

```jsx
/etc/hosts 파일은 내 컴퓨터만 사용하는 개인적인 전화번호부라고 생각하면 됩니다.

이 파일에 도메인 이름과 IP 주소를 직접 설정해 두면,

내 컴퓨터는 DNS 서버를 거치지 않고도 해당 도메인 이름을 IP 주소로 바로 연결할 수 있습니다

127.0.0.1       localhost
172.17.123.66   myserver.local

이 경우, 내 컴퓨터는 "myserver.local"이라는 도메인 이름을 IP 주소 172.17.123.66으로 자동 연결합니다.

DNS 서버에 물어볼 필요 없이 내 컴퓨터 안에 있는 작은 전화번호부를 바로 사용하는 거죠.
```

## `/etc/resolv.conf`

```jsx
/etc/resolv.conf 파일은 내 컴퓨터가 외부의 DNS 서버에 접근하도록 설정하는 파일입니다.

인터넷 상에서 수많은 도메인 이름을 사용하려면,

DNS 서버의 도움을 받아야 하는데, 이 파일은 그 DNS 서버를 어디에 있는지 알려주는 역할을 합니다.

nameserver 61.101.247.200

이 설정은 도메인 이름을 해석할 때 이 DNS 서버(61.101.247.200)에 물어보도록 하는 것입니다.

내 컴퓨터가 인터넷에 있는 다양한 도메인(예: www.google.com)을 IP 주소로 바꿔야 할 때 이 DNS 서버를 거칩니다.
```

## 우선순위

```jsx
컴퓨터는 먼저 /etc/hosts 파일을 확인합니다. 만약 hosts 파일에서 도메인 이름이 정의되어 있으면,

바로 그 IP 주소로 연결합니다. 만약 hosts에 설정이 없다면,

그때는 /etc/resolv.conf에서 설정한 DNS 서버에 요청을 보내 도메인 이름을 IP로 변환합니다.
```

# 공용 DNS 서버

```jsx
구글 공용 DNS: 8.8.8.8 (안정적이고 빠른 편입니다)

클라우드플레어 DNS: 1.1.1.1 (개인정보 보호에 강점이 있습니다)

기본 ISP(인터넷 서비스 제공자) DNS: 보통은 인터넷 회사에서 자동으로 제공하는 DNS를 사용합니다.

nameserver 8.8.8.8
nameserver 8.8.4.4
```

# nslookup 명령어로 DNS 확인

```jsx
DNS 설정이 정상적으로 동작하는지 테스트하기 위해 nslookup 명령어를 사용할 수 있습니다.

nslookup www.google.com

이 명령어를 실행하면, 설정한 nameserver로부터 IP 주소를 받는지 확인할 수 있습니다.
```

# systemctl restart network 를 사용한 네트워크 재시작

```jsx
모든 설정을 완료한 뒤

systemctl restart network

를 사용해서 네트워크를 재시작 해줘야 반영된다
```
