# { 포탑을 마우스 방향으로 회전시키기 }

## 🎯 목표

**포탑(터렛)이 마우스 커서를 향해 자동으로 회전!**

```
마우스 여기 → 포탑 이쪽으로 회전
마우스 저기 → 포탑 저쪽으로 회전
부드럽게 천천히!
```

---

## 🧮 수학 원리 (쉽게!)

### 문제: 포탑을 어떻게 회전시키나?

**우리가 가진 것:**

```
1. 포탑 위치 (TM - Turret Mesh)
2. 마우스 위치 (IP - Impact Point)
```

**필요한 것:**

```
포탑 → 마우스를 가리키는 벡터
```

---

### 벡터 수학 (간단 버전!)

**두 점 사이의 방향 벡터 구하기:**

```
공식: 방향 = 목표점 - 시작점

우리의 경우:
방향 벡터 = ImpactPoint - TurretPosition
```

**그림으로 이해하기:**

```
TM (포탑)
  •─────────────────────> 이 화살표가 필요!
                        •
                       IP (마우스)

화살표 = IP - TM
```

---

### 회전 구하기

**벡터 → 회전각으로 변환:**

```cpp
FVector 방향벡터;
FRotator 회전각 = 방향벡터.Rotation();
```

**시각화:**

```
방향 벡터:
    →

회전각 (Yaw):
북쪽 기준으로 45도
```

## 💻 코드 구현

### 왜 BasePawn에 만드나?

```
BasePawn (부모 클래스)
├─ Tank (플레이어)
│  └─ 마우스 커서 향해 회전
└─ Enemy (적)
   └─ 플레이어 향해 회전

→ 둘 다 포탑 회전 필요!
→ 부모 클래스에 공통 함수 만들기
```

---

### 📄 BasePawn.h

```cpp
// 포탑 회전 함수 선언
void RotateTurret(FVector LookAtTarget);
```

**파라미터:**

```
LookAtTarget:
- Tank의 경우 → ImpactPoint (마우스 위치)
- Enemy의 경우 → Tank 위치 (다음에 구현)
```

---

### 📄 BasePawn.cpp - RotateTurret 함수

```cpp
void ABasePawn::RotateTurret(FVector LookAtTarget)
{
    // 1. 방향 벡터 계산
    FVector VectorToTarget = LookAtTarget - TurretMesh->GetComponentLocation();

    // 2. 회전각 구하기
    FRotator LookAtRotation = FRotator(0.f, VectorToTarget.Rotation().Yaw, 0.f);

    // 3. 부드러운 보간
    FRotator InterpolatedRotation = FMath::RInterpTo(
        TurretMesh->GetComponentRotation(),  // 현재 회전
        LookAtRotation,                       // 목표 회전
        GetWorld()->GetDeltaSeconds(),        // 시간
        25.f                                  // 속도
    );

    // 4. 회전 적용
    TurretMesh->SetWorldRotation(InterpolatedRotation);
}
```

---

## 🔍 코드 단계별 분해

### 1단계: 방향 벡터 계산

```cpp
FVector VectorToTarget = LookAtTarget - TurretMesh->GetComponentLocation();
```

**무슨 일이 일어나나?**

```
LookAtTarget (마우스 위치):
예: (1000, 500, 0)

TurretMesh->GetComponentLocation() (포탑 위치):
예: (200, 100, 0)

VectorToTarget (방향):
= (1000, 500, 0) - (200, 100, 0)
= (800, 400, 0)
→ "오른쪽 앞으로 800, 400만큼"
```

**GetComponentLocation()이란?**

```
컴포넌트의 월드 공간 위치를 반환

중요: 로컬 위치 아님!
→ 레벨 전체를 기준으로 한 절대 좌표
```

---

### 2단계: 회전각 구하기

```cpp
FRotator LookAtRotation = FRotator(0.f, VectorToTarget.Rotation().Yaw, 0.f);
```

**단계별 분해:**

```cpp
VectorToTarget.Rotation()
↓
이 벡터가 가리키는 방향의 회전각 반환
(Pitch, Yaw, Roll 모두 포함)

.Yaw
↓
그 중에서 Yaw(좌우 회전)만 추출

FRotator(0.f, Yaw, 0.f)
↓
새 회전 생성:
- Pitch = 0 (위아래 회전 없음)
- Yaw = 계산된 값 (좌우만!)
- Roll = 0 (기울기 없음)
```

**왜 Yaw만?**

```
포탑 회전:
        ↑
        | (포탑)
        |
    ────┼────

좌우로만 돌면 됨 (Yaw)
위아래(Pitch), 기울기(Roll) 필요 없음!
```

---

### 3단계: 부드러운 보간 (Interpolation)

```cpp
FRotator InterpolatedRotation = FMath::RInterpTo(
    TurretMesh->GetComponentRotation(),  // 1. 현재 회전
    LookAtRotation,                       // 2. 목표 회전
    GetWorld()->GetDeltaSeconds(),        // 3. DeltaTime
    25.f                                  // 4. 보간 속도
);
```

---

### 보간(Interpolation)이란?

**즉시 회전 (보간 없음) ❌:**

```
현재: 0도
목표: 90도

다음 프레임: 90도 (뚝!)
→ 끊기는 느낌, 부자연스러움
```

**부드러운 회전 (보간 있음) ✅:**

```
현재: 0도
목표: 90도

프레임1: 10도
프레임2: 20도
프레임3: 30도
...
프레임9: 90도 도달

→ 자연스럽게 천천히 회전
```

**비유:**

```
보간 없음 = 순간이동
보간 있음 = 걸어가기
```

---

### RInterpTo 파라미터 설명

```cpp
FMath::RInterpTo(현재, 목표, 시간, 속도)
```

**1. 현재 회전 (Current):**

```cpp
TurretMesh->GetComponentRotation()
→ 지금 포탑이 향하고 있는 각도
```

**2. 목표 회전 (Target):**

```cpp
LookAtRotation
→ 포탑이 향해야 할 각도 (마우스 방향)
```

**3. DeltaTime:**

```cpp
GetWorld()->GetDeltaSeconds()
→ 지난 프레임부터 지금까지 시간
→ 프레임 속도 보정
```

**4. 보간 속도 (InterpSpeed):**

```cpp
25.f
→ 얼마나 빠르게 목표에 도달할까?

높을수록: 빠르게 도달 (10, 25, 50)
낮을수록: 천천히 도달 (1, 5, 10)
```

---

### 보간 속도 이해하기

**속도별 비교:**

```
속도 = 50 (빠름):
0도 → 90도 목표
1초 후: ~90도 도달

속도 = 25 (적당):
0도 → 90도 목표
2초 후: ~90도 도달

속도 = 10 (느림):
0도 → 90도 목표
5초 후: ~90도 도달
```

**우리는 25 사용** → 적당히 빠르고 부드러움!

---

### 4단계: 회전 적용

```cpp
TurretMesh->SetWorldRotation(InterpolatedRotation);
```

**함수 이름 분해:**

```
Set → "설정해"
World → "월드 공간에서"
Rotation → "회전을"

→ "월드 공간에서 이 회전으로 설정해!"
```

**왜 World Rotation?**

```
Local Rotation (로컬):
- 부모 기준
- 탱크 회전하면 포탑도 같이 회전

World Rotation (월드):
- 레벨 기준
- 탱크 회전해도 포탑은 마우스 향함 ✅
```

## 🎮 Tank에서 사용하기

### 📄 Tank.cpp - Tick 함수

```cpp
void ATank::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    // PlayerController 얻기
    if (APlayerController* PlayerController = Cast<APlayerController>(GetController()))
    {
        // 마우스 커서 위치 찾기
        FHitResult HitResult;
        PlayerController->GetHitResultUnderCursor(ECC_Visibility, false, HitResult);

        // 포탑을 그 위치로 회전 (여기가 핵심!)
        RotateTurret(HitResult.ImpactPoint);
    }
}
```

**흐름:**

```
매 프레임마다:
1. 마우스 커서 위치 찾기 (ImpactPoint)
2. RotateTurret 호출
   → BasePawn의 함수 사용 가능! (상속)
3. 포탑이 부드럽게 회전
```

## 🎬 전체 과정 애니메이션

### 마우스를 오른쪽으로 움직인다면:

```
프레임 1:
마우스: (1000, 0, 0)
포탑: 0도 → 목표: 45도
보간: 0도 + (45-0) × 속도 × 시간 = 5도
결과: 5도로 회전

프레임 2:
포탑: 5도 → 목표: 45도
보간: 5도 + (45-5) × 속도 × 시간 = 10도
결과: 10도로 회전

프레임 3:
포탑: 10도 → 목표: 45도
...

프레임 N:
포탑: 거의 45도
→ 마우스를 계속 추적!
```


```
World Rotation:
- 절대 좌표 기준
- 탱크 돌아도 포탑은 마우스 향함 ✅
```

# { 적 타워(Tower) 클래스 만들기 }

## 🎯 목표

**플레이어를 공격할 적 타워 만들기!**

```
Tower (적)
- BasePawn 상속
- 탱크를 향해 포탑 회전
- 나중에 발사 기능 추가
```

---

## 🏗️ 클래스 구조 이해하기

### 상속 구조

```
BasePawn (부모)
├─ Tank (플레이어)
│  ├─ 카메라
│  ├─ 스프링 암
│  └─ 입력 시스템
│
└─ Tower (적) ← 지금 만들 것!
   ├─ 탱크 추적
   └─ 자동 발사 (나중에)
```

**왜 BasePawn을 상속?**

```
BasePawn에 이미 있는 것:
✅ CapsuleComp (충돌)
✅ BaseMesh (바닥)
✅ TurretMesh (포탑)
✅ RotateTurret() (회전 함수)

→ 코드 재사용! 다시 안 만들어도 됨!
```

## 💻 C++ 클래스 생성

### 1단계: 새 클래스 만들기

**언리얼 에디터에서:**

```

```

### 2단계: Tower.h (헤더 파일)

```cpp
#pragma once
#include "CoreMinimal.h"
#include "BasePawn.h"

    GENERATED_BODY()

public:
    // 매 프레임마다 호출
```

```cpp
#include "Tower.h"

    Super::Tick(DeltaTime);
```

```cpp
void ATower::Tick(float DeltaTime)
```

```
if로 확인:
```

## 💻 코드 구현

### 📄 BattleBlasterGameMode.h

```cpp
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/GameModeBase.h"
#include "Tank.h"
#include "BattleBlasterGameMode.generated.h"

UCLASS()
class BATTLEBLASTER_API ABattleBlasterGameMode : public AGameModeBase
{
    GENERATED_BODY()

protected:
    virtual void BeginPlay() override;

private:
    // 플레이어 탱크 참조
    ATank* Tank;

    // 타워 개수
    int32 TowerCount;
};
```

---

### 📄 BattleBlasterGameMode.cpp

```cpp
#include "BattleBlasterGameMode.h"
#include "Kismet/GameplayStatics.h"
#include "Tower.h"

void ABattleBlasterGameMode::BeginPlay()
{
    Super::BeginPlay();

    // 1. 모든 타워 찾기
    TArray<AActor*> Towers;
    UGameplayStatics::GetAllActorsOfClass(GetWorld(), ATower::StaticClass(), Towers);

    // 2. 타워 개수 저장
    TowerCount = Towers.Num();
    UE_LOG(LogTemp, Display, TEXT("Number of towers: %d"), TowerCount);

    // 3. 플레이어 찾기
    APawn* PlayerPawn = UGameplayStatics::GetPlayerPawn(GetWorld(), 0);

    if (PlayerPawn)
    {
        // 4. Tank로 캐스팅
        Tank = Cast<ATank>(PlayerPawn);

        if (!Tank)
        {
            UE_LOG(LogTemp, Error, TEXT("GameMode: Failed to find the tank actor"));
        }
    }
}
```

## 🔍 코드 완전 분해

### 1단계: 모든 타워 찾기

```cpp
TArray<AActor*> Towers;
UGameplayStatics::GetAllActorsOfClass(GetWorld(), ATower::StaticClass(), Towers);

```

---

### TArray란?

**언리얼의 동적 배열**

```cpp
TArray<AActor*> Towers;
  ↑     ↑        ↑
  |     |        변수 이름
  |     담을 타입
  배열 클래스
```

**일반 배열 vs TArray:**

```cpp
// C++ 일반 배열 (크기 고정)
AActor* Towers[4];  // 정확히 4개만

// TArray (크기 자동)
TArray<AActor*> Towers;  // 몇 개든 OK!
```

**비유:**

```
일반 배열 = 4인용 식탁 (딱 4명)
TArray = 뷔페 테이블 (몇 명이든 OK)
```

---

### GetAllActorsOfClass 함수

```cpp
UGameplayStatics::GetAllActorsOfClass(
    GetWorld(),           // 1. 어느 월드?
    ATower::StaticClass(), // 2. 무슨 클래스?
    Towers                // 3. 결과 저장할 곳
);
```

**파라미터 설명:**

**1. GetWorld():**

```cpp
현재 게임 월드를 반환

월드 = 레벨의 모든 것을 담는 컨테이너
```

**2. ATower::StaticClass():**

```cpp
ATower 클래스 자체를 나타내는 객체

StaticClass() = "이 클래스의 정보"
```

**StaticClass() 이해하기:**

```cpp
ATower::StaticClass()
  ↑        ↑
  클래스   클래스 정보 얻기

의미: "ATower라는 클래스 자체"
```

**왜 필요한가?**

```
함수가 어떤 클래스를 찾아야 할지 알려주려면
"클래스 자체"를 전달해야 함

비유:
"사과 찾아줘" (X) - 뭔지 모름
"사과 클래스 찾아줘" (O) - 명확!
```

**3. Towers (Out Parameter):**

```cpp
결과를 담을 배열

Out Parameter:
- 함수가 값을 채워줌
- 빈 배열로 전달
- 함수 후 가득 참
```

---

### 전체 과정 시각화

```
게임 시작
    ↓
GetAllActorsOfClass 호출
    ↓
월드를 뒤져서 ATower 타입 찾기
    ↓
   🏰 Tower1 발견!
   🏰 Tower2 발견!
   🏰 Tower3 발견!
   🏰 Tower4 발견!
    ↓
Towers 배열에 4개 저장
    ↓
Towers = [Tower1, Tower2, Tower3, Tower4]
```

```
    {
```

### 왜 캐스팅이 필요한가?

**타입 변환:**

```cpp
APawn* PlayerPawn;
↓ (캐스팅)
ATank* Tank;
```

**이유:**

```
GetPlayerPawn은 APawn* 반환
→ Pawn의 기능만 사용 가능

우리는 Tank* 필요
→ Tank의 특별한 기능 사용 가능
```

**비유:**

```
"동물"로 반환 받음 (Pawn)
→ "개"인지 확인 (Cast)
→ "짖기" 가능 (Tank 전용 기능)
```

---

### 캐스팅 검증

```cpp
if (PlayerPawn)  // 1차 검증
{
    Tank = Cast<ATank>(PlayerPawn);

    if (!Tank)  // 2차 검증
    {
        // 에러!
    }
}
```

**1차 검증 (PlayerPawn):**

```
PlayerPawn이 nullptr인가?
→ 플레이어가 아예 없음
```

**2차 검증 (!Tank):**

```
캐스팅이 실패했나?
→ Pawn은 있지만 Tank가 아님
```

**두 번 체크하는 이유:**

```
1차: 존재 여부
2차: 타입 정확성

안전한 프로그래밍!
```

## 📊 Out Parameter 이해하기

### Out Parameter란?

**일반 파라미터 vs Out 파라미터:**

```cpp
// 일반 파라미터 (입력)
void Function(int Value)
{
    // Value를 받아서 사용
}

// Out 파라미터 (출력)
void Function(int& OutValue)
{
    OutValue = 10;  // 값을 채워줌
}
```

**GetAllActorsOfClass의 경우:**

```cpp
TArray<AActor*> Towers;  // 빈 배열

GetAllActorsOfClass(..., Towers);
// 함수가 Towers를 채움

// 이제 Towers에 액터들이 가득!
```

**비유:**

```
빈 바구니(Out Parameter)
    ↓
함수에게 건네기
    ↓
함수가 사과 담아줌
    ↓
가득 찬 바구니 돌려받기
```

# { 배열 반복문 상세 설명 }

## 📚 배열 인덱싱 기초

### 배열이란?

```cpp
TArray<AActor*> Towers;  // 타워들을 담는 "서랍장"
```

- 여러 개의 값을 순서대로 저장하는 자료구조
- 각 칸에 번호가 매겨져 있음 (인덱스)

### 인덱스 사용법

```cpp
Towers[0]  // 첫 번째 타워
Towers[1]  // 두 번째 타워
Towers[2]  // 세 번째 타워
Towers[3]  // 네 번째 타워
```

**중요:**

- 인덱스는 **0부터 시작**
- 4개 요소 → 인덱스는 0, 1, 2, 3
- 마지막 인덱스 = 개수 - 1

---

## 🔄 While 반복문 구조

```cpp
int32 LoopIndex = 0;              // ① 시작값 설정
while (LoopIndex < TowerCount)    // ② 조건 검사
{
    // ③ 실행할 코드
    AActor* TowerActor = Towers[LoopIndex];

    LoopIndex++;                  // ④ 증가 (필수!)
}
```

### 각 부분 설명

**① 시작값**: 어디서부터 시작할지

- `LoopIndex = 0` → 첫 번째 요소부터

**② 조건**: 언제까지 반복할지

- `LoopIndex < TowerCount` → 타워 개수만큼만
- 4개면 0, 1, 2, 3 까지만 (4는 제외)

**③ 실행 코드**: 각 반복마다 할 일

- `Towers[LoopIndex]`로 타워 하나씩 꺼내기

**④ 증가**: 다음으로 넘어가기

- `LoopIndex++` 없으면 **무한 반복!**

---

## 🎬 실행 과정 시뮬레이션

타워가 3개 있다고 가정: Tower_1, Tower_2, Tower_3

```
【시작 전】
TowerCount = 3
LoopIndex = 0

┌─────────────────────────────────┐
│  1번째 반복                      │
├─────────────────────────────────┤
│ 조건: 0 < 3 ? → 참 (반복 진행)  │
│ 실행: Towers[0] → Tower_1 꺼냄   │
│      → Tower_1에게 Tank 알려줌  │
│ 증가: LoopIndex = 1              │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│  2번째 반복                      │
├─────────────────────────────────┤
│ 조건: 1 < 3 ? → 참 (반복 진행)  │
│ 실행: Towers[1] → Tower_2 꺼냄   │
│      → Tower_2에게 Tank 알려줌  │
│ 증가: LoopIndex = 2              │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│  3번째 반복                      │
├─────────────────────────────────┤
│ 조건: 2 < 3 ? → 참 (반복 진행)  │
│ 실행: Towers[2] → Tower_3 꺼냄   │
│      → Tower_3에게 Tank 알려줌  │
│ 증가: LoopIndex = 3              │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│  종료                            │
├─────────────────────────────────┤
│ 조건: 3 < 3 ? → 거짓 (종료)     │
└─────────────────────────────────┘
```

## 🛡️ 안전 검사 (Null Check)

```cpp
if (TowerActor)  // TowerActor가 실제로 존재하는가?
{
    ATower* Tower = Cast<ATower>(TowerActor);  // 변환
    if (Tower && Tank)  // 둘 다 유효한가?
    {
        Tower->Tank = Tank;  // Tower 객체 안에 있는 Tank 변수에 접근
    }
}
```

**왜 필요한가?**

- 배열 요소가 `nullptr`(빈 값)일 수 있음
- 검사 없이 사용하면 → **크래시!**
- 2단계 검사: ① 배우 확인 → ② 타워로 변환 확인

---

## 🔑 Cast 개념

```cpp
AActor* TowerActor = Towers[LoopIndex];     // 일반 액터
ATower* Tower = Cast<ATower>(TowerActor);   // 타워로 변환
```

**비유:**

- `AActor`는 "사람" (일반적인 개념)
- `ATower`는 "군인" (구체적인 개념)
- Cast는 "이 사람이 군인인지 확인하고 변환"

**결과:**

- 성공 → `Tower`에 값 들어감
- 실패 → `Tower = nullptr` (빈 값)

## ⚠️ 흔한 실수

```cpp
// ❌ 잘못된 예
while (LoopIndex < 10)  // 타워가 3개인데 10번 반복
{
    Towers[LoopIndex];  // 3번째 이후는 범위 초과!
}

// ❌ 잘못된 예
while (LoopIndex < TowerCount)
{
    // LoopIndex++가 없음 → 무한 반복!
}

// ✅ 올바른 예
while (LoopIndex < TowerCount)
{
    Towers[LoopIndex];
    LoopIndex++;  // 필수!
}
```

## 📊 정리

| 항목        | 값/설명        |
| ----------- | -------------- |
| 배열 크기   | `Towers.Num()` |
| 인덱스 범위 | 0 ~ (크기-1)   |
| 반복 조건   | `< TowerCount` |
| 증가        | `LoopIndex++`  |
| 안전 검사   | `if (객체)`    |

**최종 목적:** 모든 타워가 플레이어 탱크 위치를 알아서, 탱크를 향해 회전/공격할 수 있게 만들기!

# `Tower` 별표(\*) 설명

## 🎯 핵심 개념

```cpp
UE_LOG(LogTemp, Display, TEXT("%s setting the tank variable"), *Tower->GetActorNameOrLabel());
                                                                 ↑ 이 별표!
```

**간단 답변:** `GetActorNameOrLabel()`이 반환하는 게 **FString**인데, `TEXT("%s")`는 **C++ 문자열**을 원해서!

---

## 📦 타입 변환 과정

```cpp
Tower->GetActorNameOrLabel()
// 반환: FString (언리얼 문자열)
// 예: FString("BP_Tower_1")

*Tower->GetActorNameOrLabel()
// 변환: const TCHAR* (C++ 문자열 포인터)
// 예: "BP_Tower_1" (UE_LOG가 이해할 수 있는 형태)
```

---

## 🔄 비유로 이해하기

**상황:** 한국어를 영어로 번역

```
GetActorNameOrLabel() → "타워1" (한국어 = FString)

*를 붙이면 → "Tower1" (영어 = TCHAR*)

UE_LOG는 영어만 알아들음 → *가 필요!
```

---

## ⚠️ 별표 없으면?

```cpp
// ❌ 컴파일 에러!
UE_LOG(LogTemp, Display, TEXT("%s"), Tower->GetActorNameOrLabel());
// 에러: FString을 TCHAR*로 변환할 수 없음

// ✅ 정상 작동
UE_LOG(LogTemp, Display, TEXT("%s"), *Tower->GetActorNameOrLabel());
// *가 FString을 TCHAR*로 변환
```

---

## 📌 규칙

```cpp
// FString을 UE_LOG에서 %s로 출력할 때
FString Name = Tower->GetActorNameOrLabel();

UE_LOG(LogTemp, Display, TEXT("%s"), *Name);  // * 필수!
                                      ↑
                              FString → TCHAR* 변환
```

**정리:** `*`는 "언리얼 문자열(FString)을 C++ 문자열(TCHAR\*)로 변환하는 연산자"

# { 적 타워가 플레이어 탱크를 추적 }

## 📋 전체 코드 구조

```cpp
#include "Tower.h"

void ATower::BeginPlay()
{
    Super::BeginPlay();
}

void ATower::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    if (Tank)
    {
        float DistanceToTank = FVector::Dist(GetActorLocation(), Tank->GetActorLocation());

        if (DistanceToTank <= FireRange)
        {
            RotateTurret(Tank->GetActorLocation());
        }
    }
}
```

---

## 🎯 코드가 하는 일

- \*"적 타워가 플레이어 탱크를 추적하는 기능"\*\*을 구현한 코드입니다.

---

## 📖 함수별 설명

### 1. **BeginPlay() - 게임 시작할 때 한 번만 실행**

```cpp
void ATower::BeginPlay()
{
    Super::BeginPlay();  // 부모 클래스의 BeginPlay 먼저 실행
}
```

- 게임이 시작될 때 딱 한 번 호출됩니다
- 현재는 특별한 코드가 없고, 부모 클래스의 기능만 실행합니다

---

### 2. **Tick() - 매 프레임마다 실행되는 핵심 함수**

```cpp
void ATower::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);  // 부모 클래스의 Tick 먼저 실행

    // 여기서부터 우리가 작성한 코드
}
```

- **매 프레임**(초당 60번 정도)마다 계속 실행됩니다
- 플레이어가 움직이는 걸 계속 추적하려면 매 프레임 체크해야 합니다

---

## 🔍 핵심 로직 단계별 분석

### **1단계: 탱크가 존재하는지 확인**

```cpp
if (Tank)
```

- `Tank`는 플레이어 탱크를 가리키는 포인터입니다
- 탱크가 없거나 파괴되었으면 이 안의 코드는 실행되지 않습니다
- **안전장치** 역할입니다

---

### **2단계: 거리 계산**

```cpp
float DistanceToTank = FVector::Dist(GetActorLocation(), Tank->GetActorLocation());
```

**나눠서 이해하기:**

- `GetActorLocation()` → 타워 자신의 위치
- `Tank->GetActorLocation()` → 플레이어 탱크의 위치
- `FVector::Dist()` → 두 위치 사이의 거리를 계산해주는 함수

**결과:** `DistanceToTank` 변수에 타워와 탱크 사이의 거리가 저장됩니다

---

### **3단계: 사거리 안에 있는지 확인**

```cpp
if (DistanceToTank <= FireRange)
```

- `FireRange`는 타워의 사격 범위입니다 (예: 700cm)
- 계산한 거리가 사격 범위보다 **작거나 같으면** 조건이 참입니다

**예시:**

- 거리가 500cm이고 FireRange가 700cm → 조건 참 ✅
- 거리가 900cm이고 FireRange가 700cm → 조건 거짓 ❌

---

### **4단계: 포탑 회전**

```cpp
RotateTurret(Tank->GetActorLocation());
```

- 탱크가 사거리 안에 있으면 이 코드가 실행됩니다
- `RotateTurret()` 함수에 탱크의 위치를 전달합니다
- 포탑이 탱크 방향으로 회전합니다

---

## 🎮 실제 동작 흐름

```
매 프레임마다:
┌─────────────────────────────┐
│ 1. 탱크가 존재하나요?        │
│    ↓ 예                      │
│ 2. 탱크와의 거리 계산        │
│    ↓                         │
│ 3. 사거리 안에 있나요?       │
│    ↓ 예                      │
│ 4. 포탑을 탱크 쪽으로 회전   │
└─────────────────────────────┘
```

**시나리오 예시:**

1. **플레이어가 멀리 있을 때 (예: 1000cm)**
   - 거리 계산: 1000cm
   - 1000 > 700 (FireRange) → 회전 안 함
2. **플레이어가 가까이 올 때 (예: 500cm)**
   - 거리 계산: 500cm
   - 500 ≤ 700 (FireRange) → 포탑 회전 시작!
3. **플레이어가 계속 움직일 때**
   - 매 프레임마다 새로운 위치 계산
   - 계속 추적하며 회전

## 💡 주요 개념 정리

### **Tick 함수를 사용하는 이유**

- 플레이어는 계속 움직입니다
- 한 번만 체크하면 안 되고, **계속 추적**해야 합니다
- 그래서 매 프레임 실행되는 Tick 함수를 사용합니다

### **거리 체크를 하는 이유**

- 타워가 맵 반대편의 플레이어도 추적하면 이상합니다
- 특정 범위 안에서만 작동하게 해서 **현실감**을 줍니다
- 게임플레이 **난이도 조절**에도 사용됩니다

### **포인터 체크(if Tank)를 하는 이유**

- 게임 중 탱크가 파괴될 수 있습니다
- Tank가 null이면 프로그램이 **크래시**됩니다
- 안전하게 코드를 실행하기 위한 필수 체크입니다
