```java
문법 : 자식타입 변수  = (자식타입)부모타입;

       Child child = (Child)parent;  //강제 타입 변환

// 부모 타입을 자식 타입으로 강제 변환
// 조건 : 자식 타입이 부모 타입으로 자동 타입 변환한 후 다시 반대로 변환할 떄 사용
// Parent parent = new Child(); 앞에서 배운 자동타입 변환을 사용해야함
```

```java
//부모 클래스
class parent {
	String field1;
	void method1() {...}
	void method2() {...}
}

//자식 클래스
class Child extends parent { // parent 상속
	String feild2;
	void method3() {...}
}
```

```java
class ChildExample {
	public static void main(String[] args) {
	Parent parent = new Child();
	parent.field1 = "xxx";    // 부모 클래스에 존재하는 필드기 때문에 사용가능
	parent.method1();         // 사용 가능
	parent.method2();         // 사용 가능
	parent.field2 = "yyy";    // 자식 클래스에 있지만 부모 클래스에 없기 때문에 사용 불가능
	parent.method3();         // 사용 불가

	// 이때 field2 와 method3 를 사용하고 싶으면

	Child child = (Child)parent;  //강제 타입 변화를 사용하여 사용가능
	child.field2 = "yyy";         // 부모 타입을 자식 타입으로 변환
	child.method3();              // 위의 Parent parent = new Child(); 덕분에 조건도 부합
	}
}
```

- 어떤 객체가 어느 클래스의 인스턴스(객체) 인지 확인
- 메소느 내 강제 타입 변환이 필요한 경우 타입을 확인하지 않고 시도하면 ClassCastException 이 발생할 수 있다.
- instanceof 연산자를 통해 확인 후 안전하게 실행

```java
문법 : boolean result = 좌항(객체) instanceof 우향(타입)

                           parent instanceof Child  // parent 매개변수가 참조하는 객체가
                                                    // Child 인지 조사후 faulse, ture
```

Parent parent = new Parent();
Child child = (Child) parent;  //강제 타입 변환 불가

public void method(Parent parent) { //Parent 객체에는 paernt 객체와 모든 자식 객체가 매개변수로 사용 가능
	if(parent instanceof Child) { //위에 대입되는 parent 객체가 참조하는 객체가Child 인지 조사
		Child child = (Child) parent; //사실이라면 사용 가능하니 instanceof 연산자 실행

```java
**클래스 타입 변환** : 다른 클래스 타입으로 객체를 대입 자동타입 변환과 강제타입 변환 2가지가 있음
```

```java
**자동 타입 변환** : 자식 객체를 부모 타입 변수에 대입할 때 자동으로 타입 변환됨

부모타입 변수 = 자식타입;

Anilmal animal = new Cat();

// 부모와 자식 관계여아지 타입 변환이 가능하다.
```

```java
**강제 타입 변환** : 부모 타입 객체를 다시 자식 타입에 대입할 때 강제타입 변환이 필요하다.

자식타입 변수 = (자식타입)부모타입;  // 부모 타입을 자식 타입으로 변환

Child child = (Child)parent;

 // 자식 타입이 부모 타입으로 자동 타입 변환후 다시 반대로 변환할 때 사용
 // Parent parent = new Child(); 앞의 자동 타입 변환후 사용가능
```

```java
**instanceof 연산자** : 객체가 어떤 타입인지 조사할때 instanceof 연산자를 사용한다.

 boolean result = 좌항(객체) instanceof 우향(타입)

                      parent instanceof Child      // parent 가 Child 객체를 참조하는지
```
