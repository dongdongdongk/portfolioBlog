# 모듈 불러오기 & 사용하기

```jsx
Node.js에서 다른 파일에서 코드를 불러오고 재사용하는 방법에 대해 설명한다

이러한 방법을 사용하여 Node.js에서 모듈을 정의하고 다른 파일에서 재사용할 수 있다.

각 파일은 모듈 시스템을 통해 필요한 부분만을 불러와서 사용할 수 있으며, 코드의 재사용성과 구조화를 증진시킨다
```

## **모듈 만들기**

```jsx
새로운 파일을 만들어서 코드를 작성 예를 들어, math.js 파일을 만들고 여기에 함수와 변수를 정의

( module.exports로 객체를 보냄 )
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381412/notion-blog/_/The_Web_Developer_2022/node_js/_NPM/Untitled.png)

```jsx
const add = (x, y) => x + y

const PI = 3.14159

const square = (x) => x * x

// 이 방법도 있다
// module.exports.add = add;
// module.exports.PI = PI;
// module.exports.square = square;

module.exports = {
  add: add,
  PI: PI,
  square: square,
} // 객체기 때문에 {} 로 내보내기
```

## **모듈 불러오기**

```jsx
다른 파일에서 math.js 모듈을 불러와서 사용할 수 있다
```

```jsx

// math 모듈의 함수와 변수 사용
```

# NPM(노드 패키지 매니저)

```jsx
NPM(노드 패키지 매니저)은 Node.js 패키지를 관리하고 공유하는 데 사용되는 도구

NPM은 두 가지 주요 측면에서 정의될 수 있다.
```

## **라이브러리로서의 NPM**

```jsx
NPM은 무수한 패키지로 이루어진 라이브러리 이다.

이 패키지들은 다른 개발자들이 만든 도구 및 코드로 구성되어 있다.

대부분의 경우, 이 패키지들은 무료로 제공된다.

패키지는 React, Express와 같은 주요 라이브러리부터

무지개 색 텍스트를 터미널에 출력하는 등 다양한 작업을 수행하는 도구까지 다양하다.
```

## **명령줄 도구로서의 NPM**

```jsx
NPM은 명령줄 도구로도 정의된다. 이 도구를 사용하여 패키지를 쉽게 설치하고 관리할 수 있다.

npm 명령을 사용하여 패키지를 설치하고, 버전을 관리하며, 프로젝트에 종속성을 추가할 수 있다.

NPM을 통해 패키지를 손쉽게 설치하거나 업데이트할 수 있다.

* 명령줄(CLI)은 텍스트 기반의 사용자 인터페이스를 의미
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381410/notion-blog/_/The_Web_Developer_2022/node_js/_NPM/Untitled_7.png)

## **로컬 설치의 이유**

```jsx

그 부분이 처음 설치시 나왔던  **package.json** 어쩌고 하는 오류이다
```

# Package.json의 중요성

## Package.json 이란?

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381406/notion-blog/_/The_Web_Developer_2022/node_js/_NPM/Untitled_31.png)

```jsx
package.json은 노드 앱에 필수적인 메타 데이터를 담고 있는 파일이다.

프로젝트에 대한 정보(이름, 버전, 설명, 라이센스 등)과 종속성(dependencies)이 기록된다.

이 파일은 프로젝트의 루트 디렉토리에 위치하며, NPM (Node Package Manager)을 통해 프로젝트의 의존성을 관리하고 프로젝트 설정을 기술한다

* Spring의 POM 과 유사한 목적을 가지고 있다. 둘 다 프로젝트의 의존성을 정의하고 프로젝트를 빌드하고 관리하는 데 사용
```

## **디펜던시 관리**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381406/notion-blog/_/The_Web_Developer_2022/node_js/_NPM/Untitled_32.png)

# 한 프로젝트에 대한 모든 종속 요소 설치하기

```jsx
package.json 파일은 프로젝트의 메타데이터와 의존성을 관리하는데 중요한 역할을 한다.

프로젝트 정보, 의존성 목록, 버전 등이 기록된다.
```

## **의존성 관리**

```jsx
프로젝트에 필요한 의존성은 package.json의 dependencies 섹션에 명시된다.

**npm install** 명령어를 통해 package.json에 기록된 의존성을 다운로드한다.
```

## **소스 코드 공유**

```jsx
노드 앱을 공유할 때, 특히 GitHub이나 Git을 사용하는 경우, node_modules는 포함시키지 않는다.

( 이는 용량이 상당히 높고 그럼 무거워진다 )

소스 코드만을 공유하고, 의존성은 package.json을 통해 관리한다.
```
