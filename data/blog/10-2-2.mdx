# { 프로젝트의 색 구성표를 선택하는 방법 }

## 1. 색상 팔레트 선택 방법 개요

```tsx
회사 가이드라인:

	실제 프로젝트에서는 회사나 고객사가 설정한 색상 가이드라인을 사용하는 것이 일반적입니다.

팔레트 선택:

	가이드라인이 없는 경우, 인터넷에서 색상 팔레트를 선택할 수 있습니다. 다양한 자료가 있지만, Coolors 같은 인기 있는 웹사이트를 소개합니다.
```

## 2. Coolors 웹사이트 사용 방법

```tsx
Coolors 소개:

	Coolors는 색상 팔레트를 빠르게 생성할 수 있는 인기 있는 웹사이트입니다.

색상 팔레트 생성:

	웹사이트에서 스페이스바를 눌러 여러 색상 팔레트를 생성할 수 있습니다. 원하는 색상을 고르고, 헥스 코드나 쉐이드를 확인할 수 있습니다.

미리 만들어진 팔레트:

	Coolors에서 제공하는 미리 만들어진 색상 팔레트도 선택할 수 있습니다. 특정 색상(예: 갈색)을 검색해 관련 팔레트를 탐색할 수 있습니다.

색상 팔레트 내보내기:

	원하는 색상 팔레트를 모두 선택한 후, "Export Color Palette" 옵션을 사용해 SVG 파일로 내보낼 수 있습니다.

	이 파일을 Figma로 가져와 색상을 적용할 수 있습니다.
```

## 3. Figma 플러그인을 통한 색상 팔레트 생성

```tsx
Figma 커뮤니티 플러그인:

	Figma 커뮤니티에는 색상 팔레트를 생성하는 데 사용할 수 있는 여러 플러그인이 있습니다.

AI Color Palette Generator:

	이 플러그인은 Unsplash 이미지에서 색상 팔레트를 생성하거나 AI를 사용해 특정 색상의 다양한 변형 및 조합을 제안합니다.

	예를 들어, 노란색이나 빨간색 색상 팔레트를 쉽게 생성할 수 있습니다.

Image Palette 플러그인:

	이 플러그인은 이미지에서 색상 팔레트를 추출합니다. 특정 이미지를 선택하면 그 이미지에서 자동으로 색상 팔레트를 생성해줍니다.
```


## 1. 색상 팔레트 복사 및 배치

```tsx
색상 팔레트 복사:

	Shift 키를 누른 상태에서 색상 팔레트의 각 색상을 하나씩 선택한 후, Command + C를 눌러 복사합니다.

색상 팔레트 붙여넣기:

	복사한 색상 팔레트를 작업 중인 페이지에 붙여넣습니다.
```

## 2. 색상 정렬 및 디자인 시스템에 추가

```tsx
색상 정렬:

	색상 팔레트를 어두운 색에서 밝은 색 순으로 정렬합니다.

색상 추가:

	정렬한 색상 팔레트의 각 색상을 선택합니다.

	작은 더하기 아이콘을 클릭해 디자인 시스템에 색상을 추가합니다.

	각 색상에 이름을 지정합니다. 예를 들어, 진한 녹색 1, 진한 녹색 2, 밝은 녹색 1, 밝은 녹색 2, 밝은 녹색 3 등으로 이름을 설정합니다.
```

## 3. 색상 팔레트 삭제

```tsx
색상 팔레트 삭제:

	색상 팔레트를 선택한 후, 삭제 키를 눌러 페이지에서 제거합니다.

디자인 시스템 확인:

	색상 팔레트는 디자인 시스템에 추가되어 있기 때문에, 페이지에서 삭제해도 Color Style 내부에서 해당 색상이 남아 있습니다.
```

## 4. 웹 페이지에 색상 적용

```tsx
그리드 비활성화:

	색상을 적용하기 전에 그리드를 끕니다.

배경색 변경:

	배경색을 검정색에서 "진한 녹색 1"로 변경합니다.

텍스트 색상 변경:

	텍스트 색상을 배경에 맞춰 "진한 녹색 1"로 변경합니다.

목록 및 스트로크 색상 변경:

	목록의 스트로크 색상을 검정색에서 "밝은 녹색"으로 변경합니다.

	목록 텍스트의 색상도 "진한 녹색"으로 변경합니다.

	아이콘 색상도 "진한 녹색 1"로 변경합니다.
```
