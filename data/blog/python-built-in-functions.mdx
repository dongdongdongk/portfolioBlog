```python
내장 함수는 파이썬에 이미 내장되어 있는 함수들을 의미한다.

이러한 내장 함수들은 파이썬을 사용하는데 있어서 매우 유용하며, 다양한 작업을 보다 쉽게 수행할 수 있도록 도와준다
```

# **print() 함수**:

```python
화면에 출력하는 함수
```

```python
print("안녕하세요, 파이썬!")
```

# **input() 함수**:

```python
사용자로부터 입력을 받는 함수 ( 이것만 써도 입력이 된다! )
```

```python
name = input("이름을 입력하세요: ")
print("안녕하세요,", name, "님!")
```

# **len() 함수**:

```python
퀀스(문자열, 리스트, 튜플 등)의 길이를 반환하는 함수
```

```python
my_list = [1, 2, 3, 4, 5]
print("리스트의 길이:", len(my_list))
```

# **range() 함수**:

```python
연속된 숫자들의 시퀀스를 생성하는 함수
```

```python
for i in range(1, 6):
    print(i)
```

# **sum() 함수**:

```python
퀀스의 합을 반환하는 함수
```

```python
numbers = [1, 2, 3, 4, 5]
total = sum(numbers)
print("리스트의 합:", total)
```

# **max() 함수**:

```python
시퀀스의 최댓값을 반환하는 함수
```

```python
numbers = [1, 2, 3, 4, 5]
max_value = max(numbers)
print("최댓값:", max_value)
```

# **min() 함수**:

```python
퀀스의 최솟값을 반환하는 함수
```

```python
numbers = [1, 2, 3, 4, 5]
min_value = min(numbers)
print("최솟값:", min_value)
```
