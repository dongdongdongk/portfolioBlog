### 1. STS 3 다운

[Spring Tool Suite 3 · spring-attic/toolsuite-distribution Wiki](https://github.com/spring-projects/toolsuite-distribution/wiki/Spring-Tool-Suite-3)

### 2. 압축 해제 후 사용

```jsx
- 해제시 파일명이 길어서 오류 발생 할 수 있음
- 반디집 같은 프로그램으로 해제(알집 X)
```

### 3. 실행 후 환경 설정

```jsx
1. windows > preferences > general > workspace > Default Encoding 을 UTF-8로 변경

2. windows > preferences > general > web browser > External 선택, Chrome 선택

3. windows > preferences > web > html > Enconding > UTF-8 변경

4. windows > preferences > web > css > Enconding > UTF-8 변경

5. windows > preferences > web > jsp > Enconding > UTF-8 변경
```

### 4. Tomcat 설치

```jsx
1. Tomcat 9.0 다운
https://tomcat.apache.org/download-90.cgi

2. 압축 해제

3. 환경변수 설정
	a. 환경변수 편집
	b. 시스템 변수 > 새로만들기
	c. 변수 이름 : CATALINA_HOME
	d. 변수값    : 압축 푼 Tomcat 폴더 (bin 폴더 이전까지) 경로입력

	e. 시스템 변수 > path > 편집
	f. 새로만들기 : %CATALINA_HOME%\bin 입력
```

### 5. STS Tomcat 연동

```jsx
1. windows > preferences > server > RunTime Env...

2. Add > Apatch 폴더에서 Tomcat9.0 선택

3. Browser에서 Tomcat설치 폴더 찾기 (Bin폴더가 보이는 곳까지, ATALINA_HOME과 동일한 경로)
```

### 6. 프로젝트 생성

```jsx
1. FIle > new > Spring Legacy 선택
2. 프로젝트명 입력
3. Template > Spring MVC Project 선택
4. Base 패키지명 입력 : ex) com.iu.start

- 패키지명의 마지막 이름은 Root 이름(Context Name)으로 만들어짐
- Tomcat에서 실행시 같은 Context Name이 있으면 중복 오류
```
