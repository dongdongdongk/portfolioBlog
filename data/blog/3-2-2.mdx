## 📊 Sequence 노드 (정리 도구)

### 왜 필요한가?

```
Before (지저분):
Tick ──▶── 노드1 ──▶── 노드2 ──▶── 노드3
        (한 줄로 길게...)

After (깔끔):
Tick ──▶── [Sequence]
             ├─ 0 ──▶── 노드1
             ├─ 1 ──▶── 노드2
             └─ 2 ──▶── 노드3
```

### 사용법

```
우클릭 → "sequence" 검색
  ↓
[Sequence]
  ├─ 입력: 실행 핀
  └─ 출력: 0, 1, 2... (순서대로)
```

### 핀 추가/제거

```
"Add pin" 클릭
  └─ 새 출력 핀 추가

출력 핀 우클릭
  └─ "Remove execution pin"
      └─ 핀 제거
```

### 실행 순서

```
[Sequence]
  ├─ 0 실행 → 완료
  ├─ 1 실행 → 완료
  └─ 2 실행 → 완료
      ↓
순서대로, 하지만 즉시!
(같은 프레임 내)
```

# { Vector 크기(Magnitude) 계산하기 }

## 🎯 Vector 크기란?

```
Magnitude (크기) = 벡터의 길이
  ↓
화살표가 얼마나 긴가?
  ↓
숫자 하나로 표현!
```

---

## 📐 2D Vector 크기 계산

### 피타고라스 정리 활용

### 직각삼각형 형성

```
Vector V = (3, 4)
  ↓
직각삼각형 만들어짐:
  ├─ 다리 a = X성분 = 3
  ├─ 다리 b = Y성분 = 4
  └─ 빗변 c = Vector 길이 = ?
```

### 피타고라스 정리

```
c² = a² + b²
  ↓
c = √(a² + b²)
```

---

## 🔢 2D 크기 공식

### 일반 공식

```
Vector V = (x, y)
  ↓
|V| = √(x² + y²)
```

**표기법:** |V| = Vector V의 크기

### 계산 예제

```
V = (3, 4)
  ↓
|V| = √(3² + 4²)
    = √(9 + 16)
    = √25
    = 5 ✅
```

---

## 📊 3D Vector 크기 계산

### 단계적 접근

### 1단계: XY 평면 벡터

```
V = (x, y, z)
  ↓
먼저 Z를 무시:
V_xy = (x, y, 0)
  ↓
|V_xy| = √(x² + y²)
```

### 2단계: 3D로 확장

```
V와 V_xy로 새 직각삼각형:
  ├─ 다리 1 = |V_xy| = √(x² + y²)
  ├─ 다리 2 = Z성분 = z
  └─ 빗변 = |V| = ?
```

### 3단계: 최종 계산

```
|V|² = |V_xy|² + z²
     = (x² + y²) + z²
  ↓
|V| = √(x² + y² + z²) ✅
```

---

## 🎓 3D 크기 공식

### 완성된 공식

```
Vector V = (x, y, z)
  ↓
|V| = √(x² + y² + z²)
```

### 계산 예제

```
V = (2, 3, 6)
  ↓
|V| = √(2² + 3² + 6²)
    = √(4 + 9 + 36)
    = √49
    = 7 ✅
```

---

## 📏 거리 계산 활용

### 두 점 사이 거리

### 문제

```
캐릭터 위치: V₁ = (x₁, y₁)
적 위치: V₂ = (x₂, y₂)
  ↓
거리는? 🤔
```

### 해결 과정

### Step 1: 방향 벡터

```
V₁ → V₂ 벡터 계산:
  ↓
V₃ = V₂ - V₁
   = (x₂ - x₁, y₂ - y₁)
```

### Step 2: 크기 계산

```
거리 = |V₃|
     = √((x₂-x₁)² + (y₂-y₁)²)
```

---

## 💡 거리 공식 (Distance Formula)

### 2D 거리

```
점1: (x₁, y₁)
점2: (x₂, y₂)
  ↓
거리 = √((x₂-x₁)² + (y₂-y₁)²)
```

### 3D 거리

```
점1: (x₁, y₁, z₁)
점2: (x₂, y₂, z₂)
  ↓
거리 = √((x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²)
```

---

## 🎮 게임 개발 활용 예시

### 예제 1: 공격 범위 체크

```
플레이어: (0, 0, 0)
적: (3, 4, 0)
  ↓
방향 벡터: (3, 4, 0)
  ↓
거리 = √(3² + 4²)
     = 5
  ↓
공격 범위 10 > 거리 5
  └─ 공격 가능! ✅
```

### 예제 2: 시야 범위

```
NPC: (10, 10, 5)
플레이어: (15, 14, 5)
  ↓
방향: (5, 4, 0)
  ↓
거리 = √(25 + 16)
     = √41 ≈ 6.4
  ↓
시야 범위 8 > 거리 6.4
  └─ 발견됨! 👁️
```

### 예제 3: 충돌 감지

```
오브젝트 A: (0, 0, 0), 반지름 2
오브젝트 B: (3, 0, 0), 반지름 1
  ↓
거리 = 3
충돌 거리 = 2 + 1 = 3
  ↓
거리 = 충돌 거리
  └─ 딱 닿음! 🎯
```

```

2. 각 성분 제곱
   └─ x², y², z²

3. 제곱들 더하기
   └─ x² + y² + z²

4. 제곱근 구하기
   └─ √(x² + y² + z²)
```


### 3D

```
Vector: (x, y, z)
크기: |V| = √(x² + y² + z²)

```

## ⚠️ 중요 사항

### 항상 양수!

```

  ↓

```

```
  ↓
음수 답은 무시
```

## 📐 이론: 위치 간 Vector 구하기

### 위치를 Vector로 표현

```
점 A → 위치 벡터 V_A
  ├─ 꼬리: 원점 (0, 0, 0)
  └─ 머리: 점 A 위치
      ↓

```

### A → B Vector 구하기

### 2D 예제

```
점 A: (x_a, y_a)
점 B: (x_b, y_b)
  ↓
A → B 벡터는?
```

### 성분 계산

```
X성분: x_b - x_a
Y성분: y_b - y_a
  ↓
V_C = (x_b - x_a, y_b - y_a)
```

### 핵심 공식 🔑

```
시작점 → 목적지 벡터
```

## 🔢 다른 비교 연산자들

```

  └─ A > B (A가 B보다 큰가?)

== (Equal)
  └─ A == B (A와 B가 같은가?)

!= (Not Equal)
  └─ A ≠ B (A와 B가 다른가?)
```

### 입력 방법

```

> → Shift + 마침표
```

```
방향: 유지
  ↓
모든 방향에 대해 존재 가능!
```

### 예시

```
V1, V2, V3, V4
  ├─ 각자 다른 방향
  └─ 공통점: 모두 길이 1
      ↓
단위 벡터들!
```

---

## 📏 정규화(Normalization)란?

```
Normalization = 길이를 1로 만들기
  ↓
방향은 유지
크기만 1로!
```

### 왜 필요한가?

```
방향만 필요할 때
  ├─ 이동 방향
  ├─ 바라보는 방향
  └─ 발사 방향
      ↓
크기는 1로 고정!
```

---

## 🧮 정규화 공식

### 핵심 공식 🔑

```
정규화된 벡터 = 원래 벡터 / 크기
  ↓
V_normalized = V / |V|
  ↓
또는
V_normalized = V × (1 / |V|)
```

---

## 📐 2D 예제: V = (3, 4)

### 1단계: 크기 계산

```
V = (3, 4)
  ↓
|V| = √(3² + 4²)
    = √(9 + 16)
    = √25
    = 5
```

### 2단계: 정규화

```
V_n = V / |V|
    = (3, 4) / 5
    = (3/5, 4/5)
    = (0.6, 0.8)
```

### 3단계: 검증 (길이 = 1?)

```
|V_n| = √((3/5)² + (4/5)²)
      = √(9/25 + 16/25)
      = √(25/25)
      = √1
      = 1 ✅
```

---

## 🔢 계산 과정 상세

### 성분별 계산

```
원래: V = (3, 4)
크기: |V| = 5
  ↓
X성분: 3 × (1/5) = 3/5 = 0.6
Y성분: 4 × (1/5) = 4/5 = 0.8
  ↓
정규화: V_n = (0.6, 0.8)
```

### 비교

```
Before:
  방향: →
  길이: 5

After:
  방향: → (같음!)
  길이: 1 (변함!)
```

## 💡 정규화의 효과

### 크기 변화

```

  ↓

  ↓

```

### 방향 유지

```

  ↓ 크기만 조절

```

## 🎮 게임 활용 예제

### 시나리오: 적이 플레이어 추적

### 상황

```
플레이어: V_P (위치)
적: V_E (위치)
  ↓
적이 플레이어 향해 이동
속도: 초당 1 유닛
```

### 1단계: 방향 벡터

```
V_direction = V_P - V_E
  ↓
적 → 플레이어 방향
```

### 2단계: 정규화

```
V_normalized = V_direction / |V_direction|
  ↓
길이 1인 방향 벡터!
```

### 3단계: 이동

```
적의 새 위치 = V_E + V_normalized
  ↓
초당 정확히 1 유닛씩 이동! ✅
```

## 🔄 정규화 과정 정리

```
1. 원래 벡터: V = (x, y, z)

2. 크기 계산: |V| = √(x² + y² + z²)

3. 나누기: V_n = V / |V|
           = (x/|V|, y/|V|, z/|V|)

4. 결과: 길이 1, 방향 동일
```

## 📝 핵심 정리

### 용어

```
Unit Vector (단위 벡터)
  └─ 길이가 1인 벡터

Normalization (정규화)
  └─ 벡터를 Unit Vector로 만들기

Magnitude (크기)
  └─ 벡터의 길이
```

### 공식

```
정규화:
  V_normalized = V / |V|

크기:
  |V| = √(x² + y² + z²)

검증:
  |V_normalized| = 1
```

## ⚠️ 주의사항

### 0 벡터

```
V = (0, 0, 0)
  ↓
|V| = 0
  ↓
V / 0 = 불가능! ⚠️
  ↓
정규화 불가!
```

### 해결

```
정규화 전 체크:
if (|V| > 0) {
  V_normalized = V / |V|
} else {
  // 기본 방향 사용
}
```
