# 뷰티풀수프(beautifulsoup) 기초 사용법

# 같은 요소를 찾는 다양한 방법

```python
import requests
from bs4 import BeautifulSoup

url = "https://www.naver.com"

headers = {
    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

req = requests.get(url, headers=headers)

html = req.text

soup = BeautifulSoup(html, "html.parser")

print(soup.h1)
print("")

h1 = soup.find('h1')
print(h1)
print("")

h1 = soup.select_one('h1')
print(h1)
print("")

```

```python
이런 식으로 같은 요소도 다른 3가지 방식으로 가져올 수 있다

다이렉트하게

find 로

select 로
```

# 기본 문법

## 1. **태그, 클래스, 아이디로 요소 선택하기**:

```python
from bs4 import BeautifulSoup

# HTML 문서
html_doc = """
<html>
<head>
    <title>HTML 문서 예제</title>
</head>
<body>
    <div class="content">
        <h1 id="title">제목</h1>
        <p>첫 번째 문단</p>
        <p>두 번째 문단</p>
    </div>
</body>
</html>
"""

# BeautifulSoup 객체 생성
soup = BeautifulSoup(html_doc, 'html.parser')

# .find(): 특정 태그, 클래스, 아이디 등을 가진 첫 번째 요소 선택
first_paragraph = soup.find('p')
print(".find() 결과:", first_paragraph.text)

# .find_all(): 특정 태그, 클래스, 아이디 등을 가진 모든 요소 선택
all_paragraphs = soup.find_all('p')
print(".find_all() 결과:")
for p in all_paragraphs:
    print(p.text)

# .select(): CSS 선택자를 사용하여 요소 선택
title = soup.select('#title')
print(".select() 결과:", title[0].text)
```

### **`find()`**: HTML 문서에서 원하는 요소를 찾는 메서드로, 첫 번째로 일치하는 요소를 반환합니다

```python
result = soup.find('태그명', 속성='값')
```

### **`find_all()`**: HTML 문서에서 모든 일치하는 요소를 찾는 메서드로, 리스트 형태로 반환합니다

```python
results = soup.find_all('태그명', 속성='값')
```

### **`select()`**: CSS 선택자를 활용하여 요소를 찾는 메서드로, 모든 일치하는 요소를 리스트 형태로 반환합니다.

```python
results = soup.select('선택자')
```

### **`get_text()`**: 요소의 텍스트 내용을 반환합니다.

```python
text = element.get_text()
```

### **`get()`** 메서드: 요소의 속성 값을 가져옵니다.

```python
value = element.get('속성명')
```

### **`parent`**, **`children`**, **`next_sibling`**, **`previous_sibling`**

```python
속성을 사용하여 요소의 부모, 자식, 형제 요소에 접근할 수 있다.
```

### CSS 선택자에서 사용되는 문법도 지원

```python
CSS 선택자에서 사용되는 문법도 지원된다. 예를 들어, 클래스 이름이 'example' 인 요소를 찾는다면:

result = soup.find('태그명', class_='example')
```

### 속성의 존재를 확인하고 싶을 때는 **`has_attr()`**

```python
속성의 존재를 확인하고 싶을 때는 has_attr() 메서드를 사용

if element.has_attr('속성명'):
    # 속성이 존재하는 경우
```
