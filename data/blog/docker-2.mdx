# 1. Docker 설치

## 1. OS 확인

### Windows

```java
Docker는 Linux OS에서 돌아가는 프로그램
Windows 에서 Docker를 쓸려면 Linux 가상 머신이 필요함

Hyper-V WSL(Windows Subsystem for Linux 2)) 를 이용하여 설치
	a. Pro 이상 은 두가지 중 하나를 이용해 설치
		 - Hyper-V
		 - WSL2
	b. Home 은 한가지만 가능 (Hyper-v 없음)
		 - WSL2

```


### 3. WSL 설치 진행

```java

https://learn.microsoft.com/ko-kr/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package

4. x64 머신용 최신 WSL2 Linux 커널 업데이트 패키지 를 클릭 해서 설치

	 - wsl --set-default-version 2

6. Microsoft Store에서 Linux 다운

	 - 처음 실행시 root의 계정과 비번을 만들어서 입력
```

# 2. Docker 기본 사용

### 1. Image

```bash
Docker 원본 파일

1. Image 검색
	 a. Web의 DockerHub에서 원하는 이미지 검색
		  https://www.docker.com/products/docker-hub/
	 b. CMD에서 명령어로 이미지 검색
		  # Docker search 검색어
		  docker search mariadb

2. Image Down
	 #docker pull 이미지명:태그
	 docker pull mariadb

	 # 태그는 보통 버전을 명시
	 # 태그가 latest면 최신 버전임
	 # 태그를 생략하면 latest 임

3. Image List
	 # Down 받은 Image 목록 확인
	 docker images

4. Image Delete
	 # Image 삭제
	 docker rmi 이미지명 또는 ImageId
```

### 2. Container 생성 및 실행

```bash
Image를 Copy해서 Container가 만들어지고 실행
Container를 변경해도 Image는 영향 없음

1. Container 생성 및 실행
# docker run [option 들] [이미지명]
docker run -d -p HostPort:ContainerPort --name ContainerName ImageName
docker run -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root --name mydb3 mariadb

# -d                                : 백그라운드로 실행
# -p [Host port]:[Container port]   : port Foward
# --name [container 이름]           : 다른 컨테이너와 구분하는 이름(직접 작성)
# -e MYSQL_ROOT_PASSWORD=[비밀번호] : root 유저의 비밀번호 지정(직접 작성, DB용)
# ContainerName                     : Container 이름 지정, 사용자가 직접 정함
# ImageName                         : 다운받은 Image 명

2. Container 실행 중지
   docker stop container명 또는 id

3. 중지 된 Container 실행
	 docker start container명 또는 id

4. Container 삭제
	 docker rm container명 또는 id

5. 실행중인 Container 내부 접속
	 # docker exec -it [Container 이름 or Container ID] [실행할 shell]
	 docker exec -it db /bin/bash
```

### 3. Host 와 Container 폴더 공유

```bash
Container가 삭제 되면 내부의 모든 것이 삭제

기존의 내용은 유지하고 Container만 변경시에도 사용

Host pc의 폴더에 실제 내용을 저장하고 Container가 그 폴더를 참조 하는 형식

Container 생성시 -v(또는 --volume) 사용

# docker -v [Host 폴더 경로]:[Container 폴더 경로]
1. Host가 Linux 인경우
	docker run -v /app:/app -p 80:80  --name containerName imageName  /bin/sh

**2. Host가 Windows 인경우
	- 위의 명령어로 실행 가능 해야 하나 잘 안될 경우 실행**

	- Webserver Container 생성시
	docker run **-it** -p 80:80 -v C:\data:/app --name t3 ubuntu **/bin/sh**
	**-it 옵션을 주어야 정상 작동

	- DB Container 생성시
	docker run -p 3306:3306 -v c:\app\data:/var/lib/mysql -e MYSQL_ROOT_PASSWORD=root --name test1 mariadb**
```
