# 변수 & 상수 소개

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381252/notion-blog/_/JavaScript/JavaScript_/_2_/Untitled_3.png)

## 변수

```jsx
let userName = 'Max';

새로운 값 할당

userName = 'Manu';

1. 변수는 데이터를 보관하는 데이터 컨테이너라 할 수 있다.

2. 변수는 언제든 새로운 값을 재할당 받을 수 있다.

3. let 은 처음에 변수를 선언 할 때만 사용한다.(새로운 변수가 있다 라는 의미)
```

## 상수

```jsx
const totalUsers = 15;

1. 상수는 값이 고정된 데이터 컨테이너라 할 수 있다

2. 상수는 값이 변하면 오류를 일으킨다.

* 상수를 최대한 자주 사용하는게 좋다. (다른 개발자 에게 나의 의도를 정확하게 전달 가능하다.(다른 개발자에게 이 값은 프로그램 전체에 걸쳐 바뀌지 않는 값이란걸 바로 전달 가능)
```
