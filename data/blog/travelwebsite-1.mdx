## `:root`에 대한 설명

```jsx
:root는 HTML 문서의 최상위 요소를 의미합니다. 일반적으로 HTML 문서에서 html 요소와 동일하게 동작합니다.

CSS 변수를 전역적으로 정의할 때 :root를 사용하면, 이 변수들은 모든 곳에서 접근 가능합니다.

이렇게 하면 페이지 전체에 걸쳐 일관된 변수를 사용할 수 있습니다.
```

## CSS Custom Properties

```jsx
CSS 변수는 --로 시작하며, 변수 이름을 지정할 수 있습니다.

변수의 값을 불러올 때는 var() 함수로 가져옵니다.
```

```jsx
:root {
    --main-color: #3498db; /* 변수 선언 */
    --font-size: 16px;
}

h1 {
    color: var(--main-color); /* 변수를 불러와 적용 */
    font-size: var(--font-size);
}
```

```jsx
import { MdTravelExplore } from 'react-icons/md' // React Icons 라이브러리에서 여행 아이콘을 가져옴

// Navbar 컴포넌트 정의
export const Navbar = () => {
  // active 상태를 'navBar'로 초기화 (기본 네비게이션 바 상태)
  const [active, setActive] = useState('navBar')

  // 네비게이션 바를 활성화시키는 함수 (토글 시 실행)
  const showNav = () => {
    // 상태를 'navBar activeNavBar'로 변경 (메뉴가 열림)
    setActive('navBar activeNavBar')
  }

  // 네비게이션 바를 비활성화시키는 함수 (닫기 아이콘 클릭 시 실행)
  const removeNav = () => {
    // 상태를 다시 'navBar'로 변경 (메뉴가 닫힘)
    setActive('navBar')
  }

              Dot
            </h1>
          </a>
        </div>

        {/* 네비게이션 바 메뉴 */}
        <div className={active}>
          <ul className="navLists flex">
            {/* 네비게이션 메뉴 항목들 */}
            <li className="navItem">
              <a href="#" className="navLink">
                Home
              </a>
            </li>
            <li className="navItem">
              <a href="#" className="navLink">
                Products
              </a>
            </li>
            <li className="navItem">
              <a href="#" className="navLink">
                Resources
              </a>
            </li>
            <li className="navItem">
              <a href="#" className="navLink">
                Contact
              </a>
            </li>
            <li className="navItem">
              <a href="#" className="navLink">
                Blog
              </a>
            </li>

            {/* 로그인 및 회원가입 버튼 */}
            <div className="headerBtns flex">
              {/* 로그인 버튼 */}
              <button className="btn loginBtn">
                <a href="#">Login</a>
              </button>
              {/* 회원가입 버튼 */}
              <button className="btn">
                <a href="#">Sign up</a>
              </button>
            </div>
          </ul>

          {/* 네비게이션 바 닫기 아이콘 */}
          <div onClick={removeNav} className="closeNavbar">
            <AiFillCloseCircle className="icon" />
          </div>
        </div>

        {/* 네비게이션 바 토글 버튼 (작은 화면에서 메뉴 열기) */}
        <div onClick={showNav} className="toggleNavbar">
          <TbGridDots className="icon" />
        </div>
      </div>
    </section>
  )
}
```

```jsx
useState로 상태 관리:

		const [active, setActive] = useState('navBar'): 네비게이션 바의 상태를 관리하는 데 사용됩니다. 기본 상태는 'navBar'입니다.


		active 상태: 네비게이션 바가 열리고 닫힐 때 이 상태 값이 변경됩니다.

				기본적으로 'navBar' 상태를 유지하다가, 네비게이션 바를 열면 'navBar activeNavBar' 상태로 변경됩니다.

네비게이션 바를 여는 함수:

		const showNav = () => { setActive('navBar activeNavBar') }: 이 함수는 메뉴 토글 버튼을 클릭했을 때 실행되며,

		네비게이션 바가 열리도록 상태를 'navBar activeNavBar'로 변경합니다.

네비게이션 바를 닫는 함수:

		const removeNav = () => { setActive('navBar') }: 이 함수는 닫기 아이콘을 클릭했을 때 실행되며,

		네비게이션 바가 닫히도록 상태를 다시 'navBar'로 변경합니다.

네비게이션 바 섹션 (<section className='navBarSection'>):

		전체 네비게이션 바 영역을 감싸는 섹션입니다.

로고 섹션 (<div className="logoDiv">):

		로고와 아이콘이 표시되는 부분입니다. MdTravelExplore 아이콘과 "Dot" 텍스트로 구성된 로고가 있습니다.

네비게이션 메뉴 항목들:

		ul 태그 안에 여러 li 태그로 네비게이션 항목이 정의되어 있습니다.

		각 항목에는 a 태그로 링크가 걸려있습니다 (예: Home, Products, Resources 등).

로그인 및 회원가입 버튼:

		로그인 및 회원가입 버튼이 네비게이션 바 안에 정의되어 있습니다.

		각각의 버튼은 a 태그를 포함하고 있어 클릭하면 링크가 작동합니다.

네비게이션 닫기 버튼 (<AiFillCloseCircle />):

		닫기 버튼은 AiFillCloseCircle 아이콘을 사용합니다. 이 아이콘을 클릭하면 removeNav 함수가 호출되어 네비게이션 바가 닫힙니다.

네비게이션 토글 버튼 (<TbGridDots />):

		작은 화면에서 메뉴를 열기 위한 토글 버튼입니다.

		그리드 점 아이콘(TbGridDots)을 클릭하면 showNav 함수가 호출되어 네비게이션 바가 열립니다.
```

```jsx
position: absolute:

		.homeCard는 position: absolute 속성을 사용하고 있습니다.


		position: absolute는 부모 요소인 .secContainer 내에서 절대적인 위치를 설정할 수 있게 해줍니다.

		즉, .homeCard는 페이지 내에서 고정된 위치에 배치되지 않고, 부모 요소를 기준으로 자유롭게 배치됩니다.

bottom: -35%:

		.homeCard의 bottom: -35%는 부모 요소인 .secContainer의 아래쪽에서 35%만큼 위로 올려 배치합니다.


		이 값은 음수이므로, 원래 부모 요소의 경계 밖으로 내려가지만 그만큼 위로 올라가는 효과를 줍니다.


		이 설정 때문에 .homeCard가 부모 섹션의 하단을 넘어, 마치 다른 요소와 겹치는 것처럼 보이게 됩니다.

transform: translate(-50%):

		transform: translate(-50%)는 .homeCard를 수평으로 50% 왼쪽으로 이동시킵니다.


		이는 .homeCard가 부모 요소 안에서 정확히 가운데에 위치하도록 만듭니다. 기본적으로,

		absolute로 배치된 요소는 left: 50% 속성만으로 정확히 중앙에 오지 않습니다.


		그래서 translate(-50%)로 왼쪽으로 50% 이동시켜 중앙에 맞춥니다.

left: 50%:

		left: 50%는 .homeCard를 부모 요소의 왼쪽에서 50% 위치로 이동시킵니다.

		즉, 카드의 왼쪽 기준으로 부모 요소의 가운데에 위치시킵니다.
```

## 애니메이션 작동방식

### 아이콘의 애니메이션

```jsx
.icon {
    position: absolute;
    right: 10px;
    bottom: 10px;
    padding: .5rem;
    background: var(--PrimaryColor);
    font-size: 2.5rem;
    border-radius: 50%;
    color: var(--whiteColor);
    border: 1px solid transparent;
    transition: background 0.3s ease, color 0.3s ease, border 0.3s ease;

    &:hover {
        background: var(--blackColor); /* 배경색이 검은색으로 바뀜 */
        border: 1px solid var(--PrimaryColor); /* 테두리가 주 색상으로 바뀜 */
        color: var(--PrimaryColor); /* 아이콘 색상이 주 색상으로 바뀜 */
    }
}
```

```jsx
기본 상태:

		.icon은 처음에 background: var(--PrimaryColor) (주 색상), color: var(--whiteColor) (아이콘의 흰색),

		그리고 border: 1px solid transparent (투명한 테두리)로 설정되어 있습니다.

		이 상태에서는 아이콘이 주 색상 배경과 흰색 아이콘으로 보이며, 테두리는 보이지 않습니다.

호버 상태:

		마우스를 아이콘 위에 올리면 (:hover), 세 가지 속성의 변화가 발생합니다.

		배경 색상이 var(--blackColor) (검은색)으로 변합니다.

		테두리가 transparent에서 var(--PrimaryColor) (주 색상)으로 바뀌어, 테두리가 눈에 띄게 됩니다.

		아이콘 색상은 흰색에서 var(--PrimaryColor) (주 색상)으로 변경됩니다.

이 과정에서 transition 속성 덕분에 변화가 0.3초 동안 부드럽게 진행됩니다. transition 속성은 다음과 같이 동작합니다:

		background 0.3s ease: 배경색이 0.3초 동안 ease 함수에 따라 부드럽게 검은색으로 변합니다.

		color 0.3s ease: 아이콘의 색상도 0.3초 동안 동일하게 주 색상으로 변환됩니다.

		border 0.3s ease: 테두리도 투명에서 주 색상으로 서서히 바뀝니다.
```

