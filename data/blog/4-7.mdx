## 📁 사운드 파일 임포트

### 1. 폴더 구조 생성

```
Content/Assets/
  └─ Sounds/          (새로 생성)
      └─ Drone/       (새로 생성)
```

**작업 순서**

1. Content Browser에서 우클릭
2. New Folder → "Sounds"
3. Sounds 폴더 내 New Folder → "Drone"

```

**방법 2: Import 버튼**

- Import 클릭 → 파일 선택 → Open

**임포트된 파일**

- Drone_Energy_Rifle_01.wav
- Drone_Energy_Rifle_02.wav

## 🎵 메타사운드(MetaSound) 생성

### 메타사운드란?

```
WAV 파일 = 단순 오디오 파일
  ↓
MetaSound = 커스터마이징 가능한 사운드 시스템
  ├─ 모노/스테레오 선택
  ├─ 랜덤 변화 적용
  ├─ 피치 조절
  └─ 감쇠 설정
```

### 1. 메타사운드 생성

```
Sounds/Drone 폴더에서 우클릭
  ↓
Audio → Meta Sound Source
  ↓
이름: SFX_Energy_Rifle
```

**명명 규칙**

- `SFX_` 접두사: Sound Effect
- 용도를 명확히 표시

### 2. 메타사운드 에디터 구조

```
MetaSound Editor
  ├─ Graph (중앙)
  ├─ Details Panel (우측)
  └─ Members Panel (좌측)
      ├─ Inputs
      ├─ Outputs
      └─ Variables
```

### 1. 출력 형식 변경

**현재 상태**

```

✓ 단순 오디오 재생

```

  → 거리 무관 동일 볼륨

```
동일 사운드 반복
  → 지루함
  → 기계적

랜덤 사운드 + 피치
  → 자연스러움
  → 다양성

## 🎯 핵심 개념 정리

### Delay vs Timer

```
Delay
  ├─ 간단하지만 제어 불가
  └─ 테스트용으로만 사용

Timer
  ├─ 정교한 제어 가능
  ├─ 프로덕션 코드에 적합
  └─ Looping, 취소 지원
```

### FlipFlop 활용

```
교대 실행이 필요한 경우:
  ├─ 좌우 교차
  ├─ On/Off 토글
  └─ 상태 전환

→ FlipFlop 노드 활용
```

### Custom Event

```
이벤트 = 재사용 가능한 실행 흐름
  ├─ 함수처럼 호출 가능
  ├─ Timer에 연결 가능
  └─ 여러 곳에서 호출 가능
```

### Niagara 방향 제어

```
Add Velocity from Point
  └─ Origin Offset으로 방향 조절
  └─ X축 오프셋 = 전후 방향
```
