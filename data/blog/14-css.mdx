## CSS 그리드에 대한 이해

```jsx
CSS 그리드는 웹 페이지의 레이아웃을 설정하는 강력한 도구입니다.

그리드를 사용하면 HTML 요소를 행(row)과 열(column)로 구성할 수 있으며, 복잡한 레이아웃도 간단하게 구현할 수 있습니다.
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381544/notion-blog/_/_/CSS/_CSS_/_14_CSS_/image.png)

```jsx
.container {
    margin: 20px;
    display: grid;
    gap: 20px; // 그리드 간의 거리
}

.el1 {
    background: rgba(255, 154, 72, 0.5);
}

.el2 {
    background: rgba(255, 0, 0, 0.5);
}

.el3 {
    background: rgba(0, 128, 0, 0.5);
}

.el4 {
    background: rgba(0, 4, 255, 0.5);
}
```

## 예제: 기본 CSS 그리드 설정

```jsx
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="styles.css">
    <title>CSS Grid Example</title>
</head>
<body>
    <div class="container">
        <div class="item">Item 1</div>
        <div class="item">Item 2</div>
        <div class="item">Item 3</div>
        <div class="item">Item 4</div>
    </div>
</body>
</html>
```

```jsx
/* styles.css */

.container {
    display: grid; /* 그리드 컨테이너로 설정 */
    gap: 10px; /* 그리드 아이템 사이의 간격 설정 */
}

.item {
    background-color: #4CAF50;
    color: white;
    padding: 20px;
    font-size: 1.5em;
    text-align: center;
}
```

```jsx
그리드 설정:

		display: grid;를 사용하여 .container를 그리드 컨테이너로 설정합니다.

		이 설정으로 인해 .container 내부의 직계 자식 요소(.item 클래스가 있는 <div>들)가 그리드 아이템이 됩니다.

기본 그리드 동작:

		기본적으로, display: grid;는 하나의 열(column)을 생성하고, 자식 요소의 개수만큼 행(row)을 생성합니다.

		이 예제에서는 4개의 <div>가 있기 때문에 4개의 행이 생성되고 각 행에 하나의 아이템이 배치됩니다.

CSS 개발자 도구에서의 확인:

		웹 브라우저의 개발자 도구를 사용하여 .container 요소를 확인하면 display: grid;가 적용된 것을 볼 수 있습니다.

		그리드 레이아웃은 기본적으로 하나의 열과 여러 행을 가지므로, 각 아이템이 한 줄씩 차지하게 됩니다.


그리드 레이아웃의 시각적 표시:

		개발자 도구에서 그리드 아이콘을 클릭하면 그리드 라인이 표시됩니다.

		이는 그리드 레이아웃의 시각적 구조를 확인하는 데 유용합니다.
```

## 그리드 용어

```jsx
그리드 컨테이너(Grid Container): display: grid; 속성을 적용한 요소로, 그리드를 포함하는 부모 요소입니다.

그리드 아이템(Grid Item): 그리드 컨테이너 내에 포함된 자식 요소들입니다.

그리드 라인(Grid Line): 그리드의 시작과 끝을 정의하는 선입니다.

그리드 셀(Grid Cell): 그리드 라인에 의해 형성된 하나의 사각형 영역입니다.
그
리드 트랙(Grid Track): 연속된 그리드 셀들의 집합으로, 행 또는 열을 말합니다.

그리드 영역(Grid Area): 여러 그리드 셀을 하나로 묶은 직사각형 영역입니다.
```

# { 열(column)과 행(row) 정의하기 }

```jsx
그리드를 설정하려면 그리드 컨테이너의 CSS에 display: grid;를 추가하고,

grid-template-columns 및 grid-template-rows 속성을 사용하여 그리드의 행과 열을 정의합니다.
```

### grid-template-columns

```jsx
이 속성은 그리드의 열을 정의하며, 각 열의 너비를 설정합니다.

열의 너비를 절대 값(예: px, rem)이나 상대 값(예: %, fr)으로 지정할 수 있습니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: 200px 150px 20% 1fr;
}
```

```jsx
200px: 첫 번째 열의 너비를 200픽셀로 설정.

150px: 두 번째 열의 너비를 150픽셀로 설정.

20%: 세 번째 열의 너비를 컨테이너의 20%로 설정.

1fr: 네 번째 열은 남아 있는 공간을 하나의 분수 단위로 설정 (fr는 "fraction"의 약자).
```

### grid-template-rows

```jsx
이 속성은 그리드의 행을 정의하며, 각 행의 높이를 설정합니다.

이 속성도 절대 값이나 상대 값을 사용할 수 있습니다.
```

```jsx
.container {
  display: grid;
  grid-template-rows: 5rem 2.5rem;
}
```

```jsx
5rem: 첫 번째 행의 높이를 5rem으로 설정.

2.5rem: 두 번째 행의 높이를 2.5rem으로 설정.
```

## 중요한 개념들

```jsx
열과 행의 크기:

		grid-template-columns와 grid-template-rows는 각각 열과 행의 크기를 설정합니다.

		절대 값(예: 200px, 150px)은 고정된 크기를 의미하며,

		상대 값(예: 20%, 1fr)은 유연한 크기를 의미합니다.

분수 단위 (fr):

		fr 단위는 그리드 컨테이너 내에서 남은 공간을 분할하는 비율을 나타냅니다.

		예를 들어, 1fr 2fr로 설정하면 두 번째 열이 첫 번째 열보다 두 배 더 큰 공간을 차지합니다.

그리드 자동 배치:

		그리드에 명시적으로 설정되지 않은 행과 열은 기본값을 사용하여 자동으로 배치됩니다.

		grid-template-rows와 grid-template-columns에서

		지정한 크기에 따라 추가적인 행과 열이 자동으로 생성될 수 있습니다.

그리드 라인:

		그리드의 시작과 끝을 정의하며, 행과 열을 구분하는 선입니다.

		그리드 라인은 CSS의 grid 기능을 사용할 때 중요한 요소입니다.
```

# { ‘element-sizing(요소 크기)’ 프로퍼티 및 ‘repeat(반복)’ 함수와 ‘minmax(최대최소)’ 함수 }

```jsx
CSS Grid에서 사용할 수 있는 추가적인 기능과 유용한 함수들에 대해 다룹니다.

특히, auto, repeat(), minmax() 함수의 사용 방법과 그 유용성에 대해 설명합니다.
```

## 1. `auto` 값의 사용

```jsx
auto는 CSS Grid에서 유연한 크기를 설정할 때 사용됩니다.

열(column)과 행(row)에 적용될 수 있으며, 남은 공간을 자동으로 채우거나 콘텐츠에 맞는 크기를 자동으로 설정해 줍니다.
```

```jsx
<div class="container">
  <div class="item">Element 1</div>
  <div class="item">Element 2</div>
  <div class="item">Element 3</div>
  <div class="item">Element 4</div>
</div>
```

```jsx
.container {
  display: grid;
  grid-template-columns: 5rem auto; /* 첫 번째 열은 5rem, 두 번째 열은 남은 공간을 채움 */
  grid-template-rows: auto; /* 콘텐츠에 맞게 자동으로 높이를 설정 */
}
```

```jsx
grid-template-columns: 5rem auto;: 첫 번째 열의 너비는 5rem, 두 번째 열은 남은 모든 공간을 차지합니다.

grid-template-rows: auto;: 행의 높이는 콘텐츠의 높이에 따라 자동으로 설정됩니다.
```

## 2. `repeat()` 함수의 사용

```jsx
repeat() 함수는 CSS Grid에서 반복되는 패턴을 간결하게 작성할 수 있도록 도와줍니다.

열이나 행의 크기를 반복적으로 지정해야 할 때 매우 유용합니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* 4개의 열을 동일한 비율로 설정 */
  grid-template-rows: repeat(2, 100px); /* 2개의 행을 100px로 설정 */
}
```

## 3. `minmax()` 함수의 사용

```jsx
minmax() 함수는 그리드 셀의 최소 및 최대 크기를 설정할 때 사용됩니다.

특정 셀이나 트랙이 특정 범위 내에서 크기를 조절할 수 있도록 유연하게 설정할 수 있습니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: minmax(50px, 150px) auto; /* 첫 번째 행의 높이는 50px에서 150px 사이, 두 번째 행은 자동 높이 */
}
```

```jsx
minmax(50px, 150px): 첫 번째 행의 높이는 최소 50px, 최대 150px까지 확장될 수 있습니다.

auto: 두 번째 행은 콘텐츠에 맞게 자동으로 높이를 설정합니다.
```

## 종합 예제: 다양한 함수와 단위를 사용하는 그리드 설정

```jsx
<div class="container">
  <div class="item">Element 1</div>
  <div class="item">Element 2</div>
  <div class="item">Element 3</div>
  <div class="item">Element 4</div>
</div>
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr) auto; /* 3개의 열은 동일한 비율로 설정하고, 마지막 열은 남은 공간을 채움 */
  grid-template-rows: minmax(50px, 150px) 200px; /* 첫 번째 행은 50px에서 150px 사이로 설정하고, 두 번째 행은 200px로 설정 */
}
```

```jsx
첫 번째 열부터 세 번째 열은 동일한 비율로 공간을 나누며,

마지막 열은 남아 있는 모든 공간을 차지합니다.

첫 번째 행은 높이가 최소 50px에서 최대 150px까지 변경될 수 있으며,

두 번째 행은 고정 높이인 200px로 설정됩니다.
```

# { 고급 요소 배치 span }

## `span` 키워드를 사용한 배치

```jsx
span 키워드를 사용하면 라인 번호 대신에 그리드 항목이 차지할 셀의 개수를 지정할 수 있습니다.

예를 들어, Element 3이 2개의 셀을 차지하게 하려면 grid-column-end를 span 2로 설정할 수 있습니다.
```

```jsx
.el3 {
  grid-column-start: 3; /* 세 번째 열에서 시작 */
  grid-column-end: span 2; /* 두 개의 열을 차지 */
}
```

```jsx
이 설정은 Element 3이 세 번째 열에서 시작하여 그다음 두 개의 열을 차지하게 합니다.
```

## 음수 라인 번호를 사용한 배치

```jsx
그리드의 마지막 라인부터 배치하고자 할 때는 음수 라인 번호를 사용할 수 있습니다.

-1은 그리드의 마지막 라인을 의미하며, 이를 사용하면 그리드의 끝을 기준으로 배치할 수 있습니다.
```

```jsx
.el2 {
  grid-column-start: 1; /* 첫 번째 열에서 시작 */
  grid-column-end: -1;  /* 마지막 열까지 차지 */
}
```

```jsx
이 설정은 Element 2가 첫 번째 열에서 시작하여 마지막 열까지 모든 열을 차지하게 만듭니다.
```

## 그리드 항목의 중첩

```jsx
그리드 항목은 같은 셀을 공유할 수 있으며, 이 경우 겹쳐서 표시됩니다.

기본적으로 DOM 순서에 따라 나중에 정의된 항목이 앞에 표시되지만,

z-index를 사용해 어떤 항목이 앞에 표시될지를 설정할 수 있습니다.
```

```jsx
el2 {
  grid-column-start: 1; /* 첫 번째 열에서 시작 */
  grid-column-end: -1;  /* 마지막 열까지 차지 */
  grid-row-start: 2;    /* 두 번째 행에서 시작 */
  grid-row-end: span 1; /* 하나의 행을 차지 */
  z-index: 10;          /* z-index를 사용하여 우선순위를 높임 */
}

.el3 {
  grid-column-start: 2; /* 두 번째 열에서 시작 */
  grid-column-end: span 3; /* 세 개의 열을 차지 */
  grid-row-start: 2;    /* 두 번째 행에서 시작 */
  grid-row-end: 3;      /* 세 번째 행까지 차지 */
}
```

```jsx
Element 2는 두 번째 행을 차지하도록 설정되며, 전체 열을 차지합니다.

Element 3은 세 개의 열을 차지하도록 설정되어 있으며, 두 번째 행에서 시작하여 세 번째 행까지 차지합니다.

Element 2의 z-index를 10으로 설정하여, Element 3 위에 나타나도록 설정할 수 있습니다.
```

## 요약

```jsx
grid-column-start 및 grid-column-end: 그리드 항목의 시작과 끝 열을 명시적으로 설정할 수 있습니다.

span 키워드: 지정된 개수만큼의 셀을 차지하도록 설정할 수 있습니다.

음수 라인 번호: 그리드의 끝에서부터 배치할 수 있으며, 라인 번호를 기준으로 배치할 때 유연성을 제공합니다.

그리드 항목 중첩: z-index를 사용하여 겹쳐진 항목의 우선순위를 설정할 수 있습니다.
```

# { 라인에 이름을 붙여서 사용하는 방법 }

## 1. 라인에 이름 지정하기

```jsx
그리드 레이아웃에서 특정 라인(수평선 또는 수직선)에 이름을 지정하여,

그리드 항목을 배치할 때 라인 번호 대신 이름으로 참조할 수 있습니다.

라인 이름을 지정하는 방법은 grid-template-rows나 grid-template-columns 속성에서 대괄호 []를 사용하여 이름을 추가하는 것입니다.
```

### 예제: 행(Row)에 라인 이름 지정하기

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* 4개의 열을 동일한 비율로 설정 */
  grid-template-rows: [row-1-start] 100px [row-1-end row-2-start] 100px [row-2-end row-3-start] 100px [row-3-end];
}
```

```jsx
[row-1-start]: 첫 번째 행의 시작 라인에 row-1-start라는 이름을 지정.

[row-1-end row-2-start]: 첫 번째 행의 끝이자 두 번째 행의 시작 라인에 row-1-end와 row-2-start라는 이름을 지정.

[row-2-end row-3-start]: 두 번째 행의 끝이자 세 번째 행의 시작 라인에 row-2-end와 row-3-start라는 이름을 지정.

[row-3-end]: 세 번째 행의 끝 라인에 row-3-end라는 이름을 지정.
```

## 2. 라인 이름으로 그리드 항목 배치하기

```jsx
이제, 라인 이름을 사용하여 그리드 항목을 배치하는 방법을 보겠습니다.

라인 번호 대신 라인 이름을 사용하면 코드가 더 읽기 쉽게 됩니다.
```

```jsx
.el3 {
  grid-row-start: row-2-start; /* 두 번째 행의 시작 라인 */
  grid-row-end: row-2-end;     /* 두 번째 행의 끝 라인 */
}
```

```jsx
grid-row-start: row-2-start;: row-2-start라는 이름이 붙은 라인에서 시작하도록 지정합니다.

grid-row-end: row-2-end;: row-2-end라는 이름이 붙은 라인에서 끝나도록 지정합니다.
```

# { ‘grid-column(그리드 열)’ & ‘grid-row(그리드 행)’ 축약 이해하기 }

```jsx
 CSS Grid의 축약형(syntax shorthand)과 고급 배치 기능에 대해 배웁니다.

 특히, grid-column, grid-row, 그리고 grid-area를 사용한 축약형 표기법을 다룹니다.

 이러한 축약형을 사용하면 코드가 더 간결해지고 읽기 쉬워집니다
```

## 1. 축약형 사용의 필요성

```jsx
CSS Grid에서는 배치를 지정할 때 많은 속성을 사용하게 됩니다.

하지만 각 속성을 개별적으로 작성하면 코드가 길어질 수 있습니다.

축약형을 사용하면 이러한 속성들을 한 줄로 표현할 수 있어 코드가 더 간결해지고 관리하기 쉬워집니다.
```

## 2. `grid-column`과 `grid-row` 축약형

```jsx
속성들을 축약형을 사용하여 한 줄로 표현할 수 있습니다.
```

```jsx
/* 긴 버전 */
.el {
  grid-column-start: 1;
  grid-column-end: 3;
}

/* 축약형 */
.el {
  grid-column: 1 / 3; /* 첫 번째 열에서 시작하여 세 번째 열까지 */
```

## 3. `grid-area` 축약형

```jsx
grid-area는 grid-row-start, grid-column-start, grid-row-end, grid-column-end의

네 가지 속성을 모두 축약하여 한 줄로 표현할 수 있습니다.

이 축약형은 그리드 항목의 시작과 끝을 모두 포함하여 한 번에 설정할 수 있게 해줍니다.
```

```jsx
/* 긴 버전 */
.el3 {
  grid-row-start: row-1-start;
  grid-column-start: 2;
  grid-row-end: row-2-end;
  grid-column-end: span 3;
}

/* grid-area 축약형 */
.el3 {
  grid-area: row-1-start / 2 / row-2-end / span 3;
}
```

# { Gaps(간격)를 활용해서 작업하기 }

```jsx
기본적으로 CSS Grid에서 각 행과 열은 서로 밀착되어 있으며,

그 사이에 여백이 없습니다.

요소 간의 여백을 설정하려면 그리드 컨테이너에 여백을 추가해야 합니다.
```

## 요소 간의 여백 설정하기

```jsx
문제점:

		요소에 바깥쪽 여백(margin)을 추가하면,

		요소 간의 거리가 떨어져 보일 수 있지만, 실제로 그리드 레이아웃의 배치에는 영향을 미치지 않습니다.

		그리드의 라인(line) 구조는 변하지 않기 때문입니다.

해결책:

		그리드 컨테이너에 여백을 설정하면,

		그리드의 라인과 요소 간의 공백을 명확하게 만들 수 있습니다.
```

## `grid-column-gap`과 `grid-row-gap` 사용

```jsx
grid-column-gap: 열(column) 사이의 공백을 설정합니다.

grid-row-gap: 행(row) 사이의 공백을 설정합니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(2, 100px);
  grid-column-gap: 20px; /* 열 사이의 공백을 20px로 설정 */
  grid-row-gap: 10px; /* 행 사이의 공백을 10px로 설정 */
}
```

## `grid-gap` 축약형 사용

```jsx
grid-gap은 grid-row-gap과 grid-column-gap을 함께 설정할 수 있는 축약형입니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(2, 100px);
  grid-gap: 10px 20px; /* 행 사이의 공백은 10px, 열 사이의 공백은 20px로 설정 */
}
```

### 동일한 공백 설정

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(2, 100px);
  grid-gap: 15px; /* 행과 열 모두 15px의 공백으로 설정 */
}
```

```jsx
이렇게 하면 행과 열 사이의 모든 공백이 15px로 설정됩니다.
```

# { 이름을 지정한 템플릿 영역 추가하기 }

```jsx
CSS Grid의 고급 배치 기능을 통해 그리드를 **영역(Area)**으로 나누고,

각 영역에 이름을 붙여 쉽게 요소를 배치하는 방법을 배웁니다.

이를 통해 더 직관적이고 유연한 레이아웃을 구성할 수 있습니다.
```

## 그리드 영역(Area) 이름 지정하기

```jsx
그리드 항목의 배치를 더 직관적으로 설정하기 위해 **그리드 영역(Area)**에 이름을 붙일 수 있습니다.

영역을 지정하는 방법은 grid-template-areas 속성을 사용하는 것입니다.
```

### `grid-template-areas` 속성 사용하기

```jsx
이 속성은 그리드의 각 셀에 이름을 지정하여, 해당 이름으로 그리드 항목을 배치할 수 있게 합니다.

그리드 영역을 정의할 때는 큰 따옴표 " "로 묶인 문자열을 사용하여 각 행을 정의합니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: 100px 100px 100px;
  grid-template-areas:
    "header header header header"
    "side side main main"
    "footer footer footer footer";
}

```

```jsx
grid-template-areas 설명:

		첫 번째 행: "header header header header" — 네 개의 열을 모두 header 영역으로 설정

		두 번째 행: "side side main main" — 두 개의 열은 side, 나머지 두 개의 열은 main 영역으로 설정

		세 번째 행: "footer footer footer footer" — 네 개의 열을 모두 footer 영역으로 설정
```

## 그리드 영역을 이용한 요소 배치

```jsx
grid-area 속성을 사용해 각 그리드 항목을 특정 영역에 배치할 수 있습니다.
```

```jsx
.el3 {
  grid-area: header; /* 'header' 영역에 배치 */
}

.el2 {
  grid-area: main; /* 'main' 영역에 배치 */
}

.el4 {
  grid-area: footer; /* 'footer' 영역에 배치 */
}
```

## 기본적인 라인 이름 지정 방법

```jsx
CSS Grid에서 라인에 이름을 지정하는 것은 그리드 항목을 배치하는 데 유용합니다.

이전에는 열(column)에 이름을 지정하지 않았지만,

이번에는 repeat() 함수를 사용하여 열에 이름을 지정하는 방법을 살펴보겠습니다.
```

```jsx
<div class="container">
  <div class="item el1">Element 1</div>
  <div class="item el2">Element 2</div>
  <div class="item el3">Element 3</div>
  <div class="item el4">Element 4</div>
</div>
```

```jsx
.container {
  display: grid;
  grid-template-columns: [col-start] repeat(4, 1fr [col-end]) [col-end];
  grid-template-rows: [row-1-start] 5rem [row-1-end row-2-start] auto [row-2-end row-3-start] 5rem [row-3-end];
}

* [col-start]: 첫 번째 열의 시작 지점에 col-start라는 이름을 붙입니다.

	repeat(4, 1fr [col-end]): 이 부분은 반복적으로 4개의 열을 정의합니다.

			1fr: 각 열의 너비를 균등하게 나눕니다. fr은 'fraction'(분수)의 약자이며, 가용 공간을 4개의 열에 균등하게 분할합니다.

			[col-end]: 각 열의 끝 지점에 col-end라는 이름을 붙입니다.

	[col-end]: 마지막 열의 끝에 col-end라는 이름을 추가로 붙입니다.
```

```jsx
[col-start]와 [col-end]: 열의 시작과 끝에 이름을 지정합니다. 이 이름은 반복됩니다.

[row-1-start], [row-1-end] 등: 행에 이름을 지정합니다. 이 이름은 각 행의 시작과 끝을 나타냅니다.
```

## `repeat()` 함수와 라인 이름 지정

```jsx
repeat() 함수 내에서 라인 이름을 지정할 수 있습니다.

이는 그리드의 반복되는 열이나 행에 동일한 라인 이름을 지정할 수 있어 매우 유용합니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: [col-start] repeat(4, 1fr [col-end]) [col-end];
}
```

## 라인 이름을 사용한 요소 배치

```jsx
라인 이름을 사용하여 그리드 항목을 더 쉽게 배치할 수 있습니다.

이 방법은 열과 행의 특정 라인 이름을 사용하여 항목의 위치를 지정합니다.
```

```jsx
.el1 {
  grid-column: col-start 2 / col-end 2; /* 두 번째 열의 시작과 끝 */
  grid-row: row-2-start / row-2-end; /* 두 번째 행 */
}
```

```jsx
grid-column: col-start 2 / col-end 2;: 두 번째 열의 시작(col-start 2)부터 끝(col-end 2)까지 설정합니다.

grid-row: row-2-start / row-2-end;: 두 번째 행의 시작(row-2-start)부터 끝(row-2-end)까지 설정합니다.
```

## 자동 생성된 그리드 영역 이름 사용하기

```jsx
CSS Grid에서는 **-start**와 **-end**로 이름이 지정된 라인 이름 패턴을 통해 자동으로 그리드 영역 이름이 생성됩니다.

이 기능을 사용하면 라인 이름을 수동으로 지정하지 않아도 됩니다.
```

```jsx
.container {
  display: grid;
  grid-template-columns: [hd-start] repeat(4, 1fr [hd-end]) [hd-end];
  grid-template-rows: [hd-start] 5rem [hd-end];
}
```

```jsx
[hd-start]: 첫 번째 열과 행의 시작에 이름을 지정합니다.

[hd-end]: 마지막 열과 행의 끝에 이름을 지정합니다

이 패턴에 따라 자동으로 **hd**라는 그리드 영역 이름이 생성됩니다.

**hd-start**와 hd-end 사이에 있는 모든 셀이 hd 영역으로 간주됩니다.
```

### 자동 생성된 영역 이름으로 요소 배치

```jsx
.el3 {
  grid-area: hd; /* 'hd'라는 자동 생성된 영역에 배치 */
}
```

```jsx
grid-area: hd;: 자동 생성된 hd 영역에 Element 3을 배치합니다.
```
