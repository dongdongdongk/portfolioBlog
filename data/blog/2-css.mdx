## 1. **기본 스타일 적용**

```html
CSS 파일에서 h1 선택자를 사용하여 텍스트 스타일을 변경할 수 있습니다. 예를 들어, 다음과 같이 color와
font-family 속성을 추가하여 텍스트의 색상과 폰트를 설정할 수 있습니다:
```

```html

```

```html
  부분에 import 링크를 추가합니다: 그런 다음, CSS에서 해당 폰트를 font-family로 지정합니다.
</head>
```


## 1. **태그 선택자**

```css
태그 선택자는 동일한 태그에 동일한 스타일을 적용합니다.

예를 들어, 모든 h1 태그에 동일한 스타일을 적용하려면 다음과 같이 설정합니다
```

```css
h1 {
  color: white;
  font-family: 'Anton', sans-serif;
}
```

## 2. **ID 선택자**

```css
ID 선택자는 특정 요소 하나에만 스타일을 적용합니다. ID는 페이지에서 유일해야 합니다.

# 기호를 사용하여 ID 선택자를 지정합니다
```

```css
#product-overview {
  background: #ff1b68;
}

HTML에서 ID는 이렇게 설정합니다

<section id="product-overview">
  <h1>Get the freedom you deserve.</h1>
</section>
```

## 3. **클래스 선택자**

```css
클래스선택자는여러 요소에 동일한 스타일을 적용할 수 있으며, 재사용이 가능합니다.

. 기호로 클래스 선택자를 지정합니다: * 재사용을 원하면 class 선택자로 만드는게 옳은 선택이다
  (id 선택자는 한번만 사용 가능하기 떄문에);
```

```css
.section-title {
  color: #2ddf5c;
}

html에서클래스는이렇게 추가합니다: <h1 class= 'section-title' >Choose Your Plan</h1>;
```

# { CSS 명시도와 선택자 우선순위 요약 }

## 1. **캐스케이딩(Cascading)**

```css
**캐스케이딩 스타일 시트(CSS)**는 여러 규칙이 동일한 요소에 적용될 수 있음을 의미합니다.

이로 인해 충돌이 발생할 수 있으며, 이러한 충돌을 해결하기 위해 **명시도(specificity)**라는 개념이 사용됩니다.
```

## 2. **명시도(specificity)**

```css
명시도는 충돌을 해결할 때 어떤 규칙이 우선하는지 결정합니다.

선택자의 종류에 따라 명시도의 순서가 다릅니다:

	1. 태그 선택자 (h1, p 등): 가장 낮은 명시도를 가짐.

	2. 클래스 선택자 (.section-title), 의사 클래스 (:hover 등), 속성 선택자 ([type="text"]): 중간 명시도를 가짐.

	3. ID 선택자 (#product-overview): 높은 명시도를 가짐.

	4. 인라인 스타일링 (style="color: red;"): 가장 높은 명시도를 가짐.

순서 역시 중요합니다. 같은 선택자 유형에서는 뒤에 위치한 규칙이 앞의 규칙을 덮어씁니다.
```

## 3. **예제 분석**

```css
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>CSS Specificity Example</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <section id="intro">
      <h1 class="section-title">Welcome to the Intro Section</h1>
    </section>
    <section id="details">
      <h1 class="section-title">Details Section</h1>
    </section>
  </body>
</html>
```

```css
/* 태그 선택자 */
h1 {
  color: blue;
  font-family: Arial, sans-serif;
}

/* 클래스 선택자 */
.section-title {
  color: green;
}

/* ID 선택자 */
#intro {
  background-color: lightgray;
}

/* 인라인 스타일링은 HTML 파일 내에서 사용됩니다 */
```

```css
모든 h1 태그의 텍스트 색상은 기본적으로 파란색(color: blue;)으로 설정됩니다.

그러나 section-title 클래스를 가진 h1 태그는 녹색(color: green;)으로 표시됩니다.

클래스 선택자의 명시도가 태그 선택자보다 높기 때문입니다.

#intro ID를 가진 section의 배경색은 연한 회색(background-color: lightgray;)으로 설정됩니다.
```

# { 상속 이해하기 }

## 상속(Inheritance) 개념

```css
상속이란 CSS에서 자식 요소가 부모 요소의 스타일을 물려받는 것을 의미합니다.

상속은 주로 폰트와 관련된 스타일(예: font-family, color)에 적용됩니다.

그러나 상속된 스타일의 명시도는 매우 낮습니다. ( 제일 낮다 )

즉, 동일한 스타일 속성에 대해 명시도가 더 높은 규칙이 존재하면, 그 규칙이 우선 적용됩니다.
```

## 글로벌 스타일 설정 및 상속 활용

```css
프로젝트 전반에 걸쳐 동일한 폰트를 사용하고 싶다면, 글로벌 폰트 스타일을 설정할 수 있습니다.

body 요소에 폰트 스타일을 설정하면, 해당 폰트는 모든 자식 요소에 상속됩니다.

상속된 스타일은 특정 선택자나 인라인 스타일링보다 명시도가 낮기 때문에, 필요한 경우 이를 쉽게 덮어쓸 수 있습니다.
```

## 예제 코드

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="ie=edge" />
    <title>uHost</title>
    <link rel="shortcut icon" href="favicon.png" />
    <link rel="stylesheet" href="main.css" />
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <link href="https://fonts.googleapis.com/css2?family=Anton&display=swap" rel="stylesheet" />
    <link
      href="https://fonts.googleapis.com/css2?family=Anton&family=Montserrat:ital,wght@0,100..900;1,100..900&display=swap"
      rel="stylesheet"
    />
  </head>

  <body>
    <main>
      <section id="product-overview">
        <h1>Get the freedom you deserve.</h1>
      </section>
      <section id="plans">
        <h1 class="section-title">Choose Your Plan</h1>
        <p>Make sure you get the most for your money!</p>
      </section>
    </main>
  </body>
</html>
```

```css
/* 주석 처리된 글로벌 폰트 설정 */
/* * {
    font-family: sans-serif;
} */

/* 더 효율적인 글로벌 폰트 설정 */
body {
  font-family: 'Montserrat', sans-serif;
}

/* 특정 섹션의 배경 설정 */
#product-overview {
  background: #ff1b68;
}

/* 클래스 선택자를 통한 텍스트 색상 설정 */
.section-title {
  color: #2ddf5c;
}

/* h1 태그에 Anton 폰트 및 텍스트 색상 설정 */
h1 {
  color: white;
  font-family: 'Anton', sans-serif;
}

/* 이전 h1 태그 폰트 설정을 주석 처리 */
/* h1 {
    font-family: sans-serif;
} */
```

```css
글로벌 폰트 설정:

	body에 "Montserrat", sans-serif 폰트를 설정하면, 이 폰트는 모든 자식 요소에 상속됩니다.

	이 방법은 별표 선택자(*)를 사용하는 것보다 더 효율적입니다.

명시도 확인:

	h1 태그에 "Anton", sans-serif 폰트를 직접 설정했기 때문에, 상속된 "Montserrat", sans-serif 폰트보다 높은 명시도를 가집니다.

	따라서, h1 태그에는 Anton 폰트가 적용됩니다.

상속된 스타일 확인:

	p 태그에는 별도로 폰트를 설정하지 않았기 때문에, body로부터 상속된 "Montserrat" 폰트가 적용됩니다.
```

# { 결합자 추가하기 }

## 1. **결합자(Combinator)**

```html
결합자는 여러 선택자를 결합하여 특정 요소를 더 정확하게 선택할 수 있게 합니다. 예를 들어,
#product-overview h1은 id가 product-overview인 섹션 내의 모든 h1 태그를 선택합니다. 결합자는
선택자의 명시도를 높이며, 더 구체적인 스타일 적용을 가능하게 합니다.
```

## 2. **상속(Inheritance)과 결합자**

```html
1. 상속은 부모 요소의 스타일이 자식 요소로 전달되는 과정입니다. 하지만 상속의 명시도는 낮기 때문에
직접 선택된 스타일보다 우선순위가 낮습니다. 2. 결합자를 사용하면 특정 요소에 명시적으로 스타일을
적용할 수 있어, 상속된 스타일보다 우선 적용됩니다.
```

## 3. **`inherit` 키워드**

```html
inherit 키워드는 부모 요소로부터 스타일을 상속받도록 강제합니다. 특정 스타일을 기본으로 되돌릴 때
유용하지만, 클래스마다 inherit를 사용해야 하므로 비효율적일 수 있습니다.
```

```html
#product-overview h1 { font-family: "Anton", sans-serif; }
```

```html
위와 같은 방식으로 사용한다 이렇게 사용하면 명시도가 높아져서
```

```css
/* * {
    font-family: sans-serif;
} */

body {
  font-family: 'Montserrat', sans-serif;
}

#product-overview {
  background: #ff1b68;
}

.section-title {
  color: #2ddf5c;
}

#product-overview h1 {
  color: white;
  font-family: 'Anton', sans-serif;
}

h1 {
  font-family: sans-serif;
}
```

```css
위와 같을 때 #product-overview h1 이 주변의 h1 과 다른 폰트보다 높은 명시도를 가져

그대로 출력되게 된다
```

# { 주요 결합자(Combinator) 개념 및 예제 정리 }

```css
CSS에서 결합자는 여러 선택자를 조합해 특정 요소에 스타일을 더 정확하게 적용할 수 있게 해주는 도구입니다.

여기에서는 네 가지 주요 결합자에 대해 알아보고, 각 결합자의 작동 원리와 예제를 살펴보겠습니다.
```

## 1. **인접 형제 결합자 (`+`)**

```css
정의: 특정 요소의 바로 다음에 오는 형제 요소를 선택합니다.

예제: h2 + p

	이 선택자는 h2 태그 바로 다음에 나오는 p 태그만을 선택합니다.
```

```css
h2 + p {
  color: red;
}
```

```css
<h2>Header</h2>
<p>This paragraph will be red because it's directly after the h2.</p>
<h3>Subheader</h3>
<p>This paragraph will not be red because it’s not directly after an h2.</p>

```

```css
설명:
  첫 번째 p 태그는 h2 태그의 인접 형제이므로 빨간색으로 표시됩니다. 반면,
  두 번째 p 태그는 h3 태그 뒤에 있어서 영향을 받지 않습니다.;
```

## 2. **일반 형제 결합자 (`~`)**

```css
정의: 특정 요소 뒤에 나오는 모든 형제 요소를 선택합니다. 요소가 반드시 바로 뒤에 있지 않아도 됩니다.

예제: h2 ~ p

	이 선택자는 h2 뒤에 오는 모든 p 태그를 선택합니다.
```

```css
h2 ~ p {
  color: blue;
}
```

```css
<h2>Header</h2>
<h3>Subheader</h3>
<p>This paragraph will be blue because it's a sibling of the h2.</p>
<p>This paragraph will also be blue.</p>
```

```css
설명: h2 뒤에 있는 모든 p 태그가 파란색으로 표시됩니다. h2와 p 태그 사이에 다른 요소(h3) 가 있더라도
  상관없습니다.;
```

## 3. **자식 결합자 (`>`)**

```css
정의: 특정 요소의 직속 자식 요소만을 선택합니다.

예제: div > p

	이 선택자는 div 태그의 직속 자식인 p 태그만을 선택합니다.
```

```css
div > p {
  color: green;
}
```

```css
<div>
  <p>This paragraph will be green.</p>
  <article>
    <p>This paragraph will not be green because it's nested inside an article.</p>
  </article>
</div>
```

```css
설명:
  div의 직속 자식인 첫 번째 p 태그는 녹색으로 표시되지만,
  article 내에 있는 p 태그는 영향을 받지 않습니다.;
```

## 4. **자손 결합자 (공백)**

```css
정의: 특정 요소의 모든 자손 요소를 선택합니다. 직속 자식뿐만 아니라 그 아래의 모든 자손 요소도 포함됩니다.

예제: div p

	이 선택자는 div 태그 내의 모든 p 태그를 선택합니다.
```

```css
div p {
  color: purple;
}
```

```css
<div>
  <p>This paragraph will be purple.</p>
  <article>
    <p>This paragraph will also be purple.</p>
  </article>
</div>
```

```css
설명: div 내의 모든 p 태그가 보라색으로 표시됩니다. p 태그가 div의 직속 자식이 아니더라도 스타일이
  적용됩니다.;
```

## 요약

```css
인접 형제 결합자 (+): 특정 요소 바로 뒤에 오는 형제 요소만 선택합니다.

일반 형제 결합자 (~): 특정 요소 뒤에 오는 모든 형제 요소를 선택합니다.

자식 결합자 (>): 특정 요소의 직속 자식만 선택합니다.

자손 결합자 (공백): 특정 요소의 모든 자손을 선택합니다.
```

## CSS의 기초 개념: 선택자, 프로퍼티, 값

```css
이번 강의에서는 CSS의 기본 원리를 이해하고, 선택자, 프로퍼티, 값의 개념을 살펴봤습니다.

아래에 그 주요 내용을 정리합니다.
```

## 1. **선택자 (Selector)**

```css
선택자는 CSS에서 특정 HTML 요소를 선택하기 위한 규칙입니다.

예시:
	div: 모든 <div> 요소를 선택.

	.blog-post: blog-post 클래스를 가진 요소를 선택.

	#main-title: main-title ID를 가진 요소를 선택.

	[disabled]: disabled 속성이 있는 요소를 선택.

	*: 전체 선택자로, 모든 요소를 선택.
```

## 2. **프로퍼티 (Property)**

```css
프로퍼티는 CSS에서 요소의 스타일 속성을 정의하는 키워드입니다.

예시:

	background-color: 요소의 배경 색상을 지정.

	width: 요소의 너비를 설정.

	color: 텍스트의 색상을 지정.

	margin: 요소의 외부 여백을 설정.

	display: 요소의 표시 방법을 지정.

* MDN CSS Reference에서 다양한 프로퍼티에 대한 정보를 확인할 수 있습니다.

모든 프로퍼티를 외울 필요는 없으며, 자주 사용하는 20개 정도의 프로퍼티만 익혀도 충분합니다.
```

## 3. **값 (Value)**

```css
값은 CSS 프로퍼티에 할당되는 실제 데이터입니다.

예시:

	색상: red, #ff0000 (헥스 코드)

	길이/크기: 100px, 50%

	사전 정의된 옵션 값: display: block, overflow: auto

	함수: url(image.jpg) (배경 이미지 설정), rotate(45deg) (요소 회전)

값의 범주:

	사전 정의된 옵션 값: block, auto 등, 특정 프로퍼티에 맞게 미리 정의된 값.

	색상 값: red, #ff0000 등의 색상 관련 값.

	길이, 크기, 숫자: px, %, 숫자 등으로 표현되는 값.

	함수: URL 설정, 변형 등의 기능을 수행하는 함수 값.
```
