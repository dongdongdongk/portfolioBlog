생성자는 객체를 생성 , 초기화 하는 역할을 한다.

```java
Car myCar = new Car(); // new Car() 의 Car 이 생성자다 (생성자를 호출하는 코드)
```

![Untitled](<29%20%EC%9E%90%EB%B0%94%20%EC%83%9D%EC%84%B1%EC%9E%90(1)/Untitled%201.png>)

생성자는 public 이 붙어 있을 수 도있고 생략 될 수 도 있다.

```java
[public]클래스() {}
//public class 클래스{} 처럼 클래스를 선언할 때 public 이 붙어있으면 자동으로 생성자에 [public]
이 붙는다. (선언때 없으면 자동으로 붙지 x)
```

### **기본 생성자**

클래스 내부에서 생성자 선언을 생략하면, 컴파일러가 자동으로 만들어주는 생성자.

소괄호와 중괄호 모두 비어있는 형태이다.

즉, 어떤 매개변수도 받지 않고 어떤 기능도 하지 않는다.

만약 클래스 내부에 생성자가 하나라도 있다면, 컴파일러는 기본 생성자를 만들지 않는다.

따라서 다른 생성자가 있는 상태에서 '컴파일러가 기본 생성자 만들어주겠지'하고 Car( ){ }을 선언하지 않고

Car dreamCar = new Car( );를 실행하면 오류가 발생한다.

=> 생성자를 하나라도 선언하면 기본 생성자는 만들어지지 않음

자바에서 객체를 생성할 때애는 반드시 new + 생성자 이름 + ( )을 해줘야 한다.

또 클래스 내부에서 생성자를 선언하지 않더라도 기본 생성자가 자동으로 만들어지므로

모든 객체는 생성자를 거쳐 만들어지게 되어있다.

이처럼 클래스에 생성자를 선언하지 않았는데 new 생성자() 를 호출할수 있던 이유가 **기본 생성자** 가

자동으로 추가 되었기 때문이다.

Ex. public class Car { } 을 컴파일한 바이트코드 파일에는

public class Car {

public Car( ) { }

}으로 텅 빈 기본 생성자가 들어가있다.

```java
public class Korean {
	//필드 //Korean 이라는 객체가 가져야 할 데이터
	String nation = "대한민국"; //Korean 한국인 이기 때문에 고정값으로 "대한민국"
	String name;     //이름과 주민번호 두가지는 초기값이 필요하다 이를 생성자에서
	String ssn;

	//생성자
	public Korean(String n, String s) { // 외부로 부터 받은 n, s 값을 필드에 저장한다
		name = n; //이때 생성자의 내부에 들어가는 코드를 객체 초기화 코드라 함
		ssn = s;
	}
}

//외부값
Korean k1 = new Korean ("박자바", "011225-1234567");//k1 의 번지를 참조하고 k1은 객체를 잠조
Korean k2 = new Korean ("김자바", "930525-0654321");//korean 이라는 객체는 필드값을 모두
																									  //가짐(nation, name, ssn)

*결과적으로 생성자는 new 연산자 뒤에서 호출이 되어서(Korean) 객체를 생성하기도 하지만 객체의
데이터를 초기화 하는 역할(외부로 부터 데이터를 받아서 필드에 값 저장) 도 한다.
```

```java
public class Korean {
	//필드 //
	String nation = "대한민국";
	String name;
	String ssn;

	//생성자
	public Korean(String n, String s) {
		this.name//필드 = name//매개변수;
		this.ssn = ssn;
	}
}
```

필드의 name 과 매개변수 이름을 똑같이 name으로 지어준다

그러나 이렇게 저장하면 생성자의 name으로 name(필드)을 만들어 버리기 때문에

생성자 매개변수 name(매개변수) = name(매개변수) 이 되버린다

이를 해결하기 위해서 필드의 name을 **this.name** 으로 해준다
