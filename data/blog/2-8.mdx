# **LESSON 06 네트워크의 규칙**

## 네트워크의 규칙: 프로토콜

```jsx
네트워크에서 통신을 원활하게 하기 위해서는 일정한 규칙이 필요합니다.

이 규칙을 프로토콜이라고 합니다. 프로토콜은 네트워크 통신을 위한 규약이자 약속입니다.

많은 네트워크 용어 뒤에 붙는 'P'는 Protocol의 약자입니다 (예: TCP, IP, HTTP 등).
```

### 프로토콜의 기본 요소

```jsx
구문 (Syntax)

	데이터의 형식: 데이터가 어떻게 형성되는지 규정합니다.

	부호화: 데이터를 어떻게 부호화할지 결정합니다.

	신호 레벨: 신호의 강도나 전압 수준을 정의합니다.

의미 (Semantics)

	협조 사항: 통신 중에 필요한 조치를 규정합니다.

	오류 관리: 오류를 어떻게 제어하고 처리할지 정합니다.

시간 (Timing)

	통신 속도: 데이터가 전달되는 속도를 규정합니다.

	메시지의 순서 제어: 메시지가 올바른 순서로 전달되도록 합니다.
```

### 프로토콜의 기능

```jsx
프로토콜은 다양한 기능을 제공합니다. 그중 주요 기능은 다음과 같습니다:

캡슐화: 데이터에 플래그, 주소, 제어 정보, 오류 검출 부호 등을 추가하여 전송합니다.

흐름 제어: 데이터가 너무 빠르게 보내져서 수신자가 따라가지 못하는 상황을 방지합니다.

오류 제어: 전송 중 발생할 수 있는 오류를 검출하고 수정합니다.

순서 결정: 데이터가 올바른 순서로 도착하도록 합니다.
```

# **LESSON 07 OSI 모델과 TCP/IP 모델**

## **OSI 모델?**

```jsx
국제 표준화 기구 ISO(International Organization for Standardization)에서 제정한 표준 규격.

네트워크 기술의 기본이 되는 모델이다.

데이터를 전송하며 내부에서 많은 일들이 일어나는데, 이런 일들은 7개 계층(Layer)으로 나뉜다.
```

# **LESSON 08 캡슐화와 역캡슐화**

```jsx
 데이터를 보낼 때, 데이터의 앞부분에 전송하는 데 필요한 정보를 붙여 다음 계층으로 보내야 한다.

 이 정보를 헤더라고 하며, 데이터를 전달받을 상대방에 대한 정보도 포함되어 있어 내용/성격을 식별 또는 제어하는 데 사용된다.



 이렇게 헤더를 붙이는 것을 캡슐화라고 하고, 헤더를 제거하는 것을 역캡슐화라고 한다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380902/notion-blog/_/_/_/_2_-_/Untitled_7.png)

## 데이터 전송 과정: 캡슐화

```jsx
응용 계층

	사용자가 웹사이트에 접속하기 위한 요청 데이터를 만듭니다.

전송 계층

	신뢰할 수 있는 통신을 위해 응용 계층 데이터에 헤더를 추가합니다. 이 헤더에는 포트 번호와 같은 정보가 포함됩니다.

네트워크 계층

	다른 네트워크와의 통신을 위해 전송 계층 데이터에 헤더를 추가합니다. 이 헤더에는 IP 주소 등이 포함됩니다.

데이터 링크 계층

	물리적인 통신 채널을 연결하기 위해 네트워크 계층 데이터에 헤더와 트레일러를 추가합니다. 트레일러는 데이터 전송 중 발생할 수 있는 오류를 감지하는 기능도 합니다.

물리 계층

	데이터 링크 계층에서 만들어진 데이터(응용 계층 데이터 + 전송 계층 헤더 + 네트워크 계층 헤더 + 데이터 링크 계층 헤더 + 트레일러)를

	전기 신호로 변환하여 수신 측으로 보냅니다.
```

## 데이터 수신 과정: 역캡슐화

```jsx
물리 계층

	전기 신호를 받아 데이터 링크 계층으로 전달합니다.

데이터 링크 계층

	데이터 링크 계층 헤더와 트레일러를 제거하고, 데이터를 네트워크 계층으로 전달합니다.

네트워크 계층

	네트워크 계층 헤더를 제거하고, 데이터를 전송 계층으로 전달합니다.

전송 계층

	전송 계층 헤더를 제거하고, 데이터를 응용 계층으로 전달합니다.

응용 계층

	모든 헤더가 제거된 데이터를 최종적으로 응용 프로그램에 전달합니다.
```

## 예시: 웹 사이트 접속

```jsx
1. 요청 데이터 생성 (응용 계층): 사용자가 웹 사이트에 접속하려는 요청 데이터를 만듭니다.

2. 신뢰할 수 있는 통신 준비 (전송 계층): 포트 번호 등 정보를 포함하는 헤더를 추가합니다.

3. 네트워크 통신 준비 (네트워크 계층): IP 주소 등 정보를 포함하는 헤더를 추가합니다.

4. 물리적 통신 준비 (데이터 링크 계층): 헤더와 트레일러를 추가합니다.

5. 전기 신호 변환 (물리 계층): 데이터를 전기 신호로 변환하여 전송합니다.
```

## VPN(Virtual Private Network, 가상 사설망)

```jsx
VPN은 가상 통신 터널을 통해 인터넷을 통해 사내 네트워크에 접속하거나, 거점 간에 안전하게 데이터를 교환할 수 있는 기술입니다.

이는 물리적 거리에 구애받지 않고 안전한 네트워크 연결을 제공합니다.
```

```jsx
종류

1. 인터넷 VPN

	거점 간 접속: 일반적으로 인터넷을 통해 거점 간 네트워크를 연결합니다. IPsec이라는 암호화 기술 프로토콜(L3)을 사용하여 안전한 연결을 보장합니다.

	원격 접속 연결: 외부에서 사내 네트워크에 접속할 때 사용됩니다. 암호화된 통신로를 통해 데이터를 안전하게 전송합니다.

2. IP-VPN

	MPLS 기술 사용: 인터넷 대신 통신 사업자의 전용 폐쇄망(MPLS)을 통해 연결합니다.

	이는 외부에서 접근할 수 없는 폐쇄적인 네트워크이므로 추가적인 암호화가 필요하지 않습니다.


	보안: 제삼자에 의한 해킹이나 데이터 변조 위험을 줄이기 위해 매우 안전한 환경을 제공합니다.

VPN 기술은 비즈니스와 개인 모두에게 데이터 보안과 원격 접근성을 제공하여 효율적인 업무 운영을 지원합니다.
```

# **Chapter Check-up**

```jsx
프로토콜이 무엇인가요?

	컴퓨터 간 정보를 주고받을 때의 통신 방법에 대한 규칙, 표준.

OSI 모델과 TCP/IP 모델을 설명하세요.

	OSI 모델은 ISO에서 정의한 국제 통신 표준 규약이고, 네트워크의 기본 구조를 7 계층으로 나눠서 표준화한 통신 규약이다.

	TCP/IP 모델은 OSI 모델 7 계층에서 네트워크에서 데이터를 전송하는 과정을 4 계층으로 단순화시켜 사용하는 모델이다. 인터넷 모델이라고도 한다.

캡슐화와 역캡슐화가 무엇인가요?

	캡슐화는 상위 계층의 프로토콜 정보를 데이터에 추가하여 하위 계층으로 전송하는 기술이고,

	역캡슐화는 상위 계층의 프로토콜에서 하위 계층에서 추가된 정보와 데이터 사이를 분리하는 기술이다.
```
