# 리액트 폼 개념

## **폼과 리액트의 상태(State)**

```jsx
폼은 리액트의 state와 연관이 있으며, 폼을 다루는 방식은 리액트의 state 관리 방법과 연관이 있다.
```

## **리액트에서의 상태 관리 필요성**

```jsx
일반적인 JavaScript에서는 폼은 사용자 입력에 따라 데이터를 추적하고 제출할 때 작업을 수행한다.

리액트에서는 컴포넌트 안에 상태를 두어 폼의 내용을 관리하고 사용자 입력에 따른 반응을 처리한다.

( 반응에 따라 계속 실시간으로값을 바꾸고 다시 렌더링 한다 )
```

## **제어 컴포넌트(Controlled Component)**

```jsx
리액트에서는 제어 컴포넌트를 만들어 사용자 입력에 따라 컴포넌트의 state를 업데이트한다.

이를 통해 폼의 내용을 완벽하게 제어하고, 리액트가 폼의 상태를 관리한다.
```

# **예제를 통한 제어 컴포넌트 구현**

```jsx
UsernameForm이라는 새로운 컴포넌트를 만들어 사용자명을 입력받는 폼을 구현한다

useState를 사용하여 username이라는 state를 초기화하고, 이를 이용해 폼의 입력 값을 제어한다.
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381423/notion-blog/_/The_Web_Developer_2022/REACT/_/Untitled.png)

```jsx
import { useState } from 'react'
function UsernameForm() {
  const [username, setUsername] = useState('dongk')
  const updateUsername = (e) => {
    setUsername(e.target.value)
  }

  return (
    <div>
      <input type="text" placeholder="username" value={username} onChange={updateUsername} />
      <button>Submit</button>
    </div>
  )
}

export default UsernameForm
```

## **onChange 이벤트와 업데이트 함수**

```jsx
사용자가 입력할 때마다 onChange 이벤트가 발생하며, 해당 이벤트에서 updateUsername 함수를 호출한다.

updateUsername 함수는 이벤트 객체를 통해 사용자의 입력을 읽고, 이를 username state에 업데이트한다.
```

## **제어 컴포넌트의 동작 원리**

```jsx
제어 컴포넌트는 사용자가 입력하면 즉시 해당 내용을 리액트의 state에 반영하고, 이로 인해 컴포넌트가 다시 렌더링된다.

중간 단계에서 state의 업데이트가 발생하므로, 폼의 내용은 언제든지 리액트의 state와 동기화된다.

**제어 컴포넌트의 장점**

언제든지 컴포넌트 내에서 state를 확인하면 폼의 내용을 알 수 있으며, 별도의 선택 또는 검색이 필요하지 않다.

제어 컴포넌트를 사용함으로써 리액트가 폼을 효과적으로 제어하고, 제출 시 state에서 필요한 데이터를 쉽게 추출할 수 있다.
```

# 더 효율적인 입력폼

```jsx
이전에는 각 폼 필드에 대한 state 조각과 업데이트 함수를 개별적으로 만드는 방법을 배웠다.

그러나 이 방법은 복잡하고 비효율적일 수 있다. 대신, 객체에 폼 데이터를 저장하고 범용적인 handleChange 함수를 활용하는 방법이 있다.
```

```jsx
위 코드에서는 모든 폼 데이터를 하나의 객체에 저장하고(formData), 범용적인 handleChange 함수를 활용하여 간단하게 데이터를 업데이트 한다
```

```jsx
import { useState } from 'react'
function BetterSignUpForm() {
  // formData는 현재의 폼 데이터를 담고 있는 객체이며, 초기값은 빈 문자열을 가진 firstName, lastName, password 세 가지 필드를 가진 객체
  const [formData, setFormData] = useState({ firstName: '', lastName: '', password: '' })
  const handleSubmit = () => {
    console.log(formData)
  }

  const handleChange = (evt) => {
    const changeField = evt.target.name
    const newValue = evt.target.value
    setFormData((currData) => {
      currData[changeField] = newValue
      return { ...currData }
    })
  }

  return (
    <div>
      <label htmlFor="firstName">First Name</label>
      <input
        type="text"
        placeholder="firstName"
        value={formData.firstName}
        onChange={handleChange}
        id="firstName"
        name="firstName"
      />
      <button onClick={handleSubmit}>Submit</button>

      <label htmlFor="lastName">Last Name</label>
      <input
        type="text"
        placeholder="lastName"
        value={formData.lastName}
        onChange={handleChange}
        id="lastName"
        name="lastName"
      />
      <button onClick={handleSubmit}>Submit</button>

      <label htmlFor="password">Password</label>
      <input
        type="password"
        placeholder="password"
        value={formData.password}
        onChange={handleChange}
        id="password"
        name="password"
      />
      <button onClick={handleSubmit}>Submit</button>
    </div>
  )
}
```

```jsx
const handleChange = (evt) => {
  const changeField = evt.target.name
  const newValue = evt.target.value

    currData[changeField] = newValue

```

```jsx
폼 데이터의 모든 필드는 state 객체에 정확히 일치하는 name 속성을 가져야 하며, ( 이 함수에게 업데이트할 state의 필드를 알려주는 부분이기 때문 )

handleChange 함수를 통해 이 필드들을 업데이트할 수 있다.

evt 는 현재 이벤트가 발생하는 입력란이고

evt 의 name 과 value 를 가져와서 각각 필드에 저장하고

아래의 setFormData 에서 currData = 현재 상태값

새로운 상태의 값 currData[changeField] = newValue; 전달

return {...currData}: 변경된 상태를 복사하여 반환한다.

상태를 직접 수정하지 않고 복사하여 새로운 상태를 만들어 리턴함으로써 리액트가 상태의 변경을 감지할 수 있도록 한다.
```

# **계산된 프로퍼티 이름 구문**

```jsx
계산된 프로퍼티 이름"은 JavaScript에서 객체의 프로퍼티 이름을 동적으로 결정하는 방법이다.

예를 들어, 특정 변수의 값을 프로퍼티 이름으로 사용할 수 있다.

변수를 키로 사용할 때 대괄호로 감싸는 방식(object[mystery])을 사용한다.
```

## **계산된 프로퍼티 이름 활용 예시:**

```jsx
변수 mystery를 활용하여 객체를 업데이트하는 예시를 살펴보자

object[mystery] = "Eggs"와 같이 사용하여 객체의 특정 키에 동적으로 값을 할당할 수 있다.
```

```jsx
const mystery = 'chicken'
const obj = {
  a: 1,
  blue: 4,
}

// 기존 방식
obj[mystery] = 'Eggs' // 변수의 이름이 동적으로 위에서 chicken 으로 되어있으니 chicken : Eggs 로 객체에 들어감
// 결과: { a: 1, blue: 4, chicken: "Eggs" }
```

## **React에서의 계산된 프로퍼티 이름 활용:**

```jsx
React 이벤트 핸들러 함수(handleChange)에서 계산된 프로퍼티 이름을 사용하여 state를 업데이트하는 방법을 알아본다

예제에서는 changedField를 활용하여 동적으로 state를 업데이트하고, 계산된 프로퍼티 이름 구문을 사용하여 코드를 더 간결하게 만든다.
```

```jsx

	  const handleChange = (evt) => {
        const changeField = evt.target.name;
        const newValue = evt.target.value;

            currData[changeField] = newValue;

	 const handleChange = (evt) => {

        })
    }

// 이렇게 되면 changeField 에 firstName,lastName,password 각각의 필드 가 들어오고 newValue 로 값 대입
```

```jsx
import { useState } from 'react'
import { v4 as uuid } from 'uuid'
import ShoppingListForm from './ShoppingListForm'
function ShoppingList() {
  const [item, setItem] = useState([
    { id: uuid(), product: 'Bananas', quantity: 8 },
    { id: uuid(), product: 'Egg', quantity: 12 },
  ])
  const addItem = (item) => {
    setItem((currItems) => {
      return [...currItems, { ...item, id: uuid() }]
    })
  }
  return (
    <div>
      <h1>ShoppingList</h1>
      <ul>
        {item.map((i) => (
          <li key={i.id}>
            {i.product}-{i.quantity}
          </li>
        ))}
      </ul>
      <ShoppingListForm addItem={addItem} />
    </div>
  )
}

export default ShoppingList
```

## **ShoppingListForm.jsx**

```jsx
import { useState } from 'react'
function ShoppingListForm({ addItem }) {
  const [formData, setFormData] = useState({ product: '', quantity: 0 })
  const handleChange = (evt) => {
    setFormData((currData) => {
      return {
        ...currData,
        [evt.target.name]: evt.target.value,
      }
    })
  }
  const handleSubmit = (e) => {
    e.preventDefault()
    console.log('submit')
    addItem(formData)
    setFormData({ product: '', quantity: 0 }) // 폼 제출 후 입력란 비우기
  }

  return (
    <form onSubmit={handleSubmit}>
      <h1>
        Product is : {formData.product} and quantity is : {formData.quantity}
      </h1>
      <label htmlFor="product">Product Name</label>
      <input
        type="text"
        placeholder="product name"
        name="product"
        id="product"
        onChange={handleChange}
        value={formData.product}
      />

      <label htmlFor="quantity">Quantity</label>
      <input
        type="number"
        placeholder="1"
        name="quantity"
        id="quantity"
        onChange={handleChange}
        value={formData.quantity}
      />
      <button>AddItem</button>
    </form>
  )
}

export default ShoppingListForm
```

```jsx
handleChange 함수는 input 요소의 값이 변경될 때 호출된다.

setFormData를 사용하여 현재 formData를 복사하고, 변경된 필드의 값을 업데이트한다.

**setFormData(currData => {...}**: setFormData 함수의 인자로 이전 상태(currData)를 받아오는 함수를 전달한다.

**{...currData,[evt.target.name]: evt.target.value,}**: 전개 연산자(...)를 사용하여 이전 상태를 복사하고,

				                                            변경된 필드(evt.target.name)의 값을 업데이트한다.
```

### **handleSubmit 함수 정의:**

```jsx
const handleSubmit = (e) => {
  e.preventDefault()
  console.log('submit')
  addItem(formData)
  setFormData({ product: '', quantity: 0 }) // 폼 제출 후 입력란 비우기
}
```

```jsx
handleSubmit 함수는 폼이 제출될 때 호출된다. ( 사용자가 폼 안에 있는 "AddItem" 버튼을 클릭하면 onSubmit 이벤트가 발생 )

e.preventDefault()를 사용하여 폼의 기본 동작(페이지 새로고침)을 방지한다.

"submit"이라는 콘솔 로그를 출력하고, addItem 함수를 호출하여 현재 formData를 부모 컴포넌트로 전달한다.
```

### **폼 렌더링:**


```jsx
onSubmit 이벤트에 handleSubmit 함수를 등록하여 폼이 제출될 때 해당 함수가 호출되도록 한다.

입력값과 현재 formData 값을 표시하는 <h1> 요소와 두 개의 입력 필드가 있다.

"AddItem"이라는 텍스트를 가진 버튼이 있으며, 이 버튼을 클릭하면 handleSubmit 함수가 호출된다.
```

# 직접 작성하는 폼 유효성 검사

```jsx
리액트 에서 유효성 검사를 직접 실시하려면 상당히 어려운 점이 많다

이 때문에 대부분 라이브러리를 사용하고 있다

아래를 보면 validate 때문에 state 를 만들고 함수를 만들어서 에러 글자가 표시되게 해주고 있다

여기서 state 의 동작 원리 때문에 state 가 변한다고 바로 글자가 변하는게 아니여서 두 글자를 써야지만 에러가 출력되서

더 복잡한 방법으로 코드를 작성했다 + 버튼에 disable 을 사용하는 방법을 사용해봤다
```

```jsx
import { useState } from 'react'
function ValidatedShoppingListForm({ addItem }) {
  const [formData, setFormData] = useState({ product: '', quantity: 0 })
  const [productIsValid, setProductIsValid] = useState(false)

  const validate = (product) => {
    if (product.length === 0) {
      setProductIsValid(false)
    } else {
      setProductIsValid(true)
    }
  }

  const handleChange = (evt) => {
    if (evt.target.name === 'product') {
      validate(evt.target.value)
    }
    setFormData((currData) => {
      return {
        ...currData,
        [evt.target.name]: evt.target.value,
      }
    })
  }
  const handleSubmit = (e) => {
    e.preventDefault()
    if (productIsValid) {
      console.log('submit')
      addItem(formData)
      setFormData({ product: '', quantity: 0 }) // 폼 제출 후 입력란 비우기
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <h1>
        Product is : {formData.product} and quantity is : {formData.quantity}
      </h1>
      <label htmlFor="product">Product Name</label>
      <input
        type="text"
        placeholder="product name"
        name="product"
        id="product"
        onChange={handleChange}
        value={formData.product}
      />

      {!productIsValid && <p style={{ color: 'red' }}>Product name cannot be empty</p>}

      <label htmlFor="quantity">Quantity</label>
      <input
        type="number"
        placeholder="1"
        name="quantity"
        id="quantity"
        onChange={handleChange}
        value={formData.quantity}
      />
      <button disabled={!productIsValid}>AddItem</button>
    </form>
  )
}

export default ValidatedShoppingListForm
```

```jsx
import { useForm } from 'react-hook-form'

// FormDemo 컴포넌트 정의
export default function FormDemo() {
  // react-hook-form 라이브러리의 useForm 훅을 사용하여 폼 상태를 관리
  const {
    register, // input 요소를 등록하는 함수
    handleSubmit, // 폼 제출을 처리하는 함수
    formState: { errors }, // 폼 에러 상태를 가져오는 객체
  } = useForm({ mode: 'onChange' }) // 폼의 모드를 설정하여 입력값이 변경될 때마다 유효성을 검사하도록 함

  // 폼 제출 시 실행되는 함수
  const handleRegistration = (formData) => {
    console.log('FORM SUBMITTED')
    console.log(formData)
  }

  // 폼 유효성 검사 에러 시 실행되는 함수
  const handleError = (errors) => {}

  // 입력 필드에 대한 유효성 검사 규칙 정의
  const registerOptions = {
    name: { required: 'Name cannot be blank' },
    email: { required: 'Email cannot be blank' },
    password: {
      required: 'Password is required',
      minLength: {
        value: 10,
        message: 'Password must be at least 10 characters',
      },
    },
    quantity: {
      required: 'Quantity is required',
      min: {
        value: 0,
        message: 'Quantity must be greater than 0',
      },
      max: {
        value: 10,
        message: 'Quantity must be less than 10',
      },
    },
  }

  // 폼 컴포넌트 렌더링
  return (
    <form onSubmit={handleSubmit(handleRegistration, handleError)}>
      {/* 이름 입력 필드 */}
      <div>
        <label>Name</label>
        <input
          name="name"
          type="text"
          {...register('name', registerOptions.name)} // 이름 필드에 대한 유효성 검사 규칙 적용
        />
        <small className="text-danger">
          {errors?.name && errors.name.message} {/* 이름 필드의 유효성 검사 에러 메시지 표시 */}
        </small>
      </div>

      {/* 이메일 입력 필드 */}
      <div>
        <label>Email</label>
        <input
          type="email"
          name="email"
          {...register('email', registerOptions.email)} // 이메일 필드에 대한 유효성 검사 규칙 적용
        />
        <small className="text-danger">
          {errors?.email && errors.email.message} {/* 이메일 필드의 유효성 검사 에러 메시지 표시 */}
        </small>
      </div>

      {/* 패스워드 입력 필드 */}
      <div>
        <label>Password</label>
        <input
          type="password"
          name="password"
          {...register('password', registerOptions.password)} // 패스워드 필드에 대한 유효성 검사 규칙 적용
        />
        <small className="text-danger">
          {errors?.password && errors.password.message}{' '}
          {/* 패스워드 필드의 유효성 검사 에러 메시지 표시 */}
        </small>
      </div>

      {/* 수량 입력 필드 */}
      <div>
        <label>Quantity</label>
        <input
          type="number"
          name="quantity"
          {...register('quantity', registerOptions.quantity)} // 수량 필드에 대한 유효성 검사 규칙 적용
        />
        <small className="text-danger">
          {errors?.quantity && errors.quantity.message}{' '}
          {/* 수량 필드의 유효성 검사 에러 메시지 표시 */}
        </small>
      </div>

      {/* 제출 버튼 */}
      <button>Submit</button>
    </form>
  )
}
```
