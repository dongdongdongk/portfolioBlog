- 수학의 행렬과 같은 구조로 가로와 세로로 표가 만들어진다고 생각하자.

![Untitled](<24%20%EC%9E%90%EB%B0%94%20%EB%B0%B0%EC%97%B4(3)/Untitled%201.png>)

- 실제로 자바가 표와 같은 형태로 2차원 행렬 데이터를 저장하지는 않는다. 1차원 배열이 다시 1차원 배열을 참조하는 방식으로 2차배열을 만든다.
- int[][] score = new int[2][3] 에서; [2] 가 행 [3] 가 열이다.

![Untitled](<24%20%EC%9E%90%EB%B0%94%20%EB%B0%B0%EC%97%B4(3)/Untitled%202.png>)

```xml
scores.length //2(배열 A의 길이)
scores[0].length //3(배열 B의 길이)
scores[1].length //3(배열 C의 길이)

```

scores의 length값을 구하면 처음 행의 길이(2)를 구하게 되지만 scores[0], scores[1]의 길이는 그 행이 참조하고 있는 열의 길이(3)를 구하게 된다.

자바는 1차원 배열을 연결하여 다차원 배열을 만들기 때문에 행렬 구조가 아니라 계단식 구조도 만들 수 있다.

```java
int[][] scores = new int[2][]; //처음엔 행 수만을 입력하고 열의 값을 비워둔다.
scores[0] = new int[2];  // 0번 째 인덱스에 2칸의 행렬을 대입한다
scores[1] = new int[3];   //1번 째 인덱스에 3칸의 행렬을 대입한다
```

모양의 행렬이 만들어 진다.

![Untitled](<24%20%EC%9E%90%EB%B0%94%20%EB%B0%B0%EC%97%B4(3)/Untitled%203.png>)

scores.length; // 2 (배열 A의 길이)

scores[0].length; // 2 (배열 B의 길이)

scores[1].length; // 3 (배열 C의 길이)

### **계단형 배열에서 주의할 점**

- 배열의 길이를 알고 인덱스를 사용해야 한다!

**scores[0][2]**;   // **ArrayIndexOutOfBoundsException 발생**

배열 B 의 객체의 마지막 인덱스는 1이기 때문이다.

scores[1][2]는 배열 C 객체의 세 번째 항목을 가리킨다.

#int score = new int[2][3] 과 score[0][2] 를 헷갈리지 말자 앞은 배열 인덱스를 설정 해주는거고 뒤는 배열의 위치를 찾아 가는 것
