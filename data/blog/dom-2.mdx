# **Document란?**

```jsx
Document(문서) 는 웹페이지에서 사용되는 용어 중 하나로, HTML 문서의 구조와 내용을 표현하는 객체이다.

JavaScript에서는 웹페이지의 문서 구조를 동적으로 조작할 수 있는 API를 제공하는데, 이를 "DOM(Document Object Model)"이라고 한다.
```

```jsx
정의: Document는 웹페이지의 전체 구조를 나타내며, HTML 문서의 모든 요소에 대한 트리 구조를 형성한다.

표현: DOM은 문서를 트리 구조로 표현하며, 각 HTML 요소는 트리의 노드로 표현된다.

제어: JavaScript를 사용하여 Document를 조작하면, 웹페이지의 내용이나 스타일 등을 동적으로 변경할 수 있다.
```

# getElementById

```jsx
getElementById는 Document 객체의 메서드 중 하나로, 주어진 ID 값과 일치하는 HTML 요소를 찾아 반환
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>getElementById 예제</title>
</head>
<body>

  <h1 id="myHeader">안녕하세요!</h1>

  <script>
    // getElementById를 사용하여 ID가 'myHeader'인 요소를 찾음
    const headerElement = document.getElementById('myHeader');

    // 찾은 요소의 내용을 변경
    headerElement.innerHTML = '반갑습니다!';
  </script>

</body>
</html>
```

# getElementsByTagName & className

## getElementsByTagName

```jsx
getElementsByTagName 메서드는 특정 HTML 태그 이름을 가진 모든 요소를 선택한다.

반환되는 값은 HTMLCollection이며, 이는 유사한 배열 형태를 가지고 있다.
```

```jsx
!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>getElementsByTagName 예제</title>
</head>
<body>

  <ul>
    <li>사과</li>
    <li>바나나</li>
    <li>체리</li>
  </ul>

  <script>
    // ul 태그 아래에 있는 모든 li 태그를 선택
    const listItems = document.getElementsByTagName('li');

    // 선택된 모든 li 요소에 대해 반복
    for (const item of listItems) {
      console.log(item.textContent);
    }
  </script>

</body>
</html>
```

## getElementsByclassName

```jsx
className 속성은 HTML 요소의 클래스 이름을 나타낸다.

이 속성을 통해 클래스 이름을 읽거나 변경할 수 있다.
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>className 예제</title>
  <style>
    .highlight {
      color: red;
      font-weight: bold;
    }
  </style>
</head>
<body>

  <p id="myParagraph">이 문장은 일반적인 스타일을 가지고 있습니다.</p>

  <script>
    // id가 'myParagraph'인 요소를 선택
    const paragraph = document.getElementById('myParagraph');

    // 클래스 이름 추가
    paragraph.className = 'highlight';
  </script>

</body>
</html>
```

## **주의사항**

```jsx
* getElementsByTagName의 반환 값은 HTMLCollection으로,

	배열과 유사하지만 배열이 아니다. 필요하다면 배열로 변환해야 한다.

* className을 사용하여 클래스를 변경하면 해당 요소의 기존 클래스가 모두 대체된다.

	클래스를 추가하거나 제거하려면 classList 속성을 사용하는 것이 더 안전하다.
```

```jsx
// className을 사용한 방법 (주의: 기존 클래스가 대체됨)
element.className = 'newClass'

// classList를 사용한 방법 (추가 및 제거가 용이함)
element.classList.add('newClass')
element.classList.remove('oldClass')
```

# querySelector & querySelectorAll

```jsx
querySelector와 querySelectorAll은 CSS 선택자를 사용하여 Document에서 요소를 선택하는 메서드다.

이 두 메서드는 특정 요소나 요소 집합을 선택하는 데 유용

(ID, 클래스 , 이름, 요소 모든걸 선택 가능)
```

## **`querySelector` 메서드**

```jsx
querySelector 메서드는 CSS 선택자를 사용하여 문서에서 첫 번째로 일치하는 요소를 반환
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>querySelector 예제</title>
</head>
<body>

  <div class="container">
    <p id="myParagraph">이 문장은 선택됩니다.</p>
  </div>

  <script>
    // CSS 선택자를 사용하여 id가 'myParagraph'인 요소를 선택
    const selectedElement = document.querySelector('#myParagraph');

    // 선택된 요소에 스타일을 적용
    selectedElement.style.color = 'red';
  </script>

</body>
</html>
```

### type 속성을 이용해서 선택하기

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>input[type] 선택 예제</title>
</head>
<body>

  <input type="text" id="username" placeholder="사용자명 입력">
  <input type="password" id="password" placeholder="비밀번호 입력">
  <input type="checkbox" id="rememberMe"> <label for="rememberMe">로그인 기억하기</label>
  <button id="loginButton">로그인</button>

  <script>
    // 쿼리 셀렉터를 사용하여 type이 'text'인 input 요소를 선택
    const textInput = document.querySelector('input[type="text"]');

    // 쿼리 셀렉터를 사용하여 type이 'password'인 input 요소를 선택
    const passwordInput = document.querySelector('input[type="password"]');

    // 쿼리 셀렉터를 사용하여 type이 'checkbox'인 input 요소를 선택
    const checkboxInput = document.querySelector('input[type="checkbox"]');

    // 쿼리 셀렉터를 사용하여 id가 'loginButton'인 button 요소를 선택
    const loginButton = document.querySelector('#loginButton');

    // 선택된 요소들에 이벤트 리스너를 추가하는 등의 동작을 수행할 수 있음
    loginButton.addEventListener('click', function() {
      // 예제에서는 간단하게 선택된 input 요소들의 값을 콘솔에 출력
      console.log('사용자명:', textInput.value);
      console.log('비밀번호:', passwordInput.value);
      console.log('기억하기 체크 여부:', checkboxInput.checked);
    });
  </script>

</body>
</html>
```

## **`querySelectorAll` 메서드**

```jsx
querySelectorAll 메서드는 CSS 선택자를 사용하여 문서에서 일치하는 모든 요소를 NodeList로 반환

( 최신 방법으로 요즘은 거의 이걸 사용 )
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>querySelectorAll 예제</title>
</head>
<body>

  <ul>
    <li class="fruit">사과</li>
    <li class="fruit">바나나</li>
    <li class="fruit">체리</li>
  </ul>

  <script>
    // CSS 선택자를 사용하여 클래스가 'fruit'인 모든 li 요소를 선택
    const selectedElements = document.querySelectorAll('li.fruit');

    // 선택된 모든 요소에 스타일을 적용
    selectedElements.forEach(element => {
      element.style.color = 'green';
    });
  </script>

</body>
</html>
```

## **주의사항**

```jsx
* querySelector와 querySelectorAll은 모든 최신 브라우저에서 지원되지만,

	오래된 버전의 Internet Explorer에서는 일부 기능이 제한될 수 있다.

* 반환된 값은 NodeList이며, 배열과 유사하지만 배열이 아니다. 필요한 경우 배열로 변환해야 할 수 있다.
```

# **`innerHTML`**, **`textContent`**, 그리고 **`innerText`**

## **`innerHTML`**

```jsx
innerHTML 속성은 HTML 요소의 내용을 나타내며, 해당 요소의 자식 요소들을 포함한 모든 HTML 태그와 텍스트를 문자열로 반환한다.

또한, innerHTML을 통해 HTML 코드를 삽입하거나 변경할 수 있다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>innerHTML 예제</title>
</head>
<body>

  <div id="myDiv">현재 내용: <span>안녕하세요</span></div>

  <script>
    // id가 'myDiv'인 요소의 innerHTML 변경
    const myDiv = document.getElementById('myDiv');
    myDiv.innerHTML = '새로운 내용: <strong>안녕하세요</strong>';
  </script>

</body>
</html>
```

## **`textContent`**

```jsx
textContent 속성은 HTML 요소의 내용을 나타내며, 해당 요소의 모든 텍스트 내용을 문자열로 반환

 HTML 태그는 모두 무시하고 텍스트만을 가져온다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>textContent 예제</title>
</head>
<body>

  <div id="myDiv">현재 내용: <span>안녕하세요</span></div>

  <script>
    // id가 'myDiv'인 요소의 textContent 변경
    const myDiv = document.getElementById('myDiv');
    myDiv.textContent = '새로운 내용: 안녕하세요';
  </script>

</body>
</html>
```

## **`innerText`**

```jsx
innerText 속성은 HTML 요소의 내용을 나타내며, 해당 요소의 텍스트 내용을 문자열로 반환

innerText는 텍스트를 렌더링되는 방식에 영향을 받으며, CSS에 의해 숨겨진 텍스트를 반환하지 않는다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>innerText 예제</title>
  <style>
    .hidden {
      display: none;
    }
  </style>
</head>
<body>

  <div id="myDiv">현재 내용: <span class="hidden">숨겨진 텍스트</span></div>

  <script>
    // id가 'myDiv'인 요소의 innerText 변경
    const myDiv = document.getElementById('myDiv');
    myDiv.innerText = '새로운 내용: 숨겨진 텍스트';
  </script>

</body>
</html>
```

## **주의사항**

```jsx
* innerHTML은 HTML 코드를 포함한 문자열로 작동하므로, 주입된 HTML 코드에 대한 보안 고려가 필요하다

	사용자 입력이 들어가는 경우 주의가 필요

* textContent와 innerText는 모든 HTML 태그를 무시하고 텍스트만을 다루므로, 일반적으로 textContent를 선호한다

*	innerText는 CSS에 의해 숨겨진 텍스트를 가져오지 않으므로 주의가 필요
```

# **`getAttribute`**와 **`setAttribute`**

```jsx
JavaScript에서 HTML 요소의 속성(attribute)을 조작하기 위한 메서드들
```

## **`getAttribute` 메서드**

```jsx
getAttribute 메서드는 특정 HTML 요소의 속성 값을 반환합니다. 이 메서드를 사용하여 요소의 속성 값을 읽을 수 있다
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>getAttribute 예제</title>
</head>
<body>

  <a href="https://www.example.com" id="myLink">링크</a>

  <script>
    // id가 'myLink'인 링크 요소의 href 속성 값을 얻음
    const link = document.getElementById('myLink');
    const hrefValue = link.getAttribute('href');
    console.log(hrefValue); // 출력: 'https://www.example.com'
  </script>

</body>
</html>
```

## **`setAttribute` 메서드**

```jsx
setAttribute 메서드는 특정 HTML 요소의 속성 값을 설정하거나 새로운 속성을 추가
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>setAttribute 예제</title>
</head>
<body>

  <button id="myButton">클릭하세요</button>

  <script>
    // id가 'myButton'인 버튼 요소에 새로운 속성을 추가
    const button = document.getElementById('myButton');
    button.setAttribute('data-action', 'click'); // 속성 이름은 data-action , 속성 내용은 click
  </script>

</body>
</html>
```

## **주의사항**

```jsx
* getAttribute는 특정 속성의 값을 반환하며, 속성이 존재하지 않으면 null을 반환

* setAttribute를 사용하여 속성을 설정할 때, 속성이 이미 존재하면 값을 변경하고, 없으면 새로운 속성을 추가

* 주로 getAttribute는 HTML 요소의 기존 속성 값을 읽어오는 데 사용되고, setAttribute는 동적으로 속성을 추가하거나 변경하는 데 사용
```

```jsx
// id가 'myElement'인 요소의 'data-custom' 속성 값을 얻음
const customValue = document.getElementById('myElement').getAttribute('data-custom')

// id가 'myElement'인 요소의 'data-custom' 속성 값을 설정 또는 변경
document.getElementById('myElement').setAttribute('data-custom', 'new-value')
```

## **주의사항**

```jsx
* dataset은 data-* 형식의 사용자 정의 데이터 속성을 편리하게 다룰 수 있는 방법이다.

* 속성 객체를 사용할 때에는 주의해서 사용해야 하며, 존재하지 않는 속성에 접근하면 에러가 발생할 수 있다.
```

# 자바스크립트 스타일 변경하기

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>스타일 변경 예제</title>

    #myBox {
      width: 100px;
      height: 100px;
      background-color: blue;
      color: white;
      text-align: center;
      line-height: 100px;
      cursor: pointer;
    }
  </style>

  <div id="myBox">클릭하세요</div>

  <script>
    // id가 'myBox'인 요소를 선택
    const myBox = document.getElementById('myBox');

    // 선택된 요소에 클릭 이벤트 리스너 추가
    myBox.addEventListener('click', function() {
      // 스타일 변경
      myBox.style.backgroundColor = 'red';
      myBox.style.color = 'black';
      myBox.style.width = '150px';
    });
  </script>

</body>
</html>
```

# **classList**

```jsx
classList를 사용하면 클래스를 추가, 제거, 토글할 수 있어서 JavaScript에서 동적으로 요소의 클래스를 조작하는 데 유용
```

```jsx
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>classList 예제</title>
  <style>
    .highlight {
      background-color: yellow;
    }
  </style>
</head>
<body>

  <div id="myElement">이 요소를 클릭하세요</div>

  <script>
    // id가 'myElement'인 요소를 선택
    const myElement = document.getElementById('myElement');

    // 선택된 요소에 클릭 이벤트 리스너 추가
    myElement.addEventListener('click', function() {
      // 'highlight' 클래스를 추가
      myElement.classList.add('highlight');

      // 일정 시간 후에 'highlight' 클래스를 제거 (토글)
      setTimeout(function() {
        myElement.classList.remove('highlight');
      }, 1000);
    });
  </script>

</body>
</html>
```

## classList 의 대표적인 메서드

### **`add(className1, className2, ...)`**

```jsx
클래스를 요소의 클래스 목록에 추가

여러 개의 클래스를 동시에 추가할 수 있다.
```

```jsx
element.classList.add('highlight', 'italic')
```

### **`remove(className1, className2, ...)`**

```jsx
클래스를 요소의 클래스 목록에서 제거

여러 개의 클래스를 동시에 제거할 수 있다.
```

```jsx
element.classList.remove('highlight', 'italic')
```

### **`toggle(className, force)`**

```jsx
클래스를 요소의 클래스 목록에서 토글합니다.

force 매개변수를 사용하여 특정 클래스를 강제로 추가 또는 제거할 수 있다.
```

```jsx
element.classList.toggle('highlight') // 토글
element.classList.toggle('italic', true) // 강제로 추가
element.classList.toggle('italic', false) // 강제로 제거
```

### **`contains(className)`**

```jsx
특정 클래스가 요소의 클래스 목록에 포함되어 있는지 확인

true 또는 false 값을 반환
```

```jsx
const hasHighlightClass = element.classList.contains('highlight')
```

### **`replace(oldClassName, newClassName)`**

```jsx
특정 클래스를 다른 클래스로 교체

기존 클래스가 없으면 새 클래스를 추가하고,

기존 클래스가 있으면 기존 클래스를 제거하고 새 클래스를 추가
```

```jsx
element.classList.replace('oldClass', 'newClass')
```

# **`append`**와 **`appendChild`**

```jsx
DOM에서 요소를 다른 요소에 추가할 때 사용되는 메서드
```

## **`append` 메서드**

```jsx
append 메서드는 하나 이상의 노드 또는 문자열을 특정 부모 요소의 자식으로 추가

이 메서드는 여러 개의 인수를 받을 수 있다
```

```jsx
parentElement.append(child1, child2, ..., childN);
```

```jsx
const parentDiv = document.getElementById('parent')

const childElement1 = document.createElement('div')
childElement1.textContent = '첫 번째 자식'

const childElement2 = document.createElement('div')
childElement2.textContent = '두 번째 자식'

parentDiv.append(childElement1, childElement2)
```

## **`appendChild` 메서드**

```jsx
appendChild 메서드는 하나의 노드를 특정 부모 요소의 자식으로 추가
```

```jsx
parentElement.appendChild(childNode)
```

```jsx
const parentDiv = document.getElementById('parent')

const childElement1 = document.createElement('div')
childElement1.textContent = '첫 번째 자식'

const childElement2 = document.createElement('div')
childElement2.textContent = '두 번째 자식'

parentDiv.appendChild(childElement1)
parentDiv.appendChild(childElement2)
```

## **차이점**

```jsx
* append는 여러 개의 인수를 받을 수 있고, 각각의 인수를 부모 요소에 추가

* appendChild는 하나의 노드만을 부모 요소에 추가

append는 여러 개의 요소를 한 번에 추가하는 데 편리하며, appendChild는 하나의 요소를 추가할 때 사용
```

# **prepend**

```jsx
지정된 부모 노드의 맨 앞에 하나 이상의 자식 노드 또는 텍스트 노드를 추가

이를 통해 새로운 노드를 부모 노드의 맨 앞에 추가할 수 있다.
```

```jsx
// 새로운 div 요소를 생성
const newDiv = document.createElement('div')
newDiv.textContent = '안녕하세요!'

// 새로운 span 요소를 생성
const newSpan = document.createElement('span')
newSpan.textContent = '이것은 새로운 요소입니다.'

// 문서의 특정 부모 요소를 선택
const parentElement = document.getElementById('parent')

// prepend 메서드를 사용하여 부모 요소의 맨 앞에 요소 추가
parentElement.prepend(newDiv, newSpan)
```

# **createElement**

```jsx
DOM(Document Object Model)에서 새로운 HTML 요소를 생성하는 JavaScript의 메서드
```

```jsx
// 새로운 div 요소를 생성
const newDiv = document.createElement('div')

// 생성된 div에 텍스트 내용 설정
newDiv.textContent = '안녕하세요!'

// 생성된 div에 클래스 추가
newDiv.classList.add('example-class')

// 생성된 div를 문서의 특정 부모 요소에 추가
const parentElement = document.getElementById('parent')
parentElement.appendChild(newDiv)
```

```jsx
이러한 방식으로 createElement를 사용하면 JavaScript로 동적인 HTML 요소를 생성하고 조작할 수 있다.

 이는 특히 웹 페이지가 로드된 후에 동적으로 콘텐츠를 추가하거나 업데이트해야 할 때 유용
```

# **`remove`**와 **`removeChild`**

```jsx
remove는 자체적으로 호출 가능한 메서드이며, removeChild는 특정 부모에서 특정 자식을 제거할 때 사용
```

## **`remove` 메서드**

```jsx
remove 메서드는 자바스크립트로 선택된 요소를 DOM에서 완전히 제거 이 메서드를 호출하면 요소가 삭제되고 메모리에서도 해제
```

## **`removeChild` 메서드**

```jsx
removeChild 메서드는 부모 노드에서 자식 노드를 제거합니다. 이 메서드는 제거할 자식 노드를 명시적으로 지정
```

```jsx
<div id="parent">
  <div id="child">제거될 요소</div>
</div>

JavaScript:

// remove 메서드 사용
const elementToRemove = document.getElementById('child');
elementToRemove.remove();

// removeChild 메서드 사용
const parentElement = document.getElementById('parent');
const childElement = document.getElementById('child');
parentElement.removeChild(childElement);
```
