```python
파이썬에서 딕셔너리(dictionary)는 키(key)와 값(value) 쌍을 요소로 가지는 컬렉션 자료형이다.

딕셔너리는 중괄호 {} 또는 dict() 함수를 사용하여 생성할 수 있으며,

키는 딕셔너리 내에서 유일해야 하고, 값은 다양한 데이터 타입이 될 수 있다.

딕셔너리는 순서를 보장하지 않으며, 인덱스 대신 키를 사용하여 값을 조회하거나 수정한다.

( 사전 처럼 어떤 key 를 가지고 찾는것 )
```

```python
# 중괄호 {}를 사용한 딕셔너리 생성
my_dict = {'name': 'John', 'age': 30, 'city': 'New York'}

# dict() 함수를 사용한 딕셔너리 생성
my_dict2 = dict(name='Alice', age=25, city='Los Angeles')

print(my_dict)  # 출력: {'name': 'John', 'age': 30, 'city': 'New York'}
print(my_dict2) # 출력: {'name': 'Alice', 'age': 25, 'city': 'Los Angeles'}
```

# **요소 접근 및 수정**

```python
딕셔너리의 요소에 접근하거나 수정할 때는 키를 사용한다.
```

```python
# 요소 접근
print(my_dict['name'])  # 출력: John

# 요소 수정
my_dict['age'] = 31
print(my_dict)  # 출력: {'name': 'John', 'age': 31, 'city': 'New York'}
```

# **요소 추가 및 삭제**

```python
딕셔너리에 새로운 요소를 추가하거나 기존 요소를 삭제할 수 있다.
```

```python
# 요소 추가
my_dict['email'] = 'john@example.com'
print(my_dict)  # 출력: {'name': 'John', 'age': 31, 'city': 'New York', 'email': 'john@example.com'}

# 요소 삭제
del my_dict['email']
print(my_dict)  # 출력: {'name': 'John', 'age': 31, 'city': 'New York'}

# pop 메소드를 사용한 요소 삭제
age = my_dict.pop('age')
print(age)  # 출력: 31
print(my_dict)  # 출력: {'name': 'John', 'city': 'New York'}
```

# **딕셔너리 순회**

```python
딕셔너리의 키나 값을 순회할 수 있다.
```

```python
# 모든 키 출력
for key in my_dict:
    print(key)  # 출력: name, city

# 모든 값 출력
for value in my_dict.values():
    print(value)  # 출력: John, New York

# 키와 값 모두 출력
for key, value in my_dict.items():
    print(key, value)  # 출력: name John, city New York
```

# **리스트와의 차이점**

```python
**변경 가능성**: 리스트는 요소의 추가, 삭제, 수정이 가능하지만, 딕셔너리도 마찬가지이다.

그러나 딕셔너리의 키는 변경할 수 없다.

**정렬**: 리스트는 순서가 있는 반면, 딕셔너리는 Python 3.7부터는 삽입 순서를 유지하지만, 그 이전 버전에서는 순서를 유지하지 않는다.

**인덱싱**: 리스트는 숫자 인덱스를 사용하여 요소에 접근하지만, 딕셔너리는 키를 사용하여 값에 접근한다.

딕셔너리는 데이터를 키와 값의 형태로 저장하여 빠르게 접근할 수 있게 해주는 유용한 자료형이다.

복잡한 데이터 구조를 표현할 때 매우 유용하게 사용된다.
```

# 딕셔너리 메서드

```python
딕셔너리 자료형을 다룰 때 자주 사용하는 몇 가지 중요한 메서드들을 소개
```

```python
# 딕셔너리 초기화
my_dict = {'name': 'John', 'age': 30, 'city': 'New York'}
```

## **`dict.get(key[, default])`:**

```python
주어진 키에 해당하는 값을 반환. 키가 딕셔너리에 없는 경우 default를 반환한다. default는 선택적 인자이며, 기본값은 None이다.
```

```python
# get 메서드 사용 예제
print(my_dict.get('name'))  # 출력: John
print(my_dict.get('job', 'No job specified'))  # 출력: No job specified
```

## **`dict.setdefault(key[, default])`:**

```python
딕셔너리에 키가 있으면 해당 값을 반환.

키가 없는 경우에는 default 값을 가진 키를 딕셔너리에 추가하고, default를 반환합니다. 여기서도 default는 선택적 인자이다.
```

```python
# setdefault 메서드 사용 예제
print(my_dict.setdefault('name', 'Unknown'))  # 출력: John
print(my_dict.setdefault('job', 'Engineer'))  # 출력: Engineer
print(my_dict)  # 출력: {'name': 'John', 'age': 30, 'city': 'New York', 'job': 'Engineer'}
```

## **`dict.keys()`:**

```python
딕셔너리의 모든 키를 담은 뷰(view)를 반환한다. 이 뷰는 딕셔너리의 키가 변경될 때 업데이트되는 동적인 뷰이다.
```

```python
# keys 메서드 사용 예제
print(my_dict.keys())  # 출력: dict_keys(['name', 'age', 'city', 'job'])
```

## **`dict.values()`:**

```python
딕셔너리의 모든 값을 담은 뷰를 반환한다. 이 뷰도 딕셔너리의 값이 변경될 때 업데이트된다.
```

```python
# values 메서드 사용 예제
print(my_dict.values())  # 출력: dict_values(['John', 30, 'New York', 'Engineer'])
```

## **`dict.items()`:**

```python
딕셔너리의 모든 키-값 쌍을 튜플로 묶은 뷰를 반환한다. 이 뷰는 딕셔너리가 변경될 때 업데이트된다.
```

```python
# items 메서드 사용 예제
print(my_dict.items())  # 출력: dict_items([('name', 'John'), ('age', 30), ('city', 'New York'), ('job', 'Engineer')])
```

## **`dict.update([other])`:**

```python
다른 딕셔너리 또는 키-값 쌍의 반복 가능한 객체로부터 키-값 쌍을 추가하거나 업데이트한다. 이미 존재하는 키의 값은 새 값으로 업데이트된다.
```

```python
# update 메서드 사용 예제
my_dict.update({'age': 31, 'city': 'Boston'})
print(my_dict)  # 출력: {'name': 'John', 'age': 31, 'city': 'Boston', 'job': 'Engineer'}
```

## **`dict.pop(key[, default])`:**

```python
주어진 키에 해당하는 항목을 제거하고, 그 값을 반환.

키가 딕셔너리에 없는 경우 default를 반환. 여기서도 default는 선택적 인자이며, 지정하지 않고 키가 없는 경우 KeyError가 발생한다.
```

```python
# pop 메서드 사용 예제
removed_value = my_dict.pop('job')
print(removed_value)  # 출력: Engineer
print(my_dict)  # 출력: {'name': 'John', 'age': 31, 'city': 'Boston'}
```

## **`dict.popitem()`:**

```python
딕셔너리에서 임의의 키-값 쌍을 제거하고, 해당 쌍을 튜플로 반환한다. 딕셔너리가 비어있는 경우 KeyError가 발생.
```

```python
# popitem 메서드 사용 예제
removed_item = my_dict.popitem()
print(removed_item)  # 출력: ('city', 'Boston')
print(my_dict)  # 출력: {'name': 'John', 'age': 31}
```

## **`dict.clear()`:**

```python
딕셔너리의 모든 항목을 제거
```

```python
# clear 메서드 사용 예제
my_dict.clear()
print(my_dict)  # 출력: {}
```

# 리스트 , 튜플, 딕셔너리 최종 정리

## 리스트(List)

```python
리스트는 순서가 있는 요소들의 집합이다.

요소의 추가, 삭제, 수정이 자유로워 데이터를 유동적으로 관리할 때 적합하다.

예시: 여러 종류의 과일 이름을 저장하거나, 할 일 목록을 관리할 때 사용한다.
```

## **튜플(Tuple)**

```python
튜플은 순서가 있는 요소들의 집합이지만, 한 번 생성되면 그 내용을 변경할 수 없다(불변).

데이터가 고정된 경우나 변경되지 않아야 하는 경우에 사용된다.

예시: 좌표 값이나 날짜 같이 변경되지 않아야 하는 데이터를 저장할 때 사용한다.
```

## **딕셔너리(Dictionary)**

```python
딕셔너리는 키(key)와 값(value)의 쌍으로 이루어진 데이터 구조이다.

키를 통해 빠르게 값을 검색할 수 있어, 데이터에 빠르게 접근해야 할 때 유용하다.

예시: 사람의 이름을 키로, 연락처를 값으로 저장하여 주소록을 만들 때 사용한다.
```

```python
요약하자면, 리스트는 요소의 추가, 삭제, 수정이 자주 일어나는 경우에 적합하고,

튜플은 변경되지 않는 데이터를 안전하게 저장할 때,

딕셔너리는 키를 통한 빠른 데이터 접근이 필요할 때 주로 사용한다.

각각의 특성을 잘 이해하고 상황에 맞게 선택하여 사용하는 것이 중요하다.
```
