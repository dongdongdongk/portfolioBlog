**객체 :** 물리적으로 존재하거나 (자동차) 추상적으로 생각할 수 있는 것(회사) 중에서 자신의 속성을 가지며 식별이 가능한 것

ex) 속성 : 자동차 - 동작 : 색깔 ,모델명
속성 : 회사 - 동작 : 설립년도, 대표이사 ,회사명

속성(필드 field) + 동작(메소드 method) 로 구성

**객체 모델링 :** 이런 식으로 현실 세계의 객체를 소프트 웨어인 자바로 설계 하는것을 객체 모델링 이라고 한다.

**객체 지향 프로그래밍** : 객체를 만들고 이를 조립해 완성된 프로그램을 만드는 기법
자바는 특히 현실 세계의 객체를 소프트 웨어로 만들수 있도록 잘 되어 있기 때문에 객체 지향 프로그램 이라고 불린다

이때 사용하는 게 메소드 이고 이렇게 객체가 다른 객체의 기능을 이용하는 걸 **메소드 호출** 이라고 한다.

```jsx

```

**객체 간의 관계**

**집합 관계** : 엔진 객체, 타이어 객체, 핸들 객체 를 결합하여 자동차 객체가 만들어 진다. 자동차와 이들의 관계는 부품과 완성품 즉 집합 관계 라고 한다.

**사용 관계** : 객체 간의 상호작용을 통해서 메소드를 호출해서 이용하는 관계 (사람과 자동차) 사람은 자동차의 메소드를 메소드 호출을 통해 사용한다.

**상속 관계** : 상위 객체 (기계 객체) 를 기반으로 하위 객체(자동차) 를 생성하는 것 이때 하위 개체 는 상위 개체의 속성을 물려받아 사용될 수 있다.

**1-1.** **클래스(Class)**

```java
public class Car {
    // 클래스 정의
}
```

- 객체를 생성하기 위해 객체의 필드와 메소드를 정의해 놓은 설계도.
- 클래스에 적용할 수 있는 접근 제한자는 public과 default 두 가지이다. (다른 패키지에서도 접근 가능하게 하려면 public을 붙이고, 같은 패키지 내에서만 접근 가능하게 하려면 default를 붙이거나 접근제한자를 생략한다.)
- 클래스는 2가지 용도가 있다.

**(1) 라이브러리(API: Application Program Interface)용**:

라이브러리 클래스는 다른 클래스에서 이용될 목적으로 설계된다.

**(2) 실행용**

실행 클래스는 프로그램의 실행 진입점인 main()메소드를 제공하는 역할을 한다.

**1-2. 객체(Object)**

```java
public class Car {
    // 클래스 정의

    // 객체 생성
    public static void main(String[] args) {
        Car myCar = new Car();
    }
}
```

클래스에 정의된 대로 메모리에 생성되며, 자신의 속성을 가지고 있고 다른 것과 식별되는 것이다.

객체는 속성과 동작으로 구성되며, 이것은 자바에서 필드와 메소드로 정의된다.

**1-3. 인스턴스(Instance)**

```java
public class Car {
    // 클래스 정의

    // 객체 생성과 인스턴스
    public static void main(String[] args) {
        Car myCar = new Car(); // myCar는 Car 클래스의 인스턴스입니다.
    }
}
```

클래스로부터 만들어진 객체를 해당 클래스의 인스턴스라고 말한다.

(인스턴스화 = 클래스로부터 객체를 만드는 과정)

**2**. **클래스의 구성 멤버**

클래스에는 객체가 가져야할 구성멤버(**필드, 생성자, 메소드**)가 선언된다.

**2-1.** **필드(field)**

```java
public class Car {
    // 필드
    private String brand; // 브랜드
    private String color; // 색상
    private int year; // 연도
}
```

- 객체의 데이터가 저장되는 곳
- 어떤 곳에서도 필드 선언이 가능하지만 생성자와 메소드 중괄호 블록 내부에는 선언될 수 없다. 그 안에 선언되면 모두 로컬 변수가 된다.
- 필드의 초기값은 필드 선언시 주어질 수도 있고, 생략될 수도 있다. 필드의 초기값이 생략되면 타입별 초기값으로 설정된다.

**2-2.** **생성자(constructor)**

```java
public class Car {
    // 필드

    // 생성자
    public Car(String brand, String color, int year) {
        this.brand = brand;
        this.color = color;
        this.year = year;
    }
}
```

- 인스턴스 생성시 new 연산자로 호출되는 중괄호 블록{ } 이다.
- 객체의 초기화 역할을 담당한다. 필드를 초기화하거나, 메소드를 호출해서 객체를 사용할 준비를 한다.
- 모든 클래스는 생성자가 반드시 존재하며 하나 이상을 가질 수 있다.
- 생성자에는 모든 접근 제한자를 적용할 수 있다.
- 명시적으로 생성자를 선언하는*(=생성자 오버로딩)* 이유는 객체를 다양하게 초기화하기 위해서이다.

**2-2-(1). new 연산자**

```java
public class Car {
    // 필드

    // 생성자

    public static void main(String[] args) {


		Car myCar = new Car(); // new 연산자를 사용하여 객체 생성
    }
}
```

new연산자에 의해 생성자가 성공적으로 실행되면, 힙 영역에 객체가 생성되고, 객체의 주소가 리턴된다. 메모리 내에서 생성된 객체의 위치를 모르면 객체를 사용할 수 없다. 그러므로 리턴된 주소를 참조타입인 클래스 변수에 저장하고, 해당 변수를 통해 객체를 사용할 수 있다.

클래스 변수 = new 클래스();

**2-2-(2). 기본생성자**

```java
public class Car {
    // 필드

    // 기본 생성자
    public Car() {
        // 생성자 코드
    }
}
```

- 클래스 내부에 생성자 선언을 생략하면, 컴파일러가 중괄호 { } 블록이 비어있는 기본 생성자를 바이트 코드에 자동 추가시킨다.
- 기본생성자의 접근제한자는 클래스의 접근제한자와 동일한 접근제한자(public 또는 default)가 적용된다.

**2-3. 메소드(method)**

```java
public class Car {
    // 필드

    // 생성자

    // 메소드
    public void startEngine() {
        // 메소드 코드
    }

    public void accelerate() {
        // 메소드 코드
    }

    public void brake() {
        // 메소드 코드
    }
}
```

- 객체의 동작에 해당하는 중괄호 실행 블록이다. 객체가 메소드 호출을 통해 다른 객체의 기능을 이용하며 상호작용하는 수단이다.

**3. 객체의 구성요소 (= 객체의 멤버)**

필드, 메서드

**3-1.** **필드(field)** = **멤버 변수(member variable)**

현실 세계 객체의 속성(property)에 해당

**3-2.** **메소드(method)**

현실 세계 객체의 기능(function)에 해당
