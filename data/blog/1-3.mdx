# **{ Wwise 프로젝트 처음 시작하기 }**

## 1단계: Wwise 실행하기

```csharp
1. Audiokinetic Launcher 열기

		Wwise를 설치하면 Audiokinetic Launcher라는 앱도 같이 설치됩니다.

		이 런처를 실행하세요.

2. Wwise 탭 선택하기

		왼쪽 메뉴에서 Wwise 탭을 클릭하세요.

		여기서 Wwise 애플리케이션을 실행할 수 있어요.

3. Wwise Project Launcher 열기

		Wwise가 실행되면 자동으로 Project Launcher 창이 열립니다.

		지금은 아직 프로젝트가 없기 때문에 아무 목록도 안 보일 수 있어요. 괜찮습니다!
```

## 2단계: 새 프로젝트 만들기

```csharp
1. New 버튼 클릭하기

		Project Launcher 창 왼쪽 아래에 있는 [New] 버튼을 클릭하세요.

2. 프로젝트 이름 정하기

		팝업 창에서 프로젝트 이름을 입력합니다.

		Wwise-101 Lesson 1 이라고 입력하세요.

3. 프로젝트 저장 위치 정하기

		아래쪽에 있는 Location 옆의 […] 버튼을 클릭하세요.

		Wwise-101 폴더 안의 Lesson 1 폴더를 선택합니다.
```

## 3단계: 에셋 가져오기 (Asset Import)

```csharp
프로젝트를 만들 때 불필요한 사운드 파일들이 자동으로 포함되지 않게 할 수 있어요.

1. Import Assets to Project 섹션에서 [Select None] 클릭

2. OK 버튼 클릭
```

# **{ 게임 프로파일링하기 }**

```csharp
Cube 게임에서 어떤 소리 이벤트가 발생하는지 확인하고, 이를 Wwise로 가져와 분석하는 것입니다.

즉, 게임 속에서 발생하는 소리 관련 정보(Event 등)를 Wwise에서 실시간으로 확인하고,

어떤 문제가 있는지 파악하는 훈련이에요.
```

## 1. 사운드 통합 전 준비사항

### ❓ 왜 Cube와 Wwise를 연결해야 하나요?

```csharp
게임이 소리를 내는 방식은 다음과 같습니다:

		1. 게임에서 어떤 일이 발생함 → (예: 캐릭터가 얼음 보석을 던짐)

		2. 게임이 Wwise에 **"나 지금 얼음 보석 던졌어!"**라고 알림 → Event 발생

		3. Wwise는 그 Event에 맞는 소리를 찾아서 재생

🎯 그런데, 지금 상태에서는 3번이 안 되고 있어요.

게임이 Wwise에 이벤트를 보내긴 하지만, Wwise는 그걸 어떻게 처리할지 모르는 상태예요.
```

## 2. 단계별 전체 흐름 설명

### 1단계: Cube 게임(프로파일러 버전) 실행

```csharp
Cube는 Wwise 학습용 게임입니다.

프로파일러 버전은 Wwise와 통신할 수 있도록 만든 특별한 버전입니다.

🔽 해야 할 일:

운영체제에 맞는 방법으로 Cube 프로파일러 버전을 실행합니다.

설치 챕터의 "Cube 플레이하기 실습" 참고
```

### 2단계: Wwise 실행 후 **Profiler 레이아웃** 열기

```csharp
Wwise에서 다양한 정보를 보기 위한 창(View)이 있습니다.

여러 개의 창을 보기 쉽게 묶어놓은 것을 레이아웃(Layout) 이라고 합니다.

Profiler 레이아웃은 게임에서 오는 정보를 분석하는 데 특화된 레이아웃입니다.

🔽 해야 할 일:

Wwise에서 메뉴 > Layouts > Profiler 선택하거나 키보드 F6 누르기

Profiler 레이아웃이 열리면 여러 창들이 함께 표시됩니다.

특히 좌측 위에 'Capture Log' 뷰가 중요합니다.
```

### 3단계: Wwise와 Cube 연결 (Remote Connect)

```csharp

같은 컴퓨터에서 둘 다 실행 중이면 자동으로 감지됩니다.

2. Remote Connections 창이 뜨면 자신의 컴퓨터 선택

3. Connect 클릭

툴바에 빨간 버튼이 생기고, 시간 카운트가 시작됩니다.

지금부터 Wwise는 게임에서 들어오는 모든 이벤트를 기록하기 시작한 거예요.
```

## 개념 정리

| 용어               | 의미                                          | 예시               |
| ------------------ | --------------------------------------------- | ------------------ |
| **Event**          | 게임에서 발생한 사건을 Wwise에 알리는 것      | Fire_IceGem_Player |
| **Game Object**    | 이벤트를 발생시킨 주체 (캐릭터, 오브젝트 등)  | LocalPlayer        |
| **Capture**        | Wwise가 게임에서 오는 정보를 기록하는 행위    | 보석 던지기 로그   |
| **Profiler**       | Wwise에서 정보를 분석하는 화면 구성           | `F6`으로 진입      |
| **Remote Connect** | 게임과 Wwise가 통신할 수 있도록 연결하는 과정 | Connect 버튼       |

# 🎧 Wwise와 Cube 연결 개념 정리

## 1. **Wwise와 Cube 연결의 목적**

- **Cube**는 오디오 테스트용 데모 게임(환경).
- **Wwise**는 오디오 미들웨어 툴.
- 둘을 연결하면:
  - 게임에서 발생하는 **이벤트(Event)** 와 **게임 동기화 값(Game Syncs)** 을 Wwise에서 직접 확인 가능.
  - 사운드 디자이너가 Cube의 실제 환경에서 **사운드 디자인을 테스트 및 수정**할 수 있음.
  - 변경 사항이 게임에 **실시간 반영** → 빠른 반복 작업 가능.

---

## 2. **연결 방법**

1. **게임과 Wwise 실행**
   - Cube 실행 후, Wwise 실행.
2. **원격 연결 열기**
   - Wwise 툴바 → **Connect to Remote Platform (Shift+H)** 클릭.
   - → 네트워크에서 실행 중인 Wwise 사운드 엔진 기반 게임 목록 표시.
3. **Remote Connections 대화 상자 설정**
   - (1) **자신의 컴퓨터 선택**
     Cube가 실행 중인 PC(보통 본인 PC).
   - (2) **Start capture on connect 해제**
     → 연결 시 자동으로 캡처 시작 안 함 (불필요한 데이터 수집 방지).
   - (3) **Profile and Edit (Sync All Modified Objects) 선택**
     → 연결하면 프로젝트의 수정 사항을 Cube 게임과 **동기화**.
   - (4) **Connect 클릭**
     → Wwise ↔ Cube 연결 완료.

---

## 3. **연결 후 상태**

- Cube에서 발생하는 게임 이벤트/파라미터 → Wwise로 전달되어 분석 가능.
- 연결된 상태에서 **Wwise 프로젝트 수정 가능**:
  - 이벤트 속성, 효과, 믹싱 등을 변경 → Cube에 즉시 반영.
- 결과적으로 **게임과 오디오 제작 간의 실시간 상호작용**이 가능해짐.

---

## 4. **SoundBank 개념 (중요)**

- **SoundBank**: Wwise 프로젝트에서 **게임이 사용할 수 있는 오디오 데이터와 설정을 묶은 패키지**.
- Cube에서는 Profile and Edit 모드를 쓰려면 최소 한 번은 SoundBank를 생성해야 함.
  - 생성 시 **Init.bnk** 파일이 만들어짐.
  - Init.bnk = **게임과 Wwise 엔진 간 통신에 필요한 필수 정보**를 담은 초기화용 SoundBank.
- 따라서 SoundBank를 생성하지 않으면 Cube가 Wwise와 제대로 소통할 수 없음.

---

## 5. **정리된 개념 흐름**

1. **Cube 실행** → 테스트 환경 준비.
2. **Wwise 실행** → 사운드 엔진 및 프로젝트 준비.
3. **Remote Connections 설정** → Cube와 Wwise 네트워크 연결.
4. **Profile and Edit 모드 활성화** → 프로젝트 변경 사항 실시간 반영.
5. **SoundBank 생성(Init.bnk 포함)** → Cube와 Wwise 엔진 간 원활한 통신 보장.
