# **nodeType**

```jsx
nodeType 프로퍼티는 DOM 노드의 '타입’을 알아내고자 할 때 쓰이는 구식 프로퍼티이다.

각 노드 타입은 상수값을 가진다.
```

```jsx
elem.nodeType == 1 – 요소 노드
elem.nodeType == 3 – 텍스트 노드
elem.nodeType == 9 – 문서 객체
```

## 예제

```jsx
<body>
  <script>
    let elem = document.body; // 타입을 알아봅시다. alert(elem.nodeType); // 1 => 요소 노드 // 첫
    번째 자식 노드 alert(elem.firstChild.nodeType); // 3 => 텍스트 노드 // 문서 객체의 타입 확인
    alert( document.nodeType ); // 9 => 문서 객체
  </script>
</body>
```

```jsx
모던 자바스크립트에선 노드의 타입을 instanceof나 클래스 기반의 테스트를 이용해 확인하는데,

가끔은 nodeType를 쓰는 게 간단할 때도 있다. 다만, nodeType은 타입 확인 하는 데만 쓸 수 있고 바꾸지는 못한다.
```
