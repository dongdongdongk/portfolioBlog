## 눈금자 도구 사용

```tsx
Shift + R 이 룰러 단축키

X와 Y 값을 0으로 설정하여 디자인 작업 시 눈금자 도구 사용이 용이하도록 함.
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381578/notion-blog/_/_/_/_UI_UX_/_11_3_UI_UX_/image_1.png)

## 홈페이지 디자인 시작

```tsx
네비게이션 바 및 이미지 카드 구성

	홈페이지는 네비게이션 바, 이미지, 텍스트로 구성.

	이미지 카드용 400 x 400 크기의 프레임 생성.

	Unsplash에서 초상화 이미지를 검색하고 선택한 후 중앙에 배치, corner radius를 10으로 설정.
```

## 서체 선택 및 타이포그래피 리소스

```tsx
Google Fonts 활용

	Google Fonts를 통해 적절한 서체 선택.

	다양한 서체 스타일 확인 및 필터링하여 디자인에 맞는 서체 결정.

	피그마 내에서 Google Fonts의 서체 사용 가능.
```

## 텍스트 스타일 설정

```tsx
서체 크기 및 스타일 설정

	텍스트의 크기를 12, 36, 64픽셀로 조정하고, 각기 다른 서체 스타일 (미디엄, 세미 볼드) 적용.

	선택한 텍스트에 자동 레이아웃 추가, 간격을 20으로 설정.
```

## 버튼 생성

```tsx
다운로드 버튼 만들기

	텍스트 도구로 버튼 텍스트 작성, 자동 레이아웃 추가.

	채우기 색상 설정 및 색상 스타일 디자인 시스템에 추가.

	Feather Icons에서 다운로드 아이콘을 검색해 버튼에 추가.
```

# { 모든 페이지 조인하고 BEHANCE에 포트폴리오 업로드하기 }

```tsx
모든 페이지를 연결하여 포트폴리오를 만들고, 이를 Behance에 업로드하는 과정을 다룹니다.
```

## 1. 모든 페이지 연결

```tsx
새 페이지 생성: 새 페이지를 만들고, 프레임의 이름을 "Portfolio Prototype"으로 변경합니다.

페이지 복사 및 붙여넣기:

	Command + A로 모든 페이지를 선택합니다.

	Command + C로 복사한 다음, 새로 만든 페이지에 Command + V로 붙여넣습니다.

메인 프레임 설정:

	데스크탑 사이즈의 프레임을 가져와 높이를 늘리고, 모든 페이지를 포함할 수 있도록 메인 프레임 안에 넣습니다.

	이 메인 프레임의 이름을 "Portfolio"로 변경합니다.

프로토타입 확인:

	프레임을 선택한 후, 프로토타입 모드로 이동하여 실제 브라우저에서 어떻게 보이는지 확인합니다.
```

## 2. Behance에 업로드

```tsx
Behance 접속 및 계정 생성:

	Google에서 Behance를 검색하고 Behance 닷넷 사이트에 접속합니다.

	계정이 없는 경우, 새 계정을 생성하거나 소셜 미디어 계정으로 가입합니다.

	계정이 있는 경우 로그인합니다.

업로드 가이드라인 확인:

	Behance의 가이드라인에 따라 JPEG 파일 형식과 1400픽셀~2800픽셀 해상도로 프로젝트를 내보내야 합니다.

포트폴리오 내보내기:

	피그마로 돌아가 프레임을 선택한 후, 파일 형식을 JPEG로 변경하고 내보냅니다.

Behance에 이미지 업로드:

	Behance에서 "Share your work"를 클릭하고, 내보낸 이미지를 업로드합니다.

	프로젝트 제목을 "UI/UX Portfolio Design"으로 입력하고, 태그에 "portfolio", "web design", "UI/UX"를 추가합니다.

	사용한 도구로 피그마를 선택하고, UI/UX Design과 Web Design을 프로젝트 카테고리로 설정합니다.

	프로젝트의 표지 이미지를 설정하고, 게시 버튼을 눌러 포트폴리오를 공개합니다.
```

## 3. 포트폴리오 공유

```tsx

이미지 해상도: 이미지가 흐릿해 보일 경우, 더 높은 해상도로 이미지를 다시 내보낼 수 있습니다.
```
