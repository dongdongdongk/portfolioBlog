## 자바스크립트의 기본타입 5가지

```java
Number :

1.정수(-1, 0, 1), 실수(소수점이 있는 숫자), NaN(Not a Number, 숫자가 아님이라는 값)

2.자바스크립트는 다른 언어와 다르게 정수와 실수를 따로 구분하지 않고, 모든 수를 실수 하나로만 표현한다.

String :

1.문자열은 작은따옴표(''), 큰따옴표(""), 백 틱(``)으로 둘러싸인 문자의 집합을 의미한다.

Boolean :

1.참/거짓(true/false)을 표현한다.

Null :

1.object 타입이며, '값'이 정해지지 않은 것을 의미한다.

Undefined : null과는 달리 '타입'이 정해지지 않은 것을 의미

1.값이 할당되지 않아 '타입'이 정해지지 않은 것을 의미한다.

2.초기화되지 않은 변수나 존재하지 않는 값에 접근할 때 반환된다.
```

## NaN

```java
NaN은 "Not a Number"의 약어로, 자바스크립트에서 숫자가 아닌 값을 나타내는 특별한 값

1.수학적으로 유효하지 않은 연산:

0으로 나누기: 0/0 또는 x/0 (x는 0이 아닌 값)
어떤 숫자를 0으로 나누기: x/0 (x는 숫자)

2.숫자로 변환할 수 없는 문자열:

숫자가 아닌 문자열을 숫자로 변환하려고 할 때: parseInt("abc")
숫자로 변환할 수 없는 형식의 숫자 문자열: parseInt("10px")
```

## let

```java
let 은 변수에 재할당이 가능하다

let name = 'bathingape'
    console.log(name) // bathingape

    let name = 'javascript'
    console.log(name)
    // Uncaught SyntaxError: Identifier 'name' has already been declared

    name = 'react'
    console.log(name) //react
```

## const

```java
const는 상수 변수 재선언, 변수 재할당 모두 불가능하다.

const name = 'bathingape'
    console.log(name) // bathingape

    const name = 'javascript'
    console.log(name)
    // Uncaught SyntaxError: Identifier 'name' has already been declared

    name = 'react'
    console.log(name)
    //Uncaught TypeError: Assignment to constant variable.
```

## 변수 명명과 규칙

```java
1. 변수명에 공백이 생기면 x

ex)let hello world

2. 변수명 첫 글자에 숫자가 오면 x

ex)let 1cdf

3. boolean 은 변수명에 is

ex)let isTest

4. 변수명 첫 글자는 대문자로 하지말자
```
