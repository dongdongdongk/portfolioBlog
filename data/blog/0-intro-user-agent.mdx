# 네이버 크롤링과 함께하는 웹 크롤링 맛보기

```python
pip install requests 를 터미널에 입력해서 설치해준다

(  라이브러리는 HTTP 요청을 보내고 받는 기능을 제공하여 웹 상의 데이터를 가져오거나 웹 서비스와 통신하는 데 사용된다. 주로 웹 크롤링, 웹 API 호출 등의 작업에 활용된다. )
```

```python
pip install beautifulsoup4 를 입력해서 설치

( beautifulsoup4 라이브러리는 HTML 및 XML 문서를 파싱하고 분석하는 기능을 제공하여 웹 스크래핑(scraping) 작업을 할 때 사용e된다. HTML 문서에서 원하는 정보를 추출하거나 조작하는 데 유용 )
```

## 예제

```python
import requests  # requests 라이브러리를 import하여 웹 페이지에 HTTP 요청을 보내기 위한 기능을 가져옵니다.
from bs4 import BeautifulSoup  # BeautifulSoup 라이브러리를 import하여 HTML 문서를 파싱하고 분석하는 기능을 가져옵니다.

url = "https://m.naver.com/"  # 크롤링할 웹 페이지의 URL을 변수에 저장합니다.

req = requests.get(url)  # 지정한 URL에 HTTP GET 요청을 보내고, 서버로부터 응답을 받습니다.

html = req.text  # HTTP 응답으로 받은 HTML 문서를 가져와 변수에 저장합니다.

# print(html)  # 받아온 HTML 문서를 출력합니다. (주석 처리하여 출력하지 않습니다.)

soup = BeautifulSoup(html, "html.parser")  # BeautifulSoup을 사용하여 HTML 문서를 파싱합니다. html.parser는 Python 표준 라이브러리에 내장된 HTML 파서입니다. 이 파서는 HTML 문서를 파싱하고, 각 요소의 구조를 이해하여 BeautifulSoup 객체로 변환

# ( 요약하면 html 변수에 저장된 문자열을 HTML로 파싱하고, 이를 BeautifulSoup 객체로 만들어주는 역할 )

logo = soup.select_one(".mf_logo_naver").text  # HTML 문서에서 클래스명이 "mf_logo_naver"인 요소를 선택하고, 해당 요소의 텍스트를 가져옵니다.

print(logo)  # 선택한 요소의 텍스트를 출력합니다.
```

```python
큰 흐름을 보자면

url 변수에 주소를 넣어주고

requests.get(url) 를 사용하여 url 주소에 get 요청을 보내 응답을 받고

html 변수에 html 로 응답받은 html 문서를 저장한다

그리고 BeautifulSoup 의 html.parser 를 사용해서 html 문서를 파싱하고

soup.select_one 을 사용해서 하나의 요소를 선택하고 .text 로 텍스트를 가져온다
```

## User-Agent 란?

```python
User-Agent"는 HTTP 요청 헤더 중 하나로, 클라이언트가 서버에게 자신을 식별하는 데 사용되는 정보이다.

일반적으로 웹 브라우저의 종류 및 버전, 운영 체제 등의 정보를 포함된다.

이 정보는 서버가 클라이언트에 맞춤형 콘텐츠를 제공하거나 요청을 처리하는 데 도움이 될 수 있다.
```
