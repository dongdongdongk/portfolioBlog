```java
  	@Override
    public GuestbookDTO read(Long gno) {
        Optional<Guestbook> result  = repository.findById(gno);

        return result.isPresent() ? entityToDto(result.get()) : null;
    }
```

```java
구현 클래스에서 오버라이드로 구현을 해준다

findById 를 활용해서 GuestBook Repository 에서 엔티티 객체를 가지고 왔다면

entityToDto 를 활용해서 객체를 DTO 로 변환해서 반환한다 (.isPresent() 는 객체가 존재하면 true 없으면 false 를 반환한다

(삼항 연산자를 이용해서 거짓이면 null 을 반환하게 하였다)

  	// 게시글 삭제
    @Override
    public void remove(Long gno) {
        repository.deleteById(gno);
    }
    // 게시글 수정
    @Override
    public void modify(GuestbookDTO dto) {
        // 업데이트 항목 제목, 내용
        Optional<Guestbook> result = repository.findById(dto.getGno());
        if(result.isPresent()) {
            // result.get()은 Optional 객체 안에 실제로 값이 존재한다면 그 값을 반환,
            // 값이 없는 경우에는 NoSuchElementException을 발생
            Guestbook entity = result.get();

            entity.changeTitle(dto.getTitle());
            entity.changeContent(dto.getContent());

            repository.save(entity);
        }
    }
```

```java
서비스 구현 클래스에 내용을 작성해준다 ( 삭제는 javaScript 를 이용해서 form 의 주소등 속성을 변경해서 사용한다 )

// 게시글 수정
    @PostMapping("/modify")
    public String modify(GuestbookDTO dto, @ModelAttribute("requestDTO") PageRequestDTO requestDTO, RedirectAttributes redirectAttributes) {
        log.info("post modify");
        log.info("dto:" + dto);

        service.modify(dto);

        redirectAttributes.addAttribute("page",redirectAttributes);
        redirectAttributes.addAttribute("gno", dto.getGno());
        return "redirect:/guestbook/read";
    }
```

```java

리다이렉트로 객체를 넣어 이동하기 위한 RedirectAttributes

```

## 수정 화면에서 다시 리스트로

```java
수정 페이지에서 리스트 페이지에 자바 스크립트를 사용해서 리스트 페이지( 선택한 글이 있는 페이지 ) 로 돌아간다
```

```jsx
 	<script th:inline="javascript">
      const removeBtn = document.querySelector(".removeBtn");
      const actionForm = document.querySelector("form");
      const modifyBtn = document.querySelector(".modifyBtn");
      const pageInfo = document.querySelector("input[name='page']");  // 숨겨둔 페이지 값 선택
      const listBtn = document.querySelector(".listBtn");

			  removeBtn.addEventListener('click', function (){
        actionForm.setAttribute("action","/guestbook/remove")
        actionForm.method = "post";
        actionForm.submit();
      });

      modifyBtn.addEventListener('click', function (){
        if(!confirm("수정하시겠습니까?")){
          return;
        }
        actionForm.setAttribute("action", "/guestbook/modify")
        actionForm.method = "post"
        actionForm.submit();
      });

      listBtn.addEventListener("click", function (){
        actionForm.innerHTML=""; //form 태그의 내용 삭제
        actionForm.append(pageInfo); // 목록에 필요한 페이지 값 추가
        actionForm.setAttribute("action", "/guestbook/list") // 폼에 다시 값 추가
        actionForm.method = "get"; // 메서드 get
        actionForm.submit();
      });

    </script>
```
