# 📱 React Native 풀스택 모바일 개발 강의 요약

> 초보자를 위한 10시간 완성 코스 — 강사: Adrian

---

## 🎯 이 강의가 필요한 이유

모바일 앱 개발을 혼자 시작하면 이런 일이 생깁니다:

- Flutter, React Native, Swift, Kotlin 중 뭘 배울지 2주간 고민
- 개발 환경 세팅 3일 → `SDK location not found` 에러로 멘붕
- YouTube, Reddit, 옛날 블로그 글 사이를 헤매며 시간 낭비
- 패키지 18개 설치 → 버그 하나 고치는 데 6시간 소비

**이 강의는 이 모든 과정을 하나로 정리해줍니다.**

## 📚 강의 구성 (총 3개 프로젝트)

### 1️⃣ React Native 입문 + 영화 앱

- React Native가 뭔지, 왜 인기 있는지 설명
- 파일 기반 라우팅, 컴포넌트 구조, API 라우트 등 핵심 개념 학습
- **완성 앱**: 트렌딩 영화 목록 + 검색 + 상세 페이지

### 2️⃣ 부동산 앱 (풀스택)

- 구글 로그인 인증 구현
- 매물 목록 검색·필터링
- 사용자 프로필 편집
- **배우는 기술**: React Native Expo + Tailwind CSS + TypeScript

### 3️⃣ 음식 배달 앱 (6화면 구성)

- 이메일/비밀번호 로그인
- 탭 + 스택 내비게이션
- 실시간 주문 화면
- 장바구니 + 추가 옵션 기능
- 에러 모니터링 (실무 수준)

## 💡 React Native란?

> 하나의 코드로 iOS와 Android 앱을 동시에 만들 수 있는 프레임워크

### 예전의 문제점

- iOS용 코드 따로, Android용 코드 따로 작성해야 했음
- → 개발 비용 2배, 시간 2배

### React Native가 해결한 것

- **하나의 코드베이스**로 두 플랫폼 동시 지원
- Meta, Discord, Microsoft, Tesla, Amazon, Airbnb 등 대기업도 사용 중

### 최신 아키텍처 (성능 개선)

| 기능                           | 설명                                      |
| ------------------------------ | ----------------------------------------- |
| **JSI** (JavaScript Interface) | JS ↔ 네이티브 코드 직접 통신 → 속도 향상 |
| **Turbo Modules**              | 필요한 모듈만 불러오기 → 시작 시간 단축   |
| **Fabric**                     | UI 렌더링 최적화 → 애니메이션 부드럽게    |

→ 결론: **React Native 앱 = 네이티브 앱 수준의 성능**

## 📦 Expo란?

> React Native 개발을 쉽게 만들어주는 공식 도구

- **비유**: Vite가 웹 개발을 쉽게 해주듯, Expo는 React Native를 쉽게 해줌
- React Native 공식 문서에서도 **Expo를 추천**

### Expo의 장점

- Android Studio 같은 복잡한 환경 설정 불필요
- 카메라, 지도, 제스처 등 기본 컴포넌트 제공
- **OTA 업데이트**: 앱스토어 심사 없이 즉시 업데이트 가능
- Discord, Burger King, Coinbase, Xbox 등 2,000개 이상 기업 사용 중
