## 1. 퍼블리싱이란?

디자이너가 만든 시각적 결과물(피그마, XD, Zeplin 등)을 실제 브라우저에서 동작하는 HTML/CSS/JS 코드로 변환하는 작업입니다.

```
디자이너 (피그마)  →  퍼블리셔 (HTML/CSS)  →  개발자 (백엔드 연동)
```

**퍼블리셔의 핵심 역할**

- 디자인을 픽셀 단위로 정확하게 구현
- 반응형(모바일/태블릿/PC) 대응
- 접근성(스크린리더, 키보드 탐색) 고려
- 개발자가 작업하기 좋은 클린한 마크업 전달

---

## 2. 전체 작업 흐름

```
① 디자인 파악     →  전체 구조 파악, 컴포넌트 목록화, 반응형 기준 확인
② 환경 세팅       →  폴더 구조, reset CSS, 공통 변수 설정
③ 수치 추출       →  피그마에서 색상, 폰트, 간격, 이미지 추출
④ HTML 마크업     →  시멘틱 태그, 컴포넌트 단위 작성
⑤ CSS 스타일링    →  레이아웃 → 공통 → 페이지별 순서로 작업
⑥ 반응형 작업     →  모바일 퍼스트 or 데스크탑 퍼스트
⑦ 인터랙션        →  hover, 애니메이션, JS 동작
⑧ QA & 검수       →  크로스 브라우저, 픽셀 비교, 접근성 점검
⑨ 납품            →  폴더 정리, 파일명 정리, 핸드오프 문서 작성
```

## 3. STEP 1 — 디자인 파악 & 분석

코드를 한 줄도 짜기 전에, 전체 디자인을 충분히 이해하는 것이 가장 중요합니다.

### 1-1. 페이지 & 컴포넌트 목록 파악

디자인 파일을 열면 가장 먼저 다음을 파악합니다.

```
✅ 체크리스트
□ 총 몇 개의 페이지인가?
□ 공통으로 반복되는 컴포넌트는 무엇인가? (헤더, 푸터, 카드, 버튼 등)
□ 상태별 디자인이 있는가? (hover, active, disabled, loading, empty)
□ 반응형 기준 해상도는? (모바일 360px? 1280px? 1920px?)
□ 다크모드/라이트모드 구분이 있는가?
□ 팝업, 모달, 드롭다운 등 레이어 요소가 있는가?
```

### 1-2. 디자인 시스템 파악

피그마의 **Styles** 패널이나 **Design System** 페이지를 먼저 확인합니다.

```
색상 팔레트   →  Primary, Secondary, Neutral, Error, Success 색상 정리
타이포그래피  →  Heading 1~6, Body, Caption 등 텍스트 스타일
간격 체계     →  4px 단위? 8px 단위? 스페이싱 규칙
컴포넌트      →  버튼 종류(크기, 색상), 인풋, 카드 등
아이콘 세트   →  어떤 아이콘 라이브러리? 커스텀 SVG?
```

### 1-3. 레이아웃 구조 스케치

페이지를 보면서 박스로 구조를 잡아봅니다. (종이에 손으로 그려도 좋습니다)

```
┌─────────────────────────────┐
│           HEADER            │
├─────────────────────────────┤
│  SIDEBAR  │   MAIN CONTENT  │
│           │                 │
├─────────────────────────────┤
│           FOOTER            │
└─────────────────────────────┘
```

## 5. STEP 3 — 피그마에서 수치 뽑기

### 5-1. 피그마 기본 조작

| 단축키 (Mac/Win)            | 기능                   |
| --------------------------- | ---------------------- |
| `Cmd/Ctrl + 클릭`           | 그룹 안 요소 선택      |
| 요소 선택 후 `I`            | 스포이드 (색상 추출)   |
| `Alt + 드래그`              | 간격 측정              |
| 요소 선택 → 다른 요소 hover | 두 요소 사이 간격 표시 |
| `Cmd/Ctrl + Shift + C`      | 선택 요소 CSS 복사     |

### 5-2. 오른쪽 패널에서 수치 읽기

```
선택한 요소 → 오른쪽 패널

[Design 탭]
W: 너비   H: 높이
X: 좌표   Y: 좌표
Radius: border-radius
Opacity: 투명도
Fill: 배경색 (HEX, RGB, 그라디언트)
Stroke: 테두리 (색상, 두께)
Effects: 그림자 (box-shadow)

[Inspect 탭] ← CSS 값을 직접 보여줌
```

### 5-3. CSS 직접 복사 (Inspect 탭)

요소 선택 → 오른쪽 패널 `Inspect` 탭 → `Copy CSS` 클릭

```css
/* 피그마가 생성해주는 CSS 예시 */
width: 320px;
height: 48px;
background: #3b82f6;
border-radius: 8px;
font-family: 'Pretendard';
font-weight: 600;
font-size: 16px;
line-height: 24px;
color: #ffffff;
```

> ⚠️ **주의**: 피그마의 CSS는 참고용입니다. 그대로 쓰면 `position: absolute`로 고정 좌표가 생겨 반응형이 깨집니다. 수치만 참고하고 CSS 구조는 직접 작성합니다.

### 5-4. 이미지/아이콘 내보내기

```
이미지 선택 → 오른쪽 패널 하단 Export

포맷 선택:
- PNG  : 사진, 복잡한 그래픽 (2x, 3x 배율로 내보내기)
- SVG  : 아이콘, 로고 (크기 무관하게 선명, 코드로 조작 가능)
- WebP : 최신 브라우저용 (더 작은 파일 크기)
- JPG  : 사진 (투명 배경 불필요한 경우)

권장:
- 아이콘/로고 → SVG
- 사진/썸네일 → WebP + JPG 폴백
- Retina 대응 → PNG 2x (파일명: image@2x.png)
```

### 5-5. 색상 추출 팁

```
방법 1: Fill 패널 HEX 값 직접 복사
방법 2: 오른쪽 패널 Fill → HEX 코드 클릭 복사
방법 3: 플러그인 사용 → 'Design Tokens' 플러그인으로 전체 토큰 JSON 추출
```

## 6. STEP 4 — 마크업 작성 (HTML)

### 6-1. 시멘틱 태그 사용 원칙

```html
<!-- ❌ 나쁜 예: 의미없는 div 남발 -->
<div class="header">
  <div class="nav">
    <div class="nav-item">홈</div>
  </div>
</div>

<!-- ✅ 좋은 예: 시멘틱 태그 사용 -->
<header class="site-header">
  <nav class="gnb">
    <ul>
      <li><a href="/">홈</a></li>
    </ul>
  </nav>
</header>
```

| 태그        | 용도                               |
| ----------- | ---------------------------------- |
| `<header>`  | 페이지 또는 섹션의 머리글          |
| `<nav>`     | 내비게이션 메뉴                    |
| `<main>`    | 페이지 주요 콘텐츠 (페이지당 하나) |
| `<section>` | 주제별 콘텐츠 묶음                 |
| `<article>` | 독립적인 콘텐츠 (블로그 글, 카드)  |
| `<aside>`   | 사이드바, 부가 정보                |
| `<footer>`  | 페이지 또는 섹션의 바닥글          |
| `<h1>~<h6>` | 제목 계층 (페이지당 `h1` 하나)     |
| `<figure>`  | 이미지 + 캡션 묶음                 |
| `<button>`  | 클릭 동작 (링크 이동이 아닌 경우)  |
| `<a>`       | 페이지 이동, URL 링크              |

### 6-2. BEM 방법론 (클래스 네이밍)

가장 널리 쓰이는 CSS 클래스 명명 규칙입니다.

```
Block__Element--Modifier

블록(Block)      : 독립적인 컴포넌트 단위       .card
요소(Element)    : 블록의 구성 요소             .card__title
수정자(Modifier) : 상태나 변형                 .card--featured
```

```html
<!-- BEM 예시 -->
<div class="card card--featured">
  <div class="card__thumbnail">
    <img src="..." alt="..." />
  </div>
  <div class="card__body">
    <span class="card__badge card__badge--new">NEW</span>
    <h3 class="card__title">카드 제목</h3>
    <p class="card__description">설명 텍스트</p>
  </div>
  <div class="card__footer">
    <button class="btn btn--primary btn--sm">자세히 보기</button>
  </div>
</div>
```

### 6-3. 페이지 기본 템플릿

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <meta name="description" content="페이지 설명" />
    <title>페이지 제목 | 사이트명</title>

    <!-- CSS -->
    <link rel="stylesheet" href="css/reset.css" />
    <link rel="stylesheet" href="css/variables.css" />
    <link rel="stylesheet" href="css/common.css" />
    <link rel="stylesheet" href="css/pages/main.css" />

    <!-- 파비콘 -->
    <link rel="icon" type="image/svg+xml" href="images/favicon.svg" />
  </head>
  <body>
    <header class="site-header">
```

### 실수 3: z-index 난무

```css
/* ❌ 의미 없이 큰 숫자 사용 */
.dropdown {
  z-index: 9999;
}
.modal {
  z-index: 99999;
}

/* ✅ 변수로 체계적으로 관리 */
.dropdown {
  z-index: var(--z-dropdown);
} /* 100 */
.modal {
  z-index: var(--z-modal);
} /* 400 */
```

### 실수 4: 전체 선택자 남발

```css
/* ❌ 성능 이슈, 의도치 않은 스타일 적용 */
* {
  transition: all 0.3s;
}

/* ✅ 필요한 요소에만 적용 */
.btn,
.card,
.link {
  transition: ...;
}
```

### 실수 5: position: absolute 남용

```css
/* ❌ 콘텐츠 흐름에서 벗어나 반응형 구현 어려움 */
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}

/* ✅ 부모에 position: relative를 명시하고 사용 */
.card {
  position: relative;
}
.card__badge {
  position: absolute;
  top: var(--space-2);
  right: var(--space-2);
}
```

### 피그마 → CSS 변환 대조표

| 피그마 속성              | CSS 속성                                     |
| ------------------------ | -------------------------------------------- |
| Frame 너비/높이          | `width` / `height`                           |
| Corner Radius            | `border-radius`                              |
| Fill (Solid)             | `background-color` / `color`                 |
| Fill (Gradient)          | `background: linear-gradient(...)`           |
| Stroke                   | `border: {두께}px solid {색상}`              |
| Drop Shadow              | `box-shadow: {x} {y} {blur} {spread} {색상}` |
| Inner Shadow             | `box-shadow: inset ...`                      |
| Opacity                  | `opacity`                                    |
| Auto Layout (가로)       | `display: flex; flex-direction: row`         |
| Auto Layout (세로)       | `display: flex; flex-direction: column`      |
| Auto Layout Gap          | `gap`                                        |
| Auto Layout Padding      | `padding`                                    |
| Clip Content             | `overflow: hidden`                           |
| Text > Line Height       | `line-height`                                |
| Text > Letter Spacing    | `letter-spacing`                             |
| Text > Paragraph Spacing | `margin-bottom` (단락 간격)                  |
| Constraints (Fill)       | `width: 100%`                                |
| Constraints (Fixed)      | `width: {고정값}px`                          |
