### 1.Generic

ArrayList<Integer>ar 처럼 컬렉션 형태의 변수를 선언할 때, 제네릭 타입의 <Integer> 가 자바의 int 자료형과 매팅되는 클래스이다.

### 2.Casting(형변환)

예를들어 String 형태의 정수 타입의 변수를 int 형태의 기본타입으로 casting 할 때 Integer 래퍼 클래스의 parseInt() 라는 메소드를 사용하여 캐스팅을 진행한다.

```java
String str = "2";
int strToInt = Integer.parseInt(str);     // String 을 int 타입으로 캐스팅
```

## Boxing(박싱) Unboxing(언박싱)

기본형(primitive type 과 Wrapper class 는 상호변환이 이루어지고 이 과정을 각각 boxing , unboxing 이라고 한다.

**boxing : 기본 타입에서 wrapper 클래스로 전환**

**unboxing : wrapper 클래스 객체를 기본타입으로 전환**

Integer wrapper 클래스의 객체를 생성하는 박싱은 생성자의 매개변수로 int 값을 넣어주기

```java
Integer n = new Integer(5);;
```

wrapper 클래스 객체를 기본형으로 전환하기 intValue() 메소드를 사용한다.

```java
int i = n.intValue()

//다양한 자료형
Float a = new Float(9.5f);
byte num1 = a.byteValue();
short num2 = a.shortValue();
int num3 = a.intValue();
long num4 = a.longValue();
double num5 = a.doubleValue();
```

## Auto - Boxing(박싱) Unboxing(언박싱)

기본타입 값을 직접 박싱,언박싱 하지 않아도 자동적으로 박싱과 언방싱을 할 수 있다.

포장 클래스 타입에 기본값이 대입될 경우 발생한다

```java
Integger num = 16; //자동 박싱 (포장 클래스에 기본값 대입)(자동으로 힙영역에 객체생성)

int n = num; //자동 언박싱 (래퍼 클래스 변수 num 을 기본타입 n 에 언박싱 하였다)
```

## **StringBuffer**

StringBuffer는 문자열을 추가하거나 변경 할 때 주로 사용하는 **자료형**

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380966/notion-blog/_/JAVA/_/_StringBuffer/Untitled_3.png)

```java
문법 : StringBuffer sb = new StringBuffer("hello");

       sb.append("world");                           //결과 hello world
```

- String 클래스의 + 는 둘을 합치는 것이 아닌 새로운 객체를 만들어 낸다. 이러한 연산이 다수 중첩될시 성능에 나쁜 영향을 미칠 수 있다.
- 문자열의 추가,삭제,수정 등 의 연산이 자주 일어날 경우 StringBuffer 클래스를 사용하는 것 이 효율적이다

```java
STringBuffer 의 메소드

1. .append();       // 문자열 추가
System.out.println(str.append("추가할 문자열));

2. .delete();       // 전달된 인덱스 문자열 부분 삭제
System.out.println(str.delete(4,8);     // 4,8번 인덱스에 문자삭제

3. .insert();        // 지정한 인덱스에 문자열 추가
System.out.println(str.insert(4, "Script"));
```
