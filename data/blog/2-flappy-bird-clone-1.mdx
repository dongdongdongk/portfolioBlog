```jsx
// Phaser 라이브러리와 필요한 모듈 가져오기
import Phaser, { Physics, Scene } from 'phaser'

// Phaser 게임 설정 객체 (config)
// 게임 캔버스와 물리 엔진, 장면(scene) 등을 정의
const config = {

  width: 800,
```

```jsx
1. Phaser란 무엇인가?

		Phaser는 HTML5 기반의 2D 게임 제작 프레임워크입니다.

		게임 내 물리 엔진, 장면 관리, 그래픽 렌더링 등을 쉽게 설정할 수 있는 도구를 제공합니다.

		Phaser는 WebGL(웹 그래픽 라이브러리)을 주로 사용하며, WebGL이 지원되지 않는 환경에서는 Canvas로 대체합니다.

2. 기본 Phaser 설정

		type: Phaser.AUTO: 렌더러 타입 자동 선택(WebGL > Canvas).

		width와 height: 게임 캔버스의 크기(픽셀 단위).

		physics: 게임 오브젝트의 물리적 동작을 정의. 여기서는 arcade 물리 엔진을 사용.

		scene: 게임의 주요 논리를 작성하는 부분으로, 3가지 주요 함수로 구성:

				preload: 게임 실행 전에 필요한 리소스(예: 이미지, 사운드)를 미리 로드.

				create: 리소스를 사용해 장면을 초기화하거나 게임 요소를 화면에 추가.

				update: 지속적으로 호출되어 게임 루프에서 오브젝트를 업데이트.

3. WebGL과 Phaser

		WebGL(Web Graphics Library):

				2D 및 3D 그래픽을 브라우저에서 GPU 가속으로 렌더링.

				Phaser는 WebGL을 활용하여 고성능 그래픽을 제공.

				거의 모든 현대 브라우저에서 지원.

4. Arcade 물리 엔진

		간단한 물리적 동작을 제공하는 가벼운 엔진.

		중력, 속도, 충돌 등을 간단히 처리할 수 있음.

		Phaser에서 기본 물리 엔진으로 제공되며 초보자나 간단한 게임에 적합.

5. Scene(장면)이란?

		게임의 각 상태나 화면을 관리하는 단위.

		장면에는 3가지 주요 함수가 존재:

				1. preload: 자산 로드 단계(이미지, 사운드 등).

				2. create: 로드된 자산을 사용해 초기화 단계.

				3. update: 루프 단계. 게임의 프레임별 동작 정의.

6. 디버깅

		debugger: 함수 호출 시 개발자 도구를 열어 디버깅.

		강의에서는 preload와 create 함수의 실행 순서를 디버깅하여 확인.

7. 앞으로 추가할 내용

		preload: this.load.image를 사용하여 이미지를 로드.

		create: this.add.image를 사용하여 로드한 이미지를 화면에 표시.

		게임 내 상호작용(중력, 속도, 충돌 등)을 arcade physics를 활용해 구현.
```

# { Phaser 이미지의 원점(origin) 좌표 }

```jsx
**원점(origin)**은 Phaser에서 이미지를 배치할 때 기준이 되는 점입니다.

이 점은 이미지 내부의 특정 위치를 나타내며,

캔버스의 좌표와 연결되어 이미지가 화면에 배치됩니다.
```

```jsx
이 그림을 통해, 원점(origin)을 변경함으로써 이미지를 원하는 위치에 배치할 수 있다는 점을 알 수 있습니다.

추가적으로 Phaser의 setOrigin(x, y) 메서드를 사용하여 이런 변화를 실습해 볼 수 있습니다.

( 즉 0, 0 이 기본인데 이걸 변경한다는거  )
```

```jsx
setOrigin(x, y)로 원점을 설정할 수 있습니다.

기본값은 (0.5, 0.5)로, 이미지의 중심입니다.

원점 값 (x, y)	위치 설명	그림으로 표현

		(0, 0)	이미지의 왼쪽 위	↖️ 왼쪽 위를 기준으로 배치

		(1, 0)	이미지의 오른쪽 위	↗️ 오른쪽 위를 기준으로 배치

		(0, 1)	이미지의 왼쪽 아래	↙️ 왼쪽 아래를 기준으로 배치

		(1, 1)	이미지의 오른쪽 아래	↘️ 오른쪽 아래를 기준으로 배치

		(0.5, 0.5)	이미지의 중앙 (기본값)	🎯 중앙을 기준으로 배치
```

# **{ 이미지와 스프라이트 개념 }**

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380492/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_1_-/image_6.png)

```jsx
import Phaser, { Physics, Scene } from 'phaser'

const config = {
  type: Phaser.AUTO,
  width: 800, // 게임 화면의 가로 크기
  height: 600, // 게임 화면의 세로 크기
  physics: {
    default: 'arcade', // 물리 엔진 설정
  },
  scene: {
    preload, // 게임 자원(이미지 등)을 로드하는 함수
    create, // 게임이 시작될 때 실행되는 함수
  },
}

function preload() {
  // 게임에서 사용할 이미지를 로드
  this.load.image('sky', 'assets/sky.png') // 배경 이미지
  this.load.image('bird', 'assets/bird.png') // 새 이미지
}

function create() {
  // 배경 이미지를 화면 왼쪽 상단(0, 0)으로 배치
  this.add.image(0, 0, 'sky').setOrigin(0)

  // 새 이미지를 화면 중앙에 배치
  this.add.sprite(config.width / 2, config.height / 2, 'bird').setOrigin(0)
}

// Phaser 게임을 시작
new Phaser.Game(config)
```

```jsx
이미지와 스프라이트 개념:

		Phaser에서 이미지는 단순히 화면에 표시되는 정적인 이미지를 의미합니다.

		**스프라이트(Sprite)**는 이미지뿐만 아니라 그 이미지의 위치,

		회전, 크기, 움직임 등의 속성을 다룰 수 있는 게임 객체입니다.

게임 객체 생성:

		this.add.sprite(x, y, 'key')를 사용하여 스프라이트를 생성합니다.

		여기서 x와 y는 스프라이트의 위치를 결정하며, 'key'는 로드한 이미지를 참조하는 키 값입니다.

		setOrigin(0)는 스프라이트의 기준점을 설정하는 함수입니다.

		여기서 0은 스프라이트의 왼쪽 상단 모서리가 기준점이 되도록 합니다.

이미지 로드:

		이미지는 this.load.image('key', 'path')로 로드합니다.

		'key'는 해당 이미지를 참조하는 키이며, 'path'는 이미지 파일의 경로입니다.

위치 설정:

		예제에서는 게임 화면의 중앙에 스프라이트를 배치하고, 그 후에는 다른 위치에 배치하는 방법을 설명합니다.

		스프라이트의 위치는 config.width / 2, config.height / 2로 설정하여 화면의 중앙에 배치합니다.

간단한 과제:

		강의 중간에는 "새로운 위치에 스프라이트를 배치하는 방법"을 다룹니다.

		예를 들어, 화면의 중앙이 아닌 왼쪽 1/10 지점에 배치하도록 하였습니다.

		이 방법은 config.width / 10을 사용하여 X 위치를 설정하고,

		Y 위치는 config.height / 2로 설정하여 화면 중간 높이에 배치하도록 합니다.
```

## 속도와 중력의 차이

```jsx
1) 속도(Velocity)

		속도는 물체가 일정한 방향으로 일정한 속도로 이동합니다.

		예시: bird.body.velocity.y = 200

		⇒ 매초 200px씩 같은 속도로 이동.

2) 중력(Gravity)

		중력은 시간에 따라 속도가 계속 증가합니다.

		예시: bird.body.gravity.y = 200

		⇒ 1초 후 200px/s, 2초 후 400px/s, 3초 후 600px/s.
```

```jsx
FPS (Frames Per Second): 게임 화면이 1초에 몇 번 그려지는지.

Delta Time: 두 프레임 간의 시간 차이.

60fps 기준: 16ms * 60 ≈ 1000ms(1초)
```

```jsx
import Phaser from 'phaser' // Phaser 라이브러리를 가져옵니다.

const config = {
  type: Phaser.AUTO, // 렌더링 방식: WebGL 또는 Canvas 자동 선택

  },
  scene: {
    preload, // 리소스를 로드하는 함수
    create, // 게임 오브젝트를 생성하는 함수
    update, // 프레임마다 게임 상태를 갱신하는 함수
  },

let bird

}

function update(time, delta) {
  totalDelta += delta // 매 프레임 경과 시간 누적

  if (totalDelta >= 1000) {
```

## 화면 밖으로 겹쳐 나가는 이슈

```jsx
현재 코드에서는 새가 화면의 오른쪽 끝으로 이동할 때 X 좌표가 새의 왼쪽 모서리 기준으로 판단됩니다.

이로 인해 새가 화면의 오른쪽 끝을 넘어간 뒤에야 방향이 바뀌어, 새의 일부가 화면 밖으로 겹쳐 나가게 됩니다.

문제가 발생하는 이유

		bird.x는 스프라이트의 왼쪽 상단 좌표입니다.

		새의 넓이 bird.width를 고려하지 않으면 오른쪽 끝에서 스프라이트가 완전히 보이지 않게 됩니다.

해결 방법

		화면 너비에서 새의 너비를 뺀 값과 비교

		오른쪽으로 이동할 때 bird.x가 config.width - bird.width 이상이 되면 이동 방향을 반전합니다.
```

```jsx
  width: 800, // 게임 화면 너비
  height: 600, // 게임 화면 높이
  physics: {
    // 물리 엔진 설정
    default: 'arcade', // 간단한 물리 엔진 사용
    arcade: {
      gravity: { y: 400 }, // Y축 방향으로 중력 설정 (400의 힘)
      debug: true, // 디버그 모드 활성화 (충돌 박스 표시 등)
    },
  },
  scene: {
    // 게임의 주요 상태(장면) 정의
    preload, // 자원을 미리 로드하는 단계
    create, // 게임 객체를 생성하는 단계
    update, // 매 프레임마다 실행되는 업데이트 단계
  },
}

// 게임에 사용될 이미지 파일들을 미리 로드하는 함수
function preload() {
  // 배경 이미지 로드
  this.load.image('sky', 'assets/sky.png')
  // 새 이미지 로드
  this.load.image('bird', 'assets/bird.png')
}

// 전역 변수 정의
const VELOCITY = 200 // 기본 속도 (사용되지 않음)
const flapVelocity = 250 // 새가 위로 날아오를 때의 속도
const initialBirdPosition = { x: config.width * 0.1, y: config.height / 2 } // 새의 초기 위치

let bird = null // 새 객체를 저장할 변수

// 게임 객체를 생성하는 함수
function create() {
  // 배경 이미지 추가 (화면의 왼쪽 상단이 기준)
  this.add.image(0, 0, 'sky').setOrigin(0)

  // 새를 화면에 추가하고 물리 엔진에 등록
  bird = this.physics.add.sprite(initialBirdPosition.x, initialBirdPosition.y, 'bird').setOrigin(0)

  // 마우스 클릭 시 새가 날아오르게 설정
  this.input.on('pointerdown', flap)

  // 스페이스바 키 입력을 감지하기 위한 설정
  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)
}

// 매 프레임마다 실행되는 업데이트 함수 (기본적으로 초당 60회 실행)
function update() {
  // 스페이스바가 눌렸는지 확인
  if (this.spaceKey.isDown) {
    flap() // 날아오르는 동작 수행
  }

  // 새가 화면 밖으로 나갔는지 확인
  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition() // 새 위치와 속도를 초기화하는 함수 호출
  }
}

// 새 위치와 속도를 초기화하는 함수
function restartBirdPosition() {
  // 새의 위치를 초기 위치로 복원
  bird.x = initialBirdPosition.x
  bird.y = initialBirdPosition.y

  // 새의 Y축 속도를 0으로 초기화 (중력에 의해 가속된 속도를 리셋)
  bird.body.velocity.y = 0

  // 경고 메시지로 패배 알림 표시
  alert('패배')
}

// 새가 날아오르는 동작을 구현한 함수
function flap() {
  // 새의 Y축 속도를 음수로 설정 (위로 이동)
  bird.body.velocity.y = -flapVelocity
}

// Phaser 게임 객체 생성 및 설정 적용
new Phaser.Game(config)
```

```jsx
1. 마우스 클릭 또는 스페이스바를 누르면 새가 하늘로 올라감.

2. 새가 화면 밖으로 나가면 게임을 재시작함.

3. 화면 위쪽으로 나갈 때는 새의 높이를 고려하여 새가 완전히 벗어났을 때만 게임이 재시작됨.

4. 게임이 재시작되면 새의 위치와 속도를 초기화함.
```

## 1. 새가 화면 밖으로 나가면 게임을 재시작

```jsx
function update() {
  // 스페이스바가 눌렸는지 확인하고 새를 위로 이동
  if (this.spaceKey.isDown) {
    flap()
  }

  // 새가 화면 바깥으로 나갔는지 확인
  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition() // 새의 위치를 초기화하고 게임 재시작
  }
}
```

```jsx
bird.y > config.height: 새가 화면 아래로 벗어나는 경우.

bird.y < -bird.height: 새가 화면 위로 벗어나 완전히 보이지 않는 경우.

조건이 만족되면 restartBirdPosition() 함수를 호출해 게임을 재시작.
```

## 2. 게임 재시작 기능

```jsx
강의에서는 새의 초기 위치와 속도를 재설정하는 방법을 설명했습니다.
```

```jsx
function restartBirdPosition() {
  bird.x = initialBirdPosition.x // 새의 초기 x 위치
  bird.y = initialBirdPosition.y // 새의 초기 y 위치
  bird.body.velocity.y = 0 // 속도를 0으로 설정 (중력 초기화)
  alert('패배') // 경고창으로 패배 알림
}
```

```jsx
x와 y 위치 초기화: 새를 초기 위치로 되돌림.

속도 초기화: 중력으로 인해 속도가 누적되지 않도록 0으로 설정.

알림 표시: 플레이어에게 게임이 끝났음을 알림.
```

## 3. 위쪽 경계 체크 로직 개선

```jsx
강의에서 새가 화면 위로 나갔을 때 새의 높이를 고려해야 한다고 강조했습니다.
```

```jsx
if (bird.y < -bird.height) {
  // 화면 위로 새가 완전히 사라진 경우
  restartBirdPosition()
}
```

```jsx
-bird.height는 새가 화면 위쪽으로 완전히 사라졌을 때 게임을 재시작하도록 조건을 설정하는 부분입니다.

예를 들어, 화면의 맨 위는 y = 0인데,

새의 몸 일부가 화면에 보일 때는 아직 게임이 끝난 상태가 아니라고 판단합니다.

그래서 "새의 높이만큼 더 위로 올라가야 완전히 사라졌다"고 간주하여 게임을 재시작하는 조건으로 -bird.height를 사용합니다.
```
