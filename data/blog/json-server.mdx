# json-server 설치하기

```jsx
npm i -g json-server
```

# fake 디렉토리 추가

```jsx
루트 디렉토리에 아래 폴더와 파일을 추가해준다
```

```jsx
mkdir fake-server

touch db.json
```

# db.json

```jsx
{
  "memo": [
      {
          "id": 1,
          "title": "첫 메모 제목",
          "body": "첫 메모 내용"
      }
  ]
}
```

# 서버 실행

```jsx
json-server --watch db.json --port 3001
```
