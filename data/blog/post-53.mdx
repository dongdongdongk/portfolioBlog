# Node.js 란 무엇인가

## JavaScript 란?

```java
JavaScript 는 브라우저에서 많이 사용하는 프로그래밍 언어로 도메인을 편집하거나

브라우저에서 로딩된 페이지를 편집하거나 팝업, 모달,효과를 불러 오는데 사용한다

자바 스크립트는 브라우저에서 실행되는 언어로 로딩 후에도 페이지와 상호작용 가능하게 해준다

(인터렉티브 사용자 인터페이스를 구현하는데 필수적인 요소)
```

## Node.js 란?

```java
Node.js 는 javaScript 런타임 이다 ( JavaScript 코드를 실행할 수 있는 환경이라는 뜻 )

Node.js 는 다른 버전의 JavaScript 라고 할 수 있다

Node.js 는 JavaScript로 서버 측 프로그래밍을 할 수 있게 해주는 환경

기존에는 JavaScript가 주로 웹 브라우저에서 동작하는 언어로 알려져 있었는데,

Node.js를 통해 이제는 서버에서도 JavaScript를 사용할 수 있게 되었다.

( JavaScript 기반으로 만들어 졌으며 몇몇 기능을 더하고 기존 JavaScript 로 브라우저에서 가능했던

몇몇 기능이 빠졌다 )

**요약하자면 Node.js 는 JavaScript 를 브라우저 밖에서 사용 가능하도록 해준다**
```

## Node.js 작동 원리

```java
Node.js는 구글 크롬 브라우저의 V8 JavaScript 엔진을 기반으로 만들어졌다 (V8 은 C++ 기반이다)

JavaScript 코드는 일반적으로 웹 브라우저에서 실행되는데, V8은 이를 브라우저에서 독립시켜 서버 환경에서도 JavaScript를 실행할 수 있게 해준다

V8는 JavaScript 코드를 소스 코드에서 바이트코드( 다른 프로그램에 의해 해석되거나 변환되어야 하는 중간 단계의 코드 JVM 같은거) 로 변환하고,

최종적으로는 머신 코드( 컴퓨터의 CPU에서 직접 실행되는 이진 형태의 코드) 로 변환하여 실행한다
```

## Node.js 의 기능

```java
Node.js 는

로컬 시스템 활용, 파일 열기, 파일 읽기, 파일 삭제 등의 기능을 추가해준다

이러한 작업은 브라우저에서는 불가능 하다 (보안상의 이유로 로컬 파일에 엑세스할 수 없다)

Node.js 는 V8 엔진을 기반으로 이를 가능하게 해준다

"쉽게 말하면 브라우저 대신에 Node.js 에서 자바스크립트를 돌린다는거 이렇게 하면 다양한 브라우저에서 할 수 없는 기능을 사용 가능하는것"
```

## 파일 생성 프로그램 만들어보기

```java
조금더 복잡한 파일을 만들어 주는 프로그램을 만들어 본다

node.js 가 제공하는 기능을 사용할것이다

먼저

파일에 임포트를 하여 노드에게 이 기능을 사용할것이라고 알려야 한다

require 함수를 사용하여 Node.js의 내장된 fs 모듈을 불러온다

( fs 모듈은 파일 및 디렉토리를 생성, 읽기, 쓰기, 삭제하고 파일과 디렉토리에 대한 다양한 작업을 수행할 수 있도록 도구를 제공 )

* **require 함수**는 Node.js에서 모듈을 불러오는데 사용되는 특별한 함수

	이 함수를 사용하여 외부의 다른 파일(모듈)에서 정의된 코드를 현재 파일에서 사용할 수 있게 된다

* **모듈**은 코드의 부분을 묶어서 특정 기능을 담당하는 조각으로 만든 것
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381048/notion-blog/_/Node_js/NodeJS_MVC_REST_APIs_GraphQL_Deno/_/Untitled_6.png)

```java
const  fs = require('fs');

fs.writeFileSync('hello.txt','Hello from Node.js');

첫번째 인수는 파일의 이름 hello.txt

두번째 인수는 파일의 내용이다 Hello from Node.js
```
