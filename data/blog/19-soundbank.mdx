## 1. SoundBank와 메모리 예산 개념 이해하기

### 🎧 SoundBank란?

- Wwise에서 **게임에 포함될 오디오 데이터(Event, 음악, 사운드, 스트림 등)**를 묶어둔 단위입니다.
- 쉽게 말하면, “게임 안에서 필요한 소리들을 묶어서 담은 파일”이라고 볼 수 있습니다.
- 게임 실행 시 이 SoundBank가 로드되어, 거기 담긴 오디오 리소스가 재생됩니다.

### 💾 메모리 예산(Max Size) 개념

- 각 SoundBank는 **게임의 전체 메모리 중 일부**를 차지합니다.
- 이때 **각 SoundBank에 허용되는 최대 메모리 크기(바이트 단위)**를 정해둘 수 있습니다.
- 이를 **메모리 예산(Memory Budget)**이라고 합니다.

### ⚙️ 왜 메모리 예산이 중요한가?

- 게임은 오디오뿐만 아니라 그래픽, 물리 연산, AI 등 많은 시스템이 메모리를 공유합니다.
- 오디오에 너무 많은 메모리를 사용하면 다른 시스템(예: 그래픽 품질)에 지장이 생길 수 있습니다.
- 따라서 **팀 내에서 미리 정한 예산 내에서 사운드를 구성**하는 것이 중요합니다.

> 🎯 목표:
>
> - 각 SoundBank의 크기를 확인하고,
> - 예산(최대 크기)을 설정한 뒤,
> - SoundBank가 메모리 제한을 초과했는지 확인하기.

## 2. SoundBank Manager 열기

1. Wwise를 실행하고 **Module 19 프로젝트 파일**을 엽니다.
2. 상단 메뉴에서

   **`Layouts > SoundBank (F7)`** 을 클릭합니다.

3. 이제 오른쪽 상단 영역에 **SoundBank Manager** 창이 열립니다.

> 💡 SoundBank Manager는 SoundBank 생성, 크기 확인, 예산 설정을 모두 담당하는 관리 도구입니다.

---

## 3. SoundBank 생성하기 (Generate All)

1. SoundBank Manager의 오른쪽 상단에 있는 **“Generate All”** 버튼을 클릭합니다.
2. **Generating SoundBanks** 대화 상자가 나타나고, SoundBank를 생성하는 과정이 표시됩니다.
3. 생성이 완료되면 **Close** 버튼을 클릭하여 창을 닫습니다.

이 단계에서 실제로 SoundBank 파일이 생성되며,

Wwise가 각 SoundBank의 **실제 데이터 크기**를 계산할 수 있게 됩니다.

---

## 4. SoundBank 크기 확인하기

1. SoundBank Manager에서 **Default Work Unit**을 펼칩니다.
2. 그 아래에 프로젝트에 포함된 두 개의 SoundBank가 표시됩니다.
   - `DCP_the_core`
   - `Main`

각 SoundBank의 “Size” 열에서 현재 SoundBank가 사용하는 **실제 메모리 크기**(바이트 단위)를 확인할 수 있습니다.

## 5. SoundBank 최대 크기 설정하기 (Max Size)

이제 각 SoundBank에 **메모리 예산(최대 크기)**을 설정합니다.

| SoundBank 이름 | 설정할 Max Size      |
| -------------- | -------------------- |
| DCP_the_core   | 6,000,000 (약 6MB)   |
| Main           | 9,500,000 (약 9.5MB) |

SoundBank Manager에서 각 SoundBank의 **Max Size** 열에 위 값을 입력하세요.

---

## 6. 메모리 초과 상태 확인하기

Max Size를 설정한 후, Wwise가 자동으로 **SoundBank의 상태를 시각적으로 표시**합니다.

- 두 SoundBank의 **데이터 크기(Actual Size)**가 **빨간색**으로 표시됩니다.
- 이는 각 SoundBank가 **지정된 메모리 예산을 초과했음**을 의미합니다.
- **Free Space** 열이 음수로 표시되는데,
  이 숫자는 “예산에 맞추기 위해 줄여야 하는 데이터 양(바이트)”을 의미합니다.

예시:

| SoundBank    | Size (실제 크기) | Max Size  | Free Space |
| ------------ | ---------------- | --------- | ---------- |
| DCP_the_core | 6,700,000        | 6,000,000 | -700,000   |
| Main         | 10,200,000       | 9,500,000 | -700,000   |

> 🟥 빨간색 수치는 경고 표시로, SoundBank가 너무 커서 최적화가 필요함을 알립니다.

## 7. 정리 및 다음 단계

이 단원에서는 **SoundBank의 메모리 관리** 개념을 배웠습니다.

### 🧠 핵심 정리

- **SoundBank** = 게임 내 오디오 데이터를 묶어둔 단위
- **Max Size (메모리 예산)** = SoundBank에 허용되는 최대 용량
- **Free Space가 음수** → 메모리 초과 상태
- 메모리 예산은 **그래픽, AI, 물리 등 다른 시스템과의 밸런스를 맞추기 위해** 설정됨
- 초과된 SoundBank는 나중에 불필요한 오디오를 제거하거나 압축을 통해 줄일 수 있음

## 1. 오디오 변환 개념 이해하기

### 🎯 변환(Conversion)의 목적

- **SoundBank 크기 감소**
  → WAV 파일은 비압축 PCM 형식이라 용량이 큼.
  → 압축 포맷으로 변환하면 메모리 사용량을 크게 줄일 수 있음.

### 🎚️ 변환 시 고려할 수 있는 요소

| 요소                             | 설명                                           | 영향                          |
| -------------------------------- | ---------------------------------------------- | ----------------------------- |
| **샘플 레이트(Sample Rate)**     | 초당 소리 샘플의 개수. 낮출수록 파일 크기 감소 | 음질 저하 가능                |
| **채널 수(Channel)**             | 스테레오 → 모노로 변환 가능                    | 공간감 손실                   |
| **포맷(Format)**                 | PCM(무압축) → Vorbis(압축)                     | 파일 크기 대폭 감소           |
| **모노 믹스 다운(Mono Downmix)** | 좌우 채널을 하나로 합침                        | 음상(Position) 정보 일부 손실 |

> ⚠️ 변환은 음질에 영향을 주지만, 메모리 최적화를 위해 필수적인 타협이 될 수 있음.

## 2. Conversion Settings ShareSet 만들기

Wwise에서는 **Conversion Settings**를 개별 파일마다 적용할 수도 있지만,

보통은 여러 오브젝트에 한 번에 적용하기 위해 **ShareSet(공유 설정)**을 만듭니다.

### 🧭 단계별 실습

1. **레이아웃 변경:**
   - 메뉴 바 → `Layouts > Designer (F5)` 클릭
2. **오브젝트 선택:**
   - `Project Explorer` → `Audio` 탭 선택
   - `Actor-Mixer Hierarchy > Default Work Unit > Magic Actor-Mixer` 선택
3. **Conversion 탭 열기:**
   - `Property Editor` 하단의 **Conversion** 탭 클릭
4. **새 ShareSet 생성:**
   - `More options` 버튼 클릭 → `New` 선택
   - 대화 상자에서 Name에 **“SFX”** 입력 → **OK 클릭**
5. **ShareSet 적용 확인:**
   - `SFX` ShareSet이 `Magic Actor-Mixer`에 자동으로 할당됨
   - Property Editor에서 `SFX` ShareSet을 더블 클릭하면
     → **Conversion Settings Editor** 창이 열림

### 🧩 Conversion Settings Editor 구조

| 영역          | 설명                                                                                |
| ------------- | ----------------------------------------------------------------------------------- |
| **상단 영역** | ShareSet에 공통으로 적용되는 변환 매개변수 표시                                     |
| **하단 영역** | 이 ShareSet에 연결된 오디오 파일 목록, 각 파일의 샘플 레이트·채널·원본 크기 등 표시 |

> 🟦 Audio Source 이름이 파란색이고 Converted Size에 “–” 표시 →
>
> 아직 변환이 수행되지 않은 상태를 의미함.

---

### 💡 Tip: 사운드 유형별 ShareSet 활용

- **SFX (효과음)** → 높은 다이내믹 레인지, 보통 중간 품질로 충분
- **Voice (대사)** → 낮은 샘플 레이트 사용 가능 (음질 손실 적음)
- **Music (음악)** → 주파수 범위가 넓기 때문에 낮은 품질 변환에 민감함 → 별도 ShareSet 권장

## 3. Vorbis 압축 포맷 적용하기

### 🧠 개념 요약

- Wwise는 **MP3 대신 Vorbis** 포맷을 지원함.
- Vorbis는 MP3와 유사하지만 **더 좋은 음질 대비 압축 효율**로 인해
  현재 **게임 오디오 통합의 표준**으로 자리 잡음.

---

### ⚙️ Vorbis 설정 방법

1. `Format` 목록에서 **Vorbis** 선택
2. 새로 표시되는 **Quality 속성** 확인

| 속성        | 설명                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------- |
| **Quality** | 변환 후 음질 수준 ( -2 ~ 10 ) -2 → 최저 품질 (가장 작은 크기) 10 → 최고 품질 (가장 큰 크기) |

> 🎯 권장값: 4
>
> - 파일 크기를 70~80% 줄이면서도
>   대부분의 경우 “허용 가능한 음질” 유지.

---

### 🖱️ 변환 실행

1. **Convert 버튼 클릭**
2. 시스템 플랫폼(Windows/Mac) 선택
3. 다시 **Convert 클릭**하여 변환 실행

변환 완료 후:

- Audio Source 이름 색상: 파란색 → 흰색(또는 검정색)으로 변경
- “Converted Size” 열에 변환 후 파일 크기 표시

> ✅ 대부분의 파일이 70~80% 용량 절감됨.

## 4. SoundBank 다시 생성하고 결과 확인하기

변환된 설정은 **SoundBank 생성 시에도 적용**됩니다.

### 📌 단계

1. 메뉴 바 → `Layouts > SoundBank (F7)` 선택
2. **SoundBank Manager** 오른쪽 상단 → `Generate All` 클릭

4. 완료 후 `Close` 클릭

### 📊 결과 확인

- **Main SoundBank**:
  변환 덕분에 데이터 크기가 **메모리 예산 내로 들어옴** ✅
- **DCP_the_core SoundBank**:
  여전히 예산 초과 → 추후 별도 조정 예정.

## 5. 추가 팁: 기본 Conversion Settings 지정하기

**Default Conversion Settings ShareSet** 선택

> 🧩 계층 구조에 따라
>
> 하위 오브젝트는 상위 오브젝트의 Conversion Settings를 자동 상속합니다.

| **Quality 속성**        | 변환 음질 수준 (-2~10), 권장값 4                           |
| **적용 시점**           | SoundBank 생성 시 자동 적용                                |
| **효과**                | 평균 70~80% 용량 절감, 메모리 예산 관리 용이               |

✅ **이 강의의 핵심 요약**

> “Wwise에서는 오디오 파일을 설계 후 마지막 단계에서
>
> Conversion Settings와 ShareSet을 사용해 변환 품질을 조정한다.
>
> Vorbis 압축 포맷은 음질 손실을 최소화하면서도 SoundBank의 크기를 대폭 줄이는
>
> 실질적인 게임 오디오 최적화 도구이다.”

## 1. 오디오 변환 개념 이해하기

### 🎧 오디오 변환이란?

- **WAV, ADPCM, Vorbis 등** 다양한 형식으로 오디오를 변환할 수 있습니다.
- 변환 시 다음과 같은 요소들이 변경될 수 있습니다:
  - **Sample Rate (샘플레이트)**: 초당 샘플 수를 줄이면 파일 크기는 줄지만 음질이 저하됨.
  - **Bit Depth (비트 깊이)**: 비트 깊이가 낮을수록 정밀도가 떨어짐.
  - **Channels (채널 수)**: 스테레오 → 모노 변환 시, 파일 크기 절약 가능.
  - **Compression (압축 방식)**: 비손실/손실 압축에 따라 음질 차이가 발생.

💡 **핵심 개념**:

SoundBank의 크기를 줄이기 위해 오디오를 변환하지만,

그 결과물이 **청감상 문제가 없는 수준인지** 반드시 들어보고 확인해야 합니다.

## 1. SoundBank 용량 관리 개념 이해하기

### 💡 SoundBank란?

- Wwise에서 게임 내 오디오를 **패키지 형태로 묶어 저장하는 단위**입니다.
- 각 SoundBank는 메모리를 차지하며,
  게임 플랫폼(콘솔, 모바일 등)마다 메모리 예산이 제한되어 있습니다.

### ⚙️ 용량 줄이는 방법 2가지

1. **오디오 파일 변환 / 압축**
   - 샘플레이트, 채널 수, 압축 형식을 조정하여 크기를 줄임.
2. **오디오 제외 (이번 강의의 핵심)**
   - 불필요하거나 중복되는 사운드를 SoundBank에서 제외시켜 용량을 절약.

> 🔸 하지만, 사운드가 게임 플레이에 직접 필요한 경우에는 제거하면 안 됩니다.
>
> 특히 유일한 사운드(예: 특정 효과음 하나뿐인 경우)는 제외하면 게임 체험에 바로 영향을 미칩니다.

---

## 2. Random Container 개념 이해하기

### 🎲 Random Container란?

- 여러 개의 사운드 파일을 **무작위로 재생**할 수 있는 Wwise의 오브젝트입니다.
- 예를 들어 “점프(Jump)” 사운드가 항상 똑같이 들리면 단조롭기 때문에,
  여러 개의 점프 음원을 넣고 Random Container로 묶어
  **매번 다른 사운드가 재생되도록** 설정합니다.

### ⚙️ 구조 예시

```
Main Character
 └── Jump (Random Container)
       ├── jump_01.wav
       ├── jump_02.wav
       └── jump_03.wav
 └── Pain (Random Container)
       ├── pain_01.wav
       ├── pain_02.wav
       ├── pain_03.wav
```

이 경우, jump_01~03 중 하나가 랜덤하게 재생됩니다.

즉, 몇 개를 제외하더라도 완전히 사운드가 사라지지 않고

“조금 덜 다양한” 소리로만 바뀌게 됩니다.

---

## 3. SoundBank에서 오디오 제외하기

### 🎯 목표

- 파일을 실제로 삭제하지 않고,
  **SoundBank에 포함되지 않도록 설정**합니다.
- 나중에 다시 체크하면 언제든지 다시 포함 가능.

### 🧭 단계

1. **Project Explorer**에서 아래 경로를 엽니다:

   ```
   Actor-Mixer Hierarchy > Default Work Unit > Main Character
   ```

2. **Main Character** 오브젝트를 펼칩니다.
   - 그 아래에 **Jump**와 **Pain**이라는 Random Container가 있습니다.
3. 각각의 Random Container를 펼쳐서,

   **내부에 있는 Sound SFX 오브젝트들을 확인**합니다.

4. Sound SFX 항목 옆의 **체크 박스(✔)** 를 해제합니다.
   - 체크 해제된 파일은 SoundBank에 **포함되지 않음(Excluded)** 상태가 됩니다.

> ⚠️ 주의
>
> - 체크 해제는 “삭제(Delete)”가 아닙니다.
> - 파일은 프로젝트에 남아 있으며,
>   필요할 때 언제든 다시 체크하여 SoundBank에 추가할 수 있습니다.

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380556/notion-blog/_/WWISE/Wwise_/19_SoundBank_/image_6.png)

## 4. 변경된 컨테이너 사운드 확인하기

### 🎧 테스트 방법

1. Jump 또는 Pain Random Container를 선택하고 **스페이스 바(Space)** 를 눌러 재생합니다.
2. 일부 사운드가 제외된 상태이므로,
   - 예전보다 **재생되는 소리의 종류가 줄어듦**
   - 하지만 여전히 여러 사운드가 랜덤하게 들림

즉, 사운드의 **다양성은 줄었지만 품질이나 기능은 유지**됩니다.

그리고 SoundBank 용량은 이전보다 감소합니다.
