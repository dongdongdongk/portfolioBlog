## 1. Early Reflections (초기 반사음)

소리가 벽에 처음 부딪혀 돌아오는 반사음. 방의 크기와 모양을 느끼게 해주는 가장 중요한 요소입니다.

### **✅ V Early reflections (체크박스)**

```
켜짐: 초기 반사음 활성화
꺼짐: 리버브만 사용 (초기 반사음 없음)

추천: ✓ 항상 켜기
→ 현실적인 공간감을 위해 필수

```

### **ER Pattern (반사 패턴)**

```
옵션: Small Room, Large Room, Hall 등

Small Room: 작은 방 (사무실)
- 빠르고 밀집된 반사
- 친밀하고 따뜻한 느낌

Large Room: 큰 방
- 넓게 퍼진 반사
- 개방적인 느낌

Hall: 홀/강당
- 매우 넓은 반사
- 웅장한 느낌

선택 기준: 실제 게임 공간 크기에 맞춰 선택

```

### **Room Size (방 크기)**

```
값: 16 (예시)
범위: 보통 10~100

작은 값 (10~30): 작은 방
- 빠른 반사
- 친밀한 공간

큰 값 (50~100): 큰 방
- 느린 반사
- 넓은 공간

사용: ER Pattern과 함께 조절
→ 같은 Small Room이라도 Size로 미세 조정

```

### **Surround Delay (서라운드 딜레이)**

```
값: 0 (예시)
범위: 0~100ms

용도: 5.1/7.1 서라운드 사운드에서 뒤쪽 스피커 딜레이

0ms: 앞뒤 동시 재생
20ms: 뒤쪽이 약간 늦게 → 공간감 증가

게임 사용: 대부분 0~10ms로 유지
→ 너무 크면 부자연스러움

```

## 2. Reverb (리버브 본체)

초기 반사 이후 계속 이어지는 울림. "웅~~~" 하고 길게 남는 소리입니다.

### **Pre Delay (프리 딜레이)**

```
값: 20ms (예시)
범위: 0~200ms

의미: 원본 소리 → 리버브 시작까지 지연 시간

작은 값 (0~10ms): 작은 방
- 즉시 울림 시작
- 답답할 수 있음

중간 값 (20~50ms): 일반적
- 자연스러운 공간감
- 가장 많이 사용

큰 값 (50~100ms): 큰 공간
- 명확한 원본 소리
- 공간이 매우 넓게 느껴짐

공식: Pre Delay ≈ 방 크기 / 소리 속도
→ 큰 방 = 큰 Pre Delay

```

### **Decay Time (감쇠 시간)**

```
값: 1.1초 (예시)
범위: 0.1~10초

의미: 리버브가 사라지는데 걸리는 시간

짧음 (0.2~0.5초): 작은 방/흡음재 많음
- 사무실, 카펫 깔린 방
- 명료함

중간 (0.8~1.5초): 일반적인 공간
- 복도, 큰 사무실
- 자연스러움

김 (2~4초): 큰 공간
- 던전, 성당, 동굴
- 웅장함, 으스스함

매우 김 (5초+): 특수 공간
- 거대한 동굴, 비현실적 공간

```

### **HF Damping (고음 감쇠)**

```
값: 1.05 (예시)
범위: 0~2.0 (배율)

의미: 고음이 얼마나 빨리 사라지는가

낮음 (0.5~0.8): 밝은 공간
- 타일, 유리, 금속 벽
- 화장실, 복도
- 날카롭고 반짝임

중간 (0.9~1.2): 일반적
- 벽과 가구 적절히 섞임
- 사무실, 일반 방

높음 (1.5~2.0): 어두운 공간
- 카펫, 커튼, 흡음재
- 던전 (돌벽)
- 둔탁하고 먼 느낌

재질별 추천:
- 화장실 (타일): 0.1~0.3 (매우 밝음)
- 사무실: 1.0~1.2
- 던전 (돌): 0.5~0.8
- 카펫 방: 1.5~2.0

```

### **Density (밀도)**

```
값: 72% (예시)
범위: 0~100%

의미: 리버브 소리의 촘촘함

낮음 (30~50%): 성긴 반사
- 개별 에코 들림
- 동굴 같은 느낌

중간 (60~80%): 일반적
- 부드러운 리버브
- 대부분의 방

높음 (90~100%): 매우 촘촘
- 부드럽고 매끄러움
- 음악적 리버브

게임 추천: 70~80%
→ 자연스러우면서 깨끗함

```

### **Room Shape (방 모양)**

```
값: 55 (예시)
범위: 0~100

의미: 방의 기하학적 모양

낮음 (0~30): 정사각형/직육면체
- 규칙적인 반사
- 사무실, 방

중간 (40~60): 일반적 모양
- 자연스러운 불규칙성

높음 (70~100): 불규칙한 모양
- 복잡한 반사
- 동굴, 이상한 공간

게임 사용: 대부분 40~60으로 유지

```

### **Quality (품질)**

```
값: 10 (예시)
범위: 1~50

의미: 계산 품질 (CPU 사용량)

낮음 (1~5): 낮은 품질
- CPU 사용 적음
- 거친 소리

중간 (8~15): 일반적
- 균형잡힌 품질
- 대부분 사용

높음 (20~50): 최고 품질
- CPU 사용 많음
- 매우 부드러움
- 시네마틱용

게임 추천: 10 정도
→ 성능과 품질의 균형

```

### **Diffusion (확산)**

```
값: 72% (예시)
범위: 0~100%

의미: 리버브가 얼마나 부드럽게 퍼지는가

낮음 (30~50%): 날카로운 에코
- 개별 반사 명확
- 타일, 금속

중간 (60~80%): 자연스러움
- 대부분의 공간
- 일반적인 방

높음 (90~100%): 매우 부드러움
- 흐릿한 리버브
- 음악용

게임 추천: 70~80%

```

### **Stereo Width (스테레오 폭)**

```
값: 135% (예시)
범위: 0~200%

의미: 좌우 퍼짐 정도

좁음 (50~80%): 모노에 가까움
- 중앙에 집중
- 작은 공간

일반 (100~120%): 자연스러움
- 현실적인 퍼짐

넓음 (150~200%): 매우 넓음
- 과장된 공간감
- 특수 효과

게임 추천: 100~130%
→ 자연스러운 공간감

```

## 3. Tone (음색 조절)

리버브의 주파수별 음량 조절. EQ(이퀄라이저)와 비슷합니다.

### **Filter Band 1 - Low Shelf (저음 선반)**

```
Insert: ER + Reverb (적용 대상)
Curve: Low Shelf (저음 선반형)
Gain: -96.3 dB (음소거)
Frequency: 590 Hz

의미: 590Hz 이하 저음 조절

사용 예:
Gain -96.3: 저음 완전 제거
Gain 0: 변화 없음
Gain +6: 저음 증폭

용도:
- 웅웅거리는 소리 제거
- 명료도 향상

게임 추천: -3 ~ 0 dB
→ 약간 줄이면 깔끔

```

### **Filter Band 2 - Peaking (중음 피킹)**

```
Insert: ER + Reverb
Curve: Peaking (종 모양)
Gain: -23 dB
Frequency: 6000 Hz
Q: 1 (폭)

의미: 6000Hz 주변만 조절

사용 예:
Gain -23: 해당 주파수 많이 줄임
→ 날카로운 고음 제거

Frequency: 조절할 주파수 선택
Q: 1 = 넓게, 10 = 좁게

용도:
- 특정 주파수 문제 해결
- "쉿" 소리 줄이기

게임 사용: 필요시만 조절

```

### **Filter Band 3 - High Shelf (고음 선반)**

```
Insert: ER + Reverb
Curve: High Shelf (고음 선반형)
Gain: -2 dB
Frequency: 8440 Hz

의미: 8440Hz 이상 고음 조절

사용 예:
Gain -2: 고음 약간 줄임
→ 부드러운 리버브

Gain -10: 고음 많이 제거
→ 어두운 공간 (던전)

Gain +3: 고음 증폭
→ 밝은 공간 (화장실)

공간별 추천:
- 화장실: 0 ~ +3 dB (밝게)
- 사무실: -2 ~ 0 dB
- 던전: -6 ~ -3 dB (어둡게)

```

## 4. Output Levels (출력 레벨)

각 요소의 최종 음량 조절입니다.

### **Reverb Levels (리버브 레벨)**

```
Front: 앞쪽 스피커 (좌우)
Rear: 뒤쪽 스피커 (서라운드)
Center: 센터 스피커
LFE: 서브우퍼 (저음)

대부분 0 dB로 유지
→ 특별한 이유 없으면 변경 불필요

```

### **Output Levels (출력 레벨)**

```
Dry: 원본 소리
- -96.3 dB = 음소거
- Aux Bus는 Wet(리버브)만 보내므로 음소거

ER: Early Reflections (초기 반사)
- 값: 설정에 따라 조절
- 추천: -6 ~ 0 dB

Reverb: 리버브 본체
- 값: 설정에 따라 조절
- 추천: -6 ~ 0 dB

Dry/ER/Reverb 밸런스:
- Dry: -96 (Aux Bus에서는 항상)
- ER: -3 dB (초기 반사)
- Reverb: -6 dB (리버브)
→ 자연스러운 비율

```

## 🎯 초보자를 위한 빠른 가이드

### **꼭 조절해야 할 3가지:**

```
1. Decay Time (감쇠 시간)
   → 방 크기에 맞춰 조절
   작은 방: 0.3~0.6초
   큰 방: 1.5~3.0초

2. HF Damping (고음 감쇠)
   → 재질에 맞춰 조절
   밝은 곳 (타일): 0.1~0.5
   일반: 0.8~1.2
   어두운 곳 (돌): 1.5~2.0

3. Pre Delay (프리 딜레이)
   → 공간감 조절
   작은 방: 5~15ms
   큰 방: 30~50ms

```
