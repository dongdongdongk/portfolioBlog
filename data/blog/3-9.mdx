### 1. Notice

```jsx
1. 글목록
	- 글 목록을 10개 출력
	-  URL   : /notice/list.확장자
		 Param : X
		 Method: GET
		 JSP   : /WEB-INF/views/notice/list.jsp

2. 글쓰기
	- 글제목, 작성자, 내용을 입력
		1) 입력폼
		URL    : /notice/add.확장자
		param  : X
	  Method : GET
		JSP    : /WEB-INF/views/notice/add.jsp

		2) Insert
		URL    : /notice/add.확장자
		param  : 글제목, 글작성자,글내용
	  Method : POST


3. 글상세보기
	- 글목록에서 제목을 클릭했을때 해당 글이 상세 내용 출력
		URL    : /notice/detail.확장자
		param  : 글번호
	  Method : GET
		JSP    : /WEB-INF/views/notice/detail.jsp

4. 글 수정
	- 작성자만 글을 수정, 제목과 내용만 수정가능
		1) 수정폼
		URL    : /notice/update.확장자
		param  : 글번호
	  Method : GET
		JSP    : /WEB-INF/views/notice/update.jsp

		2) Update
		URL    : /notice/update.확장자
		param  : 글제목, 글내용, 글번호
	  Method : POST

5. 글 삭제
	- 작성자만 글 삭제
		URL    : /notice/delete.확장자
		param  : 글번호
	  Method : GET

```

### 2. Qna

```jsx
1. Notice와 기능이 같음

2. 답변(댓글) 작성
		1) 답글입력폼
		URL    : /qna/reply.확장자
		param  : 글번호
	  Method : GET
		JSP    : /WEB-INF/views/qna/reply.jsp

		2) 답글 Insert
		URL    : /qna/reply.확장자
		param  : 글제목, 글내용, 글번호
	  Method : POST
```

### 3. Comment

```jsx
** AJAX 사용
** JSP가 따로 없음

1 댓글 쓰기
URL       :  /bankbook/commentAdd
Method    :  POST
Parameter : bookNum, writer, contents

2. 댓글 리스트
URL        : /bankbook/commentList
Method     : GET
Parameter  : page, bookNum

3. 댓글 수정
URL        : /bankbook/commentUpdate
Method     : POST
Parameter  : num, contents

4. 댓글 삭제
URL        : /bankbook/commentDelete
Method     : POST
Parameter  : num
```
