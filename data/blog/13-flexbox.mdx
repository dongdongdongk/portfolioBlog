# { Flexbox 이해하기 }

## 1. Flexbox란 무엇인가?

```jsx
Flexbox(Flexible Box Layout)는 CSS의 레이아웃 모델 중 하나로, 요소들을 더 쉽게 정렬하고 배치할 수 있게 해줍니다.

Flexbox를 사용하면 요소들이 가로 또는 세로 방향으로 자유롭게 늘어나거나 줄어들 수 있어, 레이아웃을 유연하게 조정할 수 있습니다.

Flexbox 레이아웃을 사용하기 위해서는 부모 요소에 display: flex를 설정하여 Flex 컨테이너로 만들고,

이 안의 자식 요소들이 자동으로 Flex 항목이 되어 Flexbox의 배치 규칙을 따르게 됩니다.
```

## 2. Flex 컨테이너와 Flex 항목

```jsx
Flex 컨테이너:

		display: flex를 사용하여 정의된 요소입니다. 이 요소는 Flexbox 레이아웃을 사용할 준비가 된 부모 요소가 됩니다.

Flex 항목:

		Flex 컨테이너 안에 포함된 모든 자식 요소들을 의미합니다. 이 자식 요소들은 Flexbox의 영향을 받으며 유연하게 배치됩니다.
```

## 3. 주요 프로퍼티

### Flex 컨테이너에 적용할 수 있는 프로퍼티:

```jsx
flex-flow:

		주축 방향(flex-direction)과 줄바꿈 여부(flex-wrap)를 정의합니다.

justify-content:

		주축 방향(가로축 또는 세로축)에서 항목을 어떻게 정렬할지 결정합니다. (예: 시작, 끝, 가운데, 균등 간격 등)

align-content:

		여러 줄이 있을 때 각 줄 간의 간격을 설정합니다.

align-items:

		단일 축에서의 항목을 어떻게 정렬할지 결정합니다. (예: 시작, 끝, 가운데, 스트레치 등)
```

### Flex 항목에 적용할 수 있는 프로퍼티:

```jsx
order:

		항목의 순서를 변경합니다. 기본값은 0이며, 값이 낮을수록 먼저 배치됩니다.

flex:

		항목의 크기를 어떻게 늘리고 줄일지를 설정합니다. 이 프로퍼티는 flex-grow, flex-shrink, flex-basis의 단축형입니다.

align-self:

		개별 항목을 컨테이너 내에서 다르게 정렬하고 싶을 때 사용합니다. align-items의 값을 덮어쓸 수 있습니다.
```

## 1. Flexbox 기초 설정

```jsx
Flex Container 생성:

		Flexbox 레이아웃을 만들기 위해서는 먼저 요소에 display: flex 또는 display: inline-flex 속성을 추가하여

		'flex 컨테이너'로 지정해야 합니다.

Flex 항목:

		Flex 컨테이너 안에 있는 모든 자식 요소들은 자동으로 'flex 항목'이 됩니다.

		즉, flex 컨테이너 안에 있는 div 요소들(item-1부터 item-6)은 모두 flex 항목으로 취급됩니다.
```

## 2. 기본적인 Flexbox 동작

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381538/notion-blog/_/_/CSS/_CSS_/_13_Flexbox_/image_1.png)

```jsx
display: flex를 사용하여 flex 컨테이너를 설정한 후의 기본 동작을 설명합니다.
```

```jsx
한 행에 배치:

		Flex 컨테이너로 지정하면 기본적으로 모든 flex 항목들이 한 행에 배치됩니다.

		이는 블록 레벨 요소의 기본 동작과 다릅니다.

요소의 높이와 너비:

		기본적으로 flex 항목들은 사용 가능한 높이와 너비를 차지하려고 합니다.

		예를 들어, 높이가 지정되지 않은 항목들은 가장 높은 항목의 높이를 따르게 됩니다.

너비 조정:

		flex 컨테이너의 너비를 줄이면 요소들의 너비도 줄어듭니다.

		이때 최소 너비는 콘텐츠가 요구하는 최소 공간을 넘지 않는 범위 내에서 조정됩니다.
```

## 3. `display: flex` vs `display: inline-flex`

```jsx
display: flex:

		Flex 컨테이너가 블록 레벨 요소로 동작합니다. 이는 flex 항목들이 한 행에 배치되고,

		부모 컨테이너의 너비를 꽉 채우는 등의 전형적인 블록 레벨 동작을 따릅니다.

display: inline-flex:

		Flex 컨테이너가 인라인 요소처럼 동작합니다.

		이는 컨테이너의 크기가 내용에 따라 결정되고, 부모 요소의 너비를 가득 채우지 않습니다.
```

# { ‘flex-direction(축 방향)’ & flex-wrap(줄바꿈)’ 활용하기 }

## 1. Flexbox의 자동 적용 프로퍼티

```jsx
Flexbox를 사용할 때 자동으로 적용되는 두 가지 기본 프로퍼티는 다음과 같습니다:
```

```jsx
flex-direction:

		Flex 항목들이 배치되는 기본 방향을 설정합니다.

		기본값은 row로, 이는 항목들이 행 방향(수평)으로 배치된다는 것을 의미합니다.

flex-wrap:

		Flex 항목들이 한 줄에 다 담기지 않을 경우 줄바꿈을 할지 여부를 설정합니다.

		기본값은 nowrap으로, 항목들이 한 줄에 모두 배치되도록 강제합니다.
```

## 2. `flex-direction` 프로퍼티

```jsx
flex-direction 프로퍼티는 Flex 컨테이너 안의 항목들이 배치되는 방향을 결정합니다. 다음 네 가지 값을 가질 수 있습니다:
```

```jsx
row (기본값):

		항목들이 왼쪽에서 오른쪽으로 수평 배치됩니다.

row-reverse:

		항목들이 오른쪽에서 왼쪽으로 수평 배치됩니다. 행의 시작점과 끝점이 반대로 됩니다.

column:

		항목들이 위에서 아래로 수직 배치됩니다. 블록 레벨 요소의 동작과 유사합니다.

column-reverse:

		항목들이 아래에서 위로 수직 배치됩니다. 열의 시작점과 끝점이 반대로 됩니다.
```

## 예제: `flex-direction`의 다양한 값

### **기본값 `row`**:

```jsx
.flex-container {
  display: flex;
  flex-direction: row; /* 기본값 */
}

* 동작: 항목들이 수평으로 나란히 배치됩니다.
```

### **`row-reverse`**:

```jsx
.flex-container {
  display: flex;
  flex-direction: row-reverse;
}

* 동작: 항목들이 수평으로 배치되지만, 순서가 반대로 나열됩니다. 예를 들어,

	첫 번째 항목이 오른쪽에, 마지막 항목이 왼쪽에 배치됩니다.
```

### **`column`**:

```jsx
.flex-container {
  display: flex;
  flex-direction: column;
}

* 동작: 항목들이 수직으로 나란히 배치됩니다.
```

### **`column-reverse`**:

```jsx
.flex-container {
  display: flex;
  flex-direction: column-reverse;
}

* 동작: 항목들이 수직으로 배치되지만, 순서가 반대로 나열됩니다.

	예를 들어, 첫 번째 항목이 아래에, 마지막 항목이 위에 배치됩니다.
```

## 3. `flex-wrap` 프로퍼티

```jsx
flex-wrap 프로퍼티는 Flex 컨테이너의 너비나 높이가 부족할 때, flex 항목들이 줄바꿈을 할지 결정합니다.

다음 세 가지 값을 가질 수 있습니다:
```

```jsx
nowrap (기본값):

		줄바꿈이 없이 모든 항목들이 한 줄에 배치됩니다. 화면 너비가 좁아져도 모든 항목이 한 줄에 유지됩니다.

wrap:

		항목들이 컨테이너의 너비를 넘어갈 경우, 줄바꿈을 하여 다음 줄에 배치됩니다.

wrap-reverse:

		줄바꿈이 있지만, 줄바꿈되는 방향이 반대로 설정됩니다. 즉, 아래에서 위로 줄바꿈이 됩니다.
```

## 예제: `flex-wrap`의 다양한 값

### **기본값 `nowrap`**:

```jsx
.flex-container {
  display: flex;
  flex-wrap: nowrap; /* 기본값 */
}

* 동작: 항목들이 한 줄에 모두 배치됩니다. 화면 너비가 좁아져도 줄바꿈이 일어나지 않습니다.
```

### **`wrap`**:

```jsx
.flex-container {
  display: flex;
  flex-wrap: wrap;
}

* 동작: 항목들이 한 줄에 다 담기지 않으면 자동으로 줄바꿈을 합니다.

	예를 들어, 너비가 350px인 항목이 한 줄에 다 담기지 않으면 다음 줄로 내려갑니다.
```

### **`wrap-reverse`**:

```jsx
.flex-container {
  display: flex;
  flex-wrap: wrap-reverse;
}

* 동작: 항목들이 줄바꿈을 하는데, 줄바꿈 방향이 반대가 됩니다.

	즉, 아래에서 위로 항목들이 추가됩니다.
```

# { 기본 축과 교차 축의 중요성 이해하기 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381540/notion-blog/_/_/CSS/_CSS_/_13_Flexbox_/image_2.png)

## **기본 축(main axis)**과 **교차 축(cross axis)**의 개념

```jsx
Flexbox 레이아웃을 이해하기 위해서는 flex-direction 프로퍼티가 설정하는

**기본 축(main axis)**과 **교차 축(cross axis)**의 개념을 명확히 이해하는 것이 중요합니다.

기본 축과 교차 축의 설정에 따라 Flex 항목들이 배치되는 방식이 달라집니다.
```

## 1. 축 방향(flex-direction)과 기본 축(main axis)

```jsx
flex-direction 프로퍼티는 Flex 컨테이너에서 항목들이 배치되는 기본 축의 방향을 결정합니다.

기본 축은 항목들이 주로 나열되는 방향이며, 교차 축은 이와 수직인 방향입니다.

기본 축(main axis):

		Flex 항목들이 배치되는 주된 방향.

교차 축(cross axis):

		기본 축과 수직인 방향.



* 쉽게 말하면 기본축 기본적으로 왼쪽에서 쌓여감

	교차 축은 왼쪽으로 하나하나 쌓여가다 아래로 쌓임 ( 세로 )
```

## flex-flow

```jsx
축 방향(flex-direction): Flex 컨테이너 내부의 아이템들이 정렬되는 기본 방향을 설정합니다.

row:

		아이템들이 가로로 정렬됩니다. (기본값)

column:

		아이템들이 세로로 정렬됩니다.

줄바꿈(flex-wrap): 아이템들이 Flex 컨테이너의 경계를 넘어갈 때 어떻게 배치되는지를 결정합니다.

nowrap:

		모든 아이템을 한 줄에 배치합니다. (기본값)

wrap:

		아이템들을 여러 줄에 걸쳐 배치합니다.

이 두 프로퍼티를 한 줄로 축약하여 사용할 수 있는데, 이때 사용하는 프로퍼티가 **flex-flow**입니다.

 /* flex-flow: row wrap; 합쳐서 하나로 작성 가능*/
```

## 2. 항목 정렬(`align-items`)

```jsx
항목 정렬(align-items):

Flex 컨테이너의 교차 축(cross-axis)을 기준으로 아이템을 정렬합니다.

교차 축은 기본 축과 직교하는 방향입니다.
```

```jsx
stretch: 아이템들이 교차 축을 따라 늘어납니다. (기본값)

center: 아이템들이 교차 축의 가운데에 정렬됩니다.

flex-start: 아이템들이 교차 축의 시작점에 정렬됩니다.

flex-end: 아이템들이 교차 축의 끝점에 정렬됩니다.

baseline: 아이템들이 텍스트 기준선에 맞춰 정렬됩니다.
```

### **`stretch`** (기본값)

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381541/notion-blog/_/_/CSS/_CSS_/_13_Flexbox_/image_4.png)

```jsx
설명:

		아이템들이 교차 축을 따라 가능한 최대한 늘어나도록 설정됩니다.

언제 사용되나요?:

		컨테이너의 높이나 너비에 맞춰 아이템의 크기가 자동으로 조정되길 원할 때 사용합니다.

예시:

		Flex 컨테이너의 높이가 200px이고, 아이템의 기본 높이가 따로 지정되지 않은 경우,

		stretch는 아이템의 높이를 200px로 자동 확장시켜서 모든 아이템이 컨테이너를 가득 채우도록 만듭니다.

```

```jsx
설명:

		아이템들이 교차 축의 끝점에 정렬됩니다.

		아이템들을 컨테이너의 아래쪽 또는 오른쪽(교차 축의 끝점)에 정렬하고 싶을 때 사용합니다.

예시:

```

### baseline

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381543/notion-blog/_/_/CSS/_CSS_/_13_Flexbox_/image_8.png)

```jsx
설명:

		아이템들이 각자의 텍스트 기준선에 맞춰 정렬됩니다. 텍스트의 기준선(baseline)이란,

		텍스트의 대부분이 위치하는 선을 말하며, 일반적으로 소문자의 바닥선에 해당합니다.

언제 사용되나요?:

		텍스트가 있는 아이템들이 서로 다른 높이로 되어 있을 때 텍스트 기준선을 맞추고 싶을 때 사용합니다.

예시:

		Flex 컨테이너 안에 여러 텍스트 요소들이 있는데, 각 요소의 폰트 크기가 다르거나 텍스트가 다르게 배치된 경우,

		baseline을 사용하면 각 텍스트의 기준선이 동일한 위치에 정렬됩니다.
```

## 3. 콘텐츠 맞춤(`justify-content`)

```jsx
콘텐츠 맞춤(justify-content):

		justify-content 프로퍼티는 Flex 컨테이너의 기본 축(main axis)을 기준으로 아이템들을 정렬하는 역할을 합니다.

		기본 축은 flex-direction으로 설정된 방향을 의미하며, 이를 통해 아이템들이 어떻게 배치될지를 결정합니다.
```

```jsx
flex-start: 기본 축의 시작점에서부터 아이템들을 정렬합니다. (기본값)

flex-end: 기본 축의 끝점에서부터 아이템들을 정렬합니다.

center: 기본 축의 중앙에 아이템들을 정렬합니다.

space-between: 첫 번째 아이템은 시작점에, 마지막 아이템은 끝점에, 나머지 아이템들은 그 사이에 동일한 간격으로 정렬됩니다.

space-around: 아이템들 사이에 동일한 간격을 두고 정렬합니다. 시작점과 끝점에도 일정한 간격이 있습니다.
```

### baseline

# { ‘align-content(콘텐츠 정렬)’ 알아보기 }

```jsx
align-content는 Flex 컨테이너가 여러 줄로 아이템들을 나눴을

때 각 줄들이 어떻게 배치될지를 정하는 프로퍼티입니다

**align-content**는 Flex 컨테이너의 **교차 축(cross-axis)**을 기준으로 여러 줄로

나뉜 Flex 아이템들이 어떻게 배치될지를 결정하는 프로퍼티입니다.

**align-items**와 비슷하지만, 여러 줄에 걸쳐 있는 아이템들의 배치를 조정하는 데 사용됩니다.

Flex 컨테이너에 콘텐츠가 단 한 줄만 있을 때는 **align-content**가 아무런 영향을 주지 않습니다.

* 쉽게 말하면 align-content 는 화면이 줄어들 때 교차축을 기준으로 항목을 정렬하게 된다
```


```jsx
order 프로퍼티는 Flex 항목의 순서를 지정할 때 사용합니다. 기본값은 0이며,
```

# { flex-grow(Flexbox 팽창)’ 이해하기 }

```jsx
flex-grow는 Flex 컨테이너의 가용 공간을 Flex 항목들이 어떻게 나눌지를 결정하는 프로퍼티입니다.

이 프로퍼티를 통해 각 항목이 Flex 컨테이너 내에서 얼마나 커질 수 있는지를 설정할 수 있습니다.
```

## `flex-grow`의 기본 개념

```jsx
기본값: 0 (항목이 가용 공간을 차지하지 않음)

사용 방법: flex-grow 값이 큰 항목이 Flex 컨테이너의 가용 공간을 더 많이 차지합니다.
```

## `flex-grow` 예제와 사용법

```jsx
<div class="container">
  <div class="item item-5">Item 5</div>
  <div class="item item-6">Item 6</div>
</div>
```

```jsx
.container {
  display: flex;
  flex-wrap: nowrap; /* Flex 항목이 한 줄에 나타나도록 설정 */
}

.item {
  width: 350px; /* 기본 너비 */
}

.item-5 {
  flex-grow: 1; /* 1의 가중치로 가용 공간 차지 */
}

.item-6 {
  flex-grow: 0; /* 가용 공간을 차지하지 않음 */
}
```

```jsx
위 코드에서는 .item-5가 flex-grow: 1;로 설정되어 있어, Flex 컨테이너의 가용 공간이 있으면 이를 차지합니다.

반면 .item-6는 flex-grow: 0;으로 설정되어 있어, 가용 공간을 추가로 차지하지 않고 기본 너비인 350px로 유지됩니다.
```

## `flex-grow` 값의 변화에 따른 동작

```jsx
모든 항목의 flex-grow가 0인 경우:

		모든 항목이 가용 공간을 추가로 차지하지 않고, 지정된 너비(예: 350px)만 사용합니다.

flex-grow 값이 1로 설정된 항목:

		가용 공간을 나눌 때, 해당 항목이 1의 비율로 공간을 나눠 차지합니다.

여러 항목에 다른 flex-grow 값을 설정하는 경우:

		예를 들어, item-5에 flex-grow: 1;, item-6에 flex-grow: 2;를 설정하면, 남은 공간이 3개의 비율로 나눠집니다.

		이 경우 item-5는 남는 공간의 1/3을 차지하고, item-6는 2/3를 차지합니다.
```

```jsx
늘려서 공간이 남으면 2 + 3 을해서 5개로 나눈 뒤 2 : 3 으로 공간을 차지
```

# { flex-shrink(Flexbox 축소)’ 적용하기 }

## Flexbox의 `flex-shrink` 프로퍼티

```jsx
flex-shrink 프로퍼티는 Flexbox 레이아웃에서 Flex 항목이 축소될 때의 비율을 결정하는 속성입니다.

이 속성은 Flex 컨테이너의 크기가 줄어들 때, 각 항목이 얼마나 축소될 수 있는지를 정의합니다.
```

## 기본 동작

```jsx
기본적으로 flex-shrink의 값은 1로 설정되어 있습니다.

이 값은 컨테이너의 크기가 줄어들 때 항목이 축소될 수 있음을 의미합니다.

만약 flex-shrink 값을 0으로 설정하면, 해당 항목은 절대로 축소되지 않습니다.
```

## `flex-shrink`의 원리

```jsx
flex-shrink는 컨테이너의 크기가 줄어들 때, 각 항목이 상대적으로 얼마나 축소될지를 결정합니다.

기본값은 1이지만, 값을 0으로 설정하면 항목은 축소되지 않습니다.

다른 항목에 대해 flex-shrink 값이 크면 해당 항목은 더 많이 축소됩니다.

flex-shrink는 Flex 항목이 수축될 때 적용되며, 다른 항목에 비해 축소되는 정도를 비율로 정의합니다.
```

# { ‘flex-basis(Flexbox 기본 크기)’와 ‘width(너비)’ 및 ‘height(높이)’ 비교하기 }

## Flexbox의 `flex-basis` 프로퍼티

```jsx
flex-basis는 Flex 항목의 기본 크기를 설정하는 프로퍼티로,

항목이 Flex 컨테이너 내에서 차지할 공간의 기준점을 정의합니다.
```

## `flex-basis`의 역할

```jsx
크기 정의:

	flex-basis는 기본 축을 따라 Flex 항목의 초기 크기를 설정합니다.

  기본 축은 flex-direction의 값에 따라 달라집니다.


기본 값:

		기본값은 auto로, auto로 설정되면 요소의 크기는 해당 항목의 width 또는 height 속성에 따라 결정됩니다.

flex-direction에 따른 작동:

		flex-direction: row: flex-basis가 width 속성을 대신합니다.

		flex-direction: column: flex-basis가 height 속성을 대신합니다.
```

## `flex-basis`의 `auto` 값

```jsx
flex-basis: auto: 이 값은 기본적으로 항목의 width나 height 속성에 의해 결정됩니다.

		**flex-direction: row**일 때: flex-basis: auto는 항목의 width 값과 동일하게 동작합니다.

		**flex-direction: column**일 때: flex-basis: auto는 항목의 height 값과 동일하게 동작합니다.
```

## `flex-basis`와 다른 프로퍼티와의 관계

```jsx
flex-grow: 컨테이너에 여유 공간이 있을 때 항목이 확장될 비율을 설정합니다.

flex-shrink: 컨테이너 크기가 줄어들 때 항목이 축소될 비율을 설정합니다.
```

```jsx
백분율 값 사용:

		flex-basis는 픽셀(px) 뿐만 아니라 백분율(%) 값으로도 설정할 수 있습니다.

		예를 들어 flex-basis: 10%는 컨테이너의 너비의 10%를 차지합니다.
```

```jsx
flex 축약 프로퍼티

flex-basis와 함께 flex-grow와 flex-shrink를 조합하여 flex 축약 프로퍼티를 사용할 수 있습니다.

		구문: flex: [flex-grow] [flex-shrink] [flex-basis];

		기본값: flex: 0 1 auto;

				flex-grow: 0

				flex-shrink: 1

				flex-basis: auto
```
