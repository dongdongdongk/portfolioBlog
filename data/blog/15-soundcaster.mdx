## 1. Soundcaster 개념 이해하기

- 🎮 **Soundcaster란?**
  - Wwise에서 제공하는 **오디오 시뮬레이션 도구**로,
    실제 게임처럼 여러 사운드를 동시에 재생하며 **믹싱(조화로운 소리 균형)** 을 테스트할 수 있음.
  - 즉, 개발 중인 사운드들이 서로 잘 어울리는지, 방해되지는 않는지를 확인하는 용도.
- 🧩 **왜 필요한가?**
  - 게임은 영상처럼 순서가 정해진 게 아니라, **플레이어의 행동에 따라 다양한 사운드가 동시 재생**됨.
  - 예:
    - 배경음악(BGM)
    - 발자국 소리
    - 총격음
    - 대사 등
  - 이때 사운드 간의 밸런스를 미리 조정해둘 필요가 있음 → Soundcaster가 그 역할 수행.
- 💡 **핵심 개념 요약**
  | 개념 | 설명 |
  | --------------------- | ------------------------------------------------------------- |
  | **Soundcaster View** | 여러 사운드를 동시에 재생·조정하는 공간 |
  | **Session** | Soundcaster의 작업 단위. 즉, 특정 테스트 상황을 모아놓은 세트 |
  | **Transport Control** | 개별 사운드를 재생·정지하는 조작 인터페이스 |
  | **Mixing Controls** | 볼륨, 피치, 로우패스 등을 조정해 사운드 밸런스 테스트 |

## 2. Soundcaster 세션 만들기

- **세션(Session)** 은 Soundcaster에서 **테스트할 오브젝트(사운드) 묶음**을 관리하는 단위.

### 🪜 만들기 절차

1. **Soundcaster 뷰 열기**
   - 메뉴에서 `Layouts → Soundcaster` 선택
   - 또는 Wwise 메인 인터페이스 하단 탭 중 `Soundcaster` 클릭
2. **새 세션 생성**
   - Soundcaster 뷰 상단에서 `New` 버튼 클릭
   - 원하는 이름을 입력 (예: “MainCharacterTest”)
3. **세션 저장**
   - “Save Session” 버튼 클릭
   - 나중에 같은 믹스 환경을 다시 불러올 수 있음

🧠 **핵심 포인트:**

Soundcaster 세션은 "테스트 무대"와 같음.

여러 사운드를 올려두고, 실제 게임처럼 동시에 재생하며 밸런스를 확인할 수 있다.

## 3. Project Explorer Search 사용하기

Soundcaster에 오브젝트를 추가하려면 **Project Explorer에서 오디오 오브젝트를 찾아야 함.**

### 🔍 검색 기능 사용법

1. **Project Explorer** 창 상단의 **Search 창 클릭**
2. 재생하려는 오브젝트 이름 입력 (예: “MainCharacter”, “Footstep”, “GunShot”)
3. 검색 결과에서 원하는 사운드를 선택

💡 **Tip:**

검색창은 대소문자 구분 없이 작동하며,

**Actor-Mixer Hierarchy** 내부의 모든 오브젝트를 대상으로 검색한다.

---

## 4. Soundcaster 세션에 오브젝트 추가하기

검색으로 찾은 사운드를 Soundcaster 세션에 등록해

여러 개를 동시에 재생할 수 있다.

### 🪜 추가 방법

1. Project Explorer에서 원하는 **오브젝트(예: Footstep, Voice, Ambience 등)** 찾기
2. 해당 오브젝트를 **Soundcaster 뷰로 드래그 앤 드롭**
3. Soundcaster 내에 **Transport Control 인스턴스**가 생성됨
   - 각각의 인스턴스는 **해당 오브젝트를 대표**함

### 🎛 Transport Control의 기능

| 버튼/항목          | 기능                                     |
| ------------------ | ---------------------------------------- |
| ▶️ Play            | 선택한 사운드 재생                       |
| ⏹ Stop            | 사운드 정지                              |
| 🔁 Loop            | 반복 재생                                |
| 🔊 Volume          | 해당 오브젝트의 볼륨 개별 조정           |
| 🎚 Pitch           | 음정 조정 (높게/낮게)                    |
| 🌫 Low-pass Filter | 고주파 감쇠 → ‘멀리 있는 느낌’ 표현 가능 |

📌 **중요:**

이제 여러 Transport Control을 동시에 재생시켜, 실제 게임 상황처럼 여러 소리가 겹칠 때의 밸런스를 확인할 수 있다.

---

## 5. Soundcaster 뷰에서 볼륨·피치·로우패스 조정하기

Soundcaster에서는 오브젝트별로 **실시간으로 파라미터를 조정**할 수 있다.

이는 실제 게임에서의 믹싱 작업을 미리 시뮬레이션하는 과정이다.

### 🎚 주요 조정 항목

1. **Volume (볼륨)**
   - 사운드의 크기 조절.
   - 예: 대사가 너무 크면 낮추고, 배경음이 묻히면 올린다.
2. **Pitch (피치)**
   - 음의 높낮이 조절.
   - 빠른 동작에는 피치를 높여 긴박감 연출 가능.
3. **Low-pass Filter (로우패스 필터)**
   - 일정 주파수 이상을 차단하여 **멀리 있는 소리나 벽 너머의 느낌** 연출 가능.
   - 값이 커질수록 고음이 줄고, 소리가 ‘답답’해진다.

## 1. Soundcaster 세션의 개념 이해하기

- **Soundcaster Session이란?**
  - Wwise 안에서 **사운드 오브젝트를 빠르게 테스트하고 조합**할 수 있는 **프리셋 레이아웃(Preset Layout)**.
  - 쉽게 말해, **게임 내 상황을 흉내내며 사운드를 미리 들어보는 공간**이라고 할 수 있습니다.
  - 게임을 실제로 실행하지 않아도, 캐릭터의 행동에 따라 어떤 소리가 어떤 볼륨으로 들리는지 바로 확인 가능.
- **왜 사용하는가?**
  - 개발 중에는 “발소리와 마법소리가 동시에 들릴 때 밸런스가 맞는가?” 같은 상황을 자주 테스트해야 합니다.
  - Soundcaster를 이용하면 이 과정을 **게임을 빌드하지 않고 바로 확인**할 수 있습니다.
  - 또한 여러 상황(예: Player, Enemy, Environment 등)에 맞춘 **다양한 세션을 따로 만들어 저장**할 수 있습니다.
- **활용 예시:**
  - 주인공이 **얼음 보석을 발사할 때** 발소리와 마법 사운드가 **자연스럽게 섞여 들리는지** 확인하는 데 사용합니다.

---

## 2. Soundcaster 뷰 열기

1. **Wwise 실행 후 프로젝트 파일 열기**
   - Module 15 프로젝트 파일을 엽니다.
   - 이미 해당 프로젝트에는 필요한 사운드 오브젝트들이 설정되어 있습니다.
2. **Soundcaster 뷰 열기**
   - 상단 메뉴 바에서 **`Views > Soundcaster`** 선택
   - 단축키: **`Shift + S`**
3. **결과 확인**
   - Soundcaster 창이 열립니다.
   - 창의 구성 요소:
     - **상단:** Transport Control (재생, 정지 등 기본 컨트롤)
     - **중간:** 게임의 **States**, **Switches**, **RTPC**, **Triggers**
       - → 이 부분은 실제 게임 상태나 변수에 따른 사운드 변화를 테스트할 때 사용됩니다.
     - **하단:** 빈 영역 (이곳에 **세션 오브젝트를 추가**하게 됩니다.)

## 3. 새로운 Soundcaster 세션 만들기

이제 실제로 **Soundcaster 세션을 생성**해봅시다.

1. **새 세션 만들기 버튼 열기**
   - Soundcaster 창의 **왼쪽 상단 모서리**에 있는 **`[>>]` 버튼** 클릭
   - 메뉴가 열리면 **`New`** 선택
2. **세션 이름 입력**
   - 새 대화 상자가 열립니다.
   - Work Unit 선택: **`Default Work Unit`**
   - Name 입력: **`Player`**
   - → 이는 주인공(Player) 관련 사운드 테스트용 세션이라는 의미입니다.
   - **OK** 클릭
3. **결과**
   - 새로운 **Soundcaster Session “Player”** 가 생성됩니다.
   - 왼쪽 상단 탭에 “Player Soundcaster Session”이 표시되면, 해당 세션이 **활성화 상태**입니다.

## 4. Soundcaster 세션 구성 이해하기

- 세션이 만들어졌지만, 처음에는 **빈 화면**만 보입니다.
- 자세히 보면 **점선으로 된 격자(grid)** 가 있습니다.
  - 이 격자 위에 **Sound Object**들을 **드래그 앤 드롭하여 배치**할 수 있습니다.
  - 예:
    - `Wizard Footstep` 사운드
    - `Ice Gem Spell` 사운드
  - 이런 식으로 여러 오브젝트를 넣고 각각 **재생, 정지, 볼륨, 파라미터 조절**이 가능합니다.
- **Project Explorer 확인하기**
  - Wwise 창 왼쪽의 **Project Explorer** 탭에서
    - 상단의 **“Sessions” 탭** 선택
    - 여기서 **Soundcaster Sessions** 폴더 안에 방금 만든 **Player Session**이 표시됩니다.
  - 이렇게 여러 세션을 만들어 **상황별로 빠르게 전환하며 테스트**할 수 있습니다.

## 1. Soundcaster Session 개념 이해하기

- **Soundcaster Session**은 Wwise에서 **사운드를 실시간으로 테스트하고 믹싱하기 위한 작업 공간**입니다.
- Soundcaster는 일종의 **사운드 콘솔(Transport 레이아웃)** 역할을 하며,
  - 이벤트를 불러와 재생하거나
  - Switch 값 변경, RTPC 값 조절 등을 실험할 수 있습니다.
- 게임 안에서 이벤트가 실제로 어떻게 작동하는지 시뮬레이션할 수 있기 때문에,
  **사운드 디자이너와 오디오 프로그래머 간 협업 시 매우 유용**합니다.

🧠 **핵심 개념 요약**

- 오브젝트(주로 Event)를 드래그하여 세션에 추가 → 버튼 형태의 모듈 생성
- 각 모듈에서 직접 재생, 정지, 파라미터 조정 가능
- Soundcaster는 프로젝트 내의 모든 Event, Switch, RTPC를 실험할 수 있는 “테스트 무대”

---

## 2. Project Explorer에서 오브젝트 검색하기

1. **Project Explorer 창**에서 **Events 탭**을 선택합니다.
   - 여기에는 프로젝트 내 모든 이벤트(Event) 오브젝트가 표시됩니다.
2. 상단 검색창에 **`player`** 입력 → 이름이나 Notes에 “player”가 포함된 모든 오브젝트가 **노란색으로 강조 표시**됩니다.
   - 예: `Foot_Player`, `Defeated_Player`, `Attack_Player` 등
   - 또한, 계층 구조가 자동으로 펼쳐져 관련 오브젝트를 쉽게 찾을 수 있습니다.
3. 주의할 점:
   - **버스(Bus) 오브젝트는 추가 불가**
     → Transport Control에서 재생할 수 없기 때문입니다.
   - 즉, Soundcaster Session에는 **이벤트(Event)** 중심으로 추가해야 합니다.

💡 **팁**

검색 결과는 이름뿐 아니라 **Notes** 필드에도 반응합니다.

예를 들어, `Grunt_Rhino`는 이름에 player가 없지만 Notes에 “player”가 있다면 검색 결과로 표시됩니다.

## 3. Soundcaster Session에 Event 추가하기

1. Project Explorer에서 **`Defeated_Player` Event**를 찾습니다.
2. 해당 이벤트를 **Soundcaster Session 좌측 상단**으로 **드래그 앤 드롭**합니다.
   - Soundcaster Session 안에 **작은 모듈(사각형 버튼)** 형태로 추가됩니다.
3. 모듈 안의 **재생(▶️) 버튼**을 클릭하여 재생 테스트를 진행합니다.
   - 이로써 `Defeated_Player` 이벤트가 트리거되어 관련 사운드가 재생됩니다.

🎯 **결과**

- 실제 게임을 실행하지 않고도 이벤트 작동과 사운드 반응을 즉시 확인 가능.

## 4. Switch 컨테이너와 Material 드롭다운 실험하기

1. 이번에는 **`Foot_Player` Event**를 Soundcaster Session으로 드래그합니다.
2. 추가 후 확인해보면, **Material 드롭다운 목록**이 새로 표시됩니다.
   - 이유: `Foot_Player` Event의 대상이 **Switch Container**이기 때문입니다.
   - Switch Container는 **하나의 이벤트가 여러 사운드 버전을 선택적으로 재생**하도록 하는 구조입니다.
     예: 캐릭터 발소리가 **“모래 / 돌 / 나무”** 재질에 따라 다르게 재생됨.
3. **Material 드롭다운에서 값 변경**
   - 예: Sand → Wood → Metal
   - 각 Switch 값에 따라 다른 사운드가 즉시 재생되어 재질별 발소리를 테스트할 수 있습니다.

🎧 **결론**

> Soundcaster를 통해 게임 내에서 Switch 값이 바뀔 때 사운드가 어떻게 변화하는지 손쉽게 시뮬레이션할 수 있습니다.

## 5. Game Sync 및 RTPC 표시 제어하기

- Soundcaster는 기본적으로 **현재 불러온 오브젝트와 관련 있는 Game Sync**(Switch, State, RTPC 등)만 표시합니다.
- 하지만, 특정 Game Sync를 모두 보고 싶을 때는:
  - 각 Game Sync 헤더 오른쪽의 **“Show All” 버튼**을 클릭합니다.

👉 **RTPCs 영역에서 Show All 선택**

- RTPC(Real-Time Parameter Control)는 실시간으로 변경 가능한 사운드 파라미터를 의미합니다.
  (예: 속도, 체력, 거리 등에 따라 볼륨/피치 조절)

이 버튼을 누르면 관련된 RTPC뿐 아니라 프로젝트 내의 모든 RTPC를 확인할 수 있습니다.

## 6. 다른 Event 추가 및 배치 실험

1. Wizard(주인공 캐릭터)의 다른 동작과 관련된 Event들을 추가합니다.

   예를 들어:
   - `Attack_Player`
   - `Jump_Player`
   - `Cast_Magic_Player`
   - `Defend_Player`
     등…

2. 드래그하여 Soundcaster Session으로 추가하면, 각각의 모듈이 생성됩니다.
3. **Soundcaster 모듈 재배치**
   - 드래그하여 위치를 자유롭게 옮길 수 있습니다.
   - 비슷한 카테고리끼리 묶어 배치하면 테스트하기 편리합니다.
4. **다양한 Event 재생 실험**
   - 여러 Event를 순서대로 혹은 동시에 재생하면서
     사운드 밸런스와 타이밍을 조정할 수 있습니다.

## 7. Volume, Pitch, LPF 속성 이해하기

- Soundcaster의 각 Event 모듈 오른쪽에는 **Volume**, **Pitch**, **LPF (Low-Pass Filter)** 입력란이 있습니다.
  → 하지만 현재는 값이 비어 있습니다.
- 이유:
  - Event 오브젝트 자체에는 이러한 속성이 직접 포함되어 있지 않기 때문입니다.
  - 해당 Event가 트리거하는 **사운드 오브젝트(예: Sound SFX, Random Container)** 를 포함시켜야
    이 파라미터들을 조정할 수 있습니다.

💡 **참고**

> Volume, Pitch, LPF는 사운드 믹싱의 핵심 파라미터로, 각각 소리의 크기, 음정, 저음 필터 강도를 제어합니다.

## 1. Soundcaster Session 개념 이해하기

- **Soundcaster Session**은 Wwise 내에서 여러 사운드를 동시에 테스트하고 조정할 수 있는 **사운드 믹싱용 시뮬레이션 공간**입니다.
- 게임 내 다양한 이벤트(Event)가 **실시간으로 함께 작동할 때의 밸런스**를 확인할 수 있습니다.
- 이를 통해 개발자는:
  - 실제 게임에 들어가기 전에 사운드의 **조화(믹싱)**를 미리 맞출 수 있습니다.
  - 특정 상황(예: 불 보석 던지기, 폭발 등)을 직접 **순서대로 시뮬레이션**해볼 수 있습니다.

## 2. 새로운 Soundcaster Session 만들기

이제 불의 보석(Fire Gem) 관련 사운드를 관리할 새로운 세션을 생성합니다.

1. **Soundcaster 패널의 [>>] 선택 메뉴 클릭**
2. **New**를 선택 → 새 세션 생성
3. 세션 이름을 **“Fire Gem”** 으로 지정

이제 “Fire Gem Soundcaster Session”이라는 이름의 새 탭이 생기며,

이 안에서 오브젝트를 자유롭게 추가하고 배치할 수 있습니다.

## 3. Event 오브젝트 추가하기

Fire Gem은 단일 이벤트가 아니라,

**3개의 Event**가 서로 연결되어 하나의 연속적인 사운드 경험을 만듭니다.

| Event 이름              | 역할 설명                                             |
| ----------------------- | ----------------------------------------------------- |
| **Fire_FireGem_Player** | 플레이어가 불 보석을 던질 때 발생                     |
| **End_FireGem_Player**  | 불 보석이 공중에서 날아가는 동안 발생하는 사운드 종료 |
| **Hit_FireGem_Player**  | 불 보석이 충돌했을 때 폭발 사운드 재생                |

이 3개의 Event를 **Fire Gem Soundcaster Session의 첫 번째 줄(상단)** 에 추가합니다.

→ 즉, Soundcaster에서 각각의 Event를 재생하며 전체 사운드 흐름을 시뮬레이션할 수 있습니다.

## 4. Actor-Mixer 오브젝트 추가하기

이제 Event들이 트리거하는 실제 사운드 오브젝트(Actor-Mixer)들을 세션에 추가합니다.

Project Explorer의 **Actor-Mixer Hierarchy**에서 아래 오브젝트를 찾습니다:

- `FireGem Magic`
- `FireGem Blast`
- `FireGem Explode`
- `FireGem_Flight`

이 4개를 **Soundcaster Session의 두 번째 줄(하단)** 에 드래그해서 추가합니다.

💡 이렇게 하면 각 오브젝트의 속성(Volume, Pitch, LPF)을 Soundcaster에서 바로 조정할 수 있습니다.

## 5. Soundcaster 레이아웃 재배치하기

이제 세션 내에서 시각적 정돈을 해줍니다.

각 사운드가 대응되는 Event와 **가깝게 배치**되어야

시뮬레이션 시 직관적으로 이해할 수 있습니다.

- **FireGem Magic** → 첫 번째 줄의 **마지막 위치**로 이동
  (이 오브젝트는 Actor-Mixer이기 때문에 직접 재생은 불가)
- **FireGem Blast**, **FireGem Explode**, **FireGem_Flight** →
  각각 **격자선 기준 왼쪽으로 한 칸씩 이동**

이렇게 배치하면 Event와 사운드 오브젝트가 **시간 흐름(왼쪽 → 오른쪽)** 순으로 잘 대응됩니다.

→ 던지기 → 비행 → 충돌 폭발 → 마법 전체의 조화 확인이 쉬워집니다.

## 6. 사운드 속성 조정하기 (Volume, Pitch, LPF)

이제 모든 준비가 끝났습니다.

각 오브젝트에는 다음 3가지 속성이 표시됩니다:

| 속성                      | 설명                                                          |
| ------------------------- | ------------------------------------------------------------- |
| **Volume**                | 사운드의 전체 음량                                            |
| **Pitch**                 | 음높이 (사운드의 빠르기 및 에너지감 조절)                     |
| **LPF (Low-Pass Filter)** | 고주파를 깎아 사운드를 더 둔탁하게 혹은 먼 거리처럼 들리게 함 |

🎧 **조정 방법:**

1. 왼쪽에서 오른쪽으로 Event 오브젝트를 차례대로 재생

   → 실제 게임처럼 불 보석을 던지고 → 날아가고 → 폭발하는 흐름 확인

2. 각 사운드의 **Volume, Pitch, LPF를 미세 조정**

   → 전체가 조화롭게 들릴 때까지 반복

## 7. FireGem Magic의 상속 관계 이해하기 (Tip)

- **FireGem Magic**은 Actor-Mixer 오브젝트로,
  그 안에 **FireGem Blast**, **FireGem Explode**, **FireGem_Flight** 오브젝트를 **포함**하고 있습니다.

🧩 즉, FireGem Magic의 속성을 조정하면 →

그 하위에 있는 모든 오브젝트에도 **오프셋(Offset)** 값이 적용됩니다.

예시:

FireGem Magic의 Volume을 -2dB 낮추면 →

내부의 Blast, Explode, Flight도 전체적으로 -2dB씩 감소하게 됩니다.

(상대적인 볼륨 관계는 유지됩니다.)

⚠️ 주의:

FireGem Magic은 **Actor-Mixer**이므로 **재생 버튼(▶)** 을 눌러도 직접 재생되지 않습니다.

이는 Event에 의해 트리거되는 상위 컨테이너이기 때문입니다.

## 8. 정리 및 학습 포인트

| 구분          | 학습 내용                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| **핵심 목표** | 여러 개의 사운드를 동시에 관리하고, Soundcaster에서 조합적으로 조정하기                                     |
| **핵심 개념** | Soundcaster Session = 실시간 사운드 믹싱 툴                                                                 |
| **실습 요약** | ① Fire Gem 세션 생성 → ② 3개의 Event 추가 → ③ 관련 Actor-Mixer 추가 → ④ 배치 정돈 → ⑤ Volume/Pitch/LPF 조정 |
| **주의할 점** | FireGem Magic은 상위 컨테이너이며 직접 재생 불가                                                            |
| **Tip**       | 상위 Actor-Mixer 조정 시 하위 오브젝트에 오프셋 적용됨                                                      |
| **결과**      | 불 보석 던지기, 비행, 폭발까지의 전체 사운드를 한 번에 시뮬레이션 가능                                      |

🎯 **요약**

이번 강의에서는 **Soundcaster Session**의 기본 개념과 생성 방법,

그리고 **Fire Gem** 사운드처럼 여러 이벤트를 조합해

**볼륨, 피치, LPF를 실시간으로 조정하는 믹싱 프로세스**를 배웠습니다.

이를 통해 실제 게임 상황을 시뮬레이션하며

사운드 밸런스를 정교하게 맞출 수 있는 능력을 갖추게 되었습니다.
