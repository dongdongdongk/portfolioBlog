# 개념

```java
1. 인터셉터(Interceptor)는 스프링 프레임워크에서 요청(Request)과 응답(Response) 처리 사이에 위치하여, 요청과 응답을 가로채는 역할을 한다. 정리하자면

인터셉터는 컨트롤러에 요청이 전달되기 전에 요청 정보를 변경하거나 검증하고, 컨트롤러의 처리가 끝나 응답이 전달되기 전에 응답 정보를 변경하거나 추가할 수 있다.

2. 인터셉터를 사용하면 요청/응답에 대한 공통적인 작업을 중복해서 처리하는 것을 방지할 수 있으며, 보안, 로깅, 권한 체크, 캐싱, 트랜잭션 처리 등 다양한 용도로 사용된다.
```

# 인터셉터 구현하기

```java
1. 인터셉터는 HandlerInterceptor 인터페이스를 구현하여 만들 수 있다. (기존의 인터페이스 개념과 다르게 메서드를 모두 구현하지 않아도 괜찮다.)

2. 이 인터페이스에는 세 가지 메서드

	1. preHandle: 컨트롤러에 요청이 들어가기 전에 실행되며, false를 반환하면 컨트롤러로 요청이 전달되지 않는다.

	2. postHandle: 컨트롤러의 요청 처리가 끝난 후, 뷰(View)가 렌더링 되기 전에 실행된다.

	3. afterCompletion: 뷰가 렌더링 된 후 실행되며, 예외 발생 여부에 상관없이 실행된다.
```

# 예제

## 예제1

### 로그인한 사용자만 접근 가능한 페이지에 접근하는 경우 가로채서 로그인 페이지로 리다이렉트

```java
로그인한 사용자만 접근 가능한 페이지에 접근하는 경우 가로채서 로그인 페이지로 리다이렉트
```

```java
public class AuthInterceptor implements HandlerInterceptor {       // HandlerInterceptor 인터페이스를 구현하여 인터페이스 역할을 수행
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception { //HttpServletRequest는 요청 정보를 담고 있는 객체 , HttpServletResponse는 응답 정보를 담고 있는 객체,Object는 핸들러(Controller) 객체
        HttpSession session = request.getSession();  // getSession() 메서드를 사용하여 현재 세션을 가져와 session 에 대입
        User user = (User) session.getAttribute("user"); // getAttribute() 메서드를 사용하여 session 에 저장된 "user" 속성값을 가져와 User 클래스 타입으로 형변환
                                                         // 이는 세션에 저장된 "user" 속성값이 Object 타입으로 저장되기 때문
        if (user == null) {
            response.sendRedirect("/login");  // user가 null인 경우, 로그인 페이지로 redirect 하고 false를 반환
            return false;  // 즉, 로그인하지 않은 사용자가 접근하면 요청 처리를 중단하고, 로그인 페이지로 이동
        }

        return true;
    }
}

@Configuration  // 설정파일을 만들기 위한 애노테이션 or Bean을 등록하기 위한 애노테이션
public class WebConfig implements WebMvcConfigurer { // WebMvcConfigurer는 개발자가 Spring MVC 프레임워크의 구성을 사용자 정의할 수 있도록 Spring MVC에서 제공하는 인터페이스
    @Override
    public void addInterceptors(InterceptorRegistry registry) { // addInterceptors: 이 메소드는 Spring MVC 프레임워크에 사용자 정의 인터셉터를 추가하는 데 사용
        registry.addInterceptor(new AuthInterceptor()) // AuthInterceptor를 인터셉터로 등록
            .addPathPatterns("/**") // 인터셉터를 적용할 URL 패턴을 설정 ( 여기서는 모든 URL에 대해 인터셉터를 적용)
            .excludePathPatterns("/login", "/register"); // 인터셉터를 적용하지 않을 URL 패턴을 설정0
    }
}

// * 핸들러 객체 : 클라이언트의 요청을 처리하는 컨트롤러(Controller)
```

### 로그인 체크 인터셉터 예시

```java
@Component
public class LoginInterceptor implements HandlerInterceptor { // HandlerInterceptor 인터페이스를 구현하여 인터페이스 역할을 수행

    @Autowired
    private UserService userService;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        HttpSession session = request.getSession();
        if (session.getAttribute("userId") == null) {
            response.sendRedirect("/login"); // 로그인 페이지로 이동
            return false;
        } else {
            return true;
        }
    }
}
```

### 실행시간 측정 인터셉터 예시

```java
@Component
public class PerformanceInterceptor implements HandlerInterceptor {

    private static final Logger logger = LoggerFactory.getLogger(PerformanceInterceptor.class);

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        request.setAttribute("startTime", System.currentTimeMillis()); // 요청의 시작 시간을 저장하기 위해 HttpServletRequest에 startTime 속성을 추가
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        long startTime = (long) request.getAttribute("startTime"); // 요청의 시작 시간을 HttpServletRequest에서 가져온다.
        long endTime = System.currentTimeMillis(); // 요청의 끝나는 시간을 가져온다. (afterCompletion jsp 랜더링뒤)
        long executeTime = endTime - startTime; // 요청 처리 시간을 계산한다.
        logger.info("{} : {}ms", request.getRequestURI(), executeTime);  // 처리된 요청 URI와 요청 처리 시간을 로그로 출력한다.
    }
}
```

### 권한 체크 인터셉터 예시

```java
@Component
public class AuthInterceptor implements HandlerInterceptor {

    @Autowired
    private AuthService authService;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        String requestUrl = request.getRequestURI(); // 현재 요청의 URI를 가져와서 requestUrl 변수에 저장
        boolean isPermitted = authService.isPermitted(requestUrl); // authService의 isPermitted 메서드를 호출하여 현재 사용자가 해당 요청을 허용할 수 있는지 검사
        if (!isPermitted) {         // isPermitted 는 AuthService 클래스에 의존성을 가지고 있으며, AuthService 클래스의 isPermitted 메서드를 호출하여 현재 사용자의 권한을 검사
            response.sendError(HttpServletResponse.SC_FORBIDDEN, "Forbidden"); // 권한이 없는 경우에는 HTTP 응답 코드로 403 Forbidden을 반환하며, 요청 처리를 중단
            return false;
        }
        return true;
    }
}
```

## 예제2

### 요청이 들어오고 나가는 과정에서 로그를 출력하는 인터셉터

```java
public class LoggingInterceptor implements HandlerInterceptor { // HandlerInterceptor 인터페이스를 구현하여 인터페이스 역할을 수행

    private static final Logger logger = LoggerFactory.getLogger(LoggingInterceptor.class); // SLF4J lombok 사용으로 객체 선언이 필요없어졌다.

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        // 요청이 들어올 때 로그를 출력합니다.
			  //HttpServletRequest는 요청 정보를 담고 있는 객체 , HttpServletResponse는 응답 정보를 담고 있는 객체,Object는 핸들러(Controller) 객체
        logger.info("Request URL: {}", request.getRequestURL());
        return true;
    }

    @Override
    public void postHandle(HttpServletRequest request, HttpServletResponse response, Object handler, ModelAndView modelAndView) throws Exception {  //실제로 사용되지 않는 mv
        // 요청 처리가 완료되고 뷰가 렌더링되기 전에 로그를 출력합니다.
        logger.info("Response Status: {}", response.getStatus());
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        // 요청 처리가 완료된 후 로그를 출력합니다.
        logger.info("Request Completed");
    }
}
```
