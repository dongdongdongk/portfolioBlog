## 설치 및 실행 방법

```jsx
npx https://github.com/google-gemini/gemini-cli
```

## 또는 2. **전역 설치 후 실행**

```jsx
npm install -g @google/gemini-cli

gemini
```

## 실행 후 초기 설정

```jsx
색상 테마 선택

개인 Google 계정 로그인 →

→ 분당 최대 60개 / 하루 최대 1,000개 요청 가능
```

## Gemini API 키 사용 방법 (선택 사항)

```jsx
1. Google AI Studio에서 API 키 생성

2. 환경 변수로 설정

export GEMINI_API_KEY="YOUR_API_KEY"

3. (선택) API 키를 유료 플랜으로 업그레이드 → 더 많은 요청 가능
```
