## 직사각형 도구 사용

```jsx
직사각형 만들기: 도형 도구에서 직사각형을 선택하고 캔버스의 아무 곳이나 클릭하여 직사각형을 만듭니다. 단축키는 R입니다.
```

## 직사각형 속성 조절

```jsx
위치 변경 (X, Y 값): 오른쪽 패널에서 직사각형의 X 및 Y 값을 조절하여 위치를 변경할 수 있습니다.

크기 변경 (너비, 높이): 너비와 높이를 변경할 수 있으며, 예시로 너비를 50, 높이를 150으로 설정합니다.

비례적 크기 조절: 컨스트레인트를 잠글 수 있으며, 이를 통해 비례적으로 크기를 변경할 수 있습니다. 예를 들어, 너비를 500으로 설정하면 높이도 자동으로 조절됩니다.

회전: 직사각형을 회전시킬 수 있으며, Shift 키를 누른 상태에서 15도씩 회전할 수 있습니다.

모서리 곡률 조절: 모서리 곡률을 개별적으로 변경할 수 있습니다. 예시로 왼쪽 상단 0, 오른쪽 상단 20, 오른쪽 하단 및 왼쪽 하단에 10을 입력합니다.
```

## 직사각형과 프레임의 차이

```jsx
기본 속성: 직사각형과 프레임은 기본 속성이 유사하지만 중요한 차이점이 있습니다.

추가 속성: 프레임에는 레이아웃 그리드와 오토 레이아웃이라는 두 가지 추가 속성이 있으며, 이는 디자인할 때 매우 중요합니다. 직사각형에는 이 두 속성이 없습니다.
```

## 타원의 속성 조절

```jsx
위치 변경 (X축, Y축): 타원의 위치를 조절하여 캔버스 내부에 배치합니다.

너비와 높이 조절: 타원의 너비와 높이를 변경할 수 있습니다.

	원: 너비와 높이가 같을 때 원이 됩니다.

	타원: 너비와 높이가 다를 때 타원이 됩니다.

비례적 조절: 컨스트레인트 잠금을 통해 너비와 높이를 비례적으로 조절할 수 있습니다.

회전: 타원을 회전시킬 수 있습니다. 원도 회전 가능하지만 둥글기가 같기 때문에 시각적으로는 변화를 확인할 수 없습니다.
```

## 아크(Arc) 옵션

```jsx
아크 설정: 원의 아크 옵션을 클릭하여 세 가지 옵션을 볼 수 있습니다.

	Start: 원의 시작점을 변경합니다.

	Sweep: 원의 완전도를 백분율로 표시합니다.

	Ratio: 중심에서 제거된 원의 면적을 백분율로 표시합니다.
```

# { 다각형 및 별 도구 설명 }

## 다각형 도구 사용

```jsx
다각형 생성: 모양 도구에서 다각형을 선택한 후 캔버스의 아무 곳이나 클릭하여 기본 100px 크기의 다각형을 만듭니다.

속성 조절:

	위치 변경: X 및 Y 값을 사용하여 위치를 변경합니다.

	너비와 높이 변경: 너비와 높이를 조절할 수 있습니다. 컨스트레인트를 잠그면 비례적으로 크기를 조절할 수 있습니다.

	회전: 다각형을 회전시키고, Shift 키를 누른 상태에서 15도씩 회전할 수 있습니다.

	코너 반경 조절: 모서리의 반경을 조절할 수 있습니다.

	모서리 개수 변경: 기본 3개에서 최대 60개까지 모서리 개수를 조절할 수 있습니다.

	채우기 변경: 단색, 그라데이션, 이미지로 채우기를 변경할 수 있습니다.

	스트로크 전환: Shift + X를 눌러 채우기와 스트로크를 전환할 수 있습니다.
```

## 별 모양 도구 사용

```jsx
별 생성: 모양 도구에서 별을 선택한 후 캔버스의 아무 곳이나 클릭하여 별을 만듭니다.

속성 조절:

	높이 및 너비 변경: 높이와 너비를 조절할 수 있습니다.

	위치 및 회전 변경: 위치와 회전을 조절할 수 있습니다.

	카운트: 모서리 개수를 변경할 수 있습니다. 예를 들어, 10개의 모서리를 가진 별을 만들 수 있습니다.

	비율 조절: 스파이크의 두께를 백분율 값으로 조절할 수 있습니다. 최대값은 100%, 최소값은 1.1%입니다.
```

## 래스터와 벡터의 차이점 이해

```jsx
래스터 그래픽: 픽셀 기반 (예: 사진), 파일 확장자: JPG, GIF, TIF

벡터 그래픽: 패스와 선으로 구성 (예: 일러스트레이션, 로고), 파일 확장자: SVG, PDF, AI

확대/축소 품질: 래스터 그래픽은 확대하면 품질이 떨어지지만, 벡터 그래픽은 품질이 유지됩니다.
```

## 불리언 연산 개요

```jsx
불리언 연산 정의: 여러 모양을 단일 모양으로 결합하기 위해 사용됩니다.

결합된 모양은 단일 모양으로 작동하며 채우기와 스트로크 속성을 공유합니다.

불리언 연산 종류: 합치기(Union), 빼기(Subtract), 교집합(Intersect), 제외(Exclude)
```

## 불리언 연산 종류별 예제

```jsx
4.1 합치기(Union)

	합치기 실행: 두 모양을 선택하고 '합치기' 옵션을 선택합니다.

	결과 확인: 두 모양이 단일 모양으로 합쳐집니다. 레이어 패널에서 'Union' 안에 두 개의 타원이 존재함을 확인할 수 있습니다.

4.2 빼기(Subtract)

	빼기 실행: 두 번째 셀의 두 모양을 선택하고 '빼기' 옵션을 선택합니다.

	결과 확인: 기본 레이어에서 최상위 레이어가 제거됩니다.

4.3 교집합(Intersect)

	교집합 실행: 세 번째 셀의 두 모양을 선택하고 '교집합' 옵션을 선택합니다.

	결과 확인: 겹치는 부분만 유지됩니다.

4.4 제외(Exclude)

	제외 실행: 네 번째 셀의 두 모양을 선택하고 '제외' 옵션을 선택합니다.

	결과 확인: 겹치는 부분이 제거됩니다.
```
