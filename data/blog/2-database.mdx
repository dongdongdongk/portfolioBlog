### 1. Notice

| 이름(컬럼명) | Type          | 설명                               | 제약조건 | 자동증가 |
| ------------ | ------------- | ---------------------------------- | -------- | -------- |
| NUM          | NUMBER        | 구분 용도, 중복 불가               | PK       | O        |
| TITLE        | VARCHAR2(200) | 글 제목, 사용자 입력               | NN       |          |
| WRITER       | VARCHAR2(200) | 작성자, 로그인한 사용자가 자동입력 |          |          |
| CONTENTS     | CLOB          | 글 내용, 사용자 입력               |          |          |
| REGDATE      | Date          | 작성일, 글 작성시(Insert) 날짜     |          |          |
| HIT          | NUMBER        | 조회수, 글을 조회 할 때 1씩 증가   |          |          |
