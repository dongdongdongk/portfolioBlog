# 본문에 템플릿 넣어주기 ( Generating Email body )

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380868/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_9_Robot_7_Email_Automation/Untitled_22.png)

```jsx
이제 위의 EmailBody 를 사용해서

Send Email 의 본문에 첨부하도록 한다

String.Format(EmailBody,DateTime.Now.ToString,str_OutputReport)

위의식을 사용해서 메일의 본문을 만든다

EmailBody 는 메일의 전체 틀  ( 템플릿 ) 이고

DateTime.Now 는 {0} 에 들어가며

str_OutputReport 는 {1} 에 들어간다

* String.Format 메서드는 C#에서 문자열 내에 있는 형식 항목을 지정된 값으로 대체하는 데 사용됩니다.

	EmailBody 문자열에는 {0}, {1}, {2} 등의 자리 표시자가 포함되어 있어야 합니다. 이 자리 표시자는 메서드 호출 시 전달되는 값으로 대체


* EmailBody는 포맷 문자열이다. 이 문자열은 {0}, {1} 등의 형식 항목을 포함하고 있어야 한다. 이 형식 항목은 String.Format 호출 시 전달되는 인수들로 대체된다.

	예를 들어, EmailBody가 "Today is {0} and the report is {1}"라면, {0}과 {1}이 각각 첫 번째와 두 번째 인수로 대체된다.
```

위와 같이 메일이 전송된다

DateTime.Now.ToString + ": " + CurrentMail.Subject.ToString + Environment.NewLine
