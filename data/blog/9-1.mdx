```jsx

1.2 프레임 설정

	데스크탑 사이즈 프레임 추가: 데스크탑 사이즈의 프레임을 추가합니다.

	크기 및 위치 설정: 프레임의 높이를 120으로 설정하고, x 및 y 값을 0으로 설정합니다.
```

## 네비게이션 바 구성

```jsx
2.1 네비게이션 바 설정

	프레임 이름 변경: 프레임의 이름을 '네비게이션 바'로 변경합니다.

2.2 텍스트 요소 추가

	텍스트 도구 사용: 텍스트 도구를 사용하여 'Hobby Class'라고 입력합니다.

	서체 변경: 서체를 Roboto에서 Source Sans Pro로 변경합니다.

	글꼴 크기 조정: 글꼴 크기를 36으로 설정합니다.

	텍스트 복사: 옵션 키를 누른 상태에서 드래그하여 텍스트 복사본을 만들고,

							각각의 텍스트를 'Explore Classes', 'Mentor Details', 'LogIn'으로 변경합니다.

2.3 텍스트 정렬

	텍스트 크기 조정: 모든 텍스트를 선택하고 크기를 36에서 24로 줄입니다.

	레이아웃 그리드 추가: 상위 프레임을 선택하고 레이아웃 그리드를 추가합니다.

	그리드 설정: 10픽셀 열의 그리드로 변경하고, 6열 및 여백 100으로 설정합니다.
```

## 텍스트 정렬 및 배치

```jsx
3.1 자 도구 사용

	자 도구 활성화: Shift + R을 눌러 자 도구를 활성화합니다.

	텍스트 정렬: 자 도구를 사용하여 텍스트를 중앙 및 오른쪽 모서리에 맞춥니다.

3.2 텍스트 간격 조정

	정렬 도구 사용: Shift 키를 누른 채 텍스트를 선택하고 가로 간격을 분배합니다.

	자동 레이아웃 사용: 텍스트를 선택하고, Command+G를 눌러 그룹화한 후, 마우스 오른쪽 버튼을 클릭하여 자동 레이아웃을 추가합니다.

		자동 레이아웃 설정: 간격을 80으로 설정합니다. ( 글자간의 간격을 맞추기 위해서 사용 )
```

## 1. 프레임 생성 및 이름 변경

```jsx
프레임 생성:

	데스크탑 사이즈의 새로운 프레임을 이전 프레임 아래에 놓습니다.

	높이 설정: 프레임의 높이를 300으로 줄입니다.

프레임 이름 변경: 이 프레임의 이름을 "Footer"로 변경합니다.
```

## 2. 텍스트 추가 및 스타일 설정

```jsx
텍스트 추가:

	텍스트 도구(T)를 사용하여 "Explore"라고 입력합니다.

	텍스트 크기를 18픽셀에서 24픽셀로 변경합니다.

	텍스트 색상: 검은색에서 파란색으로 변경합니다.

텍스트 복사:

	"Explore" 텍스트를 두 번 복사하여 각각 "Company"와 "Follow Us"로 이름을 변경합니다.
```

## 3. 메뉴 항목 추가 및 정렬

```jsx
메뉴 항목 추가:

	텍스트 도구(T)를 사용하여 다음 항목을 입력합니다:

		Programs

		Mentors

		About Us

		FAQs

텍스트 스타일 변경:

	이 네 가지 항목을 모두 선택하고 텍스트 크기를 24픽셀에서 18픽셀로 변경합니다.

	텍스트 색상: 기본 회색으로 변경합니다.

정렬 및 자동 레이아웃:

	세 개의 텍스트 그룹("Explore", "Company", "Follow Us")을 선택하고, 자동 레이아웃을 추가합니다.

	단축키: Shift + A

	간격을 30으로 설정하고 중앙에 정렬합니다.
```

## 4. 소셜 미디어 아이콘 추가 및 정렬

```jsx
아이콘 검색 및 추가:

	Feather Icons 플러그인을 사용하여 Facebook과 Twitter 아이콘을 검색합니다.

	아이콘을 푸터 프레임에 추가합니다.

아이콘 정렬 및 스타일 변경:

	세 개의 아이콘을 선택하고, 자동 레이아웃을 추가합니다.

	아이콘 사이의 간격을 16으로 설정합니다.

	아이콘을 텍스트 아래에 정렬하고 색상을 기본 파란색으로 변경합니다.
```

## 2. 프레임 복사 및 붙여넣기

```jsx
프레임 생성:

	데스크톱 사이즈의 프레임을 새 페이지에 추가합니다.

	높이 설정: 프레임의 높이를 기존의 약 5배로 늘립니다.

프레임 복사 및 붙여넣기:

	전체 선택: 모든 프레임을 선택하려면 Command + A를 누릅니다.

	복사: 선택된 프레임을 Command + C로 복사합니다.

	붙여넣기: 새 프레임에 Command + V로 복사한 프레임을 붙여넣습니다.
```

## 3. 프레임 정렬 및 이름 변경

```jsx
프레임 정렬:

	모든 프레임을 메인 프레임 기준으로 중앙에 정렬합니다.

	하나씩 정리하며 모든 프레임이 올바르게 배열되었는지 확인합니다.

메인 프레임 이름 변경:

	메인 프레임을 선택하고 이름을 "Edtech Website"로 변경합니다.
```
