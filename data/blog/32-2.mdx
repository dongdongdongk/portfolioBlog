```java
매개 변수의 개수를 모를경우 2가지 방법으로 배열을 만들어 줄수 있다.
//선언
1.매개 변수를 배열 타입으로 선언
int sum(int[] values) {내용} // sum이라는 메소드를 선언할때

//호출하는법(실행 class)
int[] values = {1, 2, 3 ); // 배열객체를 만들어서
int result = sum1(values); //sum1 에 제공 할수도 있고
int result = sum1(new int[] { 1, 2, 3, 4, 5 }); // sum1 호출과 동시에 배열객체를 생성할수도
있다.
```

```java
//선언
2.배열을 생성하지 않고 값의 목록만 넘겨주는 방법
int sum2(int ... values) {내용}

//호출하는법(실행 class)
int result = sum2(1, 2, 3);

int[] values = {1 ,2 ,3 }; //배열을 만들고
int result = sum2(values); // 이값을 sum2 에 제공을 해도 동작한다.
int result = sum2(new int[] { 1, 2, 3, 4, 5 }); //sum2 호출과 동시에 배열객체 생성
```

- return 이란 자신이 호출된 메소드에 값을 반환하는 것이다. 추가적으로 return 은 메소드를 종료시킨다.
- 리턴 값이 있는 메소드는 메소드 이름앞에 리턴 값의 타입이 와야 한다.

```java
int plus(int x, int y) { //메소드 plus 에 값을 반환한다. 이때 반환 값과 같은 int 를 붙여준다.
int result = x + y;
return result; //result 값이 plus 로 반환된다. 동시에 메소드 종료
```

![Untitled](<32%20%EC%9E%90%EB%B0%94%20%EB%A9%94%EC%86%8C%EB%93%9C%20(2)/Untitled%204.png>)

- 리턴 값이 없는 메소드는 리턴 타입에 void가 와야 한다.(ex : void run)
- return 과 break 는 비슷 하지만 살짝 다르다. return 은 바로 메소드가 종료 되지만 break 는 중괄호를 벗어나서 실행문 까지 실행하고 종료 된다.
