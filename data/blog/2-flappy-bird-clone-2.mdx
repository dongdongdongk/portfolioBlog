# { 파이프 추가 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380494/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_2_-/image.png)

```jsx
import Phaser, { Physics, Scene } from 'phaser'

// Phaser 설정 객체
const config = {
  // Phaser가 사용할 렌더링 방식을 자동으로 선택 (WebGL 또는 Canvas)
  type: Phaser.AUTO,

  // 게임 화면의 크기 (폭: 800, 높이: 600)
  width: 800,
  height: 600,

  // 물리 엔진 설정
  physics: {
    default: 'arcade', // 기본 물리 엔진으로 Arcade 사용
    arcade: {
      // 중력 및 디버그 옵션 설정
      debug: true, // 충돌 박스와 물리 속성을 시각적으로 확인 가능
    },
  },

  // 게임의 각 단계(씬)를 정의
  scene: {
    preload, // 리소스 로드
    create, // 객체 초기화
    update, // 매 프레임 호출
  },
}

// Phaser의 preload 단계: 게임에 사용할 리소스를 미리 로드
function preload() {
  this.load.image('sky', 'assets/sky.png') // 배경 이미지 로드
  this.load.image('bird', 'assets/bird.png') // 새 이미지 로드
  this.load.image('pipe', 'assets/pipe.png') // 파이프 이미지 로드
}

// 상수 정의
const VELOCITY = 200 // 기본 속도 (사용되지 않음)
const flapVelocity = 250 // 새가 점프할 때 속도
const initialBirdPosition = { x: config.width * 0.1, y: config.height / 2 } // 새의 초기 위치

// 전역 변수 선언
let bird = null // 새 객체
let upperPipe = null // 위쪽 파이프 객체
let lowerPipe = null // 아래쪽 파이프 객체

// Phaser의 create 단계: 초기 객체 생성 및 설정
function create() {
  // 배경 이미지 추가, 좌상단(0, 0) 기준으로 설정
  this.add.image(0, 0, 'sky').setOrigin(0)

  // 새 객체 생성 및 중력 적용
  bird = this.physics.add.sprite(initialBirdPosition.x, initialBirdPosition.y, 'bird').setOrigin(0)
  bird.body.gravity.y = 400 // Y축 방향으로 중력 설정 (새가 아래로 떨어짐)

  // 위쪽 파이프 생성 (왼쪽 아래를 원점으로 설정)
  upperPipe = this.physics.add.sprite(400, 100, 'pipe').setOrigin(0, 1)

  // 아래쪽 파이프 생성 (위쪽 파이프의 아래쪽에서 100px 떨어진 위치)
  lowerPipe = this.physics.add.sprite(400, upperPipe.y + 100, 'pipe').setOrigin(0, 0)

  // 마우스 클릭 이벤트에 점프(flap) 동작 연결
  this.input.on('pointerdown', flap)

  // 키보드의 스페이스바 입력 감지 설정
  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)
}

// Phaser의 update 단계: 매 프레임 호출 (초당 60번 실행)
function update() {
  // 스페이스바가 눌렸을 때 점프
  if (this.spaceKey.isDown) {
    flap()
  }

  // 새가 화면 밖으로 벗어나면 초기 위치로 재시작
  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition()
  }
}

// 새의 위치를 초기화하고 게임을 재시작
function restartBirdPosition() {
  bird.x = initialBirdPosition.x // 초기 X 위치로 이동
  bird.y = initialBirdPosition.y // 초기 Y 위치로 이동
  bird.body.velocity.y = 0 // Y축 속도 초기화
  alert('패배') // 패배 메시지 출력
}

// 새를 위로 점프시키는 함수
function flap() {
  bird.body.velocity.y = -flapVelocity // 점프 시 속도를 음수로 설정하여 위로 이동
}

// Phaser 게임 객체 생성 및 설정 적용
new Phaser.Game(config)
```

## 1. 파이프 추가 및 위치 설명

```jsx
파이프의 역할

		새가 장애물을 피해서 지나가야 하는 초록색 직사각형.

		두 개의 파이프를 만들고, 그 사이에 새가 지나갈 수 있는 틈을 만들어야 함.

파이프의 위치

		위쪽 파이프: 화면 상단에서 아래로 이어지는 장애물.

		아래쪽 파이프: 화면 하단에서 위로 이어지는 장애물.

		이 두 파이프 사이에 플레이어가 지나갈 수 있는 **공간(Opening)**을 만듦.
```

## 2. 파이프의 위치와 원점 (Origin)

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380493/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_2_-/image_1.png)

```jsx
원점의 역할

		파이프의 위치를 정확히 배치하기 위해 좌표계 원점을 설정.

		Phaser에서 원점은 0~1 사이의 값을 사용하여 스프라이트의 기준점을 설정.

파이프의 원점 설정

		위쪽 파이프:


				원점(0, 1): 왼쪽 아래를 기준으로 위치 지정. ( 파이프의 왼쪽 아래를 기준으로 )

				Y 좌표가 100일 경우, 아래쪽 끝이 Y=100에 위치.


		아래쪽 파이프:


				원점(0, 0): 왼쪽 위를 기준으로 위치 지정. ( 파이프의 왼쪽 위를 기준으로 )

				Y 좌표는 위쪽 파이프의 Y 좌표 + 간격으로 계산.
```

# { 파이프 사이의 간격(열림 거리)을 동적으로 설정 }

```jsx
import Phaser, { Physics, Scene } from 'phaser'

const config = {
  //
  type: Phaser.AUTO,
  width: 800,
  height: 600,
  physics: {
    default: 'arcade',
    arcade: {
      // gravity: { y: 400 },
      debug: true,
    },
  },
  scene: {
    preload,
    create,
    update,
  },
}

const VELOCITY = 200
const flapVelocity = 250
const initialBirdPosition = { x: config.width * 0.1, y: config.height / 2 }

let bird = null
let upperPipe = null
let lowerPipe = null

const pipeVerticalDistanceRange = [150, 250]
let pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange)

function preload() {
  this.load.image('sky', 'assets/sky.png')
  this.load.image('bird', 'assets/bird.png')
  this.load.image('pipe', 'assets/pipe.png')
}

function create() {
  this.add.image(0, 0, 'sky').setOrigin(0)

  bird = this.physics.add.sprite(initialBirdPosition.x, initialBirdPosition.y, 'bird').setOrigin(0)
  bird.body.gravity.y = 400

  upperPipe = this.physics.add.sprite(400, 100, 'pipe').setOrigin(0, 1)
  lowerPipe = this.physics.add
    .sprite(400, upperPipe.y + pipeVerticalDistance, 'pipe')
    .setOrigin(0, 0)

  this.input.on('pointerdown', flap)

  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)
}

// 60fps
// 60 times
function update() {
  // 스페이스바가 눌렸는지 확인
  if (this.spaceKey.isDown) {
    flap()
  }

  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition()
  }
}

function restartBirdPosition() {
  bird.x = initialBirdPosition.x
  bird.y = initialBirdPosition.y
  bird.body.velocity.y = 0
  alert('패배')
}

function flap() {
  bird.body.velocity.y = -flapVelocity
}

new Phaser.Game(config)
```

```jsx
강의에서 설명한 부분은 파이프 사이의 간격(열림 거리)을 동적으로 설정하는 방법을 다룹니다.

즉, 매번 브라우저를 새로 고칠 때마다 파이프 사이의 간격이 랜덤한 값으로 변경되도록 만드는 방법입니다.
```

## 1. 파이프 간격을 설정하는 변수 생성

```jsx
강의에서는 파이프 사이의 열림 거리를 저장할 변수를 생성합니다. 이 값은 두 파이프 사이의 수직 간격을 동적으로 결정합니다.

1.1. pipeVerticalDistanceRange 생성

		파이프 간격의 범위를 설정하기 위해 배열을 생성합니다.

		예를 들어, 파이프 간격이 150픽셀에서 250픽셀 사이가 되도록 합니다.
```

```jsx
const pipeVerticalDistanceRange = [150, 250]
```

## 2. 랜덤한 간격을 계산

```jsx
배열에 설정된 범위 내에서 랜덤한 값을 생성하려면 Phaser의 Phaser.Math.Between 함수를 사용합니다.

2.1. Phaser.Math.Between 함수란?

		이 함수는 두 숫자 사이의 랜덤한 값을 반환합니다.

		예: Phaser.Math.Between(150, 250) → 150에서 250 사이의 임의의 값을 반환.

2.2. 파이프 간격 계산

		Phaser.Math.Between을 사용하여 위에서 만든 pipeVerticalDistanceRange의 값을 기반으로 랜덤한 간격을 계산합니다.
```

```jsx
let pipeVerticalDistance = Phaser.Math.Between(
  pipeVerticalDistanceRange[0], // 최소값 150
  pipeVerticalDistanceRange[1] // 최대값 250
)
```

## 3. 파이프 간격 적용

```jsx
랜덤하게 생성된 pipeVerticalDistance 값을 두 파이프의 위치에 적용합니다.

3.1. 기존 코드의 변경

		이전에는 파이프 간격을 하드코딩(고정된 값)으로 설정했지만, 이제 랜덤 값으로 설정합니다.



여기서 upperPipe.y + pipeVerticalDistance는 아래쪽 파이프의 위치를 위쪽 파이프의 위치와 간격 값에 따라 계산한 것입니다.
```

```jsx
upperPipe = this.physics.add.sprite(400, 100, 'pipe').setOrigin(0, 1)
lowerPipe = this.physics.add.sprite(400, upperPipe.y + pipeVerticalDistance, 'pipe').setOrigin(0, 0)
```

## 4. 배열 구조 분해 할당 (Destructuring)

```jsx
파이프 간격을 범위 배열에서 쉽게 추출하기 위해 구조 분해 할당을 사용합니다.

4.1. 구조 분해 할당이란?

		배열에서 값들을 개별 변수로 분리하는 방식입니다. 예를 들어:

		아래 코드는 배열 [150, 250]에서 첫 번째 값을 minDistance로, 두 번째 값을 maxDistance로 저장합니다.
```

```jsx
let pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange)
```

```jsx
개선된 코드

		Phaser.Math.Between에 배열 값을 직접 넣는 대신 구조 분해 할당을 사용해 가독성을 높입니다.

const [minDistance, maxDistance] = pipeVerticalDistanceRange;
let pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange);
```

# { 위쪽 파이프의 위치를 화면 높이 내에서 랜덤으로 배치 }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380493/notion-blog/_/Game_Development_in_JS_TS_-_The_Complete_Guide_w_/_2_Flappy_Bird_Clone_-_2_-/image_2.png)

## 문제 정의

```jsx
화면에 나오는 두 개의 파이프(위쪽 파이프와 아래쪽 파이프) 사이의 간격은 이미 동적으로 설정하고 있습니다.

이번에는 위쪽 파이프의 위치를 화면 높이 내에서 랜덤으로 배치하고,

이로 인해 두 파이프가 어디에서 나타날지 매번 다르게 보이도록 설정할 것입니다.

또한, 파이프의 위치를 설정할 때 파이프가 화면을 벗어나지 않도록 안전한 범위를 제한해야 합니다.
```

## 2. **파이프 세로 위치 설정**

```jsx
1) 범위 지정

파이프의 세로 위치(위쪽 파이프의 위치)는 화면의 높이를 기준으로 일정 범위 내에서 랜덤하게 설정됩니다.

		화면 위쪽으로 너무 올라가지 않도록 20px 이상 떨어진 위치에서 시작합니다.

		화면 아래쪽으로도 너무 내려가지 않도록 화면 높이에서 20px을 뺀 위치까지만 설정합니다.
```

```jsx
let pipeVerticalPosition = Phaser.Math.Between(20, config.height - 20)
```

```jsx
(2) 두 파이프 사이 간격 반영

		위쪽 파이프와 아래쪽 파이프 사이의 간격을 고려해야 합니다.

		만약 위쪽 파이프가 너무 아래에 위치한다면, 아래쪽 파이프가 화면 아래를 벗어날 수 있습니다.

		이를 방지하기 위해 위쪽 파이프의 위치에서 두 파이프 사이 간격을 빼줍니다.


예제 상황 1

		위쪽 파이프 위치: y=500

		아래쪽 파이프 위치: y=500 + 200 = 700

		결과: 아래쪽 파이프의 **y=700**은 화면(600px)을 초과하므로 아래쪽 파이프가 화면 밖으로 나감.
```

```jsx
let pipeVerticalPosition = Phaser.Math.Between(20, config.height - 20 - pipeVerticalDistance)
```

# { 파이프를 렌더링하고 이동시키기 }

## 1. 목표

```jsx
1. 플레이어 앞에 여러 개의 파이프를 렌더링합니다.

2. 파이프들이 플레이어 쪽으로 이동하도록 설정합니다.

3. 플레이어가 파이프를 피하도록 게임의 기본 메커니즘을 구현합니다.
```

```jsx
import Phaser, { Physics, Scene } from 'phaser'

// Phaser의 기본 설정 객체
const config = {
  type: Phaser.AUTO, // 렌더링 방식 자동 결정 (WebGL 또는 Canvas)
  width: 800, // 게임 화면의 너비
  height: 600, // 게임 화면의 높이
  physics: {
    default: 'arcade', // 기본 물리 엔진으로 'arcade' 사용
    arcade: {
      debug: true, // 디버그 모드 활성화 (충돌 박스 표시 등)
    },
  },
  scene: {
    preload, // 리소스 로드 함수
    create, // 게임 객체 생성 및 초기화 함수
    update, // 매 프레임 호출되는 업데이트 함수
  },
}

const VELOCITY = 200 // 파이프 이동 속도
const PIPES_TO_RENDER = 4 // 생성할 파이프 쌍의 수
const flapVelocity = 250 // 새가 점프할 때의 속도
const initialBirdPosition = { x: config.width * 0.1, y: config.height / 2 } // 새의 초기 위치

let bird = null // 새 객체
let upperPipe = null // 위쪽 파이프 객체
let lowerPipe = null // 아래쪽 파이프 객체
let pipeHorizontalDistance = 0 // 파이프 간 가로 거리

const pipeVerticalDistanceRange = [150, 250] // 파이프 간 세로 거리의 최소 및 최대값

// 리소스(이미지) 로드
function preload() {
  this.load.image('sky', 'assets/sky.png') // 배경 이미지
  this.load.image('bird', 'assets/bird.png') // 새 이미지
  this.load.image('pipe', 'assets/pipe.png') // 파이프 이미지
}

// 초기화 및 게임 객체 생성
function create() {
  this.add.image(0, 0, 'sky').setOrigin(0) // 배경 이미지 설정 (좌측 상단 기준)

  // 새 객체 생성 및 중력 설정
  bird = this.physics.add.sprite(initialBirdPosition.x, initialBirdPosition.y, 'bird').setOrigin(0)
  bird.body.gravity.y = 400

  // 파이프 생성 루프
  for (let i = 0; i < PIPES_TO_RENDER; i++) {
    pipeHorizontalDistance += 400 // 각 파이프 쌍 간의 가로 거리
    let pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange) // 세로 거리 랜덤 설정
    let pipeVerticalPosition = Phaser.Math.Between(
      0 + 20,
      config.height - 20 - pipeVerticalDistance
    ) // 파이프 생성 위치 계산

    // 위쪽 파이프 생성
    upperPipe = this.physics.add
      .sprite(pipeHorizontalDistance, pipeVerticalPosition, 'pipe')
      .setOrigin(0, 1)

    // 아래쪽 파이프 생성
    lowerPipe = this.physics.add
      .sprite(upperPipe.x, upperPipe.y + pipeVerticalDistance, 'pipe')
      .setOrigin(0, 0)

    // 파이프 속도 설정
    upperPipe.body.velocity.x = -200
    lowerPipe.body.velocity.x = -200
  }

  // 사용자 입력 이벤트 설정
  this.input.on('pointerdown', flap) // 마우스 클릭 시 flap 함수 호출
  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE) // 스페이스바 입력 등록
}

// 매 프레임 호출 (게임 로직 업데이트)
function update() {
  if (this.spaceKey.isDown) {
    flap() // 스페이스바가 눌리면 새가 점프
  }

  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition() // 새가 화면 밖으로 나가면 초기 위치로 재설정
  }
}

// 새의 위치 초기화
function restartBirdPosition() {
  bird.x = initialBirdPosition.x
  bird.y = initialBirdPosition.y
  bird.body.velocity.y = 0
}

// 새가 점프하는 기능
function flap() {
  bird.body.velocity.y = -flapVelocity
}

// Phaser 게임 인스턴스 생성
new Phaser.Game(config)
```

```jsx
2. 각 파이프의 속도를 개별적으로 설정하지 않고, 그룹화하여 관리하도록 구현.
```

```jsx
import Phaser, { Physics, Scene } from 'phaser' // Phaser 라이브러리와 필요한 모듈 불러오기

// 게임 기본 설정 객체
const config = {
  type: Phaser.AUTO, // 렌더링 타입: 웹GL 또는 Canvas 중 자동 선택
  width: 800, // 게임 화면의 너비
  height: 600, // 게임 화면의 높이
  physics: {
    default: 'arcade', // 물리 엔진으로 Arcade 사용
    arcade: {
      debug: true, // 디버그 모드 활성화 (충돌 박스 등이 보임)
    },
  },
  scene: {
    preload, // 게임 자원을 미리 로드하는 함수
    create, // 게임 초기 상태를 설정하는 함수
    update, // 매 프레임마다 호출되는 함수
  },
}

// 상수 설정
const VELOCITY = 200 // 파이프의 이동 속도
const PIPES_TO_RENDER = 4 // 렌더링할 파이프의 개수
const flapVelocity = 250 // 새가 날아오르는 속도
const initialBirdPosition = { x: config.width * 0.1, y: config.height / 2 } // 새의 초기 위치

// 전역 변수
let bird = null // 새 객체
let pipeHorizontalDistance = 0 // 파이프 간의 수평 거리 초기값

const pipeVerticalDistanceRange = [150, 250] // 파이프 상단과 하단 간의 수직 거리 범위

// 게임에 필요한 자원(이미지 등)을 미리 로드
function preload() {
  this.load.image('sky', 'assets/sky.png') // 하늘 배경 이미지
  this.load.image('bird', 'assets/bird.png') // 새 이미지
  this.load.image('pipe', 'assets/pipe.png') // 파이프 이미지
}

// 초기 상태 설정
function create() {
  this.add.image(0, 0, 'sky').setOrigin(0) // 화면에 하늘 배경을 추가 (좌측 상단 기준)

  // 새 객체 생성 및 중력 설정
  bird = this.physics.add.sprite(initialBirdPosition.x, initialBirdPosition.y, 'bird').setOrigin(0) // 새를 초기 위치에 추가
  bird.body.gravity.y = 400 // 새가 아래로 떨어지는 중력 값

  // 여러 개의 파이프 생성
  for (let i = 0; i < PIPES_TO_RENDER; i++) {
    const upperPipe = this.physics.add.sprite(0, 0, 'pipe').setOrigin(0, 1) // 상단 파이프
    const lowerPipe = this.physics.add.sprite(0, 0, 'pipe').setOrigin(0, 0) // 하단 파이프

    placePipe(upperPipe, lowerPipe) // 파이프를 화면에 배치
  }

  // 화면을 클릭했을 때 새가 날도록 설정
  this.input.on('pointerdown', flap)

  // 스페이스바를 누르면 새가 날도록 설정
  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)
}

// 매 프레임 호출되는 함수 (게임 상태 갱신)
function update() {
  // 스페이스바가 눌렸는지 확인하고 새를 날림
  if (this.spaceKey.isDown) {
    flap()
  }

  // 새가 화면 밖으로 나갔을 때 초기 위치로 되돌림
  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition()
  }
}

// 파이프를 특정 위치에 배치하고 속도를 설정
function placePipe(uPipe, lPipe) {
  pipeHorizontalDistance += 400 // 파이프 간의 수평 거리 증가
  let pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange) // 상하단 파이프 간의 랜덤 수직 거리 계산
  let pipeVerticalPosition = Phaser.Math.Between(
    0 + 20, // 화면 상단에서 일정 거리 아래
    config.height - 20 - pipeVerticalDistance // 화면 하단에서 일정 거리 위
  )

  // 상단 파이프 위치 설정
  uPipe.x = pipeHorizontalDistance // 수평 위치
  uPipe.y = pipeVerticalPosition // 수직 위치

  // 하단 파이프 위치 설정
  lPipe.x = uPipe.x // 수평 위치는 상단 파이프와 동일
  lPipe.y = uPipe.y + pipeVerticalDistance // 상단 파이프 위치에서 수직 거리만큼 아래

  // 파이프 속도 설정 (왼쪽으로 이동)
  lPipe.body.velocity.x = -200
  uPipe.body.velocity.x = -200
}

// 새를 초기 위치로 되돌림
function restartBirdPosition() {
  bird.x = initialBirdPosition.x // 초기 수평 위치
  bird.y = initialBirdPosition.y // 초기 수직 위치
  bird.body.velocity.y = 0 // 수직 속도를 0으로 설정
}

// 새가 날아오르는 동작
function flap() {
  bird.body.velocity.y = -flapVelocity // 위로 상승하도록 수직 속도를 설정
}

// 게임 시작
new Phaser.Game(config)
```

# { Phaser에서 그룹(Group)을 사용해 객체 관리하기 }

```jsx
이 강의에서는 **Phaser의 그룹(Group)**을 활용하여 여러 개의 객체(여기서는 파이프들)를 더 효율적으로 관리하고,

그룹에 물리적인 속성을 한꺼번에 적용하는 방법을 소개합니다.
```

## 1. **왜 그룹(Group)을 사용하나요?**

```jsx
Phaser에서 여러 개의 객체(스프라이트)를 각각 관리하는 대신, 이들을 그룹으로 묶으면 다음과 같은 장점이 있습니다:


		한 번에 물리 속성 적용 가능: 그룹 전체에 속도나 중력을 적용할 수 있음.

		조작이 간단: 그룹 안에 있는 특정 객체를 쉽게 추가/삭제/조작 가능.

		코드 간소화: 같은 종류의 객체를 개별적으로 다루는 코드를 줄일 수 있음.
```

## 2. **그룹 생성 방법**

```jsx
객체를 그룹으로 묶으려면 this.physics.add.group()을 사용합니다.

이 그룹은 동적인 객체들(예: 물리 속성을 가진 스프라이트)을 관리하는 데 적합합니다.
```

```jsx
변수 선언

		그룹을 담을 변수를 만들고 초기값을 null로 설정합니다.

		let pipes = null;


그룹 초기화

		create() 함수에서 그룹을 초기화합니다.

		pipes = this.physics.add.group();
```

## 3. **객체를 그룹에 추가하기**

```jsx
기존에는 각각의 파이프를 개별적으로 생성했지만,

그룹을 사용하면 다음과 같은 방법으로 생성과 그룹 추가를 한 번에 처리할 수 있습니다.
```

```jsx
기존 방식:

		const upperPipe = this.physics.add.sprite(...);
		const lowerPipe = this.physics.add.sprite(...);

새로운 방식 (그룹 사용):

		그룹의 create 메서드를 호출해 객체를 생성하면, 해당 객체가 자동으로 그룹에 추가됩니다.

		const upperPipe = pipes.create(0, 0, "pipe").setOrigin(0, 1);
		const lowerPipe = pipes.create(0, 0, "pipe").setOrigin(0, 0);

```

## 4. **그룹 전체에 물리 속성 적용하기**

```jsx
그룹을 사용하면 속도를 개별적으로 설정할 필요가 없습니다.

그룹의 setVelocityX 메서드를 이용해 전체 파이프 그룹에 동일한 속도를 적용할 수 있습니다.

이렇게 하면 그룹에 속한 모든 파이프가 왼쪽으로 움직이게 됩니다.
```

```jsx
pipes.setVelocityX(-200)
```

```jsx

pipes.create()를 통해 객체를 생성하면 자동으로 그룹에 추가됩니다.
```

```jsx
  this.load.image('bird', 'assets/bird.png') // 새 이미지 로드
  this.load.image('pipe', 'assets/pipe.png') // 파이프 이미지 로드
}

// 게임 초기화 및 객체 배치
function create() {
  // 배경 이미지 추가
  this.add.image(0, 0, 'sky').setOrigin(0)

  // 새 객체 생성 및 물리 엔진 추가

  this.spaceKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)
}

// 게임 상태를 매 프레임마다 업데이트
function update(time, delta) {
  // 새가 화면 밖으로 벗어나면 초기 위치로 되돌림
  if (bird.y > config.height || bird.y < -bird.height) {
    restartBirdPosition()
  }

  // 스페이스바가 눌리면 새가 날아오르게 함
  if (this.spaceKey.isDown) {
    flap()
  }
}

// 파이프의 위치를 지정하는 함수
function placePipe(uPipe, lPipe) {
  const rightMostX = getRightMostPipe() // 가장 오른쪽에 있는 파이프의 X 좌표
  const pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange) // 랜덤한 수직 거리 설정
  const pipeVerticalPosition = Phaser.Math.Between(
    0 + 20,
    config.height - 20 - pipeVerticalDistance
  ) // 랜덤한 수직 위치 설정
  const pipeHorizontalDistance = Phaser.Math.Between(...pipeHorizontalDistanceRange) // 랜덤한 수평 거리 설정

  // 위쪽 파이프 위치 지정
  uPipe.x = rightMostX + pipeHorizontalDistance
  uPipe.y = pipeVerticalPosition

  // 아래쪽 파이프 위치 지정 (위쪽 파이프 아래에 배치)
  lPipe.x = uPipe.x
  lPipe.y = uPipe.y + pipeVerticalDistance
}

// 가장 오른쪽에 있는 파이프의 X 좌표를 반환하는 함수
function getRightMostPipe() {
  let rightMostX = 0

  pipes.getChildren().forEach(function (pipe) {
    rightMostX = Math.max(pipe.x, rightMostX) // 가장 큰 X 좌표 찾기
  })

  return rightMostX
}

// 새의 위치를 초기화하는 함수
function restartBirdPosition() {
  bird.x = initalBirdPosition.x // 초기 X 위치
  bird.y = initalBirdPosition.y // 초기 Y 위치
  bird.body.velocity.y = 0 // 수직 속도를 0으로 초기화
}

// 새가 날아오르는 함수
function flap() {
  bird.body.velocity.y = -flapVelocity // 위로 올라가도록 수직 속도 설정
}

// Phaser 게임 인스턴스 생성
new Phaser.Game(config)
```

```jsx
화면에서 가장 오른쪽에 있는 파이프의 위치를 계산하여 새로운 파이프를 배치하는 방법입니다.
```

## 1. **목표**

```jsx
파이프들을 그룹으로 관리하며, 매번 새로운 파이프를 화면 오른쪽에 적당한 거리를 두고 배치.

가장 오른쪽에 있는 파이프의 위치를 동적으로 계산하여 다음 파이프의 위치를 설정.
```

## 2. **핵심 개념**

```jsx
파이프 그룹

		Phaser의 그룹(Group)은 여러 개의 스프라이트를 묶어 한꺼번에 관리할 수 있는 기능입니다.

		➡️ 모든 파이프를 그룹에 추가하고, 그룹 전체에 속성(속도)을 쉽게 적용.

가로 거리

		파이프 사이의 가로 간격은 pipeHorizontalDistanceRange로 설정합니다.

		가로 간격은 Phaser.Math.Between을 사용해 랜덤한 값(500~550)으로 정해집니다.

가장 오른쪽 파이프 계산

		화면에 있는 모든 파이프 중 가장 오른쪽에 있는 파이프를 찾아 위치를 기준으로 삼습니다.

		이 계산을 통해 새로운 파이프의 시작 위치를 설정.

```

```jsx
pipes = this.physics.add.group(): 파이프를 그룹으로 생성.
```

### 3.3. 파이프 위치 설정

```jsx
function placePipe(uPipe, lPipe) {
  const rightMostX = getRightMostPipe() // 가장 오른쪽 파이프 위치
  const pipeVerticalDistance = Phaser.Math.Between(...pipeVerticalDistanceRange) // 세로 간격
  const pipeVerticalPosition = Phaser.Math.Between(20, config.height - 20 - pipeVerticalDistance) // 세로 위치
  const pipeHorizontalDistance = Phaser.Math.Between(...pipeHorizontalDistanceRange) // 가로 간격

  uPipe.x = rightMostX + pipeHorizontalDistance // 가장 오른쪽 파이프 기준으로 가로 간격 추가
  uPipe.y = pipeVerticalPosition

  lPipe.x = uPipe.x
  lPipe.y = uPipe.y + pipeVerticalDistance // 아래쪽 파이프는 위 파이프 기준으로 세로 간격만큼 아래
}
```

```jsx
getRightMostPipe로 가장 오른쪽 파이프 위치 계산:

		기존 파이프 중 가장 오른쪽에 있는 파이프의 x 좌표를 계산.

		새 파이프를 그 위치에서 일정 거리만큼 오른쪽으로 떨어진 곳에 배치.

Phaser.Math.Between으로 랜덤 값 생성:

		가로 간격: pipeHorizontalDistanceRange에 따라 500~550 사이 값.

		세로 간격: pipeVerticalDistanceRange에 따라 150~250 사이 값.

파이프 위치 설정:

		uPipe.x, uPipe.y: 위쪽 파이프 위치.

		lPipe.x, lPipe.y: 위쪽 파이프 기준으로 세로 간격만큼 아래.
```

### 3.4. 가장 오른쪽 파이프 계산

```jsx
function getRightMostPipe() {
  let rightMostX = 0 // 초기값은 0

  pipes.getChildren().forEach(function (pipe) {
    rightMostX = Math.max(pipe.x, rightMostX) // 가장 오른쪽 파이프의 x 좌표 계산
  })

  return rightMostX // 가장 오른쪽 파이프의 x 좌표 반환
}
```

```jsx
pipes.getChildren():

		그룹 내 모든 파이프를 배열로 가져옴.

Math.max(pipe.x, rightMostX):

		각 파이프의 x 좌표를 비교하여 가장 큰 값을 찾음.

결과:

		화면에 있는 파이프들 중 가장 오른쪽에 있는 파이프의 x 좌표를 반환
```

## 파이프 재활용 기능 (Recycle Pipes)

```jsx
이 함수는 화면 밖으로 나간 파이프를 재활용하여 새로운 위치로 이동시키는 역할을 합니다.

이를 통해 게임 성능을 최적화하고 무한히 파이프가 생성되는 것처럼 보이게 만듭니다.
```

```jsx
function recyclePipes() {
  const tempPipes = [] // 재활용할 파이프를 임시로 저장할 배열

  // 모든 파이프를 순회하며, 화면 밖으로 나간 파이프를 찾음
  pipes.getChildren().forEach((pipe) => {
    if (pipe.getBounds().right <= 0) {
      // 화면 왼쪽으로 나갔는지 확인 pipe.getBounds()는 파이프 객체의 위치와 크기를 정의하는 사각형 정보를 제공
      tempPipes.push(pipe) // 임시 배열에 추가
      if (tempPipes.length === 2) {
        // 파이프 쌍이 모두 찾았을 때
        placePipe(...tempPipes) // 두 파이프를 재배치
      }
    }
  })
}
```

```jsx
const tempPipes = [];

		tempPipes 배열:

				재활용할 파이프(위쪽 파이프와 아래쪽 파이프)를 임시로 저장하기 위해 사용하는 배열입니다.



pipes.getChildren().forEach(pipe => { ... });

		pipes.getChildren():

				현재 화면에 존재하는 모든 파이프를 가져옵니다.

				이 메서드는 pipes 그룹에 추가된 모든 파이프를 배열 형태로 반환합니다.


		forEach 반복문:

				배열에 포함된 각 파이프를 하나씩 처리합니다.

if (pipe.getBounds().right <= 0) { ... }


		pipe.getBounds().right:

				현재 파이프의 오른쪽 끝 위치를 가져옵니다.

				만약 이 값이 0 이하라면, 파이프가 화면 왼쪽으로 완전히 사라졌음을 의미합니다.


		조건문 (<= 0):

				오른쪽 끝 위치가 화면 경계를 넘어갔다면 해당 파이프는 재활용 대상이 됩니다.


tempPipes.push(pipe);

		조건에 맞는 파이프(화면 밖으로 나간 파이프)를 tempPipes 배열에 추가합니다.

		배열에 저장하여 한 쌍(위쪽과 아래쪽)으로 묶어서 재활용할 준비를 합니다.



if (tempPipes.length === 2) { ... }

		파이프 쌍 확인:

				tempPipes 배열의 길이가 2가 되었는지 확인합니다.

				길이가 2라면, 위쪽 파이프와 아래쪽 파이프가 모두 화면 밖으로 나갔음을 의미합니다.


placePipe(...tempPipes);

재배치:

		placePipe 함수는 파이프를 새로운 위치에 배치하는 역할을 합니다.

		**...tempPipes**는 배열에 저장된 두 파이프를 인자로 전달합니다.

				첫 번째 파이프 → 위쪽 파이프

				두 번째 파이프 → 아래쪽 파이프
```

