# Enviroment

## Variables

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381168/notion-blog/_/_/_/01_/Untitled_6.png)

```java
예를들어 기본 시스템(그룹웨어) 에 로그인 하여 사용하다 특정 버튼을 누르면 넥사크로 플랫폼으로 만들어진 시스템으로 접속하게 되는것이다 이때

다시 로그인 하는것은 불편하고 번거롭다 이떄 기본 시스템의 정보를 넥사크로 플랫폼 시스템으로 전달 해줘야 하는데 그때

시스템과 시스템 간의 인터페이스 할 수 있는 무엇인가 있어야 값을 전달해 줄수있기 때문에 사용하는것이 Variables

요약

시스템간 값을 주고받을 때 변수 값을 지정하는곳
```

### Variables 값 저장과 삭제

```java
Variables 의 특징은 해당 브라우저의 로컬 스토리지에 저장되는데

로컬 스토리지는 특성상 개발자가 지워주는 스크립트를 작성해 주지 않으면 계속 쌓이게 된다

그래서 반드시 값을 셋팅했다면 값을 삭제해주는 스크립트가 들어가야 한다 (추가적으로 암호화도 필요하다)

(이는 후에 보안감사? 같은 절차를 진행하면서 값이 남아있으면 문제를 일으킬 수 있다)

요약

1. 값을 지워주는 스크립트 꼭 작성

2. 암호화 필요
```

### Cookies

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381168/notion-blog/_/_/_/01_/Untitled_7.png)

```java
쿠키는 클라이언트와 서버 간의 세션 값을 유지하는데 있어서 필요한 세션의 변수값을 정의하는곳

(WAS 에서 세션 변수 값을 확인 후 해당 변수를 맞도록 변경해 주면 된다)
```

### Http Header

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381170/notion-blog/_/_/_/01_/Untitled_8.png)

```java
Http Protocol 을 사용하게 되면 클라이언트와 서버 간의 통신시 기본 헤더 정보를 가지는데

기본 정보에 추가적으로 해당 정보를 추가하고 싶을떄 사용하는 변수 값이다

(예를 들어 방화벽 정책 관련 문제가 있을때 추가하기도 한다 이때 여기에 방화벽이 원하는 변수값을 지정해놓으면 알아서 통신때 값을 넘겨준다)
```

```java
Object 쪽에 나와있는 부분이 현재 개발에 사용할 수 있는 컴포넌트(버튼 등등) 리스트 라고 보면 된다

여길 눌러보면 javaScript 파일이 쭉 뜨는데 소스를 확인 가능하고 javaScript 를 모아놓은것이 Json 파일이라고 보면된다 (살짝 개념이 다른듯)
```

# ApplicationVariables

```java
어플리케이션의 글로벌 같은 개념이다

Variables = 는 변수 하나의 값을 가지고 있다 (글로벌 변수)
```
