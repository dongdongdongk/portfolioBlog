- 바이트 코드 파일 (A.class) 를 포함하고 있는 폴더를 패키지 라고 볼 수 있다.
- 패키지는 클래스의 일부분으로 클래스를 유일하게(com.mycom.A 와 com.yourcompany.B 는 다르니까) 만들어 주는(이름을 유일하게) 식별자 역할
- 클래스 이름이 동일 하더라도 패키지가 다르면 다른 클래스로 인식한다.
- (상위패키지.하위패키지.클래스)

       com.mycomany.A 와 com.yourcompany.B 는 다름

- 회사 도메인 역순으로 ex)com.google

- 클래스 작성시 package 를 선언한다.
- 폴더의 이름이 변하거나 package 이름이 폴더와 다르면 사용이 불가능 해진다.

![Untitled](<37%20%ED%8C%A8%ED%82%A4%EC%A7%80%EC%99%80%20%EC%A0%91%EA%B7%BC%20%EC%A0%9C%ED%95%9C%EC%9E%90(1)/Untitled%203.png>)

```java
문법 : import com.hankook.Tire;

		   import 상위패키지.하위패키지.클래스 이름; ( * 사용가능)
```

```java
package com.mycompany;

import com.hankook.Tire;           //패키지 선언과 class 선언 사이에 작성한다.
[또는 import com.hankook.*;

public class Car {
	Tire tire = new Tire();
}

// import com.hankook.*; 이런식으로 * 를 붙여주면 hankook 하위 폴더를 전부 임포트 한다.
// 주의 할건 hankook 하위의 하위 폴더는 인식 하지 못하므로 그럴땐 별도로 임포트 필요
```
