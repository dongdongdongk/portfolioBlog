## **다형성**

- 사용 방법은 동일하지만 다양한 객체를 활용해 여러 실행결과가 나오도록 하는 성질
- 메소드 재정의 + 타입변환 으로 구현한다.

```java
int i = 10;
double d= i; // 이렇게 하면 자동으로 int i 가 double 로 변하는 것 처럼

A a = new A();     // a라는 객체를 만들고
B b = a;           // 이런식으로 타입을 변환 시켜줄 수 있다.
```

```java
자동차는 타이어 타입으로 Hankook 타이어와 Kumho 타이어를 사용하지만,
각 타이어의 성능은 다르게 나온다. (다형성) 이를 코드로 표현하면

Tire t1 = new HankiikTire(); // 자식 타입 객체 대입
Tire t2 = new kumhoTire();
```

```java
문법 : 부모타입 변수 = 자식타입;

Animal animal = new Cat();

// 조건은 무조건 부모와 자식의 관계여야지 타입변환 가능

// 하위 객체가 상위 객체로 변환이 가능한 것

// Animal 타입의 Cat 객체를 참조하는(객체번지) animal 변수
```

```java
Cat cat = new Cat(); // cat 이라는 객체를 생성하고

Animal animal = cat;  // cat 의 데이터 타입을 Animal 로 자동 타입 변환 시켜준다.

Animal animal = new Cat(); 도 가능

// cat 이 참조하고 있는 객체의 번지를 animal 이라는 변수에 대입을 했다.
// 즉 animal 은 Cat 이라는 객체를 참조하는 번지를 가진다.

// 이처럼 Cat 타입의 변수가 Animal 타입의 변수로 자동 변환 되는걸 자동 타입 변환 이라고 한다.
```

- B 와 E 는 상속 관계가 없기 때문에 자동 타입 변환이 불가능 하다.
- D 와 A 같은 경우는 상속 계층에서 상위 타입 이여서 자동 타입 변환이 가능하다.

![Untitled](<42%20%ED%83%80%EC%9E%85%20%EB%B3%80%ED%99%98%EA%B3%BC%20%EB%8B%A4%ED%98%95%EC%84%B1(1)/Untitled%203.png>)

```java
Class Parent {                // 부모 클래스
	void method1() { ... }
	void method2() { ... }
}

Class Child extends Parent {   // 자식 클래스
	void method2() { ... }       // 메소드 재정의
	void method3() { ... }
}

/*부모 타입으로 자동 타입 변환된 변수는 부모 클래스에 선언된 필드와 메소드만 접근 가능하다.

비록 변수는 자식 객체를 참조하지만,

변수로 접근 가능한 멤버는 부모 클래스 멤버로 한정된다.

예외) 메소드가 자식 클래스에서 오버라이딩되었다면, 자식 클래스의 메소드가 대신 호출된다.

(다형성과 관련)

오버라이딩되었다면, 자식 클래스의 메소드에 접근 가능하다.*/

Clas ChildExample {
	public static void main(String[] args) {
		Child child = new Child();

		Parent parent = child;   // 자동 타입 변환

		parent.method1();        // 부모 클래스의 메소드로 접근 가능

		parent.method2();        // 메소드 재정의를 거쳤기 때문에 자식 클래스의 재정의된 메소드에
                             // 접근하게 된다.
		parent.method3();        // 부모 클래스에 존재하는 메소드가 아니기 때문에 호출 불가능
	}
}
```
