**필드 :** 필드는 객체의 고유 데이터, 가져야 할 부품, 객체의 현재 상태 데이터 등을 저장한다.

**고유 데이터 :** 변하지 않는 데이터

**상태 데이터 :** 고정되지 않은 그때그때 변하는 데이터

**부품 :** 객체를 만들기 위해 필요한 것

```java
public class Car {

	String company; // 변수에 맞게 타입을 지정해서 선언 해준다.
	String model;   // String 은 필드 타입 model 은 필드 이 름
	String color;
	int maxSpeed;

	int speed;
	int rpm;

	Body boby; //기본 타입이 아닌 또 다른 클래스 타입으로 선언 되었다.
	Engine engine;
	Tire tire;

}
```

### 필드선언

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380997/notion-blog/_/JAVA/_/28_/Untitled_1.png)

```java
생성자

xxx() {
	String model = "그랜저"

메소드

voidmethod(xxx) {

}
```

필드 선언은 변수와 선언 형태가 유사하나 변수가 아님에 주의한다

클래스 블록에서 선언되면 필드 생성자나 메소드 에서 선언되면 로컬변수 선언 위치에 따라 달라진다.

이러한 필드는 생성자나 메소드와 달리 중괄호가 끝난다고 사라지는 것이 아닌 객체가 만들어 졌을때 항상 그 안에 존재하게 된다.

```java
타입 필드 = 초기값;
String company = "현대자동차"
int currentSpeed; // 기본값 자동으로
```

**클래스 내부 생성자 또는 메소드 에서 사용하는 경우 :필드 이름으로 읽고 변경**

```java
//필드
int speed; //클래스 내부에서 이렇게 필드 선언을 하면

//생성자
Car() {
speed = 0; // 생성자 또는 메소드 에서 이름(speed) 만으로 값을 저장,변경,출력 등 할 수 있다.
}

//메소드
void method(...) {
speed = 10;
}
```

**클래스 외부에서 사용하는 경우** : 클래스 객체를 생성한 뒤 필드 사용

```java
void method() {
//Car 객체 생성
Car myCar = new Car();

//필드 사용 (값 변경)
myCar.speed=60; //speed 필드 사용(값 변경)
                //. 의 뜻은 myCar 가 참조하는 객체로 가서 안에 있는 speed 에 접근하라
```
