## 자동 레이아웃 속성

```jsx
자동 레이아웃 옵션:

	디자인 패널의 오른쪽에서 프레임과 연결된 자동 레이아웃 속성을 확인합니다.

수평 패딩:

	요소 주변의 패딩을 늘리거나 줄입니다.

	가로 패딩을 60으로 설정합니다.

수직 패딩:

	수직 패딩을 40으로 설정합니다.

개별 패딩 조절:

	패딩 값을 수동으로 변경할 수 있습니다. 예: 왼쪽 패딩 60, 오른쪽 패딩 80.

	옵션 키를 누른 채로 패딩을 동일하게 변경할 수 있습니다. 예: 100으로 설정.

	작은 분홍색 막대를 사용하여 패딩을 조절할 수 있습니다.

	옵션+쉬프트 키를 눌러 모든 면의 패딩을 동일하게 변경할 수 있습니다.
```

## 요소 정렬

```jsx
정렬 도구:

	자동 레이아웃 프레임 내부의 요소를 정렬할 수 있습니다. 예: 중앙 정렬.

	프레임을 늘리거나 줄이면 요소가 프레임에 따라 동작합니다.

	상단 왼쪽 정렬로 변경하면 프레임 크기 변경 시 요소가 위쪽에 정렬됩니다.
```

## 자동 레이아웃 속성

```jsx
채우기 및 패딩 적용:

	기본적으로 가로 방향입니다. 방향을 세로로 변경할 수 있습니다.

	채우기를 추가하고 양쪽에 패딩을 적용합니다.

간격 변경:

	간격을 변경하고, 마이너스 값을 입력하여 요소들이 겹치도록 할 수 있습니다.

	색상을 변경하여 간격이 어떻게 작동하는지 확인합니다.

캔버스 스택 변경:

	디폴트 값은 Last on top입니다. 이를 First on top으로 변경하여 순서를 변경할 수 있습니다.
```

```jsx
컴포넌트를 사용하면 UI 요소를 한 번만 생성하고 여러 번 재사용할 수 있습니다.

또한, 자식 컴포넌트를 마스터 컴포넌트로 변환하여 변경 사항을 쉽게 관리할 수 있습니다.
```

## 배리언트 생성

```jsx
배리언트 추가:

버튼을 선택하고 복사본을 만들어 배리언트를 추가합니다.

첫 번째 배리언트는 'Dark'로 이름을 바꾸고, 채우기 색상을 흰색에서 검정색으로, 텍스트 색상은 검정색에서 흰색으로 변경합니다.

추가 배리언트 생성:

두 번째 배리언트는 채우기 색상을 파란색으로 변경하고, 이름을 'Main Color'로 설정합니다.

세 번째 배리언트는 채우기 색상을 회색으로, 텍스트 색상을 회색으로 변경하고, 이름을 'Disabled'로 설정합니다.

네 번째 배리언트는 기본 색상으로, 이름을 'Light'로 설정합니다.
```

## 배리언트 활용

```jsx
에셋 패널 활용:

에셋 패널로 이동하면 배리언트로 가득 차지 않고, 마스터 컴포넌트로 변환된 버튼이 하나만 나타납니다.

버튼 텍스트 변경:

버튼을 드래그하여 텍스트를 'SignUp' 또는 'Login'으로 변경합니다.

테마 변경:

버튼 테마를 클릭하여 'Light'에서 'Dark'로 변경할 수 있습니다.

다른 배리언트를 활용하여 텍스트를 'Click Here' 또는 'Don't Click Here'로 변경하고, 배리언트를 'Disabled'로 설정할 수 있습니다.
```
