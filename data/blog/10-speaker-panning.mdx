## 1. Speaker Panning 개념 이해하기

- **Speaker Panning**이란?
  → 사운드를 실제 3D 공간상의 좌표가 아닌, **리스너(플레이어) 기준의 스피커 위치에 따라 분배(pan)** 하는 방식입니다.
  → 즉, 사운드가 “어느 스피커에서 얼마나 크게 들릴지”를 조정하는 기술입니다.
- **3D 오디오 시스템과 차이점**
  | 구분 | 3D 오디오(Spatial Audio) | Speaker Panning |
  | ----------- | --------------------------------------- | ------------------------------------ |
  | 위치 기준 | 게임 오브젝트의 실제 x, y, z 좌표 | 리스너 기준의 상대적 스피커 위치 |
  | 사운드 변화 | 리스너 이동 시 사운드 방향, 거리감 변함 | 리스너가 움직여도 사운드 위치는 고정 |
  | 용도 | 실제 공간에 존재하는 소리 | HUD, UI, 나레이션, 배경음악 등 |
- **핵심 개념 요약**
  - 사운드는 **실제 위치에 존재하지 않음.**
  - 대신 **리스너의 시점에서 고정된 방향**으로 들림.
  - 주로 **화면 UI 사운드**, **내레이션**, **음악** 등에 사용됨.

---

## 2. 게임 내 사운드 배치 원리

- Cube 게임 내 상황:
  - Wwizard(마법사)가 지팡이를 휘두를 때 오른쪽 화면 밖으로 소리가 이동하는 듯한 연출이 필요.
  - 보석이 충전되는 “마법 사운드”도 시각적 효과와 함께 들려야 함.
- 그러나 이 사운드들은 **별도의 게임 오브젝트로 존재하지 않음**.
  → 즉, 오디오 소스가 3D 공간 좌표 (x, y, z)에 배치되지 않음.
- 이런 경우 **Speaker Panning**이 적합.
  - 사운드가 리스너 시점에 “항상 같은 위치”에서 발생하도록 설정 가능.
  - 지팡이 휘두름 소리는 **오른쪽 전방 스피커**,
    보석 충전 사운드는 **화면 중앙 또는 살짝 왼쪽 앞쪽 스피커**로 배치할 수 있음.

---

## 3. Speaker Panning 설정 방법

> 💡 Unity나 FMOD, Wwise 같은 오디오 엔진에서도 Speaker Panning은 주로 “2D Sound” 또는 “Stereo Pan” 옵션으로 설정됩니다.

- **기본 설정 절차 예시**
  1. 오디오 소스에서 **Spatial Blend**를 `0` (2D)으로 설정.

     → 3D 공간의 영향을 받지 않음.

  2. **Pan 설정(Panning)** 을 사용하여 소리를 어느 방향 스피커에서 재생할지 조정.
     - `Pan = -1` → 왼쪽 스피커
     - `Pan = 0` → 중앙
     - `Pan = +1` → 오른쪽 스피커
  3. 필요 시 **서라운드 채널** 설정:
     - 전방(Front) / 후방(Rear) / 좌우(Surround)로 배치 가능.
     - 예: 나레이션을 리스너 뒤에서 들리게 하려면 **Rear Left, Rear Right 스피커**로 지정.

---

## 4. Speaker Panning의 활용 사례

| 상황                  | Speaker Panning 사용 예시              | 이유                                    |
| --------------------- | -------------------------------------- | --------------------------------------- |
| **UI 버튼 클릭 소리** | 화면 중앙 또는 왼쪽 위 HUD 근처 스피커 | UI 위치에 대응되는 방향감 부여          |
| **게임 음악 (BGM)**   | 좌우 앞 스피커 중심                    | 실제 밴드가 눈앞에서 연주하는 듯한 느낌 |
| **나레이션**          | 뒤쪽 서라운드 스피커                   | 리스너 뒤에서 누가 말하는 듯한 효과     |
| **마법 충전 사운드**  | 오른쪽 앞 스피커                       | 지팡이를 휘두르는 시각적 방향감과 일치  |

## 5. 정리: 리스너 상대 사운드 배치 기술

- **Speaker Panning의 핵심 목표**
  → “사운드를 리스너의 시점에서 상대적이고 고정된 위치에 두는 것”
- **이 단원에서 익히는 기술**
  1. 실제 게임 오브젝트가 없는 사운드를 처리하는 방법.
  2. 사운드를 리스너 기준의 스피커에 배치하는 방법.
  3. 음악, 나레이션, 마법 사운드처럼 **3D 위치 정보가 필요 없는 오디오**를 다루는 법.

## 1. Actor-Mixer 개념과 활용

### 🧩 Actor-Mixer란?

- **Wwise의 오브젝트 계층 구조에서 "폴더" 역할을 하는 오브젝트**입니다.
- 여러 사운드 오브젝트를 하나로 묶을 수 있으며,
  그 안에 포함된 모든 사운드에 **공통 속성을 한 번에 적용**할 수 있습니다.

### 🎯 사용 목적

- 사운드 관리 효율화
- 동일한 속성(예: 위치, 볼륨, 패닝 등)을 여러 사운드에 동시에 적용
- 프로젝트 구조를 명확히 정리

## 3. 사운드 오브젝트 묶기

### 🎵 대상 오브젝트

- `Gem_Recharge_Magic`
- `Gem_Recharge_Woosh`

### 🪄 묶는 방법

1. **Project Explorer**에서 위 두 오브젝트 선택
2. 마우스 오른쪽 클릭 → **New Parent > Actor-Mixer** 선택
3. 새로 생성된 Actor-Mixer의 이름을 **“Staff Recharge”** 로 변경
4. 이제 두 사운드는 “Staff Recharge”의 하위 오브젝트로 묶임

### 💡 결과

- 앞으로 “Staff Recharge”에 적용하는 속성(예: 위치, 볼륨, 패닝 등)은
  내부의 두 사운드(`Magic`, `Woosh`) 모두에 동일하게 적용됨.

## 4. Speaker Panning 설정하기

### 🧠 패닝(Panning)이란?

- 소리를 **스피커(혹은 채널) 간에 분배하는 기술**로,
  청취자에게 특정 방향에서 소리가 들리는 것처럼 느끼게 합니다.

---

### ⚙️ 설정 단계

1. **“Staff Recharge” 오브젝트 선택**
2. **Property Editor** 패널 → **Positioning 탭 선택**
3. **Speaker Panning** 목록에서

   기본값인 **Direct Assignment** → **Balance-Fade** 로 변경

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380538/notion-blog/_/WWISE/Wwise_/10_Speaker_Panning_/image_1.png)

---

### 🔍 옵션 설명

### 🔸 Direct Assignment (기본값)

- 각 사운드의 채널이 **왼쪽/오른쪽 전면 스피커**로만 직접 출력됨.
- 서라운드 환경에서는 입체감이 제한적임.

### 🔸 Balance-Fade (변경할 옵션)

- 사운드가 **여러 스피커 간에 부드럽게 분배되어 재생**됨.
- 전면/후면 스피커 간의 **볼륨 균형(Fade)** 을 조절하여
  **서라운드 공간감**을 자연스럽게 만듦.

## 5. 사운드 위치 지정하기

### 🧭 절차

1. **Edit the Speaker Panning** 버튼 클릭

   → **Speaker Panner 창**이 열림

2. 화면 설명:
   - **5.1 서라운드 환경의 평면도**처럼 표시됨.
   - 중앙의 아이콘 = **플레이어(리스너)**
   - 주변 스피커 배치가 시각적으로 표시됨.
3. \*기준점(Cursor)**을 **플레이어의 오른쪽 앞쪽으로 살짝 드래그\*\*

   → 사운드의 공간적 위치를 지정함.
