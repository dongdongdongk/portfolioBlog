# 1. **픽셀 (px)**

```scss
**픽셀(px)**은 고정된 단위로, 화면에서 1픽셀의 크기를 나타냅니다.
```

```scss
.box {
  width: 100px;
  height: 50px;
  background-color: lightblue;
}
```

# 2. **퍼센트 (%)**

```scss
**퍼센트(%)**는 부모 요소의 크기에 대한 비율로 크기를 지정합니다.
```

```scss
.container {
  width: 500px;
}

.box {
  width: 50%; /* 부모 요소인 .container의 50% */
  height: 50px;
  background-color: lightgreen;
}
```

# 3. **뷰포트 단위 (vw, vh, vmin, vmax)**

```scss
vw (Viewport Width): 뷰포트 너비의 1%

vh (Viewport Height): 뷰포트 높이의 1%

vmin: 뷰포트의 너비와 높이 중 작은 값의 1%

vmax: 뷰포트의 너비와 높이 중 큰 값의 1%

* 뷰포트(Viewport)는 웹 브라우저에서 웹 페이지를 표시하는 영역을 의미해요.

	쉽게 말해, 사용자가 현재 보고 있는 웹 페이지의 창 크기를 뜻합니다.
```

```scss
.box {
  width: 50vw; /* 뷰포트 너비의 50% */
  height: 50vh; /* 뷰포트 높이의 50% */
  background-color: lightcoral;
}
```

# 4. **엠 (em)**

```scss
**엠(em)**은 부모 요소의 글꼴 크기를 기준으로 하는 상대적인 단위입니다.
```

```scss
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em; /* 부모 요소의 글꼴 크기인 20px의 1.5배 = 30px */
}
```

# 5. **렙 (rem)**

```scss
**렙(rem)**은 루트 요소(html)의 글꼴 크기를 기준으로 하는 상대적인 단위입니다.
```

```scss
html {
  font-size: 16px;
}

.box {
  font-size: 2rem; /* 루트 요소의 글꼴 크기인 16px의 2배 = 32px */
}
```

# 6. **프랙셔널 유닛 (fr)**

```scss
**프랙셔널 유닛(fr)**은 그리드 레이아웃에서 가용 공간을 비율에 따라 나누는 단위입니다.
```

```scss
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

.box1,
.box2,
.box3 {
  background-color: lightblue;
}

.box1 {
  grid-column: 1;
}

.box2 {
  grid-column: 2;
}

.box3 {
  grid-column: 3;
}
```
