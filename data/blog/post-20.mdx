## 테스트 등록 관련 방식 선택

```csharp
1. 새로운 테스트 등록 과정을 결정

2. 관리자 페이지에서 등록 하던 방식에서 매번 새롭게 배포하는 방식으로 결정

3. 아래 두가지 방식 중에 하나를 선택해야함
```

| 항목              | **1번: 직접 폴더 추가 방식**                      | **2번: Git + 자동배포 방식**                    |
| ----------------- | ------------------------------------------------- | ----------------------------------------------- |
| **배포 위치**     | 서버의 `/public/psych-tests/` 같은 폴더           | 외부 호스팅 (Netlify, Vercel, Firebase 등)      |
| **배포 방식**     | 빌드 결과를 **수동으로 복사/업로드**              | Git에 푸시하면 **자동으로 배포**                |
| **서버 관리**     | 직접 관리 (온프레미스/웹서버 필요)                | 자동 관리 (외부 서비스 사용)                    |
| **테스트 URL 예** | `/psych-tests/love-style/index.html`              | `https://your-app.netlify.app/tests/love-style` |
| **장점**          | - 내부망/사설망에서도 가능- 구조 단순함           | - 배포 자동화- 서버 없이 가능- 버전관리 쉬움    |
| **단점**          | - 매번 직접 복사해야 함- 서버 용량/권한 관리 필요 | - Git 이해 필요- 외부 서비스 의존               |
| **적합한 상황**   | 온프레미스 서버, 내부망 환경                      | 퍼블릭 웹서비스, 개발자 많은 팀, 배포 빈도 높음 |
