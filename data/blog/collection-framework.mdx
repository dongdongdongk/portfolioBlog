## 컬렉션 프레임워크

배열의 문제점인

1. 크기가 고정적임
2. 인덱스 삭제시 빈 인덱스 데이터로 인해 데이터 낭비

이를 해결하기 위해 데이터를 효율적으로 관리(추가,삭제,검색,저장) 할 수 있는 자료구조를 만들어둔 라이브러리 컬렉션 프레임 워크

(List, Set, Map, Stack, Queue)

### List컬렉션 (ArrayList, LinkedList, Vector)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380963/notion-blog/_/JAVA/_/Collection_Framework/Untitled_1.png)

- List컬렉션은 객체를 일렬로 늘어놓은 구조
- 객체를 인덱스로 관리 (인덱스로 검색,삭제 기능제공)
- 동일한 객체를 중복 저장 가능 (null 도 저장가능)
- List 인터페이스를 같이 상속(Array,Linked,Vector)

### 1.ArrayList

```jsx
문법 : ArrayLIst<String> list = new ArrayList<>();

       ArrayList<제네릭> 변수 = new 생성자
```

```jsx
제네릭 : 자료형의 안정성을 위해 사용되며 <> 타입의 객체들만
add 되어질 수 있다.

* 제네릭스는 객체 타입만 선언 가능하다.
ex) int 는 Integer 같은 wrapper 클래스로 사용 해야한다
```

```java
다양한 선언법
ArrayList list = new ArrayList(); //타입 미설정 Object로 선언된다.
ArrayList<Student> members = new ArrayList<Student>(); //타입설정 Student객체만 사용가능
ArrayList<Integer> num = new ArrayList<Integer>(); //타입설정 int타입만 사용가능
ArrayList<Integer> num2 = new ArrayList<>(); // new에서 타입 파라미터 생략가능
ArrayList<Integer> num3 = new ArrayList<Integer>(10); //초기 용량(capacity)지정
ArrayList<Integer> list2 = new ArrayList<Integer>(Arrays.asList(1,2,3);//생성시 값추가

*Arrays.asList() 를 사용하면 추가, 삭제가 불가능하다
```

**ArrayList 값 추가**

```jsx
문법 : .add(index,value);

ArrayList<Integer> list = new ArrayList<Integer>();
list.add(3);
list.add(null);
list.add(1,10) // index 1에 10 삽입
```

- ArrayList 에 값을 추가하려면 add(index,value) 메소드를 사용
- 맨 뒤부터 데이터가 추가되며 중간에 값을 추가하면 모두 1씩 밀려남
- insert 가 많다면 LinkedList 가 더 효과적

**ArrayList 값 삭제**

```jsx
문법 : .remove();

list.remove(1); // index 1 제거

list.clear(); //모든 값 제거
```

- remove() 함수를 사용하여 특정 인덱스 객체를 제거하면 뒤 인덱스부터 모두 앞으로 1씩 당겨짐

**ArrayList 크기(길이) 구하기**

```java
문법 : .size();

ArrayList<Integer> list = new ArrayList<Integer>(Arrays.asList(1,2,3));

System.out.println(list.size()); //list 크기 : 3
```

- size() 메소드를 사용하여 배열의 크기(길이) 를 구할 수 있다.

**ArrayList값 출력**

```java

문법 : .get(index);

ArrayList<Integer> list = new ArrayList<Integer>(Arrays.asList(1,2,3);

System.out.println(list.get(0)); //0번째 인덱스 출력

for(Integer i : list) { //for문을 통한 전체출력
	System.out.pirntln(i);
}

Iterator iter = lis.iterator(); // Iterator 선언 (후에 추가)

while(iter.hasNext()) { // 다음값이 있는지 체크

```

**ArrayList 값 검색**

```java
문법 : contains(value) 값이 있다면 true 없다는 false 가 리턴된다.
       indexOf(value) 값이 있는 index 번호를 반환 없으면 -1

ArrayList<Integer> list = new ArrayList<Integer>(Arrays.asList(1,2,3));
System.out.println(list.contains(1)); // list에 1이 있는지 검색 : true
System.out.println(list.indexOf(1)); // 1이 있는 index반환 없으면 -1
```

### 2.LinkedList

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380964/notion-blog/_/JAVA/_/Collection_Framework/Untitled_2.png)

- ArrayList 는 검색이 많은경우, LinkedList 는 잦은 삽입/삭제시 사용한다.
- ArrayList 와 달리 객체 추가 삭제시 인덱스가 밀리거나 당겨지지 않는다.
- ArrayList 와 달리 초기의 크기를 설정할 수 없다.
- ArrayList 는 한 덩어리의 큰 배열을 사용하지만 LinkedList 는 양방향 연결 리스트로 구현
- 각각의 데이터 노드 +nex (다음노드) prev(이전노드) 값을 내부적으로 가지고있다.

**LinkedList 값 추가**

```java
문법 : .add(index,value)

LinkedList<Integer> ar = new Linkedlist<Integer>();
ar.addFirst(1); // 가장 앞에 데이터 추가
ar.addLast(2); // 가장 뒤에 데이터 추가
ar.add(3); //데이터 추가
ar.add(1,10); /// index 1에 데이터 10 넣기
```

```java
LinkedList<Student> list = new LinkedList<Student>();
Student student = new Student(name.age);
members.add(student);
members.add(new Member("홍길동,15));
```

**LinkedList 값 삭제**

```java
문법 : .remove(index,value)

list.removeFirst();  // 가장 앞의 데이터 제거
list.removerLast();  // 가장 뒤의 데이터 제거
list.remove();  //생략시 0번째 index 제거
list.remove(1); // index 1 제거
list.clear();  // 모든값 제거
```

**LinkedList 크기 구하기**

```java
문법 : System.out.println(list.size());   // list 의 크기 구하기
```

**LinkedList 값 출력**

```java

문법 : .get();     Iterator 사용

System.out.println(list.get(0); // 0번째 index 출력

for(Integer i : list) { // 향상된 for문을 통한 전체 출력
	System.out.println(i);
}

Iterator<Integer> iter = list.iterator(); // Iterator 선언

while(iter.hasNext()) { // 다음값이 있는지 체크
	System.out.println(iter.next()); //값 출력
}
```

**LinkedList 값 검색**

```java
문법 : .indexOf();      .contains();

System.out.println(list.contains(1)); // list에 1이 있는지 검색 : 결과 true
System.out.println(list.indexOf(1)); // 1이 있는 index 반환 없으면 -1
```

### Set 컬렉션 (HashSet,TreeSet)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380964/notion-blog/_/JAVA/_/Collection_Framework/Untitled_3.png)

- List 컬랙션과 다르게 순서대로 저장되지 않는다.
- 순서가 없으므로 인덱스로 객체를 검색하여 불러올 수 없다. .get() 사용 불가능
- 중복 저장이 불가능하고 그로인해 null 도 하나만 존재할 수 있다. (유리)
- 추가 삭제가 list 보다 느리다.

### 1.HashSet

**HashSet 선언**

```java
HashSet<Integer> set1 = new HashSet<Integer>(); //HashSet 생성
HashSet<Integer> set2 = new HashSet<>(); // new에서 타입 파라미터 생략가능
HashSet<Integer> set3 = new HashSet<Integer>(set1) // set1의 모든 값을 가진 HashSet생성
HashSet<Integer> set4 = new HashSet<Integer>(10); // 초기용량 지정
HashSet<Integer> set5 = new HashSet<Integer>(Array.asList(1,2,3)); // 초기값 지정

*Set 은 한칸씩 공간을 늘리지 않고 저장용량을 두배로 늘린다 과부하가 많이 발생하니 초기
 저장 데이터 갯수를 설정해주는것이 좋다.
```

**HashSet 값 추가**

```java
문법 : set.add(1) // 값 추가
```

**HashSet 값 삭제**

```java

			 set.clear();   // 모든 값 제거

*리스트와 다르게 인덱스가 아닌 값을 찾아서 제거
```

**HashSet 의 크기**

```java

```

**HashSet 출력**


### Map 컬렉션 (HashMap,TreeMap)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380964/notion-blog/_/JAVA/_/Collection_Framework/Untitled_4.png)

- key 와 값(value) 로 구성된 자료구조
- 키는 중복으로 저장할 수 없으며 값은 중복으로 저장 가능하다. (key 가 중복되면 기존 key 는 사라지고 새로운 값으로 대체된다.)
- 많은 양의 데이터를 검색 하는데 있어 뛰어나 기능
