```sass
// 미디어 쿼리 매니저 (Media Query Manager)

/*
  다양한 화면 크기별로 스타일을 적용하기 위한 미디어 쿼리 관리 믹스인입니다.
  주어진 화면 폭 범위에 따라 서로 다른 스타일을 적용하기 위해 사용됩니다.

  0 -- 600px: Phone (폰)
  600px - 900px: Tablet Portrait (태블릿 세로 모드)
  900px - 1200px: Tablet Landscape (태블릿 가로 모드)
  1200px - 1800px: Desktop (데스크탑)

  $breakpoin: 화면 크기에 따른 구분을 의미하는 매개변수이며, 다음 선택지를 가집니다.

  - phone: 600px 이하의 폰 화면
  - tab-port: 600px - 900px 사이의 태블릿 세로 모드 화면
  - tab-land: 900px - 1200px 사이의 태블릿 가로 모드 화면
  - desktop: 1200px 이상의 데스크탑 화면 (이 경우에는 기본 스타일이 적용됩니다)
*/

@mixin respond($breakpoin) {
    // breakpoin에 따라 해당하는 미디어 쿼리가 생성됨
    // @mixin respond($breakpoin): respond라는 이름의 믹스인이고, $breakpoin이라는 매개변수를 받습니다

    @if $breakpoin == phone {
        // phone 화면에 대한 미디어 쿼리
        @media screen and (max-width: 37.5rem) {
            // 37.5rem은 600px을 의미, 600px 이하의 화면에서 스타일이 적용됨
            @content; // 해당 블록 내의 스타일을 삽입함
        }
    }

    @if $breakpoin == tab-port {
        // tablet portrait (세로 모드)에 대한 미디어 쿼리
        @media screen and (max-width: 56.25rem) {
            // 56.25rem은 900px을 의미, 900px 이하의 화면에서 스타일이 적용됨
            @content;
        }
    }

    @if $breakpoin == tab-land {
        // tablet landscape (가로 모드)에 대한 미디어 쿼리
        @media screen and (max-width: 75rem) {
            // 75rem은 1200px을 의미, 1200px 이하의 화면에서 스타일이 적용됨
            @content;
        }
    }
}

```

### @content

```sass
믹스인 내부에서 특정 스타일 블록을 정의하지 않고, 믹스인을 호출할 때 그 자리에 CSS 스타일을 삽입할 수 있도록 해주는 역할을 합니다.
```

```sass
@mixin example {
  border: 1px solid black;
  @content;
}
```

```sass
.my-element {
  @include example {
    color: red; // @content 부분에 이 스타일이 삽입됨
  }
}
```

```jsx

```

    content: "앞에 ";
}
p::after {
    content: " 뒤에";
}

```jsx
// Navbar.scss 파일에서 스타일을 가져옵니다.
import './Navbar.scss'
// React의 useState 훅을 가져옵니다.
import { useState } from 'react'
// 로고 이미지 파일을 가져옵니다.
import Logo from '../../assets/logo.png'
// 이메일 아이콘과 햄버거 메뉴 아이콘을 가져옵니다.
import { PiEnvelopeOpen } from 'react-icons/pi'
import { FaBars } from 'react-icons/fa'

// Navbar 컴포넌트를 정의합니다.
export const Navbar = () => {
  // 네비게이션 바의 표시 상태를 관리하는 상태 변수입니다.
  // 초기 상태는 false로 설정되어 네비게이션 바가 숨겨져 있습니다.
  const [showNav, setShowNav] = useState(false)

  return (
    // 네비게이션 바를 정의하는 <nav> 태그입니다.
    <nav className="navbar">
      {/* 네비게이션 바의 컨테이너입니다. 내부에 wrapper 클래스를 사용하여 스타일을 적용합니다. */}
      <div className="navbar__container wrapper">
        {/* 로고를 클릭하면 네비게이션 바를 닫습니다. */}
        <a href="#hero" className="navbar__logo" onClick={() => setShowNav(false)}>
          {/* 로고 이미지를 표시합니다. */}
          <img src={Logo} alt="Logo" />
        </a>

        {/* 네비게이션 링크 목록입니다. 
                    `showNav` 상태에 따라 'display' 클래스를 조건부로 적용합니다. */}
        <ul className={`navbar__links ${showNav ? 'display' : ''}`}>
          {/* 각 링크를 클릭하면 네비게이션 바를 닫습니다. */}
          <li onClick={() => setShowNav(false)}>
            <a href="#hero">Home</a>
          </li>
          <li onClick={() => setShowNav(false)}>
            <a href="#services">Services</a>
          </li>
          <li onClick={() => setShowNav(false)}>
            <a href="#portfolio">Portfolio</a>
          </li>
          <li onClick={() => setShowNav(false)}>
            <a href="#reviews">Reviews</a>
          </li>
        </ul>
        {/* 연락처 버튼입니다. 클릭 시 연락처 섹션으로 이동합니다. */}
        <a href="#contact" className="navbar__btn btn">
          {/* 이메일 아이콘을 표시합니다. */}
          <PiEnvelopeOpen /> Contact
        </a>

        {/* 햄버거 메뉴 아이콘입니다. 
                    클릭 시 네비게이션 바의 표시 상태를 토글합니다. */}
        <div
          className={`navbar__menu ${showNav ? 'bg-color' : ''}`}
          onClick={() => setShowNav(!showNav)}
        >
          {/* 햄버거 아이콘을 표시합니다. */}
          <FaBars />
        </div>
      </div>
    </nav>
  )
}
```

```jsx
버튼을 보면 아까전에 전역에서 설정해준 모양으로 만들어 지고 있다

상태 관리 (useState):

		showNav는 모바일에서 메뉴가 열려 있는지 여부를 관리합니다.

		setShowNav를 통해 메뉴가 열리거나 닫히게 상태를 변경합니다.

로고 클릭:

		로고를 클릭하면 setShowNav(false)로 메뉴를 닫습니다.

네비게이션 링크:

		각각의 링크는 클릭 시 메뉴를 닫는 동시에 특정 섹션(예: Home, Services)으로 이동시킵니다.

Contact 버튼:

		PiEnvelopeOpen 아이콘과 함께 'Contact' 버튼이 표시됩니다.

햄버거 메뉴:

		모바일에서 사용자가 햄버거 아이콘을 클릭하면 showNav 상태가 변경되어 메뉴가 열리거나 닫히게 됩니다.

동적 클래스:

		showNav 값에 따라 'navbar__links ${showNav ? "display" : ""}'와

		'navbar__menu ${showNav ? "bg-color" : ""}' 클래스가 동적으로 적용됩니다.

		이를 통해 메뉴의 표시 여부와 배경색 등을 제어할 수 있습니다.
```

### repeat 와 auto-fit 을 이용한 그리드 만들기

```jsx
grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr));

		화면 크기가 커지면 열의 너비가 최대 1fr까지 커지고, 화면 크기가 작아지면 열이 최소 15rem까지 줄어듭니다.

		**auto-fit**은 화면 크기에 맞게 열의 개수를 조정해 주므로,

		작은 화면에서는 열이 자동으로 줄어들고, 큰 화면에서는 열이 자동으로 늘어납니다.
```
