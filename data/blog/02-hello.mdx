## 버튼의 속성 변경하기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381495/notion-blog/_/_/_/02_Hello/Untitled_13.png)

```java
this.Button00_onclick = function(obj:nexacro.Button,e:nexacro.ClickEventInfo)
{
	this.alert("Hello");

	// 로그를 찍는방법
	//.trace 가 로그다
	nexacro.getApplication().trace("안녕");

	// 똑같은 로그 찍는 기능 이지만 다른 방식
	var objApp = nexacro.getApplication();
	objApp.trace("안녕하세요");

	//버튼의 텍스트를 바꾸는 기능
	this.Button00.set_text("안녕");// set_속성명 을 꼭 적어줘야한다

	//버튼의 텍스트를 get 하는방법 .text 하면 된다
	this.alert(this.Button00.text);
};
```

```java
1. 버튼의 속성을 바꿀때는 set_속성명 을 적어서 바꿔준다

2. 속성을 get 할때는 get 을 써주는게 아니라 .text 같은 방법으로 가져온다
```

## This 가 아닌 obj 사용하기

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381496/notion-blog/_/_/_/02_Hello/Untitled_14.png)

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381496/notion-blog/_/_/_/02_Hello/Untitled_15.png)

```java
ID 를 btnHello 로 바꾸면 id 를 찾지 못하여서 오류가 발생한다

this.Button00.set_text("안녕"); 를 btnHello 로 바꾸면 문제가 해결 되겠지만 코드가 많아지고 이렇게 수정이 필요할 때

id 와 스크립트를 모두 수정해 주는건 어려울것 이다
```

```java
this.Button00_onclick = function(obj:nexacro.Button,e:nexacro.ClickEventInfo)
{
	this.alert("Hello");

	// 로그를 찍는방법
	//.trace 가 로그다
	nexacro.getApplication().trace("안녕");

	// 똑같은 로그 찍는 기능 이지만 다른 방식
	var objApp = nexacro.getApplication();
	objApp.trace("안녕하세요");

	//버튼의 텍스트를 바꾸는 기능
	this.Button00.set_text("안녕");// set_속성명 을 꼭 적어줘야한다

	//버튼의 텍스트를 get 하는방법 .text 하면 된다
	this.alert(this.Button00.text);
};
```

```java
넥사크로는 function 에 항상 파라미터 obj 와 e 이벤트가 따라다닌다

여기서 obj 는 this.Button00 을 뜻한다

그러면

this.Button00.set_text("안녕"); 이 아니라

obj.set_text("안녕"); 를 사욯하면 id 가 바뀌더라도 별도의 Script 수정 없이 바로 사용할 수 있다

(obj 가 이 function 의 클릭 버튼을 뜻하기 때문에)
```

```java

var -> var 을 사용하면 Hello.xfdl 스크립트 내부에서만 사용 가능하다 Form 과 Form 간에 값을 참조할 수 없다 또한 디자인 탭에서 컴포넌트가 var 값을 참조해서 사용 불가능하다

this -> 가장 추천하는 방식으로 스크립트 Form 과 Form ,컴포넌트가 값을 모두 참조 가능하다
```
