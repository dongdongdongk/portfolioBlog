## 지오메트리 브러시란?

복잡한 도형을 쉽게 만들 수 있는 레벨 디자인 도구입니다.

## 기본 사용법

### 1. 브러시 배치하기

- **위치**: 모드 패널 > 지오메트리 메뉴
- **사용법**: 박스를 클릭하고 드래그해서 레벨에 배치

### 2. 크기 조절

- Transform의 Scale 대신 **브러시 설정** 사용
- X, Y, Z 값으로 크기 조절
  - 예: X=1000, Y=60, Z=400

## 핵심 기능: 덧셈과 뺄셈

### 덧셈 브러시 (기본)

- 일반적인 도형 추가

### 뺄셈 브러시 ⭐

- 다른 브러시에서 부분을 잘라냄
- **사용 예시**:
  - 벽에 창문 만들기
  - 문 구멍 뚫기
  - 복잡한 형태 제작

## 1. C++ 클래스 생성하기

### 🔧 클래스 생성 단계

**1단계: 새 클래스 메뉴 열기**

- **선택 이유**: 움직이는 플랫폼을 게임 월드에 배치하기 위함
- Actor를 선택하면 언리얼의 모든 내장 기능을 상속받아 기본적으로 Actor처럼 작동

  - 각 단어의 첫 글자를 대문자로 작성 (PascalCase)
  - 예: MovingPlatform, PlayerCharacter, EnemySpawner
  - 필수는 아니지만 언리얼 엔진의 표준 규칙

## 2. 헤더 파일(.h)과 소스 파일(.cpp)의 역할

### 📄 헤더 파일 (MovingPlatform.h)

**역할: "메뉴판" 역할**

```cpp
// ============================================================================
// MovingPlatform.h (헤더 파일)
// 역할: 클래스의 "설계도" - 어떤 변수와 함수가 있는지 선언
// ============================================================================

// #pragma once: 이 헤더 파일이 여러 번 포함되는 것을 방지
// (같은 파일을 두 번 이상 include하면 오류 발생하므로 보호)
#pragma once

// 언리얼 엔진의 핵심 기능들을 사용하기 위한 기본 헤더 파일
// 예: FVector, FString 등의 기본 타입 사용 가능
#include "CoreMinimal.h"

// AActor 클래스를 사용하기 위해 필요한 헤더 파일
// AActor는 게임 월드에 배치할 수 있는 모든 객체의 기본 클래스
#include "GameFramework/Actor.h"

// 언리얼 빌드 시스템이 자동으로 생성하는 파일
// UCLASS 같은 언리얼 매크로가 제대로 작동하도록 도와줌
// 주의: 반드시 마지막에 include해야 함!
#include "MovingPlatform.generated.h"

// ============================================================================
// UCLASS(): 언리얼 엔진에게 "이 클래스를 인식하고 관리해줘"라고 알림
// 이 매크로 덕분에:
// - 에디터에서 클래스를 볼 수 있음
// - 블루프린트에서 사용 가능
// - 리플렉션 시스템 사용 가능 (런타임에 클래스 정보 확인)
// ============================================================================
UCLASS()

// OBSTACLEASSAULT_API: DLL 내보내기/가져오기 선언 (고급 주제, 지금은 무시 가능)
// AMovingPlatform: 우리가 만드는 클래스 이름
//   - 'A' 접두사: Actor 클래스를 의미하는 언리얼 명명 규칙
//   - 'MovingPlatform': 실제 클래스 이름
// : public AActor: AActor를 부모로 상속받음
//   - AActor의 모든 기능(변수, 함수)을 자동으로 물려받음
//   - 예: GetActorLocation(), SetActorLocation() 등 사용 가능
class OBSTACLEASSAULT_API AMovingPlatform : public AActor
{
	// GENERATED_BODY(): 언리얼이 자동으로 생성하는 코드를 삽입하는 위치
	// 반드시 클래스 본문 첫 줄에 있어야 함!
	GENERATED_BODY()

// ============================================================================
// public: 접근 지정자 - 외부에서 접근 가능한 멤버들
// 이 섹션의 함수/변수는 다른 클래스나 블루프린트에서 호출/사용 가능
// ============================================================================
public:
	// 생성자 (Constructor) 선언
	// - 클래스 이름과 동일한 특수 함수
	// - 객체가 생성될 때 자동으로 딱 한 번 호출됨
	// - 역할: 멤버 변수 초기화, 기본 설정
	// - 반환 타입 없음 (void도 쓰지 않음)
	AMovingPlatform();

// ============================================================================
// protected: 접근 지정자 - 제한적 접근
// 이 섹션의 멤버는:
// - 이 클래스 내부에서 접근 가능
// - 이 클래스를 상속받은 자식 클래스에서도 접근 가능
// - 외부에서는 직접 접근 불가 (보호됨)
// ============================================================================
protected:
	// BeginPlay 함수 선언
	// virtual: 이 함수는 부모 클래스에서 정의되었고, 우리가 재정의할 수 있음
	// void: 반환값이 없음 (아무것도 돌려주지 않음)
	// BeginPlay: 함수 이름
	//   - Actor가 게임에 스폰되거나 게임이 시작될 때 자동으로 호출됨
	//   - 초기화 작업을 여기서 수행 (시작 위치 저장, 초기 설정 등)
	// override: "부모 클래스의 함수를 재정의(덮어쓰기)합니다"라는 명시적 선언
	//   - 컴파일러가 실수를 잡아줌 (오타가 있으면 오류 발생)
	//   - 코드 가독성 향상
	virtual void BeginPlay() override;

// ============================================================================
// public: 다시 public 섹션 (접근 지정자는 여러 번 사용 가능)
// ============================================================================
public:
	// Tick 함수 선언
	// virtual: 재정의 가능한 함수
	// void: 반환값 없음
	// Tick: 함수 이름
	//   - 매 프레임마다 자동으로 호출됨 (초당 60회라면 1초에 60번 실행)
	//   - 움직임, 회전 등 지속적인 업데이트 작업을 여기서 수행
	// float DeltaTime: 매개변수
	//   - 이전 프레임과 현재 프레임 사이의 시간 간격 (초 단위)
	//   - 예: 60fps라면 약 0.0166초
	//   - 프레임율에 독립적인 움직임을 만들 때 사용
	// override: 부모의 Tick 함수를 재정의함을 명시
	virtual void Tick(float DeltaTime) override;

}; // 클래스 선언 끝 - 세미콜론 필수! (없으면 컴파일 오류)
```

**헤더 파일의 특징:**

- 클래스가 **무엇을 가지고 있는지** 선언
- \*데이터(변수)**와 **기능(함수)\*\*의 목록 표시
- 실제 구현은 하지 않음 (선언만)
- 다른 파일에서 이 클래스를 사용할 때 참고하는 "설명서"

### 💻 소스 파일 (MovingPlatform.cpp)

**역할: "주방" 역할**

```cpp
// ============================================================================
// MovingPlatform.cpp (소스 파일)
// 역할: 헤더 파일에서 선언한 함수들의 "실제 구현"
// 헤더가 "메뉴판"이라면, 소스 파일은 "주방" (실제 요리하는 곳)
// ============================================================================

// 우리가 만든 헤더 파일을 포함
// 이를 통해 AMovingPlatform 클래스 정의를 사용할 수 있음
#include "MovingPlatform.h"

// ============================================================================
// 생성자 구현
// AMovingPlatform::AMovingPlatform()
//   - AMovingPlatform:: : "AMovingPlatform 클래스의" (범위 지정 연산자)
//   - AMovingPlatform() : 생성자 함수 이름 (클래스 이름과 동일)
//
// 호출 시점:
//   - 에디터에서 월드에 배치할 때
//   - 코드로 SpawnActor를 호출할 때
//   - 게임 시작 시 월드에 있는 객체들이 생성될 때
// ============================================================================
AMovingPlatform::AMovingPlatform()
{
	// PrimaryActorTick: 이 Actor의 Tick 관련 설정을 담은 구조체
	// bCanEverTick: "이 Actor가 Tick 함수를 사용할 수 있는가?"를 결정하는 불리언 변수
	//   - true: Tick 함수가 매 프레임 호출됨 (움직임 필요 시)
	//   - false: Tick 함수 호출 안 함 (성능 최적화 - 정적인 객체는 false 설정)
	//
	// 왜 여기서 설정할까?
	//   - 움직이는 플랫폼이므로 매 프레임 위치를 업데이트해야 함
	//   - Tick이 필요 없다면 false로 설정해서 성능 향상 가능
	PrimaryActorTick.bCanEverTick = true;
}

// ============================================================================
// BeginPlay 함수 구현
// void: 반환값 없음
// AMovingPlatform::BeginPlay(): AMovingPlatform 클래스의 BeginPlay 함수
//
// 호출 시점:
//   - 게임이 시작되고 이 Actor가 활성화될 때 딱 한 번만 호출
//   - 에디터에서 Play 버튼을 누르면 월드에 있는 모든 Actor의 BeginPlay 실행
//   - 런타임에 SpawnActor로 생성되면 그 시점에 호출
//
// 용도:
//   - 초기화 작업 (시작 위치 저장, 변수 설정 등)
//   - 다른 Actor 찾기 및 참조 저장
//   - 이벤트 바인딩
//   - 초기 상태 로그 출력
// ============================================================================
void AMovingPlatform::BeginPlay()
{
	// Super::BeginPlay(): 부모 클래스(AActor)의 BeginPlay 함수를 호출
	//
	// Super: 부모 클래스를 가리키는 키워드 (여기서는 AActor)
	// ::BeginPlay(): 부모의 BeginPlay 함수
	//
	// 왜 부모의 BeginPlay를 먼저 호출해야 할까?
	//   1. 상속 체인의 모든 초기화가 순서대로 이루어져야 함
	//      (할아버지 → 아버지 → 자식 순으로 초기화)
	//   2. AActor의 BeginPlay에는 언리얼 엔진이 필요로 하는
	//      중요한 초기화 코드가 있음
	//   3. 부모의 기능을 유지하면서 우리 기능을 추가하는 "확장"
	//
	// 주의: Super::BeginPlay()를 호출하지 않으면
	//       언리얼 엔진의 기본 기능이 제대로 작동하지 않을 수 있음!
	Super::BeginPlay();

	// UE_LOG: 언리얼 엔진의 로그 출력 매크로 (함수처럼 사용)
	//
	// 매개변수 분석:
	//   1. LogTemp: 로그 카테고리
	//      - Temp = Temporary (임시)
	//      - 테스트/디버깅용으로 사용하는 기본 카테고리
	//      - 나중에 LogMovingPlatform 같은 커스텀 카테고리 생성 가능
	//
	//   2. Warning: 로그 레벨 (메시지의 중요도)
	//      - Log: 일반 정보 (흰색/회색)
	//      - Warning: 경고, 주의 필요 (노란색) ← 눈에 잘 띔!
	//      - Error: 오류 (빨간색)
	//      - Fatal: 치명적 오류 (빨간색, 프로그램 중단 가능)
	//
	//   3. TEXT("Moving Platform Activated"): 출력할 메시지
	//      - TEXT(): 문자열을 언리얼 엔진 형식으로 변환하는 매크로
	//      - 반드시 TEXT()로 감싸야 함! (유니코드 지원, 플랫폼 호환성)
	//      - 큰따옴표("") 사용, 작은따옴표('') 사용 불가
	//
	// 결과: Output Log에 노란색으로 표시됨
	//   "LogTemp: Warning: Moving Platform Activated"
	//
	// 용도:
	//   - 코드가 실행되는지 확인 (디버깅)
	//   - 변수 값 확인 (나중에 배움)
	//   - 게임 흐름 추적
	//   - 오류 발생 위치 파악
	UE_LOG(LogTemp, Warning, TEXT("Moving Platform Activated"));

	// 이 함수가 끝나면 자동으로 반환 (void이므로 return 문 필요 없음)
	// 다음 단계: 게임이 계속 진행되고 Tick 함수가 매 프레임마다 호출되기 시작
}

// ============================================================================
// Tick 함수 구현
// void: 반환값 없음
// AMovingPlatform::Tick: AMovingPlatform 클래스의 Tick 함수
// float DeltaTime: 매개변수 - 이전 프레임과의 시간 차이 (초 단위)
//
// 호출 시점:
//   - 매 프레임마다 자동으로 호출됨
//   - 60fps 게임이라면 1초에 약 60번 호출
//   - 생성자에서 PrimaryActorTick.bCanEverTick = true로 설정했기에 호출됨
//
// DeltaTime 예시:
//   - 60fps: 약 0.0166초 (1/60)
//   - 30fps: 약 0.0333초 (1/30)
//   - 프레임율이 변해도 움직임 속도를 일정하게 유지하려면 DeltaTime 사용!
//
// 용도:
//   - 지속적인 움직임 (위치 변경)
//   - 회전 업데이트
//   - 애니메이션
//   - 물리 계산
//   - 매 프레임 상태 체크
// ============================================================================
void AMovingPlatform::Tick(float DeltaTime)
{
	// Super::Tick(DeltaTime): 부모 클래스(AActor)의 Tick 함수를 호출
	//
	// Super: 부모 클래스 (AActor)
	// ::Tick(DeltaTime): 부모의 Tick 함수에 DeltaTime 전달
	//
	// 왜 호출해야 할까?
	//   - 부모 클래스의 Tick 로직도 실행되어야 함
	//   - Actor의 기본 업데이트 처리
	//   - 상속 체인의 모든 Tick이 순서대로 실행
	//
	// 주의: BeginPlay처럼 Super::Tick도 거의 항상 호출해야 함!
	Super::Tick(DeltaTime);

	// 현재는 비어있지만, 나중에 여기에 코드 추가:
	//
	// 예시 1: 플랫폼을 앞으로 이동
	//   FVector NewLocation = GetActorLocation();
	//   NewLocation.X += Speed * DeltaTime;  // DeltaTime으로 일정한 속도 유지
	//   SetActorLocation(NewLocation);
	//
	// 예시 2: 플랫폼을 회전
	//   FRotator NewRotation = GetActorRotation();
	//   NewRotation.Yaw += RotationSpeed * DeltaTime;
	//   SetActorRotation(NewRotation);
	//
	// 예시 3: 왕복 운동
	//   if (DistanceMoved > MaxDistance)
	//   {
	//       Direction *= -1;  // 방향 반전
	//   }
	//   MoveDistance = Speed * DeltaTime;
	//   DistanceMoved += MoveDistance;

	// 함수 종료 (다음 프레임에 다시 호출됨)
}

// ============================================================================
// 전체 실행 흐름 요약:
//
// 1. 에디터에서 Play 버튼 클릭
//    ↓
// 2. 게임 월드 로드
//    ↓
// 3. 월드에 배치된 MovingPlatform Actor 발견
//    ↓
// 4. AMovingPlatform() 생성자 호출
//    - PrimaryActorTick.bCanEverTick = true 설정
//    ↓
// 5. BeginPlay() 호출 (딱 한 번)
//    - Super::BeginPlay() 실행 (부모 초기화)
//    - UE_LOG로 "Moving Platform Activated" 출력
//    ↓
// 6. 게임 루프 시작 - 매 프레임마다:
//    - Tick(DeltaTime) 호출
//    - Super::Tick(DeltaTime) 실행
//    - (현재는 비어있지만 나중에 움직임 코드 추가)
//    ↓
// 7. 게임 종료 시까지 Tick 반복
//    ↓
// 8. Actor 소멸 (게임 종료 또는 Destroy 호출)
// ============================================================================
```

**소스 파일의 특징:**

## 3. Actor 클래스와 컴포넌트 개념

### 🎭 Actor란?

- 언리얼 엔진에서 게임 월드에 배치할 수 있는 **기본 객체**
- 예시: 캐릭터, 바닥, 벽, 조명, 카메라, 움직이는 플랫폼 등
- **Transform** 정보 포함 가능:
  - Location(위치): X, Y, Z 좌표
  - Rotation(회전): 각도
  - Scale(크기): 확대/축소

### 🧩 Component(컴포넌트)란?

- Actor에 **기능을 추가하는 부품**
- 레고 블록처럼 여러 컴포넌트를 조합하여 복잡한 Actor 제작

**주요 컴포넌트 예시:**

- **Static Mesh Component**: 3D 모델 표시
- **Brush Component**: 기본 도형 표시
- **Transform Component**: 위치, 회전, 크기 정보

**현재 MovingPlatform 상태:**

- 빈 Actor (컴포넌트 없음)
- Transform 표시 안 됨
- 기즈모는 (0,0,0) 좌표만 표시
- 나중에 컴포넌트 추가 예정

```cpp
{
```

- 외부에서 호출 가능

## 5. BeginPlay 함수 이해하기

### 🎬 BeginPlay란?

- Actor가 **게임에 스폰될 때** 호출되는 **특수한 함수**
- "게임 시작 시 딱 한 번" 실행
- 초기화 작업 수행

### ⏰ 호출 시점

**경우 1: 게임 시작 시**

```
Play 버튼 클릭 → 게임 로드 → BeginPlay() 자동 호출 → 게임 진행
```

**경우 2: 런타임 스폰 시**

```
게임 진행 중 → SpawnActor로 생성 → BeginPlay() 자동 호출
```

### 📝 BeginPlay 구조

```cpp
void AMovingPlatform::BeginPlay()
{
	Super::BeginPlay();  // 1. 부모 클래스 초기화 먼저

	// 2. 우리가 추가한 코드
	UE_LOG(LogTemp, Warning, TEXT("Moving Platform Activated"));
}
```

**함수 시그니처:**

- `void`: 반환값 없음
- `AMovingPlatform::`: AMovingPlatform 클래스의 멤버 함수
- `BeginPlay()`: 함수 이름

### 🔄 Super::BeginPlay()

```cpp
Super::BeginPlay();
```

- `Super`: 부모 클래스(AActor)를 가리킴
- **반드시 먼저 호출**: 부모의 초기화가 먼저 완료되어야 함
- 언리얼 엔진의 기본 초기화 수행

**호출 순서:**

```
1. Super::BeginPlay()
   → AActor의 초기화 실행
2. 우리 코드 실행
   → UE_LOG 등 추가 작업

```

### 🎯 BeginPlay의 용도

```cpp
// 초기 설정
void AMovingPlatform::BeginPlay()
{
	Super::BeginPlay();

	StartLocation = GetActorLocation();  // 시작 위치 저장
	Speed = 100.0f;                      // 속도 초기화
}

```

## FString 앞에 별표(\*)가 필요한 이유

### 문제 상황

```cpp
FString MyName = "John";  // 언리얼 전용 문자열 타입
UE_LOG(LogTemp, Warning, TEXT("이름: %s"), MyName);  // ❌ 오류!
```

### 왜 별표가 필요한가?

### 1. **타입 변환**

- `FString`은 **언리얼 엔진 전용** 문자열 클래스 (복잡한 객체)
- `UE_LOG`의 `%s`는 **C++ 기본 문자열** (const char\*) 형식을 원함
- 별표()는 FString을 C++ 기본 형식으로 변환하는 **변환 연산자**

```cpp
FString MyName = "John";
// MyName은 복잡한 FString 객체

*MyName
// → "John"이라는 기본 C++ 문자열(const char*)로 변환
```

### 2. **데이터 접근 방식**

```cpp
// FString은 문자열을 "포장"하고 있음
FString MyName = "John";
┌─────────────────┐
│   FString 객체   │
│  ┌───────────┐  │
│  │  "John"   │  │  ← 실제 문자열 데이터
│  └───────────┘  │
└─────────────────┘

// 별표(*)로 내부 데이터 꺼내기
*MyName → "John"
```

### 3. **비유로 이해하기**

```
FString = 선물 상자 (포장된 문자열)
별표(*) = 상자를 열어서 내용물 꺼내기
UE_LOG = 포장 없는 내용물만 받음
```

### 다른 타입은 왜 별표가 필요 없나?

```cpp
int32 Number = 10;      // 기본 타입 - 그대로 전달 OK
float Value = 3.14f;    // 기본 타입 - 그대로 전달 OK
FString Name = "John";  // 언리얼 객체 - 변환 필요! (*)
```

- `int`, `float` 등은 **C++ 기본 타입**이라서 변환 불필요
- `FString`은 **언리얼 전용 클래스**라서 변환 필요

### 기술적 설명

```cpp
// FString 클래스 내부에는 이런 변환 연산자가 있음
class FString
{
    // 별표(*) 연산자 오버로딩
    const TCHAR* operator*() const
    {
        return GetCharArray().GetData();  // 내부 문자열 포인터 반환
    }
};

// 그래서 이렇게 사용하면
*MyName
// → operator*()가 호출됨
// → const TCHAR* (C++ 기본 문자열 포인터) 반환
```

```cpp
int32 NumApples = 10;

UE_LOG(LogTemp, Warning, TEXT("사과: %d, 오렌지: %d"),
```

# { C++ 연산자 우선순위 }

## 연산자 우선순위란?

여러 연산이 포함된 식에서 **어떤 연산을 먼저 수행할지** 결정하는 규칙

## 기본 우선순위 규칙

### 1순위: 곱셈(\*), 나눗셈(/)

### 2순위: 덧셈(+), 뺄셈(-)

```cpp
int Result = 10 + 20 / 4 - 3.5;
//              ↓ 1. 나눗셈 먼저 (20/4 = 5)
//           10 + 5 - 3.5
//           ↓ 2. 왼쪽부터 덧셈 (10+5 = 15)
//           15 - 3.5
//           ↓ 3. 뺄셈 (15-3.5 = 11.5)
//           = 11.5
```

## 같은 우선순위 규칙

같은 우선순위 연산자는 **왼쪽에서 오른쪽**으로 계산

### 예시 1: 곱셈과 나눗셈

```cpp
int Result = 20 / 4 * 10;
//           ↓ 1. 왼쪽 먼저 (20/4 = 5)
//           5 * 10
//           ↓ 2. 곱셈 (5*10 = 50)
//           = 50
```

### 예시 2: 덧셈과 뺄셈

```cpp
int Result = 8 + 2.5 - 1;
//           ↓ 1. 왼쪽 먼저 (8+2.5 = 10.5)
//           10.5 - 1
//           ↓ 2. 뺄셈 (10.5-1 = 9.5)
//           = 9.5
```

## 우선순위 표

| 순위  | 연산자  | 설명         | 방향       |
| ----- | ------- | ------------ | ---------- |
| **1** | `()`    | 괄호         | -          |
| **2** | `*` `/` | 곱셈, 나눗셈 | ← 왼쪽부터 |
| **3** | `+` `-` | 덧셈, 뺄셈   | ← 왼쪽부터 |

## 괄호로 우선순위 제어

### 최우선 연산자: 괄호 ()

**괄호 안의 계산을 무조건 먼저 수행**

```cpp
// 괄호 없음
int Result = 8 + 2.5 - 1 * 10;
//                      ↓ 곱셈 먼저
//           8 + 2.5 - 10
//           = 0.5

// 괄호 사용
int Result = 8 + (2.5 - 1) * 10;
//               ↓ 1. 괄호 먼저! (2.5-1 = 1.5)
//           8 + 1.5 * 10
//               ↓ 2. 곱셈 (1.5*10 = 15)
//           8 + 15
//               ↓ 3. 덧셈 (8+15 = 23)
//           = 23
```

## 실전 예제

### 예제 1: 복잡한 계산

```cpp
int Result = 20 / 4 + 10 - 3.5;

// 계산 순서:
// 1. 20 / 4 = 5 (나눗셈 우선)
// 2. 5 + 10 = 15 (왼쪽부터)
// 3. 15 - 3.5 = 11.5 (다음 연산)
// 결과: 11.5
```

### 예제 2: 곱셈과 나눗셈 혼합

```cpp
int Result = 20 / 4 * 10;

// 계산 순서:
// 1. 20 / 4 = 5 (왼쪽부터)
// 2. 5 * 10 = 50 (다음)
// 결과: 50
```

### 예제 3: 괄호 활용

```cpp
// 원하는 계산: 먼저 빼고, 그 다음 곱하기
int Result = (2.5 - 1) * 10;

// 계산 순서:
// 1. (2.5 - 1) = 1.5 (괄호 먼저!)
```

## 언리얼 엔진 실전 예제

```cpp
void AMyActor::BeginPlay()
{
    // 체력 계산: 기본 체력 + (레벨 * 10) - 받은 데미지
    int BaseHealth = 100;
    int Level = 5;
    int Damage = 20;

    // 잘못된 계산 (괄호 없음)
    int Health1 = BaseHealth + Level * 10 - Damage;
    // → 100 + 50 - 20 = 130

    // 올바른 계산 (괄호 사용)
    int Health2 = (BaseHealth + Level * 10) - Damage;
    // → (100 + 50) - 20 = 130

    // 의도가 다른 경우
    int Health3 = BaseHealth + (Level * (10 - Damage));
    // → 100 + (5 * -10) = 50

    UE_LOG(LogTemp, Warning, TEXT("체력1: %d"), Health1);
    UE_LOG(LogTemp, Warning, TEXT("체력2: %d"), Health2);
    UE_LOG(LogTemp, Warning, TEXT("체력3: %d"), Health3);
}
```

## 핵심 정리

### ✅ 기억할 것

1. **곱셈/나눗셈** 먼저 → **덧셈/뺄셈** 나중
2. 같은 우선순위는 **왼쪽부터** 오른쪽으로
3. **괄호 ()** 가 최우선!
4. 복잡한 계산은 **괄호로 명확하게**

### 우선순위 순서

```
1. ( )        ← 가장 먼저
2. * /        ← 그 다음
3. + -        ← 마지막
```

### 실전 팁

```cpp
// ❌ 헷갈리는 코드
int Result = 10 + 20 / 4 * 2 - 3;

// ✅ 명확한 코드 (괄호 사용)
int Result = 10 + ((20 / 4) * 2) - 3;
```

## 자주 하는 실수

### 실수 1: 괄호 없이 복잡한 계산

```cpp
// 의도: (10 + 20)을 먼저 계산하고 싶음
int Wrong = 10 + 20 * 2;  // ❌ 결과: 50 (예상과 다름!)
int Right = (10 + 20) * 2;  // ✅ 결과: 60
```

### 실수 2: 왼쪽-오른쪽 순서 무시

```cpp
int Result = 100 / 10 / 2;
// 잘못된 생각: 100 / (10/2) = 20 ❌
// 올바른 계산: (100/10) / 2 = 5 ✅
```

## 디버깅 팁

복잡한 계산은 단계별로 나눠서 확인:

```cpp
// 복잡한 한 줄
int Final = 100 + 50 / 10 * 2 - 5;

// 단계별 확인
int Step1 = 50 / 10;        // 5
int Step2 = Step1 * 2;      // 10
int Step3 = 100 + Step2;    // 110
int Final = Step3 - 5;      // 105

UE_LOG(LogTemp, Warning, TEXT("최종 결과: %d"), Final);
```

**핵심:** 헷갈리면 괄호를 사용하라! 코드의 의도가 명확해집니다.

# { 언리얼 엔진 멤버 변수 (Member Variables) }

## 로컬 변수 vs 멤버 변수

### 로컬 변수 (Local Variable)

```cpp
void AMyActor::BeginPlay()
{
    int LocalInt = 100;      // 로컬 변수
    float LocalFloat = 3.14f;

    // ❌ 이 함수가 끝나면 삭제됨!
}
```

**특징:**

- 함수 **안에서만** 사용 가능
- 함수 **종료 시 삭제**됨
- **다른 함수에서 접근 불가**
- 단기 데이터 저장용

### 멤버 변수 (Member Variable)

```cpp
// MyActor.h - 헤더 파일
class AMyActor : public AActor
{
    UPROPERTY()
    float MemberFloat = 10.0f;  // 멤버 변수
};
```

**특징:**

- \*헤더 파일(.h)\*\*에 선언
- **모든 함수**에서 접근 가능
- 함수 종료해도 **데이터 유지**
- 장기 데이터 저장용
- 클래스가 살아있는 동안 계속 존재

## 비교표

| 구분          | 로컬 변수         | 멤버 변수          |
| ------------- | ----------------- | ------------------ |
| **선언 위치** | 함수 내부 (.cpp)  | 클래스 내부 (.h)   |
| **접근 범위** | 해당 함수만       | 모든 함수          |
| **수명**      | 함수 종료 시 삭제 | 클래스와 함께 유지 |
| **용도**      | 임시 계산         | 게임 데이터 저장   |

## 멤버 변수 선언 방법

### 1. 헤더 파일에 선언

```cpp
// MovingPlatform.h
class AMovingPlatform : public AActor
{
    GENERATED_BODY()

public:
    // 멤버 변수 선언
    float MemberFloat = 10.0f;  // 기본값 10
    int32 MemberInt = 5;
};
```

### 2. CPP 파일에서 사용

```cpp
// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    // 멤버 변수 접근 가능!
    MemberFloat = 20.0f;

    UE_LOG(LogTemp, Warning, TEXT("멤버 플로트: %f"), MemberFloat);
}

void AMovingPlatform::Tick(float DeltaTime)
{
    // 다른 함수에서도 접근 가능!
    MemberFloat += DeltaTime;
}
```

## UPROPERTY 매크로

### 역할

멤버 변수를 **언리얼 엔진에 등록**하여 에디터에서 보고 편집할 수 있게 함

### 기본 문법

```cpp
UPROPERTY(옵션)
데이터타입 변수이름 = 기본값;
```

### 주요 옵션

### 1. EditAnywhere - 어디서나 편집 가능

```cpp
UPROPERTY(EditAnywhere)
float Speed = 100.0f;
```

- 에디터에서 **값 변경 가능**
- 가장 많이 사용

### 2. VisibleAnywhere - 어디서나 보기만 가능

```cpp
UPROPERTY(VisibleAnywhere)
int32 Score = 0;
```

- 에디터에서 **값 확인만** 가능
- **편집 불가** (읽기 전용)

## 실전 예제

### 전체 코드 예시

```cpp
// MovingPlatform.h
UCLASS()
class AMovingPlatform : public AActor
{
    GENERATED_BODY()

public:
    // 편집 가능한 속도
    UPROPERTY(EditAnywhere)
    float MoveSpeed = 100.0f;

    // 편집 가능한 이동 거리
    UPROPERTY(EditAnywhere)
    float MoveDistance = 500.0f;

    // 보기만 가능한 현재 위치
    UPROPERTY(VisibleAnywhere)
    float CurrentDistance = 0.0f;

protected:
    virtual void BeginPlay() override;
    virtual void Tick(float DeltaTime) override;
};
```

```cpp
// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    Super::BeginPlay();

    // 멤버 변수 사용
    UE_LOG(LogTemp, Warning, TEXT("속도: %f"), MoveSpeed);
    UE_LOG(LogTemp, Warning, TEXT("거리: %f"), MoveDistance);
}

void AMovingPlatform::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    // 모든 함수에서 멤버 변수 접근 가능
    CurrentDistance += MoveSpeed * DeltaTime;

    if (CurrentDistance >= MoveDistance)
    {
        UE_LOG(LogTemp, Warning, TEXT("목표 도달!"));
    }
}
```

### 2. 디테일 패널 확인

```
┌─────────────────────────┐
│ Moving Platform         │
├─────────────────────────┤
│ Move Speed      [100.0] │ ← EditAnywhere (편집 가능)
│ Move Distance   [500.0] │ ← EditAnywhere (편집 가능)
│ Current Distance  0.0   │ ← VisibleAnywhere (보기만)
└─────────────────────────┘
```

- `EditAnywhere` 변수는 클릭해서 값 수정 가능

```cpp
class AGameCharacter : public ACharacter

    float CurrentHealth = 100.0f;

};
```

```cpp
// Character.cpp
void AGameCharacter::BeginPlay()
{

    UE_LOG(LogTemp, Warning, TEXT("현재 체력: %f"), CurrentHealth);
}

void AGameCharacter::TakeDamage(float Damage)

    if (CurrentHealth <= 0)

}
```

# { C++ 구조체 (Struct) }

## 구조체란?

**여러 변수를 하나의 이름으로 묶어 패키징한 것**

### 비유

```
구조체 = 여러 물건을 담는 상자
- 상자 이름: FVector
- 내용물: X, Y, Z (세 개의 float)
```

## 구조체 선언 방법

### 기본 문법

```cpp
struct 구조체이름
{
    변수1;
    변수2;
    변수3;
};  // ← 세미콜론 필수!
```

### 예시: FVector 구조체

```cpp
struct FVector
{
    float X;
    float Y;
    float Z;
};
```

## 구조체 = 레시피

```cpp
// 1. 구조체 정의 (레시피 작성)
struct FVector
{
    float X;
    float Y;
    float Z;
};

// 2. 구조체로 변수 생성 (레시피로 요리)
FVector MyVector;
```

## 구조체 사용 방법

### 1. 변수 생성

```cpp
FVector TestVector;  // FVector 타입 변수 생성
```

### 2. 생성자로 값 할당

```cpp
FVector TestVector = FVector(11.2f, 3.4f, 7.6f);
//                          ↑      ↑      ↑
//                          X      Y      Z
```

**생성자(Constructor):** 값을 받아서 구조체를 만들어주는 특수 함수

### 3. 점 연산자(.)로 접근

```cpp
FVector TestVector = FVector(11.2f, 3.4f, 7.6f);

// 값 읽기
float XValue = TestVector.X;  // 11.2
float YValue = TestVector.Y;  // 3.4
float ZValue = TestVector.Z;  // 7.6

// 값 변경
TestVector.X = 100.0f;
TestVector.Y = 50.0f;
TestVector.Z = 2.5f;
```

## 점 연산자 (Dot Operator)

```cpp
변수이름.속성이름
```

### 예시

```cpp
FVector MyVector = FVector(1.0f, 2.0f, 3.0f);

MyVector.X  // X 값에 접근
MyVector.Y  // Y 값에 접근
MyVector.Z  // Z 값에 접근
```

## 실전 예제: 플랫폼 이동

```cpp
// MovingPlatform.h
UCLASS()
class AMovingPlatform : public AActor
{
    GENERATED_BODY()

public:
    UPROPERTY(EditAnywhere, Category = "Movement")
    FVector StartLocation = FVector(0.0f, 0.0f, 0.0f);

    UPROPERTY(EditAnywhere, Category = "Movement")
    FVector EndLocation = FVector(500.0f, 0.0f, 0.0f);

    UPROPERTY(VisibleAnywhere, Category = "Movement")
    FVector CurrentLocation;

protected:
    virtual void BeginPlay() override;
    virtual void Tick(float DeltaTime) override;
};
```

```cpp
// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    Super::BeginPlay();

    // 시작 위치 설정
    CurrentLocation = GetActorLocation();

    UE_LOG(LogTemp, Warning, TEXT("시작 위치: X=%f, Y=%f, Z=%f"),
           CurrentLocation.X, CurrentLocation.Y, CurrentLocation.Z);
}

void AMovingPlatform::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    // 현재 위치 가져오기
    CurrentLocation = GetActorLocation();

    // X 위치를 EndLocation까지 이동
    if (CurrentLocation.X < EndLocation.X)
    {
        CurrentLocation.X += 100.0f * DeltaTime;
        SetActorLocation(CurrentLocation);
    }
}
```

## 언리얼의 주요 구조체

| 구조체         | 용도         | 멤버 변수                 |
| -------------- | ------------ | ------------------------- |
| **FVector**    | 3D 위치/방향 | X, Y, Z (float)           |
| **FRotator**   | 회전         | Pitch, Yaw, Roll (float)  |
| **FVector2D**  | 2D 위치      | X, Y (float)              |
| **FColor**     | 색상         | R, G, B, A (uint8)        |
| **FTransform** | 변환         | Location, Rotation, Scale |

## 비교: 로컬 변수 vs 멤버 변수

```cpp
// MovingPlatform.h
class AMovingPlatform : public AActor
{
    // 멤버 변수 - 모든 함수에서 접근 가능
    UPROPERTY(EditAnywhere)
    FVector MyVector = FVector(1.0f, 2.0f, 3.0f);
};

// MovingPlatform.cpp
void AMovingPlatform::BeginPlay()
{
    // 로컬 변수 - 이 함수 안에서만 사용
    FVector TestVector = FVector(5.0f, 6.0f, 7.0f);

    // 멤버 변수는 다른 함수에서도 접근 가능
    MyVector.X = 100.0f;
}

void AMovingPlatform::Tick(float DeltaTime)
{
    // MyVector는 접근 가능 ✅
    MyVector.Y += DeltaTime;

    // TestVector는 접근 불가 ❌ (BeginPlay의 로컬 변수)
    // TestVector.Y += DeltaTime;  // 컴파일 에러!
}
```

## 중요 포인트

### ✅ 기억할 것

1. 구조체는 **여러 변수를 하나로 묶은 것**
2. \*점 연산자(.)\*\*로 내부 변수 접근
3. **생성자**로 값 초기화: `FVector(X, Y, Z)`
4. **FVector**는 언리얼에서 가장 많이 사용하는 구조체
5. Transform의 **Location, Rotation, Scale**이 모두 구조체

### 구조체 사용 패턴

```cpp
// 1. 생성
FVector MyVector;

// 2. 초기화
MyVector = FVector(1.0f, 2.0f, 3.0f);

// 3. 접근
float X = MyVector.X;

// 4. 수정
MyVector.X = 100.0f;
```
