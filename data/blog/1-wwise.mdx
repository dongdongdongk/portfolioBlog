# 🎮 1인칭 호러 게임 기획서

## 📋 프로젝트 개요

- **장르**: 1인칭 심리 호러
- **플레이 타임**: 12-15분
- **목표**: 유니티 개발 + WWISE 사운드 디자인 역량 시연
- **컨셉**: 야근 중 회사의 어두운 비밀 발견

---

## 🔄 핵심 게임플레이

### **게임 구조**

`사이클 0 (튜토리얼) → 사이클 1 → 사이클 2 → 화장실 → 사이클 3 → 사이클 4 → 엔딩`

### **한 사이클 흐름**

1. 책상에서 F키 → 업무 시작 (2.5~3분)
2. 업무 완료 → 복도 커피머신으로 이동 필수
3. 커피 마시기 → 책상 복귀
4. 다음 사이클 (이상현상 레벨 증가)

### **중요 규칙**

- 업무 완료 후 **반드시 커피 마셔야 함**
- 커피 안 마시고 바로 책상 인터랙션 → 즉시 해고 엔딩
- **사이클 2 완료 후 화장실 필수** (1회만)
- 화장실 안 가고 사이클 3 시작 → 2분 후 오줌싸게 엔딩
- 업무 게이지만 UI 표시, 나머지는 플레이어 판단

## 🚪 던전 파트

**구조:** 입구 → 계단 → 복도 → 제단실

**입장:** 열쇠 사용 → 뒤에서 문 쾅! 닫힘 (탈출 불가)

**제단실:** 돌 제단, 의식용 칼/책, 크툴루 조각, 마법진, 회사 문서

**인터랙션:**

- 제단 조사 (E키) → 진실 엔딩
- 의식용 칼 사용 (E키) → 희생 엔딩

---

## 🎬 엔딩 목록

### **기본 엔딩**

1. **평범한 엔딩**: 던전 무시, 업무 완료
2. **진실 엔딩**: 던전 입장, 제단 조사
3. **해고 엔딩**: 커피 안 마시고 업무 재시도
4. **감전 엔딩**: 복도 변압기 만지기
5. **오줌싸게 엔딩**: 화장실 안 가고 사이클 3 진행

### **히든 엔딩**

1. **번아웃 엔딩**: 커피 6잔 이상 마심
2. **희생 엔딩**: 던전에서 의식용 칼 사용
3. **탈출 엔딩**: 던전에서 비상구 발견
4. **동화 엔딩**: 귀신 10번 목격, 도망 안 치고 평범하게 끝냄

## 🔊 WWISE 사운드 시스템

### **Game Parameters (RTPC)**

- `AnomalyLevel` (0~4): 사이클별 이상현상 강도
- `DistanceToDungeonDoor` (0~10m): 던전 문 근접도

### **사운드 레이어**

```
레벨드론1드론2찬트노이즈0----110%---220%15%희미간헐340%30%20%지속4100%100%60%최대
```

### **공간별 음향**

- **사무실**: Small Room Reverb, 형광등/컴퓨터 팬
- **복도**: Large Hallway Reverb, 발소리 강한 잔향
- **화장실**: Bathroom Reverb, 환풍기/물방울
- **던전**: Cave Reverb, 물방울/찬트/드론

### **인터랙티브 사운드**

- 타이핑: 랜덤 리듬, 엔터/마우스 클릭
- 커피머신: 버튼 → 작동 → 액체 쏟아짐 (3단계)
- 플래시라이트: 배터리 레벨 따라 변화
- 귀신: 거리 기반 속삭임/숨소리, 뒤돌아보면 멈춤

## 💻 유니티 구현 기술

**Phase 1:** 1인칭 이동/상호작용, 플래시라이트, 사이클 관리, 기본 엔딩 5개

**Phase 2:** WWISE 통합, 적응형 사운드, 3D 공간 음향

**Phase 3:** 이상현상 이벤트, 던전 파트, 히든 엔딩 4개

## 🎞️ 사이클 0 (3분)

### 📂 업무 (사무실)

1. **전화 벨소리**
   - 전화를 받으면 **아무 대답 없음**, **잡음만 들림**
2. **뒤에서 의자 삐걱거리는 소리**
   - 누군가 움직이는 듯한 느낌
3. **창밖에서 둔탁한 소리**
   - 무언가 **부딪히는 소리**,
   - 플레이어가 고개를 돌리면 **누군가 창밖에서 보고 있음**
4. 복도로 통하는 문이 열림

- 커피를 뽑는 동안 **희미한 웃음소리**가 들림
- 커피를 뽑고 **고개를 돌리면 귀신 등장**

### 🔙 복귀 (사무실)

- 의자가 혼자서 움직임

## 🎞️ 사이클 1

### 📂 업무 (사무실)

1. 복도에서 누가 소리 지름 비명
2. 책상 밑에 **무언가 있음** → 빠르게 기어서 **책상 뒤로 도망**
3. 모니터에 **업무 사진 속에 불길한 사진이 섞여 있음 (1~2장)**
4. **뒤에서 숨소리** 들림 → 돌아보면 **아무도 없음**

---

### ☕ 커피 (복도)

- 커피를 따르는 동안 **천천히 다가오는 발소리**
- 벽면에 **피자국**

---

### 🚻 화장실

- **물 내리는 소리**
- **여자 화장실**: 흐느끼는 목소리
- **남자 화장실**: 문을 열자마자 **여자 귀신이 비명 지르며 사라짐**
- 볼일 보는 동안 **옆 칸 문이 천천히 열림**

---

### 🔙 복귀 (사무실)

- 복도에서 **뒤쪽에서 빠른 발소리 (뛰는 소리)**
- 돌아보면 **아무도 없음**
- 사무실 어딘가에서 키보드 소리가 들림

void Update()
{
    if (hasTriggered && playOnce)
        return;

    if (IsTargetInView())
    {
        TriggerJumpScare();
    }
}

private bool IsTargetInView()
{
    if (targetObject == null || detectionCamera == null)
        return false;

    Ray ray = new Ray(detectionCamera.position, detectionCamera.forward);
    RaycastHit hit;

    if (Physics.Raycast(ray, out hit, detectionDistance))
    {
        if (hit.collider.gameObject == targetObject ||
            hit.collider.transform.IsChildOf(targetObject.transform))
        {
            return true;
        }
    }

    return false;
}

private IEnumerator JumpScareSequence()
{
    // 1. 점프스케어 오브젝트 활성화
    if (jumpScareObject != null)
        jumpScareObject.SetActive(true);

    // 2. Wwise 사운드 재생
    StopJumpScareSound.Post(gameObject);

    // 3. 카메라 쉐이크
    StartCoroutine(PlayerCameraShake());

    // 4. 지속 시간
    yield return new WaitForSeconds(jumpScareDuration);

    // 5. 정리
    if (jumpScareObject != null)
        jumpScareObject.SetActive(false);

    if (targetObject != null)
        targetObject.SetActive(false);
}
