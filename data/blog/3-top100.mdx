```python
import requests
from bs4 import BeautifulSoup

url = "https://www.melon.com/chart/index.htm"

headers = {
    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

req = requests.get(url, headers=headers)

html = req.text

soup = BeautifulSoup(html, "html.parser")

lst50 = soup.select(".lst50")
lst100 = soup.select(".lst100")

lst = lst50 + lst100

for rank, i in enumerate(lst, 1):
    title = i.select_one(".ellipsis.rank01 a")
    print(f"{rank} : {title.text}")
```

```python
enumerate 를 사용해서 랭크와 함께 리스트를 출력한다

rank는 인덱스를 표현하고 enumerate 의 두번째 인자는 시작 인덱스를 설정한다 ( 기본은 0 )
```

## enumerate

```python
enumerate 함수는 파이썬에서 반복 가능한(iterable) 객체(리스트, 튜플, 문자열 등)를 받아 해당 객체의 각 요소와 인덱스를 함께 반환하는 함수.

enumerate 함수는 주로 반복문에서 요소의 인덱스를 함께 활용해야 할 때 사용
```

```python
enumerate(반복가능한객체, 시작인덱스)
```

```python
fruits = ['사과', '바나나', '딸기', '포도']

for index, fruit in enumerate(fruits, 1):
    print(f'인덱스 {index}: {fruit}')
```

```python
import requests
from bs4 import BeautifulSoup

url = "https://www.melon.com/chart/index.htm"

    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}
```

```python
song_num_text = "javascript:melon.link.goAlbumDetail('11474894');"

# 빈 리스트 song_num을 생성합니다.
def get_song_nums(song_num_text):
    song_num = []

    # song_num_text의 각 문자에 대해 반복합니다.
    for num in song_num_text:
        # 만약 문자가 숫자인지 확인합니다.

            song_num.append(num)

    print(song_num)
```

## **`isdigit()`** 함수

```python
문자열이 모두 숫자인지 여부를 판단하는 파이썬의 문자열 메서드

이 함수는 문자열이 모두 숫자인 경우에는 True를 반환하고, 그렇지 않은 경우에는 False를 반환

( 위의 예제는 숫자면 리스트에 추가해서 숫자만 출력하게 해줬다 )

text = "12345"

# 문자열이 모두 숫자로 이루어져 있으므로 True를 반환합니다.
print(text.isdigit())  # 출력: True

text = "abc123"

# 문자열에 숫자 이외의 문자가 포함되어 있으므로 False를 반환합니다.
print(text.isdigit())  # 출력: False
```

## **`join()`** 메서드

```python
join() 메서드는 파이썬에서 문자열을 이어붙일 때 사용되는 메서드이다.

이 메서드는 문자열의 시퀀스를 하나의 문자열로 결합한다.

일반적으로 리스트나 튜플과 같은 반복 가능한(iterable) 객체에 대해 사용된다.
```

```python
구분자.join(반복가능한객체)
```

```python
fruits = ['사과', '바나나', '딸기', '포도']

# 리스트의 각 요소를 ", "로 연결하여 하나의 문자열로 만듭니다.
result = ", ".join(fruits)

print(result)  # 출력: 사과, 바나나, 딸기, 포도
```

### 리스트 컴프리헨션

```python
파이썬 리스트 생성 기법이다.

리스트 컴프리헨션을 사용하면 반복문과 조건문을 한 줄에 표현하여 리스트를 생성할 수 있다.

리스트 컴프리헨션에서 조건에 맞는 경우에만 표현식 부분이 실행되며,

해당 결과가 리스트에 추가된다.

따라서 표현식 부분은 조건에 맞는 각 항목에 대해 수행되는 연산이나 표현식을 의미한다.

이렇게 리스트 컴프리헨션은 조건에 따라 특정한 값을 리스트에 추가하는 효과를 갖는다
```

```python
[표현식 for 항목 in 반복가능객체 if 조건]
```

```python
# 1부터 10까지의 숫자 중에서 짝수만을 포함하는 리스트를 생성합니다.
even_numbers = [x for x in range(1, 11) if x % 2 == 0]

print(even_numbers)  # 출력: [2, 4, 6, 8, 10]
```
