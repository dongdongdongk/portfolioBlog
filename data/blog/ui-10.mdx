# { 4.접근성(폰트 컬러 4.5:1 이상 컬러 활용) }

```jsx
대비 비율이란?

		대비 비율은 두 색상이 얼마나 차이가 나는지를 수치로 나타낸 것인데, 이 비율은 1:1부터 21:1까지 있어.

		1:1은 두 색상이 완전히 동일한 경우(예: 검은 배경에 검은 글자).

		21:1은 완전히 다른 경우(예: 검은 배경에 흰 글자).

		여기서 말하는 4.5:1은 글자와 배경색이 이 정도로 차이가 나야 글자가 충분히 눈에 잘 띈다는 기준을 나타내.

		이 비율은 사용자가 글을 쉽게 읽을 수 있게 해줘.

왜 4.5:1인가?

		이 비율은 세계적으로 웹 접근성을 개선하기 위해 만들어진 **WCAG(Web Content Accessibility Guidelines)**라는 표준에서

		권장하는 최소 기준이야. 이 기준에 따르면:

		일반 텍스트는 4.5:1 이상의 대비를 가져야 하고,

		큰 텍스트(18pt 이상)는 3:1로 더 낮아도 괜찮아.

		이 비율을 충족시키지 못하면 시력이 약하거나 색각 이상을 가진 사용자들이 글자와 배경을 구분하기 힘들어질 수 있어.

예시로 이해해 보자:

		대비 비율 1.6:1: 옅은 회색 글자에 밝은 회색 배경 (글씨를 구분하기 힘듦)

		대비 비율 4.5:1: 어두운 회색 글자에 밝은 회색 배경 (글씨가 더 잘 보임)

		대비 비율 21:1: 검은 배경에 흰 글자 (가장 큰 대비로 매우 잘 보임)
```
