## Push , Pop

```jsx
push와 pop은 배열의 마지막 요소를 추가하거나 제거하는 메서드
```

```jsx
위와 같이 새로운 값을 추가할 때 매번 마지막 인덱스를 찾아서 추가하려면 번거롭고 불편하다

그때 아래와 같이

.push('추가할 값') 을 하면 마지막에 추가 가능하다 (여러개 동시에도 가능하다)

.**pop**() 을 사용하면 마지막 인덱스의 값이 사라진다 ( 여기에는 인수가 필요없다 )
```

```jsx
const fruits = ['apple', 'banana']
const newLength = fruits.push('orange', 'kiwi')

console.log(newLength) // 출력: 4
console.log(fruits) // 출력: ['apple', 'banana', 'orange', 'kiwi']
```

```jsx
const fruits = ['apple', 'banana', 'orange']
const poppedFruit = fruits.pop()

console.log(poppedFruit) // 출력: 'orange'
console.log(fruits) // 출력: ['apple', 'banana']
```

## Shift, Unshift

```jsx
배열의 첫 번째 요소를 추가하거나 제거하는 메서드
```

```jsx
**shift** 메서드는 배열에서 첫 번째 요소를 제거하고 해당 요소를 반환

**unshift** 메서드는 배열의 맨 앞에 하나 이상의 요소를 추가하고, 새로운 배열의 길이를 반환
```

```jsx
const fruits = ['apple', 'banana', 'orange']
const shiftedFruit = fruits.shift()

console.log(shiftedFruit) // 출력: 'apple'
console.log(fruits) // 출력: ['banana', 'orange']
```

```jsx
const fruits = ['banana', 'orange']
const newLength = fruits.unshift('apple', 'kiwi')

console.log(newLength) // 출력: 4
console.log(fruits) // 출력: ['apple', 'kiwi', 'banana', 'orange']
```

## concat

```jsx
concat 메서드는 하나 이상의 배열을 합쳐서 새로운 배열을 생성
```

```jsx
const fruits1 = ['apple', 'banana'];
const fruits2 = ['orange', 'kiwi'];
const combinedFruits = fruits1.concat(fruits2);

console.log(combinedFruits); // 출력: ['apple', 'banana', 'orange', 'kiwi']

* concat을 호출하면 fruits1과 fruits2 배열이 합쳐져서 combinedFruits 배열이 생성
```

## indexOf

```jsx
indexOf 메서드는 배열에서 특정 요소의 인덱스를 반환 해당 요소가 없으면 -1을 반환
```

```jsx
const fruits = ['apple', 'banana', 'orange', 'kiwi'];
const indexOfOrange = fruits.indexOf('orange');

console.log(indexOfOrange); // 출력: 2

* indexOf를 호출하면 'orange'의 인덱스인 2가 반환
```

## includes

```jsx
includes 메서드는 배열에 특정 요소가 포함되어 있는지 여부를 불리언 값으로 반환
```

```jsx
const fruits = ['apple', 'banana', 'orange', 'kiwi'];
const includesOrange = fruits.includes('orange');

console.log(includesOrange); // 출력: true

* includes를 호출하면 'orange'가 배열에 포함되어 있으므로 true가 반환
```

## reverse

```jsx
reverse 메서드는 배열의 순서를 뒤집는다
```

```jsx
const fruits = ['apple', 'banana', 'orange', 'kiwi'];
const reversedFruits = fruits.reverse();

console.log(reversedFruits); // 출력: ['kiwi', 'orange', 'banana', 'apple']

* reverse를 호출하면 배열의 순서가 뒤집혀서 reversedFruits 배열이 생성
```

### Array.from

```jsx
유사 배열 객체나 반복 가능한(iterable) 객체를 배열로 변환하는

JavaScript의 메서드

* 유사 배열 : 인수(arguments), NodeList 배열처럼 보이고 동작하지만 진짜 배열은 아닌 객체

* iteration : 배열, Set, Map 여러 값을 포함하고 있는 객체
```

```jsx
const str = 'hello'
const newArray = Array.from(str)

console.log(newArray) // ['h', 'e', 'l', 'l', 'o']
```

```jsx
const arrayLike = { length: 3, 0: 1, 1: 2, 2: 3 }
const newArray = Array.from(arrayLike, (x) => x * 2)

console.log(newArray) // [2, 4, 6]
```

```jsx
const arrayLike = { length: 3, 0: 1, 1: 2, 2: 3 }
const newArray = Array.from(arrayLike, (x) => x * 2)

console.log(newArray) // [2, 4, 6]

// length 가 3 길이가 3인 배열을 만듬

// 0번인덱스 1 , 1번 인덱스 2, 2번인덱스 3
```
