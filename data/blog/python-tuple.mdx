# 튜플과 리스트의 차이

```python
파이썬에서 튜플(tuple)은 리스트(list)와 매우 유사한 자료형이다.

그러나 가장 큰 차이점은 튜플이 불변(immutable)하다는 것이다.

즉, 튜플은 생성 후 그 내용을 변경할 수 없다.

이와 반대로, 리스트는 가변(mutable)하여 리스트 생성 후에도 그 내용을 변경할 수 있다.

이 차이점으로 인해 튜플과 리스트는 서로 다른 상황에서 사용한다
```

# **튜플의 생성 및 사용 예제**

```python
튜플은 소괄호 ()를 사용하여 생성할 수 있습니다. 또는 괄호 없이 항목을 쉼표로 구분하여 생성할 수도 있다.
```

```python
# 튜플 생성 예시
my_tuple = (1, 2, 3)
print(my_tuple)

# 괄호 없이 튜플 생성
another_tuple = 4, 5, 6
print(another_tuple)

# 한 개의 요소를 가진 튜플 생성
single_element_tuple = (7,)
print(single_element_tuple)
```

# **튜플의 불변성**

```python
튜플의 불변성은 튜플의 요소를 변경하거나 추가, 삭제할 수 없다는 것을 의미
```

```python
my_tuple = (1, 2, 3)

# 튜플의 요소 변경 시도
# my_tuple[1] = 4  # 이 코드는 TypeError를 발생시킵니다.

# 튜플에 요소 추가 시도
# my_tuple.append(4)  # AttributeError, 튜플에는 append 메소드가 없습니다.
```

# **리스트와 튜플의 사용 시점**

```python
리스트: 내용이 변경될 가능성이 있는 데이터의 시퀀스를 다룰 때 사용한다.

예를 들어, 사용자가 입력하는 데이터 목록이나, 프로그램 실행 중에 수정될 수 있는 데이터 집합 등이다.

튜플: 변경될 수 없는 데이터의 시퀀스를 다룰 때 사용한다.

예를 들어, 좌표나 날짜와 같이 변경되지 않는 값들을 다룰 때 사용할 수 있다. 또한 튜플은 딕셔너리의 키로 사용될 수 있다.
```

# **요약**

```python
리스트와 튜플은 파이썬에서 중요한 데이터 구조로, 둘 다 순서가 있는 데이터의 집합을 저장한다.

그러나 리스트는 변경 가능한 반면, 튜플은 한 번 생성되면 변경할 수 없는 불변의 특성을 가지고 있다.

이러한 차이점으로 인해 각각의 사용 사례가 달라잔다.
```
