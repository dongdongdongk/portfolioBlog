# **BeautifulSoup에서 CSS 셀렉터 사용 예제**

```python
from bs4 import BeautifulSoup

html = '''
<!DOCTYPE html>
<html>
<head>
    <title>Example Page</title>
</head>
<body>
    <div id="main" class="container">
        <h1 class="title">Hello World</h1>
        <p class="description">This is an example page.</p>
        <a href="https://example.com" class="link">Example Link</a>
        <ul class="scripts-list">
            <li><a href="movie/Disney_Intertwined_Live-27512578">Disney Intertwined Live (2023)</a></li>
            <li><a href="movie/Mystre__la_Sorbonne-8653328">Mystère à la Sorbonne (2018)</a></li>
            <li><a href="movie/Blind_Massage-3469964">Blind Massage (2014)</a></li>
        </ul>
    </div>
</body>
</html>
'''

soup = BeautifulSoup(html, 'html.parser')

# 1. 태그 이름 셀렉터
title_tag = soup.select('title')
print(title_tag[0].get_text())  # Output: Example Page

# 2. 클래스 셀렉터
title_class = soup.select('.title')
print(title_class[0].get_text())  # Output: Hello World

# 3. 아이디 셀렉터
main_id = soup.select('#main')
print(main_id[0].get_text().strip())

# 4. 자식 셀렉터
title_child = soup.select('div > h1')
print(title_child[0].get_text())  # Output: Hello World

# 5. 후손 셀렉터
description_descendant = soup.select('div p')
print(description_descendant[0].get_text())  # Output: This is an example page.

# 6. 속성 셀렉터
link_attribute = soup.select('a[href="https://example.com"]')
print(link_attribute[0].get_text())  # Output: Example Link

# 'ul.scripts-list' 클래스 안의 모든 'a' 태그를 선택
links = soup.select('ul.scripts-list a')

# 각 'a' 태그의 'href' 속성을 추출하여 리스트에 저장
hrefs = [link.get('href') for link in links]
print(hrefs)
# Output: ['movie/Disney_Intertwined_Live-27512578', 'movie/Mystre__la_Sorbonne-8653328', 'movie/Blind_Massage-3469964']
```

# **CSS 셀렉터 상세 설명**

## **태그 이름 셀렉터**

```python
태그 이름 셀렉터 (title): HTML에서 특정 태그 이름을 가진 모든 요소를 선택합니다.
```

```python
soup.select('title')
```

## **클래스 셀렉터**

```python
클래스 셀렉터 (.title): 특정 클래스 이름을 가진 모든 요소를 선택합니다. 클래스 이름 앞에 점(.)을 붙입니다.
```

```python
soup.select('.title')
```

## **아이디 셀렉터**

```python
아이디 셀렉터 (#main): 특정 아이디를 가진 요소를 선택합니다. 아이디 앞에 샵(#)을 붙입니다.
```

```python
soup.select('#main')
```

## **자식 셀렉터**

```python
자식 셀렉터 (div > h1): 특정 부모 요소의 자식 요소를 선택합니다. 부모와 자식 사이에 >를 사용합니다.
```

```python
soup.select('div > h1')
```

## **후손 셀렉터**

```python
후손 셀렉터 (div p): 특정 부모 요소의 모든 후손 요소를 선택합니다. 부모와 후손 사이에 공백을 사용합니다.
```

```python
soup.select('div p')
```

## **속성 셀렉터**

```python
속성 셀렉터 (a[href="https://example.com"]): 특정 속성을 가진 요소를 선택합니다. 속성명을 대괄호([]) 안에 넣습니다.
```

```python
soup.select('a[href="https://example.com"]')
```
