# 총 쏘기 입력 설정하기

## 🎯 이번에 만들 것

마우스 **왼쪽 버튼**을 누르면 총을 쏘는 기능입니다!

아직 실제로 총알이 발사되지는 않고, **버튼을 눌렀는지 감지**하는 것까지만 만듭니다.

```
마우스 클릭! → "Shoot!" 메시지 출력
```

---

## 🧩 전체 과정 (큰 그림)

언리얼에서 입력을 만드는 3단계:

```
1단계: Input Action 만들기
   ↓  (무엇을 할 건지 정의)

2단계: Mapping Context에 연결
   ↓  (어떤 버튼으로 할 건지)

3단계: C++ 함수에 연결
   ↓  (실제 동작 구현)
```

---

## 📝 Step 1: Input Action 만들기

### Input Action이 뭔가요?

**"이런 동작을 할 거야"** 라고 선언하는 것입니다.

예시:

- 점프하기
- 달리기
- **총 쏘기** ← 우리가 만들 것

### 어떻게 만들어요?

**Content Browser에서:**

```
1. Input 폴더 찾기
2. 우클릭 → Input → Input Action
3. 이름: "IA_Shoot" (Input Action_Shoot)
4. 더블클릭해서 열기
```

### 설정하기

**아무것도 안 해도 됩니다!** ✅

```
Value Type: Boolean (기본값)
```

**왜 Boolean이에요?**

- 총을 쏘거나 / 안 쏘거나
- True(참) / False(거짓)
- 중간값이 필요 없음

**다른 타입 예시:**

- Float: 자동차 가속 (0~100%)
- Vector2D: 캐릭터 이동 (앞/뒤/좌/우)
- Vector3D: 비행 (위/아래 포함)

---

## 🎮 Step 2: Mapping Context에 연결

### Mapping Context가 뭔가요?

**"어떤 버튼을 누르면 동작할까?"** 를 정하는 것입니다.

```
IA_Shoot → 마우스 왼쪽 버튼
IA_Shoot → 게임패드 X버튼
```

### 설정하기

**IMC_Default (Input Mapping Context) 열기**

```
1. Mappings 섹션에서 "+" 클릭
2. Action: "IA_Shoot" 선택
3. Key: "Left Mouse Button" 선택
```

**게임패드도 추가하기 (선택사항)**

```
1. 같은 IA_Shoot에 "+" 클릭 (매핑 추가)
2. Key: "Gamepad Face Button Bottom" (X버튼)
```

**결과:**

```
IA_Shoot
  ├─ Left Mouse Button (마우스)
  └─ Gamepad X (게임패드)
```

**저장하기!** 💾

## 💻 Step 3: C++ 함수 만들기

이제 실제로 **총을 쏘는 함수**를 만들 차례입니다.

### 3-1: 헤더 파일 (.h)

**ShooterSamCharacter.h** 열기

**Input Action 변수 추가:**


**총 쏘는 함수 선언:**

```cpp
// 다른 함수들 아래에 추가 (public: 섹션에)

```

---

### 3-2: 구현 파일 (.cpp)

**ShooterSamCharacter.cpp** 열기

**Step A: 함수 구현하기**

파일 맨 아래에 추가:

```cpp
void AShooterSamCharacter::Shoot()
{
    // 일단 메시지만 출력 (테스트용)
    UE_LOG(LogTemp, Display, TEXT("Shoot!"));
}
```

**코드 설명:**

- `UE_LOG` = 언리얼 로그 시스템
- `LogTemp` = 임시 로그 카테고리
- `Display` = 일반 정보 레벨
- `TEXT("Shoot!")` = 출력할 메시지

---

**Step B: 입력과 함수 연결하기**

`SetupPlayerInputComponent` 함수 안에서:

```cpp
void AShooterSamCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
    if (UEnhancedInputComponent* EnhancedInputComponent = Cast<UEnhancedInputComponent>(PlayerInputComponent))
    {
        // Jumping (기존 코드)
        EnhancedInputComponent->BindAction(JumpAction, ETriggerEvent::Started, this, &ACharacter::Jump);

        // 다른 입력들...

        // ===== 여기에 추가! =====
        EnhancedInputComponent->BindAction(ShootAction, ETriggerEvent::Started, this, &AShooterSamCharacter::Shoot);
    }
}
```

**코드 한 줄씩 이해:**

```cpp
BindAction(ShootAction, ETriggerEvent::Started, this, &AShooterSamCharacter::Shoot);
```

1. `ShootAction` = 어떤 입력?
2. `ETriggerEvent::Started` = 언제? → **버튼을 누르는 순간**
3. `this` = 누가? → 이 캐릭터
4. `&AShooterSamCharacter::Shoot` = 무엇을? → Shoot 함수 실행

---

### Trigger Event 종류

```cpp
ETriggerEvent::Started   // 버튼 누르는 순간 (1번만)
ETriggerEvent::Triggered // 버튼 누르고 있는 동안 (계속)
ETriggerEvent::Completed // 버튼 떼는 순간 (1번만)
```

**총 쏘기는 Started가 적합합니다!**

- 한 번 누르면 한 발만 발사
- Triggered 쓰면? → 연사됨 (나중에 기관총 만들 때 사용)

# { 총(Gun) 액터 만들기 }

## 🎯 이번에 만들 것

플레이어가 **손에 들고 쏠 수 있는 총** 을 만듭니다!

지금은 총 모델만 만들고, 나중에 캐릭터 손에 붙일 예정입니다.

---

## 🤔 왜 총을 따로 만드나요?

### 방법 1: 캐릭터 모델에 총이 붙어있음 ❌

```
캐릭터 메시
  └─ 손
      └─ 총 (고정됨)
```

**단점:**

- 총 한 개만 가능
- 무기 교체 불가능
- 총마다 캐릭터를 새로 만들어야 함

### 방법 2: 총을 별도 액터로 만듦 ✅

```
캐릭터
  └─ 손 소켓
      └─ 총 액터 (교체 가능)
          ├─ 소총
          ├─ 샷건
          └─ 런처
```

**장점:**

- 무기 여러 개 만들 수 있음
- 무기 교체 가능
- 각 무기마다 독립적인 기능

**이 방법을 사용합니다!** 🎯

---

## 🏗️ 총의 구조 설계

### 컴포넌트 계층

```
AGun (액터)
  └─ SceneRoot (씬 컴포넌트) ← 루트
      └─ Mesh (스켈레탈 메시) ← 총 모델
```

### 왜 이렇게 만드나요?

**SceneRoot를 중간에 두는 이유:**

```
방법 1: Mesh를 바로 루트로
Mesh (루트)
  └─ 위치 조정이 어려움

방법 2: SceneRoot를 루트로 (우리 방법)
SceneRoot (루트) ← 이걸 손에 붙임
  └─ Mesh ← 이걸 조정해서 정렬
```

**비유:**

- SceneRoot = 손잡이
- Mesh = 실제 총

손잡이(SceneRoot)를 손에 붙이고, 총(Mesh)의 위치를 조정하면 정렬이 쉬워집니다!

## 📝 Step 1: C++ 총 클래스 만들기

### 1-1: 새 C++ 클래스 생성

**언리얼 에디터:**

```
Tools → New C++ Class
→ Actor 선택
→ 이름: "Gun"
→ Create Class
```

---

### 1-2: 헤더 파일 작성 (Gun.h)

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Gun.generated.h"

UCLASS()
class SHOOTERSAM_API AGun : public AActor
{
    GENERATED_BODY()

public:
    AGun();

    // ===== 컴포넌트 =====

    // 루트 컴포넌트 (빈 씬)
    UPROPERTY(VisibleAnywhere)
    USceneComponent* SceneRoot;

    // 총 모델
    UPROPERTY(VisibleAnywhere)
    USkeletalMeshComponent* Mesh;

    // ===== 함수 =====

    // 총 쏘기 함수
    void PullTrigger();
};
```

**코드 설명:**

**SceneRoot (씬 컴포넌트)**

```cpp
USceneComponent* SceneRoot;
```

- 빈 컴포넌트 (보이지 않음)
- 위치/회전/크기만 가짐
- 다른 컴포넌트들의 부모 역할

**Mesh (스켈레탈 메시)**

```cpp
USkeletalMeshComponent* Mesh;
```

- 실제 총 모델
- 스켈레탈 메시 = 뼈대가 있는 모델
- 애니메이션 가능 (장전, 발사 등)

**PullTrigger (방아쇠 당기기)**

```cpp
void PullTrigger();
```

- 나중에 총을 쏠 때 호출할 함수
- 지금은 테스트용 메시지만

---

### 1-3: 구현 파일 작성 (Gun.cpp)

**생성자에서 컴포넌트 만들기:**

```cpp
#include "Gun.h"

AGun::AGun()
{
    PrimaryActorTick.bCanEverTick = true;

    // 1단계: SceneRoot 만들기
    SceneRoot = CreateDefaultSubobject<USceneComponent>(TEXT("Scene Root"));
    SetRootComponent(SceneRoot);  // 루트로 설정!

    // 2단계: Mesh 만들기
    Mesh = CreateDefaultSubobject<USkeletalMeshComponent>(TEXT("Mesh"));
    Mesh->SetupAttachment(SceneRoot);  // SceneRoot에 붙이기!
}
```

**한 줄씩 이해하기:**

```cpp
SceneRoot = CreateDefaultSubobject<USceneComponent>(TEXT("Scene Root"));
```

- `CreateDefaultSubobject` = 컴포넌트 생성
- `<USceneComponent>` = 씬 컴포넌트 타입
- `TEXT("Scene Root")` = 에디터에서 보일 이름

```cpp
SetRootComponent(SceneRoot);
```

- 이 컴포넌트를 액터의 **루트(뿌리)** 로 만듦
- 모든 것의 기준점이 됨

```cpp
Mesh->SetupAttachment(SceneRoot);
```

- Mesh를 SceneRoot의 **자식**으로 붙임
- SceneRoot가 움직이면 Mesh도 따라감

---

**PullTrigger 함수 구현:**

```cpp
void AGun::PullTrigger()
{
    // 테스트용: "Bang" 메시지 출력
    UE_LOG(LogTemp, Display, TEXT("Bang"));
}
```

지금은 메시지만 출력하지만, 나중에 여기서:

- 총알 발사
- 사운드 재생
- 이펙트 생성

등을 구현할 예정입니다.

## 📚 핵심 개념 정리

### Actor (액터)

게임에 배치할 수 있는 모든 오브젝트

- 총, 캐릭터, 문, 상자 등

### Component (컴포넌트)

액터를 구성하는 부품

- 메시, 라이트, 사운드 등

### Scene Component

위치/회전/크기 정보만 있는 빈 컴포넌트

- 다른 컴포넌트들의 부모 역할
- 눈에 보이지 않음

### Skeletal Mesh Component

뼈대가 있는 3D 모델

- 애니메이션 가능
- 캐릭터, 동물, 움직이는 물체

### Root Component

액터의 최상위 컴포넌트

- 액터의 위치 = 루트 컴포넌트의 위치
- 모든 자식 컴포넌트의 기준점

**Step 3: 총 주인 설정**

```cpp
if (Gun)
{
    Gun->SetOwner(this);
}
```

**if (Gun) 체크하는 이유:**

```cpp
// 만약 총 생성 실패하면?
Gun = nullptr  // Gun이 null

// null 포인터로 함수 호출하면?
Gun->SetOwner(this);  // 💥 게임 크래시!

// 그래서 체크 필수!
if (Gun)  // Gun이 유효한지 확인
{
    Gun->SetOwner(this);  // 안전하게 호출
}
```

**SetOwner(this)의 의미:**

```cpp
Gun->SetOwner(this);
```

- `SetOwner` = 주인 지정하기
- `this` = 이 캐릭터 자신

```cpp
    // 주인의 위치 확인
    // 등등...
}
```

**비유:**

```
총 = 도구
주인 = 도구를 사용하는 사람

```

**가능한 원인:**

3. **월드가 null**
