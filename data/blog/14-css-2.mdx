```jsx
먼저, body 요소에 CSS Grid를 적용하여 기본 레이아웃을 설정합니다.

shared.css 파일에서 body에 display: grid;를 추가합니다.
```

```jsx

}
```

```jsx
이제 페이지를 새로 고침하면 body 요소가 그리드 컨테이너로 변하게 됩니다.

하지만 헤더, 백드롭, 모달 등은 그리드의 일부가 아닙니다. 이들은 문서의 정적 위치에 따라 배치됩니다.
```

## 2. 행(행과 열) 정의하기

```jsx
헤더, 메인 영역, 푸터를 포함한 레이아웃을 정의하기 위해 grid-template-rows를 설정합니다.

헤더를 고정하고, 메인 영역과 푸터의 높이를 지정할 수 있습니다.
```

```jsx
body {
    display: grid;
    grid-template-rows: auto 1fr 8rem; /* 헤더는 auto, 메인 영역은 1fr, 푸터는 8rem */
}
```

```jsx
auto: 헤더의 높이에 맞춰 자동으로 조절됩니다.

1fr: 메인 영역이 남은 공간을 차지합니다.

8rem: 푸터의 고정 높이입니다.
```

## 3. 문제 해결: 헤더 고정 및 콘텐츠 영역 조정



## 1. 기본 문제 확인

```jsx
문제:

		메인 페이지에서 이미지 위에 흰 공백이 나타나며,

		푸터가 모바일에서 페이지의 맨 아래에 위치하지 않는 문제가 발생했습니다.

원인:

		main 요소에 margin-top이 있어 여백이 추가되었습니다.

		모바일 뷰에서 푸터의 크기가 커져서 푸터가 페이지의 맨 아래에 위치하지 않음.
```

## 2. `margin-top`과 `min-height` 문제 해결

```jsx
해결:

		shared.css 파일에서 margin-top과 min-height를 삭제합니다.

		이전에 설정한 행을 추가하여 헤더의 공간을 잡는 방식으로 레이아웃을 수정했기 때문에 이 코드들이 불필요해졌습니다.
```

```jsx
main {
  margin-top: 0; /* 불필요한 바깥쪽 여백 제거 */
  min-height: 0; /* 불필요한 최소 높이 제거 */
}
```

## 3. 모바일 뷰에서 푸터 문제 해결

```jsx
문제:

		모바일 기기에서 푸터가 전체 페이지의 맨 아래에 위치하지 않으며, 푸터의 콘텐츠가 크기에 따라 레이아웃이 깨짐.

원인:

		grid-template-rows에 설정된 고정 높이(예: 8rem)로 인해 푸터의 크기가 커질 때 문제가 발생합니다.

		auto를 사용해도 레이아웃이 제대로 되지 않음.
```

## 4. `fit-content` 활용

```jsx
fit-content는 CSS Grid에서 콘텐츠에 따라 자동으로 크기를 조절할 수 있는 유용한 기능입니다.

해결:

		grid-template-rows의 푸터 행을 fit-content로 설정하여

		푸터가 최소 크기를 가지면서도 필요한 만큼의 공간을 차지하도록 합니다.
```

```jsx
body {
  display: grid;
  grid-template-areas:
    "header"
    "main"
    "footer";
  grid-template-rows: auto 1fr fit-content(8rem); /* 푸터의 최소 크기를 8rem으로 설정하고, 콘텐츠가 필요에 따라 크기 조절 */
}
```

```jsx
fit-content(8rem):

		푸터의 기본 크기를 8rem으로 설정하며,

		콘텐츠가 더 필요할 경우 크기를 조정합니다. 따라서 콘텐츠가 작을 경우 8rem을 유지하고,

		더 많은 콘텐츠가 있을 경우 필요에 따라 크기를 늘릴 수 있습니다.
```

### `auto`와 `fit-content`의 차이점

```jsx
크기 결정 기준:

		auto:

				콘텐츠의 크기와 부모 요소의 공간에 맞춰 요소의 크기를 자동으로 조정합니다.

		fit-content:

				콘텐츠의 크기와 주어진 최대 크기 중 더 작은 값을 사용하여 요소의 크기를 결정합니다.

주 사용 사례:

		auto:

				일반적인 레이아웃에서 요소가 콘텐츠의 크기에 맞도록 자동으로 크기를 조절할 때 사용합니다.

		fit-content:

				CSS Grid나 Flexbox 레이아웃에서 콘텐츠에 맞는 최소 크기를 유지하면서, 최대 크기를 제한하고 싶을 때 사용합니다.

```

# { CSS Grid에서 요소 배치하기: `justify-items`와 `align-items` }

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381544/notion-blog/_/_/CSS/_CSS_/_14_CSS_-_2/image_1.png)

```jsx
CSS Grid를 사용하면서 요소의 기본 배치가 마음에 들지 않을 때,

요소를 원하는 위치에 배치하기 위해 사용할 수 있는 몇 가지 프로퍼티가 있습니다.

이 강의에서는 justify-items와 align-items를 활용하여 그리드 내에서 요소를 어떻게 배치할 수 있는지 배웁니다.
```

## 1. `justify-items` 프로퍼티

```jsx
justify-items는 그리드 셀의 수평 축에서 요소를 배치하는 방법을 지정하는 프로퍼티입니다.

기본값은 stretch로, 요소가 셀의 전체 너비를 채우도록 합니다.

그러나 다른 값을 사용하여 요소의 배치를 조정할 수 있습니다.
```

```jsx
사용 가능한 값:

stretch (기본값): 요소가 그리드 셀의 전체 너비를 채우도록 합니다.

center: 요소를 그리드 셀의 수평 중앙에 배치합니다.

start: 요소를 그리드 셀의 시작점(읽기 방향에 따라 왼쪽 또는 오른쪽)에 배치합니다.

end: 요소를 그리드 셀의 끝점(읽기 방향에 따라 왼쪽 또는 오른쪽)에 배치합니다.

```

```jsx
.container {
  display: grid;
  justify-items: center; /* 요소를 셀의 수평 중앙에 배치 */
}
```

## 2. `align-items` 프로퍼티

```jsx
align-items는 그리드 셀의 수직 축에서 요소를 배치하는 방법을 지정하는 프로퍼티입니다.

이 역시 기본값은 stretch로, 요소가 셀의 전체 높이를 채우도록 합니다.
```

```jsx
사용 가능한 값:

stretch (기본값): 요소가 그리드 셀의 전체 높이를 채우도록 합니다.

center: 요소를 그리드 셀의 수직 중앙에 배치합니다.

start: 요소를 그리드 셀의 시작점(위쪽)에 배치합니다.

end: 요소를 그리드 셀의 끝점(아래쪽)에 배치합니다.
```

```jsx
.container {
  display: grid;
  align-items: center; /* 요소를 셀의 수직 중앙에 배치 */
}
```

## 3. `justify-items`와 `align-items`를 함께 사용하기

```jsx
justify-items와 align-items를 함께 사용하여 그리드 내 요소의 위치를 더욱 정밀하게 조정할 수 있습니다.

예를 들어, 요소를 그리드 셀의 중앙에 배치하려면 두 프로퍼티를 모두 center로 설정하면 됩니다.
```

```jsx
.container {
  display: grid;
  justify-items: center; /* 수평 중앙 배치 */
  align-items: center;   /* 수직 중앙 배치 */
}
```

# {CSS Grid에서 그리드 전체 배치 조정하기: `justify-content`와 `align-content`}

```jsx
CSS Grid를 사용할 때, 그리드 컨테이너의 크기가 콘텐츠보다 큰 경우,

그리드 전체의 배치를 조정해야 할 때가 있습니다.

이런 상황에서 그리드 전체의 위치를 컨테이너 내에서 조정하는 데 유용한 두 가지 프로퍼티가 있습니다: justify-content와 align-content.
```

## 1. 그리드 전체 배치 문제

```jsx
일반적으로 그리드는 지정된 행과 열을 통해 요소들을 배치합니다.

그러나 그리드 컨테이너가 설정된 너비와 높이를 가지고 있고,

그리드의 행과 열이 모두 이 컨테이너를 채우지 않는다면, 그리드 전체를 컨테이너 내에서 어디에 배치할 것인지 결정해야 합니다.

이럴 때 justify-content와 align-content 프로퍼티를 사용하면,

그리드 전체를 x축(수평 방향)과 y축(수직 방향)에서 정렬할 수 있습니다.

* 한마디로 div 내의 그리드가 꽉 차는 그리드가 아니라면 그리드 전체를 어디에 딱 붙일거냐 이런 의미 (위 아래 옆 중앙 등등 )
```

## 2. `justify-content` 프로퍼티

```jsx
justify-content는 그리드 전체를 수평(x축) 방향에서 배치하는 방법을 지정합니다.

사용 가능한 값:

		start: 그리드를 컨테이너의 시작점(왼쪽)으로 배치합니다. 이것이 기본값입니다.

		center: 그리드를 컨테이너의 수평 중앙에 배치합니다.

		end: 그리드를 컨테이너의 끝(오른쪽)으로 배치합니다.

		stretch: 그리드가 컨테이너의 너비를 채우도록 확장합니다. 단, 그리드 템플릿 설정에서 정의한 열 크기를 덮어쓰지 않습니다.
```

```jsx
.container {
  display: grid;
  justify-content: center; /* 그리드를 컨테이너의 수평 중앙에 배치 */
}
```

## 3. `align-content` 프로퍼티

```jsx
align-content는 그리드 전체를 수직(y축) 방향에서 배치하는 방법을 지정합니다.

사용 가능한 값:

		start: 그리드를 컨테이너의 시작점(위쪽)으로 배치합니다. 이것이 기본값입니다.

		center: 그리드를 컨테이너의 수직 중앙에 배치합니다.

		end: 그리드를 컨테이너의 끝(아래쪽)으로 배치합니다.

		stretch: 그리드가 컨테이너의 높이를 채우도록 확장합니다. 하지만, 그리드 템플릿 설정에서 정의한 행 크기를 덮어쓰지 않습니다.
```

# { 개별 그리드 셀의 배치 조정: `justify-self`와 `align-self` }

```jsx
CSS Grid를 사용해 레이아웃을 구축할 때, 모든 그리드 요소를 동일하게 배치하는 것이 기본이지만,

특정 요소만 다르게 배치하고 싶은 경우가 있을 수 있습니다.

이런 경우 justify-self와 align-self 프로퍼티를 사용해 개별 요소의 배치를 세밀하게 조정할 수 있습니다.
```

## 1. 기본 배치 설정

```jsx
기본적으로, 그리드의 모든 요소는 그리드 셀의 전체 너비와 높이를 차지하도록 설정되어 있습니다.

즉, x축(수평 방향)과 y축(수직 방향) 모두를 채우게 됩니다.

이런 기본 설정은 justify-items와 align-items 프로퍼티의 기본값인 stretch에 의해 적용됩니다.
```

## 2. 개별 요소의 배치 조정하기

```jsx
특정 요소를 다른 요소와는 다르게 배치하고 싶다면, 해당 요소에만 적용되는 배치 스타일을 지정할 수 있습니다.

예를 들어, 그리드 내의 두 번째 요소(Element 2)를 중앙으로 정렬하고 싶다면,

justify-self와 align-self를 사용하여 조정할 수 있습니다.
```

```jsx
.el2 {
  justify-self: center; /* 수평 중앙 정렬 */
  align-self: center; /* 수직 중앙 정렬 */
}
```

## 3. 실용적인 사용법

```jsx
justify-self와 align-self 프로퍼티는 특정 요소를 그리드 내의 다른 요소와 다르게 배치하고 싶을 때 유용합니다.

예를 들어, 강조 표시된 콘텐츠나 특정 디자인 요구사항에 맞추기 위해 개별 요소의 배치를 조정할 수 있습니다.

이 프로퍼티들을 사용하면, 그리드 레이아웃의 유연성을 극대화하여 각 요소를 독립적으로 조정할 수 있으며,

복잡한 레이아웃 요구사항도 충족시킬 수 있습니다.
```

## 1. 기본 그리드 레이아웃 설정

```jsx

grid-template-columns와 grid-template-rows 속성을 사용해 그리드의 행과 열을 설정합니다.

grid-template-areas 속성은 그리드 영역을 정의하는 데 사용됩니다.
```

```jsx
.container {
    margin: 20px;
```

# { CSS Grid의 자동 기능: 자동 행과 자동 열}

```jsx
CSS Grid의 자동 기능을 활용하면 콘텐츠가 많거나 동적으로 변하는 상황에서도 깔끔하게 레이아웃을 유지할 수 있습니다.

이 강의에서는 grid-auto-rows, grid-auto-columns,

그리고 grid-auto-flow와 같은 속성을 사용하여 그리드의 자동 배치 기능을 조절하는 방법을 배웁니다.
```

## 1. 자동 행 생성 (`grid-auto-rows`)

```jsx
CSS Grid의 기본 동작에서는, 그리드 컨테이너에 display: grid를 설정하면 모든 자식 요소가 자동으로 새로운 행에 배치됩니다.

이 기본 동작은 grid-template-rows로 명시적으로 설정하지 않은 경우에 적용되며, 행은 필요한 만큼 자동으로 생성됩니다.

* 기본 설정: 자동으로 생성된 행의 높이는 auto입니다. 각 행의 높이는 그 행에 있는 콘텐츠의 크기에 따라 결정됩니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem);
}

* 위 코드는 두 개의 열을 정의하지만 행은 정의하지 않기 때문에,

	자식 요소가 추가될 때마다 새로운 행이 자동으로 생성됩니다.
```

### `grid-auto-rows` 사용

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem);
    grid-auto-rows: 12rem; /* 자동으로 생성되는 모든 행의 높이를 12rem으로 설정 */
}

* grid-auto-rows 속성: 이 속성을 사용하면 자동으로 생성되는 행의 높이를 지정할 수 있습니다.

	위 코드를 적용하면, 새로 생성되는 모든 행의 높이가 고정되어 12rem이 됩니다.
```

### `minmax` 사용

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem);
    grid-auto-rows: minmax(8rem, auto); /* 최소 높이는 8rem, 최대 높이는 콘텐츠에 맞춰 자동 */
}

* 이렇게 설정하면, 각 행의 높이가 최소 8rem 이상이 되며, 최대 높이는 그 행에 포함된 콘텐츠에 따라 결정됩니다.
```

## 2. 자동 열 생성 (`grid-auto-columns`)

```jsx
기본적으로 CSS Grid는 콘텐츠가 추가되면 자동으로 새로운 행에 배치하지만,

때로는 새 콘텐츠를 열에 추가하고 싶을 수 있습니다. 이를 위해 grid-auto-flow 속성을 사용합니다.
```

### grid-auto-flow 사용

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem);
    grid-auto-flow: column; /* 새 콘텐츠를 열에 추가 */
}

* grid-auto-flow 속성: 그리드의 자동 배치 방향을 설정합니다.

	기본값은 row로, 새로운 콘텐츠가 행에 추가됩니다. column으로 설정하면 새로운 콘텐츠가 열에 추가됩니다.
```

### `grid-auto-columns` 사용

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem);
    grid-auto-flow: column;
    grid-auto-columns: 5rem; /* 자동으로 생성되는 모든 열의 너비를 5rem으로 설정 */
}

* grid-auto-columns 속성: grid-auto-flow: column이 설정된 상태에서, 새로 생성되는 열의 너비를 지정할 수 있습니다.
```

# { CSS Grid의 암시적 그리드와 명시적 그리드 }

## 1. 명시적 그리드 (Explicit Grid)

```jsx
명시적 그리드는 개발자가 grid-template-columns와 grid-template-rows를 사용하여 명시적으로 정의한 그리드를 의미합니다.

 즉, 그리드의 구조(열과 행의 개수 및 크기)를 명확하게 설정하는 것입니다.
```

```jsx
명시적 그리드의 정의:

grid-template-columns: 열의 크기와 개수를 명시적으로 정의합니다.

grid-template-rows: 행의 높이와 개수를 명시적으로 정의합니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem); /* 두 개의 열을 각각 15rem로 정의 */
    grid-template-rows: 20rem; /* 첫 번째 행의 높이를 20rem로 정의 */
}
```

## 2. 암시적 그리드 (Implicit Grid)

```jsx
암시적 그리드는 명시적으로 정의되지 않은 영역에서 CSS Grid가 자동으로 생성하는 그리드를 의미합니다.

이는 명시적으로 설정된 열과 행 외에 추가적으로 생성되는 행과 열을 처리하는 방식입니다.
```

```jsx
암시적 그리드의 정의:

명시적으로 정의된 그리드에 포함되지 않은 자식 요소들을 자동으로 추가된 행과 열에 배치합니다.

grid-auto-rows와 grid-auto-columns 속성으로 자동으로 생성되는 행과 열의 크기를 제어할 수 있습니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(2, 15rem); /* 명시적으로 두 개의 열 정의 */
    grid-template-rows: 20rem; /* 명시적으로 첫 번째 행 정의 */
    /* 명시적 정의가 없는 나머지 영역은 자동 생성됨 */
}
```

## 1. 기본 그리드 동작의 문제점

```jsx
기본적으로 CSS Grid는 자식 요소를 배치할 때, 설정된 열의 개수와 크기에 따라 배치됩니다.

하지만 화면의 크기를 조정해도 그리드는 자동으로 변경되지 않으며,

콘텐츠가 뷰포트의 가장자리를 넘어가거나, 반대로 뷰포트의 공간이 더 생겨도 변화가 없습니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(3, 10rem); /* 세 개의 열을 10rem로 정의 */
}

* 이 설정에서는 화면 크기에 상관없이 세 개의 고정된 열이 정의됩니다. 뷰포트의 크기가 변해도 콘텐츠 배치는 변하지 않습니다.
```

## 2. `auto-fill` 사용하기

```jsx
**auto-fill**은 그리드의 열을 자동으로 추가하여 가능한 최대 항목을 행에 배치한 후,

그 다음에 새 행을 시작하도록 합니다.

이 설정은 화면 크기가 변경될 때 그리드가 유동적으로 조정되도록 합니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(auto-fill, 10rem); /* 열을 자동으로 채움 */
}
```

```jsx
동작 설명:

		auto-fill은 현재 행을 가능한 많은 열로 채우고, 더 이상 채울 수 없을 때 새 행을 만듭니다.

		화면을 넓히면 더 많은 열이 추가되고, 화면을 좁히면 자동으로 줄바꿈됩니다.

실제 효과:

		화면이 넓으면 항목이 더 많은 열에 배치되어 첫 번째 행이 확장됩니다.

		화면이 좁아지면 더 많은 항목이 다음 행으로 넘어가게 됩니다.
```

## 3. `auto-fit` 사용하기

```jsx
**auto-fit**은 auto-fill과 유사하게 동작하지만,

추가적으로 전체 행을 채울 수 없는 경우 남은 빈 공간을 활용하여 항목을 자동으로 확장하거나 축소합니다.

결과적으로, 콘텐츠가 가운데 정렬되고, 화면 공간을 최대한 활용하게 됩니다.
```

```jsx
.container {
    display: grid;
    grid-template-columns: repeat(auto-fit, 10rem); /* 열을 자동으로 맞춤 */
}
```

```jsx
동작 설명:

		auto-fit은 auto-fill과 비슷하게 작동하지만,

		열이 부족할 경우 남은 공간을 채우기 위해 열을 확장하여 가운데 정렬 효과를 제공합니다.

실제 효과:

		화면이 넓으면 항목이 중앙에 정렬되고, 여분의 공간을 활용해 항목이 확장됩니다.

		화면이 좁아지면 항목이 자동으로 줄바꿈됩니다.
```

## 4. `auto-fill`과 `auto-fit`의 비교

```jsx
**auto-fill**은 항목이 충분하지 않아도 고정된 열을 유지하며, 가능한 많은 열을 채웁니다.

**auto-fit**은 남은 공간을 활용하여 항목이 가운데 정렬되고, 부족한 열을 채우기 위해 유연하게 대응합니다.
```

## 요약

```jsx
auto-fill:

		현재 행을 가능한 많은 열로 채우고, 부족한 경우 새 행을 만듭니다.

		항목의 수와 관계없이 최대한 많은 열을 유지합니다.

auto-fit:

		화면의 공간을 최대한 활용하여 항목을 중앙에 정렬하고,

		부족한 열은 유연하게 조정하여 가운데 정렬합니다.

활용 방법:

		화면 크기에 따라 동적으로 열을 추가하고,

		콘텐츠를 배치하려면 auto-fill과 auto-fit을 사용하여 유연한 그리드 레이아웃을 구성할 수 있습니다.
```

# { CSS Grid와 Flexbox의 차이점 및 사용 가이드 }

```jsx
CSS Grid와 Flexbox는 웹 페이지의 레이아웃을 설계할 때 사용하는 두 가지 주요 도구입니다.

두 기술 모두 레이아웃을 구성하는 데 매우 유용하지만,

각각의 사용 목적과 최적의 용도가 다릅니다. 이 두 가지를 언제, 어떻게 사용하는지에 대해 자세히 알아보겠습니다.
```

## 1. CSS Grid와 Flexbox의 기본 개념

```jsx
CSS Grid:

		2차원 레이아웃 시스템:

				행(Row)과 열(Column)을 기반으로 구성된 레이아웃입니다.


		주요 특징:

				Grid는 요소를 가로와 세로, 즉 행과 열의 두 방향으로 동시에 제어할 수 있어 복잡한 레이아웃을 쉽게 구성할 수 있습니다.


		사용 목적:

				주로 전체 페이지 레이아웃 또는 중첩된 복잡한 레이아웃에 사용됩니다.

CSS Flexbox:

		1차원 레이아웃 시스템:

				한 방향(가로 또는 세로)으로 요소를 배치합니다.


		주요 특징:

				Flexbox는 한 축(주 축 또는 교차 축)에 요소를 정렬하고 배치하는 데 최적화되어 있습니다.


		사용 목적:

				주로 간단한 레이아웃이나 요소를 한 방향으로 정렬하는 데 사용됩니다.
```

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381546/notion-blog/_/_/CSS/_CSS_/_14_CSS_-_2/image_8.png)

## 3. 사용 예시

```jsx
CSS Grid 사용 예시:

		페이지 레이아웃:

				헤더, 사이드바, 메인 콘텐츠, 푸터를 배치할 때 Grid를 사용하면 간편합니다.

		다차원 배치:

				요소들을 여러 행과 열로 나누어 배치할 때 적합합니다. 예를 들어,

				폼을 디자인할 때 레이블과 입력 필드를 행과 열에 맞춰 나란히 배치하는 경우입니다.
```

```jsx
/* 예시: 페이지 레이아웃 */
.container {
    display: grid;
    grid-template-columns: 1fr 3fr; /* 두 열 구성 */
    grid-template-rows: auto 1fr auto; /* 세 행 구성 */
}

/* 예시: 폼 레이아웃 */
.signup-form {
    display: grid;
    grid-template-columns: 10rem auto; /* 두 개의 열 생성 */
    grid-gap: 1rem; /* 간격 추가 */
}
```

```jsx
CSS Flexbox 사용 예시:

		단순한 1차원 정렬:

				버튼 그룹, 네비게이션 바, 카드 목록과 같이 한 방향으로 요소를 정렬하는 경우에 적합합니다.


		반응형 디자인:

				Flexbox는 flex-wrap을 사용하여 뷰포트 크기에 맞춰 요소를 감쌀 수 있어 반응형 디자인에 유리합니다.
```

```jsx
/* 예시: 네비게이션 바 */
.nav {
    display: flex;
    justify-content: space-between; /* 요소 간의 간격 조절 */
}

/* 예시: 카드 목록 */
.card-container {
    display: flex;
    flex-wrap: wrap; /* 요소가 뷰포트에 맞게 감싸기 */
    gap: 1rem; /* 요소 간 간격 */
}
```

## 4. CSS Grid와 Flexbox를 함께 사용하는 경우

```jsx
Grid와 Flexbox는 동시에 사용할 수 있습니다. 복잡한 페이지 레이아웃에서는 Grid를 사용하고,

그 안에서의 세부적인 요소 정렬에는 Flexbox를 사용하는 방식이 일반적입니다.

예를 들어, 페이지 전체를 Grid로 구성하고, 각 섹션 내에서 버튼이나 카드 정렬에 Flexbox를 사용할 수 있습니다.
```

```jsx
/* 전체 페이지 레이아웃 - Grid */
.page-layout {
    display: grid;
    grid-template-columns: 1fr 3fr; /* 사이드바와 메인 콘텐츠 */
    grid-template-rows: auto 1fr auto; /* 헤더, 콘텐츠, 푸터 */
}

/* 메인 콘텐츠 내 버튼 그룹 - Flexbox */
.button-group {
    display: flex;
    gap: 1rem; /* 버튼 간의 간격 */
    justify-content: center; /* 가운데 정렬 */
}
```
