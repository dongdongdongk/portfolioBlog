# 여러가지 OCR 엔진 ( Types of OCR Engines )

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380864/notion-blog/_/RPA/Complete_UiPath_RPA_Developer_Course/_8_Robot_6_Optical_Character_Recognition/Untitled_6.png)

```python
UiPath에는 기본적으로 Google에서 제공하는 무료 Tesseract OCR 엔진이 포함되어 있다.

이 엔진은 연습이나 학습 목적으로만 사용하는 것이 좋으며, 실제 프로젝트에서는 정확도가 낮아 권장되지 않는다.

**UiPath에서 제공하는 OCR 엔진**

UiPath에서는 다양한 유형의 OCR 엔진을 제공한다. 스튜디오의 액티비티 패널에서 "OCR"를 검색하면 확인할 수 있다.

주요 OCR 엔진으로는 다음이 있다:

1.Microsoft Computer Vision OCR:

이 OCR 엔진은 이미지나 문서 내의 전체 텍스트를 한번에 읽어내는 데 적합

예를 들어, 전체 문서나 책 페이지 등을 OCR로 디지털화할 때 유용하다.

전체 텍스트를 한꺼번에 추출하므로 작업 효율성이 높다.

2.Google Cloud Vision OCR:

이 엔진은 이미지나 문서 내의 특정 영역이나 부분의 텍스트를 선택적으로 읽어내는 데 유리하다.

예를 들어, 영수증의 총 금액 부분만 추출하거나, 신분증의 이름 부분만 인식하는 등의 작업에 유용하다.

필요한 특정 정보만 추출할 수 있어 유연성이 높다.

3.UiPath Screen OCR:

이 엔진은 컴퓨터 화면에 표시되는 이미지나 텍스트를 인식하도록 최적화되어 있다.

RPA(Robotic Process Automation) 작업 중 애플리케이션 화면에서 데이터를 추출할 때 유용하다.

화면 캡처 이미지에서 텍스트를 읽어내는 데 특화되어 있다.

4.UiPath Document OCR:

이 엔진은 스캔된 문서나 문서 이미지에서 텍스트를 읽어내는 데 최적화되어 있다.

UiPath의 Document Understanding 활동과 연계하여 사용된다.

송장, 영수증, 계약서 등 특정 유형의 문서를 처리하고 구조화된 데이터를 추출할 때 유용하다.

기계 학습 기술을 활용하여 문서 레이아웃이 변경되어도 관련 정보를 인식할 수 있다.

**API 키와 엔드포인트**

1.Tesseract OCR과 Microsoft OCR은 무료 엔진이므로 API 키가 필요하지 않다.

2.Google Cloud Vision OCR에는 API 키만 필요하며, 엔드포인트는 없다.

3.Microsoft Computer Vision OCR의 API 키와 엔드포인트는 Azure 포털에서 찾을 수 있다.

4.UiPath Screen OCR의 엔드포인트는 UiPath 스튜디오의 해당 활동에서 확인할 수 있다.

5.UiPath Document OCR의 엔드포인트는 UiPath 클라우드 포털에서 찾을 수 있으며,

	다양한 문서 유형(인보이스, 영수증 등)에 대한 공용 엔드포인트가 제공된다.
```

소수 부분만 20.34 등등 선택하고 싶은데 정규식을 입력해도 문제가 생긴다

그 이유는
