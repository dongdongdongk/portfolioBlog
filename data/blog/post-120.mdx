# 터미널 명령어를 알아야 하는 이유

```jsx
**작업 속도 향상**: 많은 개발자들이 터미널을 오랫동안 사용해왔기 때문에 터미널에서의 작업이 매우 익숙하며 빠르다

명령어를 정확히 이해하고 기억하면 한 줄의 타이핑으로 여러 가지 명령어를 실행할 수 있다.

이는 일반적으로 GUI(그래픽 사용자 인터페이스)를 사용하는 것보다 빠른 작업을 의미한다

**액세스 권한 및 강력한 기능**: 터미널은 컴퓨터의 모든 액세스 권한을 제공하며, 설정 파일 등에 대한 접근이 가능하다.

이는 특정 작업을 수행하는 데 필요한 능력을 제공하며, 일부 고급 작업을 실행할 수 있도록 한다.

**개발자 도구와 플랫폼 통합**: 많은 개발 도구 및 플랫폼이 터미널 기반으로 동작한다.

Node.js, Express, 데이터베이스 등 많은 기술 및 도구는 터미널을 사용하여 실행되며, 터미널에서의 명령어 입력이 필수적이다.

**효율성 및 유연성**: 터미널을 사용하면 간단한 명령어로도 다양한 작업을 수행할 수 있다.

특히 스크립트 작성 및 자동화에 용이하며, 루프 및 조건문과 같은 제어 구조를 통해 더 복잡한 작업을 수행할 수 있다.

**결론**:

터미널은 개발자에게 강력한 도구로서의 역할을 하며, 정확한 사용은 개발 작업을 향상시킬 수 있다.
```

# **터미널(Terminal)과 셸(Shell):**

## 터미널

```jsx
터미널은 컴퓨터 사용자가 텍스트 기반 인터페이스를 통해 컴퓨터와 상호작용하는 환경을 제공하는 소프트웨어이다

사용자는 명령어를 입력하여 파일 관리, 프로그램 실행, 시스템 설정 등을 수행할 수 있다.

터미널은 일종의 명령 프롬프트를 제공하며, 이를 통해 다양한 작업을 수행할 수 있다.
```

## **셸**

```jsx
셸은 터미널에서 명령어를 해석하고 실행하는 소프트웨어이다.

사용자가 입력한 명령어를 해석하고, 그에 따라 컴퓨터 시스템에 명령을 전달한다.

터미널과 셸은 상호작용하여 사용자의 명령을 이해하고 실행한다.

흔히 사용되는 셸에는 Bash, Z Shell(Zsh), Fish 등이 있으며, 각각 특정 기능을 제공한다.
```

## 결론

```jsx
종합적으로, 터미널은 사용자에게 명령어를 입력하고 시스템과 상호작용할 수 있는 인터페이스를 제공하며,

셸은 이러한 명령어를 이해하고 실행하여 실제로 작업을 수행하는 소프트웨어이다.

이 둘은 함께 작동하여 컴퓨터를 효과적으로 제어할 수 있도록 도와준다.
```

# 터미널 명령어

## **LS 명령어**

```jsx
LS는 List의 약자로, 터미널에서 사용하는 명령어 중 하나

**현재 디렉터리의 내용을 나열한다**

ls를 입력하고 Enter를 누르면 현재 디렉터리의 파일 및 폴더 목록이 출력된다

터미널을 열 때마다 Home Directory에서 시작되며, 이곳에서 ls 명령어를 통해 현재 디렉터리의 내용을 확인할 수 있다.

* Home Directory 로 가는 단축키는 cd ~ 다
```

## **PWD 명령어**

```jsx
PWD는 Print Working Directory의 약자로, 현재 작업 중인 디렉터리의 위치를 터미널에 출력

pwd를 입력하고 Enter를 누르면 현재 위치한 디렉터리의 전체 경로가 표시된다

pwd 명령어는 현재 위치를 확인하는데 유용
```

## **CD 명령어**

```jsx
CD는 Change Directory의 약자로, 디렉터리를 변경하는 명령어

cd 디렉터리명을 입력하면 해당 디렉터리로 이동

예를 들어, cd Code를 입력하면 현재 위치한 디렉터리가 Code로 변경된다

자동 완성 기능을 활용하여 디렉터리 명을 빠르게 입력할 수 있다.

( CD + ctrl + 스페이스 하면 내부 내용을 편하게 볼 수 있다 )
```

### **이동과 존재하는 디렉터리 확인**

```jsx
cd 명령어를 입력한 후 디렉터리 명을 사용하면 해당 디렉터리로 이동

ls 명령어를 통해 현재 디렉터리의 내용을 확인할 수 있다.

cd .. 명령어를 사용하면 한 단계 위의 디렉터리로 이동할 수 있다.
```

# 절대 경로와 상대 경로

## **절대 경로(Absolute Path)**

```jsx
절대 경로는 루트 디렉터리(/)에서 시작하여 목적지까지의 완벽한 경로를 나타낸다.

/는 루트 디렉터리를 나타낸다

어디에서든 실행할 수 있다.

예: /Users/coltsteele, /Users/coltsteele/Pets, /Users/coltsteele/Code/HTML_Forms_Tables 등

* 절대 경로 또한 / 입력 후 ctrl + 스페이스 를 사용하면 경로를 자동으로 완성 가능하다
```

## **상대 경로(Relative Path)**

```jsx
상대 경로는 현재 작업 중인 디렉터리에서 시작하여 목적지까지의 경로를 나타낸다.

현재 위치에 따라 상대적으로 변할 수 있다.

상대 경로는 현재 위치를 기반으로 한다.

예: cd Pets는 현재 디렉터리에 Pets가 있을 때만 작동하며, cd ../..은 두 단계 상위 디렉터리로 이동한다.
```

## **mkdir 명령어**

```jsx
make directory"의 줄임말로, 리눅스나 유닉스 기반 시스템에서 디렉토리(폴더)를 생성하는 명령어

이 명령어를 사용하면 현재 위치나 지정한 경로에 새로운 폴더를 만들 수 있다

**기본 사용법 :** mkdir [폴더명]  ( ex mkdir Documents )

**여러 폴더 한 번에 생성 :** mkdir [폴더1] [폴더2] [폴더3]

하위 폴더 생성 : mkdir [상위폴더]/[하위폴더]

상위 경로에 폴더 생성 : mkdir ../[상위폴더명]
```

## **man 명령어**

```jsx
man 명령어는 "manual"의 줄임말로, 매뉴얼 또는 명령어에 대한 상세한 설명을 제공

예시: man ls 명령어를 입력하면 ls 명령어에 대한 매뉴얼 페이지가 표시된다
```

## **플래그(Flag) ( 윈도우는 다른거 같다 )**

```jsx
플래그는 명령어에 부가적인 동작을 지시하는 역할을 한다

예시: ls 명령어에는 -l, -a, -r 등 다양한 플래그가 있다.
```

### **ls 명령어와 플래그 예시**

```jsx
ls 명령어는 현재 디렉토리의 파일과 폴더를 나열하는데 사용

예시: ls -l 명령어는 파일 및 폴더의 상세한 정보를 긴 형식으로 나열한다

예시: ls -a 명령어는 숨겨진 파일을 포함하여 모든 파일을 나열한다
```
