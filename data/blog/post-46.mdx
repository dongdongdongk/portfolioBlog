## 예외(Excption)

- 예외에는 컴파일 시 발생하는 **컴파일 에러** 프로그램 구동 중 발생하는 **런타임 에러**가 있다.
- 컴파일 오류는 문법상의 오류로 런타임 오류는 설계의 오류로 발생한다.
- 자바는 이러한 excption 을 처리하기 위해 java,lang.Exception 이라는 최상위 클래스를 제공

```java
문법 :

try {
				//실행되어야 할 로직
} catch (예외 클래스 e) {
        //예외처리 코드
} finally {
				//예외와 관계없이 무조건 실행되는 코드(생략가능)
}

*정상 실행되면 try 이후 finally 도 실행 (return 문 사용시도 finally는 실행.
```

```java
public class TryCatchFinallyExample {
	public static void main(String[] args) {
		try{
			Class clazz = class.forNmae("java.lang.String2");
		} catch(ClassNotFoundException e) {  //상위객체 Exeption 으로 변경도 가능하
				System.out.println("클래스가 존재하지 않습니다");
		}
	}
}
```

### 다중 catch

try 블록에서 하나가 아닌 다양한 예외가 발생할 수 있다. 이 경우 예외별로 예외 처리 코드를 다르게 적용하기 위해 **다중catch** 를 사용할 수 있다

```java
try {

	ArrayindexOutOfBoundsExeption 발생

	NumberFormatException 발생

} catch(ArrayindexOutOfBoundsExeption e) {
		예외 처리 1
} catch(NumberFormatException e) {
		예외 처리 2
}
```

**catch 의 순서**

다중 catch 블록 작성시 상위 예외 클래스는 하위 클래스 보다 아래쪽에 위치해야 한다.

예외 처리는 위에서 부터 아래로 처리하기 때문에 상위 예외 클래스가 상후에 있다면 아래 하위 예외 클래스는 실행되지 못한다.

**예외 떠넘기기**

메소드를 호출한 곳으로 예외를 떠넘길 수도 있다. 이때 사용하는 키워드가 throws

메소드 선언부 끝에 작성되어 메소드에서 처리하지 않은 예외를 호출한 곳으로 넘긴다.

```java
리턴타입 메소드이름 (매개변수,...) throws 예외클래스1, 예외클래스2 {}

리턴타입 메소드이름 (매개변수,...) throws Exception { }

//종류별로 throws 뒤에 나열할수도 있고 throws Exception 으로 간단히 끝낼수도 있다.

public void method1() throws Exception { ]

```
