## 1. Wwise 콜백 시스템 이해하기

### 콜백(Callback)이란?

- **정의**: 특정 이벤트가 발생했을 때 자동으로 호출되는 함수
- **비유**: "소리가 끝나면 나한테 알려줘!"라고 예약을 걸어두는 것
- **장점**: 소리 재생 시간을 수동으로 계산할 필요 없이 정확한 타이밍에 작업 수행 가능

### AkCallbackType.AK_EndOfEvent

- **용도**: 소리 재생이 완전히 끝났을 때를 감지
- **사용 시기**:
  - 소리 끝나면 오브젝트 비활성화
  - 소리 끝나면 다음 이벤트 트리거
  - 소리 끝나면 UI 업데이트

### PostEvent의 구조

```csharp
uint playingID = AkUnitySoundEngine.PostEvent(
    "Event_Name",           // 1. 재생할 Event 이름
    gameObject,             // 2. 재생 위치 (어느 오브젝트에서)
    (uint)AkCallbackType,   // 3. 콜백 타입 (언제 알림받을지)
    CallbackFunction,       // 4. 실행할 함수
    null                    // 5. 추가 데이터 (옵션)
);
```

### Playing ID (uint)

- **정의**: 재생 중인 소리의 고유 식별 번호
- **uint 타입**: Unsigned Integer (부호 없는 정수) = 0 이상의 양수만
  - 일반 int: -2억 ~ +2억 (음수 포함)
  - uint: 0 ~ 4억 (양수만)
  - 이유: ID는 음수가 없으므로 uint 사용
- **값의 의미**:
  - 0 = 유효하지 않음 (재생 안 됨)
  - 1 이상 = 유효한 재생 ID
- **용도**: 나중에 특정 소리를 멈추거나 제어할 때 사용

## 2. AkAmbient와 PostEvent의 중복 재생 문제

### 문제 상황

```
GameObject 활성화
    ↓
AkAmbient가 자동으로 Event 재생 (1번째)
    ↓
WwiseAutoDeactivate도 PostEvent 실행 (2번째)
    ↓
결과: 같은 소리가 2번 재생됨! ❌
```

### 해결 방법: AkAmbient 트리거 비활성화

- **Inspector 설정**:
  - AkAmbient 컴포넌트의 **Trigger On: None**으로 설정
  - 이렇게 하면 AkAmbient는 Event 정보만 저장하고 자동 재생하지 않음
- **스크립트에서 처리**:
  ```csharp
  akAmbient.enabled = false; // 컴포넌트만 비활성화
  ```

### AkAmbient의 역할 변화

- **Before**: 자동으로 Event를 재생하는 컴포넌트
- **After**: Event 정보를 저장하는 컨테이너 역할
- **장점**: 스크립트에서 재생 타이밍과 콜백을 완전히 제어 가능

## 3. 자동 비활성화 컴포넌트 만들기

### 전체 구조

```
[RequireComponent(typeof(AkAmbient))]
    ↓
Awake: AkAmbient 참조 저장
    ↓
OnEnable: 활성화 시 소리 재생 + 콜백 등록
    ↓
소리 재생 중...
    ↓
OnSoundFinished: 콜백 실행 → GameObject 비활성화
    ↓
OnDisable: 혹시 모를 재생 중 소리 정리
```

### RequireComponent 속성

```csharp
[RequireComponent(typeof(AkAmbient))]
```

- **기능**: 이 스크립트를 추가하면 AkAmbient가 자동으로 함께 추가됨
- **장점**:
  - 필수 컴포넌트 누락 방지
  - 실수로 AkAmbient 삭제 시 경고
  - 의존성 명확화
  - 자동 추가WwiseAutoDeactivate 추가 시 AkAmbient 자동 추가
  - 삭제 방지AkAmbient 함부로 못 지움
  - 안전 보장GetComponent 결과가 절대 null 아님

### 변수 선언부

```csharp
private AkAmbient akAmbient;  // AkAmbient 참조
private uint playingID;       // 재생 ID 저장
```

- **akAmbient**: GetComponent로 찾아온 AkAmbient를 저장
- **playingID**: 나중에 소리를 멈출 때 사용할 ID
  - 초기값 0 = 재생 안 함
  - PostEvent가 돌려주는 값 저장

### 안전성 체크

```csharp
if (akAmbient == null || akAmbient.data == null)
{
    Debug.LogWarning("설정 안 됨");
    return; // 함수 종료
}
```

- **첫 번째 체크**: AkAmbient 컴포넌트가 있는지
- **두 번째 체크**: Event가 할당되어 있는지
- **return**: 조건 불만족 시 함수 즉시 종료 (아래 코드 실행 안 함)

## 4. Unity 생명주기 함수 활용하기

### Awake()

- **호출 시점**: 오브젝트가 생성될 때 단 1번
- **용도**: 초기화 작업
- **예시**:
  ```csharp
  akAmbient = GetComponent<AkAmbient>();
  ```
- **특징**:
  - 비활성 상태여도 실행됨
  - Start()보다 먼저 실행
  - 주로 내부 참조 설정에 사용

### OnEnable()

- **호출 시점**: GameObject가 활성화될 때마다
- **호출 횟수**: SetActive(true) 할 때마다 반복 실행
- **용도**: 활성화 시 수행할 작업
- **예시**:
  ```csharp
  void OnEnable() {    PlayWithCallback(); // 소리 재생}
  ```
- **활용**:
  - 오브젝트 풀링 패턴에 적합
  - 재사용 가능한 이벤트에 유용

### OnDisable()

- **호출 시점**: GameObject가 비활성화될 때
- **용도**: 정리 작업 (Clean up)
- **예시**:
  ```csharp
  void OnDisable() {    AkUnitySoundEngine.StopPlayingID(playingID);    playingID = 0;}
  ```
- **중요성**:
  - 메모리 누수 방지
  - 불필요한 소리 재생 중단
  - 다음 활성화를 위한 초기화

### 생명주기 순서

```
오브젝트 생성
    ↓
Awake() - 1회 실행
    ↓
OnEnable() - 활성화될 때마다
    ↓
(게임 진행...)
    ↓
OnDisable() - 비활성화될 때마다
    ↓
OnDestroy() - 파괴될 때 1회
```

## 5. 콜백 함수 작성하기

### 콜백 함수 시그니처

```csharp
void OnSoundFinished(object cookie, AkCallbackType type, AkCallbackInfo info)
```

### 매개변수 설명:

1. **object cookie**:
   - PostEvent 호출 시 전달한 추가 데이터
   - null 전달 시 사용 안 함
   - 여러 소리에 같은 콜백 사용 시 구분용
2. **AkCallbackType type**:
   - 어떤 이벤트가 발생했는지 (AK_EndOfEvent, AK_Duration 등)
   - 여러 콜백 타입 등록 시 구분 필요
3. **AkCallbackInfo info**:
   - 상세 정보 (재생 시간, 오브젝트 등)
   - 필요 시 타입 캐스팅해서 사용

### 타입 확인의 중요성

```csharp
if (type == AkCallbackType.AK_EndOfEvent)
{
    // 처리
}
```

- **이유**: 하나의 콜백에 여러 타입 등록 가능
- **예시**: `AK_EndOfEvent | AK_Duration` (비트 OR 연산)
- **안전성**: 원하는 타입일 때만 동작하도록 필터링

### 주요 변경점

1. **클래스 이름 변경**:


   ```csharp
   // ❌ 구버전

   ```

- Wwise 버전 확인: 프로젝트에 맞는 API 사용

## 💡 핵심 정리

1. **콜백 = 나중에 자동 호출되는 함수**
2. **AK_EndOfEvent = 소리 끝남 감지**
3. **uint = 0 이상 양수만 (ID용)**
4. **OnEnable/OnDisable = 활성화/비활성화 시점**
5. **AkAmbient Trigger Off = 중복 재생 방지**
6. **Wwise 2024 = AkUnitySoundEngine 사용**

이 시스템을 사용하면 소리가 재생되는 모든 오브젝트를 효율적으로 관리할 수 있습니다! 🎵

## 방법 1: AkAmbient 비활성화 + 직접 PostEvent (추천)

```csharp
using UnityEngine;

/// <summary>
/// Wwise Event 재생 후 자동으로 GameObject를 비활성화하는 컴포넌트
/// AkAmbient가 있는 GameObject에 추가하세요
/// </summary>
[RequireComponent(typeof(AkAmbient))]
public class WwiseAutoDeactivate : MonoBehaviour
{
    // === 변수 선언 ===
    private AkAmbient akAmbient;  // AkAmbient 컴포넌트를 저장할 변수
    private uint playingID;       // 재생 중인 소리의 ID 번호 (0 = 재생 안 함)

    // === Unity 생명주기 함수들 ===

    /// <summary>
    /// 오브젝트가 생성될 때 딱 한 번 실행됩니다
    /// </summary>
    void Awake()
    {
        // 같은 오브젝트에 붙어있는 AkAmbient 컴포넌트를 찾아서 저장
        akAmbient = GetComponent<AkAmbient>();
    }

    /// <summary>
    /// 이 오브젝트가 활성화될 때마다 실행됩니다
    /// (SetActive(true)를 하면 실행됨)
    /// </summary>
    void OnEnable()
    {
        // 활성화되자마자 소리 재생!
        PlayWithCallback();
    }

    /// <summary>
    /// Wwise 소리를 재생하고, 끝나면 알림받을 준비를 합니다
    /// </summary>
    void PlayWithCallback()
    {
        // 안전 체크: AkAmbient나 Event가 없으면 경고 메시지만 띄우고 종료
        if (akAmbient == null || akAmbient.data == null)
        {
            Debug.LogWarning($"{gameObject.name}: AkAmbient 또는 Event가 설정되지 않았습니다.");
            return;  // 여기서 함수 종료 (아래 코드 실행 안 함)
        }

        // === 여기가 핵심! ===
        // Wwise에게 "소리 재생해줘!"라고 요청하는 부분
        // ⭐ Wwise 2024부터는 AkUnitySoundEngine 사용
        playingID = AkUnitySoundEngine.PostEvent(
            // 1번째 인자: 어떤 소리를 재생할지 (Event 이름)
            // ⭐ Wwise 2024부터는 .Name으로 직접 접근
            akAmbient.data.Name,

            // 2번째 인자: 어느 오브젝트에서 재생할지
            gameObject,

            // 3번째 인자: 언제 알림받을지 (소리가 끝날 때)
            (uint)AkCallbackType.AK_EndOfEvent,

            // 4번째 인자: 소리 끝나면 어느 함수를 실행할지
            OnSoundFinished,

            // 5번째 인자: 추가 데이터 (지금은 안 씀)
            null
        );

        // PostEvent는 재생 ID를 돌려줘요 (나중에 이 소리를 멈출 때 사용)
    }

    /// <summary>
    /// 소리 재생이 끝났을 때 Wwise가 자동으로 이 함수를 호출해요
    /// (콜백 함수 = 나중에 자동으로 불려지는 함수)
    /// </summary>
    void OnSoundFinished(object cookie, AkCallbackType type, AkCallbackInfo info)
    {
        // 진짜로 "소리 끝남" 이벤트인지 확인
        if (type == AkCallbackType.AK_EndOfEvent)
        {
            // 로그 출력 (디버깅용)
            Debug.Log($"✅ {gameObject.name} 소리 재생 완료 - 비활성화");

            // 이 오브젝트를 비활성화 (꺼버림)
            gameObject.SetActive(false);
        }
    }

    /// <summary>
    /// 이 오브젝트가 비활성화될 때 실행됩니다
    /// (SetActive(false)를 하거나, 위에서 자동으로 꺼질 때)
    /// </summary>
    void OnDisable()
    {
        // 혹시 소리가 재생 중이면 멈춰야 해요
        // (playingID가 0이 아니면 = 재생 중이면)
        if (playingID != 0)
        {
            // ⭐ Wwise 2024부터는 AkUnitySoundEngine 사용
            // Wwise에게 "이 ID의 소리 멈춰!"라고 명령
            AkUnitySoundEngine.StopPlayingID(playingID);

            // playingID를 0으로 초기화 (더 이상 재생 안 함을 표시)
            playingID = 0;
        }
    }
}
```

**설정:**

- AkAmbient: Trigger On을 **"None"**으로 설정 (Inspector에서)
- 또는 스크립트가 자동으로 비활성화시킴

## 방법 2: AkAmbient의 Playing ID 가져오기 (더 깔끔)

```csharp
using UnityEngine;
using System.Collections;

/// <summary>
/// AkAmbient가 재생한 소리를 감지해서 끝나면 자동 비활성화
/// </summary>
[RequireComponent(typeof(AkAmbient))]
public class WwiseAutoDeactivate : MonoBehaviour
{
    private AkAmbient akAmbient;

    void Awake()
    {
        akAmbient = GetComponent<AkAmbient>();
    }

    void OnEnable()
    {
        // AkAmbient가 재생할 시간을 줌
        StartCoroutine(WaitAndRegisterCallback());
    }

    IEnumerator WaitAndRegisterCallback()
    {
        // 1프레임 대기 (AkAmbient가 재생하도록)
        yield return null;

        if (akAmbient == null || akAmbient.data == null)
        {
            Debug.LogWarning($"{gameObject.name}: AkAmbient 또는 Event가 설정되지 않았습니다.");
            yield break;
        }

        // AkAmbient가 이미 재생했으므로, 우리는 콜백만 등록
        // (새로 재생하지 않고 기존 재생에 콜백 추가)
        uint playingID = AkUnitySoundEngine.GetPlayingID(gameObject);

        if (playingID != AkSoundEngine.AK_INVALID_PLAYING_ID)
        {
            // 기존 재생 중인 소리에 콜백 등록
            AkUnitySoundEngine.RegisterGameObj(gameObject);
        }
        else
        {
            // 재생이 안 됐으면 우리가 직접 재생
            playingID = AkUnitySoundEngine.PostEvent(
                akAmbient.data.Name,
                gameObject,
                (uint)AkCallbackType.AK_EndOfEvent,
                OnSoundFinished,
                null
            );
        }
    }

    void OnSoundFinished(object cookie, AkCallbackType type, AkCallbackInfo info)
    {
        if (type == AkCallbackType.AK_EndOfEvent)
        {
            Debug.Log($"✅ {gameObject.name} 소리 재생 완료 - 비활성화");
            gameObject.SetActive(false);
        }
    }
}
```

## 🎯 가장 간단한 해결책 (추천):

**Inspector 설정만으로 해결:**

```
각 소리 오브젝트에서:
1. AkAmbient 컴포넌트
   └─ Trigger On: "None" ⭐ (자동 재생 끄기)

2. WwiseAutoDeactivate 스크립트 추가
```

**이렇게 하면:**

- AkAmbient는 Event 정보만 저장 (재생 안 함)
- WwiseAutoDeactivate가 직접 재생 (1번만)
- 콜백으로 자동 비활성화 ✅
