## baseUrl 만들어주기

```python
천번째로 baseUrl 을 만들어준다

원하는 주소로 들어가서 검색을 하고 검색어 쿼리 부분을 찾아준다

https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query=joris+de+man+

내가 검색한 부분은 joris+de+man+ 부분이다
```

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380929/notion-blog/_/_/_/_1_/Untitled.png)

```python
import requests
from bs4 import BeautifulSoup

baseUrl = "https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query="

keyword = input("검색어를 입력하세요 : ")

url = baseUrl + keyword;

print(url)

headers = {
    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

req = requests.get(url, headers=headers);

html = req.text;

soup = BeautifulSoup(html, "html.parser");
```

```python
baseUrl 에 쿼리 부분에 input 으로 입력을 받아서 넣도록 해준다

그리고 완성된 url 을 출력하고 클릭해보면 원하는 검색 결과창으로 이동된다.
```

# 형식 리스트로 변환하기

```python
현재 형식을 list 로 바꿔지는지 확인하고 반복문을 사용하려고 한다

이떄 list() 함수를 사용한다

list() 함수는 다양한 객체를 리스트로 변환하는 함수. list() 함수를 사용하여 문자열, 튜플, 집합 등의 객체를 리스트로 변환할 수 있다.

<class 'bs4.element.ResultSet'> 가 list 형식으로 변환이 된다면 반복문을 사용 가능하다는 것이다
```

```python
req = requests.get(url, headers=headers);

html = req.text;

soup = BeautifulSoup(html, "html.parser");

# title_link

result = soup.select(".title_link")

# print(result)

# print("타입은??????????????",type(result))

print(list(result)) # 가져온 데이터를 리스트로 변환 성공적으로 변환된다
```

# zip 을 활용해서 출력하기 ( 비추천 )

```python
zip 함수를 활용해서 주소와 유저명 두개를 함께 출력한다

두개의 이터레이터 에서 같은 인덱스를 가진걸 묶어서 (튜플로) 함께 출력하는것이다
```

```python
import requests
from bs4 import BeautifulSoup

baseUrl = "https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query="

keyword = input("검색어를 입력하세요 : ")

url = baseUrl + keyword;

# print(url)

headers = {
    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

req = requests.get(url, headers=headers);

html = req.text;

soup = BeautifulSoup(html, "html.parser");

# title_link

results = soup.select(".title_link")

name = soup.select(".user_info")

for result, user_info in zip (results,name):
    print("주소",result['href'])
    print("유저명",user_info.text)
    # print(result.text)
    print("")
```

```python
zip() 함수는 두 개 이상의 순차적인(iterable) 객체를 병렬로 묶어주는 역할을 한다.

각각의 객체에서 동일한 위치에 있는 요소들끼리 튜플로 묶어서 새로운 이터레이터(iterator)를 만들어 반환

numbers = [1, 2, 3]
letters = ['a', 'b', 'c']

zipped = zip(numbers, letters)

for item in zipped:
    print(item)


간단한 예제로 설명하자면, 예를 들어 zip() 함수를 사용하여 두 개의 리스트를 묶으면 각 리스트에서

동일한 인덱스에 있는 요소들을 순서대로 묶어서 튜플로 반환
```

# 상위 클래스를 선택해서 출력하기

```python
import requests
from bs4 import BeautifulSoup

baseUrl = "https://search.naver.com/search.naver?where=nexearch&sm=top_hty&fbm=0&ie=utf8&query="

keyword = input("검색어를 입력하세요 : ")

url = baseUrl + keyword;

# print(url)

headers = {
    "User-Agent" : "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

req = requests.get(url, headers=headers);

html = req.text;

soup = BeautifulSoup(html, "html.parser");

total_area = soup.select(".view_wrap")

timeline_area = soup.select(".timeline_area")

# 만약 어떤 페이지에는 있는데 어떤 페이지에는 없다면 두개를 이렇게 찾게 해준다
if total_area:
    areas = total_area
elif timeline_area:
    areas = timeline_area
else:
    print("확인요망")

for area in areas:
    title = area.select_one(".title_link")
    name = area.select_one(".user_info")
    print(title.text)
    print(name.text)
```

```python
상위 클래스를 선택하여 그 클래스에 하위 내용들을 함께 출력한다

이 방법이 더 쉽고 선호되며

추가적으로 만약 이 페이지에는 있지만 다른 페이지에는 이름이 다르게 클래스가 되어 있을 수 있는데

이럴때는 if 문을 사용해서 선택해서 출력하도록 한다
```
