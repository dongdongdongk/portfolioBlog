## 1. Actor-Mixer 개념 이해하기

### 🔹 Actor-Mixer란?

- **Wwise의 오디오 구조를 관리하는 상위 컨테이너 오브젝트**입니다.
- 여러 개의 사운드 오브젝트(Sound Object)나 컨테이너를 **논리적/기능적으로 묶어서 관리**할 수 있습니다.

### 🔹 주요 기능

1. **공통 속성 상속 (Inheritance)**
   - Actor-Mixer에 설정한 값(예: Volume, Bus Routing, Effect Chain 등)은
     하위에 포함된 모든 사운드 오브젝트에 **자동으로 적용**됩니다.
   - 즉, 한 번 설정으로 수십 개의 사운드에 동일한 효과를 부여할 수 있습니다.
2. **효율적인 수정 및 유지보수**
   - 개별 사운드마다 일일이 조정하지 않아도 되므로 **작업 시간 단축**.
   - 대규모 프로젝트에서 **일관된 사운드 톤과 밸런스 유지**에 유리합니다.
3. **조직적인 구조 정리**
   - 사운드를 종류, 상황, 레이어별로 그룹화하여
     프로젝트의 가독성과 관리 효율을 높입니다.

## 2. Actor-Mixer 하위에 사운드 그룹화하기

### 🔹 기본 구조 예시

```
► SFX (Actor-Mixer)
   ├─ Footsteps (Actor-Mixer)
   │   ├─ Footstep_Grass
   │   ├─ Footstep_Stone
   │   └─ Footstep_Wood
   ├─ UI (Actor-Mixer)
   │   ├─ Button_Click
   │   └─ Menu_Open
   └─ Environment (Actor-Mixer)
       ├─ Wind
       ├─ Rain
       └─ Water
```

### 🔹 그룹화 방법

1. **Project Explorer → Audio 탭**에서 Actor-Mixer Hierarchy 확인
2. **Actor-Mixer 생성**
   - 우클릭 → `New Child → Actor-Mixer` 선택
   - 이름 지정 (예: `Footsteps`, `Weapons`, `UI_Sounds`)
3. **사운드 오브젝트를 해당 Actor-Mixer로 드래그**
   - 하위에 포함시키면 자동으로 **그룹화 완료**

### 🔹 그룹화의 장점

- 상위 Actor-Mixer에서 **볼륨, 필터, 버스 라우팅** 등을 조정하면
  모든 하위 사운드에 동일하게 적용됩니다.
- 예를 들어, `Environment` 그룹의 볼륨을 3dB 낮추면
  그 아래의 Wind, Rain, Water 사운드 모두 동일하게 감소합니다.
- 따라서 **효율적인 전체 밸런스 관리**가 가능합니다.

## 3. 사운드 색상 지정하기

### 🔹 색상 지정의 목적

- Wwise 내에서 사운드가 많아질수록 시각적으로 구분이 어려워집니다.
- **색상(Color Tag)** 기능을 이용하면
  사운드 종류별로 빠르게 식별할 수 있습니다.

### 🔹 색상 지정 방법

1. **Actor-Mixer 또는 Sound Object 선택**
2. **Property Editor** 상단의 **색상 아이콘(Color Box)** 클릭
3. **원하는 색상 선택** (예:
   - BGM → 파란색
   - UI → 주황색
   - SFX → 초록색
   - Voice → 보라색 등)
4. 선택한 색상은 **Project Explorer, Mixer, 기타 모든 뷰**에서 동일하게 표시됩니다.

### 🔹 사용 예시

| 사운드 종류  | 색상 예시 | 설명                    |
| ------------ | --------- | ----------------------- |
| BGM (배경음) | 파란색    | 안정감 있고 구분 쉬움   |
| SFX (효과음) | 초록색    | 다양한 환경 효과 구분   |
| UI 사운드    | 주황색    | 인터페이스 관련 강조    |
| Voice        | 보라색    | 대사 오디오 명확히 표시 |

> 💡 색상은 단순한 장식이 아니라, 대규모 프로젝트의 시각적 정리와 탐색 속도 향상을 위한 실무적 관리 도구입니다.

## 1. Actor-Mixer 개념 이해하기

- **Actor-Mixer란?**
  - **Wwise의 핵심 오디오 관리 단위**로, 여러 사운드 오브젝트(예: 이벤트 사운드, 루프, 효과음 등)를 하나로 묶는 **계층적 컨테이너(Container)**.
  - 즉, **비슷한 성격의 사운드**를 그룹화하여 한 번에 속성(볼륨, 피치, RTPC 등)을 조정할 수 있는 구조입니다.
- **Actor-Mixer Hierarchy**
  - Wwise의 **Project Explorer → Audio 탭**에서 볼 수 있는 오디오의 계층 구조(Tree View).
  - 여기서 **Actor-Mixer, Sound SFX, Blend Container** 등이 계층적으로 정리됩니다.
  - 모든 오디오 자산의 기본 부모는 **Default Work Unit**입니다.

> 🎯 개념 포인트:
>
> - “Actor-Mixer는 **폴더이자 믹싱 단위**이다.”
> - “Actor-Mixer Hierarchy는 **오디오의 구조적 설계도**이다.”

## 2. 프로젝트 열고 오브젝트 구조 확인하기

1. **Wwise 실행 → 프로젝트 열기**
   - 강의에서는 **Module 11** 프로젝트를 사용합니다.
   - 이 프로젝트에는 여러 캐릭터 및 아이템 관련 사운드가 미리 준비되어 있습니다.
2. **Project Explorer → Audio 탭 선택**
   - 위치:
     `Project Explorer → Audio → Actor-Mixer Hierarchy → Default Work Unit`
3. **Default Work Unit 확장하기**
   - 현재 프로젝트에 포함된 모든 사운드 오브젝트를 볼 수 있습니다.
   - 예시로 “Heartbeat”, “Defeated”, “Jump”, “Pain” 등의 사운드가 존재합니다.

> 💡 참고:
>
> - Work Unit은 **Wwise의 논리적 파일 단위**로, 여러 Actor-Mixer나 사운드를 저장하는 컨테이너입니다.
> - Default Work Unit은 프로젝트 생성 시 자동으로 만들어집니다.

## 3. Items Actor-Mixer 생성 및 정리하기

### 🎯 목표

Wwizard(게임 내 캐릭터나 시스템)가 찾을 수 있는 **“아이템 관련 사운드들”**을 하나의 Actor-Mixer로 정리합니다.

---

### 단계별 절차

1. **Default Work Unit 선택**
   - Actor-Mixer Hierarchy 내에서 Default Work Unit 클릭.
2. **새로운 Actor-Mixer 생성**
   - 상단의 “Create new 'Actor-Mixer'” 버튼 클릭
   - 또는 마우스 우클릭 → “New Child” → “Actor-Mixer”
3. **이름 지정**
   - 새로 생성된 Actor-Mixer의 이름을 `Items`로 변경합니다.
4. **아이템 관련 사운드 이동**
   - `Heartbeat` 아래의 모든 오브젝트 선택 (즉, 아이템 관련 사운드들)
   - 선택된 오브젝트들을 **드래그하여 Items Actor-Mixer로 이동**

> ✅ 결과:
>
> - “Items” Actor-Mixer 아래에 관련 사운드가 모두 포함되어
>   오디오 트리 구조가 정돈됨.

> 💡 개념 요약
>
> - 이렇게 그룹화하면 “아이템 관련 사운드만 따로 관리” 가능.
> - 나중에 볼륨이나 필터 등을 한 번에 적용할 수 있음.

## 4. Main Character Actor-Mixer 생성하기

### 🎯 목표

이번에는 **주요 캐릭터(Main Character)** 와 관련된 사운드를 한 Actor-Mixer로 묶습니다.

이번에는 다른 방법(“New Parent”)으로 진행합니다.

---

### 단계별 절차

1. **다음 오브젝트들을 선택:**
   - `Defeated`, `Jump`, `Pain`, `Footsteps`, `Body_Impact`, `Heartbeat`
2. **New Parent 생성**
   - 선택된 오브젝트 중 하나를 **우클릭**
   - 메뉴에서 **New Parent → Actor-Mixer** 선택
3. **새 Actor-Mixer 이름 변경**
   - 새로 생성된 Actor-Mixer의 이름을 **Main Character**로 변경

> ✅ 결과:
>
> - “Main Character”라는 상위 Actor-Mixer가 자동 생성되며,
>   선택한 오브젝트들이 그 아래로 이동됩니다.

> 💡 개념 요약
>
> - “New Parent” 기능은 **기존 오브젝트들을 자동으로 새로운 상위 그룹으로 묶는** 기능입니다.
> - 수동으로 이동할 필요 없이 **즉시 계층 구조를 정리**할 수 있습니다.

## 5. Actor-Mixer 그룹화의 장점

| 구분                     | 설명                                                                      |
| ------------------------ | ------------------------------------------------------------------------- |
| 🎛 **일괄 제어**         | 한 Actor-Mixer 아래 모든 오브젝트의 볼륨, 피치, 이펙트를 동시에 조절 가능 |
| 🧭 **조직화**            | 사운드를 논리적으로 묶어 프로젝트 구조를 명확히 정리                      |
| 🔍 **검색 및 접근 용이** | 관련 사운드를 빠르게 찾고 수정 가능                                       |
| 🔁 **유지보수성 향상**   | 이후 변경사항(예: Volume Curve, RTPC) 적용 시 편리                        |
| 🧩 **믹싱 효율 향상**    | 그룹별로 믹싱 밸런스를 손쉽게 조절 가능                                   |

> 📘 핵심 정리
>
> - Actor-Mixer는 단순한 폴더가 아니라, **믹싱 단위로서 기능하는 오디오 컨테이너**.
> - 프로젝트 규모가 커질수록, **논리적 그룹화는 필수적인 관리 기법**.

## 1. 오브젝트 색상 지정의 개념 이해하기

- **Wwise에서의 색상 지정 목적**
  오브젝트의 색상을 지정하는 것은 **단순한 꾸미기 기능이 아니라, 프로젝트 관리 도구**입니다.
  즉, **Actor-Mixer 그룹**이나 **Container**, **Event** 등의 오브젝트를 색상으로 구분함으로써
  “이 오브젝트가 어떤 역할을 하는지”를 **시각적으로 빠르게 파악**할 수 있습니다.
- **Actor-Mixer 그룹과 색상 관리의 관계**
  - Wwise에서는 **Actor-Mixer Hierarchy(액터 믹서 계층)** 구조를 사용하여 오디오 오브젝트를 논리적으로 그룹화합니다.
  - 그룹화된 구조의 **상위 노드(부모 오브젝트)**에 색상을 지정하면,
    해당 색상이 **모든 하위 오브젝트(자식 노드)**에 자동으로 반영됩니다.
  - 이를 통해 **계층 전체의 성격을 색상으로 표현**할 수 있습니다.
    예를 들어, “몬스터 관련 사운드 그룹은 빨간색”, “주인공 관련 사운드 그룹은 보라색” 등으로 관리할 수 있습니다.

## 2. Actor-Mixer 그룹에 색상 지정하기

1. **Actor-Mixer 그룹 선택하기**
   - Wwise 프로젝트 트리에서 `Items Actor-Mixer`를 찾습니다.
   - 해당 그룹을 **마우스 오른쪽 버튼으로 클릭(Right Click)** 합니다.
2. **Set Color 명령 실행하기**
   - 우클릭 메뉴에서 **Set Color(색상 지정)** 항목을 선택합니다.
   - 그러면 **색상 선택 메뉴(Color Picker)** 창이 열립니다.
3. **색상 선택하기**
   - 색상 팔레트가 표시되며, 여러 개의 색상 사각형이 나타납니다.
   - 이 중에서 **초록색 사각형(Green Square)** 을 클릭하여 선택합니다.
     > 💡 Tip: 이 색상은 단순히 보기 좋게 만드는 것이 아니라,
     >
     > 프로젝트 내에서 이 그룹이 “Items 관련 사운드”임을 직관적으로 표현하기 위한 시각적 약속입니다.

## 3. 하위 오브젝트에 색상 자동 적용 확인하기

1. **Items Actor-Mixer 그룹 확장하기**
   - 그룹 왼쪽의 ▶ 버튼을 눌러 **하위 오브젝트를 펼칩니다.**
2. **색상 적용 확인하기**
   - 상위 오브젝트(Items Actor-Mixer)에 지정한 초록색이
     **모든 하위 오브젝트에도 자동으로 동일하게 적용**된 것을 확인할 수 있습니다.
   - 이 기능 덕분에 **계층 전체가 하나의 색상으로 통일**되어,
     시각적으로 “이 그룹이 한 범주에 속함”을 명확히 구분할 수 있습니다.

## 4. 다른 Actor-Mixer 그룹 색상 설정하기

같은 방식으로 나머지 그룹에도 각각 색상을 지정합니다.

| 그룹 이름          | 지정 색상 | 의미                  |
| ------------------ | --------- | --------------------- |
| **Magic**          | 🔵 파란색 | 마법 관련 사운드      |
| **Main Character** | 🟣 보라색 | 주인공 관련 사운드    |
| **Monster**        | 🔴 빨간색 | 적/몬스터 관련 사운드 |

1. 각 Actor-Mixer를 차례로 우클릭 → **Set Color** 선택
2. 위 표의 색상에 맞춰 지정
3. 모든 색상이 설정되면, **Actor-Mixer를 모두 접기(Collapse)** 하여

   색상만으로 각 그룹이 시각적으로 구분되는 것을 확인합니다.

## 🎯 이번 단원 핵심 정리

- **배운 내용**
  1. Actor-Mixer 그룹 단위로 오브젝트를 논리적으로 그룹화했다.
  2. 색상 지정 기능을 이용해 그룹별 역할을 시각적으로 구분했다.
  3. 상위 그룹의 색상이 하위 오브젝트에 자동 적용되는 구조를 확인했다.
- **학습 효과**
  프로젝트 구조를 **시각적으로 체계화**하여
  복잡한 오디오 프로젝트에서도 **빠른 인식과 효율적 관리**가 가능해졌습니다.
