```sql
- 한번의 쿼리문으로 여러개의 테이블의 컬럼들을 한번에 조회
- 여러개의 테이블을 하나로 합쳐서 가상의 테이블로 사용
- Oracle 전용, ANSI 표준

1. 조인 연산자에 따른 구분 (문법이 아님)               : EQUI JOIN(=), NON EQUI JOIN (>. <), CARTESIAN JOIN(CROSS JOIN)
2. 조인할 테이블에 따른 구분 (문법이 아님)             : SELF JOIN2
3. 조인 Data가 있는 테이블 따른 구분  (문법이 아님)    : INNER JOIN, OUTER JOIN(Left, Right, Full, SEMI JOIN,

ANSI JOIN 문법

SELECT
FROM 테이블명 A
		 {INNER, LEFT || RIGHT || FULL OUTER, NATURAL} JOIN  --- {} 쓰는거 아님
		 테이블명 B
		 ON (A.컬럼명 = B.컬럼명) || USING(컬럼명)             ----- 조인 조건
		 {INNER, LEFT || RIGHT || FULL OUTER, NATURAL} JOIN  --- {} 쓰는거 아님
		 테이블명 C
		 ON (A.컬럼명 = B.컬럼명) || USING(컬럼명)             ----- 조인 조건

WHERE...
GROUP BY...
HAVING ...
ORDER BY ...

- SELECT의 컬럼명을 나열할 때, 같은 컬럼을 나열 할 때는 테이블명을 명시 해야 함

A. **조인 연산자 (조건)으로 구분**

1. Equi Join
	- 조인하는 두 테이블에서 공통적으로 존재하는 컬럼의 값이 일치하는 행을 연결
	- ON 조건에 ' = ' 를 사용하는 경우

2. NON Equi Join
	- 공통적 컬럼없이 범위( >,< )를 사용해서 조인할 때
	- ON 조건에 ' > or < ' 를 사용하는 경우

	SELECT E.EMPLOYEE_ID, J.JOB_TITLE
  FROM employees E
     join
     JOBS J
    on E.SALARY BETWEEN 8200 and 16000;

3. CARTESIAN JOIN(CROSS JOIN)
	- 조인 조건이 없을 때 또는 잘못 적용 했을 때
	- ON 조건이 없는 경우(안쓴 경우)

**B. 조인 Data가 있는 테이블 따른 구분

1. Inner Join**
	 - 조인 조건을 만족하는 컬럼 기준 조회
	 - 테이블간의 공통 컬럼의 값이 같은 것을 연결하는 조인 방법
	 - NULL은 조회결과에서 제외

2. Natural Join
	- Inner Join과 비슷
	- 조인 조건의 컬럼명 같을 경우 사용하는 JOIN
	- 조인 조건을 명시하지 않음
	- 공통 컬럼명이 조인 조건이 되었을 경우 SELECT에 사용 할 때는 테이블명을 명시 하지 않음

3. Self Join
	- 같은 테이블을 JOIN
	- A 테이블과 A 테이블을 JOIN
	- 별칭을 이용해서 다른 테이블로 인식
	- SELF 키워드는 없음
	- 일반적인 JOIN 키워드 사용

4. Outer Join
	- 조인 조건을 만족하지 않는 경우에 조회가 X
	- 조인 조건을 만족하지 않더라도 조회 하고자 하는 경우
	- 데이터가 있는 방향을 지정
	- 테이블이 선언된 순서
	- 왼쪽에 데이터가 있는 경우   : LEFT
	- 오른쪽에 데이터가 있는 경우 : RIGHT
	- 두 방향 전부               : FULL
	****- 단, FULL Join은  ANSI 표준 문법에만 존재 함
		Oracle 문법에는 X

**C. Join 조건**
	1. ON
		- 조인 조건 명시
		- () 생략 가능
		- 컬럼명이 다를 수 도 있음
		- AND 연산자를 사용가능

	2. USING
		- 조인 조건의 컬럼명이 같을 경우 ON 대신 사용
		- USING(조인조건으로 사용할 컬럼명)
		- 테이블은 명시하지 않음  : USING(D.DEPARTMENT_ID) X, USING(DEPARTMENT_ID) O
		- 공통 컬럼명이 조인 조건이 되었을 경우 SELECT에 사용 할 때는 테이블명을 명시 하지 않음
		- AND 연산자 사용 불가능
```
