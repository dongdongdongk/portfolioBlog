# AJAX

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381362/notion-blog/_/The_Web_Developer_2022/JavaScript/AJAX_API/Untitled_1.png)

## **AJAX의 개요**

```jsx
* AJAX는 비동기적으로 서버와 데이터를 교환하여 페이지를 새로 고치지 않고 동적으로 데이터를 불러오는 웹 개발 기술

* XMLHttpRequest 객체를 사용하여 서버에 비동기 요청을 보내고, 서버는 데이터를 응답
```

## **데이터 요청의 예시**

```jsx
* Reddit의 글 불러오기와 Pitchfork에서의 실시간 검색은 AJAX를 사용한 예시

* 사용자가 페이지를 새로 고치지 않아도 서버에 데이터를 요청하고, 동적으로 업데이트된 결과를 화면에 표시
```

## **API와 데이터 요청**

```jsx
* API는 Application Programming Interface의 약자로, 서버와 클라이언트 간의 통신을 위한 인터페이스를 제공

* 데이터 요청을 통해 서버로부터 필요한 정보를 받아오며, 이를 활용하여 동적인 웹 페이지를 생성할 수 있다.
```

## **XML 및 JSON**

```jsx
* AJAX 요청으로 주고받는 데이터 형식으로는 주로 XML 또는 JSON이 사용됨

* JSON은 더 간결하고 가독성이 좋아서 현대적인 웹 개발에서 더 많이 사용된다
```

# **API(애플리케이션 프로그래밍 인터페이스) 개요**

```jsx
**정의**: API는 소프트웨어 응용 프로그램 간의 상호 작용을 위한 인터페이스로,

서로 다른 프로그램들이 데이터를 교환하고 서비스를 공유할 수 있게 한다

**종류**: WebAPI는 주로 웹 기술과 HTTP 프로토콜을 사용하는 API를 의미
```

## **API의 중요성**

```jsx
**상호 운용성**: API를 통해 서로 다른 응용 프로그램이 효과적으로 통신할 수 있어 상호 운용성이 향상된다

**모듈화**: API를 사용하면 각각의 기능을 모듈화하여 독립적으로 개발하고 업데이트할 수 있다.
```

## **API의 구성 요소**

```jsx
**엔드포인트(Endpoint)**: API에서 특정 기능에 접근하기 위한 URL 또는 URI

**HTTP 메서드**: 주로 사용되는 메서드는 GET(데이터 조회), POST(데이터 전송), PUT(데이터 수정), DELETE(데이터 삭제) 등이 있다.

**요청(Request)과 응답(Response)**: 클라이언트가 서버에 보내는 요청과 서버가 클라이언트에게 보내는 응답은 데이터를 주고받는 주요 수단이다.
```

# API 응답 데이터의 포맷

## 포맷 개요

```jsx
**의미**: API가 데이터를 전송할 때 사용하는 포맷은 HTML, CSS, JavaScript보다 훨씬 경량하며,

		  오로지 데이터 자체를 제공하기 위한 목적으로 설계되었다.

**특징**: 스타일, 이벤트, 마크업 등이 없으며, 오직 순수한 데이터만을 포함한다
```

### **XML (eXtensible Markup Language)**

```jsx
**정의**: 확장성 있는 마크업 언어로, 초기에 많이 사용되었으나 현재는 JSON이 주로 사용된다.

**특징**: HTML과 유사한 태그 구조를 가지며, 데이터를 계층적으로 표현할 수 있다.
```

### **JSON (JavaScript Object Notation)**

```jsx
**정의**: JavaScript 객체 문법을 기반으로 하는 경량 데이터 교환 형식

**특징**: 키-값 쌍을 사용하며, 모든 키는 큰따옴표로 둘러싸여 있다.

			값으로 문자열, 숫자, 객체, 배열, 불리언, null 등을 허용한다.

			JavaScript 객체 구문과 유사하지만 일관된 데이터 형식을 갖는다.
```

## **JSON 변환 메서드**

### JSON.parse()

```jsx
JSON 형식의 문자열을 JavaScript 객체로 파싱한다 ( 응답을 사용하기 위해 )

예제: const parsedData = JSON.parse(data)
```

### JSON.stringify()

```jsx
JavaScript 객체를 JSON 형식의 문자열로 변환한다 ( 요청을 서버로 보내기 위해서 )

예제: const jsonString = JSON.stringify(obj);
```

```jsx
// API 응답 데이터(JSON 형식) 예시
const data = '{"ticker": {"price": 123.45}}'

// JSON.parse를 사용하여 JavaScript 객체로 변환
const parsedData = JSON.parse(data)

// 변환된 객체에서 정보 추출
const bitcoinPrice = parsedData.ticker.price
console.log(bitcoinPrice) // 123.45

// JavaScript 객체를 JSON 문자열로 변환
const dog = { name: 'Buddy', breed: 'Labrador', age: undefined }
const jsonString = JSON.stringify(dog)
console.log(jsonString)
// 출력: {"name":"Buddy","breed":"Labrador","age":null}
```

```jsx
**의미**: HTTP 동사는 클라이언트가 서버에게 어떤 동작을 수행해야 하는지를 나타낸다.

**예시 동사**: Get, Post, Put, Patch, Delete 등이 있으며,

Hoppscotch나 Postman과 같은 도구에서 이 동사들을 선택하여 다양한 요청을 생성할 수 있다.
```

### **Get 요청**

```jsx
**용도**: 정보를 가져오는 데 사용

**예시**: Cat Fact API의 /breeds 엔드포인트는 Get 요청만 지원하며, 해당 URL로 Get 요청을 보내면 정보를 가져올 수 있다.
```

### **Post 요청**

```jsx
**용도**: 데이터를 서버로 전송하여 저장하거나 영향을 미치는 데 사용

		  대부분의 API는 주로 Get 요청을 기반으로 하지만, 데이터를 전송할 때는 Post 요청을 사용
```

# HTTP Status Codes

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381365/notion-blog/_/The_Web_Developer_2022/JavaScript/AJAX_API/Untitled_3.png)

## **HTTP 상태 코드 개요**

```jsx
**의미**: HTTP 상태 코드는 서버가 클라이언트에게 응답할 때, 응답의 성공 또는 실패를 나타내는 숫자로 이루어진 코드이다

**예시 상태 코드**: 200은 성공적인 응답을 의미하며, 404는 찾을 수 없음, 500은 서버 내부 오류 등을 나타낸다
```

## **주요 상태 코드**

```jsx
**2로 시작하는 상태 코드 (성공)**:

200 OK: 요청이 성공적으로 처리되었음을 나타낸다. 가장 흔한 상태 코드 중 하나이다

201 Created: Post 요청이 성공적으로 생성되었음을 나타낸다.

**3으로 시작하는 상태 코드 (리디렉션)**:

301 Moved Permanently: 리소스가 영구적으로 새 위치로 이동되었음을 나타낸다. (리다이렉션 되었다는 이야기)

**4로 시작하는 상태 코드 (클라이언트 오류)**:

400 Bad Request: 클라이언트 요청이 잘못되었거나 부적절함을 나타낸다.

401 Unauthorized: 인증이 필요한 리소스에 접근 시 인증이 실패했음을 나타낸다.

404 Not Found: 요청한 리소스를 서버에서 찾을 수 없음을 나타낸다.

**5로 시작하는 상태 코드 (서버 오류)**:

500 Internal Server Error: 서버 측에서 오류가 발생하여 요청을 수행할 수 없음을 나타낸다
```

# Understanding Query Strings

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381366/notion-blog/_/The_Web_Developer_2022/JavaScript/AJAX_API/Untitled_4.png)

```jsx
쿼리 문자열(Query String)은 URL에 추가 정보를 전달하는 데 사용되는 일련의 문자들이다.

주로 웹 요청에서 서버로 데이터를 전송하거나 요청된 데이터를 필터링하는 데 활용된다

쿼리 문자열은 URL 끝에 물음표(?)로 시작하며, 그 뒤에 키-값 쌍이 이어진다.
```

```jsx
https://example.com/search?q=programming&lang=en
```

```jsx
이 URL에서 쿼리 문자열은 ?q=programming&lang=en 이다

이 중에서 q와 lang은 각각 키(Key)이고, programming과 en은 그에 대응하는 값(Value)이다.
```

## **주요 구성 요소**

```jsx
**키(Key)**: 쿼리 문자열에서 데이터를 식별하는 데 사용되는 이름 부분입니다. 예를 들어, q는 검색어를 나타내는 키이다

**값(Value)**: 각 키에 대응하는 실제 데이터 또는 정보를 나타낸다. 위의 예에서 programming은 검색어이며, en은 언어를 나타낸다.

**등호(=)**: 키와 값 사이를 연결하는데 사용되는 기호이다.

**앰퍼샌드(&)**: 여러 개의 키-값 쌍을 구분하는데 사용되는 기호이다. 위의 예에서 q=programming과 lang=en을 구분한다.
```

```jsx
이 경우 :id는 사용자의 고유한 식별자를 나타내는 변수이다.
```

# HTTP Headers

```jsx
HTTP 헤더는 HTTP 요청 및 응답에서 메타데이터를 전달하는 역할을 한다

간단하게 말하면, 헤더는 요청이나 응답의 부가적인 정보를 담고 있는 것이다. 개발자가 직접 설정하거나 읽을 수 있다.

HTTP 헤더는 크게 두 부분으로 나뉜다. 요청 헤더(Headers)와 응답 헤더(Headers)이다.
```

## **요청 헤더(Request Headers)**

```jsx
**User-Agent**: 클라이언트 정보를 식별하는데 사용되며, 어떤 브라우저나 디바이스를 사용하는지 등을 확인할 수 있다.

**Accept**: 클라이언트가 원하는 응답의 미디어 타입(예: HTML, JSON)을 지정한다.

**Authorization**: 보안 목적으로 사용되며, 서버에게 요청자의 인증 정보를 전달한다.

**Content-Type**: 요청 본문의 미디어 타입을 지정한다.
```

## **응답 헤더(Response Headers)**

```jsx
**Content-Type**: 서버가 보내는 데이터의 미디어 타입을 나타낸다.

**Server**: 서버의 소프트웨어 및 버전 정보를 제공한다.

**Set-Cookie**: 브라우저에게 쿠키를 저장하도록 지시하는 헤더이다.

**Location**: 리다이렉션 시 새로운 위치를 알려주는 헤더이다.
```

## 응답 객체의 본문은 자동으로 구문 분석되지 않는다

```jsx
fetch 함수로 요청을 보내면 반환되는 객체가 Response 객체이다.

이 객체에는 요청에 대한 여러 정보가 들어있는데, 그 중에서도 우리가 주로 다루는 것은 응답의 본문(body)이다.

일반적으로 서버는 응답할 데이터를 본문에 담아 클라이언트에게 전송한다.

그러나 fetch 함수는 이 데이터를 비동기적으로 처리하기 위해 Response 객체의 body 프로퍼티에 ReadableStream 객체를 제공한다.

ReadableStream은 데이터의 흐름을 나타내는 개념으로,

데이터를 효율적으로 처리하기 위한 방식 중 하나이다. 이 객체는 현재 시점에서 실제 데이터의 내용을 가지고 있지 않다.

대신, 데이터를 스트림으로 받아오는 방식을 제공한다.

그래서 Response 객체의 body 프로퍼티를 직접 확인하면 ReadableStream 객체가 반환되어,

이 시점에서는 아직 데이터가 완전히 로드되지 않았음을 의미한다.

**만약 실제 데이터를 확인하려면 ReadableStream에서 데이터를 읽어오는 작업을 해주어야 한다**.

이를 간편하게 처리하기 위해 json() 메서드나 text() 메서드 등을 사용한다.
```

```jsx
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script src="https://cdn.jsdelivr.net/npm/axios@1.1.2/dist/axios.min.js"></script>
```

```jsx
    <h1>TV Show Search</h1>
    <form id="searchForm">

    <script src="app.js"></script>
```

```jsx
const form = document.querySelector('#searchForm')
form.addEventListener('submit', async function (e) {
  e.preventDefault()
  // 입력한 값 저장
  const searchTerm = form.querySelector('input[name="query"]').value
  // config 를 만들어서 파라미터를 만들어서 axios 에 넣어줌
  const config = { params: { q: searchTerm, isFunny: 'colt' } }
  // 템플릿 리터럴 ` 를 사용
  const res = await axios.get(`https://api.tvmaze.com/search/shows`, config)
  makeImages(res.data)
  form.querySelector('input[name="query"]').value = ''
})

const makeImages = (shows) => {
  for (let result of shows) {
    if (result.show.image) {
      const img = document.createElement('IMG')
      img.src = result.show.image.medium
      document.body.append(img)
    }
  }
}
```

```jsx
* e.preventDefault(); 를 이용해서 form 을 submit 했을때 새로고침 되는걸 방지한다

* 템플릿 리터럴을 사용해서 ${} 로 변수를 넣어준다 ( 뒤에 수정해서 없어졌다 )

* config 로 파라미터 여러개를 axios 에 넣어 요청을 보낸다
```
