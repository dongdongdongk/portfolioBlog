# JSP

```sql
**JSP** :

서블릿은 자바 코드안에 html 을 쓰는것 (초창기 사용)

JSP는 반대로 html 안에 자바 코드를 넣는것

직접적으로 out.print(); 를 하는것이 아니라 서블릿으로 작성해 놓으면 자동으로

서블릿으로 변환(컴파일)(결국jsp도 서블릿)

*jsp 파일을 생성해서 만듬

*html 의 형태에 위의 코드가 추가
```
