```jsx
계단식으로 작성된 CSS(SCSS) 구조는 중첩이 과도해지는 문제를 일으킬 수 있습니다.

이는 코드의 가독성을 떨어뜨리고 유지보수를 어렵게 만듭니다.

이런 문제를 해결하기 위해 CSS 구조 및 중첩 규칙을 적용하는 것이 좋습니다. 아래는 해결 방법과 적용할 수 있는 규칙들입니다:
```

# { 1. **BEM(Block Element Modifier) 방법론 사용 }**

## 기존 구조:

```jsx
.offer {
   .secContainer {
      .mainContent {
         .singleOffer {
            .destImage {
               .discount {
                   ...
               }
            }
         }
      }
   }
}
```

## BEM 구조로 변경:

```jsx
.offer {
   &__sec-container {
      &__main-content {
         &__single-offer {
            &__dest-image {
               &__discount {
                   ...
               }
            }
         }
      }
   }
}
```

```jsx
이렇게 작성하면 HTML 클래스가 명확해지며 중첩이 줄어듭니다:
```

```jsx
<div class="offer__sec-container">
  <div class="offer__main-content">
    <div class="offer__single-offer">
      <div class="offer__dest-image">
        <span class="offer__discount">30% Off</span>
      </div>
    </div>
  </div>
</div>
```

# { 2. **중첩 제한 규칙 }**

```jsx
중첩을 3단계 이내로 제한하는 것이 좋습니다.

너무 깊은 중첩은 성능에 영향을 미칠 수 있고, CSS 우선순위 문제를 일으킬 수 있습니다.
```

```jsx
// 중첩 3단계 이내로 제한
.offer {
   .mainContent {
      .singleOffer {
         // 여기까지가 최대 중첩
      }
   }
}
```

# { 3. **공통 스타일 분리 }**

```jsx
공통 스타일은 중복을 피하고 재사용성을 높이기 위해 별도로 분리하여 사용합니다.
```

```jsx
.flex {
   display: flex;
   justify-content: space-between;
}

.icon {
   font-size: 20px;
   color: var(--textColor);
}
```

```jsx
필요한 곳에서 재사용:
```

```jsx
.singleOffer {
   @extend .flex; // 공통 flex 스타일을 확장하여 적용
   .icon {
      @extend .icon; // 공통 icon 스타일 적용
   }
}
```

# { 결론: }

```jsx
BEM과 같은 명명 규칙을 사용하면 중첩을 줄이고 유지보수성을 높일 수 있습니다.

중첩을 3단계 이하로 유지하는 규칙을 통해 코드 복잡성을 줄입니다.

공통 스타일을 분리하여 재사용 가능하게 만들어 유지보수를 쉽게 할 수 있습니다.

CSS 선택자의 범위를 명확하게 설정해 다른 요소에 영향을 주지 않도록 관리합니다.
```
