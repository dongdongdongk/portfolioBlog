# Vue.js의 필요성

## JavaScript의 한계

```python
1. 순수 JavaScript만으로도 모든 웹 애플리케이션을 구축할 수 있지만, 직접 모든 코드를 작성해야 하므로 비효율적일 수 있다.

2. Vue.js와 같은 프레임워크는 코드 작성의 규칙을 제공하여, 팀 전체가 일관된 방식으로 코드를 작성하고, 핵심 비즈니스 로직에 집중할 수 있게 한다.
```

## Vue.js의 장점

```python
1. 명확한 규칙을 제공하여, 코드 구조와 철학을 팀 전체가 쉽게 이해하고 따라갈 수 있다.

2. 핵심 비즈니스 로직에 집중할 수 있도록 도와주며, 페이지 업데이트와 같은 반복적이고 성가신 작업은 Vue에 맡길 수 있다.
```

# Vue.js의 사용 방식

## Vue를 사용하는 두 가지 방식

```python
HTML 페이지의 일부분 제어

Vue를 사용하여 페이지의 특정 요소를 반응형이면서 대화형으로 만든다.

예시: 페이지의 사이드바 제어, 동적 요소 로드, 챗 오버레이 제어 등.

모든 요소에 Vue를 사용할 필요는 없으며, 대화형 요소가 필요한 부분에만 사용한다.

이러한 방식을 통해 작은 위젯을 구축할 수 있다.

* 위젯이란?

위젯은 일반적으로 쓰이는 용어는 아니지만, 페이지 일부를 제어하는 작은 기능을 의미한다.

예시: 챗 화면, 대화형 사이드바 등.

페이지 내 다른 부분은 Vue에 영향을 받지 않는다.
```

## 대화형과 반응형

```python
대화형 (Interactive):

사용자가 화면과 상호작용할 수 있도록 만든 요소이다. 예를 들어,

버튼을 클릭하거나 폼을 작성하는 것처럼 사용자의 행동에 따라 즉각적인 피드백이나 변화가 일어나는 기능을 말한다.

반응형 (Reactive):

데이터나 상태의 변화에 따라 자동으로 화면이 업데이트되는 기능을 말한다.

예를 들어, 입력 필드에 값을 입력할 때 실시간으로 유효성 검사가 이루어지는 것처럼,

사용자의 행동 없이도 데이터 변경에 따라 화면이 자동으로 갱신된다.
```

## 싱글 페이지 애플리케이션 (SPA) 접근 방식

```python
SPA란?

Vue를 사용해 페이지 내 모든 요소를 조정하고 렌더링하는 방식이다.

서버는 HTML 페이지 하나만 전송하며, 마크업은 포함되지 않지만 Vue와 Vue 코드를 불러오는 스크립트는 포함된다.

페이지가 로드된 후 Vue 코드는 브라우저 내에서 화면에 무엇을 렌더링할지 정의한다.
```

# Vue 로 순수 js 재 구축 하기

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>A First App</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <div id="app">
      <div>
        <label for="goal">Goal</label>
        <input type="text" id="goal" v-model="enteredValue" />
        <button v-on:click="addGoal">Add Goal</button>
      </div>
      <ul>
        <li v-for="goal in goals">{{ goal }}</li>
      </ul>
    </div>
    <!-- <script src="https://unpkg.com/vue@next"></script> -->
    <script src="app.js"></script>
  </body>
</html>
```

```jsx
const buttonEl = document.querySelector('button')
const inputEl = document.querySelector('input')
const listEl = document.querySelector('ul')

function addGoal() {
  const enteredValue = inputEl.value
  const listItemEl = document.createElement('li')
  listItemEl.textContent = enteredValue
  listEl.appendChild(listItemEl)
  inputEl.value = ''
}

buttonEl.addEventListener('click', addGoal)
```

```jsx
위와 같이 html 과 바닐라 js 로 이루어진 간단한 앱을 vue 로 재 구축 해본다
```

## 리빌드 코드

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>A First App</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <!-- Vue 앱이 마운트될 요소를 정의합니다 -->
    <div id="app">
      <div>
        <label for="goal">Goal</label>
        <!-- Vue의 v-model 디렉티브를 사용해 enteredValue 데이터 속성과 바인딩합니다 -->
        <input type="text" id="goal" v-model="enteredValue" />
        <!-- Vue의 v-on 디렉티브를 사용해 버튼 클릭 이벤트에 addGoal 메서드를 연결합니다 -->
        <button v-on:click="addGoal">Add Goal</button>
      </div>
      <!-- Vue의 v-for 디렉티브를 사용해 goals 배열을 순회하며 각 목표를 목록 항목으로 출력합니다 -->
      <ul>
        <li v-for="goal in goals">{{ goal }}</li>
      </ul>
    </div>
    <!-- Vue.js 라이브러리를 CDN을 통해 불러옵니다 -->
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <!-- Vue 애플리케이션 로직이 포함된 JavaScript 파일을 불러옵니다 -->
    <script src="app.js"></script>
  </body>
</html>
```

```jsx
v-model: 입력 요소의 값과 Vue 인스턴스의 데이터 속성(enteredValue)을 양방향으로 바인딩합니다.

v-on:click: 버튼 클릭 이벤트와 Vue 인스턴스의 메서드(addGoal)를 연결합니다.

v-for: 배열(goals)을 순회하여 각 항목을 렌더링합니다.
```

```jsx
// Vue 애플리케이션 생성
const app = Vue.createApp({
  // data() 함수는 Vue 인스턴스에서 사용하는 데이터를 반환합니다.
  data() {
    return {
      enteredValue: '', // 사용자가 입력한 값을 저장하는 데이터 속성
      goals: [], // 목표를 저장하는 배열
    }
  },
  // methods 객체는 Vue 인스턴스에서 사용할 메서드를 정의합니다.
  methods: {
    // addGoal 메서드는 새로운 목표를 goals 배열에 추가합니다.
    addGoal() {
      if (this.enteredValue) {
        // enteredValue가 비어있지 않은 경우에만 실행
        this.goals.push(this.enteredValue) // enteredValue를 goals 배열에 추가
        this.enteredValue = '' // 입력 필드를 비웁니다.
      }
    },
  },
})

// Vue 애플리케이션을 id가 'app'인 HTML 요소에 마운트합니다.
app.mount('#app')
```

```jsx
Vue.createApp():

새로운 Vue 애플리케이션을 생성합니다. 여기서는 데이터와 메서드를 포함하는 객체를 인자로 전달합니다.

data():

Vue 인스턴스에서 사용할 데이터를 정의하는 함수입니다. 이 함수는 객체를 반환하며, 반환된 객체의 속성들이 Vue 인스턴스의 반응형 데이터로 사용됩니다.

methods:

Vue 인스턴스에서 사용할 메서드를 정의하는 객체입니다.

this:

Vue 인스턴스 내부에서 현재 인스턴스를 참조합니다. 여기서는 this.enteredValue와 this.goals를 사용하여 데이터 속성에 접근합니다.

app.mount():

Vue 애플리케이션을 특정 DOM 요소에 마운트합니다. 여기서는 id가 app인 요소에 마운트합니다.
```

## Vue 문법 설명

### v-model

```jsx
v-model 디렉티브는 양방향 데이터 바인딩을 설정한다.

예를 들어, <input v-model="enteredValue">는 input 요소의 값과 enteredValue 데이터를 동기화한다.
```

### v-on

```jsx
v-on 디렉티브는 이벤트 리스너를 설정한다.

예를 들어, <button v-on:click="addGoal">는 버튼이 클릭될 때 addGoal 메서드를 실행한다.

v-on은 @ 기호로 축약할 수 있다 (v-on:click는 @click으로 표현 가능).
```

### v-for

```jsx
v-for 디렉티브는 배열이나 객체를 순회하며, 각 항목을 렌더링한다.

예를 들어, <li v-for="goal in goals">{{ goal }}</li>는 goals 배열의 각 항목을 <li> 요소로 렌더링한다.
```
