# { BasePawn 클래스 - **발사체 스폰 준비** }

## 📋 전체 코드 구조

```cpp
#include "BasePawn.h"

// 생성자
ABasePawn::ABasePawn()
{
    PrimaryActorTick.bCanEverTick = true;

    // 컴포넌트 생성
    CapsuleComp = CreateDefaultSubobject<UCapsuleComponent>(TEXT("CapsuleComp"));
    SetRootComponent(CapsuleComp);

    BaseMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("BaseMesh"));
    BaseMesh->SetupAttachment(CapsuleComp);

    TurretMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("TurretMesh"));
    TurretMesh->SetupAttachment(BaseMesh);

    ProjectileSpawnPoint = CreateDefaultSubobject<USceneComponent>(TEXT("ProjectileSpawnPoint"));
    ProjectileSpawnPoint->SetupAttachment(TurretMesh);
}

// 포탑 회전 함수
void ABasePawn::RotateTurret(FVector LookAtTarget)
{
    FVector VectorToTarget = LookAtTarget - TurretMesh->GetComponentLocation();
    FRotator LookAtRotation = FRotator(0.f, VectorToTarget.Rotation().Yaw, 0.f);
    FRotator InterpolatedRotation = FMath::RInterpTo(
        TurretMesh->GetComponentRotation(),
        LookAtRotation,
        GetWorld()->GetDeltaSeconds(),
        25.0f
    );
    TurretMesh->SetWorldRotation(InterpolatedRotation);
}

// 발사 함수
void ABasePawn::Fire()
{
    FVector SpawnLocation = ProjectileSpawnPoint->GetComponentLocation();
    FRotator SpawnRotation = ProjectileSpawnPoint->GetComponentRotation()
}
```

## 🏗️ 생성자(Constructor) - 컴포넌트 조립

### **컴포넌트 계층 구조**

```
CapsuleComp (루트)
    └── BaseMesh (탱크 몸체)
            └── TurretMesh (회전하는 포탑)
                    └── ProjectileSpawnPoint (발사 위치)

```

### **1. 캡슐 컴포넌트 (루트)**

```cpp
CapsuleComp = CreateDefaultSubobject<UCapsuleComponent>(TEXT("CapsuleComp"));
SetRootComponent(CapsuleComp);
```

- 전체 구조의 **기초**가 되는 컴포넌트
- 충돌 감지에 사용
- 이것이 움직이면 전체가 움직입니다

---

### **2. 베이스 메시 (탱크 몸체)**

```cpp
BaseMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("BaseMesh"));
BaseMesh->SetupAttachment(CapsuleComp);
```

- 탱크의 **몸체** 부분
- CapsuleComp에 부착 → 캡슐이 움직이면 같이 움직임

---

### **3. 터렛 메시 (회전하는 포탑)**

```cpp
TurretMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("TurretMesh"));
TurretMesh->SetupAttachment(BaseMesh);
```

- 탱크의 **포탑** 부분
- BaseMesh에 부착
- **독립적으로 회전 가능** → 몸체는 그대로, 포탑만 돌아감

---

### **4. 발사체 스폰 포인트 (발사 위치) ⭐**

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380635/notion-blog/_/_/_5_C_/_4_Battle_Blaster_-_4/image.png)

```cpp
ProjectileSpawnPoint = CreateDefaultSubobject<USceneComponent>(TEXT("ProjectileSpawnPoint"));
ProjectileSpawnPoint->SetupAttachment(TurretMesh);
```

**왜 USceneComponent를 사용하나요?**

- **보이지 않는** 컴포넌트입니다 (메시가 없음)
- 하지만 **위치, 회전, 크기 정보**는 가지고 있습니다
- 단순히 "여기서 발사체가 나올 거야"라는 **마커 역할**만 합니다

**왜 TurretMesh에 부착하나요?**

```
포탑이 이쪽 방향 →  [발사 지점도 이쪽]
포탑이 저쪽 방향 →  [발사 지점도 저쪽]
```

- 포탑이 회전하면 발사 위치도 **자동으로 같이 회전**합니다
- 포탑이 바라보는 방향으로 발사체가 나갑니다

## 🔄 RotateTurret 함수 (포탑 회전)

이미 이전 강의에서 배운 내용이므로 간단히 정리:

```cpp
void ABasePawn::RotateTurret(FVector LookAtTarget)
{
    // 1. 목표 방향 계산
    FVector VectorToTarget = LookAtTarget - TurretMesh->GetComponentLocation();

    // 2. 회전값 생성 (Yaw만 사용)
    FRotator LookAtRotation = FRotator(0.f, VectorToTarget.Rotation().Yaw, 0.f);

    // 3. 부드럽게 회전 (보간)
    FRotator InterpolatedRotation = FMath::RInterpTo(
        TurretMesh->GetComponentRotation(),  // 현재 회전
        LookAtRotation,                       // 목표 회전
        GetWorld()->GetDeltaSeconds(),        // 델타 타임
        25.0f                                 // 회전 속도
    );

    // 4. 회전 적용
    TurretMesh->SetWorldRotation(InterpolatedRotation);
}
```

## 💡 핵심 개념 정리

### **1. 왜 BasePawn에 Fire 함수를 만들었나요?**

```
BasePawn (부모 클래스)
    ├── Tank (플레이어)      → Fire 함수 사용
    └── Tower (적)           → Fire 함수 사용

```

- 탱크와 타워 **둘 다** 발사 기능이 필요합니다
- 같은 코드를 두 번 작성하지 않고, **부모 클래스에 한 번만** 작성합니다
- 이것을 **코드 재사용**이라고 합니다

---

### **2. USceneComponent의 역할**

**일반 컴포넌트:**

```
UStaticMeshComponent → 3D 모델 표시 + 위치 정보

```

**씬 컴포넌트:**

```
USceneComponent → 위치 정보만 (보이지 않음)

```

**언제 사용하나요?**

- "이 위치에서 뭔가를 생성하고 싶은데, 눈에 보일 필요는 없을 때"
- 발사 지점, 스폰 지점, 체크포인트 등에 사용

---

### **3. 부착(Attachment)의 중요성**

```cpp
ProjectileSpawnPoint->SetupAttachment(TurretMesh);

```

**부착하지 않으면:**

- 포탑이 회전해도 발사 지점은 그대로
- 발사체가 엉뚱한 방향으로 날아감

**부착하면:**

- 포탑이 회전하면 발사 지점도 자동으로 회전
- 발사체가 항상 포탑이 향하는 방향으로 날아감

## 🎓 초보자를 위한 비유

### **컴포넌트 계층 구조 = 장난감 로봇**

```
몸통 (CapsuleComp)
  └── 하체 (BaseMesh) - 나사로 고정
        └── 상체 (TurretMesh) - 회전 가능한 관절
              └── 손끝 (ProjectileSpawnPoint) - 총알 나가는 곳

```

- 하체를 움직이면 → 전체가 움직임
- 상체만 돌리면 → 손끝도 같이 돌아감
- 손끝은 눈에 보이지 않지만, **총알이 나갈 위치를 표시**

---

### **Fire 함수 = 총 발사 준비**

현재 상태:

```
1. 총알 나갈 위치 확인 ✅
2. 총알 나갈 방향 확인 ✅
3. 총알 발사 ⏳ (아직 안 만듦)
```

다음 강의에서:

```
실제 발사체(Projectile) 클래스를 만들고
이 위치와 방향으로 발사체를 스폰할 예정
```

# { Tower 클래스 - 타이머 시스템 }

## 📋 전체 코드 구조

```cpp
#include "Tower.h"

void ATower::BeginPlay()
{
    Super::BeginPlay();
    FTimerHandle FireTimerHandle;
    GetWorldTimerManager().SetTimer(FireTimerHandle, this, &ATower::CheckFireCondition, FireRate, true);
}

void ATower::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);
    if (IsInFireRange())
    {
        RotateTurret(Tank->GetActorLocation());
    }
}

void ATower::CheckFireCondition()
{
    if (Tank && IsInFireRange())
    {
        Fire();
    }
}

bool ATower::IsInFireRange()
{
    bool Result = false;
    if (Tank)
    {
        float DistanceToTank = FVector::Dist(GetActorLocation(), Tank->GetActorLocation());
        Result = (DistanceToTank <= FireRange);
    }
    return Result;
}
```

## 🎯 이 코드가 하는 일

- \*"적 타워가 2초마다 자동으로 플레이어를 향해 발사하는 AI 시스템"\*\*입니다.

핵심 기능:

- ⏱️ 타이머를 사용한 자동 발사
- 🎯 거리 체크 후 사격 여부 결정
- 🔄 매 프레임 포탑 회전

---

## 📖 함수별 상세 설명

### 1. **BeginPlay() - 게임 시작 시 타이머 설정**

```cpp
void ATower::BeginPlay()
{
    Super::BeginPlay();

    FTimerHandle FireTimerHandle;
    GetWorldTimerManager().SetTimer(
        FireTimerHandle,              // 타이머 식별자
        this,                         // 이 타워 객체
        &ATower::CheckFireCondition,  // 호출할 함수
        FireRate,                     // 시간 간격 (2초)
        true                          // 반복 여부
    );
}
```

### **타이머 파라미터 상세 분석:**

**1) FTimerHandle FireTimerHandle**

```cpp
FTimerHandle FireTimerHandle;
```

- 타이머를 구분하는 **ID 카드** 같은 역할
- 나중에 이 타이머를 멈추거나 수정할 때 사용
- 예: "FireTimerHandle이라는 타이머를 멈춰줘"

**2) this 키워드**

```cpp
this  // 현재 Tower 객체를 가리키는 포인터
```

- "이 타워" 객체를 의미
- Tank 클래스에서 사용하면 → `ATank*` 포인터
- Tower 클래스에서 사용하면 → `ATower*` 포인터

**3) &ATower::CheckFireCondition**

```cpp
&ATower::CheckFireCondition  // 함수 주소
```

- 타이머가 호출할 함수의 **주소**
- `&` = "주소를 가져와"
- "2초마다 CheckFireCondition 함수를 실행해줘"

**4) FireRate (2초)**

```cpp
FireRate  // 2.0f (2초)
```

- 타이머가 기다리는 시간
- 2초마다 함수가 호출됩니다

**5) true (반복 설정)**

```cpp
true  // 계속 반복
```

- `true` → 함수 실행 후 타이머 재시작 (무한 반복)
- `false` → 한 번만 실행하고 멈춤

---

### 2. **Tick() - 매 프레임 포탑 회전**

```cpp
void ATower::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    if (IsInFireRange())  // 사거리 안에 있으면
    {
        RotateTurret(Tank->GetActorLocation());  // 포탑 회전
    }
}
```

**이전 코드와 비교:**

```cpp
// ❌ 이전 코드 (중복된 로직)
if (Tank)
{
    float DistanceToTank = FVector::Dist(GetActorLocation(), Tank->GetActorLocation());
    if (DistanceToTank <= FireRange)
    {
        RotateTurret(Tank->GetActorLocation());
    }
}

// ✅ 개선된 코드 (함수로 분리)
if (IsInFireRange())
{
    RotateTurret(Tank->GetActorLocation());
}
```

**개선 포인트:**

- 거리 체크 로직을 `IsInFireRange()` 함수로 분리
- 코드가 간결하고 읽기 쉬워짐
- 같은 로직을 여러 곳에서 재사용 가능

---

### 3. **CheckFireCondition() - 발사 조건 확인**

```cpp
void ATower::CheckFireCondition()
{
    if (Tank && IsInFireRange())  // 탱크 존재 & 사거리 안
    {
        Fire();  // 발사!
    }
}
```

**동작 순서:**

```
2초마다 이 함수 호출
    ↓
Tank가 존재하나요? (Tank != nullptr)
    ↓ 예
사거리 안에 있나요? (IsInFireRange())
    ↓ 예
Fire() 함수 호출 → 발사!
```

**조건 체크:**

```cpp
if (Tank && IsInFireRange())
```

- `Tank` → 탱크가 파괴되지 않았는지 확인
- `&&` → AND 연산자 (둘 다 참이어야 함)
- `IsInFireRange()` → 거리 체크

---

### 4. **IsInFireRange() - 사거리 체크 (핵심 함수) ⭐**

```cpp
bool ATower::IsInFireRange()
{
    bool Result = false;  // 기본값: 거짓

    if (Tank)  // 탱크가 존재하면
    {
        // 거리 계산
        float DistanceToTank = FVector::Dist(
            GetActorLocation(),        // 타워 위치
            Tank->GetActorLocation()   // 탱크 위치
        );

        // 거리 비교
        Result = (DistanceToTank <= FireRange);
    }

    return Result;
}
```

### **단계별 분석:**

**1단계: 기본값 설정**

```cpp
bool Result = false;
```

- 일단 "사거리 밖"으로 가정
- 조건을 만족하면 `true`로 변경

**2단계: 탱크 존재 확인**

```cpp
if (Tank)
```

- 탱크가 없으면 → `false` 반환
- 탱크가 있으면 → 거리 계산 진행

**3단계: 거리 계산**

```cpp
float DistanceToTank = FVector::Dist(
    GetActorLocation(),        // 타워: (100, 200, 50)
    Tank->GetActorLocation()   // 탱크: (500, 300, 50)
);
```

**예시:**

```
타워 위치: (100, 200, 50)
탱크 위치: (500, 300, 50)
계산된 거리: 412cm
```

**4단계: 거리 비교**

```cpp
Result = (DistanceToTank <= FireRange);
```

**조건식 평가:**

```cpp
// FireRange = 700 인 경우
DistanceToTank = 412
Result = (412 <= 700)  // true

// FireRange = 700 인 경우
DistanceToTank = 850
Result = (850 <= 700)  // false
```

**5단계: 결과 반환**

```cpp
return Result;  // true 또는 false
```

**플레이어와 적의 차이:**

```
플레이어:
```

**타이머의 역할:**

- 일정 시간마다 자동으로 함수 실행
- 게임에서 **자동화된 행동**에 필수적
- 예: AI 패턴, 자동 스폰, 쿨다운 등

### **2. 코드 중복 제거의 중요성**

```cpp
// IsInFireRange() 함수로 분리
bool IsInFireRange()

}

// 여러 곳에서 재사용
if (IsInFireRange()) { ... }
```

**장점:**

- 코드 수정 시 한 곳만 변경

### **3. this 키워드의 의미**

```cpp

```

**this가 없으면:**

```cpp
void ABasePawn::RotateTurret(FVector LookAtTarget)
{
    FVector VectorToTarget = LookAtTarget - TurretMesh->GetComponentLocation();
    FRotator LookAtRotation = FRotator(0.f, VectorToTarget.Rotation().Yaw, 0.f);
    FRotator InterpolatedRotation = FMath::RInterpTo(
        TurretMesh->GetComponentRotation(),
        LookAtRotation,
        GetWorld()->GetDeltaSeconds(),
        25.0f
    );
    TurretMesh->SetWorldRotation(InterpolatedRotation);
}

void ABasePawn::Fire()
{
    FVector SpawnLocation = ProjectileSpawnPoint->GetComponentLocation();
    FRotator SpawnRotation = ProjectileSpawnPoint->GetComponentRotation();

    DrawDebugSphere(GetWorld(), SpawnLocation, 25.0f, 12, FColor::Red, false, 3.0f);

    GetWorld()->SpawnActor<AProjectile>(ProjectileClass, SpawnLocation, SpawnRotation);
}
```

## 🚀 ProjectileMovementComponent란?

![image.png](https://res.cloudinary.com/du1acdhxq/image/upload/v1788380635/notion-blog/_/_/_5_C_/_4_Battle_Blaster_-_4/image_3.png)

### **마법 같은 컴포넌트**

```cpp
UProjectileMovementComponent* ProjectileMovementComp;
```

**이것 하나로 모든 물리가 해결됩니다!**

언리얼 엔진이 제공하는 **특수 컴포넌트**로, 발사체의 움직임을 자동으로 처리합니다.

---

### **자동으로 해주는 것들:**

```
✅ 앞으로 날아가기 (초기 속도)
✅ 중력 적용 (포물선 궤적)
✅ 최대 속도 제한
✅ 반동 (Bounce)
✅ 충돌 시 멈춤
✅ 속도 감소 (마찰)
```

**우리가 할 일:**

```
속도만 설정하면 끝! 😎
```

## 📌 이 코드가 하는 일

발사체(Projectile)를 쏠 때 **"누가 쐈는지"** 기록하는 코드입니다.

---

## 🎯 핵심 개념: `this` 키워드

```cpp
Projectile->SetOwner(this);
```

### `this`가 뭔가요?

- \*"나 자신"\*\*을 가리키는 포인터
- 이 코드가 실행되는 **그 객체**를 의미

### 예시로 이해하기

**상황 1: 플레이어 탱크가 발사**

- `this` = 플레이어 탱크
- 발사체의 주인 = 플레이어 탱크

**상황 2: 적 타워가 발사**

- `this` = 적 타워
- 발사체의 주인 = 적 타워

→ **같은 코드인데 누가 실행하느냐에 따라 달라집니다!**

---

## 📝 코드 단계별 설명

### 1단계: 발사체 생성

```cpp
AProjectile* Projectile = GetWorld()->SpawnActor<AProjectile>(
    ProjectileClass,
    SpawnLocation,
    SpawnRotation
);
```

- 월드에 발사체를 생성
- 반환값을 `Projectile` 변수에 저장

### 2단계: 주인 설정

```cpp
if (Projectile)  // 발사체가 제대로 생성되었는지 확인
{
    Projectile->SetOwner(this);  // 주인을 "나"로 설정
}
```

---

## 🤔 왜 주인을 설정하나요?

### 나중에 데미지 계산할 때 필요

```
발사체가 적에게 맞았다!
→ "누가 쏜 발사체인가?" 확인
→ 플레이어가 쐈으면 → 플레이어 점수 증가
→ 적이 쐈으면 → 플레이어 체력 감소
```

---

## 💡 강의에서 한 테스트

### 주인의 이름 출력하기

```cpp
// 주인 가져오기
AActor* ProjectileOwner = Projectile->GetOwner();

// 이름 출력
if (ProjectileOwner)
{
    UE_LOG(LogTemp, Warning, TEXT("발사체 주인: %s"),
           *ProjectileOwner->GetActorNameOrLabel());
}
```

**결과:**

- 탱크가 쏘면 → "BP_Tank_0"
- 타워2가 쏘면 → "BP_Tower_2"

## 🎓 초보자를 위한 핵심 정리

| 개념            | 설명                                       |
| --------------- | ------------------------------------------ |
| **SetOwner()**  | 소유자 설정하는 함수 (Actor 클래스 제공)   |
| **GetOwner()**  | 소유자 가져오는 함수                       |
| **this**        | 현재 이 코드를 실행하는 객체 자신          |
| **포인터 체크** | `if (Projectile)` - 안전하게 코딩하는 습관 |

### 기억할 것

1. **발사체 생성 직후** 주인을 설정해야 함
2. **this = 나 자신** (코드를 실행하는 그 객체)
3. 나중에 **데미지/점수 계산**에 필수적
4. 포인터는 **항상 유효성 체크** 하기
