### 8. 스토리지 구성

```markdown
EBS는 인스턴스 내부 저장장치가 아닌 네트워크로 연결된 가상 저장 장치이다.
이러한 특징 때문에 인스턴스를 삭제하더라도 EBS는 따로 남아있기 때문에 데이터 자체를 보존할 수 있고
인스턴스 업그레이드가 용이하다는 장점이 있다.

또한 인스턴스 입장에서 여러 개의 EBS를 연결시거나, 하나의 EBS를 여러 개의 인스턴스로 연결이 가능하다.

EBS는 종류에따라 나뉜다.
범용(GP2, SSD) - 일반적으로 사용됨.
프로비전된 IOPS(Provisioned IOPS, SSD) - IOPS가 중요한 경우 (IOPS: 저장장치의 성능)
쓰로풋 최적화 HDD (Throughput Optimized HDD, SSD)
콜드 HDD (HDD)
마그네틱 (HDD) - 가장 저렴하지만 IOPS가 낮음

범용(GP2) 선택 후 용량 30 입력(Free tier 최대 용량)
```

![ec2_8_storage.png](<2023-04-25(AWS%EB%B0%B0%ED%8F%AC)/ec2_8_storage.png>)


![ec2_conn_1.png](<2023-04-25(AWS%EB%B0%B0%ED%8F%AC)/ec2_conn_1.png>)

### 1. Mac

```markdown
1. Terminal에서 다운 받은 키페어가 있는 디렉터리로 이동 또는 확인

ssh -i ~/디렉터리경로/키페어이름.pem id@public DNS

2. WARNING: UNPROTECTED PRIVATE KEY FILE! 에러 발생할 경우 권한 변경 후 재 접속
   chmod 400 키페어이름.pem

# Mac 용 putty 사용 가능
```

### 2. Windows

```markdown
1. putty 다운 후 설치
```

[Download PuTTY: latest release (0.78)](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html)

```markdown
2. pem 파일을 ppk로 변경

a. puttygetn.exe 실행
b. RSA 선택 후 load 버튼
c. 다운로드한 키페어.pem 선택
d. 확인을 클릭해서 키 생성
e. Save private key 클릭
f. 경고창이 뜨면 예를 클릭
g. ppk 확장자로 파일 저장

3. putty 접속
   a. putty 실행
   b. putty의 Host Name에 연결 정보 입력
   c. connection -> SSH -> Auth에 Private key file에 Browser 버튼으로 PPK 파일 찾기
   d. 만일 Auth에 Browser 버튼이 없으면 Auth -> Credentials -> Private key file에 Browser 버튼 있음
   e. open클릭
```
