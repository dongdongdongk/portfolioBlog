## 1. **Projectile(투사체) 클래스 생성**

```jsx

```

```jsx
import Phaser from 'phaser'

class Projectile extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key)

    scene.add.existing(this) // 씬에 추가
    scene.physics.add.existing(this) // 물리 엔진 적용

    this.speed = 300 // 투사체 속도 설정
  }

  fire() {
    console.log('fire') // 콘솔 로그로 발사 확인

}

```

```jsx
fire() 함수에서 setVelocityX(this.speed)를 사용해 오른쪽 방향으로 이동하도록 설정
```

# { Phaser에서 투사체(Projectile) 처리 ( 메모리 누수 방지 ) }

```jsx
이 강의에서는 Phaser의 Arcade Physics를 활용한 투사체(Projectile) 시스템을 다루며,

특정 거리(200px)를 이동한 후 자동으로 사라지도록 구현하는 방법을 설명합니다.
```

## 투사체(Projectile) 클래스 구조

```jsx
import Phaser from 'phaser'

class Projectile extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key)

    // 씬(Scene)에 추가
    scene.add.existing(this)
    scene.physics.add.existing(this)

    // 속도 및 이동 거리 관련 변수 초기화
    this.speed = 300 // 투사체 속도
    this.maxDistance = 200 // 최대 이동 거리
    this.traveledDistance = 0 // 현재 이동 거리
  }

  preUpdate(time, delta) {
    super.preUpdate(time, delta)

    // 이동 거리 누적 계산
    this.traveledDistance += this.body.deltaAbsX()

    // 최대 이동 거리 도달 시 객체 삭제
    if (this.traveledDistance >= this.maxDistance) {
      this.destroy()
    }
  }

  fire() {
    console.log('fire')
    this.setVelocityX(this.speed)
  }
}

export default Projectile
```

```jsx
(1) Phaser.Physics.Arcade.Sprite 상속

		Projectile 클래스는 Phaser.Physics.Arcade.Sprite를 상속하여, 물리 엔진의 영향을 받는 투사체를 생성합니다.

(2) 씬(Scene)과 물리 엔진에 추가

		scene.add.existing(this) → 씬에 해당 객체를 추가

		scene.physics.add.existing(this) → 물리 엔진에 해당 객체를 추가하여 충돌 및 이동 처리 가능

(3) 속도 및 이동 거리 관련 변수

		this.speed = 300; → 투사체 속도를 설정

		this.maxDistance = 200; → 최대 이동 거리(200px) 설정

		this.traveledDistance = 0; → 이동한 거리를 저장하는 변수


(4) preUpdate() 함수

		preUpdate(time, delta)는 매 프레임마다 호출되어 상태를 업데이트하는 메서드

		super.preUpdate(time, delta); → Phaser의 기본 업데이트 기능을 유지하면서 추가 기능을 정의

		this.traveledDistance += this.body.deltaAbsX();

				this.body.deltaAbsX() → 이전 프레임과 현재 프레임 사이의 X 좌표 변화량을 반환

				이를 누적하여 현재까지 이동한 거리를 계산

		if (this.traveledDistance >= this.maxDistance) { this.destroy(); }

				누적 이동 거리가 maxDistance 이상이면 객체를 제거(destroy)


(5) fire() 함수

		this.setVelocityX(this.speed); → X축 방향으로 지정한 속도로 이동 시작

		console.log("fire"); → 발사 시 콘솔에 "fire" 출력
```

### deltaAbsX()

```jsx
this.body.deltaAbsX()는 이전 프레임과 현재 프레임 사이의 X 좌표 변화량을 반환합니다.

**절대값(absolute value)**을 반환하므로 항상 양수 값이 나옵니다.
```

```jsx
this.traveledDistance += this.body.deltaAbsX()
```

```jsx
this.body.deltaAbsX()는 이전 프레임과 현재 프레임 동안 객체의 X 좌표가 얼마나 이동했는지 측정합니다.

이를 this.traveledDistance에 계속 더하면서 투사체가 이동한 총 거리를 계산합니다.
```

### destroy()

```jsx
this.destroy();는 현재 Phaser 객체를 씬(Scene)에서 제거하는 메서드입니다.

제거된 객체는 화면에 표시되지 않고, 물리 엔진에서도 사라짐.

메모리 최적화에 필수적이며, 필요 없는 객체가 씬에 계속 남아 있는 것을 방지합니다.
```

```jsx
if (this.traveledDistance >= this.maxDistance) {
  this.destroy()
}
```

```jsx
투사체가 최대 이동 거리(200px)를 넘으면 더 이상 필요 없으므로 제거.

더 이상 preUpdate()가 실행되지 않으며, 물리 엔진에서도 사라짐.
```

### preUpdate()

```jsx
preUpdate(time, delta)는 Phaser의 Arcade.Sprite가 매 프레임마다 실행하는 함수입니다.

이 함수는 기본적으로 Phaser가 객체의 상태를 업데이트할 때 자동 호출됩니다.

super.preUpdate(time, delta);를 호출하여 Phaser의 기본 업데이트 기능을 유지하면서,

추가적인 동작을 구현할 수 있습니다.
```

```jsx
preUpdate(time, delta) {
    super.preUpdate(time, delta);

    this.traveledDistance += this.body.deltaAbsX();

    if (this.traveledDistance >= this.maxDistance) {
        this.destroy();
    }
}

```

### `preUpdate()` vs `update()`

![image.png](<%EC%84%B9%EC%85%98%2010%20Projectiles%20(%20%ED%88%AC%EC%82%AC%EC%B2%B4%20)/image%201.png>)

```jsx
preUpdate()는 각 객체(투사체)마다 개별적으로 실행됨.

update()는 씬(Scene) 내 모든 객체에 대해 한 번만 실행되므로 전체적인 게임 로직 제어에 사용.
```

# { 게임 루프(Game Loop)란? }

```jsx
게임은 한 번 실행하면 끝나는 프로그램이 아니라, 계속해서 화면을 갱신하고,

사용자 입력을 받고, 물리 연산을 적용하는 과정이 반복됩니다.

이러한 과정이 돌아가는 것이 바로 **게임 루프(Game Loop)**입니다.

Phaser도 내부적으로 게임 루프를 실행하며, 특정한 순서로 여러 함수를 호출합니다.
```

## 🔷 **Phaser의 게임 루프 실행 순서**

```jsx
Phaser에서 한 프레임(화면이 한 번 그려지는 주기)마다 실행되는 주요 단계는 다음과 같습니다.

🏁 1. preUpdate (미리 업데이트)

		모든 게임 오브젝트마다 preUpdate() 함수가 호출됩니다.

		주로 게임 오브젝트의 상태를 초기화하거나,

		물리 엔진을 업데이트하기 전에 필요한 작업을 처리합니다.

🔄 2. update (업데이트)

		개발자가 직접 정의하는 핵심 업데이트 로직이 실행됩니다.

		게임 캐릭터의 이동, AI, 충돌 검사 등을 처리합니다.

		this.update(time, delta); 형태로 Scene에서 사용됩니다.

🎨 3. postUpdate (후처리)

		update() 이후 실행되는 단계로, 충돌 처리 후의 후속 작업을 수행합니다.

		예를 들어, 충돌이 발생한 후 오브젝트를 삭제하는 등의 작업을 할 수 있습니다.
```

## 🔷 **Phaser에서 한 프레임의 흐름**

```jsx
⚡ 프레임 하나의 실행 흐름 (매 프레임마다 반복됨)

		1. 입력(Input) 처리 → 키보드, 마우스 등 이벤트 감지 , W, A, S, D 키 입력 감지

		2. preUpdate() 실행 → 게임 오브젝트들의 초기 업데이트 , 내부적으로 애니메이션 프레임 업데이트 등 실행

		3. update() 실행 → 개발자가 작성한 게임 로직 실행 , update()에서 속도 변경, UI 업데이트 등 처리

		4. 충돌 감지 및 물리 연산 처리 , Phaser의 Arcade 물리 엔진이 충돌 검사 및 속도 적용 플레이어와 적이 충돌했는지 확인

		5. postUpdate() 실행 → 충돌 후 처리, 충돌 후 오브젝트를 제거하거나 후속 작업 수행 예: 적이 충돌하면 사라짐

		6. 렌더링(Rendering) → 화면에 그리기 , 모든 오브젝트가 화면에 그려짐

이 과정이 초당 60번(60FPS 기준) 반복됩니다.
```

## ✅ **언제 어디서 사용해야 할까?**

```jsx
게임의 전반적인 로직: update 사용 (Scene에서 작성)

개별 오브젝트의 업데이트: preUpdate, update, postUpdate 사용 (객체별로 작성)

물리 적용 전에 작업: preUpdate 사용

물리 적용 후 후처리: postUpdate 사용
```

## Phaser가 "원래 하던 일"이 뭔데?

```jsx
Phaser는 게임을 만들 때, 캐릭터나 물체(스프라이트)를 자동으로 움직이고, 충돌을 감지하고, 애니메이션을 재생하는 기능을 해줘!

예를 들어,

캐릭터가 계속 움직이게 하기

적과 부딪히면 충돌 판정을 하기

애니메이션을 부드럽게 재생하기

이런 것들을 Phaser가 자동으로 처리해 줘.
```

## `super.preUpdate(time, delta);`가 없으면 무슨 일이 생길까?

```jsx
우리가 preUpdate()라는 함수를 새로 만들면, Phaser가 **원래 하던 일(움직이기, 충돌 체크, 애니메이션 재생 등)**을 자동으로 실행하지 않을 수도 있어!

즉,

총알이 멈출 수도 있고,

충돌 감지가 안 될 수도 있고,

애니메이션이 멈출 수도 있어!

이걸 방지하려면 super.preUpdate(time, delta);를 호출해서

**"Phaser야, 네가 원래 하던 일 먼저 해!"**라고 말해줘야 해.
```

## Phaser의 업데이트 순서

```jsx
Phaser는 매 프레임마다(requestAnimationFrame) 게임 오브젝트를 업데이트하는데, 이때 업데이트 순서가 있어!

1️⃣ preUpdate() → 개별 오브젝트(스프라이트, 물리 객체 등)의 업데이트
2️⃣ update() → 씬(Scene) 전체의 업데이트
3️⃣ postUpdate() → 업데이트 후 정리
```

## 왜 `preUpdate()`에서 `super.preUpdate(time, delta);`를 호출할까?

```jsx
Phaser는 Phaser.Physics.Arcade.Sprite 같은 클래스에서 이미 preUpdate()를 정의해놨어.

우리가 preUpdate()를 새로 만들면, Phaser가 원래 하던 기본 동작(물리 엔진, 애니메이션 등)이 사라질 수도 있어.

그래서 우리는 super.preUpdate(time, delta);를 호출해서 Phaser가 기본적으로 하던 일들을 유지하면서, 추가 기능을 넣는 거야! 🚀
```

## 만약 `preUpdate()`가 아니라 `update()`를 쓴다면?

```jsx
update()는 씬(Scene)에서 실행되는 함수라서,

개별 오브젝트(총알, 캐릭터 등)의 물리 연산이나 충돌 감지를 직접 처리하지 않아!

즉, 오브젝트 자체가 움직이거나 충돌하는 기능은 preUpdate()에서 처리해야 정상적으로 작동해!
```

# **{ 투사체 그룹(Projectiles Group)** 을 활용 }

```jsx
여기서는 Phaser 3를 이용해 플레이어가 발사하는 투사체(Projectile)를 효율적으로 관리하는 방법을 배우게 됩니다.

기존에는 투사체를 생성하고 200픽셀을 이동하면 삭제하는 방식이었지만,

투사체 그룹(Projectiles Group) 을 활용하면

한정된 개수의 투사체를 재사용하여 성능을 최적화할 수 있습니다.
```

## 1. **투사체 그룹(Projectiles Group)이란?**

```jsx
Phaser의 Phaser.Physics.Arcade.Group을 확장하여 만든 객체 풀링(Object Pooling) 기법.

미리 지정된 개수의 투사체를 만들어 놓고, 필요할 때 활성화하여 사용.

투사체가 사거리(200픽셀)를 초과하면 삭제하는 대신 비활성화(inactive) 상태로 되돌려 재사용.
```

## 2. **투사체 그룹 코드 설명**

```jsx
// Phaser 라이브러리에서 필요한 기능을 가져옴
import Phaser from 'phaser'
// Projectile 클래스를 가져옴 (각각의 투사체가 어떻게 동작하는지 정의된 클래스)
import Projectile from './Projectile'

/**
 * Projectiles 클래스는 Phaser의 Physics.Arcade.Group을 확장하여,
 * 여러 개의 투사체(Projectile)를 관리하는 역할을 합니다.
 */
class Projectiles extends Phaser.Physics.Arcade.Group {
  /**
   * @param {Phaser.Scene} scene - 투사체가 사용될 씬 (게임의 특정 장면)
   */
  constructor(scene) {
    // Phaser의 Arcade 물리 엔진을 사용하여 그룹을 생성
    super(scene.physics.world, scene)

    /**
     * 여러 개의 Projectile 객체를 미리 생성해두고 비활성화된 상태로 유지합니다.
     * 이렇게 하면 게임 도중에 새로운 객체를 생성하는 부담을 줄이고 성능을 최적화할 수 있습니다.
     */
    this.createMultiple({
      frameQuantity: 5, // 5개의 투사체(Projectile) 미리 생성
      active: false, // 처음에는 비활성화된 상태 (충돌 처리되지 않음)
      visible: false, // 화면에 보이지 않도록 설정
      key: 'iceball', // 스프라이트 시트에서 사용할 텍스처 키 (이미지)
      classType: Projectile, // Projectile 클래스를 기반으로 투사체 생성
    })
  }

  /**

fireProjectile(initiator) {
```

## 2. 문제점: 투사체가 계속 화면에 남아 있음

```jsx
❌ 현재 문제

		투사체가 화면에서 사라지지 않고 계속 남아 있음.

		일정 거리 이상을 이동하면 투사체를 자동으로 비활성화해야 함.

🎯 해결 방법

		isOutofRange() 함수를 따로 만들어서 투사체의 이동 거리를 체크하도록 수정.

		사거리를 초과하면 setActive(false)와 setVisible(false)로 숨김 처리.
```

### 📌 **수정된 코드 (`Projectile.js`)**

```jsx
class Projectile extends Phaser.Physics.Arcade.Sprite {
  constructor(scene, x, y, key) {
    super(scene, x, y, key)

    scene.add.existing(this)
    scene.physics.add.existing(this)

    this.speed = 300 // 투사체 속도
    this.maxDistance = 200 // 최대 이동 거리
    this.traveledDistance = 0 // 이동한 거리 저장
  }

  // 이동 거리 체크 함수 (사거리 초과 여부 확인)
  isOutofRange() {
    return this.traveledDistance && this.traveledDistance >= this.maxDistance
  }

  // Phaser의 기본 update 함수 (매 프레임 실행됨)
  preUpdate(time, delta) {
    super.preUpdate(time, delta)

    // 이동한 거리 업데이트
    this.traveledDistance += this.body.deltaAbsX()

    // 사거리를 초과하면 투사체 정리
    if (this.isOutofRange()) {
      this.resetProjectile()
    }
  }

  // 투사체 초기화 (화면에서 사라지게 함)
  resetProjectile() {
    this.setActive(false) // 비활성화
    this.setVisible(false) // 숨기기
    this.body.reset(0, 0) // 좌표를 (0,0)으로 리셋
    this.traveledDistance = 0 // 이동 거리 초기화
  }

  // 투사체 발사 함수
  fire(x, y) {
    this.setActive(true)
    this.setVisible(true)
    this.body.reset(x, y)
    this.setVelocityX(this.speed)
  }
}
```

```jsx
✔ resetProjectile() 함수를 사용하여 투사체를 정리 (비활성화 및 숨김 처리)

✔ 더 이상 화면에 남아 있는 투사체가 없음
```

```jsx
		1. utils 폴더를 생성한다.

		2. utils/functions.js 파일을 만들고, 다음 코드를 추가한다.
```

## 3. `Projectiles` 클래스에서 쿨다운 적용

```jsx
Projectiles.js에서 발사 시간을 저장하고 비교하여 연속 발사를 제한한다.
```

```jsx
import { getTimestamp } from '../utils/functions'

class Projectiles extends Phaser.Physics.Arcade.Group {
  constructor(scene) {
    super(scene.physics.world, scene)

    this.createMultiple({
      frameQuantity: 5,
      active: false,
      visible: false,
      key: 'iceball',
      classType: Projectile,
    })

    this.timeFromLastProjectile = null // 마지막 발사 시간 저장 변수
  }

  fireProjectile(initiator) {
    const projectile = this.getFirstDead(false)
    if (!projectile) return

    if (
      this.timeFromLastProjectile &&
      this.timeFromLastProjectile + projectile.cooldown > getTimestamp()
    ) {
      return // 쿨다운 시간이 지나지 않았다면 발사하지 않음
    }

    const center = initiator.getCenter()
    let centerX

    if (initiator.lastDirection === Phaser.Physics.Arcade.FACING_RIGHT) {
      projectile.speed = Math.abs(projectile.speed)
      projectile.flipX = false
      centerX = center.x + 10
    } else {
      projectile.speed = -Math.abs(projectile.speed)
      projectile.flipX = true
      centerX = center.x - 10
    }

    projectile.fire(centerX, center.y)
    this.timeFromLastProjectile = getTimestamp() // 마지막 발사 시간 업데이트
  }
}
```

### 4. 쿨다운이 적용되는 방식

```jsx
1. 투사체를 발사할 때 getTimestamp()로 현재 시간을 저장 (this.timeFromLastProjectile).

2. 다음 발사 시 현재 시간과 마지막 발사 시간을 비교.

3. this.timeFromLastProjectile + projectile.cooldown > getTimestamp()가 참이면 발사하지 않음.

4. 설정한 쿨다운 시간(예: 1000ms)이 지나면 다시 발사 가능.
```

## ⚙ **4. 공격 중일 때 다른 애니메이션이 덮어쓰이지 않도록 처리**

```jsx
현재 update()에서 이동과 점프 애니메이션이 항상 실행되므로,

"throw" 애니메이션이 끝나기 전에 다른 애니메이션이 덮어쓰이는 문제가 발생한다.

👉 이를 방지하려면 공격 애니메이션이 실행 중일 때 다른 애니메이션이 실행되지 않도록 조건을 추가해야 한다.
```

### 📌 **Player.js - update() 수정**

```jsx
update() {
    if (this.hasBeenHit) {
        return;
    }

    if (this.isPlayingAnims('throw')) {
        return; // 공격 애니메이션이 실행 중이면 다른 애니메이션 실행 X
    }

    const { left, right, space } = this.cursors;
    const onFloor = this.body.onFloor();
    const isSpaceJustDown = Phaser.Input.Keyboard.JustDown(space);

    if (left.isDown) {
        this.lastDirection = Phaser.Physics.Arcade.FACING_LEFT;
        this.setVelocityX(-this.playerSpeed);
        this.setFlipX(true);
    } else if (right.isDown) {
        this.lastDirection = Phaser.Physics.Arcade.FACING_RIGHT;
        this.setVelocityX(this.playerSpeed);
        this.setFlipX(false);
    } else {
        this.setVelocityX(0);
    }

    if (isSpaceJustDown && (onFloor || this.jumpCount < this.consecutiveJumps)) {
        this.setVelocityY(this.jumpSpeed);
        this.jumpCount++;
    }

    if (onFloor) {
        this.jumpCount = 0;
    }

    onFloor
        ? this.body.velocity.x !== 0
            ? this.play("run", true)
            : this.play("idle", true)
        : this.play("jump", true);
}

```

```jsx
🔍 변경점
if (this.isPlayingAnims('throw')) return;

👉 "throw" 애니메이션이 실행 중이면 다른 애니메이션 실행 X

이제 공격 중일 때 이동해도 애니메이션이 덮어씌워지지 않음.

✅ 완벽하게 투척 애니메이션이 실행됨!
```

## 5. 애니메이션 체크 로직을 따로 관리하기 (Mixin)

```jsx
위 코드는 플레이어 클래스 내부에서만 동작하는데,

이 로직을 재사용 가능하도록 Mixins (애니메이션 유틸리티 함수) 로 따로 분리한다.
```

### 📌 **mixins/anims.js 생성**

```jsx
export default {
  /**
   * 현재 실행 중인 애니메이션이 특정 애니메이션인지 확인하는 메서드
   *
   * @param {string} animKey - 확인할 애니메이션의 키 값
   * @returns {boolean} - 현재 실행 중인 애니메이션이 animKey와 일치하면 true, 그렇지 않으면 false
   */
  isPlayingAnims(animKey) {
    // 현재 애니메이션이 실행 중인지 확인하고,
    // 실행 중이라면 현재 애니메이션의 키 값이 주어진 animKey와 같은지 비교하여 반환
    return this.anims.isPlaying && this.anims.currentAnim.key === animKey
  },
}
```

```jsx
isPlayingAnims(animKey) → 현재 실행 중인 애니메이션이 특정 키인지 확인

this.anims.isPlaying

정의: 현재 애니메이션이 실행 중인지 여부를 나타내는 불리언(boolean) 값입니다.

역할: true이면 현재 애니메이션이 실행 중이고, false이면 실행 중이지 않음을 의미

this.anims.currentAnim

정의: 현재 실행 중인 애니메이션의 정보를 담고 있는 객체입니다.

역할: 현재 실행 중인 애니메이션이 어떤 애니메이션인지 확인할 수 있습니다.
```

# { 투사체(Projectile)와 적(Enemy)의 충돌 처리 및 데미지 시스템 구현 }

```jsx
Phaser 3을 사용하여 **플레이어가 발사하는 투사체(Projectile)**와 적(Enemy)

객체가 충돌했을 때 적이 데미지를 받도록 구현하고 있습니다.
```

## 1. 충돌 감지 설정 (Physics Collider)

```jsx
Phaser 3의 **물리 엔진(Arcade Physics)**을 사용하여

적과 투사체가 충돌했을 때 실행할 함수를 등록해야 합니다.
```

### 📌 Play Scene에서 충돌 감지 설정

```jsx
createEnemyColliders(enemies, { colliders }) {
    enemies
        .addColliders(colliders.platformsColliders) // 적과 바닥 충돌 설정
        .addColliders(colliders.player, this.onPlayerCollision) // 적과 플레이어 충돌 설정
        .addColliders(colliders.player.projectiles, this.onWeaponHit) // 적과 투사체 충돌 설정
}
```

```jsx
이 부분에서 addColliders(colliders.player.projectiles, this.onWeaponHit)를 통해

**적(Enemy)과 플레이어의 투사체(Projectile)**가 충돌할 경우 this.onWeaponHit 함수가 실행되도록 설정합니다.
```

## 2. 충돌 발생 시 실행되는 onWeaponHit 함수

```jsx
onWeaponHit(entity, source) {
    console.log(`${entity} is taking a hit from ${source}`);
    entity.takesHit(source);
}
```

```jsx
entity → 충돌한 객체 (여기서는 Enemy 인스턴스)

source → 충돌한 대상 (여기서는 Projectile 인스턴스)

entity.takesHit(source);를 호출하여 적이 데미지를 받도록 처리

즉, 적과 투사체가 충돌하면 takesHit() 메서드를 호출하여 적의 체력을 감소시키도록 합니다.
```

## 3. 적이 데미지를 받는 takesHit() 함수

```jsx
적이 맞았을 때 실행되는 takesHit() 메서드는 아래와 같이 구성되어 있습니다. (Enemy.js 에 구현)
```

```jsx
takesHit(source) {
    this.health -= source.damage;  // 투사체의 데미지만큼 적의 체력을 감소

    // 투사체를 비활성화 (사라지게 함)
    source.setActive(false);
    source.setVisible(false);

    console.log("Enemy health: ", this.health);

    // 적의 체력이 0 이하라면 제거
    if (this.health <= 0) {
        console.log("Enemy is terminated");
        this.destroy();  // 적 제거
    }
}
```

### 📌 `takesHit()`의 동작 방식

```jsx
1. 맞은 투사체의 데미지만큼 적의 체력을 감소 (this.health -= source.damage)

2. 투사체를 비활성화하여 화면에서 사라지게 처리 (setActive(false), setVisible(false))

3. 현재 적의 체력을 출력 (console.log("Enemy health: ", this.health);)

4. 체력이 0 이하이면 적 제거 (this.destroy();)

즉, 투사체가 적과 충돌하면, 적은 데미지를 받고, 체력이 0 이하가 되면 제거되는 방식입니다.
```

```jsx
this.health = 40; 를 init 에 추가해서 적 hp 를 만들어 주고

this.damage = 10; Projectile.js 에 투사체 데미지를 추가해서 설정해 준다
```

## 4. 충돌이 일어나는 전체적인 흐름

### ✅ **플레이어가 투사체를 발사하고, 적과 충돌하는 과정**

```jsx
1. 플레이어가 투사체를 발사

		Projectile.fire(x, y)를 호출하여 투사체를 생성하고 이동시킴

2. 투사체가 적과 충돌

		createEnemyColliders()에서 this.onWeaponHit가 호출됨

3. onWeaponHit() 함수 실행

		takesHit(source)를 호출하여 적의 체력을 감소시킴

4. takesHit()에서 적이 데미지를 받음

		this.health -= source.damage;

		체력이 0이면 this.destroy();를 실행하여 적을 제거
```
