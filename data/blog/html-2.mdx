### **HTML :** 웹페이지의 명사 같은 것으로 콘텐츠의 구조를 규정 하는 것

(Hypertext Markup Language)

HTML 은 완전한 프로그래밍 언어가 아니다. 복잡한 논리가 필요한 것 도 아니며 단순히 문서에

**마크업** 을 할 뿐이다.

굵은 글씨 , 숫자나 기호가 붙은 목록, 링크, 이탤릭체, 문단 만들기 등등

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381356/notion-blog/_/The_Web_Developer_2022/HTML/HTML_/Untitled.png)

CSS = 형용사

## 개발자 도구 사용하기

구글에서 만든 웹 브라우저인 크롬에는 개발을 도와주는 다양한 도구가 기본적으로 제공된다. 이를 **개발자 도구**라고 한다.

개발자 도구를 이용하면 HTML, CSS, JavaScript의 생산성을 극대화할 수 있다. 언뜻 보면 개발자를 위한 도구인 것 같지만, 글자 크기, 색, 간격 등 정확한 값을 확인해야 하는 디자이너에게도 없어서는 안 될 매우 중요한 도구이다.

(우 클릭 후 검사)

## HTML 문서의 기본 구조

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381355/notion-blog/_/The_Web_Developer_2022/HTML/HTML_/Untitled_3.png)

```html
<!DOCTYPE html> //HTML5 를 사용하고 있다는 표식 (뒤에 계속 설명)

<html></html>
//HTML 문서의 루트 를 나타내며 루트 요소라 부름 모든 다른 요소는
<html></html>
의 사이에 들어가야 한다 <요소의 후손>

<head></head> //문서 메타데이터 (헤더) 페이지 상 보이지 않는 내용을 담고있다.
제목,CSS,JS,폰트,아이콘 등

<title></title> //브라우저 탭 상에 표시되는 이름 , 구글은 이걸로 검색을 한다.

<body></body>
//문서의 모든 내용을 담고 있는 요소 다. 한 문서에 하나의 body 만 존재한다. (head 와 body 는 한쌍)
```

## VSCode 팁 : 자동 포맷

HTML 을 가독성 좋게 정리 해주는 방법

1. Ctrl + Shift + p 로 Cimmand Palette 를 연다.
2. Format Document 검색 후 엔터
3. 자동으로 정렬 (추가적으로 format 으로 검색후 셋팅에서 Format on save 를 체크 하면 저장 할때 마다 자동으로 정렬 해준다.

## HTML 목록 요소

```html
<ul>
  // 점으로 표시된 목록 시작
  <li>Silkie</li>
  <ul>
    // 항목 속의 항목
    <li>Easter</li>
    <li>Egger</li>
  </ul>
  <li>Polish</li>
  <li>Easter Egger</li>
  <li>Rhode Island Red</li>
  // 항목을 표시할땐
  <li></li>
</ul>

<ol>
  // 숫자로 된 목록
  <li>Silkie</li>
  <li>Polish</li>
  <li>Easter Egger</li>
  <li>Rhode Island Red</li>
</ol>

<ul></ul>
//점으로 된 목록을 표시

<ol></ol>
//숫자로 된 목록을 표시

<li></li>
//목록에 들어가는 항목
<ol>
  또는
  <ul>
    사이에 들어가 있어야 한다.
  </ul>
</ol>
```

## HTML 이미지

![Untitled](https://res.cloudinary.com/du1acdhxq/image/upload/v1788381356/notion-blog/_/The_Web_Developer_2022/HTML/HTML_/Untitled_5.png)

```html
<img src="주소" /> // 위와 같은 형태를 가지고 있고 이미지를 넣는데 사용한다. //이미지 파일의 이름을

// 외부 이미지 링크 또한 사용할수 있다.
```
