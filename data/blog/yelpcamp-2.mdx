[Passport.js](https://www.passportjs.org/)

### **Passport 설정 부분**

```jsx
passport.use(new LocalStrategy(User.authenticate()))
passport.serializeUser(User.serializeUser())
passport.deserializeUser(User.deserializeUser())
```

```jsx
passport.use:

passport.use는 Passport에게 로컬 전략(LocalStrategy)을 사용하도록 지시한다.

여기서 로컬 전략은 사용자의 아이디와 비밀번호를 이용한 기본적인 사용자 인증 방식을 의미한다.

User.authenticate()는 몽구스에서 제공하는 사용자 인증 함수로, 해당 함수는 사용자의 아이디와 비밀번호를 확인하여 사용자를 인증하는 역할을 한다

passport.serializeUser:

사용자 정보를 세션에 저장할 때 어떤 필드를 사용할지를 정의하는 메소드이다. User.serializeUser()는 몽구스에서 제공하는 사용자 모델의 메소드로, 사용자의 ID를 세션에 저장한다.

passport.deserializeUser:

세션에 저장된 사용자 정보를 어떻게 복원할지를 정의하는 메소드이다. User.deserializeUser()는 몽구스에서 제공하는 사용자 모델의 메소드로, 세션에서 얻은 ID를 사용해 사용자 정보를 복원합니다.

사용자가 로그인하면 세션에는 사용자의 ID가 저장되어 있다.

이후 사용자가 새로운 요청을 보낼 때, Passport는 세션에서 해당 ID를 얻어오고, passport.deserializeUser를 호출하여 그 ID에 해당하는 실제 사용자 정보를 데이터베이스에서 찾아온다.

이러한 과정을 통해 세션에 저장된 사용자 정보를 복원하고, 해당 정보를 요청 객체(request object)에 추가하여 사용자가 로그인한 상태를 유지할 수 있다.
```

### **세션 설정 부분**

```jsx
const sessionConfig = {
  secret: 'apple',
  resave: false,
  saveUninitialized: true,
  cookie: {
    httpOnly: true,
    expires: Date.now() + 1000 * 60 * 60 * 24 * 7,
    maxAge: 1000 * 60 * 60 * 24 * 7,
  },
}
app.use(session(sessionConfig))
```

```jsx
session:

Express에 세션 미들웨어를 추가한다. 이 미들웨어는 세션을 관리하고 유지한다.

secret:

세션을 암호화하는 데 사용되는 키다.

resave:

 세션을 강제로 저장할지 여부를 결정하는 옵션으로, false로 설정하여 성능을 향상시킨다.

saveUninitialized:

초기화되지 않은 세션도 저장할지 여부를 결정하는 옵션이다.

cookie:

세션 쿠키의 설정을 정의한다. 여기서는 쿠키의 만료 기간을 1주일로 설정했다.
```

### **Passport 및 세션 미들웨어 등록 부분**

```jsx
passport.initialize():

passport.initialize()는 Passport를 초기화하는 메소드이다.

이를 사용하면 Passport가 요청(request) 객체(req)에 필요한 메소드 및 기능을 추가한다.

초기화된 Passport는 사용자의 요청을 인증(authenticate)하고, 로그인 상태를 확인하는 등의 기능을 수행할 수 있다. 따라서 Passport를 사용하기 전에 반드시 초기화를 해주어야 한다.

예를 들어, 사용자가 로그인한 상태인지 확인하려면 Passport가 제공하는 req.isAuthenticated() 메소드를 사용할 수 있다. 이러한 Passport의 기능을 사용하려면 passport.initialize()가 필요하다.

passport.session():

passport.session()은 Express 세션을 사용하여 Passport를 설정하는 메소드이다.

이 미들웨어를 사용하면 Passport가 세션을 활용하여 사용자의 로그인 상태를 지속적으로 유지할 수 있다.

사용자가 로그인하면, Passport는 해당 사용자의 정보를 세션에 저장한다.

이후 사용자가 다른 요청을 보낼 때마다 Passport는 세션에서 사용자 정보를 가져와서 요청 객체(req)에 추가한다.

따라서 passport.session()을 사용하면 로그인한 사용자의 정보를 세션에서 읽어와서 요청 처리 중에 활용할 수 있다.

종합적으로, passport.initialize()는 Passport의 기능을 요청 객체에 추가하고,

passport.session()은 세션을 통해 사용자의 로그인 상태를 유지하는 역할을 한다.
```

### Passport의 local 전략이란?

```jsx
"Passport의 local 전략을 사용하여 로그인을 시도한다"는 말은 Passport 라이브러리에서 제공하는 인증 전략 중 하나인

"local" 전략을 사용하여 로그인을 시도한다는 것을 의미한다.

여기서 "local" 전략은 사용자의 아이디와 비밀번호를 사용하여 인증하는 전략이다.

일반적으로 웹 애플리케이션에서는 로그인 시에 사용자가 제공한 아이디(일반적으로 이메일 또는 사용자명)와 비밀번호를 검사하여

사용자를 인증하는데 사용된다.

P
assport는 다양한 인증 전략을 제공하며, 각 전략은 특정 유형의 인증을 처리한다.

"local" 전략은 웹 애플리케이션에서 일반적으로 사용되는 아이디와 비밀번호를 이용한 인증을 담당한다.

사용자가 로그인을 시도할 때, Passport는 이 아이디와 비밀번호를 확인하여 유효한 사용자인지 판단하고,

성공 또는 실패에 따라 적절한 동작을 수행한다.

로그인 시도를 처리하는 라우터에서 passport.authenticate('local')를 사용하면 Passport는 "local" 전략을 실행하여

사용자의 인증을 시도하게 된다.

만약 인증이 성공하면 로그인이 허용되고, 실패하면 로그인이 거부된다.

인증이 성공했을 경우, 이후의 로직(예: 세션 생성, 토큰 발급 등)을 개발자가 직접 구현할 수 있다.
```

```jsx
const express = require('express')
const router = express.Router()
const User = require('../models/user')
const catchAsync = require('../util/catchAsync')
const passport = require('passport')

// 회원 가입
router.post(
  '/register',
  catchAsync(async (req, res) => {
    try {
      // 요청 바디에서 이메일, 사용자 이름, 비밀번호 추출
      const { email, username, password } = req.body

      // User 모델을 이용해 새로운 사용자 생성
      const user = new User({ email, username })

      // Passport의 User 모델 메소드인 register를 사용하여 사용자 등록
      const registerUser = await User.register(user, password)

      // 등록이 성공하면 콘솔에 등록된 사용자 정보 출력 및 성공 응답 전송
      console.log(registerUser)
      res.send('Success')
    } catch (error) {
      // 등록 실패 시 401 상태 코드와 에러 메시지 전송
      res.status(401).send('Fail', error)
    }
  })
)

// 로그인
router.post('/login', passport.authenticate('local'), (req, res) => {
  // Passport의 local 전략을 사용하여 로그인 시도 후 성공하면 'Success Login' 응답 전송
  res.send('Success Login')
})

// 모듈 내보내기
module.exports = router
```

## login.jsx

```jsx
import { useState } from 'react'
import { Link, useNavigate } from 'react-router-dom'
import axios from 'axios'
import Button from 'react-bootstrap/Button'
import Col from 'react-bootstrap/Col'
import Form from 'react-bootstrap/Form'
import InputGroup from 'react-bootstrap/InputGroup'
import Row from 'react-bootstrap/Row'
import FloatingLabel from 'react-bootstrap/FloatingLabel'

const Login = () => {
  const navigate = useNavigate()
  const [validated, setValidated] = useState(false)
  //상태 초기화
  const [formData, setFormData] = useState({
    username: '',
    email: '',
    password: '',
  })

  // 입력값 변경 핸들러
  const handleChange = (e) => {
    const { name, value } = e.target
    setFormData((prevDate) => ({
      ...prevDate,
      [name]: value,
    }))
  }

  // 폼 제출 핸들러
  const onSubmitHandler = async (e) => {
    e.preventDefault()

    const form = e.currentTarget

    if (form.checkValidity() === false) {
      setValidated(true)
      return
    }

    setValidated(false)

    // 폼 데이터 전송
    try {
      await axios.post('http://localhost:4000/login', formData, { withCredentials: true })
      navigate('/campground')
    } catch (error) {
      console.error('SAVE FAIL', error)
    }
  }

  return (
    <>
      <h1>UserLogin</h1>
      <Form noValidate validated={validated} onSubmit={onSubmitHandler}>
        <Row className="mb-3">
          <Form.Group as={Col} md="6" controlId="username">
            <Form.Label>UserName</Form.Label>
            <Form.Control
              type="text"
              placeholder="username"
              name="username"
              value={formData.username}
              onChange={handleChange}
              required
            />
            <Form.Control.Feedback type="invalid">
              Please provide a valid username.
            </Form.Control.Feedback>
          </Form.Group>
        </Row>
        <Row className="mb-3">
          <Form.Group as={Col} md="6" controlId="password">
            <Form.Label>Password</Form.Label>
            <Form.Control
              type="password"
              placeholder="password"
              name="password"
              value={formData.password}
              onChange={handleChange}
              required
            />
            <Form.Control.Feedback type="invalid">
              Please provide a valid password.
            </Form.Control.Feedback>
          </Form.Group>
        </Row>
        <Button type="submit">Submit form</Button>
      </Form>
    </>
  )
}

export default Login

const express = require('express')

const jwt = require('jsonwebtoken')

import './App.css'
import { Route, Routes } from 'react-router-dom'
import Home from './pages/home'
import CampGround from './pages/campground'
import CampGroundDetail from './pages/campgroundDetail'
import CampGroundAdd from './pages/campgroundAdd'
import CampGroundUpdate from './pages/campgroundUpdate'
import AdditionalContent from './pages/AdditionalContent'
import Register from './pages/register'
import Login from './pages/login'
import axios from 'axios'
import { useEffect, useState } from 'react'
import Header from './layout/header'
import Footer from './layout/footer'

function App() {
  const [isLogin, setIsLogin] = useState(false)
  const [user, setUser] = useState({})

  const logout = () => {
    axios({
      url: 'http://localhost:8123/logout',
      method: 'POST',
      withCredentials: true,
    }).then((result) => {
      if (result.status === 200) {
        window.open('/', '_self')
      }
    })
  }

  useEffect(() => {
    try {
      axios({
        url: 'http://localhost:4000/login/success',
        method: 'GET',
        withCredentials: true,
      })
        .then((result) => {
          if (result.data) {
            setIsLogin(true)
            setUser(result.data)
          }
        })
        .catch((error) => {
          console.log(error)
        })
    } catch (error) {
      console.log(error)
    }
  }, [setUser])

  return (
    <div className="d-flex flex-column min-vh-100">
      <Header isLogin={isLogin} logout={logout} />
      <div className="container mt-3 flex-grow-1">
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="register" element={<Register />} />
          <Route path="login" element={<Login />} />
          <Route path="campground" element={<CampGround />} />
          <Route path="campground/:id" element={<CampGroundDetail />} />
          <Route path="campground/new" element={<CampGroundAdd />} />
          <Route path="campground/:id/edit" element={<CampGroundUpdate />} />
          <Route path="*" element={<AdditionalContent />} />
        </Routes>
      </div>
      <Footer />
    </div>
  )
}

export default App
```
